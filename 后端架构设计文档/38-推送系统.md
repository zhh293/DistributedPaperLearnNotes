# 推送系统架构设计

## 一、问题背景

### 1.1 业务场景

消息推送是移动互联网应用与用户建立实时连接的核心能力。一个完善的推送系统需要支撑以下关键业务场景：

1. **交易通知**：订单状态变更、支付成功、配送进度等实时通知。
2. **营销触达**：促销活动、优惠券发放、个性化推荐等运营消息。
3. **系统消息**：账户安全提醒、系统公告、版本升级等。
4. **即时通信**：IM 消息、客服消息等实时交互场景。

在大型互联网平台中，推送系统每天需要处理数亿级别的消息推送，面临以下核心挑战：

| 挑战 | 描述 |
|------|------|
| 多通道管理 | iOS (APNs)、Android 各厂商通道、自建长连接通道的统一管理 |
| 到达率保障 | 不同通道的推送策略、降级机制、重试策略 |
| 消息质量 | 频率控制、用户打扰管控、消息去重 |
| 高并发 | 峰值数十万 QPS，秒级送达要求 |
| 可观测性 | 全链路追踪，送达确认，效果归因 |

#### 1.2.2 推送消息类型

推送消息分为两大类：

1. **通知栏消息（passthrough=0）**：直接展示在系统通知栏，无需 App 存活。支持所有通道。
2. **透传消息（passthrough=1）**：消息透传给 App 自行处理，需要 App 存活。仅自建长连接通道支持。

```java
/**
 * 推送消息类型
 */
public enum PushMessageType {
    /**
     * 通知栏消息 - 直接展示在通知栏
     * passthrough = 0
     */
    NOTIFICATION(0, "通知栏消息"),

    /**
     * 透传消息 - 透传给应用自行处理
     * passthrough = 1，仅自建通道支持
     */
    PASSTHROUGH(1, "透传消息");

    private final int code;
    private final String desc;

    PushMessageType(int code, String desc) {
        this.code = code;
        this.desc = desc;
    }

    public int getCode() { return code; }
    public String getDesc() { return desc; }
}
```

### 3.1 PushToken 管理

#### 3.1.1 Token 注册与映射

PushToken 是推送系统的核心标识，建立了设备/用户与推送通道之间的映射关系。

```java
/**
 * PushToken 实体
 */
@Data
public class PushTokenEntity {
    private Long id;
    private Long userId;                // 用户ID
    private String deviceId;            // 设备ID
    private String pushToken;           // 推送Token
    private PushChannel channel;        // 推送通道
    private String appPackage;          // 应用包名
    private String deviceModel;         // 设备型号
    private String osVersion;           // 操作系统版本
    private Integer tokenStatus;        // Token状态：1-有效，0-无效
    private Date createTime;
    private Date updateTime;
    private Date lastActiveTime;        // 最后活跃时间
}

/**
 * 推送通道枚举
 */
public enum PushChannel {
    APNS("APNs", "Apple Push Notification Service"),
    XIAOMI("小米推送", "Xiaomi Push"),
    HUAWEI("华为推送", "Huawei Push"),
    OPPO("OPPO推送", "OPPO Push"),
    VIVO("VIVO推送", "VIVO Push"),
    FCM("FCM", "Firebase Cloud Messaging"),
    SELF_BUILT("自建通道", "Self-built Long Connection");

    private final String name;
    private final String fullName;

    PushChannel(String name, String fullName) {
        this.name = name;
        this.fullName = fullName;
    }

/**
 * PushToken 管理服务
 */
@Service
public class PushTokenService {

    @Autowired
    private PushTokenRepository tokenRepository;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String TOKEN_CACHE_PREFIX = "push:token:user:";
    private static final String DEVICE_TOKEN_PREFIX = "push:token:device:";
    private static final int TOKEN_CACHE_EXPIRE_HOURS = 24;

    /**
     * 设备注册/更新 PushToken
     * SDK 启动时调用
     */
    @Transactional(rollbackFor = Exception.class)
    public void registerToken(TokenRegisterRequest request) {
        Long userId = request.getUserId();
        String deviceId = request.getDeviceId();
        String pushToken = request.getPushToken();
        PushChannel channel = request.getChannel();

        // 1. 查询该设备是否已有 Token
        PushTokenEntity existing = tokenRepository
                .findByDeviceIdAndChannel(deviceId, channel);

        if (existing != null) {
            // 更新已有记录
            existing.setUserId(userId);
            existing.setPushToken(pushToken);
            existing.setTokenStatus(1);
            existing.setUpdateTime(new Date());
            existing.setLastActiveTime(new Date());
            existing.setOsVersion(request.getOsVersion());
            existing.setDeviceModel(request.getDeviceModel());
            tokenRepository.save(existing);
        } else {
            // 创建新记录
            PushTokenEntity entity = new PushTokenEntity();
            entity.setUserId(userId);
            entity.setDeviceId(deviceId);
            entity.setPushToken(pushToken);
            entity.setChannel(channel);
            entity.setAppPackage(request.getAppPackage());
            entity.setDeviceModel(request.getDeviceModel());
            entity.setOsVersion(request.getOsVersion());
            entity.setTokenStatus(1);
            entity.setCreateTime(new Date());
            entity.setUpdateTime(new Date());
            entity.setLastActiveTime(new Date());
            tokenRepository.save(entity);
        }

        // 2. 处理账号切换：同一设备的旧用户 Token 失效
        if (userId != null) {
            tokenRepository.invalidateOtherUsers(deviceId, userId, channel);
        }

        // 3. 更新缓存
        refreshTokenCache(userId, deviceId);
    }

    /**
     * Token 失效处理
     * 当厂商通道返回 Token 无效时调用
     */
    public void invalidateToken(String pushToken, PushChannel channel) {
        PushTokenEntity entity = tokenRepository.findByPushTokenAndChannel(pushToken, channel);
        if (entity != null) {
            entity.setTokenStatus(0);
            entity.setUpdateTime(new Date());
            tokenRepository.save(entity);

            // 清理缓存
            refreshTokenCache(entity.getUserId(), entity.getDeviceId());

            log.info("Token 已失效: channel={}, deviceId={}", channel, entity.getDeviceId());
        }
    }

    /**
     * 获取用户的有效 PushToken 列表
     */
    public List<PushTokenEntity> getUserTokens(long userId) {
        String cacheKey = TOKEN_CACHE_PREFIX + userId;
        String cached = redisTemplate.opsForValue().get(cacheKey);

        if (cached != null) {
            return JSON.parseArray(cached, PushTokenEntity.class);
        }

        List<PushTokenEntity> tokens = tokenRepository
                .findByUserIdAndTokenStatus(userId, 1);

        // 缓存
        if (!tokens.isEmpty()) {
            redisTemplate.opsForValue().set(cacheKey, JSON.toJSONString(tokens),
                    TOKEN_CACHE_EXPIRE_HOURS, TimeUnit.HOURS);
        }

        return tokens;
    }

    /**
     * 批量获取用户 Token（用于群推）
     */
    public Map<Long, List<PushTokenEntity>> batchGetUserTokens(List<Long> userIds) {
        Map<Long, List<PushTokenEntity>> result = new HashMap<>();

        // Pipeline 批量从 Redis 获取
        List<String> keys = userIds.stream()
                .map(id -> TOKEN_CACHE_PREFIX + id)
                .collect(Collectors.toList());
        List<String> cachedValues = redisTemplate.opsForValue().multiGet(keys);

        List<Long> missedUserIds = new ArrayList<>();
        for (int i = 0; i < userIds.size(); i++) {
            String cached = cachedValues.get(i);
            if (cached != null) {
                result.put(userIds.get(i),
                        JSON.parseArray(cached, PushTokenEntity.class));
            } else {
                missedUserIds.add(userIds.get(i));
            }
        }

        // 从数据库批量查询未命中的
        if (!missedUserIds.isEmpty()) {
            Map<Long, List<PushTokenEntity>> dbTokens = tokenRepository
                    .batchFindByUserIds(missedUserIds);
            result.putAll(dbTokens);

            // 回写缓存
            for (Map.Entry<Long, List<PushTokenEntity>> entry : dbTokens.entrySet()) {
                String key = TOKEN_CACHE_PREFIX + entry.getKey();
                redisTemplate.opsForValue().set(key, JSON.toJSONString(entry.getValue()),
                        TOKEN_CACHE_EXPIRE_HOURS, TimeUnit.HOURS);
            }
        }

        return result;
    }

    /**
     * 定时清理过期 Token
     * 超过90天未活跃的 Token 标记为无效
     */
    @Scheduled(cron = "0 0 3 * * ?") // 每天凌晨3点
    public void cleanExpiredTokens() {
        Date threshold = new Date(System.currentTimeMillis() - 90L * 24 * 3600 * 1000);
        int cleaned = tokenRepository.invalidateByLastActiveTimeBefore(threshold);
        log.info("清理过期Token数量: {}", cleaned);
    }

    private void refreshTokenCache(Long userId, String deviceId) {
        if (userId != null) {
            redisTemplate.delete(TOKEN_CACHE_PREFIX + userId);
        }
        if (deviceId != null) {
            redisTemplate.delete(DEVICE_TOKEN_PREFIX + deviceId);
        }
    }
}
```

### 3.2 通道选择引擎

```java
/**
 * 推送通道选择引擎
 * 核心逻辑：
 * - App 前台 -> 优先自建长连接通道
 * - App 后台 -> 厂商通道 / APNs
 */
@Service
public class ChannelSelectionEngine {

    @Autowired
    private DeviceOnlineService deviceOnlineService;
    @Autowired
    private ChannelQuotaService channelQuotaService;

    /**
     * 为每个目标设备选择最优推送通道
     */
    public List<ChannelRouteResult> selectChannel(PushMessageDTO message,
                                                    List<PushTokenEntity> tokens) {
        List<ChannelRouteResult> results = new ArrayList<>();

        for (PushTokenEntity token : tokens) {
            ChannelRouteResult route = selectChannelForToken(message, token);
            if (route != null) {
                results.add(route);
            }
        }

        return results;
    }

    /**
     * 为单个 Token 选择通道
     */
    private ChannelRouteResult selectChannelForToken(PushMessageDTO message,
                                                      PushTokenEntity token) {
        // 1. 透传消息只能走自建通道
        if (message.getPassthrough() == PushMessageType.PASSTHROUGH.getCode()) {
            if (isDeviceOnline(token.getDeviceId())) {
                return new ChannelRouteResult(token, PushChannel.SELF_BUILT);
            }
            // 透传消息且设备不在线，无法推送
            log.info("透传消息目标设备不在线, deviceId={}", token.getDeviceId());
            return null;
        }

        // 2. 通知栏消息选择通道
        PushChannel selectedChannel;

        // 2.1 检查设备是否在线（App 前台）
        boolean isOnline = isDeviceOnline(token.getDeviceId());

        if (isOnline) {
            // App 前台：优先自建通道（可以自定义展示样式）
            selectedChannel = PushChannel.SELF_BUILT;
        } else {
            // App 后台：使用厂商通道或 APNs
            selectedChannel = selectVendorChannel(token, message);
        }

        if (selectedChannel == null) {
            log.warn("无法找到有效推送通道, deviceId={}", token.getDeviceId());
            return null;
        }

        return new ChannelRouteResult(token, selectedChannel);
    }

    /**
     * 选择厂商通道
     */
    private PushChannel selectVendorChannel(PushTokenEntity token,
                                             PushMessageDTO message) {
        PushChannel deviceChannel = token.getChannel();

        // iOS 设备使用 APNs
        if (deviceChannel == PushChannel.APNS) {
            return PushChannel.APNS;
        }

        // Android 设备使用对应厂商通道
        // 检查通道配额
        if (channelQuotaService.hasQuota(deviceChannel, message.getCategory())) {
            return deviceChannel;
        }

        // 配额不足，尝试降级到自建通道
        log.warn("厂商通道配额不足, channel={}, category={}",
                deviceChannel, message.getCategory());
        if (isDeviceOnline(token.getDeviceId())) {
            return PushChannel.SELF_BUILT;
        }

        return null; // 无可用通道
    }

    /**
     * 检查设备是否在线
     */
    private boolean isDeviceOnline(String deviceId) {
        return deviceOnlineService.isOnline(deviceId);
    }
}

 * 通道路由结果
 */
@Data
@AllArgsConstructor

/**
 * 设备在线状态服务
 * 基于自建长连接的心跳维护
 */
@Service
public class DeviceOnlineService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String ONLINE_PREFIX = "device:online:";
    private static final int HEARTBEAT_EXPIRE_SECONDS = 120; // 2分钟无心跳视为离线

    /**
     * 设备心跳上报
     */
    public void heartbeat(String deviceId) {
        String key = ONLINE_PREFIX + deviceId;
        redisTemplate.opsForValue().set(key, String.valueOf(System.currentTimeMillis()),
                HEARTBEAT_EXPIRE_SECONDS, TimeUnit.SECONDS);
    }

    /**
     * 检查设备是否在线
     */
    public boolean isOnline(String deviceId) {
        String key = ONLINE_PREFIX + deviceId;
        return Boolean.TRUE.equals(redisTemplate.hasKey(key));
    }

    /**
     * 设备断开连接
     */
    public void disconnect(String deviceId) {
        String key = ONLINE_PREFIX + deviceId;
        redisTemplate.delete(key);
    }

    /**
     * 批量查询在线状态
     */
    public Map<String, Boolean> batchIsOnline(List<String> deviceIds) {
        List<String> keys = deviceIds.stream()
                .map(id -> ONLINE_PREFIX + id)
                .collect(Collectors.toList());

        List<String> values = redisTemplate.opsForValue().multiGet(keys);

        Map<String, Boolean> result = new HashMap<>();
        for (int i = 0; i < deviceIds.size(); i++) {
            result.put(deviceIds.get(i), values.get(i) != null);
        }
        return result;
    }
}
```

### 3.3 消息发送引擎

```java
/**
 * 消息发送引擎
 * 统一推送入口
 */
@Service
public class PushSendEngine {

    @Autowired
    private PushTokenService tokenService;
    @Autowired
    private ChannelSelectionEngine channelEngine;
    @Autowired
    private Map<PushChannel, ChannelAdapter> channelAdapters;
    @Autowired
    private PushRateLimiter rateLimiter;
    @Autowired
    private PushDeliveryTracker deliveryTracker;

    /**
     * 发送推送消息
     */
    public PushResult send(PushMessageDTO message) {
        String messageId = message.getMessageId();
        if (messageId == null) {
            messageId = UUID.randomUUID().toString();
            message.setMessageId(messageId);
        }

        PushResult result = new PushResult();
        result.setMessageId(messageId);

        // 1. 消息校验
        validateMessage(message);

        // 2. 频率控制
        if (!rateLimiter.allowPush(message)) {
            result.setSuccess(false);
            result.setFailReason("频率限制");
            return result;
        }

        // 3. 遍历目标用户
        List<PushSendDetail> sendDetails = new ArrayList<>();
        for (Long userId : message.getTargetUserIds()) {
            List<PushSendDetail> details = sendToUser(userId, message);
            sendDetails.addAll(details);
        }

        // 4. 汇总发送结果
        long successCount = sendDetails.stream()
                .filter(PushSendDetail::isSuccess).count();
        result.setSuccess(successCount > 0);
        result.setTotalCount(sendDetails.size());
        result.setSuccessCount((int) successCount);
        result.setSendDetails(sendDetails);

        // 5. 记录投递追踪
        deliveryTracker.trackSend(messageId, sendDetails);

        return result;
    }

    /**
     * 向单个用户发送推送
     */
    private List<PushSendDetail> sendToUser(long userId, PushMessageDTO message) {
        List<PushSendDetail> details = new ArrayList<>();

        // 1. 获取用户的有效 Token
        List<PushTokenEntity> tokens = tokenService.getUserTokens(userId);
        if (tokens.isEmpty()) {
            PushSendDetail detail = new PushSendDetail();
            detail.setUserId(userId);
            detail.setSuccess(false);
            detail.setFailReason("无有效Token");
            details.add(detail);
            return details;
        }

        // 2. 选择通道
        List<ChannelRouteResult> routes = channelEngine.selectChannel(message, tokens);
        if (routes.isEmpty()) {
            PushSendDetail detail = new PushSendDetail();
            detail.setUserId(userId);
            detail.setSuccess(false);
            detail.setFailReason("无可用通道");
            details.add(detail);
            return details;
        }

        // 3. 通过对应通道发送
        for (ChannelRouteResult route : routes) {
            PushSendDetail detail = sendViaChannel(route, message);
            detail.setUserId(userId);
            details.add(detail);
        }

        return details;
    }

    /**
     * 通过指定通道发送
     */
    private PushSendDetail sendViaChannel(ChannelRouteResult route,
                                           PushMessageDTO message) {
        PushSendDetail detail = new PushSendDetail();
        detail.setChannel(route.getSelectedChannel());
        detail.setDeviceId(route.getToken().getDeviceId());

        ChannelAdapter adapter = channelAdapters.get(route.getSelectedChannel());
        if (adapter == null) {
            detail.setSuccess(false);
            detail.setFailReason("通道适配器不存在");
            return detail;
        }

        try {
            ChannelSendResult channelResult = adapter.send(route.getToken(), message);
            detail.setSuccess(channelResult.isSuccess());
            detail.setChannelMessageId(channelResult.getChannelMessageId());
            if (!channelResult.isSuccess()) {
                detail.setFailReason(channelResult.getErrorMessage());
                // Token 无效时标记
                if (channelResult.isTokenInvalid()) {
                    tokenService.invalidateToken(
                            route.getToken().getPushToken(),
                            route.getSelectedChannel());
                }
            }
        } catch (Exception e) {
            detail.setSuccess(false);
            detail.setFailReason("发送异常: " + e.getMessage());
            log.error("推送发送异常, channel={}, deviceId={}",
                    route.getSelectedChannel(), route.getToken().getDeviceId(), e);
        }

        return detail;
    }

    /**
     * 消息校验
     */
    private void validateMessage(PushMessageDTO message) {
        if (message.getTargetUserIds() == null || message.getTargetUserIds().isEmpty()) {
            throw new IllegalArgumentException("目标用户列表不能为空");
        }
        if (message.getTitle() == null || message.getTitle().isEmpty()) {
            throw new IllegalArgumentException("推送标题不能为空");
        }
        if (message.getTargetUserIds().size() > 10000) {
            throw new IllegalArgumentException("单次推送用户数不能超过10000");
        }
    }
}
```

```java
@Component
public class ConnectionManager {

    // deviceId -> Channel
    private final ConcurrentHashMap<String, Channel> connections = new ConcurrentHashMap<>();

    // Channel -> deviceId
    private final ConcurrentHashMap<Channel, String> reverseMap = new ConcurrentHashMap<>();

    /**
     * 注册连接
     */
    public void register(String deviceId, Channel channel) {
        // 关闭旧连接
        Channel oldChannel = connections.get(deviceId);
        if (oldChannel != null && oldChannel != channel) {
            oldChannel.close();
            reverseMap.remove(oldChannel);
        }

        connections.put(deviceId, channel);
        reverseMap.put(channel, deviceId);

        log.info("设备连接注册, deviceId={}, channelId={}", deviceId, channel.id());
    }

    /**
     * 注销连接
     */
    public void unregister(Channel channel) {
        String deviceId = reverseMap.remove(channel);
        if (deviceId != null) {
            connections.remove(deviceId, channel);
            log.info("设备连接注销, deviceId={}", deviceId);
        }
    }

    /**
     * 获取连接
     */
    public Channel getChannel(String deviceId) {
        return connections.get(deviceId);
    }

    /**
     * 获取在线连接数
     */
    public int getOnlineCount() {
        return connections.size();
    }
}

    private final ConnectionManager connectionManager;
    private final DeviceOnlineService deviceOnlineService;

    public PushWebSocketHandler(ConnectionManager connectionManager,
                                 DeviceOnlineService deviceOnlineService) {
        this.connectionManager = connectionManager;
        this.deviceOnlineService = deviceOnlineService;
    }

    @Override
    protected void channelRead0(ChannelHandlerContext ctx, TextWebSocketFrame frame) {
        String text = frame.text();
        JSONObject json = JSON.parseObject(text);
        String type = json.getString("type");

        switch (type) {
            case "register":
                handleRegister(ctx, json);
                break;
            case "heartbeat":
                handleHeartbeat(ctx, json);
                break;
            case "ack":
                handleAck(ctx, json);
                break;
            default:
                log.warn("未知消息类型: {}", type);
        }
    }

    private void handleRegister(ChannelHandlerContext ctx, JSONObject json) {
        String deviceId = json.getString("deviceId");
        connectionManager.register(deviceId, ctx.channel());
        deviceOnlineService.heartbeat(deviceId);

        // 回复注册成功
        JSONObject response = new JSONObject();
        response.put("type", "registerResult");
        response.put("success", true);
        ctx.writeAndFlush(new TextWebSocketFrame(response.toJSONString()));
    }

    private void handleHeartbeat(ChannelHandlerContext ctx, JSONObject json) {
        String deviceId = json.getString("deviceId");
        deviceOnlineService.heartbeat(deviceId);

        // 回复心跳
        JSONObject pong = new JSONObject();
        pong.put("type", "pong");
        pong.put("timestamp", System.currentTimeMillis());
        ctx.writeAndFlush(new TextWebSocketFrame(pong.toJSONString()));
    }

    private void handleAck(ChannelHandlerContext ctx, JSONObject json) {
        String messageId = json.getString("messageId");
        // 记录消息送达确认
        deliveryTracker.trackDelivery(messageId);
    }

    @Override
    public void channelInactive(ChannelHandlerContext ctx) {
        connectionManager.unregister(ctx.channel());
    }

    @Override
    public void userEventTriggered(ChannelHandlerContext ctx, Object evt) {
        if (evt instanceof IdleStateEvent) {
            // 超时未收到心跳，关闭连接
            log.info("连接心跳超时, channelId={}", ctx.channel().id());
            ctx.close();
        }
    }
}
```

```java
public class PushRateLimiter {

    @Autowired

    /**
     * 用户维度频率限制配置
     */
    private static final Map<MessageCategory, RateLimitConfig> USER_LIMITS = new HashMap<>();
    static {
        // 营销消息：每用户每天最多3条
        USER_LIMITS.put(MessageCategory.MARKETING,
                new RateLimitConfig(3, 86400));
        // 系统消息：每用户每天最多20条
        USER_LIMITS.put(MessageCategory.SYSTEM,

    }

     * 应用维度频率限制
     * 厂商通道配额限制
     */
    private static final Map<PushChannel, DailyQuota> CHANNEL_QUOTAS = new HashMap<>();
    static {
        // 各厂商通道日配额
        CHANNEL_QUOTAS.put(PushChannel.XIAOMI,
                new DailyQuota(1000000, 100000)); // 系统100万，营销10万
        CHANNEL_QUOTAS.put(PushChannel.HUAWEI,
                new DailyQuota(5000000, 500000));
        CHANNEL_QUOTAS.put(PushChannel.OPPO,
                new DailyQuota(2000000, 200000));
        CHANNEL_QUOTAS.put(PushChannel.VIVO,
                new DailyQuota(2000000, 200000));
    }

    /**
     * 检查是否允许推送
     */
    public boolean allowPush(PushMessageDTO message) {
        MessageCategory category = message.getCategory();
        if (category == null) {
            category = MessageCategory.SYSTEM;
        }

        // 1. 用户维度频率检查
        for (Long userId : message.getTargetUserIds()) {
            if (!checkUserRateLimit(userId, category)) {
                log.info("用户频率限制, userId={}, category={}", userId, category);
                return false;
            }
        }

        // 2. 应用维度频率检查（营销消息）
        if (category == MessageCategory.MARKETING) {
            if (!checkAppRateLimit(message.getBizSource())) {
                log.warn("应用频率限制, bizSource={}", message.getBizSource());
                return false;
            }
        }

        return true;
    }

    /**
     * 用户维度频率检查
     * 使用 Redis 计数器实现滑动窗口
     */
    private boolean checkUserRateLimit(long userId, MessageCategory category) {
        RateLimitConfig config = USER_LIMITS.get(category);
        if (config == null) return true;

        String key = String.format("push:rate:user:%d:%s:%s",
                userId, category.name(), getTodayStr());

        Long count = redisTemplate.opsForValue().increment(key, 1);
        if (count == 1) {
            redisTemplate.expire(key, config.getWindowSeconds(), TimeUnit.SECONDS);
        }

        return count <= config.getMaxCount();
    }

    /**
     * 应用维度频率检查
     */
    private boolean checkAppRateLimit(String bizSource) {
        String key = String.format("push:rate:app:%s:%s", bizSource, getTodayStr());
        Long count = redisTemplate.opsForValue().increment(key, 1);
        if (count == 1) {
            redisTemplate.expire(key, 86400, TimeUnit.SECONDS);
        }
        // 单个业务每天最多推送100万条
        return count <= 1000000;
    }

    private String getTodayStr() {
        return LocalDate.now().format(DateTimeFormatter.BASIC_ISO_DATE);
    }
}
```

```java
@Service
public class CertificateManager {

    @Autowired
    private CertificateRepository certificateRepo;

    /**
     * 获取当前有效的 APNs 证书
     */
    public CertificateInfo getAPNsCertificate() {
        CertificateInfo cert = certificateRepo.findLatestValid(PushChannel.APNS);
        if (cert == null) {
            throw new RuntimeException("无有效的APNs证书");
        }
        return cert;
    }

    /**
     * 上传新证书
     */
    @Transactional(rollbackFor = Exception.class)
    public void uploadCertificate(MultipartFile certFile, String password,
                                   PushChannel channel) {
        // 1. 验证证书有效性
        validateCertificate(certFile, password);

        // 2. 保存证书文件
        String certPath = saveCertFile(certFile);

        // 3. 记录证书信息
        CertificateInfo cert = new CertificateInfo();
        cert.setChannel(channel);
        cert.setCertPath(certPath);
        cert.setPassword(password);
        cert.setUploadTime(new Date());
        cert.setExpireTime(extractExpireTime(certFile, password));
        cert.setValid(true);
        certificateRepo.save(cert);

        log.info("新证书上传成功, channel={}, expireTime={}", channel, cert.getExpireTime());
    }

    /**
     * 证书过期预警检查
     * 每天执行一次
     */
    @Scheduled(cron = "0 0 10 * * ?")
    public void checkCertificateExpiry() {
        List<CertificateInfo> certs = certificateRepo.findAllValid();
        for (CertificateInfo cert : certs) {
            long daysToExpire = Duration.between(
                    Instant.now(),
                    cert.getExpireTime().toInstant()
            ).toDays();

            if (daysToExpire <= 30) {
                alertService.sendAlert(AlertLevel.HIGH,
                        String.format("APNs证书即将过期, 剩余%d天, channel=%s",
                                daysToExpire, cert.getChannel()));
            } else if (daysToExpire <= 60) {
                alertService.sendAlert(AlertLevel.MEDIUM,
                        String.format("APNs证书将在%d天后过期, channel=%s",
                                daysToExpire, cert.getChannel()));
            }
        }
    }

    private void validateCertificate(MultipartFile certFile, String password) {
        try {
            KeyStore keyStore = KeyStore.getInstance("PKCS12");
            keyStore.load(certFile.getInputStream(), password.toCharArray());
        } catch (Exception e) {
            throw new BusinessException("证书验证失败: " + e.getMessage());
        }
    }

    private String saveCertFile(MultipartFile certFile) {
        String fileName = "apns_" + System.currentTimeMillis() + ".p12";
        String path = "/data/certs/" + fileName;
        try {
            certFile.transferTo(new File(path));
        } catch (IOException e) {
            throw new RuntimeException("保存证书文件失败", e);
        }
        return path;
    }

    private Date extractExpireTime(MultipartFile certFile, String password) {
        try {
            KeyStore keyStore = KeyStore.getInstance("PKCS12");
            keyStore.load(certFile.getInputStream(), password.toCharArray());
            String alias = keyStore.aliases().nextElement();
            X509Certificate cert = (X509Certificate) keyStore.getCertificate(alias);
            return cert.getNotAfter();
        } catch (Exception e) {
            throw new RuntimeException("读取证书过期时间失败", e);
        }
    }
}

/**
```

```java
@Service
public class PushTroubleshootService {

    @Autowired
    private PushTokenService tokenService;
    @Autowired
    private PushDeliveryTracker deliveryTracker;
    @Autowired
    private DeviceOnlineService deviceOnlineService;

    /**
     * 排查推送问题
     */
    public TroubleshootResult troubleshoot(long userId, String messageId) {
        TroubleshootResult result = new TroubleshootResult();
        result.setUserId(userId);
        result.setMessageId(messageId);
        List<String> issues = new ArrayList<>();

        // 1. 检查 Token 有效性
        List<PushTokenEntity> tokens = tokenService.getUserTokens(userId);
        if (tokens.isEmpty()) {
            issues.add("用户无有效的PushToken，可能未注册推送或Token已失效");
            result.setIssues(issues);
            return result;
        }
        result.setTokenCount(tokens.size());

        // 2. 检查设备在线状态
        for (PushTokenEntity token : tokens) {
            DeviceOnlineInfo online = deviceOnlineService
                    .getOnlineInfo(token.getDeviceId());
            if (online == null || !online.isOnline()) {
                issues.add(String.format("设备 %s 不在线，最后活跃: %s",
                        token.getDeviceId(),
                        online != null ? online.getLastActiveTime() : "未知"));
            }
        }

        // 3. 检查消息投递记录
        if (messageId != null) {
            DeliveryRecord delivery = deliveryTracker.getDeliveryStatus(messageId);
            if (delivery == null) {
                issues.add("消息ID不存在或已过期");
            } else {
                result.setDeliveryRecord(delivery);
                if (delivery.getSendSuccessCount() == 0) {
                    issues.add("消息发送失败，所有通道均未成功");
                } else if (delivery.getDeliveredCount() == 0) {
                    issues.add("消息已发送但未收到送达确认，可能被系统拦截");
                }
            }
        }

        // 4. 检查通道状态
        for (PushTokenEntity token : tokens) {
            PushChannel channel = token.getChannel();
            if (channel == PushChannel.APNS) {
                // 检查 APNs 证书
                try {
                    CertificateInfo cert = certificateManager.getAPNsCertificate();
                    if (cert.getExpireTime().before(new Date())) {
                        issues.add("APNs证书已过期");
                    }
                } catch (Exception e) {
                    issues.add("APNs证书不可用");
                }
            }
        }

        // 5. 检查频率限制
        String rateKey = String.format("push:rate:user:%d:SYSTEM:%s",
                userId, LocalDate.now().format(DateTimeFormatter.BASIC_ISO_DATE));
        String rateCount = redisTemplate.opsForValue().get(rateKey);
        if (rateCount != null && Integer.parseInt(rateCount) >= 20) {
            issues.add("用户今日推送次数已达频率限制上限");
        }

        // 6. 检查用户通知设置
        boolean notificationEnabled = checkUserNotificationSetting(userId);
        if (!notificationEnabled) {
            issues.add("用户已关闭APP通知权限");
        }

        result.setIssues(issues);
        result.setDiagnosis(issues.isEmpty() ? "未发现明显问题" : "发现" + issues.size() + "个问题");
        return result;
    }

    private boolean checkUserNotificationSetting(long userId) {
        // 查询用户的通知设置
        String key = "user:notification:setting:" + userId;
        String setting = redisTemplate.opsForValue().get(key);
        return setting == null || "1".equals(setting);
    }
}

/**
```
```java
 * 推送通道熔断器
 * 当某个通道连续失败时触发熔断
 */
@Service
public class PushChannelCircuitBreaker {

    private final Map<PushChannel, CircuitBreakerState> channelStates
            = new ConcurrentHashMap<>();

    private static final int FAILURE_THRESHOLD = 50;    // 失败阈值
    private static final long HALF_OPEN_TIMEOUT = 60000; // 半开超时 60s

    /**
     * 检查通道是否可用
     */
    public boolean isChannelAvailable(PushChannel channel) {
        CircuitBreakerState state = channelStates.get(channel);
        if (state == null) return true;

        switch (state.getStatus()) {
            case CLOSED:
                return true;
            case OPEN:
                // 检查是否可以进入半开状态
                if (System.currentTimeMillis() - state.getLastFailTime() > HALF_OPEN_TIMEOUT) {
                    state.setStatus(CircuitBreakerStatus.HALF_OPEN);
                    return true;
                }
                return false;
            case HALF_OPEN:
                return true;
            default:
                return true;
        }
    }

    /**
     * 记录成功
     */
    public void recordSuccess(PushChannel channel) {
        CircuitBreakerState state = channelStates.get(channel);
        if (state != null) {
            if (state.getStatus() == CircuitBreakerStatus.HALF_OPEN) {
                // 半开状态下成功，恢复为关闭
                state.setStatus(CircuitBreakerStatus.CLOSED);
                state.setFailureCount(0);
            }
        }
    }

    /**
     * 记录失败
     */
    public void recordFailure(PushChannel channel) {
        CircuitBreakerState state = channelStates.computeIfAbsent(channel,
                k -> new CircuitBreakerState());
        state.setFailureCount(state.getFailureCount() + 1);
        state.setLastFailTime(System.currentTimeMillis());

        if (state.getFailureCount() >= FAILURE_THRESHOLD) {
            state.setStatus(CircuitBreakerStatus.OPEN);
            log.warn("推送通道熔断, channel={}, failCount={}",
                    channel, state.getFailureCount());
            alertService.sendAlert(AlertLevel.HIGH,
                    String.format("推送通道 %s 已熔断", channel.name()));
        }
    }
}

@Data
public class CircuitBreakerState {
    private CircuitBreakerStatus status = CircuitBreakerStatus.CLOSED;
    private int failureCount = 0;
    private long lastFailTime = 0;
}

public enum CircuitBreakerStatus {
    CLOSED, OPEN, HALF_OPEN
}
```

```java
/**
 * 推送消息重试服务
 */
@Service
public class PushRetryService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private PushSendService pushSendService;

    private static final int MAX_RETRY_COUNT = 3;
    private static final long[] RETRY_DELAYS = {30000, 120000, 300000}; // 30s, 2min, 5min

    /**
     * 将失败消息加入重试队列
     */
    public void scheduleRetry(PushMessageDTO message, PushSendDetail failDetail) {
        int retryCount = message.getRetryCount() != null ? message.getRetryCount() : 0;
        if (retryCount >= MAX_RETRY_COUNT) {
            log.warn("推送重试次数已达上限, messageId={}, retryCount={}",
                    message.getMessageId(), retryCount);
            return;
        }

        // 不可重试的错误不进行重试
        if (isNonRetryableError(failDetail.getFailReason())) {
            return;
        }

        message.setRetryCount(retryCount + 1);
        long delay = RETRY_DELAYS[retryCount];

        // 使用 Redis Sorted Set 实现延迟队列
        double executeTime = System.currentTimeMillis() + delay;
        String key = "push:retry:queue";
        redisTemplate.opsForZSet().add(key, JSON.toJSONString(message), executeTime);

        log.info("推送加入重试队列, messageId={}, retryCount={}, delayMs={}",
                message.getMessageId(), retryCount + 1, delay);
    }

    /**
     * 处理重试队列（定时任务）
     */
    @Scheduled(fixedRate = 5000)
    public void processRetryQueue() {
        String key = "push:retry:queue";
        double now = System.currentTimeMillis();

        // 获取到期的消息
        Set<String> messages = redisTemplate.opsForZSet()
                .rangeByScore(key, 0, now, 0, 100);

        if (messages == null || messages.isEmpty()) {
            return;
        }

        for (String msgStr : messages) {
            // 原子性移除并处理
            Long removed = redisTemplate.opsForZSet().remove(key, msgStr);
            if (removed != null && removed > 0) {
                try {
                    PushMessageDTO message = JSON.parseObject(msgStr, PushMessageDTO.class);
                    pushSendService.send(message);
                } catch (Exception e) {
                    log.error("重试推送失败, message={}", msgStr, e);
                }
            }
        }
    }

    private boolean isNonRetryableError(String reason) {
        if (reason == null) return false;
        return reason.contains("Token无效")
                || reason.contains("BadDeviceToken")
                || reason.contains("Unregistered")
                || reason.contains("无有效Token");
    }
}
```

```java
     * 检查消息是否过期
     */
    public boolean isExpired(PushMessageDTO message) {
        if (message.getExpireSeconds() <= 0) {
            return false; // 永不过期
        }

        long now = System.currentTimeMillis();
        return (now - createTime) > message.getExpireSeconds() * 1000L;
    }

    /**
     * 清理过期消息（定时任务）
     */
    @Scheduled(fixedRate = 300000) // 5分钟

        String key = "push:retry:queue";
        Set<ZSetOperations.TypedTuple<String>> messages =
                redisTemplate.opsForZSet().rangeWithScores(key, 0, -1);

        if (messages == null) return;

        int cleanedCount = 0;
        for (ZSetOperations.TypedTuple<String> tuple : messages) {
            String msgStr = tuple.getValue();
            PushMessageDTO message = JSON.parseObject(msgStr, PushMessageDTO.class);
            if (isExpired(message)) {
                redisTemplate.opsForZSet().remove(key, msgStr);
                cleanedCount++;
            }
        }

        if (cleanedCount > 0) {
            log.info("清理过期推送消息: {} 条", cleanedCount);
        }
    }
```

### 5.1 批量推送优化

```java
/**
 * 批量推送处理器
 * 将大批量推送拆分为小批次，异步并行处理
 */
@Service
public class BatchPushProcessor {

    @Autowired
    private PushSendService pushSendService;
    @Autowired
    private ExecutorService pushExecutor;

    private static final int BATCH_SIZE = 500;

    /**
     * 大批量推送
     */
    public BatchPushResult batchPush(PushMessageDTO message) {
        List<Long> allUsers = message.getTargetUserIds();
        int totalUsers = allUsers.size();

        // 分批处理
        List<List<Long>> batches = partition(allUsers, BATCH_SIZE);
        List<CompletableFuture<PushResult>> futures = new ArrayList<>();

        for (List<Long> batch : batches) {
            PushMessageDTO batchMsg = message.clone();
            batchMsg.setTargetUserIds(batch);

            CompletableFuture<PushResult> future = CompletableFuture
                    .supplyAsync(() -> pushSendService.send(batchMsg), pushExecutor);
            futures.add(future);
        }

        // 汇总结果
        BatchPushResult batchResult = new BatchPushResult();
        batchResult.setTotalUsers(totalUsers);
        batchResult.setBatchCount(batches.size());

        int successCount = 0;
        int failCount = 0;

        for (CompletableFuture<PushResult> future : futures) {
            try {
                PushResult result = future.get(30, TimeUnit.SECONDS);
                successCount += result.getSuccessCount();
                failCount += result.getTotalCount() - result.getSuccessCount();
            } catch (Exception e) {
                log.error("批量推送分片执行异常", e);
                failCount += BATCH_SIZE;
            }
        }

        batchResult.setSuccessCount(successCount);
        batchResult.setFailCount(failCount);
        return batchResult;
    }

    private <T> List<List<T>> partition(List<T> list, int size) {
        List<List<T>> partitions = new ArrayList<>();
        for (int i = 0; i < list.size(); i += size) {
            partitions.add(list.subList(i, Math.min(i + size, list.size())));
        }
        return partitions;
    }
}

@Data
public class BatchPushResult {
    private int totalUsers;
    private int batchCount;
    private int successCount;
    private int failCount;
}
```

```java
@Service
public class TokenCacheService {

    // 本地缓存：userId -> tokens
    private final Cache<Long, List<PushTokenEntity>> localCache = Caffeine.newBuilder()
            .maximumSize(500_000)
            .expireAfterWrite(5, TimeUnit.MINUTES)
            .build();

    @Autowired
    private PushTokenService tokenService;

    /**
     * 获取用户 Token（缓存优先）
     */
    public List<PushTokenEntity> getUserTokens(long userId) {

        if (cached != null) {
            return cached;
        }

        List<PushTokenEntity> tokens = tokenService.getUserTokens(userId);
        if (tokens != null && !tokens.isEmpty()) {
            localCache.put(userId, tokens);
        }
        return tokens != null ? tokens : Collections.emptyList();
    }

    /**
     * 批量获取用户 Token
     */
    public Map<Long, List<PushTokenEntity>> batchGetTokens(List<Long> userIds) {
        Map<Long, List<PushTokenEntity>> result = new HashMap<>();
        List<Long> missedIds = new ArrayList<>();

        // 先查本地缓存
        for (Long userId : userIds) {
            List<PushTokenEntity> cached = localCache.getIfPresent(userId);
            if (cached != null) {
                result.put(userId, cached);
            } else {
                missedIds.add(userId);
            }
        }

        // 缓存未命中的批量查询
        if (!missedIds.isEmpty()) {
            Map<Long, List<PushTokenEntity>> fromDb = tokenService.batchGetTokens(missedIds);
            fromDb.forEach((userId, tokens) -> {
                localCache.put(userId, tokens);
                result.put(userId, tokens);
            });
        }

        return result;
    }

    /**
     * 失效缓存
     */
    public void invalidate(long userId) {
        localCache.invalidate(userId);
    }
```

## 六、最佳实践

### 6.1 推送系统设计原则

1. **通道冗余**：每种设备至少配置两个推送通道（如 Android 设备同时支持厂商通道和自建通道），一个不可用时自动切换到另一个。

2. **消息格式统一**：对业务方暴露统一的消息格式，屏蔽底层不同通道的协议差异。使用 `extraDataMap` 字段传递业务扩展数据。

3. **频率控制必须有**：无论业务需求多急迫，都必须有频率控制机制。过度推送会导致用户关闭通知权限，得不偿失。

4. **Token 生命周期管理**：定期清理无效 Token，及时处理厂商返回的 Token 失效通知。无效 Token 会拉低推送成功率指标。

5. **证书自动续签提醒**：APNs 证书每年需要续签，必须在到期前 30 天开始告警，设置多级提醒。

### 6.2 通道选择策略建议

| 场景 | 推荐通道 | 原因 |
|------|---------|------|
| APP 在前台 | 自建长连接 | 实时性最高，支持透传 |
| APP 在后台（iOS） | APNs | 系统级推送通道 |
| APP 在后台（Android） | 厂商通道 | 系统级推送，到达率高 |
| 透传消息 | 自建长连接 | 厂商通道不支持透传（passthrough=1） |
| 大批量营销推送 | 厂商通道 | 注意配额限制 |

### 6.4 关键注意事项

1. **厂商通道配额**：营销类消息在各厂商通道有严格的日配额限制。需要监控配额使用量，接近上限时切换到自建通道或降级。

2. **消息到达率统计**：推送系统的核心指标是到达率，需要区分「发送成功率」和「实际到达率」。发送成功只代表消息送达厂商服务器，用户是否真正收到还需要通过 SDK 回调确认。

3. **iOS 前后台差异**：iOS 在前台时 APNs 推送会被 SDK 拦截，不会展示在通知栏。前台推送应使用自建长连接通道，由 APP 自行处理展示。

4. **Android 厂商碎片化**：不同 Android 厂商的推送 SDK 接口、限制、错误码各不相同。需要统一抽象层，降低接入和维护成本。

5. **用户隐私合规**：推送涉及用户隐私数据（设备ID、位置等），需遵守相关法规。敏感内容不要放在推送正文中。

6. **灰度发布**：推送系统的变更需要灰度，特别是通道选择逻辑的调整。按用户 ID 尾号灰度，先小范围验证再全量。

7. **降级策略**：
   - 厂商通道不可用 -> 降级到自建通道（仅APP在线时有效）
   - 自建通道不可用 -> 降级到厂商通道
   - 所有通道不可用 -> 降级到短信通知（仅关键消息）

### 7.1 案例一：单点推送全链路

#### 7.1.1 业务场景

订单服务在支付成功后，需要给用户推送一条"支付成功"通知。链路为：**业务触发 -> 推送中心 -> 目标设备 Token 查询 -> 调用 APNs/FCM -> 推送结果回调 -> 状态记录**。

核心难点：

1. 订单支付回调可能因消息重复投递而多次触发，推送侧必须做**幂等控制**，避免用户收到重复通知。
2. 需要记录每一次推送的**全生命周期状态**（创建 -> 发送中 -> 已送达厂商 -> 回调确认 -> 失败/成功终态），便于排障和对账。
3. 需要对 APNs/FCM 调用失败进行分类处理（可重试 vs 不可重试）。

```java
    private SinglePushService singlePushService;

     * 消费订单支付成功事件
     * 使用手动 ACK，确保处理成功后才提交位移，避免消息丢失
     */
    @KafkaListener(topics = "order-pay-success", groupId = "push-center-order")

        try {
            OrderPaySuccessEvent event = JSON.parseObject(record.value(), OrderPaySuccessEvent.class);

            // 业务侧生成幂等键：同一订单的支付成功事件只推送一次
            String idempotentKey = "ORDER_PAY_SUCCESS:" + event.getOrderId();

            SinglePushRequest request = new SinglePushRequest();
            request.setIdempotentKey(idempotentKey);
            request.setUserId(event.getUserId());
            request.setTitle("支付成功");
            request.setContent(String.format("您的订单 %s 已支付成功，金额 %.2f 元",
                    event.getOrderId(), event.getPayAmount()));
            request.setCategory(MessageCategory.SYSTEM);
            request.setBizSource("order-service");
            request.getExtraDataMap().put("orderId", event.getOrderId());
            request.getExtraDataMap().put("jumpUrl", "/order/detail?id=" + event.getOrderId());

            singlePushService.pushSingle(request);

            // 处理成功，提交位移
            ack.acknowledge();
        } catch (BusinessException e) {
            // 业务异常（如参数非法）不重试，记录日志后直接 ACK，避免消息堆积
            log.error("订单支付推送业务异常, orderId={}, reason={}", orderId, e.getMessage());
            ack.acknowledge();
        } catch (Exception e) {

            log.error("订单支付推送系统异常, orderId={}, 消息将重试消费", orderId, e);
        }
    }
```

#### 7.1.4 推送中心核心服务：幂等控制 + 全链路编排

```java
/**
 * 单点推送请求
 */
@Data
public class SinglePushRequest {
    private String idempotentKey;
    private Long userId;
    private String title;
    private String content;
    private MessageCategory category;
    private String bizSource;
    private Map<String, String> extraDataMap = new HashMap<>();
}

/**
 * 单点推送服务
 * 全链路：幂等校验 -> Token查询 -> 通道选择 -> 调用APNs/FCM -> 状态落库 -> 异步等待回调
 */
@Service
public class SinglePushService {

    private static final Logger log = LoggerFactory.getLogger(SinglePushService.class);

    @Autowired
    private SinglePushRecordRepository recordRepository;
    @Autowired
    private PushTokenService tokenService;
    @Autowired
    private ChannelSelectionEngine channelEngine;
    @Autowired
    private Map<PushChannel, ChannelAdapter> channelAdapters;
    @Autowired
    private PushRateLimiter rateLimiter;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private PushRetryService retryService;

    private static final String IDEMPOTENT_LOCK_PREFIX = "push:single:idempotent:";
    private static final long IDEMPOTENT_LOCK_EXPIRE_SECONDS = 60;

    /**
     * 单点推送主流程
     */
    public SinglePushResult pushSingle(SinglePushRequest request) {
        Objects.requireNonNull(request.getIdempotentKey(), "幂等键不能为空");
        Objects.requireNonNull(request.getUserId(), "userId不能为空");

        // 1. 幂等控制：先查库，再抢分布式锁，双重保险
        SinglePushRecordEntity existing = recordRepository
                .findByIdempotentKey(request.getIdempotentKey());
        if (existing != null) {
            log.info("单点推送幂等命中，跳过重复推送, idempotentKey={}, existingStatus={}",
                    request.getIdempotentKey(), existing.getStatus());
            return SinglePushResult.duplicate(existing.getMessageId());
        }

        String lockKey = IDEMPOTENT_LOCK_PREFIX + request.getIdempotentKey();
        Boolean lockAcquired = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, "1", IDEMPOTENT_LOCK_EXPIRE_SECONDS, TimeUnit.SECONDS);
        if (!Boolean.TRUE.equals(lockAcquired)) {
            log.warn("单点推送并发请求被拦截, idempotentKey={}", request.getIdempotentKey());
            return SinglePushResult.duplicate(null);
        }

        try {
            return doPushSingle(request);
        } finally {
            // 无论成功失败，主流程结束后释放锁；已落库的记录本身即是持久化的幂等凭证
            redisTemplate.delete(lockKey);
        }
    }

    /**
     * 执行推送核心逻辑
     */
    private SinglePushResult doPushSingle(SinglePushRequest request) {
        String messageId = UUID.randomUUID().toString();

        // 2. 落库创建记录（CREATED 状态），作为幂等的最终凭证
        SinglePushRecordEntity recordEntity = new SinglePushRecordEntity();
        recordEntity.setIdempotentKey(request.getIdempotentKey());
        recordEntity.setMessageId(messageId);
        recordEntity.setUserId(request.getUserId());
        recordEntity.setTitle(request.getTitle());
        recordEntity.setContent(request.getContent());
        recordEntity.setStatus(SinglePushStatus.CREATED.getCode());
        recordEntity.setRetryCount(0);
        recordEntity.setCreateTime(new Date());
        recordEntity.setUpdateTime(new Date());

        try {
            recordRepository.save(recordEntity);
        } catch (DataIntegrityViolationException e) {
            // 唯一索引冲突：并发场景下另一个线程/实例已抢先落库，直接返回幂等结果
            log.warn("单点推送记录唯一键冲突（并发幂等）, idempotentKey={}",
                    request.getIdempotentKey());
            SinglePushRecordEntity concurrent = recordRepository
                    .findByIdempotentKey(request.getIdempotentKey());
            return SinglePushResult.duplicate(concurrent != null ? concurrent.getMessageId() : null);
        }

        PushMessageDTO message = new PushMessageDTO();
        message.setMessageId(messageId);
        message.setTargetUserIds(Collections.singletonList(request.getUserId()));
        message.setTitle(request.getTitle());
        message.setContent(request.getContent());
        message.setPassthrough(PushMessageType.NOTIFICATION.getCode());
        message.setCategory(request.getCategory());
        message.setBizSource(request.getBizSource());
        message.setExtraDataMap(request.getExtraDataMap());
        message.setExpireSeconds(3600);

        try {
            // 3. 频率控制
            if (!rateLimiter.allowPush(message)) {
                updateStatus(recordEntity, SinglePushStatus.FAILED, "触发频率限制");
                return SinglePushResult.fail(messageId, "频率限制");
            }

            updateStatus(recordEntity, SinglePushStatus.SENDING, null);

            // 4. 目标设备 Token 查询
            List<PushTokenEntity> tokens = tokenService.getUserTokens(request.getUserId());
            if (tokens.isEmpty()) {
                log.warn("单点推送无有效Token, userId={}, messageId={}",
                        request.getUserId(), messageId);
                updateStatus(recordEntity, SinglePushStatus.FAILED, "无有效Token");
                return SinglePushResult.fail(messageId, "无有效Token");
            }

            // 5. 通道选择（APNs / FCM / 厂商通道 / 自建通道）
            List<ChannelRouteResult> routes = channelEngine.selectChannel(message, tokens);
            if (routes.isEmpty()) {
                updateStatus(recordEntity, SinglePushStatus.FAILED, "无可用推送通道");
                return SinglePushResult.fail(messageId, "无可用推送通道");
            }

            // 6. 调用通道适配器发送（以第一个可用路由为例，通常单设备只有一个主路由）
            ChannelRouteResult route = routes.get(0);
            recordEntity.setDeviceId(route.getToken().getDeviceId());
            recordEntity.setChannel(route.getSelectedChannel().name());

            ChannelSendResult sendResult = sendWithExceptionHandling(route, message);

            if (sendResult.isSuccess()) {
                updateStatus(recordEntity, SinglePushStatus.SENT_TO_VENDOR, null);
                log.info("单点推送已提交厂商通道, messageId={}, userId={}, channel={}, channelMsgId={}",
                        messageId, request.getUserId(), route.getSelectedChannel(),
                        sendResult.getChannelMessageId());
                return SinglePushResult.success(messageId);
            } else {
                handleSendFailure(recordEntity, route, message, sendResult);
                return SinglePushResult.fail(messageId, sendResult.getErrorMessage());
            }
        } catch (Exception e) {
            log.error("单点推送执行异常, messageId={}, userId={}", messageId, request.getUserId(), e);
            updateStatus(recordEntity, SinglePushStatus.FAILED, "系统异常: " + e.getMessage());
            return SinglePushResult.fail(messageId, "系统异常");
        }
    }

    /**
     * 调用通道适配器，隔离异常，防止单个通道故障影响主流程
     */
    private ChannelSendResult sendWithExceptionHandling(ChannelRouteResult route,
                                                          PushMessageDTO message) {
        ChannelAdapter adapter = channelAdapters.get(route.getSelectedChannel());
        if (adapter == null) {
            return ChannelSendResult.fail("通道适配器不存在", false);
        }
        try {
            return adapter.send(route.getToken(), message);
        } catch (Exception e) {
            log.error("通道调用异常, channel={}, deviceId={}",
                    route.getSelectedChannel(), route.getToken().getDeviceId(), e);
            return ChannelSendResult.fail("通道调用异常: " + e.getMessage(), false);
        }
    }

    /**
     * 处理发送失败：区分 Token 失效（不可重试）和临时故障（可重试）
     */
    private void handleSendFailure(SinglePushRecordEntity recordEntity,
                                    ChannelRouteResult route,
                                    PushMessageDTO message,
                                    ChannelSendResult sendResult) {
        updateStatus(recordEntity, SinglePushStatus.FAILED, sendResult.getErrorMessage());

        if (sendResult.isTokenInvalid()) {
            tokenService.invalidateToken(route.getToken().getPushToken(), route.getSelectedChannel());
            log.warn("单点推送Token已失效，不再重试, messageId={}, deviceId={}",
                    message.getMessageId(), route.getToken().getDeviceId());
            return;
        }

        // 临时故障（网络超时、厂商限流等）加入重试队列
        PushSendDetail failDetail = new PushSendDetail();
        failDetail.setUserId(route.getToken().getUserId());
        failDetail.setDeviceId(route.getToken().getDeviceId());
        failDetail.setChannel(route.getSelectedChannel());
        failDetail.setSuccess(false);
        failDetail.setFailReason(sendResult.getErrorMessage());

        message.setRetryCount(recordEntity.getRetryCount());
        retryService.scheduleRetry(message, failDetail);
        recordEntity.setRetryCount(recordEntity.getRetryCount() + 1);
    }

    private void updateStatus(SinglePushRecordEntity recordEntity, SinglePushStatus status,
                               String failReason) {
        recordEntity.setStatus(status.getCode());
        recordEntity.setFailReason(failReason);
        recordEntity.setUpdateTime(new Date());
        recordRepository.save(recordEntity);
    }
}

/**
 * 单点推送结果
 */
@Data
public class SinglePushResult {
    private String messageId;
    private boolean success;
    private boolean duplicate;
    private String failReason;

    public static SinglePushResult success(String messageId) {
        SinglePushResult result = new SinglePushResult();
        result.setMessageId(messageId);

    }

    public static SinglePushResult fail(String messageId, String reason) {
```

#### 7.1.5 推送结果回调：APNs/FCM 送达确认

厂商通道（尤其是 FCM）支持通过 Webhook 或客户端 SDK 上报的方式回传送达/点击状态，推送中心需要暴露回调接口完成状态闭环。

```java
/**
 * 推送结果回调控制器
 * 接收厂商通道 / 客户端 SDK 的送达确认回调
 */
@RestController
@RequestMapping("/api/push/callback")
public class PushCallbackController {

    private static final Logger log = LoggerFactory.getLogger(PushCallbackController.class);

    @Autowired
    private PushCallbackService callbackService;

    /**
     * FCM / 客户端 SDK 送达回调
     * 幂等：同一 messageId + deviceId 的重复回调只处理一次
     */
    @PostMapping("/delivered")
    public ApiResponse<Void> onDelivered(@RequestBody PushDeliveredCallback callback) {
        try {
            if (callback.getMessageId() == null || callback.getDeviceId() == null) {
                return ApiResponse.fail(400, "参数缺失");
            }
            callbackService.handleDeliveredCallback(callback);
            return ApiResponse.success();
        } catch (Exception e) {
            log.error("处理推送送达回调异常, callback={}", JSON.toJSONString(callback), e);
            // 回调处理异常也返回200，避免厂商侧不断重推回调造成风暴，问题通过日志/告警跟进
            return ApiResponse.success();
        }
    }
}

@Data
public class PushDeliveredCallback {
    private String messageId;
    private String deviceId;
    private String channel;
    private long deliveredTime;
}

/**
 * 推送回调处理服务
 */
@Service
public class PushCallbackService {

    private static final Logger log = LoggerFactory.getLogger(PushCallbackService.class);

    @Autowired
    private SinglePushRecordRepository recordRepository;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String CALLBACK_DEDUP_PREFIX = "push:callback:dedup:";
    private static final int DEDUP_EXPIRE_HOURS = 24;

    /**
     * 处理送达回调，做幂等去重后更新状态
     */
    @Transactional(rollbackFor = Exception.class)
    public void handleDeliveredCallback(PushDeliveredCallback callback) {
        String dedupKey = CALLBACK_DEDUP_PREFIX + callback.getMessageId() + ":" + callback.getDeviceId();
        Boolean firstTime = redisTemplate.opsForValue()
                .setIfAbsent(dedupKey, "1", DEDUP_EXPIRE_HOURS, TimeUnit.HOURS);
        if (!Boolean.TRUE.equals(firstTime)) {
            log.info("送达回调重复上报，已忽略, messageId={}, deviceId={}",
                    callback.getMessageId(), callback.getDeviceId());
            return;
        }

        SinglePushRecordEntity recordEntity = recordRepository.findByMessageId(callback.getMessageId());
        if (recordEntity == null) {
            log.warn("送达回调找不到对应推送记录, messageId={}", callback.getMessageId());
            return;
        }

        // 终态记录不再重复更新（例如已经手工标记失败的场景）
        if (recordEntity.getStatus() == SinglePushStatus.DELIVERED.getCode()) {
            return;
        }

        recordEntity.setStatus(SinglePushStatus.DELIVERED.getCode());
        recordEntity.setDeliveredTime(new Date(callback.getDeliveredTime()));
        recordEntity.setUpdateTime(new Date());
        recordRepository.save(recordEntity);

        log.info("推送送达确认完成, messageId={}, deviceId={}, channel={}",
                callback.getMessageId(), callback.getDeviceId(), callback.getChannel());
    }
}
```

#### 7.1.6 链路小结

| 环节 | 组件 | 幂等/异常处理要点 |
|------|------|------|
| 业务触发 | `OrderPaySuccessListener` | Kafka 手动 ACK；业务异常直接 ACK 不重试，系统异常不 ACK 触发重投 |
| 幂等控制 | `SinglePushService.pushSingle` | 先查库 + Redis 分布式锁双重校验，唯一索引兜底 |
| Token 查询 | `PushTokenService` | 无 Token 时快速失败，记录 FAILED 状态 |
| 通道调用 | `sendWithExceptionHandling` | try-catch 隔离通道异常，Token 失效与临时故障分类处理 |
| 结果回调 | `PushCallbackService` | Redis Key 去重，避免重复回调重复更新状态 |
| 状态记录 | `SinglePushRecordEntity` | 全生命周期状态机，落库支持排障与对账 |

### 7.2 案例二：批量推送全链路

#### 7.2.1 业务场景

运营人员在后台配置一次营销推送任务，圈选"最近30天活跃且未下单"的用户群体，链路为：**运营配置推送任务 -> 人群圈选 -> 分批发送 -> 速率控制 -> 到达率统计**。

核心难点：

1. 人群规模可能达到百万级，不能一次性加载到内存，需要**游标分页 + 分批处理**。
2. 需要**任务级幂等**：任务重复提交或调度重跑不应重复群发。
3. 需要**动态速率控制**，避免瞬时流量打垮下游厂商通道及自身系统。
4. 需要按批次统计**到达率**，支持任务执行进度和效果可观测。

```java
@Service
public class BatchPushTaskService {

    private static final Logger log = LoggerFactory.getLogger(BatchPushTaskService.class);

    @Autowired
    private BatchPushTaskRepository taskRepository;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /**
     * 创建批量推送任务（运营后台调用）
     * 幂等：taskKey 由前端生成的操作流水号，防止重复提交

    @Transactional(rollbackFor = Exception.class)

        if (existing != null) {
            log.info("批量推送任务幂等命中，返回已有任务, taskKey={}, taskId={}",
                    request.getTaskKey(), existing.getId());
            return existing;
        }

        // 校验人群规则合法性
        validateCrowdRule(request.getCrowdRule());

        try {
            BatchPushTaskEntity task = new BatchPushTaskEntity();
            task.setTaskKey(request.getTaskKey());
            task.setTaskName(request.getTaskName());
            task.setTitle(request.getTitle());
            task.setContent(request.getContent());
            task.setCrowdRuleJson(JSON.toJSONString(request.getCrowdRule()));
            task.setStatus(BatchTaskStatus.PENDING.getCode());
            task.setProcessedCount(0);
            task.setSendSuccessCount(0);
            task.setDeliveredCount(0);
            task.setRateLimitPerSecond(request.getRateLimitPerSecond() > 0
                    ? request.getRateLimitPerSecond() : 500);
            task.setCreateTime(new Date());
            taskRepository.save(task);

            log.info("批量推送任务创建成功, taskId={}, taskName={}", task.getId(), task.getTaskName());
            return task;
        } catch (DataIntegrityViolationException e) {
            // 并发重复提交兜底
            log.warn("批量推送任务taskKey冲突，返回已有任务, taskKey={}", request.getTaskKey());
            return taskRepository.findByTaskKey(request.getTaskKey());
        }
    }

            throw new BusinessException("活跃天数范围不合法");
        }
    }
```

#### 7.2.5 分批发送 + 速率控制：批量推送执行器

```java
/**
 * 批量推送执行器
 * 全链路：任务调度 -> 人群分页拉取 -> 分批发送 -> 令牌桶限速 -> 进度与到达率统计
 */
@Service
public class BatchPushExecutor {

    private static final Logger log = LoggerFactory.getLogger(BatchPushExecutor.class);

    @Autowired
    private BatchPushTaskRepository taskRepository;
    @Autowired
    private CrowdSelectionService crowdSelectionService;
    @Autowired
    private PushTokenService tokenService;
    @Autowired
    private ChannelSelectionEngine channelEngine;
    @Autowired
    private Map<PushChannel, ChannelAdapter> channelAdapters;
    @Autowired
    private PushRateLimiter rateLimiter;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private ThreadPoolTaskExecutor batchPushThreadPool;

    private static final String TASK_RUNNING_LOCK_PREFIX = "push:batch:task:lock:";
    private static final String TASK_CURSOR_PREFIX = "push:batch:task:cursor:";

    /**
     * 启动批量推送任务
     * 幂等：同一 taskId 同一时刻只能有一个执行实例（分布式锁保护，防止多实例重复调度）
     */
    public void startTask(long taskId) {
        String lockKey = TASK_RUNNING_LOCK_PREFIX + taskId;
        Boolean locked = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, String.valueOf(System.currentTimeMillis()),
                        6, TimeUnit.HOURS);
        if (!Boolean.TRUE.equals(locked)) {
            log.warn("批量推送任务已在执行中，跳过重复启动, taskId={}", taskId);
            return;
        }

        try {
            executeTask(taskId);
        } catch (Exception e) {
            log.error("批量推送任务执行异常, taskId={}", taskId, e);
            markTaskFailed(taskId, e.getMessage());
        } finally {
            redisTemplate.delete(lockKey);
        }
    }

    /**
     * 执行任务主流程：支持断点续跑（游标持久化在 Redis，任务重启后从上次游标继续）
     */
    private void executeTask(long taskId) {
        BatchPushTaskEntity task = taskRepository.findById(taskId)
                .orElseThrow(() -> new BusinessException("任务不存在: " + taskId));

        if (task.getStatus() == BatchTaskStatus.COMPLETED.getCode()) {
            log.info("批量推送任务已完成，跳过, taskId={}", taskId);
            return;
        }

        CrowdRule rule = JSON.parseObject(task.getCrowdRuleJson(), CrowdRule.class);

        // 统计总人数（仅首次执行时统计）
        if (task.getTotalCount() == null || task.getTotalCount() == 0) {
            long total = crowdSelectionService.countCrowd(rule);
            task.setTotalCount((int) total);
        }
        task.setStatus(BatchTaskStatus.RUNNING.getCode());
        task.setStartTime(task.getStartTime() != null ? task.getStartTime() : new Date());
        taskRepository.save(task);

        // 恢复游标：支持任务中断后续跑，避免重复推送
        String cursorKey = TASK_CURSOR_PREFIX + taskId;
        String cursorStr = redisTemplate.opsForValue().get(cursorKey);
        long cursor = cursorStr != null ? Long.parseLong(cursorStr) : 0L;

        while (true) {
            // 支持运营中途暂停/取消任务
            BatchPushTaskEntity latest = taskRepository.findById(taskId).orElse(null);
            if (latest == null || latest.getStatus() == BatchTaskStatus.PAUSED.getCode()
                    || latest.getStatus() == BatchTaskStatus.CANCELLED.getCode()) {
                log.info("批量推送任务被暂停或取消，停止执行, taskId={}, status={}",
                        taskId, latest == null ? "null" : latest.getStatus());
                return;
            }

            List<Long> userIds = crowdSelectionService.fetchNextPage(rule, cursor);
            if (userIds.isEmpty()) {
                break; // 人群拉取完毕
            }

            BatchPageResult pageResult = sendBatchWithRateLimit(task, userIds);

            cursor = userIds.get(userIds.size() - 1);
            redisTemplate.opsForValue().set(cursorKey, String.valueOf(cursor), 7, TimeUnit.DAYS);

            // 更新任务进度（原子递增，避免并发场景下的计数覆盖）
            taskRepository.incrementProgress(taskId, userIds.size(),
                    pageResult.getSuccessCount());
        }

        // 任务完成
        BatchPushTaskEntity finalTask = taskRepository.findById(taskId)
                .orElseThrow(() -> new BusinessException("任务不存在: " + taskId));
        finalTask.setStatus(BatchTaskStatus.COMPLETED.getCode());
        finalTask.setFinishTime(new Date());
        taskRepository.save(finalTask);
        redisTemplate.delete(cursorKey);

        log.info("批量推送任务执行完成, taskId={}, total={}, success={}",
                taskId, finalTask.getTotalCount(), finalTask.getSendSuccessCount());
    }

    /**
     * 分批发送 + 速率控制
     * 使用 Guava RateLimiter 实现令牌桶限速，避免瞬时打爆下游通道
     */
    private BatchPageResult sendBatchWithRateLimit(BatchPushTaskEntity task, List<Long> userIds) {
        RateLimiter rateLimiter = RateLimiter.create(task.getRateLimitPerSecond());

        List<CompletableFuture<Boolean>> futures = new ArrayList<>();
        for (Long userId : userIds) {
            // 限速：控制发送速率，不至于打满线程池/下游通道
            rateLimiter.acquire();

            CompletableFuture<Boolean> future = CompletableFuture.supplyAsync(
                    () -> sendToOneUser(task, userId), batchPushThreadPool)
                    .exceptionally(ex -> {
                        log.error("批量推送单用户发送异常, taskId={}, userId={}",
                                task.getId(), userId, ex);
                        return false;
                    });
            futures.add(future);
        }

        int successCount = 0;
        for (CompletableFuture<Boolean> future : futures) {
            try {
                if (future.get(10, TimeUnit.SECONDS)) {
                    successCount++;
                }
            } catch (Exception e) {
                log.error("批量推送等待结果超时/异常, taskId={}", task.getId(), e);
            }
        }

        BatchPageResult result = new BatchPageResult();
        result.setTotalCount(userIds.size());
        result.setSuccessCount(successCount);
        return result;
    }

    /**
     * 单用户发送逻辑，含 Token 查询与通道调用异常隔离
     */
    private boolean sendToOneUser(BatchPushTaskEntity task, long userId) {
        try {
            List<PushTokenEntity> tokens = tokenService.getUserTokens(userId);
            if (tokens.isEmpty()) {
                return false;
            }

            PushMessageDTO message = new PushMessageDTO();
            message.setMessageId(task.getId() + ":" + userId);
            message.setTargetUserIds(Collections.singletonList(userId));
            message.setTitle(task.getTitle());
            message.setContent(task.getContent());
            message.setPassthrough(PushMessageType.NOTIFICATION.getCode());
            message.setCategory(MessageCategory.MARKETING);
            message.setExpireSeconds(7200);

            // 营销消息受频控限制，超过用户每日营销消息上限则跳过
            if (!rateLimiterAllow(message)) {
                return false;
            }

            List<ChannelRouteResult> routes = channelEngine.selectChannel(message, tokens);
            if (routes.isEmpty()) {
                return false;
            }

            boolean anySuccess = false;
            for (ChannelRouteResult route : routes) {
                ChannelAdapter adapter = channelAdapters.get(route.getSelectedChannel());
                if (adapter == null) {
                    continue;
                }
                try {
                    ChannelSendResult sendResult = adapter.send(route.getToken(), message);
                    if (sendResult.isSuccess()) {
                        anySuccess = true;
                    } else if (sendResult.isTokenInvalid()) {
                        tokenService.invalidateToken(route.getToken().getPushToken(),
                                route.getSelectedChannel());
                    }
                } catch (Exception e) {
                    log.error("批量推送通道调用异常, taskId={}, userId={}, channel={}",
                            task.getId(), userId, route.getSelectedChannel(), e);
                }
            }
            return anySuccess;
        } catch (Exception e) {
            log.error("批量推送单用户处理异常, taskId={}, userId={}", task.getId(), userId, e);
            return false;
        }
    }

    private boolean rateLimiterAllow(PushMessageDTO message) {
        try {
            return rateLimiter.allowPush(message);
        } catch (Exception e) {
            log.warn("频率控制检查异常，默认放行, messageId={}", message.getMessageId(), e);
            return true;
        }
    }

    private void markTaskFailed(long taskId, String reason) {
        taskRepository.findById(taskId).ifPresent(task -> {
            task.setStatus(BatchTaskStatus.FAILED.getCode());
            task.setFinishTime(new Date());
            taskRepository.save(task);
        });
        log.error("批量推送任务标记为失败, taskId={}, reason={}", taskId, reason);
    }
}

@Data
public class BatchPageResult {
    private int totalCount;
    private int successCount;
}
```

#### 7.2.6 到达率统计

```java
/**
 * 批量推送到达率统计服务
 * 消费 SDK/厂商侧上报的送达事件，按任务维度聚合到达率
 */
@Service
public class BatchDeliveryStatsService {

    private static final Logger log = LoggerFactory.getLogger(BatchDeliveryStatsService.class);

    @Autowired
    private BatchPushTaskRepository taskRepository;

    /**
     * 消费送达事件，累加任务到达数
     * 幂等：使用 Redis HyperLogLog 按 taskId+deviceId 去重计数，避免重复上报导致到达率虚高
     */
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String DELIVERY_HLL_PREFIX = "push:batch:delivery:hll:";

    @KafkaListener(topics = "push-delivery-log", groupId = "push-batch-stats")
    public void onDeliveryEvent(ConsumerRecord<String, String> record, Acknowledgment ack) {
        try {
            JSONObject event = JSON.parseObject(record.value());
            String messageId = event.getString("messageId");

            // 批量推送的 messageId 约定格式为 "taskId:userId"
            if (messageId == null || !messageId.contains(":")) {
                ack.acknowledge();
                return;
            }
            long taskId = Long.parseLong(messageId.split(":")[0]);
            String deviceId = event.getString("deviceId");

            String hllKey = DELIVERY_HLL_PREFIX + taskId;
            redisTemplate.opsForHyperLogLog().add(hllKey, deviceId);
            redisTemplate.expire(hllKey, 30, TimeUnit.DAYS);

            ack.acknowledge();
        } catch (Exception e) {
            log.error("批量推送到达事件处理异常, record={}", record.value(), e);
            // 统计类消息处理失败不影响主流程，ACK 后跳过，避免阻塞消费
            ack.acknowledge();
        }
    }

    /**
     * 定时汇总到达率写入任务表
     */
    @Scheduled(fixedRate = 60000)
    public void syncDeliveryCountToTask() {
        List<BatchPushTaskEntity> runningTasks = taskRepository
                .findByStatusIn(Arrays.asList(BatchTaskStatus.RUNNING.getCode(),
                        BatchTaskStatus.COMPLETED.getCode()));

        for (BatchPushTaskEntity task : runningTasks) {
            try {
                String hllKey = DELIVERY_HLL_PREFIX + task.getId();
                Long deliveredCount = redisTemplate.opsForHyperLogLog().size(hllKey);
                if (deliveredCount != null) {
                    task.setDeliveredCount(deliveredCount.intValue());
                    taskRepository.save(task);
                }
            } catch (Exception e) {
                log.error("同步任务到达率异常, taskId={}", task.getId(), e);
            }
        }
    }

    /**
     * 查询任务到达率
     */
    public double getDeliveryRate(long taskId) {
        BatchPushTaskEntity task = taskRepository.findById(taskId)
                .orElseThrow(() -> new BusinessException("任务不存在: " + taskId));
        if (task.getSendSuccessCount() == null || task.getSendSuccessCount() == 0) {
            return 0.0;
        }
        int delivered = task.getDeliveredCount() != null ? task.getDeliveredCount() : 0;
        return delivered * 1.0 / task.getSendSuccessCount();
    }
}
```

#### 7.2.7 链路小结

| 环节 | 组件 | 幂等/异常处理要点 |
|------|------|------|
| 任务创建 | `BatchPushTaskService.createTask` | `taskKey` 唯一索引 + 先查后建，防止重复提交 |
| 任务调度 | `BatchPushExecutor.startTask` | Redis 分布式锁防止多实例重复执行，游标持久化支持断点续跑 |
| 人群圈选 | `CrowdSelectionService` | 游标分页替代 offset 分页，避免大结果集与深分页问题 |
| 分批发送 | `sendBatchWithRateLimit` | `RateLimiter` 令牌桶限速；单用户异常被 `exceptionally` 捕获，不影响整批 |
| 到达率统计 | `BatchDeliveryStatsService` | HyperLogLog 按设备去重计数，避免重复回调导致到达率失真 |

### 7.3 案例三：长连接推送全链路

#### 7.3.1 业务场景

IM/客服类场景要求消息实时送达在线设备，若设备离线则消息暂存，待设备重新上线后补推。链路为：**WebSocket/长轮询 -> 用户在线状态 -> 实时推送 -> 离线消息存储 -> 上线补推**。

核心难点：

1. 需要维护**全局在线状态**（可能多实例部署，需要基于 Redis 而非仅本机内存）。
2. 消息发送需要**先判断在线状态**，在线走长连接实时推送，离线则**持久化离线消息**。
3. 设备重新上线后需要**补推离线消息**，且需要避免消息重复推送（幂等 + ACK 确认机制）。
4. 长连接断开、重连、多端登录等边界场景需要妥善处理。

#### 7.3.2 离线消息模型

#### 7.3.3 实时推送入口：在线状态判断 + 长连接下发

```java
/**
 * 长连接实时推送服务
 * 全链路：判断在线状态 -> 在线走长连接下发 -> 离线落库暂存
 */
@Service
public class RealtimePushService {

    private static final Logger log = LoggerFactory.getLogger(RealtimePushService.class);

    @Autowired
    private DeviceOnlineService deviceOnlineService;
    @Autowired
    private ConnectionManager connectionManager;
    @Autowired
    private OfflineMessageRepository offlineMessageRepository;
    @Autowired
    private PushTokenService tokenService;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String SEND_IDEMPOTENT_PREFIX = "push:realtime:idempotent:";
    private static final long DEFAULT_OFFLINE_EXPIRE_HOURS = 72;

    /**
     * 实时推送消息给用户所有在线/离线设备
     * 幂等：同一 messageId 只处理一次（防止业务方重复调用或消息重放）
     */
    public RealtimePushResult push(RealtimePushRequest request) {
        String messageId = request.getMessageId() != null
                ? request.getMessageId() : UUID.randomUUID().toString();

        String idempotentKey = SEND_IDEMPOTENT_PREFIX + messageId;
        Boolean firstTime = redisTemplate.opsForValue()
                .setIfAbsent(idempotentKey, "1", 24, TimeUnit.HOURS);
        if (!Boolean.TRUE.equals(firstTime)) {
            log.info("长连接实时推送幂等命中，跳过重复处理, messageId={}", messageId);
            return RealtimePushResult.duplicate(messageId);
        }

        RealtimePushResult result = new RealtimePushResult();
        result.setMessageId(messageId);

        try {
            List<PushTokenEntity> tokens = tokenService.getUserTokens(request.getUserId());
            if (tokens.isEmpty()) {
                log.warn("实时推送目标用户无注册设备, userId={}", request.getUserId());
                result.setSuccess(false);
                result.setFailReason("无注册设备");
                return result;
            }

            int onlineDelivered = 0;
            int offlineStored = 0;

            for (PushTokenEntity token : tokens) {
                String deviceId = token.getDeviceId();
                boolean online = deviceOnlineService.isOnline(deviceId);

                if (online) {
                    boolean delivered = deliverViaLongConnection(deviceId, messageId, request);
                    if (delivered) {
                        onlineDelivered++;
                    } else {
                        // 长连接下发失败（如瞬时网络抖动），兜底落库为离线消息
                        storeOfflineMessage(request, messageId, deviceId);
                        offlineStored++;
                    }
                } else {
                    storeOfflineMessage(request, messageId, deviceId);
                    offlineStored++;
                }
            }

            result.setSuccess(true);
            result.setOnlineDeliveredCount(onlineDelivered);
            result.setOfflineStoredCount(offlineStored);

            log.info("实时推送处理完成, messageId={}, userId={}, online={}, offline={}",
                    messageId, request.getUserId(), onlineDelivered, offlineStored);
            return result;
        } catch (Exception e) {
            log.error("实时推送处理异常, messageId={}, userId={}", messageId, request.getUserId(), e);
            result.setSuccess(false);
            result.setFailReason("系统异常: " + e.getMessage());
            return result;
        }
    }

    /**
     * 通过长连接下发消息
     */
    private boolean deliverViaLongConnection(String deviceId, String messageId,
                                              RealtimePushRequest request) {
        Channel channel = connectionManager.getChannel(deviceId);
        if (channel == null || !channel.isActive()) {
            return false;
        }

        try {
            PushProtocolMessage protocolMsg = new PushProtocolMessage();
            protocolMsg.setMessageId(messageId);
            protocolMsg.setType(PushMessageType.PASSTHROUGH.getCode());
            protocolMsg.setTitle(request.getTitle());
            protocolMsg.setContent(request.getContent());
            protocolMsg.setExtraData(request.getExtraDataMap());
            protocolMsg.setTimestamp(System.currentTimeMillis());
            // 要求客户端收到后必须回 ACK，服务端据此判断是否需要补推
            protocolMsg.setRequireAck(true);

            String json = JSON.toJSONString(protocolMsg);
            ChannelFuture future = channel.writeAndFlush(new TextWebSocketFrame(json));
            boolean writeOk = future.await(3, TimeUnit.SECONDS) && future.isSuccess();

            if (!writeOk) {
                log.warn("长连接写出失败, deviceId={}, messageId={}", deviceId, messageId);
            }
            return writeOk;
        } catch (Exception e) {
            log.error("长连接下发异常, deviceId={}, messageId={}", deviceId, messageId, e);
            return false;
        }
    }

    /**
     * 存储离线消息，等待设备上线后补推
     */
    private void storeOfflineMessage(RealtimePushRequest request, String messageId, String deviceId) {
        try {
            OfflineMessageEntity entity = new OfflineMessageEntity();
            entity.setMessageId(messageId);
            entity.setUserId(request.getUserId());
            entity.setDeviceId(deviceId);
            entity.setTitle(request.getTitle());
            entity.setContent(request.getContent());
            entity.setExtraDataJson(JSON.toJSONString(request.getExtraDataMap()));
            entity.setDeliveryStatus(0);
            entity.setCreateTime(new Date());
            entity.setExpireTime(new Date(System.currentTimeMillis()
                    + DEFAULT_OFFLINE_EXPIRE_HOURS * 3600 * 1000));
            offlineMessageRepository.save(entity);
        } catch (Exception e) {
            // 离线消息落库失败是较严重的问题（消息可能永久丢失），需要告警而非静默吞掉
            log.error("离线消息落库失败, deviceId={}, messageId={}", deviceId, messageId, e);
            alertService.sendAlert(AlertLevel.HIGH,
                    "离线消息落库失败: deviceId=" + deviceId + ", messageId=" + messageId);
        }
    }
}

@Data
public class RealtimePushRequest {
    private String messageId;
    private Long userId;
    private String title;
    private String content;
    private Map<String, String> extraDataMap = new HashMap<>();
}

@Data
public class RealtimePushResult {
    private String messageId;
    private boolean success;
    private boolean duplicate;
    private String failReason;
    private int onlineDeliveredCount;
    private int offlineStoredCount;

    }
```

#### 7.3.4 上线补推：设备重连后拉取离线消息

```java
/**
 * 上线补推服务
 * 设备重新建立长连接后，主动拉取该设备的离线消息进行补推
 */
@Service
public class OfflineMessageRedeliverService {

    private static final Logger log = LoggerFactory.getLogger(OfflineMessageRedeliverService.class);

    @Autowired
    private OfflineMessageRepository offlineMessageRepository;
    @Autowired
    private ConnectionManager connectionManager;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String REDELIVER_LOCK_PREFIX = "push:offline:redeliver:lock:";
    private static final int BATCH_SIZE = 100;

    /**
     * 设备上线事件触发补推
     * 幂等：单设备补推加锁，防止同一设备短时间内多次重连触发并发补推导致重复下发
     */
    public void onDeviceOnline(String deviceId) {
        String lockKey = REDELIVER_LOCK_PREFIX + deviceId;
        Boolean locked = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, "1", 30, TimeUnit.SECONDS);
        if (!Boolean.TRUE.equals(locked)) {
            log.info("设备补推任务正在执行，跳过并发触发, deviceId={}", deviceId);
            return;
        }

        try {
            redeliverForDevice(deviceId);
        } catch (Exception e) {
            log.error("离线消息补推异常, deviceId={}", deviceId, e);
        } finally {
            redisTemplate.delete(lockKey);
        }
    }

    /**
     * 分批查询并补推离线消息，按创建时间正序保证顺序性
     */
    private void redeliverForDevice(String deviceId) {
        Channel channel = connectionManager.getChannel(deviceId);
        if (channel == null || !channel.isActive()) {
            log.warn("补推时设备已不在线，放弃本次补推, deviceId={}", deviceId);
            return;
        }

        int page = 0;
        int totalRedelivered = 0;

        while (true) {
            List<OfflineMessageEntity> pendingMessages = offlineMessageRepository
                    .findPendingByDeviceId(deviceId, 0, PageRequest.of(page, BATCH_SIZE,
                            Sort.by(Sort.Direction.ASC, "createTime")));

            if (pendingMessages.isEmpty()) {
                break;
            }

            for (OfflineMessageEntity msg : pendingMessages) {
                // 逐条判断是否已过期
                if (msg.getExpireTime() != null && msg.getExpireTime().before(new Date())) {
                    msg.setDeliveryStatus(2);
                    offlineMessageRepository.save(msg);
                    continue;
                }

                boolean sent = sendOfflineMessage(channel, msg);
                if (sent) {
                    totalRedelivered++;
                }
                // 注意：这里不立即标记为已投递，而是等待客户端 ACK 回调后再更新状态，
                // 避免"写出成功但客户端未真正处理"导致消息丢失的假阳性
            }

            page++;
            // 防御性退出：避免单设备离线消息异常堆积导致补推任务长时间占用连接
            if (page > 50) {
                log.warn("设备离线消息数量过多，本轮补推提前结束, deviceId={}", deviceId);
                break;
            }
        }

        log.info("离线消息补推完成, deviceId={}, redeliveredCount={}", deviceId, totalRedelivered);
    }

    private boolean sendOfflineMessage(Channel channel, OfflineMessageEntity msg) {
        try {
            PushProtocolMessage protocolMsg = new PushProtocolMessage();
            protocolMsg.setMessageId(msg.getMessageId());
            protocolMsg.setType(PushMessageType.PASSTHROUGH.getCode());
            protocolMsg.setTitle(msg.getTitle());
            protocolMsg.setContent(msg.getContent());
            protocolMsg.setExtraData(msg.getExtraDataJson() != null
                    ? JSON.parseObject(msg.getExtraDataJson(), Map.class) : null);
            protocolMsg.setTimestamp(System.currentTimeMillis());
            protocolMsg.setRequireAck(true);

            String json = JSON.toJSONString(protocolMsg);
            ChannelFuture future = channel.writeAndFlush(new TextWebSocketFrame(json));
            boolean writeOk = future.await(3, TimeUnit.SECONDS) && future.isSuccess();
            if (!writeOk) {
                log.warn("离线消息补推写出失败, deviceId={}, messageId={}",
                        msg.getDeviceId(), msg.getMessageId());
            }
            return writeOk;
        } catch (Exception e) {
            log.error("离线消息补推异常, deviceId={}, messageId={}",
                    msg.getDeviceId(), msg.getMessageId(), e);
            return false;
        }
    }

    /**
     * 客户端 ACK 回调：确认补推消息已被处理，更新投递状态
     * 幂等：重复 ACK 只会重复更新为同一终态，不会产生副作用
     */
    @Transactional(rollbackFor = Exception.class)
    public void onClientAck(String deviceId, String messageId) {
        try {
            OfflineMessageEntity msg = offlineMessageRepository
                    .findByDeviceIdAndMessageId(deviceId, messageId);
            if (msg == null) {
                // 可能是实时消息（未落离线表）的 ACK，属正常情况，仅记录调试日志
                log.debug("未找到对应离线消息记录（可能是实时消息ACK）, deviceId={}, messageId={}",
                        deviceId, messageId);
                return;
            }
            if (msg.getDeliveryStatus() == 1) {
                return; // 已是终态，避免重复更新
            }
            msg.setDeliveryStatus(1);
            msg.setDeliveredTime(new Date());
            offlineMessageRepository.save(msg);
        } catch (Exception e) {
            log.error("处理离线消息ACK异常, deviceId={}, messageId={}", deviceId, messageId, e);
        }
    }

    /**
     * 定时清理过期未投递的离线消息
     */
    @Scheduled(cron = "0 30 3 * * ?")
    public void cleanExpiredOfflineMessages() {
        try {
            int cleaned = offlineMessageRepository.markExpiredMessages(new Date());
            log.info("清理过期离线消息数量: {}", cleaned);
        } catch (Exception e) {
            log.error("清理过期离线消息任务异常", e);
        }
    }
}
```

#### 7.3.5 WebSocket 接入层改造：上线事件触发补推

在原有 `PushWebSocketHandler`（见 3.4.3 节）的基础上，注册成功后触发补推，并处理客户端 ACK：

```java
/**
 * WebSocket 消息处理器（扩展版）
 * 在设备注册成功后触发离线消息补推，并处理补推消息的客户端 ACK
 */
public class OfflineAwarePushWebSocketHandler extends SimpleChannelInboundHandler<TextWebSocketFrame> {

    private static final Logger log = LoggerFactory.getLogger(OfflineAwarePushWebSocketHandler.class);

    private final ConnectionManager connectionManager;
    private final DeviceOnlineService deviceOnlineService;
    private final OfflineMessageRedeliverService redeliverService;

    public OfflineAwarePushWebSocketHandler(ConnectionManager connectionManager,
                                             DeviceOnlineService deviceOnlineService,
                                             OfflineMessageRedeliverService redeliverService) {
        this.connectionManager = connectionManager;
        this.deviceOnlineService = deviceOnlineService;
        this.redeliverService = redeliverService;
    }

    @Override
    protected void channelRead0(ChannelHandlerContext ctx, TextWebSocketFrame frame) {
        try {
            JSONObject json = JSON.parseObject(frame.text());
            String type = json.getString("type");

            switch (type) {
                case "register":
                    handleRegister(ctx, json);
                    break;
                case "heartbeat":
                    handleHeartbeat(json);
                    break;
                case "ack":
                    handleAck(json);
                    break;
                default:
                    log.warn("未知的长连接消息类型: {}, channelId={}", type, ctx.channel().id());
            }
        } catch (Exception e) {
            // 单条消息解析/处理异常不应关闭连接，记录日志后继续处理后续帧
            log.error("处理长连接消息异常, channelId={}", ctx.channel().id(), e);
        }
    }

    private void handleRegister(ChannelHandlerContext ctx, JSONObject json) {
        String deviceId = json.getString("deviceId");
        if (deviceId == null || deviceId.isEmpty()) {
            log.warn("设备注册缺少deviceId, channelId={}", ctx.channel().id());
            ctx.close();
            return;
        }

        connectionManager.register(deviceId, ctx.channel());
        deviceOnlineService.heartbeat(deviceId);

        JSONObject response = new JSONObject();
        response.put("type", "registerResult");
        response.put("success", true);
        ctx.writeAndFlush(new TextWebSocketFrame(response.toJSONString()));

        // 异步触发离线消息补推，避免阻塞当前 EventLoop 线程
        CompletableFuture.runAsync(() -> {
            try {
                redeliverService.onDeviceOnline(deviceId);
            } catch (Exception e) {
                log.error("触发离线消息补推异常, deviceId={}", deviceId, e);
            }
        });

        log.info("设备上线并触发补推检查, deviceId={}, channelId={}", deviceId, ctx.channel().id());
    }

    private void handleHeartbeat(JSONObject json) {
        String deviceId = json.getString("deviceId");
        if (deviceId != null) {
            deviceOnlineService.heartbeat(deviceId);
        }
    }

    private void handleAck(JSONObject json) {
        String deviceId = json.getString("deviceId");
        String messageId = json.getString("messageId");
        if (deviceId == null || messageId == null) {
            return;
        }
        redeliverService.onClientAck(deviceId, messageId);
    }

    @Override
    public void channelInactive(ChannelHandlerContext ctx) {
        connectionManager.unregister(ctx.channel());
    }

    @Override
    public void exceptionCaught(ChannelHandlerContext ctx, Throwable cause) {
        log.error("WebSocket连接异常, channelId={}", ctx.channel().id(), cause);
        ctx.close();
    }

    @Override
    public void userEventTriggered(ChannelHandlerContext ctx, Object evt) {
        if (evt instanceof IdleStateEvent) {
            log.info("连接心跳超时，主动关闭, channelId={}", ctx.channel().id());
            ctx.close();
        }
    }
}
```

#### 7.3.6 链路小结

| 环节 | 组件 | 幂等/异常处理要点 |
|------|------|------|
| 在线状态判断 | `DeviceOnlineService` | 基于 Redis 心跳 Key，支持多实例部署下的全局在线状态一致 |
| 实时推送 | `RealtimePushService.push` | `messageId` 幂等去重；长连接写出失败自动降级为离线存储 |
| 离线消息存储 | `storeOfflineMessage` | 落库失败触发高优先级告警，防止消息静默丢失 |
| 上线补推 | `OfflineMessageRedeliverService` | 设备级分布式锁防止并发重复补推；ACK 确认后才更新终态，避免假阳性 |
| 长连接接入层 | `OfflineAwarePushWebSocketHandler` | 单帧异常隔离处理，不影响连接上其他消息；补推异步化避免阻塞 EventLoop |

---

至此，三个案例分别覆盖了推送系统中最典型的**单点触达**、**大规模批量触达**、**长连接实时触达与离线补偿**三类场景。三者共享同一套 Token 管理、通道选择、发送引擎等底层能力，差异主要体现在：幂等键的设计粒度（消息级 / 任务级 / 设备补推级）、速率控制的作用维度（单用户频控 / 任务限速 / 长连接背压），以及状态追踪的存储介质（关系型状态机 / HyperLogLog 去重统计 / 离线消息表)。实际落地时应根据业务对**实时性、到达率、可观测性**的不同要求，选择合适的组合。
