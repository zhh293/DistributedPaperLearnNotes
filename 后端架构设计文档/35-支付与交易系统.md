# 支付与交易系统架构设计文档

## 一、问题背景

### 1.1 要解决的核心问题

支付与交易系统是任何涉及资金流转的业务的核心基础设施，其特殊性在于**一旦出现错误，损失的是真实货币，而非普通业务数据错误那样可以简单回滚了事**。支付交易系统要解决的核心问题可以归纳为：

1. **资金安全与数据一致性问题**：支付系统涉及资金交易，对数据的安全性和一致性有远高于普通业务系统的要求，任何环节的疏漏都可能直接演变为资金损失（资损）事故。
2. **多方协作下的状态同步问题**：一笔支付交易通常涉及用户、商户、支付渠道（银行、第三方支付机构）、平台自身系统等多方，各方系统之间存在网络延迟和故障的可能性，如何保证多方对交易状态的认知最终一致，是支付系统设计的核心难题。
3. **分布式环境下的幂等与重复处理问题**：网络超时、客户端重试、消息重复投递在分布式系统中是常态而非异常，支付这类涉及资金变更的操作，一旦因为重复处理造成重复扣款或重复退款，会直接造成资金损失且难以挽回。
4. **规模化交易下的稳定性与性能问题**：大型交易系统往往需要支撑亿级用户、千万级商户、亿级日交易单量、百亿级日资金处理量，在此规模下系统链路日益复杂，任何薄弱环节都可能在高并发下被放大成严重故障。

### 1.2 典型场景

- **C端用户下单支付**：用户在收银台选择支付方式，发起支付请求，系统需要与银行或第三方支付渠道交互完成扣款。
- **押金与免押两种业务模式**：押金模式下用户预先支付押金、服务结束后原路退回剩余款项；免押模式下用户基于信用体系先享受服务，服务结束后完成扣款。
- **平台型多方结算**：商户入驻平台后，平台需要在用户支付完成、交易完成履约后，按照约定的账期和规则将款项结算给商户。
- **扫码支付场景**：如商家收银台扫用户付款码、用户扫商家收款码等场景，涉及预下单、支付渠道对接、订单状态同步、异常补单等完整链路。
- **对账与差错处理**：每日与支付渠道、银行的账单进行核对，发现差异及时排查处理，这是保障资金安全的最后一道防线。

### 1.3 不解决的后果

- **资损事故**：资损是指由于产品或业务策略设计不当、代码质量与系统实现问题、人为操作不当、安全漏洞等导致的直接或间接资金损失。真实的资损案例包括：优惠券使用规则配置错误导致非预期商品被以远低于成本的价格购买；系统漏洞被黑产用户批量利用进行薅羊毛；测试环境的 Mock 流量意外流入生产环境，导致用户被错误告知"已完成扣款/还款"而实际资金未发生变化。
- **资损难以追回且成本高昂**：资金损失一旦发生，往往极难追回，即便能够追回也需要投入高昂的追偿成本。
- **舆情与品牌信任危机**：资损类事件在互联网行业极易演变为高关注度的舆情事件。
- **合规与资质风险**：对于持有支付牌照等资质的机构而言，资损类事件会直接影响相关的行业资质评定和监管评价。
- **多方账目不一致引发的经营纠纷**：如果对账机制缺失或不完善，将导致平台与商户、平台与支付渠道之间的账目长期无法核实。

## 二、整体架构设计

### 2.1 支付系统的核心组成部分

一个完整的支付系统架构通常由以下几个核心部分构成：

| 组成部分 | 核心职责 |
|---|---|
| 支付渠道层 | 对接外部银行、第三方支付机构，屏蔽不同渠道的接口差异，向上层提供统一的支付能力抽象 |
| 支付网关层 | 作为支付系统对外的统一入口，承担协议转换、请求路由、安全校验等职责 |
| 支付核心层（交易核心） | 承载支付交易的核心业务逻辑，包括支付单的创建、状态流转、支付结果处理 |
| 支付账户层 | 管理用户、商户的账户余额、资金归属关系，是资金安全的核心记账体系 |
| 支付风控层 | 在支付链路中嵌入风险识别能力，拦截欺诈、盗刷等风险交易 |
| 对账与清结算层 | 与渠道、银行进行账务核对，并完成商户资金的结算打款 |

### 2.2 交易系统与支付系统的关系与分工

交易系统（负责订单、交易流程编排）与支付系统（专注支付渠道对接和资金处理）往往是两个相对独立、但紧密协作的系统。这种拆分背后的架构考量是：**将业务多样性强、需求变化快的部分（交易系统）与安全性要求高、需要保持稳定的部分（支付核心）分离**，可以避免业务侧频繁的需求变更影响支付核心链路的稳定性。

### 2.3 资金链路建设的基本原则

在决定是否新建一条独立的资金链路时，应当遵循"**资金链路不盲建**"的原则：新建一条资金链路意味着相关能力需要完全重新建设，隐性成本很高（服务 SLA 保障、凭证一致性保障、财务系统对接等），因此应优先复用已经过验证的成熟资金链路。

### 2.4 设计权衡

- **强一致性 vs 最终一致性的权衡**：涉及资金变更的核心操作通常要求强一致性，依赖本地数据库事务保证；而跨系统的状态同步往往只能接受最终一致性。
- **实时处理 vs 异步处理的权衡**：支付主链路需要尽可能实时响应；而清结算、对账等环节通常采用异步批处理方式。
- **安全性 vs 用户体验的权衡**：过多的风控校验会拖慢支付流程；过少的安全校验则会放大欺诈风险。

## 三、核心链路设计

### 3.1 步骤一：支付交易的基础模型——交易、凭证与经济活动

理解支付系统设计的第一步，是准确理解几个核心概念的定义和关系：

- **交易**：买卖双方对"有价物品及服务"互通有无的行为，交易过程中发生了资金、货物的转移。
- **经济活动**：整个交易过程中涉及资金信息的具体活动，例如用户下单支付、发放促销优惠、结算打款等。
- **凭证**：用来证明经济活动事项发生、明确经济责任的资金信息记录，本质上记录着资金的流动。一张合格的凭证应该能够清晰地回答"谁、在什么时候、什么场景下、发生了什么资金变化"。

这三者的关系是：**每一次经济活动的发生，都应该有且仅有一张与之对应的凭证**，凭证是经济活动在系统中留下的、可被审计追溯的证据。这个"一一对应"的关系是后续设计幂等机制和一致性保障的理论基础。

```java
// 凭证模型设计——记录资金流动的核心数据结构
@Entity

    @Column(name = "payee_account")
    private String payeeAccount;        // 收款方账户

    @Column(name = "amount")
    private BigDecimal amount;          // 金额
```

### 3.2 步骤二：支付预下单与状态机驱动的交易流程

支付交易的核心处理逻辑通常采用状态机模型驱动，典型的处理链路如下：

1. **参数校验与风控检测**：请求到达支付系统后，首先进行参数合法性校验，并调用风控能力对本次交易进行风险评估。
2. **创建订单记录（预下单）**：在本地数据库中创建支付订单记录，初始状态设置为"已创建"或"待支付"，遵循**先落库、再对外交互**的设计原则。
3. **调用支付渠道预下单接口**：向银行或第三方支付渠道发起预下单请求，获取支付凭证。
4. **更新本地订单状态**：根据渠道预下单结果更新状态。
5. **支付结果的获取与状态终态流转**：通过异步回调或主动查询获取最终支付结果。

```java
// 支付核心状态机设计
public enum PaymentStatus {
    CREATED("已创建"),
    INITIALIZED("已完成渠道预下单"),
    PAYING("支付中"),
    SUCCESS("支付成功"),
    FAILED("支付失败"),
    CLOSED("已关闭"),
    UNKNOWN("状态未知");

    private final String desc;
    PaymentStatus(String desc) { this.desc = desc; }

    // 状态流转规则表——集中定义所有合法流转路径
    private static final Map<PaymentStatus, Set<PaymentStatus>> TRANSITIONS = new EnumMap<>(PaymentStatus.class);

    static {
        TRANSITIONS.put(CREATED, EnumSet.of(INITIALIZED, CLOSED));
        TRANSITIONS.put(INITIALIZED, EnumSet.of(PAYING, CLOSED));
        TRANSITIONS.put(PAYING, EnumSet.of(SUCCESS, FAILED, UNKNOWN));
        TRANSITIONS.put(UNKNOWN, EnumSet.of(SUCCESS, FAILED)); // 未知状态查询确认后流转到终态
        // SUCCESS / FAILED / CLOSED 是终态，不设置流出边
    }

    public boolean canTransitTo(PaymentStatus target) {
        Set<PaymentStatus> allowed = TRANSITIONS.getOrDefault(this, Collections.emptySet());
        return allowed.contains(target);
    }
}

// 支付订单实体
@Entity
@Table(name = "payment_order")
public class PaymentOrder {
    @Id
    private Long id;

    @Column(name = "order_id", unique = true)
    private String orderId;

    @Column(name = "biz_order_id")
    private String bizOrderId;          // 业务订单号（幂等键）

    @Enumerated(EnumType.STRING)
    private PaymentStatus status;

    private BigDecimal amount;
    private String currency;
    private String channelCode;
    private String channelOrderId;      // 渠道侧订单号
    private String userId;
    private String merchantId;

    @Version
    private Long version;               // 乐观锁版本号

    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    private LocalDateTime expireTime;   // 支付超时时间

    // 状态流转方法——内置合法性校验
    public void transitTo(PaymentStatus target) {
        if (!this.status.canTransitTo(target)) {
            throw new IllegalPaymentStateTransitionException(
                    String.format("支付单[%s]不允许从[%s]流转到[%s]", orderId, status, target));
        }
        this.status = target;
        this.updateTime = LocalDateTime.now();
    }

    // 幂等的成功处理——已经是成功状态时直接返回
    public boolean tryMarkSuccess(String channelOrderId) {
        if (this.status == PaymentStatus.SUCCESS) {
            return false; // 已是终态，幂等放行
        }
        transitTo(PaymentStatus.SUCCESS);
        this.channelOrderId = channelOrderId;
        return true;
    }
}
```

### 3.3 步骤三：三态化处理——支付领域幂等与容错设计的核心方法论

支付系统设计中一个极其重要的设计原则是：**对下游依赖（尤其是支付渠道）的调用结果，必须做三态化处理，而不是简单的二元成功/失败处理**。

**问题的本质**：当系统调用支付渠道发起扣款请求后，网络超时是常见的异常场景。此时系统面临一个根本性的不确定问题——**扣款请求究竟是没有到达渠道、到达渠道但未处理、还是已经在渠道侧处理成功只是响应没有返回**。

**常见的错误做法**：将超时情况直接当作失败处理——这是资损事故的高发根源之一。

**正确的设计方法——三态设计**：将调用结果明确区分为三种状态：**成功、失败、未知（不确定）**。

```java
// 三态化处理核心实现
public class PaymentChannelInvoker {

    private final ChannelClient channelClient;
    private final PaymentOrderRepository orderRepository;
    private final ChannelQueryScheduler queryScheduler;

    // 调用支付渠道并做三态化结果处理
    public PaymentCallResult pay(PaymentOrder order) {
        try {
            ChannelResponse response = channelClient.pay(buildChannelRequest(order));

            if (response.isSuccess()) {
                order.transitTo(PaymentStatus.SUCCESS);
                order.setChannelOrderId(response.getChannelOrderId());
                orderRepository.save(order);
                return PaymentCallResult.success(response.getChannelOrderId());
            } else if (response.isDefinitelyFailed()) {
                // 渠道明确返回业务失败（如余额不足、卡号错误）
                order.transitTo(PaymentStatus.FAILED);
                orderRepository.save(order);
                return PaymentCallResult.failed(response.getErrorCode(), response.getErrorMsg());
            } else {
                // 渠道返回了处理中等非终态状态，也应视为UNKNOWN
                order.transitTo(PaymentStatus.UNKNOWN);
                orderRepository.save(order);
                queryScheduler.scheduleQuery(order.getOrderId());
                return PaymentCallResult.unknown("渠道处理中");
            }

        } catch (SocketTimeoutException | ConnectTimeoutException e) {
            // 关键：网络超时绝对不能直接判定为失败
            order.transitTo(PaymentStatus.UNKNOWN);
            orderRepository.save(order);
            queryScheduler.scheduleQuery(order.getOrderId());
            return PaymentCallResult.unknown("网络超时");

        } catch (ChannelSystemException e) {
            // 渠道系统异常（如渠道内部错误），同样视为UNKNOWN
            order.transitTo(PaymentStatus.UNKNOWN);
            orderRepository.save(order);
            queryScheduler.scheduleQuery(order.getOrderId());
            return PaymentCallResult.unknown("渠道系统异常: " + e.getMessage());
        }
    }
}

// UNKNOWN状态的主动查询补偿任务
@Component
public class UnknownOrderQueryScheduler {

    private final PaymentOrderRepository orderRepository;
    private final ChannelClient channelClient;

    // 定时扫描UNKNOWN状态的订单，主动查询渠道确认真实状态
    @Scheduled(fixedRate = 5000) // 每5秒执行一次
    public void queryUnknownOrders() {
        List<PaymentOrder> unknownOrders = orderRepository.findByStatus(PaymentStatus.UNKNOWN);

        for (PaymentOrder order : unknownOrders) {
            try {
                ChannelQueryResult queryResult = channelClient.queryStatus(
                        order.getChannelCode(), order.getOrderId());

                if (queryResult.isConfirmedSuccess()) {
                    order.transitTo(PaymentStatus.SUCCESS);
                    order.setChannelOrderId(queryResult.getChannelOrderId());
                    orderRepository.save(order);
                    // 触发支付成功后的后续流程（通知业务方、更新账户等）
                    paymentSuccessHandler.handle(order);

                } else if (queryResult.isConfirmedFailed()) {
                    order.transitTo(PaymentStatus.FAILED);
                    orderRepository.save(order);

                } else {
                    // 仍然无法确认，检查是否超过最大等待时间
                    if (isExceedMaxWaitTime(order)) {
                        escalateToManualReview(order);
                    }
                    // 否则保持UNKNOWN，等待下一轮查询
                }
            } catch (Exception e) {
                // 查询本身也可能失败，记录日志但不改变订单状态
                log.warn("查询UNKNOWN订单[{}]状态失败", order.getOrderId(), e);
            }
        }
    }

    private boolean isExceedMaxWaitTime(PaymentOrder order) {
        return Duration.between(order.getCreateTime(), LocalDateTime.now()).toMinutes() > 30;
    }

    private void escalateToManualReview(PaymentOrder order) {
        // 超过最大等待时间后升级为人工审核
        manualReviewService.createReviewTicket(order, "UNKNOWN状态超时未收敛");
    }
}
```

### 3.4 步骤四：接口幂等设计——凭证产生与传递环节的幂等保障

凡是涉及**凭证产生和传递**的接口，都必须在设计阶段就充分考虑幂等性。

```java
// 基于幂等键的支付幂等控制
@Service
public class IdempotentPaymentService {

    private final PaymentOrderRepository orderRepository;
    private final PaymentChannelInvoker channelInvoker;

    @Transactional
    public PaymentResult createAndPay(PaymentRequest request) {
        // 1. 幂等检查：使用业务订单号 + 请求类型作为幂等键
        String idempotentKey = request.getBizOrderId() + ":" + request.getRequestType();
        PaymentOrder existingOrder = orderRepository.findByIdempotentKey(idempotentKey);

        if (existingOrder != null) {
            // 已存在相同幂等键的订单，直接返回已有结果
            return buildResultFromExisting(existingOrder);
        }

        // 2. 创建支付订单（先落库）
        PaymentOrder order = new PaymentOrder();
        order.setOrderId(generateOrderId());
        order.setBizOrderId(request.getBizOrderId());
        order.setIdempotentKey(idempotentKey);
        order.setAmount(request.getAmount());
        order.setCurrency(request.getCurrency());
        order.setStatus(PaymentStatus.CREATED);
        order.setCreateTime(LocalDateTime.now());
        order.setExpireTime(LocalDateTime.now().plusMinutes(30));

        try {
            orderRepository.save(order); // 唯一索引保证并发场景下的幂等
        } catch (DuplicateKeyException e) {
            // 并发场景下唯一索引冲突，重新查询已有记录
            existingOrder = orderRepository.findByIdempotentKey(idempotentKey);
            return buildResultFromExisting(existingOrder);
        }

        // 3. 执行支付渠道调用
        PaymentCallResult callResult = channelInvoker.pay(order);
        return buildResult(order, callResult);
    }

    private PaymentResult buildResultFromExisting(PaymentOrder existingOrder) {
        switch (existingOrder.getStatus()) {
            case SUCCESS:
                return PaymentResult.success(existingOrder.getOrderId());
            case FAILED:
            case CLOSED:
                return PaymentResult.failed(existingOrder.getOrderId(), "交易已关闭");
            default:
                // CREATED / INITIALIZED / PAYING / UNKNOWN 等中间态
                return PaymentResult.processing(existingOrder.getOrderId());
        }
    }
}
```

### 3.5 步骤五：凭证一致性保障——避免定时任务扫描引发的数据不一致

凭证的生成除了在经济活动发生的同步/异步路径中直接触发外，另一种常见方式是**通过定时任务扫描数据库中相应的业务数据状态**。这种方式存在一个容易被忽视的陷阱：**如果定时任务扫描时读取的是数据库的从库（读库），而主库到从库之间存在主从复制延迟，可能导致定时任务读到尚未同步的旧数据状态**。

```java
// 凭证一致性保障：定时任务读取主库 + 幂等处理
@Component
public class VoucherConsistencyTask {

    // 关键配置：使用主库数据源，避免主从延迟导致的数据不一致
    @Qualifier("masterDataSource")
    private final PaymentOrderRepository masterOrderRepository;

    private final PaymentVoucherRepository voucherRepository;

    @Scheduled(fixedRate = 60000) // 每分钟扫描一次
    public void checkAndGenerateVouchers() {
        // 查询已支付成功但尚未生成凭证的订单（从主库读取）
        List<PaymentOrder> ordersWithoutVoucher =
                masterOrderRepository.findSuccessOrdersWithoutVoucher();

        for (PaymentOrder order : ordersWithoutVoucher) {
            try {
                generateVoucherIdempotently(order);

                log.error("为订单[{}]生成凭证失败", order.getOrderId(), e);
            }
        }

    // 幂等的凭证生成：重复调用不会产生重复凭证
    private void generateVoucherIdempotently(PaymentOrder order) {
        String voucherNo = "V" + order.getOrderId(); // 基于订单号生成确定性的凭证号

        // 通过唯一索引保证幂等
        PaymentVoucher existingVoucher = voucherRepository.findByVoucherNo(voucherNo);
        if (existingVoucher != null) {
            return; // 凭证已存在，幂等返回
        }

        PaymentVoucher voucher = new PaymentVoucher();
        voucher.setVoucherNo(voucherNo);
        voucher.setBizOrderId(order.getBizOrderId());
        voucher.setVoucherType(VoucherType.PAY);
        voucher.setAmount(order.getAmount());
        voucher.setCurrency(order.getCurrency());
        voucher.setStatus(VoucherStatus.SUCCESS);
        voucher.setCreateTime(LocalDateTime.now());

        try {
            voucherRepository.save(voucher);
        } catch (DuplicateKeyException e) {
            // 并发场景的兜底，唯一索引保证不重复
            log.info("凭证[{}]已被并发创建", voucherNo);
```

```java
// 支付路由引擎
@Service
public class PaymentRouteEngine {

    private final List<RouteRuleEvaluator> ruleEvaluators;
    private final ChannelHealthMonitor channelHealthMonitor;

    public ChannelRoute selectChannel(PaymentRequest request) {
        // 1. 获取该交易类型下所有可用渠道
        List<ChannelConfig> candidates = channelConfigService.getAvailableChannels(
                request.getPaymentMethod(), request.getCurrency());

        // 2. 过滤掉不可用的渠道
        candidates = candidates.stream()
                .filter(c -> channelHealthMonitor.isHealthy(c.getChannelCode()))
                .filter(c -> isAmountInRange(c, request.getAmount()))
                .collect(Collectors.toList());

        if (candidates.isEmpty()) {
            throw new NoAvailableChannelException("无可用支付渠道");
        }

        // 3. 按路由规则进行评分排序
        List<ChannelScore> scoredChannels = candidates.stream()
                .map(c -> scoreChannel(c, request))
                .sorted(Comparator.comparingDouble(ChannelScore::getTotalScore).reversed())
                .collect(Collectors.toList());

        // 4. 选择得分最高的渠道
        return new ChannelRoute(scoredChannels.get(0).getChannelConfig());
    }

    private ChannelScore scoreChannel(ChannelConfig channel, PaymentRequest request) {
        double score = 0.0;

        // 成功率权重：40%
        double successRate = channelHealthMonitor.getSuccessRate(
                channel.getChannelCode(), Duration.ofMinutes(30));
        score += successRate * 0.4;

        // 费率权重：30%（费率越低得分越高）
        double feeRate = channel.getFeeRate(request.getPaymentMethod());
        score += (1.0 - feeRate) * 0.3;

        // 响应延迟权重：15%（延迟越低得分越高）
        double avgLatency = channelHealthMonitor.getAvgLatency(channel.getChannelCode());
        score += Math.max(0, (1.0 - avgLatency / 5000.0)) * 0.15;

        // 渠道偏好权重：15%（如用户常用渠道加分）
        if (isUserPreferredChannel(request.getUserId(), channel.getChannelCode())) {
            score += 0.15;
        }

        return new ChannelScore(channel, score);
    }
}

@Component
public class ChannelHealthMonitor {

    private final MeterRegistry meterRegistry;
    // 使用滑动窗口统计各渠道的成功率和延迟
    private final Map<String, SlidingWindowCounter> successCounters = new ConcurrentHashMap<>();
    private final Map<String, SlidingWindowCounter> totalCounters = new ConcurrentHashMap<>();

    public void recordResult(String channelCode, boolean success, long latencyMs) {
        totalCounters.computeIfAbsent(channelCode, k -> new SlidingWindowCounter(Duration.ofMinutes(30)))
                .increment();
        if (success) {
            successCounters.computeIfAbsent(channelCode, k -> new SlidingWindowCounter(Duration.ofMinutes(30)))
                    .increment();
        }
        meterRegistry.timer("channel.latency", "channel", channelCode)
                .record(latencyMs, TimeUnit.MILLISECONDS);
    }

    public double getSuccessRate(String channelCode, Duration window) {
        long total = totalCounters.getOrDefault(channelCode, SlidingWindowCounter.EMPTY).getCount();
        long success = successCounters.getOrDefault(channelCode, SlidingWindowCounter.EMPTY).getCount();
        return total > 0 ? (double) success / total : 1.0;
    }

    public boolean isHealthy(String channelCode) {
        double successRate = getSuccessRate(channelCode, Duration.ofMinutes(5));
        // 近5分钟成功率低于50%判定为不健康
        return successRate >= 0.5;
    }
}
```

```java
// 对账核心服务
@Service
public class ReconciliationService {

    private final PaymentOrderRepository localOrderRepository;
    private final ChannelBillClient channelBillClient;
    private final ReconciliationDiffRepository diffRepository;

    // 每日对账主流程
    public ReconciliationReport reconcile(LocalDate billDate, String channelCode) {
        // 1. 获取本方流水
        List<PaymentOrder> localRecords = localOrderRepository
                .findSuccessOrdersByDateAndChannel(billDate, channelCode);

        // 2. 获取渠道账单
        List<ChannelBillRecord> channelBill = channelBillClient.fetchBill(billDate, channelCode);

        // 3. 构建渠道账单索引
        Map<String, ChannelBillRecord> channelBillMap = channelBill.stream()
                .collect(Collectors.toMap(ChannelBillRecord::getOrderId, r -> r,
                        (r1, r2) -> r2)); // 处理可能的重复记录

        List<ReconciliationDiff> diffs = new ArrayList<>();

        // 4. 正向核对：以本方流水为基准
        for (PaymentOrder local : localRecords) {
            ChannelBillRecord channelRecord = channelBillMap.remove(local.getOrderId());

            if (channelRecord == null) {
                // 本方有记录，渠道无记录——长款
                diffs.add(ReconciliationDiff.builder()
                        .diffType(DiffType.LOCAL_ONLY)
                        .orderId(local.getOrderId())
                        .localAmount(local.getAmount())
                        .priority(DiffPriority.HIGH)
                        .build());

            } else if (!amountsMatch(local.getAmount(), channelRecord.getAmount())) {
                // 金额不一致
                diffs.add(ReconciliationDiff.builder()
                        .diffType(DiffType.AMOUNT_MISMATCH)
                        .orderId(local.getOrderId())
                        .localAmount(local.getAmount())
                        .channelAmount(channelRecord.getAmount())
                        .priority(DiffPriority.CRITICAL)
                        .build());

            } else if (!statusMatch(local.getStatus(), channelRecord.getStatus())) {
                // 状态不一致
                diffs.add(ReconciliationDiff.builder()
                        .diffType(DiffType.STATUS_MISMATCH)
                        .orderId(local.getOrderId())
                        .localStatus(local.getStatus().name())
                        .channelStatus(channelRecord.getStatus())
                        .priority(DiffPriority.HIGH)
                        .build());
            }
        }

        // 5. 反向核对：渠道有记录但本方无记录——短款
        for (ChannelBillRecord remaining : channelBillMap.values()) {
            diffs.add(ReconciliationDiff.builder()
                    .diffType(DiffType.CHANNEL_ONLY)
                    .orderId(remaining.getOrderId())
                    .channelAmount(remaining.getAmount())
                    .priority(DiffPriority.CRITICAL) // 短款是最严重的差异
                    .build());
        }

        // 6. 持久化差异记录并触发告警
        diffRepository.saveAll(diffs);
        if (!diffs.isEmpty()) {
            alertService.sendReconciliationAlert(billDate, channelCode, diffs);
        }

        return new ReconciliationReport(billDate, channelCode,
                localRecords.size(), channelBill.size(), diffs);
    }

    private boolean amountsMatch(BigDecimal local, BigDecimal channel) {
        return local.compareTo(channel) == 0;
    }
}
```

```java
public class AssetLossClassification {

    // 理论资损：故障影响到的最大可能金额
    public BigDecimal calculateTheoreticalLoss(IncidentContext incident) {
        // 基于故障影响的订单范围和金额计算
        List<PaymentOrder> affectedOrders = orderRepository.findByTimeRange(
                incident.getStartTime(), incident.getEndTime());
        return affectedOrders.stream()
                .map(PaymentOrder::getAmount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
    }

    // 实际资损：经过追偿后的实际损失金额
    public BigDecimal calculateActualLoss(IncidentContext incident) {
        BigDecimal theoretical = calculateTheoreticalLoss(incident);
        BigDecimal recovered = recoveryService.getRecoveredAmount(incident.getIncidentId());
        return theoretical.subtract(recovered);
    }

    // 定级：取高原则
    public IncidentLevel classifyLevel(BigDecimal theoreticalLoss, BigDecimal actualLoss) {
        BigDecimal maxLoss = theoreticalLoss.max(actualLoss);

        if (maxLoss.compareTo(BigDecimal.valueOf(1000000)) >= 0) {
            return IncidentLevel.P0; // 百万级以上
        } else if (maxLoss.compareTo(BigDecimal.valueOf(100000)) >= 0) {
            return IncidentLevel.P1; // 十万级
        } else if (maxLoss.compareTo(BigDecimal.valueOf(10000)) >= 0) {
            return IncidentLevel.P2; // 万级
        } else {
            return IncidentLevel.P3; // 千级及以下
        }
    }
}
```

```java
// 退款服务——支持全额退款和部分退款
@Service
public class RefundService {

    private final PaymentOrderRepository orderRepository;
    private final RefundOrderRepository refundOrderRepository;
    private final ChannelClient channelClient;

    @Transactional
    public RefundResult refund(RefundRequest request) {
        // 1. 查询原支付订单
        PaymentOrder originalOrder = orderRepository.findByOrderId(request.getOriginalOrderId());
        if (originalOrder == null || originalOrder.getStatus() != PaymentStatus.SUCCESS) {
            throw new IllegalRefundException("原订单不存在或未支付成功");
        }

        // 2. 校验退款金额
        BigDecimal totalRefunded = refundOrderRepository.sumRefundedAmount(request.getOriginalOrderId());
        BigDecimal remainingRefundable = originalOrder.getAmount().subtract(totalRefunded);

        if (request.getRefundAmount().compareTo(remainingRefundable) > 0) {
            throw new RefundAmountExceededException(
                    String.format("退款金额[%s]超出可退金额[%s]",
                            request.getRefundAmount(), remainingRefundable));
        }

        // 3. 创建退款单（先落库）
        RefundOrder refundOrder = new RefundOrder();
        refundOrder.setRefundOrderId(generateRefundOrderId());
        refundOrder.setOriginalOrderId(request.getOriginalOrderId());
        refundOrder.setRefundAmount(request.getRefundAmount());
        refundOrder.setRefundReason(request.getReason());
        refundOrder.setStatus(RefundStatus.CREATED);
        refundOrder.setChannelCode(originalOrder.getChannelCode());
        refundOrderRepository.save(refundOrder);

        // 4. 调用渠道退款接口
        try {
            ChannelRefundResponse response = channelClient.refund(
                    originalOrder.getChannelCode(),
                    originalOrder.getChannelOrderId(),
                    refundOrder.getRefundOrderId(),
                    request.getRefundAmount());

            if (response.isSuccess()) {
                refundOrder.setStatus(RefundStatus.SUCCESS);
            } else if (response.isDefinitelyFailed()) {
                refundOrder.setStatus(RefundStatus.FAILED);
            } else {
                refundOrder.setStatus(RefundStatus.UNKNOWN);
                // 调度查询任务确认最终状态
            }
        } catch (Exception e) {
            refundOrder.setStatus(RefundStatus.UNKNOWN);
        }

        refundOrderRepository.save(refundOrder);

        // 5. 生成退款凭证
        if (refundOrder.getStatus() == RefundStatus.SUCCESS) {
            voucherService.createRefundVoucher(refundOrder);
        }

        return new RefundResult(refundOrder.getRefundOrderId(), refundOrder.getStatus());
    }
}
```

## 四、异常处理与容错机制

### 4.1 状态未知场景的兜底处理机制

除了主动查询补偿机制外，还需要设置合理的时间窗口和升级机制——如果经过多次重试查询依然无法确认交易的真实状态，且超过预设的时间阈值，应当触发人工介入流程。

### 4.2 渠道故障的降级与切换

成熟的支付系统架构通常会对接多个支付渠道，具备渠道路由和故障自动切换的能力——当某个渠道出现异常时，能够将流量自动切换到备用渠道。如上文PaymentRouteEngine中ChannelHealthMonitor的实现所示。

### 4.3 退款与冲正的补偿机制

退款/冲正操作本身也需要具备幂等性；需要有明确的状态机约束退款/冲正只能在特定的原交易状态下发起；需要记录完整的退款/冲正凭证。

### 4.4 定时任务与批处理的容错设计

```java
@Component
public class IdempotentTaskExecutor {

    @Transactional
    public void executeWithIdempotency(String taskId, String batchKey, Runnable task) {
        // 尝试插入执行记录，通过唯一索引保证同一批次不重复执行
        TaskExecutionRecord record = new TaskExecutionRecord();
        record.setTaskId(taskId);
        record.setBatchKey(batchKey);
        record.setStatus(TaskStatus.RUNNING);
        record.setStartTime(LocalDateTime.now());

        try {
            taskRecordRepository.save(record);
        } catch (DuplicateKeyException e) {
            // 该批次已被执行过
            TaskExecutionRecord existing = taskRecordRepository.findByBatchKey(batchKey);
            if (existing.getStatus() == TaskStatus.COMPLETED) {
                log.info("批次[{}]已执行完成，跳过", batchKey);
                return;
            }
            // 如果是RUNNING状态，可能是上次执行中断，需要判断是否超时后重新执行
            if (existing.getStatus() == TaskStatus.RUNNING
                    && isTimeout(existing.getStartTime())) {
                // 超时后允许重新执行
                taskRecordRepository.updateStatus(batchKey, TaskStatus.TIMEOUT);
            } else {
                return;
            }
        }

        try {
            task.run();
            taskRecordRepository.updateStatus(batchKey, TaskStatus.COMPLETED);
        } catch (Exception e) {
            taskRecordRepository.updateStatus(batchKey, TaskStatus.FAILED);
            throw e;
        }
    }
}
```

## 五、性能优化

### 5.1 核心链路的同步与异步分离

支付主链路（用户发起到获得支付结果反馈）应尽量保持轻量和快速响应，将非关键路径的处理通过异步消息的方式解耦出主链路之外。

### 5.2 状态查询接口的性能保障

三态化设计要求对未知状态的交易进行主动查询确认，查询类接口需要具备高可用保障能力，同时可以对短时间内的重复查询请求做合并或限流处理。

### 5.3 对账处理的批量化与增量化

对账涉及的数据量通常很大，通常采用增量对账的方式，通过缩小每次核对的处理范围来控制整体耗时。

### 5.4 高并发场景下账户余额更新的锁竞争优化

如前文3.10节所述，使用乐观锁替代悲观锁，对热点账户采用分段计数方式分散写入热点。

## 六、最佳实践与总结

### 6.1 设计原则总结

1. **三态化处理是支付系统区别于普通业务系统的核心设计原则**：任何对外部依赖的调用，都必须清晰区分成功、失败、未知三种结果，未知状态绝不能等同于失败处理。
2. **凭证与经济活动必须一一对应**：这是保障资金安全审计能力的基础。
3. **先落库、再交互**：任何对外部渠道的调用之前，先在本地持久化交易意图和初始状态。
4. **核对设计先行，而非事后补救**：对账方案应该在业务设计阶段就一并考虑。
5. **资金链路优先复用，谨慎新建**：新建资金链路的隐性成本很高。
6. **支付路由智能化**：基于成功率、费率、延迟等多维指标进行动态路由决策。
7. **幂等设计全覆盖**：凡涉及凭证产生和资金变动的接口必须具备幂等性。

### 6.2 常见陷阱

- **将网络超时等同于失败处理**：这是支付系统资损事故的高发根源。
- **重试逻辑导致的凭证与经济活动不匹配**：业务系统内部的重试或循环逻辑，如果没有仔细设计幂等边界，容易导致凭证的重复发送。
- **测试环境流量误入生产环境**：Mock 数据或测试专用逻辑意外在生产环境生效。
- **定时任务读从库导致的数据不一致**：主从复制延迟被忽视。
- **对账机制缺失或流于形式**：只是简单核对总金额而不做逐笔明细核对。
- **退款金额未做累计校验**：多次部分退款的总额超出原交易金额。
- **渠道故障未做自动降级**：单一渠道故障导致全部支付不可用。

### 6.3 演进方向

- **风险敞口的实时化度量**：向实时监控资金风险敞口、提前预警异常资金流动模式演进。
- **对账能力的智能化**：引入统计分析和异常检测手段。
- **多渠道智能路由**：从静态配置向基于多维指标的动态智能路由演进。
- **资金安全体系化建设**：从需求设计到上线运维的全生命周期建立体系化的质量保障机制。
- **区块链技术在对账场景的应用**：利用分布式账本技术实现多方实时对账，减少对账差异的发生。

## 七、全链路实战案例

前文从架构设计和核心方法论的角度阐述了支付交易系统的设计原则。本节通过三个端到端的全链路实战案例，将上述设计原则落地为可运行的代码实现，每个案例均包含完整 Java 代码、异常处理、日志输出和幂等控制。

### 7.1 案例一：用户下单支付全链路

**场景描述**：用户在收银台选择支付方式后，系统完成创建支付单 -> 调用支付渠道 -> 银行扣款 -> 异步回调 -> 状态同步的完整链路。

**链路流程图**：

```
用户收银台
  │
  ▼
CashierController.choosePayMethod()   ← 选择支付方式（微信/支付宝/银行卡）
  │
  ▼
PaymentFacade.createAndPay()          ← 创建支付单 + 幂等控制
  │
  ├──► PaymentOrderService.createOrder()       ← 先落库（CREATED）
  │
  ├──► PaymentChannelInvoker.invokePay()       ← 调用渠道（三态化处理）
  │       │
  │       ├── SUCCESS → 更新本地状态 → 返回成功
  │       ├── FAILED  → 更新本地状态 → 返回失败
  │       └── UNKNOWN → 调度查询补偿 → 返回处理中
  │
  ▼

  │
  ▼
PaymentCallbackController.handleCallback()     ← 验签 + 幂等 + 状态同步
  │
  ├──► PaymentCallbackService.processCallback()
  │       │
  │       ├── 幂等检查（重复回调直接返回）
  │       ├── 状态机流转校验
  │       ├── 更新支付单状态
  │       ├── 生成支付凭证
  │       └── 发送 MQ 通知业务方
  │
  ▼
业务方消费 MQ → 更新业务订单状态
```

```java
// ==================== 收银台控制器 ====================

/**
 * 收银台控制器——用户选择支付方式的统一入口
 */
@RestController
@RequestMapping("/cashier")
@Slf4j
public class CashierController {

    @Autowired
    private PaymentFacade paymentFacade;

    /**
     * 用户在收银台选择支付方式并发起支付
     *
     * 幂等控制：以 bizOrderId + payMethod 作为幂等键，
     * 同一业务订单重复发起支付时返回已有支付单状态，不会重复扣款。
     */
    @PostMapping("/pay")
    public ApiResponse<PaymentResult> pay(@RequestBody @Valid CashierPayRequest request) {
        log.info("收银台支付请求: bizOrderId={}, userId={}, payMethod={}, amount={}",
                request.getBizOrderId(), request.getUserId(),
                request.getPayMethod(), request.getAmount());

        try {
            PaymentResult result = paymentFacade.createAndPay(request);
            log.info("收银台支付请求处理完成: bizOrderId={}, paymentOrderId={}, status={}",
                    request.getBizOrderId(), result.getPaymentOrderId(), result.getStatus());
            return ApiResponse.success(result);

        } catch (PaymentBizException e) {
            log.warn("收银台支付业务异常: bizOrderId={}, code={}, msg={}",
                    request.getBizOrderId(), e.getCode(), e.getMessage());
            return ApiResponse.fail(e.getCode(), e.getMessage());

        } catch (Exception e) {
            log.error("收银台支付系统异常: bizOrderId={}", request.getBizOrderId(), e);
            return ApiResponse.fail("SYSTEM_ERROR", "系统异常，请稍后重试");
        }
    }
}

/**
 * 支付门面——编排创建支付单与调用渠道的完整流程
 */
@Service
@Slf4j
public class PaymentFacade {

    @Autowired
    private PaymentOrderService orderService;

    @Autowired
    private PaymentChannelInvoker channelInvoker;

    @Autowired
    private PaymentRouteEngine routeEngine;

    /**
     * 创建支付单并发起渠道扣款
     *
     * 幂等策略：
     *   1. 以 bizOrderId + payMethod 构造幂等键
     *   2. 数据库唯一索引兜底并发场景
     *   3. 已存在支付单时直接返回当前状态，不重复调用渠道
     */
    @Transactional
    public PaymentResult createAndPay(CashierPayRequest request) {
        // ---- 步骤1：幂等检查 ----
        String idempotentKey = request.getBizOrderId() + ":" + request.getPayMethod();
        PaymentOrder existingOrder = orderService.findByIdempotentKey(idempotentKey);

        if (existingOrder != null) {
            log.info("幂等命中: idempotentKey={}, existingOrderId={}, status={}",
                    idempotentKey, existingOrder.getOrderId(), existingOrder.getStatus());
            return buildResultFromExisting(existingOrder);
        }

        // ---- 步骤2：创建支付单（先落库） ----
        PaymentOrder order = orderService.createOrder(request, idempotentKey);
        log.info("支付单创建成功: orderId={}, bizOrderId={}, amount={}",
                order.getOrderId(), order.getBizOrderId(), order.getAmount());

        // ---- 步骤3：路由选择支付渠道 ----
        ChannelRoute route = routeEngine.selectChannel(
                PaymentRequest.builder()
                        .paymentMethod(request.getPayMethod())
                        .amount(request.getAmount())
                        .currency("CNY")
                        .userId(request.getUserId())
                        .build());
        order.setChannelCode(route.getChannelCode());
        orderService.save(order);

        // ---- 步骤4：调用渠道扣款（三态化处理） ----
        PaymentCallResult callResult;
        try {
            callResult = channelInvoker.invokePay(order);
        } catch (Exception e) {
            log.error("渠道扣款异常: orderId={}, channelCode={}", order.getOrderId(), order.getChannelCode(), e);
            // 渠道调用异常时标记为UNKNOWN，由查询补偿任务兜底
            orderService.transitStatus(order.getOrderId(), PaymentStatus.UNKNOWN);
            return PaymentResult.processing(order.getOrderId());
        }

        // ---- 步骤5：根据渠道返回结果更新本地状态 ----
        switch (callResult.getStatus()) {
            case SUCCESS:
                orderService.markSuccess(order.getOrderId(), callResult.getChannelOrderId());
                log.info("支付成功: orderId={}, channelOrderId={}", order.getOrderId(), callResult.getChannelOrderId());
                return PaymentResult.success(order.getOrderId());

            case FAILED:
                orderService.markFailed(order.getOrderId(), callResult.getErrorCode(), callResult.getErrorMsg());
                log.info("支付失败: orderId={}, errorCode={}, errorMsg={}",
                        order.getOrderId(), callResult.getErrorCode(), callResult.getErrorMsg());
                return PaymentResult.failed(order.getOrderId(), callResult.getErrorMsg());

            case UNKNOWN:
            default:
                log.warn("支付状态未知: orderId={}, reason={}", order.getOrderId(), callResult.getUnknownReason());
                return PaymentResult.processing(order.getOrderId());
        }
    }

    private PaymentResult buildResultFromExisting(PaymentOrder existing) {
        switch (existing.getStatus()) {
            case SUCCESS:
                return PaymentResult.success(existing.getOrderId());
            case FAILED:
            case CLOSED:
                return PaymentResult.failed(existing.getOrderId(), "交易已关闭");
            default:
                return PaymentResult.processing(existing.getOrderId());
        }
    }
}

/**
 * 支付单服务——负责支付单的创建、状态流转、持久化
 */
@Service
@Slf4j
public class PaymentOrderService {

    @Autowired
    private PaymentOrderRepository orderRepository;

    /**
     * 创建支付单——先落库原则
     * 幂等保障：idempotentKey 上建有唯一索引，并发插入时触发 DuplicateKeyException
     */
    @Transactional
    public PaymentOrder createOrder(CashierPayRequest request, String idempotentKey) {
        PaymentOrder order = new PaymentOrder();
        order.setOrderId(generateOrderId());
        order.setBizOrderId(request.getBizOrderId());
        order.setIdempotentKey(idempotentKey);
        order.setUserId(request.getUserId());
        order.setAmount(request.getAmount());
        order.setCurrency("CNY");
        order.setStatus(PaymentStatus.CREATED);
        order.setCreateTime(LocalDateTime.now());
        order.setExpireTime(LocalDateTime.now().plusMinutes(30));

        try {
            return orderRepository.save(order);
        } catch (DuplicateKeyException e) {
            // 并发场景：另一个线程已经创建了相同幂等键的支付单
            log.info("并发创建支付单冲突，回查已有记录: idempotentKey={}", idempotentKey);
            return orderRepository.findByIdempotentKey(idempotentKey);
        }
    }

    /**
     * 标记支付成功——乐观锁 + 状态机校验
     */
    @Transactional
    public boolean markSuccess(String orderId, String channelOrderId) {
        PaymentOrder order = orderRepository.findByOrderId(orderId);
        if (order == null) {
            log.error("标记成功时支付单不存在: orderId={}", orderId);
            throw new PaymentOrderNotFoundException("支付单不存在: " + orderId);
        }

        // 幂等：已经是成功状态则直接返回
        if (order.getStatus() == PaymentStatus.SUCCESS) {
            log.info("支付单已是成功状态，幂等返回: orderId={}", orderId);
            return false;
        }

        // 状态机校验
        if (!order.getStatus().canTransitTo(PaymentStatus.SUCCESS)) {
            log.error("非法状态流转: orderId={}, currentStatus={}, targetStatus=SUCCESS",
                    orderId, order.getStatus());
            throw new IllegalPaymentStateTransitionException(
                    String.format("支付单[%s]不允许从[%s]流转到[SUCCESS]", orderId, order.getStatus()));
        }

        order.transitTo(PaymentStatus.SUCCESS);
        order.setChannelOrderId(channelOrderId);
        orderRepository.save(order); // @Version 乐观锁兜底并发
        return true;
    }

    @Transactional
    public void markFailed(String orderId, String errorCode, String errorMsg) {
        PaymentOrder order = orderRepository.findByOrderId(orderId);
        if (order != null && order.getStatus().canTransitTo(PaymentStatus.FAILED)) {
            order.transitTo(PaymentStatus.FAILED);
            orderRepository.save(order);
        }
    }

    @Transactional
    public void transitStatus(String orderId, PaymentStatus target) {
        PaymentOrder order = orderRepository.findByOrderId(orderId);
        if (order != null && order.getStatus().canTransitTo(target)) {
            order.transitTo(target);
            orderRepository.save(order);
        }
    }

    public PaymentOrder findByIdempotentKey(String idempotentKey) {
        return orderRepository.findByIdempotentKey(idempotentKey);
    }

    public void save(PaymentOrder order) {
        orderRepository.save(order);
    }

    private String generateOrderId() {
        return "PAY" + System.currentTimeMillis() + ThreadLocalRandom.current().nextInt(1000, 9999);
    }
}

// ==================== 渠道调用器（三态化处理） ====================

/**
 * 支付渠道调用器——对外部渠道的调用结果做三态化处理
 */
@Component
@Slf4j
public class PaymentChannelInvoker {

    @Autowired
    private ChannelClient channelClient;

    @Autowired
    private UnknownOrderQueryScheduler queryScheduler;

    /**
     * 调用渠道扣款——三态化结果处理
     *
     * 关键原则：网络超时绝不等同于失败，必须标记为 UNKNOWN 并触发查询补偿
     */
    public PaymentCallResult invokePay(PaymentOrder order) {
        ChannelPayRequest channelRequest = ChannelPayRequest.builder()
                .outTradeNo(order.getOrderId())
                .channelCode(order.getChannelCode())
                .amount(order.getAmount())
                .currency(order.getCurrency())
                .subject("订单支付-" + order.getBizOrderId())
                .expireTime(order.getExpireTime())
                .build();

        try {
            log.info("调用渠道扣款: orderId={}, channelCode={}, amount={}",
                    order.getOrderId(), order.getChannelCode(), order.getAmount());

            ChannelPayResponse response = channelClient.pay(channelRequest);
            log.info("渠道扣款响应: orderId={}, channelCode={}, channelStatus={}, channelOrderId={}",
                    order.getOrderId(), order.getChannelCode(),
                    response.getChannelStatus(), response.getChannelOrderId());

            if (response.isSuccess()) {
                return PaymentCallResult.success(response.getChannelOrderId());

            } else if (response.isDefinitelyFailed()) {
                // 渠道明确返回业务失败（余额不足、卡号错误等）
                return PaymentCallResult.failed(response.getErrorCode(), response.getErrorMsg());

            } else {
                // 渠道返回处理中等非终态——视为UNKNOWN
                log.warn("渠道返回非终态: orderId={}, channelStatus={}", order.getOrderId(), response.getChannelStatus());
                queryScheduler.scheduleQuery(order.getOrderId());
                return PaymentCallResult.unknown("渠道处理中");
            }

        } catch (SocketTimeoutException e) {
            // 网络超时——核心：绝不判定为失败
            log.error("渠道扣款网络超时: orderId={}, channelCode={}", order.getOrderId(), order.getChannelCode(), e);
            queryScheduler.scheduleQuery(order.getOrderId());
            return PaymentCallResult.unknown("网络超时");

        } catch (ConnectException e) {
            // 连接被拒绝——渠道可能不可用
            log.error("渠道扣款连接失败: orderId={}, channelCode={}", order.getOrderId(), order.getChannelCode(), e);
            queryScheduler.scheduleQuery(order.getOrderId());
            return PaymentCallResult.unknown("连接失败");

        } catch (ChannelSystemException e) {
            // 渠道系统异常（如渠道内部5xx）
            log.error("渠道系统异常: orderId={}, channelCode={}", order.getOrderId(), order.getChannelCode(), e);
            queryScheduler.scheduleQuery(order.getOrderId());
            return PaymentCallResult.unknown("渠道系统异常: " + e.getMessage());

        } catch (Exception e) {
            // 其他未知异常——安全起见也标记为UNKNOWN
            log.error("渠道扣款未知异常: orderId={}", order.getOrderId(), e);
            queryScheduler.scheduleQuery(order.getOrderId());
            return PaymentCallResult.unknown("未知异常: " + e.getMessage());
        }
    }
}

/**
 * 支付回调控制器——接收渠道异步回调
 */
@RestController
@RequestMapping("/callback")
@Slf4j
public class PaymentCallbackController {

    @Autowired
    private PaymentCallbackService callbackService;

    /**
     * 渠道异步回调入口
     *
     * 幂等控制：渠道可能因网络重试多次发送同一回调，
     * 通过回调流水号唯一索引保证同一回调只处理一次。
     */
    @PostMapping("/pay/{channelCode}")
    public String handlePayCallback(@PathVariable String channelCode,
                                     @RequestBody String callbackBody,
                                     HttpServletRequest request) {
        String callbackId = request.getHeader("X-Callback-Serial-No");
        log.info("收到支付回调: channelCode={}, callbackId={}", channelCode, callbackId);

        try {
            CallbackProcessResult result = callbackService.processCallback(
                    channelCode, callbackBody, callbackId);

            // 向渠道返回成功接收标识，避免渠道反复重试
            return result.isSuccess() ? "SUCCESS" : "FAIL";

        } catch (Exception e) {
            log.error("支付回调处理异常: channelCode={}, callbackId={}", channelCode, callbackId, e);
            return "FAIL"; // 返回FAIL让渠道重试
        }
    }
}

/**
 * 回调处理服务——验签 + 幂等 + 状态同步 + 后续流程编排
 */
@Service
@Slf4j
public class PaymentCallbackService {

    @Autowired
    private PaymentOrderRepository orderRepository;

    @Autowired
    private CallbackRecordRepository callbackRecordRepository;

    @Autowired
    private PaymentVoucherRepository voucherRepository;

    @Autowired
    private ChannelSignatureVerifier signatureVerifier;

    @Autowired
    private RocketMQTemplate mqTemplate;

    /**
     * 处理渠道回调
     *
     * 幂等策略：
     *   1. 回调流水号（callbackId）入库唯一索引
     *   2. 支付单状态已是SUCCESS时直接返回（双重幂等保障）
     */
    @Transactional
    public CallbackProcessResult processCallback(String channelCode, String callbackBody, String callbackId) {
        // ---- 步骤1：记录回调流水（幂等控制） ----
        CallbackRecord record = new CallbackRecord();
        record.setCallbackId(callbackId);
        record.setChannelCode(channelCode);
        record.setCallbackBody(callbackBody);
        record.setReceiveTime(LocalDateTime.now());

        try {
            callbackRecordRepository.save(record);
        } catch (DuplicateKeyException e) {
            // 同一回调流水号已处理过，幂等返回
            log.info("回调幂等命中，跳过处理: callbackId={}", callbackId);
            return CallbackProcessResult.success("回调已处理");
        }

        // ---- 步骤2：验签 ----
        CallbackPayload payload;
        try {
            payload = signatureVerifier.verifyAndParse(channelCode, callbackBody);
        } catch (SignatureVerifyException e) {
            log.error("回调验签失败: channelCode={}, callbackId={}", channelCode, callbackId, e);
            return CallbackProcessResult.fail("验签失败");
        }

        // ---- 步骤3：查找本地支付单 ----
        PaymentOrder order = orderRepository.findByOrderId(payload.getOutTradeNo());
        if (order == null) {
            log.error("回调对应的支付单不存在: orderId={}, callbackId={}", payload.getOutTradeNo(), callbackId);
            return CallbackProcessResult.fail("支付单不存在");
        }

        // ---- 步骤4：幂等检查——已是终态则直接返回 ----
        if (order.getStatus() == PaymentStatus.SUCCESS) {
            log.info("支付单已成功，回调幂等返回: orderId={}", order.getOrderId());
            return CallbackProcessResult.success("支付单已成功");
        }

        // ---- 步骤5：状态机校验 + 状态流转 ----
        if (!order.getStatus().canTransitTo(PaymentStatus.SUCCESS)) {
            log.error("回调状态流转非法: orderId={}, currentStatus={}, callbackStatus=SUCCESS",
                    order.getOrderId(), order.getStatus());
            return CallbackProcessResult.fail("状态流转非法");
        }

        order.transitTo(PaymentStatus.SUCCESS);
        order.setChannelOrderId(payload.getChannelOrderId());
        orderRepository.save(order); // 乐观锁兜底并发
        log.info("回调状态同步成功: orderId={}, channelOrderId={}", order.getOrderId(), payload.getChannelOrderId());

        // ---- 步骤6：生成支付凭证（幂等） ----
        generateVoucherIdempotently(order);

        // ---- 步骤7：发送MQ通知业务方 ----
        PaymentSuccessMessage message = PaymentSuccessMessage.builder()
                .paymentOrderId(order.getOrderId())
                .bizOrderId(order.getBizOrderId())
                .amount(order.getAmount())
                .channelCode(order.getChannelCode())
                .successTime(LocalDateTime.now())
                .build();

        try {
            mqTemplate.syncSend("payment-success-topic", message);
            log.info("支付成功MQ发送成功: orderId={}, bizOrderId={}", order.getOrderId(), order.getBizOrderId());
        } catch (Exception e) {
            // MQ发送失败不影响回调返回，由本地消息表兜底重发
            log.error("支付成功MQ发送失败，将由本地消息表补偿: orderId={}", order.getOrderId(), e);
        }

        return CallbackProcessResult.success("回调处理成功");
    }

    /**
     * 幂等的凭证生成
     */
    private void generateVoucherIdempotently(PaymentOrder order) {
        String voucherNo = "V" + order.getOrderId();

        if (voucherRepository.findByVoucherNo(voucherNo) != null) {
            log.info("支付凭证已存在，幂等返回: voucherNo={}", voucherNo);
            return;
        }

        PaymentVoucher voucher = new PaymentVoucher();
        voucher.setVoucherNo(voucherNo);
        voucher.setBizOrderId(order.getBizOrderId());
        voucher.setVoucherType(VoucherType.PAY);
        voucher.setAmount(order.getAmount());
        voucher.setCurrency(order.getCurrency());
        voucher.setChannelCode(order.getChannelCode());
        voucher.setChannelSerialNo(order.getChannelOrderId());
        voucher.setStatus(VoucherStatus.SUCCESS);
        voucher.setCreateTime(LocalDateTime.now());

        try {
            voucherRepository.save(voucher);
            log.info("支付凭证生成成功: voucherNo={}, orderId={}", voucherNo, order.getOrderId());
        } catch (DuplicateKeyException e) {
            log.info("支付凭证并发创建冲突，已存在: voucherNo={}", voucherNo);
        }
    }
}

/**
 * 未知状态查询补偿调度器
 *
 * 对UNKNOWN状态的支付单定期主动查询渠道，收敛到终态
 */
@Component
@Slf4j
public class UnknownOrderQueryScheduler {

    @Autowired
    private PaymentOrderRepository orderRepository;

    @Autowired
    private ChannelClient channelClient;

    @Autowired
    private PaymentVoucherRepository voucherRepository;

    @Autowired
    private RocketMQTemplate mqTemplate;

    private static final int MAX_QUERY_RETRY = 10;
    private static final long MAX_WAIT_MINUTES = 30;

    /**
     * 对单个UNKNOWN订单发起查询（由查询调度器或MQ延迟队列触发）
     */
    @Transactional
    public void queryAndResolve(String orderId) {
        PaymentOrder order = orderRepository.findByOrderId(orderId);
        if (order == null || order.getStatus() != PaymentStatus.UNKNOWN) {
            log.info("查询补偿跳过: orderId={}, status={}", orderId,
                    order == null ? "NULL" : order.getStatus());
            return;
        }

        // 超时检查
        if (Duration.between(order.getCreateTime(), LocalDateTime.now()).toMinutes() > MAX_WAIT_MINUTES) {
            log.error("UNKNOWN状态超时未收敛，升级人工审核: orderId={}", orderId);
            escalateToManualReview(order);
            return;
        }

        try {
            ChannelQueryResult queryResult = channelClient.queryStatus(
                    order.getChannelCode(), order.getOrderId());
            log.info("渠道查询结果: orderId={}, channelStatus={}", orderId, queryResult.getStatus());

            if (queryResult.isConfirmedSuccess()) {
                // 确认成功——执行与回调相同的成功处理逻辑
                if (order.getStatus().canTransitTo(PaymentStatus.SUCCESS)) {
                    order.transitTo(PaymentStatus.SUCCESS);
                    order.setChannelOrderId(queryResult.getChannelOrderId());
                    orderRepository.save(order);
                    log.info("查询补偿确认成功: orderId={}, channelOrderId={}", orderId, queryResult.getChannelOrderId());

                    // 生成凭证 + 发送MQ
                    generateVoucherIdempotently(order);
                    sendSuccessMessage(order);
                }

            } else if (queryResult.isConfirmedFailed()) {
                if (order.getStatus().canTransitTo(PaymentStatus.FAILED)) {
                    order.transitTo(PaymentStatus.FAILED);
                    orderRepository.save(order);
                    log.info("查询补偿确认失败: orderId={}", orderId);
                }

            } else {
                // 仍未确认，记录日志等待下一轮查询
                log.warn("查询补偿仍未确认: orderId={}, channelStatus={}", orderId, queryResult.getStatus());
            }

        } catch (Exception e) {
            log.warn("查询补偿异常: orderId={}", orderId, e);
            // 查询失败不改变状态，等待下一轮
        }
    }

    private void generateVoucherIdempotently(PaymentOrder order) {
        String voucherNo = "V" + order.getOrderId();
        if (voucherRepository.findByVoucherNo(voucherNo) != null) {
            return;
        }
        PaymentVoucher voucher = new PaymentVoucher();
        voucher.setVoucherNo(voucherNo);
        voucher.setBizOrderId(order.getBizOrderId());
        voucher.setVoucherType(VoucherType.PAY);
        voucher.setAmount(order.getAmount());
        voucher.setCurrency(order.getCurrency());
        voucher.setStatus(VoucherStatus.SUCCESS);
        voucher.setCreateTime(LocalDateTime.now());
        try {
            voucherRepository.save(voucher);
        } catch (DuplicateKeyException ignored) {
            // 并发场景兜底
        }
    }

    private void sendSuccessMessage(PaymentOrder order) {
        try {
            mqTemplate.syncSend("payment-success-topic",
                    PaymentSuccessMessage.builder()
                            .paymentOrderId(order.getOrderId())
                            .bizOrderId(order.getBizOrderId())
                            .amount(order.getAmount())
                            .build());
        } catch (Exception e) {
            log.error("MQ发送失败，本地消息表补偿: orderId={}", order.getOrderId(), e);
        }
    }

    private void escalateToManualReview(PaymentOrder order) {
        log.error("升级人工审核: orderId={}, bizOrderId={}, amount={}",
                order.getOrderId(), order.getBizOrderId(), order.getAmount());
        // 创建人工审核工单...
    }

    public void scheduleQuery(String orderId) {
        // 将orderId投递到延迟队列，5秒后触发首次查询
        log.info("调度UNKNOWN查询: orderId={}", orderId);
    }
}
```

### 7.2 案例二：退款全链路

**场景描述**：用户发起退款申请后，系统完成退款单创建 -> 渠道退款 -> 回调处理 -> 资金到账 -> 对账的完整链路。

**链路流程图**：

```
用户/业务方
  │
  ▼
RefundController.applyRefund()                ← 退款申请入口
  │
  ▼
RefundFacade.executeRefund()                   ← 退款编排（幂等控制）
  │
  ├──► RefundOrderService.createRefundOrder()   ← 退款单创建（先落库）
  │       │
  │       ├── 校验原订单状态（必须SUCCESS）
  │       ├── 校验退款金额（累计退款不超原金额）
  │       └── 落库退款单（CREATED）
  │
  ├──► ChannelRefundInvoker.invokeRefund()      ← 调用渠道退款（三态化）
  │       │
  │       ├── SUCCESS → 更新退款单 → 生成退款凭证 → 通知业务方
  │       ├── FAILED  → 更新退款单 → 通知业务方退款失败
  │       └── UNKNOWN → 调度查询补偿
  │
  ▼
渠道异步回调
  │
  ▼
RefundCallbackService.processCallback()        ← 回调处理（幂等 + 状态同步）
  │
  ├── 验签
  ├── 幂等检查
  ├── 状态机流转
  ├── 生成退款凭证
  ├── 更新账户余额（退款入账）
  └── 通知业务方退款到账
  │
  ▼
日终对账（见案例三）
```

```java
/**

@RestController
@RequestMapping("/refund")
@Slf4j
public class RefundController {

    @Autowired
    private RefundFacade refundFacade;

    /**
     * 发起退款
     *
     * 幂等控制：以 originalOrderId + refundRequestId 作为幂等键，
     * 同一退款请求重复提交时返回已有退款单状态。
     */
    @PostMapping("/apply")
    public ApiResponse<RefundResult> applyRefund(@RequestBody @Valid RefundApplyRequest request) {

            RefundResult result = refundFacade.executeRefund(request);

        } catch (RefundBizException e) {
            log.warn("退款业务异常: originalOrderId={}, code={}, msg={}",
                    request.getOriginalOrderId(), e.getCode(), e.getMessage());
            return ApiResponse.fail(e.getCode(), e.getMessage());

        } catch (Exception e) {
            log.error("退款系统异常: originalOrderId={}", request.getOriginalOrderId(), e);
            return ApiResponse.fail("SYSTEM_ERROR", "系统异常，请稍后重试");
        }
    }
}

/**
 * 退款门面——编排退款单创建、渠道退款、回调处理的完整流程
 */
@Service
@Slf4j
public class RefundFacade {

    @Autowired
    private RefundOrderService refundOrderService;

    @Autowired
    private ChannelRefundInvoker channelInvoker;

    @Autowired
    private RefundUnknownQueryScheduler unknownQueryScheduler;

    /**
     * 执行退款
     *
     * 幂等策略：
     *   1. 以 originalOrderId + refundRequestId 构造幂等键
     *   2. 数据库唯一索引兜底并发
     *   3. 已存在退款单时返回当前状态，不重复调用渠道
     */
    @Transactional
    public RefundResult executeRefund(RefundApplyRequest request) {
        // ---- 步骤1：幂等检查 ----
        String idempotentKey = request.getOriginalOrderId() + ":" + request.getRefundRequestId();
        RefundOrder existingRefund = refundOrderService.findByIdempotentKey(idempotentKey);

        if (existingRefund != null) {
            log.info("退款幂等命中: idempotentKey={}, refundOrderId={}, status={}",
                    idempotentKey, existingRefund.getRefundOrderId(), existingRefund.getStatus());
            return buildResultFromExisting(existingRefund);
        }

        // ---- 步骤2：创建退款单（含原订单校验 + 金额校验） ----
        RefundOrder refundOrder = refundOrderService.createRefundOrder(request, idempotentKey);
        log.info("退款单创建成功: refundOrderId={}, originalOrderId={}, refundAmount={}",
                refundOrder.getRefundOrderId(), refundOrder.getOriginalOrderId(), refundOrder.getRefundAmount());

        // ---- 步骤3：调用渠道退款（三态化处理） ----
        ChannelRefundResult refundResult;
        try {
            refundResult = channelInvoker.invokeRefund(refundOrder);
        } catch (Exception e) {
            log.error("渠道退款异常: refundOrderId={}", refundOrder.getRefundOrderId(), e);
            refundOrderService.transitStatus(refundOrder.getRefundOrderId(), RefundStatus.UNKNOWN);
            unknownQueryScheduler.scheduleQuery(refundOrder.getRefundOrderId());
            return RefundResult.processing(refundOrder.getRefundOrderId());
        }

        // ---- 步骤4：根据渠道返回更新退款单状态 ----
        switch (refundResult.getStatus()) {
            case SUCCESS:
                refundOrderService.markSuccess(refundOrder.getRefundOrderId(), refundResult.getChannelRefundNo());
                log.info("退款成功: refundOrderId={}, channelRefundNo={}",
                        refundOrder.getRefundOrderId(), refundResult.getChannelRefundNo());
                return RefundResult.success(refundOrder.getRefundOrderId());

            case FAILED:
                refundOrderService.markFailed(refundOrder.getRefundOrderId(),
                        refundResult.getErrorCode(), refundResult.getErrorMsg());
                log.info("退款失败: refundOrderId={}, errorCode={}, errorMsg={}",
                        refundOrder.getRefundOrderId(), refundResult.getErrorCode(), refundResult.getErrorMsg());
                return RefundResult.failed(refundOrder.getRefundOrderId(), refundResult.getErrorMsg());

            case UNKNOWN:
            default:
                log.warn("退款状态未知: refundOrderId={}, reason={}",
                        refundOrder.getRefundOrderId(), refundResult.getUnknownReason());
                unknownQueryScheduler.scheduleQuery(refundOrder.getRefundOrderId());
                return RefundResult.processing(refundOrder.getRefundOrderId());
        }
    }

    private RefundResult buildResultFromExisting(RefundOrder existing) {
        switch (existing.getStatus()) {
            case SUCCESS:
                return RefundResult.success(existing.getRefundOrderId());
            case FAILED:
                return RefundResult.failed(existing.getRefundOrderId(), "退款失败");
            default:
                return RefundResult.processing(existing.getRefundOrderId());
        }
    }
}

/**
 * 退款单服务——退款单的创建、状态流转、金额校验
 */
@Service
@Slf4j
public class RefundOrderService {

    @Autowired
    private PaymentOrderRepository paymentOrderRepository;

    @Autowired
    private RefundOrderRepository refundOrderRepository;

    /**
     * 创建退款单
     *
     * 校验项：
     *   1. 原支付订单存在且状态为SUCCESS
     *   2. 退款金额不超过可退余额（原金额 - 已退金额）
     *   3. 幂等键唯一索引兜底并发
     */
    @Transactional
    public RefundOrder createRefundOrder(RefundApplyRequest request, String idempotentKey) {
        // ---- 校验原订单 ----
        PaymentOrder originalOrder = paymentOrderRepository.findByOrderId(request.getOriginalOrderId());
        if (originalOrder == null) {
            log.warn("退款失败：原订单不存在: originalOrderId={}", request.getOriginalOrderId());
            throw new RefundBizException("ORIGINAL_ORDER_NOT_FOUND", "原订单不存在");
        }
        if (originalOrder.getStatus() != PaymentStatus.SUCCESS) {
            log.warn("退款失败：原订单状态非成功: originalOrderId={}, status={}",
                    request.getOriginalOrderId(), originalOrder.getStatus());
            throw new RefundBizException("ORIGINAL_ORDER_NOT_SUCCESS", "原订单未支付成功");
        }

        // ---- 校验退款金额 ----
        BigDecimal totalRefunded = refundOrderRepository.sumRefundedAmountByOriginalOrderId(
                request.getOriginalOrderId());
        BigDecimal remainingRefundable = originalOrder.getAmount().subtract(totalRefunded);

        if (request.getRefundAmount().compareTo(remainingRefundable) > 0) {
            log.warn("退款失败：退款金额超出可退金额: refundAmount={}, remainingRefundable={}",
                    request.getRefundAmount(), remainingRefundable);
            throw new RefundBizException("REFUND_AMOUNT_EXCEEDED",
                    String.format("退款金额[%s]超出可退金额[%s]", request.getRefundAmount(), remainingRefundable));
        }

        // ---- 创建退款单（先落库） ----
        RefundOrder refundOrder = new RefundOrder();
        refundOrder.setRefundOrderId(generateRefundOrderId());
        refundOrder.setOriginalOrderId(request.getOriginalOrderId());
        refundOrder.setIdempotentKey(idempotentKey);
        refundOrder.setRefundAmount(request.getRefundAmount());
        refundOrder.setRefundReason(request.getReason());
        refundOrder.setChannelCode(originalOrder.getChannelCode());
        refundOrder.setChannelOrderId(originalOrder.getChannelOrderId());
        refundOrder.setStatus(RefundStatus.CREATED);
        refundOrder.setCreateTime(LocalDateTime.now());

        try {
            return refundOrderRepository.save(refundOrder);
        } catch (DuplicateKeyException e) {
            log.info("并发创建退款单冲突，回查已有记录: idempotentKey={}", idempotentKey);
            return refundOrderRepository.findByIdempotentKey(idempotentKey);
        }
    }

    /**
     * 标记退款成功——乐观锁 + 状态机校验
     */
    @Transactional
    public boolean markSuccess(String refundOrderId, String channelRefundNo) {
        RefundOrder refundOrder = refundOrderRepository.findByRefundOrderId(refundOrderId);
        if (refundOrder == null) {
            throw new RefundBizException("REFUND_ORDER_NOT_FOUND", "退款单不存在: " + refundOrderId);
        }

        // 幂等
        if (refundOrder.getStatus() == RefundStatus.SUCCESS) {
            log.info("退款单已成功，幂等返回: refundOrderId={}", refundOrderId);
            return false;
        }

        // 状态机校验
        if (!refundOrder.getStatus().canTransitTo(RefundStatus.SUCCESS)) {
            log.error("退款单非法状态流转: refundOrderId={}, current={}, target=SUCCESS",
                    refundOrderId, refundOrder.getStatus());
            throw new IllegalRefundStateTransitionException(
                    String.format("退款单[%s]不允许从[%s]流转到[SUCCESS]", refundOrderId, refundOrder.getStatus()));
        }

        refundOrder.transitTo(RefundStatus.SUCCESS);
        refundOrder.setChannelRefundNo(channelRefundNo);
        refundOrderRepository.save(refundOrder);
        return true;
    }

    @Transactional
    public void markFailed(String refundOrderId, String errorCode, String errorMsg) {
        RefundOrder refundOrder = refundOrderRepository.findByRefundOrderId(refundOrderId);
        if (refundOrder != null && refundOrder.getStatus().canTransitTo(RefundStatus.FAILED)) {
            refundOrder.transitTo(RefundStatus.FAILED);
            refundOrderRepository.save(refundOrder);
        }
    }

    @Transactional
    public void transitStatus(String refundOrderId, RefundStatus target) {
        RefundOrder refundOrder = refundOrderRepository.findByRefundOrderId(refundOrderId);
        if (refundOrder != null && refundOrder.getStatus().canTransitTo(target)) {
            refundOrder.transitTo(target);
            refundOrderRepository.save(refundOrder);
        }
    }

    public RefundOrder findByIdempotentKey(String idempotentKey) {
        return refundOrderRepository.findByIdempotentKey(idempotentKey);
    }

    private String generateRefundOrderId() {
        return "RFD" + System.currentTimeMillis() + ThreadLocalRandom.current().nextInt(1000, 9999);
    }
}

// ==================== 渠道退款调用器（三态化） ====================

/**
 * 渠道退款调用器——退款同样需要三态化处理
 */
@Component
@Slf4j
public class ChannelRefundInvoker {

    @Autowired
    private ChannelClient channelClient;

    /**
     * 调用渠道退款接口
     *
     * 退款的三态化与支付同等重要：
     *   超时不等于退款失败——可能渠道已退款成功只是响应未返回
     */
    public ChannelRefundResult invokeRefund(RefundOrder refundOrder) {
        ChannelRefundRequest channelRequest = ChannelRefundRequest.builder()
                .outRefundNo(refundOrder.getRefundOrderId())
                .channelCode(refundOrder.getChannelCode())
                .channelOrderId(refundOrder.getChannelOrderId())
                .refundAmount(refundOrder.getRefundAmount())
                .build();

        try {
            log.info("调用渠道退款: refundOrderId={}, channelCode={}, refundAmount={}",
                    refundOrder.getRefundOrderId(), refundOrder.getChannelCode(), refundOrder.getRefundAmount());

            ChannelRefundResponse response = channelClient.refund(channelRequest);
            log.info("渠道退款响应: refundOrderId={}, channelStatus={}, channelRefundNo={}",
                    refundOrder.getRefundOrderId(), response.getChannelStatus(), response.getChannelRefundNo());

            if (response.isSuccess()) {
                return ChannelRefundResult.success(response.getChannelRefundNo());

            } else if (response.isDefinitelyFailed()) {
                return ChannelRefundResult.failed(response.getErrorCode(), response.getErrorMsg());

            } else {
                log.warn("渠道退款返回非终态: refundOrderId={}, channelStatus={}",
                        refundOrder.getRefundOrderId(), response.getChannelStatus());
                return ChannelRefundResult.unknown("渠道处理中");
            }

        } catch (SocketTimeoutException e) {
            log.error("渠道退款网络超时: refundOrderId={}", refundOrder.getRefundOrderId(), e);
            return ChannelRefundResult.unknown("网络超时");

        } catch (ChannelSystemException e) {
            log.error("渠道系统异常: refundOrderId={}", refundOrder.getRefundOrderId(), e);
            return ChannelRefundResult.unknown("渠道系统异常: " + e.getMessage());

        } catch (Exception e) {
            log.error("渠道退款未知异常: refundOrderId={}", refundOrder.getRefundOrderId(), e);
            return ChannelRefundResult.unknown("未知异常: " + e.getMessage());
        }
    }
}

// ==================== 退款回调处理 ====================

/**
 * 退款回调服务——验签 + 幂等 + 状态同步 + 资金入账 + 通知业务方
 */
@Service
@Slf4j
public class RefundCallbackService {

    @Autowired
    private RefundOrderRepository refundOrderRepository;

    @Autowired
    private RefundCallbackRecordRepository refundCallbackRecordRepository;

    @Autowired
    private ChannelSignatureVerifier signatureVerifier;

    @Autowired
    private AccountService accountService;

    @Autowired
    private PaymentVoucherRepository voucherRepository;

    @Autowired
    private RocketMQTemplate mqTemplate;

    /**
     * 处理退款回调
     *
     * 幂等策略：
     *   1. 回调流水号唯一索引
     *   2. 退款单已SUCCESS时直接返回（双重幂等）
     */
    @Transactional
    public CallbackProcessResult processCallback(String channelCode, String callbackBody, String callbackId) {
        // ---- 步骤1：记录回调流水（幂等控制） ----
        RefundCallbackRecord record = new RefundCallbackRecord();
        record.setCallbackId(callbackId);
        record.setChannelCode(channelCode);
        record.setCallbackBody(callbackBody);
        record.setReceiveTime(LocalDateTime.now());

        try {
            refundCallbackRecordRepository.save(record);
        } catch (DuplicateKeyException e) {
            log.info("退款回调幂等命中: callbackId={}", callbackId);
            return CallbackProcessResult.success("回调已处理");
        }

        // ---- 步骤2：验签 ----
        RefundCallbackPayload payload;
        try {
            payload = signatureVerifier.verifyAndParseRefundCallback(channelCode, callbackBody);
        } catch (SignatureVerifyException e) {
            log.error("退款回调验签失败: callbackId={}", callbackId, e);
            return CallbackProcessResult.fail("验签失败");
        }

        // ---- 步骤3：查找退款单 ----
        RefundOrder refundOrder = refundOrderRepository.findByRefundOrderId(payload.getOutRefundNo());
        if (refundOrder == null) {
            log.error("退款回调对应的退款单不存在: refundOrderId={}", payload.getOutRefundNo());
            return CallbackProcessResult.fail("退款单不存在");
        }

        // ---- 步骤4：幂等检查 ----
        if (refundOrder.getStatus() == RefundStatus.SUCCESS) {
            log.info("退款单已成功，回调幂等返回: refundOrderId={}", refundOrder.getRefundOrderId());
            return CallbackProcessResult.success("退款单已成功");
        }

        // ---- 步骤5：状态机校验 + 状态流转 ----
        if (!refundOrder.getStatus().canTransitTo(RefundStatus.SUCCESS)) {
            log.error("退款回调状态流转非法: refundOrderId={}, current={}",
                    refundOrder.getRefundOrderId(), refundOrder.getStatus());
            return CallbackProcessResult.fail("状态流转非法");
        }

        refundOrder.transitTo(RefundStatus.SUCCESS);
        refundOrder.setChannelRefundNo(payload.getChannelRefundNo());
        refundOrder.setSuccessTime(LocalDateTime.now());
        refundOrderRepository.save(refundOrder);
        log.info("退款回调状态同步成功: refundOrderId={}, channelRefundNo={}",
                refundOrder.getRefundOrderId(), payload.getChannelRefundNo());

        // ---- 步骤6：生成退款凭证（幂等） ----
        generateRefundVoucherIdempotently(refundOrder);

        // ---- 步骤7：资金入账——更新用户/商户账户余额 ----
        try {
            accountService.refundToAccount(refundOrder);
            log.info("退款资金入账成功: refundOrderId={}, amount={}",
                    refundOrder.getRefundOrderId(), refundOrder.getRefundAmount());
        } catch (Exception e) {
            // 资金入账失败不影响回调返回，由补偿任务兜底
            log.error("退款资金入账失败，将由补偿任务重试: refundOrderId={}",
                    refundOrder.getRefundOrderId(), e);
        }

        // ---- 步骤8：通知业务方退款到账 ----
        RefundSuccessMessage message = RefundSuccessMessage.builder()
                .refundOrderId(refundOrder.getRefundOrderId())
                .originalOrderId(refundOrder.getOriginalOrderId())
                .refundAmount(refundOrder.getRefundAmount())
                .successTime(refundOrder.getSuccessTime())
                .build();

        try {
            mqTemplate.syncSend("refund-success-topic", message);
            log.info("退款成功MQ发送成功: refundOrderId={}", refundOrder.getRefundOrderId());
        } catch (Exception e) {
            log.error("退款成功MQ发送失败，本地消息表补偿: refundOrderId={}",
                    refundOrder.getRefundOrderId(), e);
        }

        return CallbackProcessResult.success("退款回调处理成功");
    }

    private void generateRefundVoucherIdempotently(RefundOrder refundOrder) {
        String voucherNo = "RV" + refundOrder.getRefundOrderId();

        if (voucherRepository.findByVoucherNo(voucherNo) != null) {
            log.info("退款凭证已存在，幂等返回: voucherNo={}", voucherNo);
            return;
        }

        PaymentVoucher voucher = new PaymentVoucher();
        voucher.setVoucherNo(voucherNo);
        voucher.setBizOrderId(refundOrder.getOriginalOrderId());
        voucher.setVoucherType(VoucherType.REFUND);
        voucher.setAmount(refundOrder.getRefundAmount().negate()); // 退款为负数
        voucher.setChannelCode(refundOrder.getChannelCode());
        voucher.setChannelSerialNo(refundOrder.getChannelRefundNo());
        voucher.setStatus(VoucherStatus.SUCCESS);
        voucher.setCreateTime(LocalDateTime.now());

        try {
            voucherRepository.save(voucher);
            log.info("退款凭证生成成功: voucherNo={}, refundOrderId={}", voucherNo, refundOrder.getRefundOrderId());
        } catch (DuplicateKeyException e) {
            log.info("退款凭证并发创建冲突: voucherNo={}", voucherNo);
        }
    }
}

/**
 * 退款状态枚举——与支付状态机同理，集中定义合法流转路径
 */
public enum RefundStatus {
    CREATED("已创建"),
    PROCESSING("退款中"),
    SUCCESS("退款成功"),
    FAILED("退款失败"),
    UNKNOWN("状态未知"),
    CLOSED("已关闭");

    private final String desc;
    RefundStatus(String desc) { this.desc = desc; }

    private static final Map<RefundStatus, Set<RefundStatus>> TRANSITIONS = new EnumMap<>(RefundStatus.class);

    static {
        TRANSITIONS.put(CREATED, EnumSet.of(PROCESSING, FAILED, UNKNOWN, SUCCESS));
        TRANSITIONS.put(PROCESSING, EnumSet.of(SUCCESS, FAILED, UNKNOWN));
        TRANSITIONS.put(UNKNOWN, EnumSet.of(SUCCESS, FAILED));
        // SUCCESS / FAILED / CLOSED 是终态
    }

    public boolean canTransitTo(RefundStatus target) {
        return TRANSITIONS.getOrDefault(this, Collections.emptySet()).contains(target);
    }
}

/**
 * 退款未知状态查询补偿调度器
 */
@Component
@Slf4j
public class RefundUnknownQueryScheduler {

    @Autowired
    private RefundOrderRepository refundOrderRepository;

    @Autowired
    private ChannelClient channelClient;

    @Autowired
    private AccountService accountService;

    @Autowired
    private PaymentVoucherRepository voucherRepository;

    @Autowired
    private RocketMQTemplate mqTemplate;

    private static final long MAX_WAIT_MINUTES = 60; // 退款允许更长的等待时间

    @Transactional
    public void queryAndResolve(String refundOrderId) {
        RefundOrder refundOrder = refundOrderRepository.findByRefundOrderId(refundOrderId);
        if (refundOrder == null || refundOrder.getStatus() != RefundStatus.UNKNOWN) {
            log.info("退款查询补偿跳过: refundOrderId={}, status={}", refundOrderId,
                    refundOrder == null ? "NULL" : refundOrder.getStatus());
            return;
        }

        if (Duration.between(refundOrder.getCreateTime(), LocalDateTime.now()).toMinutes() > MAX_WAIT_MINUTES) {
            log.error("退款UNKNOWN状态超时未收敛，升级人工审核: refundOrderId={}", refundOrderId);
            escalateToManualReview(refundOrder);
            return;
        }

        try {
            ChannelRefundQueryResult queryResult = channelClient.queryRefundStatus(
                    refundOrder.getChannelCode(), refundOrder.getRefundOrderId());
            log.info("退款渠道查询结果: refundOrderId={}, channelStatus={}", refundOrderId, queryResult.getStatus());

            if (queryResult.isConfirmedSuccess()) {
                if (refundOrder.getStatus().canTransitTo(RefundStatus.SUCCESS)) {
                    refundOrder.transitTo(RefundStatus.SUCCESS);
                    refundOrder.setChannelRefundNo(queryResult.getChannelRefundNo());
                    refundOrder.setSuccessTime(LocalDateTime.now());
                    refundOrderRepository.save(refundOrder);
                    log.info("退款查询补偿确认成功: refundOrderId={}", refundOrderId);

                    // 凭证 + 入账 + MQ（同回调逻辑）
                    generateRefundVoucher(refundOrder);
                    accountService.refundToAccount(refundOrder);
                    sendRefundSuccessMessage(refundOrder);
                }

            } else if (queryResult.isConfirmedFailed()) {
                if (refundOrder.getStatus().canTransitTo(RefundStatus.FAILED)) {
                    refundOrder.transitTo(RefundStatus.FAILED);
                    refundOrderRepository.save(refundOrder);
                    log.info("退款查询补偿确认失败: refundOrderId={}", refundOrderId);
                }

            } else {
                log.warn("退款查询补偿仍未确认: refundOrderId={}", refundOrderId);
            }

        } catch (Exception e) {
            log.warn("退款查询补偿异常: refundOrderId={}", refundOrderId, e);
        }
    }

    private void generateRefundVoucher(RefundOrder refundOrder) {
        String voucherNo = "RV" + refundOrder.getRefundOrderId();
        if (voucherRepository.findByVoucherNo(voucherNo) != null) return;

        PaymentVoucher voucher = new PaymentVoucher();
        voucher.setVoucherNo(voucherNo);
        voucher.setBizOrderId(refundOrder.getOriginalOrderId());
        voucher.setVoucherType(VoucherType.REFUND);
        voucher.setAmount(refundOrder.getRefundAmount().negate());
        voucher.setStatus(VoucherStatus.SUCCESS);
        voucher.setCreateTime(LocalDateTime.now());
        try {
            voucherRepository.save(voucher);
        } catch (DuplicateKeyException ignored) {
            // 并发兜底
        }
    }

    private void sendRefundSuccessMessage(RefundOrder refundOrder) {
        try {
            mqTemplate.syncSend("refund-success-topic",
                    RefundSuccessMessage.builder()
                            .refundOrderId(refundOrder.getRefundOrderId())
                            .originalOrderId(refundOrder.getOriginalOrderId())
                            .refundAmount(refundOrder.getRefundAmount())
                            .build());
        } catch (Exception e) {
            log.error("退款MQ发送失败: refundOrderId={}", refundOrder.getRefundOrderId(), e);
        }
    }

    private void escalateToManualReview(RefundOrder refundOrder) {
        log.error("退款升级人工审核: refundOrderId={}, originalOrderId={}, amount={}",
                refundOrder.getRefundOrderId(), refundOrder.getOriginalOrderId(), refundOrder.getRefundAmount());
    }

    public void scheduleQuery(String refundOrderId) {
        log.info("调度退款UNKNOWN查询: refundOrderId={}", refundOrderId);
    }
}
```

### 7.3 案例三：日终对账全链路

**场景描述**：每日凌晨系统自动拉取渠道账单，与本地订单逐笔匹配，发现差异后自动处理单边/多边差异并调平。

**链路流程图**：

```
定时任务（每日凌晨02:00）
  │
  ▼
DailyReconciliationJob.run()                    ← 对账任务入口（幂等控制）
  │
  ├──► ChannelBillFetcher.fetchBill()            ← 拉取渠道账单文件
  │       │
  │       ├── 下载渠道账单（HTTP/FTP/SFTP）
  │       ├── 解析账单记录
  │       └── 落库渠道账单明细
  │
  ├──► ReconciliationMatcher.match()             ← 逐笔匹配
  │       │
  │       ├── 正向核对：本方流水 → 渠道账单
  │       │     ├── 匹配成功 → 标记一致
  │       │     ├── 本方有渠道无 → LOCAL_ONLY（长款）
  │       │     └── 金额/状态不一致 → MISMATCH
  │       │
  │       └── 反向核对：渠道账单剩余 → 本方流水
  │             └── 渠道有本方无 → CHANNEL_ONLY（短款）
  │
  ├──► DiffAutoResolver.resolve()                ← 差异自动处理
  │       │
  │       ├── LOCAL_ONLY（长款）→ 查询渠道确认 → 补单/冲正
  │       ├── CHANNEL_ONLY（短款）→ 查询本地确认 → 补记账/挂账
  │       ├── AMOUNT_MISMATCH → 人工审核工单
  │       └── STATUS_MISMATCH → 查询渠道确认 → 状态订正
  │
  └──► ReconciliationReportGenerator.generate()  ← 生成对账报告
          │
          ├── 对账总数 / 一致数 / 差异数
          ├── 差异明细列表
          └── 告警通知
```

```java
// ==================== 日终对账定时任务 ====================

/**
 * 日终对账定时任务——每日凌晨执行
 *
 * 幂等控制：通过批次号（日期+渠道）唯一索引保证同一批次不重复执行
 */
@Component
@Slf4j
public class DailyReconciliationJob {

    @Autowired
    private ChannelBillFetcher billFetcher;

    @Autowired
    private ReconciliationMatcher matcher;

    @Autowired
    private DiffAutoResolver diffResolver;

    @Autowired
    private ReconciliationReportGenerator reportGenerator;

    @Autowired
    private IdempotentTaskExecutor taskExecutor;

    @Autowired
    private ChannelConfigRepository channelConfigRepository;

    @Autowired
    private AlertService alertService;

    /**
     * 每日凌晨02:00触发
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void runDailyReconciliation() {
        LocalDate billDate = LocalDate.now().minusDays(1); // 对前一天的账
        log.info("日终对账任务启动: billDate={}", billDate);

        // 获取所有需要对账的渠道
        List<ChannelConfig> channels = channelConfigRepository.findAllActiveChannels();

        for (ChannelConfig channel : channels) {
            String batchKey = "RECON-" + billDate.toString() + "-" + channel.getChannelCode();

            try {
                // 幂等执行：同一渠道同一天的对账只执行一次
                taskExecutor.executeWithIdempotency(
                        "daily-reconciliation",
                        batchKey,
                        () -> reconcileForChannel(billDate, channel.getChannelCode()));

            } catch (Exception e) {
                log.error("对账任务执行失败: billDate={}, channelCode={}", billDate, channel.getChannelCode(), e);
            }
        }

        log.info("日终对账任务完成: billDate={}", billDate);
    }

    /**
     * 单渠道对账全流程
     */
    private void reconcileForChannel(LocalDate billDate, String channelCode) {
        log.info("开始渠道对账: billDate={}, channelCode={}", billDate, channelCode);

        // ---- 步骤1：拉取渠道账单 ----
        List<ChannelBillRecord> channelBill;
        try {
            channelBill = billFetcher.fetchBill(billDate, channelCode);
            log.info("渠道账单拉取成功: billDate={}, channelCode={}, recordCount={}",
                    billDate, channelCode, channelBill.size());
        } catch (Exception e) {
            log.error("渠道账单拉取失败: billDate={}, channelCode={}", billDate, channelCode, e);
            alertService.sendBillFetchFailAlert(billDate, channelCode, e.getMessage());
            return;
        }

        // ---- 步骤2：逐笔匹配 ----
        ReconciliationMatchResult matchResult = matcher.match(billDate, channelCode, channelBill);
        log.info("对账匹配完成: billDate={}, channelCode={}, total={}, matched={}, diffs={}",
                billDate, channelCode, matchResult.getTotalCount(),
                matchResult.getMatchedCount(), matchResult.getDiffs().size());

        // ---- 步骤3：差异自动处理 ----
        if (!matchResult.getDiffs().isEmpty()) {
            DiffResolutionResult resolveResult = diffResolver.resolve(matchResult.getDiffs());
            log.info("差异处理完成: billDate={}, channelCode={}, autoResolved={}, manualEscalated={}",
                    billDate, channelCode,
                    resolveResult.getAutoResolvedCount(), resolveResult.getManualEscalatedCount());
        }

        // ---- 步骤4：生成对账报告 ----
        ReconciliationReport report = reportGenerator.generate(billDate, channelCode, matchResult);
        log.info("对账报告生成: billDate={}, channelCode={}, reportId={}",
                billDate, channelCode, report.getReportId());

        // ---- 步骤5：差异告警 ----
        if (matchResult.getDiffs().stream().anyMatch(d -> d.getPriority() == DiffPriority.CRITICAL)) {
            alertService.sendReconciliationCriticalAlert(billDate, channelCode, report);
        }
    }
}

// ==================== 渠道账单拉取器 ====================

/**
 * 渠道账单拉取器——下载 + 解析 + 落库
 */
@Component
@Slf4j
public class ChannelBillFetcher {

    @Autowired
    private ChannelBillClient channelBillClient;

    @Autowired
    private ChannelBillRecordRepository billRecordRepository;

    /**
     * 拉取并解析渠道账单
     *
     * 幂等控制：以 billDate + channelCode + orderId 建立唯一索引，
     * 重复拉取时通过 INSERT IGNORE 或 ON DUPLICATE KEY UPDATE 兜底
     */
    @Transactional
    public List<ChannelBillRecord> fetchBill(LocalDate billDate, String channelCode) {
        // 1. 检查是否已拉取过（幂等）
        List<ChannelBillRecord> existing = billRecordRepository.findByBillDateAndChannelCode(billDate, channelCode);
        if (!existing.isEmpty()) {
            log.info("渠道账单已拉取过，直接返回缓存: billDate={}, channelCode={}, count={}",
                    billDate, channelCode, existing.size());
            return existing;
        }

        // 2. 下载渠道账单文件
        ChannelBillFile billFile;
        try {
            billFile = channelBillClient.downloadBill(billDate, channelCode);
            log.info("渠道账单文件下载成功: billDate={}, channelCode={}, fileSize={}, fileFormat={}",
                    billDate, channelCode, billFile.getSize(), billFile.getFormat());
        } catch (ChannelBillNotReadyException e) {
            // 渠道账单尚未生成，等待后重试
            log.warn("渠道账单未就绪: billDate={}, channelCode={}", billDate, channelCode);
            throw e;
        } catch (Exception e) {
            log.error("渠道账单下载失败: billDate={}, channelCode={}", billDate, channelCode, e);
            throw new RuntimeException("渠道账单下载失败", e);
        }

        // 3. 解析账单文件
        List<ChannelBillRecord> records;
        try {
            records = parseBillFile(billFile, billDate, channelCode);
            log.info("渠道账单解析完成: billDate={}, channelCode={}, parsedCount={}",
                    billDate, channelCode, records.size());
        } catch (Exception e) {
            log.error("渠道账单解析失败: billDate={}, channelCode={}", billDate, channelCode, e);
            throw new RuntimeException("渠道账单解析失败", e);
        }

        // 4. 批量落库（幂等：唯一索引兜底）
        for (ChannelBillRecord record : records) {
            try {
                billRecordRepository.save(record);
            } catch (DuplicateKeyException e) {
                // 重复记录跳过
                log.debug("渠道账单记录已存在，跳过: orderId={}", record.getOrderId());
            }
        }

        return records;
    }

    /**
     * 解析账单文件——支持CSV/JSON等格式
     */
    private List<ChannelBillRecord> parseBillFile(ChannelBillFile billFile, LocalDate billDate, String channelCode) {
        List<ChannelBillRecord> records = new ArrayList<>();

        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(billFile.getInputStream(), StandardCharsets.UTF_8))) {

            String line;
            boolean headerSkipped = false;
            while ((line = reader.readLine()) != null) {
                if (!headerSkipped) {
                    headerSkipped = true; // 跳过表头
                    continue;
                }

                try {
                    ChannelBillRecord record = parseLine(line, billDate, channelCode);
                    if (record != null) {
                        records.add(record);
                    }
                } catch (Exception e) {
                    log.warn("账单行解析失败，跳过: line={}", line, e);
                }
            }

        } catch (IOException e) {
            throw new RuntimeException("账单文件读取失败", e);
        }

        return records;
    }

    private ChannelBillRecord parseLine(String line, LocalDate billDate, String channelCode) {
        String[] fields = line.split(",");
        if (fields.length < 6) return null;

        ChannelBillRecord record = new ChannelBillRecord();
        record.setBillDate(billDate);
        record.setChannelCode(channelCode);
        record.setOrderId(fields[0].trim());
        record.setChannelOrderId(fields[1].trim());
        record.setAmount(new BigDecimal(fields[2].trim()));
        record.setStatus(fields[3].trim());
        record.setFee(new BigDecimal(fields[4].trim()));
        record.setTradeTime(LocalDateTime.parse(fields[5].trim(),
                DateTimeFormatter.ISO_LOCAL_DATE_TIME));
        return record;
    }
}

// ==================== 对账匹配器 ====================

/**
 * 对账匹配器——正向核对 + 反向核对
 */
@Service
@Slf4j
public class ReconciliationMatcher {

    @Autowired
    private PaymentOrderRepository paymentOrderRepository;

    @Autowired
    private RefundOrderRepository refundOrderRepository;

    @Autowired
    private ReconciliationDiffRepository diffRepository;

    /**
     * 执行逐笔匹配
     *
     * 匹配维度：orderId（本方支付单号 ↔ 渠道账单订单号）
     * 核对维度：金额、状态
     */
    @Transactional
    public ReconciliationMatchResult match(LocalDate billDate, String channelCode,
                                            List<ChannelBillRecord> channelBill) {
        // 1. 获取本方流水（支付 + 退款）
        List<PaymentOrder> localPayments = paymentOrderRepository
                .findSuccessOrdersByDateAndChannel(billDate, channelCode);
        List<RefundOrder> localRefunds = refundOrderRepository
                .findSuccessRefundsByDateAndChannel(billDate, channelCode);

        log.info("对账数据准备: billDate={}, channelCode={}, localPayments={}, localRefunds={}, channelBill={}",
                billDate, channelCode, localPayments.size(), localRefunds.size(), channelBill.size());

        // 2. 构建渠道账单索引（处理可能的重复记录）
        Map<String, ChannelBillRecord> channelBillMap = new HashMap<>();
        for (ChannelBillRecord record : channelBill) {
            String key = record.getOrderId();
            if (channelBillMap.containsKey(key)) {
                log.warn("渠道账单存在重复记录: orderId={}", key);
                // 重复记录作为差异上报
                diffRepository.save(ReconciliationDiff.builder()
                        .billDate(billDate)
                        .channelCode(channelCode)
                        .diffType(DiffType.CHANNEL_DUPLICATE)
                        .orderId(key)
                        .channelAmount(record.getAmount())
                        .priority(DiffPriority.HIGH)
                        .build());
            } else {
                channelBillMap.put(key, record);
            }
        }

        List<ReconciliationDiff> diffs = new ArrayList<>();
        int matchedCount = 0;

        // 3. 正向核对：以本方支付流水为基准
        for (PaymentOrder localPayment : localPayments) {
            ChannelBillRecord channelRecord = channelBillMap.remove(localPayment.getOrderId());

            if (channelRecord == null) {
                // 本方有、渠道无——长款
                diffs.add(ReconciliationDiff.builder()
                        .billDate(billDate)
                        .channelCode(channelCode)
                        .diffType(DiffType.LOCAL_ONLY)
                        .orderId(localPayment.getOrderId())
                        .localAmount(localPayment.getAmount())
                        .localStatus(localPayment.getStatus().name())
                        .priority(DiffPriority.HIGH)
                        .description("本方支付成功但渠道账单无记录")
                        .build());
                log.warn("对账差异-长款: orderId={}, amount={}", localPayment.getOrderId(), localPayment.getAmount());

            } else if (localPayment.getAmount().compareTo(channelRecord.getAmount()) != 0) {
                // 金额不一致
                diffs.add(ReconciliationDiff.builder()
                        .billDate(billDate)
                        .channelCode(channelCode)
                        .diffType(DiffType.AMOUNT_MISMATCH)
                        .orderId(localPayment.getOrderId())
                        .localAmount(localPayment.getAmount())
                        .channelAmount(channelRecord.getAmount())
                        .priority(DiffPriority.CRITICAL)
                        .description(String.format("金额不一致: 本方=%s, 渠道=%s",
                                localPayment.getAmount(), channelRecord.getAmount()))
                        .build());
                log.error("对账差异-金额不一致: orderId={}, localAmount={}, channelAmount={}",
                        localPayment.getOrderId(), localPayment.getAmount(), channelRecord.getAmount());

            } else {
                matchedCount++;
            }
        }

        // 4. 正向核对：退款流水
        for (RefundOrder localRefund : localRefunds) {
            String refundKey = localRefund.getRefundOrderId();
            ChannelBillRecord channelRecord = channelBillMap.remove(refundKey);

            if (channelRecord == null) {
                diffs.add(ReconciliationDiff.builder()
                        .billDate(billDate)
                        .channelCode(channelCode)
                        .diffType(DiffType.LOCAL_ONLY)
                        .orderId(refundKey)
                        .localAmount(localRefund.getRefundAmount())
                        .priority(DiffPriority.HIGH)
                        .description("本方退款成功但渠道账单无记录")
                        .build());
                log.warn("对账差异-退款长款: refundOrderId={}", refundKey);

            } else if (localRefund.getRefundAmount().compareTo(channelRecord.getAmount()) != 0) {
                diffs.add(ReconciliationDiff.builder()
                        .billDate(billDate)
                        .channelCode(channelCode)
                        .diffType(DiffType.AMOUNT_MISMATCH)
                        .orderId(refundKey)
                        .localAmount(localRefund.getRefundAmount())
                        .channelAmount(channelRecord.getAmount())
                        .priority(DiffPriority.CRITICAL)
                        .description("退款金额不一致")
                        .build());
                log.error("对账差异-退款金额不一致: refundOrderId={}", refundKey);

            } else {
                matchedCount++;
            }
        }

        // 5. 反向核对：渠道有记录但本方无——短款（最严重的差异）
        for (ChannelBillRecord remaining : channelBillMap.values()) {
            diffs.add(ReconciliationDiff.builder()
                    .billDate(billDate)
                    .channelCode(channelCode)
                    .diffType(DiffType.CHANNEL_ONLY)
                    .orderId(remaining.getOrderId())
                    .channelAmount(remaining.getAmount())
                    .channelStatus(remaining.getStatus())
                    .priority(DiffPriority.CRITICAL)
                    .description("渠道账单有记录但本方无记录——短款")
                    .build());
            log.error("对账差异-短款: orderId={}, channelAmount={}", remaining.getOrderId(), remaining.getAmount());
        }

        // 6. 持久化差异记录
        if (!diffs.isEmpty()) {
            diffRepository.saveAll(diffs);
            log.info("对账差异已落库: billDate={}, channelCode={}, diffCount={}",
                    billDate, channelCode, diffs.size());
        }

        int totalCount = localPayments.size() + localRefunds.size();
        return new ReconciliationMatchResult(billDate, channelCode, totalCount, matchedCount, diffs);
    }
}

// ==================== 差异自动处理器 ====================

/**
 * 差异自动处理器——根据差异类型执行不同的调平策略
 *
 * 处理策略：
 *   LOCAL_ONLY（长款）   → 主动查询渠道确认 → 渠道确实无记录则本地冲正
 *   CHANNEL_ONLY（短款） → 主动查询本地确认 → 本地确实无记录则补记账
 *   AMOUNT_MISMATCH      → 升级人工审核（金额差异不可自动处理）
 *   STATUS_MISMATCH      → 查询渠道确认后订正本地状态
 */
@Service
@Slf4j
public class DiffAutoResolver {

    @Autowired
    private ReconciliationDiffRepository diffRepository;

    @Autowired
    private ChannelClient channelClient;

    @Autowired
    private PaymentOrderRepository paymentOrderRepository;

    @Autowired
    private PaymentVoucherRepository voucherRepository;

    @Autowired
    private ManualReviewService manualReviewService;

    /**
     * 批量处理差异
     */
    @Transactional
    public DiffResolutionResult resolve(List<ReconciliationDiff> diffs) {
        int autoResolved = 0;
        int manualEscalated = 0;

        for (ReconciliationDiff diff : diffs) {
            try {
                boolean resolved = resolveSingle(diff);
                if (resolved) {
                    autoResolved++;
                } else {
                    manualEscalated++;
                }
            } catch (Exception e) {
                log.error("差异处理异常: diffId={}, orderId={}", diff.getId(), diff.getOrderId(), e);
                manualEscalated++;
                diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                diffRepository.save(diff);
            }
        }

        return new DiffResolutionResult(autoResolved, manualEscalated);
    }

    /**
     * 处理单个差异——根据差异类型路由到不同处理策略
     */
    private boolean resolveSingle(ReconciliationDiff diff) {
        log.info("处理对账差异: diffId={}, diffType={}, orderId={}",
                diff.getId(), diff.getDiffType(), diff.getOrderId());

        switch (diff.getDiffType()) {

            case LOCAL_ONLY:
                // 长款：本方有记录、渠道无记录
                // 策略：查询渠道确认，如果渠道确实没有，则本地冲正
                return resolveLocalOnly(diff);

            case CHANNEL_ONLY:
                // 短款：渠道有记录、本方无记录
                // 策略：查询本地确认，如果本地确实没有，则补记账
                return resolveChannelOnly(diff);

            case AMOUNT_MISMATCH:
                // 金额不一致——不可自动处理，升级人工
                log.error("金额差异升级人工: orderId={}, local={}, channel={}",
                        diff.getOrderId(), diff.getLocalAmount(), diff.getChannelAmount());
                manualReviewService.createTicket(diff, "金额不一致，需人工核实");
                diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                diffRepository.save(diff);
                return false;

            case STATUS_MISMATCH:
                // 状态不一致——查询渠道确认后订正
                return resolveStatusMismatch(diff);

            case CHANNEL_DUPLICATE:
                // 渠道账单重复——人工核实
                manualReviewService.createTicket(diff, "渠道账单存在重复记录");
                diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                diffRepository.save(diff);
                return false;

            default:
                log.warn("未知差异类型: diffType={}", diff.getDiffType());
                manualReviewService.createTicket(diff, "未知差异类型");
                diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                diffRepository.save(diff);
                return false;
        }
    }

    /**
     * 长款处理：本方有记录、渠道无记录
     * 自动策略：查询渠道确认 → 渠道确实无 → 本地冲正（撤销支付状态）
     */
    private boolean resolveLocalOnly(ReconciliationDiff diff) {
        try {
            ChannelQueryResult queryResult = channelClient.queryStatus(diff.getChannelCode(), diff.getOrderId());
            log.info("长款差异查询渠道: orderId={}, channelStatus={}", diff.getOrderId(), queryResult.getStatus());

            if (queryResult.isConfirmedFailed() || queryResult.isNotFound()) {
                // 渠道确认该订单不存在或已失败 → 本地冲正
                PaymentOrder order = paymentOrderRepository.findByOrderId(diff.getOrderId());
                if (order != null && order.getStatus() == PaymentStatus.SUCCESS) {
                    // 冲正：将支付状态回退为FAILED，并冲正凭证
                    order.transitTo(PaymentStatus.FAILED);
                    paymentOrderRepository.save(order);
                    log.info("长款冲正完成: orderId={}", diff.getOrderId());

                    // 冲正凭证
                    reverseVoucher(order);
                }

                diff.setResolutionStatus(ResolutionStatus.AUTO_RESOLVED);
                diff.setResolutionRemark("渠道确认无记录，本地已冲正");
                diffRepository.save(diff);
                return true;

            } else if (queryResult.isConfirmedSuccess()) {
                // 渠道确认成功但账单未出 → 可能是账单延迟，标记为待下轮对账
                diff.setResolutionStatus(ResolutionStatus.PENDING);
                diff.setResolutionRemark("渠道确认成功，账单可能延迟，待下轮对账");
                diffRepository.save(diff);
                log.info("长款差异待下轮对账: orderId={}", diff.getOrderId());
                return true;

            } else {
                // 渠道也无法确认 → 升级人工
                manualReviewService.createTicket(diff, "渠道状态不明确");
                diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                diffRepository.save(diff);
                return false;
            }

        } catch (Exception e) {
            log.error("长款差异处理异常: orderId={}", diff.getOrderId(), e);
            throw new RuntimeException("长款差异处理失败", e);
        }
    }

    /**
     * 短款处理：渠道有记录、本方无记录
     * 自动策略：查询本地确认 → 本地确实没有 → 补记账
     */
    private boolean resolveChannelOnly(ReconciliationDiff diff) {
        try {
            PaymentOrder localOrder = paymentOrderRepository.findByOrderId(diff.getOrderId());

            if (localOrder != null) {
                // 本地有记录但可能状态不同 → 转为状态差异处理
                log.info("短款差异实际为状态差异: orderId={}, localStatus={}", diff.getOrderId(), localOrder.getStatus());
                diff.setDiffType(DiffType.STATUS_MISMATCH);
                diff.setLocalStatus(localOrder.getStatus().name());
                diff.setLocalAmount(localOrder.getAmount());
                return resolveStatusMismatch(diff);

            } else {
                // 本地确实无记录 → 查询渠道确认后补记账
                ChannelQueryResult queryResult = channelClient.queryStatus(diff.getChannelCode(), diff.getOrderId());

                if (queryResult.isConfirmedSuccess()) {
                    // 渠道确认成功 → 补建支付单 + 补建凭证
                    PaymentOrder compensOrder = new PaymentOrder();
                    compensOrder.setOrderId(diff.getOrderId());
                    compensOrder.setBizOrderId("COMPENS-" + diff.getOrderId());
                    compensOrder.setAmount(diff.getChannelAmount());
                    compensOrder.setCurrency("CNY");
                    compensOrder.setStatus(PaymentStatus.SUCCESS);
                    compensOrder.setChannelCode(diff.getChannelCode());
                    compensOrder.setChannelOrderId(queryResult.getChannelOrderId());
                    compensOrder.setCreateTime(diff.getBillDate().atStartOfDay());
                    compensOrder.setUpdateTime(LocalDateTime.now());
                    paymentOrderRepository.save(compensOrder);
                    log.info("短款补记账完成: orderId={}, amount={}", diff.getOrderId(), diff.getChannelAmount());

                    // 补建凭证
                    String voucherNo = "V" + diff.getOrderId();
                    if (voucherRepository.findByVoucherNo(voucherNo) == null) {
                        PaymentVoucher voucher = new PaymentVoucher();
                        voucher.setVoucherNo(voucherNo);
                        voucher.setBizOrderId(compensOrder.getBizOrderId());
                        voucher.setVoucherType(VoucherType.PAY);
                        voucher.setAmount(diff.getChannelAmount());
                        voucher.setCurrency("CNY");
                        voucher.setChannelCode(diff.getChannelCode());
                        voucher.setStatus(VoucherStatus.SUCCESS);
                        voucher.setCreateTime(LocalDateTime.now());
                        try {
                            voucherRepository.save(voucher);
                        } catch (DuplicateKeyException ignored) {
                            // 并发兜底
                        }
                    }

                    diff.setResolutionStatus(ResolutionStatus.AUTO_RESOLVED);
                    diff.setResolutionRemark("渠道确认成功，本地已补记账");
                    diffRepository.save(diff);
                    return true;

                } else {
                    // 渠道也无法确认 → 升级人工
                    manualReviewService.createTicket(diff, "短款但渠道状态不明确，需人工核实");
                    diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                    diffRepository.save(diff);
                    return false;
                }
            }

        } catch (Exception e) {
            log.error("短款差异处理异常: orderId={}", diff.getOrderId(), e);
            throw new RuntimeException("短款差异处理失败", e);
        }
    }

    /**
     * 状态差异处理：查询渠道确认后订正本地状态
     */
    private boolean resolveStatusMismatch(ReconciliationDiff diff) {
        try {
            ChannelQueryResult queryResult = channelClient.queryStatus(diff.getChannelCode(), diff.getOrderId());
            log.info("状态差异查询渠道: orderId={}, channelStatus={}", diff.getOrderId(), queryResult.getStatus());

            PaymentOrder order = paymentOrderRepository.findByOrderId(diff.getOrderId());
            if (order == null) {
                manualReviewService.createTicket(diff, "状态差异但本地订单不存在");
                diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                diffRepository.save(diff);
                return false;
            }

            if (queryResult.isConfirmedSuccess() && order.getStatus() != PaymentStatus.SUCCESS) {
                // 渠道成功、本地非成功 → 订正为成功
                if (order.getStatus().canTransitTo(PaymentStatus.SUCCESS)) {
                    order.transitTo(PaymentStatus.SUCCESS);
                    paymentOrderRepository.save(order);
                    log.info("状态订正为成功: orderId={}", diff.getOrderId());
                }
                diff.setResolutionStatus(ResolutionStatus.AUTO_RESOLVED);
                diff.setResolutionRemark("渠道确认成功，本地状态已订正");
                diffRepository.save(diff);
                return true;

            } else if (queryResult.isConfirmedFailed() && order.getStatus() == PaymentStatus.SUCCESS) {
                // 渠道失败、本地成功 → 需要冲正，但自动冲正风险较高，升级人工
                manualReviewService.createTicket(diff, "渠道失败但本地成功，需要冲正，请人工确认");
                diff.setResolutionStatus(ResolutionStatus.ESCALATED);
                diffRepository.save(diff);
                return false;

            } else {
                // 状态一致或渠道也无法确认
                diff.setResolutionStatus(ResolutionStatus.PENDING);
                diff.setResolutionRemark("渠道状态不明确，待下轮对账");
                diffRepository.save(diff);
                return true;
            }

        } catch (Exception e) {
            log.error("状态差异处理异常: orderId={}", diff.getOrderId(), e);
            throw new RuntimeException("状态差异处理失败", e);
        }
    }

    /**
     * 冲正凭证——生成一张与原凭证金额相反的冲正凭证
     */
    private void reverseVoucher(PaymentOrder order) {
        String reverseVoucherNo = "RV-" + order.getOrderId();
        if (voucherRepository.findByVoucherNo(reverseVoucherNo) != null) {
            return;
        }

        PaymentVoucher reverseVoucher = new PaymentVoucher();
        reverseVoucher.setVoucherNo(reverseVoucherNo);
        reverseVoucher.setBizOrderId(order.getBizOrderId());
        reverseVoucher.setVoucherType(VoucherType.PAY);
        reverseVoucher.setAmount(order.getAmount().negate()); // 金额取反
        reverseVoucher.setCurrency(order.getCurrency());
        reverseVoucher.setChannelCode(order.getChannelCode());
        reverseVoucher.setStatus(VoucherStatus.FAILED);
        reverseVoucher.setCreateTime(LocalDateTime.now());

        try {
            voucherRepository.save(reverseVoucher);
            log.info("冲正凭证生成: voucherNo={}, orderId={}", reverseVoucherNo, order.getOrderId());
        } catch (DuplicateKeyException e) {
            log.info("冲正凭证已存在: voucherNo={}", reverseVoucherNo);
        }
    }
}

/**

public enum DiffType {

    CHANNEL_ONLY("渠道有记录，本方无记录——短款"),
    AMOUNT_MISMATCH("金额不一致"),
    STATUS_MISMATCH("状态不一致"),

    private final String desc;
    DiffType(String desc) { this.desc = desc; }

/**
 * 对账报告生成器——汇总统计 + 报告输出
 */
@Service
@Slf4j
public class ReconciliationReportGenerator {

    @Autowired
    private ReconciliationReportRepository reportRepository;

    @Transactional
    public ReconciliationReport generate(LocalDate billDate, String channelCode,
                                          ReconciliationMatchResult matchResult) {
        ReconciliationReport report = new ReconciliationReport();
        report.setReportId("RPT-" + billDate.toString() + "-" + channelCode);
        report.setBillDate(billDate);
        report.setChannelCode(channelCode);
        report.setTotalCount(matchResult.getTotalCount());
        report.setMatchedCount(matchResult.getMatchedCount());
        report.setDiffCount(matchResult.getDiffs().size());

        // 计算一致率
        double consistencyRate = matchResult.getTotalCount() > 0
                ? (double) matchResult.getMatchedCount() / matchResult.getTotalCount() * 100
                : 100.0;
        report.setConsistencyRate(consistencyRate);

        // 按差异类型统计
        Map<DiffType, Long> diffTypeStats = matchResult.getDiffs().stream()
                .collect(Collectors.groupingBy(ReconciliationDiff::getDiffType, Collectors.counting()));
        report.setDiffTypeStats(diffTypeStats);

        // 按优先级统计
        long criticalCount = matchResult.getDiffs().stream()
                .filter(d -> d.getPriority() == DiffPriority.CRITICAL)
                .count();
        report.setCriticalDiffCount(criticalCount);

        report.setGenerateTime(LocalDateTime.now());
        reportRepository.save(report);

        log.info("对账报告生成完成: reportId={}, billDate={}, channelCode={}, total={}, matched={}, diff={}, consistencyRate={}%",
                report.getReportId(), billDate, channelCode,
                report.getTotalCount(), report.getMatchedCount(), report.getDiffCount(),
                String.format("%.2f", consistencyRate));

        return report;
    }
}
```

### 7.4 三个案例的幂等与异常处理要点总结

| 维度 | 案例一（支付） | 案例二（退款） | 案例三（对账） |
|---|---|---|---|
| **幂等键** | bizOrderId + payMethod | originalOrderId + refundRequestId | billDate + channelCode（批次级） |
| **幂等实现** | 唯一索引 + DuplicateKeyException 回查 | 唯一索引 + DuplicateKeyException 回查 | 唯一索引 + IdempotentTaskExecutor |
| **三态化处理** | 渠道扣款超时/异常 → UNKNOWN + 查询补偿 | 渠道退款超时/异常 → UNKNOWN + 查询补偿 | 渠道账单查询不确定 → PENDING + 下轮对账 |
| **状态机** | CREATED → INITIALIZED → PAYING → SUCCESS/FAILED/UNKNOWN | CREATED → PROCESSING → SUCCESS/FAILED/UNKNOWN | NEW → MATCHED / LOCAL_ONLY / CHANNEL_ONLY / MISMATCH → AUTO_RESOLVED / ESCALATED |
| **异常兜底** | 查询补偿 + 超时人工审核 | 查询补偿 + 超时人工审核 | 自动调平 + 人工审核工单 |
| **凭证生成** | 回调/查询确认成功后生成支付凭证 | 回调/查询确认成功后生成退款凭证（金额取反） | 补记账时补建凭证；冲正时生成反向凭证 |
| **日志规范** | 全链路 traceId 贯穿，每步操作记录 orderId + 关键字段 | 全链路 traceId 贯穿，每步操作记录 refundOrderId + 关键字段 | 批次级日志 + 逐笔差异日志 + 报告汇总日志 |
