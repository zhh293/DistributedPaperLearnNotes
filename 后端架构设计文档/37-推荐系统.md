# 推荐系统架构设计

## 一、问题背景

### 1.1 业务场景

在大型互联网平台中，推荐系统是连接用户（User）与物品（Item）的核心桥梁。无论是电商平台的商品推荐、内容平台的信息流推荐，还是 O2O 平台的商家推荐，其本质都是从已有的用户-物品交互关系中，预测用户未来可能感兴趣的物品。

推荐系统的核心解决两类问题：

1. **评分预测（Rating Prediction）**：预测用户对物品的评分，如预测用户对某部电影的评分是 4.5 分。
2. **行为预测（CTR Prediction）**：预测用户是否会对某个物品产生点击、购买等行为，即点击率/转化率预估。

### 1.2 推荐系统的隐性问题

除了核心的推荐精度之外，实际生产环境还面临以下隐性挑战：

| 问题类型 | 描述 | 影响 |
|---------|------|------|
| 冷启动 | 新用户/新物品没有历史行为数据 | 无法进行协同过滤 |
| 探索-利用（EE） | Exploitation vs Exploration 的平衡 | 推荐结果过度同质化 |
| 安全攻击 | 刷单、水军等恶意行为污染数据 | 推荐结果被人为操控 |
| 数据稀疏性 | 用户行为矩阵极度稀疏 | 协同过滤效果不佳 |
| 实时性 | 用户兴趣实时变化 | 离线模型无法及时响应 |

### 1.3 推荐系统演进路线

大型平台的推荐系统经历了以下演进阶段：

```
协同过滤(CF) -> XGBoost树模型 -> 深度学习(FNN -> LSTM+FNN -> ESMM)
```

早期以协同过滤为主，依赖人工特征工程；中期引入树模型处理非线性特征交叉；现阶段以深度学习为主，自动学习特征表示和交叉。

### 1.4 设计目标

| 目标维度 | 具体要求 |
|---------|---------|
| 推荐精度 | CTR 预估 AUC > 0.75 |
| 响应延迟 | P99 < 200ms |
| 吞吐量 | 支持 10w QPS 在线推荐 |
| 实时性 | 用户行为 5 分钟内反映到推荐结果 |
| 可扩展 | 支持多业务线快速接入 |

## 三、核心链路设计

### 3.1 用户画像（User Profile）

用户画像是推荐系统的基础数据资产，其核心目标是将用户特征向量化，使其能够被机器高效读取和处理。

```java
/**
 * 用户画像实体
 * 强调机器可读性和动态更新
 */
public class UserProfile {

    private Long userId;

    /**
     * 基础属性特征（静态）
     */
    private Map<String, Object> staticFeatures;

    /**
     * 行为特征（动态，需要实时更新）
     */
    private Map<String, Object> behaviorFeatures;

    /**
     * 兴趣标签向量（定期更新）
     */
    private float[] interestVector;

    /**
     * 实时行为序列（最近N次行为）
     */
    private List<UserAction> recentActions;

    /**
     * 上下文特征（请求时实时获取）
     */
    private Map<String, Object> contextFeatures;
}

/**
 * 用户画像服务
 */
@Service
public class UserProfileService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private HBaseTemplate hBaseTemplate;

    private static final String PROFILE_CACHE_PREFIX = "user:profile:";
    private static final String ACTION_SEQ_PREFIX = "user:actions:";
    private static final int MAX_ACTION_LENGTH = 50;

    /**
     * 获取用户画像
     */
    public UserProfile getUserProfile(long userId) {
        UserProfile profile = new UserProfile();
        profile.setUserId(userId);

        // 1. 从 Redis 获取实时行为特征
        String behaviorJson = redisTemplate.opsForValue()
                .get(PROFILE_CACHE_PREFIX + userId);
        if (behaviorJson != null) {
            profile.setBehaviorFeatures(JSON.parseObject(behaviorJson, Map.class));
        }

        // 2. 从 HBase 获取离线特征
        Map<String, Object> offlineFeatures = hBaseTemplate
                .get("user_profile", String.valueOf(userId));
        profile.setStaticFeatures(offlineFeatures);

        // 3. 获取兴趣向量
        String vectorStr = redisTemplate.opsForValue()
                .get("user:vector:" + userId);
        if (vectorStr != null) {
            profile.setInterestVector(parseVector(vectorStr));
        }

        // 4. 获取实时行为序列
        List<String> actions = redisTemplate.opsForList()
                .range(ACTION_SEQ_PREFIX + userId, 0, MAX_ACTION_LENGTH - 1);
        if (actions != null) {
            profile.setRecentActions(actions.stream()
                    .map(a -> JSON.parseObject(a, UserAction.class))
                    .collect(Collectors.toList()));
        }

        return profile;
    }

    /**
     * 更新用户行为序列
     * 用户每次行为（点击、购买等）都实时更新
     */
    public void appendUserAction(long userId, UserAction action) {
        String key = ACTION_SEQ_PREFIX + userId;
        String actionJson = JSON.toJSONString(action);

        // 左端插入，保持时间降序
        redisTemplate.opsForList().leftPush(key, actionJson);
        // 保持固定长度
        redisTemplate.opsForList().trim(key, 0, MAX_ACTION_LENGTH - 1);
        // 设置过期时间
        redisTemplate.expire(key, 7, TimeUnit.DAYS);
    }

    /**
     * 批量获取用户画像 - 在线服务需要高性能
     */
    public Map<Long, UserProfile> batchGetProfiles(List<Long> userIds) {
        // 使用 Redis Pipeline 批量获取
        List<String> keys = userIds.stream()
                .map(id -> PROFILE_CACHE_PREFIX + id)
                .collect(Collectors.toList());

        List<String> values = redisTemplate.opsForValue().multiGet(keys);

        Map<Long, UserProfile> result = new HashMap<>();
        for (int i = 0; i < userIds.size(); i++) {
            if (values.get(i) != null) {
                UserProfile profile = JSON.parseObject(values.get(i), UserProfile.class);
                result.put(userIds.get(i), profile);
            }
        }
        return result;
    }

    private float[] parseVector(String vectorStr) {
        String[] parts = vectorStr.split(",");
        float[] vector = new float[parts.length];
        for (int i = 0; i < parts.length; i++) {
            vector[i] = Float.parseFloat(parts[i]);
        }
        return vector;
    }
}
```

### 3.2 协同过滤算法

#### 3.2.1 基于物品的协同过滤（Item-Based CF）

在实际生产中，基于物品的协同过滤（Item-CF）比基于用户的协同过滤（User-CF）更常用，原因在于：

1. **用户数量通常远大于物品数量**：计算物品相似度矩阵更高效
2. **用户兴趣变化快于物品属性变化**：物品相似度矩阵更稳定
3. **数据稀疏性**：用户行为矩阵极度稀疏，基于物品的方法受影响更小

```java
/**
 * 基于物品的协同过滤实现
 */
@Service
public class ItemBasedCFService {

    @Autowired
    private UserBehaviorRepository behaviorRepo;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String ITEM_SIM_PREFIX = "item:sim:";
    private static final int TOP_K_SIMILAR = 50;

    /**
     * 计算物品相似度矩阵（离线任务）
     * 使用余弦相似度
     */
    public void computeItemSimilarity() {
        // 1. 构建物品-用户倒排表
        // 格式：itemId -> List<userId>
        Map<Long, Set<Long>> itemUsers = behaviorRepo.buildItemUserInvertedIndex();

        // 2. 构建用户-物品正排表
        // 格式：userId -> List<itemId>
        Map<Long, Set<Long>> userItems = behaviorRepo.buildUserItemIndex();

        // 3. 计算物品共现矩阵
        Map<Long, Map<Long, Integer>> coOccurrence = new HashMap<>();
        Map<Long, Integer> itemClickCount = new HashMap<>();

        for (Map.Entry<Long, Set<Long>> entry : userItems.entrySet()) {
            List<Long> items = new ArrayList<>(entry.getValue());
            for (int i = 0; i < items.size(); i++) {
                Long itemA = items.get(i);
                itemClickCount.merge(itemA, 1, Integer::sum);

                for (int j = i + 1; j < items.size(); j++) {
                    Long itemB = items.get(j);
                    coOccurrence.computeIfAbsent(itemA, k -> new HashMap<>())
                            .merge(itemB, 1, Integer::sum);
                    coOccurrence.computeIfAbsent(itemB, k -> new HashMap<>())
                            .merge(itemA, 1, Integer::sum);
                }
            }
        }

        // 4. 计算余弦相似度并存储到 Redis
        for (Map.Entry<Long, Map<Long, Integer>> entry : coOccurrence.entrySet()) {
            Long itemA = entry.getKey();
            int countA = itemClickCount.getOrDefault(itemA, 1);

            // 使用 TreeMap 按相似度排序，保留 Top-K
            TreeMap<Double, Long> topSimilar = new TreeMap<>(Comparator.reverseOrder());

            for (Map.Entry<Long, Integer> coEntry : entry.getValue().entrySet()) {
                Long itemB = coEntry.getKey();
                int countB = itemClickCount.getOrDefault(itemB, 1);
                int coCount = coEntry.getValue();

                // 余弦相似度: coCount / sqrt(countA * countB)
                double similarity = coCount / Math.sqrt((double) countA * countB);
                topSimilar.put(similarity, itemB);

                // 只保留 Top-K
                if (topSimilar.size() > TOP_K_SIMILAR) {
                    topSimilar.pollLastEntry();
                }
            }

            // 存储到 Redis
            String key = ITEM_SIM_PREFIX + itemA;
            Map<String, Double> simMap = new LinkedHashMap<>();
            topSimilar.forEach((sim, itemId) -> simMap.put(String.valueOf(itemId), sim));
            redisTemplate.opsForHash().putAll(key, simMap.entrySet().stream()
                    .collect(Collectors.toMap(Map.Entry::getKey,
                            e -> String.valueOf(e.getValue()))));
            redisTemplate.expire(key, 24, TimeUnit.HOURS);
        }
    }

    /**
     * 基于 Item-CF 进行推荐召回
     */
    public List<RecallItem> recall(long userId, int topN) {
        // 1. 获取用户最近交互的物品
        UserProfile profile = userProfileService.getUserProfile(userId);
        List<UserAction> recentActions = profile.getRecentActions();

        if (recentActions == null || recentActions.isEmpty()) {
            return Collections.emptyList();
        }

        // 2. 对每个交互物品，查找相似物品
        Map<Long, Double> candidateScores = new HashMap<>();
        Set<Long> interactedItems = recentActions.stream()
                .map(UserAction::getItemId)
                .collect(Collectors.toSet());

        for (UserAction action : recentActions) {
            Long itemId = action.getItemId();
            String key = ITEM_SIM_PREFIX + itemId;

            // 获取相似物品
            Map<Object, Object> simItems = redisTemplate.opsForHash().entries(key);
            for (Map.Entry<Object, Object> entry : simItems.entrySet()) {
                Long candidateId = Long.parseLong(entry.getKey().toString());
                double similarity = Double.parseDouble(entry.getValue().toString());

                // 过滤已交互物品
                if (interactedItems.contains(candidateId)) {
                    continue;
                }

                // 时间衰减权重
                double timeWeight = calculateTimeDecay(action.getTimestamp());
                // 行为类型权重：购买 > 收藏 > 点击
                double actionWeight = getActionWeight(action.getActionType());

                double score = similarity * timeWeight * actionWeight;
                candidateScores.merge(candidateId, score, Double::sum);
            }
        }

        // 3. 排序返回 Top-N
        return candidateScores.entrySet().stream()
                .sorted(Map.Entry.<Long, Double>comparingByValue().reversed())
                .limit(topN)
                .map(e -> new RecallItem(e.getKey(), e.getValue(), "ITEM_CF"))
                .collect(Collectors.toList());
    }

    /**
     * 时间衰减函数
     * 越近的行为权重越大
     */
    private double calculateTimeDecay(long actionTimestamp) {
        long hoursDiff = (System.currentTimeMillis() - actionTimestamp) / (1000 * 3600);
        // 指数衰减：半衰期 24 小时
        return Math.exp(-0.693 * hoursDiff / 24.0);
    }

    /**
     * 行为类型权重
     */
    private double getActionWeight(String actionType) {
        switch (actionType) {
            case "purchase": return 5.0;
            case "collect": return 3.0;
            case "click": return 1.0;
            case "share": return 4.0;
            default: return 1.0;
        }
    }
}
```

#### 3.2.2 矩阵分解（SVD）

```java
/**
 * 矩阵分解推荐模型
 * R ≈ U * Σ * V^T
 * 使用梯度下降 / ALS 优化
 */
public class MatrixFactorizationModel {

    private double[][] userMatrix;   // U: userCount x k
    private double[][] itemMatrix;   // V: itemCount x k
    private double[] userBias;
    private double[] itemBias;
    private double globalBias;

    private final int latentFactors;  // 隐因子维度
    private final double learningRate;
    private final double regularization;
    private final int maxIterations;

    public MatrixFactorizationModel(int latentFactors, double learningRate,
                                     double regularization, int maxIterations) {
        this.latentFactors = latentFactors;
        this.learningRate = learningRate;
        this.regularization = regularization;
        this.maxIterations = maxIterations;
    }

    /**
     * 训练模型 - 随机梯度下降（SGD）
     */
    public void train(List<RatingRecord> ratings, int userCount, int itemCount) {
        // 初始化矩阵
        Random random = new Random(42);
        userMatrix = new double[userCount][latentFactors];
        itemMatrix = new double[itemCount][latentFactors];
        userBias = new double[userCount];
        itemBias = new double[itemCount];

        // 随机初始化
        for (int i = 0; i < userCount; i++) {
            for (int k = 0; k < latentFactors; k++) {
                userMatrix[i][k] = random.nextGaussian() * 0.01;
            }
        }
        for (int j = 0; j < itemCount; j++) {
            for (int k = 0; k < latentFactors; k++) {
                itemMatrix[j][k] = random.nextGaussian() * 0.01;
            }
        }

        // 计算全局偏置
        globalBias = ratings.stream()
                .mapToDouble(RatingRecord::getRating)
                .average()
                .orElse(0.0);

        // SGD 迭代
        for (int iter = 0; iter < maxIterations; iter++) {
            Collections.shuffle(ratings);
            double totalLoss = 0.0;

            for (RatingRecord record : ratings) {
                int u = record.getUserIndex();
                int i = record.getItemIndex();
                double actual = record.getRating();

                // 预测评分
                double predicted = predict(u, i);
                double error = actual - predicted;
                totalLoss += error * error;

                // 更新偏置
                userBias[u] += learningRate * (error - regularization * userBias[u]);
                itemBias[i] += learningRate * (error - regularization * itemBias[i]);

                // 更新隐因子向量
                for (int k = 0; k < latentFactors; k++) {
                    double userVal = userMatrix[u][k];
                    double itemVal = itemMatrix[i][k];

                    userMatrix[u][k] += learningRate
                            * (error * itemVal - regularization * userVal);
                    itemMatrix[i][k] += learningRate
                            * (error * userVal - regularization * itemVal);
                }
            }

            double rmse = Math.sqrt(totalLoss / ratings.size());
            if (iter % 10 == 0) {
                System.out.printf("Iteration %d, RMSE: %.4f%n", iter, rmse);
            }
        }
    }

    /**
     * 预测评分
     */
    public double predict(int userIndex, int itemIndex) {
        double pred = globalBias + userBias[userIndex] + itemBias[itemIndex];
        for (int k = 0; k < latentFactors; k++) {
            pred += userMatrix[userIndex][k] * itemMatrix[itemIndex][k];
        }
        return pred;
    }

    /**
     * 为用户推荐 Top-N 物品
     */
    public List<RecallItem> recommend(int userIndex, Set<Integer> excludeItems, int topN) {
        PriorityQueue<RecallItem> topItems = new PriorityQueue<>(
                Comparator.comparingDouble(RecallItem::getScore));

        for (int i = 0; i < itemMatrix.length; i++) {
            if (excludeItems.contains(i)) {
                continue;
            }
            double score = predict(userIndex, i);
            topItems.offer(new RecallItem((long) i, score, "MF"));
            if (topItems.size() > topN) {
                topItems.poll();
            }
        }

        List<RecallItem> result = new ArrayList<>(topItems);
        result.sort(Comparator.comparingDouble(RecallItem::getScore).reversed());
        return result;
    }
}

/**
 * BPR（贝叶斯个性化排序）
 * 构造四元组 (user, item_positive, item_negative, relative_order)
 */
public class BPRModel {

    private double[][] userVectors;
    private double[][] itemVectors;
    private final int latentDim;
    private final double learningRate;
    private final double regularization;

    public BPRModel(int latentDim, double learningRate, double regularization) {
        this.latentDim = latentDim;
        this.learningRate = learningRate;
        this.regularization = regularization;
    }

    /**
     * BPR 训练
     * 核心思想：用户对正样本的偏好应高于负样本
     */
    public void train(Map<Integer, Set<Integer>> userPositiveItems,
                      int userCount, int itemCount, int iterations) {
        Random random = new Random(42);
        userVectors = initMatrix(userCount, latentDim, random);
        itemVectors = initMatrix(itemCount, latentDim, random);

        List<Integer> allItems = IntStream.range(0, itemCount)
                .boxed().collect(Collectors.toList());

        for (int iter = 0; iter < iterations; iter++) {
            double totalLoss = 0.0;

            for (Map.Entry<Integer, Set<Integer>> entry : userPositiveItems.entrySet()) {
                int u = entry.getKey();
                Set<Integer> positiveItems = entry.getValue();

                for (int posItem : positiveItems) {
                    // 随机采样负样本
                    int negItem;
                    do {
                        negItem = allItems.get(random.nextInt(itemCount));
                    } while (positiveItems.contains(negItem));

                    // 计算偏好差值
                    double xDiff = dotProduct(userVectors[u], itemVectors[posItem])
                            - dotProduct(userVectors[u], itemVectors[negItem]);
                    double sigmoid = 1.0 / (1.0 + Math.exp(-xDiff));
                    double gradient = 1.0 - sigmoid;
                    totalLoss += Math.log(sigmoid);

                    // 更新参数
                    for (int k = 0; k < latentDim; k++) {
                        double uVal = userVectors[u][k];
                        double posVal = itemVectors[posItem][k];
                        double negVal = itemVectors[negItem][k];

                        userVectors[u][k] += learningRate
                                * (gradient * (posVal - negVal)
                                - regularization * uVal);
                        itemVectors[posItem][k] += learningRate
                                * (gradient * uVal - regularization * posVal);
                        itemVectors[negItem][k] += learningRate
                                * (gradient * (-uVal) - regularization * negVal);
                    }
                }
            }

            if (iter % 100 == 0) {
                System.out.printf("BPR Iteration %d, Loss: %.4f%n", iter, totalLoss);
            }
        }
    }

    private double dotProduct(double[] a, double[] b) {
        double sum = 0.0;
        for (int i = 0; i < a.length; i++) {
            sum += a[i] * b[i];
        }
        return sum;
    }

    private double[][] initMatrix(int rows, int cols, Random random) {
        double[][] matrix = new double[rows][cols];
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                matrix[i][j] = random.nextGaussian() * 0.01;
            }
        }
        return matrix;
    }
```

```java
/**
```

```java
 * GBDT 用于自动特征组合，LR 用于最终 CTR 预测

public class GBDTLRModel {

    private GBDTModel gbdtModel;
    private LogisticRegressionModel lrModel;

    /**
     * 训练 GBDT + LR
     */
    public void train(List<FeatureVector> features, List<Integer> labels) {
        // 1. 训练 GBDT 模型
        gbdtModel = new GBDTModel(100, 6, 0.1); // 100棵树，深度6，学习率0.1
        gbdtModel.fit(features, labels);

        // 2. 用 GBDT 的叶子节点作为新特征
        List<float[]> gbdtFeatures = new ArrayList<>();
        for (FeatureVector fv : features) {
            int[] leafIndices = gbdtModel.getLeafIndices(fv);
            float[] newFeature = encodeLeafIndices(leafIndices, gbdtModel.getTreeCount(),
                    gbdtModel.getMaxLeafCount());
            gbdtFeatures.add(newFeature);
        }

        // 3. 训练 LR 模型
        lrModel = new LogisticRegressionModel(0.01, 0.001, 1000);
        lrModel.fit(gbdtFeatures, labels);
    }

    /**
     * 预测 CTR
     */
    public double predictCTR(FeatureVector fv) {
        // 1. GBDT 提取叶子节点特征
        int[] leafIndices = gbdtModel.getLeafIndices(fv);
        float[] gbdtFeature = encodeLeafIndices(leafIndices, gbdtModel.getTreeCount(),
                gbdtModel.getMaxLeafCount());

        // 2. LR 预测
        return lrModel.predict(gbdtFeature);
    }

    /**
     * 将 GBDT 叶子节点编码为 one-hot 特征
     */
    private float[] encodeLeafIndices(int[] leafIndices, int treeCount, int maxLeafCount) {
        float[] encoded = new float[treeCount * maxLeafCount];
        for (int i = 0; i < leafIndices.length; i++) {
            int offset = i * maxLeafCount + leafIndices[i];
            if (offset < encoded.length) {
                encoded[offset] = 1.0f;
            }
        }
        return encoded;
    }
}

/**
 * 逻辑回归模型 - CTR 预估
 */
public class LogisticRegressionModel {

    private double[] weights;
    private double bias;
    private final double learningRate;
    private final double regularization;
    private final int maxIterations;

    public LogisticRegressionModel(double learningRate, double regularization,
                                    int maxIterations) {
        this.learningRate = learningRate;
        this.regularization = regularization;
        this.maxIterations = maxIterations;
    }

    /**
     * 训练 LR
     */
    public void fit(List<float[]> features, List<Integer> labels) {
        int featureDim = features.get(0).length;
        weights = new double[featureDim];
        bias = 0.0;

        for (int iter = 0; iter < maxIterations; iter++) {
            double totalLoss = 0.0;

            for (int i = 0; i < features.size(); i++) {
                float[] x = features.get(i);
                int y = labels.get(i);

                double pred = sigmoid(dot(weights, x) + bias);
                double error = y - pred;
                totalLoss += -y * Math.log(pred + 1e-10)
                        - (1 - y) * Math.log(1 - pred + 1e-10);

                // 更新权重
                for (int j = 0; j < featureDim; j++) {
                    weights[j] += learningRate * (error * x[j]
                            - regularization * weights[j]);
                }
                bias += learningRate * error;
            }

            if (iter % 100 == 0) {
                System.out.printf("LR Iteration %d, Loss: %.4f%n", iter,
                        totalLoss / features.size());
            }
        }
    }

    public double predict(float[] features) {
        return sigmoid(dot(weights, features) + bias);
    }

    private double sigmoid(double x) {
        return 1.0 / (1.0 + Math.exp(-x));
    }

    private double dot(double[] w, float[] x) {
        double sum = 0.0;
        for (int i = 0; i < Math.min(w.length, x.length); i++) {
            sum += w[i] * x[i];
        }
        return sum;
    }
}
```

```java
/**
 * Wide & Deep 模型
 * Wide 部分：记忆力强，捕捉已知的特征组合
 * Deep 部分：泛化能力强，发现新的特征交叉
 */
public class WideAndDeepModel {

    // Wide 部分参数
    private double[] wideWeights;
    private double wideBias;

    // Deep 部分参数
    private double[][] embeddingTable;  // 离散特征 Embedding
    private double[][][] deepWeights;   // 深度网络权重
    private double[][] deepBiases;      // 深度网络偏置
    private int[] layerSizes;           // 各层神经元数

    private final int embeddingDim;
    private final double learningRate;

    public WideAndDeepModel(int embeddingDim, int[] layerSizes, double learningRate) {
        this.embeddingDim = embeddingDim;
        this.layerSizes = layerSizes;
        this.learningRate = learningRate;
    }

    /**
     * 前向传播
     */
    public double forward(float[] wideInput, float[] deepInput) {
        // Wide 部分：线性计算
        double wideOutput = wideBias;
        for (int i = 0; i < wideInput.length; i++) {
            wideOutput += wideWeights[i] * wideInput[i];
        }

        // Deep 部分：多层全连接
        double[] hiddenOutput = new double[deepInput.length];
        for (int i = 0; i < deepInput.length; i++) {
            hiddenOutput[i] = deepInput[i];
        }

        for (int l = 0; l < deepWeights.length; l++) {
            double[] newOutput = new double[layerSizes[l + 1]];
            for (int j = 0; j < layerSizes[l + 1]; j++) {
                double sum = deepBiases[l][j];
                for (int i = 0; i < hiddenOutput.length; i++) {
                    sum += deepWeights[l][i][j] * hiddenOutput[i];
                }
                // ReLU 激活
                newOutput[j] = Math.max(0, sum);
            }
            hiddenOutput = newOutput;
        }

        // Deep 输出（最后一层只有1个神经元）
        double deepOutput = hiddenOutput[0];

        // 合并 Wide + Deep
        double combined = wideOutput + deepOutput;
        return sigmoid(combined);
    }

    /**
     * 构建 Wide 特征
     * 显式特征交叉
     */
    public float[] buildWideFeatures(FeatureVector fv) {
        List<Float> wideFeatures = new ArrayList<>();

        // 原始特征
        for (Map.Entry<String, Double> entry : fv.getContinuousFeatures().entrySet()) {
            wideFeatures.add(entry.getValue().floatValue());
        }

        // 人工交叉特征
        double price = fv.getContinuousFeatures().getOrDefault("item_price", 0.0);
        double avgAmount = fv.getContinuousFeatures()
                .getOrDefault("user_avg_order_amount", 0.0);
        wideFeatures.add((float) (price * avgAmount)); // 价格交叉

        float[] result = new float[wideFeatures.size()];
        for (int i = 0; i < wideFeatures.size(); i++) {
            result[i] = wideFeatures.get(i);
        }
        return result;
    }

    /**
     * 构建 Deep 特征
     * Embedding 拼接 + 连续特征
     */
    public float[] buildDeepFeatures(FeatureVector fv,
                                      FeatureIndexMapping indexMapping) {
        List<Float> deepFeatures = new ArrayList<>();

        // 离散特征 -> Embedding
        for (Map.Entry<String, String> entry : fv.getCategoricalFeatures().entrySet()) {
            int idx = indexMapping.getIndex(entry.getKey(), entry.getValue());
            double[] embedding = embeddingTable[idx];
            for (double v : embedding) {
                deepFeatures.add((float) v);
            }
        }

        // 连续特征直接拼接
        for (Map.Entry<String, Double> entry : fv.getContinuousFeatures().entrySet()) {
            deepFeatures.add(entry.getValue().floatValue());
        }

        float[] result = new float[deepFeatures.size()];
        for (int i = 0; i < deepFeatures.size(); i++) {
            result[i] = deepFeatures.get(i);
        }
        return result;
    }

    private double sigmoid(double x) {
        return 1.0 / (1.0 + Math.exp(-x));
    }
```

```java
/**
 * 多臂老虎机策略 - 解决 EE（Exploration-Exploitation）问题
 */
public class MultiArmedBandit {

    /**
     * Thompson Sampling（汤普森采样）
     * 每个臂维护一个 Beta 分布参数 (alpha, beta)
     */
    public static class ThompsonSampling {
        private double[] alphas;  // 成功次数 + 1
        private double[] betas;   // 失败次数 + 1
        private final int armCount;
        private final Random random = new Random();

        public ThompsonSampling(int armCount) {
            this.armCount = armCount;
            this.alphas = new double[armCount];
            this.betas = new double[armCount];
            Arrays.fill(alphas, 1.0); // 先验
            Arrays.fill(betas, 1.0);
        }

        /**
         * 选择臂：从每个臂的 Beta 分布中采样，选最大值
         */
        public int selectArm() {
            double maxSample = -1;
            int bestArm = 0;

            for (int i = 0; i < armCount; i++) {
                // 从 Beta(alpha, beta) 分布采样
                double sample = sampleBeta(alphas[i], betas[i]);
                if (sample > maxSample) {
                    maxSample = sample;
                    bestArm = i;
                }
            }
            return bestArm;
        }

        /**
         * 更新：根据反馈更新 Beta 分布参数
         */
        public void update(int arm, boolean reward) {
            if (reward) {
                alphas[arm] += 1.0;
            } else {
                betas[arm] += 1.0;
            }
        }

        private double sampleBeta(double alpha, double beta) {
            double x = sampleGamma(alpha);
            double y = sampleGamma(beta);
            return x / (x + y);
        }

        private double sampleGamma(double shape) {
            // 使用 Marsaglia and Tsang 方法
            if (shape < 1) {
                return sampleGamma(shape + 1) * Math.pow(random.nextDouble(), 1.0 / shape);
            }
            double d = shape - 1.0 / 3.0;
            double c = 1.0 / Math.sqrt(9.0 * d);
            while (true) {
                double x, v;
                do {
                    x = random.nextGaussian();
                    v = 1 + c * x;
                } while (v <= 0);
                v = v * v * v;
                double u = random.nextDouble();
                if (u < 1 - 0.0331 * (x * x) * (x * x)) return d * v;
                if (Math.log(u) < 0.5 * x * x + d * (1 - v + Math.log(v))) return d * v;
            }
        }
    }

    /**
     * UCB（Upper Confidence Bound）
     * 选择置信区间上界最大的臂
     */
    public static class UCB {
        private double[] rewards;       // 累计奖励
        private int[] pullCounts;       // 拉动次数
        private int totalPulls;
        private final int armCount;

        public UCB(int armCount) {
            this.armCount = armCount;
            this.rewards = new double[armCount];
            this.pullCounts = new int[armCount];
            this.totalPulls = 0;
        }

        public int selectArm() {
            // 确保每个臂至少被拉一次
            for (int i = 0; i < armCount; i++) {
                if (pullCounts[i] == 0) return i;
            }

            double maxUcb = -1;
            int bestArm = 0;

            for (int i = 0; i < armCount; i++) {
                double avgReward = rewards[i] / pullCounts[i];
                double exploration = Math.sqrt(2 * Math.log(totalPulls) / pullCounts[i]);
                double ucbValue = avgReward + exploration;

                if (ucbValue > maxUcb) {
                    maxUcb = ucbValue;
                    bestArm = i;
                }
            }
            return bestArm;
        }

        public void update(int arm, double reward) {
            rewards[arm] += reward;
            pullCounts[arm]++;
            totalPulls++;
        }
    }

    /**
     * Epsilon-Greedy
     */
    public static class EpsilonGreedy {
        private double[] avgRewards;
        private int[] pullCounts;
        private final int armCount;
        private double epsilon;
        private final Random random = new Random();

        public EpsilonGreedy(int armCount, double epsilon) {
            this.armCount = armCount;
            this.epsilon = epsilon;
            this.avgRewards = new double[armCount];
            this.pullCounts = new int[armCount];
        }

        public int selectArm() {
            if (random.nextDouble() < epsilon) {
                // 探索：随机选择
                return random.nextInt(armCount);
            } else {
                // 利用：选择平均奖励最高的
                int bestArm = 0;
                double maxReward = avgRewards[0];
                for (int i = 1; i < armCount; i++) {
                    if (avgRewards[i] > maxReward) {
                        maxReward = avgRewards[i];
                        bestArm = i;
                    }
                }
                return bestArm;
            }
        }

        public void update(int arm, double reward) {
            pullCounts[arm]++;
            // 增量更新均值
            avgRewards[arm] += (reward - avgRewards[arm]) / pullCounts[arm];
        }
    }
}
```

```java
/**

@Service
public class MultiRecallService {

    @Autowired
    private ItemBasedCFService itemCFService;
    @Autowired
    private HotItemRecallService hotItemService;
    @Autowired
    private GeoRecallService geoRecallService;
    @Autowired
    private TagRecallService tagRecallService;
    @Autowired
    private VectorRecallService vectorRecallService;
    @Autowired
    private ExecutorService recallExecutor;

    private static final int RECALL_PER_CHANNEL = 200;
    private static final long RECALL_TIMEOUT_MS = 100;

    /**
     * 多路并行召回
     */
    public List<RecallItem> multiRecall(long userId, RecallContext context) {
        // 并行执行多路召回
        CompletableFuture<List<RecallItem>> cfFuture = CompletableFuture
                .supplyAsync(() -> itemCFService.recall(userId, RECALL_PER_CHANNEL),
                        recallExecutor);

        CompletableFuture<List<RecallItem>> hotFuture = CompletableFuture
                .supplyAsync(() -> hotItemService.recall(context, RECALL_PER_CHANNEL),
                        recallExecutor);

        CompletableFuture<List<RecallItem>> geoFuture = CompletableFuture
                .supplyAsync(() -> geoRecallService.recall(userId, context,
                        RECALL_PER_CHANNEL), recallExecutor);

        CompletableFuture<List<RecallItem>> tagFuture = CompletableFuture
                .supplyAsync(() -> tagRecallService.recall(userId, RECALL_PER_CHANNEL),
                        recallExecutor);

        CompletableFuture<List<RecallItem>> vectorFuture = CompletableFuture
                .supplyAsync(() -> vectorRecallService.recall(userId, RECALL_PER_CHANNEL),
                        recallExecutor);

        // 等待所有结果，设置超时
        List<RecallItem> allItems = new ArrayList<>();
        try {
            CompletableFuture.allOf(cfFuture, hotFuture, geoFuture,
                    tagFuture, vectorFuture)
                    .get(RECALL_TIMEOUT_MS, TimeUnit.MILLISECONDS);

            collectResults(allItems, cfFuture);
            collectResults(allItems, hotFuture);
            collectResults(allItems, geoFuture);
            collectResults(allItems, tagFuture);
            collectResults(allItems, vectorFuture);
        } catch (TimeoutException e) {
            // 部分召回超时，收集已完成的结果
            log.warn("部分召回通道超时, userId={}", userId);
            collectCompletedResults(allItems, cfFuture, hotFuture, geoFuture,
                    tagFuture, vectorFuture);
        } catch (Exception e) {
            log.error("召回异常, userId={}", userId, e);
        }

        // 合并去重
        return mergeAndDeduplicate(allItems);
    }

    /**
     * 合并去重 - 同一物品被多路召回时取最高分
     */
    private List<RecallItem> mergeAndDeduplicate(List<RecallItem> allItems) {
        Map<Long, RecallItem> merged = new LinkedHashMap<>();
        for (RecallItem item : allItems) {
            merged.merge(item.getItemId(), item, (existing, newItem) -> {
                // 保留分数更高的
                if (newItem.getScore() > existing.getScore()) {
                    return newItem;
                }
                // 记录被多路召回
                existing.addRecallSource(newItem.getRecallSource());
                return existing;
            });
        }
        return new ArrayList<>(merged.values());
    }

    @SuppressWarnings("unchecked")
    private void collectResults(List<RecallItem> allItems,
                                CompletableFuture<List<RecallItem>> future) {
        try {
            List<RecallItem> items = future.get(1, TimeUnit.MILLISECONDS);
            allItems.addAll(items);
        } catch (Exception e) {
            // 忽略
        }
    }

    @SafeVarargs
    private void collectCompletedResults(List<RecallItem> allItems,
                                          CompletableFuture<List<RecallItem>>... futures) {
        for (CompletableFuture<List<RecallItem>> future : futures) {
            if (future.isDone() && !future.isCompletedExceptionally()) {
                try {
                    allItems.addAll(future.get());
                } catch (Exception e) {
                    // 忽略
                }
            }
        }
    }
```

```java
/**
 * 在线排序服务
 * 接收召回结果，进行精细化排序

@Service
public class OnlineRankingService {

    @Autowired
    private FeatureEngineeringService featureService;
    @Autowired
    private ModelServingClient modelClient;

    /**
     * 精排
     */
    public List<RankedItem> rank(long userId, List<RecallItem> candidates,
                                  Map<String, Object> context) {
        if (candidates.isEmpty()) {
            return Collections.emptyList();
        }

        // 1. 批量提取特征
        List<FeatureVector> featureVectors = new ArrayList<>();
        for (RecallItem candidate : candidates) {
            FeatureVector fv = featureService.extractFeatures(
                    userId, candidate.getItemId(), context);
            featureVectors.add(fv);
        }

        // 2. 批量模型预测
        List<Double> ctrScores = modelClient.batchPredict(
                "ctr_model", featureVectors);
        List<Double> cvrScores = modelClient.batchPredict(
                "cvr_model", featureVectors);

        // 3. 综合排序分 = CTR * CVR * bid（ECPM 排序）
        List<RankedItem> rankedItems = new ArrayList<>();
        for (int i = 0; i < candidates.size(); i++) {
            RecallItem candidate = candidates.get(i);
            double ctr = ctrScores.get(i);
            double cvr = cvrScores.get(i);

            // ECPM = CTR * CVR * 预估客单价
            double estimatedGMV = getEstimatedGMV(candidate.getItemId());
            double rankScore = ctr * cvr * estimatedGMV;

            RankedItem item = new RankedItem();
            item.setItemId(candidate.getItemId());
            item.setCtrScore(ctr);
            item.setCvrScore(cvr);
            item.setRankScore(rankScore);
            item.setRecallSource(candidate.getRecallSource());
            rankedItems.add(item);
        }

        // 4. 按综合分排序
        rankedItems.sort(Comparator.comparingDouble(RankedItem::getRankScore).reversed());

        return rankedItems;
    }

    private double getEstimatedGMV(long itemId) {
        // 获取物品预估 GMV
        ItemInfo item = itemService.getItemInfo(itemId);
        return item != null ? item.getPrice() : 30.0; // 默认30
    }
}
```

```java
        results.addAll(hotItems);

        // 策略4：引导行为收集（探索）
        // 新用户前几次请求加大探索力度

            List<RecallItem> exploreItems = diverseExploration(30);
            results.addAll(exploreItems);
        }

        return mergeAndDeduplicate(results);
    }

     * 新物品冷启动
     */
    public double predictNewItemCTR(long itemId, FeatureVector itemFeatures) {
        // 1. 基于物品属性的内容相似度
        List<Long> similarItems = contentBasedSimilar(itemId, 10);

        // 2. 使用相似物品的 CTR 作为先验
        double avgCtr = 0.0;
        int count = 0;
        for (Long simItemId : similarItems) {
            Double ctr = itemCtrCache.get(simItemId);
            if (ctr != null) {
                avgCtr += ctr;
                count++;
            }
        }

        if (count > 0) {
            avgCtr /= count;
        } else {
            avgCtr = 0.02; // 全局平均 CTR
        }

        return avgCtr;
    }

/**
```
```java
 * A/B 测试分流服务

@Service
public class ABTestService {

    @Autowired
    private ABTestConfigRepository configRepo;

    /**
     * 获取用户的实验分组
     */
    public ExperimentGroup getExperimentGroup(long userId, String experimentId) {
        ABTestConfig config = configRepo.findById(experimentId);
        if (config == null || !config.isActive()) {
            return ExperimentGroup.CONTROL; // 默认对照组
        }

        // 使用 hash 分流，保证同一用户始终进入同一分组
        int hash = murmurHash(userId + "_" + experimentId);
        int bucket = Math.abs(hash) % 100;

        // 根据流量占比分配分组
        int cumulative = 0;
        for (ExperimentGroup group : config.getGroups()) {
            cumulative += group.getTrafficPercent();
            if (bucket < cumulative) {
                return group;
            }
        }
        return ExperimentGroup.CONTROL;
    }

    /**
     * 在推荐链路中使用 A/B 测试
     */
    public List<RankedItem> recommendWithABTest(long userId,
                                                 Map<String, Object> context) {
        // 1. 确定模型实验分组
        ExperimentGroup modelGroup = getExperimentGroup(userId, "rec_model_v2");

        // 2. 确定召回实验分组
        ExperimentGroup recallGroup = getExperimentGroup(userId, "rec_recall_v3");

        // 3. 根据分组选择不同的模型/策略
        String modelVersion = modelGroup.getParams()
                .getOrDefault("model_version", "v1");
        String recallStrategy = recallGroup.getParams()
                .getOrDefault("recall_strategy", "default");

        // 4. 执行推荐
        List<RecallItem> recalls = multiRecallService
                .multiRecall(userId, buildContext(context, recallStrategy));
        List<RankedItem> ranked = onlineRankingService
                .rankWithModel(userId, recalls, context, modelVersion);

        // 5. 记录实验日志
        logExperiment(userId, modelGroup, recallGroup, ranked);

        return ranked;
    }

    private int murmurHash(String key) {
        // MurmurHash3 简化实现
        int h = 0;
        for (int i = 0; i < key.length(); i++) {
            h = h * 31 + key.charAt(i);
        }
        return h;
    }

    private void logExperiment(long userId, ExperimentGroup modelGroup,
                                ExperimentGroup recallGroup, List<RankedItem> results) {
        ExperimentLog log = new ExperimentLog();
        log.setUserId(userId);
        log.setModelGroup(modelGroup.getName());
        log.setRecallGroup(recallGroup.getName());
        log.setResultCount(results.size());
        log.setTimestamp(System.currentTimeMillis());
        experimentLogService.asyncLog(log);
    }
```

```java
        String redisVal = redisTemplate.opsForValue().get("feature:" + featureKey);

            redisTemplate.opsForValue().set("feature:" + featureKey,
                    JSON.toJSONString(computed), 30, TimeUnit.MINUTES);
        }
        return computed;
    }
```

## 六、最佳实践

### 6.1 推荐系统设计原则

1. **召回要广，排序要准**：召回阶段追求覆盖率（Recall），排序阶段追求精确率（Precision）。两阶段分工明确，不要在召回阶段做太复杂的排序。

2. **特征为王**：好的特征比好的模型更重要。投入 70% 精力在特征工程上，包括特征选择、交叉、实时化。

3. **离散特征 Embedding 化**：对所有离散特征统一做 Embedding 处理，而非 one-hot 编码。这既降低了维度，又增强了泛化能力。

4. **实时性分层**：不同特征的实时性要求不同。用户实时行为序列需要秒级更新，用户画像可以分钟级更新，物品属性可以小时级更新。

5. **EE 机制必须有**：没有探索的推荐系统会陷入信息茧房。Thompson Sampling 是效果和工程复杂度的最佳平衡点。

### 6.2 系统工程建议

1. **召回超时容忍**：设置合理的召回超时（如 100ms），超时的召回通道直接跳过，保证整体响应时间。

2. **模型降级**：模型服务不可用时，降级为规则排序或缓存结果。永远不要给用户返回空列表。

3. **A/B 测试驱动**：任何算法改进必须通过线上 A/B 测试验证，不要相信离线指标。

4. **特征一致性**：训练和在线 serving 使用的特征必须一致，这是最常见的坑。建议使用统一的特征平台。

5. **日志闭环**：推荐 -> 曝光 -> 点击 -> 转化，全链路日志必须打通，才能做准确的模型训练和效果分析。

### 6.3 常见陷阱

| 陷阱 | 描述 | 解决方案 |
|------|------|---------|
| 训练/服务特征不一致 | 离线训练和在线服务用的特征计算方式不同 | 统一特征计算框架 |
| 数据泄露 | 使用未来数据训练模型 | 严格按时间切分训练/验证集 |
| 位置偏差 | 曝光位置影响点击率 | 使用 IPW (Inverse Propensity Weighting) |
| Simpson 悖论 | 分组分析与整体分析结论矛盾 | 分层分析，控制混淆变量 |
| 流行度偏差 | 热门物品始终被推荐 | 增加探索，降低热门物品的推荐权重 |

```java
/**
 * 首页推荐列表请求全链路服务
 * 完整覆盖：画像加载 → 多路召回 → 粗排 → 精排 → 重排 → 返回
 */
@Slf4j
@Service
public class HomePageRecommendService {

    @Autowired
    private UserProfileService userProfileService;
    @Autowired
    private MultiRecallService multiRecallService;
    @Autowired
    private PreRankingService preRankingService;
    @Autowired
    private OnlineRankingService onlineRankingService;
    @Autowired
    private ReRankingService reRankingService;
    @Autowired
    private RecommendationDegradeService degradeService;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private ExposureLogService exposureLogService;
    @Autowired
    private RecDataQualityMonitor qualityMonitor;

    /** 幂等缓存前缀 */
    private static final String IDEMPOTENT_PREFIX = "rec:idempotent:";
    /** 推荐结果缓存前缀 */
    private static final String RESULT_CACHE_PREFIX = "rec:result:";
    /** 幂等过期时间 */
    private static final long IDEMPOTENT_TTL_SECONDS = 60;
    /** 结果缓存过期时间 */
    private static final long RESULT_CACHE_TTL_SECONDS = 30;
    /** 链路总超时 */
    private static final long CHAIN_TIMEOUT_MS = 200;

    /**
     * 首页推荐列表请求入口
     *
     * @param request 推荐请求
     * @return 推荐结果
     */
    public RecommendResponse recommend(RecommendRequest request) {
        long startTime = System.currentTimeMillis();
        String requestId = request.getRequestId();
        long userId = request.getUserId();

        // ========== 1. 幂等控制 ==========
        if (StringUtils.isBlank(requestId)) {
            requestId = generateRequestId(userId, request);
            request.setRequestId(requestId);
        }
        String idempotentKey = IDEMPOTENT_PREFIX + requestId;
        Boolean isFirst = redisTemplate.opsForValue()
                .setIfAbsent(idempotentKey, "1", IDEMPOTENT_TTL_SECONDS, TimeUnit.SECONDS);
        if (Boolean.FALSE.equals(isFirst)) {
            log.info("幂等命中, requestId={}, userId={}", requestId, userId);
            // 尝试返回缓存结果
            RecommendResponse cached = getCachedResult(userId, requestId);
            if (cached != null) {
                return cached;
            }
            // 缓存也没有，说明上次请求可能未完成，允许重新执行
            redisTemplate.opsForValue().set(idempotentKey, "1",
                    IDEMPOTENT_TTL_SECONDS, TimeUnit.SECONDS);
        }

        MDC.put("requestId", requestId);
        MDC.put("userId", String.valueOf(userId));
        log.info("推荐请求开始, userId={}, requestId={}, scene={}",
                userId, requestId, request.getScene());

        try {
            // ========== 2. 参数校验 & 上下文构建 ==========
            RecommendContext context = buildContext(request);
            log.info("上下文构建完成, userId={}, context={}", userId, context);

            // ========== 3. 用户画像加载 ==========
            UserProfile profile = loadUserProfileWithFallback(userId);
            context.setUserProfile(profile);
            log.info("用户画像加载完成, userId={}, hasBehavior={}, interestVectorDim={}",
                    userId,
                    profile.getBehaviorFeatures() != null && !profile.getBehaviorFeatures().isEmpty(),
                    profile.getInterestVector() != null ? profile.getInterestVector().length : 0);

            // ========== 4. 多路召回 ==========
            List<RecallItem> recallItems = executeRecall(userId, context);
            log.info("召回完成, userId={}, recallCount={}", userId, recallItems.size());

            if (recallItems.isEmpty()) {
                log.warn("召回结果为空, userId={}, 降级到热门推荐", userId);
                recallItems = degradeService.degrade(userId, DegradeLevel.LEVEL_3, context.getFeatures());
            }

            // ========== 5. 粗排 ==========
            List<RecallItem> preRanked = preRankingService.preRank(userId, recallItems, context);
            log.info("粗排完成, userId={}, preRankedCount={}", userId, preRanked.size());

            // ========== 6. 精排 ==========
            List<RankedItem> ranked = onlineRankingService.rank(userId, preRanked, context.getFeatures());
            log.info("精排完成, userId={}, rankedCount={}", userId, ranked.size());

            // ========== 7. 重排 ==========
            List<RankedItem> reRanked = reRankingService.reRank(userId, ranked, context);
            log.info("重排完成, userId={}, finalCount={}", userId, reRanked.size());

            // ========== 8. 组装响应 ==========
            RecommendResponse response = buildResponse(request, reRanked, context);

            // ========== 9. 缓存结果 ==========
            cacheResult(userId, requestId, response);

            // ========== 10. 异步记录曝光日志 ==========
            exposureLogService.asyncLogExposure(userId, requestId, reRanked, context);

            long costMs = System.currentTimeMillis() - startTime;
            log.info("推荐请求完成, userId={}, requestId={}, cost={}ms, resultCount={}",
                    userId, requestId, costMs, reRanked.size());

            // 链路耗时监控
            if (costMs > CHAIN_TIMEOUT_MS) {
                log.warn("推荐链路超时, userId={}, cost={}ms, threshold={}ms",
                        userId, costMs, CHAIN_TIMEOUT_MS);
                qualityMonitor.reportChainTimeout(userId, costMs);
            }

            return response;

        } catch (RecallException e) {
            log.error("召回阶段异常, userId={}, requestId={}", userId, requestId, e);
            return buildFallbackResponse(request, degradeService.degrade(
                    userId, DegradeLevel.LEVEL_2, null));
        } catch (ModelServingException e) {
            log.error("模型服务异常, userId={}, requestId={}", userId, requestId, e);
            return buildFallbackResponse(request, degradeService.degrade(
                    userId, DegradeLevel.LEVEL_1, null));
        } catch (Exception e) {
            log.error("推荐链路未知异常, userId={}, requestId={}", userId, requestId, e);
            return buildFallbackResponse(request, degradeService.degrade(
                    userId, DegradeLevel.LEVEL_3, null));
        } finally {
            MDC.remove("requestId");
            MDC.remove("userId");
        }
    }

    /**
     * 用户画像加载（带降级）
     */
    private UserProfile loadUserProfileWithFallback(long userId) {
        try {
            UserProfile profile = userProfileService.getUserProfile(userId);
            if (profile == null || profile.getStaticFeatures() == null) {
                log.warn("用户画像为空, userId={}, 使用默认画像", userId);
                return buildDefaultProfile(userId);
            }
            return profile;
        } catch (Exception e) {
            log.error("用户画像加载失败, userId={}, 使用默认画像", userId, e);
            return buildDefaultProfile(userId);
        }
    }

    /**
     * 执行多路召回
     */
    private List<RecallItem> executeRecall(long userId, RecommendContext context) {
        try {
            List<RecallItem> items = multiRecallService.multiRecall(userId, context);
            if (items.isEmpty()) {
                // 召回为空时尝试冷启动策略
                log.info("常规召回为空, 尝试冷启动, userId={}", userId);
                items = multiRecallService.coldStartRecall(userId, context);
            }
            return items;
        } catch (Exception e) {
            throw new RecallException("多路召回失败, userId=" + userId, e);
        }
    }

    /**
     * 构建默认画像（冷启动/降级用）
     */
    private UserProfile buildDefaultProfile(long userId) {
        UserProfile profile = new UserProfile();
        profile.setUserId(userId);
        profile.setStaticFeatures(new HashMap<>());
        profile.getStaticFeatures().put("city", "unknown");
        profile.getStaticFeatures().put("gender", "unknown");
        profile.setBehaviorFeatures(new HashMap<>());
        return profile;
    }

    /**
     * 构建上下文
     */
    private RecommendContext buildContext(RecommendRequest request) {
        RecommendContext context = new RecommendContext();
        context.setScene(request.getScene());
        context.setPage(request.getPage());
        context.setPageSize(request.getPageSize());
        context.setFeatures(request.getContextFeatures());
        context.setRequestTime(System.currentTimeMillis());
        return context;
    }

    /**
     * 构建响应
     */
    private RecommendResponse buildResponse(RecommendRequest request,
                                             List<RankedItem> items,
                                             RecommendContext context) {
        RecommendResponse response = new RecommendResponse();
        response.setRequestId(request.getRequestId());
        response.setUserId(request.getUserId());
        response.setItems(items);
        response.setTimestamp(System.currentTimeMillis());
        response.setTraceId(MDC.get("requestId"));
        return response;
    }

    /**
     * 构建降级响应
     */
    private RecommendResponse buildFallbackResponse(RecommendRequest request,
                                                     List<RecallItem> fallbackItems) {
        RecommendResponse response = new RecommendResponse();
        response.setRequestId(request.getRequestId());
        response.setUserId(request.getUserId());
        response.setTimestamp(System.currentTimeMillis());
        response.setDegraded(true);
        response.setItems(fallbackItems.stream()
                .map(item -> {
                    RankedItem ranked = new RankedItem();
                    ranked.setItemId(item.getItemId());
                    ranked.setRankScore(item.getScore());
                    ranked.setRecallSource(item.getRecallSource());
                    return ranked;
                })
                .collect(Collectors.toList()));
        log.warn("返回降级响应, userId={}, requestId={}, itemCount={}",
                request.getUserId(), request.getRequestId(), fallbackItems.size());
        return response;
    }

    /**
     * 缓存推荐结果
     */
    private void cacheResult(long userId, String requestId, RecommendResponse response) {
        try {
            String key = RESULT_CACHE_PREFIX + userId + ":" + requestId;
            redisTemplate.opsForValue().set(key,
                    JSON.toJSONString(response),
                    RESULT_CACHE_TTL_SECONDS, TimeUnit.SECONDS);
        } catch (Exception e) {
            log.warn("缓存推荐结果失败, userId={}, requestId={}", userId, requestId, e);
        }
    }

    /**
     * 获取缓存结果
     */
    private RecommendResponse getCachedResult(long userId, String requestId) {
        try {
            String key = RESULT_CACHE_PREFIX + userId + ":" + requestId;
            String cached = redisTemplate.opsForValue().get(key);
            if (cached != null) {
                return JSON.parseObject(cached, RecommendResponse.class);
            }
        } catch (Exception e) {
            log.warn("获取缓存结果失败, userId={}, requestId={}", userId, requestId, e);
        }
        return null;
    }

    /**
     * 生成请求ID（幂等键）
     */
    private String generateRequestId(long userId, RecommendRequest request) {
        return "rec_" + userId + "_" + request.getScene() + "_"
                + System.currentTimeMillis() + "_"
                + UUID.randomUUID().toString().substring(0, 8);
    }
}

/**
 * 粗排服务
 * 使用轻量级双塔模型快速筛选

@Slf4j
@Service
public class PreRankingService {

    @Autowired
    private ModelServingClient modelClient;
    @Autowired
    private FeatureEngineeringService featureService;

    private static final int PRE_RANK_TOP_N = 200;

    /**
     * 粗排：快速筛选候选集
     */
    public List<RecallItem> preRank(long userId, List<RecallItem> candidates,
                                     RecommendContext context) {
        if (candidates.isEmpty()) {
            return Collections.emptyList();
        }

        // 候选集过大时先截断
        List<RecallItem> input = candidates.size() > 1000
                ? candidates.subList(0, 1000) : candidates;

        try {
            // 1. 批量提取粗排特征（轻量级，只用核心特征）
            List<FeatureVector> features = new ArrayList<>();
            for (RecallItem item : input) {
                FeatureVector fv = featureService.extractFeatures(
                        userId, item.getItemId(), context.getFeatures());
                features.add(fv);
            }

            // 2. 双塔模型批量预测
            List<Double> scores = modelClient.batchPredict("pre_rank_model", features);

            // 3. 按分数排序截断
            List<RecallItem> result = new ArrayList<>();
            for (int i = 0; i < input.size(); i++) {
                RecallItem item = input.get(i);
                item.setScore(scores.get(i));
                result.add(item);
            }
            result.sort(Comparator.comparingDouble(RecallItem::getScore).reversed());

            int cutSize = Math.min(PRE_RANK_TOP_N, result.size());
            log.info("粗排筛选, userId={}, input={}, output={}",
                    userId, input.size(), cutSize);
            return result.subList(0, cutSize);

        } catch (ModelServingException e) {
            log.error("粗排模型服务异常, userId={}, 降级为召回分数排序", userId, e);
            // 降级：直接使用召回分数排序截断
            input.sort(Comparator.comparingDouble(RecallItem::getScore).reversed());
            return input.subList(0, Math.min(PRE_RANK_TOP_N, input.size()));
        }
    }
}

/**
 * 重排服务
 * 多样性、去重、业务规则
 */
@Slf4j
@Service
public class ReRankingService {

    @Autowired
    private ItemService itemService;

    private static final int MAX_SAME_CATEGORY = 3;      // 同品类连续最多
    private static final int MAX_SAME_BRAND = 2;          // 同品牌连续最多
    private static final double DIVERSITY_PENALTY = 0.1;  // 多样性惩罚系数

    /**
     * 重排
     */
    public List<RankedItem> reRank(long userId, List<RankedItem> ranked,
                                     RecommendContext context) {
        if (ranked.isEmpty()) {
            return Collections.emptyList();
        }

        // 1. 去重：同一物品只保留分数最高的
        Map<Long, RankedItem> deduped = new LinkedHashMap<>();
        for (RankedItem item : ranked) {
            deduped.merge(item.getItemId(), item, (existing, newItem) ->
                    newItem.getRankScore() > existing.getRankScore() ? newItem : existing);
        }
        List<RankedItem> items = new ArrayList<>(deduped.values());
        log.info("重排去重, userId={}, before={}, after={}", userId, ranked.size(), items.size());

        // 2. 多样性重排：MMR (Maximal Marginal Relevance)
        List<RankedItem> result = mmrReRank(items, context.getPageSize());

        // 3. 业务规则过滤
        result = applyBusinessRules(result, context);

        // 4. 截断到请求数量
        int pageSize = context.getPageSize() > 0 ? context.getPageSize() : 20;
        if (result.size() > pageSize) {
            result = result.subList(0, pageSize);
        }

        log.info("重排完成, userId={}, finalCount={}", userId, result.size());
        return result;
    }

    /**
     * MMR 多样性重排
     */
    private List<RankedItem> mmrReRank(List<RankedItem> items, int topN) {
        List<RankedItem> selected = new ArrayList<>();
        Set<String> recentCategories = new LinkedHashSet<>();
        Set<Long> recentBrands = new LinkedHashSet<>();

        PriorityQueue<RankedItem> pool = new PriorityQueue<>(
                Comparator.comparingDouble(RankedItem::getRankScore).reversed());
        pool.addAll(items);

        while (!pool.isEmpty() && selected.size() < topN) {
            RankedItem best = null;
            double bestScore = Double.NEGATIVE_INFINITY;

            for (RankedItem candidate : pool) {
                ItemInfo info = itemService.getItemInfo(candidate.getItemId());
                if (info == null) continue;

                // 多样性惩罚
                double penalty = 0.0;
                if (recentCategories.contains(info.getCategoryId())) {
                    penalty += DIVERSITY_PENALTY;
                }
                if (recentBrands.contains(info.getBrandId())) {
                    penalty += DIVERSITY_PENALTY * 0.5;
                }

                double adjustedScore = candidate.getRankScore() * (1.0 - penalty);
                if (adjustedScore > bestScore) {
                    bestScore = adjustedScore;
                    best = candidate;
                }
            }

            if (best == null) {
                best = pool.poll();
            } else {
                pool.remove(best);
            }

            selected.add(best);

            // 更新最近品类/品牌窗口
            ItemInfo info = itemService.getItemInfo(best.getItemId());
            if (info != null) {
                recentCategories.add(info.getCategoryId());
                recentBrands.add(info.getBrandId());
                // 只保留最近3个品类
                while (recentCategories.size() > MAX_SAME_CATEGORY) {
                    recentCategories.remove(recentCategories.iterator().next());
                }
                while (recentBrands.size() > MAX_SAME_BRAND) {
                    recentBrands.remove(recentBrands.iterator().next());
                }
            }
        }

        return selected;
    }

    /**
     * 业务规则过滤
     */
    private List<RankedItem> applyBusinessRules(List<RankedItem> items,
                                                 RecommendContext context) {
        List<RankedItem> filtered = new ArrayList<>();
        for (RankedItem item : items) {
            // 规则1：下架商品过滤
            ItemInfo info = itemService.getItemInfo(item.getItemId());
            if (info == null || !info.isOnSale()) {
                log.debug("商品已下架, 过滤, itemId={}", item.getItemId());
                continue;
            }
            // 规则2：库存检查
            if (info.getStock() <= 0) {
                log.debug("商品无库存, 过滤, itemId={}", item.getItemId());
                continue;
            }
            filtered.add(item);
        }
        return filtered;
    }
}

/**
```
```java
 * 用户行为实时反馈全链路
 * 行为上报 → Kafka → 实时特征更新 → 模型更新 → 下次推荐生效
 */
@Slf4j
@Service
public class UserBehaviorFeedbackService {

    @Autowired
    private KafkaTemplate<String, String> kafkaTemplate;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private UserProfileService userProfileService;
    @Autowired
    private FeatureStoreService featureStoreService;
    @Autowired
    private ModelUpdateService modelUpdateService;
    @Autowired
    private BehaviorLogRepository behaviorLogRepo;

    /** Kafka topic */
    private static final String BEHAVIOR_TOPIC = "user_behavior";
    /** 幂等去重前缀 */
    private static final String IDEMPOTENT_PREFIX = "behavior:idempotent:";
    /** 实时特征前缀 */
    private static final String REALTIME_FEATURE_PREFIX = "user:rt_feature:";
    /** 幂等过期时间 */
    private static final long IDEMPOTENT_TTL_SECONDS = 300;

    // ==================== 第一阶段：行为上报 ====================

    /**
     * 行为上报入口（网关调用）
     * 幂等控制：同一 behaviorId 只处理一次
     */
    public BehaviorReportResponse reportBehavior(BehaviorEvent event) {
        long startTime = System.currentTimeMillis();
        String behaviorId = event.getBehaviorId();
        long userId = event.getUserId();

        MDC.put("behaviorId", behaviorId);
        MDC.put("userId", String.valueOf(userId));
        log.info("行为上报开始, userId={}, behaviorId={}, type={}, itemId={}",
                userId, behaviorId, event.getActionType(), event.getItemId());

        try {
            // 1. 参数校验
            validateEvent(event);

            // 2. 幂等控制：基于 behaviorId 去重
            String idempotentKey = IDEMPOTENT_PREFIX + behaviorId;
            Boolean isFirst = redisTemplate.opsForValue()
                    .setIfAbsent(idempotentKey, "1", IDEMPOTENT_TTL_SECONDS, TimeUnit.SECONDS);
            if (Boolean.FALSE.equals(isFirst)) {
                log.info("行为上报幂等命中, behaviorId={}", behaviorId);
                return BehaviorReportResponse.duplicate(behaviorId);
            }

            // 3. 补充上下文信息
            enrichEvent(event);

            // 4. 发送 Kafka 消息
            String message = JSON.toJSONString(event);
            try {
                ListenableFuture<SendResult<String, String>> future =
                        kafkaTemplate.send(BEHAVIOR_TOPIC, String.valueOf(userId), message);
                future.addCallback(
                        result -> log.info("Kafka发送成功, behaviorId={}, partition={}, offset={}",
                                behaviorId,
                                result.getRecordMetadata().partition(),
                                result.getRecordMetadata().offset()),
                        ex -> {
                            log.error("Kafka发送失败, behaviorId={}", behaviorId, ex);
                            // 发送失败时删除幂等标记，允许重试
                            redisTemplate.delete(idempotentKey);
                        }
                );
            } catch (Exception e) {
                log.error("Kafka发送异常, behaviorId={}", behaviorId, e);
                redisTemplate.delete(idempotentKey);
                throw new BehaviorReportException("Kafka发送失败", e);
            }

            // 5. 同步更新用户行为序列（Redis List，保证实时性）
            try {
                userProfileService.appendUserAction(userId, buildUserAction(event));
            } catch (Exception e) {
                log.warn("行为序列更新失败, userId={}, behaviorId={}", userId, behaviorId, e);
                // 不影响主流程，后续 Kafka 消费者会补偿
            }

            long costMs = System.currentTimeMillis() - startTime;
            log.info("行为上报完成, userId={}, behaviorId={}, cost={}ms",
                    userId, behaviorId, costMs);

            return BehaviorReportResponse.success(behaviorId);

        } catch (IllegalArgumentException e) {
            log.warn("行为上报参数校验失败, behaviorId={}, error={}", behaviorId, e.getMessage());
            return BehaviorReportResponse.invalidParam(behaviorId, e.getMessage());
        } catch (BehaviorReportException e) {
            log.error("行为上报异常, behaviorId={}", behaviorId, e);
            return BehaviorReportResponse.fail(behaviorId, e.getMessage());
        } catch (Exception e) {
            log.error("行为上报未知异常, behaviorId={}", behaviorId, e);
            return BehaviorReportResponse.fail(behaviorId, "系统异常");
        } finally {
            MDC.remove("behaviorId");
            MDC.remove("userId");
        }
    }

    /**
     * 参数校验
     */
    private void validateEvent(BehaviorEvent event) {
        if (event.getUserId() == null || event.getUserId() <= 0) {
            throw new IllegalArgumentException("userId无效");
        }
        if (event.getItemId() == null || event.getItemId() <= 0) {
            throw new IllegalArgumentException("itemId无效");
        }
        if (StringUtils.isBlank(event.getActionType())) {
            throw new IllegalArgumentException("actionType不能为空");
        }
        if (!Arrays.asList("click", "purchase", "collect", "share", "expose").contains(
                event.getActionType())) {
            throw new IllegalArgumentException("actionType无效: " + event.getActionType());
        }
        if (StringUtils.isBlank(event.getBehaviorId())) {
            throw new IllegalArgumentException("behaviorId不能为空");
        }
    }

    /**
     * 补充事件上下文
     */
    private void enrichEvent(BehaviorEvent event) {
        if (event.getTimestamp() == null) {
            event.setTimestamp(System.currentTimeMillis());
        }
        if (event.getServerTime() == null) {
            event.setServerTime(System.currentTimeMillis());
        }
    }

    private UserAction buildUserAction(BehaviorEvent event) {
        UserAction action = new UserAction();
        action.setItemId(event.getItemId());
        action.setActionType(event.getActionType());
        action.setTimestamp(event.getTimestamp());
        action.setContext(event.getContext());
        return action;
    }

    // ==================== 第二阶段：Kafka 消费 → 实时特征更新 ====================

    /**
     * Kafka 消费者：处理行为消息，更新实时特征
     */
    @Slf4j
    @Component
    public static class BehaviorKafkaConsumer {

        @Autowired
        private RedisTemplate<String, String> redisTemplate;
        @Autowired
        private FeatureStoreService featureStoreService;
        @Autowired
        private ModelUpdateService modelUpdateService;
        @Autowired
        private BehaviorLogRepository behaviorLogRepo;

        private static final String REALTIME_FEATURE_PREFIX = "user:rt_feature:";
        private static final String PROCESSED_PREFIX = "behavior:processed:";

        /**
         * 消费行为消息
         */
        @KafkaListener(topics = "user_behavior", groupId = "rec_behavior_group")
        public void onMessage(ConsumerRecord<String, String> record,
                              Acknowledgment ack) {
            String behaviorId = null;
            try {
                BehaviorEvent event = JSON.parseObject(record.value(), BehaviorEvent.class);
                behaviorId = event.getBehaviorId();
                long userId = event.getUserId();

                // 1. 消费幂等：防止 Kafka 重试导致重复处理
                String processedKey = PROCESSED_PREFIX + behaviorId;
                Boolean isNew = redisTemplate.opsForValue()
                        .setIfAbsent(processedKey, "1", 7, TimeUnit.DAYS);
                if (Boolean.FALSE.equals(isNew)) {
                    log.info("消费幂等命中, behaviorId={}", behaviorId);
                    ack.acknowledge();
                    return;
                }

                log.info("消费行为消息, userId={}, behaviorId={}, type={}, offset={}",
                        userId, behaviorId, event.getActionType(), record.offset());

                // 2. 更新实时特征
                updateRealtimeFeatures(userId, event);

                // 3. 写入行为日志（持久化）
                persistBehaviorLog(event);

                // 4. 触发模型增量更新（异步）
                modelUpdateService.triggerIncrementalUpdate(event);

                // 5. 手动提交 offset
                ack.acknowledge();

                log.info("行为消息处理完成, userId={}, behaviorId={}", userId, behaviorId);

            } catch (JsonParseException e) {
                log.error("消息解析失败, offset={}, value={}", record.offset(), record.value(), e);
                // 毒消息：跳过，不重试
                ack.acknowledge();
                // 删除幂等标记，避免后续正常消息被影响
                if (behaviorId != null) {
                    redisTemplate.delete(PROCESSED_PREFIX + behaviorId);
                }
            } catch (Exception e) {
                log.error("行为消息处理异常, behaviorId={}, offset={}", behaviorId, record.offset(), e);
                // 删除幂等标记，允许重试
                if (behaviorId != null) {
                    redisTemplate.delete(PROCESSED_PREFIX + behaviorId);
                }
                // 不 ack，让 Kafka 重试
                throw e;
            }
        }

        /**
         * 更新实时特征
         * 维护用户维度的实时统计特征
         */
        private void updateRealtimeFeatures(long userId, BehaviorEvent event) {
            String featureKey = REALTIME_FEATURE_PREFIX + userId;

            try {
                // 使用 Redis Hash 存储实时特征
                String actionType = event.getActionType();

                switch (actionType) {
                    case "click":
                        redisTemplate.opsForHash().increment(featureKey, "click_count_7d", 1);
                        redisTemplate.opsForHash().increment(featureKey, "click_count_1d", 1);
                        break;
                    case "purchase":
                        redisTemplate.opsForHash().increment(featureKey, "purchase_count_30d", 1);
                        redisTemplate.opsForHash().increment(featureKey, "purchase_count_1d", 1);
                        // 更新消费金额
                        Double amount = event.getContext() != null
                                ? toDouble(event.getContext().get("amount")) : 0.0;
                        redisTemplate.opsForHash().increment(featureKey,
                                "total_amount_30d", amount);
                        break;
                    case "collect":
                        redisTemplate.opsForHash().increment(featureKey, "collect_count_7d", 1);
                        break;
                    case "share":
                        redisTemplate.opsForHash().increment(featureKey, "share_count_7d", 1);
                        break;
                    default:
                        break;
                }

                // 更新最后活跃时间
                redisTemplate.opsForHash().put(featureKey, "last_active_time",
                        String.valueOf(System.currentTimeMillis()));

                // 设置过期时间
                redisTemplate.expire(featureKey, 7, TimeUnit.DAYS);

                log.info("实时特征更新完成, userId={}, type={}", userId, actionType);

            } catch (Exception e) {
                log.error("实时特征更新失败, userId={}", userId, e);
            }
        }

        private void persistBehaviorLog(BehaviorEvent event) {

        }

        private double toDouble(Object val) {
            if (val == null) return 0.0;
            try {
                return Double.parseDouble(val.toString());
            } catch (NumberFormatException e) {
                return 0.0;
            }
        }

    // ==================== 第三阶段：模型增量更新 ====================

    /**
     * 模型增量更新服务
     * 当用户行为积累到一定量级时，触发模型在线增量更新
     */
    @Slf4j
    @Service
    public static class ModelUpdateService {

        @Autowired
        private RedisTemplate<String, String> redisTemplate;
        @Autowired
        private ModelServingClient modelClient;

        private static final String UPDATE_COUNTER_PREFIX = "model:update_counter:";
        private static final String UPDATE_LOCK_PREFIX = "model:update_lock:";
        private static final int UPDATE_THRESHOLD = 10000;   // 每积累1万条行为触发更新
        private static final long LOCK_TTL_SECONDS = 300;     // 分布式锁超时5分钟

        /**
         * 触发增量更新
         */
        public void triggerIncrementalUpdate(BehaviorEvent event) {
            String counterKey = UPDATE_COUNTER_PREFIX + event.getActionType();
            Long count = redisTemplate.opsForValue().increment(counterKey);

            if (count != null && count >= UPDATE_THRESHOLD) {
                // 分布式锁：保证只有一个节点执行更新
                String lockKey = UPDATE_LOCK_PREFIX + event.getActionType();
                Boolean locked = redisTemplate.opsForValue()
                        .setIfAbsent(lockKey, "1", LOCK_TTL_SECONDS, TimeUnit.SECONDS);

                if (Boolean.TRUE.equals(locked)) {
                    try {
                        // 重置计数器
                        redisTemplate.opsForValue().set(counterKey, "0");
                        log.info("触发模型增量更新, type={}, accumulatedCount={}",
                                event.getActionType(), count);

                        // 异步执行增量更新
                        CompletableFuture.runAsync(() -> {
                            try {
                                doIncrementalUpdate(event.getActionType());
                            } catch (Exception e) {
                                log.error("模型增量更新失败, type={}", event.getActionType(), e);
                            } finally {
                                redisTemplate.delete(lockKey);
                            }
                        });

                    } catch (Exception e) {
                        log.error("触发增量更新异常", e);
                        redisTemplate.delete(lockKey);
                    }
                } else {
                    log.info("其他节点正在执行模型更新, 跳过, type={}", event.getActionType());
                }
            }
        }

        /**
         * 执行增量更新
         */
        private void doIncrementalUpdate(String actionType) {
            long startTime = System.currentTimeMillis();
            log.info("开始模型增量更新, type={}", actionType);

            try {
                // 1. 收集最近的行为数据作为训练样本
                // 2. 调用模型训练服务进行在线学习
                modelClient.incrementalTrain("ctr_model", actionType);

                // 3. 验证新模型效果
                double newAuc = modelClient.evaluate("ctr_model", "validation");
                log.info("模型增量更新完成, type={}, newAUC={}, cost={}ms",
                        actionType, newAuc, System.currentTimeMillis() - startTime);

                // 4. 如果新模型优于当前模型，切换线上模型
                if (newAuc > 0.75) {
                    modelClient.publishModel("ctr_model", "v_incremental_" + System.currentTimeMillis());
                    log.info("新模型已发布, AUC={}", newAuc);
                } else {
                    log.warn("新模型AUC不达标, 不切换, AUC={}", newAuc);
                }

            } catch (Exception e) {
                log.error("模型增量更新失败, type={}", actionType, e);
            }
        }
    }
}
```

#### 7.3.2 全链路代码实现

```java
/**
 * 推荐 ABTest 全链路
 * 实验配置 → 流量分桶 → 不同策略 → 效果统计 → 最优上线
 */
@Slf4j
@Service
public class ABTestFullChainService {

    @Autowired
    private ABTestConfigRepository configRepo;
    @Autowired
    private MultiRecallService multiRecallService;
    @Autowired
    private OnlineRankingService onlineRankingService;
    @Autowired
    private ReRankingService reRankingService;
    @Autowired
    private ABTestMetricsService metricsService;
    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /** 实验日志 topic */
    private static final String EXPERIMENT_LOG_TOPIC = "experiment_log";
    /** 幂等前缀 */
    private static final String IDEMPOTENT_PREFIX = "abtest:idempotent:";
    /** 流量分桶数 */
    private static final int TOTAL_BUCKETS = 100;

    // ==================== 第一阶段：实验配置管理 ====================

    /**
     * 实验配置实体
     */
    @Data
    public static class ABTestConfig {
        private String experimentId;          // 实验ID
        private String experimentName;        // 实验名称
        private String description;           // 实验描述
        private boolean active;               // 是否激活
        private long startTime;               // 开始时间
        private long endTime;                 // 结束时间
        private List<ExperimentGroup> groups; // 实验分组
        private List<String> metrics;         // 关注指标
        private int minSampleSize;            // 最小样本量
    }

    @Data
    public static class ExperimentGroup {
        private String name;                 // 分组名称
        private int trafficPercent;          // 流量占比（百分比）
        private String modelVersion;         // 模型版本
        private String recallStrategy;       // 召回策略
        private Map<String, String> params;  // 其他参数
    }

    /**
     * 创建实验配置
     */
    public String createExperiment(ABTestConfig config) {
        // 参数校验
        if (config.getGroups() == null || config.getGroups().isEmpty()) {
            throw new IllegalArgumentException("实验分组不能为空");
        }
        int totalPercent = config.getGroups().stream()
                .mapToInt(ExperimentGroup::getTrafficPercent)
                .sum();
        if (totalPercent != 100) {
            throw new IllegalArgumentException(
                    "流量占比总和必须为100, 当前=" + totalPercent);
        }

        String experimentId = "exp_" + System.currentTimeMillis() + "_"
                + UUID.randomUUID().toString().substring(0, 8);
        config.setExperimentId(experimentId);
        config.setActive(false);
        config.setStartTime(System.currentTimeMillis());

        configRepo.save(config);
        log.info("实验配置创建完成, experimentId={}, name={}",
                experimentId, config.getExperimentName());
        return experimentId;
    }

    /**
     * 启动实验
     */
    public void startExperiment(String experimentId) {
        ABTestConfig config = configRepo.findById(experimentId);
        if (config == null) {
            throw new IllegalArgumentException("实验不存在: " + experimentId);
        }
        if (config.isActive()) {
            log.warn("实验已启动, experimentId={}", experimentId);
            return;
        }
        config.setActive(true);
        configRepo.save(config);
        log.info("实验已启动, experimentId={}, name={}",
                experimentId, config.getExperimentName());
    }

    // ==================== 第二阶段：流量分桶 ====================

    /**
     * 流量分桶
     * 使用 MurmurHash 保证同一用户始终进入同一分组
     */
    public ExperimentGroup assignGroup(long userId, String experimentId) {
        ABTestConfig config = configRepo.findById(experimentId);
        if (config == null || !config.isActive()) {
            log.warn("实验不存在或未激活, experimentId={}, 返回默认对照组", experimentId);
            return config.getGroups().get(0); // 默认对照组
        }

        // 检查实验是否过期
        if (config.getEndTime() > 0 && System.currentTimeMillis() > config.getEndTime()) {
            log.warn("实验已过期, experimentId={}", experimentId);
            return config.getGroups().get(0);
        }

        // MurmurHash 分桶
        int hash = murmurHash3(userId + "_" + experimentId);
        int bucket = Math.abs(hash) % TOTAL_BUCKETS;

        // 根据流量占比分配分组
        int cumulative = 0;
        for (ExperimentGroup group : config.getGroups()) {
            cumulative += group.getTrafficPercent();
            if (bucket < cumulative) {
                return group;
            }
        }

        return config.getGroups().get(0);
    }

    /**
     * MurmurHash3 简化实现
     */
    private int murmurHash3(String key) {
        int h = 0;
        for (int i = 0; i < key.length(); i++) {
            h = h * 31 + key.charAt(i);
        }
        h ^= (h >>> 16);
        h *= 0x85ebca6b;
        h ^= (h >>> 13);
        h *= 0xc2b2ae35;
        h ^= (h >>> 16);
        return h;
    }

    // ==================== 第三阶段：执行不同策略的推荐 ====================

    /**
     * ABTest 推荐入口
     */
    public RecommendResponse recommendWithABTest(RecommendRequest request) {
        long startTime = System.currentTimeMillis();
        String requestId = request.getRequestId();
        long userId = request.getUserId();
        String experimentId = request.getExperimentId();

        // 幂等控制
        String idempotentKey = IDEMPOTENT_PREFIX + requestId;
        Boolean isFirst = redisTemplate.opsForValue()
                .setIfAbsent(idempotentKey, "1", 60, TimeUnit.SECONDS);
        if (Boolean.FALSE.equals(isFirst)) {
            log.info("ABTest请求幂等命中, requestId={}", requestId);
            return getCachedABTestResult(userId, requestId);
        }

        MDC.put("requestId", requestId);
        MDC.put("userId", String.valueOf(userId));
        log.info("ABTest推荐请求开始, userId={}, experimentId={}", userId, experimentId);

        try {
            // 1. 分桶：确定实验分组
            ExperimentGroup group = assignGroup(userId, experimentId);
            log.info("用户分桶完成, userId={}, experimentId={}, group={}",
                    userId, experimentId, group.getName());

            // 2. 根据分组配置执行不同策略
            List<RankedItem> result = executeStrategy(userId, request, group);

            // 3. 组装响应
            RecommendResponse response = new RecommendResponse();
            response.setRequestId(requestId);
            response.setUserId(userId);
            response.setItems(result);
            response.setTimestamp(System.currentTimeMillis());

            // 4. 记录实验日志（用于效果统计）
            logExperimentAssignment(userId, experimentId, group, requestId, result);

            // 5. 缓存结果
            cacheABTestResult(userId, requestId, response);

            long costMs = System.currentTimeMillis() - startTime;
            log.info("ABTest推荐完成, userId={}, group={}, cost={}ms, itemCount={}",
                    userId, group.getName(), costMs, result.size());

            return response;

        } catch (Exception e) {
            log.error("ABTest推荐异常, userId={}, experimentId={}", userId, experimentId, e);
            // 降级：使用默认策略
            List<RankedItem> fallback = executeDefaultStrategy(userId, request);
            RecommendResponse response = new RecommendResponse();
            response.setRequestId(requestId);
            response.setUserId(userId);
            response.setItems(fallback);
            response.setDegraded(true);
            response.setTimestamp(System.currentTimeMillis());
            return response;
        } finally {
            MDC.remove("requestId");
            MDC.remove("userId");
        }
    }

    /**
     * 根据实验分组执行不同推荐策略
     */
    private List<RankedItem> executeStrategy(long userId, RecommendRequest request,
                                              ExperimentGroup group) {
        log.info("执行实验策略, userId={}, group={}, modelVersion={}, recallStrategy={}",
                userId, group.getName(), group.getModelVersion(), group.getRecallStrategy());

        // 1. 召回：根据策略选择不同召回方式
        RecommendContext context = buildContext(request);
        List<RecallItem> recallItems;

        switch (group.getRecallStrategy()) {
            case "enhanced_vector":
                recallItems = multiRecallService.enhancedVectorRecall(userId, context);
                break;
            case "graph_recall":
                recallItems = multiRecallService.graphBasedRecall(userId, context);
                break;
            default:
                recallItems = multiRecallService.multiRecall(userId, context);
                break;
        }

        if (recallItems.isEmpty()) {
            log.warn("召回为空, userId={}, strategy={}", userId, group.getRecallStrategy());
            recallItems = multiRecallService.coldStartRecall(userId, context);
        }

        // 2. 排序：根据策略选择不同模型版本
        List<RankedItem> ranked = onlineRankingService.rankWithModel(
                userId, recallItems, context.getFeatures(), group.getModelVersion());

        // 3. 重排
        List<RankedItem> reRanked = reRankingService.reRank(userId, ranked, context);

        return reRanked;
    }

    /**
     * 默认策略（降级用）
     */
    private List<RankedItem> executeDefaultStrategy(long userId, RecommendRequest request) {
        RecommendContext context = buildContext(request);
        List<RecallItem> recallItems = multiRecallService.multiRecall(userId, context);
        List<RankedItem> ranked = onlineRankingService.rank(userId, recallItems, context.getFeatures());
        return reRankingService.reRank(userId, ranked, context);
    }

         * 获取实验指标快照

        public ExperimentMetrics getMetrics(String experimentId, String groupName) {
            String key = "abtest:metrics:" + experimentId + ":" + groupName;
            ExperimentMetrics metrics = new ExperimentMetrics();
            metrics.setExperimentId(experimentId);
            metrics.setGroupName(groupName);

            try {
                Map<Object, Object> rawMetrics = redisTemplate.opsForHash().entries(key);

                long exposure = toLong(rawMetrics.get("exposure_count"));
                long click = toLong(rawMetrics.get("click_count"));
                long conversion = toLong(rawMetrics.get("conversion_count"));
                double gmv = toDouble(rawMetrics.get("total_gmv"));

                long exposureUU = redisTemplate.opsForHyperLogLog().size(key + ":exposure_uu");
                long clickUU = redisTemplate.opsForHyperLogLog().size(key + ":click_uu");
                long conversionUU = redisTemplate.opsForHyperLogLog().size(key + ":conversion_uu");

                metrics.setExposureCount(exposure);
                metrics.setClickCount(click);
                metrics.setConversionCount(conversion);
                metrics.setTotalGMV(gmv);
                metrics.setExposureUU(exposureUU);
                metrics.setClickUU(clickUU);
                metrics.setConversionUU(conversionUU);
                metrics.setCtr(exposure > 0 ? (double) click / exposure : 0.0);
                metrics.setCvr(click > 0 ? (double) conversion / click : 0.0);
                metrics.setAvgGMV(conversion > 0 ? gmv / conversion : 0.0);

            } catch (Exception e) {
                log.error("获取实验指标失败, experimentId={}, groupName={}",
                        experimentId, groupName, e);
            }

            return metrics;
        }

        private long toLong(Object val) {
            if (val == null) return 0;
            return Long.parseLong(val.toString());

        private double toDouble(Object val) {
            if (val == null) return 0.0;
            return Double.parseDouble(val.toString());
        }

    /**
     * 实验效果分析服务
     */
    @Slf4j
    @Service
    public static class ABTestAnalysisService {

        @Autowired
        private ABTestConfigRepository configRepo;
        @Autowired
        private ABTestMetricsService metricsService;

        /**
         * 分析实验结果
         */
        public ExperimentAnalysisResult analyze(String experimentId) {
            ABTestConfig config = configRepo.findById(experimentId);
            if (config == null) {
                throw new IllegalArgumentException("实验不存在: " + experimentId);
            }

            ExperimentAnalysisResult result = new ExperimentAnalysisResult();
            result.setExperimentId(experimentId);
            result.setExperimentName(config.getExperimentName());

            // 1. 获取各分组指标
            ExperimentMetrics controlMetrics = null;
            Map<String, ExperimentMetrics> experimentMetricsMap = new HashMap<>();

            for (ExperimentGroup group : config.getGroups()) {
                ExperimentMetrics metrics = metricsService.getMetrics(
                        experimentId, group.getName());
                if (group.getName().equals("control") || group.getName().equals("baseline")) {
                    controlMetrics = metrics;
                } else {
                    experimentMetricsMap.put(group.getName(), metrics);
                }
                result.addGroupMetrics(group.getName(), metrics);
            }

            if (controlMetrics == null) {
                log.warn("未找到对照组, experimentId={}", experimentId);
                result.setConclusion("NO_CONTROL_GROUP");
                return result;
            }

            // 2. 样本量检查
            if (controlMetrics.getExposureCount() < config.getMinSampleSize()) {
                log.info("样本量不足, experimentId={}, controlExposure={}, minSample={}",
                        experimentId, controlMetrics.getExposureCount(), config.getMinSampleSize());
                result.setConclusion("INSUFFICIENT_SAMPLE");
                return result;
            }

            // 3. 显著性检验（t-test 简化版）
            String bestGroup = null;
            double bestCtr = controlMetrics.getCtr();
            double bestCvr = controlMetrics.getCvr();
            double bestGmv = controlMetrics.getTotalGMV();

            for (Map.Entry<String, ExperimentMetrics> entry : experimentMetricsMap.entrySet()) {
                String groupName = entry.getKey();
                ExperimentMetrics expMetrics = entry.getValue();

                // CTR 显著性检验
                boolean ctrSignificant = isSignificant(
                        controlMetrics.getCtr(), expMetrics.getCtr(),
                        controlMetrics.getExposureCount(), expMetrics.getExposureCount());

                // CVR 显著性检验
                boolean cvrSignificant = isSignificant(
                        controlMetrics.getCvr(), expMetrics.getCvr(),
                        controlMetrics.getClickCount(), expMetrics.getClickCount());

                double ctrLift = (expMetrics.getCtr() - controlMetrics.getCtr())
                        / Math.max(controlMetrics.getCtr(), 1e-10);
                double cvrLift = (expMetrics.getCvr() - controlMetrics.getCvr())
                        / Math.max(controlMetrics.getCvr(), 1e-10);
                double gmvLift = (expMetrics.getTotalGMV() - controlMetrics.getTotalGMV())
                        / Math.max(controlMetrics.getTotalGMV(), 1e-10);

                log.info("实验组分析, group={}, ctrLift={:.4f}%, cvrLift={:.4f}%, gmvLift={:.4f}%, "
                                + "ctrSignificant={}, cvrSignificant={}",
                        groupName, ctrLift * 100, cvrLift * 100, gmvLift * 100,
                        ctrSignificant, cvrSignificant);

                result.addLiftResult(groupName, ctrLift, cvrLift, gmvLift,
                        ctrSignificant, cvrSignificant);

                // 选择 CTR 显著提升且 GMV 不下降的最优组
                if (ctrSignificant && expMetrics.getCtr() > bestCtr
                        && expMetrics.getTotalGMV() >= controlMetrics.getTotalGMV()) {
                    bestCtr = expMetrics.getCtr();
                    bestCvr = expMetrics.getCvr();
                    bestGmv = expMetrics.getTotalGMV();
                    bestGroup = groupName;
                }
            }

            // 4. 结论
            if (bestGroup != null) {
                result.setWinningGroup(bestGroup);
                result.setConclusion("WINNER_FOUND");
                log.info("实验分析完成, 最优策略组={}, experimentId={}", bestGroup, experimentId);
            } else {
                result.setConclusion("NO_SIGNIFICANT_WINNER");
                log.info("无显著最优策略, experimentId={}", experimentId);
            }

            return result;
        }

        /**
         * 显著性检验（z-test 简化版，适用于比例指标）
         */
        private boolean isSignificant(double rate1, double rate2,
                                       long n1, long n2) {
            if (n1 < 30 || n2 < 30) return false; // 样本量过小

            double p1 = rate1;
            double p2 = rate2;
            double p = (p1 * n1 + p2 * n2) / (n1 + n2);
            double se = Math.sqrt(p * (1 - p) * (1.0 / n1 + 1.0 / n2));

            if (se < 1e-10) return false;

            double z = Math.abs(p2 - p1) / se;
            // z > 1.96 对应 95% 置信水平
            return z > 1.96;
        }

        /**
         * 最优策略全量上线
         */
        public void promoteWinner(String experimentId, String winningGroup) {
            ABTestConfig config = configRepo.findById(experimentId);
            if (config == null) {
                throw new IllegalArgumentException("实验不存在: " + experimentId);
            }

            ExperimentGroup winner = config.getGroups().stream()
                    .filter(g -> g.getName().equals(winningGroup))
                    .findFirst()
                    .orElseThrow(() -> new IllegalArgumentException("分组不存在: " + winningGroup));

            // 1. 将最优策略设为100%流量
            for (ExperimentGroup group : config.getGroups()) {
                if (group.getName().equals(winningGroup)) {
                    group.setTrafficPercent(100);
                } else {
                    group.setTrafficPercent(0);
                }
            }

            // 2. 标记实验结束
            config.setActive(false);
            config.setEndTime(System.currentTimeMillis());
            configRepo.save(config);

            log.info("最优策略已全量上线, experimentId={}, winningGroup={}, modelVersion={}, recallStrategy={}",
                    experimentId, winningGroup, winner.getModelVersion(), winner.getRecallStrategy());
        }
    }
```

### 7.4 全链路案例总结

| 案例 | 核心链路 | 幂等方案 | 异常处理 | 日志埋点 |
|------|---------|---------|---------|---------|
| 首页推荐请求 | 画像→召回→粗排→精排→重排→返回 | requestId + Redis SETNX | 三级降级（缓存→部分召回→热门兜底） | MDC 链路追踪 + 各阶段耗时日志 |
| 行为实时反馈 | 上报→Kafka→实时特征→模型更新 | behaviorId + Redis SETNX（上报侧） + processed标记（消费侧） | Kafka 发送失败删幂等允许重试 + 消费异常不 ack 触发重试 | 全链路 behaviorId 串联 + MDC |
| ABTest 全链路 | 配置→分桶→不同策略→统计→上线 | requestId + Redis SETNX | 降级到默认策略 + 实验过期返回对照组 | 实验日志异步记录 + 指标实时聚合 |

**幂等控制要点**：
1. **上报侧**：客户端生成唯一 behaviorId/requestId，服务端用 Redis SETNX 去重，TTL 覆盖重试窗口。
2. **消费侧**：Kafka 消费者使用 processed 标记去重，处理失败时删除标记允许重试，毒消息（解析失败）直接 ack 跳过。
3. **模型更新**：使用 Redis 分布式锁保证只有一个节点执行增量训练，避免重复更新。

**异常处理要点**：
1. **分级降级**：模型不可用→缓存结果，召回不可用→部分召回，全面故障→预计算热门列表。
2. **不返回空列表**：任何异常场景都保证返回推荐结果（即使是降级的热门列表）。
3. **异步补偿**：主流程失败的异步操作（如行为序列更新）不阻塞主流程，由后续 Kafka 消费者补偿。

**日志埋点要点**：
1. **链路追踪**：使用 MDC 注入 requestId/userId，贯穿全链路日志。
2. **阶段耗时**：每个阶段（画像、召回、排序、重排）记录耗时，便于性能瓶颈定位。
3. **效果闭环**：推荐→曝光→点击→转化，全链路日志打通，支撑模型训练和效果分析。
