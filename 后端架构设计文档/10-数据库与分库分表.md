# 数据库与分库分表

## 一、问题背景

### 1.1 单机数据库的瓶颈

随着业务快速发展，需要处理的数据量和高并发压力越来越大，单机数据库依赖硬件SCALE UP已不足以解决大规模OLTP需求，面临以下四大挑战：

1. **存不下**：单表/单库/单机受到天然的硬件限制，无法存储海量数据。当单表数据量达到千万级甚至亿级时，数据库的存储容量逼近极限。
2. **扛不住**：随着业务用户增加，在线实时高并发吞吐支撑不足。单机数据库的连接数、CPU、IO等资源存在上限，高并发写入会导致数据库响应变慢甚至崩溃。
3. **性能慢**：随着数据量增加，查询性能急剧下降。B+树索引在单表数据量过大时，树的层级增加，磁盘IO次数增多，查询延迟显著上升。大表DDL操作（如加列、加索引）耗时极长，影响业务连续性。
4. **扩展差**：大表在线DDL扩展风险巨大，可能锁表导致业务不可用。单机数据库无法通过简单增加机器来提升容量和性能。

### 1.2 分库分表的基本概念

**分库**：将数据从单个数据库拆分成多个数据库的过程，分为垂直分库和水平分库。

- **垂直分库**：根据业务领域划分，将相互之间可以明确划分领域边界的库表拆分到多个数据库中，分散数据存储和读取的压力，降低数据层面的耦合程度。例如将用户库、订单库、支付库拆分为独立的数据库实例。
- **水平分库**：当单表数据量过大时，根据一定的规则将单表拆分成多个表，存储在不同的库中，解决单库存储容量和性能瓶颈问题。

**分表**：将单张数据表拆分成多张表的过程，分为垂直分表和水平分表。

- **垂直分表**：根据数据表不同列的实际应用场景，将部分列拆分出来。可以结合冷热数据列拆分、大字段独立存储等方式。例如将订单基本信息和订单详情（大字段）拆分为两张表。
- **水平分表**：当单表数据量过大且持续增长时，根据一定规则将单表拆分成多表，降低单表容量，提升查询效率。

### 1.3 分库分表带来的挑战

分库分表解决了单表数据量大、单库读写压力大的问题，但也提高了系统的复杂度：

- **跨库关联问题**：分库分表后，单库下的表连接操作需要进行处理，常见方式有冗余存储数据、应用层拼接等
- **事务问题**：分库分表后，单库的本地事务变为分布式事务，需要根据不同场景采用分布式事务实现方式保证数据一致性
- **分布式ID问题**：单库单表可以采用自增主键保证ID唯一；分库分表后，不同库的自增ID会冲突，需要全局ID生成器
- **非分片键查询问题**：分库分表后以分片键路由，非分片键查询会导致全库扫描，需要异构索引等方案
- **数据迁移问题**：从单库单表迁移到分库分表，需要不停机迁移策略，保证平稳过渡

## 二、整体架构设计

### 2.1 透明化分片架构

业界大多采用透明化分片方案，通过数据库访问中间件对业务层屏蔽后端复杂的分布式存储逻辑，使业务使用分布式集群像使用单机数据库一样。该架构的优点是满足ACID准则、技术成熟成本可控、业务可平滑升级。

## 三、核心链路设计

### 3.1 分片策略设计

#### 3.1.1 分片键选择

分片键的选择是分库分表设计中最关键的决策，直接影响数据分布均匀度和查询效率。

**选择原则**：
1. 数据分布均匀：分片键的值分布应尽可能均匀，避免数据倾斜
2. 查询高频使用：分片键应是业务查询中最常用的条件字段
3. 不可变：分片键一旦确定不应变化，否则需要数据迁移
4. 单一性：一张表只选择一个主分片键，辅助维度通过异构索引解决

**常见分片键选择**：

```java
// 分片键选择示例
public class ShardKeyStrategy {

    // 以用户ID为分片键 - 适合C2C场景
    // 优点：用户维度查询直接路由，数据分布均匀
    // 缺点：商家维度查询需要异构索引
    public static final String SHARD_KEY_USER_ID = "user_id";

    // 以订单ID为分片键 - 适合订单场景
    // 优点：订单ID全局唯一，可以嵌入分片信息
    // 缺点：用户维度查询需要异构索引
    public static final String SHARD_KEY_ORDER_ID = "order_id";

    // 以租户ID为分片键 - 适合SaaS场景
    // 优点：租户隔离，大租户可独立分片
    // 缺点：租户间数据量不均可能导致倾斜
    public static final String SHARD_KEY_TENANT_ID = "tenant_id";
}
```

#### 3.1.2 分片算法

```java
// 分片算法接口
public interface ShardingAlgorithm {
    /**
     * 精确分片：根据分片键值路由到具体的库和表
     */
    String[] doShard(Collection<String> availableDbNames,
                     Collection<String> availableTableNames,
                     Comparable<?> shardValue);

    /**
     * 范围分片：根据分片键范围路由
     */
    Collection<String> doRangeShard(Collection<String> availableTargetNames,
                                     Range<Comparable<?>> range);
}

// 哈希取模分片算法
public class HashModShardingAlgorithm implements ShardingAlgorithm {

    @Override
    public String[] doShard(Collection<String> dbNames,
                             Collection<String> tableNames,
                             Comparable<?> shardValue) {
        String value = String.valueOf(shardValue);
        int hash = Math.abs(value.hashCode());

        List<String> dbList = new ArrayList<>(dbNames);
        List<String> tableList = new ArrayList<>(tableNames);

        int dbIndex = hash % dbList.size();
        // 二次哈希确定表索引
        int tableIndex = (hash / dbList.size()) % tableList.size();

        return new String[]{
            dbList.get(dbIndex),
            tableList.get(tableIndex)
        };
    }

    @Override
    public Collection<String> doRangeShard(Collection<String> targetNames,
                                             Range<Comparable<?>> range) {
        // 哈希分片不支持范围查询，返回所有分片
        return targetNames;
    }
}

// 一致性哈希分片算法
public class ConsistentHashShardingAlgorithm implements ShardingAlgorithm {

    private final TreeMap<Long, String> ring = new TreeMap<>();
    private final int virtualNodes = 160;

    public ConsistentHashShardingAlgorithm(Collection<String> nodes) {
        for (String node : nodes) {
            for (int i = 0; i < virtualNodes; i++) {
                long hash = hash(node + "#" + i);
                ring.put(hash, node);
            }
        }
    }

    @Override
    public String[] doShard(Collection<String> dbNames,
                             Collection<String> tableNames,
                             Comparable<?> shardValue) {
        long hash = hash(String.valueOf(shardValue));
        SortedMap<Long, String> tail = ring.tailMap(hash);
        String target = tail.isEmpty() ? ring.firstEntry().getValue()
                                        : tail.get(tail.firstKey());
        return new String[]{target};
    }

    private long hash(String key) {
        return Murmur3_128.hash().hashUnencodedChars(key).asLong();
    }
}

// 日期范围分片算法 - 适合按时间增长的数据
public class DateRangeShardingAlgorithm implements ShardingAlgorithm {

    @Override
    public Collection<String> doRangeShard(Collection<String> targetNames,
                                             Range<Comparable<?>> range) {
        String lower = String.valueOf(range.lowerEndpoint());
        String upper = String.valueOf(range.upperEndpoint());

        List<String> result = new ArrayList<>();
        for (String name : targetNames) {
            // 表名格式：order_202301, order_202302...
            if (name.compareTo(lower) >= 0 && name.compareTo(upper) <= 0) {
                result.add(name);
            }
        }
        return result;
    }
}
```

#### 3.1.3 容量规划

容量规划是分库分表设计的基础，需要预估3-5年的数据增长量。

**表数目决策**：一般情况下，建议单个物理分表的容量不超过1000万行数据。

```
分表数 = (未来3-5年总记录行数) / (单张表建议记录行数)
       = (总行数) / 1000万
```

建议表的数目是2的幂次个数，方便未来可能的迁移。

**库数目决策**：按照存储容量计算。

```
分库数 = (3-5年内的存储容量) / (单个库建议存储容量)
       = (总存储) / 300GB
```

单个库建议存储容量控制在300GB以内，库的数目才是最终决定容量大小。

**实际案例**：某系统预估5年后工单总量约31.6亿，28张关联表合计数据量约42TB：
- 分表数：31.6亿 / 1000万 = 316，取2的幂次方 → 512张表
- 分库数：42TB / 0.3TB = 140，考虑80%使用率 → 128个库
- 单库数据量：420GB（在300GB*1.4的安全范围内）

### 3.2 SQL路由引擎

#### 3.2.1 路由流程

```java
// SQL路由引擎核心流程
public class SQLRouteEngine {

    private final ShardingRule shardingRule;
    private final SQLParser sqlParser;

    public RouteResult route(String sql, List<Object> parameters) {
        // 1. 解析SQL
        SQLStatement sqlStatement = sqlParser.parse(sql);

        // 2. 提取分片键值
        Optional<Comparable<?>> shardValue = extractShardValue(
            sqlStatement, parameters);

        // 3. 判断SQL类型并路由
        if (sqlStatement instanceof SelectStatement) {
            return routeSelect(sqlStatement, shardValue);
        } else if (sqlStatement instanceof InsertStatement) {
            return routeInsert(sqlStatement, shardValue);
        } else if (sqlStatement instanceof UpdateStatement) {
            return routeUpdate(sqlStatement, shardValue);
        } else if (sqlStatement instanceof DeleteStatement) {
            return routeDelete(sqlStatement, shardValue);
        }

        // 4. 无法提取分片键，全路由
        return routeAll();
    }

    private RouteResult routeSelect(SQLStatement stmt,
                                     Optional<Comparable<?>> shardValue) {
        if (shardValue.isPresent()) {
            // 精确路由
            String[] target = shardingRule.getAlgorithm()
                .doShard(shardingRule.getDbNames(),
                         shardingRule.getTableNames(),
                         shardValue.get());
            return RouteResult.singleRoute(target[0], target[1]);
        }

        // 检查是否有范围查询
        Optional<Range<Comparable<?>>> range = extractRange(stmt);
        if (range.isPresent()) {
            Collection<String> targets = shardingRule.getAlgorithm()
                .doRangeShard(shardingRule.getTableNames(), range.get());
            return RouteResult.multiRoute(targets);
        }

        // 无分片键，全路由（生产环境应告警）
        logger.warn("SQL缺少分片键，执行全路由: {}", stmt);
        return routeAll();
    }

    private RouteResult routeInsert(SQLStatement stmt,
                                     Optional<Comparable<?>> shardValue) {
        if (!shardValue.isPresent()) {
            throw new ShardingException("INSERT语句必须包含分片键");
        }
        String[] target = shardingRule.getAlgorithm()
            .doShard(shardingRule.getDbNames(),
                     shardingRule.getTableNames(),
                     shardValue.get());
        return RouteResult.singleRoute(target[0], target[1]);
    }
}
```

#### 3.2.2 SQL改写

路由到具体分库分表后，需要将逻辑表名改写为物理表名：

```java
// SQL改写引擎
public class SQLRewriteEngine {

    public String rewrite(String originalSql, RouteResult routeResult) {
        SQLStatement stmt = sqlParser.parse(originalSql);

        // 1. 表名改写：逻辑表名 → 物理表名
        String logicalTable = stmt.getTableName();
        String physicalTable = routeResult.getPhysicalTableName();
        String rewrittenSql = originalSql.replaceAll(
            "\\b" + logicalTable + "\\b", physicalTable);

        // 2. AVG聚合函数改写为SUM/COUNT
        if (stmt instanceof SelectStatement) {
            rewrittenSql = rewriteAvgFunction(rewrittenSql);
        }

        // 3. LIMIT改写（分页优化）
        if (stmt instanceof SelectStatement && hasOffset(stmt)) {
            rewrittenSql = rewriteLimitForPagination(rewrittenSql, stmt);
        }

        // 4. ORDER BY改写（归并排序优化）
        rewrittenSql = addOrderByIfMissing(rewrittenSql, stmt);

        return rewrittenSql;
    }

    // AVG改写：SELECT AVG(score) → SELECT SUM(score), COUNT(score)
    private String rewriteAvgFunction(String sql) {
        return sql.replaceAll("AVG\\((\\w+)\\)", "SUM($1) AS sum_$1, COUNT($1) AS count_$1");
    }

    // 分页改写：LIMIT 10 OFFSET 20 → LIMIT 30 (取前30条在内存中归并)
    private String rewriteLimitForPagination(String sql, SQLStatement stmt) {
        int offset = stmt.getLimit().getOffset();
        int rowCount = stmt.getLimit().getRowCount();
        return sql.replaceAll(
            "LIMIT\\s+\\d+\\s*(OFFSET|,)?\\s*\\d*",
            "LIMIT " + (offset + rowCount));
    }
}
```

#### 3.2.3 结果归并

```java
// 结果归并引擎
public class MergeEngine {

    public ResultSet merge(List<ResultSet> resultSets, SQLStatement stmt) {
        if (stmt instanceof SelectStatement) {
            SelectStatement select = (SelectStatement) stmt;

            if (select.hasGroupBy()) {
                return mergeGroupBy(resultSets, select);
            } else if (select.hasOrderBy()) {
                return mergeOrderBy(resultSets, select);
            } else if (select.hasAggregate()) {
                return mergeAggregate(resultSets, select);
            } else if (select.hasLimit()) {
                return mergeLimit(resultSets, select);
            }
        }
        return new SimpleMergedResultSet(resultSets);
    }

    // 聚合函数归并
    private ResultSet mergeAggregate(List<ResultSet> resultSets,
                                      SelectStatement select) {
        Map<String, AggregateMerger> mergers = new HashMap<>();
        mergers.put("COUNT", new CountMerger());
        mergers.put("SUM", new SumMerger());
        mergers.put("MAX", new MaxMerger());
        mergers.put("MIN", new MinMerger());
        mergers.put("AVG", new AvgMerger());

        // 从各分片结果中提取聚合值，在内存中合并
        return new AggregateMergedResultSet(resultSets, mergers, select);
    }

    // 排序归并 - 使用归并排序
    private ResultSet mergeOrderBy(List<ResultSet> resultSets,
                                    SelectStatement select) {
        // 各分片结果已按排序字段排序，使用优先队列进行归并
        return new OrderByMergedResultSet(resultSets, select.getOrderBy());
    }

    // 分页归并
    private ResultSet mergeLimit(List<ResultSet> resultSets,
                                  SelectStatement select) {
        int offset = select.getLimit().getOffset();
        int rowCount = select.getLimit().getRowCount();
        // 各分片已取 offset+rowCount 条，合并后跳过offset条，取rowCount条
        return new LimitMergedResultSet(resultSets, offset, rowCount);
    }
}
```

### 3.3 读写分离设计

```java
// 读写分离路由
public class ReadWriteSplittingRouter {

    private final LoadBalanceStrategy loadBalanceStrategy;

    public DataSource route(SQLStatementType type, String sql) {
        if (isWriteOperation(type)) {
            // 写操作路由到主库
            return masterDataSource;
        }

        // 读操作路由到从库
        // 1. 检查是否在主从延迟容忍范围内
        if (isInTransaction()) {
            // 事务内读操作路由到主库，保证一致性
            return masterDataSource;
        }

        // 2. 根据负载均衡策略选择从库
        List<DataSource> availableSlaves = getHealthySlaves();
        if (availableSlaves.isEmpty()) {
            // 无可用从库，降级到主库
            logger.warn("无可用从库，读请求降级到主库");
            return masterDataSource;
        }

        return loadBalanceStrategy.select(availableSlaves);
    }

    private boolean isWriteOperation(SQLStatementType type) {
        return type == SQLStatementType.INSERT
            || type == SQLStatementType.UPDATE
            || type == SQLStatementType.DELETE
            || type == SQLStatementType.REPLACE;
    }
}

// 负载均衡策略
public interface LoadBalanceStrategy {
    DataSource select(List<DataSource> slaves);
}

// 轮询负载均衡
public class RoundRobinStrategy implements LoadBalanceStrategy {
    private final AtomicInteger counter = new AtomicInteger(0);

    @Override
    public DataSource select(List<DataSource> slaves) {
        int index = Math.abs(counter.getAndIncrement()) % slaves.size();
        return slaves.get(index);
    }
}

// 基于权重的负载均衡
public class WeightedStrategy implements LoadBalanceStrategy {
    @Override
    public DataSource select(List<DataSource> slaves) {
        int totalWeight = slaves.stream()
            .mapToInt(this::getWeight).sum();
        int random = ThreadLocalRandom.current().nextInt(totalWeight);

        int cumulative = 0;
        for (DataSource slave : slaves) {
            cumulative += getWeight(slave);
            if (random < cumulative) {
                return slave;
            }
        }
        return slaves.get(0);
    }
}
```

### 3.4 非分片键查询方案

分库分表后以分片键路由，非分片键查询会导致全库扫描。业内一般通过"异构索引"方案解决——采用异步机制将原表的每次创建或更新，按另一个维度保存一份完整的数据表或索引表，以空间换时间。

```java
// 异构索引方案
public class HeterogeneousIndexService {

    @Autowired
    private OrderMapper orderMapper; // 分库分表数据源
    @Autowired
    private IndexMapper indexMapper; // 异构索引数据源

    // 创建订单时同时写入异构索引
    @Transactional
    public void createOrder(Order order) {
        // 1. 写入主表（以orderId为分片键）
        orderMapper.insert(order);

        // 2. 异步写入异构索引（以userId为分片键）
        OrderIndex index = new OrderIndex();
        index.setOrderId(order.getOrderId());
        index.setUserId(order.getUserId());
        index.setMerchantId(order.getMerchantId());
        index.setOrderStatus(order.getStatus());
        index.setCreateTime(order.getCreateTime());
        indexMapper.insert(index);
    }

    // 非分片键查询：先查异构索引获取orderId，再查主表

        // 1. 通过异构索引（以userId分片）查询orderId列表
        List<OrderIndex> indexes = indexMapper.findByUserId(userId);
```

### 3.5 数据迁移方案

从单库单表迁移到分库分表是一个风险性极高的操作。不停机数据迁移的关键步骤：

**1. 存量数据迁移**：将老库的历史数据按分库分表规则迁移到新库

**2. 增量数据同步**：迁移期间老库持续产生新数据，需要同步到新库

**3. 数据一致性校验**：确认新老库数据完全一致

**4. 流量切换**：逐步将读写流量从老库切换到新库

```java
// DAO层双写迁移方案
@Intercepts({
    @Signature(type = Executor.class, method = "update",
               args = {MappedStatement.class, Object.class})
})
public class DualWriteInterceptor implements Interceptor {

    private volatile boolean dualWriteEnabled = false;
    private final DataSource oldDataSource;
    private final DataSource newDataSource;

    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        if (!dualWriteEnabled) {
            // 双写未开启，只写老库
            return invocation.proceed();
        }

        MappedStatement ms = (MappedStatement) invocation.getArgs()[0];
        Object parameter = invocation.getArgs()[1];

        // 1. 写老库
        Object result = invocation.proceed();

        // 2. 异步写新库
        try {
            executeOnNewDataSource(ms, parameter);
        } catch (Exception e) {
            logger.error("新库写入失败，需要人工介入", e);
            alertService.alert("双写新库失败", e);
        }

        return result;
    }

    public void setDualWriteEnabled(boolean enabled) {
        this.dualWriteEnabled = enabled;
        logger.info("双写开关切换: {}", enabled);
    }
}
```

**灰度策略**：

| 阶段 | 读策略 | 写策略 | 说明 |
| --- | --- | --- | --- |
| 数据迁移阶段 | 读老库 | 写老库 | CDC数据同步工具迁移存量+增量数据 |
| 灰度阶段1 | 部分读新库 | 双写新老库 | 验证新库读取正确性 |
| 灰度阶段2 | 全部读新库 | 双写新老库 | 验证新库全量读取 |
| 全量切换 | 全部读新库 | 只写新库 | 下线老库写入 |

**回滚策略**：整个灰度阶段保持新老库双写，读出现问题切回老库，写出现问题关闭新库写入并开启CDC数据同步保证数据一致。

### 3.6 多数据源事务管理

分库分表改造中，新老库双写需要管理多个数据源的事务。声明式事务（@Transactional）无法管理多数据源，需要使用编程式事务：

```java
// 多数据源事务管理
@Aspect
public class MultiTransactionalAspect {

    @Around(value = "@annotation(multiTransactional)")
    public Object around(ProceedingJoinPoint pjp,
                         MultiTransactional multiTransactional) throws Throwable {
        Stack<DataSourceTransactionManager> txManagerStack = new Stack<>();
        Stack<TransactionStatus> txStatusStack = new Stack<>();

        try {
            // 1. 开启所有数据源的事务
            for (String txManagerName : multiTransactional.values()) {
                DataSourceTransactionManager txManager =
                    SpringApplicationContextHelper.getBean(txManagerName,
                        DataSourceTransactionManager.class);
                TransactionStatus status = txManager.getTransaction(
                    new DefaultTransactionDefinition());
                txManagerStack.push(txManager);
                txStatusStack.push(status);
            }

            // 2. 执行业务逻辑
            Object result = pjp.proceed();

            // 3. 提交所有事务
            while (!txManagerStack.isEmpty()) {
                txManagerStack.pop().commit(txStatusStack.pop());
            }
            return result;

        } catch (Throwable e) {
            // 4. 异常回滚所有事务
            while (!txManagerStack.isEmpty()) {
                try {
                    txManagerStack.pop().rollback(txStatusStack.pop());
                } catch (Exception rollbackEx) {
                    logger.error("事务回滚失败", rollbackEx);
                }
            }
            throw e;
        }
    }
}
```

```java
// 数据倾斜检测
public class DataSkewDetector {

    @Scheduled(cron = "0 0 2 * * ?")
    public void detectSkew() {
        Map<String, Long> shardDataSizes = new HashMap<>();

        // 统计各分片数据量
        for (String shard : allShards) {
            long count = countByShard(shard);
            shardDataSizes.put(shard, count);

        double avg = shardDataSizes.values().stream()
            .mapToLong(Long::longValue).average().orElse(0);

            if (entry.getValue() > threshold) {

                    entry.getKey(), entry.getValue(), avg));
            }
        }
    }
}
```

```java
// 批量插入优化
public class BatchInsertOptimizer {

    public void batchInsert(List<Order> orders) {
        // 按分片分组
        Map<String, List<Order>> groupedByShard = orders.stream()
            .collect(Collectors.groupingBy(this::calculateShard));

        // 并行插入各分片
        groupedByShard.entrySet().parallelStream().forEach(entry -> {
            String shard = entry.getKey();
            List<Order> shardOrders = entry.getValue();

            // 批量插入
            SqlSession session = sqlSessionFactory.openSession(ExecutorType.BATCH);
            try {
                OrderMapper mapper = session.getMapper(OrderMapper.class);
                for (Order order : shardOrders) {
                    mapper.insert(order);
                }
                session.commit();
            } finally {
                session.close();
            }
        });
    }

    private String calculateShard(Order order) {
        String[] target = shardingAlgorithm.doShard(
            dbNames, tableNames, order.getOrderId());
        return target[0] + ":" + target[1];
    }
}
```

## 六、最佳实践

### 6.1 分片键选择原则

1. **优先选择查询频率最高的字段**。分片键的选择直接决定了路由效率，查询频率最高的字段作为分片键可以最大化精确路由的覆盖率。
2. **确保数据分布均匀**。可以通过预采样分析分片键值分布，避免倾斜。
3. **避免使用可变字段**。分片键一旦确定不应变化，否则需要数据迁移。
4. **主维度和辅助维度尽量不要放在同一个数据库集群上**。辅助维度通过异构索引或分布式数据库解决。

### 6.2 容量规划建议

- 单个物理分表不超过1000万行数据
- 单个物理分库不超过300GB存储
- 分表数建议为2的幂次方（128、256、512等），方便未来迁移
- 预估3-5年的数据增长，留足扩展余量
- 库的数目决定最终容量上限，表数决定单表性能

### 6.3 常见踩坑

**坑1：非分片键查询导致全库扫描**。务必在中间件层拦截非分片键的查询操作，配置全路由告警。通过异构索引或分布式数据库解决非分片键查询需求。

**坑2：INSERT语句缺少分片键**。分片键是路由的依据，INSERT必须包含分片键，否则无法确定写入的目标分片。

**坑3：大表DDL导致锁表**。分库分表后DDL需要同时在多个分片执行，风险更大。建议使用pt-online-schema-change等在线DDL工具。

**坑4：读写分离在延迟面前失效**。主从延迟时，写后立即读可能读到从库的旧数据。对一致性敏感的场景应强制读主库。

**坑5：分布式事务未正确处理**。分库分表后，跨库操作不再是本地事务，需要根据场景选择合适的分布式事务方案。

**坑6：分表数设置不合理**。分表数太少导致单表数据量仍然过大；分表数太多导致路由开销增加和跨分片查询性能下降。

## 七、总结

分库分表是解决单机数据库容量和性能瓶颈的核心手段。通过透明化分片架构和数据库访问中间件，可以在对业务低侵入的前提下实现数据的水平扩展。

关键设计决策包括：
- **分片键选择**：选择查询频率最高、分布均匀的字段作为分片键
- **容量规划**：单表不超1000万行，单库不超300GB，分表数为2的幂次方
- **非分片键查询**：通过异构索引或分布式数据库解决
- **数据迁移**：采用双写+灰度切换策略，确保可回滚
- **事务一致性**：按场景选择合适的分布式事务方案

分库分表提高了系统的复杂度，在引入前应充分评估必要性，并做好充分的容量规划和迁移方案设计。

**场景描述**：用户下单后，系统根据 `userId` 路由到对应分库分表，通过 ShardingSphere 路由规则写入目标分片，同时生成全局唯一订单号。要求保证写入幂等性，防止重复下单。

**完整代码实现**：

```java
// ==================== 1. 全局订单号生成器 ====================

/**
 * 全局唯一订单号生成器
 * 订单号结构：[1位符号位][41位时间戳][10位机器ID][12位序列号] = 64bit
 * 订单号中嵌入分片信息，支持通过订单号反查分片位置
 */
public class OrderIdGenerator {

    private static final long EPOCH = 1672531200000L; // 2023-01-01 00:00:00
    private static final long MACHINE_ID_BITS = 10L;
    private static final long SEQUENCE_BITS = 12L;
    private static final long MAX_MACHINE_ID = ~(-1L << MACHINE_ID_BITS); // 1023
    private static final long SEQUENCE_MASK = ~(-1L << SEQUENCE_BITS);    // 4095

    private static final long MACHINE_ID_SHIFT = SEQUENCE_BITS;
    private static final long TIMESTAMP_SHIFT = SEQUENCE_BITS + MACHINE_ID_BITS;

    private final long machineId;
    private long sequence = 0L;
    private long lastTimestamp = -1L;

    private static final Logger logger = LoggerFactory.getLogger(OrderIdGenerator.class);

    public OrderIdGenerator(long machineId) {
        if (machineId < 0 || machineId > MAX_MACHINE_ID) {
            throw new IllegalArgumentException(
                "machineId 超出范围 [0, " + MAX_MACHINE_ID + "]");
        }
        this.machineId = machineId;
    }

    public synchronized long nextId() {
        long currentTimestamp = System.currentTimeMillis();

        // 时钟回拨检测
        if (currentTimestamp < lastTimestamp) {
            long offset = lastTimestamp - currentTimestamp;
            if (offset <= 5) {
                logger.warn("时钟回拨 {}ms，等待时钟追上", offset);
                try {
                    Thread.sleep(offset << 1);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    throw new IllegalStateException("时钟回拨等待被中断", e);
                }
                currentTimestamp = System.currentTimeMillis();
                if (currentTimestamp < lastTimestamp) {
                    throw new IllegalStateException(
                        "时钟回拨超过5ms，拒绝生成ID: " + offset);
                }
            } else {
                throw new IllegalStateException(
                    "时钟回拨超过5ms，拒绝生成ID: " + offset);
            }
        }

        if (currentTimestamp == lastTimestamp) {
            sequence = (sequence + 1) & SEQUENCE_MASK;
            if (sequence == 0) {
                // 当前毫秒序列号耗尽，等待下一毫秒
                currentTimestamp = tilNextMillis(lastTimestamp);
            }
        } else {
            sequence = 0L;
        }

        lastTimestamp = currentTimestamp;

        return ((currentTimestamp - EPOCH) << TIMESTAMP_SHIFT)
                | (machineId << MACHINE_ID_SHIFT)
                | sequence;
    }

    private long tilNextMillis(long lastTimestamp) {
        long timestamp = System.currentTimeMillis();
        while (timestamp <= lastTimestamp) {
            timestamp = System.currentTimeMillis();
        }
        return timestamp;
    }
}

// ==================== 2. 分片路由工具 ====================

/**
 * 分片路由计算工具
 * 分库规则：db_index = hash(userId) % dbCount
 * 分表规则：table_index = (hash(userId) / dbCount) % tableCount
 */
public class ShardRoutingUtil {

    private static final int DB_COUNT = 8;    // 8个分库
    private static final int TABLE_COUNT = 16; // 每库16张分表

    private static final Logger logger = LoggerFactory.getLogger(ShardRoutingUtil.class);

    /**
     * 根据userId计算目标库和表
     */
    public static String[] route(Long userId) {
        if (userId == null) {
            throw new ShardingException("分片键userId不能为空");
        }
        int hash = Math.abs(userId.hashCode());
        int dbIndex = hash % DB_COUNT;
        int tableIndex = (hash / DB_COUNT) % TABLE_COUNT;

        String dbName = String.format("ds_%04d", dbIndex);
        String tableName = String.format("t_order_%04d", tableIndex);

        logger.debug("userId={} 路由到 {}.{}", userId, dbName, tableName);
        return new String[]{dbName, tableName};
    }

    /**
     * 根据订单号反查分片位置（订单号中嵌入了路由信息）
     */
    public static String[] routeByOrderId(Long orderId) {
        // 订单号低10位中取高8位作为dbIndex，低2位+其他作为tableIndex
        // 实际项目中通常在订单号中嵌入userId的hash信息
        int dbIndex = (int) ((orderId >> 12) & 0xFF) % DB_COUNT;
        int tableIndex = (int) ((orderId >> 22) & 0xFF) % TABLE_COUNT;

        String dbName = String.format("ds_%04d", dbIndex);
        String tableName = String.format("t_order_%04d", tableIndex);
        return new String[]{dbName, tableName};
    }
}

public class OrderDbShardingAlgorithm implements StandardShardingAlgorithm<Long> {

    private static final int DB_COUNT = 8;

    @Override
    public String doShard(Collection<String> availableTargetNames,
                          PreciseShardingValue<Long> shardingValue) {
        Long userId = shardingValue.getValue();
        if (userId == null) {
            throw new ShardingException("分片键user_id不能为空");
        }
        int dbIndex = Math.abs(userId.hashCode()) % DB_COUNT;
        String target = String.format("ds_%04d", dbIndex);
        logger.debug("分库路由: userId={} -> {}", userId, target);
        return target;
    }

    @Override
    public Collection<String> doShard(Collection<String> availableTargetNames,
                                       RangeShardingValue<Long> shardingValue) {
        // 范围查询时返回所有库
        logger.warn("范围查询触发全库路由: {}", shardingValue);
        return availableTargetNames;
    }

    @Override
    public void init() {}
    @Override
    public String getType() { return "ORDER_DB_HASH_MOD"; }
}

public class OrderTableShardingAlgorithm implements StandardShardingAlgorithm<Long> {

    private static final int DB_COUNT = 8;
    private static final int TABLE_COUNT = 16;

    @Override
    public String doShard(Collection<String> availableTargetNames,
                          PreciseShardingValue<Long> shardingValue) {
        Long userId = shardingValue.getValue();
        if (userId == null) {
            throw new ShardingException("分片键user_id不能为空");
        }
        int hash = Math.abs(userId.hashCode());
        int tableIndex = (hash / DB_COUNT) % TABLE_COUNT;
        String target = String.format("t_order_%04d", tableIndex);
        logger.debug("分表路由: userId={} -> {}", userId, target);
        return target;
    }

    @Override
    public Collection<String> doShard(Collection<String> availableTargetNames,
                                       RangeShardingValue<Long> shardingValue) {
        return availableTargetNames;
    }

    @Override
    public void init() {}
    @Override
    public String getType() { return "ORDER_TABLE_HASH_MOD"; }
}

@Service
@Slf4j
public class OrderCreateService {

    @Autowired
    private OrderMapper orderMapper;
    @Autowired
    private OrderIndexService orderIndexService; // 异构索引
    @Autowired
    private RedisTemplate<String, String> redisTemplate;
    @Autowired
    private OrderIdGenerator orderIdGenerator;
    @Autowired
    private AlertService alertService;
    @Autowired
    private MeterRegistry meterRegistry;

    private static final String IDEMPOTENT_KEY_PREFIX = "order:create:";
    private static final long IDEMPOTENT_EXPIRE_SECONDS = 86400; // 24小时
    private static final int MAX_RETRY = 3;

    /**
     * 创建订单全链路入口
     */
    public OrderCreateResult createOrder(OrderCreateRequest request) {
        // ========== 1. 参数校验 ==========
        validateRequest(request);

        // ========== 2. 幂等检查 ==========
        String idempotentKey = request.getIdempotentKey();
        String redisKey = IDEMPOTENT_KEY_PREFIX + idempotentKey;

        String existingOrderId = redisTemplate.opsForValue().get(redisKey);
        if (existingOrderId != null) {
            log.info("幂等命中, idempotentKey={}, orderId={}, 直接返回已有订单",
                     idempotentKey, existingOrderId);
            return OrderCreateResult.alreadyExist(Long.valueOf(existingOrderId));
        }

        // ========== 3. 幂等锁（防并发） ==========
        Boolean locked = redisTemplate.opsForValue()
            .setIfAbsent(redisKey + ":lock", "1", 30, TimeUnit.SECONDS);
        if (Boolean.FALSE.equals(locked)) {
            log.warn("幂等锁竞争失败, idempotentKey={}, 短暂等待后重试", idempotentKey);
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            existingOrderId = redisTemplate.opsForValue().get(redisKey);
            if (existingOrderId != null) {
                return OrderCreateResult.alreadyExist(Long.valueOf(existingOrderId));
            }
            throw new BusinessException("订单创建中，请勿重复提交");
        }

        try {
            // ========== 4. 生成全局唯一订单号 ==========
            long orderId = orderIdGenerator.nextId();
            log.info("生成订单号: orderId={}, userId={}", orderId, request.getUserId());

            // ========== 5. 构建订单实体 ==========
            Order order = new Order();
            order.setOrderId(orderId);
            order.setUserId(request.getUserId());
            order.setMerchantId(request.getMerchantId());
            order.setAmount(request.getAmount());
            order.setStatus(0); // 待支付
            order.setIdempotentKey(idempotentKey);
            order.setCreateTime(LocalDateTime.now());
            order.setUpdateTime(LocalDateTime.now());

            // ========== 6. 写入分片（含重试） ==========
            boolean success = false;
            Exception lastException = null;

            for (int attempt = 1; attempt <= MAX_RETRY; attempt++) {
                try {
                    long start = System.currentTimeMillis();

                    // ShardingSphere自动路由：根据userId定位ds_x.t_order_y
                    orderMapper.insert(order);

                    long elapsed = System.currentTimeMillis() - start;
                    log.info("订单写入成功 attempt={} orderId={} userId={} " +
                             "elapsed={}ms target={}",
                             attempt, orderId, request.getUserId(), elapsed,
                             Arrays.toString(ShardRoutingUtil.route(request.getUserId())));

                    // 记录链路指标
                    meterRegistry.timer("db.shard.insert",
                        "shard", ShardRoutingUtil.route(request.getUserId())[0])
                        .record(elapsed, TimeUnit.MILLISECONDS);

                    success = true;
                    break;

                } catch (DuplicateKeyException e) {
                    // 唯一键冲突 = 幂等命中（数据库层面）
                    log.warn("订单号冲突（幂等）, orderId={}, 幂等返回", orderId);
                    return OrderCreateResult.alreadyExist(orderId);

                } catch (SQLException e) {
                    lastException = e;
                    log.error("订单写入失败 attempt={} orderId={} errorCode={} sqlState={}",
                              attempt, orderId, e.getErrorCode(), e.getSQLState(), e);
                    if (attempt < MAX_RETRY) {
                        // 指数退避
                        long backoff = (1L << attempt) * 100L;
                        try {
                            Thread.sleep(backoff);
                        } catch (InterruptedException ie) {
                            Thread.currentThread().interrupt();
                            throw new BusinessException("写入被中断", ie);
                        }
                    }
                } catch (Exception e) {
                    lastException = e;
                    log.error("订单写入未知异常 attempt={} orderId={}",
                              attempt, orderId, e);
                    break; // 非可重试异常，直接退出
                }
            }

            if (!success) {
                // 写入彻底失败，清理幂等锁
                redisTemplate.delete(redisKey + ":lock");
                alertService.alert(String.format(
                    "订单写入失败 userId=%d orderId=%d",
                    request.getUserId(), orderId), lastException);
                throw new BusinessException("订单创建失败，请稍后重试", lastException);
            }

            // ========== 7. 写入幂等标记 ==========
            redisTemplate.opsForValue().set(
                redisKey, String.valueOf(orderId),
                IDEMPOTENT_EXPIRE_SECONDS, TimeUnit.SECONDS);
            redisTemplate.delete(redisKey + ":lock");

            // ========== 8. 异步写入异构索引 ==========
            try {
                orderIndexService.asyncCreateIndex(order);
            } catch (Exception e) {
                // 异构索引写入失败不影响主流程，记录日志后续补偿
                log.error("异构索引写入失败 orderId={}, 后续MQ补偿", orderId, e);
            }

            // ========== 9. 返回结果 ==========
            log.info("订单创建全链路完成 orderId={} userId={}",
                     orderId, request.getUserId());
            return OrderCreateResult.success(orderId);

        } catch (BusinessException e) {
            throw e;
        } catch (Exception e) {
            log.error("订单创建全链路异常 userId={}", request.getUserId(), e);
            redisTemplate.delete(redisKey + ":lock");
            throw new BusinessException("订单创建异常", e);
        }
    }

    private void validateRequest(OrderCreateRequest request) {
        if (request == null) {
            throw new IllegalArgumentException("请求不能为空");
        }
        if (request.getUserId() == null || request.getUserId() <= 0) {
            throw new IllegalArgumentException("userId非法");
        }
        if (request.getMerchantId() == null || request.getMerchantId() <= 0) {
            throw new IllegalArgumentException("merchantId非法");
        }
        if (request.getAmount() == null
            || request.getAmount().compareTo(BigDecimal.ZERO) <= 0) {
            throw new IllegalArgumentException("amount必须大于0");
        }
        if (StringUtils.isBlank(request.getIdempotentKey())) {
            throw new IllegalArgumentException("幂等键不能为空");
        }
    }
}
```

### 案例二：跨分片查询全链路

**场景描述**：商家后台需要查询订单列表，查询条件为 `merchant_id`（非分片键），需要广播到所有分片查询，然后将结果归并排序，并进行分页处理。

**全链路流程**：

```
商家查询请求(merchant_id, page, size)
  │
  ▼
┌──────────────────────┐
│ 1. 检查异构索引       │ ── 有索引: 精确路由，跳过广播
│  (merchant_id维度)   │ ── 无索引: 继续广播查询
└──────────┬───────────┘
           │ (无索引)
           ▼
┌──────────────────────┐
│ 2. SQL改写            │ ── LIMIT 0,10 → LIMIT 0,10 (各分片)
│  (分页改写)          │ ── 添加ORDER BY create_time DESC
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 3. 广播查询           │ ── 并行查8库×16表 = 128个分片
│  (全路由)            │ ── 设置单分片超时500ms
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 4. 结果归并排序       │ ── 优先队列归并排序
│  (PriorityQueue)     │ ── 按create_time DESC
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 5. 分页处理           │ ── 跳过offset条，取size条
│  (内存分页)          │ ── 记录游标用于下一页
└──────────┬───────────┘
           │
           ▼
┌──────────────────────┐
│ 6. 结果返回 + 监控    │ ── 记录广播查询耗时
│                     │ ── 超阈值告警
└──────────────────────┘
```

**完整代码实现**：

```java
// ==================== 1. 跨分片查询Service ====================

@Service
@Slf4j
public class CrossShardQueryService {

    @Autowired
    private OrderMapper orderMapper;
    @Autowired
    private OrderIndexMapper indexMapper;
    @Autowired
    private ShardingDataSource shardingDataSource;
    @Autowired
    private MeterRegistry meterRegistry;
    @Autowired
    private AlertService alertService;

    // 广播查询的最大允许分片超时时间
    private static final long SHARD_QUERY_TIMEOUT_MS = 500;
    // 广播查询最大返回行数限制
    private static final int MAX_BROADCAST_RESULT = 10000;
    // 深度分页阈值
    private static final int DEEP_PAGINATION_THRESHOLD = 10000;

    /**
     * 商家订单查询全链路
     * 查询条件merchant_id为非分片键，需要跨分片查询
     */
    public PageResult<Order> queryMerchantOrders(MerchantOrderQuery query) {
        long startTime = System.currentTimeMillis();
        String traceId = MDC.get("traceId");

        try {
            // ========== 1. 参数校验与深度分页检查 ==========
            validateQuery(query);
            checkDeepPagination(query);

            // ========== 2. 优先尝试异构索引精确路由 ==========
            Optional<PageResult<Order>> indexResult = tryIndexRoute(query);
            if (indexResult.isPresent()) {
                log.info("异构索引命中, traceId={}, merchantId={}, " +
                         "无需广播查询, elapsed={}ms",
                         traceId, query.getMerchantId(),
                         System.currentTimeMillis() - startTime);
                return indexResult.get();
            }

            // ========== 3. 无索引，执行广播查询 ==========
            log.warn("未命中异构索引, 执行广播查询, traceId={}, merchantId={}",
                     traceId, query.getMerchantId());

            // ========== 4. SQL改写：各分片取 offset+size 条 ==========
            int fetchSize = query.getOffset() + query.getSize();
            // ShardingSphere会自动将LIMIT改写为各分片LIMIT fetchSize
            // 并在各分片结果上添加ORDER BY create_time DESC

            // ========== 5. 并行广播查询所有分片 ==========
            List<ShardQueryResult> shardResults = broadcastQuery(query, fetchSize);

            // ========== 6. 检查各分片查询结果 ==========
            int totalFetched = shardResults.stream()
                .mapToInt(r -> r.getOrders().size())
                .sum();

            if (totalFetched > MAX_BROADCAST_RESULT) {
                alertService.alert(String.format(
                    "广播查询返回数据量过大 merchantId=%d total=%d",
                    query.getMerchantId(), totalFetched));
                log.warn("广播查询结果过大, total={}, 截断处理", totalFetched);
            }

            // ========== 7. 归并排序 ==========
            List<Order> mergedOrders = mergeSort(shardResults, query);

            // ========== 8. 内存分页 ==========
            List<Order> pageData = applyPagination(mergedOrders,
                query.getOffset(), query.getSize());

            // ========== 9. 统计总数（优化：异构索引表count） ==========
            long total = countTotalOrders(query);

            long elapsed = System.currentTimeMillis() - startTime;
            log.info("跨分片查询完成 traceId={} merchantId={} " +
                     "shards={} merged={} pageData={} total={} elapsed={}ms",
                     traceId, query.getMerchantId(),
                     shardResults.size(), mergedOrders.size(),
                     pageData.size(), total, elapsed);

            // ========== 10. 监控 ==========
            meterRegistry.timer("db.shard.broadcast_query",
                "merchant_id", String.valueOf(query.getMerchantId()))
                .record(elapsed, TimeUnit.MILLISECONDS);

            if (elapsed > 1000) {
                alertService.alert(String.format(
                    "广播查询耗时过长 merchantId=%d elapsed=%dms",
                    query.getMerchantId(), elapsed));
            }

            return PageResult.of(pageData, total, query.getOffset(), query.getSize());

        } catch (Exception e) {
            log.error("跨分片查询异常 traceId={} merchantId={}",
                      traceId, query.getMerchantId(), e);
            throw new BusinessException("查询失败，请稍后重试", e);
        }
    }

    // ==================== 2. 异构索引路由尝试 ====================

    private Optional<PageResult<Order>> tryIndexRoute(MerchantOrderQuery query) {
        try {
            // 异构索引以merchant_id为分片键，可以精确路由
            // 先查出orderId列表，再批量查主表
            PageResult<Long> orderIdPage = indexMapper.findOrderIdsByMerchantId(
                query.getMerchantId(),
                query.getStatus(),
                query.getStartTime(),
                query.getEndTime(),
                query.getOffset(),
                query.getSize());

            if (orderIdPage == null || orderIdPage.getData().isEmpty()) {
                return Optional.of(PageResult.empty(
                    query.getOffset(), query.getSize()));
            }

            // 根据orderId批量查主表（ShardingSphere会自动路由）
            List<Order> orders = new ArrayList<>();
            for (Long orderId : orderIdPage.getData()) {
                Order order = orderMapper.findById(orderId);
                if (order != null) {
                    orders.add(order);
                }
            }

            // 索引命中且数据完整
            if (orders.size() == orderIdPage.getData().size()) {
                return Optional.of(PageResult.of(
                    orders, orderIdPage.getTotal(),
                    query.getOffset(), query.getSize()));
            }

            // 部分数据缺失（可能索引与主表不完全一致），降级广播查询
            log.warn("异构索引数据不完整, 命中{}/{}条, 降级广播查询",
                     orders.size(), orderIdPage.getData().size());
            return Optional.empty();

        } catch (Exception e) {
            log.warn("异构索引查询异常, 降级广播查询", e);
            return Optional.empty();
        }
    }

    // ==================== 3. 并行广播查询 ====================

    /**
     * 并行查询所有分片
     */
    private List<ShardQueryResult> broadcastQuery(MerchantOrderQuery query,
                                                   int fetchSize) {
        // ShardingSphere在SQL层面自动完成广播：
        // SELECT * FROM t_order WHERE merchant_id = ?
        //   ORDER BY create_time DESC LIMIT ?
        // → 改写为各分片的物理查询，并行执行，归并结果

        // 使用线程池并行查各分片
        ExecutorService executor = Executors.newFixedThreadPool(
            8, r -> {
                Thread t = new Thread(r, "broadcast-query-" + System.nanoTime());
                t.setDaemon(true);
                return t;
            });

        try {
            // ShardingSphere内部已实现并行执行，这里展示手动控制的逻辑
            List<CompletableFuture<ShardQueryResult>> futures = new ArrayList<>();

            for (int dbIndex = 0; dbIndex < 8; dbIndex++) {
                for (int tableIndex = 0; tableIndex < 16; tableIndex++) {
                    final int db = dbIndex;
                    final int tbl = tableIndex;

                    CompletableFuture<ShardQueryResult> future =
                        CompletableFuture.supplyAsync(() -> {
                            long shardStart = System.currentTimeMillis();
                            try {
                                // 使用Hint指定分片路由
                                HintManager hintManager = HintManager.getInstance();
                                hintManager.addDatabaseShardingValue(
                                    "t_order", String.format("ds_%04d", db));
                                hintManager.addTableShardingValue(
                                    "t_order", String.format("t_order_%04d", tbl));

                                List<Order> orders = orderMapper.findByMerchantId(
                                    query.getMerchantId(),
                                    query.getStatus(),
                                    query.getStartTime(),
                                    query.getEndTime(),
                                    fetchSize);

                                long elapsed = System.currentTimeMillis() - shardStart;
                                log.debug("分片查询完成 ds_{}{} t_order_{}{} " +
                                          "rows={} elapsed={}ms",
                                          String.format("%04d", db),
                                          String.format("%04d", tbl),
                                          orders.size(), elapsed);

                                return ShardQueryResult.success(
                                    db, tbl, orders, elapsed);

                            } catch (Exception e) {
                                long elapsed = System.currentTimeMillis() - shardStart;
                                log.error("分片查询失败 ds_{:04d}.t_order_{:04d} " +
                                          "elapsed={}ms", db, tbl, elapsed, e);
                                return ShardQueryResult.failed(db, tbl, e, elapsed);
                            } finally {
                                HintManager.clear();
                            }
                        }, executor)
                        .orTimeout(SHARD_QUERY_TIMEOUT_MS, TimeUnit.MILLISECONDS);

                    futures.add(future);
                }
            }

            // 等待所有分片查询完成
            CompletableFuture.allOf(
                futures.toArray(new CompletableFuture[0]))
                .join();

            return futures.stream()
                .map(f -> {
                    try {
                        return f.get();
                    } catch (Exception e) {
                        log.error("获取分片查询结果异常", e);
                        return ShardQueryResult.failed(-1, -1, e, 0);
                    }
                })
                .filter(r -> r.getOrders() != null && !r.getOrders().isEmpty())
                .collect(Collectors.toList());

        } finally {
            executor.shutdownNow();
        }
    }

    // ==================== 4. 归并排序 ====================

    /**
     * 多分片结果归并排序
     * 各分片结果已按create_time DESC排序，使用优先队列进行K路归并
     */
    private List<Order> mergeSort(List<ShardQueryResult> shardResults,
                                   MerchantOrderQuery query) {
        // 构建各分片的迭代器
        List<PeekableIterator<Order>> iterators = shardResults.stream()
            .map(r -> new PeekableIterator<>(r.getOrders().iterator()))
            .collect(Collectors.toList());

        // 优先队列：按create_time DESC排序
        PriorityQueue<PeekableIterator<Order>> pq = new PriorityQueue<>(
            (a, b) -> {
                Order orderA = a.peek();
                Order orderB = b.peek();
                if (orderA == null) return 1;
                if (orderB == null) return -1;
                // create_time降序
                return orderB.getCreateTime().compareTo(orderA.getCreateTime());
            });

        // 初始化优先队列
        for (PeekableIterator<Order> iter : iterators) {
            if (iter.hasNext()) {
                pq.offer(iter);
            }
        }

        // K路归并
        List<Order> merged = new ArrayList<>();
        while (!pq.isEmpty()) {
            PeekableIterator<Order> top = pq.poll();
            merged.add(top.next());
            if (top.hasNext()) {
                pq.offer(top);
            }
        }

        log.debug("归并排序完成, 输入分片数={}, 输出行数={}",
                  shardResults.size(), merged.size());
        return merged;
    }

    // ==================== 5. 内存分页 ====================

    private List<Order> applyPagination(List<Order> merged,
                                         int offset, int size) {
        if (offset >= merged.size()) {
            return Collections.emptyList();
        }
        int end = Math.min(offset + size, merged.size());
        return merged.subList(offset, end);
    }

    // ==================== 6. 总数统计 ====================

    private long countTotalOrders(MerchantOrderQuery query) {
        try {
            // 优先从异构索引表count（精确路由，性能好）
            return indexMapper.countByMerchantId(
                query.getMerchantId(),
                query.getStatus(),
                query.getStartTime(),
                query.getEndTime());
        } catch (Exception e) {
            log.warn("索引表count失败, 降级广播count", e);
            // 降级：广播count
            return orderMapper.countByMerchantIdBroadcast(
                query.getMerchantId(),
                query.getStatus(),
                query.getStartTime(),
                query.getEndTime());
        }
    }

    // ==================== 7. 校验与保护 ====================

    private void validateQuery(MerchantOrderQuery query) {
        if (query.getMerchantId() == null || query.getMerchantId() <= 0) {
            throw new IllegalArgumentException("merchantId非法");
        }
        if (query.getSize() <= 0 || query.getSize() > 100) {
            throw new IllegalArgumentException("每页大小必须在1-100之间");
        }
        if (query.getOffset() < 0) {
            throw new IllegalArgumentException("offset不能为负");
        }
    }

    private void checkDeepPagination(MerchantOrderQuery query) {
        if (query.getOffset() > DEEP_PAGINATION_THRESHOLD) {
            log.warn("深度分页警告 merchantId={} offset={} 超过阈值{}",
                     query.getMerchantId(), query.getOffset(),
                     DEEP_PAGINATION_THRESHOLD);
            throw new BusinessException(
                "查询深度过大，请使用时间范围缩小查询或使用游标分页");
        }
    }

    // ==================== 8. 辅助类 ====================

    /**
     * 可窥视迭代器，用于归并排序
     */
    private static class PeekableIterator<T> implements Iterator<T> {
        private final Iterator<T> delegate;
        private T next;

        PeekableIterator(Iterator<T> delegate) {
            this.delegate = delegate;
            this.next = delegate.hasNext() ? delegate.next() : null;
        }

        T peek() { return next; }

        @Override
        public boolean hasNext() { return next != null; }

        @Override
        public T next() {
            T current = next;
            next = delegate.hasNext() ? delegate.next() : null;
            return current;
        }
    }

    @Data
    @AllArgsConstructor
    private static class ShardQueryResult {
        private int dbIndex;
        private int tableIndex;
        private List<Order> orders;
        private long elapsedMs;
        private boolean success;
        private String errorMsg;

        static ShardQueryResult success(int db, int tbl,
                                         List<Order> orders, long elapsed) {
            return new ShardQueryResult(db, tbl, orders, elapsed, true, null);
        }

        static ShardQueryResult failed(int db, int tbl, Exception e, long elapsed) {
            return new ShardQueryResult(db, tbl, Collections.emptyList(),
                elapsed, false, e.getMessage());
        }
    }
}
```

### 案例三：分库分表扩容全链路

```java
/**
 * 新旧两套路由算法
 * 旧路由: db = hash(userId) % 4, table = (hash(userId)/4) % 8
 * 新路由: db = hash(userId) % 8, table = (hash(userId)/8) % 16
 */
public class DualRoutingUtil {

    private static final Logger logger = LoggerFactory.getLogger(DualRoutingUtil.class);

    public static String[] routeOld(Long userId) {
        int hash = Math.abs(userId.hashCode());
        int dbIndex = hash % 4;
        int tableIndex = (hash / 4) % 8;
        return new String[]{
            String.format("ds_%04d", dbIndex),
            String.format("t_order_%04d", tableIndex)
        };
    }

    public static String[] routeNew(Long userId) {
        int hash = Math.abs(userId.hashCode());
        int dbIndex = hash % 8;
        int tableIndex = (hash / 8) % 16;
        return new String[]{
            String.format("ds_%04d", dbIndex),
            String.format("t_order_%04d", tableIndex)
        };
    }

    /**
     * 判断新旧路由是否在同一分片（用于判断是否需要迁移）
     */
    public static boolean needsMigration(Long userId) {
        String[] oldRoute = routeOld(userId);
        String[] newRoute = routeNew(userId);
        return !oldRoute[0].equals(newRoute[0]) || !oldRoute[1].equals(newRoute[1]);
    }
}

// ==================== 3. 双写拦截器（核心） ====================

/**
 * 双写拦截器：在DAO层拦截写操作，同时写入新旧库
 */
@Intercepts({
    @Signature(type = Executor.class, method = "update",
               args = {MappedStatement.class, Object.class})
})
@Slf4j
public class DualWriteInterceptor implements Interceptor {

    @Autowired
    private ScaleConfigManager configManager;
    @Autowired
    private DataSource oldShardingDataSource;  // 旧分库分表数据源
    @Autowired
    private DataSource newShardingDataSource;  // 新分库分表数据源
    @Autowired
    private AlertService alertService;
    @Autowired
    private MeterRegistry meterRegistry;

    // 双写失败计数器
    private final AtomicLong newWriteFailCount = new AtomicLong(0);
    // 双写失败阈值告警
    private static final long FAIL_ALERT_THRESHOLD = 10;

    @Override
    public Object intercept(Invocation invocation) throws Throwable {
        if (!configManager.isScaleEnabled()) {
            // 扩容未启动，直接走原逻辑
            return invocation.proceed();
        }

        MappedStatement ms = (MappedStatement) invocation.getArgs()[0];
        Object parameter = invocation.getArgs()[1];

        // 判断操作类型
        SqlCommandType sqlCommandType = ms.getSqlCommandType();
        if (sqlCommandType == SqlCommandType.SELECT) {
            // 读操作：按灰度比例路由
            return handleRead(invocation);
        }

        // 写操作：双写
        return handleWrite(invocation, ms, parameter, sqlCommandType);
    }

    // ==================== 写操作双写 ====================

    private Object handleWrite(Invocation invocation, MappedStatement ms,
                                Object parameter, SqlCommandType cmdType)
            throws Throwable {

        if (configManager.isWriteNewOnly()) {
            // 已切为只写新库
            return executeOnNew(ms, parameter, cmdType);
        }

        // ========== 1. 写旧库（主库） ==========
        Object oldResult;
        try {
            oldResult = invocation.proceed();
            log.debug("旧库写入成功 sqlId={} cmd={}", ms.getId(), cmdType);
        } catch (Exception e) {
            log.error("旧库写入失败 sqlId={}", ms.getId(), e);
            throw e; // 旧库写入失败，直接抛出，影响业务
        }

        // ========== 2. 双写新库 ==========
        if (configManager.isDualWriteNewEnabled()) {
            try {
                executeOnNew(ms, parameter, cmdType);
                log.debug("新库双写成功 sqlId={}", ms.getId());
            } catch (Exception e) {
                long failCount = newWriteFailCount.incrementAndGet();
                log.error("新库双写失败 sqlId={} failCount={}",
                          ms.getId(), failCount, e);

                // 记录失败指标
                meterRegistry.counter("db.dualwrite.new.fail",
                    "sqlId", ms.getId()).increment();

                // 达到阈值告警
                if (failCount >= FAIL_ALERT_THRESHOLD) {
                    alertService.alert(String.format(
                        "双写新库失败次数达到阈值 %d, 建议暂停扩容", failCount), e);
                }

                // 双写新库失败不影响主流程（旧库已成功）
                // 记录到补偿队列，后续重试
                recordForCompensation(ms, parameter, cmdType);
            }
        }

        return oldResult;
    }

    // ==================== 读操作灰度路由 ====================

    private Object handleRead(Invocation invocation) throws Throwable {
        int readNewPercent = configManager.getReadNewPercent();
        if (readNewPercent <= 0) {
            // 全读旧库
            return invocation.proceed();
        }

        // 按灰度比例决定路由
        int random = ThreadLocalRandom.current().nextInt(100);
        if (random < readNewPercent) {
            // 路由到新库
            try {
                Object result = executeReadOnNew(invocation);
                log.debug("灰度读新库成功 percent={}", readNewPercent);
                return result;
            } catch (Exception e) {
                log.error("新库读取失败, 降级读旧库", e);
                meterRegistry.counter("db.scaleread.new.fail").increment();
                return invocation.proceed(); // 降级读旧库
            }
        }

        return invocation.proceed();
    }

    // ==================== 新库执行 ====================

    private Object executeOnNew(MappedStatement ms, Object parameter,
                                 SqlCommandType cmdType) {
        // 切换到新数据源执行
        DynamicDataSourceContextHolder.push("newShardingDataSource");
        try {
            SqlSession session = newSqlSession(newShardingDataSource);
            try {
                Executor executor = session.getConfiguration()
                    .getEnvironment().getExecutorFactory()
                    .getExecutor(session.getConfiguration(), false);
                return executor.update(ms, parameter);
            } finally {
                session.close();
            }
        } catch (Exception e) {
            throw new RuntimeException("新库执行失败: " + ms.getId(), e);
        } finally {
            DynamicDataSourceContextHolder.poll();
        }
    }

    private Object executeReadOnNew(Invocation invocation) throws Throwable {
        DynamicDataSourceContextHolder.push("newShardingDataSource");
        try {
            return invocation.proceed();
        } finally {
            DynamicDataSourceContextHolder.poll();
        }
    }

    // ==================== 补偿记录 ====================

    /**
     * 双写失败的记录发送到MQ补偿队列
     */
    private void recordForCompensation(MappedStatement ms, Object parameter,
                                        SqlCommandType cmdType) {
        try {
            CompensationMessage msg = new CompensationMessage();
            msg.setSqlId(ms.getId());
            msg.setParameter(JSON.toJSONString(parameter));
            msg.setCmdType(cmdType.name());
            msg.setFailTime(LocalDateTime.now());
            msg.setMaxRetry(5);

            // 发送到MQ，由消费者异步重试
            // mqProducer.send("dualwrite-compensation", msg);
            log.info("补偿消息已记录 sqlId={}", ms.getId());
        } catch (Exception e) {
            log.error("补偿消息发送失败, 需人工介入 sqlId={}", ms.getId(), e);
            alertService.alert("双写补偿消息发送失败: " + ms.getId(), e);
        }

@Service
@Slf4j
public class DataMigrationService {

    @Autowired
    private DataSource oldShardingDataSource;
    @Autowired
    private DataSource newShardingDataSource;
    @Autowired
    private ScaleConfigManager configManager;
    @Autowired
    private AlertService alertService;
    @Autowired
    private MeterRegistry meterRegistry;

    private static final int BATCH_SIZE = 500;
    private static final int MAX_CONCURRENT = 4;

    /**
     * 全量数据迁移：将旧库数据按新路由规则迁移到新库
     */
    public void migrateFullData() {
        log.info("========== 全量数据迁移开始 ==========");

        long totalStart = System.currentTimeMillis();
        AtomicLong totalMigrated = new AtomicLong(0);
        AtomicLong totalFailed = new AtomicLong(0);

        // 按旧分片并行迁移
        ExecutorService executor = Executors.newFixedThreadPool(MAX_CONCURRENT);
        List<CompletableFuture<Void>> futures = new ArrayList<>();

        for (int db = 0; db < configManager.getOldDbCount(); db++) {
            for (int tbl = 0; tbl < configManager.getOldTableCount(); tbl++) {
                final int dbIdx = db;
                final int tblIdx = tbl;

                futures.add(CompletableFuture.runAsync(() -> {
                    migrateShard(dbIdx, tblIdx, totalMigrated, totalFailed);
                }, executor));
            }
        }

        // 等待所有分片迁移完成
        CompletableFuture.allOf(futures.toArray(new CompletableFuture[0])).join();
        executor.shutdown();

        long elapsed = System.currentTimeMillis() - totalStart;
        log.info("========== 全量数据迁移完成 migrated={} failed={} elapsed={}ms ==========",
                 totalMigrated.get(), totalFailed.get(), elapsed);

        if (totalFailed.get() > 0) {
            alertService.alert(String.format(
                "数据迁移有失败记录, total=%d failed=%d",
                totalMigrated.get(), totalFailed.get()));
        }
    }

    /**
     * 迁移单个旧分片数据
     */
    private void migrateShard(int dbIdx, int tblIdx,
                               AtomicLong migrated, AtomicLong failed) {
        String oldDb = String.format("ds_%04d", dbIdx);
        String oldTbl = String.format("t_order_%04d", tblIdx);
        String shardName = oldDb + "." + oldTbl;

        log.info("开始迁移分片 {}", shardName);
        long shardStart = System.currentTimeMillis();

        // 使用游标分页迁移，避免大查询OOM
        Long lastOrderId = 0L;
        int batchCount = 0;

        try (Connection oldConn = oldShardingDataSource.getConnection();
             Connection newConn = newShardingDataSource.getConnection()) {

            // 设置新库批量写入
            newConn.setAutoCommit(false);

            while (true) {
                // 1. 从旧库批量读取
                String selectSql = String.format(
                    "SELECT * FROM %s.%s WHERE order_id > ? ORDER BY order_id LIMIT ?",
                    oldDb, oldTbl);

                List<Order> batch = new ArrayList<>(BATCH_SIZE);
                try (PreparedStatement ps = oldConn.prepareStatement(selectSql)) {
                    ps.setLong(1, lastOrderId);
                    ps.setInt(2, BATCH_SIZE);
                    try (ResultSet rs = ps.executeQuery()) {
                        while (rs.next()) {
                            batch.add(mapRowToOrder(rs));
                        }
                    }
                }

                if (batch.isEmpty()) {
                    break; // 该分片数据迁移完成
                }

                // 2. 写入新库（ShardingSphere自动按新路由规则分布）
                for (Order order : batch) {
                    try {
                        insertOrderToNew(newConn, order);
                        migrated.incrementAndGet();
                    } catch (SQLException e) {
                        if (e.getErrorCode() == 1062) {
                            // 主键冲突 = 已迁移过，跳过（幂等）
                            log.debug("迁移跳过(已存在) orderId={}",
                                      order.getOrderId());
                        } else {
                            failed.incrementAndGet();
                            log.error("迁移写入失败 orderId={}",
                                      order.getOrderId(), e);
                        }
                    }
                }

                newConn.commit();
                batchCount++;
                lastOrderId = batch.get(batch.size() - 1).getOrderId();

                // 每批次日志
                if (batchCount % 10 == 0) {
                    log.debug("分片 {} 迁移进度: batches={} lastOrderId={}",
                              shardName, batchCount, lastOrderId);
                }
            }

            long elapsed = System.currentTimeMillis() - shardStart;
            log.info("分片 {} 迁移完成 batches={} elapsed={}ms",
                     shardName, batchCount, elapsed);

            meterRegistry.gauge("db.migration.shard_elapsed",
                Tags.of("shard", shardName), elapsed);

        } catch (Exception e) {
            log.error("分片 {} 迁移异常", shardName, e);
            failed.incrementAndGet();
            alertService.alert("分片迁移异常: " + shardName, e);
        }
    }

    private Order mapRowToOrder(ResultSet rs) throws SQLException {
        Order order = new Order();
        order.setOrderId(rs.getLong("order_id"));
        order.setUserId(rs.getLong("user_id"));
        order.setMerchantId(rs.getLong("merchant_id"));
        order.setAmount(rs.getBigDecimal("amount"));
        order.setStatus(rs.getInt("status"));
        order.setIdempotentKey(rs.getString("idempotent_key"));
        order.setCreateTime(rs.getTimestamp("create_time").toLocalDateTime());
        order.setUpdateTime(rs.getTimestamp("update_time").toLocalDateTime());
        return order;
    }

    private void insertOrderToNew(Connection conn, Order order) throws SQLException {
        String sql = "INSERT INTO t_order (order_id, user_id, merchant_id, " +
                     "amount, status, idempotent_key, create_time, update_time) " +
                     "VALUES (?, ?, ?, ?, ?, ?, ?, ?)";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setLong(1, order.getOrderId());
            ps.setLong(2, order.getUserId());
            ps.setLong(3, order.getMerchantId());
            ps.setBigDecimal(4, order.getAmount());
            ps.setInt(5, order.getStatus());
            ps.setString(6, order.getIdempotentKey());
            ps.setTimestamp(7, Timestamp.valueOf(order.getCreateTime()));
            ps.setTimestamp(8, Timestamp.valueOf(order.getUpdateTime()));
            ps.executeUpdate();
        }
    }
}

// ==================== 5. 数据一致性校验 ====================

@Service
@Slf4j
public class DataConsistencyChecker {

    @Autowired
    private DataSource oldShardingDataSource;
    @Autowired
    private DataSource newShardingDataSource;
    @Autowired
    private AlertService alertService;

    private static final int CHECK_BATCH = 1000;

    /**
     * 全量一致性校验：逐条比对新旧库数据
     */
    public ConsistencyReport checkConsistency() {
        log.info("========== 开始数据一致性校验 ==========");
        long startTime = System.currentTimeMillis();

        ConsistencyReport report = new ConsistencyReport();

        for (int db = 0; db < 4; db++) {
            for (int tbl = 0; tbl < 8; tbl++) {
                checkShardConsistency(db, tbl, report);
            }
        }

        long elapsed = System.currentTimeMillis() - startTime;
        report.setElapsedMs(elapsed);

        log.info("========== 一致性校验完成 total={} match={} mismatch={} " +
                 "missing={} elapsed={}ms ==========",
                 report.getTotal(), report.getMatched(),
                 report.getMismatched(), report.getMissing(), elapsed);

        if (report.getMismatched() > 0 || report.getMissing() > 0) {
            alertService.alert(String.format(
                "数据一致性校验发现差异: mismatch=%d missing=%d",
                report.getMismatched(), report.getMissing()));
        }

        return report;
    }

    private void checkShardConsistency(int dbIdx, int tblIdx,
                                        ConsistencyReport report) {
        String oldDb = String.format("ds_%04d", dbIdx);
        String oldTbl = String.format("t_order_%04d", tblIdx);

        Long lastOrderId = 0L;

        try (Connection oldConn = oldShardingDataSource.getConnection();
             Connection newConn = newShardingDataSource.getConnection()) {

            while (true) {
                // 从旧库批量取数据
                List<Order> oldBatch = new ArrayList<>();
                String sql = String.format(
                    "SELECT * FROM %s.%s WHERE order_id > ? ORDER BY order_id LIMIT ?",
                    oldDb, oldTbl);
                try (PreparedStatement ps = oldConn.prepareStatement(sql)) {
                    ps.setLong(1, lastOrderId);
                    ps.setInt(2, CHECK_BATCH);
                    try (ResultSet rs = ps.executeQuery()) {
                        while (rs.next()) {
                            oldBatch.add(mapRowToOrder(rs));
                        }
                    }
                }

                if (oldBatch.isEmpty()) break;

                // 逐条比对
                for (Order oldOrder : oldBatch) {
                    report.incrementTotal();

                    // 在新库中查找对应记录（通过orderId精确路由）
                    Order newOrder = findInNew(newConn, oldOrder.getOrderId());

                    if (newOrder == null) {
                        report.incrementMissing();
                        log.error("新库缺失记录 orderId={}", oldOrder.getOrderId());
                    } else if (!equals(oldOrder, newOrder)) {
                        report.incrementMismatched();
                        log.error("数据不一致 orderId={} oldAmount={} newAmount={}",
                                  oldOrder.getOrderId(),
                                  oldOrder.getAmount(), newOrder.getAmount());
                    } else {
                        report.incrementMatched();
                    }
                }

                lastOrderId = oldBatch.get(oldBatch.size() - 1).getOrderId();
            }

        } catch (Exception e) {
            log.error("一致性校验异常 shard={}.{}", oldDb, oldTbl, e);
        }
    }

    private Order findInNew(Connection conn, Long orderId) throws SQLException {
        String sql = "SELECT * FROM t_order WHERE order_id = ?";
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setLong(1, orderId);
            try (ResultSet rs = ps.executeQuery()) {
                if (rs.next()) {
                    return mapRowToOrder(rs);
                }
            }
        }
        return null;
    }

    private boolean equals(Order a, Order b) {
        return Objects.equals(a.getOrderId(), b.getOrderId())
            && Objects.equals(a.getUserId(), b.getUserId())
            && Objects.equals(a.getMerchantId(), b.getMerchantId())
            && a.getAmount().compareTo(b.getAmount()) == 0
            && Objects.equals(a.getStatus(), b.getStatus());
    }

    private Order mapRowToOrder(ResultSet rs) throws SQLException {
        Order order = new Order();
        order.setOrderId(rs.getLong("order_id"));
        order.setUserId(rs.getLong("user_id"));
        order.setMerchantId(rs.getLong("merchant_id"));
        order.setAmount(rs.getBigDecimal("amount"));
        order.setStatus(rs.getInt("status"));
        order.setCreateTime(rs.getTimestamp("create_time").toLocalDateTime());
        order.setUpdateTime(rs.getTimestamp("update_time").toLocalDateTime());
        return order;
    }
}

@RestController
@RequestMapping("/scale")
@Slf4j
public class ScaleController {

    @Autowired
    private DataMigrationService migrationService;
    @Autowired
    private DataConsistencyChecker consistencyChecker;
    @Autowired
    private ScaleConfigManager configManager;
    @Autowired
    private AlertService alertService;

    /**
     * 阶段1：全量数据迁移
     */
    @PostMapping("/migrate")
    public String startMigration() {
        if (configManager.isScaleEnabled()) {
            new Thread(() -> {
                try {
                    migrationService.migrateFullData();
                } catch (Exception e) {
                    log.error("全量迁移异常", e);
                    alertService.alert("全量数据迁移异常", e);
                }
            }, "data-migration").start();
            return "迁移任务已启动";
        }
        return "请先开启扩容总开关";
    }

    /**
     * 阶段2：一致性校验
     */
    @PostMapping("/check")
    public ConsistencyReport checkConsistency() {
        return consistencyChecker.checkConsistency();
    }

    /**
     * 阶段3：开启双写
     */
    @PostMapping("/dualwrite/{enabled}")
    public String toggleDualWrite(@PathVariable boolean enabled) {
        configManager.setDualWriteNewEnabled(enabled);
        log.warn("双写开关已变更: {}", enabled);
        alertService.alert("双写开关已变更: " + enabled);
        return "双写开关: " + enabled;
    }

    /**
     * 阶段4：灰度切读
     */
    @PostMapping("/readnew/{percent}")
    public String setReadNewPercent(@PathVariable int percent) {
        if (percent < 0 || percent > 100) {
            throw new IllegalArgumentException("灰度比例必须在0-100之间");
        }
        configManager.setReadNewPercent(percent);
        log.warn("读路由灰度比例变更: {}%", percent);
        alertService.alert("读路由灰度比例变更: " + percent + "%");
        return "灰度比例: " + percent + "%";
    }

    /**
     * 阶段5：切为只写新库
     */
    @PostMapping("/writenewonly/{enabled}")
    public String toggleWriteNewOnly(@PathVariable boolean enabled) {
        configManager.setWriteNewOnly(enabled);
        log.warn("只写新库开关变更: {}", enabled);
        alertService.alert("只写新库开关变更: " + enabled);
        return "只写新库: " + enabled;
    }

    /**
     * 阶段6：下线旧库
     */
    @PostMapping("/decommission")
    public String decommissionOld() {
        if (!configManager.isWriteNewOnly()) {
            throw new IllegalStateException("请先切换为只写新库");
        }
        // 最终一致性校验
        ConsistencyReport report = consistencyChecker.checkConsistency();
        if (report.getMismatched() > 0 || report.getMissing() > 0) {
            throw new IllegalStateException(String.format(
                "一致性校验未通过, mismatch=%d missing=%d",
                report.getMismatched(), report.getMissing()));
        }
        configManager.setOldClusterDecommissioned(true);
        log.warn("旧库已标记下线");
        alertService.alert("旧库已标记下线，可安全关闭");
        return "旧库已下线";
    }
}
```

**扩容阶段回滚策略**：

| 阶段 | 回滚操作 | 影响范围 |
| --- | --- | --- |
| 数据迁移 | 无需回滚（新库数据不影响旧库） | 无影响 |
| 双写开启 | 关闭 `dualWriteNew`，旧库数据完整 | 无影响 |
| 灰度切读 | `readNewPercent` 调回 0 | 读流量回到旧库 |
| 只写新库 | 关闭 `writeNewOnly`，重新开启双写 | 需CDC补齐旧库增量 |
| 旧库下线 | **不可回滚**，需人工介入恢复旧库 | 需重新部署旧库 |

**幂等控制设计要点**：

| 操作 | 幂等机制 | 说明 |
| --- | --- | --- |
| 数据迁移 | 主键冲突跳过 | 重复迁移同一记录时，INSERT遇到唯一键冲突自动跳过 |
| 双写补偿 | MQ重试+最大重试次数 | 双写失败的消息入MQ，消费者按最大5次重试 |
| 一致性校验 | 游标分页+断点续传 | 按orderId游标推进，中断后可从断点继续 |
| 切读灰度 | 百分比动态调整 | 可随时回调灰度比例，逐步验证 |
