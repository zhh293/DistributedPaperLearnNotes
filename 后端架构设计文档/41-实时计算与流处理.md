# 实时计算与流处理架构设计

## 一、问题背景

### 1.1 业务驱动

在当今互联网业务场景中，数据的实时性需求日益增强。传统的离线批处理（T+1）模式已经无法满足以下核心业务场景：

- **实时监控与告警**：系统运行指标、业务健康度需要秒级感知
- **实时数据看板**：运营决策依赖实时数据驱动，等待隔天数据意味着错失商机
- **实时风控反欺诈**：交易风控必须在毫秒级别完成判定，延迟等同于损失
- **实时推荐与搜索**：用户行为实时反馈到推荐模型，提升转化率
- **实时数据同步**：多系统间数据一致性保障，CDC（Change Data Capture）场景

### 1.2 实时计算的核心特征

实时计算系统需要具备以下四大核心特征：

| 特征 | 说明 | 量化目标 |
|------|------|----------|
| **高可用** | 7x24小时不间断运行，故障自愈 | 99.99% SLA |
| **可扩展** | 支持水平扩展，应对流量洪峰 | 线性扩展能力 |
| **低延迟** | 端到端延迟可控 | P99 < 1秒 |
| **聚合统计** | 支持多维度、多粒度聚合 | 窗口/全局聚合 |

### 1.3 统计口径的技术场景划分

根据业务对统计口径的不同需求，实时计算场景可以划分为三类窗口模型：

```
┌─────────────────────────────────────────────────────┐
│                  统计口径划分                          │
├───────────────┬─────────────────┬───────────────────┤
│  全局窗口      │   滚动窗口       │    滑动窗口        │
│ Global Window │ Tumbling Window │  Sliding Window   │
├───────────────┼─────────────────┼───────────────────┤
│ 从起始到当前   │  固定时间切片     │  固定窗口+滑动步长  │
│ 如：累计GMV    │ 如：每分钟PV     │ 如：近5分钟均值     │
│ 无界聚合       │  不重叠、无间隙   │  窗口可重叠         │
└───────────────┴─────────────────┴───────────────────┘
```

**全局窗口（Global Window）**：从业务起始时刻到当前时刻的累计统计，如"今日累计订单量"。状态持续增长，需要考虑状态存储上限。

**滚动窗口（Tumbling Window）**：将时间轴切分为固定大小的、不重叠的窗口，如"每5分钟统计一次"。窗口关闭后触发计算并释放状态。

**滑动窗口（Sliding Window）**：固定窗口大小 + 滑动步长，如"窗口5分钟、步长1分钟"。窗口之间存在重叠，同一数据可能参与多个窗口计算。

### 1.4 行业现状与挑战

当前实时计算领域面临几个核心挑战：

1. **计算框架选型困难**：Storm、Flink、Spark Streaming 各有优劣
2. **Exactly-Once 语义难保障**：端到端的精确一次语义需要全链路配合
3. **状态管理复杂**：大规模状态的存储、恢复、迁移
4. **实时数仓分层设计**：如何在保证低延迟的同时实现数据复用
5. **数据质量保障**：实时数据的准确性、完整性、时效性

## 二、整体架构设计

### 2.1 架构范式对比

#### 2.1.1 Lambda 架构

Lambda 架构由 Nathan Marz 提出，是经典的批流混合架构：

```
                    ┌──────────────────┐
                    │    数据源          │
                    │  (Kafka/MQ)       │
                    └────────┬─────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              │              ▼
   ┌──────────────┐          │     ┌──────────────┐
   │  Speed Layer  │         │     │  Batch Layer  │
   │  (Flink/Storm)│         │     │  (Spark/Hive) │
   │  低延迟实时计算 │         │     │  高精度批处理   │
   └──────┬───────┘          │     └──────┬───────┘
          │                  │            │
          ▼                  │            ▼
   ┌──────────────┐          │     ┌──────────────┐
   │  实时视图      │         │     │   批视图       │
   │  (Redis/ES)   │         │     │  (Hive/HDFS)  │
   └──────┬───────┘          │     └──────┬───────┘
          │                  │            │
          └──────────┬───────┘────────────┘
                     ▼
              ┌──────────────┐
              │ Serving Layer │
              │  查询合并层    │
              └──────────────┘
```

**Lambda 架构的优缺点**：

| 优点 | 缺点 |
|------|------|
| 批处理保证最终准确性 | 需要维护两套代码逻辑 |
| 实时层保证低延迟 | 开发和运维成本高 |
| 容错性好 | 批实时结果一致性难保障 |

#### 2.1.2 Kappa 架构

Kappa 架构由 Jay Kreps 提出，核心思想是用统一的流处理引擎替代 Lambda 的双层设计：

```
              ┌──────────────────┐
              │    数据源          │
              │  (Kafka 持久化)    │
              └────────┬─────────┘
                       │
                       ▼
              ┌──────────────────┐
              │  Stream Layer     │
              │  (Flink 统一处理)  │
              │  一套代码完成全部   │
              └────────┬─────────┘
                       │
                       ▼
              ┌──────────────────┐
              │  Serving Layer    │
              │  (ES/Druid/Doris) │
              └──────────────────┘
```

**Kappa 架构的优缺点**：

| 优点 | 缺点 |
|------|------|
| 单一处理逻辑，维护简单 | 复杂聚合场景精度受限 |
| 开发效率高 | 依赖 Kafka 长期存储 |
| 天然低延迟 | 历史数据回溯成本高 |

### 2.3 OLAP 引擎选型对比

不同 OLAP 引擎适用于不同场景：

| 引擎 | 特点 | 适用场景 | 局限性 |
|------|------|----------|--------|
| **Druid** | 预聚合、列存储、时序优化 | 时序数据、固定维度聚合 | 不支持更新、Join能力弱 |
| **Elasticsearch** | 倒排索引、全文搜索 | 搜索 + 低基数聚合 | 高基数聚合性能差 |
| **Doris** | MPP架构、高并发、SQL丰富 | 多维分析、高并发查询 | 实时导入有延迟 |
| **ClickHouse** | 极致列存、向量化执行 | 单表大宽表分析 | 并发能力有限 |

### 2.4 流处理框架对比：Storm vs Flink

| 对比维度 | Storm | Flink |
|----------|-------|-------|
| **平台成熟度** | 较高，生产验证充分 | 高，社区活跃 |
| **SQL 支持** | 不支持 | 支持（基于 Calcite） |
| **吞吐量** | 中等 | 高 |
| **延迟** | 极低（毫秒级） | 低（毫秒~秒级） |
| **状态管理** | 无内建状态 | 完善的状态后端 |
| **窗口支持** | 基础 | 丰富（滚动/滑动/会话/全局） |
| **Exactly-Once** | At-Least-Once | 支持 Exactly-Once |
| **社区活跃度** | 降低 | 非常活跃 |

## 三、核心链路设计

### 3.1 Flink 流计算引擎核心设计

#### 3.1.1 基于 Calcite 的 SQL 配置化

Flink 流计算引擎的核心设计理念是 **SQL 配置化**——通过 Apache Calcite 对 SQL 进行 AST（抽象语法树）解析，将业务逻辑从硬编码中解耦出来。

```java
/**
 * SQL 配置化引擎 - 基于 Calcite AST 解析
 * 将用户配置的 SQL 转换为 Flink 算子链
 */
public class SqlConfigEngine {

    private final StreamExecutionEnvironment env;
    private final StreamTableEnvironment tableEnv;

    public SqlConfigEngine(StreamExecutionEnvironment env) {
        this.env = env;
        EnvironmentSettings settings = EnvironmentSettings.newInstance()
                .inStreamingMode()
                .build();
        this.tableEnv = StreamTableEnvironment.create(env, settings);
    }

    /**
     * 注册源表 - 最小化 Schema 定义
     * 源表注册只需要指定关键字段,其余字段自动推导
     */
    public void registerSourceTable(SourceTableConfig config) {
        String ddl = buildSourceDDL(config);
        tableEnv.executeSql(ddl);
    }

    /**
     * 构建源表 DDL
     * 支持 Kafka、MySQL CDC 等多种 Source
     */
    private String buildSourceDDL(SourceTableConfig config) {
        StringBuilder ddl = new StringBuilder();
        ddl.append("CREATE TABLE ").append(config.getTableName()).append(" (");

        // 最小化 Schema - 只定义业务必需字段
        for (ColumnDefinition col : config.getColumns()) {
            ddl.append(col.getName()).append(" ").append(col.getType()).append(",");
        }

        // 添加事件时间和水位线
        if (config.getEventTimeColumn() != null) {
            ddl.append("event_time TIMESTAMP(3),");
            ddl.append("WATERMARK FOR event_time AS event_time - INTERVAL '")
               .append(config.getWatermarkDelay())
               .append("' SECOND");
        }

        ddl.append(") WITH (");
        ddl.append("'connector' = '").append(config.getConnector()).append("',");
        ddl.append("'topic' = '").append(config.getTopic()).append("',");
        ddl.append("'properties.bootstrap.servers' = '").append(config.getBootstrapServers()).append("',");
        ddl.append("'format' = '").append(config.getFormat()).append("'");
        ddl.append(")");

        return ddl.toString();
    }

    /**
     * 执行配置化 SQL 查询
     * 通过 Calcite 解析 SQL AST,转换为 Flink 算子
     */
    public Table executeConfigSql(String sql) {
        return tableEnv.sqlQuery(sql);
    }

    /**
     * 将查询结果输出到目标表
     */
    public void sinkToTarget(Table resultTable, String sinkTableName) {
        tableEnv.executeSql("INSERT INTO " + sinkTableName + " " + resultTable.toString());
    }
}
```

#### 3.1.2 源表配置与注册

```java
/**
 * 源表配置定义
 * 最小化 Schema: 只定义业务核心字段,减少配置复杂度
 */
@Data
@Builder
public class SourceTableConfig {
    private String tableName;
    private List<ColumnDefinition> columns;
    private String connector;        // kafka / mysql-cdc
    private String topic;
    private String bootstrapServers;
    private String format;           // json / avro / protobuf
    private String eventTimeColumn;
    private int watermarkDelay;      // 水位线延迟(秒)
    private String primaryKey;       // 主键字段(用于 Upsert 流)
}

@Data
@AllArgsConstructor
public class ColumnDefinition {
    private String name;
    private String type;
}

/**
 * 源表注册器 - 统一管理所有数据源注册
 */
public class SourceTableRegistry {

    private final SqlConfigEngine engine;
    private final Map<String, SourceTableConfig> registeredTables = new ConcurrentHashMap<>();

    public SourceTableRegistry(SqlConfigEngine engine) {
        this.engine = engine;
    }

    /**
     * 从配置中心加载并注册所有源表
     */
    public void registerFromConfig(List<SourceTableConfig> configs) {
        for (SourceTableConfig config : configs) {
            registerSingleTable(config);
        }
    }

    private void registerSingleTable(SourceTableConfig config) {
        // 校验配置合法性
        validateConfig(config);

        // 注册到引擎
        engine.registerSourceTable(config);
        registeredTables.put(config.getTableName(), config);

        log.info("源表注册成功: tableName={}, connector={}, topic={}",
                config.getTableName(), config.getConnector(), config.getTopic());
    }

    private void validateConfig(SourceTableConfig config) {
        if (config.getTableName() == null || config.getTableName().isEmpty()) {
            throw new IllegalArgumentException("表名不能为空");
        }
        if (config.getColumns() == null || config.getColumns().isEmpty()) {
            throw new IllegalArgumentException("列定义不能为空");
        }
        if (registeredTables.containsKey(config.getTableName())) {
            throw new IllegalStateException("表已存在: " + config.getTableName());
        }
    }
}
```

#### 3.1.3 Upsert 流与状态表转换

Upsert 流是实时计算中处理数据变更的核心概念。将 Upsert 流转换为状态表，是实现实时维表关联和增量聚合的基础。

```java
/**
 * Upsert 流到状态表的转换器
 * 
 * 核心思想: 按主键分组,使用 latest(obj, timestamp) 聚合函数
 * 实现基于时间戳的去重和排序
 * 
 * 输入: Upsert 流 (INSERT/UPDATE/DELETE 事件)
 * 输出: 状态表 (每个主键保留最新一条记录)
 */
public class UpsertStreamToStateTable {

    /**
     * latest() 自定义聚合函数
     * 根据时间戳保留每个 key 的最新记录
     */
    public static class LatestAggFunction extends AggregateFunction<Row, LatestAccumulator> {

        @Override
        public LatestAccumulator createAccumulator() {
            return new LatestAccumulator();
        }

        /**
         * 核心: 比较时间戳,保留较新的记录
         */
        public void accumulate(LatestAccumulator acc, Row value, Long timestamp) {
            if (acc.getLatestTimestamp() == null || timestamp > acc.getLatestTimestamp()) {
                acc.setLatestTimestamp(timestamp);
                acc.setLatestValue(value);
            }
        }

        public void retract(LatestAccumulator acc, Row value, Long timestamp) {
            // Retract 场景: 当上游撤回记录时,需要重新计算最新值
            // 这里简化处理,实际需要维护有序列表
            if (acc.getLatestTimestamp() != null && timestamp.equals(acc.getLatestTimestamp())) {
                acc.setLatestTimestamp(null);
                acc.setLatestValue(null);
            }
        }

        @Override
        public Row getValue(LatestAccumulator acc) {
            return acc.getLatestValue();
        }
    }

    @Data
    public static class LatestAccumulator {
        private Long latestTimestamp;
        private Row latestValue;
    }

    /**
     * 将 Upsert 流转换为状态表的 SQL
     * 
     * SELECT order_id,
     *        latest(order_info, update_time) as latest_info
     * FROM upsert_stream
     * GROUP BY order_id   -- 按主键分组,每个key保留最新记录
     */
    public static String buildStateTableSql(String sourceTable, String primaryKey,
                                             String valueColumn, String timestampColumn) {
        return String.format(
            "SELECT %s, latest(%s, %s) as latest_value " +
            "FROM %s " +
            "GROUP BY %s",
            primaryKey, valueColumn, timestampColumn, sourceTable, primaryKey
        );
    }
}
```

#### 3.1.4 Retract 流的窗口聚合问题与解决方案

Flink 的一个重要限制是：**无法直接对 Retract 流进行窗口聚合**。这是因为 Retract 流包含撤回消息（-U），而窗口算子无法正确处理撤回语义。

```java
/**
 * Retract 流窗口聚合的解决方案
 * 
 * 问题: Flink 不支持对 Retract 流直接做窗口聚合
 * 
 * 解决方案: 通过 UDF 生成时间分段字段,
 *          将窗口语义转换为 GROUP BY 语义
 * 
 * 滚动窗口 -> GROUP BY time_segment
 * 全局窗口 -> GROUP BY 固定值(如 "global")
 */
public class RetractStreamWindowSolution {

    /**
     * 时间分段 UDF - 模拟滚动窗口
     * 将时间戳映射到对应的窗口标识
     */
    public static class TimeSegmentUDF extends ScalarFunction {

        private final long windowSizeMs;

        public TimeSegmentUDF(long windowSizeMs) {
            this.windowSizeMs = windowSizeMs;
        }

        /**
         * 将时间戳转换为窗口标识
         * 例如: windowSize=60000ms (1分钟)
         *   timestamp=1634567890123 -> "2021-10-18 20:38"
         *   timestamp=1634567891000 -> "2021-10-18 20:38"  (同一窗口)
         *   timestamp=1634567950123 -> "2021-10-18 20:39"  (下一窗口)
         */
        public String eval(Long timestamp) {
            if (timestamp == null) {
                return "UNKNOWN";
            }
            long windowStart = (timestamp / windowSizeMs) * windowSizeMs;
            return new SimpleDateFormat("yyyy-MM-dd HH:mm")
                    .format(new Date(windowStart));
        }
    }

    /**
     * 全局窗口 UDF - 模拟全局聚合
     * 所有记录映射到同一个分段
     */
    public static class GlobalSegmentUDF extends ScalarFunction {
        public String eval(Long timestamp) {
            return "GLOBAL";
        }
    }

    /**
     * 注册 UDF 并构建查询
     */
    public static void registerAndQuery(StreamTableEnvironment tableEnv) {
        // 注册时间分段 UDF (5分钟窗口)
        tableEnv.createTemporaryFunction("time_segment",
                new TimeSegmentUDF(5 * 60 * 1000L));

        // 注册全局分段 UDF
        tableEnv.createTemporaryFunction("global_segment",
                new GlobalSegmentUDF());

        // 使用 UDF 模拟滚动窗口聚合 (替代 TUMBLE 窗口)
        String tumblingWindowSql =
            "SELECT time_segment(event_time) as window_key, " +
            "       category, " +
            "       SUM(amount) as total_amount, " +
            "       COUNT(*) as order_count " +
            "FROM retract_order_stream " +
            "GROUP BY time_segment(event_time), category";

        // 使用 UDF 模拟全局窗口聚合
        String globalWindowSql =
            "SELECT global_segment(event_time) as window_key, " +
            "       category, " +
            "       SUM(amount) as total_amount " +
            "FROM retract_order_stream " +
            "GROUP BY global_segment(event_time), category";

        Table tumblingResult = tableEnv.sqlQuery(tumblingWindowSql);
        Table globalResult = tableEnv.sqlQuery(globalWindowSql);
    }
}
```

### 3.2 FCS 批内存计算引擎核心设计

FCS（Fast Compute Service）是一个分布式分片任务驱动的批内存计算引擎，适用于分钟级延迟可接受的准实时场景。

#### 3.2.1 FCS 核心架构

```java
/**
 * FCS 批内存计算引擎
 * 
 * 核心流程:
 * 1. 定时调度引擎按分钟触发任务
 * 2. 通过 MQ 分发分片任务到各计算节点
 * 3. 计算节点从 Redis 拉取数据到内存表(H2DB)
 * 4. 在内存表上执行 SQL 计算
 * 5. 结果写回 Redis/Hive
 */
public class FCSComputeEngine {

    private final H2MemoryTableManager memoryTableManager;
    private final RedisDataFetcher redisDataFetcher;
    private final MQTaskDistributor taskDistributor;
    private final ResultWriter resultWriter;

    /**
     * 处理分片任务
     * 每个分片独立处理一部分数据
     */
    public void processShardTask(ShardTask task) {
        long startTime = System.currentTimeMillis();

        try {
            // Step 1: 从 Redis 拉取本分片数据
            List<DataRecord> records = redisDataFetcher.fetchByShardKey(
                    task.getDataKey(),
                    task.getShardIndex(),
                    task.getTotalShards()
            );

            // Step 2: 加载数据到 H2DB 内存表
            String memoryTableName = memoryTableManager.createAndLoad(
                    task.getTableSchema(),
                    records
            );

            // Step 3: 执行 SQL 计算
            List<Map<String, Object>> results = memoryTableManager.executeSql(
                    task.getComputeSql(),
                    memoryTableName
            );

            // Step 4: 写回结果到 Redis
            resultWriter.writeToRedis(task.getResultKey(), results);

            // Step 5: 同时写入 Hive 做离线备份(用于降级)
            resultWriter.writeToHive(task.getHiveTable(), results);

            // 上报监控指标
            reportMetrics(task, startTime, records.size(), results.size());

        } catch (Exception e) {
            handleComputeException(task, e);
        } finally {
            // 清理内存表
            memoryTableManager.dropTable(task.getTableSchema().getTableName());
        }
    }

    /**
     * 上报监控指标
     * 监控维度: 输入量、输出量、计算耗时、指标值、上下界
     */
    private void reportMetrics(ShardTask task, long startTime,
                                int inputCount, int outputCount) {
        long duration = System.currentTimeMillis() - startTime;

        MetricsReporter.report(MetricPoint.builder()
                .taskId(task.getTaskId())
                .inputVolume(inputCount)
                .outputVolume(outputCount)
                .computeDuration(duration)
                .timestamp(System.currentTimeMillis())
                .build());
    }
}
```

```java
/**
 * H2DB 内存表管理器
 * 利用 H2 数据库的内存模式,实现高速 SQL 计算
 */
public class H2MemoryTableManager {

    private final JdbcTemplate jdbcTemplate;

    public H2MemoryTableManager() {
        // H2 内存模式连接
        HikariDataSource ds = new HikariDataSource();
        ds.setJdbcUrl("jdbc:h2:mem:fcs;DB_CLOSE_DELAY=-1");
        ds.setMaximumPoolSize(10);
        this.jdbcTemplate = new JdbcTemplate(ds);
    }

    /**
     * 创建内存表并加载数据
     * 
     * @param schema 表结构定义
     * @param records 要加载的数据记录
     * @return 内存表名
     */
    public String createAndLoad(TableSchema schema, List<DataRecord> records) {
        String tableName = schema.getTableName() + "_" + System.currentTimeMillis();

        // 创建内存表
        String createSql = buildCreateTableSql(tableName, schema);
        jdbcTemplate.execute(createSql);

        // 批量插入数据
        String insertSql = buildInsertSql(tableName, schema);
        jdbcTemplate.batchUpdate(insertSql, new BatchPreparedStatementSetter() {
            @Override
            public void setValues(PreparedStatement ps, int i) throws SQLException {
                DataRecord record = records.get(i);
                for (int j = 0; j < schema.getColumns().size(); j++) {
                    ps.setObject(j + 1, record.getValue(schema.getColumns().get(j).getName()));
                }
            }

            @Override
            public int getBatchSize() {
                return records.size();
            }
        });

        log.info("内存表创建成功: table={}, records={}", tableName, records.size());
        return tableName;
    }

    /**
     * 在内存表上执行 SQL
     */
    public List<Map<String, Object>> executeSql(String sql, String tableName) {
        // 替换 SQL 中的表名占位符
        String actualSql = sql.replace("${TABLE}", tableName);
        return jdbcTemplate.queryForList(actualSql);
    }

    /**
     * 清理内存表
     */
    public void dropTable(String tableName) {
        jdbcTemplate.execute("DROP TABLE IF EXISTS " + tableName);
    }

    private String buildCreateTableSql(String tableName, TableSchema schema) {
        StringBuilder sb = new StringBuilder();
        sb.append("CREATE TABLE ").append(tableName).append(" (");
        for (int i = 0; i < schema.getColumns().size(); i++) {
            ColumnDef col = schema.getColumns().get(i);
            sb.append(col.getName()).append(" ").append(col.getH2Type());
            if (i < schema.getColumns().size() - 1) sb.append(",");
        }
        sb.append(")");
        return sb.toString();
    }

    private String buildInsertSql(String tableName, TableSchema schema) {
        int colCount = schema.getColumns().size();
        String placeholders = String.join(",", Collections.nCopies(colCount, "?"));
        return "INSERT INTO " + tableName + " VALUES (" + placeholders + ")";
    }
}
```

```java
        return orderStream
                .keyBy(OrderEvent::getCategory)
                .window(GlobalWindows.create())
                .trigger(ContinuousProcessingTimeTrigger.of(Time.seconds(10)))
                .aggregate(new OrderAggregateFunction(), new OrderWindowFunction());

     * 聚合函数: 计算订单金额总和与计数

            implements AggregateFunction<OrderEvent, OrderAccumulator, OrderAccumulator> {

        @Override
        public OrderAccumulator createAccumulator() {
            return new OrderAccumulator(0L, 0.0, 0L);
        }

        @Override
        public OrderAccumulator add(OrderEvent event, OrderAccumulator acc) {
            return new OrderAccumulator(
                    acc.getCount() + 1,
                    acc.getTotalAmount() + event.getAmount(),
                    Math.max(acc.getMaxTimestamp(), event.getEventTime())
            );
        }

        @Override
        public OrderAccumulator getResult(OrderAccumulator acc) {
            return acc;
        }

        @Override
        public OrderAccumulator merge(OrderAccumulator a, OrderAccumulator b) {
            return new OrderAccumulator(
                    a.getCount() + b.getCount(),
                    a.getTotalAmount() + b.getTotalAmount(),
                    Math.max(a.getMaxTimestamp(), b.getMaxTimestamp())
            );
        }
    }

    /**

            out.collect(MetricResult.builder()

                    .windowStart(window.getStart())
                    .windowEnd(window.getEnd())
                    .orderCount(acc.getCount())
                    .totalAmount(acc.getTotalAmount())
                    .avgAmount(acc.getTotalAmount() / acc.getCount())
                    .computeTime(System.currentTimeMillis())
                    .build());
        }
    }

    @AllArgsConstructor

        private double totalAmount;
```

```java
/**
 * 水位线策略管理
 * 处理乱序数据的核心机制
 */
public class WatermarkStrategyManager {

    /**
     * 有界乱序水位线
     * 允许一定范围内的乱序数据
     */
    public static <T> WatermarkStrategy<T> boundedOutOfOrder(
            Duration maxOutOfOrderness,
            SerializableTimestampAssigner<T> timestampAssigner) {

        return WatermarkStrategy
                .<T>forBoundedOutOfOrderness(maxOutOfOrderness)
                .withTimestampAssigner(timestampAssigner)
                .withIdleness(Duration.ofMinutes(1)); // 空闲源超时推进水位线
    }

    /**
     * 自定义水位线生成器
     * 支持多数据源水位线对齐
     */
    public static class AlignedWatermarkGenerator<T>
            implements WatermarkGenerator<T> {

        private final Duration maxOutOfOrderness;
        private long currentMaxTimestamp = Long.MIN_VALUE;
        private long lastEmittedWatermark = Long.MIN_VALUE;

        public AlignedWatermarkGenerator(Duration maxOutOfOrderness) {
            this.maxOutOfOrderness = maxOutOfOrderness;
        }

        @Override
        public void onEvent(T event, long eventTimestamp, WatermarkOutput output) {
            currentMaxTimestamp = Math.max(currentMaxTimestamp, eventTimestamp);
        }

        @Override
        public void onPeriodicEmit(WatermarkOutput output) {
            long newWatermark = currentMaxTimestamp - maxOutOfOrderness.toMillis();

            // 水位线只能单调递增
            if (newWatermark > lastEmittedWatermark) {
                output.emitWatermark(new Watermark(newWatermark));
                lastEmittedWatermark = newWatermark;
            }
        }
    }

    /**
     * 迟到数据处理策略
     * 超出水位线的数据发送到侧输出
     */
    public static DataStream<OrderEvent> handleLateData(
            DataStream<OrderEvent> stream,
            OutputTag<OrderEvent> lateDataTag) {

        SingleOutputStreamOperator<MetricResult> result = stream
                .keyBy(OrderEvent::getCategory)
                .window(TumblingEventTimeWindows.of(Time.minutes(1)))
                .allowedLateness(Time.minutes(5))  // 允许5分钟迟到
                .sideOutputLateData(lateDataTag)    // 超过5分钟的发送到侧输出
                .aggregate(new WindowComputeEngine.OrderAggregateFunction(),
                          new WindowComputeEngine.OrderWindowFunction());

        // 处理迟到数据
        DataStream<OrderEvent> lateStream = result.getSideOutput(lateDataTag);
        lateStream.addSink(new LateDataAlertSink());

        return stream;
    }
}
```

```java
/**
 * 端到端 Exactly-Once 语义实现
 * 
 * 数据平台提供 At-Least-Once 保证
 * 业务层通过幂等更新实现 Exactly-Once 效果
 */
public class ExactlyOnceGuarantee {

    /**
     * Flink Checkpoint 配置
     * 结合 Kafka 事务实现 Source-to-Sink 的 Exactly-Once
     */
    public static void configureCheckpoint(StreamExecutionEnvironment env) {
        // 启用 Exactly-Once checkpoint
        env.enableCheckpointing(60000, CheckpointingMode.EXACTLY_ONCE);

        CheckpointConfig config = env.getCheckpointConfig();
        // Checkpoint 最小间隔
        config.setMinPauseBetweenCheckpoints(30000);
        // Checkpoint 超时时间
        config.setCheckpointTimeout(120000);
        // 最大并发 Checkpoint 数
        config.setMaxConcurrentCheckpoints(1);
        // 任务取消后保留 Checkpoint
        config.setExternalizedCheckpointCleanup(
            CheckpointConfig.ExternalizedCheckpointCleanup.RETAIN_ON_CANCELLATION);

        // 使用 RocksDB 作为状态后端(支持增量checkpoint)
        env.setStateBackend(new EmbeddedRocksDBStateBackend(true));
    }

    /**
     * 幂等更新 Sink
     * 基于业务数据特征,实现去重和幂等
     */
    public static class IdempotentRedisSink extends RichSinkFunction<MetricResult> {

        private transient RedisClient redisClient;

        @Override
        public void open(Configuration parameters) {
            redisClient = RedisClient.create();
        }

        @Override
        public void invoke(MetricResult result, Context context) {
            String key = buildRedisKey(result);
            String field = result.getCategory();

            // 基于时间戳的幂等更新
            // 只有当新数据的时间戳 >= 已有数据时间戳时才更新
            String existingJson = redisClient.hget(key, field);
            if (existingJson != null) {
                MetricResult existing = JSON.parseObject(existingJson, MetricResult.class);
                if (existing.getComputeTime() >= result.getComputeTime()) {
                    // 已有更新的数据,跳过本次更新
                    return;
                }
            }

            // 使用 Lua 脚本保证原子性
            String luaScript =
                "local existing = redis.call('hget', KEYS[1], ARGV[1]) " +
                "if existing then " +
                "  local existTs = cjson.decode(existing)['computeTime'] " +
                "  if existTs >= tonumber(ARGV[3]) then return 0 end " +
                "end " +
                "redis.call('hset', KEYS[1], ARGV[1], ARGV[2]) " +
                "return 1";

            redisClient.eval(luaScript,
                    Collections.singletonList(key),
                    Arrays.asList(field, JSON.toJSONString(result),
                            String.valueOf(result.getComputeTime())));
        }

        private String buildRedisKey(MetricResult result) {
            SimpleDateFormat sdf = new SimpleDateFormat("yyyyMMddHHmm");
            return "metric:" + sdf.format(new Date(result.getWindowStart()));
        }

        @Override
        public void close() {
            if (redisClient != null) {
                redisClient.close();
            }
        }
    }
}
```

```java
/**
 * 两阶段提交 Sink 实现
 * 配合 Flink Checkpoint 实现端到端 Exactly-Once
 */
public class TwoPhaseCommitSink extends TwoPhaseCommitSinkFunction<MetricResult,
        TwoPhaseCommitSink.TransactionState, Void> {

    public TwoPhaseCommitSink() {
        super(new KryoSerializer<>(TransactionState.class, new ExecutionConfig()),
              VoidSerializer.INSTANCE);
    }

    @Override
    protected TransactionState beginTransaction() {
        // 开始新事务: 创建临时写缓冲区
        return new TransactionState(UUID.randomUUID().toString(), new ArrayList<>());
    }

    @Override
    protected void invoke(TransactionState transaction, MetricResult value, Context context) {
        // 预写阶段: 数据写入事务缓冲区,尚未提交
        transaction.getBuffer().add(value);
    }

    @Override
    protected void preCommit(TransactionState transaction) {
        // 预提交: 将缓冲区数据刷写到外部存储的临时位置
        log.info("预提交事务: txId={}, records={}",
                transaction.getTxId(), transaction.getBuffer().size());

        // 写入临时表/临时Key
        for (MetricResult result : transaction.getBuffer()) {
            String tempKey = "temp:" + transaction.getTxId() + ":" + result.getCategory();
            externalStorage.put(tempKey, JSON.toJSONString(result));
        }
    }

    @Override
    protected void commit(TransactionState transaction) {
        // 正式提交: Checkpoint 成功后,将临时数据移动到正式位置
        log.info("正式提交事务: txId={}", transaction.getTxId());

        for (MetricResult result : transaction.getBuffer()) {
            String tempKey = "temp:" + transaction.getTxId() + ":" + result.getCategory();
            String formalKey = "metric:" + result.getCategory();

            // 原子性地将临时数据移到正式位置
            String data = externalStorage.get(tempKey);
            externalStorage.put(formalKey, data);
            externalStorage.delete(tempKey);
        }
    }

    @Override
    protected void abort(TransactionState transaction) {
        // 中止: Checkpoint 失败,清理临时数据
        log.warn("中止事务: txId={}", transaction.getTxId());

        for (MetricResult result : transaction.getBuffer()) {
            String tempKey = "temp:" + transaction.getTxId() + ":" + result.getCategory();
            externalStorage.delete(tempKey);
        }
    }

    @Data
    @AllArgsConstructor
    public static class TransactionState implements Serializable {
        private String txId;
        private List<MetricResult> buffer;
    }
}
```

```java
/**
 * 组件化 ETL 框架
 * 支持: 清洗、过滤、关联、补全、转换、加密 等操作
 * 通过配置组合形成 ETL 流水线

public class ComponentizedETL {

    /**
     * ETL 组件接口
     */
    public interface ETLComponent<IN, OUT> {
        OUT process(IN input, ETLContext context);
        String getComponentType();
    }

    /**
     * 清洗组件 - 数据格式标准化
     */
    public static class CleanComponent implements ETLComponent<JSONObject, JSONObject> {
        @Override
        public JSONObject process(JSONObject input, ETLContext context) {
            JSONObject cleaned = new JSONObject();
            for (FieldMapping mapping : context.getFieldMappings()) {
                Object value = input.get(mapping.getSourceField());
                // 类型转换
                Object converted = TypeConverter.convert(value, mapping.getTargetType());
                // 默认值填充
                if (converted == null && mapping.getDefaultValue() != null) {
                    converted = mapping.getDefaultValue();
                }
                cleaned.put(mapping.getTargetField(), converted);
            }
            return cleaned;
        }

        @Override
        public String getComponentType() { return "CLEAN"; }
    }

    /**
     * 过滤组件 - 条件过滤
     */
    public static class FilterComponent implements ETLComponent<JSONObject, JSONObject> {
        @Override
        public JSONObject process(JSONObject input, ETLContext context) {
            for (FilterRule rule : context.getFilterRules()) {
                if (!rule.evaluate(input)) {
                    return null; // 不满足条件,过滤掉
                }
            }
            return input;
        

        @Override
        public String getComponentType() { return "FILTER"; }
    }

    /**
     * 关联组件 - 维表关联
     */
    public static class JoinComponent implements ETLComponent<JSONObject, JSONObject> {
        private final DimTableLoader dimLoader;

        public JoinComponent(DimTableLoader dimLoader) {
            this.dimLoader = dimLoader;
        }

        @Override
        public JSONObject process(JSONObject input, ETLContext context) {
            for (JoinConfig joinConfig : context.getJoinConfigs()) {
                String joinKey = input.getString(joinConfig.getJoinField());
                Map<String, Object> dimRecord = dimLoader.lookup(
                        joinConfig.getDimTable(), joinKey);
                if (dimRecord != null) {
                    for (String field : joinConfig.getSelectFields()) {
                        input.put(field, dimRecord.get(field));
                    }
                }
            }
            return input;
        }

        @Override
        public String getComponentType() { return "JOIN"; }
    }

    /**
     * 加密组件 - 敏感字段加密
     */
    public static class EncryptComponent implements ETLComponent<JSONObject, JSONObject> {
        @Override
        public JSONObject process(JSONObject input, ETLContext context) {
            for (String sensitiveField : context.getSensitiveFields()) {
                Object value = input.get(sensitiveField);
                if (value != null) {
                    String encrypted = EncryptUtil.encrypt(value.toString());
                    input.put(sensitiveField, encrypted);
                }
            }
            return input;
        }

        @Override
        public String getComponentType() { return "ENCRYPT"; }
    }

    /**
     * ETL 流水线编排器
     * 根据配置动态组装 ETL 组件
     */
    public static class ETLPipelineBuilder {

        public static List<ETLComponent<JSONObject, JSONObject>> buildPipeline(
                PipelineConfig config) {
            List<ETLComponent<JSONObject, JSONObject>> components = new ArrayList<>();

            for (ComponentConfig compConfig : config.getComponents()) {
                switch (compConfig.getType()) {
                    case "CLEAN":
                        components.add(new CleanComponent());
                        break;
                    case "FILTER":
                        components.add(new FilterComponent());
                        break;
                    case "JOIN":
                        components.add(new JoinComponent(new DimTableLoader()));
                        break;
                    case "ENCRYPT":
                        components.add(new EncryptComponent());
                        break;
                    default:
                        throw new IllegalArgumentException(
                            "未知组件类型: " + compConfig.getType());
                }
            }

            return components;
        }
    }
}
```

```java
                        completeness * 100, config.getMinCompleteness() * 100)));

                    : SLAResult.fail(jobId, violations);
```

```java
         */

            // 尝试从 MySQL 快速获取
            MetricResult cached = mysqlClient.queryHistoricalMetric(

            if (cached != null) {
                cached.setDegraded(true);

                return cached;

            // MySQL 未命中,从 Hive 查询
            MetricResult hiveResult = hiveClient.queryHistoricalMetric(
                    metricId, historicalTimestamp);
            if (hiveResult != null) {
                // 回写 MySQL 加速后续查询
                mysqlClient.saveHistoricalMetric(metricId, hiveResult);
                hiveResult.setDegraded(true);
                hiveResult.setDegradeSource("HIVE_HISTORICAL");
                return hiveResult;
            }

            // 兜底: 返回默认值
            return MetricResult.defaultValue(metricId, targetTimestamp);
        }
    }

        private final Map<String, Boolean> dcHealth = new ConcurrentHashMap<>();

        /**
         * 健康检查与自动切换
         */
        @Scheduled(fixedRate = 10000)
        public void healthCheck() {
            for (String dc : dataCenters) {
                boolean healthy = checkDCHealth(dc);
                dcHealth.put(dc, healthy);

                if (!healthy) {
                    log.warn("机房 {} 异常,触发流量切换", dc);
                    redistributeTasks(dc);
                }
            }

        private void redistributeTasks(String failedDC) {
            List<String> healthyDCs = dataCenters.stream()
                    .filter(dc -> dcHealth.getOrDefault(dc, false))
                    .collect(Collectors.toList());

            if (healthyDCs.isEmpty()) {
                log.error("所有机房异常! 触发全面降级");
                triggerFullDegradation();
                return;
            }

            // 将失败机房的任务重新分配到健康机房
            List<ShardTask> pendingTasks = getPendingTasks(failedDC);
            for (int i = 0; i < pendingTasks.size(); i++) {
                String targetDC = healthyDCs.get(i % healthyDCs.size());
                reAssignTask(pendingTasks.get(i), targetDC);
            }
        }
    }
```

```java
public class DeduplicationStrategy {

    /**
     * 基于业务主键的幂等去重
     */
    public static class IdempotentDeduplicator extends KeyedProcessFunction<String, OrderEvent, OrderEvent> {

        // 使用 Flink 状态存储已处理的事件ID
        private ValueState<Set<String>> processedIds;

        @Override
        public void open(Configuration parameters) {
            ValueStateDescriptor<Set<String>> descriptor =
                    new ValueStateDescriptor<>("processedIds",
                        TypeInformation.of(new TypeHint<Set<String>>() {}));
            // 设置 TTL,避免状态无限增长
            StateTtlConfig ttlConfig = StateTtlConfig.newBuilder(Time.hours(24))
                    .setUpdateType(StateTtlConfig.UpdateType.OnCreateAndWrite)
                    .setStateVisibility(StateTtlConfig.StateVisibility.NeverReturnExpired)
                    .cleanupFullSnapshot()
                    .build();
            descriptor.enableTimeToLive(ttlConfig);
            processedIds = getRuntimeContext().getState(descriptor);
        }

        @Override
        public void processElement(OrderEvent event, Context ctx,
                                    Collector<OrderEvent> out) throws Exception {
            Set<String> ids = processedIds.value();
            if (ids == null) {
                ids = new HashSet<>();
            }

            // 基于业务唯一键去重
            String deduplicationKey = event.getOrderId() + "_" + event.getEventType();
            if (!ids.contains(deduplicationKey)) {
                ids.add(deduplicationKey);
                processedIds.update(ids);
                out.collect(event);
            } else {
                log.debug("重复事件已过滤: key={}", deduplicationKey);
            }
        }
    }
}
```

```java
public class DataSkewHandler {

    /**
     * 两阶段聚合 - 解决热点 Key 问题
     * 第一阶段: 加随机前缀打散
     * 第二阶段: 去掉前缀再聚合
     */
    public static DataStream<MetricResult> twoStageAggregation(
            DataStream<OrderEvent> stream, int splitFactor) {

        // 第一阶段: 局部聚合 (加随机前缀打散)
        DataStream<MetricResult> partialResult = stream
                .map(event -> {
                    // 加随机后缀打散热点 Key
                    int suffix = ThreadLocalRandom.current().nextInt(splitFactor);
                    event.setCategory(event.getCategory() + "_" + suffix);
                    return event;
                })
                .keyBy(OrderEvent::getCategory)
                .window(TumblingEventTimeWindows.of(Time.minutes(1)))
                .aggregate(new WindowComputeEngine.OrderAggregateFunction(),
                          new WindowComputeEngine.OrderWindowFunction());

        // 第二阶段: 全局聚合 (去掉随机后缀)
        return partialResult
                .map(result -> {
                    // 去掉随机后缀,恢复原始 Key
                    String originalCategory = result.getCategory()
                            .substring(0, result.getCategory().lastIndexOf('_'));
                    result.setCategory(originalCategory);
                    return result;
                })
                .keyBy(MetricResult::getCategory)
                .window(TumblingEventTimeWindows.of(Time.minutes(1)))
                .reduce((a, b) -> MetricResult.builder()
                        .category(a.getCategory())
                        .windowStart(a.getWindowStart())
                        .windowEnd(a.getWindowEnd())
                        .orderCount(a.getOrderCount() + b.getOrderCount())
                        .totalAmount(a.getTotalAmount() + b.getTotalAmount())
                        .build());
    }
```

### 6.3 上线 Checklist

1. **状态管理**: 所有 ValueState/ListState 必须设置 TTL
2. **Checkpoint**: 间隔 >= 30s,超时 >= 180s,容忍失败次数 >= 3
3. **水位线**: 乱序容忍度与业务延迟对齐,设置空闲超时
4. **资源配置**: TaskManager 内存 >= 4GB,并行度根据数据量评估
5. **监控告警**: 输入输出量、处理延迟、Checkpoint 耗时、反压比例
6. **降级预案**: 准备历史同期数据降级方案
7. **去重策略**: 明确幂等更新机制,防止 At-Least-Once 导致的重复
8. **数据质量**: 配置上下界告警,异常值自动拦截
9. **灰度发布**: 先在预发环境验证,再灰度线上流量
10. **回滚方案**: 保留上一版本 Savepoint,支持快速回滚

```java
import org.apache.flink.api.common.eventtime.*;
import org.apache.flink.api.common.functions.*;
import org.apache.flink.api.common.restartstrategy.RestartStrategies;
import org.apache.flink.api.common.serialization.SimpleStringSchema;
import org.apache.flink.api.java.tuple.Tuple3;
import org.apache.flink.configuration.Configuration;
import org.apache.flink.runtime.state.filesystem.FsStateBackend;
import org.apache.flink.streaming.api.CheckpointingMode;
import org.apache.flink.streaming.api.datastream.DataStream;
import org.apache.flink.streaming.api.environment.CheckpointConfig;
import org.apache.flink.streaming.api.environment.StreamExecutionEnvironment;
import org.apache.flink.streaming.api.functions.KeyedProcessFunction;
import org.apache.flink.streaming.api.functions.sink.RichSinkFunction;
import org.apache.flink.streaming.api.functions.source.SourceFunction;
import org.apache.flink.streaming.api.windowing.assigners.TumblingEventTimeWindows;
import org.apache.flink.streaming.api.windowing.time.Time;
import org.apache.flink.streaming.connectors.kafka.FlinkKafkaConsumer;
import org.apache.flink.util.Collector;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.time.Duration;
import java.util.*;

/**
 * 实时订单统计全链路作业
 *
 * 链路: Kafka -> Flink 窗口聚合 -> Redis(实时查询) + ClickHouse(历史分析) -> Dashboard
 *
 * 容错保障:
 *   - Checkpoint Exactly-Once
 *   - Redis Sink: 基于时间戳的幂等更新 (Lua 脚本保证原子性)
 *   - ClickHouse Sink: 基于订单ID + 窗口时间戳的去重
 */
public class OrderStatisticsPipeline {

    private static final Logger LOG = LoggerFactory.getLogger(OrderStatisticsPipeline.class);

    private static final String KAFKA_TOPIC = "ods_order_events";
    private static final String KAFKA_GROUP = "flink-order-stats";
    private static final String REDIS_KEY_PREFIX = "order_stats:";
    private static final String CK_TABLE = "realtime_order_stats";

    public static void main(String[] args) throws Exception {
        // ========== 1. 环境配置 ==========
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
        env.setParallelism(8);
        env.enableCheckpointing(60_000, CheckpointingMode.EXACTLY_ONCE);

        CheckpointConfig cpConfig = env.getCheckpointConfig();
        cpConfig.setMinPauseBetweenCheckpoints(30_000);
        cpConfig.setCheckpointTimeout(180_000);
        cpConfig.setTolerableCheckpointFailureNumber(3);
        cpConfig.setMaxConcurrentCheckpoints(1);
        cpConfig.setExternalizedCheckpointCleanup(
            CheckpointConfig.ExternalizedCheckpointCleanup.RETAIN_ON_CANCELLATION);

        env.setStateBackend(new FsStateBackend("hdfs:///flink/checkpoints/order-stats"));
        env.setRestartStrategy(RestartStrategies.fixedDelayRestart(5, 60_000));

        // ========== 2. Kafka Source ==========
        Properties kafkaProps = new Properties();
        kafkaProps.setProperty("bootstrap.servers", "kafka-01:9092,kafka-02:9092");
        kafkaProps.setProperty("group.id", KAFKA_GROUP);
        kafkaProps.setProperty("auto.offset.reset", "latest");
        // 仅在 Checkpoint 完成后提交 offset，保证 Exactly-Once
        kafkaProps.setProperty("enable.auto.commit", "false");
        kafkaProps.setProperty("isolation.level", "read_committed");

        FlinkKafkaConsumer<String> kafkaSource = new FlinkKafkaConsumer<>(
            KAFKA_TOPIC, new SimpleStringSchema(), kafkaProps);
        kafkaSource.setStartFromLatest();

        DataStream<String> rawStream = env.addSource(kafkaSource)
            .name("Kafka-OrderEvent-Source")
            .uid("kafka-source-order");

        // ========== 3. 数据解析 + 异常处理 ==========
        DataStream<OrderEvent> orderStream = rawStream
            .map(new OrderEventParser())
            .name("OrderEvent-Parse")
            .uid("parse-order-event")
            // 过滤解析失败的脏数据，避免污染下游
            .filter(event -> event != null && event.getOrderId() != null);

        // ========== 4. 水位线 + 窗口聚合 ==========
        DataStream<OrderWindowResult> windowResultStream = orderStream
            .assignTimestampsAndWatermarks(
                WatermarkStrategy.<OrderEvent>forBoundedOutOfOrderness(Duration.ofSeconds(10))
                    .withTimestampAssigner((event, ts) -> event.getEventTimestamp())
                    .withIdleness(Duration.ofMinutes(1)))
            // 按类目分组，每类目独立窗口
            .keyBy(OrderEvent::getCategory)
            .window(TumblingEventTimeWindows.of(Time.minutes(1)))
            .aggregate(new OrderAggregateFunction(), new OrderWindowFunction())
            .name("OrderStats-1min-TumblingWindow")
            .uid("window-aggregate");

        // ========== 5. 双写 Sink: Redis + ClickHouse ==========
        // 5.1 Redis Sink（供 Dashboard 实时查询，秒级刷新）
        windowResultStream.addSink(new IdempotentRedisOrderSink())
            .name("Redis-OrderStats-Sink")
            .uid("redis-sink-order");

        // 5.2 ClickHouse Sink（供历史趋势分析）
        windowResultStream.addSink(new ClickHouseOrderSink())
            .name("ClickHouse-OrderStats-Sink")
            .uid("clickhouse-sink-order");

        env.execute("Realtime-Order-Statistics-Pipeline");
    }

    // ====================================================================
    // 数据解析器
    // ====================================================================
    /**
     * 订单事件解析器
     *
     * 异常处理策略:
     *   - JSON 解析失败: 记录错误日志，返回 null（由下游 filter 过滤）
     *   - 字段缺失: 使用默认值，记录 WARN 日志
     *   - 金额异常（<=0）: 记录 WARN 日志，仍然输出（由下游窗口聚合时过滤）
     */
    public static class OrderEventParser extends RichMapFunction<String, OrderEvent> {

        private transient Counter parseErrorCounter;
        private transient Counter parseSuccessCounter;

        @Override
        public void open(Configuration parameters) {
            parseErrorCounter = getRuntimeContext().getMetricGroup()
                .counter("order_event_parse_error");
            parseSuccessCounter = getRuntimeContext().getMetricGroup()
                .counter("order_event_parse_success");
        }

        @Override
        public OrderEvent map(String raw) {
            try {
                OrderEvent event = JSON.parseObject(raw, OrderEvent.class);
                if (event == null || event.getOrderId() == null) {
                    parseErrorCounter.inc();
                    LOG.warn("订单事件解析为空或订单ID缺失, raw={}", raw);
                    return null;
                }
                if (event.getAmount() <= 0) {
                    LOG.warn("订单金额异常, orderId={}, amount={}", event.getOrderId(), event.getAmount());
                    parseErrorCounter.inc();
                    return null;
                }
                parseSuccessCounter.inc();
                return event;
            } catch (Exception e) {
                parseErrorCounter.inc();
                LOG.error("订单事件JSON解析失败, raw={}", raw, e);
                return null;
            }
        }
    }

    // ====================================================================
    // 窗口聚合函数
    // ====================================================================

    /**
     * 聚合函数：在窗口内维护累加器
     * 累加器: {orderCount, totalAmount, totalQuantity, maxAmount, minAmount}
     */
    public static class OrderAggregateFunction
            implements AggregateFunction<OrderEvent, OrderAccumulator, OrderAggregate> {

        @Override
        public OrderAccumulator createAccumulator() {
            return new OrderAccumulator(0, 0.0, 0, Double.MIN_VALUE, Double.MAX_VALUE);
        }

        @Override
        public OrderAccumulator add(OrderEvent event, OrderAccumulator acc) {
            return new OrderAccumulator(
                acc.count + 1,
                acc.totalAmount + event.getAmount(),
                acc.totalQuantity + event.getQuantity(),
                Math.max(acc.maxAmount, event.getAmount()),
                Math.min(acc.minAmount, event.getAmount())
            );
        }

        @Override
        public OrderAggregate getResult(OrderAccumulator acc) {
            double avgAmount = acc.count > 0 ? acc.totalAmount / acc.count : 0.0;
            return new OrderAggregate(
                acc.count, acc.totalAmount, acc.totalQuantity,
                acc.maxAmount, acc.minAmount, avgAmount
            );
        }

        @Override
        public OrderAccumulator merge(OrderAccumulator a, OrderAccumulator b) {
            return new OrderAccumulator(
                a.count + b.count,
                a.totalAmount + b.totalAmount,
                a.totalQuantity + b.totalQuantity,
                Math.max(a.maxAmount, b.maxAmount),
                Math.min(a.minAmount, b.minAmount)
            );
        }
    }

    /**
     * 窗口函数：将聚合结果附加窗口时间信息
     */
    public static class OrderWindowFunction
            implements ProcessWindowFunction<OrderAggregate, OrderWindowResult, String, TimeWindow> {

        @Override
        public void process(String category, Context ctx,
                            Iterable<OrderAggregate> results, Collector<OrderWindowResult> out) {
            TimeWindow window = ctx.window();
            OrderAggregate agg = results.iterator().next();

            OrderWindowResult result = new OrderWindowResult();
            result.setCategory(category);
            result.setWindowStart(window.getStart());
            result.setWindowEnd(window.getEnd());
            result.setOrderCount(agg.count);
            result.setTotalAmount(agg.totalAmount);
            result.setTotalQuantity(agg.totalQuantity);
            result.setAvgAmount(agg.avgAmount);
            result.setMaxAmount(agg.maxAmount);
            result.setMinAmount(agg.minAmount);
            result.setComputeTime(System.currentTimeMillis());

            LOG.info("窗口聚合完成, category={}, window=[{} - {}], orderCount={}, totalAmount={}",
                category, window.getStart(), window.getEnd(), agg.count, agg.totalAmount);

            out.collect(result);
        }
    }

    // ====================================================================
    // Redis 幂等 Sink
    // ====================================================================

    /**
     * Redis 幂等 Sink
     *
     * 幂等策略:
     *   - Key: order_stats:{category}:{windowEnd}
     *   - 使用 Lua 脚本比较 computeTime，仅当新数据 computeTime >= 已有值时更新
     *   - 保证 Flink Checkpoint 恢复后重复写入不会覆盖更新的数据
     *
     * 异常处理:
     *   - Redis 连接失败: 重试 3 次，间隔 1s，失败后记录 DLQ 日志
     *   - Lua 脚本执行异常: 记录 ERROR 日志，不中断流
     */
    public static class IdempotentRedisOrderSink extends RichSinkFunction<OrderWindowResult> {

        private static final Logger SINK_LOG = LoggerFactory.getLogger(IdempotentRedisOrderSink.class);
        private transient JedisPool jedisPool;

        // Lua 脚本：基于 computeTime 的幂等更新
        private static final String IDEMPOTENT_UPDATE_LUA =
            "local key = KEYS[1] " +
            "local field = ARGV[1] " +
            "local value = ARGV[2] " +
            "local newTs = tonumber(ARGV[3]) " +
            "local existing = redis.call('hget', key, field) " +
            "if existing then " +
            "  local existTs = tonumber(cjson.decode(existing)['computeTime']) " +
            "  if existTs >= newTs then return 0 end " +
            "end " +
            "redis.call('hset', key, field, value) " +
            "redis.call('expire', key, 86400) " +
            "return 1";

        @Override
        public void open(Configuration parameters) {
            JedisPoolConfig poolConfig = new JedisPoolConfig();
            poolConfig.setMaxTotal(16);
            poolConfig.setMaxIdle(8);
            poolConfig.setMinIdle(2);
            poolConfig.setTestOnBorrow(true);
            jedisPool = new JedisPool(poolConfig, "redis-host", 6379, 3000, "password");
            SINK_LOG.info("Redis Sink 初始化完成, pool={}", jedisPool);
        }

        @Override
        public void invoke(OrderWindowResult result, Context context) {
            String redisKey = REDIS_KEY_PREFIX + result.getCategory() + ":" + result.getWindowEnd();
            String fieldValue = JSON.toJSONString(result);
            String computeTs = String.valueOf(result.getComputeTime());

            int maxRetry = 3;
            for (int attempt = 1; attempt <= maxRetry; attempt++) {
                try (Jedis jedis = jedisPool.getResource()) {
                    Object ret = jedis.eval(
                        IDEMPOTENT_UPDATE_LUA,
                        Collections.singletonList(redisKey),
                        Arrays.asList("stats", fieldValue, computeTs)
                    );
                    if (ret != null && ((Long) ret) == 1L) {
                        SINK_LOG.debug("Redis 幂等写入成功, key={}, category={}", redisKey, result.getCategory());
                    } else {
                        SINK_LOG.debug("Redis 幂等跳过(已有更新数据), key={}", redisKey);
                    }
                    return; // 成功则退出
                } catch (Exception e) {
                    SINK_LOG.warn("Redis 写入失败, attempt={}/{}, key={}, error={}",
                        attempt, maxRetry, redisKey, e.getMessage());
                    if (attempt >= maxRetry) {
                        SINK_LOG.error("Redis 写入最终失败, 数据进入DLQ, key={}, data={}",
                            redisKey, fieldValue, e);
                        // 写入 DLQ topic 供后续补偿
                        sendToDLQ("redis_sink_dlq", fieldValue);
                    }
                    try { Thread.sleep(1000L * attempt); } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                    }
                }
            }
        }

        @Override
        public void close() {
            if (jedisPool != null) {
                jedisPool.close();
                SINK_LOG.info("Redis 连接池已关闭");
            }
        }

        private void sendToDLQ(String dlqTopic, String data) {
            // 实际实现中发送到 Kafka DLQ topic
            SINK_LOG.warn("数据写入DLQ, topic={}, data={}", dlqTopic, data);
        }
    }

    // ====================================================================
    // ClickHouse Sink
    // ====================================================================

    /**
     * ClickHouse Sink
     *
     * 批量写入策略:
     *   - 攒满 500 条或 10 秒触发一次批量写入
     *   - 使用 ClickHouse 的 ReplacingMergeTree 引擎实现幂等
     *   - 排序键: (category, windowEnd, computeTime)，相同 key 自动去重保留最新版本
     *
     * 异常处理:
     *   - 写入失败: 重试 3 次，失败后写入 DLQ
     *   - 连接超时: 重建连接
     */
    public static class ClickHouseOrderSink extends RichSinkFunction<OrderWindowResult> {

        private static final Logger CK_LOG = LoggerFactory.getLogger(ClickHouseOrderSink.class);
        private transient ClickHouseConnection connection;
        private transient List<OrderWindowResult> batchBuffer;
        private static final int BATCH_SIZE = 500;
        private static final long FLUSH_INTERVAL_MS = 10_000;
        private transient long lastFlushTime;

        @Override
        public void open(Configuration parameters) {
            initializeConnection();
            batchBuffer = new ArrayList<>(BATCH_SIZE);
            lastFlushTime = System.currentTimeMillis();
            CK_LOG.info("ClickHouse Sink 初始化完成");
        }

        private void initializeConnection() {
            try {
                ClickHouseProperties props = new ClickHouseProperties();
                props.setHost("clickhouse-host");
                props.setPort(8123);
                props.setDatabase("realtime_dw");
                props.setUser("default");
                props.setPassword("password");
                props.setSocketTimeout(30000);
                connection = new ClickHouseDataSource("jdbc:clickhouse://clickhouse-host:8123/realtime_dw", props)
                    .getConnection();
                CK_LOG.info("ClickHouse 连接建立成功");
            } catch (Exception e) {
                CK_LOG.error("ClickHouse 连接初始化失败", e);
                throw new RuntimeException("ClickHouse 连接失败", e);
            }
        }

        @Override
        public void invoke(OrderWindowResult result, Context context) {
            batchBuffer.add(result);

            boolean sizeTrigger = batchBuffer.size() >= BATCH_SIZE;
            boolean timeTrigger = (System.currentTimeMillis() - lastFlushTime) >= FLUSH_INTERVAL_MS;

            if (sizeTrigger || timeTrigger) {
                flush();
            }
        }

        private void flush() {
            if (batchBuffer.isEmpty()) return;

            List<OrderWindowResult> batch = new ArrayList<>(batchBuffer);
            batchBuffer.clear();
            lastFlushTime = System.currentTimeMillis();

            int maxRetry = 3;
            for (int attempt = 1; attempt <= maxRetry; attempt++) {
                try {
                    batchInsert(batch);
                    CK_LOG.info("ClickHouse 批量写入成功, count={}", batch.size());
                    return;
                } catch (Exception e) {
                    CK_LOG.warn("ClickHouse 写入失败, attempt={}/{}, error={}",
                        attempt, maxRetry, e.getMessage());
                    if (attempt >= maxRetry) {
                        CK_LOG.error("ClickHouse 写入最终失败, 数据进入DLQ, count={}", batch.size(), e);
                        for (OrderWindowResult r : batch) {
                            sendToDLQ("ck_sink_dlq", JSON.toJSONString(r));
                        }
                    }
                    // 重试前重建连接
                    if (attempt < maxRetry) {
                        try { connection.close(); } catch (Exception ignored) {}
                        initializeConnection();
                        try { Thread.sleep(2000L * attempt); } catch (InterruptedException ie) {
                            Thread.currentThread().interrupt();
                        }
                    }
                }
            }
        }

        private void batchInsert(List<OrderWindowResult> batch) throws Exception {
            String sql = "INSERT INTO " + CK_TABLE +
                " (category, window_start, window_end, order_count, total_amount, " +
                "total_quantity, avg_amount, max_amount, min_amount, compute_time) " +
                "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)";

            try (ClickHousePreparedStatement ps = (ClickHousePreparedStatement)
                    connection.prepareStatement(sql)) {
                for (OrderWindowResult r : batch) {
                    ps.setString(1, r.getCategory());
                    ps.setLong(2, r.getWindowStart());
                    ps.setLong(3, r.getWindowEnd());
                    ps.setLong(4, r.getOrderCount());
                    ps.setDouble(5, r.getTotalAmount());
                    ps.setLong(6, r.getTotalQuantity());
                    ps.setDouble(7, r.getAvgAmount());
                    ps.setDouble(8, r.getMaxAmount());
                    ps.setDouble(9, r.getMinAmount());
                    ps.setLong(10, r.getComputeTime());
                    ps.addBatch();
                }
                ps.executeBatch();
            }
        }

        @Override
        public void close() {
            flush(); // 关闭前刷新缓冲区
            if (connection != null) {
                try { connection.close(); } catch (Exception ignored) {}
                CK_LOG.info("ClickHouse 连接已关闭");
            }
        }

        private void sendToDLQ(String dlqTopic, String data) {
            CK_LOG.warn("数据写入DLQ, topic={}, data={}", dlqTopic, data);
        }
    }

    // ====================================================================
    // 辅助数据结构
    // ====================================================================

    /** 窗口聚合累加器 */

        public long count;
        public double totalAmount;
        public long totalQuantity;
        public double maxAmount;
        public double minAmount;

        public OrderAccumulator(long count, double totalAmount, long totalQuantity,
                                double maxAmount, double minAmount) {
            this.count = count;
            this.totalAmount = totalAmount;
            this.totalQuantity = totalQuantity;
            this.maxAmount = maxAmount;
            this.minAmount = minAmount;
        }
    }

    /** 窗口聚合结果 */
    public static class OrderAggregate implements Serializable {
        public long count;
        public double totalAmount;
        public long totalQuantity;
        public double maxAmount;
        public double minAmount;
        public double avgAmount;

        public OrderAggregate(long count, double totalAmount, long totalQuantity,
                              double maxAmount, double minAmount, double avgAmount) {
            this.count = count;
            this.totalAmount = totalAmount;
            this.totalQuantity = totalQuantity;
            this.maxAmount = maxAmount;
            this.minAmount = minAmount;
            this.avgAmount = avgAmount;
        }
    }

    /** 窗口输出结果 */
    public static class OrderWindowResult implements Serializable {
        private String category;
        private long windowStart;
        private long windowEnd;
        private long orderCount;
        private double totalAmount;
        private long totalQuantity;
        private double avgAmount;
        private double maxAmount;

        // 省略 getter/setter
    }
}
```

```java
@RestController
@RequestMapping("/api/dashboard/order")
public class OrderDashboardController {

    private static final Logger LOG = LoggerFactory.getLogger(OrderDashboardController.class);

    @Autowired
    private JedisPool jedisPool;

    /**
     * 查询指定类目的实时订单统计
     * Key: order_stats:{category}:{windowEnd}
     */
    @GetMapping("/stats/{category}")
    public Result<OrderWindowResult> getOrderStats(@PathVariable String category) {
        try (Jedis jedis = jedisPool.getResource()) {
            // 获取最近一分钟的窗口 key
            long currentWindowEnd = System.currentTimeMillis() / 60_000 * 60_000;
            String key = "order_stats:" + category + ":" + currentWindowEnd;
            String json = jedis.hget(key, "stats");
            if (json != null) {
                return Result.success(JSON.parseObject(json, OrderWindowResult.class));
            }
            // 当前窗口尚未产出，回退到上一个窗口
            long prevWindowEnd = currentWindowEnd - 60_000;
            String prevKey = "order_stats:" + category + ":" + prevWindowEnd;
            json = jedis.hget(prevKey, "stats");
            if (json != null) {
                return Result.success(JSON.parseObject(json, OrderWindowResult.class));
            }
            return Result.success(null);
        } catch (Exception e) {
            LOG.error("Dashboard 查询失败, category={}", category, e);
            return Result.fail("查询失败: " + e.getMessage());
        }
    }
```

#### 7.2.2 Flink CEP 风控全链路作业

```java
import org.apache.flink.cep.CEP;
import org.apache.flink.cep.PatternSelectFunction;
import org.apache.flink.cep.PatternStream;
import org.apache.flink.cep.pattern.Pattern;
import org.apache.flink.cep.pattern.conditions.SimpleCondition;
import org.apache.flink.streaming.api.datastream.DataStream;
import org.apache.flink.streaming.api.environment.StreamExecutionEnvironment;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.List;
import java.util.Map;

/**
 * 实时风控决策全链路
 *
 * 链路: 用户行为事件 -> Kafka -> Flink CEP模式匹配 -> 规则引擎 -> 风险决策 -> 拦截/放行
 *
 * 检测模式:
 *   1. 短时间内多次登录失败后成功登录 -> 账户被盗风险
 *   2. 登录后短时间内大额转账 -> 欺诈风险
 *   3. 不同IP短时间内多次操作 -> 账户共享风险
 *
 * 容错保障:
 *   - Checkpoint Exactly-Once
 *   - 风控决策 Sink: 基于 eventId 幂等写入
 *   - 拦截指令: 基于 eventId + decisionTime 幂等下发
 */
public class RiskControlPipeline {

    private static final Logger LOG = LoggerFactory.getLogger(RiskControlPipeline.class);

    public static void main(String[] args) throws Exception {
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
        env.setParallelism(4);
        env.enableCheckpointing(30_000, CheckpointingMode.EXACTLY_ONCE);

        CheckpointConfig cpConfig = env.getCheckpointConfig();
        cpConfig.setMinPauseBetweenCheckpoints(15_000);
        cpConfig.setCheckpointTimeout(120_000);
        cpConfig.setTolerableCheckpointFailureNumber(5);

        env.setStateBackend(new EmbeddedRocksDBStateBackend(true));
        env.setRestartStrategy(RestartStrategies.fixedDelayRestart(10, 30_000));

        // ========== 1. Kafka Source ==========
        Properties kafkaProps = new Properties();
        kafkaProps.setProperty("bootstrap.servers", "kafka-01:9092,kafka-02:9092");
        kafkaProps.setProperty("group.id", "flink-risk-control");
        kafkaProps.setProperty("auto.offset.reset", "latest");

        FlinkKafkaConsumer<String> kafkaSource = new FlinkKafkaConsumer<>(
            "user_behavior_events", new SimpleStringSchema(), kafkaProps);
        kafkaSource.setStartFromLatest();

        DataStream<UserBehaviorEvent> eventStream = env.addSource(kafkaSource)
            .name("Kafka-UserBehavior-Source")
            .uid("kafka-source-behavior")
            .map(new BehaviorEventParser())
            .name("BehaviorEvent-Parse")
            .filter(e -> e != null && e.getUserId() != null);

        // ========== 2. CEP 模式1: 短时间多次登录失败后成功登录 ==========
        Pattern<UserBehaviorEvent, ?> loginFraudPattern = Pattern
            .<UserBehaviorEvent>begin("loginFailures")
            .where(new SimpleCondition<UserBehaviorEvent>() {
                @Override
                public boolean filter(UserBehaviorEvent event) {
                    return "LOGIN".equals(event.getEventType()) && event.getRiskLevel() > 50;
                }
            })
            .timesOrMore(3)
            .within(Time.seconds(60))
            .followedBy("loginSuccess")
            .where(new SimpleCondition<UserBehaviorEvent>() {
                @Override
                public boolean filter(UserBehaviorEvent event) {
                    return "LOGIN".equals(event.getEventType()) && event.getRiskLevel() == 0;
                }
            })
            .within(Time.seconds(30));

        PatternStream<UserBehaviorEvent> loginFraudPatternStream = CEP.pattern(
            eventStream.keyBy(UserBehaviorEvent::getUserId), loginFraudPattern);

        DataStream<RiskAlert> loginFraudAlerts = loginFraudPatternStream
            .select(new LoginFraudAlertFunction())
            .name("CEP-LoginFraud-Detector")
            .uid("cep-login-fraud");

        // ========== 3. CEP 模式2: 登录后短时间大额转账 ==========
        Pattern<UserBehaviorEvent, ?> transferFraudPattern = Pattern
            .<UserBehaviorEvent>begin("recentLogin")
            .where(new SimpleCondition<UserBehaviorEvent>() {
                @Override
                public boolean filter(UserBehaviorEvent event) {
                    return "LOGIN".equals(event.getEventType());
                }
            })
            .followedBy("largeTransfer")
            .where(new SimpleCondition<UserBehaviorEvent>() {
                @Override
                public boolean filter(UserBehaviorEvent event) {
                    return "TRANSFER".equals(event.getEventType()) && event.getAmount() > 50000;
                }
            })
            .within(Time.minutes(5));

        PatternStream<UserBehaviorEvent> transferFraudPatternStream = CEP.pattern(
            eventStream.keyBy(UserBehaviorEvent::getUserId), transferFraudPattern);

        DataStream<RiskAlert> transferFraudAlerts = transferFraudPatternStream
            .select(new TransferFraudAlertFunction())
            .name("CEP-TransferFraud-Detector")
            .uid("cep-transfer-fraud");

        // ========== 4. 合并告警流 -> 规则引擎 -> 风险决策 ==========
        DataStream<RiskAlert> allAlerts = loginFraudAlerts
            .union(transferFraudAlerts);

        DataStream<RiskDecision> decisionStream = allAlerts
            .keyBy(RiskAlert::getUserId)
            .process(new RiskDecisionProcessFunction())
            .name("RiskDecision-Engine")
            .uid("risk-decision-engine");

        // ========== 5. 决策结果 Sink: 拦截/放行 ==========
        decisionStream.addSink(new IdempotentRiskDecisionSink())
            .name("RiskDecision-Sink")
            .uid("risk-decision-sink");

        env.execute("Realtime-Risk-Control-Pipeline");
    }

    // ====================================================================
    // 事件解析器
    // ====================================================================

    public static class BehaviorEventParser extends RichMapFunction<String, UserBehaviorEvent> {

        private transient Counter parseErrorCounter;

        @Override
        public void open(Configuration parameters) {
            parseErrorCounter = getRuntimeContext().getMetricGroup()
                .counter("behavior_event_parse_error");
        }

        @Override
        public UserBehaviorEvent map(String raw) {
            try {
                UserBehaviorEvent event = JSON.parseObject(raw, UserBehaviorEvent.class);
                if (event == null || event.getUserId() == null || event.getEventId() == null) {
                    parseErrorCounter.inc();
                    LOG.warn("行为事件解析失败(关键字段缺失), raw={}", raw);
                    return null;
                }
                return event;
            } catch (Exception e) {
                parseErrorCounter.inc();
                LOG.error("行为事件JSON解析失败, raw={}", raw, e);
                return null;
            }
        }
    }

    // ====================================================================
    // CEP 告警函数
    // ====================================================================

    /**
     * 登录欺诈告警提取
     */
    public static class LoginFraudAlertFunction
            implements PatternSelectFunction<UserBehaviorEvent, RiskAlert> {

        @Override
        public RiskAlert select(Map<String, List<UserBehaviorEvent>> pattern) {
            List<UserBehaviorEvent> failures = pattern.get("loginFailures");
            UserBehaviorEvent success = pattern.get("loginSuccess").get(0);

            RiskAlert alert = new RiskAlert();
            alert.setAlertId(UUID.randomUUID().toString());
            alert.setUserId(success.getUserId());
            alert.setAlertType("LOGIN_FRAUD");
            alert.setRiskScore(80);
            alert.setDescription(String.format(
                "用户%s在%d秒内登录失败%d次后成功登录，疑似账户被盗",
                success.getUserId(),
                60, failures.size()));
            alert.setEventIds(failures.stream()
                .map(UserBehaviorEvent::getEventId)
                .collect(Collectors.toList()));
            alert.setEventIds(Arrays.asList(success.getEventId()));
            alert.setAlertTime(System.currentTimeMillis());

            LOG.warn("检测到登录欺诈风险, userId={}, failCount={}",
                success.getUserId(), failures.size());
            return alert;
        }
    }

    /**
     * 转账欺诈告警提取
     */
    public static class TransferFraudAlertFunction
            implements PatternSelectFunction<UserBehaviorEvent, RiskAlert> {

        @Override
        public RiskAlert select(Map<String, List<UserBehaviorEvent>> pattern) {
            UserBehaviorEvent login = pattern.get("recentLogin").get(0);
            UserBehaviorEvent transfer = pattern.get("largeTransfer").get(0);

            RiskAlert alert = new RiskAlert();
            alert.setAlertId(UUID.randomUUID().toString());
            alert.setUserId(transfer.getUserId());
            alert.setAlertType("TRANSFER_FRAUD");
            alert.setRiskScore(75);
            alert.setDescription(String.format(
                "用户%s登录后%d分钟内发起大额转账%.2f元，疑似欺诈",
                transfer.getUserId(), 5, transfer.getAmount()));
            alert.setEventIds(Arrays.asList(login.getEventId(), transfer.getEventId()));
            alert.setAlertTime(System.currentTimeMillis());

            LOG.warn("检测到转账欺诈风险, userId={}, amount={}",
                transfer.getUserId(), transfer.getAmount());
            return alert;
        }
    }

    // ====================================================================
    // 规则引擎 + 风险决策
    // ====================================================================

    /**
     * 风险决策处理函数
     *
     * 决策逻辑:
     *   1. 查询用户历史风险记录（状态）
     *   2. 结合 CEP 告警 + 历史风险 + 规则引擎 综合决策
     *   3. 输出: 拦截 / 放行 / 人工审核
     *
     * 幂等控制:
     *   - 基于 alertId 去重，同一 alertId 只决策一次
     *   - 状态中记录已处理的 alertId 集合
     */
    public static class RiskDecisionProcessFunction
            extends KeyedProcessFunction<String, RiskAlert, RiskDecision> {

        private static final Logger DECISION_LOG = LoggerFactory.getLogger(RiskDecisionProcessFunction.class);

        /** 已处理的 alertId 集合（幂等去重） */
        private transient ValueState<Set<String>> processedAlertIds;
        /** 用户历史风险分 */
        private transient ValueState<Integer> historicalRiskScore;
        /** 用户风险事件计数 */
        private transient ValueState<Long> riskEventCount;

        @Override
        public void open(Configuration parameters) {
            ValueStateDescriptor<Set<String>> alertIdDescriptor =
                new ValueStateDescriptor<>("processed-alert-ids", TypeInformation.of(new TypeHint<Set<String>>() {}));
            // 设置 TTL，7天后自动清理
            StateTtlConfig ttlConfig = StateTtlConfig.newBuilder(Time.days(7))
                .setUpdateType(StateTtlConfig.UpdateType.OnCreateAndWrite)
                .setStateVisibility(StateTtlConfig.StateVisibility.NeverReturnExpired)
                .build();
            alertIdDescriptor.enableTimeToLive(ttlConfig);

            processedAlertIds = getRuntimeContext().getState(alertIdDescriptor);
            historicalRiskScore = getRuntimeContext().getState(
                new ValueStateDescriptor<>("historical-risk-score", Integer.class));
            riskEventCount = getRuntimeContext().getState(
                new ValueStateDescriptor<>("risk-event-count", Long.class));
        }

        @Override
        public void processElement(RiskAlert alert, Context ctx, Collector<RiskDecision> out) {
            try {
                // ========== 幂等检查 ==========
                Set<String> processedIds = processedAlertIds.value();
                if (processedIds == null) {
                    processedIds = new HashSet<>();
                }
                if (processedIds.contains(alert.getAlertId())) {
                    DECISION_LOG.info("告警已处理(幂等跳过), alertId={}, userId={}",
                        alert.getAlertId(), alert.getUserId());
                    return;
                }
                processedIds.add(alert.getAlertId());
                processedAlertIds.update(processedIds);

                // ========== 规则引擎决策 ==========
                int histScore = historicalRiskScore.value() != null ? historicalRiskScore.value() : 0;
                long eventCount = riskEventCount.value() != null ? riskEventCount.value() : 0;

                // 综合风险分 = CEP告警分 * 0.6 + 历史风险分 * 0.3 + 频率惩罚 * 0.1
                int frequencyPenalty = (int) Math.min(eventCount * 5, 50);
                int compositeScore = (int) (alert.getRiskScore() * 0.6 + histScore * 0.3 + frequencyPenalty * 0.1);
                compositeScore = Math.min(compositeScore, 100);

                // 决策阈值
                String decision;
                if (compositeScore >= 80) {
                    decision = "BLOCK";  // 拦截
                } else if (compositeScore >= 60) {
                    decision = "REVIEW"; // 人工审核
                } else {
                    decision = "PASS";   // 放行
                }

                // 更新历史状态
                historicalRiskScore.update(Math.min(histScore + 10, 100));
                riskEventCount.update(eventCount + 1);

                RiskDecision riskDecision = new RiskDecision();
                riskDecision.setDecisionId(UUID.randomUUID().toString());
                riskDecision.setAlertId(alert.getAlertId());
                riskDecision.setUserId(alert.getUserId());
                riskDecision.setAlertType(alert.getAlertType());
                riskDecision.setCompositeScore(compositeScore);
                riskDecision.setDecision(decision);
                riskDecision.setDescription(alert.getDescription());
                riskDecision.setDecisionTime(System.currentTimeMillis());

                DECISION_LOG.info("风险决策完成, userId={}, alertType={}, score={}, decision={}",
                    alert.getUserId(), alert.getAlertType(), compositeScore, decision);

                out.collect(riskDecision);

                // 如果决策为拦截，注册定时器延迟触发拦截指令（给人工审核留窗口）
                if ("BLOCK".equals(decision)) {
                    long triggerTime = ctx.timerService().currentProcessingTime() + 5000L;
                    ctx.timerService().registerProcessingTimeTimer(triggerTime);
                }
            } catch (Exception e) {
                DECISION_LOG.error("风险决策处理异常, alertId={}, userId={}",
                    alert.getAlertId(), alert.getUserId(), e);
                // 异常时默认放行，避免误拦截影响正常用户
                RiskDecision fallback = new RiskDecision();
                fallback.setDecisionId(UUID.randomUUID().toString());
                fallback.setAlertId(alert.getAlertId());
                fallback.setUserId(alert.getUserId());
                fallback.setDecision("PASS");
                fallback.setDescription("决策异常,默认放行: " + e.getMessage());
                fallback.setDecisionTime(System.currentTimeMillis());
                out.collect(fallback);
            }
        }

        @Override
        public void onTimer(long timestamp, OnTimerContext ctx, Collector<RiskDecision> out) {
            // 定时器触发时，可以发送拦截确认指令
            DECISION_LOG.info("拦截定时器触发, userId={}, time={}", ctx.getCurrentKey(), timestamp);
        }
    }

    // ====================================================================
    // 幂等决策 Sink
    // ====================================================================

    /**
     * 风控决策幂等 Sink
     *
     * 写入目标:
     *   - MySQL: 风控决策记录表（审计日志）
     *   - Redis: 实时拦截指令（供交易系统消费）
     *
     * 幂等策略:
     *   - MySQL: INSERT ON DUPLICATE KEY UPDATE（基于 alertId 唯一索引）
     *   - Redis: SETNX + TTL（基于 alertId）
     */
    public static class IdempotentRiskDecisionSink extends RichSinkFunction<RiskDecision> {

        private static final Logger SINK_LOG = LoggerFactory.getLogger(IdempotentRiskDecisionSink.class);
        private transient Connection mysqlConn;
        private transient JedisPool jedisPool;
        private transient Counter blockCounter;
        private transient Counter passCounter;

        @Override
        public void open(Configuration parameters) {
            try {
                // MySQL 连接
                mysqlConn = DriverManager.getConnection(
                    "jdbc:mysql://mysql-host:3306/risk_control", "root", "password");
                // Redis 连接
                jedisPool = new JedisPool("redis-host", 6379);

                blockCounter = getRuntimeContext().getMetricGroup().counter("risk_block_count");
                passCounter = getRuntimeContext().getMetricGroup().counter("risk_pass_count");

                SINK_LOG.info("RiskDecision Sink 初始化完成");
            } catch (Exception e) {
                SINK_LOG.error("Sink 初始化失败", e);
                throw new RuntimeException(e);
            }
        }

        @Override
        public void invoke(RiskDecision decision, Context context) {
            // ========== 1. MySQL 幂等写入 ==========
            String sql = "INSERT INTO risk_decision_log " +
                "(decision_id, alert_id, user_id, alert_type, composite_score, " +
                "decision, description, decision_time) " +
                "VALUES (?, ?, ?, ?, ?, ?, ?, ?) " +
                "ON DUPLICATE KEY UPDATE " +
                "composite_score=VALUES(composite_score), decision=VALUES(decision)";

            int maxRetry = 3;
            for (int attempt = 1; attempt <= maxRetry; attempt++) {
                try (PreparedStatement ps = mysqlConn.prepareStatement(sql)) {
                    ps.setString(1, decision.getDecisionId());
                    ps.setString(2, decision.getAlertId());
                    ps.setString(3, decision.getUserId());
                    ps.setString(4, decision.getAlertType());
                    ps.setInt(5, decision.getCompositeScore());
                    ps.setString(6, decision.getDecision());
                    ps.setString(7, decision.getDescription());
                    ps.setLong(8, decision.getDecisionTime());
                    ps.executeUpdate();

                    SINK_LOG.info("MySQL 决策记录写入成功, alertId={}, decision={}",
                        decision.getAlertId(), decision.getDecision());
                    break;
                } catch (SQLException e) {
                    SINK_LOG.warn("MySQL 写入失败, attempt={}/{}, error={}",
                        attempt, maxRetry, e.getMessage());
                    if (attempt >= maxRetry) {
                        SINK_LOG.error("MySQL 写入最终失败, 数据进入DLQ, alertId={}",
                            decision.getAlertId(), e);
                    }
                    try { Thread.sleep(1000L * attempt); } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                    }
                }
            }

            // ========== 2. Redis 拦截指令下发 ==========
            if ("BLOCK".equals(decision.getDecision())) {
                blockCounter.inc();
                try (Jedis jedis = jedisPool.getResource()) {
                    // 使用 SETNX 实现幂等：同一 alertId 只下发一次拦截指令
                    String blockKey = "risk_block:" + decision.getAlertId();
                    String blockValue = JSON.toJSONString(decision);
                    // TTL 1小时，超时自动释放
                    String result = jedis.set(blockKey, blockValue, "NX", "EX", 3600);
                    if ("OK".equals(result)) {
                        SINK_LOG.warn("拦截指令已下发, userId={}, alertId={}",
                            decision.getUserId(), decision.getAlertId());
                    } else {
                        SINK_LOG.info("拦截指令已存在(幂等跳过), alertId={}", decision.getAlertId());
                    }
                } catch (Exception e) {
                    SINK_LOG.error("Redis 拦截指令下发失败, alertId={}", decision.getAlertId(), e);
                }
            } else {
                passCounter.inc();
                SINK_LOG.info("交易放行, userId={}, decision={}",
                    decision.getUserId(), decision.getDecision());
            }
        }

        @Override
        public void close() {
            try { if (mysqlConn != null) mysqlConn.close(); } catch (Exception ignored) {}
            if (jedisPool != null) jedisPool.close();
            SINK_LOG.info("RiskDecision Sink 资源已释放");
        }
    }

    // ====================================================================
    // 辅助数据结构
    // ====================================================================

    public static class RiskAlert implements Serializable {
        private String alertId;
        private String userId;
        private String alertType;
        private int riskScore;
        private String description;
        private List<String> eventIds;
        private long alertTime;
        // 省略 getter/setter
    }

    public static class RiskDecision implements Serializable {
        private String decisionId;
        private String alertId;
        private String userId;
        private String alertType;
        private int compositeScore;
        private String decision;  // BLOCK / REVIEW / PASS
        private String description;
        private long decisionTime;
        // 省略 getter/setter
    }
}
```

#### 7.3.1 多源数据接入与清洗

```java
import org.apache.flink.api.common.eventtime.WatermarkStrategy;
import org.apache.flink.api.common.functions.RichMapFunction;
import org.apache.flink.api.common.state.*;
import org.apache.flink.api.common.typeinfo.TypeHint;
import org.apache.flink.api.common.typeinfo.TypeInformation;
import org.apache.flink.configuration.Configuration;

/**
 * 实时数据 ETL 全链路
 *
 * 链路: 多源接入 -> 清洗转换 -> 维表关联 -> 输出下游 -> Checkpoint容错
 *
 * 数据源:
 *   1. MySQL CDC (binlog) -> 商品维表变更
 *   2. Kafka 业务事件 -> 交易事实数据
 *   3. SFTP 文件流 -> 外部供应商数据
 *
 * 输出:
 *   1. Kafka DWD topic -> 供下游实时数仓
 *   2. Elasticsearch -> 供实时检索
 *
 * 容错:
 *   - Checkpoint Exactly-Once (60s间隔, RocksDB状态后端)
 *   - 维表关联: Async I/O + 缓存 + 降级策略
 *   - 幂等: 基于事件ID + 版本号的去重
 */
public class RealtimeETLPipeline {

    private static final Logger LOG = LoggerFactory.getLogger(RealtimeETLPipeline.class);

    // 侧输出标签
    private static final OutputTag<String> DIRTY_DATA_TAG =
        new OutputTag<String>("dirty-data") {};
    private static final OutputTag<String> DEAD_LETTER_TAG =
        new OutputTag<String>("dead-letter") {};

    public static void main(String[] args) throws Exception {
        StreamExecutionEnvironment env = StreamExecutionEnvironment.getExecutionEnvironment();
        env.setParallelism(6);
        env.enableCheckpointing(60_000, CheckpointingMode.EXACTLY_ONCE);

        CheckpointConfig cpConfig = env.getCheckpointConfig();
        cpConfig.setMinPauseBetweenCheckpoints(30_000);
        cpConfig.setCheckpointTimeout(300_000);
        cpConfig.setTolerableCheckpointFailureNumber(3);
        cpConfig.setMaxConcurrentCheckpoints(1);
        cpConfig.setExternalizedCheckpointCleanup(
            CheckpointConfig.ExternalizedCheckpointCleanup.RETAIN_ON_CANCELLATION);

        // RocksDB 状态后端（支持增量 Checkpoint）
        env.setStateBackend(new EmbeddedRocksDBStateBackend(true));
        env.setRestartStrategy(RestartStrategies.fixedDelayRestart(10, 60_000));

        // ========== 1. 多源接入 ==========

        // 1.1 MySQL CDC Source (商品维表变更)
        DataStream<SourceRecord> cdcStream = env.addSource(new MySqlCdcSource(
            "mysql-cdc-host:3306", "product_db", "products"))
            .name("MySQL-CDC-Source")
            .uid("cdc-source");

        // 1.2 Kafka 业务事件 Source
        Properties kafkaProps = new Properties();
        kafkaProps.setProperty("bootstrap.servers", "kafka-01:9092");
        kafkaProps.setProperty("group.id", "flink-etl-pipeline");
        FlinkKafkaConsumer<String> kafkaConsumer = new FlinkKafkaConsumer<>(
            "business_events", new SimpleStringSchema(), kafkaProps);
        kafkaConsumer.setStartFromLatest();

        DataStream<SourceRecord> kafkaStream = env.addSource(kafkaConsumer)
            .name("Kafka-BusinessEvent-Source")
            .uid("kafka-source-etl")
            .map(new BusinessEventParser());

        // 1.3 合并多源数据流
        DataStream<SourceRecord> unionStream = cdcStream.union(kafkaStream);

        // ========== 2. 数据清洗 + 去重 ==========
        SingleOutputStreamOperator<SourceRecord> cleanedStream = unionStream
            .keyBy(SourceRecord::getRecordId)
            .process(new DedupAndCleanFunction())
            .name("DataClean-Dedup")
            .uid("clean-dedup");

        // 脏数据侧输出 -> DLQ
        DataStream<String> dirtyData = cleanedStream.getSideOutput(DIRTY_DATA_TAG);
        dirtyData.addSink(new KafkaDLQSink("dirty_data_dlq"))
            .name("DirtyData-DLQ-Sink")
            .uid("dirty-dlq-sink");

        // ========== 3. 维表关联 (Async I/O) ==========
        SingleOutputStreamOperator<EnrichedRecord> enrichedStream = AsyncDataStream
            .unorderedWait(
                cleanedStream,
                new AsyncDimensionJoinFunction(),
                3000,  // 超时 3 秒
                TimeUnit.MILLISECONDS,
                100    // 并发 100 个异步请求
            )
            .name("AsyncDimension-Join")
            .uid("async-dim-join");

        // ========== 4. 输出: Kafka + Elasticsearch ==========
        // 4.1 Kafka DWD topic
        enrichedStream
            .map(record -> JSON.toJSONString(record))
            .addSink(new FlinkKafkaProducer<String>(
                "dwd_enriched_events",
                new SimpleStringSchema(),
                kafkaProps))
            .name("Kafka-DWD-Sink")
            .uid("kafka-dwd-sink");

        // 4.2 Elasticsearch Sink
        enrichedStream.addSink(new ElasticsearchSink(
            "http://es-host:9200", "enriched_records"))
            .name("ES-Sink")
            .uid("es-sink");

        // ========== 5. Checkpoint 完成监控 ==========
        env.getCheckpointConfig().setCheckpointInterceptor(point -> {
            LOG.info("Checkpoint 完成, id={}, duration={}ms",
                point.getCheckpointId(), point.getDuration());
        });

        env.execute("Realtime-ETL-Pipeline");
    }

    public static class BusinessEventParser extends RichMapFunction<String, SourceRecord> {

        private transient Counter parseErrorCounter;

        @Override
        public void open(Configuration parameters) {
            parseErrorCounter = getRuntimeContext().getMetricGroup()
                .counter("business_event_parse_error");
        }

        @Override
        public SourceRecord map(String raw) {
            try {
                SourceRecord record = JSON.parseObject(raw, SourceRecord.class);
                if (record == null || record.getRecordId() == null) {
                    parseErrorCounter.inc();

                    return null;

                return record;
            } catch (Exception e) {
                parseErrorCounter.inc();
                LOG.error("业务事件JSON解析失败, raw={}", raw, e);
                return null;
            }
        }

    // ====================================================================
    // 去重 + 清洗函数
    // ====================================================================

    /**
     * 去重 + 数据清洗
     *
     * 幂等策略:
     *   - 基于 recordId 去重
     *   - 状态中保存最近 1 小时已处理的 recordId 集合
     *   - TTL 自动过期，避免状态膨胀
     *
     * 清洗规则:
     *   - 空值检查: 必填字段缺失 -> 侧输出到 dirty-data
     *   - 格式校验: 时间戳合理性、金额非负
     *   - 标准化: 统一时间格式、统一金额单位（分 -> 元）
     */
    public static class DedupAndCleanFunction
            extends KeyedProcessFunction<String, SourceRecord, SourceRecord> {

        private static final Logger CLEAN_LOG = LoggerFactory.getLogger(DedupAndCleanFunction.class);

        /** 已处理的 recordId（幂等去重） */
        private transient ValueState<Set<String>> processedIds;
        /** 去重状态 TTL 配置 */
        private static final long DEDUP_TTL_MS = 3600_000L; // 1小时

        @Override
        public void open(Configuration parameters) {
            ValueStateDescriptor<Set<String>> descriptor = new ValueStateDescriptor<>(
                "processed-record-ids", TypeInformation.of(new TypeHint<Set<String>>() {}));

            StateTtlConfig ttlConfig = StateTtlConfig.newBuilder(
                org.apache.flink.api.common.time.Time.milliseconds(DEDUP_TTL_MS))
                .setUpdateType(StateTtlConfig.UpdateType.OnCreateAndWrite)
                .setStateVisibility(StateTtlConfig.StateVisibility.NeverReturnExpired)
                .build();
            descriptor.enableTimeToLive(ttlConfig);

            processedIds = getRuntimeContext().getState(descriptor);
        }

        @Override
        public void processElement(SourceRecord record, Context ctx,
                                   Collector<SourceRecord> out) {
            String recordId = record.getRecordId();

            try {
                // ========== 幂等去重 ==========
                Set<String> ids = processedIds.value();
                if (ids == null) {
                    ids = new HashSet<>();
                }
                if (ids.contains(recordId)) {
                    CLEAN_LOG.debug("重复数据已跳过(幂等), recordId={}", recordId);
                    return;
                }
                ids.add(recordId);
                processedIds.update(ids);

                // ========== 数据清洗 ==========

                // 规则1: 必填字段检查
                if (record.getRecordId() == null || record.getRecordId().isEmpty()) {
                    ctx.output(DIRTY_DATA_TAG, JSON.toJSONString(record));
                    CLEAN_LOG.warn("必填字段缺失(记录ID), 数据进入脏数据侧输出, record={}", record);
                    return;
                }

                // 规则2: 时间戳合理性
                if (record.getEventTimestamp() <= 0) {
                    record.setEventTimestamp(System.currentTimeMillis());
                    CLEAN_LOG.warn("时间戳异常，已修正为当前时间, recordId={}", recordId);
                }

                // 规则3: 金额非负
                if (record.getAmount() < 0) {
                    ctx.output(DIRTY_DATA_TAG, JSON.toJSONString(record));
                    CLEAN_LOG.warn("金额为负值, 数据进入脏数据侧输出, recordId={}, amount={}",
                        recordId, record.getAmount());
                    return;
                }

                // 规则4: 标准化 - 金额单位转换（分 -> 元）
                if ("CENT".equals(record.getAmountUnit())) {
                    record.setAmount(record.getAmount() / 100.0);
                    record.setAmountUnit("YUAN");
                }

                // 规则5: 标准化 - 统一时间格式为毫秒时间戳
                record.setProcessTime(System.currentTimeMillis());

                CLEAN_LOG.debug("数据清洗完成, recordId={}, source={}", recordId, record.getSource());
                out.collect(record);

            } catch (Exception e) {
                CLEAN_LOG.error("清洗过程异常, recordId={}", recordId, e);
                ctx.output(DEAD_LETTER_TAG, JSON.toJSONString(record));
            }
        }
    }

    // ====================================================================
    // 异步维表关联
    // ====================================================================

    /**
     * 异步维表关联
     *
     * 维表存储: Redis (用户维度) + HBase (商品维度)
     *
     * 降级策略:
     *   - Redis 超时 -> 查 HBase
     *   - HBase 超时 -> 使用缓存默认值
     *   - 全部失败 -> 输出未关联记录（下游容忍空值）
     *
     * 缓存策略:
     *   - 本地 LRU 缓存（10000 条，TTL 5分钟）
     *   - 减少远程查询次数
     */
    public static class AsyncDimensionJoinFunction
            extends RichAsyncFunction<SourceRecord, EnrichedRecord> {

        private static final Logger DIM_LOG = LoggerFactory.getLogger(AsyncDimensionJoinFunction.class);

        private transient ExecutorService executorService;
        private transient JedisPool redisPool;
        private transient Connection hbaseConn;

        /** 本地缓存: recordId -> 维度信息 */
        private transient Map<String, DimensionInfo> localCache;
        private static final int CACHE_MAX_SIZE = 10000;
        private static final long CACHE_TTL_MS = 300_000L; // 5分钟

        @Override
        public void open(Configuration parameters) {
            executorService = Executors.newFixedThreadPool(50);
            redisPool = new JedisPool("redis-host", 6379);
            // HBase 连接初始化（省略具体代码）
            localCache = new LinkedHashMap<String, DimensionInfo>(CACHE_MAX_SIZE, 0.75f, true) {
                @Override
                protected boolean removeEldestEntry(Map.Entry<String, DimensionInfo> eldest) {
                    return size() > CACHE_MAX_SIZE;
                }
            };
            DIM_LOG.info("AsyncDimensionJoin 初始化完成, 线程池大小=50");
        }

        @Override
        public void asyncInvoke(SourceRecord record, ResultFuture<EnrichedRecord> resultFuture) {
            CompletableFuture.supplyAsync(() -> {
                EnrichedRecord enriched = new EnrichedRecord(record);

                try {
                    // ========== 1. 查本地缓存 ==========
                    String cacheKey = record.getRecordId();
                    DimensionInfo cachedInfo = localCache.get(cacheKey);
                    if (cachedInfo != null && !isCacheExpired(cachedInfo)) {
                        enriched.setDimensionInfo(cachedInfo);
                        DIM_LOG.debug("维表关联命中本地缓存, recordId={}", record.getRecordId());
                        return enriched;
                    }

                    // ========== 2. 查 Redis（用户维度） ==========
                    DimensionInfo dimInfo = new DimensionInfo();
                    try (Jedis jedis = redisPool.getResource()) {
                        String userDimKey = "dim:user:" + record.getUserId();
                        String userDimJson = jedis.get(userDimKey);
                        if (userDimJson != null) {
                            UserInfo userInfo = JSON.parseObject(userDimJson, UserInfo.class);
                            dimInfo.setUserInfo(userInfo);
                        }
                    } catch (Exception e) {
                        DIM_LOG.warn("Redis 维表查询失败, recordId={}, userId={}, 降级到HBase",
                            record.getRecordId(), record.getUserId(), e);
                    }

                    // ========== 3. 查 HBase（商品维度） ==========
                    try {
                        ProductInfo productInfo = queryHBaseProduct(record.getProductId());
                        if (productInfo != null) {
                            dimInfo.setProductInfo(productInfo);
                        }
                    } catch (Exception e) {
                        DIM_LOG.warn("HBase 维表查询失败, recordId={}, productId={}, 使用默认值",
                            record.getRecordId(), record.getProductId(), e);
                        // 降级: 设置默认商品信息
                        dimInfo.setProductInfo(ProductInfo.defaultInstance());
                    }

                    // 更新本地缓存
                    dimInfo.setCacheTime(System.currentTimeMillis());
                    synchronized (localCache) {
                        localCache.put(cacheKey, dimInfo);
                    }

                    enriched.setDimensionInfo(dimInfo);
                    return enriched;

                } catch (Exception e) {
                    DIM_LOG.error("维表关联整体异常, recordId={}", record.getRecordId(), e);
                    // 最终降级: 返回未关联记录
                    enriched.setDimensionInfo(DimensionInfo.empty());
                    return enriched;
                }
            }, executorService).whenComplete((result, throwable) -> {
                if (throwable != null) {
                    DIM_LOG.error("异步维表关联失败, recordId={}", record.getRecordId(), throwable);
                    resultFuture.complete(Collections.singleton(EnrichedRecord.fromRecord(record)));
                } else {
                    resultFuture.complete(Collections.singleton(result));
                }
            });
        }

        @Override
        public void timeout(SourceRecord input, ResultFuture<EnrichedRecord> resultFuture) {
            DIM_LOG.warn("维表关联超时, recordId={}, 降级输出未关联记录", input.getRecordId());
            resultFuture.complete(Collections.singleton(EnrichedRecord.fromRecord(input)));
        }

        @Override
        public void close() {
            executorService.shutdown();
            try {
                if (!executorService.awaitTermination(5, TimeUnit.SECONDS)) {
                    executorService.shutdownNow();
                }
            } catch (InterruptedException e) {
                executorService.shutdownNow();
                Thread.currentThread().interrupt();
            }
            if (redisPool != null) redisPool.close();
            DIM_LOG.info("AsyncDimensionJoin 资源已释放");
        }

        private boolean isCacheExpired(DimensionInfo info) {
            return info != null && (System.currentTimeMillis() - info.getCacheTime()) > CACHE_TTL_MS;
        }

        private ProductInfo queryHBaseProduct(String productId) throws Exception {
            // HBase 查询实现（省略）
            return null;
        }
    }

    /**
     * Elasticsearch Sink
     *
     * 幂等策略:
     *   - 使用 recordId 作为 ES _id，重复写入自动覆盖（version-based）
     *   - 批量写入，攒满 200 条或 5 秒触发
     *
     * 异常处理:
     *   - ES 不可用: 重试 + DLQ
     */
    public static class ElasticsearchSink extends RichSinkFunction<EnrichedRecord> {

        private static final Logger ES_LOG = LoggerFactory.getLogger(ElasticsearchSink.class);
        private transient RestHighLevelClient esClient;
        private transient List<EnrichedRecord> batchBuffer;
        private static final int BATCH_SIZE = 200;
        private static final long FLUSH_INTERVAL_MS = 5_000;
        private transient long lastFlushTime;
        private transient Counter writeSuccessCounter;
        private transient Counter writeErrorCounter;

        @Override
        public void open(Configuration parameters) {
            RestClientBuilder builder = RestClient.builder(
                new HttpHost("es-host", 9200, "http"));
            esClient = new RestHighLevelClient(builder);
            batchBuffer = new ArrayList<>(BATCH_SIZE);
            lastFlushTime = System.currentTimeMillis();

            writeSuccessCounter = getRuntimeContext().getMetricGroup().counter("es_write_success");
            writeErrorCounter = getRuntimeContext().getMetricGroup().counter("es_write_error");

            ES_LOG.info("Elasticsearch Sink 初始化完成");
        }

        @Override
        public void invoke(EnrichedRecord record, Context context) {
            batchBuffer.add(record);

            boolean sizeTrigger = batchBuffer.size() >= BATCH_SIZE;
            boolean timeTrigger = (System.currentTimeMillis() - lastFlushTime) >= FLUSH_INTERVAL_MS;

            if (sizeTrigger || timeTrigger) {
                flush();
            }
        }

        private void flush() {
            if (batchBuffer.isEmpty()) return;

            List<EnrichedRecord> batch = new ArrayList<>(batchBuffer);
            batchBuffer.clear();
            lastFlushTime = System.currentTimeMillis();

            BulkRequest bulkRequest = new BulkRequest();
            for (EnrichedRecord record : batch) {
                IndexRequest indexRequest = new IndexRequest("enriched_records")
                    .id(record.getRecordId())  // 使用 recordId 作为 _id，实现幂等
                    .source(JSON.toJSONString(record), XContentType.JSON);
                bulkRequest.add(indexRequest);
            }

            int maxRetry = 3;
            for (int attempt = 1; attempt <= maxRetry; attempt++) {
                try {
                    BulkResponse response = esClient.bulk(bulkRequest, RequestOptions.DEFAULT);
                    if (response.hasFailures()) {
                        ES_LOG.warn("ES 批量写入部分失败: {}", response.buildFailureMessage());
                        writeErrorCounter.inc();
                        // 处理部分失败：将失败的记录写入 DLQ
                        for (BulkItemResponse itemResp : response.getItems()) {
                            if (itemResp.isFailed()) {
                                ES_LOG.error("ES 写入失败, recordId={}, error={}",
                                    itemResp.getId(), itemResp.getFailureMessage());
                            }
                        }
                    } else {
                        writeSuccessCounter.inc(batch.size());
                        ES_LOG.info("ES 批量写入成功, count={}", batch.size());
                    }
                    return;
                } catch (Exception e) {
                    ES_LOG.warn("ES 写入异常, attempt={}/{}, error={}",
                        attempt, maxRetry, e.getMessage());
                    if (attempt >= maxRetry) {
                        ES_LOG.error("ES 写入最终失败, 数据进入DLQ, count={}", batch.size(), e);
                        writeErrorCounter.inc(batch.size());
                        for (EnrichedRecord r : batch) {
                            sendToDLQ("es_sink_dlq", JSON.toJSONString(r));
                        }
                    }
                    try { Thread.sleep(2000L * attempt); } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                    }
                }
            }
        }

        @Override
        public void close() {
            flush();
            try {
                if (esClient != null) esClient.close();
            } catch (Exception e) {
                ES_LOG.warn("ES 客户端关闭异常", e);
            }
            ES_LOG.info("Elasticsearch Sink 资源已释放");
        }

        private void sendToDLQ(String dlqTopic, String data) {
            ES_LOG.warn("数据写入DLQ, topic={}, data={}", dlqTopic, data);
        }
    }
```

#### 7.3.2 Checkpoint 容错与恢复

```java
/**
 * Checkpoint 容错配置与监控
 *
 * 配置要点:
 *   1. RocksDB 增量 Checkpoint（减少全量 IO）
 *   2. Checkpoint 存储到 HDFS（高可用）
 *   3. 保留最近 3 个 Checkpoint（支持回退）
 *   4. 任务取消后保留 Checkpoint（支持手动恢复）
 *
 * 恢复流程:
 *   1. 从 Savepoint/Checkpoint 恢复
 *   2. Kafka Source 从上次 committed offset 消费
 *   3. Sink 端通过幂等写入消除重复数据
 */
public class CheckpointManager {

    private static final Logger LOG = LoggerFactory.getLogger(CheckpointManager.class);

    /**
     * 配置 RocksDB 增量 Checkpoint
     */
    public static void configureIncrementalCheckpoint(StreamExecutionEnvironment env) {
        // 启用 RocksDB 增量 Checkpoint
        EmbeddedRocksDBStateBackend rocksDB = new EmbeddedRocksDBStateBackend(true);

        // RocksDB 调优参数
        rocksDB.setPredefinedOptions(PredefinedOptions.SPINNING_DISK_OPTIMIZED);
        rocksDB.setRocksDBOptions(new OptionsFactory() {
            @Override
            public DBOptions createDBOptions(DBOptions currentOptions) {
                return currentOptions
                    .setMaxBackgroundCompactions(4)
                    .setMaxBackgroundFlushes(2)
                    .setUseFsync(false);
            }

            @Override
            public ColumnFamilyOptions createColumnOptions(ColumnFamilyOptions currentOptions) {
                return currentOptions
                    .setCompactionStyle(CompactionStyle.LEVEL)
                    .setMaxWriteBufferNumberToMaintain(1);
            }
        });

        env.setStateBackend(rocksDB);
        LOG.info("RocksDB 增量 Checkpoint 已配置");
    }

    /**
     * 从 Checkpoint 恢复作业
     *
     * 命令: flink run -s hdfs:///flink/checkpoints/etl-pipeline/chk-12345 \
     *        -yid application_xxx RealtimeETLPipeline.jar
     */
    public static void restoreFromCheckpoint(String checkpointPath) {
        LOG.info("准备从 Checkpoint 恢复, path={}", checkpointPath);
        // 实际通过 Flink CLI 或 REST API 触发
    }

    /**
     * Checkpoint 失败监控
     *
     * 当连续 Checkpoint 失败超过阈值时，触发告警
     */
    public static class CheckpointFailureMonitor {

        private static final int ALERT_THRESHOLD = 3;
        private int consecutiveFailures = 0;

        public void onCheckpointComplete(long checkpointId, long duration, boolean success) {
            if (success) {
                if (consecutiveFailures > 0) {
                    LOG.info("Checkpoint 恢复成功, checkpointId={}, 之前连续失败{}次",
                        checkpointId, consecutiveFailures);
                }
                consecutiveFailures = 0;
                LOG.info("Checkpoint 完成, id={}, duration={}ms", checkpointId, duration);
            } else {
                consecutiveFailures++;
                LOG.warn("Checkpoint 失败, 连续失败次数={}", consecutiveFailures);
                if (consecutiveFailures >= ALERT_THRESHOLD) {
                    LOG.error("Checkpoint 连续失败{}次，触发告警!", consecutiveFailures);
                    sendAlert("Checkpoint 连续失败", String.format(
                        "ETL Pipeline Checkpoint 连续失败 %d 次，请检查!", consecutiveFailures));
                }
            }
        }

        private void sendAlert(String title, String message) {
            // 发送告警（大象/短信/邮件）
            LOG.error("告警: {} - {}", title, message);
        }
    }
}
```
