# 搜索引擎架构设计

## 一、问题背景

### 1.1 传统数据库查询的局限性

在互联网应用中，数据检索是最基础也是最频繁的操作之一。当业务规模较小时，关系型数据库的`LIKE`查询和索引查询能够满足基本的搜索需求。但随着数据量的增长和搜索需求的复杂化，传统数据库查询暴露出了严重的瓶颈：

**（1）全文检索效率低下**

关系型数据库中的`LIKE '%关键词%'`查询无法利用索引，需要对全表进行逐行扫描。当数据量达到千万级甚至亿级时，查询延迟从毫秒级退化到秒级甚至分钟级，完全无法满足用户体验要求。

```sql
-- 反例：全表扫描，性能极差
SELECT * FROM products WHERE name LIKE '%无线蓝牙耳机%';
-- 数据量1000万行时，查询耗时可能超过10秒
```

**（2）分词与语义理解缺失**

传统数据库是基于精确匹配的，无法理解"无线蓝牙耳机"和"蓝牙无线耳机"是等价的搜索意图。更不用说同义词匹配（"手机"="手机"="cellphone"）、拼音搜索、模糊匹配等高级搜索能力。

**（3）多条件组合查询困难**

当搜索需求涉及多个字段的复杂组合（关键词匹配+价格范围+品牌筛选+评分排序）时，关系型数据库需要建立大量复合索引，且不同查询条件的组合导致索引设计异常复杂。

**（4）实时性与一致性的权衡**

在高并发写入场景下，数据库的索引更新会影响写入性能。而搜索场景通常可以接受秒级的数据延迟（近实时），这为采用专门的搜索引擎提供了空间。

### 1.2 搜索引擎的核心价值

分布式搜索引擎是专门为全文检索和复杂查询场景设计的系统。以Elasticsearch为代表的搜索引擎，基于Apache Lucene构建，提供了分布式的、RESTful风格的搜索和分析能力。其核心优势包括：

- **倒排索引**：基于倒排索引的全文检索，支持亿级文档的毫秒级搜索
- **分布式架构**：数据自动分片和副本，支持水平扩展和故障容错
- **丰富的查询语法**：支持全文搜索、精确匹配、范围查询、聚合分析等
- **近实时搜索**：数据写入后1秒内即可被搜索到
- **生态完善**：ELK技术栈（Elasticsearch + Logstash + Kibana）覆盖数据采集、存储、分析、可视化全链路

### 1.3 核心应用场景

| 场景 | 描述 | 典型需求 |
|------|------|---------|
| 网站搜索 | 商品搜索、内容搜索 | 分词、高亮、推荐、排序 |
| 日志管理 | 服务器日志、应用日志的采集与分析 | 海量写入、时间范围查询 |
| 业务分析 | 订单分析、用户行为分析 | 多维聚合、数据报表 |
| 监控告警 | 基础设施和应用的监控指标 | 实时写入、趋势分析 |
| 地理位置 | 附近的人/店/服务 | 地理坐标查询、距离排序 |

本文将从搜索引擎的核心原理出发，深入分析其架构设计、读写链路和性能优化策略。

## 二、整体架构设计

### 2.1 倒排索引原理

倒排索引（Inverted Index）是搜索引擎的核心数据结构。与正排索引（Forward Index）的"文档→词"映射相反，倒排索引建立的是"词→文档"的映射关系。

#### 2.1.1 正排索引 vs 倒排索引

**正排索引**：以文档为维度组织数据，记录每个文档中包含哪些词。

```
正排索引（Forward Index）：
┌──────────┬──────────────────────────────────┐
│ 文档ID    │ 文档内容                          │
├──────────┼──────────────────────────────────┤
│ Doc1     │ "Java并发编程实战"                 │
│ Doc2     │ "深入理解Java虚拟机"               │
│ Doc3     │ "Spring实战指南"                  │
│ Doc4     │ "Java编程思想"                    │
└──────────┴──────────────────────────────────┘

问题：搜索"Java"需要遍历所有文档，时间复杂度O(N)
```

**倒排索引**：以词（Term）为维度组织数据，记录每个词出现在哪些文档中。

```
倒排索引（Inverted Index）：

┌─────────────────┐          ┌─────────────────────────────────┐
│  Term Dictionary │          │         Posting List            │
│  （词典）         │          │        （倒排列表）               │
├─────────────────┤          ├─────────────────────────────────┤
│ Java            │────────▶ │ [Doc1, Doc2, Doc4]              │
│                 │          │  TF: [1, 1, 1]                  │
│                 │          │  Pos: [(0), (2), (0)]           │
├─────────────────┤          ├─────────────────────────────────┤
│ 并发            │────────▶ │ [Doc1]                          │
│                 │          │  TF: [1]                        │
│                 │          │  Pos: [(1)]                     │
├─────────────────┤          ├─────────────────────────────────┤
│ 编程            │────────▶ │ [Doc1, Doc4]                    │
│                 │          │  TF: [1, 1]                     │
│                 │          │  Pos: [(2), (1)]                │
├─────────────────┤          ├─────────────────────────────────┤
│ 实战            │────────▶ │ [Doc1, Doc3]                    │
│                 │          │  TF: [1, 1]                     │
│                 │          │  Pos: [(3), (1)]                │
├─────────────────┤          ├─────────────────────────────────┤
│ 虚拟机          │────────▶ │ [Doc2]                          │
│                 │          │  TF: [1]                        │
│                 │          │  Pos: [(3)]                     │
├─────────────────┤          ├─────────────────────────────────┤
│ Spring          │────────▶ │ [Doc3]                          │
│                 │          │  TF: [1]                        │
│                 │          │  Pos: [(0)]                     │
└─────────────────┘          └─────────────────────────────────┘

搜索"Java"只需一次查找，时间复杂度O(1)
```

#### 2.1.2 倒排索引的核心组成

倒排索引由两个关键部分构成：

**Term Dictionary（词典）**：记录所有出现过的词（Term），并维护每个词到倒排列表的映射关系。词典通常使用B+树或FST（Finite State Transducer）实现，支持高效的前缀匹配和范围查询。

**Posting List（倒排列表）**：每个词对应的倒排列表包含以下信息：

```java
/**
 * 倒排列表中的单个倒排项
 */
public class PostingEntry {
    /** 文档ID */
    private int docId;
    
    /** 词频（Term Frequency）：该词在文档中出现的次数
     *  用于相关性评分 - TF越高，文档与该词的相关性越强 */
    private int termFrequency;
    
    /** 位置信息（Position）：该词在文档中出现的位置列表
     *  用于短语查询（Phrase Query）- 判断多个词是否相邻出现 */
    private List<Integer> positions;
    
    /** 偏移量（Offset）：该词在原文中的字符偏移
     *  用于搜索结果高亮（Highlighting）- 定位关键词在原文中的位置 */
    private int startOffset;
    private int endOffset;
}
```

#### 2.1.3 分词器（Analyzer）

倒排索引的构建依赖于分词器（Analyzer）。分词器负责将原始文本拆分为一系列词（Term）。一个完整的分析过程包含三个阶段：

```
原始文本: "Elasticsearch是一个强大的搜索引擎！"
                    │
                    ▼
        ┌──────────────────────┐
        │  Character Filters   │  字符过滤器
        │  去除HTML标签          │  清理特殊字符
        │  替换特殊字符          │
        └──────────┬───────────┘
                   │
        "Elasticsearch是一个强大的搜索引擎"
                   │
                   ▼
        ┌──────────────────────┐
        │     Tokenizer        │  分词器
        │  中文分词（IK/jieba） │  按词切分
        │  英文按空格切分        │
        └──────────┬───────────┘
                   │
        ["elasticsearch", "是", "一个", "强大", "的", "搜索引擎"]
                   │
                   ▼
        ┌──────────────────────┐
        │   Token Filters      │  词元过滤器
        │  小写转换             │  规范化处理
        │  停用词过滤           │
        │  同义词扩展           │
        └──────────┬───────────┘
                   │
        ["elasticsearch", "强大", "搜索引擎"]
        （去除了停用词"是"、"一个"、"的"）
```


### 2.2 集群架构

Elasticsearch采用分布式架构，一个集群（Cluster）由多个节点（Node）组成。节点根据职责不同分为多种角色。

```
┌──────────────────────────────────────────────────────────────────┐
│                      Elasticsearch 集群                           │
│                                                                  │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐                │
│  │ Master Node│  │ Master Node│  │ Master Node│   Master节点     │
│  │  (Active)  │  │ (Standby)  │  │ (Standby)  │   集群状态管理    │
│  │            │  │            │  │            │   选举/元数据     │
│  └────────────┘  └────────────┘  └────────────┘                │
│         │                                                       │
│         ▼                                                       │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐                │
│  │ Data Node  │  │ Data Node  │  │ Data Node  │   Data节点      │
│  │            │  │            │  │            │   数据存储       │
│  │ Shard P0   │  │ Shard P1   │  │ Shard P2   │   CRUD/搜索     │
│  │ Shard R1   │  │ Shard R2   │  │ Shard R0   │   聚合计算      │
│  └────────────┘  └────────────┘  └────────────┘                │
│                                                                  │
│  ┌────────────┐  ┌────────────┐                                │
│  │Coordinator │  │Coordinator │   Coordinator节点               │
│  │   Node     │  │   Node     │   请求路由                      │
│  │            │  │            │   结果合并                      │
│  └────────────┘  └────────────┘                                │
│                                                                  │
│  ┌────────────┐                                                │
│  │ Ingest Node│   Ingest节点                                    │
│  │            │   数据预处理（写入前的Pipeline处理）                │
│  └────────────┘                                                │
└──────────────────────────────────────────────────────────────────┘
```

#### 2.2.1 节点角色详解

**Master节点**：
- 负责集群状态（Cluster State）管理：索引的创建/删除、分片的分配/迁移
- 通过选举机制（基于Raft或类Bully算法）选出一个Active Master，其余为Standby
- 建议部署3个专用Master节点（不存储数据），确保选举的可靠性
- 轻量级工作负载，不需要高配置的硬件

**Data节点**：
- 存储实际的索引数据，执行数据的CRUD操作
- 执行搜索查询和聚合计算，是集群中最消耗资源的节点
- 需要高性能的磁盘（推荐SSD）、充足的内存和CPU
- 可以进一步细分为Hot/Warm/Cold节点用于数据分级存储

**Coordinator节点**：
- 不存储数据，不参与选举，专门负责请求的路由和结果的合并
- 将搜索请求分发到相关的Data节点，收集各节点的结果并合并排序
- 在高查询并发的场景下，可以部署多个Coordinator节点分担压力
- 需要较大的内存来缓存搜索结果的合并过程

**Ingest节点**：
- 在数据索引之前执行预处理Pipeline（如字段提取、格式转换、GeoIP解析等）
- 减轻Data节点的处理负担
- 适合需要复杂数据预处理的场景

#### 2.2.2 索引与分片

Elasticsearch的数据组织层次如下：

```
Index（索引）──── 逻辑上的数据组织单元，类似关系型数据库中的"表"
  │
  ├── Primary Shard 0（主分片0）──── 物理上的数据存储单元
  │     │                           每个分片是一个独立的Lucene索引
  │     └── Segment 0              一个分片由多个Segment组成
  │         Segment 1              Segment是不可变的数据文件
  │         Segment 2              
  │
  ├── Primary Shard 1（主分片1）
  │     └── ...
  │
  ├── Replica Shard 0（副本分片0）── 主分片的完整拷贝
  │     └── ...                     用于故障容错和查询负载均衡
  │
  └── Replica Shard 1（副本分片1）
        └── ...
```

**分片分配策略**：

```java
/**
 * 分片分配配置
 */
public class ShardAllocationConfig {

    /**
     * 创建索引时配置分片
     */
    public Map<String, Object> createIndexSettings(int numberOfShards, 
                                                     int numberOfReplicas) {
        Map<String, Object> settings = new LinkedHashMap<>();
        
        // 主分片数量（创建后不可修改）
        // 建议：每个分片大小控制在10GB-50GB之间
        settings.put("number_of_shards", numberOfShards);
        
        // 副本数量（可动态修改）
        // 建议：生产环境至少1个副本
        settings.put("number_of_replicas", numberOfReplicas);
        
        // 分片分配感知：确保主分片和副本分布在不同的机架/AZ
        settings.put("routing.allocation.awareness.attributes", "zone");
        
        // 每个节点最多分配的分片数
        settings.put("routing.allocation.total_shards_per_node", 3);
        
        return settings;
    }

    /**
     * 计算推荐的分片数量
     * 经验公式：分片数 = 预估数据量(GB) / 单分片目标大小(GB)
     */
    public int calculateRecommendedShards(long estimatedDataGB, 
                                           int targetShardSizeGB) {
        int shards = (int) Math.ceil((double) estimatedDataGB / targetShardSizeGB);
        // 确保分片数不少于数据节点数（充分利用集群资源）
        // 确保分片数不超过合理上限（避免过多的小分片）
        return Math.max(shards, 1);
    }
}
```

```
│                    集群健康状态                                │
├──────────┬──────────────────────────────────────────────────┤

├──────────┼──────────────────────────────────────────────────┤

│          │ 常见原因：磁盘空间不足、节点宕机                     │
└──────────┴──────────────────────────────────────────────────┘
```

## 三、核心链路设计

### 3.1 数据写入流程

Elasticsearch的数据写入涉及多个内部组件的协作。写入流程的核心是先写入内存缓冲区和事务日志（Translog），然后定期刷新为不可变的Segment文件。

```
                    ┌──────────────────────────────────────┐
                    │        数据写入流程 (Index)           │
                    └──────────────────────────────────────┘

 客户端              Coordinator           Primary Shard          Replica Shard
   │                    │                      │                      │
   │ Index Request ────▶│                      │                      │
   │                    │ 路由到主分片 ─────────▶│                      │
   │                    │ (hash(docId) %       │                      │
   │                    │  num_shards)         │                      │
   │                    │                      │                      │
   │                    │                      │ 1.写入Memory Buffer  │
   │                    │                      │ 2.写入Translog       │
   │                    │                      │                      │
   │                    │                      │ 转发到副本 ────────────▶│
   │                    │                      │                      │ 写入Buffer
   │                    │                      │                      │ 写入Translog
   │                    │                      │ 副本确认 ◀────────────│
   │                    │                      │                      │
   │                    │ 写入成功 ◀────────────│                      │
   │ 200 OK ◀───────────│                      │                      │
   │                    │                      │                      │
   │                    │            【每1秒 Refresh】                 │
   │                    │                      │                      │
   │                    │                      │ Buffer → Segment     │
   │                    │                      │ (此时数据可被搜索到)    │
   │                    │                      │                      │
   │                    │            【每30分钟 或 Translog达到512MB】  │
   │                    │                      │                      │
   │                    │                      │ Flush:               │
   │                    │                      │ · Segment写入磁盘     │
   │                    │                      │ · 清空Translog        │
```

#### 3.1.1 写入流程详解

```java
/**
 * 数据写入处理器
 */
public class IndexWriteProcessor {

    /**
     * 步骤1：Coordinator节点接收请求并路由
     */
    public IndexResponse coordinateIndexRequest(IndexRequest request) {
        // 确定目标分片
        int shardId = calculateShardId(request.id(), numberOfShards);
        
        // 查找主分片所在的节点
        ShardRouting primaryShard = clusterState
            .getRoutingTable()
            .getShardRouting(request.index(), shardId);
        
        // 转发请求到主分片节点
        return forwardToPrimary(primaryShard.currentNodeId(), request);
    }

    /**
     * 分片路由算法
     * 通过文档ID的哈希值确定目标分片
     */
    private int calculateShardId(String documentId, int numberOfShards) {
        // Murmur3 哈希，保证分布均匀
        int hash = Murmur3HashFunction.hash(documentId);
        return Math.floorMod(hash, numberOfShards);
    }

    /**
     * 步骤2：主分片处理写入
     */
    public void handlePrimaryWrite(IndexRequest request) {
        // 2.1 版本冲突检查（乐观并发控制）
        long currentVersion = getDocumentVersion(request.id());
        if (request.version() != 0 && request.version() != currentVersion) {
            throw new VersionConflictException(
                "Version conflict: expected " + request.version() + 
                " but got " + currentVersion);
        }

        // 2.2 文档分析（对text类型字段进行分词）
        ParsedDocument parsedDoc = documentParser.parse(request);

        // 2.3 写入Lucene索引（Memory Buffer）
        // 此时数据在内存中，尚不可搜索
        luceneIndex.addDocument(parsedDoc.toLuceneDocument());

        // 2.4 写入Translog（事务日志，保障持久性）
        translog.add(new TranslogEntry(
            TranslogEntry.Type.INDEX,
            request.id(),
            parsedDoc.source(),
            System.currentTimeMillis()
        ));

        // 2.5 转发到副本分片
        for (ShardRouting replicaShard : replicaShards) {
            forwardToReplica(replicaShard, request);
        }
    }
}
```

#### 3.1.2 Refresh机制

Refresh是将内存缓冲区中的数据刷新为一个新的Segment，使数据变得可搜索的过程。默认每1秒执行一次，这就是Elasticsearch被称为"近实时"（Near Real-Time）搜索引擎的原因。

```java
/**
 * Refresh机制
 */
public class RefreshProcessor {

    /** 默认刷新间隔：1秒 */
    private static final long DEFAULT_REFRESH_INTERVAL_MS = 1000;

    /**
     * 执行Refresh：将内存Buffer转为Segment
     */
    public void doRefresh() {
        // 1. 将当前Memory Buffer中的文档生成一个新的Segment
        //    Segment写入文件系统缓存（OS Page Cache），尚未fsync到磁盘
        Segment newSegment = luceneIndex.createSegmentFromBuffer();
        
        // 2. 清空Memory Buffer，准备接收新的写入
        luceneIndex.clearBuffer();
        
        // 3. 打开新的SearchReader，包含新生成的Segment
        //    此后的搜索请求可以看到新写入的数据
        searchReaderManager.refreshReader();
        
        // 注意：此时Translog不会被清空
        // Translog保留到下次Flush时才清空
    }
}

/**
 * Segment内部结构
 * Segment是不可变的（Immutable），一旦生成就不会被修改
 */
public class SegmentStructure {
    
    /** 倒排索引：Term -> Posting List */
    private InvertedIndex invertedIndex;
    
    /** 正排数据（Stored Fields）：存储原始文档内容 */
    private StoredFields storedFields;
    
    /** Doc Values：列式存储，用于排序和聚合 */
    private DocValues docValues;
    
    /** 标记已删除的文档（.del文件） */
    private BitSet deletedDocs;
    
    /**
     * 文档的"删除"和"更新"操作：
     * 由于Segment不可变，删除操作只是在.del文件中标记文档
     * 更新操作 = 标记旧文档为已删除 + 在新Segment中写入新文档
     * 被标记删除的文档在Segment Merge时才会被真正物理删除
     */
}
```

#### 3.1.3 Flush与Translog

Flush操作将文件系统缓存中的Segment强制刷盘（fsync），并清空Translog。

```java
/**
 * Flush与Translog机制
 */
public class FlushProcessor {

    /** 默认Translog大小上限：512MB */
    private static final long TRANSLOG_SIZE_THRESHOLD = 512 * 1024 * 1024;
    /** 默认Flush间隔：30分钟 */
    private static final long FLUSH_INTERVAL_MS = 30 * 60 * 1000;

    /**
     * 执行Flush
     */
    public void doFlush() {
        // 1. 先执行一次Refresh，确保所有Buffer中的数据都写入Segment
        refreshProcessor.doRefresh();
        
        // 2. 将所有Segment文件fsync到磁盘
        //    确保数据持久化，即使机器宕机也不会丢失
        luceneIndex.forceMergeAndSync();
        
        // 3. 清空Translog
        //    因为所有数据已经持久化到Segment文件，Translog不再需要
        translog.clear();
        
        // 4. 创建新的Translog文件
        translog.rollGeneration();
    }

    /**
     * Translog的作用：
     * 在Refresh之后、Flush之前的这段时间内，Segment虽然存在于文件系统缓存中，
     * 但尚未fsync到磁盘。如果此时机器宕机，这部分Segment数据会丢失。
     * 
     * Translog记录了所有的写入操作，在节点重启时可以通过重放Translog来恢复数据。
     * 
     * 数据安全性保障链：
     * 写入 → Memory Buffer + Translog(已fsync)
     *   → Refresh → Segment(在Page Cache) + Translog(已fsync)
     *     → Flush → Segment(已fsync) + 清空Translog
     */
}
```

#### 3.1.4 Segment Merge（段合并）

随着不断写入，分片中的Segment数量会持续增加。过多的Segment会影响搜索性能（每次搜索需要遍历所有Segment）。Segment Merge将多个小Segment合并为一个大Segment，同时物理删除标记为已删除的文档。

```
Segment Merge 过程：

合并前：
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│Segment 0 │ │Segment 1 │ │Segment 2 │ │Segment 3 │ │Segment 4 │
│ 100 docs │ │  50 docs │ │  30 docs │ │  80 docs │ │  20 docs │
│ 5 deleted│ │ 2 deleted│ │ 0 deleted│ │ 10 deleted│ │ 1 deleted│
└──────────┘ └──────────┘ └──────────┘ └──────────┘ └──────────┘

合并后：
┌────────────────────────────────────────────────────────────────┐
│                    Merged Segment                               │
│                    262 docs (已物理删除18个标记删除的文档)          │
└────────────────────────────────────────────────────────────────┘
```

```java
/**
 * Segment合并策略
 */
public class SegmentMergePolicy {

    /**
     * TieredMergePolicy（分层合并策略，ES默认）
     * 
     * 核心思想：
     * 1. 按Segment大小分层，同层的Segment合并在一起
     * 2. 每次合并的Segment数量由 max_merge_at_once 控制（默认10）
     * 3. 单个Segment最大不超过 max_merged_segment 限制（默认5GB）
     * 4. 删除文档比例超过阈值的Segment优先合并
     */
    public MergePolicy createTieredPolicy() {
        TieredMergePolicy policy = new TieredMergePolicy();
        
        // 每次合并最多合并10个Segment
        policy.setMaxMergeAtOnce(10);
        
        // 合并后的Segment最大5GB
        policy.setMaxMergedSegmentMB(5 * 1024);
        
        // 允许的最大Segment数量（超过则触发合并）
        policy.setSegmentsPerTier(10);
        
        // 删除文档超过10%的Segment优先合并回收空间
        policy.setDeletesPctAllowed(10.0);
        
        // 合并所占用的IO带宽限制
        policy.setMaxMergeRatePerSec(20); // MB/s
        
        return policy;
    }

    /**
     * Force Merge（强制合并）
     * 将所有Segment合并为指定数量（通常为1）
     * 注意：非常消耗IO和CPU，只应在非高峰期对不再写入的索引执行
     */
    public void forceMerge(String indexName, int maxNumSegments) {
        // 只建议对只读索引执行force merge
        // 如：按天创建的日志索引，过了一天后不再写入
        ForceMergeRequest request = new ForceMergeRequest(indexName);
        request.maxNumSegments(maxNumSegments);
        request.onlyExpungeDeletes(false);
        
        client.admin().indices().forceMerge(request).actionGet();
    }
}
```

#### 3.2.1 Query Phase（查询阶段）

```java
/**
 * 查询阶段处理器
 */
public class QueryPhaseProcessor {

    /**
     * Coordinator节点：分发查询到所有相关分片
     */
    public QueryPhaseResult executeQueryPhase(SearchRequest request) {
        // 1. 确定需要搜索的分片列表
        List<ShardRouting> targetShards = resolveTargetShards(request);
        
        // 2. 并发向所有目标分片发送查询请求
        List<CompletableFuture<ShardSearchResult>> futures = new ArrayList<>();
        for (ShardRouting shard : targetShards) {
            // 注意：可以查询主分片或副本分片（负载均衡）
            ShardRouting targetShard = selectBestShard(shard);
            CompletableFuture<ShardSearchResult> future = 
                sendQueryToShard(targetShard, request);
            futures.add(future);
        }

        // 3. 收集所有分片的查询结果
        List<ShardSearchResult> shardResults = futures.stream()
            .map(CompletableFuture::join)
            .collect(Collectors.toList());

        // 4. 全局排序和截断
        // 每个分片返回 from + size 个结果（如from=10, size=10，则返回20个）
        // Coordinator合并所有分片的结果后，全局排序，取第10~19个
        return mergeAndSort(shardResults, request.from(), request.size());
    }

    /**
     * 分片内查询执行
     * 在单个Lucene索引上执行搜索
     */
    public ShardSearchResult executeOnShard(SearchRequest request) {
        // 1. 解析查询DSL，构建Lucene Query对象
        Query luceneQuery = queryParser.parse(request.getQuery());

        // 2. 在所有Segment上执行搜索
        IndexSearcher searcher = searchReaderManager.acquireSearcher();
        try {
            // from + size 个文档的优先队列
            int topN = request.from() + request.size();
            TopDocs topDocs = searcher.search(luceneQuery, topN, 
                                               request.getSort());
            
            // 3. 返回文档ID和排序值（不返回完整文档，节省网络传输）
            ShardSearchResult result = new ShardSearchResult();
            result.setTotalHits(topDocs.totalHits.value);
            
            for (ScoreDoc scoreDoc : topDocs.scoreDocs) {
                result.addHit(new SearchHitId(
                    scoreDoc.doc,        // Lucene内部文档ID
                    scoreDoc.score,      // 相关性得分
                    request.index(),
                    shardId
                ));
            }
            
            return result;
        } finally {
            searchReaderManager.releaseSearcher(searcher);
        }
    }
}
```

#### 3.2.2 相关性评分（BM25）

Elasticsearch使用BM25算法计算文档与查询的相关性得分。BM25是TF-IDF的改进版本，考虑了词频饱和度和文档长度归一化。

```java
/**
 * BM25相关性评分算法
 */
public class BM25Scorer {

    /** k1: 控制词频的饱和度。k1越大，词频的影响越线性 */
    private double k1 = 1.2;
    
    /** b: 控制文档长度的影响。b=0表示不考虑长度，b=1完全考虑 */
    private double b = 0.75;

    /**
     * 计算BM25得分
     * 
     * BM25公式：
     * score(D, Q) = Σ IDF(qi) * (f(qi, D) * (k1 + 1)) / 
     *               (f(qi, D) + k1 * (1 - b + b * |D| / avgdl))
     *
     * 其中：
     * - qi: 查询中的第i个词
     * - f(qi, D): qi在文档D中的词频（TF）
     * - |D|: 文档D的长度（词数）
     * - avgdl: 所有文档的平均长度
     * - IDF(qi): 逆文档频率
     */
    public double score(String[] queryTerms, Document doc, 
                        IndexStatistics stats) {
        double totalScore = 0.0;
        
        for (String term : queryTerms) {
            // 词频：该词在文档中出现的次数
            int tf = doc.getTermFrequency(term);
            
            // 文档频率：包含该词的文档数量
            int df = stats.getDocumentFrequency(term);
            
            // 总文档数
            long totalDocs = stats.getTotalDocuments();
            
            // 文档长度
            int docLength = doc.getLength();
            
            // 平均文档长度
            double avgDocLength = stats.getAverageDocumentLength();

            // IDF计算（对数平滑）
            double idf = Math.log(1 + (totalDocs - df + 0.5) / (df + 0.5));

            // TF归一化
            double tfNorm = (tf * (k1 + 1)) / 
                (tf + k1 * (1 - b + b * docLength / avgDocLength));

            totalScore += idf * tfNorm;
        }

        return totalScore;
    }
}
```

#### 3.2.3 Fetch Phase（获取阶段）

```java
/**
 * 获取阶段处理器
 */
public class FetchPhaseProcessor {

    /**
     * 根据Query Phase的结果，获取完整的文档内容
     */
    public SearchResponse executeFetchPhase(QueryPhaseResult queryResult,
                                             SearchRequest request) {
        // 1. 根据全局排序结果，确定需要获取的文档ID
        List<SearchHitId> hitsToFetch = queryResult.getTopHits();
        
        // 2. 按分片分组
        Map<ShardId, List<SearchHitId>> shardGroups = hitsToFetch.stream()
            .collect(Collectors.groupingBy(SearchHitId::getShardId));

        // 3. 并发从各分片获取完整文档
        List<CompletableFuture<List<SearchHit>>> futures = new ArrayList<>();
        for (Map.Entry<ShardId, List<SearchHitId>> entry : 
             shardGroups.entrySet()) {
            CompletableFuture<List<SearchHit>> future = 
                fetchFromShard(entry.getKey(), entry.getValue(), request);
            futures.add(future);
        }

        // 4. 合并结果
        List<SearchHit> allHits = futures.stream()
            .map(CompletableFuture::join)
            .flatMap(List::stream)
            .collect(Collectors.toList());

        // 5. 按得分排序（保持Query Phase的排序顺序）
        allHits.sort(Comparator.comparingDouble(SearchHit::getScore).reversed());

        // 6. 应用高亮
        if (request.getHighlightConfig() != null) {
            for (SearchHit hit : allHits) {
                applyHighlighting(hit, request);
            }
        }

        // 7. 构建响应
        SearchResponse response = new SearchResponse();
        response.setTotalHits(queryResult.getTotalHits());
        response.setHits(allHits);
        response.setTookMs(System.currentTimeMillis() - queryResult.getStartTime());
        return response;
    }

    /**
     * 搜索结果高亮
     * 利用倒排索引中的Offset信息定位关键词位置
     */
    private void applyHighlighting(SearchHit hit, SearchRequest request) {
        for (String field : request.getHighlightConfig().getFields()) {
            String originalText = hit.getSourceField(field);
            if (originalText == null) continue;
            
            // 利用分析器对查询词和原文进行分词
            List<Token> queryTokens = analyzer.analyze(request.getQueryString());
            
            // 在原文中找到匹配的词并添加高亮标签
            String highlighted = originalText;
            for (Token token : queryTokens) {
                highlighted = highlighted.replaceAll(
                    "(?i)" + Pattern.quote(token.getText()),
                    "<em>" + token.getText() + "</em>"
                );
            }
            
            hit.addHighlightField(field, highlighted);
        }
    }
}
```

### 3.5 向量检索与语义搜索

随着AI技术的发展，基于向量相似度的语义搜索成为搜索引擎的重要能力。与传统的关键词匹配不同，向量检索能够理解查询的语义，找到含义相近但关键词不同的结果。

#### 3.5.1 向量检索原理

```
                ┌────────────────────────────────────────────┐
                │          向量检索 vs 关键词检索               │
                └────────────────────────────────────────────┘

   关键词检索：
   查询: "推荐一款降噪好的耳机"
   结果: 只能匹配包含"降噪"和"耳机"关键词的文档

   向量检索：
   查询: "推荐一款降噪好的耳机"
```

#### 3.5.2 HNSW算法

HNSW（Hierarchical Navigable Small World）是目前最流行的近似最近邻（ANN）搜索算法之一，在检索精度和速度之间取得了良好的平衡。

```
                 ┌─────────────────────────────────────────────┐
                 │      HNSW 多层图结构（跳表思想）                │
                 └─────────────────────────────────────────────┘

   Layer 2 (最稀疏):    A ─────────────────── D
                        │                     │
   Layer 1 (较稀疏):    A ──── B ──── C ──── D ──── E
                        │      │      │      │      │
   Layer 0 (最稠密):    A ─ B ─ C ─ D ─ E ─ F ─ G ─ H ─ I

   搜索过程：
   1. 从最高层的入口点开始
   2. 在当前层中贪心地向离目标最近的节点移动
   3. 当在当前层无法更接近目标时，下降到下一层
   4. 在最底层找到最终结果
```

```java
/**
 * RAG检索增强生成服务
 */
public class RAGService {

    private final EmbeddingModel embeddingModel;
    private final ElasticsearchClient esClient;
    private final LLMClient llmClient;
    
    /** 文档分块大小 */
    private static final int CHUNK_SIZE = 500;
    /** 分块重叠大小 */
    private static final int CHUNK_OVERLAP = 50;

    /**
     * 离线阶段：将文档分块并索引
     */
    public void indexDocument(String docId, String content) {
        // 1. 文档分块
        List<String> chunks = splitIntoChunks(content, CHUNK_SIZE, CHUNK_OVERLAP);
        
        // 2. 批量生成向量
        List<float[]> vectors = embeddingModel.batchEncode(chunks);
        
        // 3. 索引到ES
        List<Map<String, Object>> bulkDocs = new ArrayList<>();
        for (int i = 0; i < chunks.size(); i++) {
            Map<String, Object> doc = new LinkedHashMap<>();
            doc.put("doc_id", docId);
            doc.put("chunk_index", i);
            doc.put("content", chunks.get(i));
            doc.put("content_vector", vectors.get(i));
            doc.put("indexed_at", System.currentTimeMillis());
            bulkDocs.add(doc);
        }
        
        esClient.bulkIndex("knowledge_base", bulkDocs);
    }

    /**
     * 在线阶段：检索 + 生成
     */
    public String queryWithRAG(String userQuestion) {
        // 1. 将用户问题转为向量
        float[] questionVector = embeddingModel.encode(userQuestion);
        
        // 2. 向量检索：找到最相关的知识片段
        List<SearchHit> hits = esClient.knnSearch(
            "knowledge_base",
            "content_vector",
            questionVector,
            5  // Top 5
        );
        
        // 3. 构建上下文
        StringBuilder context = new StringBuilder();
        for (SearchHit hit : hits) {
            context.append(hit.getSource().get("content")).append("\n\n");
        }
        
        // 4. 构建Prompt，调用LLM生成答案
        String prompt = String.format(
            "基于以下参考资料回答用户的问题。如果参考资料中没有相关信息，" +
            "请说明你不确定。\n\n" +
            "参考资料：\n%s\n\n" +
            "用户问题：%s\n\n" +
            "回答：",
            context.toString(), userQuestion
        );
        
        return llmClient.generate(prompt);
    }

    /**
     * 文档分块策略：滑动窗口分块
     */
    private List<String> splitIntoChunks(String text, int chunkSize, 
                                          int overlap) {
        List<String> chunks = new ArrayList<>();
        
        // 先按段落分割
        String[] paragraphs = text.split("\n\n");
        
        StringBuilder currentChunk = new StringBuilder();
        for (String paragraph : paragraphs) {
            if (currentChunk.length() + paragraph.length() > chunkSize 
                && currentChunk.length() > 0) {
                // 当前块已满，保存并开始新块
                chunks.add(currentChunk.toString().trim());
                
                // 保留overlap部分作为新块的开头
                String overlapText = getLastNChars(
                    currentChunk.toString(), overlap);
                currentChunk = new StringBuilder(overlapText);
            }
            currentChunk.append(paragraph).append("\n\n");
        }
        
        if (currentChunk.length() > 0) {
            chunks.add(currentChunk.toString().trim());
        }
        
        return chunks;
    }
}
```

```java
/**
 * 分片恢复与再平衡
 */
public class ShardRecoveryManager {

    /**
     * 节点故障时的分片恢复策略
     */
    public void handleNodeFailure(String failedNodeId) {
        // 1. 检查故障节点上的分片
        List<ShardRouting> affectedShards = clusterState
            .getRoutingTable()
            .shardsOnNode(failedNodeId);

        for (ShardRouting shard : affectedShards) {
            if (shard.isPrimary()) {
                // 主分片故障：将副本提升为新的主分片
                ShardRouting replica = findHealthyReplica(shard);
                if (replica != null) {
                    promoteToPrimary(replica);
                    // 在其他节点上创建新的副本
                    allocateNewReplica(shard.getIndex(), shard.getId());
                }
            } else {
                // 副本分片故障：在其他节点上重新创建副本
                allocateNewReplica(shard.getIndex(), shard.getId());
            }
        }
    }

    /**

    public Map<String, Object> getRecoveryThrottleSettings() {
```

```java
                "set_priority", Map.of("priority", 100)
            )
        );
        
        // Warm阶段：降低资源消耗
        Map<String, Object> warm = Map.of(
            "min_age", "7d",
            "actions", Map.of(
                "shrink", Map.of("number_of_shards", 1),
                "forcemerge", Map.of("max_num_segments", 1),
                "set_priority", Map.of("priority", 50),
                "allocate", Map.of(
                    "require", Map.of("data", "warm")
                )
            )
        );
        
        // Cold阶段：归档，可搜索但性能降低
        Map<String, Object> cold = Map.of(
            "min_age", "30d",
            "actions", Map.of(
                "set_priority", Map.of("priority", 0),
                "allocate", Map.of(
                    "require", Map.of("data", "cold")

            )
        );
        
        // Delete阶段：过期删除
        Map<String, Object> delete = Map.of(
            "min_age", "90d",
            "actions", Map.of(
                "delete", Map.of()
            )
        );
        
        policy.put("phases", Map.of(
            "hot", hot, "warm", warm, "cold", cold, "delete", delete
        ));
        
        return policy;
    }
```

## 六、最佳实践与总结

### 6.1 索引设计原则

1. **合理设置分片数**：每个分片控制在10GB~50GB之间，分片数不超过数据节点数的3倍
2. **使用别名（Alias）**：避免直接操作索引名，方便后续的索引重建和平滑迁移
3. **字段类型明确定义**：关闭动态映射，避免自动推断导致类型不正确
4. **区分text和keyword**：需要全文搜索的字段用text，精确匹配/排序/聚合的字段用keyword
5. **合理使用doc_values**：不需要排序和聚合的字段可以关闭doc_values节省空间

### 6.2 集群部署建议

| 角色 | 数量 | 配置建议 |
|------|------|---------|
| Master | 3个专用节点 | 2核4GB，低配即可 |
| Data-Hot | 按数据量计算 | 高配SSD，32GB+内存 |
| Data-Warm | 按归档数据量计算 | 大容量HDD |
| Coordinator | 2~4个 | 16GB+内存 |
| Ingest | 按需 | 中等配置 |

### 6.3 监控关键指标

- **集群级别**：健康状态、未分配分片数、活跃分片数
- **节点级别**：JVM堆使用率（建议<75%）、GC频率和耗时、磁盘使用率
- **索引级别**：索引速率、搜索延迟（TP90/TP99）、Segment数量和大小
- **查询级别**：查询QPS、查询延迟分布、慢查询数量

### 6.4 Elasticsearch vs Solr对比

| 对比维度 | Elasticsearch | Solr |
|---------|--------------|------|
| 部署复杂度 | 低，开箱即用 | 较高，需要ZooKeeper |
| 数据格式 | 仅支持JSON | 支持JSON/XML/CSV |
| 实时搜索 | 近实时（~1秒） | 需手动commit |
| 分布式 | 原生支持 | SolrCloud |
| 社区活跃度 | 非常活跃 | 相对较低 |
| 适用场景 | 实时搜索、日志分析 | 传统全文检索 |

### 6.5 总结

搜索引擎的核心设计要点：

1. **倒排索引**：是全文检索的核心数据结构。通过Term Dictionary和Posting List，将"查找包含某个词的文档"这一操作的时间复杂度从O(N)降低到O(1)
2. **分布式架构**：通过分片和副本机制，实现数据的水平扩展和故障容错。Master/Data/Coordinator角色分离确保集群的稳定性
3. **写入链路**：Memory Buffer + Translog的双重保障机制，兼顾了写入性能和数据安全性。Refresh/Flush/Merge三级刷新策略平衡了实时性和IO开销
4. **查询链路**：Query Then Fetch两阶段搜索模式，先在所有分片上进行轻量级的评分查询，再从少量分片获取完整文档，减少了网络传输量
5. **向量检索**：HNSW等ANN算法使得搜索引擎具备了语义理解能力。结合RAG架构，可以构建基于企业知识库的智能问答系统
6. **生态完善**：ELK技术栈覆盖了数据采集、处理、存储、搜索、可视化的全链路，是日志管理和数据分析的标准方案

#### 7.1.4 商品搜索全链路实现

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.slf4j.MDC;

import java.util.*;
import java.util.concurrent.*;

/**
 * 商品搜索服务 - 全链路实现
 * 
 * 完整链路：请求校验 → 幂等检查 → 分词 → 多字段匹配 → 过滤 → 排序 → 高亮 → 分页 → 结果转换
 */
public class ProductSearchService {

    private static final Logger logger = LoggerFactory.getLogger(ProductSearchService.class);

    private final ElasticsearchClient esClient;
    private final IdempotentChecker idempotentChecker;
    private final SearchMetricsCollector metricsCollector;

    /** 幂等缓存过期时间（秒） */
    private static final int IDEMPOTENT_EXPIRE_SECONDS = 30;

    /** 搜索关键词最大长度 */
    private static final int MAX_KEYWORD_LENGTH = 100;

    /** 最大分页大小 */
    private static final int MAX_PAGE_SIZE = 100;

    /** 最大分页深度（防止deep paging攻击） */
    private static final int MAX_FROM = 10000;

    public ProductSearchService(ElasticsearchClient esClient,
                                 IdempotentChecker idempotentChecker,
                                 SearchMetricsCollector metricsCollector) {
        this.esClient = esClient;
        this.idempotentChecker = idempotentChecker;
        this.metricsCollector = metricsCollector;
    }

    /**
     * 商品搜索入口方法
     * 
     * @param request 搜索请求
     * @return 分页搜索结果
     * @throws SearchException 搜索异常
     */
    public PageResult<ProductSearchHit> search(ProductSearchRequest request) throws SearchException {
        long startTime = System.currentTimeMillis();
        String requestId = request.getRequestId() != null 
            ? request.getRequestId() 
            : UUID.randomUUID().toString().replace("-", "");
        MDC.put("requestId", requestId);
        MDC.put("keyword", request.getKeyword());

        try {
            // ========== 步骤1: 请求参数校验 ==========
            validateRequest(request);
            logger.info("搜索请求参数校验通过, keyword={}, pageNum={}, pageSize={}", 
                request.getKeyword(), request.getPageNum(), request.getPageSize());

            // ========== 步骤2: 幂等控制 ==========
            // 对于相同requestId的重复请求，直接返回缓存结果
            // 防止用户快速重复提交导致的重复查询
            String idempotentKey = buildIdempotentKey(request);
            PageResult<ProductSearchHit> cachedResult = idempotentChecker.get(idempotentKey);
            if (cachedResult != null) {
                logger.info("命中幂等缓存, 直接返回缓存结果, idempotentKey={}", idempotentKey);
                return cachedResult;
            }

            // ========== 步骤3: 构建搜索DSL ==========
            // 3.1 构建多字段匹配查询（Multi-Match Query）
            Map<String, Object> queryBuilder = buildSearchQuery(request);

            // 3.2 构建过滤条件
            List<Map<String, Object>> filters = buildFilters(request);

            // 3.3 构建排序规则
            List<Map<String, Object>> sorts = buildSort(request);

            // 3.4 构建高亮配置
            Map<String, Object> highlight = buildHighlight();

            // 3.5 计算分页参数
            int from = (request.getPageNum() - 1) * request.getPageSize();
            int size = request.getPageSize();

            // ========== 步骤4: 组装最终DSL ==========
            Map<String, Object> dsl = new LinkedHashMap<>();
            
            // 组合查询和过滤
            if (filters.isEmpty()) {
                dsl.put("query", queryBuilder);
            } else {
                // 使用bool查询组合must（匹配）和filter（过滤）
                Map<String, Object> boolQuery = new LinkedHashMap<>();
                boolQuery.put("must", List.of(queryBuilder));
                boolQuery.put("filter", filters);
                dsl.put("query", Map.of("bool", boolQuery));
            }

            // 排序
            if (!sorts.isEmpty()) {
                dsl.put("sort", sorts);
            }

            // 高亮
            dsl.put("highlight", highlight);

            // 分页
            dsl.put("from", from);
            dsl.put("size", size);

            // 只返回需要的字段
            dsl.put("_source", List.of(
                "productId", "productName", "title", "description", "brand",
                "categoryName", "price", "originalPrice", "salesCount",
                "rating", "reviewCount", "tags", "shopName"
            ));

            // 超时设置：防止慢查询拖垮集群
            dsl.put("timeout", "3s");

            logger.debug("构建搜索DSL: {}", dsl);

            // ========== 步骤5: 执行搜索 ==========
            long searchStart = System.currentTimeMillis();
            Map<String, Object> response;
            try {
                response = esClient.search(ProductIndexMapping.INDEX_ALIAS, dsl);
            } catch (ElasticsearchException e) {
                // ES返回的业务错误（如查询语法错误）
                logger.error("Elasticsearch查询失败, keyword={}, error={}", 
                    request.getKeyword(), e.getMessage(), e);
                metricsCollector.incrementCounter("search.es_error");
                throw new SearchException("搜索服务暂时不可用，请稍后重试", e);
            } catch (Exception e) {
                // 网络异常、连接超时等
                logger.error("搜索请求异常, keyword={}, error={}", 
                    request.getKeyword(), e.getMessage(), e);
                metricsCollector.incrementCounter("search.network_error");
                throw new SearchException("搜索请求超时，请稍后重试", e);
            }

            long searchTook = System.currentTimeMillis() - searchStart;

            // ========== 步骤6: 解析搜索结果 ==========
            PageResult<ProductSearchHit> result = parseSearchResponse(response, request);

            // ========== 步骤7: 记录指标和日志 ==========
            long totalTime = System.currentTimeMillis() - startTime;
            logger.info("搜索完成, keyword={}, total={}, took={}ms, esTook={}ms, pageNum={}, pageSize={}", 
                request.getKeyword(), result.getTotal(), totalTime, searchTook,
                request.getPageNum(), request.getPageSize());

            metricsCollector.recordSearchLatency(totalTime);
            metricsCollector.recordCounter("search.total", 1);

            // ========== 步骤8: 幂等缓存写入 ==========
            idempotentChecker.put(idempotentKey, result, IDEMPOTENT_EXPIRE_SECONDS);

            return result;

        } catch (SearchException e) {
            throw e;
        } catch (Exception e) {
            logger.error("搜索过程中发生未预期异常, keyword={}, error={}", 
                request.getKeyword(), e.getMessage(), e);
            throw new SearchException("搜索服务内部错误", e);
        } finally {
            MDC.remove("requestId");
            MDC.remove("keyword");
        }
    }

    /**
     * 步骤1: 请求参数校验
     */
    private void validateRequest(ProductSearchRequest request) throws SearchException {
        // 关键词校验
        if (request.getKeyword() == null || request.getKeyword().trim().isEmpty()) {
            throw new SearchException("搜索关键词不能为空");
        }
        String trimmedKeyword = request.getKeyword().trim();
        if (trimmedKeyword.length() > MAX_KEYWORD_LENGTH) {
            throw new SearchException("搜索关键词过长，最大" + MAX_KEYWORD_LENGTH + "个字符");
        }
        request.setKeyword(trimmedKeyword);

        // 分页参数校验
        if (request.getPageNum() == null || request.getPageNum() < 1) {
            request.setPageNum(1);
        }
        if (request.getPageSize() == null || request.getPageSize() < 1) {
            request.setPageSize(20);
        }
        if (request.getPageSize() > MAX_PAGE_SIZE) {
            throw new SearchException("每页大小不能超过" + MAX_PAGE_SIZE);
        }

        // 分页深度校验（防止deep paging）
        int from = (request.getPageNum() - 1) * request.getPageSize();
        if (from >= MAX_FROM) {
            throw new SearchException("分页深度过大，请使用更精确的搜索条件缩小范围");
        }

        // 价格范围校验
        if (request.getMinPrice() != null && request.getMaxPrice() != null) {
            if (request.getMinPrice().compareTo(request.getMaxPrice()) > 0) {
                throw new SearchException("最低价格不能大于最高价格");
            }
        }

        // 排序字段白名单校验
        Set<String> allowedSortFields = Set.of("_score", "price", "salesCount", "rating", "createTime");
        if (!allowedSortFields.contains(request.getSortField())) {
            throw new SearchException("不支持的排序字段: " + request.getSortField());
        }
    }

    /**
     * 步骤3.1: 构建多字段匹配查询
     * 
     * 使用multi_match的cross_fields模式，将查询词视为多个字段的统一匹配
     * 不同字段设置不同的权重，商品名称权重最高
     */
    private Map<String, Object> buildSearchQuery(ProductSearchRequest request) {
        return Map.of(
            "multi_match", Map.of(
                "query", request.getKeyword(),
                "type", "cross_fields",                    // 跨字段匹配模式
                "fields", List.of(
                    "productName^3",                       // 商品名称权重x3
                    "title^2",                             // 标题权重x2
                    "description^1",                       // 描述权重x1
                    "categoryName^2",                      // 分类名称权重x2
                    "brand^2",                             // 品牌权重x2
                    "shopName^1"                           // 店铺名称权重x1
                ),
                "minimum_should_match", "75%",             // 75%的查询词需要匹配
                "tie_breaker", 0.3                         // 最佳字段得分与其他字段得分的混合系数
            )
        );
    }

    /**
     * 步骤3.2: 构建过滤条件
     * 
     * Filter不参与相关性评分，性能优于must查询
     * ES会自动缓存filter结果
     */
    private List<Map<String, Object>> buildFilters(ProductSearchRequest request) {
        List<Map<String, Object>> filters = new ArrayList<>();

        // 商品状态过滤（默认只搜上架商品）
        if (request.getStatus() != null) {
            filters.add(Map.of("term", Map.of("status", request.getStatus())));
        }

        // 分类过滤
        if (request.getCategoryId() != null && !request.getCategoryId().isEmpty()) {
            filters.add(Map.of("term", Map.of("categoryId", request.getCategoryId())));
        }

        // 品牌过滤（多选，OR关系）
        if (request.getBrands() != null && !request.getBrands().isEmpty()) {
            filters.add(Map.of("terms", Map.of("brand", request.getBrands())));
        }

        // 标签过滤（多选，OR关系）
        if (request.getTags() != null && !request.getTags().isEmpty()) {
            filters.add(Map.of("terms", Map.of("tags", request.getTags())));
        }

        // 价格范围过滤
        if (request.getMinPrice() != null || request.getMaxPrice() != null) {
            Map<String, Object> range = new LinkedHashMap<>();
            if (request.getMinPrice() != null) {
                range.put("gte", request.getMinPrice().doubleValue());
            }
            if (request.getMaxPrice() != null) {
                range.put("lte", request.getMaxPrice().doubleValue());
            }
            filters.add(Map.of("range", Map.of("price", range)));
        }

        // 评分过滤
        if (request.getMinRating() != null) {
            filters.add(Map.of("range", Map.of("rating", Map.of("gte", request.getMinRating()))));
        }

        return filters;
    }

    /**
     * 步骤3.3: 构建排序规则
     */
    private List<Map<String, Object>> buildSort(ProductSearchRequest request) {
        List<Map<String, Object>> sorts = new ArrayList<>();

        String sortField = request.getSortField();
        String sortOrder = "desc".equalsIgnoreCase(request.getSortOrder()) ? "desc" : "asc";

        if ("_score".equals(sortField)) {
            // 默认按相关性评分排序
            sorts.add(Map.of("_score", Map.of("order", "desc")));
            // 评分相同时，按销量降序作为tie-breaker
            sorts.add(Map.of("salesCount", Map.of("order", "desc")));
        } else {
            // 自定义排序时，先按指定字段排序
            sorts.add(Map.of(sortField, Map.of("order", sortOrder)));
            // 再按相关性评分降序作为tie-breaker
            sorts.add(Map.of("_score", Map.of("order", "desc")));
        }

        return sorts;
    }

    /**
     * 步骤3.4: 构建高亮配置
     */
    private Map<String, Object> buildHighlight() {
        return Map.of(
            "pre_tags", List.of("<em class=\"highlight\">"),
            "post_tags", List.of("</em>"),
            "fields", Map.of(
                "productName", Map.of(
                    "fragment_size", 150,
                    "number_of_fragments", 1
                ),
                "title", Map.of(
                    "fragment_size", 100,
                    "number_of_fragments", 1
                ),
                "description", Map.of(
                    "fragment_size", 200,
                    "number_of_fragments", 2
                )
            ),
            "require_field_match", false               // 不要求字段必须匹配才高亮
        );
    }

    /**
     * 步骤6: 解析搜索响应
     */
    @SuppressWarnings("unchecked")
    private PageResult<ProductSearchHit> parseSearchResponse(Map<String, Object> response,
                                                               ProductSearchRequest request) {
        // 解析hits
        Map<String, Object> hitsWrapper = (Map<String, Object>) response.get("hits");
        Map<String, Object> totalWrapper = (Map<String, Object>) hitsWrapper.get("total");
        long total = ((Number) totalWrapper.get("value")).longValue();
        List<Map<String, Object>> hits = (List<Map<String, Object>>) hitsWrapper.get("hits");

        // 转换为DTO
        List<ProductSearchHit> resultList = new ArrayList<>(hits.size());
        for (Map<String, Object> hit : hits) {
            ProductSearchHit productHit = new ProductSearchHit();

            // 相关性得分
            Object score = hit.get("_score");
            if (score != null) {
                productHit.setScore(((Number) score).floatValue());
            }

            // 文档源数据
            Map<String, Object> source = (Map<String, Object>) hit.get("_source");
            productHit.setProductId((String) source.get("productId"));
            productHit.setProductName((String) source.get("productName"));
            productHit.setTitle((String) source.get("title"));
            productHit.setDescription((String) source.get("description"));
            productHit.setBrand((String) source.get("brand"));
            productHit.setCategoryName((String) source.get("categoryName"));

            Object price = source.get("price");
            if (price != null) {
                productHit.setPrice(new BigDecimal(price.toString()));
            }
            Object originalPrice = source.get("originalPrice");
            if (originalPrice != null) {
                productHit.setOriginalPrice(new BigDecimal(originalPrice.toString()));
            }
            Object salesCount = source.get("salesCount");
            if (salesCount != null) {
                productHit.setSalesCount(((Number) salesCount).intValue());
            }
            Object rating = source.get("rating");
            if (rating != null) {
                productHit.setRating(((Number) rating).floatValue());
            }
            Object reviewCount = source.get("reviewCount");
            if (reviewCount != null) {
                productHit.setReviewCount(((Number) reviewCount).intValue());
            }
            Object tags = source.get("tags");
            if (tags != null) {
                productHit.setTags((List<String>) tags);
            }
            productHit.setShopName((String) source.get("shopName"));

            // 高亮字段
            Object highlight = hit.get("highlight");
            if (highlight != null) {
                productHit.setHighlightFields((Map<String, List<String>>) highlight);
            }

            resultList.add(productHit);
        }

        long tookMs = ((Number) response.getOrDefault("took", 0)).longValue();
        return PageResult.of(resultList, total, request.getPageNum(), request.getPageSize(), tookMs);
    }

    /**
     * 构建幂等Key
     * 基于请求参数生成唯一标识，相同参数的重复请求返回缓存结果
     */
    private String buildIdempotentKey(ProductSearchRequest request) {
        return String.format("product_search:%s:%s:%s:%s:%s:%s:%s:%s:%d:%d",
            request.getKeyword(),
            request.getCategoryId() != null ? request.getCategoryId() : "",
            request.getBrands() != null ? String.join(",", request.getBrands()) : "",
            request.getTags() != null ? String.join(",", request.getTags()) : "",
            request.getMinPrice() != null ? request.getMinPrice() : "",
            request.getMaxPrice() != null ? request.getMaxPrice() : "",
            request.getSortField(),
            request.getStatus() != null ? request.getStatus() : "",
            request.getPageNum(),
            request.getPageSize()
        );
    }
}
```

#### 7.1.5 幂等控制器实现

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;

/**
 * 幂等控制器
 * 
 * 基于本地缓存实现请求幂等，相同参数的重复请求直接返回缓存结果
 * 对于大规模部署，可替换为Redis实现
 */
public class IdempotentChecker {

    private static final Logger logger = LoggerFactory.getLogger(IdempotentChecker.class);

    private final ConcurrentHashMap<String, CacheEntry> cache = new ConcurrentHashMap<>();
    private final ScheduledExecutorService cleaner = Executors.newSingleThreadScheduledExecutor(r -> {
        Thread t = new Thread(r, "idempotent-cleaner");
        t.setDaemon(true);
        return t;
    });

    public IdempotentChecker() {
        // 每10秒清理一次过期缓存
        cleaner.scheduleAtFixedRate(this::cleanExpired, 10, 10, TimeUnit.SECONDS);
    }

    /**
     * 获取缓存结果
     */
    @SuppressWarnings("unchecked")
    public <T> T get(String key) {
        CacheEntry entry = cache.get(key);
        if (entry == null) {
            return null;
        }
        if (System.currentTimeMillis() > entry.expireTime) {
            cache.remove(key);
            logger.debug("幂等缓存已过期, key={}", key);
            return null;
        }
        return (T) entry.value;
    }

    /**
     * 写入缓存
     */
    public <T> void put(String key, T value, int expireSeconds) {
        long expireTime = System.currentTimeMillis() + expireSeconds * 1000L;
        cache.put(key, new CacheEntry(value, expireTime));
        logger.debug("写入幂等缓存, key={}, expireSeconds={}", key, expireSeconds);
    }

    /**
     * 清理过期缓存
     */
    private void cleanExpired() {
        long now = System.currentTimeMillis();
        int before = cache.size();
        cache.entrySet().removeIf(entry -> now > entry.getValue().expireTime);
        int removed = before - cache.size();
        if (removed > 0) {
            logger.debug("清理过期幂等缓存, removed={}, remaining={}", removed, cache.size());
        }
    }

    /**
     * 关闭清理线程
     */
    public void shutdown() {
        cleaner.shutdown();
        logger.info("幂等控制器已关闭");
    }

    private static class CacheEntry {
        final Object value;
        final long expireTime;

        CacheEntry(Object value, long expireTime) {
            this.value = value;
            this.expireTime = expireTime;
        }
    }
}
```

#### 7.2.2 全量索引重建服务

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.slf4j.MDC;

import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicLong;

/**
 * 全量索引重建服务
 * 
 * 全量重建流程：
 * 1. 创建新索引（带版本号）
 * 2. 分批从数据库读取全量数据
 * 3. 批量写入新索引
 * 4. 等待索引刷新
 * 5. 切换别名指向新索引
 * 6. 删除旧索引
 */
public class FullIndexRebuildService {

    private static final Logger logger = LoggerFactory.getLogger(FullIndexRebuildService.class);

    private final ElasticsearchClient esClient;
    private final ProductRepository productRepository;
    private final IndexConsistencyChecker consistencyChecker;

    /** 全量重建批次大小 */
    private static final int BATCH_SIZE = 2000;

    /** 全量重建并发度 */
    private static final int CONCURRENCY = 4;

    /** 索引别名 */
    private static final String INDEX_ALIAS = "products_alias";

    /** 全量重建任务幂等锁 */
    private final ConcurrentHashMap<String, Boolean> rebuildLocks = new ConcurrentHashMap<>();

    public FullIndexRebuildService(ElasticsearchClient esClient,
                                    ProductRepository productRepository,
                                    IndexConsistencyChecker consistencyChecker) {
        this.esClient = esClient;
        this.productRepository = productRepository;
        this.consistencyChecker = consistencyChecker;
    }

    /**
     * 执行全量索引重建
     * 
     * @param taskId 任务ID（用于幂等控制）
     * @throws IndexRebuildException 重建异常
     */
    public void rebuildFullIndex(String taskId) throws IndexRebuildException {
        MDC.put("taskId", taskId);
        long startTime = System.currentTimeMillis();

        try {
            // ========== 步骤1: 幂等检查 ==========
            // 同一时间只允许一个全量重建任务执行
            if (rebuildLocks.putIfAbsent(taskId, true) != null) {
                logger.warn("全量重建任务已存在, taskId={}, 跳过重复执行", taskId);
                throw new IndexRebuildException("全量重建任务正在执行中: " + taskId);
            }

            logger.info("========== 全量索引重建开始, taskId={} ==========", taskId);

            // ========== 步骤2: 获取当前别名指向的旧索引 ==========
            String oldIndexName = getCurrentIndexByAlias(INDEX_ALIAS);
            logger.info("当前别名 {} 指向旧索引: {}", INDEX_ALIAS, oldIndexName);

            // ========== 步骤3: 创建新索引 ==========
            // 新索引名称带版本号和时间戳
            String newIndexName = generateNewIndexName();
            createNewIndex(newIndexName);
            logger.info("创建新索引: {}", newIndexName);

            // ========== 步骤4: 分批全量写入 ==========
            AtomicLong totalIndexed = new AtomicLong(0);
            long totalInDb = productRepository.count();
            logger.info("数据库商品总数: {}", totalInDb);

            // 使用线程池并发批量写入
            ExecutorService executor = Executors.newFixedThreadPool(CONCURRENCY, r -> {
                Thread t = new Thread(r, "index-rebuild-worker");
                t.setDaemon(true);
                return t;
            });

            List<CompletableFuture<Void>> futures = new ArrayList<>();
            int totalPages = (int) Math.ceil((double) totalInDb / BATCH_SIZE);

            for (int pageNum = 1; pageNum <= totalPages; pageNum++) {
                final int currentPage = pageNum;
                CompletableFuture<Void> future = CompletableFuture.runAsync(() -> {
                    try {
                        int indexed = batchIndex(currentPage, newIndexName);
                        long total = totalIndexed.addAndGet(indexed);
                        logger.info("批次写入完成, page={}/{}, batchCount={}, totalCount={}/{}",
                            currentPage, totalPages, indexed, total, totalInDb);
                    } catch (Exception e) {
                        logger.error("批次写入失败, page={}, error={}", currentPage, e.getMessage(), e);
                        throw new CompletionException("批次写入失败: page=" + currentPage, e);
                    }
                }, executor);
                futures.add(future);
            }

            // 等待所有批次完成
            try {
                CompletableFuture.allOf(futures.toArray(new CompletableFuture[0]))
                    .get(2, TimeUnit.HOURS);
            } catch (TimeoutException e) {
                logger.error("全量重建超时, taskId={}", taskId);
                throw new IndexRebuildException("全量重建超时", e);
            } catch (ExecutionException e) {
                logger.error("全量重建失败, taskId={}, error={}", taskId, e.getCause().getMessage(), e);
                // 清理失败的新索引
                cleanupFailedIndex(newIndexName);
                throw new IndexRebuildException("全量重建失败", e.getCause());
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                throw new IndexRebuildException("全量重建被中断", e);
            } finally {
                executor.shutdown();
            }

            logger.info("全量写入完成, 总索引文档数: {}", totalIndexed.get());

            // ========== 步骤5: 手动Refresh，确保数据可搜索 ==========
            try {
                esClient.refresh(newIndexName);
                logger.info("新索引刷新完成: {}", newIndexName);
            } catch (Exception e) {
                logger.warn("索引刷新异常, 继续后续流程: {}", e.getMessage());
            }

            // ========== 步骤6: 一致性校验 ==========
            boolean consistent = consistencyChecker.checkCount(newIndexName, totalInDb);
            if (!consistent) {
                logger.error("一致性校验失败, 新索引文档数与数据库不一致, newIndex={}, dbCount={}",
                    newIndexName, totalInDb);
                cleanupFailedIndex(newIndexName);
                throw new IndexRebuildException("一致性校验失败: 索引文档数与数据库不一致");
            }
            logger.info("一致性校验通过, 文档数量一致");

            // ========== 步骤7: 无缝切换别名 ==========
            switchAlias(INDEX_ALIAS, oldIndexName, newIndexName);
            logger.info("别名切换完成: {} -> {}", INDEX_ALIAS, newIndexName);

            // ========== 步骤8: 删除旧索引 ==========
            if (oldIndexName != null) {
                try {
                    esClient.deleteIndex(oldIndexName);
                    logger.info("删除旧索引: {}", oldIndexName);
                } catch (Exception e) {
                    // 删除旧索引失败不影响服务，记录日志后续处理
                    logger.warn("删除旧索引失败, 旧索引={}, error={}", oldIndexName, e.getMessage(), e);
                }
            }

            long totalTime = System.currentTimeMillis() - startTime;
            logger.info("========== 全量索引重建完成, taskId={}, 耗时={}ms ==========", 
                taskId, totalTime);

        } finally {
            rebuildLocks.remove(taskId);
            MDC.remove("taskId");
        }
    }

    /**
     * 批量索引写入
     */
    private int batchIndex(int pageNum, String indexName) {
        // 从数据库分页读取
        List<ProductDO> products = productRepository.findPage(pageNum, BATCH_SIZE);
        if (products.isEmpty()) {
            return 0;
        }

        // 转换为ES文档
        List<Map<String, Object>> docs = new ArrayList<>(products.size());
        for (ProductDO product : products) {
            Map<String, Object> doc = new LinkedHashMap<>();
            doc.put("productId", product.getId());
            doc.put("productName", product.getName());
            doc.put("title", product.getTitle());
            doc.put("description", product.getDescription());
            doc.put("brand", product.getBrand());
            doc.put("categoryId", product.getCategoryId());
            doc.put("categoryName", product.getCategoryName());
            doc.put("price", product.getPrice());
            doc.put("originalPrice", product.getOriginalPrice());
            doc.put("salesCount", product.getSalesCount());
            doc.put("rating", product.getRating());
            doc.put("reviewCount", product.getReviewCount());
            doc.put("status", product.getStatus());
            doc.put("tags", product.getTags());
            doc.put("shopId", product.getShopId());
            doc.put("shopName", product.getShopName());
            doc.put("createTime", product.getCreateTime());
            doc.put("updateTime", product.getUpdateTime());
            docs.add(doc);
        }

        // 批量写入ES（使用Bulk API）
        try {
            esClient.bulkIndex(indexName, docs, "productId");
            return products.size();
        } catch (Exception e) {
            logger.error("批量写入ES失败, indexName={}, pageNum={}, error={}", 
                indexName, pageNum, e.getMessage(), e);
            throw new RuntimeException("批量写入ES失败", e);
        }

    /**
     * 生成新索引名称
     * 格式：products_v2_20240101_120000
     */
    private String generateNewIndexName() {
        Calendar cal = Calendar.getInstance();
        String timestamp = String.format("%04d%02d%02d_%02d%02d%02d",
            cal.get(Calendar.YEAR), cal.get(Calendar.MONTH) + 1,
            cal.get(Calendar.DAY_OF_MONTH), cal.get(Calendar.HOUR_OF_DAY),
            cal.get(Calendar.MINUTE), cal.get(Calendar.SECOND));
        return "products_v2_" + timestamp;
    }

    /**
     * 创建新索引
     */
    private void createNewIndex(String indexName) {
        Map<String, Object> settings = ProductIndexMapping.buildSettings(5, 1);
        Map<String, Object> mapping = ProductIndexMapping.buildMapping();
        esClient.createIndex(indexName, settings, mapping);

    /**
     * 获取别名当前指向的索引
     */
    private String getCurrentIndexByAlias(String alias) {
        try {
            return esClient.getAliasTargetIndex(alias);
        } catch (Exception e) {
            logger.warn("获取别名指向索引失败, alias={}, 可能是首次创建", alias);
            return null;
        }
    }

    /**
     * 无缝切换别名
     * 
     * 使用ES的Alias Action原子操作：
     * - remove_alias: 移除旧索引的别名
     * - add_alias: 将别名指向新索引
     * 这两个操作在一个请求中原子执行，确保切换瞬间无搜索请求丢失
     */
    private void switchAlias(String alias, String oldIndex, String newIndex) {
        List<Map<String, Object>> actions = new ArrayList<>();

        if (oldIndex != null) {
            actions.add(Map.of("remove", Map.of("index", oldIndex, "alias", alias)));
        }
        actions.add(Map.of("add", Map.of("index", newIndex, "alias", alias)));

        try {
            esClient.updateAliases(actions);
            logger.info("别名原子切换完成, actions={}", actions);
        } catch (Exception e) {
            logger.error("别名切换失败, alias={}, oldIndex={}, newIndex={}, error={}", 
                alias, oldIndex, newIndex, e.getMessage(), e);
            throw new IndexRebuildException("别名切换失败", e);
        }
    }

    /**
     * 清理失败的索引
     */
    private void cleanupFailedIndex(String indexName) {
        try {
            esClient.deleteIndex(indexName);
            logger.info("清理失败索引: {}", indexName);
        } catch (Exception e) {
            logger.warn("清理失败索引异常, indexName={}, error={}", indexName, e.getMessage());
        }
    }
}
```

#### 7.2.3 增量索引更新服务

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.slf4j.MDC;

import java.util.*;
import java.util.concurrent.*;

/**
 * 增量索引更新服务
 * 
 * 通过消费MySQL Binlog变更消息，实时更新ES索引
 * 支持商品创建、更新、删除三种操作
 * 
 * 幂等控制：基于数据库 updateTime 版本号实现乐观并发控制
 */
public class IncrementalIndexService {

    private static final Logger logger = LoggerFactory.getLogger(IncrementalIndexService.class);

    private final ElasticsearchClient esClient;
    private final ProductRepository productRepository;
    private final RetryExecutor retryExecutor;

    /** 增量更新重试次数 */
    private static final int MAX_RETRY = 3;

    /** 重试间隔（毫秒） */
    private static final long RETRY_INTERVAL_MS = 1000;

    /** 增量更新索引别名 */
    private static final String INDEX_ALIAS = "products_alias";

    /** 幂等去重缓存（已处理的消息ID） */
    private final ConcurrentHashMap<String, Long> processedMessages = new ConcurrentHashMap<>();

    public IncrementalIndexService(ElasticsearchClient esClient,
                                    ProductRepository productRepository,
                                    RetryExecutor retryExecutor) {
        this.esClient = esClient;
        this.productRepository = productRepository;
        this.retryExecutor = retryExecutor;
    }

    /**
     * 处理增量变更消息
     * 
     * @param message CDC变更消息
     * @throws IncrementalIndexException 处理异常
     */
    public void handleChange(ChangeDataEvent message) throws IncrementalIndexException {
        String messageId = message.getMessageId();
        MDC.put("messageId", messageId);
        MDC.put("operation", message.getOperation());

        try {
            // ========== 步骤1: 幂等检查 ==========
            // 检查消息是否已处理过，防止重复消费
            Long previousTime = processedMessages.get(messageId);
            if (previousTime != null) {
                logger.info("消息已处理过, 跳重复处理, messageId={}, previousTime={}", 
                    messageId, previousTime);
                return;
            }

            logger.info("处理增量变更, messageId={}, operation={}, table={}, productId={}", 
                messageId, message.getOperation(), message.getTable(), 
                message.getRecordId());

            // ========== 步骤2: 根据操作类型分发处理 ==========
            String operation = message.getOperation();
            try {
                switch (operation) {
                    case "INSERT":
                    case "UPDATE":
                        handleUpsert(message);
                        break;
                    case "DELETE":
                        handleDelete(message);
                        break;
                    default:
                        logger.warn("未知的操作类型, operation={}", operation);
                        return;
                }
            } catch (Exception e) {
                logger.error("增量处理失败, messageId={}, operation={}, error={}", 
                    messageId, operation, e.getMessage(), e);
                throw new IncrementalIndexException("增量处理失败: " + e.getMessage(), e);
            }

            // ========== 步骤3: 标记消息已处理 ==========
            processedMessages.put(messageId, System.currentTimeMillis());

            // 清理过期的幂等记录（保留最近1小时）
            cleanProcessedMessages();

        } finally {
            MDC.remove("messageId");
            MDC.remove("operation");
        }
    }

    /**
     * 处理插入/更新操作
     * 使用upsert语义：文档存在则更新，不存在则插入
     * 通过version字段实现乐观并发控制
     */
    private void handleUpsert(ChangeDataEvent message) {
        String productId = message.getRecordId();

        // 从数据库查询最新数据（不直接使用CDC中的数据，确保一致性）
        ProductDO product = productRepository.findById(productId);
        if (product == null) {
            logger.warn("数据库中未找到商品, 可能已被删除, productId={}", productId);
            handleDelete(message);
            return;
        }

        // 构建ES文档
        Map<String, Object> doc = buildEsDocument(product);

        // 构建upsert请求
        // 使用外部版本号（updateTime的时间戳），ES会自动拒绝旧版本的写入
        Map<String, Object> upsertRequest = new LinkedHashMap<>();
        upsertRequest.put("doc", doc);
        upsertRequest.put("doc_as_upsert", true);              // 文档不存在时，使用doc内容作为新文档插入
        upsertRequest.put("version_type", "external");         // 外部版本号模式
        upsertRequest.put("version", product.getUpdateTime().getTime());  // 使用更新时间戳作为版本号

        // 带重试的执行
        retryExecutor.executeWithRetry(
            () -> {
                try {
                    esClient.update(INDEX_ALIAS, productId, upsertRequest);
                    logger.info("增量upsert成功, productId={}, version={}", 
                        productId, product.getUpdateTime().getTime());
                    return true;
                } catch (VersionConflictException e) {
                    // 版本冲突：说明已有更新的数据写入了ES，当前消息是旧数据，跳过即可
                    logger.info("版本冲突, 跳过旧版本更新, productId={}, currentVersion={}, requestVersion={}", 
                        productId, e.getCurrentVersion(), product.getUpdateTime().getTime());
                    return true;  // 不需要重试
                } catch (Exception e) {
                    logger.error("增量upsert失败, productId={}, error={}", 
                        productId, e.getMessage(), e);
                    throw e;
                }
            },
            MAX_RETRY,
            RETRY_INTERVAL_MS,
            "incremental_upsert_" + productId
        );
    }

    /**
     * 处理删除操作
     */
    private void handleDelete(ChangeDataEvent message) {
        String productId = message.getRecordId();

        retryExecutor.executeWithRetry(
            () -> {
                try {
                    esClient.delete(INDEX_ALIAS, productId);
                    logger.info("增量删除成功, productId={}", productId);
                    return true;
                } catch (DocumentNotFoundException e) {
                    // 文档不存在，删除操作幂等，不算异常
                    logger.info("文档不存在, 删除操作幂等完成, productId={}", productId);
                    return true;
                } catch (Exception e) {
                    logger.error("增量删除失败, productId={}, error={}", 
                        productId, e.getMessage(), e);
                    throw e;
                }
            },
            MAX_RETRY,
            RETRY_INTERVAL_MS,
            "incremental_delete_" + productId
        );
    }

    /**
     * 构建ES文档
     */
    private Map<String, Object> buildEsDocument(ProductDO product) {
        Map<String, Object> doc = new LinkedHashMap<>();
        doc.put("productId", product.getId());
        doc.put("productName", product.getName());
        doc.put("title", product.getTitle());
        doc.put("description", product.getDescription());
        doc.put("brand", product.getBrand());
        doc.put("categoryId", product.getCategoryId());
        doc.put("categoryName", product.getCategoryName());
        doc.put("price", product.getPrice());
        doc.put("originalPrice", product.getOriginalPrice());
        doc.put("salesCount", product.getSalesCount());
        doc.put("rating", product.getRating());
        doc.put("reviewCount", product.getReviewCount());
        doc.put("status", product.getStatus());
        doc.put("tags", product.getTags());
        doc.put("shopId", product.getShopId());
        doc.put("shopName", product.getShopName());
        doc.put("createTime", product.getCreateTime());
        doc.put("updateTime", product.getUpdateTime());
        return doc;
    }

    /**
     * 清理过期的幂等记录
     */
    private void cleanProcessedMessages() {
        long threshold = System.currentTimeMillis() - 3600_000;  // 1小时前
        int before = processedMessages.size();
        processedMessages.entrySet().removeIf(entry -> entry.getValue() < threshold);
        int removed = before - processedMessages.size();
        if (removed > 0) {
            logger.debug("清理过期幂等记录, removed={}, remaining={}", removed, processedMessages.size());
        }
    }
}
```

#### 7.2.4 索引一致性校验服务

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.*;

/**
 * 索引一致性校验服务
 * 
 * 定期检查ES索引与数据库的数据一致性，发现不一致时自动修复
 * 
 * 校验维度：
 * 1. 文档数量一致性
 * 2. 抽样文档内容一致性
 * 3. 更新时间戳连续性检查
 */
public class IndexConsistencyChecker {

    private static final Logger logger = LoggerFactory.getLogger(IndexConsistencyChecker.class);

    private final ElasticsearchClient esClient;
    private final ProductRepository productRepository;

    /** 抽样比例 */
    private static final double SAMPLE_RATIO = 0.01;  // 1%抽样

    /** 单次校验最大抽样数 */
    private static final int MAX_SAMPLE_SIZE = 1000;

    public IndexConsistencyChecker(ElasticsearchClient esClient,
                                    ProductRepository productRepository) {
        this.esClient = esClient;
        this.productRepository = productRepository;
    }

    /**
     * 检查文档数量一致性
     * 
     * @param indexName ES索引名称
     * @param expectedCount 数据库中的预期文档数量
     * @return true=一致 false=不一致
     */
    public boolean checkCount(String indexName, long expectedCount) {
        try {
            long esCount = esClient.count(indexName);
            boolean consistent = (esCount == expectedCount);
            logger.info("文档数量校验, indexName={}, esCount={}, dbCount={}, consistent={}", 
                indexName, esCount, expectedCount, consistent);
            return consistent;
        } catch (Exception e) {
            logger.error("文档数量校验异常, indexName={}, error={}", 
                indexName, e.getMessage(), e);
            return false;
        }
    }

    /**
     * 执行完整一致性校验
     * 
     * @param indexName ES索引名称
     * @return 校验报告
     */
    public ConsistencyReport fullCheck(String indexName) {
        logger.info("========== 索引一致性校验开始, indexName={} ==========", indexName);
        ConsistencyReport report = new ConsistencyReport();
        report.setIndexName(indexName);
        report.setCheckTime(new Date());

        // 1. 数量校验
        long dbCount = productRepository.count();
        long esCount;
        try {
            esCount = esClient.count(indexName);
        } catch (Exception e) {
            logger.error("获取ES文档数量失败, indexName={}", indexName, e);
            report.setConsistent(false);
            report.setErrorMessage("获取ES文档数量失败: " + e.getMessage());
            return report;
        }
        report.setDbCount(dbCount);
        report.setEsCount(esCount);

        if (esCount != dbCount) {
            logger.warn("文档数量不一致, esCount={}, dbCount={}, diff={}", 
                esCount, dbCount, esCount - dbCount);
            report.setConsistent(false);
            report.addIssue(String.format("文档数量不一致: ES=%d, DB=%d, 差异=%d", 
                esCount, dbCount, esCount - dbCount));
        } else {
            logger.info("文档数量一致: {}", esCount);
        }

        // 2. 抽样内容校验
        int sampleSize = Math.min(MAX_SAMPLE_SIZE, 
            Math.max(1, (int) (dbCount * SAMPLE_RATIO)));
        List<String> sampleIds = productRepository.findRandomIds(sampleSize);
        int mismatchCount = 0;
        int missingCount = 0;

        for (String productId : sampleIds) {
            try {
                // 从DB获取最新数据
                ProductDO dbProduct = productRepository.findById(productId);
                if (dbProduct == null) {
                    continue;
                }

                // 从ES获取索引数据
                Map<String, Object> esDoc = esClient.getDocument(indexName, productId);
                if (esDoc == null) {
                    missingCount++;
                    logger.warn("ES中缺失文档, productId={}", productId);
                    // 自动修复：重新索引
                    repairDocument(indexName, productId);
                    continue;
                }

                // 对比关键字段
                if (!compareFields(dbProduct, esDoc)) {
                    mismatchCount++;
                    logger.warn("文档内容不一致, productId={}", productId);
                    // 自动修复：重新索引
                    repairDocument(indexName, productId);
                }
            } catch (Exception e) {
                logger.error("抽样校验异常, productId={}, error={}", 
                    productId, e.getMessage(), e);
                mismatchCount++;
            }
        }

        report.setSampleSize(sampleSize);
        report.setMismatchCount(mismatchCount);
        report.setMissingCount(missingCount);

        if (mismatchCount > 0 || missingCount > 0) {
            report.setConsistent(false);
            report.addIssue(String.format("抽样校验发现不一致: 内容不匹配=%d, 缺失=%d, 抽样=%d", 
                mismatchCount, missingCount, sampleSize));
        }

        logger.info("========== 索引一致性校验完成, indexName={}, consistent={}, issues={} ==========", 
            indexName, report.isConsistent(), report.getIssues().size());

        return report;
    }

    /**
     * 对比数据库与ES文档的关键字段
     */
    private boolean compareFields(ProductDO dbProduct, Map<String, Object> esDoc) {
        // 对比关键业务字段
        if (!Objects.equals(dbProduct.getName(), esDoc.get("productName"))) {
            logger.debug("字段不一致: productName, db={}, es={}", 
                dbProduct.getName(), esDoc.get("productName"));
            return false;
        }
        if (!Objects.equals(dbProduct.getBrand(), esDoc.get("brand"))) {
            logger.debug("字段不一致: brand, db={}, es={}", 
                dbProduct.getBrand(), esDoc.get("brand"));
            return false;
        }
        Object esPrice = esDoc.get("price");
        if (esPrice != null) {
            double dbPrice = dbProduct.getPrice().doubleValue();
            double indexPrice = ((Number) esPrice).doubleValue();
            if (Math.abs(dbPrice - indexPrice) > 0.01) {
                logger.debug("字段不一致: price, db={}, es={}", dbPrice, indexPrice);
                return false;
            }
        }
        if (!Objects.equals(dbProduct.getStatus(), esDoc.get("status"))) {
            logger.debug("字段不一致: status, db={}, es={}", 
                dbProduct.getStatus(), esDoc.get("status"));
            return false;
        }
        return true;
    }

    /**
     * 修复不一致的文档
     */
    private void repairDocument(String indexName, String productId) {
        try {
            ProductDO product = productRepository.findById(productId);
            if (product != null) {
                Map<String, Object> doc = new LinkedHashMap<>();
                doc.put("productId", product.getId());
                doc.put("productName", product.getName());
                doc.put("title", product.getTitle());
                doc.put("description", product.getDescription());
                doc.put("brand", product.getBrand());
                doc.put("categoryId", product.getCategoryId());
                doc.put("categoryName", product.getCategoryName());
                doc.put("price", product.getPrice());
                doc.put("originalPrice", product.getOriginalPrice());
                doc.put("salesCount", product.getSalesCount());
                doc.put("rating", product.getRating());
                doc.put("reviewCount", product.getReviewCount());
                doc.put("status", product.getStatus());
                doc.put("tags", product.getTags());
                doc.put("shopId", product.getShopId());
                doc.put("shopName", product.getShopName());
                doc.put("createTime", product.getCreateTime());
                doc.put("updateTime", product.getUpdateTime());

                esClient.index(indexName, productId, doc);
                logger.info("文档修复完成, productId={}", productId);
            } else {
                // DB中已删除，从ES中也删除
                esClient.delete(indexName, productId);
                logger.info("文档已从ES删除, productId={}", productId);
            }
        } catch (Exception e) {
            logger.error("文档修复失败, productId={}, error={}", 
                productId, e.getMessage(), e);
        }
    }
}
```

#### 7.2.5 重试执行器

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.concurrent.Callable;
import java.util.concurrent.TimeUnit;

/**
 * 重试执行器
 * 
 * 提供指数退避重试能力，用于增量更新等需要容错的场景
 */
public class RetryExecutor {

    private static final Logger logger = LoggerFactory.getLogger(RetryExecutor.class);

    /**
     * 带重试执行
     * 
     * @param task 要执行的任务
     * @param maxRetries 最大重试次数
     * @param intervalMs 重试间隔（毫秒）
     * @param taskName 任务名称（用于日志）
     */
    public <T> T executeWithRetry(Callable<T> task, int maxRetries, 
                                    long intervalMs, String taskName) {
        Exception lastException = null;

        for (int attempt = 1; attempt <= maxRetries; attempt++) {
            try {
                T result = task.call();
                if (attempt > 1) {
                    logger.info("重试成功, taskName={}, attempt={}/{}", 
                        taskName, attempt, maxRetries);
                }
                return result;
            } catch (Exception e) {
                lastException = e;
                if (attempt < maxRetries) {
                    // 指数退避：每次重试间隔翻倍
                    long delay = intervalMs * (1L << (attempt - 1));
                    logger.warn("执行失败, 将重试, taskName={}, attempt={}/{}, delayMs={}, error={}", 
                        taskName, attempt, maxRetries, delay, e.getMessage());
                    try {
                        TimeUnit.MILLISECONDS.sleep(delay);
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        throw new RuntimeException("重试被中断", ie);
                    }
                } else {
                    logger.error("重试耗尽, taskName={}, attempts={}, lastError={}", 
                        taskName, maxRetries, e.getMessage(), e);
                }
            }
        }

        throw new RuntimeException("重试耗尽: " + taskName, lastException);
    }
}
```

#### 7.3.1 链路架构

```
                    ┌──────────────────────────────────────────────┐
                    │      搜索建议与纠错全链路架构                   │
```

#### 7.3.3 搜索建议服务全链路实现

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.slf4j.MDC;

import java.util.*;
import java.util.concurrent.*;
import java.util.stream.Collectors;

/**
 * 搜索建议服务 - 全链路实现
 * 
 * 完整链路：用户输入 → Suggest补全 → 拼写纠错 → 热搜推荐 → 合并排序
 */
public class SearchSuggestionService {

    private static final Logger logger = LoggerFactory.getLogger(SearchSuggestionService.class);

    private final ElasticsearchClient esClient;
    private final IdempotentChecker idempotentChecker;
    private final SearchMetricsCollector metricsCollector;

    /** 补全建议数量 */
    private static final int COMPLETION_SIZE = 10;

    /** 纠错建议数量 */
    private static final int CORRECTION_SIZE = 3;

    /** 热搜推荐数量 */
    private static final int HOT_SEARCH_SIZE = 5;

    /** 最终返回的建议总数 */
    private static final int MAX_SUGGESTION_SIZE = 15;

    /** 幂等缓存过期时间 */
    private static final int IDEMPOTENT_EXPIRE_SECONDS = 60;

    /** 最大输入长度 */
    private static final int MAX_INPUT_LENGTH = 50;

    public SearchSuggestionService(ElasticsearchClient esClient,
                                    IdempotentChecker idempotentChecker,
                                    SearchMetricsCollector metricsCollector) {
        this.esClient = esClient;
        this.idempotentChecker = idempotentChecker;
        this.metricsCollector = metricsCollector;
    }

    /**
     * 搜索建议入口方法
     * 
     * @param input 用户输入内容
     * @param userId 用户ID（可选，用于个性化）
     * @param category 分类（可选，用于上下文过滤）
     * @param requestId 请求ID（用于幂等控制）
     * @return 搜索建议结果
     * @throws SuggestionException 建议服务异常
     */
    public SuggestionResult suggest(String input, String userId, 
                                     String category, String requestId) throws SuggestionException {
        long startTime = System.currentTimeMillis();
        String rid = requestId != null ? requestId 
            : UUID.randomUUID().toString().replace("-", "");
        MDC.put("requestId", rid);
        MDC.put("input", input);

        try {
            // ========== 步骤1: 输入校验 ==========
            if (input == null || input.trim().isEmpty()) {
                // 输入为空时，直接返回热搜推荐
                logger.info("输入为空, 返回热搜推荐");
                return getHotSearchSuggestions(userId, category);
            }

            String trimmedInput = input.trim();
            if (trimmedInput.length() > MAX_INPUT_LENGTH) {
                throw new SuggestionException("输入内容过长，最大" + MAX_INPUT_LENGTH + "个字符");
            }

            // ========== 步骤2: 幂等检查 ==========
            String idempotentKey = String.format("suggest:%s:%s:%s", trimmedInput, 
                category != null ? category : "", userId != null ? userId : "");
            SuggestionResult cached = idempotentChecker.get(idempotentKey);
            if (cached != null) {
                logger.info("命中幂等缓存, 直接返回, input={}", trimmedInput);
                return cached;
            }

            logger.info("搜索建议请求, input={}, userId={}, category={}", 
                trimmedInput, userId, category);

            // ========== 步骤3: 并行执行三类建议 ==========
            // 3.1 自动补全建议
            // 3.2 拼写纠错建议
            // 3.3 热搜推荐
            // 三类请求并行执行，减少总延迟
            CompletableFuture<List<SuggestionItem>> completionFuture = 
                CompletableFuture.supplyAsync(
                    () -> getCompletionSuggestions(trimmedInput, category));
            
            CompletableFuture<List<SuggestionItem>> correctionFuture = 
                CompletableFuture.supplyAsync(
                    () -> getSpellCorrectionSuggestions(trimmedInput));
            
            CompletableFuture<List<SuggestionItem>> hotSearchFuture = 
                CompletableFuture.supplyAsync(
                    () -> getHotSearchSuggestionsList(userId, category));

            // 等待所有建议完成
            List<SuggestionItem> completions;
            List<SuggestionItem> corrections;
            List<SuggestionItem> hotSearches;

            try {
                completions = completionFuture.get(2, TimeUnit.SECONDS);
            } catch (Exception e) {
                logger.warn("补全建议获取超时或失败, 继续返回其他建议: {}", e.getMessage());
                completions = Collections.emptyList();
            }

            try {
                corrections = correctionFuture.get(2, TimeUnit.SECONDS);
            } catch (Exception e) {
                logger.warn("纠错建议获取超时或失败, 继续返回其他建议: {}", e.getMessage());
                corrections = Collections.emptyList();
            }

            try {
                hotSearches = hotSearchFuture.get(2, TimeUnit.SECONDS);
            } catch (Exception e) {
                logger.warn("热搜建议获取超时或失败, 继续返回其他建议: {}", e.getMessage());
                hotSearches = Collections.emptyList();
            }

            // ========== 步骤4: 合并、去重、排序 ==========
            SuggestionResult result = mergeAndRankSuggestions(
                trimmedInput, completions, corrections, hotSearches);

            // ========== 步骤5: 记录指标和日志 ==========
            long totalTime = System.currentTimeMillis() - startTime;
            logger.info("搜索建议完成, input={}, completions={}, corrections={}, hotSearches={}, total={}, took={}ms", 
                trimmedInput, completions.size(), corrections.size(), 
                hotSearches.size(), result.getAllSuggestions().size(), totalTime);

            metricsCollector.recordCounter("suggestion.total", 1);
            metricsCollector.recordSuggestionLatency(totalTime);

            // ========== 步骤6: 幂等缓存写入 ==========
            idempotentChecker.put(idempotentKey, result, IDEMPOTENT_EXPIRE_SECONDS);

            return result;

        } catch (SuggestionException e) {
            throw e;
        } catch (Exception e) {
            logger.error("搜索建议过程中发生未预期异常, input={}, error={}", 
                input, e.getMessage(), e);
            throw new SuggestionException("搜索建议服务内部错误", e);
        } finally {
            MDC.remove("requestId");
            MDC.remove("input");
        }
    }

    /**
     * 步骤3.1: 自动补全建议
     * 
     * 使用ES的Completion Suggester实现
     * 特点：基于FST数据结构，查询性能极高（亚毫秒级）
     */
    @SuppressWarnings("unchecked")
    private List<SuggestionItem> getCompletionSuggestions(String input, String category) {
        try {
            // 构建completion suggester DSL
            Map<String, Object> suggest = new LinkedHashMap<>();
            
            Map<String, Object> completionOptions = new LinkedHashMap<>();
            completionOptions.put("prefix", input);
            
            Map<String, Object> completionConfig = new LinkedHashMap<>();
            completionConfig.put("field", "suggest_completion");
            completionConfig.put("size", COMPLETION_SIZE);
            completionConfig.put("skip_duplicates", true);          // 跳过重复建议
            completionConfig.put("fuzzy", Map.of(
                "fuzziness", "AUTO",                               // 自动模糊度
                "transpositions", true                             // 允许相邻字符交换
            ));

            // 上下文过滤（按分类）
            if (category != null && !category.isEmpty()) {
                completionConfig.put("contexts", Map.of(
                    "category", List.of(Map.of("context", category))
                ));
            }

            completionOptions.put("completion", completionConfig);
            suggest.put("completion_suggest", completionOptions);

            Map<String, Object> dsl = Map.of("suggest", suggest);

            // 执行查询
            Map<String, Object> response = esClient.search(
                SuggestionIndexMapping.SUGGEST_INDEX, dsl);

            // 解析结果
            List<SuggestionItem> items = new ArrayList<>();
            Map<String, Object> suggestResponse = (Map<String, Object>) response.get("suggest");
            List<Map<String, Object>> suggestionEntries = 
                (List<Map<String, Object>>) suggestResponse.get("completion_suggest");

            for (Map<String, Object> entry : suggestionEntries) {
                List<Map<String, Object>> options = 
                    (List<Map<String, Object>>) entry.get("options");
                for (Map<String, Object> option : options) {
                    SuggestionItem item = new SuggestionItem();
                    item.setText((String) option.get("text"));
                    item.setType(SuggestionType.COMPLETION);
                    item.setScore(option.get("_score") != null 
                        ? ((Number) option.get("_score")).doubleValue() : 0.0);

                    // 提取source中的额外信息
                    Map<String, Object> source = (Map<String, Object>) option.get("_source");
                    if (source != null) {
                        item.setCategory((String) source.get("category"));
                        Object searchCount = source.get("search_count");
                        if (searchCount != null) {
                            item.setSearchCount(((Number) searchCount).longValue());
                        }
                    }
                    items.add(item);
                }
            }

            logger.debug("补全建议结果, input={}, count={}", input, items.size());
            return items;

        } catch (Exception e) {
            logger.error("补全建议查询失败, input={}, error={}", input, e.getMessage(), e);
            return Collections.emptyList();
        }
    }

    /**
     * 步骤3.2: 拼写纠错建议
     * 
     * 使用ES的Term Suggester实现
     * 基于编辑距离算法，从索引中找到与输入词最相似的词
     */
    @SuppressWarnings("unchecked")
    private List<SuggestionItem> getSpellCorrectionSuggestions(String input) {
        try {
            // 构建term suggester DSL
            Map<String, Object> suggest = new LinkedHashMap<>();

            Map<String, Object> termOptions = new LinkedHashMap<>();
            termOptions.put("text", input);

            Map<String, Object> termConfig = new LinkedHashMap<>();
            termConfig.put("field", "suggest_term");
            termConfig.put("size", CORRECTION_SIZE);
            termConfig.put("suggest_mode", "missing");              // 只在原词不在索引中时建议
            termConfig.put("max_edits", 2);                         // 最大编辑距离
            termConfig.put("prefix_length", 1);                     // 前缀必须匹配的长度
            termConfig.put("min_word_length", 2);                   // 最小词长度
            termConfig.put("min_doc_freq", 1);                      // 最小文档频率

            termOptions.put("term", termConfig);
            suggest.put("spell_correction", termOptions);

            Map<String, Object> dsl = Map.of("suggest", suggest);

            // 执行查询
            Map<String, Object> response = esClient.search(
                SuggestionIndexMapping.SUGGEST_INDEX, dsl);

            // 解析结果
            List<SuggestionItem> items = new ArrayList<>();
            Map<String, Object> suggestResponse = (Map<String, Object>) response.get("suggest");
            List<Map<String, Object>> suggestionEntries = 
                (List<Map<String, Object>>) suggestResponse.get("spell_correction");

            for (Map<String, Object> entry : suggestionEntries) {
                List<Map<String, Object>> options = 
                    (List<Map<String, Object>>) entry.get("options");
                String originalTerm = (String) entry.get("text");

                for (Map<String, Object> option : options) {
                    SuggestionItem item = new SuggestionItem();
                    item.setText((String) option.get("text"));
                    item.setType(SuggestionType.SPELL_CORRECTION);
                    item.setOriginalText(originalTerm);
                    item.setScore(option.get("score") != null 
                        ? ((Number) option.get("score")).doubleValue() : 0.0);
                    items.add(item);
                }
            }

            logger.debug("纠错建议结果, input={}, count={}", input, items.size());
            return items;

        } catch (Exception e) {
            logger.error("纠错建议查询失败, input={}, error={}", input, e.getMessage(), e);
            return Collections.emptyList();
        }
    }

    /**
     * 步骤3.3: 热搜推荐
     * 
     * 基于用户搜索历史统计的热门搜索词
     * 使用ES聚合查询实现
     */
    @SuppressWarnings("unchecked")
    private List<SuggestionItem> getHotSearchSuggestionsList(String userId, String category) {
        try {
            // 构建热搜聚合查询DSL
            Map<String, Object> dsl = new LinkedHashMap<>();

            // 查询条件：最近24小时内的搜索记录
            long now = System.currentTimeMillis();
            long oneDayAgo = now - 24 * 3600 * 1000L;

            Map<String, Object> query = new LinkedHashMap<>();
            Map<String, Object> boolQuery = new LinkedHashMap<>();
            List<Map<String, Object>> must = new ArrayList<>();

            must.add(Map.of("range", Map.of("search_time", Map.of("gte", oneDayAgo))));

            if (category != null && !category.isEmpty()) {
                must.add(Map.of("term", Map.of("category", category)));
            }

            boolQuery.put("must", must);
            query.put("bool", boolQuery);
            dsl.put("query", query);

            // 聚合：按keyword分组，统计搜索次数，按搜索次数降序
            dsl.put("size", 0);  // 不返回文档，只返回聚合结果
            dsl.put("aggs", Map.of(
                "hot_keywords", Map.of(
                    "terms", Map.of(
                        "field", "keyword",
                        "size", HOT_SEARCH_SIZE,
                        "order", Map.of("_count", "desc")
                    ),
                    "aggs", Map.of(
                        "latest_time", Map.of(
                            "max", Map.of("field", "search_time")
                        )
                    )
                )
            ));

            // 执行查询
            Map<String, Object> response = esClient.search(
                SuggestionIndexMapping.HOT_SEARCH_INDEX, dsl);

            // 解析聚合结果
            List<SuggestionItem> items = new ArrayList<>();
            Map<String, Object> aggregations = 
                (Map<String, Object>) response.get("aggregations");
            Map<String, Object> hotKeywords = 
                (Map<String, Object>) aggregations.get("hot_keywords");
            List<Map<String, Object>> buckets = 
                (List<Map<String, Object>>) hotKeywords.get("buckets");

            for (Map<String, Object> bucket : buckets) {
                SuggestionItem item = new SuggestionItem();
                item.setText((String) bucket.get("key"));
                item.setType(SuggestionType.HOT_SEARCH);
                item.setSearchCount(((Number) bucket.get("doc_count")).longValue());
                // 热搜得分 = 搜索次数归一化
                item.setScore(item.getSearchCount().doubleValue());
                items.add(item);
            }

            logger.debug("热搜推荐结果, count={}", items.size());
            return items;

        } catch (Exception e) {
            logger.error("热搜推荐查询失败, error={}", e.getMessage(), e);
            return Collections.emptyList();
        }
    }

    /**
     * 步骤4: 合并、去重、排序建议
     * 
     * 合并策略：
     * 1. 纠错建议优先级最高（如果用户拼错了，应优先展示正确结果）
     * 2. 补全建议次之
     * 3. 热搜建议作为补充
     */
    private SuggestionResult mergeAndRankSuggestions(
            String input,
            List<SuggestionItem> completions,
            List<SuggestionItem> corrections,
            List<SuggestionItem> hotSearches) {

        // 去重：相同文本只保留一条（保留优先级高的）
        Set<String> seen = new HashSet<>();
        List<SuggestionItem> allSuggestions = new ArrayList<>();

        // 1. 先加纠错建议
        for (SuggestionItem correction : corrections) {
            String text = correction.getText().toLowerCase();
            if (!seen.contains(text) && !text.equals(input.toLowerCase())) {
                // 纠错建议额外加分
                correction.setScore(correction.getScore() + 1000);
                allSuggestions.add(correction);
                seen.add(text);
            }
        }

        // 2. 再加补全建议
        for (SuggestionItem completion : completions) {
            String text = completion.getText().toLowerCase();
            if (!seen.contains(text)) {
                allSuggestions.add(completion);
                seen.add(text);
            }
        }

        // 3. 最后加热搜建议
        for (SuggestionItem hot : hotSearches) {
            String text = hot.getText().toLowerCase();
            if (!seen.contains(text)) {
                allSuggestions.add(hot);
                seen.add(text);
            }
        }

        // 按分数降序排序
        allSuggestions.sort((a, b) -> Double.compare(b.getScore(), a.getScore()));

        // 截断到最大数量
        if (allSuggestions.size() > MAX_SUGGESTION_SIZE) {
            allSuggestions = allSuggestions.subList(0, MAX_SUGGESTION_SIZE);
        }

        // 构建结果
        SuggestionResult result = new SuggestionResult();
        result.setInput(input);
        result.setCompletions(completions);
        result.setCorrections(corrections);
        result.setHotSearches(hotSearches);
        result.setAllSuggestions(allSuggestions);
        result.setHasCorrection(!corrections.isEmpty());

        return result;
    }

    /**
     * 空输入时返回热搜推荐
     */
    private SuggestionResult getHotSearchSuggestions(String userId, String category) {
        List<SuggestionItem> hotSearches = getHotSearchSuggestionsList(userId, category);
        SuggestionResult result = new SuggestionResult();
        result.setInput("");
        result.setCompletions(Collections.emptyList());
        result.setCorrections(Collections.emptyList());
        result.setHotSearches(hotSearches);
        result.setAllSuggestions(hotSearches);
        result.setHasCorrection(false);
        return result;
    }
}
```

```java
/**

public enum SuggestionType {
    COMPLETION,         // 自动补全
    SPELL_CORRECTION,   // 拼写纠错
    HOT_SEARCH          // 热搜推荐
}

/**
 * 单条建议项
 */
public class SuggestionItem {

    /** 建议文本 */
    private String text;

    /** 建议类型 */
    private SuggestionType type;

    /** 原始文本（仅纠错建议有值） */
    private String originalText;

    /** 得分（越高排名越靠前） */
    private double score;

    /** 搜索次数（热搜建议有值） */
    private Long searchCount;

    /** 分类 */
    private String category;

    // --- Getters and Setters ---
    public String getText() { return text; }
    public void setText(String text) { this.text = text; }
    public SuggestionType getType() { return type; }
    public void setType(SuggestionType type) { this.type = type; }
    public String getOriginalText() { return originalText; }
    public void setOriginalText(String originalText) { this.originalText = originalText; }
    public double getScore() { return score; }
    public void setScore(double score) { this.score = score; }
    public Long getSearchCount() { return searchCount; }
    public void setSearchCount(Long searchCount) { this.searchCount = searchCount; }
    public String getCategory() { return category; }
    public void setCategory(String category) { this.category = category; }
}

/**
 * 搜索建议结果
 */
public class SuggestionResult {

    /** 用户输入 */
    private String input;

    /** 自动补全建议列表 */
    private List<SuggestionItem> completions;

    /** 拼写纠错建议列表 */
    private List<SuggestionItem> corrections;

    /** 热搜推荐列表 */
    private List<SuggestionItem> hotSearches;

    /** 合并后的全部建议（已去重排序） */
    private List<SuggestionItem> allSuggestions;

    /** 是否包含纠错建议 */
    private boolean hasCorrection;
```

#### 7.3.5 建议索引维护服务

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.*;
import java.util.concurrent.*;

/**
 * 建议索引维护服务
 * 
 * 负责维护建议词索引和热搜词索引
 * 
 * 功能：
 * 1. 新增/更新建议词
 * 2. 记录用户搜索行为到热搜索引
 * 3. 定期清理过期的热搜数据
 */
public class SuggestionIndexService {

    private static final Logger logger = LoggerFactory.getLogger(SuggestionIndexService.class);

    private final ElasticsearchClient esClient;

    /** 热搜数据保留天数 */
    private static final int HOT_SEARCH_RETENTION_DAYS = 7;

    /** 建议词更新幂等缓存 */
    private final ConcurrentHashMap<String, Long> recentUpdates = new ConcurrentHashMap<>();

    /** 幂等去重时间窗口（秒） */
    private static final int DEDUP_WINDOW_SECONDS = 60;

    public SuggestionIndexService(ElasticsearchClient esClient) {
        this.esClient = esClient;
    }

    /**
     * 新增或更新建议词
     * 
     * @param word 建议词
     * @param weight 权重
     * @param category 分类
     * @throws SuggestionException 更新异常
     */
    public void upsertSuggestionWord(String word, int weight, String category) 
            throws SuggestionException {
        if (word == null || word.trim().isEmpty()) {
            throw new SuggestionException("建议词不能为空");
        }

        String trimmedWord = word.trim();
        String docId = trimmedWord.hashCode() + "";

        // 幂等检查：短时间内相同词的重复更新直接跳过
        Long lastUpdate = recentUpdates.get(docId);
        if (lastUpdate != null && 
            System.currentTimeMillis() - lastUpdate < DEDUP_WINDOW_SECONDS * 1000L) {
            logger.debug("建议词近期已更新, 跳过, word={}", trimmedWord);
            return;
        }

        try {
            // 构建文档
            Map<String, Object> doc = new LinkedHashMap<>();
            doc.put("suggest_word", trimmedWord);
            doc.put("suggest_completion", Map.of(
                "input", List.of(trimmedWord),
                "weight", weight
            ));
            doc.put("suggest_term", trimmedWord);
            doc.put("weight", weight);
            doc.put("search_count", 0);
            doc.put("category", category != null ? category : "default");
            doc.put("last_search_time", new Date());

            // 使用upsert语义
            Map<String, Object> upsertRequest = new LinkedHashMap<>();
            upsertRequest.put("doc", doc);
            upsertRequest.put("doc_as_upsert", true);

            esClient.update(SuggestionIndexMapping.SUGGEST_INDEX, docId, upsertRequest);

            recentUpdates.put(docId, System.currentTimeMillis());
            logger.info("建议词更新成功, word={}, weight={}, category={}", 
                trimmedWord, weight, category);
        } catch (Exception e) {
            logger.error("建议词更新失败, word={}, error={}", trimmedWord, e.getMessage(), e);
            throw new SuggestionException("建议词更新失败: " + e.getMessage(), e);
        }
    }

    /**
     * 记录用户搜索行为到热搜索引
     * 
     * @param keyword 搜索关键词
     * @param userId 用户ID
     * @param category 分类
     * @throws SuggestionException 记录异常
     */
    public void recordSearchBehavior(String keyword, String userId, String category) 
            throws SuggestionException {
        if (keyword == null || keyword.trim().isEmpty()) {
            return;
        }

        String trimmedKeyword = keyword.trim();
        String docId = UUID.randomUUID().toString().replace("-", "");

        try {
            Map<String, Object> doc = new LinkedHashMap<>();
            doc.put("keyword", trimmedKeyword);
            doc.put("keyword_text", trimmedKeyword);
            doc.put("search_count", 1);
            doc.put("user_id", userId != null ? userId : "anonymous");
            doc.put("search_time", new Date());
            doc.put("category", category != null ? category : "default");

            esClient.index(SuggestionIndexMapping.HOT_SEARCH_INDEX, docId, doc);
            logger.debug("搜索行为记录成功, keyword={}, userId={}", trimmedKeyword, userId);
        } catch (Exception e) {
            // 热搜记录失败不影响主搜索流程，只记录日志
            logger.warn("搜索行为记录失败, keyword={}, error={}", trimmedKeyword, e.getMessage(), e);
        }
    }

    /**
     * 批量更新建议词搜索次数
     * 基于热搜索引聚合，更新建议词索引中的search_count
     */
    public void refreshSuggestionSearchCount() {
        try {
            logger.info("开始刷新建议词搜索次数");

            // 1. 聚合热搜索引，统计每个关键词的搜索次数
            long now = System.currentTimeMillis();
            long oneDayAgo = now - 24 * 3600 * 1000L;

            Map<String, Object> dsl = Map.of(
                "size", 0,
                "query", Map.of(
                    "range", Map.of("search_time", Map.of("gte", oneDayAgo))
                ),
                "aggs", Map.of(
                    "keyword_stats", Map.of(
                        "terms", Map.of(
                            "field", "keyword",
                            "size", 10000,
                            "order", Map.of("_count", "desc")
                        )
                    )
                )
            );

            @SuppressWarnings("unchecked")
            Map<String, Object> response = esClient.search(
                SuggestionIndexMapping.HOT_SEARCH_INDEX, dsl);
            @SuppressWarnings("unchecked")
            Map<String, Object> aggregations = 
                (Map<String, Object>) response.get("aggregations");
            @SuppressWarnings("unchecked")
            Map<String, Object> keywordStats = 
                (Map<String, Object>) aggregations.get("keyword_stats");
            @SuppressWarnings("unchecked")
            List<Map<String, Object>> buckets = 
                (List<Map<String, Object>>) keywordStats.get("buckets");

            // 2. 批量更新建议词索引
            int updated = 0;
            for (Map<String, Object> bucket : buckets) {
                String keyword = (String) bucket.get("key");
                long count = ((Number) bucket.get("doc_count")).longValue();

                String docId = keyword.hashCode() + "";
                try {
                    Map<String, Object> updateDoc = Map.of("search_count", count);
                    Map<String, Object> upsertRequest = Map.of(
                        "doc", updateDoc,
                        "upsert", Map.of(
                            "suggest_word", keyword,
                            "suggest_completion", Map.of("input", List.of(keyword), "weight", 1),
                            "suggest_term", keyword,
                            "weight", 1,
                            "search_count", count,
                            "category", "default",
                            "last_search_time", new Date()
                        )
                    );
                    esClient.update(SuggestionIndexMapping.SUGGEST_INDEX, docId, upsertRequest);
                    updated++;
                } catch (Exception e) {
                    logger.warn("更新建议词搜索次数失败, keyword={}, error={}", 
                        keyword, e.getMessage());
                }
            }

            logger.info("刷新建议词搜索次数完成, updated={}", updated);

        } catch (Exception e) {
            logger.error("刷新建议词搜索次数失败, error={}", e.getMessage(), e);
        }
    }

    /**
     * 清理过期的热搜数据
     */
    public void cleanExpiredHotSearchData() {
        try {
            long threshold = System.currentTimeMillis() 
                - (long) HOT_SEARCH_RETENTION_DAYS * 24 * 3600 * 1000L;

            Map<String, Object> deleteQuery = Map.of(
                "query", Map.of(
                    "range", Map.of("search_time", Map.of("lt", threshold))
                )
            );

            long deleted = esClient.deleteByQuery(
                SuggestionIndexMapping.HOT_SEARCH_INDEX, deleteQuery);
            logger.info("清理过期热搜数据完成, deleted={}, retentionDays={}", 
                deleted, HOT_SEARCH_RETENTION_DAYS);
        } catch (Exception e) {
            logger.error("清理过期热搜数据失败, error={}", e.getMessage(), e);
        }
    }
}
```
