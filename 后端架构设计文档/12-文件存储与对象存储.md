# 文件存储与对象存储架构设计

## 一、问题背景

### 1.1 非结构化数据的爆发式增长

随着互联网业务的快速发展，系统中需要存储和管理的非结构化数据（图片、音视频、文档、日志文件等）呈爆发式增长。一个典型的互联网平台，每天可能产生数十亿张图片、数百TB的视频内容、海量的用户上传文件。传统的文件系统和关系型数据库在面对这种规模的非结构化数据时，已经力不从心。

### 1.2 本地文件存储的痛点

在早期的系统设计中，非结构化数据通常直接存储在应用服务器的本地磁盘上。这种方案虽然简单直接，但随着业务规模的扩大，暴露出了诸多严重问题：

**（1）单点故障风险**

文件存储在单台服务器的本地磁盘上，一旦该服务器出现硬盘损坏、宕机等故障，存储在其上的所有文件都将面临丢失风险。即使通过 RAID 技术提供了一定的冗余保护，也无法应对整机故障或机房级别的灾难。

**（2）容量与吞吐瓶颈**

单台服务器的磁盘容量有限，通常在几十TB级别。当文件数量达到亿级甚至百亿级时，单机存储容量远远不够。同时，单机的磁盘IO带宽和网络带宽也存在上限，无法支撑高并发的文件读写请求。

**（3）复杂的权限管理**

文件存储在本地磁盘后，权限管理依赖于操作系统层面的文件权限机制（如Linux的rwx权限模型）。当需要实现细粒度的访问控制（如按用户、按时间、按IP进行权限管理）时，需要在应用层自行实现复杂的权限校验逻辑。

**（4）小文件的资源浪费**

在Linux文件系统中，每个文件至少占用一个inode。当系统中存在大量小文件（如缩略图、图标等）时，可能出现磁盘空间尚有剩余，但inode已经耗尽的情况。同时，每个文件至少占用一个磁盘块（通常4KB），对于大量远小于4KB的小文件，会造成严重的存储空间浪费。

**（5）多机房部署困难**

当业务需要在多个数据中心部署时，本地文件存储无法自动进行跨机房的数据同步和复制。开发团队需要自行实现文件同步机制，增加了系统的复杂性和运维成本。

### 1.3 对象存储的核心价值

对象存储（Object Storage）是一种专门针对非结构化数据设计的分布式存储系统。与传统的文件存储（基于目录树的层级结构）和块存储（基于固定大小的数据块）不同，对象存储将数据作为"对象"（Object）进行管理，每个对象包含数据本身、元数据和唯一标识符。

对象存储的核心优势包括：

- **海量存储能力**：支持存储数十亿甚至数百亿个文件，总容量可达PB乃至EB级别
- **高可用性**：通过多副本和纠删码技术，确保数据不丢失，可用性达到99.995%以上
- **弹性扩展**：存储容量和吞吐能力可以按需线性扩展，无需停机
- **低成本**：通过存储分级和数据压缩等技术，大幅降低存储成本
- **丰富的数据处理能力**：内置图片处理、视频转码、数据分析等能力

本文将从架构设计的角度，深入剖析对象存储系统的核心技术方案。

## 二、整体架构设计

### 2.1 数据模型

对象存储采用扁平化的数据组织方式，核心数据模型如下：

```
Tenant（租户）
  └── Bucket（存储桶）
        └── Object（对象）
              ├── Key（对象键，唯一标识）
              ├── Data（对象数据，实际文件内容）
              └── Metadata（元数据，自定义属性）
```

**租户（Tenant）**：对应一个独立的账号或业务线，用于实现多租户隔离。每个租户拥有独立的存储配额、访问控制策略和计费体系。

**存储桶（Bucket）**：租户下的逻辑容器，类似于文件系统中的"根目录"。Bucket名称在整个系统中全局唯一，用于组织和管理对象。每个Bucket可以独立配置访问权限、生命周期策略、跨域规则等。

**对象（Object）**：存储的基本单元。每个对象由以下部分组成：

- **Key**：对象的唯一标识符，在Bucket内唯一。Key可以包含"/"字符来模拟目录结构（如`images/2024/photo.jpg`），但底层存储是扁平的
- **Data**：对象的实际内容，大小从0字节到数TB不等
- **Metadata**：对象的描述信息，包括系统元数据（Content-Type、Content-Length、Last-Modified等）和用户自定义元数据（x-custom-header等）

### 2.3 分组架构与爆炸半径控制

为了控制故障的影响范围（爆炸半径），对象存储系统采用分组（Group）架构。每个Group拥有独立的处理单元，包括独立的协议层节点、存储节点和元数据节点。

```
┌─────────────────────────────────────────────────┐
│                  全局路由层                        │
│         （根据租户/Bucket路由到对应Group）           │
└──────┬──────────────┬──────────────┬─────────────┘
       │              │              │
  ┌────▼────┐    ┌────▼────┐    ┌────▼────┐
  │ Group A │    │ Group B │    │ Group C │
  │┌───────┐│    │┌───────┐│    │┌───────┐│
  ││ Proxy ││    ││ Proxy ││    ││ Proxy ││
  │├───────┤│    │├───────┤│    │├───────┤│
  ││ Store ││    ││ Store ││    ││ Store ││
  │├───────┤│    │├───────┤│    │├───────┤│
  ││MetaDB ││    ││MetaDB ││    ││MetaDB ││
  │└───────┘│    │└───────┘│    │└───────┘│
  └─────────┘    └─────────┘    └─────────┘
```

**分组架构的核心优势**：

1. **故障隔离**：某个Group的故障不会影响其他Group中的数据和服务
2. **独立扩展**：可以根据不同Group的负载情况独立进行扩容
3. **灰度发布**：新版本可以先在少数Group中验证，逐步推广
4. **资源隔离**：重要业务可以使用专属Group，避免被其他业务影响

### 2.4 存储核心概念

**分区（Partition）**：数据分布的基本单位。一个分区由3个副本组成，分布在不同的存储节点上。分区是数据路由和负载均衡的最小粒度。

**记录（Record）**：数据读写的基本单位，大小不超过2MB。当一个对象大于2MB时，协议层会将其拆分为多个Record进行存储。每个Record有独立的校验和，用于数据完整性验证。

```java
/**
 * 对象存储核心数据模型
 */
public class StorageObject {
    /** 对象唯一标识 */
    private String objectKey;
    /** 所属存储桶 */
    private String bucketName;
    /** 所属租户ID */
    private String tenantId;
    /** 对象大小（字节） */
    private long contentLength;
    /** 内容类型 */
    private String contentType;
    /** 内容MD5 */
    private String contentMd5;
    /** 最后修改时间 */
    private long lastModified;
    /** 存储类型：STANDARD / INFREQUENT / ARCHIVE */
    private StorageClass storageClass;
    /** 用户自定义元数据 */
    private Map<String, String> userMetadata;
    /** 数据分布信息（内部使用） */
    private List<RecordLocation> recordLocations;
}

/**
 * 记录位置信息
 */
public class RecordLocation {
    /** 记录序号 */
    private int recordIndex;
    /** 所在分区ID */
    private long partitionId;
    /** 记录在分区中的偏移量 */
    private long offset;
    /** 记录大小 */
    private int size;
    /** 校验和 */
    private long checksum;
}

/**
 * 存储类型枚举
 */
public enum StorageClass {
    /** 标准存储 - 三副本，高可用高性能 */
    STANDARD,
    /** 低频存储 - 纠删码，适合不常访问的数据 */
    INFREQUENT_ACCESS,
    /** 归档存储 - 高压缩比，取回需要等待 */
    ARCHIVE
}
```

## 三、核心链路设计

### 3.1 文件上传流程

对象存储支持多种上传方式，适用于不同的业务场景。

#### 3.1.1 简单上传（Simple Upload）

适用于小文件（通常小于100MB）的上传场景。客户端一次性将完整的文件内容发送到对象存储服务。

```
客户端                  路由层              协议层(Proxy)         存储层(Store)        元数据层
  │                     │                    │                    │                   │
  │  PUT Object ────────▶                    │                    │                   │
  │                     │  路由到对应Group ───▶                    │                   │
  │                     │                    │  1.身份认证         │                   │
  │                     │                    │  2.权限校验         │                   │
  │                     │                    │  3.参数校验         │                   │
  │                     │                    │                    │                   │
  │                     │                    │  4.数据拆分为Record │                   │
  │                     │                    │   (每个≤2MB)       │                   │
  │                     │                    │                    │                   │
  │                     │                    │  写入Record ───────▶ 5.写入三副本       │
  │                     │                    │                    │  (跨AZ分布)        │
  │                     │                    │  写入确认 ◀─────────│                   │
  │                     │                    │                    │                   │
  │                     │                    │  写入元数据 ────────────────────────────▶│
  │                     │                    │                    │                   │ 6.记录对象
  │                     │                    │                    │                   │   元数据
  │                     │                    │  元数据确认 ◀────────────────────────────│
  │                     │                    │                    │                   │
  │  200 OK ◀───────────────────────────────│                    │                   │
  │  (含ETag)           │                    │                    │                   │
```

```java
/**
 * 简单上传处理器
 */
public class SimpleUploadHandler {

    private final AuthService authService;
    private final StorageEngine storageEngine;
    private final MetadataService metadataService;
    private final int MAX_RECORD_SIZE = 2 * 1024 * 1024; // 2MB

    /**
     * 处理简单上传请求
     */
    public UploadResult handleSimpleUpload(UploadRequest request) {
        // 1. 身份认证与权限校验
        AuthResult authResult = authService.authenticate(request.getCredentials());
        if (!authResult.isSuccess()) {
            throw new AccessDeniedException("Authentication failed: " + authResult.getMessage());
        }
        authService.checkPermission(authResult.getTenantId(), 
                                     request.getBucketName(), 
                                     "PutObject");

        // 2. 参数校验
        validateRequest(request);

        // 3. 计算数据校验和
        byte[] data = request.getData();
        String md5 = DigestUtils.md5Hex(data);

        // 4. 将数据拆分为Record
        List<byte[]> records = splitIntoRecords(data);

        // 5. 写入存储层
        List<RecordLocation> locations = new ArrayList<>();
        for (int i = 0; i < records.size(); i++) {
            byte[] recordData = records.get(i);
            long checksum = calculateChecksum(recordData);
            
            // 选择目标分区（基于负载均衡策略）
            Partition partition = selectPartition(request.getBucketName());
            
            // 写入三副本
            RecordLocation location = storageEngine.writeRecord(
                partition.getPartitionId(),
                recordData,
                checksum
            );
            location.setRecordIndex(i);
            locations.add(location);
        }

        // 6. 写入元数据
        StorageObject objectMeta = new StorageObject();
        objectMeta.setObjectKey(request.getObjectKey());
        objectMeta.setBucketName(request.getBucketName());
        objectMeta.setTenantId(authResult.getTenantId());
        objectMeta.setContentLength(data.length);
        objectMeta.setContentType(request.getContentType());
        objectMeta.setContentMd5(md5);
        objectMeta.setLastModified(System.currentTimeMillis());
        objectMeta.setStorageClass(request.getStorageClass());
        objectMeta.setUserMetadata(request.getUserMetadata());
        objectMeta.setRecordLocations(locations);

        metadataService.saveObjectMeta(objectMeta);

        // 7. 返回结果
        UploadResult result = new UploadResult();
        result.setETag("\"" + md5 + "\"");
        result.setVersionId(objectMeta.getVersionId());
        return result;
    }

    /**
     * 将数据拆分为不超过2MB的Record
     */
    private List<byte[]> splitIntoRecords(byte[] data) {
        List<byte[]> records = new ArrayList<>();
        int offset = 0;
        while (offset < data.length) {
            int length = Math.min(MAX_RECORD_SIZE, data.length - offset);
            byte[] record = Arrays.copyOfRange(data, offset, offset + length);
            records.add(record);
            offset += length;
        }
        return records;
    }
}
```

#### 3.1.2 分片上传（Multipart Upload）

适用于大文件（通常大于100MB）的上传场景。将一个大文件分成多个分片（Part），各分片可以独立上传、支持并行传输，上传失败的分片可以单独重传，最终合并为一个完整的对象。

分片上传的三个阶段：

```
阶段一：初始化                阶段二：上传分片              阶段三：完成上传
┌────────────────┐          ┌────────────────┐          ┌────────────────┐
│ InitMultipart  │          │ UploadPart     │          │ CompleteUpload │
│                │          │                │          │                │
│ 创建上传任务    │──────────▶│ 并行上传各分片  │──────────▶│ 合并所有分片    │
│ 返回UploadId   │          │ 返回ETag       │          │ 生成最终对象    │
└────────────────┘          └────────────────┘          └────────────────┘
                             可以暂停/恢复
                             失败分片单独重传
```

```java
/**
 * 分片上传管理器
 */
public class MultipartUploadManager {

    private final MetadataService metadataService;
    private final StorageEngine storageEngine;

    /**
     * 阶段一：初始化分片上传
     * 创建一个上传任务，返回uploadId用于后续操作
     */
    public InitiateMultipartUploadResult initiateMultipartUpload(
            String bucketName, String objectKey, Map<String, String> metadata) {
        
        // 生成全局唯一的uploadId
        String uploadId = generateUploadId();
        
        // 创建上传任务记录
        MultipartUploadTask task = new MultipartUploadTask();
        task.setUploadId(uploadId);
        task.setBucketName(bucketName);
        task.setObjectKey(objectKey);
        task.setMetadata(metadata);
        task.setCreateTime(System.currentTimeMillis());
        task.setStatus(UploadStatus.IN_PROGRESS);
        
        // 持久化任务信息
        metadataService.saveMultipartTask(task);
        
        InitiateMultipartUploadResult result = new InitiateMultipartUploadResult();
        result.setUploadId(uploadId);
        result.setBucketName(bucketName);
        result.setObjectKey(objectKey);
        return result;
    }

    /**
     * 阶段二：上传单个分片
     * 每个分片独立上传，分片编号从1开始
     */
    public UploadPartResult uploadPart(String uploadId, int partNumber, 
                                        byte[] partData) {
        // 校验上传任务是否存在且有效
        MultipartUploadTask task = metadataService.getMultipartTask(uploadId);
        if (task == null || task.getStatus() != UploadStatus.IN_PROGRESS) {
            throw new IllegalStateException("Invalid upload task: " + uploadId);
        }

        // 计算分片校验和
        String partMd5 = DigestUtils.md5Hex(partData);
        
        // 将分片数据写入存储层
        List<RecordLocation> locations = writePartData(partData);
        
        // 记录分片信息
        PartInfo partInfo = new PartInfo();
        partInfo.setPartNumber(partNumber);
        partInfo.setSize(partData.length);
        partInfo.setETag(partMd5);
        partInfo.setRecordLocations(locations);
        partInfo.setUploadTime(System.currentTimeMillis());
        
        metadataService.savePartInfo(uploadId, partInfo);
        
        UploadPartResult result = new UploadPartResult();
        result.setPartNumber(partNumber);
        result.setETag("\"" + partMd5 + "\"");
        return result;
    }

    /**
     * 阶段三：完成分片上传
     * 将所有分片合并为一个完整的对象
     */
    public CompleteMultipartUploadResult completeMultipartUpload(
            String uploadId, List<PartETag> partETags) {
        
        MultipartUploadTask task = metadataService.getMultipartTask(uploadId);
        
        // 校验所有分片是否已上传完成
        List<PartInfo> uploadedParts = metadataService.listParts(uploadId);
        validateParts(partETags, uploadedParts);
        
        // 按分片编号排序
        uploadedParts.sort(Comparator.comparingInt(PartInfo::getPartNumber));
        
        // 合并所有分片的Record位置信息
        List<RecordLocation> allLocations = new ArrayList<>();
        long totalSize = 0;
        for (PartInfo part : uploadedParts) {
            allLocations.addAll(part.getRecordLocations());
            totalSize += part.getSize();
        }
        
        // 创建最终对象的元数据
        StorageObject objectMeta = new StorageObject();
        objectMeta.setObjectKey(task.getObjectKey());
        objectMeta.setBucketName(task.getBucketName());
        objectMeta.setContentLength(totalSize);
        objectMeta.setRecordLocations(allLocations);
        objectMeta.setLastModified(System.currentTimeMillis());
        objectMeta.setUserMetadata(task.getMetadata());
        
        // 计算合并后的ETag
        String combinedETag = calculateMultipartETag(partETags);
        objectMeta.setContentMd5(combinedETag);
        
        // 原子性地保存对象元数据并清理上传任务
        metadataService.completeMultipartUpload(objectMeta, uploadId);
        
        CompleteMultipartUploadResult result = new CompleteMultipartUploadResult();
        result.setBucketName(task.getBucketName());
        result.setObjectKey(task.getObjectKey());
        result.setETag("\"" + combinedETag + "\"");
        return result;
    }

    /**
     * 中止分片上传（清理已上传的分片数据）
     */
    public void abortMultipartUpload(String uploadId) {
        MultipartUploadTask task = metadataService.getMultipartTask(uploadId);
        if (task == null) {
            return;
        }
        
        // 清理已上传的分片数据
        List<PartInfo> parts = metadataService.listParts(uploadId);
        for (PartInfo part : parts) {
            for (RecordLocation location : part.getRecordLocations()) {
                storageEngine.deleteRecord(location);
            }
        }
        
        // 删除任务记录
        metadataService.deleteMultipartTask(uploadId);
    }
}
```

#### 3.1.3 表单直传（Form-based Direct Upload）

适用于浏览器端直接上传文件到对象存储的场景，无需经过应用服务器中转。通过预签名的表单策略（PostPolicy），客户端可以直接将文件上传到对象存储，减轻应用服务器的带宽压力。

```
浏览器                   应用服务器                  对象存储服务
  │                       │                          │
  │ 1.请求上传凭证 ────────▶│                          │
  │                       │ 2.生成PostPolicy          │
  │                       │  (含签名、过期时间、        │
  │                       │   文件大小限制等)           │
  │ 3.返回签名策略 ◀────────│                          │
  │                       │                          │
  │ 4.携带策略直传文件 ────────────────────────────────▶│
  │                       │                          │ 5.验证签名
  │                       │                          │ 6.校验策略
  │                       │                          │ 7.存储文件
  │ 8.上传结果 ◀──────────────────────────────────────│
  │                       │                          │
  │ 9.通知应用服务器 ──────▶│                          │
  │ (可选回调)             │ 10.记录文件信息            │
```

```java
/**
 * 预签名URL生成器
 * 用于生成临时授权的上传/下载URL
 */
public class PresignedUrlGenerator {

    private final String accessKeyId;
    private final String secretAccessKey;
    private final String endpoint;

    /**
     * 生成预签名上传URL
     * 客户端可以使用该URL直接上传文件，无需额外认证
     */
    public String generatePresignedPutUrl(String bucketName, String objectKey,
                                           int expireSeconds) {
        long expireTime = System.currentTimeMillis() / 1000 + expireSeconds;
        
        // 构造待签名字符串
        String stringToSign = String.join("\n",
            "PUT",
            "",  // Content-MD5
            "",  // Content-Type
            String.valueOf(expireTime),
            "/" + bucketName + "/" + objectKey
        );
        
        // 使用HMAC-SHA256计算签名
        String signature = HmacUtils.hmacSha256Hex(secretAccessKey, stringToSign);
        
        // 构造预签名URL
        return String.format("%s/%s/%s?AccessKeyId=%s&Expires=%d&Signature=%s",
            endpoint, bucketName, objectKey,
            accessKeyId, expireTime, 
            URLEncoder.encode(signature, StandardCharsets.UTF_8));
    }

    /**
     * 生成PostPolicy（表单上传策略）
     * 用于浏览器端表单直传
     */
    public PostPolicy generatePostPolicy(String bucketName, String keyPrefix,
                                          long maxFileSize, int expireSeconds) {
        long expireTime = System.currentTimeMillis() + expireSeconds * 1000L;
        
        // 构造策略JSON
        Map<String, Object> policy = new LinkedHashMap<>();
        policy.put("expiration", formatIso8601(expireTime));
        
        List<Object> conditions = new ArrayList<>();
        conditions.add(Map.of("bucket", bucketName));
        conditions.add(List.of("starts-with", "$key", keyPrefix));
        conditions.add(List.of("content-length-range", 0, maxFileSize));
        policy.put("conditions", conditions);
        
        String policyJson = JsonUtils.toJson(policy);
        String policyBase64 = Base64.getEncoder().encodeToString(
            policyJson.getBytes(StandardCharsets.UTF_8));
        
        // 签名
        String signature = HmacUtils.hmacSha256Hex(secretAccessKey, policyBase64);
        
        PostPolicy result = new PostPolicy();
        result.setAccessKeyId(accessKeyId);
        result.setPolicy(policyBase64);
        result.setSignature(signature);
        result.setEndpoint(endpoint + "/" + bucketName);
        result.setKeyPrefix(keyPrefix);
        return result;
    }
}
```

#### 3.1.4 断点续传

断点续传是分片上传的一种应用模式。其核心思想是：记录已成功上传的分片信息，在网络中断或程序重启后，只需重传未完成的分片。

```java
/**
 * 断点续传客户端
 */
public class ResumableUploader {

    private final ObjectStorageClient client;
    private final String checkpointDir;

    /**
     * 执行断点续传
     */
    public UploadResult resumableUpload(String bucketName, String objectKey,
                                         File file, long partSize) throws IOException {
        // 1. 尝试恢复上传进度
        UploadCheckpoint checkpoint = loadCheckpoint(bucketName, objectKey, file);
        
        if (checkpoint == null) {
            // 首次上传，初始化分片上传任务
            checkpoint = new UploadCheckpoint();
            checkpoint.setBucketName(bucketName);
            checkpoint.setObjectKey(objectKey);
            checkpoint.setFilePath(file.getAbsolutePath());
            checkpoint.setFileSize(file.length());
            checkpoint.setFileLastModified(file.lastModified());
            checkpoint.setPartSize(partSize);
            
            // 初始化分片上传
            String uploadId = client.initiateMultipartUpload(bucketName, objectKey);
            checkpoint.setUploadId(uploadId);
            
            // 计算分片数量
            int partCount = (int) Math.ceil((double) file.length() / partSize);
            checkpoint.initParts(partCount);
            
            saveCheckpoint(checkpoint);
        } else {
            // 校验文件是否发生变化
            if (file.length() != checkpoint.getFileSize() || 
                file.lastModified() != checkpoint.getFileLastModified()) {
                // 文件已变化，需要重新上传
                client.abortMultipartUpload(checkpoint.getUploadId());
                deleteCheckpoint(bucketName, objectKey);
                return resumableUpload(bucketName, objectKey, file, partSize);
            }
        }

        // 2. 上传未完成的分片
        try (RandomAccessFile raf = new RandomAccessFile(file, "r")) {
            for (int i = 0; i < checkpoint.getPartCount(); i++) {
                if (checkpoint.isPartCompleted(i)) {
                    continue; // 跳过已完成的分片
                }
                
                // 读取分片数据
                long offset = (long) i * partSize;
                int size = (int) Math.min(partSize, file.length() - offset);
                byte[] partData = new byte[size];
                raf.seek(offset);
                raf.readFully(partData);
                
                // 上传分片
                int partNumber = i + 1;
                UploadPartResult partResult = client.uploadPart(
                    checkpoint.getUploadId(), partNumber, partData);
                
                // 更新checkpoint
                checkpoint.setPartCompleted(i, partResult.getETag());
                saveCheckpoint(checkpoint);
            }
        }

        // 3. 完成上传
        List<PartETag> partETags = checkpoint.getCompletedPartETags();
        CompleteMultipartUploadResult result = client.completeMultipartUpload(
            checkpoint.getUploadId(), partETags);
        
        // 清理checkpoint文件
        deleteCheckpoint(bucketName, objectKey);
        
        UploadResult uploadResult = new UploadResult();
        uploadResult.setETag(result.getETag());
        return uploadResult;
    }

    /**
     * 加载上传检查点
     */
    private UploadCheckpoint loadCheckpoint(String bucketName, String objectKey, 
                                             File file) {
        String checkpointPath = getCheckpointPath(bucketName, objectKey);
        File cpFile = new File(checkpointPath);
        if (!cpFile.exists()) {
            return null;
        }
        try {
            return JsonUtils.fromJson(
                Files.readString(cpFile.toPath()), UploadCheckpoint.class);
        } catch (Exception e) {
            return null;
        }
    }

    private void saveCheckpoint(UploadCheckpoint checkpoint) {
        String checkpointPath = getCheckpointPath(
            checkpoint.getBucketName(), checkpoint.getObjectKey());
        try {
            Files.writeString(Path.of(checkpointPath), 
                JsonUtils.toJson(checkpoint));
        } catch (IOException e) {
            throw new RuntimeException("Failed to save checkpoint", e);
        }
    }
}
```

### 3.2 数据冗余策略

对象存储通过多种数据冗余策略来保障数据的持久性和可用性。

#### 3.2.1 三副本策略

标准存储采用三副本策略，将同一份数据的三个副本分布在至少2个可用区（AZ）中，确保即使一个可用区完全不可用，数据仍然可以正常读写。

```
                 ┌─────────────────────────────────────────────┐
                 │              三副本写入流程                    │
                 └─────────────────────────────────────────────┘

  Proxy                AZ-1                    AZ-2
   │          ┌────────────────┐      ┌────────────────┐
   │          │  Store Node A  │      │  Store Node C  │
   │  写入 ──▶│  [副本1-主]    │      │  [副本3]       │
   │          │                │      │                │
   │          │  同步复制 ─────────────▶│                │
   │          └────────────────┘      └────────────────┘
   │          ┌────────────────┐
   │          │  Store Node B  │
   │  写入 ──▶│  [副本2]       │
   │          │                │
   │          └────────────────┘
   │
   │  所有副本写入成功后返回客户端
```

**跨AZ强一致写入**：

```java
/**
 * 三副本写入引擎
 */
public class ThreeReplicaWriteEngine {

    private final PartitionManager partitionManager;
    private final int WRITE_QUORUM = 3; // 所有副本必须写成功

    /**
     * 写入数据到三个副本
     * 采用同步写入策略，所有副本写成功才返回
     */
    public WriteResult writeRecord(long partitionId, byte[] data, long checksum) {
        // 1. 获取分区的副本信息
        Partition partition = partitionManager.getPartition(partitionId);
        List<ReplicaInfo> replicas = partition.getReplicas();
        
        // 确保副本分布在至少2个AZ
        assert getDistinctAZCount(replicas) >= 2 : 
            "Replicas must span at least 2 availability zones";

        // 2. 并发写入所有副本
        List<CompletableFuture<ReplicaWriteResult>> futures = new ArrayList<>();
        for (ReplicaInfo replica : replicas) {
            CompletableFuture<ReplicaWriteResult> future = CompletableFuture
                .supplyAsync(() -> {
                    return writeToReplica(replica, data, checksum);
                });
            futures.add(future);
        }

        // 3. 等待所有副本写入完成
        List<ReplicaWriteResult> results = new ArrayList<>();
        for (CompletableFuture<ReplicaWriteResult> future : futures) {
            try {
                ReplicaWriteResult result = future.get(5, TimeUnit.SECONDS);
                results.add(result);
            } catch (TimeoutException e) {
                throw new WriteException("Replica write timeout", e);
            } catch (Exception e) {
                throw new WriteException("Replica write failed", e);
            }
        }

        // 4. 验证写入结果
        long successCount = results.stream()
            .filter(ReplicaWriteResult::isSuccess)
            .count();
        
        if (successCount < WRITE_QUORUM) {
            // 回滚已写入的副本
            rollbackWrites(results);
            throw new WriteException(
                "Write quorum not met: " + successCount + "/" + WRITE_QUORUM);
        }

        // 5. 返回写入结果
        WriteResult writeResult = new WriteResult();
        writeResult.setPartitionId(partitionId);
        writeResult.setOffset(results.get(0).getOffset());
        writeResult.setSize(data.length);
        writeResult.setChecksum(checksum);
        return writeResult;
    }

    /**
     * 写入单个副本
     */
    private ReplicaWriteResult writeToReplica(ReplicaInfo replica, 
                                               byte[] data, long checksum) {
        StoreNodeClient client = getStoreNodeClient(replica.getNodeAddress());
        try {
            WriteResponse response = client.write(
                replica.getPartitionId(),
                replica.getReplicaId(),
                data,
                checksum
            );
            
            ReplicaWriteResult result = new ReplicaWriteResult();
            result.setSuccess(true);
            result.setReplicaId(replica.getReplicaId());
            result.setOffset(response.getOffset());
            return result;
        } catch (Exception e) {
            ReplicaWriteResult result = new ReplicaWriteResult();
            result.setSuccess(false);
            result.setReplicaId(replica.getReplicaId());
            result.setErrorMessage(e.getMessage());
            return result;
        }
    }
}
```

#### 3.2.2 纠删码策略（Erasure Code）

纠删码是一种高效的数据冗余技术，通过将原始数据编码为更多的数据分片，在保证数据可靠性的同时大幅降低存储成本。

**基本原理**：将原始数据分为k个数据块，通过编码生成m个校验块。只要k+m个块中任意k个块可用，就可以恢复完整的原始数据。

```
原始数据                         编码后
┌──────────┐                ┌──────────┐
│ 数据块 D1 │                │ 数据块 D1 │ ──┐
├──────────┤                ├──────────┤   │
│ 数据块 D2 │    EC编码      │ 数据块 D2 │   │ 任意k个块
├──────────┤ ──────────▶    ├──────────┤   │ 可恢复
│ 数据块 D3 │                │ 数据块 D3 │   │ 原始数据
├──────────┤                ├──────────┤   │
│ 数据块 D4 │   k=4,m=2     │ 数据块 D4 │ ──┘
└──────────┘                ├──────────┤
                            │ 校验块 P1 │
                            ├──────────┤
                            │ 校验块 P2 │
                            └──────────┘
                            总共6个块，丢失任意2个可恢复
```

**LRC（Local Reconstruction Code）跨数据中心纠删码**：

标准的纠删码在修复单个损坏块时，需要从其他k个节点读取数据进行恢复。当这些节点分布在不同数据中心时，跨机房的网络带宽消耗巨大。LRC在标准纠删码的基础上引入了本地校验块（Local Parity），使得同一数据中心内的数据块可以通过本地校验块进行修复，无需跨机房读取。

```
             数据中心A                           数据中心B
   ┌───────────────────────────┐      ┌───────────────────────────┐
   │  D1   D2   D3   LP_A     │      │  D4   D5   D6   LP_B     │
   │  ┌──┐ ┌──┐ ┌──┐ ┌──┐    │      │  ┌──┐ ┌──┐ ┌──┐ ┌──┐    │
   │  │  │ │  │ │  │ │  │    │      │  │  │ │  │ │  │ │  │    │
   │  └──┘ └──┘ └──┘ └──┘    │      │  └──┘ └──┘ └──┘ └──┘    │
   │       ▲                   │      │       ▲                   │
   │       │ 本地修复           │      │       │ 本地修复           │
   │       │ (不跨机房)         │      │       │ (不跨机房)         │
   └───────────────────────────┘      └───────────────────────────┘
                          │                    │
                    ┌─────▼────────────────────▼─────┐
                    │    全局校验块 GP1  GP2          │
                    │    (用于跨机房多块故障恢复)       │
                    └────────────────────────────────┘

   LP = Local Parity (本地校验块，用于同机房快速修复)
   GP = Global Parity (全局校验块，用于跨机房故障恢复)
```

```java
/**
 * 纠删码引擎
 */
public class ErasureCodeEngine {

    /**
     * RS(Reed-Solomon)编码
     * k个数据块 + m个校验块
     */
    public byte[][] encode(byte[] originalData, int k, int m) {
        int blockSize = (int) Math.ceil((double) originalData.length / k);
        
        // 1. 将原始数据分为k个等长的数据块
        byte[][] dataBlocks = new byte[k][blockSize];
        for (int i = 0; i < k; i++) {
            int offset = i * blockSize;
            int length = Math.min(blockSize, originalData.length - offset);
            if (length > 0) {
                System.arraycopy(originalData, offset, dataBlocks[i], 0, length);
            }
        }

        // 2. 生成编码矩阵（范德蒙矩阵）
        int[][] encodingMatrix = generateVandermondeMatrix(k + m, k);

        // 3. 计算校验块
        byte[][] parityBlocks = new byte[m][blockSize];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < blockSize; j++) {
                int value = 0;
                for (int l = 0; l < k; l++) {
                    value ^= galoisMultiply(
                        encodingMatrix[k + i][l], 
                        dataBlocks[l][j] & 0xFF
                    );
                }
                parityBlocks[i][j] = (byte) value;
            }
        }

        // 4. 合并数据块和校验块
        byte[][] allBlocks = new byte[k + m][blockSize];
        System.arraycopy(dataBlocks, 0, allBlocks, 0, k);
        System.arraycopy(parityBlocks, 0, allBlocks, k, m);
        
        return allBlocks;
    }

    /**
     * 数据修复：从任意k个可用块中恢复原始数据
     */
    public byte[] decode(byte[][] availableBlocks, int[] availableIndices, 
                          int k, int m) {
        if (availableBlocks.length < k) {
            throw new IllegalArgumentException(
                "Need at least " + k + " blocks to recover, got " + 
                availableBlocks.length);
        }

        int blockSize = availableBlocks[0].length;

        // 1. 构造解码矩阵（取编码矩阵中对应行）
        int[][] encodingMatrix = generateVandermondeMatrix(k + m, k);
        int[][] subMatrix = new int[k][k];
        for (int i = 0; i < k; i++) {
            subMatrix[i] = encodingMatrix[availableIndices[i]];
        }

        // 2. 求逆矩阵
        int[][] inverseMatrix = invertMatrix(subMatrix, k);

        // 3. 恢复原始数据块
        byte[][] recoveredBlocks = new byte[k][blockSize];
        for (int i = 0; i < k; i++) {
            for (int j = 0; j < blockSize; j++) {
                int value = 0;
                for (int l = 0; l < k; l++) {
                    value ^= galoisMultiply(
                        inverseMatrix[i][l],
                        availableBlocks[l][j] & 0xFF
                    );
                }
                recoveredBlocks[i][j] = (byte) value;
            }
        }

        // 4. 合并为原始数据
        ByteArrayOutputStream output = new ByteArrayOutputStream();
        for (int i = 0; i < k; i++) {
            output.write(recoveredBlocks[i], 0, blockSize);
        }
        return output.toByteArray();
    }

    /**
     * LRC本地修复
     * 在同一数据中心内使用本地校验块修复，无需跨机房网络传输
     * 在线修复TP90 < 100ms
     */
    public byte[] localRepair(byte[][] localGroupBlocks, 
                               byte[] localParity,
                               int damagedIndex) {
        int blockSize = localParity.length;
        byte[] repaired = new byte[blockSize];
        
        // 通过XOR运算修复：损坏块 = 本地校验块 XOR 其他所有本地数据块
        for (int j = 0; j < blockSize; j++) {
            repaired[j] = localParity[j];
            for (int i = 0; i < localGroupBlocks.length; i++) {
                if (i != damagedIndex) {
                    repaired[j] ^= localGroupBlocks[i][j];
                }
            }
        }
        
        return repaired;
    }
}
```

| 存储类型 | 冗余策略 | 成本对比(vs标准) | 数据可靠性 | 适用场景 |
|---------|---------|----------------|-----------|---------|

### 3.3 文件下载与CDN分发

#### 3.3.1 文件下载流程

```
客户端                     路由层              协议层(Proxy)          存储层(Store)
  │                        │                    │                     │
  │  GET Object ───────────▶                    │                     │
  │                        │  路由到Group ───────▶                     │
  │                        │                    │  1.查询元数据         │
  │                        │                    │  2.获取Record位置    │
  │                        │                    │                     │
  │                        │                    │  读取Record ─────────▶ 3.按分区读取
  │                        │                    │                     │   各Record
  │                        │                    │  Record数据 ◀────────│
  │                        │                    │                     │
  │                        │                    │  4.合并Records       │
  │                        │                    │  5.校验完整性         │
  │                        │                    │                     │
  │  返回文件内容 ◀──────────────────────────────│                     │
  │  (流式传输)            │                    │                     │
```

```java
/**
 * 文件下载处理器
 */
public class DownloadHandler {

    private final MetadataService metadataService;
    private final StorageEngine storageEngine;

    /**
     * 处理下载请求，支持范围读取（Range）
     */
    public void handleDownload(DownloadRequest request, OutputStream outputStream) 
            throws IOException {
        // 1. 查询对象元数据
        StorageObject objectMeta = metadataService.getObjectMeta(
            request.getBucketName(), request.getObjectKey());
        
        if (objectMeta == null) {
            throw new ObjectNotFoundException("Object not found: " + 
                request.getBucketName() + "/" + request.getObjectKey());
        }

        // 2. 处理Range请求（支持断点下载）
        long startByte = 0;
        long endByte = objectMeta.getContentLength() - 1;
        
        if (request.getRange() != null) {
            long[] range = parseRange(request.getRange(), objectMeta.getContentLength());
            startByte = range[0];
            endByte = range[1];
        }

        // 3. 确定需要读取的Record范围
        List<RecordLocation> locations = objectMeta.getRecordLocations();
        long currentOffset = 0;
        
        for (RecordLocation location : locations) {
            long recordEnd = currentOffset + location.getSize() - 1;
            
            // 跳过不在范围内的Record
            if (recordEnd < startByte) {
                currentOffset += location.getSize();
                continue;
            }
            if (currentOffset > endByte) {
                break;
            }

            // 4. 从存储层读取Record数据
            byte[] recordData = storageEngine.readRecord(
                location.getPartitionId(),
                location.getOffset(),
                location.getSize()
            );

            // 5. 校验数据完整性
            long actualChecksum = calculateChecksum(recordData);
            if (actualChecksum != location.getChecksum()) {
                // 校验失败，尝试从其他副本读取
                recordData = readFromAlternateReplica(location);
            }

            // 6. 截取范围内的数据并写入输出流
            int recordStart = (int) Math.max(0, startByte - currentOffset);
            int recordLength = (int) Math.min(
                recordData.length - recordStart,
                endByte - Math.max(currentOffset, startByte) + 1
            );
            
            outputStream.write(recordData, recordStart, recordLength);
            outputStream.flush();
            
            currentOffset += location.getSize();
        }
    }
}
```

#### 3.3.2 CDN加速分发

CDN（Content Delivery Network，内容分发网络）通过将内容缓存到距离用户最近的边缘节点，大幅降低访问延迟和回源带宽。对象存储与CDN的配合是大规模内容分发的标准方案。

```
                     ┌──────────────────────────────────────────┐
                     │              CDN分发架构                   │
                     └──────────────────────────────────────────┘

  用户A(北京)   用户B(上海)   用户C(广州)
     │              │              │
     ▼              ▼              ▼
  ┌─────┐       ┌─────┐       ┌─────┐
  │边缘  │       │边缘  │       │边缘  │      L1 边缘节点
  │节点A │       │节点B │       │节点C │      (最近接入点)
  └──┬──┘       └──┬──┘       └──┬──┘
     │              │              │
     ▼              ▼              ▼
  ┌─────────┐  ┌─────────┐  ┌─────────┐
  │ 区域节点 │  │ 区域节点 │  │ 区域节点 │    L2 区域节点
  │ (华北)   │  │ (华东)   │  │ (华南)   │    (区域缓存)
  └────┬─────┘  └────┬─────┘  └────┬─────┘
       │              │              │
       └──────────────┼──────────────┘
                      │
                      ▼
               ┌─────────────┐
               │   对象存储    │                 源站
               │  (源站服务)   │
               └─────────────┘
```

```java
/**
 * 预签名URL的签名验证流程
 */
public class SignatureVerifier {

    /**
     * 验证预签名URL的签名
     */
    public boolean verifyPresignedUrl(HttpRequest request) {
        // 1. 提取URL中的签名参数
        String accessKeyId = request.getParameter("AccessKeyId");
        long expires = Long.parseLong(request.getParameter("Expires"));
        String signature = request.getParameter("Signature");

        // 2. 检查是否过期
        if (System.currentTimeMillis() / 1000 > expires) {
            throw new AuthException("Presigned URL has expired");
        }

        // 3. 根据AccessKeyId查找对应的SecretAccessKey
        String secretAccessKey = credentialService.getSecretKey(accessKeyId);
        if (secretAccessKey == null) {
            throw new AuthException("Invalid AccessKeyId");
        }

        // 4. 重新计算签名
        String stringToSign = String.join("\n",
            request.getMethod(),
            request.getHeader("Content-MD5", ""),
            request.getHeader("Content-Type", ""),
            String.valueOf(expires),
            request.getRequestURI()
        );
        
        String expectedSignature = HmacUtils.hmacSha256Hex(
            secretAccessKey, stringToSign);

        // 5. 比较签名
        return MessageDigest.isEqual(
            signature.getBytes(StandardCharsets.UTF_8),
            expectedSignature.getBytes(StandardCharsets.UTF_8)
        );
    }
}
```

```java
/**
 * 图片处理引擎
 */
public class ImageProcessingEngine {

    /**
     * 解析并执行图片处理指令
     */
    public byte[] processImage(byte[] sourceImage, String processCommand) 
            throws IOException {
        
        BufferedImage image = ImageIO.read(new ByteArrayInputStream(sourceImage));
        String outputFormat = "jpg"; // 默认输出格式

        // 解析处理指令链（支持多个操作用 / 分隔）
        String[] operations = processCommand.split("/");
        
        for (String operation : operations) {
            String[] parts = operation.split(",");
            String action = parts[0];
            Map<String, String> params = parseParams(parts);

            switch (action) {
                case "resize":
                    image = resize(image, params);
                    break;
                case "crop":
                    image = crop(image, params);
                    break;
                case "rotate":
                    image = rotate(image, params);
                    break;
                case "watermark":
                    image = addWatermark(image, params);
                    break;
                case "format":
                    outputFormat = params.getOrDefault("type", "jpg");
                    break;
                case "quality":
                    // 质量参数在最终编码时使用
                    break;
                default:
                    throw new IllegalArgumentException(
                        "Unknown operation: " + action);
            }
        }

        // 编码输出
        ByteArrayOutputStream output = new ByteArrayOutputStream();
        ImageIO.write(image, outputFormat, output);
        return output.toByteArray();
    }

    /**
     * 等比缩放
     */
    private BufferedImage resize(BufferedImage source, Map<String, String> params) {
        int targetWidth = Integer.parseInt(params.getOrDefault("w", "0"));
        int targetHeight = Integer.parseInt(params.getOrDefault("h", "0"));
        String mode = params.getOrDefault("m", "lfit"); // lfit=等比缩放 fill=裁剪填充

        int srcWidth = source.getWidth();
        int srcHeight = source.getHeight();

        if (targetWidth == 0 && targetHeight == 0) {
            return source;
        }

        // 计算等比缩放的目标尺寸
        if ("lfit".equals(mode)) {
            if (targetWidth == 0) {
                targetWidth = (int) ((double) targetHeight / srcHeight * srcWidth);
            } else if (targetHeight == 0) {
                targetHeight = (int) ((double) targetWidth / srcWidth * srcHeight);
            } else {
                double ratio = Math.min(
                    (double) targetWidth / srcWidth,
                    (double) targetHeight / srcHeight
                );
                targetWidth = (int) (srcWidth * ratio);
                targetHeight = (int) (srcHeight * ratio);
            }
        }

        BufferedImage resized = new BufferedImage(
            targetWidth, targetHeight, source.getType());
        Graphics2D g2d = resized.createGraphics();
        g2d.setRenderingHint(RenderingHints.KEY_INTERPOLATION,
            RenderingHints.VALUE_INTERPOLATION_BILINEAR);
        g2d.drawImage(source, 0, 0, targetWidth, targetHeight, null);
        g2d.dispose();
        
        return resized;
    }

    /**
     * 裁剪
     */
    private BufferedImage crop(BufferedImage source, Map<String, String> params) {
        int x = Integer.parseInt(params.getOrDefault("x", "0"));
        int y = Integer.parseInt(params.getOrDefault("y", "0"));
        int w = Integer.parseInt(params.getOrDefault("w", 
            String.valueOf(source.getWidth())));
        int h = Integer.parseInt(params.getOrDefault("h", 
            String.valueOf(source.getHeight())));

        // 边界检查
        x = Math.max(0, Math.min(x, source.getWidth() - 1));
        y = Math.max(0, Math.min(y, source.getHeight() - 1));
        w = Math.min(w, source.getWidth() - x);
        h = Math.min(h, source.getHeight() - y);

        return source.getSubimage(x, y, w, h);
    }

    /**
     * 添加文字水印
     */
    private BufferedImage addWatermark(BufferedImage source, 
                                        Map<String, String> params) {
        String text = new String(Base64.getDecoder().decode(
            params.getOrDefault("text", "")), StandardCharsets.UTF_8);
        int fontSize = Integer.parseInt(params.getOrDefault("size", "20"));
        String color = params.getOrDefault("color", "FFFFFF");
        float opacity = Float.parseFloat(params.getOrDefault("t", "50")) / 100f;
        String position = params.getOrDefault("g", "se"); // 默认右下角

        BufferedImage result = new BufferedImage(
            source.getWidth(), source.getHeight(), BufferedImage.TYPE_INT_ARGB);
        Graphics2D g2d = result.createGraphics();
        g2d.drawImage(source, 0, 0, null);

        // 设置水印字体和透明度
        g2d.setFont(new Font("SimHei", Font.BOLD, fontSize));
        g2d.setComposite(AlphaComposite.getInstance(
            AlphaComposite.SRC_OVER, opacity));
        g2d.setColor(Color.decode("#" + color));

        // 计算水印位置
        FontMetrics fm = g2d.getFontMetrics();
        int textWidth = fm.stringWidth(text);
        int textHeight = fm.getHeight();
        int[] pos = calculateWatermarkPosition(
            source.getWidth(), source.getHeight(),
            textWidth, textHeight, position);

        g2d.drawString(text, pos[0], pos[1]);
        g2d.dispose();
        
        return result;
    }

    /**
     * HEIF格式转换（节省带宽）
     * HEIF格式相比JPEG可节省约50%的带宽，同等画质下文件体积更小
     */
    public byte[] convertToHeif(byte[] sourceImage, int quality) {
        // 使用专门的HEIF编码器
        HeifEncoder encoder = new HeifEncoder();
        encoder.setQuality(quality);
        return encoder.encode(sourceImage);
    }
}
```

**暗水印（盲水印）技术**：

暗水印不同于可见水印，它将水印信息嵌入到图片的频域中，肉眼不可见但可以通过算法提取。常用于版权保护和图片溯源。

```java
/**
 * 暗水印处理器
 * 基于DCT（离散余弦变换）的频域水印
 */
public class InvisibleWatermarkProcessor {

    /**
     * 嵌入暗水印
     * 将水印信息编码到图片的中频系数中
     */
    public BufferedImage embedWatermark(BufferedImage source, String watermarkText) {
        // 1. 将水印文本转为二进制序列
        byte[] watermarkBits = textToBits(watermarkText);
        
        // 2. 对图片进行8x8块的DCT变换
        double[][][] dctBlocks = performDCT(source);
        
        // 3. 在中频系数中嵌入水印位
        int bitIndex = 0;
        for (int block = 0; block < dctBlocks.length && 
             bitIndex < watermarkBits.length; block++) {
            // 修改中频系数（位置(4,3)和(3,4)）
            // 确保修改量足够小，肉眼不可见
            double alpha = 25.0; // 嵌入强度
            if (watermarkBits[bitIndex] == 1) {
                dctBlocks[block][4][3] = 
                    Math.abs(dctBlocks[block][4][3]) + alpha;
            } else {
                dctBlocks[block][4][3] = 
                    -Math.abs(dctBlocks[block][4][3]) - alpha;
            }
            bitIndex++;
        }
        
        // 4. 进行逆DCT变换，得到嵌入水印后的图片
        return performInverseDCT(dctBlocks, source.getWidth(), source.getHeight());
    }

    /**
     * 提取暗水印
     */
    public String extractWatermark(BufferedImage watermarkedImage) {
        // 1. 对图片进行DCT变换
        double[][][] dctBlocks = performDCT(watermarkedImage);
        
        // 2. 从中频系数中提取水印位
        List<Byte> watermarkBits = new ArrayList<>();
        for (double[][] dctBlock : dctBlocks) {
            if (dctBlock[4][3] > 0) {
                watermarkBits.add((byte) 1);
            } else {
                watermarkBits.add((byte) 0);
            }
        }
        
        // 3. 将二进制序列转回文本
        return bitsToText(watermarkBits);
    }
}
```

### 3.6 存储生命周期管理

数据在其生命周期中，访问频率会随时间递减。存储生命周期管理通过自动化的策略，将数据在不同存储层级之间迁移，在保证数据可用性的前提下降低存储成本。

```
数据生命周期

  访问频率
    ▲
    │
    │  ██████
    │  ██████  ← 标准存储（热数据）
    │  ██████      频繁读写，低延迟
    │  ██████
    │  ██████████
    │         ████████
    │              ████  ← 低频存储（温数据）
    │                 ████      偶尔访问，存储成本低
    │                    ████
    │                       ████████
    │                             ████  ← 归档存储（冷数据）
    │                                ████    极少访问，解冻需等待
    │                                   ████████████
    └──────────────────────────────────────────────────▶ 时间
       创建      30天        60天        90天        365天+
```

```java
/**
 * 存储生命周期管理器
 */
public class LifecycleManager {

    /**
     * 生命周期规则定义
     */
    public LifecycleConfiguration createLifecycleConfig(String bucketName) {
        LifecycleConfiguration config = new LifecycleConfiguration();
        config.setBucketName(bucketName);
        
        List<LifecycleRule> rules = new ArrayList<>();

        // 规则1：日志文件 - 30天后转为低频存储，90天后转为归档，365天后删除
        LifecycleRule logRule = new LifecycleRule();
        logRule.setId("log-lifecycle");
        logRule.setPrefix("logs/");
        logRule.setEnabled(true);
        logRule.addTransition(new Transition(30, StorageClass.INFREQUENT_ACCESS));
        logRule.addTransition(new Transition(90, StorageClass.ARCHIVE));
        logRule.setExpirationDays(365);
        rules.add(logRule);

        // 规则2：临时文件 - 7天后自动删除
        LifecycleRule tempRule = new LifecycleRule();
        tempRule.setId("temp-cleanup");
        tempRule.setPrefix("temp/");
        tempRule.setEnabled(true);
        tempRule.setExpirationDays(7);
        rules.add(tempRule);

        // 规则3：用户上传的文件 - 60天后转为低频存储
        LifecycleRule uploadRule = new LifecycleRule();
        uploadRule.setId("upload-lifecycle");
        uploadRule.setPrefix("uploads/");
        uploadRule.setEnabled(true);
        uploadRule.addTransition(
            new Transition(60, StorageClass.INFREQUENT_ACCESS));
        rules.add(uploadRule);

        // 规则4：清理未完成的分片上传（7天后自动中止）
        LifecycleRule abortRule = new LifecycleRule();
        abortRule.setId("abort-incomplete-multipart");
        abortRule.setPrefix(""); // 适用于所有对象
        abortRule.setEnabled(true);
        abortRule.setAbortIncompleteMultipartUploadDays(7);
        rules.add(abortRule);

        config.setRules(rules);
        return config;
    }

    /**
     * 执行生命周期规则（定时任务）
     */
    public void executeLifecycleRules(String bucketName) {
        LifecycleConfiguration config = getLifecycleConfig(bucketName);
        
        for (LifecycleRule rule : config.getRules()) {
            if (!rule.isEnabled()) continue;

            // 扫描匹配前缀的对象
            List<StorageObject> objects = metadataService.listObjectsByPrefix(
                bucketName, rule.getPrefix());
            
            for (StorageObject obj : objects) {
                long ageInDays = calculateAgeDays(obj.getLastModified());
                
                // 检查是否需要删除
                if (rule.getExpirationDays() > 0 && 
                    ageInDays >= rule.getExpirationDays()) {
                    deleteObject(bucketName, obj.getObjectKey());
                    continue;
                }
                
                // 检查是否需要转换存储类型
                for (Transition transition : rule.getTransitions()) {
                    if (ageInDays >= transition.getDays() && 
                        obj.getStorageClass() != transition.getTargetStorageClass()) {
                        // 执行存储类型转换
                        transitionObject(bucketName, obj.getObjectKey(),
                            transition.getTargetStorageClass());
                        break;
                    }
                }
            }
        }
    }

    /**
     * 存储类型转换
     * 标准存储 -> 低频存储：修改冗余策略（三副本 -> 纠删码）
     * 低频存储 -> 归档存储：迁移到廉价存储介质
     */
    private void transitionObject(String bucketName, String objectKey,
                                   StorageClass targetClass) {
        StorageObject obj = metadataService.getObjectMeta(bucketName, objectKey);
        
        switch (targetClass) {
            case INFREQUENT_ACCESS:
                // 将三副本数据转换为纠删码存储
                convertToErasureCode(obj);
                break;
            case ARCHIVE:
                // 将数据迁移到归档存储
                // 归档数据需要解冻（1-5分钟到12小时不等）才能访问
                migrateToArchive(obj);
                break;
        }
        
        // 更新元数据中的存储类型
        obj.setStorageClass(targetClass);
        metadataService.updateObjectMeta(obj);
    }
}
```

### 4.1 数据损坏检测与修复

```java
/**
 * 数据完整性巡检服务
 * 定期扫描所有数据块，检测静默数据损坏（bit rot）
 */
public class DataIntegrityChecker {

    /**
     * 巡检任务：校验数据块的校验和
     */
    public void runIntegrityCheck(long partitionId) {
        Partition partition = partitionManager.getPartition(partitionId);
        List<RecordInfo> records = partition.listRecords();
        
        for (RecordInfo record : records) {
            byte[] data = storageEngine.readRecord(
                partitionId, record.getOffset(), record.getSize());
            
            long actualChecksum = calculateChecksum(data);
            
            if (actualChecksum != record.getExpectedChecksum()) {
                // 数据损坏，触发自动修复
                repairCorruptedRecord(partitionId, record);
            }
        }
    }

    /**
     * 自动修复损坏的数据块
     */
    private void repairCorruptedRecord(long partitionId, RecordInfo record) {
        Partition partition = partitionManager.getPartition(partitionId);
        StorageType storageType = partition.getStorageType();

        if (storageType == StorageType.THREE_REPLICA) {
            // 三副本模式：从其他健康副本复制数据
            for (ReplicaInfo replica : partition.getReplicas()) {
                if (replica.getReplicaId() == record.getReplicaId()) {
                    continue; // 跳过损坏的副本
                }
                try {
                    byte[] healthyData = readFromReplica(replica, record);
                    long checksum = calculateChecksum(healthyData);
                    if (checksum == record.getExpectedChecksum()) {
                        // 用健康数据覆盖损坏数据
                        overwriteRecord(partitionId, record, healthyData);
                        return;
                    }
                } catch (Exception e) {
                    // 该副本也无法读取，继续尝试下一个
                    continue;
                }
            }
        } else if (storageType == StorageType.ERASURE_CODE) {
            // 纠删码模式：通过编解码恢复数据
            repairWithErasureCode(partitionId, record);
        }

        // 所有修复手段失败，上报告警
        alertService.sendAlert(AlertLevel.CRITICAL,
            "Data repair failed for partition=" + partitionId + 
            ", record=" + record.getOffset());
    }
}
```

### 4.2 上传失败重试策略

```java
/**
 * 智能重试策略
 */
public class UploadRetryStrategy {

    private static final int MAX_RETRIES = 3;
    private static final long BASE_DELAY_MS = 200;
    private static final long MAX_DELAY_MS = 10000;

    /**
     * 带退避策略的重试上传
     */
    public <T> T executeWithRetry(Callable<T> operation) throws Exception {
        Exception lastException = null;
        
        for (int attempt = 0; attempt <= MAX_RETRIES; attempt++) {
            try {
                return operation.call();
            } catch (Exception e) {
                lastException = e;
                
                if (!isRetryable(e)) {
                    throw e; // 不可重试的异常直接抛出
                }
                
                if (attempt < MAX_RETRIES) {
                    // 指数退避 + 随机抖动
                    long delay = Math.min(
                        BASE_DELAY_MS * (1L << attempt) + 
                        ThreadLocalRandom.current().nextLong(100),
                        MAX_DELAY_MS
                    );
                    Thread.sleep(delay);
                }
            }
        }
        
        throw lastException;
    }

    /**
     * 判断异常是否可以重试
     */
    private boolean isRetryable(Exception e) {
        if (e instanceof SocketTimeoutException) return true;
        if (e instanceof ConnectException) return true;
        if (e instanceof ServiceUnavailableException) return true;
        if (e instanceof ThrottlingException) return true;
        // 客户端错误（4xx）通常不可重试
        if (e instanceof ClientException) return false;
        return false;
    }
}
```

```java
/**
 * 并行上传/下载优化

public class ParallelIOOptimizer {

    private final ExecutorService ioPool;
    private static final int DEFAULT_CONCURRENCY = 8;

    public ParallelIOOptimizer() {
        this.ioPool = new ThreadPoolExecutor(
            DEFAULT_CONCURRENCY, DEFAULT_CONCURRENCY * 2,
            60, TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(1000),
            new ThreadPoolExecutor.CallerRunsPolicy()
        );
    }

    /**
     * 并行分片上传
     * 利用多线程并发上传各分片，充分利用网络带宽
     */
    public List<PartETag> parallelUploadParts(
            String uploadId, File file, long partSize, int concurrency) 
            throws Exception {
        
        long fileSize = file.length();
        int partCount = (int) Math.ceil((double) fileSize / partSize);
        
        // 使用Semaphore控制并发度
        Semaphore semaphore = new Semaphore(concurrency);
        List<CompletableFuture<PartETag>> futures = new ArrayList<>();
        
        for (int i = 0; i < partCount; i++) {
            final int partNumber = i + 1;
            final long offset = (long) i * partSize;
            final int size = (int) Math.min(partSize, fileSize - offset);
            
            CompletableFuture<PartETag> future = CompletableFuture
                .supplyAsync(() -> {
                    try {
                        semaphore.acquire();
                        try {
                            // 读取分片数据
                            byte[] data = readFilePart(file, offset, size);
                            // 上传分片
                            UploadPartResult result = client.uploadPart(
                                uploadId, partNumber, data);
                            return new PartETag(partNumber, result.getETag());
                        } finally {
                            semaphore.release();
                        }
                    } catch (Exception e) {
                        throw new CompletionException(e);
                    }
                }, ioPool);
            
            futures.add(future);
        }

        // 等待所有分片上传完成
        return futures.stream()
            .map(CompletableFuture::join)
            .sorted(Comparator.comparingInt(PartETag::getPartNumber))
            .collect(Collectors.toList());
    }
}
```

```java
/**

public class MetadataCache {

    // L1: 本地缓存（进程内，最快）
    private final Cache<String, StorageObject> localCache;
    // L2: 分布式缓存
    private final DistributedCache distributedCache;
    // L3: 数据库
    private final MetadataRepository metadataRepository;

    public MetadataCache() {
        this.localCache = Caffeine.newBuilder()
            .maximumSize(100_000)
            .expireAfterWrite(5, TimeUnit.MINUTES)
            .build();
    }

    /**
     * 查询对象元数据，依次查找 L1 -> L2 -> L3
     */
    public StorageObject getObjectMeta(String bucketName, String objectKey) {
        String cacheKey = bucketName + ":" + objectKey;
        
        // L1: 本地缓存
        StorageObject meta = localCache.getIfPresent(cacheKey);
        if (meta != null) {
            return meta;
        }
        
        // L2: 分布式缓存
        meta = distributedCache.get(cacheKey, StorageObject.class);
        if (meta != null) {
            localCache.put(cacheKey, meta);
            return meta;
        }
        
        // L3: 数据库
        meta = metadataRepository.findByBucketAndKey(bucketName, objectKey);
        if (meta != null) {
            distributedCache.put(cacheKey, meta, Duration.ofMinutes(30));
            localCache.put(cacheKey, meta);
        }
        
        return meta;
    }

    /**
     * 更新元数据时清除缓存
     */
    public void invalidate(String bucketName, String objectKey) {
        String cacheKey = bucketName + ":" + objectKey;
        localCache.invalidate(cacheKey);
        distributedCache.delete(cacheKey);
    }
}
```

### 5.4 流式传输优化

```java
/**
 * 流式传输优化
 * 避免大文件全量加载到内存
 */
public class StreamingTransfer {

    private static final int BUFFER_SIZE = 8192; // 8KB缓冲区

    /**
     * 流式上传：边读取边传输，内存占用恒定
     */
    public String streamingUpload(String bucketName, String objectKey,
                                    InputStream inputStream, long contentLength) 
            throws IOException {
        
        MessageDigest md5Digest = MessageDigest.getInstance("MD5");
        byte[] buffer = new byte[BUFFER_SIZE];
        long totalBytes = 0;
        int bytesRead;

        // 获取存储层的写入流
        OutputStream storageStream = storageEngine.openWriteStream(
            bucketName, objectKey);

        try {
            while ((bytesRead = inputStream.read(buffer)) != -1) {
                storageStream.write(buffer, 0, bytesRead);
                md5Digest.update(buffer, 0, bytesRead);
                totalBytes += bytesRead;
            }
        } finally {
            storageStream.close();
        }

        String md5 = Hex.encodeHexString(md5Digest.digest());
        return md5;
    }

    /**
     * 流式下载：支持HTTP Range请求的流式传输
     */
    public void streamingDownload(String bucketName, String objectKey,
                                    HttpServletResponse response,
                                    String rangeHeader) throws IOException {
        
        StorageObject meta = metadataService.getObjectMeta(bucketName, objectKey);
        long fileSize = meta.getContentLength();

        // 解析Range头
        long start = 0, end = fileSize - 1;
        if (rangeHeader != null && rangeHeader.startsWith("bytes=")) {
            String[] ranges = rangeHeader.substring(6).split("-");
            start = Long.parseLong(ranges[0]);
            if (ranges.length > 1 && !ranges[1].isEmpty()) {
                end = Long.parseLong(ranges[1]);
            }
            
            response.setStatus(HttpServletResponse.SC_PARTIAL_CONTENT);
            response.setHeader("Content-Range", 
                "bytes " + start + "-" + end + "/" + fileSize);
        }

        long contentLength = end - start + 1;
        response.setContentLengthLong(contentLength);
        response.setContentType(meta.getContentType());
        response.setHeader("Accept-Ranges", "bytes");
        response.setHeader("ETag", "\"" + meta.getContentMd5() + "\"");

        // 流式输出
        try (InputStream storageStream = storageEngine.openReadStream(
                bucketName, objectKey, start, contentLength);
             OutputStream out = response.getOutputStream()) {
            
            byte[] buffer = new byte[BUFFER_SIZE];
            int bytesRead;
            while ((bytesRead = storageStream.read(buffer)) != -1) {
                out.write(buffer, 0, bytesRead);
            }
            out.flush();
        }
    }
}
```

### 6.2 存储选型决策

| 场景 | 推荐存储类型 | 冗余策略 | 关键考量 |
|-----|------------|---------|--------|
| 用户头像、商品图片 | 标准存储 | 三副本 | 高频访问，低延迟要求 |

### 6.3 安全最佳实践

1. **Bucket默认设为私有**：避免数据泄露，按需开放公共读权限
2. **使用预签名URL分享文件**：设置合理的过期时间（建议不超过1小时）
3. **启用服务端加密**：对敏感数据使用SSE加密存储
4. **配置Referer白名单**：防止资源被盗链
5. **定期审计访问日志**：监控异常访问模式

### 6.4 成本优化建议

1. **配置生命周期规则**：自动将冷数据转为低频/归档存储
2. **清理未完成的分片上传**：避免无效分片占用存储空间
3. **使用CDN分发热点内容**：减少回源带宽费用
4. **启用HEIF/WebP格式**：相比JPEG节省30%~50%带宽
5. **合理设置分片大小**：大文件使用更大的分片（如100MB），减少请求次数

### 6.5 总结

对象存储系统的核心设计要点：

1. **分层架构**：路由层、协议层、存储层、元数据层各司其职，通过Group隔离控制爆炸半径
2. **数据冗余**：三副本保障热数据的高可用，纠删码在保证可靠性的前提下显著降低存储成本
3. **灵活的上传方式**：简单上传、分片上传、表单直传、预签名URL覆盖不同业务场景
4. **CDN加速**：通过边缘节点缓存实现就近访问，大幅降低延迟和回源带宽
5. **生命周期管理**：自动化的数据分级存储策略，平衡访问性能与存储成本
6. **多层安全防护**：ACL、Bucket Policy、预签名URL、加密存储构成完整的安全体系

对象存储已经成为互联网应用的基础设施。在架构设计中，应根据数据的访问模式、可靠性要求和成本预算，选择合适的存储类型和冗余策略，并通过CDN、图片处理服务等周边能力构建完整的非结构化数据管理方案。

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.io.*;
import java.security.MessageDigest;
import java.util.*;
import java.util.concurrent.*;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * 大文件分片上传全链路服务
 * 负责初始化、分片切割、并行上传、合并完成和断点续传的完整流程
 */
public class LargeFileUploadService {

    private static final Logger logger = LoggerFactory.getLogger(LargeFileUploadService.class);

    /** 默认分片大小：10MB */
    private static final long DEFAULT_PART_SIZE = 10 * 1024 * 1024L;
    /** 最小分片大小：5MB（OSS要求） */
    private static final long MIN_PART_SIZE = 5 * 1024 * 1024L;
    /** 最大分片数量：10000 */
    private static final int MAX_PART_COUNT = 10000;
    /** 并行上传线程数 */
    private static final int PARALLEL_THREADS = 5;
    /** 单分片最大重试次数 */
    private static final int MAX_RETRY_PER_PART = 3;

    private final OssClient ossClient;
    private final UploadTaskRepository taskRepository;
    private final ExecutorService uploadExecutor;
    private final String bucketName;

    public LargeFileUploadService(OssClient ossClient, 
                                   UploadTaskRepository taskRepository,
                                   String bucketName) {
        this.ossClient = ossClient;
        this.taskRepository = taskRepository;
        this.bucketName = bucketName;
        this.uploadExecutor = new ThreadPoolExecutor(
            PARALLEL_THREADS, PARALLEL_THREADS, 60, TimeUnit.SECONDS,
            new LinkedBlockingQueue<>(100),
            new ThreadFactory() {
                private final AtomicInteger counter = new AtomicInteger(0);
                @Override
                public Thread newThread(Runnable r) {
                    Thread t = new Thread(r, "upload-worker-" + counter.incrementAndGet());
                    t.setDaemon(true);
                    return t;
                }
            },
            new ThreadPoolExecutor.CallerRunsPolicy()
        );
    }

    /**
     * 全链路入口：大文件分片上传
     * 支持断点续传和幂等控制
     *
     * @param file       待上传的本地文件
     * @param objectKey  目标对象Key
     * @param partSize   分片大小（字节），传0使用默认值
     * @return 上传结果
     */
    public UploadResult uploadLargeFile(File file, String objectKey, 
                                          long partSize) throws Exception {
        // 1. 参数校验
        validateFile(file);
        if (partSize <= 0) {
            partSize = calculateOptimalPartSize(file.length());
        }
        if (partSize < MIN_PART_SIZE) {
            partSize = MIN_PART_SIZE;
        }

        // 2. 生成文件唯一标识（用于幂等控制和断点续传）
        String fileId = generateFileId(bucketName, objectKey, 
                file.length(), file.lastModified());
        logger.info("[分片上传] 开始上传, file={}, size={}MB, objectKey={}, fileId={}",
                file.getName(), file.length() / 1024 / 1024, objectKey, fileId);

        // 3. 幂等校验：检查是否存在已完成的上传任务
        UploadTaskRecord existingTask = taskRepository.findByFileId(fileId);
        if (existingTask != null && existingTask.getStatus() == UploadStatus.COMPLETED) {
            logger.info("[分片上传] 文件已上传完成(幂等命中), fileId={}, eTag={}",
                    fileId, existingTask.getETag());
            UploadResult result = new UploadResult();
            result.setETag(existingTask.getETag());
            result.setObjectKey(objectKey);
            return result;
        }

        // 4. 初始化或恢复上传任务
        UploadTaskRecord taskRecord = initOrResumeUploadTask(
                existingTask, fileId, file, objectKey, partSize);
        logger.info("[分片上传] 任务初始化完成, uploadId={}, totalParts={}, completedParts={}",
                taskRecord.getUploadId(), taskRecord.getTotalParts(),
                taskRecord.getCompletedPartCount());

        try {
            // 5. 并行上传所有未完成的分片
            parallelUploadParts(file, taskRecord);

            // 6. 合并所有分片
            String eTag = completeUpload(taskRecord);

            // 7. 更新任务状态为已完成
            taskRecord.setStatus(UploadStatus.COMPLETED);
            taskRecord.setETag(eTag);
            taskRecord.setCompleteTime(System.currentTimeMillis());
            taskRepository.save(taskRecord);

            logger.info("[分片上传] 上传完成, fileId={}, objectKey={}, eTag={}",
                    fileId, objectKey, eTag);

            UploadResult result = new UploadResult();
            result.setETag(eTag);
            result.setObjectKey(objectKey);
            return result;

        } catch (Exception e) {
            logger.error("[分片上传] 上传失败, fileId={}, objectKey={}, 已完成分片={}/{}, error={}",
                    fileId, objectKey, taskRecord.getCompletedPartCount(),
                    taskRecord.getTotalParts(), e.getMessage(), e);
            // 任务记录保留，支持后续断点续传
            taskRecord.setStatus(UploadStatus.PAUSED);
            taskRepository.save(taskRecord);
            throw new UploadException("分片上传失败, 已保存进度可断点续传: " + e.getMessage(), e);
        }
    }

    /**
     * 初始化或恢复上传任务
     * 如果存在未完成的任务则恢复，否则创建新任务
     */
    private UploadTaskRecord initOrResumeUploadTask(UploadTaskRecord existing,
                                                      String fileId, File file,
                                                      String objectKey, 
                                                      long partSize) {
        if (existing != null && existing.getStatus() != UploadStatus.COMPLETED) {
            // 校验文件是否发生变化
            if (existing.getFileSize() == file.length() 
                    && existing.getFileLastModified() == file.lastModified()) {
                logger.info("[分片上传] 恢复已有上传任务, fileId={}, uploadId={}, " +
                        "completedParts={}/{}",
                        fileId, existing.getUploadId(),
                        existing.getCompletedPartCount(), existing.getTotalParts());
                existing.setStatus(UploadStatus.IN_PROGRESS);
                taskRepository.save(existing);
                return existing;
            } else {
                // 文件已变化，中止旧任务并创建新任务
                logger.warn("[分片上传] 文件已变化, 中止旧任务, fileId={}, oldUploadId={}",
                        fileId, existing.getUploadId());
                abortUploadTask(existing);
            }
        }

        // 创建新的分片上传任务
        String uploadId = ossClient.initiateMultipartUpload(bucketName, objectKey);
        int totalParts = (int) Math.ceil((double) file.length() / partSize);

        UploadTaskRecord record = new UploadTaskRecord();
        record.setFileId(fileId);
        record.setUploadId(uploadId);
        record.setBucketName(bucketName);
        record.setObjectKey(objectKey);
        record.setFileSize(file.length());
        record.setFileLastModified(file.lastModified());
        record.setTotalParts(totalParts);
        record.setPartSize(partSize);
        record.setStatus(UploadStatus.IN_PROGRESS);
        record.setPartETags(new ConcurrentHashMap<>());
        record.setCreateTime(System.currentTimeMillis());

        taskRepository.save(record);
        logger.info("[分片上传] 创建新上传任务, fileId={}, uploadId={}, totalParts={}",
                fileId, uploadId, totalParts);
        return record;
    }

    /**
     * 并行上传所有未完成的分片
     * 使用线程池并行上传，失败分片自动重试
     */
    private void parallelUploadParts(File file, UploadTaskRecord taskRecord) 
            throws Exception {
        List<Future<Void>> futures = new ArrayList<>();
        AtomicInteger completedCount = new AtomicInteger(
                taskRecord.getCompletedPartCount());

        for (int i = 0; i < taskRecord.getTotalParts(); i++) {
            final int partIndex = i;
            final int partNumber = i + 1;

            // 跳过已完成的分片（断点续传核心逻辑）
            if (taskRecord.isPartCompleted(partNumber)) {
                logger.debug("[分片上传] 跳过已完成分片, partNumber={}", partNumber);
                continue;
            }

            Future<Void> future = uploadExecutor.submit(() -> {
                uploadSinglePart(file, taskRecord, partIndex, partNumber);
                int done = completedCount.incrementAndGet();
                logger.info("[分片上传] 分片上传进度: {}/{}, partNumber={}",
                        done, taskRecord.getTotalParts(), partNumber);
                return null;
            });
            futures.add(future);
        }

        // 等待所有分片上传完成
        List<Exception> errors = new ArrayList<>();
        for (Future<Void> future : futures) {
            try {
                future.get(30, TimeUnit.MINUTES);
            } catch (ExecutionException e) {
                errors.add((Exception) e.getCause());
            } catch (TimeoutException e) {
                errors.add(new UploadException("分片上传超时"));
            }
        }

        if (!errors.isEmpty()) {
            logger.error("[分片上传] {}个分片上传失败", errors.size());
            throw errors.get(0);
        }
    }

    /**
     * 上传单个分片（带重试机制）
     */
    private void uploadSinglePart(File file, UploadTaskRecord taskRecord,
                                    int partIndex, int partNumber) throws Exception {
        long offset = (long) partIndex * taskRecord.getPartSize();
        int size = (int) Math.min(taskRecord.getPartSize(), 
                taskRecord.getFileSize() - offset);

        Exception lastException = null;

        for (int attempt = 1; attempt <= MAX_RETRY_PER_PART; attempt++) {
            try {
                // 读取分片数据
                byte[] partData = readFilePart(file, offset, size);

                // 上传分片到OSS
                UploadPartResult partResult = ossClient.uploadPart(
                        taskRecord.getBucketName(),
                        taskRecord.getObjectKey(),
                        taskRecord.getUploadId(),
                        partNumber,
                        partData
                );

                // 更新分片完成状态（持久化，支持断点续传）
                taskRecord.setPartCompleted(partNumber, partResult.getETag());
                taskRepository.updatePartProgress(
                        taskRecord.getFileId(), partNumber, partResult.getETag());

                logger.debug("[分片上传] 分片上传成功, partNumber={}, size={}KB, eTag={}",
                        partNumber, size / 1024, partResult.getETag());
                return;

            } catch (Exception e) {
                lastException = e;
                logger.warn("[分片上传] 分片上传失败, partNumber={}, attempt={}/{}, error={}",
                        partNumber, attempt, MAX_RETRY_PER_PART, e.getMessage());

                if (attempt < MAX_RETRY_PER_PART) {
                    // 指数退避重试
                    long delay = (long) Math.pow(2, attempt) * 500 
                            + ThreadLocalRandom.current().nextLong(200);
                    Thread.sleep(delay);
                }
            }
        }

        throw new UploadException("分片上传失败(已重试" + MAX_RETRY_PER_PART + "次), " +
                "partNumber=" + partNumber + ", error=" + lastException.getMessage(),
                lastException);
    }

    /**
     * 从文件中读取指定范围的数据
     */
    private byte[] readFilePart(File file, long offset, int size) throws IOException {
        try (RandomAccessFile raf = new RandomAccessFile(file, "r")) {
            raf.seek(offset);
            byte[] data = new byte[size];
            raf.readFully(data);
            return data;
        }
    }

    /**
     * 完成分片上传，合并所有分片
     */
    private String completeUpload(UploadTaskRecord taskRecord) {
        // 构建分片ETag列表（按partNumber排序）
        List<PartETag> partETags = new ArrayList<>();
        for (int i = 1; i <= taskRecord.getTotalParts(); i++) {
            String eTag = taskRecord.getPartETag(i);
            if (eTag == null) {
                throw new UploadException("分片" + i + "未上传完成");
            }
            partETags.add(new PartETag(i, eTag));
        }

        logger.info("[分片上传] 开始合并分片, uploadId={}, totalParts={}",
                taskRecord.getUploadId(), taskRecord.getTotalParts());

        CompleteMultipartUploadResult result = ossClient.completeMultipartUpload(
                taskRecord.getBucketName(),
                taskRecord.getObjectKey(),
                taskRecord.getUploadId(),
                partETags
        );

        logger.info("[分片上传] 分片合并完成, eTag={}", result.getETag());
        return result.getETag();
    }

    /**
     * 中止上传任务，清理已上传的分片
     */
    private void abortUploadTask(UploadTaskRecord taskRecord) {
        try {
            ossClient.abortMultipartUpload(
                    taskRecord.getBucketName(),
                    taskRecord.getObjectKey(),
                    taskRecord.getUploadId());
            taskRepository.delete(taskRecord.getFileId());
            logger.info("[分片上传] 中止上传任务, uploadId={}", taskRecord.getUploadId());
        } catch (Exception e) {
            logger.warn("[分片上传] 中止上传任务异常, uploadId={}, error={}",
                    taskRecord.getUploadId(), e.getMessage());
        }
    }

    /**
     * 参数校验
     */
    private void validateFile(File file) {
        if (file == null || !file.exists()) {
            throw new IllegalArgumentException("文件不存在");
        }
        if (!file.isFile()) {
            throw new IllegalArgumentException("不是有效的文件: " + file.getPath());
        }
        if (file.length() == 0) {
            throw new IllegalArgumentException("文件为空");
        }
        if (!file.canRead()) {
            throw new IllegalArgumentException("文件不可读: " + file.getPath());
        }
    }

    /**
     * 根据文件大小计算最优分片大小
     * 目标：在分片数量和分片大小之间取得平衡
     */
    private long calculateOptimalPartSize(long fileSize) {
        // 如果默认分片大小下分片数量不超过上限，使用默认值
        if (fileSize / DEFAULT_PART_SIZE <= MAX_PART_COUNT) {
            return DEFAULT_PART_SIZE;
        }
        // 否则动态计算分片大小
        long partSize = fileSize / MAX_PART_COUNT + 1;
        // 对齐到1MB
        partSize = ((partSize + 1024 * 1024 - 1) / (1024 * 1024)) * 1024 * 1024;
        return Math.max(partSize, MIN_PART_SIZE);
    }

    /**
     * 生成文件唯一标识（用于幂等控制）
     * 基于 bucketName + objectKey + fileSize + lastModified 的MD5
     */
    private String generateFileId(String bucketName, String objectKey,
                                    long fileSize, long lastModified) {
        String raw = String.join("|", bucketName, objectKey, 
                String.valueOf(fileSize), String.valueOf(lastModified));
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(raw.getBytes());
            StringBuilder sb = new StringBuilder();
            for (byte b : digest) {
                sb.append(String.format("%02x", b));
            }
            return sb.toString();
        } catch (Exception e) {
            throw new RuntimeException("MD5 calculation failed", e);
        }
    }

    /**
     * 手动触发断点续传
     * 外部可通过fileId恢复之前中断的上传任务
     */
    public UploadResult resumeUpload(String fileId, File file) throws Exception {
        UploadTaskRecord taskRecord = taskRepository.findByFileId(fileId);
        if (taskRecord == null) {
            throw new UploadException("未找到上传任务记录, fileId=" + fileId);
        }
        if (taskRecord.getStatus() == UploadStatus.COMPLETED) {
            logger.info("[断点续传] 任务已完成, fileId={}", fileId);
            UploadResult result = new UploadResult();
            result.setETag(taskRecord.getETag());
            result.setObjectKey(taskRecord.getObjectKey());
            return result;
        }

        logger.info("[断点续传] 恢复上传, fileId={}, completedParts={}/{}",
                fileId, taskRecord.getCompletedPartCount(), taskRecord.getTotalParts());
        return uploadLargeFile(file, taskRecord.getObjectKey(), taskRecord.getPartSize());
    }

    /**
     * 查询上传进度
     */
    public UploadProgress queryProgress(String fileId) {
        UploadTaskRecord taskRecord = taskRepository.findByFileId(fileId);
        if (taskRecord == null) {
            return null;
        }
        UploadProgress progress = new UploadProgress();
        progress.setFileId(fileId);
        progress.setStatus(taskRecord.getStatus());
        progress.setTotalParts(taskRecord.getTotalParts());
        progress.setCompletedParts(taskRecord.getCompletedPartCount());
        progress.setPercentage(
            taskRecord.getTotalParts() > 0 
                ? (taskRecord.getCompletedPartCount() * 100 / taskRecord.getTotalParts()) 
                : 0
        );
        return progress;
    }
}

/**
```
```java
 * 上传任务持久化记录

public class UploadTaskRecord {
    /** 文件唯一标识（幂等键） */
    private String fileId;
    /** OSS分片上传ID */
    private String uploadId;
    /** 存储桶 */
    private String bucketName;
    /** 对象Key */
    private String objectKey;
    /** 文件大小 */
    private long fileSize;
    /** 文件最后修改时间 */
    private long fileLastModified;
    /** 总分片数 */
    private int totalParts;
    /** 分片大小 */
    private long partSize;
    /** 上传状态 */
    private UploadStatus status;
    /** 已完成分片的ETag映射 (partNumber -> eTag) */
    private ConcurrentHashMap<Integer, String> partETags;
    /** 最终ETag */
    private String eTag;
    /** 创建时间 */
    private long createTime;
    /** 完成时间 */
    private long completeTime;

    public boolean isPartCompleted(int partNumber) {
        return partETags != null && partETags.containsKey(partNumber);
    }

    public void setPartCompleted(int partNumber, String eTag) {
        if (partETags == null) {
            partETags = new ConcurrentHashMap<>();
        }
        partETags.put(partNumber, eTag);
    }

    public String getPartETag(int partNumber) {
        return partETags != null ? partETags.get(partNumber) : null;
    }

    public int getCompletedPartCount() {
        return partETags != null ? partETags.size() : 0;
    }

    // 省略getter/setter
}

/**
 * 上传任务持久化仓储
 * 支持数据库或本地文件两种存储方式
 */
public class UploadTaskRepository {

    private static final Logger logger = LoggerFactory.getLogger(UploadTaskRepository.class);

    private final JdbcTemplate jdbcTemplate;

    public UploadTaskRepository(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    /**
     * 通过fileId查询上传任务（幂等查询）
     */
    public UploadTaskRecord findByFileId(String fileId) {
        try {
            return jdbcTemplate.queryForObject(
                "SELECT * FROM upload_task WHERE file_id = ?",
                new Object[]{fileId},
                (rs, rowNum) -> mapToRecord(rs)
            );
        } catch (EmptyResultDataAccessException e) {
            return null;
        }
    }

    /**
     * 保存或更新上传任务记录
     * 使用INSERT ON DUPLICATE KEY UPDATE实现幂等写入
     */
    public void save(UploadTaskRecord record) {
        jdbcTemplate.update(
            "INSERT INTO upload_task (file_id, upload_id, bucket_name, object_key, " +
            "file_size, file_last_modified, total_parts, part_size, status, " +
            "part_etags, etag, create_time, complete_time) " +
            "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?) " +
            "ON DUPLICATE KEY UPDATE status=VALUES(status), " +
            "part_etags=VALUES(part_etags), etag=VALUES(etag), " +
            "complete_time=VALUES(complete_time)",
            record.getFileId(), record.getUploadId(), record.getBucketName(),
            record.getObjectKey(), record.getFileSize(), record.getFileLastModified(),
            record.getTotalParts(), record.getPartSize(), record.getStatus().name(),
            JsonUtils.toJson(record.getPartETags()), record.getETag(),
            record.getCreateTime(), record.getCompleteTime()
        );
        logger.debug("[上传任务] 保存任务记录, fileId={}, status={}", 
                record.getFileId(), record.getStatus());
    }

    /**
     * 更新单个分片的完成状态
     */
    public void updatePartProgress(String fileId, int partNumber, String eTag) {
        // 使用JSON_SET原子更新分片进度，避免并发覆盖
        jdbcTemplate.update(
            "UPDATE upload_task SET part_etags = JSON_SET(part_etags, ?, ?) " +
            "WHERE file_id = ?",
            "$." + partNumber, eTag, fileId
        );
    }

    public void delete(String fileId) {
        jdbcTemplate.update("DELETE FROM upload_task WHERE file_id = ?", fileId);
    }
}
```

#### 7.1.3 幂等控制要点

| 环节 | 幂等策略 | 实现方式 |
|-----|---------|---------|
| 初始化上传 | 基于fileId去重 | fileId = MD5(bucketName + objectKey + fileSize + lastModified)，数据库唯一索引 |
| 分片上传 | 基于partNumber去重 | 上传前检查partETags中是否已存在该分片的ETag |
| 合并完成 | 基于uploadId幂等 | 上传状态为COMPLETED时直接返回已有结果 |
| 断点续传 | 基于checkpoint恢复 | 持久化每个分片的完成状态，重启后跳过已完成分片 |

### 7.2 案例二：图片上传与CDN分发全链路

#### 7.2.1 场景描述

在电商、社交类业务中，用户上传的图片需要经过格式校验、压缩裁剪处理后存入OSS，再通过CDN缓存预热实现就近访问。本案例实现完整的图片上传与CDN分发链路：图片上传 -> 格式校验 -> 压缩/裁剪 -> 存入OSS -> CDN缓存预热 -> 访问URL生成。

```
全链路流程：

客户端                  应用服务器                     图片处理              OSS              CDN              数据库
  │                      │                           │                   │                │                │
  │ 1.上传图片 ───────────▶│                           │                   │                │                │
  │  (文件流+业务参数)      │ 2.幂等校验(图片MD5) ────────────────────────────────────────────────────────────────▶│
  │                      │                           │                   │                │                │ 查重
  │                      │ 3.格式校验                  │                   │                │                │
  │                      │  (类型/大小/尺寸/安全扫描)   │                   │                │                │
  │                      │                           │                   │                │                │
  │                      │ 4.图片处理请求 ──────────────▶│                   │                │                │
```

#### 7.2.2 核心实现

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import javax.imageio.ImageIO;
import java.awt.*;
import java.awt.image.BufferedImage;
import java.io.*;
import java.security.MessageDigest;
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.util.*;
import java.util.List;
import java.util.concurrent.*;

/**
 * 图片上传与CDN分发全链路服务
 * 负责图片校验、处理、存储、CDN预热和URL生成的完整流程
 */
public class ImageUploadCdnService {

    private static final Logger logger = LoggerFactory.getLogger(ImageUploadCdnService.class);

    /** 允许的图片格式 */
    private static final Set<String> ALLOWED_FORMATS = Set.of("jpg", "jpeg", "png", "gif", "webp", "bmp");
    /** 最大图片大小：20MB */
    private static final long MAX_IMAGE_SIZE = 20 * 1024 * 1024L;
    /** 最大图片尺寸：10000x10000 */
    private static final int MAX_DIMENSION = 10000;
    /** 压缩质量：0.85 */
    private static final float COMPRESS_QUALITY = 0.85f;
    /** CDN预热超时：30秒 */
    private static final int CDN_PREHEAT_TIMEOUT_SECONDS = 30;

    /** 多尺寸裁剪规格 */
    private static final Map<String, int[]> RESIZE_SPECS = Map.of(
        "large",     new int[]{1080, 1080},
        "medium",    new int[]{540, 540},
        "thumbnail", new int[]{200, 200}
    );

    private final OssClient ossClient;
    private final CdnClient cdnClient;
    private final ImageRecordRepository imageRecordRepository;
    private final String cdnDomain;
    private final String bucketName;

    public ImageUploadCdnService(OssClient ossClient, CdnClient cdnClient,
                                  ImageRecordRepository imageRecordRepository,
                                  String cdnDomain, String bucketName) {
        this.ossClient = ossClient;
        this.cdnClient = cdnClient;
        this.imageRecordRepository = imageRecordRepository;
        this.cdnDomain = cdnDomain;
        this.bucketName = bucketName;
    }

    /**
     * 图片上传全链路入口
     *
     * @param imageData    图片原始数据
     * @param fileName     原始文件名
     * @param businessType 业务类型（如 user-avatar, product-image）
     * @return 上传结果（含各尺寸CDN URL）
     */
    public ImageUploadResult uploadImage(byte[] imageData, String fileName, 
                                          String businessType) {
        String imageMd5 = calculateMd5(imageData);
        String idempotentKey = businessType + ":" + imageMd5;
        logger.info("[图片上传] 开始处理, fileName={}, size={}, businessType={}, md5={}",
                fileName, imageData.length, businessType, imageMd5);

        try {
            // 1. 幂等校验：基于图片内容MD5检查是否已上传
            ImageRecord existingRecord = imageRecordRepository.findByIdempotentKey(idempotentKey);
            if (existingRecord != null) {
                logger.info("[图片上传] 图片已存在(幂等命中), md5={}, url={}", 
                        imageMd5, existingRecord.getCdnUrl());
                return buildResultFromRecord(existingRecord);
            }

            // 2. 格式校验
            ImageValidationResult validation = validateImage(imageData, fileName);
            logger.info("[图片上传] 格式校验通过, format={}, width={}, height={}",
                    validation.getFormat(), validation.getWidth(), validation.getHeight());

            // 3. 图片处理（压缩 + 多尺寸裁剪 + WebP转换）
            Map<String, ProcessedImage> processedImages = processImage(
                    imageData, validation.getFormat(), validation.getBufferedImage());
            logger.info("[图片上传] 图片处理完成, 生成{}个尺寸版本", processedImages.size());

            // 4. 上传原图和所有处理后的图片到OSS
            String basePath = generateObjectKeyBase(businessType, imageMd5);
            Map<String, String> ossKeys = uploadToOss(basePath, imageData, 
                    fileName, processedImages);
            logger.info("[图片上传] OSS上传完成, 共{}个文件", ossKeys.size());

            // 5. CDN缓存预热
            List<String> cdnUrls = preheatCdn(ossKeys);
            logger.info("[图片上传] CDN预热完成, 预热{}个URL", cdnUrls.size());

            // 6. 生成访问URL并保存记录
            ImageRecord record = saveImageRecord(
                    idempotentKey, imageMd5, fileName, businessType,
                    imageData.length, validation, ossKeys, cdnUrls);

            ImageUploadResult result = buildResultFromRecord(record);
            logger.info("[图片上传] 上传完成, md5={}, cdnUrl={}", imageMd5, result.getCdnUrl());
            return result;

        } catch (ImageValidationException e) {
            logger.warn("[图片上传] 图片校验失败, fileName={}, reason={}", 
                    fileName, e.getMessage());
            throw e;
        } catch (Exception e) {
            logger.error("[图片上传] 上传处理失败, fileName={}, md5={}, error={}",
                    fileName, imageMd5, e.getMessage(), e);
            throw new ImageUploadException("图片上传失败: " + e.getMessage(), e);
        }
    }

    /**
     * 图片格式校验
     * 包括：文件类型、文件大小、图片尺寸、文件头魔数校验
     */
    private ImageValidationResult validateImage(byte[] imageData, String fileName) {
        // 1. 文件大小校验
        if (imageData == null || imageData.length == 0) {
            throw new ImageValidationException("图片数据为空");
        }
        if (imageData.length > MAX_IMAGE_SIZE) {
            throw new ImageValidationException(
                String.format("图片大小超出限制: %dMB, 最大允许: %dMB",
                    imageData.length / 1024 / 1024, MAX_IMAGE_SIZE / 1024 / 1024));
        }

        // 2. 文件扩展名校验
        String extension = getFileExtension(fileName).toLowerCase();
        if (!ALLOWED_FORMATS.contains(extension)) {
            throw new ImageValidationException(
                "不支持的图片格式: " + extension + ", 支持: " + ALLOWED_FORMATS);
        }

        // 3. 文件头魔数校验（防止伪装文件扩展名的攻击）
        String actualFormat = detectImageFormat(imageData);
        if (actualFormat == null) {
            throw new ImageValidationException("无法识别的图片格式, 文件头不合法");
        }
        logger.debug("[图片上传] 文件头检测格式: {}, 扩展名格式: {}", actualFormat, extension);

        // 4. 读取图片并校验尺寸
        BufferedImage bufferedImage;
        try {
            bufferedImage = ImageIO.read(new ByteArrayInputStream(imageData));
        } catch (IOException e) {
            throw new ImageValidationException("图片数据损坏, 无法解析: " + e.getMessage());
        }
        if (bufferedImage == null) {
            throw new ImageValidationException("图片数据损坏, 无法解码");
        }

        int width = bufferedImage.getWidth();
        int height = bufferedImage.getHeight();
        if (width > MAX_DIMENSION || height > MAX_DIMENSION) {
            throw new ImageValidationException(
                String.format("图片尺寸超出限制: %dx%d, 最大允许: %dx%d",
                    width, height, MAX_DIMENSION, MAX_DIMENSION));
        }

        ImageValidationResult result = new ImageValidationResult();
        result.setFormat(actualFormat);
        result.setWidth(width);
        result.setHeight(height);
        result.setBufferedImage(bufferedImage);
        return result;
    }

    /**
     * 检测图片文件头魔数，识别真实格式
     */
    private String detectImageFormat(byte[] data) {
        if (data.length < 4) return null;
        // JPEG: FF D8 FF
        if (data[0] == (byte) 0xFF && data[1] == (byte) 0xD8 && data[2] == (byte) 0xFF) {
            return "jpeg";
        }
        // PNG: 89 50 4E 47
        if (data[0] == (byte) 0x89 && data[1] == (byte) 0x50 
                && data[2] == (byte) 0x4E && data[3] == (byte) 0x47) {
            return "png";
        }
        // GIF: 47 49 46
        if (data[0] == (byte) 0x47 && data[1] == (byte) 0x49 && data[2] == (byte) 0x46) {
            return "gif";
        }
        // BMP: 42 4D
        if (data[0] == (byte) 0x42 && data[1] == (byte) 0x4D) {
            return "bmp";
        }
        // WebP: 52 49 46 46 ... 57 45 42 50
        if (data.length >= 12 && data[0] == (byte) 0x52 && data[1] == (byte) 0x49
                && data[2] == (byte) 0x46 && data[3] == (byte) 0x46
                && data[8] == (byte) 0x57 && data[9] == (byte) 0x45
                && data[10] == (byte) 0x42 && data[11] == (byte) 0x50) {
            return "webp";
        }
        return null;
    }

    /**
     * 图片处理：压缩 + 多尺寸裁剪
     * 生成多个尺寸版本，每个版本同时生成原格式和WebP格式
     */
    private Map<String, ProcessedImage> processImage(byte[] originalData, 
                                                       String format,
                                                       BufferedImage originalImage) {
        Map<String, ProcessedImage> results = new LinkedHashMap<>();

        for (Map.Entry<String, int[]> spec : RESIZE_SPECS.entrySet()) {
            String sizeName = spec.getKey();
            int targetWidth = spec.getValue()[0];
            int targetHeight = spec.getValue()[1];

            try {
                // 等比例缩放
                BufferedImage resized = resizeImage(originalImage, targetWidth, targetHeight);

                // 压缩为JPEG
                byte[] compressedJpeg = compressToJpeg(resized, COMPRESS_QUALITY);
                results.put(sizeName + ".jpg", new ProcessedImage(compressedJpeg, "image/jpeg"));

                // 转换为WebP（体积更小，节省CDN带宽）
                byte[] webpData = convertToWebP(resized);
                if (webpData != null) {
                    results.put(sizeName + ".webp", new ProcessedImage(webpData, "image/webp"));
                }

                logger.debug("[图片处理] 尺寸={}, 原始={}KB, JPEG={}KB, WebP={}KB",
                        sizeName, originalData.length / 1024,
                        compressedJpeg.length / 1024,
                        webpData != null ? webpData.length / 1024 : "N/A");

            } catch (Exception e) {
                logger.warn("[图片处理] 处理{}尺寸失败, 跳过, error={}", sizeName, e.getMessage());
            }
        }

        return results;
    }

    /**
     * 等比例缩放图片
     */
    private BufferedImage resizeImage(BufferedImage original, 
                                       int maxWidth, int maxHeight) {
        int origWidth = original.getWidth();
        int origHeight = original.getHeight();

        // 如果原图已经小于目标尺寸，不进行放大
        if (origWidth <= maxWidth && origHeight <= maxHeight) {
            return original;
        }

        double ratio = Math.min((double) maxWidth / origWidth, 
                                 (double) maxHeight / origHeight);
        int newWidth = (int) (origWidth * ratio);
        int newHeight = (int) (origHeight * ratio);

        BufferedImage resized = new BufferedImage(newWidth, newHeight, 
                BufferedImage.TYPE_INT_RGB);
        Graphics2D g2d = resized.createGraphics();
        g2d.setRenderingHint(RenderingHints.KEY_INTERPOLATION, 
                RenderingHints.VALUE_INTERPOLATION_BICUBIC);
        g2d.drawImage(original, 0, 0, newWidth, newHeight, null);
        g2d.dispose();
        return resized;
    }

    /**
     * 压缩为JPEG格式
     */
    private byte[] compressToJpeg(BufferedImage image, float quality) throws IOException {
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        javax.imageio.plugins.jpeg.JPEGImageWriteParam param = 
                new javax.imageio.plugins.jpeg.JPEGImageWriteParam(null);
        param.setCompressionMode(javax.imageio.ImageWriteParam.MODE_EXPLICIT);
        param.setCompressionQuality(quality);

        javax.imageio.ImageWriter writer = ImageIO.getImageWritersByFormatName("jpeg").next();
        writer.setOutput(ImageIO.createImageOutputStream(baos));
        writer.write(null, new javax.imageio.IIOImage(image, null, null), param);
        writer.dispose();
        return baos.toByteArray();
    }

    /**
     * 转换为WebP格式（调用外部图片处理库）
     */
    private byte[] convertToWebP(BufferedImage image) {
        try {
            ByteArrayOutputStream baos = new ByteArrayOutputStream();
            // 使用 webp-imageio 或其他 WebP 编码库
            boolean success = ImageIO.write(image, "webp", baos);
            return success ? baos.toByteArray() : null;
        } catch (Exception e) {
            logger.debug("[图片处理] WebP转换不可用: {}", e.getMessage());
            return null;
        }
    }

    /**
     * 上传原图和所有处理后的图片到OSS
     *
     * @return 各版本的OSS Key映射
     */
    private Map<String, String> uploadToOss(String basePath, byte[] originalData,
                                              String fileName,
                                              Map<String, ProcessedImage> processedImages) {
        Map<String, String> ossKeys = new LinkedHashMap<>();

        // 上传原图
        String originalKey = basePath + "/original." + getFileExtension(fileName);
        ossClient.putObject(bucketName, originalKey, originalData, 
                detectContentType(fileName));
        ossKeys.put("original", originalKey);
        logger.debug("[图片上传] 原图上传完成, key={}", originalKey);

        // 上传各处理版本
        for (Map.Entry<String, ProcessedImage> entry : processedImages.entrySet()) {
            String versionKey = basePath + "/" + entry.getKey();
            ProcessedImage processed = entry.getValue();
            try {
                ossClient.putObject(bucketName, versionKey, 
                        processed.getData(), processed.getContentType());
                ossKeys.put(entry.getKey(), versionKey);
                logger.debug("[图片上传] 处理图上传完成, key={}", versionKey);
            } catch (Exception e) {
                logger.warn("[图片上传] 处理图上传失败, key={}, error={}", 
                        versionKey, e.getMessage());
                // 处理图上传失败不影响整体流程
            }
        }

        return ossKeys;
    }

    /**
     * CDN缓存预热
     * 将热点图片主动推送到CDN边缘节点，用户首次访问即可命中CDN缓存
     */
    private List<String> preheatCdn(Map<String, String> ossKeys) {
        List<String> cdnUrls = new ArrayList<>();

        for (Map.Entry<String, String> entry : ossKeys.entrySet()) {
            String cdnUrl = "https://" + cdnDomain + "/" + entry.getValue();
            cdnUrls.add(cdnUrl);
        }

        try {
            // 批量提交CDN预热任务
            String taskId = cdnClient.submitPreheatTask(cdnUrls);
            logger.info("[CDN预热] 预热任务已提交, taskId={}, urlCount={}", 
                    taskId, cdnUrls.size());

            // 异步等待预热完成（非阻塞，不影响返回结果）
            CompletableFuture.runAsync(() -> {
                try {
                    waitForPreheatComplete(taskId);
                } catch (Exception e) {
                    logger.warn("[CDN预热] 预热等待超时, taskId={}", taskId);
                }
            });

        } catch (Exception e) {
            // CDN预热失败不阻塞上传流程，用户访问时会触发回源
            logger.warn("[CDN预热] 预热提交失败, error={}, URL仍可通过回源访问", 
                    e.getMessage());
        }

        return cdnUrls;
    }

    /**
     * 等待CDN预热完成
     */
    private void waitForPreheatComplete(String taskId) {
        long startTime = System.currentTimeMillis();
        while (System.currentTimeMillis() - startTime < CDN_PREHEAT_TIMEOUT_SECONDS * 1000L) {
            CdnTaskStatus status = cdnClient.queryPreheatTask(taskId);
            if (status == CdnTaskStatus.COMPLETED) {
                logger.info("[CDN预热] 预热完成, taskId={}", taskId);
                return;
            }
            if (status == CdnTaskStatus.FAILED) {
                logger.warn("[CDN预热] 预热失败, taskId={}", taskId);
                return;
            }
            try {
                Thread.sleep(2000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                return;
            }
        }
    }

    /**
     * 生成对象Key的基础路径
     * 格式: {businessType}/{date}/{md5前4位散列}/{md5}
     */
    private String generateObjectKeyBase(String businessType, String imageMd5) {
        String date = LocalDate.now().format(DateTimeFormatter.ofPattern("yyyy/MM/dd"));
        String hashPrefix = imageMd5.substring(0, 4);
        return String.join("/", businessType, date, hashPrefix, imageMd5);
    }

    /**
     * 保存图片记录到数据库
     */
    private ImageRecord saveImageRecord(String idempotentKey, String imageMd5,
                                          String fileName, String businessType,
                                          int fileSize,
                                          ImageValidationResult validation,
                                          Map<String, String> ossKeys,
                                          List<String> cdnUrls) {
        ImageRecord record = new ImageRecord();
        record.setIdempotentKey(idempotentKey);
        record.setImageMd5(imageMd5);
        record.setOriginalFileName(fileName);
        record.setBusinessType(businessType);
        record.setFileSize(fileSize);
        record.setWidth(validation.getWidth());
        record.setHeight(validation.getHeight());
        record.setFormat(validation.getFormat());
        record.setOssKeys(JsonUtils.toJson(ossKeys));
        record.setCdnUrl(cdnUrls.isEmpty() ? null : cdnUrls.get(0));
        record.setCdnUrls(JsonUtils.toJson(cdnUrls));
        record.setCreateTime(System.currentTimeMillis());

        // 幂等写入：INSERT IGNORE避免并发重复插入
        imageRecordRepository.insertIgnore(record);
        return record;
    }

    private ImageUploadResult buildResultFromRecord(ImageRecord record) {
        ImageUploadResult result = new ImageUploadResult();
        result.setImageId(record.getImageMd5());
        result.setCdnUrl(record.getCdnUrl());
        result.setCdnUrls(JsonUtils.fromJsonToMap(record.getCdnUrls()));
        result.setWidth(record.getWidth());
        result.setHeight(record.getHeight());
        result.setFormat(record.getFormat());
        return result;
    }

    private String getFileExtension(String fileName) {
        int lastDot = fileName.lastIndexOf('.');
        return lastDot > 0 ? fileName.substring(lastDot + 1) : "";
    }

    private String detectContentType(String fileName) {
        String ext = getFileExtension(fileName).toLowerCase();
        return switch (ext) {
            case "jpg", "jpeg" -> "image/jpeg";
            case "png" -> "image/png";
            case "gif" -> "image/gif";
            case "webp" -> "image/webp";
            case "bmp" -> "image/bmp";
            default -> "application/octet-stream";
        };
    }

    private String calculateMd5(byte[] data) {
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(data);
            StringBuilder sb = new StringBuilder();
            for (byte b : digest) {
                sb.append(String.format("%02x", b));
            }
            return sb.toString();
        } catch (Exception e) {
            throw new RuntimeException("MD5 calculation failed", e);
        }
    }
}

public class ProcessedImage {

    private final String contentType;

    public ProcessedImage(byte[] data, String contentType) {
        this.data = data;

/**
 * 图片记录持久化仓储

public class ImageRecordRepository {

    private static final Logger logger = LoggerFactory.getLogger(ImageRecordRepository.class);

    private final JdbcTemplate jdbcTemplate;

    public ImageRecordRepository(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    /**
     * 基于幂等键查询图片记录
     */
    public ImageRecord findByIdempotentKey(String idempotentKey) {
        try {
            return jdbcTemplate.queryForObject(
                "SELECT * FROM image_record WHERE idempotent_key = ?",
                new Object[]{idempotentKey},
                (rs, rowNum) -> mapToImageRecord(rs)
            );
        } catch (EmptyResultDataAccessException e) {
            return null;
        }
    }

    /**
     * 幂等插入图片记录
     * 使用INSERT IGNORE避免并发重复写入
     */
    public void insertIgnore(ImageRecord record) {
        int rows = jdbcTemplate.update(
            "INSERT IGNORE INTO image_record (idempotent_key, image_md5, " +
            "original_file_name, business_type, file_size, width, height, " +
            "format, oss_keys, cdn_url, cdn_urls, create_time) " +
            "VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)",
            record.getIdempotentKey(), record.getImageMd5(),
            record.getOriginalFileName(), record.getBusinessType(),
            record.getFileSize(), record.getWidth(), record.getHeight(),
            record.getFormat(), record.getOssKeys(), record.getCdnUrl(),
            record.getCdnUrls(), record.getCreateTime()
        );
        if (rows == 0) {
            logger.debug("[图片记录] 幂等插入跳过(已存在), idempotentKey={}", 
                    record.getIdempotentKey());
        }
    }
}
```

#### 7.2.3 幂等控制要点

| 环节 | 幂等策略 | 实现方式 |
|-----|---------|---------|
| 图片上传 | 基于内容MD5去重 | idempotentKey = businessType + ":" + MD5(imageData)，数据库唯一索引 |
| 记录写入 | INSERT IGNORE | 并发请求只有第一个写入成功，后续直接查询返回 |
| CDN预热 | 异步非阻塞 | 预热失败不影响上传结果，用户访问时自动回源 |
| 多尺寸处理 | 处理图降级 | 单个尺寸处理失败不影响其他尺寸和整体流程 |

### 7.3 案例三：文件下载与防盗链全链路

#### 7.3.1 场景描述

在内容付费、文档分发等业务中，文件下载需要严格的安全控制：请求签名防篡改、用户权限验证、防盗链校验、CDN回源以及流式下载的限速控制。本案例实现完整的文件下载与防盗链链路：下载请求 -> 签名校验 -> 权限验证 -> CDN回源 -> 流式下载 -> 限速控制。

```
全链路流程：

客户端                     CDN边缘节点                  应用服务器                   OSS              数据库
  │                         │                          │                          │                │
  │ 1.请求下载(带签名URL) ───▶│                          │                          │                │
  │                         │ 2.检查CDN缓存              │                          │                │
  │                         │                          │                          │                │
  │                         │ [缓存命中]                 │                          │                │
  │                         │ 3a.校验签名+Referer ──┐    │                          │                │
  │ 4a.流式返回(限速) ◀───────│ ◀─────────────────────┘    │                          │                │
  │                         │                          │                          │                │
  │                         │ [缓存未命中/首次访问]        │                          │                │
  │                         │ 3b.回源请求 ─────────────▶│                          │                │
  │                         │                          │ 4b.签名校验               │                │
  │                         │                          │  (时间戳+密钥+参数签名)     │                │
  │                         │                          │ 5b.权限验证 ─────────────────────────────────▶│
  │                         │                          │                          │                │ 查询权限
  │                         │                          │ 6b.权限确认 ◀─────────────────────────────────│
  │                         │                          │                          │                │
  │                         │                          │ 7b.记录下载日志(幂等)       │                │
  │                         │                          │                          │                │
  │                         │                          │ 8b.从OSS获取文件 ──────────▶│                │
  │                         │                          │ 9b.流式数据 ◀──────────────│                │
  │                         │ 10b.回源响应 ◀────────────│                          │                │
  │                         │                          │                          │                │
  │                         │ 11b.缓存文件               │                          │                │
  │ 12b.流式返回(限速) ◀──────│                          │                          │                │
```

#### 7.3.2 核心实现

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import java.io.*;
import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.util.*;
import java.util.concurrent.TimeUnit;

/**
 * 文件下载与防盗链全链路服务
 * 负责签名校验、权限验证、CDN回源、流式下载和限速控制的完整流程
 */
public class FileDownloadService {

    private static final Logger logger = LoggerFactory.getLogger(FileDownloadService.class);

    /** 签名有效期：默认1小时 */
    private static final long DEFAULT_SIGN_EXPIRE_SECONDS = 3600;
    /** 签名密钥 */
    private final String signSecret;
    /** 默认下载限速：1MB/s */
    private static final long DEFAULT_RATE_LIMIT_BYTES = 1024 * 1024L;
    /** 流式传输缓冲区大小：64KB */
    private static final int STREAM_BUFFER_SIZE = 64 * 1024;
    /** 下载日志幂等窗口：5分钟内同一用户同一文件只记录一次 */
    private static final long LOG_IDEMPOTENT_WINDOW_MS = 5 * 60 * 1000L;

    /** 允许的Referer域名白名单 */
    private final Set<String> refererWhitelist;

    private final OssClient ossClient;
    private final FilePermissionService permissionService;
    private final DownloadLogRepository downloadLogRepository;
    private final String cdnDomain;
    private final String bucketName;

    public FileDownloadService(OssClient ossClient,
                                FilePermissionService permissionService,
                                DownloadLogRepository downloadLogRepository,
                                String signSecret, String cdnDomain, 
                                String bucketName,
                                Set<String> refererWhitelist) {
        this.ossClient = ossClient;
        this.permissionService = permissionService;
        this.downloadLogRepository = downloadLogRepository;
        this.signSecret = signSecret;
        this.cdnDomain = cdnDomain;
        this.bucketName = bucketName;
        this.refererWhitelist = refererWhitelist;
    }

    // ==================== 签名URL生成 ====================

    /**
     * 生成带签名的下载URL
     * URL格式: https://{cdnDomain}/{objectKey}?sign={签名}&ts={时间戳}&uid={用户ID}&nonce={随机数}
     *
     * @param objectKey     文件对象Key
     * @param userId        用户ID
     * @param expireSeconds 有效期（秒），传0使用默认值
     * @param rateLimit     限速（字节/秒），传0使用默认值
     * @return 签名下载URL
     */
    public String generateSignedDownloadUrl(String objectKey, String userId,
                                              long expireSeconds, long rateLimit) {
        if (expireSeconds <= 0) {
            expireSeconds = DEFAULT_SIGN_EXPIRE_SECONDS;
        }
        if (rateLimit <= 0) {
            rateLimit = DEFAULT_RATE_LIMIT_BYTES;
        }

        long timestamp = System.currentTimeMillis() / 1000 + expireSeconds;
        String nonce = UUID.randomUUID().toString().replace("-", "").substring(0, 16);

        // 构造签名参数（按字典序排列，防止参数顺序不同导致签名不一致）
        TreeMap<String, String> signParams = new TreeMap<>();
        signParams.put("key", objectKey);
        signParams.put("ts", String.valueOf(timestamp));
        signParams.put("uid", userId);
        signParams.put("nonce", nonce);
        signParams.put("rate", String.valueOf(rateLimit));

        String signature = calculateSignature(signParams);

        String url = String.format(
            "https://%s/%s?sign=%s&ts=%d&uid=%s&nonce=%s&rate=%d",
            cdnDomain, objectKey,
            URLEncoder.encode(signature, StandardCharsets.UTF_8),
            timestamp, userId, nonce, rateLimit
        );

        logger.info("[下载签名] 生成签名URL, objectKey={}, userId={}, expireSeconds={}, " +
                "rateLimit={}KB/s",
                objectKey, userId, expireSeconds, rateLimit / 1024);
        return url;
    }

    /**
     * 计算请求签名
     * 使用HMAC-SHA256算法，将所有参数按字典序拼接后签名
     */
    private String calculateSignature(TreeMap<String, String> params) {
        StringBuilder sb = new StringBuilder();
        for (Map.Entry<String, String> entry : params.entrySet()) {
            if (sb.length() > 0) {
                sb.append("&");
            }
            sb.append(entry.getKey()).append("=").append(entry.getValue());
        }

        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(
                    signSecret.getBytes(StandardCharsets.UTF_8), "HmacSHA256"));
            byte[] hmac = mac.doFinal(sb.toString().getBytes(StandardCharsets.UTF_8));
            StringBuilder hex = new StringBuilder();
            for (byte b : hmac) {
                hex.append(String.format("%02x", b));
            }
            return hex.toString();
        } catch (Exception e) {
            throw new RuntimeException("Signature calculation failed", e);
        }
    }

    // ==================== 下载请求处理（应用服务器/CDN回源） ====================

    /**
     * 处理文件下载请求（CDN回源或直接下载）
     * 完整流程：签名校验 -> Referer防盗链 -> 权限验证 -> 流式下载 -> 限速控制
     */
    public void handleDownloadRequest(HttpServletRequest request,
                                        HttpServletResponse response) {
        String objectKey = extractObjectKey(request);
        String requestId = UUID.randomUUID().toString().substring(0, 8);
        logger.info("[文件下载] 收到下载请求, requestId={}, objectKey={}, clientIP={}",
                requestId, objectKey, getClientIp(request));

        try {
            // 1. 签名校验
            validateSignature(request, objectKey);
            logger.debug("[文件下载] 签名校验通过, requestId={}", requestId);

            // 2. Referer防盗链校验
            validateReferer(request);
            logger.debug("[文件下载] Referer校验通过, requestId={}", requestId);

            // 3. 用户权限验证
            String userId = request.getParameter("uid");
            validatePermission(userId, objectKey);
            logger.debug("[文件下载] 权限验证通过, requestId={}, userId={}", 
                    requestId, userId);

            // 4. 记录下载日志（幂等控制：短时间内重复下载只记录一次）
            recordDownloadLog(userId, objectKey, getClientIp(request), requestId);

            // 5. 获取限速参数
            long rateLimit = parseRateLimit(request.getParameter("rate"));

            // 6. 流式下载文件（带限速）
            streamDownload(objectKey, rateLimit, request, response, requestId);

        } catch (SignatureException e) {
            logger.warn("[文件下载] 签名校验失败, requestId={}, objectKey={}, reason={}",
                    requestId, objectKey, e.getMessage());
            sendError(response, 403, "签名无效或已过期");
        } catch (RefererDeniedException e) {
            logger.warn("[文件下载] 防盗链拦截, requestId={}, objectKey={}, referer={}",
                    requestId, objectKey, e.getReferer());
            sendError(response, 403, "非法来源");
        } catch (PermissionDeniedException e) {
            logger.warn("[文件下载] 权限不足, requestId={}, objectKey={}, userId={}",
                    requestId, objectKey, e.getUserId());
            sendError(response, 403, "无权访问该文件");
        } catch (FileNotFoundException e) {
            logger.warn("[文件下载] 文件不存在, requestId={}, objectKey={}", 
                    requestId, objectKey);
            sendError(response, 404, "文件不存在");
        } catch (Exception e) {
            logger.error("[文件下载] 下载失败, requestId={}, objectKey={}, error={}",
                    requestId, objectKey, e.getMessage(), e);
            sendError(response, 500, "下载失败");
        }
    }

    /**
     * 签名校验
     * 校验内容：签名完整性 + 时间戳未过期 + 参数未被篡改
     */
    private void validateSignature(HttpServletRequest request, String objectKey) {
        String sign = request.getParameter("sign");
        String tsStr = request.getParameter("ts");
        String userId = request.getParameter("uid");
        String nonce = request.getParameter("nonce");
        String rate = request.getParameter("rate");

        // 参数完整性校验
        if (sign == null || tsStr == null || userId == null || nonce == null) {
            throw new SignatureException("签名参数不完整");
        }

        // 时间戳校验（是否过期）
        long timestamp;
        try {
            timestamp = Long.parseLong(tsStr);
        } catch (NumberFormatException e) {
            throw new SignatureException("时间戳格式无效");
        }
        long currentTime = System.currentTimeMillis() / 1000;
        if (currentTime > timestamp) {
            throw new SignatureException(
                String.format("签名已过期, ts=%d, now=%d, 过期%d秒",
                    timestamp, currentTime, currentTime - timestamp));
        }

        // 重新计算签名，与请求中的签名比对
        TreeMap<String, String> signParams = new TreeMap<>();
        signParams.put("key", objectKey);
        signParams.put("ts", tsStr);
        signParams.put("uid", userId);
        signParams.put("nonce", nonce);
        if (rate != null) {
            signParams.put("rate", rate);
        }

        String expectedSign = calculateSignature(signParams);
        if (!MessageDigest.isEqual(
                sign.getBytes(StandardCharsets.UTF_8),
                expectedSign.getBytes(StandardCharsets.UTF_8))) {
            throw new SignatureException("签名不匹配");
        }
    }

    /**
     * Referer防盗链校验
     * 校验请求的Referer头是否在白名单内
     */
    private void validateReferer(HttpServletRequest request) {
        String referer = request.getHeader("Referer");

        // 允许空Referer（直接在浏览器地址栏输入URL的场景）
        if (referer == null || referer.isEmpty()) {
            return;
        }

        // 提取Referer中的域名
        String refererHost;
        try {
            java.net.URL refererUrl = new java.net.URL(referer);
            refererHost = refererUrl.getHost().toLowerCase();
        } catch (Exception e) {
            throw new RefererDeniedException(referer, "Referer格式无效");
        }

        // 检查是否在白名单中（支持泛域名匹配）
        boolean allowed = false;
        for (String whiteHost : refererWhitelist) {
            if (whiteHost.startsWith("*.")) {
                // 泛域名匹配：*.example.com 匹配 a.example.com, b.c.example.com
                String suffix = whiteHost.substring(1); // .example.com
                if (refererHost.endsWith(suffix) || 
                        refererHost.equals(whiteHost.substring(2))) {
                    allowed = true;
                    break;
                }
            } else {
                if (refererHost.equals(whiteHost)) {
                    allowed = true;
                    break;
                }
            }
        }

        if (!allowed) {
            throw new RefererDeniedException(referer, 
                "Referer不在白名单中: " + refererHost);
        }
    }

    /**
     * 用户权限验证
     * 查询数据库校验用户是否有下载该文件的权限
     */
    private void validatePermission(String userId, String objectKey) {
        if (userId == null || userId.isEmpty()) {
            throw new PermissionDeniedException(userId, "用户ID为空");
        }

        FilePermission permission = permissionService.queryPermission(userId, objectKey);
        if (permission == null) {
            throw new PermissionDeniedException(userId, 
                "用户无该文件的下载权限: " + objectKey);
        }

        // 校验权限是否过期
        if (permission.getExpireTime() > 0 
                && System.currentTimeMillis() > permission.getExpireTime()) {
            throw new PermissionDeniedException(userId, 
                "文件下载权限已过期: " + objectKey);
        }

        // 校验下载次数限制
        if (permission.getMaxDownloads() > 0) {
            long downloadCount = downloadLogRepository.countByUserAndFile(userId, objectKey);
            if (downloadCount >= permission.getMaxDownloads()) {
                throw new PermissionDeniedException(userId,
                    String.format("已达到最大下载次数: %d/%d", 
                        downloadCount, permission.getMaxDownloads()));
            }
        }
    }

    /**
     * 记录下载日志（幂等控制）
     * 使用时间窗口去重：同一用户在5分钟内重复下载同一文件只记录一次
     */
    private void recordDownloadLog(String userId, String objectKey, 
                                     String clientIp, String requestId) {
        // 生成幂等键：userId + objectKey + 时间窗口
        long timeWindow = System.currentTimeMillis() / LOG_IDEMPOTENT_WINDOW_MS;
        String idempotentKey = String.format("%s:%s:%d", userId, objectKey, timeWindow);

        try {
            boolean inserted = downloadLogRepository.insertIfAbsent(
                idempotentKey, userId, objectKey, clientIp, requestId,
                System.currentTimeMillis()
            );
            if (inserted) {
                logger.info("[下载日志] 记录下载, userId={}, objectKey={}, clientIp={}",
                        userId, objectKey, clientIp);
            } else {
                logger.debug("[下载日志] 幂等去重, 跳过重复记录, userId={}, objectKey={}",
                        userId, objectKey);
            }
        } catch (Exception e) {
            // 日志记录失败不影响下载流程
            logger.warn("[下载日志] 记录失败, userId={}, objectKey={}, error={}",
                    userId, objectKey, e.getMessage());
        }
    }

    /**
     * 流式下载文件（带限速控制）
     * 从OSS获取文件流，以限速方式写入HTTP响应
     */
    private void streamDownload(String objectKey, long rateLimitBytesPerSec,
                                  HttpServletRequest request,
                                  HttpServletResponse response,
                                  String requestId) throws Exception {
        // 获取文件元数据
        ObjectMetadata metadata = ossClient.getObjectMetadata(bucketName, objectKey);
        if (metadata == null) {
            throw new FileNotFoundException("文件不存在: " + objectKey);
        }

        long fileSize = metadata.getContentLength();
        String contentType = metadata.getContentType();
        String fileName = extractFileName(objectKey);

        // 处理Range请求（支持断点续下载）
        long rangeStart = 0;
        long rangeEnd = fileSize - 1;
        boolean isRangeRequest = false;

        String rangeHeader = request.getHeader("Range");
        if (rangeHeader != null && rangeHeader.startsWith("bytes=")) {
            isRangeRequest = true;
            String[] ranges = rangeHeader.substring(6).split("-");
            rangeStart = Long.parseLong(ranges[0]);
            if (ranges.length > 1 && !ranges[1].isEmpty()) {
                rangeEnd = Long.parseLong(ranges[1]);
            }

            // 校验Range合法性
            if (rangeStart > rangeEnd || rangeStart >= fileSize) {
                response.setStatus(416); // Range Not Satisfiable
                response.setHeader("Content-Range", "bytes */" + fileSize);
                return;
            }
            rangeEnd = Math.min(rangeEnd, fileSize - 1);
        }

        long contentLength = rangeEnd - rangeStart + 1;

        // 设置响应头
        if (isRangeRequest) {
            response.setStatus(206); // Partial Content
            response.setHeader("Content-Range",
                String.format("bytes %d-%d/%d", rangeStart, rangeEnd, fileSize));
        } else {
            response.setStatus(200);
        }
        response.setContentType(contentType != null ? contentType : "application/octet-stream");
        response.setHeader("Content-Length", String.valueOf(contentLength));
        response.setHeader("Content-Disposition",
            "attachment; filename=\"" + 
            URLEncoder.encode(fileName, StandardCharsets.UTF_8) + "\"");
        response.setHeader("Accept-Ranges", "bytes");
        response.setHeader("ETag", "\"" + metadata.getETag() + "\"");
        response.setHeader("Cache-Control", "private, max-age=3600");

        logger.info("[文件下载] 开始流式传输, requestId={}, objectKey={}, " +
                "fileSize={}, range={}-{}, rateLimit={}KB/s",
                requestId, objectKey, fileSize, rangeStart, rangeEnd,
                rateLimitBytesPerSec / 1024);

        // 从OSS获取文件流并写入响应（带限速）
        try (InputStream ossStream = ossClient.getObject(
                bucketName, objectKey, rangeStart, rangeEnd);
             OutputStream responseOutput = response.getOutputStream()) {

            throttledTransfer(ossStream, responseOutput, 
                    contentLength, rateLimitBytesPerSec, requestId);
        }

        logger.info("[文件下载] 传输完成, requestId={}, objectKey={}, 传输字节={}",
                requestId, objectKey, contentLength);
    }

    /**
     * 限速流式传输
     * 使用令牌桶算法控制传输速率，避免单个下载请求占满带宽
     *
     * @param input        输入流（OSS文件流）
     * @param output       输出流（HTTP响应流）
     * @param totalBytes   需要传输的总字节数
     * @param rateLimitBps 限速（字节/秒）
     * @param requestId    请求ID（用于日志追踪）
     */
    private void throttledTransfer(InputStream input, OutputStream output,
                                     long totalBytes, long rateLimitBps,
                                     String requestId) throws IOException {
        byte[] buffer = new byte[STREAM_BUFFER_SIZE];
        long transferred = 0;
        long startTimeNanos = System.nanoTime();

        while (transferred < totalBytes) {
            int toRead = (int) Math.min(buffer.length, totalBytes - transferred);
            int bytesRead = input.read(buffer, 0, toRead);
            if (bytesRead == -1) {
                break;
            }

            output.write(buffer, 0, bytesRead);
            output.flush();
            transferred += bytesRead;

            // 令牌桶限速：计算应该消耗的时间 vs 实际消耗的时间
            long expectedTimeNanos = (transferred * 1_000_000_000L) / rateLimitBps;
            long actualTimeNanos = System.nanoTime() - startTimeNanos;
            long sleepNanos = expectedTimeNanos - actualTimeNanos;

            if (sleepNanos > 0) {
                try {
                    TimeUnit.NANOSECONDS.sleep(sleepNanos);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    logger.warn("[文件下载] 传输被中断, requestId={}, transferred={}/{}",
                            requestId, transferred, totalBytes);
                    throw new IOException("Download interrupted", e);
                }
            }

            // 每传输10MB输出一次进度日志
            if (transferred % (10 * 1024 * 1024) < bytesRead) {
                double progress = (double) transferred / totalBytes * 100;
                double speedKBs = transferred / 1024.0 / 
                        ((System.nanoTime() - startTimeNanos) / 1_000_000_000.0);
                logger.debug("[文件下载] 传输进度, requestId={}, progress={:.1f}%, " +
                        "speed={:.1f}KB/s",
                        requestId, progress, speedKBs);
            }
        }
    }

    // ==================== 工具方法 ====================

    private String extractObjectKey(HttpServletRequest request) {
        String path = request.getRequestURI();
        // 移除前缀（如 /download/）
        if (path.startsWith("/download/")) {
            return path.substring("/download/".length());
        }
        return path.startsWith("/") ? path.substring(1) : path;
    }

    private String extractFileName(String objectKey) {
        int lastSlash = objectKey.lastIndexOf('/');
        return lastSlash >= 0 ? objectKey.substring(lastSlash + 1) : objectKey;
    }

    private String getClientIp(HttpServletRequest request) {
        String ip = request.getHeader("X-Forwarded-For");
        if (ip != null && !ip.isEmpty()) {
            return ip.split(",")[0].trim();
        }
        ip = request.getHeader("X-Real-IP");
        if (ip != null && !ip.isEmpty()) {
            return ip;
        }
        return request.getRemoteAddr();
    }

    private long parseRateLimit(String rateStr) {
        if (rateStr == null || rateStr.isEmpty()) {
            return DEFAULT_RATE_LIMIT_BYTES;
        }
        try {
            long rate = Long.parseLong(rateStr);
            return rate > 0 ? rate : DEFAULT_RATE_LIMIT_BYTES;
        } catch (NumberFormatException e) {
            return DEFAULT_RATE_LIMIT_BYTES;
        }
    }

    private void sendError(HttpServletResponse response, int status, String message) {
        try {
            response.setStatus(status);
            response.setContentType("application/json;charset=UTF-8");
            response.getWriter().write(
                String.format("{\"code\":%d,\"message\":\"%s\"}", status, message));
        } catch (IOException e) {
            logger.warn("[文件下载] 发送错误响应失败: {}", e.getMessage());
        }
    }
}

/**
 * 下载日志持久化仓储
 */
public class DownloadLogRepository {

    private static final Logger logger = LoggerFactory.getLogger(DownloadLogRepository.class);

    private final JdbcTemplate jdbcTemplate;

    public DownloadLogRepository(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    /**
     * 幂等插入下载日志
     * 使用INSERT IGNORE + 幂等键唯一索引实现去重
     *
     * @return true表示插入成功，false表示幂等键已存在
     */
    public boolean insertIfAbsent(String idempotentKey, String userId, 
                                    String objectKey, String clientIp,
                                    String requestId, long downloadTime) {
        int rows = jdbcTemplate.update(
            "INSERT IGNORE INTO download_log " +
            "(idempotent_key, user_id, object_key, client_ip, " +
            " request_id, download_time) " +
            "VALUES (?, ?, ?, ?, ?, ?)",
            idempotentKey, userId, objectKey, clientIp, requestId, downloadTime
        );
        return rows > 0;
    }

    /**
     * 统计用户对指定文件的下载次数

    public long countByUserAndFile(String userId, String objectKey) {

            "SELECT COUNT(DISTINCT idempotent_key) FROM download_log " +
            "WHERE user_id = ? AND object_key = ?",
            Long.class, userId, objectKey
        );
        return count != null ? count : 0;
    }
```

#### 7.3.3 幂等控制要点

| 环节 | 幂等策略 | 实现方式 |
|-----|---------|---------|
| 签名URL生成 | 基于nonce防重放 | 每个签名URL包含唯一nonce，结合时间戳确保一次性 |
| 下载日志 | 时间窗口去重 | idempotentKey = userId + objectKey + 5min时间窗口，INSERT IGNORE去重 |
| 下载次数限制 | 基于去重后的日志计数 | COUNT(DISTINCT idempotent_key) 统计有效下载次数 |
| Range断点续下载 | HTTP Range头 | 支持206 Partial Content，客户端可从中断点继续下载 |
