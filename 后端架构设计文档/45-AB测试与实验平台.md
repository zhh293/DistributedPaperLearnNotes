# AB测试与实验平台

## 一、问题背景

### 1.1 业务痛点

在互联网产品迭代过程中，产品经理和算法工程师需要不断验证新策略、新功能对业务指标的影响。然而，传统的"上线后看数据"方式存在严重缺陷：

- **因果归因困难**：多个策略同时上线时，无法区分哪个策略带来了指标变化。例如，产品经理修改了首页按钮的颜色，算法工程师同时修改了推荐逻辑，最终首页点击率提升了1%，但无法判断是谁的贡献。
- **流量冲突**：多个实验同时进行时，流量分配存在冲突。如果实验A需要70%的流量，实验B需要60%的流量，总流量只有100%，无法同时满足。
- **实验干扰**：互斥的实验如果没有正确隔离，会产生交互影响。例如将按钮字体和背景都改为红色，用户看不清文字，导致下单量暴跌。
- **数据不科学**：缺乏统一的实验规范和评估标准，实验结论主观性强，无法形成可量化的因果关系。

### 1.2 AB测试的核心价值

AB测试（A/B Testing）是一种科学的产品迭代决策方法：通过随机抽样的方式抽取一部分用户，将它们分成实验组和对照组，在实验组上施加新策略，对照组保持原有策略，观察两组的指标对比来判断新策略是否有效。

其核心价值在于：
- **量化因果**：通过随机分组和控制变量，建立策略与指标之间的因果关系，而非简单相关性
- **风险控制**：在小流量上验证策略效果，避免负面策略直接全量上线造成损失
- **并行迭代**：通过分层实验架构，支持数十甚至数百个实验并行进行，加速产品迭代
- **数据驱动**：以统计显著性检验为基础，避免主观判断带来的偏差

### 1.3 实验平台的目标

实验平台旨在解决多实验并行场景下的流量管理问题，提供统一的实验配置和管理能力：

- 统一的分流模型，支持正交分层与互斥实验
- 灵活的流量配置，支持动态调整实验比例
- 完整的实验生命周期管理：创建→配置→上线→监控→评估→决策→归档
- 科学评估体系：AA校验、显著性检验、方差缩减

### 2.2 核心概念模型

实验平台的核心概念体系如下：

| 概念 | 说明 | 示例 |
|------|------|------|
| 实验(Experiment) | 一个想要进行测试的方向的集合 | 按钮改变字体颜色的实验 |
| 策略(Strategy) | 实验中的一个方案（含原始方案），策略间互斥 | 策略A：红色字体；策略B：蓝色字体；默认：黑色字体 |
| 流量(Flow) | 实验的最基本单位，一个ID的一次访问 | 用户uuid=123的一次页面访问 |
| 桶(Bucket) | 对流量全集平均划分后的每一份，平台划分为1000个桶 | 桶编号1~1000 |
| 流量组(Flow Group) | 一个实验内多个桶的集合，绑定一个策略 | 实验A的40%流量绑策略A，40%绑策略B |
| 剩余流量(LeftFlow) | 命中实验但未命中任何流量组的流量，绑定默认策略 | 剩余20%流量绑默认策略 |
| 层(Layer) | 一个单层实验模型的抽象，层间流量正交 | 层A：按钮实验；层B：图片实验 |
| 模块(Module) | 业务逻辑相关的层的集合 | 金刚区模块 |
| 页面(Page) | 业务逻辑相关的模块的集合 | 首页页面 |
| 层域(Domain) | 通过父子关系进行流量控制的实验层级 | 部门整体做功效果衡量 |

### 2.3 分层实验架构

分层实验架构参考了Google在2010年发布的Overlapping Experiment Infrastructure论文，核心思想是：通过将流量划分为多个正交的层，让同一份流量穿越多个层，在不增加总流量的前提下提升单个流量的实验利用率。

**单层实验模型**解决了互斥实验的需求，但存在流量不足的问题。**分层实验模型**引入了层的概念：

- 层内互斥：同一层内，一个流量只命中一个桶，对应一个实验
- 层间正交：不同层之间，同一流量可以命中不同实验，且实验结果互不干扰

正交性通过哈希算法保证：同一流量在不同层命中的桶号不同，且流量全集在进入每一层时都被均匀打散。上一层实验带来的指标变化被均匀投射到下一层的每一个桶中，因此下一层每个桶之间保持了相似性。

### 2.4 系统部署架构

实验平台采用混合计算模型：

- **SDK本地计算**：业务服务通过引入实验平台SDK，在进程内完成分流计算，无需远程调用，延迟极低（亚毫秒级）
- **Server远端执行**：对于不支持SDK集成的场景（如异构语言），提供RPC接口进行远程分流
- **混合模式**：SDK本地缓存实验配置，定期从Server拉取最新配置，兼顾性能与实时性

## 三、核心链路设计

### 3.1 分流算法设计

#### 3.1.1 哈希分流算法

分流的核心是将流量均匀地分配到1000个桶中。采用对标识ID做哈希再求模的方式：

```java
/**
 * 基础分流算法：将流量均匀分配到桶中
 * @param identifier 流量标识（uuid或userId）
 * @param totalBuckets 总桶数（默认1000）
 * @return 桶编号（1 ~ totalBuckets）
 */
public int getBucketNumber(String identifier, int totalBuckets) {
    // 使用MurmurHash3，分布更均匀，碰撞率低
    int hash = MurmurHash3.hash32(identifier.getBytes(StandardCharsets.UTF_8));
    // 取模后+1，桶编号从1开始
    return Math.abs(hash % totalBuckets) + 1;
}
```

#### 3.1.2 分层正交分流算法

为了保证层间正交性，在哈希计算中加入层标识：

```java
/**
 * 分层正交分流算法
 * 同一流量在不同层命中的桶号不同，保证层间正交
 * @param identifier 流量标识
 * @param layerId 层标识
 * @param totalBuckets 总桶数
 * @return 桶编号
 */
public int getBucketNumberWithLayer(String identifier, String layerId, int totalBuckets) {
    // 将identifier与layerId拼接后哈希
    String compositeKey = identifier + ":" + layerId;
    int hash = MurmurHash3.hash32(compositeKey.getBytes(StandardCharsets.UTF_8));
    return Math.abs(hash % totalBuckets) + 1;
}
```

#### 3.1.3 完整分流链路

```java
/**
 * 完整的分流链路：流量进入 → 哈希分流 → 确认实验 → 确认流量组 → 返回策略
 */
public class ExperimentRouter {

    private final ExperimentConfigManager configManager;
    private static final int TOTAL_BUCKETS = 1000;

    /**
     * 执行分流，返回命中的策略
     * @param request 分流请求
     * @return 分流结果
     */
    public DiversionResult route(DiversionRequest request) {
        String identifier = request.getIdentifier();
        String layerId = request.getLayerId();

        // 1. 白名单检查（优先级最高）
        Strategy whitelistStrategy = checkWhitelist(identifier, layerId);
        if (whitelistStrategy != null) {
            return DiversionResult.builder()
                    .strategy(whitelistStrategy)
                    .source(DiversionSource.WHITELIST)
                    .experimentId(getExperimentId(layerId))
                    .build();
        }

        // 2. 流量过滤检查
        if (isFiltered(request)) {
            return DiversionResult.defaultResult();
        }

        // 3. 哈希分流获取桶号
        int bucketNumber = getBucketNumberWithLayer(identifier, layerId, TOTAL_BUCKETS);

        // 4. 确认命中的实验
        Experiment experiment = configManager.getExperimentByBucket(layerId, bucketNumber);
        if (experiment == null) {
            return DiversionResult.defaultResult();
        }

        // 5. 确认命中的流量组
        FlowGroup flowGroup = experiment.getFlowGroupByBucket(bucketNumber);
        if (flowGroup == null) {
            // 命中实验但未命中任何流量组 → 剩余流量
            flowGroup = experiment.getLeftFlowGroup();
        }

        // 6. 获取流量组绑定的策略
        Strategy strategy = flowGroup.getStrategy();

        // 7. 记录分流日志
        logDiversion(request, experiment, flowGroup, strategy, bucketNumber);

        return DiversionResult.builder()
                .strategy(strategy)
                .source(DiversionSource.BUCKET)
                .experimentId(experiment.getId())
                .flowGroupId(flowGroup.getId())
                .bucketNumber(bucketNumber)
                .build();
    }

    private Strategy checkWhitelist(String identifier, String layerId) {
        return configManager.getWhitelistStrategy(identifier, layerId);
    }

    private boolean isFiltered(DiversionRequest request) {
        return configManager.isFiltered(request.getIdentifier(), request.getLayerId());
    }

    private void logDiversion(DiversionRequest request, Experiment exp,
                              FlowGroup group, Strategy strategy, int bucket) {
        DiversionLog log = DiversionLog.builder()
                .identifier(request.getIdentifier())
                .layerId(request.getLayerId())
                .experimentId(exp.getId())
                .flowGroupId(group.getId())
                .strategyId(strategy.getId())
                .bucketNumber(bucket)
                .timestamp(System.currentTimeMillis())
                .build();
        // 异步写入分流日志，用于后续AA校验和实验分析
        LogManager.asyncLog(log);
    }
}
```

#### 3.1.4 预分流优化

预分流能力用于提升AA校验通过率：在AB实验开始之前，利用离线历史数据对用户进行模拟分流，挑选最均匀的分流因子。

```java
/**
 * 预分流：通过多次模拟分流，选择AA差异最小的分流因子
 */
public class PreDiversionOptimizer {

    private static final int MAX_SIMULATION_ROUNDS = 100;
    private static final double SIGNIFICANCE_THRESHOLD = 0.05;

    /**
     * 执行预分流优化
     * @param userIds 目标用户ID列表
     * @param historicalMetrics 用户历史指标数据
     * @return 最优分流因子
     */
    public String optimizeDiversionFactor(List<String> userIds,
                                          Map<String, UserMetrics> historicalMetrics) {
        String bestFactor = null;
        double bestScore = Double.MAX_VALUE;

        for (int round = 0; round < MAX_SIMULATION_ROUNDS; round++) {
            String candidateFactor = generateSalt(round);
            Map<String, Integer> diversionResult = simulateDiversion(userIds, candidateFactor);

            // 计算模拟AA的差异得分
            double score = calculateAAScore(diversionResult, historicalMetrics);

            if (score < bestScore) {
                bestScore = score;
                bestFactor = candidateFactor;
            }

            // 如果已经找到通过显著性检验的因子，提前终止
            if (score < SIGNIFICANCE_THRESHOLD) {
                break;
            }
        }

        return bestFactor;
    }

    private double calculateAAScore(Map<String, Integer> diversionResult,
                                     Map<String, UserMetrics> metrics) {
        // 将用户分为模拟的实验组和对照组
        List<Double> groupA = new ArrayList<>();
        List<Double> groupB = new ArrayList<>();

        for (Map.Entry<String, Integer> entry : diversionResult.entrySet()) {
            UserMetrics m = metrics.get(entry.getKey());
            if (m == null) continue;
            if (entry.getValue() == 0) {
                groupA.add(m.getOrderCount());
            } else {
                groupB.add(m.getOrderCount());
            }
        }

        // 执行t检验，返回p值作为得分
        return TTest.calculatePValue(groupA, groupB);
    }
}
```

#### 3.2.2 实验配置管理器

```java
/**
 * 实验配置管理器
 * 负责加载、缓存和更新实验配置
 */
public class ExperimentConfigManager {

    private final ConfigStore configStore;
    private volatile ExperimentConfigSnapshot snapshot;
    private final ScheduledExecutorService scheduler;

    /**
     * 初始化：加载配置并启动定时刷新
     */
    @PostConstruct
    public void init() {
        // 首次加载配置
        reloadConfig();

        // 每30秒刷新一次配置
        scheduler.scheduleAtFixedRate(this::reloadConfig, 30, 30, TimeUnit.SECONDS);
    }

    /**
     * 重新加载实验配置
     */
    private void reloadConfig() {
        try {
            ExperimentConfigSnapshot newSnapshot = configStore.loadAll();
            // 原子替换，保证线程安全
            this.snapshot = newSnapshot;
        } catch (Exception e) {
            // 配置加载失败时保留旧配置，不影响线上分流
            log.error("Failed to reload experiment config", e);
        }
    }

    /**
     * 根据层ID和桶号获取实验
     */
    public Experiment getExperimentByBucket(String layerId, int bucketNumber) {
        Layer layer = snapshot.getLayer(layerId);
        if (layer == null) return null;

        for (Experiment exp : layer.getExperiments()) {
            if (exp.getBucketRange().contains(bucketNumber)) {
                if (exp.getStatus() == ExperimentStatus.RUNNING) {
                    return exp;
                }
            }
        }
        return null;
    }

    /**
     * 获取白名单策略
     */
    public Strategy getWhitelistStrategy(String identifier, String layerId) {
        return snapshot.getWhitelistStrategy(identifier, layerId);
    }

    /**
     * 检查流量是否被过滤
     */
    public boolean isFiltered(String identifier, String layerId) {
        Set<String> filteredIds = snapshot.getFilteredIdentifiers(layerId);
        return filteredIds != null && filteredIds.contains(identifier);
    }
}

/**
 * 实验配置快照（不可变对象，保证并发安全）
 */

    private final Map<String, Map<String, Strategy>> whitelistMap;
    private final Map<String, Set<String>> filterMap;

    private final long loadTime;
```

#### 3.2.3 层域实验管理

层域实验通过父子关系进行流量控制，用于衡量部门整体的做功效果：

```java
/**
 * 层域实验：通过父子实验关系控制流量
 * 父实验的空白组不受子实验影响，可用于衡量整体增量
 */
public class DomainExperiment {

    private String domainId;
    private Experiment parentExperiment;  // 顶层父实验
    private List<Experiment> childExperiments; // 子实验列表

    /**
     * 层域分流逻辑：
     * 1. 先命中父实验的流量组
     * 2. 在父实验流量组内再命中子实验
     * 3. 父实验空白组的流量不会进入任何子实验
     */
    public DiversionResult routeInDomain(DiversionRequest request) {
        // 先在父实验层分流
        DiversionResult parentResult = parentExperiment.route(request);

        // 如果命中父实验空白组，直接返回
        if (parentResult.isControlGroup()) {
            return parentResult;
        }

        // 在父实验命中的流量组内，继续子实验分流
        for (Experiment child : childExperiments) {
            DiversionResult childResult = child.route(request);
            if (childResult.getStrategy() != null) {
                return childResult;
            }
        }

        return parentResult;
    }
}
```

#### 3.3.2 SDK实现

```java
/**
 * 实验平台SDK默认实现
 */
public class DefaultExperimentSDK implements ExperimentSDK {

    private final ExperimentConfigManager configManager;
    private final ExperimentRouter router;
    private final DiversionLogReporter logReporter;

    @Override
    public Strategy getStrategy(String layerId, String identifier) {
        DiversionRequest request = DiversionRequest.builder()
                .layerId(layerId)
                .identifier(identifier)
                .build();
        DiversionResult result = router.route(request);
        return result.getStrategy();
    }

    @Override
    public Strategy getStrategy(String layerId, DiversionContext context) {
        DiversionRequest request = DiversionRequest.builder()
                .layerId(layerId)
                .identifier(context.getIdentifier())
                .context(context)
                .build();
        DiversionResult result = router.route(request);

        // 自动上报分流日志
        logReporter.reportAsync(request, result);
        return result.getStrategy();
    }

    @Override
    public <T> T getParam(String layerId, String identifier, String paramKey, T defaultValue) {
        Strategy strategy = getStrategy(layerId, identifier);
        if (strategy == null) {
            return defaultValue;
        }
        String value = strategy.getParams().get(paramKey);
        if (value == null) {
            return defaultValue;
        }
        return TypeConverter.convert(value, defaultValue);
    }

    @Override
    public void reportDiversion(String layerId, String identifier, Strategy strategy) {
        DiversionLog log = DiversionLog.builder()
                .layerId(layerId)
                .identifier(identifier)
                .strategyId(strategy != null ? strategy.getId() : null)
                .timestamp(System.currentTimeMillis())
                .build();
        logReporter.reportAsync(log);
    }
}
```

### 3.4 AA校验机制

AA校验用于验证分流是否均匀：在无策略干预下，通过空跑实验或回溯历史行为来判断实验组和对照组是否存在显著差异。

#### 3.4.1 三种AA校验方式

```java
/**
 * AA校验管理器
 */
public class AAValidator {

    /**
     * 方式一：实验前AA
     * 在AB实验前，让实验组和对照组在没有策略差异的情况下空跑7天
     * 7天后回收结果，比较两组用户在关键指标上是否有显著差异
     */
    public AAResult validatePreAA(Experiment experiment) {
        // 1. 确保实验处于AA阶段（所有组使用对照组策略）
        ensureAAPhase(experiment);

        // 2. 等待AA数据累积（通常7天）
        Date aaStartTime = experiment.getAaStartTime();
        Date aaEndTime = experiment.getAaEndTime();

        // 3. 收集AA期间的指标数据
        Map<String, GroupMetrics> groupMetrics = collectMetrics(
                experiment, aaStartTime, aaEndTime);

        // 4. 执行显著性检验
        AAResult result = runSignificanceTest(groupMetrics);

        if (!result.isPassed()) {
            // AA未通过，建议使用预分流优化后重新打散
            log.warn("Pre-AA not passed for experiment {}, p-value={}",
                    experiment.getId(), result.getPValue());
        }

        return result;
    }

    /**
     * 方式二：回溯AA
     * 实验进行中或完成后，回溯进组用户在进组前N天的数据
     * 通常回溯14天，对于行为稀疏的场景可拉长至30天
     */
    public AAResult validateRetrospectiveAA(Experiment experiment) {
        // 1. 获取实验进组用户列表
        List<String> experimentGroupUsers = getEnrolledUsers(experiment, true);
        List<String> controlGroupUsers = getEnrolledUsers(experiment, false);

        // 2. 回溯进组前14天的行为数据
        int lookbackDays = 14;
        Map<String, UserMetrics> expHistorical = fetchHistoricalMetrics(
                experimentGroupUsers, lookbackDays);
        Map<String, UserMetrics> ctrlHistorical = fetchHistoricalMetrics(
                controlGroupUsers, lookbackDays);

        // 3. 执行显著性检验
        return runSignificanceTest(expHistorical, ctrlHistorical);
    }

    /**
     * 方式三：实验中AA（AAB实验）
     * 多设置一个对照组，校验两个AA组的分流均匀性
     * 注意：实验中AA校验通过不代表A与B组之间一定均匀，仍需回溯AA校验
     */
    public AAResult validateDuringAA(Experiment experiment) {
        List<String> aaGroup1Users = getEnrolledUsers(experiment, "aa_group_1");
        List<String> aaGroup2Users = getEnrolledUsers(experiment, "aa_group_2");

        Map<String, UserMetrics> metrics1 = fetchCurrentMetrics(aaGroup1Users);
        Map<String, UserMetrics> metrics2 = fetchCurrentMetrics(aaGroup2Users);

        return runSignificanceTest(metrics1, metrics2);
    }

    /**
     * 显著性检验：使用t检验比较两组指标差异
     */
    private AAResult runSignificanceTest(Map<String, UserMetrics> expMetrics,
                                          Map<String, UserMetrics> ctrlMetrics) {
        List<Double> expValues = extractMetricValues(expMetrics);
        List<Double> ctrlValues = extractMetricValues(ctrlMetrics);

        // 样本比例检验（SRM检查）
        double srmPValue = SRMChecker.check(expValues.size(), ctrlValues.size());

        // t检验
        double tTestPValue = TTest.calculatePValue(expValues, ctrlValues);

        // 综合判定
        boolean passed = tTestPValue > 0.05 && srmPValue > 0.05;

        return AAResult.builder()
                .passed(passed)
                .tTestPValue(tTestPValue)
                .srmPValue(srmPValue)
                .expSampleSize(expValues.size())
                .ctrlSampleSize(ctrlValues.size())
                .build();
    }
}
```

#### 3.4.2 样本比例不匹配检查（SRM）

```java
/**
 * 样本比例不匹配检查器
 * 检查实验实际分流比例与预期比例是否一致
 */
public class SRMChecker {

    private static final double SRM_THRESHOLD = 0.05;

    /**
     * 使用卡方检验检查样本比例
     * @param actualExpCount 实际实验组样本量
     * @param actualCtrlCount 实际对照组样本量
     * @param expectedRatio 预期比例（如0.5表示1:1）
     * @return p值
     */
    public static double check(int actualExpCount, int actualCtrlCount, double expectedRatio) {
        int total = actualExpCount + actualCtrlCount;
        double expectedExp = total * expectedRatio;
        double expectedCtrl = total * (1 - expectedRatio);

        // 卡方统计量
        double chiSquare = Math.pow(actualExpCount - expectedExp, 2) / expectedExp
                         + Math.pow(actualCtrlCount - expectedCtrl, 2) / expectedCtrl;

        // 自由度为1的卡方分布p值
        double pValue = 1 - ChiSquareDistribution.cdf(chiSquare, 1);

        if (pValue < SRM_THRESHOLD) {
            log.warn("SRM check failed! exp={}, ctrl={}, expected ratio={}, p-value={}",
                    actualExpCount, actualCtrlCount, expectedRatio, pValue);
        }

        return pValue;
    }

    public static double check(int actualExpCount, int actualCtrlCount) {
        return check(actualExpCount, actualCtrlCount, 0.5);
    }
}
```

### 3.5 实验评估体系

#### 3.5.1 显著性检验

```java
/**
 * 实验显著性检验器
 */
public class SignificanceTester {

    /**
     * 执行完整的显著性检验
     * @param expData 实验组指标数据
     * @param ctrlData 对照组指标数据
     * @param metricName 指标名称
     * @return 检验结果
     */
    public SignificanceResult test(List<Double> expData, List<Double> ctrlData,
                                    String metricName) {
        // 1. 计算描述性统计
        double expMean = Statistics.mean(expData);
        double ctrlMean = Statistics.mean(ctrlData);
        double expVariance = Statistics.variance(expData);
        double ctrlVariance = Statistics.variance(ctrlData);

        // 2. 计算提升幅度
        double diff = expMean - ctrlMean;
        double relativeDiff = diff / ctrlMean;

        // 3. 执行t检验
        double tStatistic = calculateTStatistic(expMean, ctrlMean,
                expVariance, ctrlVariance,
                expData.size(), ctrlData.size());
        int degreesOfFreedom = expData.size() + ctrlData.size() - 2;
        double pValue = TDistribution.twoTailedPValue(tStatistic, degreesOfFreedom);

        // 4. 判定显著性（95%置信水平，p < 0.05为显著）
        boolean isSignificant = pValue < 0.05;

        // 5. 计算置信区间
        double[] confidenceInterval = calculateConfidenceInterval(
                diff, expVariance, ctrlVariance,
                expData.size(), ctrlData.size());

        return SignificanceResult.builder()
                .metricName(metricName)
                .expMean(expMean)
                .ctrlMean(ctrlMean)
                .absoluteDiff(diff)
                .relativeDiff(relativeDiff)
                .pValue(pValue)
                .isSignificant(isSignificant)
                .confidenceInterval(confidenceInterval)
                .expSampleSize(expData.size())
                .ctrlSampleSize(ctrlData.size())
                .build();
    }
}
```

#### 3.5.2 CUPED方差缩减

CUPED（Controlled-experiment Using Pre-Experiment Data）利用用户在实验前的历史行为数据作为协变量，消除实验前就已存在的组间系统性差异，降低指标方差，提升检测灵敏度。

```java
/**
 * CUPED方差缩减实现
 */
public class CUPEDProcessor {

    /**
     * 执行CUPED方差缩减
     * @param currentMetrics 实验期指标数据
     * @param preMetrics 实验前14天的历史指标数据（协变量）
     * @return 修正后的指标数据
     */
    public Map<String, Double> applyCUPED(Map<String, Double> currentMetrics,
                                           Map<String, Double> preMetrics) {
        // 1. 找到在currentMetrics和preMetrics中都有数据的用户
        List<String> commonUsers = currentMetrics.keySet().stream()
                .filter(preMetrics::containsKey)
                .collect(Collectors.toList());

        if (commonUsers.isEmpty()) {
            return currentMetrics; // 无历史数据，无法应用CUPED
        }

        // 2. 计算theta系数（协方差/方差）
        double[] currentValues = commonUsers.stream()
                .mapToDouble(currentMetrics::get).toArray();
        double[] preValues = commonUsers.stream()
                .mapToDouble(preMetrics::get).toArray();

        double covariance = Statistics.covariance(currentValues, preValues);
        double preVariance = Statistics.variance(preValues);
        double theta = covariance / preVariance;

        // 3. 计算实验前数据的均值
        double preMean = Statistics.mean(preValues);

        // 4. 对每个用户的指标进行CUPED修正
        // 修正公式：Y_cuped = Y - theta * (X - X_mean)
        Map<String, Double> cupedMetrics = new HashMap<>();
        for (String userId : commonUsers) {
            double y = currentMetrics.get(userId);
            double x = preMetrics.get(userId);
            double yCuped = y - theta * (x - preMean);
            cupedMetrics.put(userId, yCuped);
        }

        // 5. 对于没有历史数据的用户，保留原始值（新用户不支持CUPED）
        for (String userId : currentMetrics.keySet()) {
            if (!cupedMetrics.containsKey(userId)) {
                cupedMetrics.put(userId, currentMetrics.get(userId));
            }
        }

        log.info("CUPED applied. Theta={}, variance reduction ratio={}",
                theta, calculateVarianceReduction(currentValues, preValues, theta));

        return cupedMetrics;
    }

    /**
     * 计算方差缩减比例
     */
    private double calculateVarianceReduction(double[] current, double[] pre, double theta) {
        double originalVariance = Statistics.variance(current);
        // CUPED后的方差 = 原方差 * (1 - rho^2)
        double correlation = Statistics.correlation(current, pre);
        double reducedVariance = originalVariance * (1 - correlation * correlation);
        return 1 - (reducedVariance / originalVariance);
    }
}
```

#### 3.5.3 最小样本量计算

```java
/**
 * 最小样本量计算器
 * 基于预期提升幅度和指标方差，计算实验所需的最小样本量
 */
public class SampleSizeCalculator {

    private static final double ALPHA = 0.05;  // 显著性水平
    private static final double POWER = 0.8;    // 统计功效

    /**
     * 计算最小样本量
     * @param baselineMean 基线均值（对照组预期指标值）
     * @param mde 最小可检测提升幅度（Minimum Detectable Effect）
     * @param variance 指标方差
     * @return 每组所需的最小样本量
     */
    public static int calculateSampleSize(double baselineMean, double mde, double variance) {
        // Z值
        double zAlpha = NormalDistribution.inverseCDF(1 - ALPHA / 2); // ~1.96
        double zBeta = NormalDistribution.inverseCDF(POWER);           // ~0.84

        // 最小可检测绝对差异
        double delta = baselineMean * mde;

        // 样本量公式：n = 2 * (z_alpha + z_beta)^2 * sigma^2 / delta^2
        double n = 2 * Math.pow(zAlpha + zBeta, 2) * variance / Math.pow(delta, 2);

        return (int) Math.ceil(n);
    }

    /**
     * 根据样本量和指标方差，反算最小可检测提升幅度（MDE）
     * @param sampleSize 每组样本量
     * @param baselineMean 基线均值
     * @param variance 指标方差
     * @return MDE（相对提升幅度）
     */
    public static double calculateMDE(int sampleSize, double baselineMean, double variance) {
        double zAlpha = NormalDistribution.inverseCDF(1 - ALPHA / 2);
        double zBeta = NormalDistribution.inverseCDF(POWER);

        // 反算delta: delta = sqrt(2 * (z_alpha + z_beta)^2 * sigma^2 / n)
        double delta = Math.sqrt(2 * Math.pow(zAlpha + zBeta, 2) * variance / sampleSize);

        return delta / baselineMean;
    }

    /**
     * 推荐实验流量比例和实验周期
     * @param dailyActiveUsers 日活用户数
     * @param requiredSampleSize 所需最小样本量
     * @return 推荐配置
     */
    public static ExperimentDurationRecommendation recommendDuration(
            long dailyActiveUsers, int requiredSampleSize) {
        // 至少7天（考虑周末效应）
        int minDays = 7;

        // 计算所需流量比例
        double minTrafficRatio = (double) requiredSampleSize / (dailyActiveUsers * minDays);

        // 如果流量比例超过100%，需要延长实验周期
        int recommendedDays = minDays;
        if (minTrafficRatio > 1.0) {
            recommendedDays = (int) Math.ceil((double) requiredSampleSize / dailyActiveUsers);
            recommendedDays = roundUpToWeeks(recommendedDays);
            minTrafficRatio = 1.0;
        }

        // 建议至少使用20%流量（实验组+对照组）
        double recommendedTrafficRatio = Math.max(minTrafficRatio, 0.2);

        return ExperimentDurationRecommendation.builder()
                .recommendedDays(recommendedDays)
                .recommendedTrafficRatio(recommendedTrafficRatio)
                .build();
    }

    private static int roundUpToWeeks(int days) {
        return ((days + 6) / 7) * 7;
    }
}
```

#### 3.6.1 生命周期状态机

```java
/**
 * 实验生命周期状态枚举
 */
public enum ExperimentStatus {
    DRAFT,          // 草稿：实验配置阶段
    PRE_AA,         // 实验前AA阶段
    AA_PENDING,     // AA校验待回收
    AA_FAILED,      // AA校验未通过
    RUNNING,        // 实验运行中
    PAUSED,         // 实验暂停
    ANALYZING,      // 数据分析中
    ROLLOUT,        // 策略推全中
    FINISHED,       // 实验已结束
    ARCHIVED        // 实验已归档
}

/**
 * 实验状态转换
 * DRAFT → PRE_AA → AA_PENDING → RUNNING → ANALYZING → ROLLOUT → FINISHED → ARCHIVED
 *                                    ↓
 *                               AA_FAILED → (重新打散) → PRE_AA
 */
public class ExperimentStateMachine {

    private static final Map<ExperimentStatus, Set<ExperimentStatus>> TRANSITIONS = new HashMap<>();

    static {
        TRANSITIONS.put(ExperimentStatus.DRAFT, Set.of(ExperimentStatus.PRE_AA));
        TRANSITIONS.put(ExperimentStatus.PRE_AA, Set.of(ExperimentStatus.AA_PENDING));
        TRANSITIONS.put(ExperimentStatus.AA_PENDING,
                Set.of(ExperimentStatus.RUNNING, ExperimentStatus.AA_FAILED));
        TRANSITIONS.put(ExperimentStatus.AA_FAILED, Set.of(ExperimentStatus.PRE_AA));
        TRANSITIONS.put(ExperimentStatus.RUNNING,
                Set.of(ExperimentStatus.PAUSED, ExperimentStatus.ANALYZING));
        TRANSITIONS.put(ExperimentStatus.PAUSED, Set.of(ExperimentStatus.RUNNING));
        TRANSITIONS.put(ExperimentStatus.ANALYZING,
                Set.of(ExperimentStatus.ROLLOUT, ExperimentStatus.FINISHED));
        TRANSITIONS.put(ExperimentStatus.ROLLOUT, Set.of(ExperimentStatus.FINISHED));
        TRANSITIONS.put(ExperimentStatus.FINISHED, Set.of(ExperimentStatus.ARCHIVED));
    }

    public static boolean canTransition(ExperimentStatus from, ExperimentStatus to) {
        return TRANSITIONS.getOrDefault(from, Set.of()).contains(to);
    }

    public static void transition(Experiment experiment, ExperimentStatus to) {
        ExperimentStatus from = experiment.getStatus();
        if (!canTransition(from, to)) {
            throw new IllegalStateException(
                    String.format("Cannot transition from %s to %s", from, to));
        }
        experiment.setStatus(to);
    }
}
```

#### 3.6.2 策略推全

```java
/**
 * 策略推全管理器
 * 推全时将实验策略变为全层的默认策略
 */
public class RolloutManager {

    /**
     * 执行策略推全
     * @param experiment 实验对象
     * @param strategyId 要推全的策略ID
     * @param rolloutConfig 推全配置（灰度比例、时间节奏）
     */
    public void rollout(Experiment experiment, Long strategyId, RolloutConfig rolloutConfig) {
        // 1. 校验推全条件
        validateRolloutConditions(experiment, strategyId);

        // 2. 执行灰度推全
        if (rolloutConfig.isGrayRollout()) {
            grayRollout(experiment, strategyId, rolloutConfig);
        } else {
            fullRollout(experiment, strategyId);
        }

        // 3. 推全后监控大盘指标
        monitorAfterRollout(experiment, strategyId);
    }

    /**
     * 灰度推全：按指定时间节奏逐步放量
     */
    private void grayRollout(Experiment experiment, Long strategyId, RolloutConfig config) {
        List<RolloutStep> steps = config.getSteps();
        for (RolloutStep step : steps) {
            // 设置灰度比例
            experiment.setRolloutPercentage(step.getPercentage());
            experiment.updateDefaultStrategy(strategyId, step.getPercentage());
            configManager.update(experiment);

            // 等待观察期
            log.info("Rollout step: {}%, waiting {} days for observation",
                    step.getPercentage(), step.getObserveDays());

            // 检查大盘指标是否负向
            if (checkNegativeImpact(experiment, step)) {
                log.warn("Negative impact detected during rollout at {}%, rolling back",
                        step.getPercentage());
                rollbackRollout(experiment);
                return;
            }
        }

        // 所有灰度步骤完成，执行全量推全
        fullRollout(experiment, strategyId);
    }

    /**
     * 全量推全
     */
    private void fullRollout(Experiment experiment, Long strategyId) {
        // 将策略设为全层默认策略
        experiment.setRolloutPercentage(100);
        experiment.updateDefaultStrategy(strategyId, 100);
        configManager.update(experiment);

        // 更新实验状态
        ExperimentStateMachine.transition(experiment, ExperimentStatus.FINISHED);

        log.info("Experiment {} fully rolled out with strategy {}",
                experiment.getId(), strategyId);
    }

    /**
     * 推全条件校验
     */
    private void validateRolloutConditions(Experiment experiment, Long strategyId) {
        // 1. 实验必须处于分析阶段
        if (experiment.getStatus() != ExperimentStatus.ANALYZING) {
            throw new IllegalStateException("Experiment must be in ANALYZING status");
        }

        // 2. 目标指标必须显著正向
        SignificanceResult result = significanceTester.test(
                experiment.getExperimentGroupData(),
                experiment.getControlGroupData(),
                experiment.getTargetMetric());
        if (!result.isSignificant() || result.getRelativeDiff() <= 0) {
            throw new IllegalStateException(
                    "Target metric must be significant and positive");
        }

        // 3. 大盘指标不负向
        for (String guardMetric : experiment.getGuardMetrics()) {
            SignificanceResult guardResult = significanceTester.test(
                    experiment.getExperimentGroupData(guardMetric),
                    experiment.getControlGroupData(guardMetric),
                    guardMetric);
            if (guardResult.isSignificant() && guardResult.getRelativeDiff() < 0) {
                throw new IllegalStateException(
                        "Guard metric " + guardMetric + " is significantly negative");
            }
        }
    }
}
```

```java
            log.warn("Diversion log queue full, writing to local buffer");

                batchSender.send(batch);

                fileBuffer.writeAll(batch);
                log.error("Failed to send diversion logs, buffered for retry", e);
            }
        }
    }
```

```java
    public List<DiversionResult> batchRoute(List<DiversionRequest> requests) {

                .collect(Collectors.toList());

    /**
     * 批量获取多层策略
     * 一次请求获取用户在多个层的分流结果
     */
    public MultiLayerResult batchRouteMultiLayer(String identifier, List<String> layerIds) {
        Map<String, Strategy> results = new HashMap<>();
        for (String layerId : layerIds) {
            // 先查缓存
            Strategy cached = diversionResultCache.getCachedStrategy(layerId, identifier);
            if (cached != null) {
                results.put(layerId, cached);
            } else {
                DiversionRequest request = DiversionRequest.builder()
                        .layerId(layerId)
                        .identifier(identifier)
                        .build();
                DiversionResult result = router.route(request);
                results.put(layerId, result.getStrategy());
                diversionResultCache.cacheStrategy(layerId, identifier, result.getStrategy());
            }
        }
        return new MultiLayerResult(results);
    }
}
```

```java
public class AsyncDiversionLogger {

    private final BatchKafkaSender kafkaSender;

                ProducerType.MULTI,
                new BlockingWaitStrategy()
        );

    }

     * 发布分流日志（无阻塞）
     */
    public void log(DiversionLog log) {

        try {
            DiversionLogEvent event = disruptor.get(sequence);
            event.setLog(log);
        } finally {
            disruptor.publish(sequence);
        }
    }

    /**
     * 批量发送到Kafka
     */

        buffer.add(event.getLog());

        if (buffer.size() >= 500 || endOfBatch) {
            List<DiversionLog> batch = new ArrayList<>(buffer);
            buffer.clear();
            kafkaSender.sendBatch(batch);
        }
    }
```

## 六、最佳实践

### 6.1 实验设计规范

1. **一次验证一个假设**：每个实验最好只验证一个策略假设，避免多个干预混淆效果。如果需要验证多干预效果，通过多实验组设计来独立量化。

2. **明确决策指标集合**：每个实验需要明确策略生效指标（判断策略是否按预期生效）和结果指标（量化干预的直接目标是否达成），同时关注大盘指标（整体订单和收入）。

3. **选择合适的分流单元**：分流单元需要与分析单元保持一致。例如激励场景下，人均激励成本以用户统计，分流单元也应选择用户ID。

4. **分流环节靠近干预策略**：分流环节尽量靠近策略生效点，避免因策略在整体中占比较低导致效果稀释。

5. **合理计算样本量**：基于预期提升幅度和指标方差计算最小样本量，建议目标指标不超过3个。

6. **实验周期至少7天**：考虑周末效应，实验周期应为7天的整数倍。避免在重大节假日开展实验。

### 6.2 AA校验规范

1. **推荐使用实验前AA或回溯AA**，不建议仅依赖实验中AA。实验中AA校验的是两个AA组的均匀性，不能保证A与B组之间一定均匀。

2. **回溯AA建议回溯14天**，对于用户行为稀疏、行为周期较长的场景可拉长至30天。

3. **AA未通过时使用预分流优化**：利用离线历史数据进行多次模拟分流，挑选最均匀的分流因子，提高AA通过率。

4. **AA校验需要同时检查SRM和指标均匀性**：样本比例不匹配（SRM）是最常见的问题之一，必须先检查样本量是否均匀，再进行指标显著性检验。

### 6.3 分层实验规划

1. **不同产品模块间的实验使用正交层**：如搜索与推荐之间的实验是正交的。
2. **同一模块内的实验使用互斥层**：如推荐高卡对同一用户同一时间只能展示某一业务。
3. **层域实验用于衡量部门整体做功效果**：维护一个长期的推全组与空白组，通过对比衡量整体增量。
4. **页面互斥层用于页面级互斥实验**：同一页面内的不同互斥层实验相互互斥，每个实验分到的桶位置不重复。

### 6.4 实验评估规范

1. **使用多天累计指标而非日均指标**：日均指标只考虑活跃用户的行为表现，可能存在幸存者偏差。多天累计指标能验证留存提频的影响。

2. **通过显著性检验才能归档收益**：只有p值小于0.05的结果才能说明策略真有效果。不显著的结论无论提升幅度多高，都可能是自然波动。

3. **利用CUPED应对指标不显著**：当策略符合预期但指标不显著时，使用CUPED降低方差提升灵敏度。CUPED对均值类指标（如订单量）效果优于比率类指标（如点击率）。

4. **推全决策以大盘指标为约束**：所有实验推全要求大盘指标（整体订单和收入）不负向，除非是bug修复或必要功能迭代。

5. **推全后持续监控**：推全过程中可能出现错误配置，需监测目标指标变化是否符合预期。

### 6.5 工程接入规范

1. **优先使用SDK本地计算模式**：避免远程调用的网络开销，分流延迟控制在亚毫秒级。

2. **配置加载失败时保留旧配置**：实验配置的更新失败不应影响线上分流，SDK应缓存上一次成功的配置。

3. **分流日志必须可靠上报**：分流日志是AA校验和实验评估的数据基础，需要异步化、批量化和本地缓冲保障可靠性。

4. **白名单测试优先于灰度放量**：实验上线前先通过白名单测试验证策略是否正常生效，再进行灰度放量。

5. **Feature管理与实验配置解耦**：通过Feature管理实现策略参数的独立管理，支持推全过程中的灰度和回滚。

## 七、全链路实战案例

### 7.1 案例一：创建并启动AB实验全链路

**场景描述**：产品经理需要创建一个首页推荐算法AB实验，包含实验组（新推荐算法）和对照组（原有算法），配置分桶策略后上线，完成流量分配的全链路流程。

**全链路流程**：实验配置 -> 分桶策略 -> 实验上线 -> 流量分配

```java
/**
 * 案例一：创建并启动AB实验全链路
 * 
 * 完整流程：
 * 1. 创建实验配置（层、实验、策略、流量组）
 * 2. 配置分桶策略（桶范围分配）
 * 3. 执行AA校验
 * 4. 实验上线（状态流转 DRAFT -> PRE_AA -> RUNNING）
 * 5. 流量分配验证（模拟用户分流）
 */
@Service
@Slf4j
public class ExperimentLifecycleService {

    @Autowired
    private ExperimentConfigManager configManager;
    @Autowired
    private ExperimentRouter experimentRouter;
    @Autowired
    private AAValidator aaValidator;
    @Autowired
    private ExperimentStore experimentStore;
    @Autowired
    private IdempotentManager idempotentManager;

    private static final int TOTAL_BUCKETS = 1000;
    private static final String IDEMPOTENT_PREFIX = "EXP_CREATE:";

    /**
     * 全链路：创建并启动AB实验
     * 
     * @param request 实验创建请求
     * @return 实验启动结果
     */
    @Transactional(rollbackFor = Exception.class)
    public ExperimentLaunchResult launchExperiment(ExperimentCreateRequest request) {
        String idempotentKey = IDEMPOTENT_PREFIX + request.getRequestId();
        long startTime = System.currentTimeMillis();

        // ==================== 幂等控制 ====================
        // 防止重复提交导致创建多个相同实验
        String existingResult = idempotentManager.get(idempotentKey);
        if (existingResult != null) {
            log.info("[ExperimentLaunch] 幂等命中, requestId={}, experimentId={}", 
                    request.getRequestId(), existingResult);
            return ExperimentLaunchResult.builder()
                    .success(true)
                    .experimentId(Long.parseLong(existingResult))
                    .message("实验已存在（幂等命中）")
                    .build();
        }

        try {
            log.info("[ExperimentLaunch] 开始创建实验, requestId={}, name={}, layerId={}",
                    request.getRequestId(), request.getExperimentName(), request.getLayerId());

            // ==================== Step1: 实验配置 ====================
            Experiment experiment = createExperimentConfig(request);
            log.info("[ExperimentLaunch] 实验配置创建完成, experimentId={}, name={}, status=DRAFT",
                    experiment.getId(), experiment.getName());

            // ==================== Step2: 分桶策略 ====================
            configureBucketStrategy(experiment, request);
            log.info("[ExperimentLaunch] 分桶策略配置完成, experimentId={}, 桶范围=[1-{}], "
                    + "实验组桶数={}, 对照组桶数={}, 剩余桶数={}",
                    experiment.getId(), TOTAL_BUCKETS,
                    request.getExperimentTrafficPct() * TOTAL_BUCKETS / 100,
                    request.getControlTrafficPct() * TOTAL_BUCKETS / 100,
                    (100 - request.getExperimentTrafficPct() - request.getControlTrafficPct())
                            * TOTAL_BUCKETS / 100);

            // ==================== Step3: AA校验 ====================
            ExperimentStateMachine.transition(experiment, ExperimentStatus.PRE_AA);
            experimentStore.update(experiment);
            log.info("[ExperimentLaunch] 实验进入AA校验阶段, experimentId={}", experiment.getId());

            AAResult aaResult = aaValidator.validatePreAA(experiment);
            if (!aaResult.isPassed()) {
                log.warn("[ExperimentLaunch] AA校验未通过, experimentId={}, p-value={}, srmPValue={}",
                        experiment.getId(), aaResult.getTTestPValue(), aaResult.getSrmPValue());
                ExperimentStateMachine.transition(experiment, ExperimentStatus.AA_FAILED);
                experimentStore.update(experiment);
                return ExperimentLaunchResult.builder()
                        .success(false)
                        .experimentId(experiment.getId())
                        .message("AA校验未通过，请使用预分流优化后重试")
                        .aaResult(aaResult)
                        .build();
            }
            log.info("[ExperimentLaunch] AA校验通过, experimentId={}, p-value={}",
                    experiment.getId(), aaResult.getTTestPValue());

            // ==================== Step4: 实验上线 ====================
            ExperimentStateMachine.transition(experiment, ExperimentStatus.RUNNING);
            experiment.setStartTime(new Date());
            experimentStore.update(experiment);
            configManager.notifyConfigChange(); // 通知配置变更，刷新本地缓存
            log.info("[ExperimentLaunch] 实验已上线, experimentId={}, status=RUNNING, startTime={}",
                    experiment.getId(), experiment.getStartTime());

            // ==================== Step5: 流量分配验证 ====================
            TrafficDistributionVerify verifyResult = verifyTrafficDistribution(
                    experiment, request.getTestUserIds());
            log.info("[ExperimentLaunch] 流量分配验证完成, experimentId={}, "
                    + "实验组命中={}, 对照组命中={}, 剩余流量命中={}, 总样本={}",
                    experiment.getId(),
                    verifyResult.getExperimentGroupCount(),
                    verifyResult.getControlGroupCount(),
                    verifyResult.getLeftFlowCount(),
                    verifyResult.getTotalCount());

            // ==================== 记录幂等 ====================
            idempotentManager.set(idempotentKey, String.valueOf(experiment.getId()), 
                    24, TimeUnit.HOURS);

            long elapsed = System.currentTimeMillis() - startTime;
            log.info("[ExperimentLaunch] 实验创建并启动全链路完成, experimentId={}, 耗耗={}ms",
                    experiment.getId(), elapsed);

            return ExperimentLaunchResult.builder()
                    .success(true)
                    .experimentId(experiment.getId())
                    .message("实验创建并启动成功")
                    .aaResult(aaResult)
                    .trafficVerify(verifyResult)
                    .build();

        } catch (ExperimentStateException e) {
            log.error("[ExperimentLaunch] 实验状态流转异常, requestId={}, error={}",
                    request.getRequestId(), e.getMessage(), e);
            throw new ExperimentLaunchException("实验状态流转异常: " + e.getMessage(), e);
        } catch (BucketConflictException e) {
            log.error("[ExperimentLaunch] 桶冲突异常, requestId={}, error={}",
                    request.getRequestId(), e.getMessage(), e);
            throw new ExperimentLaunchException("分桶策略冲突: " + e.getMessage(), e);
        } catch (Exception e) {
            log.error("[ExperimentLaunch] 实验创建失败, requestId={}, error={}",
                    request.getRequestId(), e.getMessage(), e);
            throw new ExperimentLaunchException("实验创建失败: " + e.getMessage(), e);
        }
    }

    /**
     * Step1: 创建实验配置
     */
    private Experiment createExperimentConfig(ExperimentCreateRequest request) {
        // 校验层是否存在
        Layer layer = configManager.getLayerById(request.getLayerId());
        if (layer == null) {
            throw new ExperimentConfigException("层不存在: " + request.getLayerId());
        }

        // 校验实验名称唯一性
        if (experimentStore.existsByName(request.getExperimentName(), request.getLayerId())) {
            throw new ExperimentConfigException("实验名称已存在: " + request.getExperimentName());
        }

        // 创建策略
        Strategy experimentStrategy = Strategy.builder()
                .name(request.getExperimentName() + "_实验组策略")
                .params(request.getExperimentParams())
                .isDefault(false)
                .build();

        Strategy controlStrategy = Strategy.builder()
                .name(request.getExperimentName() + "_对照组策略")
                .params(request.getControlParams())
                .isDefault(true)
                .build();

        // 创建实验
        Experiment experiment = Experiment.builder()
                .name(request.getExperimentName())
                .layerId(request.getLayerId())
                .domainId(layer.getDomainId())
                .status(ExperimentStatus.DRAFT)
                .creator(request.getCreator())
                .targetUserTags(request.getTargetUserTags())
                .build();

        experiment = experimentStore.save(experiment);
        experimentStore.saveStrategies(experiment.getId(), 
                Arrays.asList(experimentStrategy, controlStrategy));

        return experiment;
    }

    /**
     * Step2: 配置分桶策略
     * 将1000个桶按流量比例分配给实验组、对照组和剩余流量
     */
    private void configureBucketStrategy(Experiment experiment, ExperimentCreateRequest request) {
        int expBuckets = request.getExperimentTrafficPct() * TOTAL_BUCKETS / 100;
        int ctrlBuckets = request.getControlTrafficPct() * TOTAL_BUCKETS / 100;
        int leftBuckets = TOTAL_BUCKETS - expBuckets - ctrlBuckets;

        if (leftBuckets < 0) {
            throw new ExperimentConfigException(
                    "流量比例总和超过100%: 实验组=" + request.getExperimentTrafficPct()
                    + "%, 对照组=" + request.getControlTrafficPct() + "%");
        }

        // 检查桶冲突：同一层内不能有重叠的桶范围
        List<Integer> occupiedBuckets = configManager.getOccupiedBuckets(experiment.getLayerId());
        List<Integer> newBuckets = IntStream.rangeClosed(1, expBuckets + ctrlBuckets)
                .boxed().collect(Collectors.toList());

        List<Integer> conflicts = newBuckets.stream()
                .filter(occupiedBuckets::contains)
                .collect(Collectors.toList());
        if (!conflicts.isEmpty()) {
            throw new BucketConflictException(
                    "桶冲突, layerId=" + experiment.getLayerId()
                    + ", 冲突桶号=" + conflicts.subList(0, Math.min(10, conflicts.size())));
        }

        // 分配桶
        List<Integer> expBucketList = IntStream.rangeClosed(1, expBuckets)
                .boxed().collect(Collectors.toList());
        List<Integer> ctrlBucketList = IntStream.rangeClosed(expBuckets + 1, expBuckets + ctrlBuckets)
                .boxed().collect(Collectors.toList());

        FlowGroup experimentGroup = FlowGroup.builder()
                .experimentId(experiment.getId())
                .name("实验组")
                .trafficPercentage(request.getExperimentTrafficPct())
                .buckets(expBucketList)
                .build();

        FlowGroup controlGroup = FlowGroup.builder()
                .experimentId(experiment.getId())
                .name("对照组")
                .trafficPercentage(request.getControlTrafficPct())
                .buckets(ctrlBucketList)
                .build();

        // 剩余流量绑定默认策略
        FlowGroup leftFlowGroup = null;
        if (leftBuckets > 0) {
            List<Integer> leftBucketList = IntStream
                    .rangeClosed(expBuckets + ctrlBuckets + 1, TOTAL_BUCKETS)
                    .boxed().collect(Collectors.toList());
            leftFlowGroup = FlowGroup.builder()
                    .experimentId(experiment.getId())
                    .name("剩余流量")
                    .trafficPercentage(100 - request.getExperimentTrafficPct()
                            - request.getControlTrafficPct())
                    .buckets(leftBucketList)
                    .build();
        }

        experiment.setFlowGroups(Arrays.asList(experimentGroup, controlGroup));
        experiment.setLeftFlowGroup(leftFlowGroup);
        experiment.setBucketRange(Arrays.asList(1, expBuckets + ctrlBuckets));

        experimentStore.update(experiment);
    }

    /**
     * Step5: 流量分配验证
     * 模拟测试用户分流，验证流量分配是否符合预期
     */
    private TrafficDistributionVerify verifyTrafficDistribution(Experiment experiment,
                                                                List<String> testUserIds) {
        int expCount = 0;
        int ctrlCount = 0;
        int leftCount = 0;

        for (String userId : testUserIds) {
            DiversionRequest request = DiversionRequest.builder()
                    .layerId(experiment.getLayerId())
                    .identifier(userId)
                    .build();
            DiversionResult result = experimentRouter.route(request);

            if (result.getFlowGroupId() != null) {
                if (result.getFlowGroupId().equals(experiment.getFlowGroups().get(0).getId())) {
                    expCount++;
                } else if (result.getFlowGroupId()
                        .equals(experiment.getFlowGroups().get(1).getId())) {
                    ctrlCount++;
                } else {
                    leftCount++;
                }
            } else {
                leftCount++;
            }
        }

        // SRM检查
        double srmPValue = SRMChecker.check(expCount, ctrlCount);
        if (srmPValue < 0.05) {
            log.warn("[TrafficVerify] SRM检查未通过, expCount={}, ctrlCount={}, p-value={}",
                    expCount, ctrlCount, srmPValue);
        }

        return TrafficDistributionVerify.builder()
                .experimentGroupCount(expCount)
                .controlGroupCount(ctrlCount)
                .leftFlowCount(leftCount)
                .totalCount(testUserIds.size())
                .srmPValue(srmPValue)
                .build();
    }
}
```

### 7.2 案例二：实验命中与分流全链路

**场景描述**：用户打开APP首页时，业务服务通过实验SDK获取推荐算法实验的分流策略，下发策略参数给客户端，同时上报曝光日志用于后续实验效果分析。

**全链路流程**：用户请求 -> 实验匹配 -> 分桶计算 -> 参数下发 -> 曝光上报

```java
/**
 * 案例二：实验命中与分流全链路
 * 
 * 完整流程：
 * 1. 用户请求到达业务服务
 * 2. SDK根据用户标识匹配实验
 * 3. 哈希分桶计算命中的流量组
 * 4. 下发策略参数给客户端
 * 5. 异步上报曝光日志
 */
@Service
@Slf4j
public class ExperimentDiversionService {

    @Autowired
    private ExperimentRouter experimentRouter;
    @Autowired
    private ExperimentConfigManager configManager;
    @Autowired
    private ExposureLogReporter exposureLogReporter;
    @Autowired
    private DiversionResultCache diversionResultCache;
    @Autowired
    private IdempotentManager idempotentManager;

    /**
     * 全链路：实验命中与分流
     * 
     * @param request 用户请求（包含userId, layerId, deviceId等）
     * @return 策略下发结果
     */
    public DiversionResponse divert(DiversionRequest request) {
        String identifier = request.getIdentifier();
        String layerId = request.getLayerId();
        String requestId = request.getRequestId();
        long startTime = System.currentTimeMillis();

        // ==================== 幂等控制 ====================
        // 同一请求在短时间内重复调用时返回缓存结果
        String idempotentKey = "DIVERT:" + requestId;
        DiversionResponse cached = idempotentManager.get(idempotentKey, DiversionResponse.class);
        if (cached != null) {
            log.info("[Diversion] 幂等命中, requestId={}, identifier={}, strategyId={}",
                    requestId, identifier, cached.getStrategyId());
            return cached;
        }

        // ==================== 参数校验 ====================
        if (StringUtils.isBlank(identifier) || StringUtils.isBlank(layerId)) {
            log.warn("[Diversion] 参数校验失败, identifier={}, layerId={}", identifier, layerId);
            return DiversionResponse.defaultResponse();
        }

        try {
            log.info("[Diversion] 开始分流, requestId={}, identifier={}, layerId={}",
                    requestId, identifier, layerId);

            // ==================== Step1: 分流结果缓存检查 ====================
            Strategy cachedStrategy = diversionResultCache.getCachedStrategy(layerId, identifier);
            if (cachedStrategy != null) {
                log.info("[Diversion] 命中分流缓存, identifier={}, layerId={}, strategyId={}",
                        identifier, layerId, cachedStrategy.getId());

                DiversionResponse response = buildResponse(cachedStrategy, layerId, identifier,
                        DiversionSource.CACHE);
                reportExposureAsync(request, response, DiversionSource.CACHE);
                idempotentManager.set(idempotentKey, response, 5, TimeUnit.MINUTES);
                return response;
            }

            // ==================== Step2: 实验匹配 + 分桶计算 ====================
            DiversionResult result = experimentRouter.route(request);
            Strategy strategy = result.getStrategy();

            if (strategy == null) {
                log.warn("[Diversion] 未命中任何实验策略, identifier={}, layerId={}, 返回默认策略",
                        identifier, layerId);
                strategy = getDefaultStrategy(layerId);
            }

            log.info("[Diversion] 分流完成, identifier={}, layerId={}, experimentId={}, "
                    + "flowGroupId={}, strategyId={}, bucket={}, source={}, 耗时={}ms",
                    identifier, layerId, result.getExperimentId(),
                    result.getFlowGroupId(), strategy.getId(),
                    result.getBucketNumber(), result.getSource(),
                    System.currentTimeMillis() - startTime);

            // ==================== Step3: 缓存分流结果 ====================
            diversionResultCache.cacheStrategy(layerId, identifier, strategy);

            // ==================== Step4: 参数下发 ====================
            DiversionResponse response = buildResponse(strategy, layerId, identifier,
                    result.getSource());
            response.setExperimentId(result.getExperimentId());
            response.setFlowGroupId(result.getFlowGroupId());
            response.setBucketNumber(result.getBucketNumber());

            // ==================== Step5: 曝光上报 ====================
            reportExposureAsync(request, response, result.getSource());

            // ==================== 记录幂等 ====================
            idempotentManager.set(idempotentKey, response, 5, TimeUnit.MINUTES);

            return response;

        } catch (ConfigNotReadyException e) {
            log.error("[Diversion] 实验配置未就绪, identifier={}, layerId={}, 返回默认策略",
                    identifier, layerId, e);
            return DiversionResponse.defaultResponse();
        } catch (HashAlgorithmException e) {
            log.error("[Diversion] 哈希分桶异常, identifier={}, layerId={}",
                    identifier, layerId, e);
            return DiversionResponse.defaultResponse();
        } catch (Exception e) {
            log.error("[Diversion] 分流异常, identifier={}, layerId={}",
                    identifier, layerId, e);
            return DiversionResponse.defaultResponse();
        }
    }

    /**
     * 构建策略下发响应
     */
    private DiversionResponse buildResponse(Strategy strategy, String layerId,
                                            String identifier, DiversionSource source) {
        DiversionResponse response = new DiversionResponse();
        response.setStrategyId(strategy.getId());
        response.setStrategyName(strategy.getName());
        response.setParams(strategy.getParams());
        response.setLayerId(layerId);
        response.setIdentifier(identifier);
        response.setSource(source);
        response.setTimestamp(System.currentTimeMillis());
        return response;
    }

    /**
     * 获取默认策略（降级策略）
     */
    private Strategy getDefaultStrategy(String layerId) {
        try {
            Strategy defaultStrategy = configManager.getDefaultStrategy(layerId);
            if (defaultStrategy != null) {
                return defaultStrategy;
            }
        } catch (Exception e) {
            log.error("[Diversion] 获取默认策略失败, layerId={}", layerId, e);
        }
        // 兜底：返回空策略
        return Strategy.builder()
                .id(0L)
                .name("fallback_default")
                .params(Collections.emptyMap())
                .isDefault(true)
                .build();
    }

    /**
     * 异步上报曝光日志
     * 曝光日志是实验效果分析的数据基础，必须可靠上报
     */
    private void reportExposureAsync(DiversionRequest request, DiversionResponse response,
                                     DiversionSource source) {
        try {
            ExposureLog exposureLog = ExposureLog.builder()
                    .requestId(request.getRequestId())
                    .identifier(request.getIdentifier())
                    .layerId(request.getLayerId())
                    .experimentId(response.getExperimentId())
                    .flowGroupId(response.getFlowGroupId())
                    .strategyId(response.getStrategyId())
                    .bucketNumber(response.getBucketNumber())
                    .source(source.name())
                    .deviceId(request.getDeviceId())
                    .timestamp(System.currentTimeMillis())
                    .build();

            exposureLogReporter.reportAsync(exposureLog);
            log.debug("[Diversion] 曝光日志已提交异步上报, identifier={}, experimentId={}, strategyId={}",
                    request.getIdentifier(), response.getExperimentId(), response.getStrategyId());

        } catch (Exception e) {
            // 曝光日志上报失败不影响业务流程，但需要记录错误日志
            log.error("[Diversion] 曝光日志上报失败, identifier={}, experimentId={}, strategyId={}",
                    request.getIdentifier(), response.getExperimentId(),
                    response.getStrategyId(), e);
        }
    }
}

/**
 * 曝光日志上报器
 * 支持异步批量上报 + 本地文件缓冲 + 重试机制
 */
@Component
@Slf4j
public class ExposureLogReporter {

    private final BlockingQueue<ExposureLog> logQueue = new LinkedBlockingQueue<>(100_000);
    private final LocalFileBuffer fileBuffer = new LocalFileBuffer("/data/exposure_buffer");
    private final KafkaProducer<ExposureLog> kafkaProducer;

    @Autowired
    private IdempotentManager idempotentManager;

    /**
     * 异步上报曝光日志
     */
    public void reportAsync(ExposureLog log) {
        // 曝光幂等：同一requestId只上报一次
        String idempotentKey = "EXPOSURE:" + log.getRequestId();
        if (!idempotentManager.setIfAbsent(idempotentKey, "1", 1, TimeUnit.HOURS)) {
            log.debug("[ExposureLog] 曝光幂等命中, skip, requestId={}", log.getRequestId());
            return;
        }

        boolean offered = logQueue.offer(log);
        if (!offered) {
            // 队列满时写入本地文件缓冲
            fileBuffer.write(log);
            log.warn("[ExposureLog] 曝光日志队列满, 写入本地缓冲, requestId={}",
                    log.getRequestId());
        }
    }

    /**
     * 定时批量上报到Kafka
     */
    @Scheduled(fixedDelay = 5000)
    public void flushToKafka() {
        List<ExposureLog> batch = new ArrayList<>(1000);
        logQueue.drainTo(batch, 1000);

        // 补充本地缓冲的日志
        batch.addAll(fileBuffer.readBatch(500));

        if (batch.isEmpty()) {
            return;
        }

        try {
            kafkaProducer.sendBatch(batch);
            log.info("[ExposureLog] 批量上报成功, count={}", batch.size());
        } catch (Exception e) {
            // 上报失败写回本地缓冲，等待下次重试
            fileBuffer.writeAll(batch);
            log.error("[ExposureLog] 批量上报失败, 缓冲重试, count={}", batch.size(), e);
        }
    }
}
```

### 7.3 案例三：实验效果分析全链路

**场景描述**：实验运行14天后，产品经理需要评估实验效果。系统自动收集实验期间的分流日志和业务埋点数据，计算关键指标，执行显著性检验和CUPED方差缩减，产出实验结论，并根据结论自动推全或下线实验。

**全链路流程**：数据收集 -> 指标计算 -> 显著性检验 -> 结论产出 -> 实验下线

```java
/**
 * 案例三：实验效果分析全链路
 * 
 * 完整流程：
 * 1. 收集实验期间分流日志和业务埋点数据
 * 2. 对齐分流日志与业务数据，计算关键指标
 * 3. 执行CUPED方差缩减 + t检验显著性检验
 * 4. 产出实验结论（显著正向/显著负向/不显著）
 * 5. 根据结论推全策略或下线实验
 */
@Service
@Slf4j
public class ExperimentAnalysisService {

    @Autowired
    private ExperimentStore experimentStore;
    @Autowired
    private DiversionLogStore diversionLogStore;
    @Autowired
    private BusinessMetricStore businessMetricStore;
    @Autowired
    private SignificanceTester significanceTester;
    @Autowired
    private CUPEDProcessor cupedProcessor;
    @Autowired
    private SRMChecker srmChecker;
    @Autowired
    private RolloutManager rolloutManager;
    @Autowired
    private IdempotentManager idempotentManager;
    @Autowired
    private NotificationService notificationService;

    private static final int LOOKBACK_DAYS = 14;
    private static final String IDEMPOTENT_PREFIX = "EXP_ANALYZE:";

    /**
     * 全链路：实验效果分析
     * 
     * @param experimentId 实验ID
     * @return 实验分析报告
     */
    public ExperimentReport analyzeExperiment(Long experimentId) {
        String idempotentKey = IDEMPOTENT_PREFIX + experimentId;
        long startTime = System.currentTimeMillis();

        // ==================== 幂等控制 ====================
        // 同一实验的分析任务在24小时内只执行一次
        ExperimentReport existingReport = idempotentManager.get(idempotentKey,
                ExperimentReport.class);
        if (existingReport != null) {
            log.info("[Analysis] 幂等命中, experimentId={}, reportId={}",
                    experimentId, existingReport.getReportId());
            return existingReport;
        }

        try {
            log.info("[Analysis] 开始实验效果分析, experimentId={}", experimentId);

            // ==================== Step1: 数据收集 ====================
            Experiment experiment = experimentStore.getById(experimentId);
            if (experiment == null) {
                throw new ExperimentNotFoundException("实验不存在: " + experimentId);
            }
            if (experiment.getStatus() != ExperimentStatus.RUNNING
                    && experiment.getStatus() != ExperimentStatus.PAUSED) {
                throw new ExperimentStateException(
                        "实验状态不支持分析: " + experiment.getStatus());
            }

            // 收集实验期间的分流日志
            Map<String, DiversionLog> diversionLogs = collectDiversionLogs(experiment);
            log.info("[Analysis] 分流日志收集完成, experimentId={}, 日志数={}",
                    experimentId, diversionLogs.size());

            // 按流量组分组用户
            List<String> experimentGroupUsers = new ArrayList<>();
            List<String> controlGroupUsers = new ArrayList<>();
            for (Map.Entry<String, DiversionLog> entry : diversionLogs.entrySet()) {
                if (isExperimentGroup(entry.getValue(), experiment)) {
                    experimentGroupUsers.add(entry.getKey());
                } else if (isControlGroup(entry.getValue(), experiment)) {
                    controlGroupUsers.add(entry.getKey());
                }
            }
            log.info("[Analysis] 用户分组完成, 实验组用户数={}, 对照组用户数={}",
                    experimentGroupUsers.size(), controlGroupUsers.size());

            // SRM检查
            double srmPValue = srmChecker.check(
                    experimentGroupUsers.size(), controlGroupUsers.size());
            if (srmPValue < 0.05) {
                log.warn("[Analysis] SRM检查未通过, expUsers={}, ctrlUsers={}, p-value={}",
                        experimentGroupUsers.size(), controlGroupUsers.size(), srmPValue);
            }

            // 收集业务埋点数据
            Map<String, UserBusinessMetrics> expBusinessMetrics =
                    businessMetricStore.fetchMetrics(experimentGroupUsers,
                            experiment.getStartTime(), new Date());
            Map<String, UserBusinessMetrics> ctrlBusinessMetrics =
                    businessMetricStore.fetchMetrics(controlGroupUsers,
                            experiment.getStartTime(), new Date());
            log.info("[Analysis] 业务数据收集完成, 实验组指标用户数={}, 对照组指标用户数={}",
                    expBusinessMetrics.size(), ctrlBusinessMetrics.size());

            // ==================== Step2: 指标计算 ====================
            List<MetricResult> metricResults = new ArrayList<>();
            for (String metricName : experiment.getTargetMetrics()) {
                MetricResult metricResult = calculateMetric(
                        metricName, expBusinessMetrics, ctrlBusinessMetrics,
                        experimentGroupUsers, controlGroupUsers);
                metricResults.add(metricResult);
                log.info("[Analysis] 指标计算完成, metric={}, expMean={}, ctrlMean={}, "
                        + "absoluteDiff={}, relativeDiff={}",
                        metricName, metricResult.getExpMean(), metricResult.getCtrlMean(),
                        metricResult.getAbsoluteDiff(), metricResult.getRelativeDiff());
            }

            // ==================== Step3: 显著性检验 ====================
            List<SignificanceResult> significanceResults = new ArrayList<>();
            for (MetricResult metricResult : metricResults) {
                // 先执行CUPED方差缩减
                Map<String, Double> expCurrent = extractMetricValues(
                        expBusinessMetrics, metricResult.getMetricName());
                Map<String, Double> ctrlCurrent = extractMetricValues(
                        ctrlBusinessMetrics, metricResult.getMetricName());

                Map<String, Double> expPre = businessMetricStore.fetchPreMetrics(
                        experimentGroupUsers, LOOKBACK_DAYS);
                Map<String, Double> ctrlPre = businessMetricStore.fetchPreMetrics(
                        controlGroupUsers, LOOKBACK_DAYS);

                Map<String, Double> expCuped = cupedProcessor.applyCUPED(expCurrent, expPre);
                Map<String, Double> ctrlCuped = cupedProcessor.applyCUPED(ctrlCurrent, ctrlPre);

                // t检验
                List<Double> expValues = new ArrayList<>(expCuped.values());
                List<Double> ctrlValues = new ArrayList<>(ctrlCuped.values());

                SignificanceResult sigResult = significanceTester.test(
                        expValues, ctrlValues, metricResult.getMetricName());
                significanceResults.add(sigResult);

                log.info("[Analysis] 显著性检验完成, metric={}, pValue={}, isSignificant={}, "
                        + "relativeDiff={}, CI=[{}, {}]",
                        metricResult.getMetricName(), sigResult.getPValue(),
                        sigResult.isSignificant(), sigResult.getRelativeDiff(),
                        sigResult.getConfidenceInterval()[0],
                        sigResult.getConfidenceInterval()[1]);
            }

            // ==================== Step4: 结论产出 ====================
            ExperimentConclusion conclusion = generateConclusion(
                    experiment, significanceResults, srmPValue);
            log.info("[Analysis] 实验结论产出, experimentId={}, conclusion={}, "
                    + "recommendAction={}, summary={}",
                    experimentId, conclusion.getConclusionType(),
                    conclusion.getRecommendAction(), conclusion.getSummary());

            ExperimentReport report = ExperimentReport.builder()
                    .reportId(UUID.randomUUID().toString())
                    .experimentId(experimentId)
                    .experimentName(experiment.getName())
                    .analysisTime(new Date())
                    .experimentDurationDays(calculateDurationDays(experiment))
                    .experimentGroupSize(experimentGroupUsers.size())
                    .controlGroupSize(controlGroupUsers.size())
                    .srmPValue(srmPValue)
                    .metricResults(metricResults)
                    .significanceResults(significanceResults)
                    .conclusion(conclusion)
                    .build();

            // ==================== Step5: 实验下线/推全 ====================
            ExperimentStateMachine.transition(experiment, ExperimentStatus.ANALYZING);
            experimentStore.update(experiment);

            handleExperimentAction(experiment, conclusion, report);

            // ==================== 记录幂等 ====================
            idempotentManager.set(idempotentKey, report, 24, TimeUnit.HOURS);

            long elapsed = System.currentTimeMillis() - startTime;
            log.info("[Analysis] 实验效果分析全链路完成, experimentId={}, reportId={}, 耗时={}ms",
                    experimentId, report.getReportId(), elapsed);

            return report;

        } catch (ExperimentNotFoundException e) {
            log.error("[Analysis] 实验不存在, experimentId={}", experimentId, e);
            throw e;
        } catch (DataCollectException e) {
            log.error("[Analysis] 数据收集失败, experimentId={}", experimentId, e);
            throw new AnalysisException("数据收集失败: " + e.getMessage(), e);
        } catch (AnalysisException e) {
            log.error("[Analysis] 分析过程异常, experimentId={}", experimentId, e);
            throw e;
        } catch (Exception e) {
            log.error("[Analysis] 实验效果分析失败, experimentId={}", experimentId, e);
            throw new AnalysisException("实验效果分析失败: " + e.getMessage(), e);
        }
    }

    /**
     * Step1: 收集实验期间的分流日志
     */
    private Map<String, DiversionLog> collectDiversionLogs(Experiment experiment) {
        Date startTime = experiment.getStartTime();
        Date endTime = new Date();

        try {
            Map<String, DiversionLog> logs = diversionLogStore.queryByExperiment(
                    experiment.getId(), startTime, endTime);
            if (logs.isEmpty()) {
                throw new DataCollectException(
                        "未找到分流日志, experimentId=" + experiment.getId());
            }
            return logs;
        } catch (DataCollectException e) {
            throw e;
        } catch (Exception e) {
            throw new DataCollectException("分流日志查询失败: " + e.getMessage(), e);
        }
    }

    /**
     * Step2: 计算单个指标
     */
    private MetricResult calculateMetric(String metricName,
                                         Map<String, UserBusinessMetrics> expMetrics,
                                         Map<String, UserBusinessMetrics> ctrlMetrics,
                                         List<String> expUsers,
                                         List<String> ctrlUsers) {
        List<Double> expValues = expUsers.stream()
                .filter(expMetrics::containsKey)
                .map(u -> expMetrics.get(u).getMetricValue(metricName))
                .filter(Objects::nonNull)
                .collect(Collectors.toList());

        List<Double> ctrlValues = ctrlUsers.stream()
                .filter(ctrlMetrics::containsKey)
                .map(u -> ctrlMetrics.get(u).getMetricValue(metricName))
                .filter(Objects::nonNull)
                .collect(Collectors.toList());

        double expMean = Statistics.mean(expValues);
        double ctrlMean = Statistics.mean(ctrlValues);
        double absoluteDiff = expMean - ctrlMean;
        double relativeDiff = ctrlMean != 0 ? absoluteDiff / ctrlMean : 0.0;

        return MetricResult.builder()
                .metricName(metricName)
                .expMean(expMean)
                .ctrlMean(ctrlMean)
                .absoluteDiff(absoluteDiff)
                .relativeDiff(relativeDiff)
                .expSampleSize(expValues.size())
                .ctrlSampleSize(ctrlValues.size())
                .build();
    }

    /**
     * Step4: 产出实验结论
     */
    private ExperimentConclusion generateConclusion(Experiment experiment,
                                                    List<SignificanceResult> sigResults,
                                                    double srmPValue) {
        // 获取目标指标和护栏指标的检验结果
        SignificanceResult targetResult = sigResults.stream()
                .filter(r -> r.getMetricName().equals(experiment.getTargetMetric()))
                .findFirst()
                .orElse(sigResults.get(0));

        // 检查护栏指标是否显著负向
        boolean guardMetricNegative = false;
        for (String guardMetric : experiment.getGuardMetrics()) {
            SignificanceResult guardResult = sigResults.stream()
                    .filter(r -> r.getMetricName().equals(guardMetric))
                    .findFirst().orElse(null);
            if (guardResult != null && guardResult.isSignificant()
                    && guardResult.getRelativeDiff() < 0) {
                guardMetricNegative = true;
                break;
            }
        }

        ConclusionType conclusionType;
        String recommendAction;
        String summary;

        if (srmPValue < 0.05) {
            conclusionType = ConclusionType.INVALID;
            recommendAction = "样本比例不匹配，实验无效，建议排查分流链路后重新实验";
            summary = String.format("SRM检查未通过(p=%.4f)，实验数据不可信", srmPValue);
        } else if (guardMetricNegative) {
            conclusionType = ConclusionType.NEGATIVE;
            recommendAction = "护栏指标显著负向，建议不推全并下线实验";
            summary = "护栏指标存在显著负向，策略有风险";
        } else if (targetResult.isSignificant() && targetResult.getRelativeDiff() > 0) {
            conclusionType = ConclusionType.POSITIVE;
            recommendAction = "目标指标显著正向，建议推全";
            summary = String.format("目标指标%s显著正向(提升%.2f%%, p=%.4f)，建议推全",
                    targetResult.getMetricName(),
                    targetResult.getRelativeDiff() * 100,
                    targetResult.getPValue());
        } else if (targetResult.isSignificant() && targetResult.getRelativeDiff() < 0) {
            conclusionType = ConclusionType.NEGATIVE;
            recommendAction = "目标指标显著负向，建议不推全并下线实验";
            summary = String.format("目标指标%s显著负向(下降%.2f%%, p=%.4f)，不建议推全",
                    targetResult.getMetricName(),
                    Math.abs(targetResult.getRelativeDiff() * 100),
                    targetResult.getPValue());
        } else {
            conclusionType = ConclusionType.INCONCLUSIVE;
            recommendAction = "指标不显著，建议延长实验周期或增大流量后重新分析";
            summary = String.format("目标指标%s不显著(提升%.2f%%, p=%.4f)，无法得出结论",
                    targetResult.getMetricName(),
                    targetResult.getRelativeDiff() * 100,
                    targetResult.getPValue());
        }

        return ExperimentConclusion.builder()
                .conclusionType(conclusionType)
                .recommendAction(recommendAction)
                .summary(summary)
                .targetMetricResult(targetResult)
                .srmPValue(srmPValue)
                .build();
    }

    /**
     * Step5: 根据结论执行推全或下线
     */
    private void handleExperimentAction(Experiment experiment,
                                        ExperimentConclusion conclusion,
                                        ExperimentReport report) {
        try {
            switch (conclusion.getConclusionType()) {
                case POSITIVE:
                    // 显著正向 -> 推全
                    log.info("[Analysis] 实验显著正向，执行推全, experimentId={}",
                            experiment.getId());
                    Long winningStrategyId = experiment.getFlowGroups().get(0).getStrategyId();
                    rolloutManager.rollout(experiment, winningStrategyId,
                            RolloutConfig.defaultGrayConfig());
                    notificationService.notify(experiment.getCreator(),
                            String.format("实验[%s]分析完成：%s\n建议操作：%s",
                                    experiment.getName(),
                                    conclusion.getSummary(),
                                    conclusion.getRecommendAction()));
                    break;

                case NEGATIVE:
                case INCONCLUSIVE:
                    // 显著负向或不显著 -> 下线实验
                    log.info("[Analysis] 实验结论为{}，执行下线, experimentId={}",
                            conclusion.getConclusionType(), experiment.getId());
                    ExperimentStateMachine.transition(experiment, ExperimentStatus.FINISHED);
                    experiment.setEndTime(new Date());
                    experimentStore.update(experiment);
                    notificationService.notify(experiment.getCreator(),
                            String.format("实验[%s]已下线：%s\n建议操作：%s",
                                    experiment.getName(),
                                    conclusion.getSummary(),
                                    conclusion.getRecommendAction()));
                    break;

                case INVALID:
                    // 数据无效 -> 暂停实验
                    log.warn("[Analysis] 实验数据无效，暂停实验, experimentId={}",
                            experiment.getId());
                    ExperimentStateMachine.transition(experiment, ExperimentStatus.PAUSED);
                    experimentStore.update(experiment);
                    notificationService.sendUrgent(experiment.getCreator(),
                            String.format("实验[%s]SRM检查未通过，已自动暂停，请排查分流链路",
                                    experiment.getName()));
                    break;

                default:
                    log.warn("[Analysis] 未知结论类型, experimentId={}, conclusionType={}",
                            experiment.getId(), conclusion.getConclusionType());
            }
        } catch (ExperimentStateException e) {
            log.error("[Analysis] 实验状态流转失败, experimentId={}, currentStatus={}",
                    experiment.getId(), experiment.getStatus(), e);
            notificationService.sendUrgent(experiment.getCreator(),
                    "实验[" + experiment.getName() + "]状态流转失败: " + e.getMessage());
        } catch (Exception e) {
            log.error("[Analysis] 实验下线/推全执行异常, experimentId={}",
                    experiment.getId(), e);
            notificationService.sendUrgent(experiment.getCreator(),
                    "实验[" + experiment.getName() + "]操作失败: " + e.getMessage());
        }
    }

    /**
     * 辅助方法：判断是否为实验组
     */
    private boolean isExperimentGroup(DiversionLog log, Experiment experiment) {
        Long expFlowGroupId = experiment.getFlowGroups().get(0).getId();
        return expFlowGroupId.equals(log.getFlowGroupId());
    }

    /**
     * 辅助方法：判断是否为对照组
     */
    private boolean isControlGroup(DiversionLog log, Experiment experiment) {
        Long ctrlFlowGroupId = experiment.getFlowGroups().get(1).getId();
        return ctrlFlowGroupId.equals(log.getFlowGroupId());
    }

    /**
     * 辅助方法：提取指标值
     */
    private Map<String, Double> extractMetricValues(
            Map<String, UserBusinessMetrics> metrics, String metricName) {
        Map<String, Double> result = new HashMap<>();
        for (Map.Entry<String, UserBusinessMetrics> entry : metrics.entrySet()) {
            Double value = entry.getValue().getMetricValue(metricName);
            if (value != null) {
                result.put(entry.getKey(), value);
            }
        }
        return result;
    }

    /**
     * 辅助方法：计算实验天数
     */
    private int calculateDurationDays(Experiment experiment) {
        long diff = System.currentTimeMillis() - experiment.getStartTime().getTime();
        return (int) (diff / (1000 * 60 * 60 * 24));
    }
}

    NEGATIVE,       // 显著负向
    INCONCLUSIVE,   // 不显著
    INVALID         // 数据无效（SRM不通过等）
}
```
