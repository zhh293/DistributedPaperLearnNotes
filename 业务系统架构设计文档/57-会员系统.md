# 会员系统架构设计

## 一、问题背景

### 1.1 业务场景

会员系统是用户运营的核心基础设施，负责管理用户等级、权益、成长值、会员卡等。一个完整的会员体系包括：用户注册成为会员 → 消费/签到等行为累积成长值 → 成长值达到阈值自动升级 → 不同等级享受不同权益（折扣、积分倍率、专属客服、优先购买等） → 会员到期降级或续费。

### 1.2 核心挑战

| 挑战维度 | 具体问题 |
|---------|---------|
| 等级计算 | 成长值实时变化，等级是否需要实时更新 |
| 权益下发 | 升级后权益如何及时生效，降级后权益如何回收 |
| 并发安全 | 多笔订单同时累加成长值，如何防超 |
| 高性能 | 会员信息查询QPS极高（每次下单都要查等级和权益） |
| 会员卡 | 实体卡/虚拟卡的发放、绑定、核销 |
| 数据一致性 | 成长值变更与等级状态的一致性 |

### 1.3 设计目标

| 目标维度 | 具体要求 |
|---------|---------|
| 等级查询 | P99 < 10ms（走缓存） |
| 成长值变更 | 最终一致，允许秒级延迟 |
| 权益生效 | 升级后1分钟内权益生效 |
| 可用性 | 99.99% |

## 三、核心链路设计

### 3.1 成长值引擎

**问题**：用户每笔订单都需要累加成长值，如何保证并发安全和防重？

**方案**：MQ异步处理 + 流水防重 + 乐观锁更新。

```java
/**
 * 成长值引擎
 *
 * 完整链路：
 * 1. 订单完成 → 发送MQ消息
 * 2. 消费者接收消息 → 流水防重检查
 * 3. 乐观锁更新成长值
 * 4. 检查是否触发等级变更
 * 5. 等级变更 → 下发权益
 */
@Service
public class GrowthValueService {

    @Autowired
    private MemberMapper memberMapper;

    @Autowired
    private GrowthValueLogMapper logMapper;

    @Autowired
    private MemberLevelService levelService;

    /**
     * 累加成长值（订单完成回调）
     */
    @Transactional(rollbackFor = Exception.class)
    public void addGrowthValue(GrowthValueMessage msg) {
        // 1. 流水防重
        GrowthValueLog existLog = logMapper.selectByBiz(msg.getBizType(), msg.getBizId());
        if (existLog != null) {
            return; // 已处理
        }

        // 2. 查询当前成长值
        Member member = memberMapper.selectByUserId(msg.getUserId());
        if (member == null) {
            return;
        }

        // 3. 乐观锁更新成长值
        long beforeValue = member.getGrowthValue();
        long afterValue = beforeValue + msg.getChangeValue();
        int updated = memberMapper.updateGrowthValue(
            msg.getUserId(), afterValue, beforeValue);

        if (updated == 0) {
            // 乐观锁冲突，重试
            throw new RuntimeException("成长值更新冲突，重试");
        }

        // 4. 记录流水
        GrowthValueLog log = new GrowthValueLog();
        log.setUserId(msg.getUserId());
        log.setChangeValue(msg.getChangeValue());
        log.setBeforeValue(beforeValue);
        log.setAfterValue(afterValue);
        log.setBizType(msg.getBizType());
        log.setBizId(msg.getBizId());
        log.setCreateTime(new Date());
        logMapper.insert(log);

        // 5. 检查等级变更
        levelService.checkLevelChange(msg.getUserId(), afterValue);
    }
}

/**
 * 成长值MQ消费者
 */
@Component
@RocketMQMessageListener(topic = "growth-value-topic",
    consumerGroup = "growth-value-consumer-group")
public class GrowthValueConsumer implements RocketMQListener<GrowthValueMessage> {

    @Autowired
    private GrowthValueService growthValueService;

    @Override
    public void onMessage(GrowthValueMessage msg) {
        try {
            growthValueService.addGrowthValue(msg);
        } catch (Exception e) {
            log.error("成长值累加失败, userId={}, bizId={}",
                msg.getUserId(), msg.getBizId(), e);
            throw e; // 触发重试
        }
    }
}
```

### 3.2 等级变更引擎

```java
/**
 * 会员等级服务
 *
 * 核心逻辑：
 * 1. 成长值变更后检查是否达到升级阈值
 * 2. 升级 → 更新等级 → 下发新权益 → 通知用户
 * 3. 降级（会员到期后）→ 更新等级 → 回收权益 → 通知用户
 */
@Service
public class MemberLevelService {

    @Autowired
    private MemberMapper memberMapper;

    @Autowired
    private MemberLevelConfigMapper configMapper;

    @Autowired
    private BenefitService benefitService;

    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 检查等级变更
     */
    public void checkLevelChange(Long userId, long currentGrowthValue) {
        Member member = memberMapper.selectByUserId(userId);
        int currentLevel = member.getLevel();

        // 查询所有等级配置
        List<MemberLevelConfig> configs = configMapper.selectAllOrdered();
        MemberLevelConfig targetLevel = null;
        for (MemberLevelConfig config : configs) {
            if (currentGrowthValue >= config.getMinGrowth()) {
                targetLevel = config;
            }
        }

        if (targetLevel == null) {
            return;
        }

        // 等级变化
        if (targetLevel.getLevel() > currentLevel) {
            // 升级
            upgrade(userId, currentLevel, targetLevel);
        }
        // 降级只在会员到期时触发，不在日常成长值变更时触发
    }

    /**
     * 升级
     */
    @Transactional(rollbackFor = Exception.class)
    public void upgrade(Long userId, int oldLevel, MemberLevelConfig newLevelConfig) {
        // 1. 更新等级
        memberMapper.updateLevel(userId, newLevelConfig.getLevel());

        // 2. 清除等级缓存
        redisTemplate.delete("member:level:" + userId);

        // 3. 下发权益
        benefitService.grantBenefits(userId, newLevelConfig.getLevel());

        // 4. 发送升级通知
        notifyService.sendUpgradeNotification(userId,
            oldLevel, newLevelConfig.getLevel());

        log.info("会员升级, userId={}, {} → {}",
            userId, oldLevel, newLevelConfig.getLevel());
    }

    /**
     * 会员到期降级检查（定时任务）
     */
    @Scheduled(cron = "0 0 1 * * ?")  // 每天凌晨1点
    public void checkExpiredMembers() {
        List<Member> expired = memberMapper.selectExpired(new Date());
        for (Member member : expired) {
            try {
                // 根据当前成长值重新计算等级
                List<MemberLevelConfig> configs = configMapper.selectAllOrdered();
                int newLevel = 0; // 默认降为注册会员
                for (MemberLevelConfig config : configs) {
                    if (member.getGrowthValue() >= config.getMinGrowth()) {
                        newLevel = config.getLevel();
                    }
                }

                if (newLevel < member.getLevel()) {
                    // 降级
                    memberMapper.updateLevel(member.getUserId(), newLevel);
                    // 回收权益
                    benefitService.revokeBenefits(member.getUserId(),
                        member.getLevel(), newLevel);
                    // 通知用户
                    notifyService.sendDowngradeNotification(
                        member.getUserId(), member.getLevel(), newLevel);
                }

                // 延长会员有效期（如果仍在成长值范围内）
                memberMapper.extendExpireTime(member.getUserId(),
                    DateUtils.addYears(new Date(), 1));
            } catch (Exception e) {
                log.error("会员到期处理失败, userId={}", member.getUserId(), e);
            }
        }
    }
}
```

### 3.3 权益引擎

```java
/**
 * 权益服务
 *
 * 权益类型：
 * 1. 积分倍率：金卡x1.5, 白金x2, 钻石x3
 * 2. 折扣优惠：金卡95折, 白金9折, 钻石85折
 * 3. 专属客服：白金及以上
 * 4. 优先购买：钻石
 * 5. 生日礼包：金卡及以上
 */
@Service
public class BenefitService {

    @Autowired
    private MemberLevelConfigMapper configMapper;

    @Autowired
    private CouponFeignClient couponClient;

    /**
     * 下发权益（升级时）
     */
    public void grantBenefits(Long userId, int level) {
        MemberLevelConfig config = configMapper.selectByLevel(level);
        List<Benefit> benefits = JSON.parseArray(
            config.getBenefits(), Benefit.class);

        for (Benefit benefit : benefits) {
            switch (benefit.getType()) {
                case "COUPON":
                    // 下发优惠券
                    couponClient.grant(userId, benefit.getCouponTemplateId());
                    break;
                case "POINT_RATE":
                    // 积分倍率是实时查询的，不需要下发
                    break;
                case "DISCOUNT":
                    // 折扣率也是实时查询的
                    break;
                case "BIRTHDAY_GIFT":
                    // 注册生日礼包定时任务
                    registerBirthdayGift(userId, level);
                    break;
            }
        }
    }

    /**
     * 回收权益（降级时）
     */
    public void revokeBenefits(Long userId, int oldLevel, int newLevel) {
        MemberLevelConfig oldConfig = configMapper.selectByLevel(oldLevel);
        MemberLevelConfig newConfig = configMapper.selectByLevel(newLevel);

        Set<String> oldBenefitTypes = JSON.parseArray(
            oldConfig.getBenefits(), Benefit.class)
            .stream().map(Benefit::getType).collect(Collectors.toSet());
        Set<String> newBenefitTypes = JSON.parseArray(
            newConfig.getBenefits(), Benefit.class)
            .stream().map(Benefit::getType).collect(Collectors.toSet());

        // 需要回收的权益 = 旧有 - 新有
        oldBenefitTypes.removeAll(newBenefitTypes);

        for (String type : oldBenefitTypes) {
            if ("BIRTHDAY_GIFT".equals(type)) {
                cancelBirthdayGift(userId);
            }
            // 积分倍率/折扣率不需要主动回收，下次查询时自动取新等级的值
        }
    }

    /**
     * 查询用户权益（高频查询，走缓存）
     */
    public MemberBenefitsVO queryBenefits(Long userId) {
        // 1. 查缓存
        String cacheKey = "member:benefits:" + userId;
        String cached = redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return JSON.parseObject(cached, MemberBenefitsVO.class);
        }

        // 2. 查DB
        Member member = memberMapper.selectByUserId(userId);
        MemberLevelConfig config = configMapper.selectByLevel(member.getLevel());

        MemberBenefitsVO vo = new MemberBenefitsVO();
        vo.setLevel(member.getLevel());
        vo.setLevelName(config.getLevelName());
        vo.setPointRate(config.getPointRate());
        vo.setDiscountRate(config.getDiscountRate());
        vo.setBenefits(JSON.parseArray(config.getBenefits(), Benefit.class));

        // 3. 回填缓存
        redisTemplate.opsForValue().set(cacheKey,
            JSON.toJSONString(vo), 10, TimeUnit.MINUTES);

        return vo;
    }
}
```

### 3.4 会员卡管理

```java
/**
 * 会员卡服务
 *
 * 会员卡类型：
 * 1. 实体卡：线下发放，用户扫码绑定
 * 2. 虚拟卡：线上购买，自动绑定
 *
 * 卡状态流转：未发放 → 已发放 → 已绑定 → 已核销/已过期
 */
@Service
public class MemberCardService {

    /**
     * 发放会员卡
     */
    @Transactional(rollbackFor = Exception.class)
    public String issueCard(CardIssueRequest request) {
        String cardNo = generateCardNo();
        MemberCard card = new MemberCard();
        card.setCardNo(cardNo);
        card.setCardType(request.getCardType());
        card.setStatus(CardStatus.ISSUED.getCode());
        card.setIssueTime(new Date());
        card.setExpireTime(DateUtils.addYears(new Date(),
            request.getValidYears()));
        cardMapper.insert(card);
        return cardNo;
    }

    /**
     * 绑定会员卡
     */
    @Transactional(rollbackFor = Exception.class)
    public void bindCard(String cardNo, Long userId) {
        MemberCard card = cardMapper.selectByCardNo(cardNo);
        if (card == null) {
            throw new BizException("会员卡不存在");
        }
        if (card.getStatus() != CardStatus.ISSUED.getCode()) {
            throw new BizException("会员卡状态不允许绑定");
        }
        if (card.getExpireTime().before(new Date())) {
            throw new BizException("会员卡已过期");
        }

        // 绑定
        card.setUserId(userId);
        card.setStatus(CardStatus.BOUND.getCode());
        card.setBindTime(new Date());
        cardMapper.updateById(card);

        // 根据卡类型设置会员等级
        // 例如：金卡 → 金卡会员等级
        memberMapper.upgradeToLevel(userId, card.getCardType());
    }
}
```

## 四、性能优化

### 4.1 等级信息缓存

```java
/**
 * 会员等级信息缓存策略
 *
 * 读取链路：Caffeine(1秒) → Redis(10分钟) → MySQL
 * 写入时：更新MySQL → 删除Redis → 等待Caffeine自然过期
 */
@Service
public class MemberCacheService {

    private final Cache<Long, MemberLevelInfo> localCache = Caffeine.newBuilder()
        .maximumSize(50000)
        .expireAfterWrite(1, TimeUnit.SECONDS)
        .build();

    public MemberLevelInfo getLevelInfo(Long userId) {
        // 本地缓存
        MemberLevelInfo local = localCache.getIfPresent(userId);
        if (local != null) {
            return local;
        }

        // Redis
        String key = "member:level:" + userId;
        String json = redisTemplate.opsForValue().get(key);
        if (json != null) {
            MemberLevelInfo info = JSON.parseObject(json, MemberLevelInfo.class);
            localCache.put(userId, info);
            return info;
        }

        // MySQL
        Member member = memberMapper.selectByUserId(userId);
        MemberLevelConfig config = configMapper.selectByLevel(member.getLevel());

        MemberLevelInfo info = new MemberLevelInfo();
        info.setUserId(userId);
        info.setLevel(member.getLevel());
        info.setLevelName(config.getLevelName());
        info.setPointRate(config.getPointRate());
        info.setDiscountRate(config.getDiscountRate());

        // 回填缓存
        redisTemplate.opsForValue().set(key,
            JSON.toJSONString(info), 10, TimeUnit.MINUTES);
        localCache.put(userId, info);

        return info;
    }
}
```

### 4.2 成长值批量处理

```java
/**
 * 成长值批量处理
 *
 * 高峰期大量订单完成会触发大量成长值变更MQ消息
 * 批量消费减少DB压力
 */
@Component
@RocketMQMessageListener(topic = "growth-value-topic",
    consumerGroup = "growth-value-batch-consumer-group",
    consumeMode = ConsumeMode.CONCURRENTLY,
    consumeThreadMax = 20)
public class GrowthValueBatchConsumer implements RocketMQListener<GrowthValueMessage> {

    // 使用本地队列缓冲，定时批量处理
    private final BlockingQueue<GrowthValueMessage> queue =
        new LinkedBlockingQueue<>(10000);

    @Override
    public void onMessage(GrowthValueMessage msg) {
        queue.offer(msg);
    }

    @Scheduled(fixedRate = 1000)
    public void batchProcess() {
        List<GrowthValueMessage> batch = new ArrayList<>(500);
        queue.drainTo(batch, 500);
        if (batch.isEmpty()) return;

        // 按用户分组
        Map<Long, List<GrowthValueMessage>> byUser = batch.stream()
            .collect(Collectors.groupingBy(GrowthValueMessage::getUserId));

        for (Map.Entry<Long, List<GrowthValueMessage>> entry : byUser.entrySet()) {
            processUserBatch(entry.getKey(), entry.getValue());
        }
    }
}
```

## 五、异常处理与容错

### 5.1 成长值对账

```java
/**
 * 成长值对账定时任务
 *
 * 对账逻辑：
 * sum(growth_value_log.change_value) = member.growth_value
 * 不一致时以流水合计为准修正
 */
@Scheduled(cron = "0 0 3 * * ?")
public void reconcileGrowthValue() {
    int pageSize = 1000;
    int offset = 0;

    while (true) {
        List<Member> members = memberMapper.selectBatch(offset, pageSize);
        if (members.isEmpty()) break;

        for (Member member : members) {
            Long sumFromLog = logMapper.sumChangeValueByUser(member.getUserId());
            if (sumFromLog == null) sumFromLog = 0L;

            if (!sumFromLog.equals(member.getGrowthValue())) {
                log.error("成长值不一致! userId={}, member={}, log={}",
                    member.getUserId(), member.getGrowthValue(), sumFromLog);

                // 以流水为准修正
                memberMapper.updateGrowthValue(
                    member.getUserId(), sumFromLog, member.getGrowthValue());

                // 重新检查等级
                levelService.checkLevelChange(member.getUserId(), sumFromLog);
            }
        }

        offset += pageSize;
    }
}
```

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 成长值累加 | MQ异步 + 乐观锁 | 不阻塞订单主流程 |
| 等级变更 | 成长值变更后触发检查 | 实时性要求不高 |
| 权益下发 | 升级时主动下发 | 权益及时生效 |
| 权益回收 | 降级时主动回收 | 防止权益滥用 |
| 等级查询 | Caffeine+Redis多级缓存 | 高性能 |
| 防重 | 流水表唯一索引 | 幂等保证 |

### 6.2 容易踩的坑

1. **成长值重复累加**：MQ重复消费导致同一笔订单加两次成长值，必须流水防重
2. **升级未下发权益**：升级了等级但忘记下发权益，用户感知不到升级
3. **降级未回收权益**：降级了等级但生日礼包等权益未取消
4. **等级缓存不一致**：升级后未及时清除缓存，用户看到的还是旧等级
5. **并发乐观锁冲突**：多笔订单同时完成，成长值并发更新冲突，需要重试机制

#### 7.1.3 Service层核心逻辑

```java
/**
 * 会员开通服务
 *
 * 职责：
 * 1. 资格校验（黑名单、重复开通检查）
 * 2. 创建会员订单
 * 3. 调用支付系统
 * 4. 处理支付回调
 * 5. 执行会员开通
 */
@Service
@Slf4j
public class MemberActivateService {

    @Autowired
    private MemberMapper memberMapper;
    @Autowired
    private MemberOrderMapper orderMapper;
    @Autowired
    private MemberBlacklistMapper blacklistMapper;
    @Autowired
    private MemberActivationLogMapper activationLogMapper;
    @Autowired
    private BenefitService benefitService;
    @Autowired
    private PayFeignClient payClient;
    @Autowired
    private RocketMQTemplate rocketMQTemplate;
    @Autowired
    private StringRedisTemplate redisTemplate;

    // ==================== 步骤2: 资格校验 ====================

    /**
     * 创建开通订单（包含资格校验）
     */
    @Transactional(rollbackFor = Exception.class)
    public MemberActivateResponse createActivateOrder(
            MemberActivateRequest request) {

        // 2.1 黑名单检查
        MemberBlacklist blacklist = blacklistMapper
            .selectByUserId(request.getUserId());
        if (blacklist != null) {
            // 检查黑名单是否过期
            if (blacklist.getExpireTime() == null
                    || blacklist.getExpireTime().after(new Date())) {
                throw new BizException("BLACKLISTED",
                    "您的账号暂时无法开通会员，原因："
                    + blacklist.getReason());
            }
        }

        // 2.2 检查是否已经是同等级或更高等级会员
        Member member = memberMapper.selectByUserId(request.getUserId());
        if (member != null && member.getLevel() >= request.getMemberType()
                && member.getExpireTime() != null
                && member.getExpireTime().after(new Date())) {
            throw new BizException("ALREADY_MEMBER",
                "您当前已是该等级或更高等级会员，如需续费请使用续费入口");
        }

        // 2.3 防重复提单：Redis分布式锁（同一用户30秒内不可重复提交）
        String lockKey = "member:activate:lock:" + request.getUserId();
        Boolean locked = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "1", 30, TimeUnit.SECONDS);
        if (locked == null || !locked) {
            throw new BizException("DUPLICATE_REQUEST",
                "操作过于频繁，请稍后再试");
        }

        try {
            // ==================== 步骤3: 创建会员订单 ====================

            // 3.1 生成订单号（雪花算法 + 业务前缀）
            String orderNo = "MEM" + snowflakeIdGenerator.nextId();

            // 3.2 计算金额
            BigDecimal amount = calculateAmount(
                request.getMemberType(), request.getDurationMonths());

            // 3.3 构建订单
            MemberOrder order = new MemberOrder();
            order.setOrderNo(orderNo);
            order.setUserId(request.getUserId());
            order.setMemberType(request.getMemberType());
            order.setDurationMonths(request.getDurationMonths());
            order.setAmount(amount);
            order.setPayType(request.getPayType());
            order.setOrderType(1); // 主动开通
            order.setStatus(0); // 待支付
            order.setCreateTime(new Date());
            // 订单30分钟过期
            order.setExpireTime(DateUtils.addMinutes(new Date(), 30));

            orderMapper.insert(order);

            log.info("[开通会员] 订单创建完成, orderNo={}, amount={}",
                orderNo, amount);

            // ==================== 步骤4: 调用支付系统 ====================

            PayCreateRequest payRequest = new PayCreateRequest();
            payRequest.setOutTradeNo(orderNo);
            payRequest.setAmount(amount);
            payRequest.setPayType(request.getPayType());
            payRequest.setSubject("开通" + getMemberTypeName(
                request.getMemberType()) + "会员");
            payRequest.setNotifyUrl(
                "https://api.example.com/api/v1/member/pay/callback");
            payRequest.setExpireMinutes(30);

            Result<PayCreateResponse> payResult = payClient.create(payRequest);

            if (!payResult.isSuccess()) {
                // 支付系统调用失败，标记订单为失败
                orderMapper.updateStatus(orderNo, 4); // 支付失败
                log.error("[开通会员] 调用支付系统失败, orderNo={}, msg={}",
                    orderNo, payResult.getMessage());
                throw new BizException("PAY_FAIL",
                    "支付服务暂不可用，请稍后重试");
            }

            // 返回支付参数给前端
            MemberActivateResponse response = new MemberActivateResponse();
            response.setOrderNo(orderNo);
            response.setPayParams(payResult.getData().getPayParams());
            response.setExpireTime(order.getExpireTime());

            return response;

        } finally {
            // 释放分布式锁
            redisTemplate.delete(lockKey);
        }
    }

    /**
     * 计算会员开通金额
     */
    private BigDecimal calculateAmount(int memberType, int durationMonths) {
        // 会员月单价配置
        Map<Integer, BigDecimal> priceMap = Map.of(
            1, new BigDecimal("9.90"),   // 银卡
            2, new BigDecimal("19.90"),  // 金卡
            3, new BigDecimal("39.90"),  // 白金
            4, new BigDecimal("69.90")   // 钻石
        );

        BigDecimal monthPrice = priceMap.get(memberType);
        if (monthPrice == null) {
            throw new BizException("INVALID_TYPE", "无效的会员类型");
        }

        BigDecimal total = monthPrice.multiply(
            BigDecimal.valueOf(durationMonths));

        // 年卡打8折
        if (durationMonths >= 12) {
            total = total.multiply(new BigDecimal("0.80"))
                .setScale(2, RoundingMode.HALF_UP);
        }

        return total;
    }
}
```

#### 7.1.4 支付回调处理（幂等校验 + 签名验证）

```java
/**
 * 支付回调Controller
 *
 * 接口说明：
 * POST /api/v1/member/pay/callback
 * 由支付系统回调，非用户直接调用
 *
 * 关键设计：
 * 1. 签名验证：防止伪造回调
 * 2. 幂等控制：防止重复开通
 * 3. 状态机校验：只有待支付的订单才能处理
 */
@RestController
@RequestMapping("/api/v1/member/pay")
@Slf4j
public class PayCallbackController {

    @Autowired
    private MemberActivateService activateService;

    @Autowired
    private PaySignatureVerifier signatureVerifier;

    @PostMapping("/callback")
    public String payCallback(@RequestBody PayCallbackRequest callback) {

        log.info("[支付回调] 收到回调, orderNo={}, tradeNo={}, status={}",
            callback.getOutTradeNo(), callback.getTradeNo(),
            callback.getTradeStatus());

        try {
            // 1. 签名验证
            boolean verified = signatureVerifier.verify(callback);
            if (!verified) {
                log.error("[支付回调] 签名验证失败, orderNo={}",
                    callback.getOutTradeNo());
                return "FAIL";
            }

            // 2. 处理回调
            activateService.handlePayCallback(callback);

            log.info("[支付回调] 处理成功, orderNo={}",
                callback.getOutTradeNo());
            return "SUCCESS";
        } catch (BizException e) {
            log.warn("[支付回调] 业务异常, orderNo={}, msg={}",
                callback.getOutTradeNo(), e.getMessage());
            // 业务异常也返回SUCCESS，避免支付系统反复重试
            return "SUCCESS";
        } catch (Exception e) {
            log.error("[支付回调] 系统异常, orderNo={}",
                callback.getOutTradeNo(), e);
            // 系统异常返回FAIL，触发支付系统重试
            return "FAIL";
        }
    }
}

/**
 * 支付回调处理Service（续）
 */
@Service
@Slf4j
public class MemberActivateService {

    // ... 前面已声明的依赖注入省略 ...

    /**
     * 处理支付回调
     */
    @Transactional(rollbackFor = Exception.class)
    public void handlePayCallback(PayCallbackRequest callback) {

        String orderNo = callback.getOutTradeNo();

        // ===== 幂等校验：先查激活日志 =====
        MemberActivationLog existLog = activationLogMapper
            .selectByOrderNo(orderNo);
        if (existLog != null && existLog.getStatus() == 1) {
            log.info("[支付回调] 已处理过, orderNo={}", orderNo);
            return; // 已成功处理，直接返回
        }

        // ===== 订单状态校验 =====
        MemberOrder order = orderMapper.selectByOrderNo(orderNo);
        if (order == null) {
            throw new BizException("ORDER_NOT_FOUND", "订单不存在");
        }

        // 状态机检查：只有待支付(0)才能流转到已支付(1)
        if (order.getStatus() != 0) {
            log.info("[支付回调] 订单状态不允许处理, orderNo={}, status={}",
                orderNo, order.getStatus());
            return;
        }

        // 支付失败
        if (!"TRADE_SUCCESS".equals(callback.getTradeStatus())) {
            orderMapper.updateStatus(orderNo, 4); // 支付失败
            log.warn("[支付回调] 支付未成功, orderNo={}, tradeStatus={}",
                orderNo, callback.getTradeStatus());
            return;
        }

        // ===== 金额校验 =====
        if (order.getAmount().compareTo(callback.getTotalAmount()) != 0) {
            log.error("[支付回调] 金额不一致! orderNo={}, "
                    + "orderAmount={}, payAmount={}",
                orderNo, order.getAmount(), callback.getTotalAmount());
            orderMapper.updateStatus(orderNo, 4);
            return;
        }

        // ===== 更新订单状态为已支付 =====
        order.setStatus(1); // 已支付
        order.setPayTradeNo(callback.getTradeNo());
        order.setPayTime(new Date());
        int updated = orderMapper.updateStatusWithCas(
            orderNo, 1, 0); // CAS: 0→1
        if (updated == 0) {
            log.warn("[支付回调] CAS更新失败(并发), orderNo={}", orderNo);
            return;
        }

        // ===== 步骤6: 执行会员开通 =====
        try {
            activateMember(order);
        } catch (Exception e) {
            log.error("[支付回调] 会员开通失败, orderNo={}", orderNo, e);
            // 发送补偿消息，异步重试
            sendCompensationMessage(order);
            throw e;
        }
    }

    // ==================== 步骤6: 会员权益开通 ====================

    /**
     * 执行会员开通
     *
     * 逻辑：
     * 1. 创建/更新会员记录
     * 2. 计算有效期（新开通/叠加）
     * 3. 下发权益
     * 4. 更新订单状态为已开通
     * 5. 清除缓存
     * 6. 通知下游系统
     */
    @Transactional(rollbackFor = Exception.class)
    public void activateMember(MemberOrder order) {

        Long userId = order.getUserId();
        String orderNo = order.getOrderNo();

        // 6.1 写入激活日志（幂等锁定）
        MemberActivationLog activationLog = new MemberActivationLog();
        activationLog.setUserId(userId);
        activationLog.setOrderNo(orderNo);
        activationLog.setStatus(0); // 处理中
        activationLog.setCreateTime(new Date());

        try {
            activationLogMapper.insert(activationLog);
        } catch (DuplicateKeyException e) {
            // 重复插入，说明已在处理中或已完成
            MemberActivationLog exist = activationLogMapper
                .selectByOrderNo(orderNo);
            if (exist != null && exist.getStatus() == 1) {
                log.info("[会员开通] 已成功处理, orderNo={}", orderNo);
                return;
            }
            // 处理中的情况，抛出异常等待重试
            throw new BizException("PROCESSING", "正在处理中");
        }

        // 6.2 查询或创建会员记录
        Member member = memberMapper.selectByUserId(userId);
        int oldLevel = 0;
        Date oldExpireTime = null;

        if (member == null) {
            // 新会员：创建会员记录
            member = new Member();
            member.setUserId(userId);
            member.setMemberNo("M" + snowflakeIdGenerator.nextId());
            member.setLevel(order.getMemberType());
            member.setGrowthValue(0L);
            member.setStatus(1);
            member.setRegisterTime(new Date());
            member.setExpireTime(DateUtils.addMonths(
                new Date(), order.getDurationMonths()));
            member.setCreateTime(new Date());
            member.setUpdateTime(new Date());
            memberMapper.insert(member);
        } else {
            // 老会员：升级或续期
            oldLevel = member.getLevel();
            oldExpireTime = member.getExpireTime();

            // 6.3 计算有效期
            Date baseTime;
            if (member.getExpireTime() != null
                    && member.getExpireTime().after(new Date())) {
                // 会员未过期，在原有效期基础上叠加
                baseTime = member.getExpireTime();
            } else {
                // 会员已过期，从当前时间开始计算
                baseTime = new Date();
            }

            Date newExpireTime = DateUtils.addMonths(
                baseTime, order.getDurationMonths());

            // 更新等级（取较高等级）
            int newLevel = Math.max(
                member.getLevel(), order.getMemberType());

            memberMapper.updateLevelAndExpire(
                userId, newLevel, newExpireTime);
            member.setLevel(newLevel);
            member.setExpireTime(newExpireTime);
        }

        // 6.4 下发权益
        benefitService.grantBenefits(userId, member.getLevel());

        // 6.5 更新订单状态为已开通
        orderMapper.updateStatus(orderNo, 2); // 已开通

        // 6.6 更新激活日志
        activationLog.setOldLevel(oldLevel);
        activationLog.setNewLevel(member.getLevel());
        activationLog.setOldExpireTime(oldExpireTime);
        activationLog.setNewExpireTime(member.getExpireTime());
        activationLog.setStatus(1); // 成功
        activationLogMapper.updateByOrderNo(activationLog);

        // 6.7 清除缓存
        redisTemplate.delete("member:level:" + userId);
        redisTemplate.delete("member:benefits:" + userId);

        log.info("[会员开通] 开通成功, userId={}, level={}, "
                + "expireTime={}, orderNo={}",
            userId, member.getLevel(), member.getExpireTime(), orderNo);

        // ==================== 步骤7: 通知下游系统 ====================
        sendDownstreamNotifications(userId, member, order);
    }

    /**
     * 通知下游系统（异步MQ）
     */
    private void sendDownstreamNotifications(
            Long userId, Member member, MemberOrder order) {

        // 7.1 用户推送通知
        MemberNotifyMessage notifyMsg = new MemberNotifyMessage();
        notifyMsg.setUserId(userId);
        notifyMsg.setTitle("会员开通成功");
        notifyMsg.setContent(String.format(
            "恭喜您成功开通%s会员，有效期至%s",
            getMemberTypeName(member.getLevel()),
            DateFormatUtils.format(
                member.getExpireTime(), "yyyy-MM-dd")));
        rocketMQTemplate.convertAndSend(
            "member-notify-topic", notifyMsg);

        // 7.2 同步到积分系统（积分倍率变更）
        MemberLevelChangeMessage levelMsg = new MemberLevelChangeMessage();
        levelMsg.setUserId(userId);
        levelMsg.setNewLevel(member.getLevel());
        levelMsg.setExpireTime(member.getExpireTime());
        rocketMQTemplate.convertAndSend(
            "member-level-change-topic", levelMsg);

        // 7.3 同步到客服系统（专属客服分配）
        if (member.getLevel() >= 3) { // 白金及以上
            CustomerServiceMessage csMsg = new CustomerServiceMessage();
            csMsg.setUserId(userId);
            csMsg.setVipLevel(member.getLevel());
            csMsg.setAction("ASSIGN_VIP_SERVICE");
            rocketMQTemplate.convertAndSend(
                "customer-service-topic", csMsg);
        }

        // 7.4 记录成长值（开通会员赠送成长值）
        GrowthValueMessage growthMsg = new GrowthValueMessage();
        growthMsg.setUserId(userId);
        growthMsg.setChangeValue(getActivateGrowthValue(
            member.getLevel()));
        growthMsg.setBizType("ACTIVATE");
        growthMsg.setBizId(order.getOrderNo());
        rocketMQTemplate.convertAndSend(
            "growth-value-topic", growthMsg);
    }

    // ==================== 步骤8: 失败补偿 ====================

    /**
     * 发送补偿消息（开通失败时）
     */
    private void sendCompensationMessage(MemberOrder order) {
        MemberActivateCompensation compensation =
            new MemberActivateCompensation();
        compensation.setOrderNo(order.getOrderNo());
        compensation.setUserId(order.getUserId());
        compensation.setRetryCount(0);
        compensation.setMaxRetry(5);
        compensation.setCreateTime(new Date());

        // 发送到延迟队列，30秒后第一次重试
        rocketMQTemplate.syncSend(
            "member-activate-compensation-topic",
            MessageBuilder.withPayload(compensation).build(),
            3000, 3); // delayLevel=3 约10秒
    }
}

/**
 * 开通失败补偿消费者
 *
 * 补偿策略：
 * 1. 最多重试5次，间隔依次为10s、30s、1min、5min、10min
 * 2. 重试前检查幂等：已开通则跳过
 * 3. 超过最大重试次数则告警，人工介入
 */
@Component
@RocketMQMessageListener(topic = "member-activate-compensation-topic",
    consumerGroup = "member-activate-compensation-group")
@Slf4j
public class ActivateCompensationConsumer
        implements RocketMQListener<MemberActivateCompensation> {

    @Autowired
    private MemberActivateService activateService;
    @Autowired
    private MemberOrderMapper orderMapper;
    @Autowired
    private MemberActivationLogMapper activationLogMapper;
    @Autowired
    private AlertService alertService;
    @Autowired
    private RocketMQTemplate rocketMQTemplate;

    // 重试延迟级别：10s, 30s, 1min, 5min, 10min
    private static final int[] DELAY_LEVELS = {3, 4, 5, 7, 8};

    @Override
    public void onMessage(MemberActivateCompensation msg) {

        String orderNo = msg.getOrderNo();
        log.info("[开通补偿] 开始处理, orderNo={}, retryCount={}",
            orderNo, msg.getRetryCount());

        // 幂等检查
        MemberActivationLog existLog = activationLogMapper
            .selectByOrderNo(orderNo);
        if (existLog != null && existLog.getStatus() == 1) {
            log.info("[开通补偿] 已成功处理, orderNo={}", orderNo);
            return;
        }

        // 查询订单
        MemberOrder order = orderMapper.selectByOrderNo(orderNo);
        if (order == null || order.getStatus() != 1) {
            log.warn("[开通补偿] 订单状态异常, orderNo={}", orderNo);
            return;
        }

        try {
            activateService.activateMember(order);
            log.info("[开通补偿] 补偿成功, orderNo={}", orderNo);
        } catch (Exception e) {
            log.error("[开通补偿] 补偿失败, orderNo={}, retry={}",
                orderNo, msg.getRetryCount(), e);

            // 超过最大重试次数，告警
            if (msg.getRetryCount() >= msg.getMaxRetry()) {
                log.error("[开通补偿] 超过最大重试次数, orderNo={}",
                    orderNo);
                alertService.sendAlert("MEMBER_ACTIVATE_FAIL",
                    "会员开通补偿失败超过最大重试次数, orderNo="
                    + orderNo);

                // 更新激活日志状态为失败
                MemberActivationLog failLog = new MemberActivationLog();
                failLog.setOrderNo(orderNo);
                failLog.setStatus(2); // 失败
                failLog.setFailReason(e.getMessage());
                activationLogMapper.updateByOrderNo(failLog);
                return;
            }

            // 递增重试次数，发送下一轮延迟消息
            msg.setRetryCount(msg.getRetryCount() + 1);
            int delayLevel = DELAY_LEVELS[Math.min(
                msg.getRetryCount(), DELAY_LEVELS.length - 1)];
            rocketMQTemplate.syncSend(
                "member-activate-compensation-topic",
                MessageBuilder.withPayload(msg).build(),
                3000, delayLevel);
        }
    }
}
```

#### 7.2.2 定时任务调度入口

```java
/**
 * 会员等级定时扫描任务
 *
 * 调度策略：
 * 1. 每天凌晨2点执行等级重算
 * 2. 分片扫描，每个分片处理一批用户
 * 3. 使用XXL-JOB分布式调度，防止多节点重复执行
 *
 * 全链路：
 * XXL-JOB触发 → 分片查询用户 → 逐个计算等级 → 状态机流转
 * → 权益处理 → 缓存刷新 → 通知用户
 */
@Component
@Slf4j
public class MemberLevelScanJob {

    @Autowired
    private MemberMapper memberMapper;
    @Autowired
    private MemberLevelCalcService levelCalcService;

    private static final int BATCH_SIZE = 500;

    /**
     * XXL-JOB分片执行入口
     * cron: 0 0 2 * * ?
     */
    @XxlJob("memberLevelScanJobHandler")
    public void execute() {
        // 获取分片参数
        int shardIndex = XxlJobHelper.getShardIndex();
        int shardTotal = XxlJobHelper.getShardTotal();

        log.info("[等级扫描] 开始执行, 分片={}/{}", shardIndex, shardTotal);

        long startTime = System.currentTimeMillis();
        int processCount = 0;
        int upgradeCount = 0;
        int downgradeCount = 0;
        long lastUserId = 0;

        while (true) {
            // 分页 + 分片查询
            // 根据userId取模分片，保证不同节点处理不同用户
            List<Member> members = memberMapper
                .selectByShardBatch(lastUserId, BATCH_SIZE,
                    shardIndex, shardTotal);

            if (members.isEmpty()) {
                break;
            }

            for (Member member : members) {
                try {
                    LevelChangeResult result =
                        levelCalcService.calculateAndApply(
                            member, "EXPIRE_CHECK");

                    if (result != null) {
                        if (result.getChangeType() == 1) upgradeCount++;
                        if (result.getChangeType() == 2) downgradeCount++;
                    }
                    processCount++;
                } catch (Exception e) {
                    log.error("[等级扫描] 处理失败, userId={}",
                        member.getUserId(), e);
                    // 单个用户失败不影响整体任务
                }
            }

            lastUserId = members.get(members.size() - 1).getUserId();
        }

        long cost = System.currentTimeMillis() - startTime;
        log.info("[等级扫描] 执行完成, 分片={}, 处理={}, "
                + "升级={}, 降级={}, 耗时={}ms",
            shardIndex, processCount, upgradeCount,
            downgradeCount, cost);

        XxlJobHelper.handleSuccess(String.format(
            "processed=%d, upgrade=%d, downgrade=%d",
            processCount, upgradeCount, downgradeCount));
    }
}
```

#### 7.2.3 等级计算规则引擎

```java
/**
 * 等级计算服务
 *
 * 规则引擎设计：
 * 1. 多维度评估：成长值 + 订单数 + 消费金额
 * 2. 每个维度有权重，加权计算综合得分
 * 3. 综合得分匹配等级区间
 * 4. 支持热更新规则配置
 */
@Service
@Slf4j
public class MemberLevelCalcService {

    @Autowired
    private MemberMapper memberMapper;
    @Autowired
    private MemberLevelConfigMapper levelConfigMapper;
    @Autowired
    private LevelCalcRuleMapper ruleMapper;
    @Autowired
    private MemberLevelChangeLogMapper changeLogMapper;
    @Autowired
    private BenefitService benefitService;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private RocketMQTemplate rocketMQTemplate;
    @Autowired
    private GrowthValueLogMapper growthLogMapper;
    @Autowired
    private OrderStatMapper orderStatMapper;

    /**
     * 等级规则配置缓存（5分钟刷新一次）
     */
    private final Cache<String, List<LevelCalcRule>> ruleCache =
        Caffeine.newBuilder()
            .expireAfterWrite(5, TimeUnit.MINUTES)
            .build();

    /**
     * 计算并应用等级变更
     *
     * @param member 当前会员
     * @param triggerSource 触发来源
     * @return 变更结果，null表示无变更
     */
    public LevelChangeResult calculateAndApply(
            Member member, String triggerSource) {

        Long userId = member.getUserId();

        // ===== 并发安全：Redis分布式锁 =====
        // 防止同一用户被多个线程/节点同时处理
        String lockKey = "member:level:calc:lock:" + userId;
        Boolean locked = redisTemplate.opsForValue()
            .setIfAbsent(lockKey, "1", 60, TimeUnit.SECONDS);
        if (locked == null || !locked) {
            log.info("[等级计算] 获取锁失败(已有任务在处理), userId={}",
                userId);
            return null;
        }

        try {
            return doCalculateAndApply(member, triggerSource);
        } finally {
            redisTemplate.delete(lockKey);
        }
    }

    /**
     * 实际执行等级计算和应用
     */
    private LevelChangeResult doCalculateAndApply(
            Member member, String triggerSource) {

        Long userId = member.getUserId();
        int currentLevel = member.getLevel();

        // ===== 幂等控制 =====
        String today = DateFormatUtils.format(new Date(), "yyyyMMdd");
        String idempotentKey = userId + "_" + today + "_" + triggerSource;

        MemberLevelChangeLog existLog = changeLogMapper
            .selectByIdempotentKey(idempotentKey);
        if (existLog != null) {
            log.info("[等级计算] 今日已处理, userId={}, source={}",
                userId, triggerSource);
            return null;
        }

        // ===== 规则引擎：多维度计算目标等级 =====
        int targetLevel = calculateTargetLevel(member);

        // 等级无变化
        if (targetLevel == currentLevel) {
            // 记录保级日志
            recordLevelChange(userId, currentLevel, currentLevel,
                3, member.getGrowthValue(), triggerSource,
                idempotentKey);
            return null;
        }

        // ===== 状态机流转 =====
        LevelChangeResult result;
        if (targetLevel > currentLevel) {
            result = doUpgrade(member, targetLevel,
                triggerSource, idempotentKey);
        } else {
            result = doDowngrade(member, targetLevel,
                triggerSource, idempotentKey);
        }

        return result;
    }

    /**
     * 多维度计算目标等级
     *
     * 计算逻辑：
     * 1. 查询各维度规则配置
     * 2. 获取用户各维度的实际值
     * 3. 从最高等级开始匹配，满足条件即返回
     */
    private int calculateTargetLevel(Member member) {
        Long userId = member.getUserId();

        // 加载规则配置（带缓存）
        List<LevelCalcRule> rules = ruleCache.get("rules", k ->
            ruleMapper.selectAllEnabled());

        // 按等级分组，从高到低排序
        Map<Integer, List<LevelCalcRule>> rulesByLevel = rules.stream()
            .collect(Collectors.groupingBy(LevelCalcRule::getLevel));

        List<Integer> sortedLevels = rulesByLevel.keySet().stream()
            .sorted(Comparator.reverseOrder())
            .collect(Collectors.toList());

        // 获取用户各维度指标
        long growthValue = member.getGrowthValue();
        long orderCount = orderStatMapper
            .countOrdersInPeriod(userId, 365);
        long totalAmount = orderStatMapper
            .sumAmountInPeriod(userId, 365);

        // 从最高等级开始匹配
        for (int level : sortedLevels) {
            List<LevelCalcRule> levelRules = rulesByLevel.get(level);
            boolean allMatch = true;

            for (LevelCalcRule rule : levelRules) {
                long actualValue;
                switch (rule.getRuleType()) {
                    case "GROWTH":
                        actualValue = growthValue;
                        break;
                    case "ORDER_COUNT":
                        actualValue = orderCount;
                        break;
                    case "ORDER_AMOUNT":
                        actualValue = totalAmount;
                        break;
                    default:
                        continue;
                }

                if (actualValue < rule.getThreshold()) {
                    allMatch = false;
                    break;
                }
            }

            if (allMatch) {
                return level;
            }
        }

        return 0; // 不满足任何等级，降为注册会员
    }

    // ===== 升级流程 =====

    /**
     * 执行升级
     *
     * 升级可以跨级（银→白金），中间跳过的等级权益也要下发
     */
    @Transactional(rollbackFor = Exception.class)
    private LevelChangeResult doUpgrade(Member member,
            int targetLevel, String triggerSource,
            String idempotentKey) {

        Long userId = member.getUserId();
        int oldLevel = member.getLevel();

        log.info("[等级升级] 开始, userId={}, {} → {}",
            userId, oldLevel, targetLevel);

        // 1. 更新会员等级（乐观锁）
        int updated = memberMapper.updateLevelWithCas(
            userId, targetLevel, oldLevel);
        if (updated == 0) {
            log.warn("[等级升级] 乐观锁冲突, userId={}", userId);
            throw new BizException("CONCURRENT_CONFLICT",
                "等级变更冲突，稍后重试");
        }

        // 2. 下发新等级权益（差异化处理：只下发新增的权益）
        benefitService.grantDiffBenefits(userId, oldLevel, targetLevel);

        // 3. 清除缓存
        redisTemplate.delete("member:level:" + userId);
        redisTemplate.delete("member:benefits:" + userId);

        // 4. 记录变更日志
        recordLevelChange(userId, oldLevel, targetLevel,
            1, member.getGrowthValue(), triggerSource,
            idempotentKey);

        // 5. 发送升级通知（异步MQ）
        MemberLevelChangeMessage changeMsg =
            new MemberLevelChangeMessage();
        changeMsg.setUserId(userId);
        changeMsg.setOldLevel(oldLevel);
        changeMsg.setNewLevel(targetLevel);
        changeMsg.setChangeType(1); // 升级
        changeMsg.setTimestamp(System.currentTimeMillis());
        rocketMQTemplate.convertAndSend(
            "member-level-change-topic", changeMsg);

        log.info("[等级升级] 完成, userId={}, {} → {}",
            userId, oldLevel, targetLevel);

        LevelChangeResult result = new LevelChangeResult();
        result.setUserId(userId);
        result.setOldLevel(oldLevel);
        result.setNewLevel(targetLevel);
        result.setChangeType(1);
        return result;
    }

    // ===== 降级流程 =====

    /**
     * 执行降级
     *
     * 降级需要回收多余的权益，但已经使用的权益不追回
     */
    @Transactional(rollbackFor = Exception.class)
    private LevelChangeResult doDowngrade(Member member,
            int targetLevel, String triggerSource,
            String idempotentKey) {

        Long userId = member.getUserId();
        int oldLevel = member.getLevel();

        log.info("[等级降级] 开始, userId={}, {} → {}",
            userId, oldLevel, targetLevel);

        // 1. 更新会员等级（乐观锁）
        int updated = memberMapper.updateLevelWithCas(
            userId, targetLevel, oldLevel);
        if (updated == 0) {
            log.warn("[等级降级] 乐观锁冲突, userId={}", userId);
            throw new BizException("CONCURRENT_CONFLICT",
                "等级变更冲突，稍后重试");
        }

        // 2. 回收差异化权益
        benefitService.revokeDiffBenefits(userId, oldLevel, targetLevel);

        // 3. 清除缓存
        redisTemplate.delete("member:level:" + userId);
        redisTemplate.delete("member:benefits:" + userId);

        // 4. 记录变更日志
        recordLevelChange(userId, oldLevel, targetLevel,
            2, member.getGrowthValue(), triggerSource,
            idempotentKey);

        // 5. 发送降级通知（异步MQ）
        MemberLevelChangeMessage changeMsg =
            new MemberLevelChangeMessage();
        changeMsg.setUserId(userId);
        changeMsg.setOldLevel(oldLevel);
        changeMsg.setNewLevel(targetLevel);
        changeMsg.setChangeType(2); // 降级
        changeMsg.setTimestamp(System.currentTimeMillis());
        rocketMQTemplate.convertAndSend(
            "member-level-change-topic", changeMsg);

        log.info("[等级降级] 完成, userId={}, {} → {}",
            userId, oldLevel, targetLevel);

        LevelChangeResult result = new LevelChangeResult();
        result.setUserId(userId);
        result.setOldLevel(oldLevel);
        result.setNewLevel(targetLevel);
        result.setChangeType(2);
        return result;
    }

    // ===== 辅助方法 =====

    private void recordLevelChange(Long userId, int oldLevel,
            int newLevel, int changeType, long growthValue,
            String triggerSource, String idempotentKey) {

        MemberLevelChangeLog log = new MemberLevelChangeLog();
        log.setUserId(userId);
        log.setOldLevel(oldLevel);
        log.setNewLevel(newLevel);
        log.setChangeType(changeType);
        log.setGrowthValue(growthValue);
        log.setTriggerSource(triggerSource);
        log.setIdempotentKey(idempotentKey);
        log.setCreateTime(new Date());

        try {
            changeLogMapper.insert(log);
        } catch (DuplicateKeyException e) {
            // 幂等保护，忽略重复插入
        }
    }
}
```

#### 7.2.4 权益差异化处理

```java
/**
 * 权益差异化处理（升降级专用）
 *
 * 升级：只下发新增权益，不重复下发
 * 降级：只回收多余权益，保留降级后仍有的权益
 */
@Service
@Slf4j
public class BenefitService {

    // ... 前面已声明的依赖注入省略 ...

    /**
     * 升级差异化权益下发
     *
     * 示例：银卡→白金
     *   银卡权益: [积分1.2倍, 月度优惠券]
     *   白金权益: [积分2倍, 月度优惠券, 专属客服, 生日礼包]
     *   新增下发: [积分2倍(覆盖), 专属客服, 生日礼包]
     */
    public void grantDiffBenefits(Long userId,
            int oldLevel, int newLevel) {

        MemberLevelConfig oldConfig = configMapper.selectByLevel(oldLevel);
        MemberLevelConfig newConfig = configMapper.selectByLevel(newLevel);

        List<Benefit> oldBenefits = oldConfig != null
            ? JSON.parseArray(oldConfig.getBenefits(), Benefit.class)
            : Collections.emptyList();
        List<Benefit> newBenefits = JSON.parseArray(
            newConfig.getBenefits(), Benefit.class);

        Set<String> oldTypes = oldBenefits.stream()
            .map(Benefit::getType).collect(Collectors.toSet());

        for (Benefit benefit : newBenefits) {
            // 跳过POINT_RATE和DISCOUNT，这些是实时查询的
            if ("POINT_RATE".equals(benefit.getType())
                    || "DISCOUNT".equals(benefit.getType())) {
                continue;
            }

            // 新增权益才需要下发
            if (!oldTypes.contains(benefit.getType())) {
                try {
                    grantSingleBenefit(userId, benefit);
                    log.info("[权益下发] 成功, userId={}, type={}",
                        userId, benefit.getType());
                } catch (Exception e) {
                    log.error("[权益下发] 失败, userId={}, type={}",
                        userId, benefit.getType(), e);
                    // 单个权益下发失败不影响整体，记录后续补偿
                    recordBenefitFailure(userId, benefit, "GRANT");
                }
            }
        }
    }

    /**
     * 降级差异化权益回收
     *
     * 示例：白金→银卡
     *   白金权益: [积分2倍, 月度优惠券, 专属客服, 生日礼包]
     *   银卡权益: [积分1.2倍, 月度优惠券]
     *   需要回收: [专属客服, 生日礼包]
     */
    public void revokeDiffBenefits(Long userId,
            int oldLevel, int newLevel) {

        MemberLevelConfig oldConfig = configMapper.selectByLevel(oldLevel);
        MemberLevelConfig newConfig = configMapper.selectByLevel(newLevel);

        List<Benefit> oldBenefits = JSON.parseArray(
            oldConfig.getBenefits(), Benefit.class);
        List<Benefit> newBenefits = newConfig != null
            ? JSON.parseArray(newConfig.getBenefits(), Benefit.class)
            : Collections.emptyList();

        Set<String> newTypes = newBenefits.stream()
            .map(Benefit::getType).collect(Collectors.toSet());

        for (Benefit benefit : oldBenefits) {
            if ("POINT_RATE".equals(benefit.getType())
                    || "DISCOUNT".equals(benefit.getType())) {
                continue;
            }

            // 旧等级有、新等级没有的权益需要回收
            if (!newTypes.contains(benefit.getType())) {
                try {
                    revokeSingleBenefit(userId, benefit);
                    log.info("[权益回收] 成功, userId={}, type={}",
                        userId, benefit.getType());
                } catch (Exception e) {
                    log.error("[权益回收] 失败, userId={}, type={}",
                        userId, benefit.getType(), e);
                    recordBenefitFailure(userId, benefit, "REVOKE");
                }
            }
        }
    }

    private void grantSingleBenefit(Long userId, Benefit benefit) {
        switch (benefit.getType()) {
            case "COUPON":
                couponClient.grant(userId, benefit.getCouponTemplateId());
                break;
            case "BIRTHDAY_GIFT":
                registerBirthdayGift(userId, benefit);
                break;
            case "VIP_SERVICE":
                // 通知客服系统分配专属客服
                customerServiceClient.assignVip(userId);
                break;
            case "PRIORITY_PURCHASE":
                // 开通优先购买权限
                tradeFeignClient.enablePriorityPurchase(userId);
                break;
            default:
                log.warn("[权益下发] 未知权益类型: {}", benefit.getType());
        }
    }

    private void revokeSingleBenefit(Long userId, Benefit benefit) {
        switch (benefit.getType()) {
            case "BIRTHDAY_GIFT":
                cancelBirthdayGift(userId);
                break;
            case "VIP_SERVICE":
                customerServiceClient.revokeVip(userId);
                break;
            case "PRIORITY_PURCHASE":
                tradeFeignClient.disablePriorityPurchase(userId);
                break;
            default:
                // COUPON类型不回收，已下发的优惠券继续有效
                break;
        }
    }

    private void recordBenefitFailure(Long userId,
            Benefit benefit, String action) {
        // 记录到失败表，定时任务补偿
        BenefitFailureLog failLog = new BenefitFailureLog();
        failLog.setUserId(userId);
        failLog.setBenefitType(benefit.getType());
        failLog.setAction(action);
        failLog.setRetryCount(0);
        failLog.setCreateTime(new Date());
        benefitFailureLogMapper.insert(failLog);
    }
}
```

#### 7.3.2 过期提醒定时任务

```java
/**
 * 会员过期提醒定时任务
 *
 * 调度策略：
 * 1. 每天上午10点执行（用户活跃时段推送）
 * 2. 分别扫描7天、3天、1天即将过期的会员
 * 3. 幂等控制：每个用户每种提醒类型每天最多发一次
 *
 * 全链路：
 * 定时任务 → 扫描即将过期会员 → 幂等检查 → 推送通知 → 记录日志
 */
@Component
@Slf4j
public class MemberExpireNotifyJob {

    @Autowired
    private MemberMapper memberMapper;
    @Autowired
    private MemberExpireNotifyLogMapper notifyLogMapper;
    @Autowired
    private PushService pushService;
    @Autowired
    private SmsService smsService;
    @Autowired
    private MemberAutoRenewMapper autoRenewMapper;

    private static final int BATCH_SIZE = 500;

    /**
     * XXL-JOB入口
     * cron: 0 0 10 * * ?
     */
    @XxlJob("memberExpireNotifyJobHandler")
    public void execute() {
        log.info("[过期提醒] 开始执行");

        Date now = new Date();
        int totalNotified = 0;

        // 分别处理7天、3天、1天
        totalNotified += processNotify(now, 7, "D7");
        totalNotified += processNotify(now, 3, "D3");
        totalNotified += processNotify(now, 1, "D1");

        log.info("[过期提醒] 执行完成, 总通知数={}", totalNotified);
    }

    /**
     * 处理某个时间窗口的过期提醒
     */
    private int processNotify(Date now, int daysBeforeExpire,
            String notifyType) {

        // 计算目标过期日期范围（当天零点到次日零点）
        Date targetDate = DateUtils.addDays(now, daysBeforeExpire);
        Date dayStart = DateUtils.truncate(targetDate, Calendar.DATE);
        Date dayEnd = DateUtils.addDays(dayStart, 1);

        int notifiedCount = 0;
        long lastUserId = 0;

        while (true) {
            List<Member> members = memberMapper
                .selectExpireBetween(dayStart, dayEnd,
                    lastUserId, BATCH_SIZE);

            if (members.isEmpty()) break;

            for (Member member : members) {
                try {
                    boolean sent = sendExpireNotify(
                        member, notifyType, daysBeforeExpire);
                    if (sent) notifiedCount++;
                } catch (Exception e) {
                    log.error("[过期提醒] 发送失败, userId={}, type={}",
                        member.getUserId(), notifyType, e);
                }
            }

            lastUserId = members.get(
                members.size() - 1).getUserId();
        }

        log.info("[过期提醒] {}完成, 通知数={}",
            notifyType, notifiedCount);
        return notifiedCount;
    }

    /**
     * 发送过期提醒（含幂等控制）
     */
    private boolean sendExpireNotify(Member member,
            String notifyType, int daysBeforeExpire) {

        Long userId = member.getUserId();
        Date today = DateUtils.truncate(new Date(), Calendar.DATE);

        // 幂等检查：今天是否已发送过该类型通知
        MemberExpireNotifyLog existLog = notifyLogMapper
            .selectByUserAndTypeAndDate(userId, notifyType, today);
        if (existLog != null) {
            return false; // 已发送，跳过
        }

        // 检查是否开通了自动续费
        MemberAutoRenew autoRenew = autoRenewMapper
            .selectByUserId(userId);
        boolean hasAutoRenew = autoRenew != null
            && autoRenew.getStatus() == 1;

        // 构建通知内容
        String title;
        String content;
        if (hasAutoRenew) {
            title = "会员即将自动续费";
            content = String.format(
                "您的%s会员将于%d天后到期，届时将自动续费。"
                + "如需取消请前往会员中心设置",
                getLevelName(member.getLevel()), daysBeforeExpire);
        } else {
            title = "会员即将到期";
            content = String.format(
                "您的%s会员将于%d天后到期，续费可继续享受专属权益",
                getLevelName(member.getLevel()), daysBeforeExpire);
        }

        // 发送APP推送
        pushService.push(userId, title, content);

        // 最后1天发送短信
        if (daysBeforeExpire <= 1) {
            smsService.send(userId, "MEMBER_EXPIRE_REMIND",
                Map.of("levelName",
                    getLevelName(member.getLevel()),
                    "days", String.valueOf(daysBeforeExpire)));
        }

        // 记录发送日志（幂等标记）
        MemberExpireNotifyLog notifyLog = new MemberExpireNotifyLog();
        notifyLog.setUserId(userId);
        notifyLog.setNotifyType(notifyType);
        notifyLog.setNotifyDate(today);
        notifyLog.setStatus(1);
        notifyLog.setCreateTime(new Date());

        try {
            notifyLogMapper.insert(notifyLog);
        } catch (DuplicateKeyException e) {
            // 并发时可能重复，忽略
        }

        return true;
    }

    private String getLevelName(int level) {
        switch (level) {
            case 1: return "银卡";
            case 2: return "金卡";
            case 3: return "白金";
            case 4: return "钻石";
            default: return "普通";
        }
    }
}
```

#### 7.3.3 自动续费扣款流程

```java
/**
 * 自动续费定时任务
 *
 * 调度策略：
 * 1. 每天凌晨0点30分执行
 * 2. 扫描今天过期且开通了自动续费的会员
 * 3. 调用支付系统代扣
 * 4. 扣款成功后自动延长会员有效期
 *
 * 全链路：
 * 定时任务 → 查询待续费会员 → 创建续费订单 → 代扣扣款
 * → 扣款成功 → 延长会员 → 通知用户
 * → 扣款失败 → 记录失败 → 延迟重试（最多3次）→ 通知用户
 */
@Component
@Slf4j
public class MemberAutoRenewJob {

    @Autowired
    private MemberMapper memberMapper;
    @Autowired
    private MemberAutoRenewMapper autoRenewMapper;
    @Autowired
    private MemberOrderMapper orderMapper;
    @Autowired
    private MemberRenewDeductLogMapper deductLogMapper;
    @Autowired
    private PayFeignClient payClient;
    @Autowired
    private MemberActivateService activateService;
    @Autowired
    private PushService pushService;
    @Autowired
    private SmsService smsService;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private RocketMQTemplate rocketMQTemplate;

    private static final int BATCH_SIZE = 200;

    /**
     * XXL-JOB入口
     * cron: 0 30 0 * * ?
     */
    @XxlJob("memberAutoRenewJobHandler")
    public void execute() {
        log.info("[自动续费] 开始执行");

        Date now = new Date();
        Date todayStart = DateUtils.truncate(now, Calendar.DATE);
        Date todayEnd = DateUtils.addDays(todayStart, 1);

        int successCount = 0;
        int failCount = 0;
        long lastUserId = 0;

        while (true) {
            // 查询今天过期且签约了自动续费的会员
            List<Member> members = memberMapper
                .selectExpireWithAutoRenew(
                    todayStart, todayEnd, lastUserId, BATCH_SIZE);

            if (members.isEmpty()) break;

            for (Member member : members) {
                try {
                    boolean success = processAutoRenew(member);
                    if (success) {
                        successCount++;
                    } else {
                        failCount++;
                    }
                } catch (Exception e) {
                    log.error("[自动续费] 处理异常, userId={}",
                        member.getUserId(), e);
                    failCount++;
                }
            }

            lastUserId = members.get(
                members.size() - 1).getUserId();
        }

        log.info("[自动续费] 执行完成, 成功={}, 失败={}",
            successCount, failCount);
    }

    /**
     * 处理单个用户的自动续费
     */
    private boolean processAutoRenew(Member member) {

        Long userId = member.getUserId();

        // 幂等检查：当天是否已成功续费
        String idempotentKey = "autorenew:" + userId + ":"
            + DateFormatUtils.format(new Date(), "yyyyMMdd");
        Boolean locked = redisTemplate.opsForValue()
            .setIfAbsent(idempotentKey, "processing",
                24, TimeUnit.HOURS);
        if (locked == null || !locked) {
            log.info("[自动续费] 已处理过, userId={}", userId);
            return true;
        }

        // 查询自动续费签约信息
        MemberAutoRenew autoRenew = autoRenewMapper
            .selectByUserId(userId);
        if (autoRenew == null || autoRenew.getStatus() != 1) {
            log.info("[自动续费] 未签约或已解约, userId={}", userId);
            return false;
        }

        // 1. 创建续费订单
        String orderNo = "RENEW" + snowflakeIdGenerator.nextId();
        BigDecimal amount = calculateRenewAmount(
            autoRenew.getMemberType(),
            autoRenew.getDurationMonths());

        MemberOrder order = new MemberOrder();
        order.setOrderNo(orderNo);
        order.setUserId(userId);
        order.setMemberType(autoRenew.getMemberType());
        order.setDurationMonths(autoRenew.getDurationMonths());
        order.setAmount(amount);
        order.setPayType(autoRenew.getPayType());
        order.setOrderType(2); // 自动续费
        order.setStatus(0);
        order.setCreateTime(new Date());
        order.setExpireTime(DateUtils.addHours(new Date(), 24));
        orderMapper.insert(order);

        // 2. 调用支付系统代扣
        MemberRenewDeductLog deductLog = new MemberRenewDeductLog();
        deductLog.setUserId(userId);
        deductLog.setOrderNo(orderNo);
        deductLog.setAmount(amount);
        deductLog.setDeductStatus(0); // 扣款中
        deductLog.setRetryCount(0);
        deductLog.setCreateTime(new Date());
        deductLog.setUpdateTime(new Date());
        deductLogMapper.insert(deductLog);

        try {
            PayDeductRequest deductReq = new PayDeductRequest();
            deductReq.setOutTradeNo(orderNo);
            deductReq.setAgreementNo(autoRenew.getPayAgreementNo());
            deductReq.setAmount(amount);
            deductReq.setSubject("会员自动续费");

            Result<PayDeductResponse> result =
                payClient.deduct(deductReq);

            if (result.isSuccess()
                    && result.getData().isDeductSuccess()) {
                // 3. 扣款成功
                handleDeductSuccess(order, deductLog,
                    result.getData().getTradeNo());
                redisTemplate.opsForValue().set(
                    idempotentKey, "success", 24, TimeUnit.HOURS);
                return true;
            } else {
                // 扣款失败
                String reason = result.isSuccess()
                    ? result.getData().getFailReason()
                    : result.getMessage();
                handleDeductFail(order, deductLog, reason,
                    autoRenew);
                return false;
            }
        } catch (Exception e) {
            log.error("[自动续费] 代扣调用异常, userId={}, orderNo={}",
                userId, orderNo, e);
            handleDeductFail(order, deductLog,
                "系统异常: " + e.getMessage(), autoRenew);
            return false;
        }
    }

    /**
     * 扣款成功处理
     */
    @Transactional(rollbackFor = Exception.class)
    private void handleDeductSuccess(MemberOrder order,
            MemberRenewDeductLog deductLog, String tradeNo) {

        Long userId = order.getUserId();
        String orderNo = order.getOrderNo();

        log.info("[自动续费] 扣款成功, userId={}, orderNo={}",
            userId, orderNo);

        // 更新扣款记录
        deductLog.setDeductStatus(1); // 成功
        deductLog.setPayTradeNo(tradeNo);
        deductLog.setUpdateTime(new Date());
        deductLogMapper.updateByOrderNo(deductLog);

        // 更新订单状态
        order.setStatus(1); // 已支付
        order.setPayTradeNo(tradeNo);
        order.setPayTime(new Date());
        orderMapper.updateById(order);

        // 执行会员开通（延长有效期）
        activateService.activateMember(order);

        // 通知用户
        pushService.push(userId,
            "会员自动续费成功",
            String.format("已为您自动续费%s会员，"
                + "扣款%.2f元",
                getMemberTypeName(order.getMemberType()),
                order.getAmount()));
    }

    /**
     * 扣款失败处理
     */
    private void handleDeductFail(MemberOrder order,
            MemberRenewDeductLog deductLog, String reason,
            MemberAutoRenew autoRenew) {

        Long userId = order.getUserId();
        String orderNo = order.getOrderNo();

        log.warn("[自动续费] 扣款失败, userId={}, orderNo={}, reason={}",
            userId, orderNo, reason);

        // 更新扣款记录
        deductLog.setDeductStatus(2); // 失败
        deductLog.setFailReason(reason);
        deductLog.setUpdateTime(new Date());
        deductLogMapper.updateByOrderNo(deductLog);

        // 更新订单状态
        orderMapper.updateStatus(orderNo, 4); // 支付失败

        // 发送扣款重试延迟消息
        if (deductLog.getRetryCount() < 3) {
            RenewRetryMessage retryMsg = new RenewRetryMessage();
            retryMsg.setUserId(userId);
            retryMsg.setAutoRenewId(autoRenew.getId());
            retryMsg.setRetryCount(deductLog.getRetryCount() + 1);
            retryMsg.setCreateTime(new Date());

            // 延迟级别：第1次2小时后，第2次6小时后，第3次12小时后
            int[] retryDelayLevels = {11, 13, 14};
            int delayLevel = retryDelayLevels[
                Math.min(deductLog.getRetryCount(),
                    retryDelayLevels.length - 1)];

            rocketMQTemplate.syncSend(
                "member-renew-retry-topic",
                MessageBuilder.withPayload(retryMsg).build(),
                3000, delayLevel);

            log.info("[自动续费] 已发送重试消息, userId={}, "
                    + "nextRetry={}",
                userId, deductLog.getRetryCount() + 1);
        } else {
            // 超过最大重试次数，通知用户手动续费
            pushService.push(userId,
                "会员自动续费失败",
                "自动续费扣款失败，请检查支付方式后手动续费，"
                + "以免会员权益中断");
            smsService.send(userId, "MEMBER_RENEW_FAIL",
                Map.of("levelName",
                    getMemberTypeName(autoRenew.getMemberType())));

            log.warn("[自动续费] 重试次数已用尽, userId={}", userId);
        }
    }

    private BigDecimal calculateRenewAmount(
            int memberType, int durationMonths) {
        Map<Integer, BigDecimal> priceMap = Map.of(
            1, new BigDecimal("9.90"),
            2, new BigDecimal("19.90"),
            3, new BigDecimal("39.90"),
            4, new BigDecimal("69.90")
        );
        return priceMap.getOrDefault(memberType, BigDecimal.ZERO)
            .multiply(BigDecimal.valueOf(durationMonths));
    }

    private String getMemberTypeName(int memberType) {
        switch (memberType) {
            case 1: return "银卡";
            case 2: return "金卡";
            case 3: return "白金";
            case 4: return "钻石";
            default: return "普通";
        }
```

#### 7.3.4 扣款失败重试消费者

```java
/**
 * 续费扣款重试消费者
 *
 * 重试策略：
 * 第1次重试：扣款失败后2小时
 * 第2次重试：扣款失败后6小时
 * 第3次重试：扣款失败后12小时
 * 超过3次：放弃自动续费，通知用户手动处理
 */
@Component
@RocketMQMessageListener(topic = "member-renew-retry-topic",
    consumerGroup = "member-renew-retry-group")
@Slf4j
public class RenewRetryConsumer
        implements RocketMQListener<RenewRetryMessage> {

    @Autowired
    private MemberAutoRenewMapper autoRenewMapper;
    @Autowired
    private MemberMapper memberMapper;
    @Autowired
    private MemberOrderMapper orderMapper;
    @Autowired
    private MemberRenewDeductLogMapper deductLogMapper;
    @Autowired
    private PayFeignClient payClient;
    @Autowired
    private MemberActivateService activateService;
    @Autowired
    private PushService pushService;
    @Autowired
    private SmsService smsService;
    @Autowired
    private RocketMQTemplate rocketMQTemplate;
    @Autowired
    private StringRedisTemplate redisTemplate;

    @Override
    public void onMessage(RenewRetryMessage msg) {

        Long userId = msg.getUserId();
        int retryCount = msg.getRetryCount();

        log.info("[续费重试] 开始, userId={}, retryCount={}",
            userId, retryCount);

        // 幂等检查
        String idempotentKey = "autorenew:" + userId + ":"
            + DateFormatUtils.format(
                msg.getCreateTime(), "yyyyMMdd");
        String val = redisTemplate.opsForValue().get(idempotentKey);
        if ("success".equals(val)) {
            log.info("[续费重试] 已成功续费, userId={}", userId);
            return;
        }

        // 检查签约状态（用户可能已解约）
        MemberAutoRenew autoRenew = autoRenewMapper
            .selectById(msg.getAutoRenewId());
        if (autoRenew == null || autoRenew.getStatus() != 1) {
            log.info("[续费重试] 用户已解约, userId={}", userId);
            return;
        }

        // 创建新的续费订单
        String orderNo = "RETRY" + snowflakeIdGenerator.nextId();
        BigDecimal amount = calculateRenewAmount(
            autoRenew.getMemberType(),
            autoRenew.getDurationMonths());

        MemberOrder order = new MemberOrder();
        order.setOrderNo(orderNo);
        order.setUserId(userId);
        order.setMemberType(autoRenew.getMemberType());
        order.setDurationMonths(autoRenew.getDurationMonths());
        order.setAmount(amount);
        order.setPayType(autoRenew.getPayType());
        order.setOrderType(2);
        order.setStatus(0);
        order.setCreateTime(new Date());
        order.setExpireTime(DateUtils.addHours(new Date(), 24));
        orderMapper.insert(order);

        // 扣款记录
        MemberRenewDeductLog deductLog = new MemberRenewDeductLog();
        deductLog.setUserId(userId);
        deductLog.setOrderNo(orderNo);
        deductLog.setAmount(amount);
        deductLog.setDeductStatus(0);
        deductLog.setRetryCount(retryCount);
        deductLog.setCreateTime(new Date());
        deductLog.setUpdateTime(new Date());
        deductLogMapper.insert(deductLog);

        try {
            PayDeductRequest deductReq = new PayDeductRequest();
            deductReq.setOutTradeNo(orderNo);
            deductReq.setAgreementNo(autoRenew.getPayAgreementNo());
            deductReq.setAmount(amount);
            deductReq.setSubject("会员自动续费(重试)");

            Result<PayDeductResponse> result =
                payClient.deduct(deductReq);

            if (result.isSuccess()
                    && result.getData().isDeductSuccess()) {
                // 扣款成功
                log.info("[续费重试] 扣款成功, userId={}, retry={}",
                    userId, retryCount);

                deductLog.setDeductStatus(1);
                deductLog.setPayTradeNo(
                    result.getData().getTradeNo());
                deductLog.setUpdateTime(new Date());
                deductLogMapper.updateByOrderNo(deductLog);

                order.setStatus(1);
                order.setPayTradeNo(result.getData().getTradeNo());
                order.setPayTime(new Date());
                orderMapper.updateById(order);

                activateService.activateMember(order);

                redisTemplate.opsForValue().set(
                    idempotentKey, "success", 24, TimeUnit.HOURS);

                pushService.push(userId,
                    "会员续费成功",
                    "自动续费已完成，会员权益继续生效");
            } else {
                // 扣款仍然失败
                String reason = result.isSuccess()
                    ? result.getData().getFailReason()
                    : result.getMessage();

                log.warn("[续费重试] 扣款失败, userId={}, retry={}, "
                        + "reason={}",
                    userId, retryCount, reason);

                deductLog.setDeductStatus(2);
                deductLog.setFailReason(reason);
                deductLog.setUpdateTime(new Date());
                deductLogMapper.updateByOrderNo(deductLog);
                orderMapper.updateStatus(orderNo, 4);

                if (retryCount < 3) {
                    // 继续重试
                    RenewRetryMessage nextRetry =
                        new RenewRetryMessage();
                    nextRetry.setUserId(userId);
                    nextRetry.setAutoRenewId(msg.getAutoRenewId());
                    nextRetry.setRetryCount(retryCount + 1);
                    nextRetry.setCreateTime(msg.getCreateTime());

                    int[] retryDelayLevels = {11, 13, 14};
                    rocketMQTemplate.syncSend(
                        "member-renew-retry-topic",
                        MessageBuilder.withPayload(nextRetry)
                            .build(),
                        3000, retryDelayLevels[retryCount]);
                } else {
                    // 最终失败
                    pushService.push(userId,
                        "会员自动续费失败",
                        "多次扣款均未成功，请手动续费以保留权益");
                    smsService.send(userId,
                        "MEMBER_RENEW_FINAL_FAIL",
                        Map.of("levelName",
                            getMemberTypeName(
                                autoRenew.getMemberType())));
                }
            }
        } catch (Exception e) {
            log.error("[续费重试] 系统异常, userId={}", userId, e);
            // 消费异常，MQ自动重试
            throw e;
        }
    }

    private BigDecimal calculateRenewAmount(
            int memberType, int durationMonths) {
        Map<Integer, BigDecimal> priceMap = Map.of(
            1, new BigDecimal("9.90"),
            2, new BigDecimal("19.90"),
            3, new BigDecimal("39.90"),
            4, new BigDecimal("69.90")
        );
        return priceMap.getOrDefault(memberType, BigDecimal.ZERO)
            .multiply(BigDecimal.valueOf(durationMonths));
    }

    private String getMemberTypeName(int memberType) {
        switch (memberType) {
            case 1: return "银卡";
            case 2: return "金卡";
            case 3: return "白金";
            case 4: return "钻石";
            default: return "普通";
        }
    }
}
```

#### 7.3.5 会员过期处理与权益回收

```java
/**
 * 会员过期处理定时任务
 *
 * 调度策略：
 * 1. 每天凌晨3点执行（在自动续费任务之后）
 * 2. 扫描已过期且未续费的会员
 * 3. 执行权益回收和优雅降级
 *
 * 全链路：
 * 定时任务 → 扫描过期会员 → 判断是否已续费 → 未续费执行降级
 * → 回收权益 → 更新等级 → 清除缓存 → 通知用户 → 优雅降级
 */
@Component
@Slf4j
public class MemberExpireProcessJob {

    @Autowired
    private MemberMapper memberMapper;
    @Autowired
    private MemberAutoRenewMapper autoRenewMapper;
    @Autowired
    private MemberRenewDeductLogMapper deductLogMapper;
    @Autowired
    private MemberLevelConfigMapper levelConfigMapper;
    @Autowired
    private BenefitService benefitService;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private RocketMQTemplate rocketMQTemplate;
    @Autowired
    private PushService pushService;

    private static final int BATCH_SIZE = 500;

    /**
     * XXL-JOB入口
     * cron: 0 0 3 * * ?
     */
    @XxlJob("memberExpireProcessJobHandler")
    public void execute() {
        log.info("[过期处理] 开始执行");

        Date now = new Date();
        int processCount = 0;
        int downgradeCount = 0;
        int gracePeriodCount = 0;
        long lastUserId = 0;

        while (true) {
            // 查询已过期的会员（expire_time < now 且 level > 0）
            List<Member> members = memberMapper
                .selectExpiredActiveMembers(now, lastUserId, BATCH_SIZE);

            if (members.isEmpty()) break;

            for (Member member : members) {
                try {
                    ExpireProcessResult result =
                        processExpiredMember(member, now);

                    processCount++;
                    if (result == ExpireProcessResult.DOWNGRADED) {
                        downgradeCount++;
                    } else if (result ==
                            ExpireProcessResult.GRACE_PERIOD) {
                        gracePeriodCount++;
                    }
                } catch (Exception e) {
                    log.error("[过期处理] 处理失败, userId={}",
                        member.getUserId(), e);
                }
            }

            lastUserId = members.get(
                members.size() - 1).getUserId();
        }

        log.info("[过期处理] 完成, 总处理={}, 降级={}, 宽限期={}",
            processCount, downgradeCount, gracePeriodCount);
    }

    /**
     * 处理单个过期会员
     */
    private ExpireProcessResult processExpiredMember(
            Member member, Date now) {

        Long userId = member.getUserId();

        // 1. 检查是否有进行中的自动续费
        MemberAutoRenew autoRenew = autoRenewMapper
            .selectByUserId(userId);
        if (autoRenew != null && autoRenew.getStatus() == 1) {
            // 检查当天是否有扣款成功记录
            String today = DateFormatUtils.format(now, "yyyyMMdd");
            MemberRenewDeductLog deductLog = deductLogMapper
                .selectSuccessByUserAndDate(userId, today);
            if (deductLog != null) {
                // 已续费成功，跳过
                return ExpireProcessResult.RENEWED;
            }

            // 检查是否还在重试中（过期后3天内允许重试）
            Date gracePeriodEnd = DateUtils.addDays(
                member.getExpireTime(), 3);
            if (now.before(gracePeriodEnd)) {
                log.info("[过期处理] 宽限期内(自动续费重试中), "
                    + "userId={}", userId);
                return ExpireProcessResult.GRACE_PERIOD;
            }
        }

        // 2. 超过宽限期或无自动续费，执行降级
        return executeDowngrade(member);
    }

    /**
     * 执行过期降级
     *
     * 降级策略：
     * 1. 降为注册会员（等级0）
     * 2. 回收所有付费权益
     * 3. 保留成长值（用户重新开通时可以直接恢复等级）
     * 4. 设置优雅降级标记（部分权益保留7天缓冲）
     */
    @Transactional(rollbackFor = Exception.class)
    private ExpireProcessResult executeDowngrade(Member member) {

        Long userId = member.getUserId();
        int oldLevel = member.getLevel();

        log.info("[过期降级] 开始, userId={}, oldLevel={}",
            userId, oldLevel);

        // 2.1 更新会员等级为注册会员
        int updated = memberMapper.updateLevelWithCas(
            userId, 0, oldLevel);
        if (updated == 0) {
            log.warn("[过期降级] 乐观锁冲突, userId={}", userId);
            return ExpireProcessResult.CONFLICT;
        }

        // 2.2 回收权益（差异化回收）
        benefitService.revokeDiffBenefits(userId, oldLevel, 0);

        // 2.3 设置优雅降级缓存
        // 部分体验权益（如折扣）保留7天，给用户缓冲时间
        setGraceDegradation(userId, oldLevel);

        // 2.4 清除正常缓存
        redisTemplate.delete("member:level:" + userId);
        redisTemplate.delete("member:benefits:" + userId);

        // 2.5 发送过期通知
        pushService.push(userId,
            "会员已过期",
            String.format("您的%s会员已过期，立即续费可恢复全部权益",
                getLevelName(oldLevel)));

        // 2.6 通知下游系统
        MemberLevelChangeMessage changeMsg =
            new MemberLevelChangeMessage();
        changeMsg.setUserId(userId);
        changeMsg.setOldLevel(oldLevel);
        changeMsg.setNewLevel(0);
        changeMsg.setChangeType(2); // 降级
        changeMsg.setTimestamp(System.currentTimeMillis());
        rocketMQTemplate.convertAndSend(
            "member-level-change-topic", changeMsg);

        log.info("[过期降级] 完成, userId={}, {} → 0",
            userId, oldLevel);

        return ExpireProcessResult.DOWNGRADED;
    }

    /**
     * 设置优雅降级
     *
     * 策略：
     * 1. 折扣权益保留7天（但折扣减半）
     * 2. 积分倍率立即恢复为1倍
     * 3. 专属客服保留3天
     * 4. 优先购买权立即回收
     */
    private void setGraceDegradation(Long userId, int oldLevel) {
        // 缓存优雅降级信息，7天后自动过期
        GraceDegradation grace = new GraceDegradation();
        grace.setUserId(userId);
        grace.setOldLevel(oldLevel);
        grace.setExpireTime(DateUtils.addDays(new Date(), 7));

        // 折扣减半：原来9折变95折
        MemberLevelConfig oldConfig = levelConfigMapper
            .selectByLevel(oldLevel);
        if (oldConfig != null) {
            BigDecimal halfDiscount = BigDecimal.ONE.subtract(
                BigDecimal.ONE.subtract(oldConfig.getDiscountRate())
                    .divide(BigDecimal.valueOf(2),
                        2, RoundingMode.HALF_UP));
            grace.setGraceDiscountRate(halfDiscount);
        }

        String cacheKey = "member:grace:" + userId;
        redisTemplate.opsForValue().set(cacheKey,
            JSON.toJSONString(grace), 7, TimeUnit.DAYS);

        log.info("[优雅降级] 设置完成, userId={}, oldLevel={}, "
                + "graceDiscount={}",
            userId, oldLevel, grace.getGraceDiscountRate());
    }

    private String getLevelName(int level) {
        switch (level) {
            case 1: return "银卡";
            case 2: return "金卡";
            case 3: return "白金";
            case 4: return "钻石";
            default: return "普通";
        }
    }
}

/**
 * 优雅降级查询服务
 *
 * 在查询用户折扣时，如果用户已过期但在优雅降级期内，
 * 返回减半折扣而非无折扣
 */
@Service
@Slf4j
public class GraceDegradationService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 获取用户实际折扣率（考虑优雅降级）
     */
    public BigDecimal getEffectiveDiscountRate(Long userId,
            int currentLevel) {

        if (currentLevel > 0) {
            // 会员未过期，正常查询等级折扣
            return null; // 返回null表示走正常逻辑
        }

        // 已过期，检查优雅降级
        String cacheKey = "member:grace:" + userId;
        String graceJson = redisTemplate.opsForValue().get(cacheKey);

        if (graceJson != null) {
            GraceDegradation grace = JSON.parseObject(
                graceJson, GraceDegradation.class);
            if (grace.getExpireTime().after(new Date())) {
                log.info("[优雅降级] 返回过渡折扣, userId={}, "
                        + "discount={}",
                    userId, grace.getGraceDiscountRate());
                return grace.getGraceDiscountRate();
            }
        }

        // 无优雅降级或已过期，返回无折扣（1.00）
        return BigDecimal.ONE;
    }
}

/**
 * 过期处理结果枚举
 */
public enum ExpireProcessResult {
    RENEWED,       // 已续费
    GRACE_PERIOD,  // 宽限期内
    DOWNGRADED,    // 已降级
    CONFLICT       // 并发冲突
}
```

### 7.4 全链路案例总结

| 维度 | 案例一：开通会员 | 案例二：等级升降级 | 案例三：续费与过期 |
|------|----------------|-------------------|-------------------|
