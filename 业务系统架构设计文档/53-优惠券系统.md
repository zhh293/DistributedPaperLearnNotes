# 优惠券系统架构设计

## 一、问题背景

### 1.1 业务场景

优惠券是营销体系中使用最广泛的促销工具。一个典型的优惠券生命周期包括：运营创建券模板 → 用户领券 → 用户下单时选券 → 系统核销券 → 订单取消/退款时回退券。

优惠券通常由以下属性组成：券名称、面额、类型（满减/折扣/立减）、成本、展示UI、发放条件、使用条件。其中最频繁变化的点是**发放条件**和**使用条件**。

举例：一张"满50减10元"的优惠券，可能需要满足以下条件才能领取和使用：
- 领取条件：最近七天未下单、对优惠敏感、商务用户
- 使用条件：仅限工作日午餐时段、仅限指定品类、不可与其他券叠加

### 1.2 核心挑战

| 挑战维度 | 具体问题 | 影响 |
|---------|---------|------|
| 条件表达 | 发放条件和使用条件千变万化，硬编码无法应对 | 每次新增条件都要改代码 |
| 高并发领券 | 热门券瞬间被抢光，并发扣减库存防超发 | 超发导致资损 |
| 叠加规则 | 多张券能否同时使用，互斥/优先级如何定义 | 算价错误 |
| 核销一致性 | 券状态变更与订单创建必须原子 | 券用了但订单没创建 |
| 防刷 | 黄牛批量领券囤积 | 真实用户领不到 |
| 退款回退 | 订单退款后券需要回退，部分退怎么处理 | 用户投诉 |

### 1.3 引擎式架构思想

学城文档《引擎式架构设计思想之优惠券系统实践》提出了一个核心观点：**优惠券系统设计核心点是如何解决好"条件"的表达和计算**。若可任意定义和添加"条件"而无需增加代码，那么整个优惠券系统就是稳定的，符合开闭原则。

引擎式架构方法分三步：
1. **抽取原子化指令集**：将条件拆解为正交的原子指令（数据读取、运算、逻辑控制等）
2. **构建执行引擎**：引擎负责解释、编译、编排、执行指令
3. **设计表达切面**：用SQL/JSON/XML等DSL描述业务条件，切面上是千变万化的业务，切面下是稳定的引擎

### 1.4 设计目标

| 目标维度 | 具体要求 |
|---------|---------|
| 条件可配置 | 新增条件无需改代码，通过配置即可 |
| 领券性能 | QPS > 5万 |
| 核销一致性 | 券状态与订单状态最终一致 |
| 防刷 | 识别并拦截批量领券 |
| 叠加灵活 | 支持互斥组、优先级、最大叠加数配置 |

## 三、核心链路设计

### 3.1 条件引擎设计（引擎式架构核心）

**问题**：优惠券的发放条件和使用条件千变万化，如"最近七天未下单"、"对优惠敏感"、"商务用户"等。如果硬编码，每次新增条件都要改代码。

**方案**：基于学城文档的引擎式架构思想，用SQL + 动态表的方式表达和计算条件。

```java
/**
 * 条件引擎
 * 
 * 核心思路（来自学城文档）：
 * 1. 将所有外部数据抽象为Dynamic Table（动态表）
 * 2. 用SQL表达条件逻辑
 * 3. 引擎负责解析SQL → 生成DAG执行计划 → 编排执行 → 返回结果
 * 
 * 示例：一张优惠券仅对"最近七天未下单"且"对优惠敏感"的用户发放
 * 条件SQL:
 *   SELECT EXISTS(
 *     SELECT 1 FROM userOrders WHERE createdAt >= DATE_SUB(NOW(), 7)
 *   ) = 0  -- 最近七天未下单
 *   AND EXISTS(
 *     SELECT 1 FROM userLabels WHERE tag = 'coupon_sensitive'
 *   )      -- 对优惠敏感
 */
@Component
public class ConditionEngine {

    /**
     * 动态表注册中心
     * 将MySQL/Redis/Kafka/API等异构数据源统一抽象为表
     */
    @Autowired
    private DynamicTableRegistry tableRegistry;

    /**
     * 评估条件
     * @param conditionSQL 条件SQL表达式
     * @param context 评估上下文（包含userId等参数）
     * @return 是否满足条件
     */
    public boolean evaluate(String conditionSQL, EvalContext context) {
        // 1. 解析SQL，提取引用的表名
        List<String> tableNames = SqlParser.extractTableNames(conditionSQL);

        // 2. 加载所需数据到内存表
        Map<String, List<Map<String, Object>>> tables = new HashMap<>();
        for (String tableName : tableNames) {
            DynamicTable table = tableRegistry.getTable(tableName);
            List<Map<String, Object>> data = table.loadData(context);
            tables.put(tableName, data);
        }

        // 3. 在内存中执行SQL求值
        // 使用Apache Calcite等SQL引擎在内存表上执行查询
        boolean result = inMemorySqlExecutor.execute(conditionSQL, tables, context);

        return result;
    }
}

/**
 * 动态表抽象
 * 将MySQL、Redis、Kafka、API等异构数据源统一抽象为表
 */
public abstract class DynamicTable {
    protected String tableName;
    protected String location;  // 数据源地址

    /**
     * 加载数据到内存
     */
    public abstract List<Map<String, Object>> loadData(EvalContext context);
}

/**
 * 用户订单表（从MySQL加载）
 */
@Component
public class UserOrdersTable extends DynamicTable {

    @Override
    public List<Map<String, Object>> loadData(EvalContext context) {
        Long userId = context.getUserId();
        // 查询用户最近30天订单
        List<OrderDO> orders = orderMapper.selectRecentOrders(userId, 30);

        return orders.stream().map(o -> {
            Map<String, Object> row = new HashMap<>();
            row.put("id", o.getId());
            row.put("userId", o.getUserId());
            row.put("createdAt", o.getCreateTime());
            row.put("useCoupon", o.getCouponValue() > 0);
            row.put("couponValue", o.getCouponValue());
            return row;
        }).collect(Collectors.toList());
    }
}

/**
 * 用户标签表（从API加载）
 */
@Component
public class UserLabelsTable extends DynamicTable {

    @Override
    public List<Map<String, Object>> loadData(EvalContext context) {
        Long userId = context.getUserId();
        // 调用BI系统获取用户标签
        UserLabelDTO label = biFeignClient.getUserLabel(userId);

        Map<String, Object> row = new HashMap<>();
        row.put("userId", userId);
        row.put("cityLevel", label.getCityLevel());
        row.put("career", label.getCareer());
        row.put("tag", label.getTags());
        return Collections.singletonList(row);
    }
}
```

### 3.2 高并发领券链路

**问题**：热门优惠券发放时，瞬间可能有数十万用户同时领取，库存只有1万张，如何保证不超发？

**方案**：Redis Lua脚本原子扣减 + MQ异步落库。

```java
/**
 * 领券服务
 * 
 * 完整链路：
 * 1. 风控检查（频率限制、设备指纹、黑名单）
 * 2. 条件引擎评估（用户是否满足领取条件）
 * 3. Redis Lua脚本原子操作：检查限领数 → 扣减库存 → 记录领取记录
 * 4. MQ异步写入MySQL
 * 5. 返回领券结果
 */
@Service
public class CouponReceiveService {

    /**
     * Lua脚本：原子性检查+扣减+记录
     * KEYS[1] = 库存key: coupon:stock:{templateId}
     * KEYS[2] = 用户领取记录set: coupon:received:{templateId}
     * KEYS[3] = 用户领取计数: coupon:usercount:{templateId}:{userId}
     * ARGV[1] = userId
     * ARGV[2] = perUserLimit (每人限领数)
     * 
     * 返回值：0=成功, 1=库存不足, 2=超过限领数
     */
    private static final String RECEIVE_LUA =
        "local userCount = tonumber(redis.call('GET', KEYS[3]) or '0')\n" +
        "if userCount >= tonumber(ARGV[2]) then\n" +
        "    return 2\n" +  // 超过限领数
        "end\n" +
        "local stock = tonumber(redis.call('GET', KEYS[1]) or '0')\n" +
        "if stock <= 0 then\n" +
        "    return 1\n" +  // 库存不足
        "end\n" +
        "redis.call('DECR', KEYS[1])\n" +  // 扣减库存
        "redis.call('INCR', KEYS[3])\n" +  // 用户领取数+1
        "redis.call('SADD', KEYS[2], ARGV[1])\n" +  // 记录领取用户
        "return 0\n";

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private ConditionEngine conditionEngine;

    @Autowired
    private RiskControlFeignClient riskClient;

    @Autowired
    private RocketMQTemplate mqTemplate;

    public ReceiveResult receive(Long templateId, Long userId, String deviceId) {
        // 1. 风控检查
        RiskResult riskResult = riskClient.check(userId, deviceId, "COUPON_RECEIVE");
        if (riskResult.isBlocked()) {
            return ReceiveResult.fail("操作频繁，请稍后再试");
        }

        // 2. 查询券模板
        CouponTemplate template = getTemplateFromCache(templateId);
        if (template == null) {
            return ReceiveResult.fail("券不存在");
        }

        // 3. 检查有效期
        long now = System.currentTimeMillis();
        if (now < template.getValidStartTime() || now > template.getValidEndTime()) {
            return ReceiveResult.fail("不在领取时间范围内");
        }

        // 4. 条件引擎评估：用户是否满足领取条件
        EvalContext context = new EvalContext(userId);
        if (!conditionEngine.evaluate(template.getReceiveCondition(), context)) {
            return ReceiveResult.fail("不满足领取条件");
        }

        // 5. Redis Lua原子扣减
        String stockKey = "coupon:stock:" + templateId;
        String receivedKey = "coupon:received:" + templateId;
        String userCountKey = "coupon:usercount:" + templateId + ":" + userId;

        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(RECEIVE_LUA);
        script.setResultType(Long.class);

        Long result = redisTemplate.execute(script,
            Arrays.asList(stockKey, receivedKey, userCountKey),
            String.valueOf(userId),
            String.valueOf(template.getPerUserLimit()));

        if (result == null || result == 1L) {
            return ReceiveResult.fail("券已抢完");
        }
        if (result == 2L) {
            return ReceiveResult.fail("已超过每人限领数");
        }

        // 6. 生成券实例ID
        Long couponId = generateCouponId();

        // 7. MQ异步写入MySQL
        CouponIssueMessage msg = new CouponIssueMessage();
        msg.setCouponId(couponId);
        msg.setTemplateId(templateId);
        msg.setUserId(userId);
        msg.setReceiveTime(now);
        msg.setExpireTime(template.getValidEndTime());

        mqTemplate.asyncSend("coupon-issue-topic", msg, new SendCallback() {
            @Override
            public void onSuccess(SendResult r) {
                log.info("券发放MQ发送成功, couponId={}", couponId);
            }
            @Override
            public void onException(Throwable e) {
                // MQ发送失败，回滚Redis
                log.error("券发放MQ失败, 回滚Redis", e);
                rollbackRedisStock(templateId, userId);
            }
        });

        return ReceiveResult.success(couponId);
    }

    /**
     * 回滚Redis库存
     */
    private void rollbackRedisStock(Long templateId, Long userId) {
        String stockKey = "coupon:stock:" + templateId;
        String userCountKey = "coupon:usercount:" + templateId + ":" + userId;
        redisTemplate.opsForValue().increment(stockKey);
        redisTemplate.opsForValue().decrement(userCountKey);
    }
}
```

### 3.3 优惠券叠加规则引擎

**问题**：用户有多张券，下单时可以同时使用几张？哪些可以叠加？哪些互斥？

**方案**：通过互斥组 + 优先级 + 最大叠加数三个维度控制。

```java
/**
 * 优惠券叠加规则引擎
 * 
 * 叠加规则：
 * 1. 互斥组：同一互斥组内的券只能用一张
 * 2. 优先级：同一互斥组内选最优（优惠金额最大）的那张
 * 3. 最大叠加数：一个订单最多使用N张券
 * 4. 品类限制：某些券仅限指定品类
 */
@Service
public class CouponStackEngine {

    /**
     * 筛选最优券组合
     * 
     * @param userCoupons 用户所有可用券
     * @param orderAmount 订单金额
     * @param items 订单商品
     * @return 最优券组合
     */
    public List<CouponInstance> selectBestCombination(
            List<CouponInstance> userCoupons,
            int orderAmount,
            List<OrderItem> items) {

        // 1. 过滤掉不满足使用条件的券
        List<CouponInstance> usable = userCoupons.stream()
            .filter(c -> isUsable(c, orderAmount, items))
            .collect(Collectors.toList());

        // 2. 按互斥组分组
        Map<String, List<CouponInstance>> groupByMutex = usable.stream()
            .collect(Collectors.groupingBy(c ->
                c.getMutexGroup() != null ? c.getMutexGroup() : "none"));

        // 3. 每个互斥组内选最优券（优惠金额最大的）
        List<CouponInstance> candidates = new ArrayList<>();
        for (List<CouponInstance> group : groupByMutex.values()) {
            CouponInstance best = group.stream()
                .max(Comparator.comparingInt(c ->
                    calculateDiscount(c, orderAmount)))
                .orElse(null);
            if (best != null) {
                candidates.add(best);
            }
        }

        // 4. 按优惠金额降序排列
        candidates.sort((a, b) ->
            calculateDiscount(b, orderAmount) - calculateDiscount(a, orderAmount));

        // 5. 取前N张（最大叠加数）
        int maxStack = 3; // 默认最多叠加3张
        return candidates.subList(0, Math.min(maxStack, candidates.size()));
    }

    /**
     * 计算单张券的优惠金额
     */
    private int calculateDiscount(CouponInstance coupon, int orderAmount) {
        CouponTemplate template = getTemplate(coupon.getTemplateId());
        switch (template.getType()) {
            case FULL_REDUCTION:
                // 满减：满threshold减faceValue
                if (orderAmount >= template.getThreshold()) {
                    return template.getFaceValue();
                }
                return 0;
            case DISCOUNT:
                // 折扣：打faceValue折（如85表示8.5折）
                return orderAmount - orderAmount * template.getFaceValue() / 100;
            case DIRECT_REDUCTION:
                // 立减：直接减faceValue
                return template.getFaceValue();
            default:
                return 0;
        }
    }

    /**
     * 判断券是否可用
     */
    private boolean isUsable(CouponInstance coupon, int orderAmount,
                              List<OrderItem> items) {
        CouponTemplate template = getTemplate(coupon.getTemplateId());

        // 检查是否满足门槛
        if (orderAmount < template.getThreshold()) {
            return false;
        }

        // 检查品类限制
        if (template.getCategoryLimit() != null) {
            boolean hasMatchCategory = items.stream()
                .anyMatch(item -> template.getCategoryLimit()
                    .contains(item.getCategoryId()));
            if (!hasMatchCategory) {
                return false;
            }
        }

        // 检查有效期
        long now = System.currentTimeMillis();
        if (now < coupon.getGettime() || now > coupon.getExpireTime()) {
            return false;
        }

        return true;
    }
}
```

### 3.4 核销链路（状态机模式）

**问题**：用户下单时选择了优惠券，券状态需要从"未使用"变为"已使用"，但如果订单创建失败，券状态需要回退。

**方案**：券状态机 + 本地事务表保障一致性。

```java
/**
 * 优惠券状态机
 * 
 * 状态流转：
 * UNUSED(未使用) → LOCKED(已锁定) → USED(已使用)
 *                ↑                  ↓
 *                └── LOCKED(回退) ──┘ (订单取消时)
 * USED → REFUNDED(已退回) (订单退款时)
 */
public enum CouponStatus {
    UNUSED,     // 未使用
    LOCKED,     // 已锁定（下单时锁定，等待支付）
    USED,       // 已使用（支付成功后核销）
    REFUNDED,   // 已退回（退款后退回，不可再用）
    EXPIRED     // 已过期
}

/**
 * 优惠券核销服务
 * 
 * 核销链路：
 * 1. 下单时：UNUSED → LOCKED（锁定券）
 * 2. 支付成功：LOCKED → USED（核销券）
 * 3. 订单取消：LOCKED → UNUSED（回退券）
 * 4. 订单退款：USED → REFUNDED（退款退券，不可再用）
 */
@Service
public class CouponRedeemService {

    /**
     * 锁定优惠券（下单时调用）
     * 使用乐观锁保证并发安全
     */
    @Transactional(rollbackFor = Exception.class)
    public void lockCoupon(Long couponId, Long userId, String orderNo) {
        // 1. 查询券实例
        CouponInstance coupon = couponMapper.selectById(couponId);
        if (coupon == null) {
            throw new BizException("券不存在");
        }
        if (coupon.getStatus() != CouponStatus.UNUSED) {
            throw new BizException("券状态不可用");
        }

        // 2. 乐观锁更新状态：UNUSED → LOCKED
        int affected = couponMapper.updateStatusWithOptimisticLock(
            couponId,
            CouponStatus.UNUSED,    // 期望的旧状态
            CouponStatus.LOCKED,    // 新状态
            orderNo,                // 关联订单号
            System.currentTimeMillis());

        if (affected == 0) {
            throw new BizException("券已被其他订单锁定，请刷新后重试");
        }

        // 3. 同步Redis中的券状态
        String couponKey = "coupon:instance:" + couponId;
        redisTemplate.opsForHash().put(couponKey, "status",
            CouponStatus.LOCKED.name());
        redisTemplate.opsForHash().put(couponKey, "orderNo", orderNo);
    }

    /**
     * 核销优惠券（支付成功后调用）
     */
    @Transactional(rollbackFor = Exception.class)
    public void redeemCoupon(String orderNo) {
        // 1. 根据订单号查询锁定的券
        CouponInstance coupon = couponMapper.selectByOrderNo(orderNo);
        if (coupon == null) {
            return; // 该订单未使用券
        }

        // 2. 状态校验
        if (coupon.getStatus() != CouponStatus.LOCKED) {
            throw new BizException("券状态异常，无法核销");
        }

        // 3. 更新状态：LOCKED → USED
        int affected = couponMapper.updateStatusWithOptimisticLock(
            coupon.getId(),
            CouponStatus.LOCKED,
            CouponStatus.USED,
            orderNo,
            System.currentTimeMillis());

        if (affected == 0) {
            throw new BizException("券核销失败，可能已被处理");
        }

        // 4. 同步Redis
        String couponKey = "coupon:instance:" + coupon.getId();
        redisTemplate.opsForHash().put(couponKey, "status",
            CouponStatus.USED.name());
        redisTemplate.opsForHash().put(couponKey, "usedTime",
            String.valueOf(System.currentTimeMillis()));

        log.info("券核销成功, couponId={}, orderNo={}", coupon.getId(), orderNo);
    }

    /**
     * 回退优惠券（订单取消时调用）
     */
    @Transactional(rollbackFor = Exception.class)
    public void rollbackCoupon(String orderNo) {
        CouponInstance coupon = couponMapper.selectByOrderNo(orderNo);
        if (coupon == null) return;

        // 只有LOCKED状态才能回退
        if (coupon.getStatus() == CouponStatus.LOCKED) {
            couponMapper.updateStatusWithOptimisticLock(
                coupon.getId(),
                CouponStatus.LOCKED,
                CouponStatus.UNUSED,  // 回退为未使用
                null,                 // 清除订单关联
                System.currentTimeMillis());

            // 同步Redis
            String couponKey = "coupon:instance:" + coupon.getId();
            redisTemplate.opsForHash().put(couponKey, "status",
                CouponStatus.UNUSED.name());
            redisTemplate.opsForHash().delete(couponKey, "orderNo");
        }
    }

    /**
     * 退款退券（订单退款时调用）
     * 注意：退款后券变为REFUNDED，不可再用
     */
    @Transactional(rollbackFor = Exception.class)
    public void refundCoupon(String orderNo) {
        CouponInstance coupon = couponMapper.selectByOrderNo(orderNo);
        if (coupon == null) return;

        if (coupon.getStatus() == CouponStatus.USED) {
            couponMapper.updateStatusWithOptimisticLock(
                coupon.getId(),
                CouponStatus.USED,
                CouponStatus.REFUNDED,
                orderNo,
                System.currentTimeMillis());

            String couponKey = "coupon:instance:" + coupon.getId();
            redisTemplate.opsForHash().put(couponKey, "status",
                CouponStatus.REFUNDED.name());
        }
    }
}
```

### 3.5 领券防刷

```java
/**
 * 领券防刷服务
 * 
 * 多维度防刷：
 * 1. 频率控制：同一用户/设备 60秒内只能领1次
 * 2. 设备指纹：识别同一设备的多个账号
 * 3. 行为分析：异常领取模式检测
 * 4. 黑名单：已知黄牛账号
 */
@Service
public class CouponAntiFraudService {

    /**
     * 领券前风控检查
     */
    public boolean checkBeforeReceive(Long userId, String deviceId,
                                       Long templateId) {
        // 1. 频率控制：滑动窗口
        String freqKey = "coupon:freq:" + userId;
        long now = System.currentTimeMillis();
        long windowStart = now - 60_000; // 60秒窗口

        Long count = redisTemplate.opsForZSet()
            .count(freqKey, windowStart, now);
        if (count != null && count >= 1) {
            log.warn("用户领券频率超限, userId={}", userId);
            return false;
        }

        // 2. 设备维度频率控制
        String deviceFreqKey = "coupon:devfreq:" + deviceId;
        Long deviceCount = redisTemplate.opsForZSet()
            .count(deviceFreqKey, windowStart, now);
        if (deviceCount != null && deviceCount >= 3) {
            log.warn("设备领券频率超限, deviceId={}", deviceId);
            return false;
        }

        // 3. 黑名单检查
        if (isInBlacklist(userId)) {
            return false;
        }

        // 4. 设备指纹关联分析：同一设备关联的账号数
        String deviceUsersKey = "coupon:deviceusers:" + deviceId;
        Long userCount = redisTemplate.opsForSet().size(deviceUsersKey);
        if (userCount != null && userCount >= 5) {
            // 同一设备关联5个以上账号，疑似黄牛
            log.warn("设备关联账号过多, deviceId={}, count={}", deviceId, userCount);
            return false;
        }

        // 记录本次领券
        redisTemplate.opsForZSet().add(freqKey,
            String.valueOf(now), now);
        redisTemplate.opsForZSet().expire(freqKey, 60, TimeUnit.SECONDS);

        redisTemplate.opsForSet().add(deviceUsersKey, String.valueOf(userId));

        return true;
    }
}
```

```java
/**
 * 券模板多级缓存

@Service
public class CouponTemplateCacheService {

    private final Cache<Long, CouponTemplate> localCache = Caffeine.newBuilder()
        .maximumSize(1000)
        .expireAfterWrite(5, TimeUnit.MINUTES)
        .build();

    public CouponTemplate getTemplate(Long templateId) {
        // 1. 本地缓存
        CouponTemplate cached = localCache.getIfPresent(templateId);
        if (cached != null) return cached;

        // 2. Redis
        String json = redisTemplate.opsForValue()
            .get("coupon:template:" + templateId);
        if (json != null) {
            CouponTemplate template = JSON.parseObject(json, CouponTemplate.class);
            localCache.put(templateId, template);
            return template;
        }

        // 3. MySQL
        CouponTemplate template = couponTemplateMapper.selectById(templateId);
        if (template != null) {
            redisTemplate.opsForValue().set("coupon:template:" + templateId,
                JSON.toJSONString(template), 30, TimeUnit.MINUTES);
            localCache.put(templateId, template);
        }
        return template;
    }
}
```

## 六、最佳实践与总结

### 6.1 设计原则

1. **引擎式架构**：条件可配置不写死代码，符合开闭原则（来自学城文档核心思想）
2. **Lua原子操作**：高并发领券用Redis Lua保证"检查+扣减+记录"原子性
3. **状态机管理**：券状态变更走状态机，不允许跳跃
4. **最终一致性**：Redis实时操作 + MQ异步落库 + 定时对账
5. **多维度防刷**：频率+设备+行为+黑名单四重防护

### 6.2 核心设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 条件表达 | SQL+动态表 | 可配置不改代码，可视化 |
| 库存扣减 | Redis Lua | 原子性+高性能 |
| 叠加规则 | 互斥组+优先级 | 灵活可扩展 |
| 核销一致性 | 本地事务表 | 最终一致，避免分布式事务 |
| 防刷 | 多维度组合 | 单一手段易被绕过 |

### 6.3 容易踩的坑

1. **条件硬编码**：把领取/使用条件写在代码里，每次改条件都要上线
2. **领券超发**：没用Lua原子操作，并发扣减导致超发
3. **核销不一致**：券锁定了但订单创建失败，券卡在LOCKED状态
4. **退款未退券**：退款流程忘记调用退券接口
5. **叠加规则错误**：互斥组配置错误导致不该叠加的券叠加了
6. **过期券未清理**：大量过期券影响查询性能，需要定时清理

```java
/**
 * 优惠券领券Controller
 */
@RestController
@RequestMapping("/api/coupon")
public class CouponReceiveController {

    @Autowired
    private CouponReceiveFacade couponReceiveFacade;

    /**
     * 用户领取优惠券
     * 
     * @param request 领券请求
     * @return 领券结果
     */
    @PostMapping("/receive")
    public Result<ReceiveVO> receive(@RequestBody @Valid ReceiveRequest request,
                                      BindingResult bindingResult,
                                      HttpServletRequest servletRequest) {
        // 1. 参数校验
        if (bindingResult.hasErrors()) {
            String errMsg = bindingResult.getFieldErrors().stream()
                .map(e -> e.getDefaultMessage())
                .collect(Collectors.joining(";"));
            log.warn("领券参数校验失败, request={}, errors={}", request, errMsg);
            return Result.fail(ErrorCode.PARAM_ERROR.getCode(), errMsg);
        }

        // 2. 从请求头中获取设备信息和用户信息
        String deviceId = servletRequest.getHeader("X-Device-Id");
        Long userId = UserContext.getUserId(); // 从线程上下文获取登录用户

        if (userId == null) {
            return Result.fail(ErrorCode.NOT_LOGIN);
        }

        // 3. 幂等检查：同一用户对同一券模板的领券请求，5秒内去重
        String idempotentKey = "coupon:receive:idem:" + userId + ":" + request.getTemplateId();
        Boolean isFirst = redisTemplate.opsForValue()
            .setIfAbsent(idempotentKey, "1", 5, TimeUnit.SECONDS);
        if (isFirst != null && !isFirst) {
            log.warn("重复领券请求被拦截, userId={}, templateId={}", userId, request.getTemplateId());
            return Result.fail(ErrorCode.DUPLICATE_REQUEST, "请勿重复领取");
        }

        // 4. 调用Facade
        ReceiveResult result = couponReceiveFacade.receive(
            request.getTemplateId(), userId, deviceId);

        if (result.isSuccess()) {
            ReceiveVO vo = new ReceiveVO();
            vo.setCouponId(result.getCouponId());
            vo.setExpireTime(result.getExpireTime());
            return Result.success(vo);
        }
        return Result.fail(result.getCode(), result.getMessage());
    }
}
```

#### 7.1.2 Facade层编排领券全链路

```java
/**
 * 领券Facade：编排领券全链路
 * 
 * 完整流程：
 * 1. 领取资格校验（活动有效性、领取时间、用户条件）
 * 2. 防刷检查（频率、设备、黑名单）
 * 3. Redis Lua原子扣减库存
 * 4. MQ异步写入用户优惠券记录
 * 5. MQ异步通知（统计、推送）
 */
@Service
@Slf4j
public class CouponReceiveFacade {

    @Autowired
    private CouponTemplateCacheService templateCacheService;
    @Autowired
    private CouponAntiFraudService antiFraudService;
    @Autowired
    private ConditionEngine conditionEngine;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private RocketMQTemplate mqTemplate;
    @Autowired
    private CouponReceiveFailLogMapper failLogMapper;

    /**
     * Lua脚本：原子性 检查限领数 + 扣减库存 + 记录领取
     * KEYS[1] = coupon:stock:{templateId}        库存
     * KEYS[2] = coupon:received:{templateId}     已领取用户Set
     * KEYS[3] = coupon:usercount:{templateId}:{userId}  用户领取计数
     * ARGV[1] = userId
     * ARGV[2] = perUserLimit
     * ARGV[3] = requestId（幂等标识）
     * KEYS[4] = coupon:reqid:{templateId}        请求ID去重Set
     * 
     * 返回值：0=成功, 1=库存不足, 2=超过限领数, 3=重复请求
     */
    private static final String RECEIVE_LUA =
        "if redis.call('SISMEMBER', KEYS[4], ARGV[3]) == 1 then\n" +
        "    return 3\n" +  // 重复请求
        "end\n" +
        "local userCount = tonumber(redis.call('GET', KEYS[3]) or '0')\n" +
        "if userCount >= tonumber(ARGV[2]) then\n" +
        "    return 2\n" +  // 超过限领数
        "end\n" +
        "local stock = tonumber(redis.call('GET', KEYS[1]) or '0')\n" +
        "if stock <= 0 then\n" +
        "    return 1\n" +  // 库存不足
        "end\n" +
        "redis.call('DECR', KEYS[1])\n" +
        "redis.call('INCR', KEYS[3])\n" +
        "redis.call('SADD', KEYS[2], ARGV[1])\n" +
        "redis.call('SADD', KEYS[4], ARGV[3])\n" +
        "redis.call('EXPIRE', KEYS[4], 3600)\n" +  // 请求ID去重1小时
        "return 0\n";

    public ReceiveResult receive(Long templateId, Long userId, String deviceId) {
        long startTime = System.currentTimeMillis();
        String requestId = RequestIdUtil.generate();

        try {
            // ========== 第一步：领取资格校验 ==========

            // 1.1 查询券模板（多级缓存）
            CouponTemplate template = templateCacheService.getTemplate(templateId);
            if (template == null) {
                log.warn("领券失败-券模板不存在, templateId={}, userId={}", templateId, userId);
                return ReceiveResult.fail("COUPON_NOT_FOUND", "券不存在");
            }

            // 1.2 检查活动状态
            if (template.getStatus() != TemplateStatus.ACTIVE) {
                log.warn("领券失败-活动未生效, templateId={}, status={}",
                    templateId, template.getStatus());
                return ReceiveResult.fail("ACTIVITY_INACTIVE", "活动未开始或已结束");
            }

            // 1.3 检查领取时间范围
            long now = System.currentTimeMillis();
            if (now < template.getValidStartTime()) {
                return ReceiveResult.fail("NOT_STARTED", "活动尚未开始");
            }
            if (now > template.getValidEndTime()) {
                return ReceiveResult.fail("ALREADY_ENDED", "活动已结束");
            }

            // 1.4 条件引擎评估：用户是否满足领取条件
            EvalContext context = new EvalContext(userId);
            context.put("templateId", templateId);
            try {
                if (!conditionEngine.evaluate(template.getReceiveCondition(), context)) {
                    log.info("领券失败-不满足领取条件, userId={}, templateId={}",
                        userId, templateId);
                    return ReceiveResult.fail("CONDITION_NOT_MET", "不满足领取条件");
                }
            } catch (Exception e) {
                log.error("条件引擎评估异常, userId={}, templateId={}",
                    userId, templateId, e);
                // 条件引擎异常时降级：放行领券，避免影响正常用户
                log.warn("条件引擎降级，放行领券, userId={}, templateId={}",
                    userId, templateId);
            }

            // ========== 第二步：防刷检查 ==========
            if (!antiFraudService.checkBeforeReceive(userId, deviceId, templateId)) {
                log.warn("领券失败-风控拦截, userId={}, deviceId={}", userId, deviceId);
                return ReceiveResult.fail("RISK_BLOCKED", "操作频繁，请稍后再试");
            }

            // ========== 第三步：Redis Lua原子扣减库存 ==========
            String stockKey = "coupon:stock:" + templateId;
            String receivedKey = "coupon:received:" + templateId;
            String userCountKey = "coupon:usercount:" + templateId + ":" + userId;
            String reqIdKey = "coupon:reqid:" + templateId;

            DefaultRedisScript<Long> script = new DefaultRedisScript<>();
            script.setScriptText(RECEIVE_LUA);
            script.setResultType(Long.class);

            Long luaResult = redisTemplate.execute(script,
                Arrays.asList(stockKey, receivedKey, userCountKey, reqIdKey),
                String.valueOf(userId),
                String.valueOf(template.getPerUserLimit()),
                requestId);

            if (luaResult == null) {
                log.error("Lua脚本执行返回null, userId={}, templateId={}", userId, templateId);
                return ReceiveResult.fail("SYSTEM_ERROR", "系统异常，请重试");
            }

            switch (luaResult.intValue()) {
                case 1:
                    log.info("领券失败-库存不足, userId={}, templateId={}", userId, templateId);
                    return ReceiveResult.fail("STOCK_EMPTY", "券已抢完");
                case 2:
                    log.info("领券失败-超过限领数, userId={}, templateId={}, limit={}",
                        userId, templateId, template.getPerUserLimit());
                    return ReceiveResult.fail("LIMIT_EXCEEDED", "已超过每人限领数");
                case 3:
                    log.info("领券失败-重复请求, userId={}, templateId={}, requestId={}",
                        userId, templateId, requestId);
                    return ReceiveResult.fail("DUPLICATE_REQUEST", "请勿重复领取");
                case 0:
                    // 成功，继续后续流程
                    break;
                default:
                    log.error("Lua脚本返回未知结果, result={}, userId={}, templateId={}",
                        luaResult, userId, templateId);
                    return ReceiveResult.fail("SYSTEM_ERROR", "系统异常，请重试");
            }

            // ========== 第四步：生成券实例ID ==========
            Long couponId = CouponIdGenerator.nextId(); // 雪花算法生成

            // ========== 第五步：MQ异步写入用户优惠券记录 ==========
            CouponIssueMessage issueMsg = new CouponIssueMessage();
            issueMsg.setCouponId(couponId);
            issueMsg.setTemplateId(templateId);
            issueMsg.setUserId(userId);
            issueMsg.setRequestId(requestId); // 用于消费端幂等
            issueMsg.setReceiveTime(now);
            issueMsg.setExpireTime(template.getValidEndTime());
            issueMsg.setFaceValue(template.getFaceValue());
            issueMsg.setCouponType(template.getType());

            try {
                mqTemplate.syncSendOrderly("coupon-issue-topic", issueMsg,
                    String.valueOf(userId)); // 按userId hash保证同一用户顺序消费
                log.info("领券MQ发送成功, couponId={}, userId={}, templateId={}",
                    couponId, userId, templateId);
            } catch (Exception e) {
                // MQ发送失败：回滚Redis库存，保证一致性
                log.error("领券MQ发送失败，回滚Redis, couponId={}, userId={}, templateId={}",
                    couponId, userId, templateId, e);
                rollbackRedisStock(templateId, userId, requestId);

                // 记录失败日志，便于后续人工补偿
                recordFailLog(templateId, userId, requestId, "MQ_SEND_FAIL", e.getMessage());
                return ReceiveResult.fail("SYSTEM_ERROR", "系统繁忙，请重试");
            }

            // ========== 第六步：MQ异步通知（统计+推送） ==========
            CouponNotifyMessage notifyMsg = new CouponNotifyMessage();
            notifyMsg.setUserId(userId);
            notifyMsg.setTemplateId(templateId);
            notifyMsg.setCouponId(couponId);
            notifyMsg.setEventTime(now);
            notifyMsg.setEventType("RECEIVE");

            // 统计消息和推送消息分属不同Topic，互不影响
            try {
                mqTemplate.asyncSend("coupon-stats-topic", notifyMsg,
                    new SendCallback() {
                        @Override
                        public void onSuccess(SendResult r) {
                            log.debug("统计消息发送成功, userId={}", userId);
                        }
                        @Override
                        public void onException(Throwable e) {
                            log.error("统计消息发送失败, userId={}", userId, e);
                            // 统计消息丢失不影响主流程，有定时对账兜底
                        }
                    });
            } catch (Exception e) {
                log.warn("统计消息发送异常，忽略, userId={}", userId, e);
            }

            // 推送通知（通过Push服务）
            try {
                mqTemplate.asyncSend("coupon-push-topic", notifyMsg,
                    new SendCallback() {
                        @Override
                        public void onSuccess(SendResult r) {}
                        @Override
                        public void onException(Throwable e) {
                            log.warn("推送消息发送失败, userId={}", userId, e);
                        }
                    });
            } catch (Exception e) {
                log.warn("推送消息发送异常，忽略, userId={}", userId, e);
            }

            long costMs = System.currentTimeMillis() - startTime;
            log.info("领券成功, userId={}, templateId={}, couponId={}, costMs={}",
                userId, templateId, couponId, costMs);

            return ReceiveResult.success(couponId, template.getValidEndTime());

        } catch (Exception e) {
            log.error("领券异常, userId={}, templateId={}", userId, templateId, e);
            return ReceiveResult.fail("SYSTEM_ERROR", "系统异常，请重试");
        }
    }

    /**
     * 回滚Redis库存（MQ发送失败时调用）
     */
    private void rollbackRedisStock(Long templateId, Long userId, String requestId) {
        try {
            String stockKey = "coupon:stock:" + templateId;
            String userCountKey = "coupon:usercount:" + templateId + ":" + userId;
            String reqIdKey = "coupon:reqid:" + templateId;

            redisTemplate.opsForValue().increment(stockKey);
            redisTemplate.opsForValue().decrement(userCountKey);
            redisTemplate.opsForSet().remove(reqIdKey, requestId);
            redisTemplate.opsForSet().remove("coupon:received:" + templateId,
                String.valueOf(userId));

            log.info("Redis库存回滚完成, templateId={}, userId={}", templateId, userId);
        } catch (Exception e) {
            log.error("Redis库存回滚失败，需要人工补偿, templateId={}, userId={}",
                templateId, userId, e);
        }
    }

    /**
     * 记录失败日志
     */
    private void recordFailLog(Long templateId, Long userId,
                                String requestId, String errorCode, String errorMsg) {
        try {
            CouponReceiveFailLog log = new CouponReceiveFailLog();
            log.setTemplateId(templateId);
            log.setUserId(userId);
            log.setRequestId(requestId);
            log.setErrorCode(errorCode);
            log.setErrorMsg(errorMsg);
            log.setCreateTime(new Date());
            failLogMapper.insert(log);
        } catch (Exception e) {
            CouponReceiveFacade.log.error("写入失败日志异常", e);
        }
    }
}
```

```java
@RocketMQMessageListener(topic = "coupon-issue-topic",

    private CouponInstanceMapper couponMapper;

    private CouponTemplateMapper templateMapper;

                return;

            instance.setId(msg.getCouponId());
            instance.setTemplateId(msg.getTemplateId());
            instance.setUserId(msg.getUserId());
            instance.setStatus(CouponStatus.UNUSED);
            instance.setGettime(msg.getReceiveTime());
            instance.setExpireTime(msg.getExpireTime());
            instance.setCreateTime(new Date());
            instance.setUpdateTime(new Date());

            log.info("券发放落库成功, couponId={}, userId={}, templateId={}",
                msg.getCouponId(), msg.getUserId(), msg.getTemplateId());

            // 并发插入冲突，说明已被其他消费者处理
```

### 7.2 案例二：下单时使用优惠券全链路

**场景描述**：用户下单时选择了一张"满100减20"优惠券，订单包含3件商品，总价120元。系统完成券有效性校验、券锁定、优惠金额分摊、支付后核销的完整流程，以及订单取消/退款时的券回退补偿。

#### 7.2.1 下单时优惠券校验与锁定

```java
/**
 * 下单使用优惠券Facade
 * 
 * 完整流程：
 * 1. 优惠券有效性校验（归属、状态、过期、门槛）
 * 2. 优惠券锁定（状态 UNUSED → LOCKED，乐观锁CAS）
 * 3. 优惠金额计算与多商品分摊
 * 4. 与订单创建在同一本地事务中
 */
@Service
@Slf4j
public class OrderCouponFacade {

    @Autowired
    private CouponInstanceMapper couponMapper;
    @Autowired
    private CouponTemplateCacheService templateCacheService;
    @Autowired
    private ConditionEngine conditionEngine;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private OrderItemMapper orderItemMapper;
    @Autowired
    private CouponDiscountSplitMapper splitMapper;

    /**
     * 下单时校验并锁定优惠券
     * 
     * @param couponId    用户选择的券ID
     * @param userId      用户ID
     * @param orderNo     订单号
     * @param orderAmount 订单总金额（分）
     * @param items       订单商品列表
     * @return 优惠金额（分）
     */
    @Transactional(rollbackFor = Exception.class)
    public int validateAndLockCoupon(Long couponId, Long userId, String orderNo,
                                      int orderAmount, List<OrderItem> items) {
        log.info("下单使用优惠券开始, couponId={}, userId={}, orderNo={}, orderAmount={}",
            couponId, userId, orderNo, orderAmount);

        // ========== 第一步：优惠券有效性校验 ==========

        // 1.1 查询券实例
        CouponInstance coupon = couponMapper.selectById(couponId);
        if (coupon == null) {
            throw new CouponBizException("COUPON_NOT_FOUND", "优惠券不存在");
        }

        // 1.2 校验归属
        if (!coupon.getUserId().equals(userId)) {
            log.error("优惠券归属校验失败, couponId={}, couponUserId={}, requestUserId={}",
                couponId, coupon.getUserId(), userId);
            throw new CouponBizException("COUPON_NOT_OWNED", "优惠券不属于当前用户");
        }

        // 1.3 校验状态
        if (coupon.getStatus() != CouponStatus.UNUSED) {
            log.warn("优惠券状态不可用, couponId={}, status={}",
                couponId, coupon.getStatus());
            throw new CouponBizException("COUPON_STATUS_INVALID",
                "优惠券状态不可用: " + coupon.getStatus());
        }

        // 1.4 校验有效期
        long now = System.currentTimeMillis();
        if (now > coupon.getExpireTime()) {
            log.warn("优惠券已过期, couponId={}, expireTime={}",
                couponId, coupon.getExpireTime());
            throw new CouponBizException("COUPON_EXPIRED", "优惠券已过期");
        }

        // 1.5 查询券模板，校验使用条件
        CouponTemplate template = templateCacheService.getTemplate(coupon.getTemplateId());
        if (template == null) {
            throw new CouponBizException("TEMPLATE_NOT_FOUND", "券模板不存在");
        }

        // 1.6 校验门槛金额
        if (orderAmount < template.getThreshold()) {
            log.warn("订单金额不满足门槛, orderAmount={}, threshold={}",
                orderAmount, template.getThreshold());
            throw new CouponBizException("THRESHOLD_NOT_MET",
                String.format("订单金额需满%d元", template.getThreshold() / 100));
        }

        // 1.7 校验品类限制
        if (template.getCategoryLimit() != null && !template.getCategoryLimit().isEmpty()) {
            boolean hasMatchCategory = items.stream()
                .anyMatch(item -> template.getCategoryLimit()
                    .contains(item.getCategoryId()));
            if (!hasMatchCategory) {
                throw new CouponBizException("CATEGORY_NOT_MATCH",
                    "优惠券不适用于当前商品品类");
            }
        }

        // 1.8 条件引擎评估使用条件
        EvalContext context = new EvalContext(userId);
        context.put("orderAmount", orderAmount);
        context.put("items", items);
        try {
            if (!conditionEngine.evaluate(template.getUseCondition(), context)) {
                throw new CouponBizException("USE_CONDITION_NOT_MET",
                    "不满足优惠券使用条件");
            }
        } catch (CouponBizException e) {
            throw e;
        } catch (Exception e) {
            log.error("使用条件评估异常, couponId={}", couponId, e);
            // 条件引擎异常降级：放行
        }

        // ========== 第二步：优惠券锁定（乐观锁CAS） ==========

        // 2.1 CAS更新：UNUSED → LOCKED
        int affected = couponMapper.updateStatusWithOptimisticLock(
            couponId,
            CouponStatus.UNUSED,    // 期望旧状态
            CouponStatus.LOCKED,    // 新状态
            orderNo,                // 关联订单号
            now);

        if (affected == 0) {
            // CAS失败，说明券状态已被其他请求修改（并发核销冲突）
            CouponInstance latest = couponMapper.selectById(couponId);
            log.error("优惠券锁定CAS失败, couponId={}, currentStatus={}, expectedStatus={}",
                couponId,
                latest != null ? latest.getStatus() : "null",
                CouponStatus.UNUSED);
            throw new CouponBizException("COUPON_LOCK_CONFLICT",
                "优惠券已被使用或锁定，请刷新后重试");
        }

        // 2.2 同步Redis券状态
        String couponKey = "coupon:instance:" + couponId;
        redisTemplate.opsForHash().put(couponKey, "status", CouponStatus.LOCKED.name());
        redisTemplate.opsForHash().put(couponKey, "orderNo", orderNo);
        redisTemplate.opsForHash().put(couponKey, "lockTime", String.valueOf(now));

        log.info("优惠券锁定成功, couponId={}, orderNo={}", couponId, orderNo);

        // ========== 第三步：优惠金额计算与分摊 ==========

        // 3.1 计算优惠总金额
        int discountAmount = calculateDiscount(template, orderAmount);
        log.info("优惠金额计算, couponId={}, type={}, orderAmount={}, discount={}",
            couponId, template.getType(), orderAmount, discountAmount);

        // 3.2 多商品优惠金额分摊
        List<CouponDiscountSplit> splits = splitDiscount(items, discountAmount, couponId, orderNo);
        for (CouponDiscountSplit split : splits) {
            splitMapper.insert(split);
        }

        log.info("优惠券分摊完成, couponId={}, orderNo={}, splitCount={}",
            couponId, orderNo, splits.size());

        return discountAmount;

        // 注意：此方法在OrderService.createOrder()的本地事务中调用
        // 如果后续订单创建步骤失败，整个事务回滚，券状态自动回退为UNUSED
    }

    /**
     * 计算优惠金额
     */
    private int calculateDiscount(CouponTemplate template, int orderAmount) {
        switch (template.getType()) {
            case FULL_REDUCTION:
                // 满减：满threshold减faceValue
                if (orderAmount >= template.getThreshold()) {
                    return template.getFaceValue();
                }
                return 0;
            case DISCOUNT:
                // 折扣：faceValue=85表示8.5折
                return orderAmount - orderAmount * template.getFaceValue() / 100;
            case DIRECT_REDUCTION:
                // 立减
                return Math.min(template.getFaceValue(), orderAmount);
            default:
                return 0;
        }
    }

    /**
     * 优惠金额分摊（按商品金额比例分摊，最后一项兜底）
     * 
     * 示例：3件商品分别40元、50元、30元，优惠20元
     *   商品1: 20 * 40/120 = 6.67 → 6分
     *   商品2: 20 * 50/120 = 8.33 → 8分
     *   商品3: 20 - 6 - 8 = 6分（兜底）
     * 
     * @param items           订单商品列表
     * @param discountAmount  优惠总金额（分）
     * @param couponId        券ID
     * @param orderNo         订单号
     * @return 分摊明细列表
     */
    private List<CouponDiscountSplit> splitDiscount(List<OrderItem> items,
                                                     int discountAmount,
                                                     Long couponId,
                                                     String orderNo) {
        List<CouponDiscountSplit> splits = new ArrayList<>();

        // 计算订单总金额
        int totalAmount = items.stream()
            .mapToInt(OrderItem::getAmount)
            .sum();

        if (totalAmount <= 0 || discountAmount <= 0) {
            return splits;
        }

        int allocated = 0; // 已分摊金额
        for (int i = 0; i < items.size(); i++) {
            OrderItem item = items.get(i);
            CouponDiscountSplit split = new CouponDiscountSplit();
            split.setOrderNo(orderNo);
            split.setCouponId(couponId);
            split.setOrderItemId(item.getId());
            split.setSkuId(item.getSkuId());

            if (i == items.size() - 1) {
                // 最后一项兜底：用剩余金额，避免分摊误差
                split.setDiscountAmount(discountAmount - allocated);
            } else {
                // 按比例分摊
                int itemDiscount = discountAmount * item.getAmount() / totalAmount;
                split.setDiscountAmount(itemDiscount);
                allocated += itemDiscount;
            }

            splits.add(split);
        }

        return splits;
    }
}
```

#### 7.2.2 支付成功后核销优惠券

```java
/**
 * 支付成功后核销优惠券
 * 
 * 监听支付成功MQ消息，将券状态从LOCKED变为USED
 */
@Component
@Slf4j
@RocketMQMessageListener(topic = "payment-success-topic",
    consumerGroup = "coupon-redeem-consumer-group")
public class CouponRedeemConsumer implements RocketMQListener<PaymentSuccessMessage> {

    @Autowired
    private CouponInstanceMapper couponMapper;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private CouponRedeemLogMapper redeemLogMapper;

    @Override
    public void onMessage(PaymentSuccessMessage msg) {
        String orderNo = msg.getOrderNo();
        log.info("收到支付成功消息，开始核销优惠券, orderNo={}", orderNo);

        try {
            // 1. 根据订单号查询锁定的券
            CouponInstance coupon = couponMapper.selectByOrderNo(orderNo);
            if (coupon == null) {
                log.info("该订单未使用优惠券, orderNo={}", orderNo);
                return;
            }

            // 2. 幂等检查：是否已核销
            if (coupon.getStatus() == CouponStatus.USED) {
                log.info("优惠券已核销，跳过, couponId={}, orderNo={}",
                    coupon.getId(), orderNo);
                return;
            }

            // 3. 状态校验
            if (coupon.getStatus() != CouponStatus.LOCKED) {
                log.error("券状态异常，无法核销, couponId={}, status={}, orderNo={}",
                    coupon.getId(), coupon.getStatus(), orderNo);
                // 记录异常日志，人工介入
                recordRedeemFailLog(coupon, orderNo, "STATUS_INVALID",
                    "券状态不是LOCKED: " + coupon.getStatus());
                return;
            }

            // 4. CAS更新：LOCKED → USED
            int affected = couponMapper.updateStatusWithOptimisticLock(
                coupon.getId(),
                CouponStatus.LOCKED,
                CouponStatus.USED,
                orderNo,
                System.currentTimeMillis());

            if (affected == 0) {
                // CAS失败，可能已被其他消费者核销（消息重复消费）
                CouponInstance latest = couponMapper.selectById(coupon.getId());
                if (latest != null && latest.getStatus() == CouponStatus.USED) {
                    log.info("券已被核销，幂等返回, couponId={}", coupon.getId());
                    return;
                }
                log.error("券核销CAS失败, couponId={}, orderNo={}", coupon.getId(), orderNo);
                recordRedeemFailLog(coupon, orderNo, "CAS_FAIL",
                    "乐观锁更新失败");
                return;
            }

            // 5. 同步Redis
            String couponKey = "coupon:instance:" + coupon.getId();
            redisTemplate.opsForHash().put(couponKey, "status", CouponStatus.USED.name());
            redisTemplate.opsForHash().put(couponKey, "usedTime",
                String.valueOf(System.currentTimeMillis()));

            // 6. 记录核销日志
            CouponRedeemLog log = new CouponRedeemLog();
            log.setCouponId(coupon.getId());
            log.setOrderNo(orderNo);
            log.setUserId(coupon.getUserId());
            log.setRedeemTime(new Date());
            log.setStatus("SUCCESS");
            redeemLogMapper.insert(log);

            log.info("优惠券核销成功, couponId={}, orderNo={}", coupon.getId(), orderNo);

        } catch (Exception e) {
            log.error("优惠券核销异常, orderNo={}", orderNo, e);
            throw new RuntimeException("核销异常，触发重试", e);
        }
    }

    private void recordRedeemFailLog(CouponInstance coupon, String orderNo,
                                      String errorCode, String errorMsg) {
        CouponRedeemLog log = new CouponRedeemLog();
        log.setCouponId(coupon.getId());
        log.setOrderNo(orderNo);
        log.setUserId(coupon.getUserId());
        log.setRedeemTime(new Date());
        log.setStatus("FAIL");
        log.setErrorCode(errorCode);
        log.setErrorMsg(errorMsg);
        redeemLogMapper.insert(log);
    }
}
```

#### 7.2.3 订单取消/退款后优惠券退回补偿流程

```java
/**
 * 订单状态变更时优惠券补偿服务
 * 
 * 场景1：订单取消（未支付） → 券 LOCKED → UNUSED（可继续使用）
 * 场景2：订单退款（已支付） → 券 USED → REFUNDED（不可再用）
 * 场景3：部分退款 → 券 USED → REFUNDED（按业务规则决定是否退券）
 */
@Component
@Slf4j
@RocketMQMessageListener(topic = "order-status-change-topic",
    consumerGroup = "coupon-refund-consumer-group")
public class CouponRefundConsumer implements RocketMQListener<OrderStatusChangeMessage> {

    @Autowired
    private CouponInstanceMapper couponMapper;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private CouponRefundLogMapper refundLogMapper;
    @Autowired
    private RocketMQTemplate mqTemplate;

    @Override
    public void onMessage(OrderStatusChangeMessage msg) {
        String orderNo = msg.getOrderNo();
        String newStatus = msg.getNewStatus();

        log.info("收到订单状态变更消息, orderNo={}, oldStatus={}, newStatus={}",
            orderNo, msg.getOldStatus(), newStatus);

        try {
            switch (newStatus) {
                case "CANCELLED":
                    handleOrderCancel(orderNo);
                    break;
                case "REFUNDED":
                    handleOrderRefund(orderNo, msg.getRefundType());
                    break;
                default:
                    // 其他状态变更不处理
                    break;
            }
        } catch (Exception e) {
            log.error("优惠券退回处理异常, orderNo={}, newStatus={}",
                orderNo, newStatus, e);
            throw new RuntimeException("退券异常，触发重试", e);
        }
    }

    /**
     * 订单取消：券 LOCKED → UNUSED
     * 用户可以继续使用该券
     */
    private void handleOrderCancel(String orderNo) {
        CouponInstance coupon = couponMapper.selectByOrderNo(orderNo);
        if (coupon == null) {
            log.info("订单未使用优惠券, orderNo={}", orderNo);
            return;
        }

        // 幂等检查
        if (coupon.getStatus() == CouponStatus.UNUSED) {
            log.info("券已退回，幂等跳过, couponId={}, orderNo={}",
                coupon.getId(), orderNo);
            return;
        }

        if (coupon.getStatus() != CouponStatus.LOCKED) {
            log.warn("券状态非LOCKED，无法退回, couponId={}, status={}",
                coupon.getId(), coupon.getStatus());
            return;
        }

        // CAS更新：LOCKED → UNUSED
        int affected = couponMapper.updateStatusWithOptimisticLock(
            coupon.getId(),
            CouponStatus.LOCKED,
            CouponStatus.UNUSED,
            null,  // 清除订单关联
            System.currentTimeMillis());

        if (affected == 0) {
            log.warn("券退回CAS失败, couponId={}, orderNo={}", coupon.getId(), orderNo);
            return;
        }

        // 同步Redis
        String couponKey = "coupon:instance:" + coupon.getId();
        redisTemplate.opsForHash().put(couponKey, "status", CouponStatus.UNUSED.name());
        redisTemplate.opsForHash().delete(couponKey, "orderNo");
        redisTemplate.opsForHash().delete(couponKey, "lockTime");

        // 清除优惠分摊记录
        splitMapper.deleteByOrderNo(orderNo);

        // 记录退券日志
        recordRefundLog(coupon, orderNo, "CANCEL_REFUND", "订单取消退券");

        // 发送通知：告知用户券已退回
        CouponNotifyMessage notify = new CouponNotifyMessage();
        notify.setUserId(coupon.getUserId());
        notify.setCouponId(coupon.getId());
        notify.setEventType("CANCEL_REFUND");
        notify.setEventTime(System.currentTimeMillis());
        mqTemplate.asyncSend("coupon-push-topic", notify, new SendCallback() {
            @Override
            public void onSuccess(SendResult r) {}
            @Override
            public void onException(Throwable e) {
                log.warn("退券通知发送失败, couponId={}", coupon.getId(), e);
            }
        });

        log.info("订单取消退券成功, couponId={}, orderNo={}", coupon.getId(), orderNo);
    }

    /**
     * 订单退款：券 USED → REFUNDED
     * 
     * @param orderNo    订单号
     * @param refundType 退款类型（FULL=全额退款, PARTIAL=部分退款）
     */
    private void handleOrderRefund(String orderNo, String refundType) {
        CouponInstance coupon = couponMapper.selectByOrderNo(orderNo);
        if (coupon == null) {
            log.info("订单未使用优惠券, orderNo={}", orderNo);
            return;
        }

        // 幂等检查
        if (coupon.getStatus() == CouponStatus.REFUNDED) {
            log.info("券已退回，幂等跳过, couponId={}", coupon.getId());
            return;
        }

        if (coupon.getStatus() != CouponStatus.USED) {
            log.warn("券状态非USED，无法退款退券, couponId={}, status={}",
                coupon.getId(), coupon.getStatus());
            return;
        }

        // 部分退款策略：根据业务规则决定是否退券
        // 策略1：部分退款不退券（券已核销，部分退款不回退）
        // 策略2：部分退款退券（需要重新核销实际使用部分）
        // 这里采用策略1：部分退款不退券
        if ("PARTIAL".equals(refundType)) {
            log.info("部分退款，不退券, couponId={}, orderNo={}", coupon.getId(), orderNo);
            recordRefundLog(coupon, orderNo, "PARTIAL_NO_REFUND",
                "部分退款不退券");
            return;
        }

        // 全额退款：CAS更新 USED → REFUNDED
        int affected = couponMapper.updateStatusWithOptimisticLock(
            coupon.getId(),
            CouponStatus.USED,
            CouponStatus.REFUNDED,
            orderNo,
            System.currentTimeMillis());

        if (affected == 0) {
            log.warn("退款退券CAS失败, couponId={}", coupon.getId());
            return;
        }

        // 同步Redis
        String couponKey = "coupon:instance:" + coupon.getId();
        redisTemplate.opsForHash().put(couponKey, "status", CouponStatus.REFUNDED.name());

        recordRefundLog(coupon, orderNo, "FULL_REFUND", "全额退款退券");

        log.info("订单退款退券成功, couponId={}, orderNo={}", coupon.getId(), orderNo);
    }

    private void recordRefundLog(CouponInstance coupon, String orderNo,
                                  String refundType, String remark) {
        CouponRefundLog log = new CouponRefundLog();
        log.setCouponId(coupon.getId());
        log.setOrderNo(orderNo);
        log.setUserId(coupon.getUserId());
        log.setRefundType(refundType);
        log.setRemark(remark);
        log.setCreateTime(new Date());
        refundLogMapper.insert(log);
    }
}
```

```java
/**
 * 定时任务：清理卡在LOCKED状态的优惠券

@Component
@Slf4j
public class CouponLockRecoveryJob {

    @Autowired
    private CouponInstanceMapper couponMapper;

    private OrderFeignClient orderFeignClient;

    private StringRedisTemplate redisTemplate;

    /**
     * 每5分钟扫描一次
     */
    @Scheduled(cron = "0 */5 * * * ?")
    public void recoverLockedCoupons() {
        // 查询LOCKED超过30分钟的券
        long threshold = System.currentTimeMillis() - 30 * 60 * 1000;
        List<CouponInstance> lockedCoupons = couponMapper
            .selectLockedBeforeTime(threshold, 100); // 每次最多处理100条

        log.info("扫描到卡在LOCKED状态的优惠券, count={}", lockedCoupons.size());

        for (CouponInstance coupon : lockedCoupons) {
            try {
                String orderNo = coupon.getOrderId();

                // 查询订单状态
                OrderDTO order = orderFeignClient.getOrderByNo(orderNo);
                if (order == null || "CANCELLED".equals(order.getStatus())) {
                    // 订单不存在或已取消，回退券
                    int affected = couponMapper.updateStatusWithOptimisticLock(
                        coupon.getId(),
                        CouponStatus.LOCKED,
                        CouponStatus.UNUSED,
                        null,
                        System.currentTimeMillis());

                    if (affected > 0) {
                        String couponKey = "coupon:instance:" + coupon.getId();
                        redisTemplate.opsForHash().put(couponKey, "status",
                            CouponStatus.UNUSED.name());
                        redisTemplate.opsForHash().delete(couponKey, "orderNo");

                    }

                    // 订单已支付但券未核销（核销消息丢失），补偿核销
                    int affected = couponMapper.updateStatusWithOptimisticLock(
                        coupon.getId(),
                        CouponStatus.LOCKED,
                        CouponStatus.USED,
                        orderNo,
                        System.currentTimeMillis());

                    if (affected > 0) {
                        String couponKey = "coupon:instance:" + coupon.getId();
                        redisTemplate.opsForHash().put(couponKey, "status",
                            CouponStatus.USED.name());
                        log.info("LOCKED券补偿核销成功, couponId={}, orderNo={}",
                            coupon.getId(), orderNo);
                    }
                }
            } catch (Exception e) {
                log.error("LOCKED券恢复异常, couponId={}", coupon.getId(), e);
            }
        }
    }
}
```

#### 7.3.2 批量发放任务创建与分批处理

```java
/**
 * 批量发放服务
 * 
 * 完整流程：
 * 1. 创建发放任务，预估目标用户数
 * 2. 将目标用户ID列表分批写入MQ
 * 3. 消费者分批处理：Redis扣减库存 + 写入券实例
 * 4. 异步统计发放结果
 * 5. 失败重试与补偿
 */
@Service
@Slf4j
public class BatchIssueService {

    @Autowired
    private CouponTemplateCacheService templateCacheService;
    @Autowired
    private BatchIssueTaskMapper taskMapper;
    @Autowired
    private UserQueryService userQueryService;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private RocketMQTemplate mqTemplate;
    @Autowired
    private BatchIssueDetailMapper detailMapper;

    /**
     * 创建批量发放任务
     */
    @Transactional(rollbackFor = Exception.class)
    public Long createBatchIssueTask(BatchIssueRule rule) {
        // 1. 创建任务记录
        BatchIssueTask task = new BatchIssueTask();
        task.setRuleId(rule.getRuleId());
        task.setTemplateId(rule.getTemplateId());
        task.setName(rule.getName());
        task.setPerUserCount(rule.getPerUserCount());
        task.setTotalLimit(rule.getTotalLimit());
        task.setValidDays(rule.getValidDays());
        task.setBatchSize(rule.getBatchSize());
        task.setStatus(TaskStatus.INIT);
        task.setCreateTime(new Date());
        taskMapper.insert(task);

        log.info("批量发放任务创建, taskId={}, templateId={}, name={}",
            task.getId(), rule.getTemplateId(), rule.getName());

        // 2. 预热库存到Redis（如果尚未预热）
        String stockKey = "coupon:stock:" + rule.getTemplateId();
        if (!redisTemplate.hasKey(stockKey)) {
            CouponTemplate template = templateCacheService.getTemplate(rule.getTemplateId());
            redisTemplate.opsForValue().set(stockKey,
                String.valueOf(template.getRemainingStock()));
        }

        // 3. 异步执行发放
        if (rule.getIssueType() == IssueType.IMMEDIATE) {
            executeBatchIssue(task.getId());
        } else {
            // 定时发放：写入调度表，由定时任务触发
            scheduleBatchIssue(task.getId(), rule.getScheduledTime());
        }

        return task.getId();
    }

    /**
     * 执行批量发放
     * 
     * 策略：
     * 1. 流式查询目标用户（避免一次性加载百万用户到内存）
     * 2. 按batchSize分批发送MQ
     * 3. 每批MQ消息包含用户ID列表，由消费者异步处理
     */
    public void executeBatchIssue(Long taskId) {
        BatchIssueTask task = taskMapper.selectById(taskId);
        if (task == null) {
            log.error("批量发放任务不存在, taskId={}", taskId);
            return;
        }

        // 更新任务状态为进行中
        taskMapper.updateStatus(taskId, TaskStatus.PROCESSING);
        taskMapper.updateStartTime(taskId, new Date());

        log.info("开始执行批量发放, taskId={}, templateId={}", taskId, task.getTemplateId());

        // 获取规则配置
        BatchIssueRule rule = JSON.parseObject(task.getRuleJson(), BatchIssueRule.class);

        // 流式查询目标用户ID
        int totalProcessed = 0;
        int totalSuccess = 0;
        int totalFail = 0;
        int batchNo = 0;

        try (Cursor<Long> userCursor = userQueryService.queryTargetUsers(
                rule.getTargetUserCondition(), task.getBatchSize())) {

            List<Long> batchUsers = new ArrayList<>(task.getBatchSize());

            while (userCursor.hasNext()) {
                batchUsers.add(userCursor.next());
                totalProcessed++;

                // 达到批次大小，发送MQ
                if (batchUsers.size() >= task.getBatchSize()) {
                    batchNo++;
                    BatchIssueMessage msg = new BatchIssueMessage();
                    msg.setTaskId(taskId);
                    msg.setBatchNo(batchNo);
                    msg.setTemplateId(task.getTemplateId());
                    msg.setUserIds(new ArrayList<>(batchUsers));
                    msg.setPerUserCount(task.getPerUserCount());
                    msg.setValidDays(rule.getValidDays());

                    mqTemplate.syncSend("coupon-batch-issue-topic", msg);

                    log.info("批次发送MQ成功, taskId={}, batchNo={}, userCount={}",
                        taskId, batchNo, batchUsers.size());

                    batchUsers.clear();

                    // 检查是否达到总发放上限
                    if (task.getTotalLimit() != null
                        && totalProcessed >= task.getTotalLimit()) {
                        log.info("达到总发放上限，停止发放, taskId={}, total={}",
                            taskId, totalProcessed);
                        break;
                    }
                }
            }

            // 处理最后不足一批的用户
            if (!batchUsers.isEmpty()) {
                batchNo++;
                BatchIssueMessage msg = new BatchIssueMessage();
                msg.setTaskId(taskId);
                msg.setBatchNo(batchNo);
                msg.setTemplateId(task.getTemplateId());
                msg.setUserIds(new ArrayList<>(batchUsers));
                msg.setPerUserCount(task.getPerUserCount());
                msg.setValidDays(rule.getValidDays());

                mqTemplate.syncSend("coupon-batch-issue-topic", msg);
                log.info("最后批次发送MQ成功, taskId={}, batchNo={}, userCount={}",
                    taskId, batchNo, batchUsers.size());
            }

        } catch (Exception e) {
            log.error("批量发放执行异常, taskId={}", taskId, e);
            taskMapper.updateStatus(taskId, TaskStatus.FAILED);
            taskMapper.updateErrorMsg(taskId, e.getMessage());
            return;
        }

        // 更新任务状态为已完成（等待消费者处理完所有批次后由统计任务更新最终状态）
        taskMapper.updateStatus(taskId, TaskStatus.SENT);
        taskMapper.updateTotalCount(taskId, totalProcessed);
        taskMapper.updateTotalBatch(taskId, batchNo);
        taskMapper.updateEndTime(taskId, new Date());

        log.info("批量发放MQ发送完成, taskId={}, totalProcessed={}, totalBatch={}",
            taskId, totalProcessed, batchNo);
    }
}
```

#### 7.3.3 批量发放MQ消费者（含幂等与重试）

```java
/**
 * 批量发放MQ消费者
 * 
 * 每条消息包含一批用户ID，消费者为每个用户扣减库存并写入券实例
 * 
 * 幂等控制：taskId + batchNo 作为幂等键
 * 重试策略：消费失败时记录失败明细，重试3次后转入死信队列
 */
@Component
@Slf4j
@RocketMQMessageListener(topic = "coupon-batch-issue-topic",
    consumerGroup = "coupon-batch-issue-consumer-group",
    maxReconsumeTimes = 3) // 最多重试3次
public class BatchIssueConsumer implements RocketMQListener<BatchIssueMessage> {

    @Autowired
    private CouponInstanceMapper couponMapper;
    @Autowired
    private CouponTemplateCacheService templateCacheService;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private BatchIssueTaskMapper taskMapper;
    @Autowired
    private BatchIssueDetailMapper detailMapper;
    @Autowired
    private BatchIssueStatsService statsService;

    /**
     * Lua脚本：批量扣减库存
     * KEYS[1] = coupon:stock:{templateId}
     * ARGV[1] = 需要扣减的数量
     * 返回值：扣减成功=0, 库存不足=1
     */
    private static final String BATCH_DEDUCT_LUA =
        "local stock = tonumber(redis.call('GET', KEYS[1]) or '0')\n" +
        "local need = tonumber(ARGV[1])\n" +
        "if stock < need then\n" +
        "    return 1\n" +
        "end\n" +
        "redis.call('DECRBY', KEYS[1], need)\n" +
        "return 0\n";

    @Override
    public void onMessage(BatchIssueMessage msg) {
        log.info("收到批量发放消息, taskId={}, batchNo={}, userCount={}",
            msg.getTaskId(), msg.getBatchNo(), msg.getUserIds().size());

        // 1. 幂等检查：该批次是否已处理
        String idemKey = "coupon:batch:done:" + msg.getTaskId() + ":" + msg.getBatchNo();
        Boolean isProcessed = redisTemplate.opsForValue()
            .setIfAbsent(idemKey, "1", 24, TimeUnit.HOURS);
        if (isProcessed != null && !isProcessed) {
            log.info("批次已处理，幂等跳过, taskId={}, batchNo={}",
                msg.getTaskId(), msg.getBatchNo());
            return;
        }

        // 2. 查询券模板
        CouponTemplate template = templateCacheService.getTemplate(msg.getTemplateId());
        if (template == null) {
            log.error("券模板不存在, templateId={}", msg.getTemplateId());
            throw new RuntimeException("券模板不存在");
        }

        // 3. 计算本批次需要扣减的总库存
        int totalNeed = msg.getUserIds().size() * msg.getPerUserCount();

        // 4. Redis原子扣减库存
        String stockKey = "coupon:stock:" + msg.getTemplateId();
        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(BATCH_DEDUCT_LUA);
        script.setResultType(Long.class);

        Long deductResult = redisTemplate.execute(script,
            Collections.singletonList(stockKey),
            String.valueOf(totalNeed));

        if (deductResult != null && deductResult == 1L) {
            // 库存不足，逐个扣减（部分成功策略）
            log.warn("批量库存不足，转为逐个发放, taskId={}, batchNo={}, need={}",
                msg.getTaskId(), msg.getBatchNo(), totalNeed);
            issueOneByOne(msg, template);
        } else {
            // 批量扣减成功，逐个写入券实例
            issueBatch(msg, template);
        }

        // 5. 异步更新统计
        statsService.updateStats(msg.getTaskId());

        log.info("批量发放批次处理完成, taskId={}, batchNo={}",
            msg.getTaskId(), msg.getBatchNo());
    }

    /**
     * 批量发放：库存已扣减，逐个写入券实例
     */
    private void issueBatch(BatchIssueMessage msg, CouponTemplate template) {
        long now = System.currentTimeMillis();
        long expireTime = now + (long) msg.getValidDays() * 24 * 60 * 60 * 1000;

        int successCount = 0;
        int failCount = 0;

        for (Long userId : msg.getUserIds()) {
            try {
                for (int i = 0; i < msg.getPerUserCount(); i++) {
                    Long couponId = CouponIdGenerator.nextId();

                    CouponInstance instance = new CouponInstance();
                    instance.setId(couponId);
                    instance.setTemplateId(msg.getTemplateId());
                    instance.setUserId(userId);
                    instance.setStatus(CouponStatus.UNUSED);
                    instance.setGettime(now);
                    instance.setExpireTime(expireTime);
                    instance.setCreateTime(new Date());
                    instance.setSource("BATCH_ISSUE");
                    instance.setSourceId(msg.getTaskId());

                    couponMapper.insert(instance);
                    successCount++;
                }
            } catch (DuplicateKeyException e) {
                // 主键冲突，跳过
                log.warn("券实例ID冲突, userId={}", userId);
                failCount++;
            } catch (Exception e) {
                log.error("写入券实例失败, userId={}, taskId={}", userId, msg.getTaskId(), e);
                failCount++;
                // 记录失败明细
                recordFailDetail(msg.getTaskId(), msg.getBatchNo(),
                    userId, e.getMessage());
            }
        }

        log.info("批次发放完成, taskId={}, batchNo={}, success={}, fail={}",
            msg.getTaskId(), msg.getBatchNo(), successCount, failCount);
    }

    /**
     * 逐个发放：库存不足时的降级策略
     * 逐个用户扣减库存，成功一个写一个
     */
    private void issueOneByOne(BatchIssueMessage msg, CouponTemplate template) {
        long now = System.currentTimeMillis();
        long expireTime = now + (long) msg.getValidDays() * 24 * 60 * 60 * 1000;
        String stockKey = "coupon:stock:" + msg.getTemplateId();

        int successCount = 0;
        int failCount = 0;

        for (Long userId : msg.getUserIds()) {
            try {
                for (int i = 0; i < msg.getPerUserCount(); i++) {
                    // 逐个扣减库存
                    Long remaining = redisTemplate.opsForValue().decrement(stockKey);
                    if (remaining == null || remaining < 0) {
                        // 库存不足，回退并结束
                        redisTemplate.opsForValue().increment(stockKey);
                        log.info("批量发放库存耗尽, taskId={}, userId={}",
                            msg.getTaskId(), userId);
                        // 更新任务状态为部分完成
                        taskMapper.updateStatus(msg.getTaskId(), TaskStatus.PARTIAL);
                        recordFailDetail(msg.getTaskId(), msg.getBatchNo(),
                            userId, "STOCK_EMPTY");
                        return;
                    }

                    Long couponId = CouponIdGenerator.nextId();
                    CouponInstance instance = new CouponInstance();
                    instance.setId(couponId);
                    instance.setTemplateId(msg.getTemplateId());
                    instance.setUserId(userId);
                    instance.setStatus(CouponStatus.UNUSED);
                    instance.setGettime(now);
                    instance.setExpireTime(expireTime);
                    instance.setCreateTime(new Date());
                    instance.setSource("BATCH_ISSUE");
                    instance.setSourceId(msg.getTaskId());

                    couponMapper.insert(instance);
                    successCount++;
                }
            } catch (Exception e) {
                log.error("逐个发放失败, userId={}, taskId={}", userId, msg.getTaskId(), e);
                failCount++;
                // 库存已扣减但写入失败，回退库存
                redisTemplate.opsForValue().increment(stockKey);
                recordFailDetail(msg.getTaskId(), msg.getBatchNo(),
                    userId, e.getMessage());
            }
        }

        log.info("逐个发放完成, taskId={}, batchNo={}, success={}, fail={}",
            msg.getTaskId(), msg.getBatchNo(), successCount, failCount);
    }

    /**
     * 记录失败明细
     */
    private void recordFailDetail(Long taskId, Integer batchNo,
                                   Long userId, String errorMsg) {
        try {
            BatchIssueDetail detail = new BatchIssueDetail();
            detail.setTaskId(taskId);
            detail.setBatchNo(batchNo);
            detail.setUserId(userId);
            detail.setStatus("FAIL");
            detail.setErrorMsg(errorMsg);
            detail.setCreateTime(new Date());
            detailMapper.insert(detail);
        } catch (Exception e) {
            log.error("写入失败明细异常", e);
        }
    }
}
```

```java
/**
 * 批量发放统计服务
 * 
 * 定时统计每个发放任务的成功/失败数量

@Service
@Slf4j
public class BatchIssueStatsService {

    @Autowired
    private BatchIssueTaskMapper taskMapper;
    @Autowired
    private BatchIssueDetailMapper detailMapper;
    @Autowired
    private CouponInstanceMapper couponMapper;

    /**
     * 更新任务统计（每次批次处理完成后调用）
     */
    public void updateStats(Long taskId) {
        try {
            // 统计已发放成功的券数量
            int issuedCount = couponMapper.countBySource("BATCH_ISSUE", taskId);

            // 统计失败数量
            int failCount = detailMapper.countByTaskId(taskId);

            // 更新任务统计
            taskMapper.updateIssuedCount(taskId, issuedCount);
            taskMapper.updateFailCount(taskId, failCount);

            log.info("发放统计更新, taskId={}, issued={}, fail={}",
                taskId, issuedCount, failCount);
        } catch (Exception e) {
            log.error("发放统计更新失败, taskId={}", taskId, e);
        }
    }

    /**
     * 定时任务：每10分钟检查发放任务是否完成
     * 
     * 判断逻辑：已发送批次 = 已处理批次 → 任务完成
     */
    @Scheduled(cron = "0 */10 * * * ?")
    public void checkTaskCompletion() {
        // 查询所有SENT状态的任务
        List<BatchIssueTask> tasks = taskMapper.selectByStatus(TaskStatus.SENT);

        for (BatchIssueTask task : tasks) {
            try {
                // 统计已处理的批次（通过Redis幂等键统计）
                int processedBatches = countProcessedBatches(task.getId());

                if (processedBatches >= task.getTotalBatch()) {
                    // 所有批次已处理完毕，更新任务为完成
                    int issuedCount = couponMapper.countBySource(
                        "BATCH_ISSUE", task.getId());
                    int failCount = detailMapper.countByTaskId(task.getId());

                    taskMapper.updateStatus(task.getId(), TaskStatus.COMPLETED);
                    taskMapper.updateIssuedCount(task.getId(), issuedCount);
                    taskMapper.updateFailCount(task.getId(), failCount);
                    taskMapper.updateCompleteTime(task.getId(), new Date());

                    log.info("批量发放任务完成, taskId={}, total={}, issued={}, fail={}",
                        task.getId(), task.getTotalCount(), issuedCount, failCount);
                }
            } catch (Exception e) {
                log.error("任务完成检查异常, taskId={}", task.getId(), e);
            }
        }
    }

    /**
     * 统计已处理的批次数
     */
    private int countProcessedBatches(Long taskId) {
        int count = 0;
        // 通过扫描Redis幂等键统计（生产环境可用更高效的方式）
        Set<String> keys = redisTemplate.keys("coupon:batch:done:" + taskId + ":*");
        if (keys != null) {
            count = keys.size();
        }
        return count;
    }
}
```

```java
/**
 * 失败重试定时任务
 * 
 * 每小时扫描失败明细，重新发放
 */
@Component
@Slf4j
public class BatchIssueRetryJob {

    @Autowired
    private BatchIssueDetailMapper detailMapper;
    @Autowired
    private CouponInstanceMapper couponMapper;
    @Autowired
    private CouponTemplateCacheService templateCacheService;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private BatchIssueTaskMapper taskMapper;

    @Scheduled(cron = "0 0 * * * ?") // 每小时执行
    public void retryFailedIssues() {
        // 查询最近24小时内的失败明细
        Date since = new Date(System.currentTimeMillis() - 24 * 60 * 60 * 1000);
        List<BatchIssueDetail> failedDetails = detailMapper
            .selectFailedSince(since, 1000); // 每次最多重试1000条

        if (failedDetails.isEmpty()) {
            return;
        }

        log.info("批量发放失败重试开始, count={}", failedDetails.size());

        int retrySuccess = 0;
        int retryFail = 0;

        for (BatchIssueDetail detail : failedDetails) {
            try {
                // 查询任务信息
                BatchIssueTask task = taskMapper.selectById(detail.getTaskId());
                if (task == null || task.getStatus() == TaskStatus.COMPLETED) {
                    continue;
                }

                CouponTemplate template = templateCacheService
                    .getTemplate(task.getTemplateId());

                // 重新扣减库存
                String stockKey = "coupon:stock:" + task.getTemplateId();
                Long remaining = redisTemplate.opsForValue().decrement(stockKey);
                if (remaining == null || remaining < 0) {
                    redisTemplate.opsForValue().increment(stockKey);
                    log.info("重试失败-库存不足, taskId={}, userId={}",
                        detail.getTaskId(), detail.getUserId());
                    retryFail++;
                    continue;
                }

                // 重新写入券实例
                long now = System.currentTimeMillis();
                long expireTime = now + (long) task.getValidDays() * 24 * 60 * 60 * 1000;

                Long couponId = CouponIdGenerator.nextId();
                CouponInstance instance = new CouponInstance();
                instance.setId(couponId);
                instance.setTemplateId(task.getTemplateId());
                instance.setUserId(detail.getUserId());
                instance.setStatus(CouponStatus.UNUSED);
                instance.setGettime(now);
                instance.setExpireTime(expireTime);
                instance.setCreateTime(new Date());
                instance.setSource("BATCH_ISSUE_RETRY");
                instance.setSourceId(task.getId());

                couponMapper.insert(instance);

                // 更新明细状态为重试成功
                detailMapper.updateStatus(detail.getId(), "RETRY_SUCCESS");

                retrySuccess++;

            } catch (Exception e) {
                log.error("重试失败, detailId={}, userId={}",
                    detail.getId(), detail.getUserId(), e);
                // 回退库存
                String stockKey = "coupon:stock:"
                    + taskMapper.selectById(detail.getTaskId()).getTemplateId();
                redisTemplate.opsForValue().increment(stockKey);
                retryFail++;
            }
        }

        log.info("批量发放失败重试完成, total={}, success={}, fail={}",
            failedDetails.size(), retrySuccess, retryFail);
    }
}
```

|------|---------|---------|---------|---------|
