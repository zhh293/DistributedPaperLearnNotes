# 计费系统架构设计文档

---

## 一、系统概述

### 1.1 背景与目标

在云基础设施管理中，当主机实例创建（绑定服务树节点）时，需要将创建信息上报到计费系统，
标记该实例**开始计费**，初始状态为"开机"；当主机下线时，将下线信息上报到计费系统，
标记该实例**停止计费**。计费服务需要对原始事件进行**二次处理与过滤**，确保数据的
准确性和一致性。同时系统需要支持**弹性 Serverless** 资源的按需计费场景。

本文档描述一套通用的云资源计费系统（Billing System）的架构设计，覆盖从事件接入、
规则匹配、费用计算到账单生成的完整链路。

### 1.2 核心需求

| 需求分类   | 具体描述                                                     |
| ---------- | ------------------------------------------------------------ |
| 功能需求   | 支持主机开机/关机计费事件上报；支持规格变更事件；支持 Serverless 弹性计费 |
| 计费模式   | 按时计费、按量计费、按规格计费、阶梯计费，及多种策略组合       |
| 账单管理   | 周期性账单生成、实时费用预估、账单核验与对账                   |
| 高可用     | 事件不丢失、幂等处理、补偿机制，保证计费数据最终一致性         |
| 扩展性     | 新增计费策略和资源类型时，无需修改核心引擎代码                 |

### 1.3 设计原则

1. **事件驱动（Event-Driven Architecture）**：所有计费行为由事件触发，解耦上游资源管理系统与计费系统。
2. **策略模式（Strategy Pattern）**：不同计费方式以可插拔策略实现，便于扩展。
3. **事件溯源（Event Sourcing）**：所有计费状态变更以不可变事件序列记录，支持任意时间点状态回溯。
4. **幂等性（Idempotency）**：同一事件重复投递不会导致重复计费。
5. **最终一致性（Eventual Consistency）**：通过补偿机制保证异步链路的数据一致。

### 2.2 各层职责

**事件接入层**：接收外部系统上报的计费事件（HTTP 接口或消息队列），完成事件
校验、二次过滤、去重（幂等校验），将合法事件转化为内部统一的 `BillingEvent` 对象。

**计费规则引擎**：根据资源类型、计费模式等维度匹配对应的计费规则和策略，
使用**策略模式**和**责任链模式**进行规则路由。

**计费计算层**：执行具体的费用计算逻辑，包括基于时间段的计费算法、阶梯价格
计算、折扣叠加，以及 `BigDecimal` 精度处理。

**账单生成层**：将计算结果聚合为账单，支持按日/周/月的周期性账单、实时费用
预估和账单核验。

**数据存储层**：持久化事件流、计费记录和账单数据，支持事件溯源回放和历史归档。

## 三、计费事件模型

### 3.1 事件类型定义

计费系统接收三种核心事件类型：**开始计费（START）**、**停止计费（STOP）**、
**规格变更（SPEC_CHANGE）**。采用**枚举 + 模板方法**模式统一建模。

```java
/**
 * 计费事件类型枚举
 *
 * 设计模式: 枚举单例模式 (Enum Singleton)
 * 每个枚举值携带自身的描述和处理优先级,
 * 利用 Java 枚举天然的单例特性保证类型安全。
 */
public enum BillingEventType {

    /**
     * 开始计费 —— 主机创建并绑定服务树时触发
     * 表示实例从此刻起进入计费状态, 初始状态为"开机"
     */
    START("开始计费", 1),

    /**
     * 停止计费 —— 主机下线时触发
     * 表示实例从此刻起退出计费状态
     */
    STOP("停止计费", 2),

    /**
     * 规格变更 —— 实例升降配时触发
     * 需要按变更前后的规格分别计算费用
     */
    SPEC_CHANGE("规格变更", 3);

    private final String description;
    private final int priority;

    BillingEventType(String description, int priority) {
        this.description = description;
        this.priority = priority;
    }

    public String getDescription() {
        return description;
    }

    public int getPriority() {
        return priority;
    }
}
```

### 3.2 计费事件实体

```java
import java.math.BigDecimal;
import java.time.Instant;
import java.util.Map;
import java.util.UUID;

/**
 * 计费事件实体 (不可变对象)
 *
 * 设计模式: 不可变对象模式 (Immutable Object Pattern)
 * - 所有字段均为 final, 创建后不可修改
 * - 使用 Builder 模式构造, 避免构造函数参数过多的问题
 * - 事件一旦生成, 即不可篡改, 保证事件溯源的可靠性
 *
 * 算法要点:
 * - eventId 使用 UUID v4 生成, 保证全局唯一性
 * - occurredAt 使用 UTC 时间戳, 避免时区歧义
 */
public final class BillingEvent {

    /** 事件唯一标识, UUID v4 */
    private final String eventId;

    /** 事件类型 */
    private final BillingEventType eventType;

    /** 资源实例 ID (如主机 ID) */
    private final String resourceId;

    /** 资源类型 (如 VM / CONTAINER / SERVERLESS) */
    private final String resourceType;

    /** 租户 ID / 业务线标识 */
    private final String tenantId;

    /** 事件发生时间 (UTC) */
    private final Instant occurredAt;

    /** 资源规格信息 (CPU核数、内存大小等) */
    private final ResourceSpec resourceSpec;

    /** 变更前规格 (仅 SPEC_CHANGE 类型使用) */
    private final ResourceSpec previousSpec;

    /** 扩展属性, 用于承载业务自定义信息 */
    private final Map<String, String> extensions;

    /** 幂等键, 用于去重判断 */
    private final String idempotencyKey;

    private BillingEvent(Builder builder) {
        this.eventId = builder.eventId != null
                ? builder.eventId : UUID.randomUUID().toString();
        this.eventType = builder.eventType;
        this.resourceId = builder.resourceId;
        this.resourceType = builder.resourceType;
        this.tenantId = builder.tenantId;
        this.occurredAt = builder.occurredAt != null
                ? builder.occurredAt : Instant.now();
        this.resourceSpec = builder.resourceSpec;
        this.previousSpec = builder.previousSpec;
        this.extensions = builder.extensions != null
                ? Map.copyOf(builder.extensions) : Map.of();
        this.idempotencyKey = builder.idempotencyKey != null
                ? builder.idempotencyKey
                : generateIdempotencyKey();
    }

    /**
     * 幂等键生成算法:
     * 组合 resourceId + eventType + 时间窗口(秒级截断)
     * 同一资源在同一秒内的同类型事件视为重复事件
     */
    private String generateIdempotencyKey() {
        long epochSecond = occurredAt.getEpochSecond();
        return resourceId + ":" + eventType.name() + ":" + epochSecond;
    }

    // ---- Getters (省略 setter, 不可变对象) ----

    public String getEventId() { return eventId; }
    public BillingEventType getEventType() { return eventType; }
    public String getResourceId() { return resourceId; }
    public String getResourceType() { return resourceType; }
    public String getTenantId() { return tenantId; }
    public Instant getOccurredAt() { return occurredAt; }
    public ResourceSpec getResourceSpec() { return resourceSpec; }
    public ResourceSpec getPreviousSpec() { return previousSpec; }
    public Map<String, String> getExtensions() { return extensions; }
    public String getIdempotencyKey() { return idempotencyKey; }

    // ---- Builder ----

    public static Builder builder() {
        return new Builder();
    }

    public static class Builder {
        private String eventId;
        private BillingEventType eventType;
        private String resourceId;
        private String resourceType;
        private String tenantId;
        private Instant occurredAt;
        private ResourceSpec resourceSpec;
        private ResourceSpec previousSpec;
        private Map<String, String> extensions;
        private String idempotencyKey;

        public Builder eventId(String eventId) {
            this.eventId = eventId;
            return this;
        }

        public Builder eventType(BillingEventType eventType) {
            this.eventType = eventType;
            return this;
        }

        public Builder resourceId(String resourceId) {
            this.resourceId = resourceId;
            return this;
        }

        public Builder resourceType(String resourceType) {
            this.resourceType = resourceType;
            return this;
        }

        public Builder tenantId(String tenantId) {
            this.tenantId = tenantId;
            return this;
        }

        public Builder occurredAt(Instant occurredAt) {
            this.occurredAt = occurredAt;
            return this;
        }

        public Builder resourceSpec(ResourceSpec spec) {
            this.resourceSpec = spec;
            return this;
        }

        public Builder previousSpec(ResourceSpec spec) {
            this.previousSpec = spec;
            return this;
        }

        public Builder extensions(Map<String, String> ext) {
            this.extensions = ext;
            return this;
        }

        public Builder idempotencyKey(String key) {
            this.idempotencyKey = key;
            return this;
        }

        public BillingEvent build() {
            if (eventType == null) {
                throw new IllegalArgumentException("eventType is required");
            }
            if (resourceId == null || resourceId.isBlank()) {
                throw new IllegalArgumentException("resourceId is required");
            }
            if (eventType == BillingEventType.SPEC_CHANGE
                    && previousSpec == null) {
                throw new IllegalArgumentException(
                    "previousSpec is required for SPEC_CHANGE event");
            }
            return new BillingEvent(this);
        }
    }
}
```

### 3.4 事件溯源模式 (Event Sourcing)

```java
import java.time.Instant;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ConcurrentMap;

/**
 * 事件存储 —— 事件溯源模式的核心组件
 *
 * 设计模式: 事件溯源 (Event Sourcing)
 * - 系统状态不通过直接修改数据库字段来变更,
 *   而是通过追加不可变的事件记录来表达所有状态变迁
 * - 任意时刻的状态都可以通过重放事件序列推导得出
 *
 * 算法: 顺序重放 (Sequential Replay)
 * - 从事件流的第一条事件开始, 依次应用每条事件
 * - 每条事件通过 apply() 方法更新聚合根的内部状态
 * - 时间复杂度 O(n), n = 事件数量
 *
 * 优化: 快照 (Snapshot)
 * - 当事件数量超过阈值时, 生成快照以减少重放开销
 * - 重放时从最近快照开始, 只需重放快照之后的事件
 */
public class EventStore {

    /** 事件流存储: resourceId -> 有序事件列表 */
    private final ConcurrentMap<String, List<BillingEvent>> eventStreams
            = new ConcurrentHashMap<>();

    /** 快照阈值: 事件数量超过此值时生成快照 */
    private static final int SNAPSHOT_THRESHOLD = 100;

    /** 快照存储: resourceId -> 最新快照 */
    private final ConcurrentMap<String, ResourceBillingSnapshot> snapshots
            = new ConcurrentHashMap<>();

    /**
     * 追加事件到事件流
     *
     * @param event 计费事件(不可变)
     */
    public void append(BillingEvent event) {
        eventStreams.computeIfAbsent(
            event.getResourceId(),
            k -> Collections.synchronizedList(new ArrayList<>())
        ).add(event);

        // 检查是否需要生成快照
        List<BillingEvent> stream = eventStreams.get(
            event.getResourceId());
        if (stream.size() % SNAPSHOT_THRESHOLD == 0) {
            generateSnapshot(event.getResourceId());
        }
    }

    /**
     * 获取指定资源的所有事件流
     *
     * @param resourceId 资源ID
     * @return 不可变的事件列表
     */
    public List<BillingEvent> getEventStream(String resourceId) {
        List<BillingEvent> stream = eventStreams.get(resourceId);
        return stream != null
                ? Collections.unmodifiableList(stream)
                : Collections.emptyList();
    }

    /**
     * 重放事件流, 还原资源的计费状态
     *
     * 算法: 顺序重放 + 快照优化
     * 1. 如果存在快照, 从快照状态开始
     * 2. 仅重放快照之后的事件
     * 3. 每条事件按类型更新聚合根状态
     *
     * @param resourceId 资源ID
     * @return 资源当前的计费状态聚合
     */
    public ResourceBillingAggregate replay(String resourceId) {
        ResourceBillingAggregate aggregate =
                new ResourceBillingAggregate(resourceId);

        // 尝试从快照恢复
        ResourceBillingSnapshot snapshot = snapshots.get(resourceId);
        int startIndex = 0;
        if (snapshot != null) {
            aggregate.restoreFromSnapshot(snapshot);
            startIndex = snapshot.getEventIndex();
        }

        // 重放快照之后的事件
        List<BillingEvent> stream = getEventStream(resourceId);
        for (int i = startIndex; i < stream.size(); i++) {
            aggregate.apply(stream.get(i));
        }

        return aggregate;
    }

    /**
     * 生成快照
     * 将当前聚合根状态序列化保存, 记录对应的事件索引位置
     */
    private void generateSnapshot(String resourceId) {
        ResourceBillingAggregate aggregate = replay(resourceId);
        List<BillingEvent> stream = getEventStream(resourceId);
        ResourceBillingSnapshot snapshot = new ResourceBillingSnapshot(
                aggregate.getStatus(),
                aggregate.getCurrentSpec(),
                aggregate.getLastEventTime(),
                stream.size()
        );
        snapshots.put(resourceId, snapshot);
    }
}
```

### 3.5 聚合根与快照

```java
import java.math.BigDecimal;
import java.time.Instant;

/**
 * 资源计费聚合根
 *
 * 设计模式: 聚合根 (Aggregate Root, DDD)
 * - 作为事件溯源中的状态载体
 * - 通过 apply() 方法接收事件并更新内部状态
 * - 保证聚合内部的一致性边界
 */
public class ResourceBillingAggregate {

    private final String resourceId;
    private BillingStatus status;
    private ResourceSpec currentSpec;
    private Instant billingStartTime;
    private Instant lastEventTime;
    private BigDecimal accumulatedAmount;

    public ResourceBillingAggregate(String resourceId) {
        this.resourceId = resourceId;
        this.status = BillingStatus.INACTIVE;
        this.accumulatedAmount = BigDecimal.ZERO;
    }

    /**
     * 应用事件, 更新聚合状态
     *
     * 算法: 状态机转换 (State Machine Transition)
     * - START 事件: INACTIVE -> ACTIVE
     * - STOP 事件: ACTIVE -> INACTIVE
     * - SPEC_CHANGE 事件: 保持 ACTIVE, 更新规格
     */
    public void apply(BillingEvent event) {
        switch (event.getEventType()) {
            case START -> {
                this.status = BillingStatus.ACTIVE;
                this.currentSpec = event.getResourceSpec();
                this.billingStartTime = event.getOccurredAt();
                this.lastEventTime = event.getOccurredAt();
            }
            case STOP -> {
                this.status = BillingStatus.INACTIVE;
                this.lastEventTime = event.getOccurredAt();
            }
            case SPEC_CHANGE -> {
                if (this.status != BillingStatus.ACTIVE) {
                    throw new IllegalStateException(
                        "Cannot change spec for inactive resource: "
                        + resourceId);
                }
                this.currentSpec = event.getResourceSpec();
                this.lastEventTime = event.getOccurredAt();
            }
        }
    }

    /** 从快照恢复状态 */
    public void restoreFromSnapshot(ResourceBillingSnapshot snapshot) {
        this.status = snapshot.getStatus();
        this.currentSpec = snapshot.getCurrentSpec();
        this.lastEventTime = snapshot.getLastEventTime();
    }

    // ---- Getters ----
    public String getResourceId() { return resourceId; }
```

```java
import java.time.Duration;
import java.time.Instant;
import java.util.ArrayList;
import java.util.List;

/**
 * 事件过滤器链
 *
 * 设计模式: 责任链模式 (Chain of Responsibility)
 * - 每个过滤器独立实现一种过滤逻辑
 * - 过滤器按顺序串联, 事件依次通过每个过滤器
 * - 任一过滤器拒绝, 事件即被丢弃
 * - 新增过滤规则只需添加新的 Filter 实现, 无需修改已有代码 (OCP)
 */
public class EventFilterChain {

    private final List<EventFilter> filters = new ArrayList<>();

    public EventFilterChain addFilter(EventFilter filter) {
        this.filters.add(filter);
        return this;
    }

    /**
     * 执行过滤链
     *
     * @param event 待过滤事件
     * @return 过滤结果, 包含是否通过和拒绝原因
     */
    public FilterResult doFilter(BillingEvent event) {
        for (EventFilter filter : filters) {
            FilterResult result = filter.filter(event);
            if (!result.isPassed()) {
                return result;
            }
        }
        return FilterResult.pass();
    }
}

/** 过滤器接口 */
interface EventFilter {
    FilterResult filter(BillingEvent event);
}

/** 过滤结果 */
class FilterResult {
    private final boolean passed;
    private final String rejectReason;

    private FilterResult(boolean passed, String rejectReason) {
        this.passed = passed;
        this.rejectReason = rejectReason;
    }

    public static FilterResult pass() {
        return new FilterResult(true, null);
    }

    public static FilterResult reject(String reason) {
        return new FilterResult(false, reason);
    }

    public boolean isPassed() { return passed; }
    public String getRejectReason() { return rejectReason; }
}

/**
 * 过滤器实现: 时间合理性检查
 * 拒绝发生时间在未来或过于久远的事件
 */
class TimeValidationFilter implements EventFilter {
    private static final Duration MAX_PAST = Duration.ofDays(30);
    private static final Duration MAX_FUTURE = Duration.ofMinutes(5);

    @Override
    public FilterResult filter(BillingEvent event) {
        Instant now = Instant.now();
        if (event.getOccurredAt().isAfter(now.plus(MAX_FUTURE))) {
            return FilterResult.reject(
                "Event time is in the future: "
                + event.getOccurredAt());
        }
        if (event.getOccurredAt().isBefore(now.minus(MAX_PAST))) {
            return FilterResult.reject(
                "Event time is too old: " + event.getOccurredAt());
        }
        return FilterResult.pass();
    }
}

/**
 * 过滤器实现: 状态一致性检查
 * 防止对已停止的资源发送停止事件等不合理情况
 */
class StateConsistencyFilter implements EventFilter {
    private final EventStore eventStore;

    public StateConsistencyFilter(EventStore eventStore) {
        this.eventStore = eventStore;
    }

    @Override
    public FilterResult filter(BillingEvent event) {
        ResourceBillingAggregate aggregate =
                eventStore.replay(event.getResourceId());

        // 不允许对已激活的资源重复发送 START 事件
        if (event.getEventType() == BillingEventType.START
                && aggregate.getStatus() == BillingStatus.ACTIVE) {
            return FilterResult.reject(
                "Resource already active: "
                + event.getResourceId());
        }

        // 不允许对未激活的资源发送 STOP 事件
        if (event.getEventType() == BillingEventType.STOP
                && aggregate.getStatus() == BillingStatus.INACTIVE) {
            return FilterResult.reject(
                "Resource already inactive: "
                + event.getResourceId());
        }

        return FilterResult.pass();
    }
}
```

### 4.4 按时计费策略

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

/**
 * 按时计费策略
 *
 * 算法: 时长 x 单价
 * - 从 BillingContext 中获取计费时段的小时数
 * - 乘以资源规格对应的每小时单价
 * - 结果保留2位小数, 向上取整 (HALF_UP)
 *
 * 适用场景: 虚拟主机、容器实例等长期运行的资源
 */
public class TimeBasedStrategy implements BillingStrategy {

    @Override
    public ChargeResult calculate(BillingContext context) {
        BigDecimal hours = context.getDurationHours();
        BigDecimal unitPrice = context.getSpec().getUnitPrice();

        // 核心算法: 费用 = 使用时长(小时) × 单价(元/小时)
        BigDecimal originalAmount = hours.multiply(unitPrice)
                .setScale(2, RoundingMode.HALF_UP);

        // 应用折扣
        BigDecimal discountAmount = applyDiscount(
                originalAmount, context.getDiscountInfo());
        BigDecimal finalAmount = originalAmount
                .subtract(discountAmount)
                .max(BigDecimal.ZERO);

        return new ChargeResult(
                originalAmount,
                discountAmount,
                finalAmount,
                getStrategyCode(),
                context.getPeriodStart(),
                context.getPeriodEnd(),
                String.format("按时计费: %.4f小时 x %.4f元/小时 = %.2f元",
                        hours, unitPrice, originalAmount)
        );
    }

    private BigDecimal applyDiscount(BigDecimal amount,
                                     DiscountInfo discount) {
        if (discount == null || discount.getDiscountRate() == null) {
            return BigDecimal.ZERO;
        }
        // 折扣额 = 原价 × (1 - 折扣率)
        BigDecimal rate = BigDecimal.ONE
                .subtract(discount.getDiscountRate());
        return amount.multiply(rate)
                .setScale(2, RoundingMode.HALF_UP);
    }

    @Override
    public String getStrategyCode() {
        return "TIME_BASED";
    }

    @Override
    public boolean supports(BillingContext context) {
        return "TIME_BASED".equals(context.getRuleCode());
    }
}
```

### 4.5 按量计费策略

```java
import java.math.BigDecimal;
import java.math.RoundingMode;

/**
 * 按量计费策略
 *
 * 算法: 实际用量 x 单价
 * - 适用于 Serverless 场景: 函数调用次数、请求数、流量等
 * - 支持最低消费和封顶金额
 *
 * 适用场景: Serverless 函数、API 网关、CDN 流量
 */
public class UsageBasedStrategy implements BillingStrategy {

    /** 最低消费金额 */
    private final BigDecimal minimumCharge;

    /** 封顶金额 (0 表示不封顶) */
    private final BigDecimal maximumCharge;

    public UsageBasedStrategy(BigDecimal minimumCharge,
                              BigDecimal maximumCharge) {
        this.minimumCharge = minimumCharge != null
                ? minimumCharge : BigDecimal.ZERO;
        this.maximumCharge = maximumCharge != null
                ? maximumCharge : BigDecimal.ZERO;
    }

    @Override
    public ChargeResult calculate(BillingContext context) {
        BigDecimal usage = context.getUsage();
        BigDecimal unitPrice = context.getSpec().getUnitPrice();

        // 核心算法: 费用 = 实际用量 × 单价
        BigDecimal originalAmount = usage.multiply(unitPrice)
                .setScale(2, RoundingMode.HALF_UP);

        // 应用最低消费
        if (originalAmount.compareTo(minimumCharge) < 0) {
            originalAmount = minimumCharge;
        }

        // 应用封顶金额
        if (maximumCharge.compareTo(BigDecimal.ZERO) > 0
                && originalAmount.compareTo(maximumCharge) > 0) {
            originalAmount = maximumCharge;
        }

        // 折扣处理
        BigDecimal discountAmount = BigDecimal.ZERO;
        DiscountInfo discount = context.getDiscountInfo();
        if (discount != null && discount.getDiscountRate() != null) {
            discountAmount = originalAmount.multiply(
                    BigDecimal.ONE.subtract(discount.getDiscountRate()))
                    .setScale(2, RoundingMode.HALF_UP);
        }

        BigDecimal finalAmount = originalAmount
                .subtract(discountAmount)
                .max(BigDecimal.ZERO);

        return new ChargeResult(
                originalAmount,
                discountAmount,
                finalAmount,
                getStrategyCode(),
                context.getPeriodStart(),
                context.getPeriodEnd(),
                String.format("按量计费: 用量=%s x 单价=%s = %.2f元",
                        usage.toPlainString(),
                        unitPrice.toPlainString(),
                        originalAmount)
        );
    }

    @Override
    public String getStrategyCode() {
        return "USAGE_BASED";
    }

    @Override
    public boolean supports(BillingContext context) {
        return "USAGE_BASED".equals(context.getRuleCode());
    }
}
```

### 4.6 按规格计费策略

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.Map;

/**
 * 按规格计费策略
 *
 * 算法: 查表法 —— 根据资源规格编码查定价表获取固定单价
 * - 不同规格对应不同的月度固定费用
 * - 不足月的按日折算, 不足日的按小时折算
 *
 * 数据结构: HashMap 定价表 (O(1) 查找)
 *
 * 适用场景: 包年包月主机、固定规格的数据库实例
 */
public class SpecBasedStrategy implements BillingStrategy {

    /** 规格定价表: specCode -> 月度单价 */
    private final Map<String, BigDecimal> pricingTable;

    /** 每月按30天折算 */
    private static final BigDecimal DAYS_PER_MONTH =
            BigDecimal.valueOf(30);
    private static final BigDecimal HOURS_PER_DAY =
            BigDecimal.valueOf(24);

    public SpecBasedStrategy(Map<String, BigDecimal> pricingTable) {
        this.pricingTable = Map.copyOf(pricingTable);
    }

    @Override
    public ChargeResult calculate(BillingContext context) {
        String specCode = context.getSpec().getSpecCode();
        BigDecimal monthlyPrice = pricingTable.get(specCode);

        if (monthlyPrice == null) {
            throw new IllegalArgumentException(
                "No pricing found for spec: " + specCode);
        }

        // 算法: 按时长折算月度价格
        // hourlyPrice = monthlyPrice / 30 / 24
        BigDecimal hourlyPrice = monthlyPrice
                .divide(DAYS_PER_MONTH, 8, RoundingMode.HALF_UP)
                .divide(HOURS_PER_DAY, 8, RoundingMode.HALF_UP);

        BigDecimal hours = context.getDurationHours();
        BigDecimal originalAmount = hours.multiply(hourlyPrice)
                .setScale(2, RoundingMode.HALF_UP);

        BigDecimal discountAmount = BigDecimal.ZERO;
        BigDecimal finalAmount = originalAmount;

        return new ChargeResult(
                originalAmount,
                discountAmount,
                finalAmount,
                getStrategyCode(),
                context.getPeriodStart(),
                context.getPeriodEnd(),
                String.format(
                    "按规格计费: 规格=%s, 月价=%.2f, "
                    + "折算时价=%.6f, 时长=%.4fh, 费用=%.2f元",
                    specCode, monthlyPrice, hourlyPrice,
                    hours, originalAmount)
        );
    }

    @Override
    public String getStrategyCode() {
        return "SPEC_BASED";
    }

    @Override
    public boolean supports(BillingContext context) {
        return "SPEC_BASED".equals(context.getRuleCode());
    }
```

### 4.7 阶梯计费策略

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

/**
 * 阶梯计费策略
 *
 * 算法: 分段累加法 (Tiered Accumulation)
 * - 将用量按阶梯区间分段
 * - 每段用量乘以该段单价
 * - 所有段的费用累加得到总费用
 *
 * 示例:
 *   阶梯1: 0~100 单位, 单价 0.10 元/单位
 *   阶梯2: 100~500 单位, 单价 0.08 元/单位
 *   阶梯3: 500+ 单位, 单价 0.05 元/单位
 *   若用量为 600:
 *     费用 = 100*0.10 + 400*0.08 + 100*0.05
 *          = 10 + 32 + 5 = 47 元
 *
 * 时间复杂度: O(T), T = 阶梯层数, 通常 T <= 10
 */
public class TieredStrategy implements BillingStrategy {

    private final List<PriceTier> tiers;

    public TieredStrategy(List<PriceTier> tiers) {
        // 按下限排序, 保证阶梯从低到高
        this.tiers = new ArrayList<>(tiers);
        this.tiers.sort(
            Comparator.comparing(PriceTier::getLowerBound));
    }

    @Override
    public ChargeResult calculate(BillingContext context) {
        BigDecimal totalUsage = context.getUsage();
        BigDecimal totalCost = BigDecimal.ZERO;
        BigDecimal remainingUsage = totalUsage;
        StringBuilder detail = new StringBuilder("阶梯计费明细:\n");

        for (PriceTier tier : tiers) {
            if (remainingUsage.compareTo(BigDecimal.ZERO) <= 0) {
                break;
            }

            // 计算当前阶梯可容纳的用量
            BigDecimal tierCapacity = tier.getUpperBound()
                    .subtract(tier.getLowerBound());
            BigDecimal usageInTier = remainingUsage.min(tierCapacity);

            // 当前阶梯的费用
            BigDecimal tierCost = usageInTier
                    .multiply(tier.getUnitPrice())
                    .setScale(2, RoundingMode.HALF_UP);

            totalCost = totalCost.add(tierCost);
            remainingUsage = remainingUsage.subtract(usageInTier);

            detail.append(String.format(
                "  阶梯[%s~%s]: 用量=%s, 单价=%s, 小计=%s元\n",
                tier.getLowerBound().toPlainString(),
                tier.getUpperBound().toPlainString(),
                usageInTier.toPlainString(),
                tier.getUnitPrice().toPlainString(),
                tierCost.toPlainString()));
        }

        // 如果用量超出所有阶梯, 使用最后一个阶梯的单价
        if (remainingUsage.compareTo(BigDecimal.ZERO) > 0) {
            PriceTier lastTier = tiers.get(tiers.size() - 1);
            BigDecimal overflowCost = remainingUsage
                    .multiply(lastTier.getUnitPrice())
                    .setScale(2, RoundingMode.HALF_UP);
            totalCost = totalCost.add(overflowCost);

            detail.append(String.format(
                "  超出阶梯: 用量=%s, 单价=%s, 小计=%s元\n",
                remainingUsage.toPlainString(),
                lastTier.getUnitPrice().toPlainString(),
                overflowCost.toPlainString()));
        }

        return new ChargeResult(
                totalCost,
                BigDecimal.ZERO,
                totalCost,
                getStrategyCode(),
                context.getPeriodStart(),
                context.getPeriodEnd(),
                detail.toString()
        );
    }

    @Override
    public String getStrategyCode() {
        return "TIERED";
    }

    @Override
    public boolean supports(BillingContext context) {
        return "TIERED".equals(context.getRuleCode());
    }
}

/**
 * 价格阶梯定义
 */
class PriceTier {

    /** 阶梯下限 (含) */
    private final BigDecimal lowerBound;

    /** 阶梯上限 (不含) */
    private final BigDecimal upperBound;

    /** 该阶梯的单价 */
    private final BigDecimal unitPrice;

    public PriceTier(BigDecimal lowerBound,
                     BigDecimal upperBound,
                     BigDecimal unitPrice) {
        this.lowerBound = lowerBound;
        this.upperBound = upperBound;
        this.unitPrice = unitPrice;
    }

    public BigDecimal getLowerBound() { return lowerBound; }
    public BigDecimal getUpperBound() { return upperBound; }
    public BigDecimal getUnitPrice() { return unitPrice; }
```

### 4.8 策略路由器 (规则匹配)

```java
import java.util.ArrayList;
import java.util.List;

/**
 * 计费策略路由器
 *
 * 设计模式: 策略模式 + 工厂模式 (Strategy + Factory)
 * - 维护所有已注册的策略实例
 * - 根据 BillingContext 中的规则编码自动匹配策略
 * - 支持运行时动态注册新策略
 *
 * 算法: 线性扫描匹配, O(S), S = 策略数量 (通常 S <= 10)
 */
public class BillingStrategyRouter {

    private final List<BillingStrategy> strategies = new ArrayList<>();

    /**
     * 注册策略
     */
    public void register(BillingStrategy strategy) {
        strategies.add(strategy);
    }

    /**
     * 根据上下文路由到合适的策略
     *
     * @param context 计费上下文
     * @return 匹配的策略
     * @throws IllegalStateException 无匹配策略时抛出
     */
    public BillingStrategy route(BillingContext context) {
        return strategies.stream()
                .filter(s -> s.supports(context))
                .findFirst()
                .orElseThrow(() -> new IllegalStateException(
                    "No strategy found for rule: "
                    + context.getRuleCode()));
    }

    /**
     * 执行计费: 路由 + 计算一步到位
     */
    public ChargeResult execute(BillingContext context) {
        BillingStrategy strategy = route(context);
        return strategy.calculate(context);
    }
}
```

### 5.1 基于时间段的计费算法

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.Duration;
import java.time.Instant;
import java.util.ArrayList;
import java.util.List;

/**
 * 基于时间段的计费计算器
 *
 * 核心算法: 时间段分割与合并 (Time Segment Split & Merge)
 *
 * 当资源在一个计费周期内发生规格变更时, 需要将整个计费周期
 * 按变更时间点切分为多个子段, 每段使用对应的规格单价分别计费,
 * 最后将各段费用累加。
 *
 * 示例:
 *   计费周期: 00:00 ~ 24:00
 *   10:00 发生规格变更: 4C8G -> 8C16G
 *   子段1: 00:00 ~ 10:00 (10小时, 按 4C8G 计费)
 *   子段2: 10:00 ~ 24:00 (14小时, 按 8C16G 计费)
 *
 * 算法步骤:
 * 1. 收集周期内所有规格变更事件, 提取变更时间点
 * 2. 按时间点将周期切分为 N+1 段 (N=变更次数)
 * 3. 每段独立计费后累加
 *
 * 时间复杂度: O(N log N), N = 变更事件数 (排序)
 */
public class TimeSegmentCalculator {

    /**
     * 计算一个完整周期内的费用 (含规格变更)
     *
     * @param periodStart  周期起始时间
     * @param periodEnd    周期结束时间
     * @param specChanges  周期内的规格变更记录 (已按时间排序)
     * @param initialSpec  周期起始时的资源规格
     * @return 各子段费用列表
     */
    public List<SegmentCharge> calculate(
            Instant periodStart,
            Instant periodEnd,
            List<SpecChangeRecord> specChanges,
            ResourceSpec initialSpec) {

        List<SegmentCharge> segments = new ArrayList<>();

        // 构建时间分割点列表
        List<Instant> splitPoints = new ArrayList<>();
        splitPoints.add(periodStart);
        for (SpecChangeRecord change : specChanges) {
            Instant changeTime = change.getChangeTime();
            if (changeTime.isAfter(periodStart)
                    && changeTime.isBefore(periodEnd)) {
                splitPoints.add(changeTime);
            }
        }
        splitPoints.add(periodEnd);

        // 按时间分割点创建子段
        ResourceSpec currentSpec = initialSpec;
        int changeIndex = 0;

        for (int i = 0; i < splitPoints.size() - 1; i++) {
            Instant segStart = splitPoints.get(i);
            Instant segEnd = splitPoints.get(i + 1);

            // 计算该段的时长 (小时)
            long seconds = Duration.between(segStart, segEnd)
                    .getSeconds();
            BigDecimal hours = BigDecimal.valueOf(seconds)
                    .divide(BigDecimal.valueOf(3600), 6,
                            RoundingMode.HALF_UP);

            // 计算该段费用 = 时长 × 单价
            BigDecimal segCost = hours
                    .multiply(currentSpec.getUnitPrice())
                    .setScale(2, RoundingMode.HALF_UP);

            segments.add(new SegmentCharge(
                    segStart, segEnd, currentSpec,
                    hours, segCost));

            // 更新下一段的规格
            if (changeIndex < specChanges.size()) {
                currentSpec = specChanges.get(changeIndex)
                        .getNewSpec();
                changeIndex++;
            }
        }

        return segments;
    }

    /**
     * 汇总所有子段费用
     */
    public BigDecimal sumSegments(List<SegmentCharge> segments) {
        return segments.stream()
                .map(SegmentCharge::getCost)
                .reduce(BigDecimal.ZERO, BigDecimal::add)
                .setScale(2, RoundingMode.HALF_UP);
    }
}

/**
 * 时间子段的计费结果
 */

    private final Instant end;
```

### 5.2 阶梯价格计算 (详细版)

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

/**
 * 阶梯价格计算器 (增强版)
 *
 * 算法: 累进阶梯分段计算 (Progressive Tiered Calculation)
 *
 * 与简单阶梯计费不同, 此版本支持:
 * 1. 累进制阶梯 —— 超出部分按更高阶梯单价计算 (类似个税)
 * 2. 全额制阶梯 —— 达到某阶梯后全部用量按该阶梯单价 (类似阶梯电价)
 *
 * 算法流程 (累进制):
 *   remaining = totalUsage
 *   totalCost = 0
 *   for each tier in sortedTiers:
 *     usageInTier = min(remaining, tier.capacity)
 *     tierCost = usageInTier * tier.unitPrice
 *     totalCost += tierCost
 *     remaining -= usageInTier
 *     if remaining <= 0: break
 *
 * 算法流程 (全额制):
 *   找到 totalUsage 落入的最高阶梯 tier
 *   totalCost = totalUsage * tier.unitPrice
 */
public class TieredPriceCalculator {

    public enum TierMode {
        /** 累进制: 每段用量按各自阶梯单价 */
        PROGRESSIVE,
        /** 全额制: 全部用量按所落入阶梯的单价 */
        FULL_AMOUNT
    }

    private final List<PriceTier> tiers;
    private final TierMode mode;

    public TieredPriceCalculator(List<PriceTier> tiers,
                                  TierMode mode) {
        this.tiers = new ArrayList<>(tiers);
        this.tiers.sort(
            Comparator.comparing(PriceTier::getLowerBound));
        this.mode = mode;
    }

    /**
     * 计算阶梯费用
     *
     * @param totalUsage 总用量
     * @return 计费结果, 含分段明细
     */
    public TieredChargeResult calculate(BigDecimal totalUsage) {
        if (mode == TierMode.PROGRESSIVE) {
            return calculateProgressive(totalUsage);
        } else {
            return calculateFullAmount(totalUsage);
        }
    }

    /**
     * 累进制计算
     *
     * 时间复杂度: O(T), T = 阶梯数
     * 空间复杂度: O(T), 存储分段明细
     */
    private TieredChargeResult calculateProgressive(
            BigDecimal totalUsage) {
        BigDecimal remaining = totalUsage;
        BigDecimal totalCost = BigDecimal.ZERO;
        List<TierDetail> details = new ArrayList<>();

        for (PriceTier tier : tiers) {
            if (remaining.compareTo(BigDecimal.ZERO) <= 0) break;

            BigDecimal tierCapacity = tier.getUpperBound()
                    .subtract(tier.getLowerBound());
            BigDecimal usageInTier = remaining.min(tierCapacity);
            BigDecimal tierCost = usageInTier
                    .multiply(tier.getUnitPrice())
                    .setScale(4, RoundingMode.HALF_UP);

            details.add(new TierDetail(
                    tier.getLowerBound(), tier.getUpperBound(),
                    tier.getUnitPrice(), usageInTier, tierCost));

            totalCost = totalCost.add(tierCost);
            remaining = remaining.subtract(usageInTier);
        }

        return new TieredChargeResult(
                totalUsage, totalCost.setScale(2, RoundingMode.HALF_UP),
                mode, details);
    }

    /**
     * 全额制计算
     *
     * 时间复杂度: O(T), T = 阶梯数 (查找所在阶梯)
     */
    private TieredChargeResult calculateFullAmount(
            BigDecimal totalUsage) {
        PriceTier matchedTier = null;
        for (PriceTier tier : tiers) {
            if (totalUsage.compareTo(tier.getLowerBound()) >= 0
                    && totalUsage.compareTo(tier.getUpperBound()) < 0) {
                matchedTier = tier;
                break;
            }
        }

        // 超出最高阶梯时使用最后一个阶梯
        if (matchedTier == null && !tiers.isEmpty()) {
            matchedTier = tiers.get(tiers.size() - 1);
        }

        BigDecimal totalCost = totalUsage
                .multiply(matchedTier.getUnitPrice())
                .setScale(2, RoundingMode.HALF_UP);

        List<TierDetail> details = List.of(new TierDetail(
                matchedTier.getLowerBound(),
                matchedTier.getUpperBound(),
                matchedTier.getUnitPrice(),
                totalUsage, totalCost));

        return new TieredChargeResult(
                totalUsage, totalCost, mode, details);
    }
}

/** 阶梯计费结果 */
class TieredChargeResult {
    private final BigDecimal totalUsage;
    private final BigDecimal totalCost;
    private final TieredPriceCalculator.TierMode mode;
    private final List<TierDetail> details;

    TieredChargeResult(BigDecimal totalUsage, BigDecimal totalCost,
                       TieredPriceCalculator.TierMode mode,
                       List<TierDetail> details) {

    }
```

### 5.3 折扣叠加计算

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.Instant;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;

/**
 * 折扣叠加计算器
 *
 * 算法: 有序折扣链式应用 (Ordered Discount Chain)
 *
 * 折扣叠加规则:
 * 1. 折扣按优先级排序 (priority 越小越先应用)
 * 2. 比例折扣: 在当前剩余金额上乘以折扣率
 * 3. 固定减免: 在当前剩余金额上直接扣减
 * 4. 混合叠加: 先应用比例折扣, 再应用固定减免
 * 5. 保底: 最终金额不低于 0
 *
 * 示例:
 *   原价 1000 元
 *   折扣1 (优先级1): 8折 -> 1000 * 0.8 = 800
 *   折扣2 (优先级2): 减免50元 -> 800 - 50 = 750
 *   折扣3 (优先级3): 9折 -> 750 * 0.9 = 675
 *   最终金额 = 675 元
 */
public class DiscountCalculator {

    /**
     * 计算叠加折扣后的最终金额
     *
     * @param originalAmount 原始金额
     * @param discounts      折扣列表
     * @param billingTime    计费时间点 (用于判断折扣有效性)
     * @return 折扣计算结果
     */
    public DiscountResult calculate(BigDecimal originalAmount,
                                    List<DiscountEntry> discounts,
                                    Instant billingTime) {
        // 1. 过滤有效折扣并按优先级排序
        List<DiscountEntry> effectiveDiscounts = discounts.stream()
                .filter(d -> d.isEffectiveAt(billingTime))
                .sorted(Comparator.comparingInt(
                    DiscountEntry::getPriority))
                .toList();

        BigDecimal currentAmount = originalAmount;
        BigDecimal totalDiscount = BigDecimal.ZERO;
        List<DiscountApplyRecord> records = new ArrayList<>();

        // 2. 链式应用折扣
        for (DiscountEntry discount : effectiveDiscounts) {
            BigDecimal beforeAmount = currentAmount;
            BigDecimal discountValue;

            switch (discount.getType()) {
                case RATE -> {
                    // 比例折扣: 当前金额 × 折扣率
                    discountValue = currentAmount.multiply(
                            BigDecimal.ONE.subtract(
                                discount.getValue()))
                            .setScale(2, RoundingMode.HALF_UP);
                    currentAmount = currentAmount
                            .subtract(discountValue);
                }
                case FIXED -> {
                    // 固定减免: 直接扣减
                    discountValue = discount.getValue()
                            .min(currentAmount);
                    currentAmount = currentAmount
                            .subtract(discountValue);
                }
                default -> {
                    discountValue = BigDecimal.ZERO;
                }
            }

            totalDiscount = totalDiscount.add(discountValue);
            records.add(new DiscountApplyRecord(
                    discount.getName(),
                    discount.getType(),
                    beforeAmount,
                    discountValue,
                    currentAmount));
        }

        // 3. 保底: 最终金额不低于 0
        currentAmount = currentAmount.max(BigDecimal.ZERO);

        return new DiscountResult(
                originalAmount, currentAmount,
                totalDiscount, records);
    }
}

/** 折扣类型 */
enum DiscountType {
    /** 比例折扣 (如 0.8 表示 8 折) */
    RATE,
    /** 固定减免金额 */

}
```

### 5.4 精度处理

```java
import java.math.BigDecimal;
import java.math.MathContext;
import java.math.RoundingMode;

/**
 * 金额精度处理工具
 *
 * 核心原则:
 * 1. 所有金额使用 BigDecimal, 绝对禁止 double/float
 * 2. 中间计算保留 8 位小数, 最终结果保留 2 位
 * 3. 统一使用 HALF_UP 舍入模式 (四舍五入)
 * 4. 分摊场景使用"最大余额法"避免精度丢失
 *
 * 算法: 最大余额法 (Largest Remainder Method)
 * 用于将一个总金额精确分摊到 N 个子项, 保证子项之和 == 总金额
 *
 * 步骤:
 * 1. 计算每个子项的精确份额 (可能有很多小数位)
 * 2. 对每个份额向下取整到 2 位小数
 * 3. 计算取整后的总和与原总额的差值
 * 4. 将差值按余数从大到小分配给各子项 (每个子项加 0.01)
 */
public class MoneyPrecision {

    /** 中间计算精度 */
    public static final int CALC_SCALE = 8;

    /** 最终展示/存储精度 */
    public static final int FINAL_SCALE = 2;

    /** 统一舍入模式 */
    public static final RoundingMode ROUNDING =
            RoundingMode.HALF_UP;

    /** 高精度数学上下文 */
    public static final MathContext MC =
            new MathContext(16, ROUNDING);

    /**
     * 安全乘法: 中间结果保留 8 位小数
     */
    public static BigDecimal multiply(BigDecimal a, BigDecimal b) {
        return a.multiply(b).setScale(CALC_SCALE, ROUNDING);
    }

    /**
     * 安全除法: 中间结果保留 8 位小数
     */
    public static BigDecimal divide(BigDecimal a, BigDecimal b) {
        return a.divide(b, CALC_SCALE, ROUNDING);
    }

    /**
     * 最终金额: 保留 2 位小数
     */
    public static BigDecimal finalAmount(BigDecimal amount) {
        return amount.setScale(FINAL_SCALE, ROUNDING);
    }

    /**
     * 最大余额法分摊
     *
     * @param total    总金额
     * @param weights  各子项的权重 (如各子项的用量比例)
     * @return 分摊后的金额数组, 保证 sum == total
     *
     * 时间复杂度: O(N log N), N = 子项数量
     */
    public static BigDecimal[] apportion(BigDecimal total,
                                          BigDecimal[] weights) {
        int n = weights.length;
        BigDecimal[] result = new BigDecimal[n];

        // 1. 计算权重总和
        BigDecimal weightSum = BigDecimal.ZERO;
        for (BigDecimal w : weights) {
            weightSum = weightSum.add(w);
        }

        // 2. 计算每个子项的精确份额并向下取整
        BigDecimal allocatedSum = BigDecimal.ZERO;
        BigDecimal[] remainders = new BigDecimal[n];
        Integer[] indices = new Integer[n];

        for (int i = 0; i < n; i++) {
            BigDecimal exact = total.multiply(weights[i])
                    .divide(weightSum, CALC_SCALE, ROUNDING);
            result[i] = exact.setScale(FINAL_SCALE,
                    RoundingMode.FLOOR);
            remainders[i] = exact.subtract(result[i]);
            allocatedSum = allocatedSum.add(result[i]);
            indices[i] = i;
        }

        // 3. 计算差值 (需要补齐的分)
        BigDecimal diff = total.setScale(FINAL_SCALE, ROUNDING)
                .subtract(allocatedSum);
        int centsToDistribute = diff.multiply(
                BigDecimal.valueOf(100)).intValue();

        // 4. 按余数从大到小排序, 依次补 0.01
        java.util.Arrays.sort(indices, (a, b) ->
                remainders[b].compareTo(remainders[a]));

        BigDecimal oneCent = new BigDecimal("0.01");
        for (int i = 0; i < centsToDistribute && i < n; i++) {
            result[indices[i]] = result[indices[i]].add(oneCent);
        }

        return result;
    }
}
```

## 六、账单生成

### 6.1 周期性账单生成器

```java
import java.math.BigDecimal;
import java.time.Instant;
import java.time.LocalDate;
import java.time.YearMonth;
import java.time.ZoneId;
import java.util.ArrayList;
import java.util.List;
import java.util.UUID;

/**
 * 周期性账单生成器
 *
 * 设计模式: 模板方法模式 (Template Method)
 * - 定义账单生成的固定流程: 数据采集 -> 费用计算 -> 账单组装 -> 持久化
 * - 子类可以覆写特定步骤 (如自定义费用计算逻辑)
 *
 * 算法: 滑动窗口扫描 (Sliding Window Scan)
 * - 按月度/日度窗口扫描所有活跃资源
 * - 每个窗口内聚合该资源的所有计费事件
 * - 生成对应的账单行项目
 *
 * 流程:
 * 1. 确定账单周期 (如 2024年1月)
 * 2. 查询该周期内所有活跃资源
 * 3. 对每个资源:
 *    a. 提取周期内的计费事件
 *    b. 按时间段分割 (处理规格变更)
 *    c. 使用策略路由器计算费用
 *    d. 应用折扣
 *    e. 生成账单行项目
 * 4. 汇总所有行项目生成账单
 * 5. 执行账单核验
 * 6. 持久化存储
 */
public class BillGenerator {

    private final EventStore eventStore;
    private final BillingStrategyRouter strategyRouter;
    private final TimeSegmentCalculator segmentCalculator;
    private final DiscountCalculator discountCalculator;

    public BillGenerator(EventStore eventStore,
                         BillingStrategyRouter strategyRouter,
                         TimeSegmentCalculator segmentCalculator,
                         DiscountCalculator discountCalculator) {
        this.eventStore = eventStore;
        this.strategyRouter = strategyRouter;
        this.segmentCalculator = segmentCalculator;
        this.discountCalculator = discountCalculator;
    }

    /**
     * 生成月度账单 (模板方法)
     *
     * @param tenantId   租户ID
     * @param yearMonth  账单月份
     * @param resources  该租户的所有资源ID列表
     * @return 生成的账单
     */
    public Bill generateMonthlyBill(String tenantId,
                                    YearMonth yearMonth,
                                    List<String> resources) {
        // Step 1: 确定周期边界
        Instant periodStart = yearMonth.atDay(1)
                .atStartOfDay(ZoneId.of("Asia/Shanghai"))
                .toInstant();
        Instant periodEnd = yearMonth.plusMonths(1).atDay(1)
                .atStartOfDay(ZoneId.of("Asia/Shanghai"))
                .toInstant();

        // Step 2: 逐资源计算
        List<BillLineItem> lineItems = new ArrayList<>();
        for (String resourceId : resources) {
            BillLineItem item = calculateResourceBill(
                    resourceId, periodStart, periodEnd);
            if (item != null) {
                lineItems.add(item);
            }
        }

        // Step 3: 汇总
        BigDecimal totalOriginal = lineItems.stream()
                .map(BillLineItem::getOriginalAmount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
        BigDecimal totalDiscount = lineItems.stream()
                .map(BillLineItem::getDiscountAmount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);
        BigDecimal totalFinal = lineItems.stream()
                .map(BillLineItem::getFinalAmount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);

        // Step 4: 生成账单对象
        Bill bill = new Bill(
                UUID.randomUUID().toString(),
                tenantId,
                yearMonth.toString(),
                periodStart,
                periodEnd,
                totalOriginal,
                totalDiscount,
                MoneyPrecision.finalAmount(totalFinal),
                lineItems,
                BillStatus.GENERATED,
                Instant.now()
        );

        // Step 5: 账单核验
        verifyBill(bill);

        return bill;
    }

    /**
     * 计算单个资源在指定周期内的费用
     */
    private BillLineItem calculateResourceBill(
            String resourceId,
            Instant periodStart,
            Instant periodEnd) {

        // 重放事件获取当前状态
        ResourceBillingAggregate aggregate =
                eventStore.replay(resourceId);

        // 跳过未激活的资源 (周期内从未开始计费)
        List<BillingEvent> events =
                eventStore.getEventStream(resourceId);
        if (events.isEmpty()) return null;

        // 过滤周期内的事件
        List<BillingEvent> periodEvents = events.stream()
                .filter(e -> !e.getOccurredAt().isBefore(periodStart)
                        && e.getOccurredAt().isBefore(periodEnd))
                .toList();

        // 提取规格变更记录
        List<SpecChangeRecord> specChanges = periodEvents.stream()
                .filter(e -> e.getEventType()
                        == BillingEventType.SPEC_CHANGE)
                .map(e -> new SpecChangeRecord(
                        e.getOccurredAt(), null,
                        e.getResourceSpec()))
                .toList();

        // 获取周期起始时的规格
        ResourceSpec initialSpec = determineInitialSpec(
                events, periodStart);
        if (initialSpec == null) return null;

        // 时间段分割计算
        List<SegmentCharge> segments =
                segmentCalculator.calculate(
                        periodStart, periodEnd,
                        specChanges, initialSpec);

        BigDecimal totalCost =
                segmentCalculator.sumSegments(segments);

        return new BillLineItem(
                resourceId,
                aggregate.getStatus().name(),
                totalCost,
                BigDecimal.ZERO,
                totalCost,
                segments.size() + " segments"
        );
    }

    /**
     * 确定资源在周期起始时间的规格
     * 算法: 反向扫描事件流, 找到最近一次携带规格信息的事件
     */
    private ResourceSpec determineInitialSpec(
            List<BillingEvent> events, Instant periodStart) {
        for (int i = events.size() - 1; i >= 0; i--) {
            BillingEvent e = events.get(i);
            if (!e.getOccurredAt().isAfter(periodStart)
                    && e.getResourceSpec() != null) {
                return e.getResourceSpec();
            }
        }
        // 如果没有找到周期前的规格, 使用最早的规格
        return events.stream()
                .filter(e -> e.getResourceSpec() != null)
                .map(BillingEvent::getResourceSpec)
                .findFirst()
                .orElse(null);
    }

    /**
     * 账单核验
     *
     * 核验规则:
     * 1. 账单总额 = 所有行项目金额之和
     * 2. 每个行项目金额 >= 0
     * 3. 折扣额不超过原始金额
     */
    private void verifyBill(Bill bill) {
        BigDecimal sumOfItems = bill.getLineItems().stream()
                .map(BillLineItem::getFinalAmount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);

        BigDecimal expectedTotal = MoneyPrecision.finalAmount(
                sumOfItems);

        if (expectedTotal.compareTo(bill.getTotalFinalAmount()) != 0) {
            throw new BillVerificationException(
                    "Bill total mismatch: expected "
                    + expectedTotal + ", got "
                    + bill.getTotalFinalAmount());
        }

        for (BillLineItem item : bill.getLineItems()) {
            if (item.getFinalAmount()
                    .compareTo(BigDecimal.ZERO) < 0) {
                throw new BillVerificationException(
                        "Negative amount for resource: "
                        + item.getResourceId());
            }
        }
    }
}

/** 账单核验异常 */
class BillVerificationException extends RuntimeException {
    public BillVerificationException(String message) {
        super(message);
    }
}
```

### 6.3 实时预估计算

```java
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.Duration;
import java.time.Instant;
import java.time.YearMonth;
import java.time.ZoneId;

/**
 * 实时费用预估器
 *
 * 算法: 线性外推法 (Linear Extrapolation)
 * - 根据当前已产生的费用和已使用时长, 线性推算月底总费用
 * - 公式: 预估月度费用 = (当前已产生费用 / 已过天数) × 月度总天数
 *
 * 优化: 加权移动平均 (Weighted Moving Average)
 * - 近期的使用量权重更高, 使预估更接近实际趋势
 */
public class RealTimeEstimator {

    private final EventStore eventStore;
    private final BillingStrategyRouter strategyRouter;

    public RealTimeEstimator(EventStore eventStore,
                             BillingStrategyRouter strategyRouter) {
        this.eventStore = eventStore;
        this.strategyRouter = strategyRouter;
    }

    /**
     * 预估指定资源到月底的总费用
     *
     * @param resourceId 资源ID
     * @return 预估结果
     */
    public EstimationResult estimate(String resourceId) {
        Instant now = Instant.now();
        YearMonth currentMonth = YearMonth.now(
                ZoneId.of("Asia/Shanghai"));

        Instant monthStart = currentMonth.atDay(1)
                .atStartOfDay(ZoneId.of("Asia/Shanghai"))
                .toInstant();
        Instant monthEnd = currentMonth.plusMonths(1).atDay(1)
                .atStartOfDay(ZoneId.of("Asia/Shanghai"))
                .toInstant();

        // 计算已产生费用 (月初到当前)
        ResourceBillingAggregate aggregate =
                eventStore.replay(resourceId);
        if (aggregate.getStatus() != BillingStatus.ACTIVE) {
            return new EstimationResult(
                    resourceId, BigDecimal.ZERO,
                    BigDecimal.ZERO, now);
        }

        // 已过时长 (小时)
        long elapsedSeconds = Duration.between(
                monthStart, now).getSeconds();
        BigDecimal elapsedHours = BigDecimal.valueOf(
                elapsedSeconds)
                .divide(BigDecimal.valueOf(3600), 6,
                        RoundingMode.HALF_UP);

        // 当前已累计费用
        BigDecimal currentCost = elapsedHours
                .multiply(aggregate.getCurrentSpec().getUnitPrice())
                .setScale(2, RoundingMode.HALF_UP);

        // 月度总时长 (小时)
        long totalSeconds = Duration.between(
                monthStart, monthEnd).getSeconds();
        BigDecimal totalHours = BigDecimal.valueOf(totalSeconds)
                .divide(BigDecimal.valueOf(3600), 6,
                        RoundingMode.HALF_UP);

        // 线性外推: 预估总费用 = 已累计费用 × (总时长 / 已过时长)
        BigDecimal estimatedTotal;
        if (elapsedHours.compareTo(BigDecimal.ZERO) > 0) {
            estimatedTotal = currentCost
                    .multiply(totalHours)
                    .divide(elapsedHours, 2, RoundingMode.HALF_UP);
        } else {
            estimatedTotal = BigDecimal.ZERO;
        }

        return new EstimationResult(
                resourceId, currentCost, estimatedTotal, now);
    }
}

/** 预估结果 */
class EstimationResult {
    private final String resourceId;
    private final BigDecimal currentCost;
    private final BigDecimal estimatedMonthlyTotal;
    private final Instant estimatedAt;

    EstimationResult(String resourceId, BigDecimal currentCost,
                     BigDecimal estimatedMonthlyTotal,
                     Instant estimatedAt) {
        this.resourceId = resourceId;
        this.currentCost = currentCost;
        this.estimatedMonthlyTotal = estimatedMonthlyTotal;
```

## 七、高可用设计

### 7.1 事件不丢失 —— 可靠事件接收

```java
import java.time.Instant;
import java.util.concurrent.BlockingQueue;
import java.util.concurrent.LinkedBlockingQueue;
import java.util.concurrent.TimeUnit;

/**
 * 可靠事件接收器
 *
 * 设计模式: 生产者-消费者模式 (Producer-Consumer)
 * - 事件到达后先写入本地持久化队列 (WAL), 再返回 ACK
 * - 消费线程从队列中取出事件进行处理
 * - 即使处理失败, 事件也不会丢失 (已持久化)
 *
 * 算法: 预写日志 (Write-Ahead Logging, WAL)
 * 1. 事件到达 -> 写入 WAL 文件 (fsync)
 * 2. 返回 ACK 给上游
 * 3. 异步消费 WAL 中的事件进行处理
 * 4. 处理成功后标记 WAL 条目为已完成
 * 5. 定期清理已完成的 WAL 条目
 *
 * 保证: 至少一次投递 (At-Least-Once Delivery)
 */
public class ReliableEventReceiver {

    /** 内存缓冲队列 */
    private final BlockingQueue<BillingEvent> buffer;

    /** WAL 持久化存储 */
    private final WriteAheadLog wal;

    /** 事件处理器 */
    private final EventProcessor processor;

    /** 消费线程是否运行 */
    private volatile boolean running = true;

    public ReliableEventReceiver(WriteAheadLog wal,
                                  EventProcessor processor,
                                  int bufferSize) {
        this.buffer = new LinkedBlockingQueue<>(bufferSize);
        this.wal = wal;
        this.processor = processor;
    }

    /**
     * 接收事件 (同步, 保证持久化后返回)
     *
     * @param event 计费事件
     * @return 接收确认
     */
    public ReceiveAck receive(BillingEvent event) {
        try {
            // 1. 先写 WAL (持久化)
            long walOffset = wal.append(event);

            // 2. 放入内存缓冲队列 (供消费线程处理)
            buffer.put(event);

            // 3. 返回确认
            return new ReceiveAck(true, walOffset,
                    Instant.now());

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return new ReceiveAck(false, -1, Instant.now());
        }
    }

    /**
     * 启动消费线程
     */
    public void startConsumer() {
        Thread consumer = new Thread(() -> {
            while (running) {
                try {
                    BillingEvent event = buffer.poll(
                            1, TimeUnit.SECONDS);
                    if (event != null) {
                        processor.process(event);
                        wal.markCompleted(event.getEventId());
                    }
                } catch (Exception e) {
                    // 处理失败, 事件仍在 WAL 中, 等待重试
                    handleProcessingFailure(e);
                }
            }
        }, "billing-event-consumer");
        consumer.setDaemon(true);
        consumer.start();
    }

    /**
     * 恢复未完成的事件 (服务重启时调用)
     * 扫描 WAL 中所有未标记为完成的条目, 重新放入处理队列
     */
    public void recover() {
        List<BillingEvent> unprocessed = wal.getUnprocessed();
        for (BillingEvent event : unprocessed) {
            try {
                buffer.put(event);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            }
        }
    }

    private void handleProcessingFailure(Exception e) {
        // 记录错误日志, 等待下次重试
        System.err.println("Event processing failed: "
                + e.getMessage());
    }

    public void shutdown() {
        this.running = false;
    }
}

/** WAL 接口 */
interface WriteAheadLog {
    long append(BillingEvent event);
    void markCompleted(String eventId);
    java.util.List<BillingEvent> getUnprocessed();
}

/** 事件处理器接口 */
interface EventProcessor {
    void process(BillingEvent event);
}

/** 接收确认 */
class ReceiveAck {
    private final boolean success;
    private final long walOffset;
    private final Instant timestamp;

    ReceiveAck(boolean success, long walOffset, Instant timestamp) {
        this.success = success;
        this.walOffset = walOffset;
        this.timestamp = timestamp;
    }

    public boolean isSuccess() { return success; }
    public long getWalOffset() { return walOffset; }
    public Instant getTimestamp() { return timestamp; }
}
```

### 7.2 幂等处理

```java
import java.time.Duration;
import java.time.Instant;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.ConcurrentMap;

/**
 * 幂等处理器
 *
 * 设计模式: 幂等令牌模式 (Idempotency Key Pattern)
 * - 每个事件携带全局唯一的 eventId 作为幂等键
 * - 处理前先检查该 eventId 是否已处理过
 * - 如果已处理, 直接返回上次的处理结果 (不重复执行)
 * - 如果未处理, 执行处理逻辑并记录结果
 *
 * 数据结构: ConcurrentHashMap
 * - Key: eventId (String)
 * - Value: 处理结果 + 过期时间
 * - 查找时间复杂度: O(1)
 *
 * 过期清理: 定期清理超过保留期的记录, 避免内存无限增长
 * 保留期默认 7 天
 */
public class IdempotencyGuard {

    /** 幂等记录存储 */
    private final ConcurrentMap<String, IdempotencyRecord> records
            = new ConcurrentHashMap<>();

    /** 记录保留时长 */
    private final Duration retentionPeriod;

    public IdempotencyGuard(Duration retentionPeriod) {
        this.retentionPeriod = retentionPeriod;
    }

    public IdempotencyGuard() {
        this(Duration.ofDays(7));
    }

    /**
     * 幂等执行
     *
     * @param eventId  事件唯一标识 (幂等键)
     * @param action   实际业务逻辑
     * @return 执行结果 (首次执行返回新结果, 重复执行返回缓存结果)
     */
    public ProcessResult executeIdempotent(String eventId,
                                           EventAction action) {
        // 1. 检查是否已处理
        IdempotencyRecord existing = records.get(eventId);
        if (existing != null && !existing.isExpired()) {
            // 已处理过, 返回缓存结果
            return existing.getResult();
        }

        // 2. 尝试锁定 (CAS 操作, 防止并发重复处理)
        IdempotencyRecord lockRecord = new IdempotencyRecord(
                eventId, ProcessResult.processing(),
                Instant.now(), retentionPeriod);

        IdempotencyRecord previous = records.putIfAbsent(
                eventId, lockRecord);
        if (previous != null && !previous.isExpired()) {
            // 另一个线程已经在处理或已完成
            return previous.getResult();
        }

        // 3. 执行业务逻辑
        try {
            ProcessResult result = action.execute();

            // 4. 更新记录为完成状态
            records.put(eventId, new IdempotencyRecord(
                    eventId, result, Instant.now(),
                    retentionPeriod));

            return result;

        } catch (Exception e) {
            // 执行失败, 移除锁定记录 (允许重试)
            records.remove(eventId);
            throw e;
        }
    }

    /**
     * 定期清理过期记录
     * 建议由调度器每小时执行一次
     */
    public void cleanup() {
        records.entrySet().removeIf(
                entry -> entry.getValue().isExpired());
    }

    /**
     * 查询事件是否已处理
     */
    public boolean isProcessed(String eventId) {
        IdempotencyRecord record = records.get(eventId);
        return record != null
                && !record.isExpired()
                && record.getResult().isSuccess();
    }
}

/** 幂等记录 */
class IdempotencyRecord {
    private final String eventId;
    private final ProcessResult result;
    private final Instant createdAt;
    private final Duration ttl;

    IdempotencyRecord(String eventId, ProcessResult result,
                      Instant createdAt, Duration ttl) {
        this.eventId = eventId;
        this.result = result;
        this.createdAt = createdAt;
        this.ttl = ttl;
    }

    public boolean isExpired() {
        return Instant.now().isAfter(createdAt.plus(ttl));
    }

    public String getEventId() { return eventId; }
    public ProcessResult getResult() { return result; }
}

/** 处理结果 */
class ProcessResult {
    private final boolean success;
    private final String message;

    private ProcessResult(boolean success, String message) {
        this.success = success;
        this.message = message;
    }

    public static ProcessResult success(String msg) {
        return new ProcessResult(true, msg);
    }

    public static ProcessResult failure(String msg) {
        return new ProcessResult(false, msg);
    }

    public static ProcessResult processing() {
        return new ProcessResult(false, "processing");
    }

    public boolean isSuccess() { return success; }
    public String getMessage() { return message; }
}

/** 事件执行动作 (函数式接口) */
@FunctionalInterface
interface EventAction {
    ProcessResult execute();
}
```

### 7.3 补偿机制

```java

import java.util.ArrayList;
import java.util.List;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;

/**
 * 补偿任务管理器
 *
 * 设计模式: Saga 补偿模式 (Saga Compensation)
 * - 将长事务拆分为多个本地事务
 * - 每个本地事务有对应的补偿操作
 * - 当某步失败时, 按逆序执行已完成步骤的补偿
 *
 * 算法: 指数退避重试 (Exponential Backoff Retry)
 * - 首次重试间隔: 1 秒
 * - 每次重试间隔翻倍: 1s, 2s, 4s, 8s, 16s...
 * - 最大重试间隔: 5 分钟
 * - 最大重试次数: 10 次
 *
 * 重试公式:
 *   delay = min(initialDelay × 2^(retryCount-1), maxDelay)
 */
public class CompensationManager {

    /** 待补偿任务列表 */
    private final List<CompensationTask> pendingTasks =
            new ArrayList<>();

    /** 调度器 */
    private final ScheduledExecutorService scheduler =
            Executors.newScheduledThreadPool(2);

    /** 重试配置 */
    private final RetryConfig retryConfig;

    public CompensationManager(RetryConfig retryConfig) {
        this.retryConfig = retryConfig;
    }

    public CompensationManager() {
        this(new RetryConfig(
                Duration.ofSeconds(1),
                Duration.ofMinutes(5),
                10));
    }

    /**
     * 注册补偿任务
     */
    public void register(CompensationTask task) {
        pendingTasks.add(task);
    }

    /**
     * 执行补偿 (逆序执行所有已注册的补偿任务)
     *
     * 算法: 逆序遍历 + 指数退避重试
     */
    public CompensationReport compensate() {
        List<CompensationResult> results = new ArrayList<>();

        // 逆序执行补偿
        for (int i = pendingTasks.size() - 1; i >= 0; i--) {
            CompensationTask task = pendingTasks.get(i);
            CompensationResult result = executeWithRetry(task);
            results.add(result);
        }

        pendingTasks.clear();
        return new CompensationReport(results);
    }

    /**
     * 带指数退避重试的执行
     *
     * 算法: 指数退避 (Exponential Backoff)
     *   delay(n) = min(initial × 2^(n-1), maxDelay)
     */
    private CompensationResult executeWithRetry(
            CompensationTask task) {
        int attempt = 0;
        Exception lastException = null;

        while (attempt < retryConfig.getMaxRetries()) {
            try {
                task.execute();
                return new CompensationResult(
                        task.getTaskName(), true,
                        attempt + 1, null);
            } catch (Exception e) {
                lastException = e;
                attempt++;

                if (attempt < retryConfig.getMaxRetries()) {
                    // 计算退避延迟
                    long delayMs = calculateBackoff(attempt);
                    try {
                        Thread.sleep(delayMs);
                    } catch (InterruptedException ie) {
                        Thread.currentThread().interrupt();
                        break;
                    }
                }
            }
        }

        return new CompensationResult(
                task.getTaskName(), false, attempt,
                lastException != null
                        ? lastException.getMessage()
                        : "Unknown error");
    }

    /**
     * 计算指数退避延迟 (毫秒)
     *
     * 公式: delay = min(initialDelay × 2^(attempt-1), maxDelay)
     */
    private long calculateBackoff(int attempt) {
        long initialMs = retryConfig.getInitialDelay()
                .toMillis();
        long maxMs = retryConfig.getMaxDelay().toMillis();
        long delay = (long) (initialMs
                * Math.pow(2, attempt - 1));
        return Math.min(delay, maxMs);
    }

    /**
     * 启动定时补偿扫描
     * 定期检查是否有遗漏的计费事件需要补偿处理
     */
    public void startPeriodicScan(EventStore eventStore,
                                   Duration scanInterval) {
        scheduler.scheduleAtFixedRate(() -> {
            try {
                scanAndCompensate(eventStore);
            } catch (Exception e) {
                System.err.println(
                    "Periodic compensation scan failed: "
                    + e.getMessage());
            }
        }, scanInterval.toSeconds(),
           scanInterval.toSeconds(),
           TimeUnit.SECONDS);
    }

    /**
     * 扫描并补偿遗漏事件
     *
     * 算法: 对账扫描 (Reconciliation Scan)
     * 1. 从上游系统获取资源创建/销毁的最终状态
     * 2. 与计费系统事件流比对
     * 3. 对缺失的事件进行补录
     */
    private void scanAndCompensate(EventStore eventStore) {
        // 获取所有应计费资源的ID列表 (从资源管理系统查询)
        // 比对计费事件流中是否有对应的 START 事件
        // 缺失的生成补偿 START 事件
        // 已销毁但计费未停止的生成补偿 STOP 事件

            "Periodic compensation scan completed at: "
            + Instant.now());
    }

    public void shutdown() {
        scheduler.shutdown();
    }
}
```

## 八、系统总结

### 8.1 架构设计要点回顾

| 层次 | 核心职责 | 关键设计模式 | 核心算法 |
|------|---------|-------------|----------|
| 事件接入层 | 接收、校验、去重计费事件 | 生产者-消费者、责任链 | WAL预写日志、CAS幂等检查 |
| 计费规则引擎 | 策略路由、规则匹配 | 策略模式、工厂模式 | 线性扫描匹配 |
| 计费计算层 | 费用计算、折扣叠加 | 模板方法、上下文对象 | 时间段分割、阶梯累进、最大余额法分摊 |
| 账单生成层 | 周期账单、实时预估 | 模板方法、观察者 | 滑动窗口扫描、线性外推预估 |
| 数据存储层 | 事件持久化、状态还原 | 事件溯源、聚合根(DDD) | 顺序重放、快照优化 |
| 高可用保障 | 不丢失、不重复、可补偿 | 幂等令牌、Saga补偿 | 指数退避重试、对账扫描 |

### 8.2 关键设计决策

**1. 事件溯源 vs 状态直存**

选择事件溯源模式的原因:
- 计费场景要求完整的审计追踪, 任何费用都必须可回溯
- 支持任意时间点的状态重建, 便于账单核对和争议处理
- 事件不可变, 天然支持并发读取
- 通过快照机制缓解重放性能问题

**2. 策略模式实现计费规则**

- 四种计费策略 (按时、按量、按规格、阶梯) 各自独立封装
- 新增计费方式只需实现 `BillingStrategy` 接口并注册到路由器
- 运行时可根据资源类型动态切换策略

**3. BigDecimal 全链路精度保证**

- 金额计算全程使用 `BigDecimal`, 杜绝浮点误差
- 中间结果保留 8 位小数, 最终结果保留 2 位
- 分摊场景使用最大余额法, 保证子项之和严格等于总额

**4. 弹性 Serverless 支持**

- 按量计费策略天然适配 Serverless 场景
- 函数调用次数、执行时长、流量等均可作为计量指标
- 支持最低消费和封顶金额, 控制成本上下界

## 九、全链路实战案例

前面章节分别拆解了事件模型、规则引擎、计算核心、账单生成与高可用机制各个
组件的设计, 本章以三个**端到端（End-to-End）**的实战案例, 把上述组件串联为
完整的业务链路, 并补齐工程落地时必需的**异常处理**、**日志记录**与**幂等控制**
细节, 便于直接对照实现。

三个案例覆盖计费系统最核心的三类场景:

| 案例 | 链路 | 核心难点 |
|------|------|----------|
| 案例一 | 按量计费全链路：使用量上报 → 计量 → 定价 → 出账 → 扣费 | 海量上报数据的聚合去重、扣费失败的重试与止损 |
| 案例二 | 包年包月计费全链路：订购 → 周期扣费 → 续费 → 到期处理 | 定时扣费的幂等与并发控制、到期降级/回收 |
| 案例三 | 账单生成与出账全链路：计费项聚合 → 优惠抵扣 → 账单生成 → 账单推送 | 多计费项聚合一致性、推送失败补偿 |

统一约定: 日志记录使用 SLF4J (`org.slf4j.Logger`) 门面接口, 与第 2.3 节
"技术选型"中 Spring Boot 技术栈保持一致；金额计算延续第五章的 `BigDecimal`
精度处理原则；幂等控制延续第 7.2 节的幂等令牌思路, 并结合 Redis 分布式锁
应对多实例部署场景。

### 9.1 案例一：按量计费全链路

#### 9.1.1 链路概览

```
┌───────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐
│ 使用量上报 │──▶│  计量聚合  │──▶│  定价计算  │──▶│  账单出账  │──▶│  余额扣费  │
│ (Report)  │   │ (Metering)│   │ (Pricing) │   │ (Billing) │   │ (Deduct)  │
└───────────┘   └───────────┘   └───────────┘   └───────────┘   └───────────┘
      │               │               │               │               │
      ▼               ▼               ▼               ▼               ▼
  幂等去重设备位     Redis滑动窗口    UsageBasedStrategy  账单流水表    分布式锁+
  (idempotencyKey)   累加 + 定时     阶梯/单价计算       (bill_item)   本地事务表
                      落库 (WAL)                                      (扣费幂等)
```

该链路适用于 Serverless 函数调用、API 网关请求量、CDN 流量等按实际用量
计费的场景。关键设计目标：

1. **上报幂等**：同一条用量数据因网络重试重复上报时, 不能重复计量。
2. **计量准确**：海量细粒度上报需要先在内存/Redis 中聚合, 再定时落库,
   避免对计费主库造成写入风暕。
3. **扣费幂等 + 最终一致**：扣费失败时不能出现"计量成功但扣费丢失"或
   "重复扣费"两种极端情况。

#### 9.1.2 使用量上报接入

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.time.Instant;

/**
 * 使用量上报请求 (值对象)
 *
 * 字段设计参考第 3.2 节 BillingEvent, 但用量上报是更高频的独立数据流,
 * 不复用 BillingEvent 模型, 避免事件表被海量细粒度数据打满。
 */
public final class UsageReportRequest {

    /** 上报幂等键, 由上游服务生成 (如: 请求ID/调用链TraceId) */
    private final String reportId;

    /** 资源实例 ID (如 Serverless 函数实例、网关应用) */
    private final String resourceId;

    /** 租户 ID */
    private final String tenantId;

    /** 计量指标编码 (如 INVOKE_COUNT / TRAFFIC_MB / GPU_SECONDS) */
    private final String metricCode;

    /** 本次上报的用量增量 */
    private final BigDecimal usageDelta;

    /** 用量发生时间 */
    private final Instant occurredAt;

    public UsageReportRequest(String reportId, String resourceId,
                               String tenantId, String metricCode,
                               BigDecimal usageDelta, Instant occurredAt) {
        this.reportId = reportId;
        this.resourceId = resourceId;
        this.tenantId = tenantId;
        this.metricCode = metricCode;
        this.usageDelta = usageDelta;
        this.occurredAt = occurredAt;
    }

    public String getReportId() { return reportId; }
    public String getResourceId() { return resourceId; }
    public String getTenantId() { return tenantId; }
    public String getMetricCode() { return metricCode; }
    public BigDecimal getUsageDelta() { return usageDelta; }
    public Instant getOccurredAt() { return occurredAt; }
}

/**
 * 用量上报校验异常
 * 区分参数错误 (客户端问题, 不重试) 与系统异常 (可重试)
 */
public class UsageReportValidationException extends RuntimeException {
    public UsageReportValidationException(String message) {
        super(message);
    }
}

/**
 * 使用量上报接入服务
 *
 * 设计模式: 门面模式 (Facade) + 幂等令牌模式
 * 职责: 接收上报请求 → 参数校验 → 幂等去重 → 转发至计量聚合器
 *
 * 幂等实现: 使用 Redis SETNX (SET key value NX EX ttl) 原子操作,
 * 保证同一 reportId 在 TTL 窗口内只会被计量一次, 天然支持分布式多实例部署。
 */
public class UsageReportIngestService {

    private static final Logger log =
            LoggerFactory.getLogger(UsageReportIngestService.class);

    /** 幂等键在 Redis 中的保留时长 (秒), 需覆盖上游最大重试窗口 */
    private static final long IDEMPOTENCY_TTL_SECONDS = 24 * 3600L;

    private final RedisIdempotencyStore idempotencyStore;
    private final UsageMeteringAggregator meteringAggregator;

    public UsageReportIngestService(RedisIdempotencyStore idempotencyStore,
                                     UsageMeteringAggregator meteringAggregator) {
        this.idempotencyStore = idempotencyStore;
        this.meteringAggregator = meteringAggregator;
    }

    /**
     * 接收单条用量上报
     *
     * @param request 上报请求
     * @return true 表示本次为新数据并已计量, false 表示重复上报被去重
     */
    public boolean ingest(UsageReportRequest request) {
        // 1. 参数校验 —— 非法请求直接拒绝, 不进入后续链路
        validate(request);

        // 2. 幂等去重 —— 基于 reportId 的分布式原子占位
        String idempotencyKey = "usage:report:" + request.getReportId();
        boolean firstSeen = idempotencyStore.setIfAbsent(
                idempotencyKey, "1", IDEMPOTENCY_TTL_SECONDS);

        if (!firstSeen) {
            log.warn("[UsageReport] 重复上报被去重, reportId={}, "
                            + "resourceId={}, metricCode={}",
                    request.getReportId(), request.getResourceId(),
                    request.getMetricCode());
            return false;
        }

        // 3. 转发计量聚合, 计量失败需要回滚幂等占位, 允许上游重试
        try {
            meteringAggregator.accumulate(request);
            log.info("[UsageReport] 上报处理成功, reportId={}, "
                            + "resourceId={}, metricCode={}, usageDelta={}",
                    request.getReportId(), request.getResourceId(),
                    request.getMetricCode(),
                    request.getUsageDelta().toPlainString());
            return true;
        } catch (Exception e) {
            // 计量失败: 回滚幂等占位, 避免"占了坑但没计量"导致用量丢失
            idempotencyStore.delete(idempotencyKey);
            log.error("[UsageReport] 计量聚合失败, 已回滚幂等占位, "
                            + "reportId={}, resourceId={}",
                    request.getReportId(), request.getResourceId(), e);
            throw new UsageMeteringException(
                    "usage metering failed, reportId=" + request.getReportId(), e);
        }
    }

    private void validate(UsageReportRequest request) {
        if (request.getReportId() == null || request.getReportId().isBlank()) {
            throw new UsageReportValidationException("reportId is required");
        }
        if (request.getResourceId() == null || request.getResourceId().isBlank()) {
            throw new UsageReportValidationException("resourceId is required");
        }
        if (request.getUsageDelta() == null
                || request.getUsageDelta().compareTo(BigDecimal.ZERO) < 0) {
            throw new UsageReportValidationException(
                    "usageDelta must be non-negative, reportId="
                            + request.getReportId());
        }
        if (request.getOccurredAt() == null) {
            throw new UsageReportValidationException("occurredAt is required");
        }
    }
}

/** 计量聚合异常, 系统性异常, 允许上游按退避策略重试 */
class UsageMeteringException extends RuntimeException {
    UsageMeteringException(String message, Throwable cause) {
        super(message, cause);
    }
}

 * Redis 幂等存储的最小接口抽象, 便于替换实现/单测 mock
 */

    /** 原子占位, 成功返回 true, key 已存在返回 false */

    void delete(String key);
}
```

#### 9.1.3 计量聚合（滑动窗口累加 + 定时落库）

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.Instant;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicReference;

/**
 * 用量计量聚合器
 *
 * 设计动机: 按量计费场景上报 QPS 可能达到数千/秒 (如网关请求计费),
 * 若每条上报都直接写计费主库, 会造成数据库写入瓶颈。
 *
 * 算法: 内存滑动窗口累加 (Sliding Window Accumulation)
 * - Key: resourceId + metricCode + 分钟级时间窗口
 * - Value: 该窗口内的用量累加值 (使用 AtomicReference<BigDecimal> 保证原子性)
 * - 定时任务 (每分钟) 将上一个完整窗口的聚合结果批量落库, 并清理内存
 *
 * 可靠性保证:
 * - 落库前先写 WAL (Write-Ahead Log), 落库成功后再清理内存窗口, 防止进程崩溃丢数据
 * - 落库操作本身依赖幂等键 (resourceId+metricCode+window) 做 UPSERT, 防止重复入库
 */
public class UsageMeteringAggregator {

    private static final Logger log =
            LoggerFactory.getLogger(UsageMeteringAggregator.class);

    /** 聚合窗口大小 (秒), 每分钟一个窗口 */
    private static final long WINDOW_SECONDS = 60L;

    /** 内存聚合表: windowKey -> 累加用量 */
    private final ConcurrentHashMap<String, AtomicReference<BigDecimal>> window
            = new ConcurrentHashMap<>();

    /** 窗口维度信息, 用于落库时还原 resourceId / metricCode / windowStart */
    private final ConcurrentHashMap<String, WindowMeta> windowMeta
            = new ConcurrentHashMap<>();

    private final UsageMeteringRepository repository;

    public UsageMeteringAggregator(UsageMeteringRepository repository) {
        this.repository = repository;
    }

    /**
     * 累加一条用量数据到对应的时间窗口
     */
    public void accumulate(UsageReportRequest request) {
        long windowStart = alignToWindow(request.getOccurredAt().getEpochSecond());
        String windowKey = buildWindowKey(
                request.getResourceId(), request.getMetricCode(), windowStart);

        window.computeIfAbsent(windowKey,
                        k -> new AtomicReference<>(BigDecimal.ZERO))
                .updateAndGet(old -> old.add(request.getUsageDelta()));

        windowMeta.putIfAbsent(windowKey, new WindowMeta(
                request.getResourceId(), request.getTenantId(),
                request.getMetricCode(), windowStart));
    }

    private long alignToWindow(long epochSecond) {
        return (epochSecond / WINDOW_SECONDS) * WINDOW_SECONDS;
    }

    private String buildWindowKey(String resourceId, String metricCode,
                                   long windowStart) {
        return resourceId + ":" + metricCode + ":" + windowStart;
    }

    /**
     * 定时任务入口: 落库所有"已完整结束"的窗口 (窗口结束时间早于当前时间)
     * 建议由 XXL-Job 每分钟调度一次
     */
    public void flushCompletedWindows() {
        long now = Instant.now().getEpochSecond();
        int flushed = 0;
        int failed = 0;

        for (Map.Entry<String, AtomicReference<BigDecimal>> entry
                : window.entrySet()) {
            String windowKey = entry.getKey();
            WindowMeta meta = windowMeta.get(windowKey);
            if (meta == null) {
                continue;
            }

            boolean windowClosed = (meta.windowStart + WINDOW_SECONDS) <= now;
            if (!windowClosed) {
                continue;
            }

            BigDecimal totalUsage = entry.getValue().get()
                    .setScale(6, RoundingMode.HALF_UP);

            // 落库幂等键: 保证同一窗口重复落库时是 UPSERT 而非累加
            String persistKey = windowKey;
            try {
                repository.upsertMeteringRecord(
                        persistKey, meta.resourceId, meta.tenantId,
                        meta.metricCode, meta.windowStart, totalUsage);

                window.remove(windowKey);
                windowMeta.remove(windowKey);
                flushed++;

                log.info("[Metering] 窗口落库成功, windowKey={}, "
                                + "resourceId={}, metricCode={}, totalUsage={}",
                        windowKey, meta.resourceId, meta.metricCode,
                        totalUsage.toPlainString());
            } catch (Exception e) {
                failed++;
                // 落库失败不清理内存窗口, 保留数据等待下次调度重试,
                // 避免用量数据丢失 (宁可重复统计也不能少统计)
                log.error("[Metering] 窗口落库失败, 保留内存等待重试, "
                        + "windowKey={}", windowKey, e);
            }
        }

        log.info("[Metering] 本轮定时落库完成, 成功={}, 失败={}, "
                + "剩余待落库窗口数={}", flushed, failed, window.size());
    }

    /** 窗口元信息 */
    private static final class WindowMeta {
        final String resourceId;
        final String tenantId;
        final String metricCode;
        final long windowStart;

        WindowMeta(String resourceId, String tenantId,
                   String metricCode, long windowStart) {
            this.resourceId = resourceId;
            this.tenantId = tenantId;
            this.metricCode = metricCode;
            this.windowStart = windowStart;
        }
    }
}

/**
 * 计量记录存储接口
 * persistKey 作为 UNIQUE KEY, 落库使用 INSERT ... ON DUPLICATE KEY UPDATE
 */
interface UsageMeteringRepository {
    void upsertMeteringRecord(String persistKey, String resourceId,
                               String tenantId, String metricCode,
                               long windowStart, BigDecimal totalUsage);
}
```

```java
    private static final Logger log =
            LoggerFactory.getLogger(UsagePricingBillingService.class);

    private final PriceConfigRepository priceConfigRepository;
    private final BillingFlowRepository billingFlowRepository;

    public UsagePricingBillingService(PriceConfigRepository priceConfigRepository,
                                       BillingFlowRepository billingFlowRepository) {
        this.priceConfigRepository = priceConfigRepository;

    /**
     * 对一条计量记录执行定价并生成出账流水
     *
     * @param record 计量聚合记录 (来自 9.1.3 落库结果)
     * @return 出账流水, 若已存在 (重复调用) 则返回历史流水而不重复计费
     */
    public BillingFlowRecord priceAndBill(MeteringRecord record) {
        String flowIdempotencyKey = "billflow:" + record.getResourceId()
                + ":" + record.getMetricCode() + ":" + record.getWindowStart();

        // 1. 幂等前置检查, 出账流水表以 idempotencyKey 建唯一索引
        BillingFlowRecord existing =
                billingFlowRepository.findByIdempotencyKey(flowIdempotencyKey);
        if (existing != null) {
            log.info("[Pricing] 出账流水已存在, 跳过重复计费, key={}",
                    flowIdempotencyKey);
            return existing;
        }

        // 2. 查询单价配置, 配置缺失属于业务配置错误, 不重试, 需人工介入
        PriceConfig priceConfig = priceConfigRepository.findByMetricCode(
                record.getTenantId(), record.getMetricCode());
        if (priceConfig == null) {
            log.error("[Pricing] 未找到计费单价配置, tenantId={}, metricCode={}",
                    record.getTenantId(), record.getMetricCode());
            throw new PriceConfigNotFoundException(
                    "price config not found for metricCode="
                            + record.getMetricCode());
        }

        // 3. 复用第 4.5 节按量计费策略进行金额计算
        BillingContext context = new BillingContext(
                null,
                Instant.ofEpochSecond(record.getWindowStart()),
                Instant.ofEpochSecond(record.getWindowStart() + 60),
                new ResourceSpec(0, 0, 0, priceConfig.getUnitPrice()),
                record.getTotalUsage(),
                priceConfig.getDiscountInfo(),
                "USAGE_BASED",
                java.util.Map.of());

        UsageBasedStrategy strategy = new UsageBasedStrategy(
                priceConfig.getMinimumCharge(), priceConfig.getMaximumCharge());

        ChargeResult chargeResult;
        try {
            chargeResult = strategy.calculate(context);
        } catch (ArithmeticException e) {
            // 金额计算异常 (如除零、精度溢出), 记录详细上下文便于排查
            log.error("[Pricing] 定价计算异常, resourceId={}, usage={}, "
                            + "unitPrice={}", record.getResourceId(),
                    record.getTotalUsage(), priceConfig.getUnitPrice(), e);
            throw new PricingCalculationException(
                    "pricing calculation failed for resourceId="
                            + record.getResourceId(), e);
        }

        // 4. 落地出账流水 (UPSERT, 以 flowIdempotencyKey 防重)
        BillingFlowRecord flow = new BillingFlowRecord(
                flowIdempotencyKey, record.getResourceId(),
                record.getTenantId(), record.getMetricCode(),
                chargeResult.getFinalAmount(), chargeResult.getOriginalAmount(),
                chargeResult.getDiscountAmount(), Instant.now());

        try {
            billingFlowRepository.insertIgnoreDuplicate(flow);
        } catch (DuplicateFlowException e) {
            // 并发场景下两个线程同时通过了前置检查, 数据库唯一索引兜底拦截
            log.warn("[Pricing] 并发写入冲突, 已存在同幂等键流水, key={}",
                    flowIdempotencyKey);
            return billingFlowRepository.findByIdempotencyKey(flowIdempotencyKey);
        }

        log.info("[Pricing] 出账流水生成成功, resourceId={}, metricCode={}, "
                        + "usage={}, finalAmount={}", record.getResourceId(),
                record.getMetricCode(), record.getTotalUsage().toPlainString(),
                chargeResult.getFinalAmount().toPlainString());

        return flow;
    }
}
```

#### 9.1.5 余额扣费（分布式锁 + 本地事务表保幂等）

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.time.Duration;
import java.time.Instant;
import java.util.concurrent.TimeUnit;

/**
 * 余额扣费服务
 *
 * 设计模式: 分布式锁 + 本地事务表 (幂等消费记录表)
 * - 分布式锁 (Redis SET NX PX) 防止同一租户账户被并发扣费导致余额超扣
 * - 幂等消费记录表 (deduction_record) 以 flowIdempotencyKey 为唯一键,
 *   保证同一笔出账流水最多触发一次真实扣费, 即使扣费服务被重复调用
 * - 扣费与余额变更在同一本地事务中提交, 保证"扣费记录"与"余额扣减"强一致
 *
 * 失败处理:
 * - 余额不足: 转为"欠费"状态, 不阻塞出账流程, 由账户系统触发降级/停服
 * - 系统异常 (DB 超时等): 记录失败流水, 加入延迟重试队列, 指数退避重试
 *   (复用第 7.3 节 CompensationService 的退避算法)
 */
public class BalanceDeductionService {

    private static final Logger log =
            LoggerFactory.getLogger(BalanceDeductionService.class);

    /** 分布式锁等待获取的最大时间 */
    private static final long LOCK_WAIT_MS = 3000L;

    /** 分布式锁自动释放时间, 需大于单次扣费事务的最大耗时 */
    private static final long LOCK_LEASE_MS = 5000L;

    private final DistributedLock distributedLock;
    private final DeductionRecordRepository deductionRecordRepository;
    private final AccountBalanceRepository accountBalanceRepository;
    private final RetryQueuePublisher retryQueuePublisher;

    public BalanceDeductionService(DistributedLock distributedLock,
                                    DeductionRecordRepository deductionRecordRepository,
                                    AccountBalanceRepository accountBalanceRepository,
                                    RetryQueuePublisher retryQueuePublisher) {
        this.distributedLock = distributedLock;
        this.deductionRecordRepository = deductionRecordRepository;
        this.accountBalanceRepository = accountBalanceRepository;
        this.retryQueuePublisher = retryQueuePublisher;
    }

    /**
     * 对一笔出账流水执行扣费
     *
     * @param flow 出账流水 (来自 9.1.4)
     * @return 扣费结果
     */
    public DeductionResult deduct(BillingFlowRecord flow) {
        // 1. 幂等前置检查: 该笔流水是否已完成扣费
        DeductionRecord existing = deductionRecordRepository
                .findByFlowKey(flow.getIdempotencyKey());
        if (existing != null) {
            log.info("[Deduction] 扣费记录已存在, 跳过重复扣费, flowKey={}, "
                            + "status={}", flow.getIdempotencyKey(),
                    existing.getStatus());
            return DeductionResult.fromExisting(existing);
        }

        String lockKey = "account:lock:" + flow.getTenantId();
        boolean locked = false;
        try {
            locked = distributedLock.tryLock(lockKey, LOCK_WAIT_MS, LOCK_LEASE_MS,
                    TimeUnit.MILLISECONDS);
            if (!locked) {
                log.warn("[Deduction] 获取账户分布式锁超时, 转入重试队列, "
                        + "tenantId={}, flowKey={}", flow.getTenantId(),
                        flow.getIdempotencyKey());
                retryQueuePublisher.publishDelayed(flow, Duration.ofSeconds(5));
                return DeductionResult.pendingRetry(flow.getIdempotencyKey());
            }

            return doDeductWithLock(flow);

        } catch (Exception e) {
            log.error("[Deduction] 扣费流程发生未预期异常, flowKey={}",
                    flow.getIdempotencyKey(), e);
            // 系统性异常, 记录失败并转入指数退避重试队列, 而非直接吞掉异常
            retryQueuePublisher.publishDelayed(flow, Duration.ofSeconds(10));
            return DeductionResult.pendingRetry(flow.getIdempotencyKey());
        } finally {
            if (locked) {
                distributedLock.unlock(lockKey);
            }
        }
    }

    /**
     * 持锁状态下执行实际扣费 (数据库本地事务)
     * 事务边界: 查询余额 → 判断是否充足 → 扣减余额 → 写入幂等消费记录
     */
    private DeductionResult doDeductWithLock(BillingFlowRecord flow) {
        // 双重检查: 持锁后再次确认幂等记录不存在, 防止锁等待期间已被其他请求处理
        DeductionRecord doubleCheck = deductionRecordRepository
                .findByFlowKey(flow.getIdempotencyKey());
        if (doubleCheck != null) {
            log.info("[Deduction] 持锁后二次检查发现已扣费, flowKey={}",
                    flow.getIdempotencyKey());
            return DeductionResult.fromExisting(doubleCheck);
        }

        BigDecimal balance = accountBalanceRepository
                .getBalance(flow.getTenantId());
        BigDecimal amount = flow.getFinalAmount();

        if (balance.compareTo(amount) < 0) {
            // 余额不足: 记录为 INSUFFICIENT 状态, 不抛异常, 属于正常业务分支
            DeductionRecord insufficientRecord = new DeductionRecord(
                    flow.getIdempotencyKey(), flow.getTenantId(), amount,
                    DeductionStatus.INSUFFICIENT_BALANCE, Instant.now());
            deductionRecordRepository.insertIgnoreDuplicate(insufficientRecord);

            log.warn("[Deduction] 余额不足, tenantId={}, balance={}, "
                            + "required={}, flowKey={}", flow.getTenantId(),
                    balance.toPlainString(), amount.toPlainString(),
                    flow.getIdempotencyKey());

            return DeductionResult.insufficientBalance(flow.getIdempotencyKey());
        }

        try {
            // 原子扣减: UPDATE balance = balance - amount WHERE balance >= amount
            boolean deducted = accountBalanceRepository
                    .deductBalance(flow.getTenantId(), amount);
            if (!deducted) {
                // 乐观锁/条件更新失败 (并发场景下余额被其他事务先行扣减)
                log.warn("[Deduction] 原子扣减失败(条件不满足), 转入重试, "
                        + "flowKey={}", flow.getIdempotencyKey());
                retryQueuePublisher.publishDelayed(flow, Duration.ofSeconds(3));
                return DeductionResult.pendingRetry(flow.getIdempotencyKey());
            }

            DeductionRecord successRecord = new DeductionRecord(
                    flow.getIdempotencyKey(), flow.getTenantId(), amount,
                    DeductionStatus.SUCCESS, Instant.now());
            deductionRecordRepository.insertIgnoreDuplicate(successRecord);

            log.info("[Deduction] 扣费成功, tenantId={}, amount={}, "
                            + "flowKey={}", flow.getTenantId(),
                    amount.toPlainString(), flow.getIdempotencyKey());

            return DeductionResult.success(flow.getIdempotencyKey());

        } catch (DuplicateFlowException e) {
            // 唯一索引兜底: 并发写入冲突, 说明已有其他线程成功写入幂等记录
            log.warn("[Deduction] 幂等记录并发写入冲突, flowKey={}",
                    flow.getIdempotencyKey());
            return DeductionResult.fromExisting(
                    deductionRecordRepository.findByFlowKey(
                            flow.getIdempotencyKey()));
        } catch (Exception e) {
            log.error("[Deduction] 扣减余额时发生异常, tenantId={}, "
                    + "flowKey={}", flow.getTenantId(),
                    flow.getIdempotencyKey(), e);
            retryQueuePublisher.publishDelayed(flow, Duration.ofSeconds(10));
            return DeductionResult.pendingRetry(flow.getIdempotencyKey());
        }
    }
}
```

#### 9.2.1 链路概览


包年包月（Subscription）与按量计费的核心差异在于：计费动作由**时间驱动**
（到期即触发），而非**事件驱动**，因此需要一个可靠的**定时调度 + 幂等扣费**
机制，并妥善处理续费失败后的宽限期与资源回收。

#### 9.2.2 订购下单与首期扣费

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.time.Instant;
import java.time.temporal.ChronoUnit;
import java.util.UUID;

/**
 * 包年包月订购单
 *
 * 设计模式: 状态机模式 (State Machine)
 * 状态流转: PENDING_PAYMENT → ACTIVE → (RENEWING) → EXPIRED / CANCELLED
 */
public class Subscription {

    private final String subscriptionId;
    private final String tenantId;
    private final String productCode;
    private final String periodUnit;   // MONTH / YEAR
    private final int periodCount;     // 购买周期数, 如 3 个月
    private final BigDecimal periodPrice; // 单周期价格
    private SubscriptionStatus status;
    private Instant currentPeriodStart;
    private Instant currentPeriodEnd;
    private boolean autoRenew;
    private int consecutiveRenewalFailures;

    public Subscription(String subscriptionId, String tenantId,
                         String productCode, String periodUnit,
                         int periodCount, BigDecimal periodPrice,
                         boolean autoRenew) {
        this.subscriptionId = subscriptionId;
        this.tenantId = tenantId;
        this.productCode = productCode;
        this.periodUnit = periodUnit;
        this.periodCount = periodCount;
        this.periodPrice = periodPrice;
        this.autoRenew = autoRenew;
        this.status = SubscriptionStatus.PENDING_PAYMENT;
        this.consecutiveRenewalFailures = 0;
    }

    public void activate(Instant start) {
        this.currentPeriodStart = start;
        this.currentPeriodEnd = calculatePeriodEnd(start);
        this.status = SubscriptionStatus.ACTIVE;
    }

    private Instant calculatePeriodEnd(Instant start) {
        ChronoUnit unit = "YEAR".equals(periodUnit)
                ? ChronoUnit.YEARS : ChronoUnit.MONTHS;
        return start.atZone(java.time.ZoneId.of("Asia/Shanghai"))
                .plus(periodCount, unit)
                .toInstant();
    }

    public void rollToNextPeriod() {
        this.currentPeriodStart = this.currentPeriodEnd;
        this.currentPeriodEnd = calculatePeriodEnd(this.currentPeriodStart);
        this.consecutiveRenewalFailures = 0;
    }

    public void markExpired() { this.status = SubscriptionStatus.EXPIRED; }
    public void markCancelled() { this.status = SubscriptionStatus.CANCELLED; }
    public void incrementFailure() { this.consecutiveRenewalFailures++; }

    // ---- Getters ----
    public String getSubscriptionId() { return subscriptionId; }
    public String getTenantId() { return tenantId; }
    public String getProductCode() { return productCode; }
    public BigDecimal getPeriodPrice() { return periodPrice; }
    public SubscriptionStatus getStatus() { return status; }
    public void setStatus(SubscriptionStatus status) { this.status = status; }
    public Instant getCurrentPeriodStart() { return currentPeriodStart; }
    public Instant getCurrentPeriodEnd() { return currentPeriodEnd; }
    public boolean isAutoRenew() { return autoRenew; }
    public void setAutoRenew(boolean autoRenew) { this.autoRenew = autoRenew; }
    public int getConsecutiveRenewalFailures() {
        return consecutiveRenewalFailures;
    }
}

enum SubscriptionStatus {
    PENDING_PAYMENT, ACTIVE, GRACE_PERIOD, EXPIRED, CANCELLED
}

/**
 * 订购服务
 *
 * 幂等设计: 下单接口要求调用方传入 requestId (通常为前端生成的幂等键),
 * 与订购单表的唯一索引绑定, 防止用户重复点击"立即购买"产生多笔订购单
 */
public class SubscriptionOrderService {

    private static final Logger log =
            LoggerFactory.getLogger(SubscriptionOrderService.class);

    private final SubscriptionRepository subscriptionRepository;
    private final BalanceDeductionService deductionService;
    private final BillingFlowRepository billingFlowRepository;

    public SubscriptionOrderService(SubscriptionRepository subscriptionRepository,
                                     BalanceDeductionService deductionService,
                                     BillingFlowRepository billingFlowRepository) {
        this.subscriptionRepository = subscriptionRepository;
        this.deductionService = deductionService;
        this.billingFlowRepository = billingFlowRepository;
    }

    /**
     * 创建订购单并完成首期扣费
     *
     * @param requestId 幂等请求ID (来自调用方, 如前端下单按钮生成的 UUID)
     */
    public Subscription subscribe(String requestId, String tenantId,
                                   String productCode, String periodUnit,
                                   int periodCount, BigDecimal periodPrice,
                                   boolean autoRenew) {
        // 1. 幂等检查: 同一 requestId 已存在订购单则直接返回, 不重复下单
        Subscription existing =
                subscriptionRepository.findByRequestId(requestId);
        if (existing != null) {
            log.info("[Subscribe] 检测到重复下单请求, 返回已有订购单, "
                    + "requestId={}, subscriptionId={}", requestId,
                    existing.getSubscriptionId());
            return existing;
        }

        Subscription subscription = new Subscription(
                UUID.randomUUID().toString(), tenantId, productCode,
                periodUnit, periodCount, periodPrice, autoRenew);

        try {
            subscriptionRepository.insertWithRequestId(requestId, subscription);
        } catch (DuplicateFlowException e) {
            // 并发重复请求, 数据库唯一索引兜底
            log.warn("[Subscribe] 并发下单冲突, requestId={}", requestId);
            return subscriptionRepository.findByRequestId(requestId);
        }

        // 2. 首期扣费, 复用案例一的扣费服务, 出账流水键 = 订购单ID+首期标识
        BillingFlowRecord firstPeriodFlow = new BillingFlowRecord(
                "subscription:" + subscription.getSubscriptionId() + ":period:0",
                subscription.getSubscriptionId(), tenantId, "SUBSCRIPTION_FEE",
                periodPrice, periodPrice, BigDecimal.ZERO, Instant.now());

        try {
            billingFlowRepository.insertIgnoreDuplicate(firstPeriodFlow);
            DeductionResult deductionResult = deductionService.deduct(firstPeriodFlow);

            if (deductionResult.getStatus() == DeductionStatus.SUCCESS) {
                subscription.activate(Instant.now());
                log.info("[Subscribe] 首期扣费成功, 订购单已激活, "
                        + "subscriptionId={}", subscription.getSubscriptionId());
            } else if (deductionResult.getStatus()
                    == DeductionStatus.INSUFFICIENT_BALANCE) {
                subscription.setStatus(SubscriptionStatus.PENDING_PAYMENT);
                log.warn("[Subscribe] 首期扣费余额不足, 订购单保持待支付, "
                        + "subscriptionId={}", subscription.getSubscriptionId());
            } else {
                // 扣费系统异常已进入重试队列, 订购单保持待支付, 等待异步回调激活
                log.warn("[Subscribe] 首期扣费转入异步重试, subscriptionId={}",
                        subscription.getSubscriptionId());
            }
        } catch (DuplicateFlowException e) {
            log.warn("[Subscribe] 首期出账流水重复写入, subscriptionId={}",
                    subscription.getSubscriptionId());
        }

        subscriptionRepository.update(subscription);
        return subscription;
    }
}

interface SubscriptionRepository {
    Subscription findByRequestId(String requestId);
    void insertWithRequestId(String requestId, Subscription subscription)
            throws DuplicateFlowException;
    void update(Subscription subscription);
    java.util.List<Subscription> findDueForRenewal(Instant before);
}
```

#### 9.2.3 周期扣费与自动续费（定时调度 + 幂等）

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.time.Duration;
import java.time.Instant;
import java.util.List;

/**
 * 周期性续费调度服务
 *
 * 调度方式: 分布式调度框架 (XXL-Job), 建议每小时执行一次扫描,
 * 提前 {@code RENEWAL_LEAD_HOURS} 小时预生成续费扣费, 避免到期瞬间因
 * 扣费系统抖动导致服务中断。
 *
 * 幂等设计:
 * - 扫描到的每个订购单以 subscriptionId + currentPeriodEnd 组合
 *   作为本周期的续费幂等键, 保证同一周期只会被扣费一次
 * - 任务本身通过分布式锁保证同一时刻只有一个调度实例在跑批,
 *   防止多实例部署下重复扫描
 */
public class SubscriptionRenewalScheduler {

    private static final Logger log =
            LoggerFactory.getLogger(SubscriptionRenewalScheduler.class);

    /** 提前续费的时间窗口 */
    private static final int RENEWAL_LEAD_HOURS = 2;

    /** 连续续费失败达到该次数后进入宽限期而非直接失败 */
    private static final int MAX_RENEWAL_RETRY = 3;

    private final SubscriptionRepository subscriptionRepository;
    private final BalanceDeductionService deductionService;
    private final BillingFlowRepository billingFlowRepository;
    private final DistributedLock distributedLock;
    private final SubscriptionExpiryHandler expiryHandler;

    public SubscriptionRenewalScheduler(
            SubscriptionRepository subscriptionRepository,
            BalanceDeductionService deductionService,
            BillingFlowRepository billingFlowRepository,
            DistributedLock distributedLock,
            SubscriptionExpiryHandler expiryHandler) {
        this.subscriptionRepository = subscriptionRepository;
        this.deductionService = deductionService;
        this.billingFlowRepository = billingFlowRepository;
        this.distributedLock = distributedLock;
        this.expiryHandler = expiryHandler;
    }

    /**
     * 定时任务入口: 扫描即将到期且开启自动续费的订购单, 执行续费扣费
     */
    public void scanAndRenew() {
        String schedulerLockKey = "scheduler:subscription:renewal";
        boolean locked = distributedLock.tryLock(
                schedulerLockKey, 1000L, 10 * 60 * 1000L,
                java.util.concurrent.TimeUnit.MILLISECONDS);
        if (!locked) {
            log.info("[Renewal] 未获取到调度锁, 跳过本轮扫描 "
                    + "(其他实例正在执行)");
            return;
        }

        try {
            Instant scanBefore = Instant.now()
                    .plus(Duration.ofHours(RENEWAL_LEAD_HOURS));
            List<Subscription> dueList =
                    subscriptionRepository.findDueForRenewal(scanBefore);

            log.info("[Renewal] 本轮扫描到待续费订购单 {} 个", dueList.size());

            int success = 0;
            int insufficient = 0;
            int failed = 0;

            for (Subscription subscription : dueList) {
                try {
                    RenewalOutcome outcome = renewOne(subscription);
                    switch (outcome) {
                        case SUCCESS -> success++;
                        case INSUFFICIENT_BALANCE -> insufficient++;
                        default -> failed++;
                    }
                } catch (Exception e) {
                    failed++;
                    log.error("[Renewal] 处理单个订购单续费时异常, "
                            + "subscriptionId={}",
                            subscription.getSubscriptionId(), e);
                    // 单个订购单异常不能影响整批处理, 继续处理下一个
                }
            }

            log.info("[Renewal] 本轮续费完成: 成功={}, 余额不足={}, 失败={}",
                    success, insufficient, failed);

        } finally {
            distributedLock.unlock(schedulerLockKey);
        }
    }

    /**
     * 处理单个订购单的续费
     */
    private RenewalOutcome renewOne(Subscription subscription) {
        if (!subscription.isAutoRenew()
                || subscription.getStatus() != SubscriptionStatus.ACTIVE) {
            return RenewalOutcome.SKIPPED;
        }

        // 续费幂等键: 订购单ID + 当前周期结束时间, 保证同一周期只续费一次
        String renewalFlowKey = "subscription:"
                + subscription.getSubscriptionId() + ":renewal:"
                + subscription.getCurrentPeriodEnd().getEpochSecond();

        BillingFlowRecord existingFlow =
                billingFlowRepository.findByIdempotencyKey(renewalFlowKey);
        if (existingFlow != null) {
            log.info("[Renewal] 该周期续费流水已存在, 跳过, key={}",
                    renewalFlowKey);
            return RenewalOutcome.SUCCESS;
        }

        BillingFlowRecord renewalFlow = new BillingFlowRecord(
                renewalFlowKey, subscription.getSubscriptionId(),
                subscription.getTenantId(), "SUBSCRIPTION_RENEWAL",
                subscription.getPeriodPrice(), subscription.getPeriodPrice(),
                BigDecimal.ZERO, Instant.now());

        try {
            billingFlowRepository.insertIgnoreDuplicate(renewalFlow);
        } catch (DuplicateFlowException e) {
            log.warn("[Renewal] 续费流水并发写入冲突, key={}", renewalFlowKey);
            return RenewalOutcome.SUCCESS;
        }

        DeductionResult result = deductionService.deduct(renewalFlow);

        switch (result.getStatus()) {
            case SUCCESS -> {
                subscription.rollToNextPeriod();
                subscriptionRepository.update(subscription);
                log.info("[Renewal] 续费成功, subscriptionId={}, "
                        + "新周期至={}", subscription.getSubscriptionId(),
                        subscription.getCurrentPeriodEnd());
                return RenewalOutcome.SUCCESS;
            }
            case INSUFFICIENT_BALANCE -> {
                subscription.incrementFailure();
                handleRenewalFailure(subscription);
                return RenewalOutcome.INSUFFICIENT_BALANCE;
            }
            default -> {
                subscription.incrementFailure();
                handleRenewalFailure(subscription);
                return RenewalOutcome.FAILED;
            }
        }
    }

    /**
     * 续费失败处理: 达到最大重试次数前进入宽限期, 超过后交给到期处理器
     */
    private void handleRenewalFailure(Subscription subscription) {
        if (subscription.getConsecutiveRenewalFailures() >= MAX_RENEWAL_RETRY) {
            log.warn("[Renewal] 连续续费失败达到上限({}), 转入到期处理, "
                            + "subscriptionId={}", MAX_RENEWAL_RETRY,
                    subscription.getSubscriptionId());
            expiryHandler.handleExpiry(subscription);
        } else {
            subscription.setStatus(SubscriptionStatus.GRACE_PERIOD);
            subscriptionRepository.update(subscription);
            log.warn("[Renewal] 续费失败, 进入宽限期, subscriptionId={}, "
                            + "失败次数={}", subscription.getSubscriptionId(),
                    subscription.getConsecutiveRenewalFailures());
        }
        subscriptionRepository.update(subscription);
    }

    private enum RenewalOutcome {
        SUCCESS, INSUFFICIENT_BALANCE, FAILED, SKIPPED
    }
}
```

#### 9.2.4 到期处理（资源降级/回收）

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.time.Instant;

/**
 * 订购到期处理器
 *
 * 设计模式: 责任链模式 (Chain of Responsibility)
 * 到期后依次执行: 状态置为 EXPIRED → 通知资源侧降级/回收 → 记录审计日志
 *
 * 幂等保证: 处理前检查订购单状态, 若已是 EXPIRED 则直接跳过,
 * 防止调度重复触发导致重复下发资源回收指令
 */
public class SubscriptionExpiryHandler {

    private static final Logger log =
            LoggerFactory.getLogger(SubscriptionExpiryHandler.class);

    private final SubscriptionRepository subscriptionRepository;
    private final ResourceLifecycleClient resourceLifecycleClient;
    private final ExpiryAuditLogRepository auditLogRepository;

    public SubscriptionExpiryHandler(
            SubscriptionRepository subscriptionRepository,
            ResourceLifecycleClient resourceLifecycleClient,
            ExpiryAuditLogRepository auditLogRepository) {
        this.subscriptionRepository = subscriptionRepository;
        this.resourceLifecycleClient = resourceLifecycleClient;
        this.auditLogRepository = auditLogRepository;
    }

    /**
     * 处理订购单到期
     */
    public void handleExpiry(Subscription subscription) {
        if (subscription.getStatus() == SubscriptionStatus.EXPIRED) {
            log.info("[Expiry] 订购单已是到期状态, 跳过重复处理, "
                    + "subscriptionId={}", subscription.getSubscriptionId());
            return;
        }

        log.warn("[Expiry] 订购单到期, 开始降级/回收资源, subscriptionId={}, "
                + "tenantId={}", subscription.getSubscriptionId(),
                subscription.getTenantId());

        subscription.markExpired();
        subscriptionRepository.update(subscription);

        try {
            // 通知资源侧执行降级 (先降级而非直接删除, 保留数据保护窗口期)
            resourceLifecycleClient.degrade(subscription.getSubscriptionId());

            auditLogRepository.record(new ExpiryAuditLog(
                    subscription.getSubscriptionId(), subscription.getTenantId(),
                    "DEGRADED", Instant.now(), null));

            log.info("[Expiry] 资源降级指令下发成功, subscriptionId={}",
                    subscription.getSubscriptionId());

        } catch (ResourceLifecycleException e) {
            // 资源侧调用失败: 记录失败审计, 交由定时补偿任务重试
            // (复用第 7.3 节 CompensationService 指数退避重试思路)
            log.error("[Expiry] 资源降级指令下发失败, 等待补偿重试, "
                    + "subscriptionId={}", subscription.getSubscriptionId(), e);

            auditLogRepository.record(new ExpiryAuditLog(
                    subscription.getSubscriptionId(), subscription.getTenantId(),
                    "DEGRADE_FAILED", Instant.now(), e.getMessage()));
        }
    }
}

/** 到期审计日志 */
class ExpiryAuditLog {
    private final String subscriptionId;
    private final String tenantId;
    private final String action;
    private final Instant occurredAt;
    private final String errorMessage;

    ExpiryAuditLog(String subscriptionId, String tenantId, String action,
                   Instant occurredAt, String errorMessage) {
        this.subscriptionId = subscriptionId;
        this.tenantId = tenantId;
        this.action = action;
        this.occurredAt = occurredAt;
        this.errorMessage = errorMessage;
    }

    public String getSubscriptionId() { return subscriptionId; }
    public String getTenantId() { return tenantId; }
    public String getAction() { return action; }
    public Instant getOccurredAt() { return occurredAt; }
    public String getErrorMessage() { return errorMessage; }
}

interface ResourceLifecycleClient {
    void degrade(String subscriptionId) throws ResourceLifecycleException;
    void reclaim(String subscriptionId) throws ResourceLifecycleException;
}

class ResourceLifecycleException extends Exception {
    ResourceLifecycleException(String message, Throwable cause) {
        super(message, cause);
    }
}

interface ExpiryAuditLogRepository {
    void record(ExpiryAuditLog log);
}
```

**案例二小结**：包年包月链路的核心是把"时间到期"转化为可靠的**定时扫描 +
幂等续费**，续费幂等键固定绑定"订购单 ID + 当前周期结束时间"，无论调度重复
触发多少次，同一周期只会产生一条续费流水；连续失败超过阈值后自动进入到期
处理，通过责任链方式先降级、后回收，避免对用户资源"一刀切"式立即删除。

### 9.3 案例三：账单生成与出账全链路

#### 9.3.1 链路概览

本案例承接第六章"账单生成"与第五章"折扣叠加计算"，串联出**从多笔计费项流水

#### 9.3.2 计费项聚合

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.Instant;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.stream.Collectors;

/**
 * 计费项聚合服务
 *
 * 职责: 汇总某租户在指定账期内产生的所有出账流水
 * (来自案例一的 BillingFlowRecord、案例二的订购续费流水等), 按资源维度分组,
 * 生成"待生成账单"的计费项列表。
 *
 * 一致性保证: 聚合过程只读取"已完成扣费或已确定金额"的流水
 * (排除 INSUFFICIENT_BALANCE / 重试中的流水), 避免账单金额与实际扣费不符。
 */
public class BillingItemAggregationService {

    private static final Logger log =
            LoggerFactory.getLogger(BillingItemAggregationService.class);

    private final BillingFlowQueryRepository billingFlowQueryRepository;

    public BillingItemAggregationService(
            BillingFlowQueryRepository billingFlowQueryRepository) {
        this.billingFlowQueryRepository = billingFlowQueryRepository;
    }

    /**
     * 聚合指定租户在账期内的计费项
     *
     * @param tenantId    租户ID
     * @param periodStart 账期起始 (含)
     * @param periodEnd   账期截止 (不含)
     * @return 按资源ID分组聚合后的计费项列表
     */
    public List<AggregatedBillingItem> aggregate(String tenantId,
                                                  Instant periodStart,
                                                  Instant periodEnd) {
        List<BillingFlowRecord> flows;
        try {
            flows = billingFlowQueryRepository.findSettledFlows(
                    tenantId, periodStart, periodEnd);
        } catch (Exception e) {
            log.error("[Aggregation] 查询出账流水失败, tenantId={}, "
                    + "period=[{}, {})", tenantId, periodStart, periodEnd, e);
            throw new BillingAggregationException(
                    "failed to query billing flows for tenantId=" + tenantId, e);
        }

        if (flows.isEmpty()) {
            log.info("[Aggregation] 账期内无出账流水, tenantId={}, "
                    + "period=[{}, {})", tenantId, periodStart, periodEnd);
            return List.of();
        }

        // 按 resourceId 分组聚合金额, 保留明细供账单行项目展示
        Map<String, List<BillingFlowRecord>> byResource = flows.stream()
                .collect(Collectors.groupingBy(BillingFlowRecord::getResourceId));

        List<AggregatedBillingItem> items = new ArrayList<>();
        for (Map.Entry<String, List<BillingFlowRecord>> entry
                : byResource.entrySet()) {
            String resourceId = entry.getKey();
            List<BillingFlowRecord> resourceFlows = entry.getValue();

            BigDecimal totalOriginal = resourceFlows.stream()
                    .map(BillingFlowRecord::getOriginalAmount)
                    .reduce(BigDecimal.ZERO, BigDecimal::add)
                    .setScale(2, RoundingMode.HALF_UP);

            BigDecimal totalFinal = resourceFlows.stream()
                    .map(BillingFlowRecord::getFinalAmount)
                    .reduce(BigDecimal.ZERO, BigDecimal::add)
                    .setScale(2, RoundingMode.HALF_UP);

            items.add(new AggregatedBillingItem(
                    resourceId, tenantId, totalOriginal, totalFinal,
                    resourceFlows.size()));
        }

        log.info("[Aggregation] 聚合完成, tenantId={}, 资源数={}, "
                + "流水条数={}", tenantId, items.size(), flows.size());

        return items;
    }
```

#### 9.3.3 优惠抵扣（复用折扣叠加引擎）

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.ArrayList;
import java.util.List;

/**
 * 账单级优惠抵扣服务
 *
 * 在计费项聚合结果的基础上, 应用租户维度的整单优惠(如满减券、账期折扣),
 * 复用第 5.3 节折扣叠加计算中的"最大余额法"分摊策略, 保证:
 * 分摊到各计费项的优惠之和严格等于整单优惠总额 (不会因四舍五入产生误差)。
 */
public class BillDiscountService {

    private static final Logger log =
            LoggerFactory.getLogger(BillDiscountService.class);

    private final CouponRepository couponRepository;

    public BillDiscountService(CouponRepository couponRepository) {
        this.couponRepository = couponRepository;
    }

    /**
     * 对聚合后的计费项列表应用整单优惠
     *
     * @param tenantId 租户ID
     * @param items    聚合后的计费项 (来自 9.3.2)
     * @return 应用优惠后的计费项 (包含每项应分摊的优惠金额)
     */
    public List<DiscountedBillingItem> applyDiscount(
            String tenantId, List<AggregatedBillingItem> items) {
        if (items.isEmpty()) {
            return List.of();
        }

        BigDecimal totalAmount = items.stream()
                .map(AggregatedBillingItem::getTotalFinalAmount)
                .reduce(BigDecimal.ZERO, BigDecimal::add);

        BigDecimal couponDeduction;
        try {
            couponDeduction = couponRepository
                    .calculateApplicableDeduction(tenantId, totalAmount);
        } catch (Exception e) {
            // 优惠计算异常不应阻塞账单生成, 降级为"本期不使用优惠", 并告警
            log.error("[Discount] 优惠计算异常, 降级为无优惠出账, "
                    + "tenantId={}, totalAmount={}", tenantId,
                    totalAmount.toPlainString(), e);
            couponDeduction = BigDecimal.ZERO;
        }

        if (couponDeduction.compareTo(BigDecimal.ZERO) <= 0) {
            return items.stream()
                    .map(item -> new DiscountedBillingItem(
                            item, BigDecimal.ZERO))
                    .toList();
        }

        // 封顶保护: 优惠金额不能超过账单总额, 防止出现负数账单
        if (couponDeduction.compareTo(totalAmount) > 0) {
            log.warn("[Discount] 优惠金额({})超过账单总额({}), 已截断为总额, "
                            + "tenantId={}", couponDeduction, totalAmount,
                    tenantId);
            couponDeduction = totalAmount;
        }

        return allocateByMaxRemainder(items, couponDeduction, totalAmount);
    }

    /**
     * 最大余额法分摊 (Largest Remainder Method)
     * 与第 5.3 节 DiscountCalculator 使用的算法一致:
     * 1. 按各项金额占比计算理论分摊值 (保留高精度小数)
     * 2. 先取整数部分之和, 剩余尾差分配给小数部分最大的若干项
     * 3. 保证所有分摊金额之和精确等于优惠总额
     */
    private List<DiscountedBillingItem> allocateByMaxRemainder(
            List<AggregatedBillingItem> items, BigDecimal couponDeduction,
            BigDecimal totalAmount) {

        List<BigDecimal> rawShares = new ArrayList<>();
        List<BigDecimal> flooredShares = new ArrayList<>();
        BigDecimal flooredSum = BigDecimal.ZERO;

        for (AggregatedBillingItem item : items) {
            BigDecimal ratio = item.getTotalFinalAmount()
                    .divide(totalAmount, 8, RoundingMode.HALF_UP);
            BigDecimal rawShare = couponDeduction.multiply(ratio)
                    .setScale(4, RoundingMode.HALF_UP);
            BigDecimal flooredShare = rawShare.setScale(
                    2, RoundingMode.DOWN);

            rawShares.add(rawShare);
            flooredShares.add(flooredShare);
            flooredSum = flooredSum.add(flooredShare);
        }

        BigDecimal remainder = couponDeduction.subtract(flooredSum);
        int centsToDistribute = remainder
                .movePointRight(2).setScale(0, RoundingMode.HALF_UP).intValue();

        // 按小数部分从大到小排序, 优先把尾差分给小数部分最大的项
        List<Integer> indexOrder = new ArrayList<>();
        for (int i = 0; i < items.size(); i++) {
            indexOrder.add(i);
        }
        indexOrder.sort((a, b) -> {
            BigDecimal fracA = rawShares.get(a).subtract(flooredShares.get(a));
            BigDecimal fracB = rawShares.get(b).subtract(flooredShares.get(b));
            return fracB.compareTo(fracA);
        });

        List<BigDecimal> finalShares = new ArrayList<>(flooredShares);
        for (int i = 0; i < centsToDistribute && i < indexOrder.size(); i++) {
            int idx = indexOrder.get(i);
            finalShares.set(idx, finalShares.get(idx)
                    .add(new BigDecimal("0.01")));
        }

        List<DiscountedBillingItem> result = new ArrayList<>();
        for (int i = 0; i < items.size(); i++) {
            result.add(new DiscountedBillingItem(
                    items.get(i), finalShares.get(i)));
        }

        log.info("[Discount] 优惠分摊完成, 项数={}, 优惠总额={}",
                items.size(), couponDeduction.toPlainString());

        return result;
    }
}

/** 应用优惠后的计费项 */
class DiscountedBillingItem {
    private final AggregatedBillingItem source;
    private final BigDecimal allocatedDiscount;

    DiscountedBillingItem(AggregatedBillingItem source,
                          BigDecimal allocatedDiscount) {
        this.source = source;
        this.allocatedDiscount = allocatedDiscount;
    }

    public AggregatedBillingItem getSource() { return source; }
    public BigDecimal getAllocatedDiscount() { return allocatedDiscount; }

    public BigDecimal getFinalPayable() {
        return source.getTotalFinalAmount()
                .subtract(allocatedDiscount)
                .max(BigDecimal.ZERO);
    }
}

interface CouponRepository {
    /** 计算租户在给定账单总额下可用的优惠券抵扣金额 */
    BigDecimal calculateApplicableDeduction(String tenantId,
                                             BigDecimal totalAmount);
}
```

#### 9.3.4 账单生成（幂等落库）

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.Instant;
import java.util.ArrayList;
import java.util.List;
import java.util.UUID;

/**
 * 账单生成服务
 *
 * 复用第 6.2 节 {@code Bill} / {@code BillLineItem} 数据结构。
 *
 * 幂等设计: 账单以 tenantId + billingPeriod 作为唯一索引,
 * 同一账期重复生成时直接返回已有账单 (支持定时任务重跑/手工补跑场景)。
 */
public class BillGenerationService {

    private static final Logger log =
            LoggerFactory.getLogger(BillGenerationService.class);

    private final BillingItemAggregationService aggregationService;
    private final BillDiscountService discountService;
    private final BillRepository billRepository;

    public BillGenerationService(BillingItemAggregationService aggregationService,
                                  BillDiscountService discountService,
                                  BillRepository billRepository) {
        this.aggregationService = aggregationService;
        this.discountService = discountService;
        this.billRepository = billRepository;
    }

    /**
     * 生成指定租户、指定账期的账单
     *
     * @param tenantId      租户ID
     * @param billingPeriod 账期标识, 如 "2024-05"
     * @param periodStart   账期起始
     * @param periodEnd     账期截止
     * @return 生成的账单 (或已存在的历史账单)
     */
    public Bill generateBill(String tenantId, String billingPeriod,
                              Instant periodStart, Instant periodEnd) {
        // 1. 幂等前置检查
        Bill existing = billRepository.findByPeriod(tenantId, billingPeriod);
        if (existing != null) {
            log.info("[BillGen] 该账期账单已存在, 直接返回, tenantId={}, "
                    + "period={}, billId={}", tenantId, billingPeriod,
                    existing.getBillId());
            return existing;
        }

        List<AggregatedBillingItem> aggregatedItems;
        List<DiscountedBillingItem> discountedItems;
        try {
            aggregatedItems = aggregationService.aggregate(
                    tenantId, periodStart, periodEnd);
            discountedItems = discountService.applyDiscount(
                    tenantId, aggregatedItems);
        } catch (BillingAggregationException e) {
            log.error("[BillGen] 计费项聚合失败, 账单生成中止, tenantId={}, "
                    + "period={}", tenantId, billingPeriod, e);
            throw new BillGenerationException(
                    "aggregate billing items failed, tenantId=" + tenantId, e);
        }

        List<BillLineItem> lineItems = new ArrayList<>();
        BigDecimal totalOriginal = BigDecimal.ZERO;
        BigDecimal totalDiscount = BigDecimal.ZERO;
        BigDecimal totalFinal = BigDecimal.ZERO;

        for (DiscountedBillingItem item : discountedItems) {
            AggregatedBillingItem src = item.getSource();
            BigDecimal finalPayable = item.getFinalPayable();

            lineItems.add(new BillLineItem(
                    src.getResourceId(), "SETTLED",
                    src.getTotalOriginalAmount(),
                    item.getAllocatedDiscount(),
                    finalPayable,
                    String.format("聚合流水%d条, 优惠抵扣%.2f元",
                            src.getFlowCount(),
                            item.getAllocatedDiscount())));

            totalOriginal = totalOriginal.add(src.getTotalOriginalAmount());
            totalDiscount = totalDiscount.add(item.getAllocatedDiscount());
            totalFinal = totalFinal.add(finalPayable);
        }

        Bill bill = new Bill(
                UUID.randomUUID().toString(), tenantId, billingPeriod,
                periodStart, periodEnd,
                totalOriginal.setScale(2, RoundingMode.HALF_UP),
                totalDiscount.setScale(2, RoundingMode.HALF_UP),
                totalFinal.setScale(2, RoundingMode.HALF_UP),
                lineItems, BillStatus.GENERATED, Instant.now());

        try {
            billRepository.insertIgnoreDuplicate(bill);
            log.info("[BillGen] 账单生成成功, tenantId={}, period={}, "
                            + "billId={}, totalFinalAmount={}", tenantId,
                    billingPeriod, bill.getBillId(),
                    bill.getTotalFinalAmount().toPlainString());
            return bill;
        } catch (DuplicateFlowException e) {
            // 并发场景下的兜底: 另一个调度实例已抢先生成该账期账单
            log.warn("[BillGen] 并发生成冲突, 已存在同账期账单, tenantId={}, "
                    + "period={}", tenantId, billingPeriod);
            return billRepository.findByPeriod(tenantId, billingPeriod);
        }
    }
}

interface BillRepository {
    Bill findByPeriod(String tenantId, String billingPeriod);
    void insertIgnoreDuplicate(Bill bill) throws DuplicateFlowException;
    void updateStatus(String billId, BillStatus status);
}

class BillGenerationException extends RuntimeException {
    BillGenerationException(String message, Throwable cause) {
        super(message, cause);
    }
}
```

#### 9.3.5 账单推送（失败重试与死信队列）

```java
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.time.Duration;
import java.time.Instant;

/**
 * 账单推送服务
 *
 * 支持多渠道推送(站内信/邮件/Webhook), 采用责任链 + 重试机制:
 * - 每个渠道推送失败互不影响, 分别记录状态
 * - 单渠道失败按指数退避重试, 超过最大重试次数后写入死信队列, 人工介入
 *
 * 幂等设计: 推送记录以 billId + channel 为唯一键,
 * 保证同一账单对同一渠道最多产生一条"最终态"推送记录, 避免重复打扰用户。
 */
public class BillPushService {

    private static final Logger log =
            LoggerFactory.getLogger(BillPushService.class);

    private static final int MAX_PUSH_RETRY = 3;

    private final BillPushRecordRepository pushRecordRepository;
    private final NotificationClient notificationClient;
    private final DeadLetterQueuePublisher deadLetterQueuePublisher;
    private final BillRepository billRepository;

    public BillPushService(BillPushRecordRepository pushRecordRepository,
                            NotificationClient notificationClient,
                            DeadLetterQueuePublisher deadLetterQueuePublisher,
                            BillRepository billRepository) {
        this.pushRecordRepository = pushRecordRepository;
        this.notificationClient = notificationClient;
        this.deadLetterQueuePublisher = deadLetterQueuePublisher;
        this.billRepository = billRepository;
    }

    /**
     * 推送账单到指定渠道
     */
    public void push(Bill bill, PushChannel channel) {
        String pushKey = bill.getBillId() + ":" + channel.name();

        BillPushRecord existing = pushRecordRepository.findByKey(pushKey);
        if (existing != null && existing.getStatus() == PushStatus.SUCCESS) {
            log.info("[BillPush] 该渠道已推送成功, 跳过重复推送, "
                    + "billId={}, channel={}", bill.getBillId(), channel);
            return;
        }

        int attempt = (existing != null ? existing.getAttemptCount() : 0) + 1;

        try {
            notificationClient.send(channel, bill);

            pushRecordRepository.upsert(new BillPushRecord(
                    pushKey, bill.getBillId(), channel, PushStatus.SUCCESS,
                    attempt, Instant.now(), null));

            billRepository.updateStatus(bill.getBillId(), BillStatus.SENT);

            log.info("[BillPush] 账单推送成功, billId={}, channel={}, "
                    + "attempt={}", bill.getBillId(), channel, attempt);

        } catch (NotificationException e) {
            log.error("[BillPush] 账单推送失败, billId={}, channel={}, "
                    + "attempt={}", bill.getBillId(), channel, attempt, e);

            if (attempt >= MAX_PUSH_RETRY) {
                pushRecordRepository.upsert(new BillPushRecord(
                        pushKey, bill.getBillId(), channel, PushStatus.FAILED,
                        attempt, Instant.now(), e.getMessage()));

                // 超过最大重试次数, 写入死信队列, 转人工/离线渠道处理
                deadLetterQueuePublisher.publish(
                        new BillPushDeadLetter(bill.getBillId(), channel,
                                e.getMessage(), Instant.now()));

                log.error("[BillPush] 达到最大重试次数, 已转入死信队列, "
                        + "billId={}, channel={}", bill.getBillId(), channel);
            } else {
                pushRecordRepository.upsert(new BillPushRecord(
                        pushKey, bill.getBillId(), channel, PushStatus.RETRYING,
                        attempt, Instant.now(), e.getMessage()));

                // 指数退避重试, 复用第 7.3 节退避公式的思路
                long backoffSeconds = (long) Math.pow(2, attempt);
                log.warn("[BillPush] 安排 {} 秒后重试, billId={}, channel={}, "
                        + "attempt={}", backoffSeconds, bill.getBillId(),
                        channel, attempt);
                schedulePushRetry(bill, channel, Duration.ofSeconds(backoffSeconds));
            }
        }
    }

    /**
     * 安排延迟重试 (实际工程中对接延迟消息队列 / 定时任务)
     */
    private void schedulePushRetry(Bill bill, PushChannel channel,
                                    Duration delay) {
        // 示例: 交由延迟队列在 delay 之后重新投递本方法调用
        // delayQueue.publish(new RetryPushTask(bill.getBillId(), channel), delay);
        log.info("[BillPush] 重试任务已登记, billId={}, channel={}, "
                + "delaySeconds={}", bill.getBillId(), channel,
                delay.getSeconds());
    }
}
```

## 十、总结

本文补充的三个全链路案例，分别覆盖了计费系统中最典型的三类业务场景：

| 案例 | 覆盖链路 | 关键幂等点 | 关键异常处理 |
|------|---------|-----------|-------------|
| 按量计费全链路 | 用量上报→计量→定价→出账→扣费 | 用量上报幂等键、扣费流水唯一键 | 计量异常降级、扣费余额不足处理、重复上报去重 |
| 包年包月全链路 | 订购→周期扣费→续费→到期处理 | 续费流水以"订购单+周期结束时间"去重 | 连续续费失败进入宽限期、超限后责任链式降级回收 |
| 账单生成与出账全链路 | 计费项聚合→优惠抵扣→账单生成→账单推送 | 账单以"租户+账期"唯一、推送以"账单+渠道"唯一 | 优惠计算异常降级为无优惠出账、推送失败指数退避重试与死信队列兜底 |

三个案例均遵循本文档第一章确立的设计原则：**事件驱动**串联各环节、
**幂等性**贯穿每一次外部调用与状态写入、**最终一致性**通过重试与补偿机制
兜底，从而在保证计费准确性的前提下，兼顾系统的高可用与可扩展性。

本系统通过分层架构和设计模式的合理运用, 实现了高内聚、低耦合的计费系统。事件溯源保证了数据的完整性和可审计性; 策略模式保证了计费规则的灵活性; WAL + 幂等 + 补偿三位一体保证了系统的高可用性。整套设计可作为通用计费系统的参考架构。
