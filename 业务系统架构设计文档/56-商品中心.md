# 商品中心系统架构设计

## 一、问题背景

### 1.1 业务场景

商品中心是电商交易链路的基石，所有下游业务（搜索、推荐、购物车、订单、库存、物流）都依赖商品数据。一个完整的商品中心需要管理从商品创建、审核、上架到下架的全生命周期，同时提供高性能的查询能力。

信息流、资金流和物流是电商的三个基本要素，其中信息流的核心就是商品信息。商品信息在交易链路（浏览→加购→下单→履约）和供给链路（建品→审核→上架→管理）中都是基础支撑。

### 1.2 核心挑战

| 挑战维度 | 具体问题 |
|---------|---------|
| 数据模型复杂 | 一个商品有基本信息、属性、规格、价格、图片、物流信息等几十个维度 |
| 多层级模型 | SPU/SKU/SSU三级模型，不同系统使用不同层级 |
| 高并发查询 | 商品详情页QPS可达十万级 |
| 数据一致性 | 多个缓存层数据需与DB保持一致 |
| 扩展性 | 新增商品属性不能改表结构 |
| 审核流程 | 商品上架需要人工+规则双重审核 |

### 1.3 SPU/SKU/SSU模型

**SPU（Standard Product Unit）**：标准化产品单元，是商品信息聚合的最小单位，是一组具有共同属性的商品集合。例如"iPhone 15"是一个SPU。

**SKU（Stock Keeping Unit）**：库存量单位，即具体到某个规格的商品。例如"iPhone 15 256G 钛原色"是一个SKU，是库存扣减和物理出库的最小单元。

**SSU（Sales SKU）**：销售单元，在SKU基础上附加销售维度信息（如渠道、区域），是上架售卖的最小单元。

```
SPU: iPhone 15
├── 属性: 品牌=Apple, 系列=iPhone, 操作系统=iOS
├── SKU: iPhone 15 128G 钛原色
│   ├── 属性: 存储=128G, 颜色=钛原色
│   ├── SSU: iPhone 15 128G 钛原色 (北京仓, 自营渠道)
│   └── SSU: iPhone 15 128G 钛原色 (上海仓, 第三方渠道)
├── SKU: iPhone 15 256G 蓝色
│   └── ...
```

```
DRAFT(草稿) ──提交审核──> REVIEWING(审核中) ──审核通过──> APPROVED(已审核)
                               │                           │
                          审核驳回                    手动上架
                               │                           │
                               ▼                           ▼
                          REJECTED(已驳回)            ON_SALE(在售)
                               │                           │

                                                           │
                                                           ▼
                                                      OFF_SALE(已下架)
```

## 三、核心链路设计

### 3.1 商品创建链路

```java
/**
 * 商品创建服务
 *
 * 链路：
 * 1. 参数校验（类目/属性必填校验）
 * 2. 创建SPU
 * 3. 创建SKU列表
 * 4. 写入动态属性值
 * 5. 提交审核
 * 6. 异步同步到搜索引擎
 */
@Service
public class ProductCreateService {

    @Autowired
    private ProductSpuMapper spuMapper;

    @Autowired
    private ProductSkuMapper skuMapper;

    @Autowired
    private ProductAttributeService attrService;

    @Autowired
    private RocketMQTemplate mqTemplate;

    @Transactional(rollbackFor = Exception.class)
    public Long createProduct(CreateProductRequest request) {
        // 1. 参数校验
        validateRequest(request);

        // 2. 校验必填属性
        List<ProductAttribute> requiredAttrs = attrService
            .getRequiredAttrsByCategory(request.getCategoryId());
        for (ProductAttribute attr : requiredAttrs) {
            if (!request.getAttrValues().containsKey(attr.getAttrId())) {
                throw new BizException("缺少必填属性: " + attr.getAttrName());
            }
        }

        // 3. 创建SPU
        ProductSpu spu = new ProductSpu();
        long spuId = idGenerator.nextId();
        spu.setSpuId(spuId);
        spu.setTitle(request.getTitle());
        spu.setSubtitle(request.getSubtitle());
        spu.setCategoryId(request.getCategoryId());
        spu.setBrandId(request.getBrandId());
        spu.setMainImage(request.getMainImage());
        spu.setStatus(ProductStatus.DRAFT.getCode());
        spu.setCreateTime(new Date());
        spu.setUpdateTime(new Date());
        spuMapper.insert(spu);

        // 4. 创建SKU列表
        for (CreateSkuRequest skuReq : request.getSkuList()) {
            ProductSku sku = new ProductSku();
            long skuId = idGenerator.nextId();
            sku.setSkuId(skuId);
            sku.setSpuId(spuId);
            sku.setSkuName(skuReq.getSkuName());
            sku.setSpecAttrs(JSON.toJSONString(skuReq.getSpecAttrs()));
            sku.setBarcode(skuReq.getBarcode());
            sku.setWeight(skuReq.getWeight());
            sku.setStatus(ProductStatus.DRAFT.getCode());
            sku.setCreateTime(new Date());
            sku.setUpdateTime(new Date());
            skuMapper.insert(sku);
        }

        // 5. 写入动态属性值
        for (Map.Entry<Long, String> entry : request.getAttrValues().entrySet()) {
            attrService.saveAttrValue(spuId, entry.getKey(), entry.getValue());
        }

        // 6. 异步同步到搜索引擎
        mqTemplate.asyncSend("product-sync-topic",
            new ProductSyncMessage(spuId, "CREATE"), null);

        return spuId;
    }
}
```

### 3.2 商品审核链路

```java
/**
 * 商品审核服务
 *
 * 审核 = 规则审核 + 人工审核
 * 1. 规则审核：敏感词过滤、属性合规性检查
 * 2. 人工审核：审核员人工确认
 */
@Service
public class ProductReviewService {

    @Autowired
    private SensitiveWordFilter sensitiveWordFilter;

    /**
     * 提交审核
     */
    public void submitReview(Long spuId) {
        ProductSpu spu = spuMapper.selectBySpuId(spuId);
        if (spu.getStatus() != ProductStatus.DRAFT.getCode()
            && spu.getStatus() != ProductStatus.REJECTED.getCode()) {
            throw new BizException("当前状态不允许提交审核");
        }

        // 1. 规则审核：敏感词检查
        if (sensitiveWordFilter.contains(spu.getTitle())) {
            throw new BizException("商品标题包含敏感词");
        }
        if (sensitiveWordFilter.contains(spu.getSubtitle())) {
            throw new BizException("商品副标题包含敏感词");
        }

        // 2. 更新状态为审核中
        spuMapper.updateStatus(spuId, ProductStatus.REVIEWING.getCode());

        // 3. 发送审核任务到审核系统
        ReviewTaskMessage msg = new ReviewTaskMessage();
        msg.setSpuId(spuId);
        msg.setReviewType("PRODUCT_CREATE");
        mqTemplate.send("product-review-topic", msg);
    }

    /**
     * 审核回调
     */
    @Transactional(rollbackFor = Exception.class)
    public void handleReviewResult(ReviewResultMessage msg) {
        if (msg.isApproved()) {
            spuMapper.updateStatus(msg.getSpuId(), ProductStatus.APPROVED.getCode());
        } else {
            spuMapper.updateStatus(msg.getSpuId(), ProductStatus.REJECTED.getCode());
            spuMapper.updateRejectReason(msg.getSpuId(), msg.getRejectReason());
        }
    }
}
```

### 3.3 商品上下架链路

```java
/**
 * 商品上下架服务
 *
 * 上下架操作需要同步更新：
 * 1. 数据库状态
 * 2. Redis缓存
 * 3. 搜索引擎索引
 */
@Service
public class ProductListingService {

    /**
     * 上架
     */
    @Transactional(rollbackFor = Exception.class)
    public void listOn(Long spuId) {
        ProductSpu spu = spuMapper.selectBySpuId(spuId);
        if (spu.getStatus() != ProductStatus.APPROVED.getCode()) {
            throw new BizException("只有已审核的商品才能上架");
        }

        // 1. 更新数据库状态
        spuMapper.updateStatus(spuId, ProductStatus.ON_SALE.getCode());

        // 2. 同步上架所有SKU
        skuMapper.updateStatusBySpu(spuId, ProductStatus.ON_SALE.getCode());

        // 3. 刷新缓存
        refreshCache(spuId);

        // 4. 通知搜索引擎建索引
        mqTemplate.send("product-search-sync-topic",
            new ProductSyncMessage(spuId, "LIST_ON"));
    }

    /**
     * 下架
     */
    @Transactional(rollbackFor = Exception.class)
    public void listOff(Long spuId, String reason) {
        // 1. 更新数据库状态
        spuMapper.updateStatus(spuId, ProductStatus.OFF_SALE.getCode());
        skuMapper.updateStatusBySpu(spuId, ProductStatus.OFF_SALE.getCode());

        // 2. 删除缓存
        String cacheKey = "product:spu:" + spuId;
        redisTemplate.delete(cacheKey);

        // 3. 通知搜索引擎删索引
        mqTemplate.send("product-search-sync-topic",
            new ProductSyncMessage(spuId, "LIST_OFF"));
    }

    /**
     * 刷新商品缓存
     */
    private void refreshCache(Long spuId) {
        ProductSpu spu = spuMapper.selectBySpuId(spuId);
        List<ProductSku> skus = skuMapper.selectBySpuId(spuId);

        ProductCacheDTO cacheDTO = new ProductCacheDTO();
        cacheDTO.setSpu(spu);
        cacheDTO.setSkuList(skus);

        String cacheKey = "product:spu:" + spuId;
        redisTemplate.opsForValue().set(cacheKey,
            JSON.toJSONString(cacheDTO), 30, TimeUnit.MINUTES);
    }
}
```

### 3.4 商品查询：多级缓存

```java
/**
 * 商品查询服务
 *
 * 多级缓存策略：
 * Caffeine(本地缓存, 1秒TTL) → Redis(分布式缓存, 30分钟TTL) → MySQL
 */
@Service
public class ProductQueryService {

    // 本地缓存：极短TTL，防止热点key打爆Redis
    private final Cache<Long, ProductCacheDTO> localCache = Caffeine.newBuilder()
        .maximumSize(10000)
        .expireAfterWrite(1, TimeUnit.SECONDS)
        .build();

    /**
     * 查询商品详情
     */
    public ProductDetailVO getProductDetail(Long spuId) {
        // 1. 本地缓存
        ProductCacheDTO local = localCache.getIfPresent(spuId);
        if (local != null) {
            return convertToVO(local);
        }

        // 2. Redis缓存
        String cacheKey = "product:spu:" + spuId;
        String json = redisTemplate.opsForValue().get(cacheKey);
        if (json != null) {
            ProductCacheDTO redisCache = JSON.parseObject(json, ProductCacheDTO.class);
            localCache.put(spuId, redisCache);
            return convertToVO(redisCache);
        }

        // 3. 查MySQL
        ProductSpu spu = spuMapper.selectBySpuId(spuId);
        if (spu == null) {
            return null;
        }
        List<ProductSku> skus = skuMapper.selectBySpuId(spuId);

        // 4. 回填缓存
        ProductCacheDTO cacheDTO = new ProductCacheDTO();
        cacheDTO.setSpu(spu);
        cacheDTO.setSkuList(skus);
        redisTemplate.opsForValue().set(cacheKey,
            JSON.toJSONString(cacheDTO), 30, TimeUnit.MINUTES);
        localCache.put(spuId, cacheDTO);

        return convertToVO(cacheDTO);
    }

    /**
     * 批量查询SKU信息（购物车场景）
     */
    public List<ProductSku> batchQuerySku(List<Long> skuIds) {
        // 1. 先查缓存，收集未命中的
        List<Long> missedIds = new ArrayList<>();
        Map<Long, ProductSku> result = new HashMap<>();

        for (Long skuId : skuIds) {
            String key = "product:sku:" + skuId;
            String json = redisTemplate.opsForValue().get(key);
            if (json != null) {
                result.put(skuId, JSON.parseObject(json, ProductSku.class));
            } else {
                missedIds.add(skuId);
            }
        }

        // 2. 批量查MySQL
        if (!missedIds.isEmpty()) {
            List<ProductSku> dbResults = skuMapper.batchSelectBySkuIds(missedIds);
            for (ProductSku sku : dbResults) {
                result.put(sku.getSkuId(), sku);
                // 回填缓存
                String key = "product:sku:" + sku.getSkuId();
                redisTemplate.opsForValue().set(key,
                    JSON.toJSONString(sku), 30, TimeUnit.MINUTES);
            }
        }

        return skuIds.stream()
            .map(result::get)
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
    }
}
```

### 3.5 动态属性引擎

**问题**：不同类目的商品有不同的属性（手机有内存/屏幕，衣服有尺码/面料），如果每加一个属性就改表结构，无法维护。

**方案**：元数据驱动——属性定义为元数据，属性值存储在通用表中。

```java
/**
 * 动态属性引擎
 *
 * 设计思路：
 * 1. 属性定义表（元数据）：定义有哪些属性、属性类型、枚举值
 * 2. 属性值表（数据）：存储商品的具体属性值
 * 3. 按类目关联：不同类目有不同的属性集合
 */
@Service
public class ProductAttributeService {

    /**
     * 根据类目获取属性模板
     */
    public List<AttributeVO> getAttrTemplateByCategory(Long categoryId) {
        // 查缓存
        String key = "attr:template:" + categoryId;
        String cached = redisTemplate.opsForValue().get(key);
        if (cached != null) {
            return JSON.parseArray(cached, AttributeVO.class);
        }

        List<ProductAttribute> attrs = attrMapper.selectByCategory(categoryId);
        List<AttributeVO> result = attrs.stream().map(a -> {
            AttributeVO vo = new AttributeVO();
            vo.setAttrId(a.getAttrId());
            vo.setAttrName(a.getAttrName());
            vo.setAttrType(a.getAttrType());
            vo.setRequired(a.getIsRequired() == 1);
            vo.setSearchable(a.getIsSearchable() == 1);
            if (a.getEnumValues() != null) {
                vo.setEnumValues(JSON.parseArray(
                    a.getEnumValues(), String.class));
            }
            return vo;
        }).collect(Collectors.toList());

        redisTemplate.opsForValue().set(key,
            JSON.toJSONString(result), 1, TimeUnit.HOURS);
        return result;
    }

    /**
     * 保存属性值
     */
    public void saveAttrValue(Long spuId, Long attrId, String value) {
        ProductAttributeValue av = new ProductAttributeValue();
        av.setSpuId(spuId);
        av.setAttrId(attrId);
        av.setAttrValue(value);
        attrValueMapper.insert(av);
    }

    /**
     * 按属性筛选商品
     * 转换为SQL: SELECT spu_id FROM product_attribute_value
     *            WHERE attr_id = ? AND attr_value = ?
     */
    public List<Long> filterByAttr(Long attrId, String value) {
        return attrValueMapper.selectSpuIdsByAttr(attrId, value);
    }
}
```

## 四、数据同步到搜索引擎

商品上架后需要同步到搜索引擎（如Elasticsearch），支持搜索和筛选功能。

```java
/**
 * 商品搜索同步消费者
 *
 * 同步策略：
 * 1. 上架 → 建索引
 * 2. 下架 → 删索引
 * 3. 更新 → 更新索引
 */
@Component
@RocketMQMessageListener(topic = "product-search-sync-topic",
    consumerGroup = "product-search-consumer-group")
public class ProductSearchSyncConsumer implements RocketMQListener<ProductSyncMessage> {

    @Autowired
    private RestHighLevelClient esClient;

    @Override
    public void onMessage(ProductSyncMessage msg) {
        switch (msg.getAction()) {
            case "LIST_ON":
                indexProduct(msg.getSpuId());
                break;
            case "LIST_OFF":
                deleteIndex(msg.getSpuId());
                break;
            case "UPDATE":
                updateIndex(msg.getSpuId());
                break;
        }
    }

    /**
     * 建索引
     */
    private void indexProduct(Long spuId) {
        ProductSpu spu = spuMapper.selectBySpuId(spuId);
        List<ProductSku> skus = skuMapper.selectBySpuId(spuId);
        List<ProductAttributeValue> attrValues = attrValueMapper.selectBySpuId(spuId);

        // 构建索引文档
        Map<String, Object> doc = new HashMap<>();
        doc.put("spuId", spu.getSpuId());
        doc.put("title", spu.getTitle());
        doc.put("subtitle", spu.getSubtitle());
        doc.put("categoryId", spu.getCategoryId());
        doc.put("brandId", spu.getBrandId());
        doc.put("mainImage", spu.getMainImage());
        doc.put("status", spu.getStatus());

        // SKU列表
        List<Map<String, Object>> skuList = new ArrayList<>();
        for (ProductSku sku : skus) {
            Map<String, Object> skuMap = new HashMap<>();
            skuMap.put("skuId", sku.getSkuId());
            skuMap.put("skuName", sku.getSkuName());
            skuMap.put("barcode", sku.getBarcode());
            skuMap.put("specAttrs", JSON.parseObject(sku.getSpecAttrs()));
            skuList.add(skuMap);
        }
        doc.put("skus", skuList);

        // 动态属性
        Map<String, String> attrs = new HashMap<>();
        for (ProductAttributeValue av : attrValues) {
            ProductAttribute attr = attrMapper.selectByAttrId(av.getAttrId());
            attrs.put(attr.getAttrName(), av.getAttrValue());
        }
        doc.put("attributes", attrs);

        // 写入ES
        IndexRequest request = new IndexRequest("product_index")
            .id(String.valueOf(spuId))
            .source(doc);
        esClient.index(request, RequestOptions.DEFAULT);
    }
}
```

```java
 * 商品缓存一致性保障

 * 1. 更新DB前先删缓存
 * 2. 更新DB

    redisTemplate.delete(cacheKey);

    spuMapper.updateById(request.toSpu());

    // 3. 延迟双删
    executor.schedule(() -> {
        redisTemplate.delete(cacheKey);
    }, 500, TimeUnit.MILLISECONDS);
}
```

## 六、最佳实践与总结

### 6.1 核心设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 数据模型 | SPU/SKU/SSU三级 | 满足展示、库存、销售不同场景 |
| 属性扩展 | 元数据驱动 | 新增属性不改表结构 |
| 缓存策略 | Caffeine+Redis多级 | 本地缓存挡热点，Redis做分布式 |
| 数据同步 | MQ异步同步ES | 不阻塞主流程 |
| 缓存一致性 | 双删延迟 | 简单有效 |
| 审核流程 | 规则+人工双重 | 合规保障 |

### 6.2 容易踩的坑

1. **属性硬编码**：把属性写成表字段，新增属性就要改表，应该用元数据驱动
2. **缓存不一致**：更新DB后忘记删缓存，或删缓存和更新DB非原子操作
3. **搜索同步延迟**：MQ消息丢失导致ES和DB不一致，需要定时全量同步兜底
4. **批量查询N+1**：购物车场景逐个查SKU，应该用批量查询
5. **状态机不严格**：草稿直接上架跳过审核，需要严格校验状态流转

```java
/**
 * 商品发布Controller
 *
 * 职责：参数校验、幂等Token校验、统一异常处理
 */
@RestController
@RequestMapping("/api/product")
@Slf4j
public class ProductController {

    @Autowired
    private ProductPublishService publishService;

    @Autowired
    private IdempotentService idempotentService;

    /**
     * 发布商品
     *
     * 幂等控制：前端在进入发布页时获取幂等Token，提交时携带。
     * 同一Token多次提交只生效一次，防止网络重试导致重复建品。
     */
    @PostMapping("/publish")
    public Result<Long> publishProduct(
            @RequestBody @Valid PublishProductRequest request,
            @RequestHeader("X-Idempotent-Token") String idempotentToken,
            @RequestHeader("X-Merchant-Id") Long merchantId) {

        log.info("[发布商品] merchantId={}, title={}, idempotentToken={}",
                merchantId, request.getTitle(), idempotentToken);

        // 1. 幂等校验
        boolean acquired = idempotentService.tryAcquire(
                "product:publish:" + idempotentToken, 24, TimeUnit.HOURS);
        if (!acquired) {
            log.warn("[发布商品] 重复请求, idempotentToken={}", idempotentToken);
            throw new BizException("请勿重复提交，商品正在创建中");
        }

        try {
            // 2. 调用发布服务
            Long spuId = publishService.publish(request, merchantId);
            log.info("[发布商品] 成功, merchantId={}, spuId={}", merchantId, spuId);
            return Result.success(spuId);
        } catch (BizException e) {
            // 业务异常，释放幂等锁，允许修改后重新提交
            idempotentService.release("product:publish:" + idempotentToken);
            log.warn("[发布商品] 业务异常, merchantId={}, msg={}",
                    merchantId, e.getMessage());
            throw e;
        } catch (Exception e) {
            idempotentService.release("product:publish:" + idempotentToken);
            log.error("[发布商品] 系统异常, merchantId={}", merchantId, e);
            throw new SystemException("系统繁忙，请稍后重试");
        }
    }
}
```

#### 7.1.3 类目属性校验

```java
/**
 * 类目属性校验器
 *
 * 校验逻辑：
 * 1. 根据类目ID获取该类目要求的所有属性模板
 * 2. 检查必填属性是否都已填写
 * 3. 检查枚举类型属性的值是否在合法范围内
 * 4. 检查数值类型属性的值是否在合理范围内
 */
@Service
@Slf4j
public class CategoryAttrValidator {

    @Autowired
    private ProductAttributeService attrService;

    /**
     * 校验商品属性
     */
    public void validate(Long categoryId, Map<Long, String> attrValues) {
        // 获取类目属性模板
        List<AttributeVO> template = attrService.getAttrTemplateByCategory(categoryId);
        if (template.isEmpty()) {
            log.warn("[属性校验] 类目{}无属性模板", categoryId);
            return;
        }

        for (AttributeVO attr : template) {
            String value = attrValues.get(attr.getAttrId());

            // 必填校验
            if (attr.isRequired() && StringUtils.isBlank(value)) {
                throw new BizException("缺少必填属性: " + attr.getAttrName());
            }

            if (StringUtils.isBlank(value)) {
                continue;
            }

            // 枚举值校验
            if (attr.getAttrType() == 1 && attr.getEnumValues() != null) {
                if (!attr.getEnumValues().contains(value)) {
                    throw new BizException(String.format(
                        "属性[%s]的值[%s]不在合法范围内，可选值: %s",
                        attr.getAttrName(), value, attr.getEnumValues()));
                }
            }

            // 数值类型校验
            if (attr.getAttrType() == 3) {
                try {
                    new BigDecimal(value);
                } catch (NumberFormatException e) {
                    throw new BizException(
                        "属性[" + attr.getAttrName() + "]的值必须是数字");
                }
            }
        }

        log.info("[属性校验] 通过, categoryId={}, attrCount={}",
                categoryId, attrValues.size());
    }
}
```

#### 7.1.4 敏感词检测与内容审核

```java
/**
 * 内容审核服务
 *
 * 审核策略：
 * 1. 敏感词过滤（本地DFA算法 + 远程审核服务双保险）
 * 2. 图片审核（调用内容安全API）
 * 3. 审核结果异步回调
 */
@Service
@Slf4j
public class ContentReviewService {

    @Autowired
    private SensitiveWordFilter sensitiveWordFilter;

    @Autowired
    private ContentSafetyClient contentSafetyClient;

    @Autowired
    private RocketMQTemplate mqTemplate;

    /**
     * 预检：同步敏感词检测 + 异步图片审核
     */
    public ReviewResult preCheck(PublishProductRequest request) {
        // 1. 敏感词检测（标题、副标题、SKU名称）
        List<String> textsToCheck = new ArrayList<>();
        textsToCheck.add(request.getTitle());
        if (StringUtils.isNotBlank(request.getSubtitle())) {
            textsToCheck.add(request.getSubtitle());
        }
        for (PublishSkuRequest sku : request.getSkuList()) {
            textsToCheck.add(sku.getSkuName());
        }

        for (String text : textsToCheck) {
            String matchedWord = sensitiveWordFilter.findFirst(text);
            if (matchedWord != null) {
                log.warn("[内容审核] 敏感词命中, text={}, word={}",
                        text, matchedWord);
                return ReviewResult.reject("包含敏感词: " + matchedWord);
            }
        }

        // 2. 图片安全审核（异步提交，回调处理）
        for (String imageUrl : request.getImageUrls()) {
            try {
                ImageReviewResult imgResult = contentSafetyClient
                        .checkImage(imageUrl)
                        .get(3, TimeUnit.SECONDS);
                if (!imgResult.isPass()) {
                    log.warn("[内容审核] 图片审核不通过, url={}, reason={}",
                            imageUrl, imgResult.getReason());
                    return ReviewResult.reject("图片审核不通过: "
                            + imgResult.getReason());
                }
            } catch (TimeoutException e) {
                log.warn("[内容审核] 图片审核超时, url={}, 转人工审核", imageUrl);
                // 超时转人工，不阻塞发布流程
            } catch (Exception e) {
                log.error("[内容审核] 图片审核异常, url={}", imageUrl, e);
                // 审核服务异常不阻塞，转人工审核兜底
            }
        }

        log.info("[内容审核] 预检通过, title={}", request.getTitle());
        return ReviewResult.pass();
    }
}
```

#### 7.1.5 商品图片上传OSS

```java
/**
 * 图片上传服务
 *
 * 策略：
 * 1. 商家上传图片先到临时空间
 * 2. 商品发布时将图片从临时空间复制到正式空间
 * 3. 生成CDN加速URL返回
 */
@Service
@Slf4j
public class OssImageService {

    @Autowired
    private OssClient ossClient;

    @Value("${oss.bucket.product}")
    private String productBucket;

    @Value("${cdn.domain}")
    private String cdnDomain;

    /**
     * 批量上传商品图片
     */
    public List<String> uploadImages(List<String> tempUrls, Long spuId) {
        List<String> cdnUrls = new ArrayList<>();
        String datePath = LocalDate.now().format(
                DateTimeFormatter.ofPattern("yyyy/MM/dd"));

        for (int i = 0; i < tempUrls.size(); i++) {
            String tempUrl = tempUrls.get(i);
            String fileExt = extractFileExt(tempUrl);
            String objectKey = String.format("product/%s/%d_%d.%s",
                    datePath, spuId, i, fileExt);

            try {
                // 从临时空间复制到正式空间
                ossClient.copyObject(
                        "temp-bucket", extractObjectKey(tempUrl),
                        productBucket, objectKey);

                // 设置图片处理参数（缩略图、水印等）
                ossClient.setObjectAcl(productBucket, objectKey,
                        CannedAccessControlList.PublicRead);

                String cdnUrl = cdnDomain + "/" + objectKey;
                cdnUrls.add(cdnUrl);
                log.info("[图片上传] 成功, tempUrl={}, cdnUrl={}",
                        tempUrl, cdnUrl);
            } catch (Exception e) {
                log.error("[图片上传] 失败, tempUrl={}", tempUrl, e);
                throw new BizException("图片上传失败: " + tempUrl);
            }
        }

        return cdnUrls;
    }

    /**
     * 异步删除临时图片（清理垃圾）
     */
    @Async
    public void cleanupTempImages(List<String> tempUrls) {
        for (String tempUrl : tempUrls) {
            try {
                ossClient.deleteObject("temp-bucket", extractObjectKey(tempUrl));
            } catch (Exception e) {
                log.warn("[图片清理] 删除临时图片失败, url={}", tempUrl);
            }
        }
    }

    private String extractObjectKey(String url) {
        // 从URL中提取OSS Object Key
        return url.substring(url.indexOf(".com/") + 5);
    }

    private String extractFileExt(String url) {
        int dotIdx = url.lastIndexOf('.');
        return dotIdx > 0 ? url.substring(dotIdx + 1) : "jpg";
    }
}
```

#### 7.1.6 商品数据入库（SPU+SKU事务写入）

```java
/**
 * 商品发布服务
 *
 * 完整发布链路：
 * 1. 类目属性校验
 * 2. 敏感词检测与内容审核
 * 3. 图片上传OSS
 * 4. SPU+SKU事务写入
 * 5. 提交审核，状态流转
 * 6. 发MQ通知下游
 */
@Service
@Slf4j
public class ProductPublishService {

    @Autowired
    private CategoryAttrValidator attrValidator;

    @Autowired
    private ContentReviewService contentReviewService;

    @Autowired
    private OssImageService ossImageService;

    @Autowired
    private ProductSpuMapper spuMapper;

    @Autowired
    private ProductSkuMapper skuMapper;

    @Autowired
    private ProductAttributeService attrService;

    @Autowired
    private ProductReviewService reviewService;

    @Autowired
    private RocketMQTemplate mqTemplate;

    @Autowired
    private IdGenerator idGenerator;

    @Autowired
    private TransactionTemplate transactionTemplate;

    /**
     * 发布商品
     */
    public Long publish(PublishProductRequest request, Long merchantId) {
        // 1. 类目属性校验
        attrValidator.validate(request.getCategoryId(), request.getAttrValues());

        // 2. 内容审核预检
        ReviewResult reviewResult = contentReviewService.preCheck(request);
        if (!reviewResult.isPass()) {
            throw new BizException("内容审核不通过: " + reviewResult.getReason());
        }

        // 3. 生成SPU ID
        long spuId = idGenerator.nextId();

        // 4. 图片上传到正式空间
        List<String> cdnUrls = ossImageService.uploadImages(
                request.getImageUrls(), spuId);
        String mainImage = StringUtils.isNotBlank(request.getMainImage())
                ? request.getMainImage() : cdnUrls.get(0);

        // 5. 事务写入 SPU + SKU + 属性值
        transactionTemplate.execute(status -> {
            try {
                // 5.1 写入SPU
                ProductSpu spu = new ProductSpu();
                spu.setSpuId(spuId);
                spu.setTitle(request.getTitle());
                spu.setSubtitle(request.getSubtitle());
                spu.setCategoryId(request.getCategoryId());
                spu.setBrandId(request.getBrandId());
                spu.setMainImage(mainImage);
                spu.setStatus(ProductStatus.DRAFT.getCode());
                spu.setCreateTime(new Date());
                spu.setUpdateTime(new Date());
                spuMapper.insert(spu);
                log.info("[发布商品] SPU写入成功, spuId={}, title={}",
                        spuId, request.getTitle());

                // 5.2 写入SKU列表
                for (PublishSkuRequest skuReq : request.getSkuList()) {
                    ProductSku sku = new ProductSku();
                    long skuId = idGenerator.nextId();
                    sku.setSkuId(skuId);
                    sku.setSpuId(spuId);
                    sku.setSkuName(skuReq.getSkuName());
                    sku.setSpecAttrs(JSON.toJSONString(skuReq.getSpecAttrs()));
                    sku.setBarcode(skuReq.getBarcode());
                    sku.setWeight(skuReq.getWeight());
                    sku.setStatus(ProductStatus.DRAFT.getCode());
                    sku.setCreateTime(new Date());
                    sku.setUpdateTime(new Date());
                    skuMapper.insert(sku);
                }
                log.info("[发布商品] SKU列表写入成功, spuId={}, skuCount={}",
                        spuId, request.getSkuList().size());

                // 5.3 写入动态属性值
                for (Map.Entry<Long, String> entry :
                        request.getAttrValues().entrySet()) {
                    attrService.saveAttrValue(
                            spuId, entry.getKey(), entry.getValue());
                }

                return null;
            } catch (Exception e) {
                status.setRollbackOnly();
                log.error("[发布商品] 事务回滚, spuId={}", spuId, e);
                throw e;
            }
        });

        // 6. 提交审核（状态：DRAFT → REVIEWING）
        reviewService.submitReview(spuId);

        // 7. 发MQ通知下游系统（搜索、推荐等）
        ProductPublishMessage msg = new ProductPublishMessage();
        msg.setSpuId(spuId);
        msg.setMerchantId(merchantId);
        msg.setCategoryId(request.getCategoryId());
        msg.setAction("PUBLISHED");
        msg.setTimestamp(System.currentTimeMillis());
        mqTemplate.asyncSend("product-publish-topic", msg, null);

        log.info("[发布商品] 全链路完成, spuId={}, merchantId={}",
                spuId, merchantId);
        return spuId;
    }
}
```

#### 7.1.7 审核状态流转与上架同步

```java
/**
 * 审核回调与上架同步消费者
 *
 * 审核通过后的处理链路：
 * 1. 更新状态：REVIEWING → APPROVED
 * 2. 自动上架（可选）：APPROVED → ON_SALE
 * 3. 同步ES索引
 * 4. 同步Redis缓存
 * 5. 通知下游系统（搜索、推荐、库存）
 */
@Component
@Slf4j
@RocketMQMessageListener(topic = "product-review-result-topic",
        consumerGroup = "product-review-result-group")
public class ProductReviewResultConsumer
        implements RocketMQListener<ReviewResultMessage> {

    @Autowired
    private ProductSpuMapper spuMapper;

    @Autowired
    private ProductSkuMapper skuMapper;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private RestHighLevelClient esClient;

    @Autowired
    private RocketMQTemplate mqTemplate;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void onMessage(ReviewResultMessage msg) {
        log.info("[审核回调] spuId={}, approved={}, reason={}",
                msg.getSpuId(), msg.isApproved(), msg.getRejectReason());

        if (msg.isApproved()) {
            // 审核通过：REVIEWING → APPROVED
            spuMapper.updateStatus(msg.getSpuId(),
                    ProductStatus.APPROVED.getCode());

            // 自动上架
            listOnAndSync(msg.getSpuId());
        } else {
            // 审核驳回：REVIEWING → REJECTED
            spuMapper.updateStatus(msg.getSpuId(),
                    ProductStatus.REJECTED.getCode());
            spuMapper.updateRejectReason(msg.getSpuId(),
                    msg.getRejectReason());

            log.info("[审核回调] 商品被驳回, spuId={}, reason={}",
                    msg.getSpuId(), msg.getRejectReason());
        }
    }

    /**
     * 上架并同步各存储
     */
    private void listOnAndSync(Long spuId) {
        // 1. 更新状态：APPROVED → ON_SALE
        spuMapper.updateStatus(spuId, ProductStatus.ON_SALE.getCode());
        skuMapper.updateStatusBySpu(spuId, ProductStatus.ON_SALE.getCode());
        log.info("[上架] 状态更新完成, spuId={}", spuId);

        // 2. 同步Redis缓存
        try {
            ProductSpu spu = spuMapper.selectBySpuId(spuId);
            List<ProductSku> skus = skuMapper.selectBySpuId(spuId);
            ProductCacheDTO cacheDTO = new ProductCacheDTO();
            cacheDTO.setSpu(spu);
            cacheDTO.setSkuList(skus);
            redisTemplate.opsForValue().set(
                    "product:spu:" + spuId,
                    JSON.toJSONString(cacheDTO),
                    30, TimeUnit.MINUTES);
            log.info("[上架] Redis缓存同步完成, spuId={}", spuId);
        } catch (Exception e) {
            log.error("[上架] Redis缓存同步失败, spuId={}", spuId, e);
            // 缓存失败不影响上架，查询时按需回填
        }

        // 3. 同步ES索引
        try {
            indexProductToEs(spuId);
            log.info("[上架] ES索引同步完成, spuId={}", spuId);
        } catch (Exception e) {
            log.error("[上架] ES索引同步失败, spuId={}, 发MQ重试", spuId, e);
            // ES同步失败发MQ重试
            mqTemplate.send("product-search-sync-topic",
                    new ProductSyncMessage(spuId, "LIST_ON"));
        }

        // 4. 发MQ通知下游系统
        ProductOnlineMessage notifyMsg = new ProductOnlineMessage();
        notifyMsg.setSpuId(spuId);
        notifyMsg.setAction("LIST_ON");
        notifyMsg.setTimestamp(System.currentTimeMillis());
        mqTemplate.send("product-online-notify-topic", notifyMsg);
        log.info("[上架] 下游通知已发送, spuId={}", spuId);
    }

    /**
     * 构建ES索引文档
     */
    private void indexProductToEs(Long spuId) throws IOException {
        ProductSpu spu = spuMapper.selectBySpuId(spuId);
        List<ProductSku> skus = skuMapper.selectBySpuId(spuId);

        Map<String, Object> doc = new HashMap<>();
        doc.put("spuId", spu.getSpuId());
        doc.put("title", spu.getTitle());
        doc.put("subtitle", spu.getSubtitle());
        doc.put("categoryId", spu.getCategoryId());
        doc.put("brandId", spu.getBrandId());
        doc.put("mainImage", spu.getMainImage());
        doc.put("status", spu.getStatus());

        List<Map<String, Object>> skuList = new ArrayList<>();
        for (ProductSku sku : skus) {
            Map<String, Object> skuMap = new HashMap<>();
            skuMap.put("skuId", sku.getSkuId());
            skuMap.put("skuName", sku.getSkuName());
            skuMap.put("specAttrs", JSON.parseObject(sku.getSpecAttrs()));
            skuList.add(skuMap);
        }
        doc.put("skus", skuList);

        IndexRequest request = new IndexRequest("product_index")
                .id(String.valueOf(spuId))
                .source(doc);
        esClient.index(request, RequestOptions.DEFAULT);
    }
```

```java
/**
 * 多级缓存查询服务
 *
 * 缓存层级：
 * 1. Caffeine本地缓存（1秒TTL）——挡热点，减少Redis访问
 * 2. Redis分布式缓存（30分钟TTL）——挡大部分查询
 * 3. MySQL数据库——最终数据源
 *
 * 防护策略：
 * - 缓存穿透：空值缓存 + 布隆过滤器
 * - 缓存击穿：互斥锁（singleflight）
 * - 缓存雪崩：随机TTL + 多级兜底
 */
@Service
@Slf4j
public class MultiLevelCacheService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private ProductSpuMapper spuMapper;

    @Autowired
    private ProductSkuMapper skuMapper;

    // 本地缓存
    private final Cache<Long, ProductCacheDTO> localCache = Caffeine.newBuilder()
            .maximumSize(10000)
            .expireAfterWrite(1, TimeUnit.SECONDS)
            .recordStats()
            .build();

    // 空值标记缓存（防穿透）
    private final Cache<Long, Boolean> nullCache = Caffeine.newBuilder()
            .maximumSize(50000)
            .expireAfterWrite(5, TimeUnit.MINUTES)
            .build();

    // 布隆过滤器（启动时加载所有spuId）
    private final BloomFilter<Long> spuBloomFilter =
            BloomFilter.create(Funnels.longFunnel(), 10_000_000, 0.001);

    // 互斥锁（防击穿，按spuId加锁）
    private final Striped<Lock> locks = Striped.lock(256);

    /**
     * 查询商品缓存数据
     */
    public ProductCacheDTO get(Long spuId) {
        // 0. 布隆过滤器前置判断（防穿透）
        if (!spuBloomFilter.mightContain(spuId)) {
            log.debug("[多级缓存] 布隆过滤器拦截, spuId={}", spuId);
            return null;
        }

        // 1. 空值缓存判断（防穿透）
        if (nullCache.getIfPresent(spuId) != null) {
            log.debug("[多级缓存] 空值缓存命中, spuId={}", spuId);
            return null;
        }

        // 2. 本地缓存
        ProductCacheDTO local = localCache.getIfPresent(spuId);
        if (local != null) {
            log.debug("[多级缓存] 本地缓存命中, spuId={}", spuId);
            return local;
        }

        // 3. Redis缓存
        String cacheKey = "product:spu:" + spuId;
        String json = redisTemplate.opsForValue().get(cacheKey);
        if (json != null) {
            if ("NULL".equals(json)) {
                // Redis空值标记
                nullCache.put(spuId, Boolean.TRUE);
                return null;
            }
            ProductCacheDTO redisCache = JSON.parseObject(json,
                    ProductCacheDTO.class);
            localCache.put(spuId, redisCache);
            log.debug("[多级缓存] Redis缓存命中, spuId={}", spuId);
            return redisCache;
        }

        // 4. 互斥锁查DB（防击穿）
        Lock lock = locks.get(spuId);
        try {
            if (lock.tryLock(100, TimeUnit.MILLISECONDS)) {
                try {
                    // 双重检查：拿到锁后再查一次缓存
                    local = localCache.getIfPresent(spuId);
                    if (local != null) return local;

                    json = redisTemplate.opsForValue().get(cacheKey);
                    if (json != null && !"NULL".equals(json)) {
                        ProductCacheDTO redisCache = JSON.parseObject(json,
                                ProductCacheDTO.class);
                        localCache.put(spuId, redisCache);
                        return redisCache;
                    }

                    // 查DB
                    ProductCacheDTO dbResult = loadFromDb(spuId);
                    if (dbResult == null) {
                        // 空值缓存（防穿透）
                        nullCache.put(spuId, Boolean.TRUE);
                        redisTemplate.opsForValue().set(cacheKey, "NULL",
                                5, TimeUnit.MINUTES);
                        log.info("[多级缓存] DB未找到, 空值缓存, spuId={}",
                                spuId);
                        return null;
                    }

                    // 回填缓存（随机TTL防雪崩）
                    int ttl = 25 + ThreadLocalRandom.current().nextInt(10);
                    redisTemplate.opsForValue().set(cacheKey,
                            JSON.toJSONString(dbResult), ttl, TimeUnit.MINUTES);
                    localCache.put(spuId, dbResult);
                    log.info("[多级缓存] DB回填缓存, spuId={}, ttl={}min",
                            spuId, ttl);
                    return dbResult;
                } finally {
                    lock.unlock();
                }
            } else {
                // 没拿到锁，短暂等待后重试缓存
                Thread.sleep(50);
                json = redisTemplate.opsForValue().get(cacheKey);
                if (json != null && !"NULL".equals(json)) {
                    return JSON.parseObject(json, ProductCacheDTO.class);
                }
                log.warn("[多级缓存] 互斥锁等待超时, spuId={}", spuId);
                return null;
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            log.error("[多级缓存] 互斥锁中断, spuId={}", spuId, e);
            return null;
        }
    }

    /**
     * 从数据库加载
     */
    private ProductCacheDTO loadFromDb(Long spuId) {
        ProductSpu spu = spuMapper.selectBySpuId(spuId);
        if (spu == null) {
            return null;
        }
        List<ProductSku> skus = skuMapper.selectBySpuId(spuId);
        ProductCacheDTO dto = new ProductCacheDTO();
        dto.setSpu(spu);
        dto.setSkuList(skus);
        return dto;
    }
}
```

```java
/**
 * 商品详情聚合服务
 *
 * 聚合内容：基本信息、SKU列表、价格、库存、评价统计、促销信息
 * 策略：多服务并行调用 + 超时降级，保证核心信息可用

@Service
@Slf4j
public class ProductDetailService {

    @Autowired
    private MultiLevelCacheService cacheService;

    @Autowired
    private InventoryFeignClient inventoryClient;

    @Autowired
    private PriceFeignClient priceClient;

    @Autowired
    private ReviewFeignClient reviewClient;

    @Autowired
    private PromotionFeignClient promotionClient;

    @Autowired
    private ThreadPoolExecutor detailAggregatorPool;

    /**
     * 获取商品详情
     */
    public ProductDetailVO getDetail(Long spuId, Long userId) {
        // 1. 查商品基础信息（多级缓存）
        ProductCacheDTO cache = cacheService.get(spuId);
        if (cache == null) {
            throw new BizException("商品不存在或已下架");
        }

        ProductDetailVO vo = new ProductDetailVO();
        vo.setSpuId(cache.getSpu().getSpuId());
        vo.setTitle(cache.getSpu().getTitle());
        vo.setSubtitle(cache.getSpu().getSubtitle());
        vo.setMainImage(cache.getSpu().getMainImage());
        vo.setCategoryId(cache.getSpu().getCategoryId());
        vo.setSkuList(cache.getSkuList());

        // 2. 并行调用下游服务（超时降级）
        List<Long> skuIds = cache.getSkuList().stream()
                .map(ProductSku::getSkuId)
                .collect(Collectors.toList());

        CompletableFuture<Void> inventoryFuture = CompletableFuture
                .supplyAsync(() -> queryInventoryWithFallback(spuId, skuIds),
                        detailAggregatorPool)
                .thenAccept(vo::setInventoryMap)
                .exceptionally(e -> {
                    log.warn("[详情聚合] 库存服务降级, spuId={}", spuId);
                    vo.setInventoryMap(Collections.emptyMap());
                    return null;
                });

        CompletableFuture<Void> priceFuture = CompletableFuture
                .supplyAsync(() -> queryPriceWithFallback(spuId, skuIds),
                        detailAggregatorPool)
                .thenAccept(vo::setPriceMap)
                .exceptionally(e -> {
                    log.warn("[详情聚合] 价格服务降级, spuId={}", spuId);
                    vo.setPriceMap(Collections.emptyMap());
                    return null;
                });

        CompletableFuture<Void> reviewFuture = CompletableFuture
                .supplyAsync(() -> queryReviewStatsWithFallback(spuId),
                        detailAggregatorPool)
                .thenAccept(vo::setReviewStats)
                .exceptionally(e -> {
                    log.warn("[详情聚合] 评价服务降级, spuId={}", spuId);
                    vo.setReviewStats(ReviewStats.empty());
                    return null;
                });

        CompletableFuture<Void> promoFuture = CompletableFuture
                .supplyAsync(() -> queryPromotionWithFallback(spuId, userId),
                        detailAggregatorPool)
                .thenAccept(vo::setPromotions)
                .exceptionally(e -> {
                    log.warn("[详情聚合] 促销服务降级, spuId={}", spuId);
                    vo.setPromotions(Collections.emptyList());
                    return null;
                });

        // 3. 等待所有任务完成（总超时800ms）
        try {
            CompletableFuture.allOf(
                    inventoryFuture, priceFuture,
                    reviewFuture, promoFuture)
                    .get(800, TimeUnit.MILLISECONDS);
        } catch (TimeoutException e) {
            log.warn("[详情聚合] 部分服务超时, spuId={}, 返回已有数据",
                    spuId);
            // 超时不取消，已有数据直接返回
        } catch (Exception e) {
            log.error("[详情聚合] 聚合异常, spuId={}", spuId, e);
        }

        log.info("[详情聚合] 完成, spuId={}, userId={}, hasInventory={}, "
                + "hasPrice={}, hasReview={}, hasPromo={}",
                spuId, userId,
                !vo.getInventoryMap().isEmpty(),
                !vo.getPriceMap().isEmpty(),
                vo.getReviewStats() != null,
                !vo.getPromotions().isEmpty());
        return vo;
    }

    /**
     * 库存查询（带降级）

            return Collections.emptyMap();
        }
    }

    /**
     * 价格查询（带降级）

        }
    }

    /**
```

```java
/**
 * 商品缓存更新策略
 *
 * Cache Aside Pattern（旁路缓存）：
 * - 读：先查缓存，miss则查DB并回填
 * - 写：先更新DB，再删缓存
 *
 * 延迟双删：
 * - 更新DB前先删一次缓存
 * - 更新DB后延迟500ms再删一次（防止旧读请求回填脏数据）
 */
@Service
@Slf4j
public class ProductCacheUpdateService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private ProductSpuMapper spuMapper;

    @Autowired
    private ScheduledExecutorService delayDeleteExecutor;

    /**
     * 商品信息变更后的缓存更新
     */
    public void onProductUpdated(Long spuId) {
        String cacheKey = "product:spu:" + spuId;

        // 1. 更新DB前先删缓存（第一次删）
        redisTemplate.delete(cacheKey);
        log.info("[缓存更新] 第一次删除, spuId={}", spuId);

        // 2. 更新DB（由调用方在事务中完成）
        // ... spuMapper.updateById(...)

        // 3. 延迟双删（第二次删）
        delayDeleteExecutor.schedule(() -> {
            try {
                redisTemplate.delete(cacheKey);
                log.info("[缓存更新] 延迟双删完成, spuId={}", spuId);
            } catch (Exception e) {
                log.error("[缓存更新] 延迟双删失败, spuId={}", spuId, e);
            }
        }, 500, TimeUnit.MILLISECONDS);

        // 4. 同时删除本地缓存引用（通过MQ广播通知所有节点）
        // 实际实现中通过MQ广播让所有节点清除本地Caffeine缓存
    }
}
```

#### 7.2.5 缓存防护策略汇总

| 防护场景 | 问题描述 | 解决方案 |
|---------|---------|---------|
| 缓存穿透 | 大量请求查询不存在的商品，直达DB | 布隆过滤器 + 空值缓存（5分钟TTL） |
| 缓存击穿 | 热点key过期瞬间，大量请求打到DB | 互斥锁（Striped Lock） + 双重检查 |
| 缓存雪崩 | 大量key同时过期，DB压力陡增 | 随机TTL（25~35分钟） + 多级缓存 |
| 热点商品 | 超级热门商品QPS极高 | Caffeine本地缓存（1秒TTL）挡Redis |

#### 7.3.2 价格变更校验

```java
/**
 * 价格变更校验器
 *
 * 校验规则：
 * 1. 价格必须大于0
 * 2. 涨幅不能超过50%（防止误操作导致价格异常）
 * 3. 跌幅不能超过80%（防止恶意低价）
 * 4. 变更金额超过阈值需审批
 */
@Service
@Slf4j
public class PriceValidator {

    @Autowired
    private PriceMapper priceMapper;

    // 涨幅上限50%，跌幅上限80%
    private static final BigDecimal MAX_INCREASE_RATE = new BigDecimal("0.5");
    private static final BigDecimal MAX_DECREASE_RATE = new BigDecimal("0.8");

    // 需要审批的变更金额阈值
    private static final BigDecimal APPROVAL_THRESHOLD = new BigDecimal("1000");

    /**
     * 校验价格变更
     *
     * @return 是否需要审批
     */
    public PriceValidateResult validate(Long skuId, BigDecimal newPrice) {
        // 1. 基础校验
        if (newPrice == null || newPrice.compareTo(BigDecimal.ZERO) <= 0) {
            throw new BizException("价格必须大于0");
        }

        // 2. 查询当前价格
        PriceVersion currentPrice = priceMapper.selectLatestValid(skuId);
        if (currentPrice == null) {
            log.info("[价格校验] 新品首次定价, skuId={}, price={}",
                    skuId, newPrice);
            return PriceValidateResult.pass(false);
        }

        BigDecimal oldPrice = currentPrice.getPrice();
        BigDecimal diff = newPrice.subtract(oldPrice);

        // 3. 涨跌幅校验
        if (diff.compareTo(BigDecimal.ZERO) > 0) {
            // 涨价
            BigDecimal increaseRate = diff.divide(oldPrice, 4,
                    RoundingMode.HALF_UP);
            if (increaseRate.compareTo(MAX_INCREASE_RATE) > 0) {
                throw new BizException(String.format(
                    "涨价幅度%.2f%%超过上限50%%，当前价=%s，新价=%s",
                    increaseRate.doubleValue() * 100,
                    oldPrice, newPrice));
            }
        } else if (diff.compareTo(BigDecimal.ZERO) < 0) {
            // 降价
            BigDecimal decreaseRate = diff.abs().divide(oldPrice, 4,
                    RoundingMode.HALF_UP);
            if (decreaseRate.compareTo(MAX_DECREASE_RATE) > 0) {
                throw new BizException(String.format(
                    "降价幅度%.2f%%超过上限80%%，当前价=%s，新价=%s",
                    decreaseRate.doubleValue() * 100,
                    oldPrice, newPrice));
            }
        }

        // 4. 审批判断
        boolean needApproval = diff.abs().compareTo(APPROVAL_THRESHOLD) >= 0;

        log.info("[价格校验] 通过, skuId={}, oldPrice={}, newPrice={}, "
                + "needApproval={}",
                skuId, oldPrice, newPrice, needApproval);

        return PriceValidateResult.pass(needApproval);
    }
}
```

#### 7.3.3 价格版本管理

```java
/**
 * 价格版本管理服务
 *
 * 设计思路：
 * 1. 每次价格变更记录一个版本（含生效时间、失效时间）
 * 2. 当前有效价格 = 生效时间 <= now < 失效时间 的最新版本
 * 3. 支持历史价格追溯和定时生效
 */
@Service
@Slf4j
public class PriceVersionManager {

    @Autowired
    private PriceMapper priceMapper;

    /**
     * 保存价格版本
     *
     * @param skuId         SKU ID
     * @param newPrice      新价格
     * @param effectiveTime 生效时间
     * @param operator      操作人
     * @param reason        变更原因
     */
    @Transactional(rollbackFor = Exception.class)
    public void saveVersion(Long skuId, BigDecimal newPrice,
                            Date effectiveTime, String operator,
                            String reason) {
        // 1. 将当前有效版本的失效时间设为新版本的生效时间
        PriceVersion current = priceMapper.selectLatestValid(skuId);
        if (current != null) {
            priceMapper.updateExpireTime(current.getId(), effectiveTime);
            log.info("[价格版本] 旧版本失效, skuId={}, versionId={}, "
                    + "expireTime={}",
                    skuId, current.getId(), effectiveTime);
        }

        // 2. 插入新版本
        PriceVersion newVersion = new PriceVersion();
        newVersion.setSkuId(skuId);
        newVersion.setPrice(newPrice);
        newVersion.setEffectiveTime(effectiveTime);
        newVersion.setExpireTime(new Date(Long.MAX_VALUE));
        newVersion.setOperator(operator);
        newVersion.setReason(reason);
        newVersion.setCreateTime(new Date());
        priceMapper.insert(newVersion);

        log.info("[价格版本] 新版本创建, skuId={}, versionId={}, "
                + "price={}, effectiveTime={}, operator={}",
                skuId, newVersion.getId(), newPrice,
                effectiveTime, operator);
    }

    /**
     * 查询历史价格
     */
    public List<PriceVersion> getPriceHistory(Long skuId, int limit) {
        return priceMapper.selectBySkuId(skuId, limit);
    }

    /**
     * 查询指定时间点的价格
     */
    public BigDecimal getPriceAtTime(Long skuId, Date queryTime) {
        PriceVersion version = priceMapper.selectBySkuIdAndTime(
                skuId, queryTime);
        return version != null ? version.getPrice() : null;
    }
}
```

#### 7.3.4 价格变更主流程

```java
/**
 * 价格变更服务
 *
 * 完整链路：
 * 1. 幂等控制
 * 2. 价格校验（涨幅限制）
 * 3. 审批流程（大变更需审批）
 * 4. 价格版本管理（版本记录 + 生效时间）
 * 5. 缓存更新（延迟双删）
 * 6. 下游通知（购物车、搜索）
 */
@Service
@Slf4n
public class PriceChangeService {

    @Autowired
    private PriceValidator priceValidator;

    @Autowired
    private PriceApprovalService approvalService;

    @Autowired
    private PriceVersionManager versionManager;

    @Autowired
    private PriceMapper priceMapper;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private RocketMQTemplate mqTemplate;

    @Autowired
    private IdempotentService idempotentService;

    @Autowired
    private ScheduledExecutorService delayDeleteExecutor;

    /**
     * 变更价格
     *
     * @param request       价格变更请求
     * @param operator      操作人
     * @param requestId     幂等请求ID
     */
    public void changePrice(PriceChangeRequest request,
                            String operator, String requestId) {
        log.info("[价格变更] 开始, skuId={}, newPrice={}, operator={}, "
                + "requestId={}",
                request.getSkuId(), request.getNewPrice(),
                operator, requestId);

        // 1. 幂等控制
        boolean acquired = idempotentService.tryAcquire(
                "price:change:" + requestId, 1, TimeUnit.HOURS);
        if (!acquired) {
            log.warn("[价格变更] 重复请求, requestId={}", requestId);
            throw new BizException("请勿重复提交");
        }

        try {
            // 2. 价格校验
            PriceValidateResult validateResult = priceValidator.validate(
                    request.getSkuId(), request.getNewPrice());

            // 3. 审批流程
            if (validateResult.isNeedApproval()) {
                String approvalId = approvalService.createApproval(
                        request, operator);
                log.info("[价格变更] 需审批, skuId={}, approvalId={}",
                        request.getSkuId(), approvalId);

                // 如果是审批流程，先返回，审批通过后异步执行
                if (!request.isForceSkipApproval()) {
                    return;
                }
            }

            // 4. 价格版本管理（事务写入）
            Date effectiveTime = request.getEffectiveTime() != null
                    ? request.getEffectiveTime() : new Date();
            versionManager.saveVersion(
                    request.getSkuId(),
                    request.getNewPrice(),
                    effectiveTime,
                    operator,
                    request.getReason());

            // 5. 缓存更新（延迟双删）
            updatePriceCache(request.getSkuId(),
                    request.getNewPrice(), effectiveTime);

            // 6. 下游通知
            notifyDownstream(request, operator);

            log.info("[价格变更] 完成, skuId={}, newPrice={}, operator={}",
                    request.getSkuId(), request.getNewPrice(), operator);

        } catch (BizException e) {
            idempotentService.release("price:change:" + requestId);
            throw e;
        } catch (Exception e) {
            idempotentService.release("price:change:" + requestId);
            log.error("[价格变更] 系统异常, skuId={}",
                    request.getSkuId(), e);
            throw new SystemException("价格变更失败");
        }
    }

    /**
     * 价格缓存更新（延迟双删）
     */
    private void updatePriceCache(Long skuId, BigDecimal newPrice,
                                  Date effectiveTime) {
        String cacheKey = "product:price:" + skuId;

        // 1. 第一次删缓存
        redisTemplate.delete(cacheKey);
        log.info("[价格缓存] 第一次删除, skuId={}", skuId);

        // 2. 写入新价格缓存（立即生效的场景）
        if (effectiveTime.before(new Date())) {
            PriceCacheDTO priceCache = new PriceCacheDTO();
            priceCache.setSkuId(skuId);
            priceCache.setPrice(newPrice);
            priceCache.setUpdateTime(new Date());
            redisTemplate.opsForValue().set(cacheKey,
                    JSON.toJSONString(priceCache),
                    30, TimeUnit.MINUTES);
            log.info("[价格缓存] 写入新价格, skuId={}, price={}",
                    skuId, newPrice);
        }

        // 3. 延迟双删（500ms后第二次删）
        delayDeleteExecutor.schedule(() -> {
            try {
                redisTemplate.delete(cacheKey);
                log.info("[价格缓存] 延迟双删完成, skuId={}", skuId);
            } catch (Exception e) {
                log.error("[价格缓存] 延迟双删失败, skuId={}", skuId, e);
            }
        }, 500, TimeUnit.MILLISECONDS);
    }

    /**
     * 下游通知
     */
    private void notifyDownstream(PriceChangeRequest request,
                                  String operator) {
        // 1. 通知购物车刷新价格
        PriceChangeMessage cartMsg = new PriceChangeMessage();
        cartMsg.setSkuId(request.getSkuId());
        cartMsg.setNewPrice(request.getNewPrice());
        cartMsg.setOperator(operator);
        cartMsg.setTimestamp(System.currentTimeMillis());
        mqTemplate.asyncSend("cart-price-refresh-topic", cartMsg, null);
        log.info("[价格变更] 购物车通知已发送, skuId={}", request.getSkuId());

        // 2. 通知搜索索引更新
        ProductSyncMessage searchMsg = new ProductSyncMessage();
        searchMsg.setSpuId(request.getSpuId());
        searchMsg.setAction("PRICE_UPDATE");
        searchMsg.setTimestamp(System.currentTimeMillis());
        mqTemplate.asyncSend("product-search-sync-topic", searchMsg, null);
        log.info("[价格变更] 搜索索引通知已发送, spuId={}",
                request.getSpuId());

        // 3. 通知价格历史记录（数据分析用）
        PriceChangeMessage historyMsg = new PriceChangeMessage();
        historyMsg.setSkuId(request.getSkuId());
        historyMsg.setNewPrice(request.getNewPrice());
        historyMsg.setOldPrice(request.getOldPrice());
        historyMsg.setOperator(operator);
        historyMsg.setReason(request.getReason());
        historyMsg.setTimestamp(System.currentTimeMillis());
        mqTemplate.asyncSend("price-change-log-topic", historyMsg, null);
    }
}
```

#### 7.3.5 价格变更消费者（下游处理）

```java
/**
 * 购物车价格刷新消费者
 *
 * 收到价格变更消息后，刷新购物车中相关商品的价格
 */
@Component
@Slf4j
@RocketMQMessageListener(topic = "cart-price-refresh-topic",
        consumerGroup = "cart-price-refresh-group")
public class CartPriceRefreshConsumer
        implements RocketMQListener<PriceChangeMessage> {

    @Autowired
    private CartService cartService;

    @Override
    public void onMessage(PriceChangeMessage msg) {
        try {
            log.info("[购物车价格刷新] 收到消息, skuId={}, newPrice={}",
                    msg.getSkuId(), msg.getNewPrice());

            // 1. 查询所有包含该SKU的购物车
            List<Cart> affectedCarts = cartService.findBySkuId(msg.getSkuId());
            if (affectedCarts.isEmpty()) {
                log.info("[购物车价格刷新] 无受影响购物车, skuId={}",
                        msg.getSkuId());
                return;
            }

            // 2. 批量更新购物车中的价格快照
            int updatedCount = cartService.batchUpdatePrice(
                    msg.getSkuId(), msg.getNewPrice());

            // 3. 删除购物车缓存（下次查询时从DB加载最新价格）
            for (Cart cart : affectedCarts) {
                String cacheKey = "cart:" + cart.getUserId();
                redisTemplate.delete(cacheKey);
            }

            log.info("[购物车价格刷新] 完成, skuId={}, affectedCarts={}, "
                    + "updatedCount={}",
                    msg.getSkuId(), affectedCarts.size(), updatedCount);

        } catch (Exception e) {
            log.error("[购物车价格刷新] 处理失败, skuId={}",
                    msg.getSkuId(), e);
            throw e; // 触发MQ重试
        }
    }
}
```

### 7.4 全链路案例总结

| 案例 | 核心链路 | 关键技术 | 异常处理 | 幂等控制 |
|------|---------|---------|---------|---------|
| 商品发布 | 参数校验→内容审核→图片上传→事务入库→审核流转→上架同步 | 事务模板、OSS、MQ异步、ES索引 | 审核失败回滚、ES同步失败MQ重试、图片审核超时转人工 | 幂等Token（24h有效期） |
| 详情查询 | 多级缓存→并行聚合→超时降级 | Caffeine+Redis多级缓存、CompletableFuture并行、布隆过滤器 | 下游服务降级返回默认值、互斥锁防击穿 | 无（读操作天然幂等） |
| 价格变更 | 校验→审批→版本管理→缓存双删→下游通知 | 价格版本表、延迟双删、MQ广播 | 幂等锁异常释放、MQ重试机制 | 幂等requestId（1h有效期） |
