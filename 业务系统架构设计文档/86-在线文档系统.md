# 在线文档协同编辑系统架构设计

## 一、系统概述

### 1.1 业务背景

在线文档系统是现代企业协作的核心基础设施，支持多人同时在线编辑同一份文档，实现实时协作。系统需要解决多人并发编辑时的冲突问题，保证所有参与者看到一致的文档内容，同时提供评论、追踪、权限管理等辅助协作功能。

### 1.2 核心需求

1. **多人协同编辑**：支持最多40人同时编辑同一文档，100人同时在线浏览
2. **实时同步**：编辑操作在毫秒级同步到所有在线用户
3. **冲突解决**：多人同时编辑同一区域时，系统自动解决冲突，保证最终一致性
4. **划词评论**：支持对文档任意片段进行精确定位评论
5. **视野追踪**：支持跟随模式（跟随某用户视角）和共享视角（同步所有人视野）
6. **默读会模式**：支持会前准备、默读+评论、明确行动项的结构化会议流程
7. **版本管理**：支持文档历史版本查看与回滚

### 1.3 技术挑战

| 挑战 | 说明 |
|------|------|
| 并发冲突 | 40人同时编辑，操作可能冲突，需保证最终一致性 |
| 实时性 | 操作延迟需控制在200ms以内 |
| 数据一致性 | 分布式环境下保证所有客户端文档状态一致 |
| 评论定位 | 文档内容变化后，评论锚点需要准确跟踪 |
| 大文档性能 | 万行级文档的编辑、渲染性能 |
| 断线恢复 | 网络抖动后的无缝重连与状态同步 |

### 1.4 设计目标

- 编辑操作端到端延迟 < 200ms
- 支持40人同时编辑，100人同时在线
- 文档最大支持100万字符
- 系统可用性 99.99%
- 操作不丢失，最终一致性保证

### 2.2 接入层设计

接入层负责WebSocket长连接的建立与管理，以及HTTP API的路由转发。

```java
/**
 * 接入层网关 - 负责连接路由和负载均衡
 * 
 * 设计模式：策略模式(Strategy Pattern) + 工厂模式(Factory Pattern)
 * - 策略模式：根据请求类型选择不同的路由策略
 * - 工厂模式：创建不同协议的连接处理器
 */
public class GatewayServer {

    private final ConnectionRouter connectionRouter;
    private final LoadBalancer loadBalancer;
    private final SessionManager sessionManager;

    /**
     * 路由策略接口 - 策略模式
     */
    interface RoutingStrategy {
        ServerNode selectNode(String documentId, String userId);
    }

    /**
     * 一致性哈希路由 - 同一文档路由到同一节点
     * 
     * 算法说明：使用一致性哈希(Consistent Hashing)确保同一文档的
     * 所有编辑请求路由到同一个协同引擎节点，避免跨节点同步开销
     */
    static class ConsistentHashRouting implements RoutingStrategy {
        // 虚拟节点数量，增加虚拟节点使负载更均匀
        private static final int VIRTUAL_NODES = 150;
        // 哈希环：key为虚拟节点哈希值，value为真实服务器节点
        private final TreeMap<Long, ServerNode> hashRing = new TreeMap<>();

        public void addNode(ServerNode node) {
            for (int i = 0; i < VIRTUAL_NODES; i++) {
                long hash = murmurHash(node.getId() + "#" + i);
                hashRing.put(hash, node);
            }
        }

        @Override
        public ServerNode selectNode(String documentId, String userId) {
            long hash = murmurHash(documentId);
            // 顺时针查找第一个大于等于该哈希值的节点
            Map.Entry<Long, ServerNode> entry = hashRing.ceilingEntry(hash);
            if (entry == null) {
                entry = hashRing.firstEntry(); // 环绕到第一个节点
            }
            return entry.getValue();
        }

        /**
         * MurmurHash3 算法 - 高性能非加密哈希
         * 特点：分布均匀、碰撞率低、计算速度快
         */
        private long murmurHash(String key) {
            byte[] data = key.getBytes(StandardCharsets.UTF_8);
            long h = 0x9747b28cL;
            for (int i = 0; i < data.length; i++) {
                h ^= data[i];
                h *= 0x5bd1e995L;
                h ^= h >> 15;
            }
            return h & 0x7fffffffffffffffL;
        }
    }

    /**
     * WebSocket连接建立流程
     */
    public WebSocketSession handleConnect(ConnectionRequest request) {
        // 1. 身份认证
        UserIdentity identity = authenticateUser(request.getToken());
        if (identity == null) {
            throw new AuthenticationException("Invalid token");
        }

        // 2. 权限校验
        Permission permission = checkDocumentPermission(
            identity.getUserId(), request.getDocumentId());
        if (!permission.canAccess()) {
            throw new AccessDeniedException("No access to document");
        }

        // 3. 路由选择 - 一致性哈希路由到对应节点
        ServerNode targetNode = connectionRouter.route(
            request.getDocumentId(), identity.getUserId());

        // 4. 建立连接会话
        WebSocketSession session = sessionManager.createSession(
            identity, request.getDocumentId(), permission);

        // 5. 发送文档初始状态
        DocumentSnapshot snapshot = loadDocumentSnapshot(request.getDocumentId());
        session.sendMessage(new InitMessage(snapshot));

        return session;
    }
}
```

### 2.3 协同编辑引擎

协同编辑引擎是系统的核心，负责处理所有编辑操作的变换与合并。

```java
/**
 * 协同编辑引擎 - 系统核心组件
 * 
 * 设计模式：中介者模式(Mediator Pattern)
 * 引擎作为中介者，协调各客户端的编辑操作
 */
public class CollaborationEngine {

    // 文档ID -> 文档编辑会话
    private final ConcurrentHashMap<String, EditSession> editSessions;
    private final OTEngine otEngine;
    private final OperationLog operationLog;
    private final BroadcastService broadcastService;

    /**
     * 处理客户端提交的编辑操作
     */
    public synchronized OperationResult processOperation(
            String documentId, String userId, Operation operation) {
        
        EditSession session = editSessions.get(documentId);
        if (session == null) {
            throw new DocumentNotFoundException(documentId);
        }

        // 1. 检查操作版本，进行OT变换
        int clientVersion = operation.getBaseVersion();
        int serverVersion = session.getCurrentVersion();

        Operation transformedOp = operation;
        if (clientVersion < serverVersion) {
            // 客户端版本落后，需要对操作进行变换
            List<Operation> concurrentOps = session.getOperationsSince(clientVersion);
            transformedOp = otEngine.transformAgainstAll(operation, concurrentOps);
        }

        // 2. 应用操作到服务端文档
        session.applyOperation(transformedOp, userId);

        // 3. 持久化操作日志
        operationLog.append(documentId, transformedOp, serverVersion + 1);

        // 4. 广播给其他客户端
        broadcastService.broadcastToOthers(documentId, userId, transformedOp);

        // 5. 返回确认
        return new OperationResult(serverVersion + 1, transformedOp);
    }
}
```

### 2.4 实时通信层

```java
/**
 * WebSocket服务集群 - 管理所有长连接
 * 
 * 设计模式：观察者模式(Observer Pattern)
 * 文档变更时通知所有订阅该文档的客户端
 */
public class WebSocketCluster {

    // 文档ID -> 连接列表
    private final ConcurrentHashMap<String, Set<WebSocketSession>> documentSessions;
    // 跨节点消息总线
    private final MessageBus messageBus;

    /**
     * 广播操作到所有连接同一文档的客户端
     */
    public void broadcast(String documentId, String excludeUserId, 
                          Operation operation) {
        Set<WebSocketSession> sessions = documentSessions.get(documentId);
        if (sessions == null) return;

        BroadcastMessage message = new BroadcastMessage(
            documentId, operation, System.currentTimeMillis());

        for (WebSocketSession session : sessions) {
            if (!session.getUserId().equals(excludeUserId)) {
                session.sendAsync(message);
            }
        }

        // 跨节点广播（通过消息总线通知其他服务器节点）
        messageBus.publish("doc:" + documentId, message);
    }
}
```

## 三、协同编辑算法

### 3.1 OT算法（Operational Transformation）

OT（操作变换）是协同编辑的核心算法，通过对并发操作进行数学变换，使得不同客户端在不同顺序下执行操作后达到相同的最终状态。

#### 3.1.1 OT算法基本原理

OT算法的核心思想是：当两个操作并发时，通过变换函数使得无论执行顺序如何，最终结果一致。

数学表达：
- 设操作 O1 和 O2 基于同一文档状态并发产生
- 变换函数 T(O1, O2) = (O1', O2')
- 先执行O1再执行O2' = 先执行O2再执行O1'

```java
/**
 * OT引擎 - 操作变换核心实现
 * 
 * 算法：Operational Transformation (操作变换)
 * 
 * 核心性质（收敛性条件）：
 * TP1: T(O1,O2)的结果使得 apply(apply(S,O1),O2') == apply(apply(S,O2),O1')
 *      即无论执行顺序，最终状态一致
 * TP2: T(O3, O1°O2') == T(T(O3,O1), O2')
 *      即变换满足结合律
 */
public class OTEngine {

    /**
     * 操作类型枚举
     */
    public enum OpType {
        INSERT,  // 插入文本
        DELETE,  // 删除文本
        RETAIN   // 保留（跳过）
    }

    /**
     * 原子操作定义
     */
    public static class AtomicOp {
        private final OpType type;
        private final int position;    // 操作位置
        private final String content;  // 插入/删除的内容
        private final int length;      // 操作长度

        public AtomicOp(OpType type, int position, String content) {
            this.type = type;
            this.position = position;
            this.content = content;
            this.length = content != null ? content.length() : 0;
        }

        // getter methods
        public OpType getType() { return type; }
        public int getPosition() { return position; }
        public String getContent() { return content; }
        public int getLength() { return length; }
    }

    /**
     * 复合操作 - 由多个原子操作组成
     */
    public static class Operation {
        private final String userId;
        private final int baseVersion;  // 基于的文档版本
        private final List<AtomicOp> ops;
        private final long timestamp;

        public Operation(String userId, int baseVersion, List<AtomicOp> ops) {
            this.userId = userId;
            this.baseVersion = baseVersion;
            this.ops = Collections.unmodifiableList(ops);
            this.timestamp = System.currentTimeMillis();
        }

        public String getUserId() { return userId; }
        public int getBaseVersion() { return baseVersion; }
        public List<AtomicOp> getOps() { return ops; }
        public long getTimestamp() { return timestamp; }
    }

    /**
     * 变换函数 - OT算法核心
     * 
     * 对两个并发操作进行变换，返回变换后的操作对
     * 
     * 算法步骤：
     * 1. 遍历两个操作的原子操作列表
     * 2. 根据操作类型组合(Insert-Insert, Insert-Delete等)
     *    计算变换后的位置和内容
     * 3. 保证变换后的操作满足TP1性质
     */
    public TransformResult transform(Operation op1, Operation op2) {
        List<AtomicOp> transformed1 = new ArrayList<>();
        List<AtomicOp> transformed2 = new ArrayList<>();

        int index1 = 0, index2 = 0;
        List<AtomicOp> ops1 = op1.getOps();
        List<AtomicOp> ops2 = op2.getOps();

        while (index1 < ops1.size() || index2 < ops2.size()) {
            AtomicOp a = index1 < ops1.size() ? ops1.get(index1) : null;
            AtomicOp b = index2 < ops2.size() ? ops2.get(index2) : null;

            if (a != null && b != null) {
                TransformPair pair = transformAtomicOps(a, b);
                if (pair.getFirst() != null) transformed1.add(pair.getFirst());
                if (pair.getSecond() != null) transformed2.add(pair.getSecond());
                index1++;
                index2++;
            } else if (a != null) {
                transformed1.add(a);
                index1++;
            } else {
                transformed2.add(b);
                index2++;
            }
        }

        Operation newOp1 = new Operation(op1.getUserId(), 
            op2.getBaseVersion() + 1, transformed1);
        Operation newOp2 = new Operation(op2.getUserId(), 
            op1.getBaseVersion() + 1, transformed2);

        return new TransformResult(newOp1, newOp2);
    }

    /**
     * 原子操作变换 - 根据操作类型对进行变换
     * 
     * 变换规则：
     * 1. Insert-Insert: 位置相同时按用户ID排序决定优先级
     * 2. Insert-Delete: 插入位置在删除范围前，删除位置后移
     * 3. Delete-Insert: 删除位置在插入位置前，插入位置前移
     * 4. Delete-Delete: 重叠部分取消，非重叠部分调整位置
     */
    private TransformPair transformAtomicOps(AtomicOp a, AtomicOp b) {
        if (a.getType() == OpType.INSERT && b.getType() == OpType.INSERT) {
            return transformInsertInsert(a, b);
        } else if (a.getType() == OpType.INSERT && b.getType() == OpType.DELETE) {
            return transformInsertDelete(a, b);
        } else if (a.getType() == OpType.DELETE && b.getType() == OpType.INSERT) {
            TransformPair reversed = transformInsertDelete(b, a);
            return new TransformPair(reversed.getSecond(), reversed.getFirst());
        } else {
            return transformDeleteDelete(a, b);
        }
    }

    /**
     * Insert-Insert 变换
     * 
     * 场景：两个用户在相同或相近位置插入文本
     * 规则：
     * - 如果位置不同，后面的操作位置+前面插入的长度
     * - 如果位置相同，按userId字典序决定谁先插入
     */
    private TransformPair transformInsertInsert(AtomicOp a, AtomicOp b) {
        if (a.getPosition() < b.getPosition()) {
            // a在b前面，b需要后移a的长度
            AtomicOp newB = new AtomicOp(OpType.INSERT, 
                b.getPosition() + a.getLength(), b.getContent());
            return new TransformPair(a, newB);
        } else if (a.getPosition() > b.getPosition()) {
            // b在a前面，a需要后移b的长度
            AtomicOp newA = new AtomicOp(OpType.INSERT, 
                a.getPosition() + b.getLength(), a.getContent());
            return new TransformPair(newA, b);
        } else {
            // 位置相同，按用户ID排序（确定性打破平局）
            // 这确保无论在哪个客户端执行，结果一致
            AtomicOp newA = a;
            AtomicOp newB = new AtomicOp(OpType.INSERT, 
                b.getPosition() + a.getLength(), b.getContent());
            return new TransformPair(newA, newB);
        }
    }

    /**
     * Insert-Delete 变换
     * 
     * 场景：一个用户插入文本，另一个用户删除文本
     * 规则：
     * - 插入位置在删除范围前：删除位置后移
     * - 插入位置在删除范围后：插入位置前移
     * - 插入位置在删除范围内：插入位置调整到删除起点
     */
    private TransformPair transformInsertDelete(AtomicOp insert, AtomicOp delete) {
        if (insert.getPosition() <= delete.getPosition()) {
            // 插入在删除前，删除位置后移
            AtomicOp newDelete = new AtomicOp(OpType.DELETE, 
                delete.getPosition() + insert.getLength(), delete.getContent());
            return new TransformPair(insert, newDelete);
        } else if (insert.getPosition() >= delete.getPosition() + delete.getLength()) {
            // 插入在删除后，插入位置前移
            AtomicOp newInsert = new AtomicOp(OpType.INSERT, 
                insert.getPosition() - delete.getLength(), insert.getContent());
            return new TransformPair(newInsert, delete);
        } else {
            // 插入在删除范围内
            AtomicOp newInsert = new AtomicOp(OpType.INSERT, 
                delete.getPosition(), insert.getContent());
            return new TransformPair(newInsert, delete);
        }
    }

    /**
     * Delete-Delete 变换
     * 
     * 场景：两个用户同时删除文本
     * 规则：处理删除范围的重叠
     */
    private TransformPair transformDeleteDelete(AtomicOp a, AtomicOp b) {
        int aStart = a.getPosition();
        int aEnd = aStart + a.getLength();
        int bStart = b.getPosition();
        int bEnd = bStart + b.getLength();

        if (aEnd <= bStart) {
            // a在b前面，无重叠
            AtomicOp newB = new AtomicOp(OpType.DELETE, 
                bStart - a.getLength(), b.getContent());
            return new TransformPair(a, newB);
        } else if (bEnd <= aStart) {
            // b在a前面，无重叠
            AtomicOp newA = new AtomicOp(OpType.DELETE, 
                aStart - b.getLength(), a.getContent());
            return new TransformPair(newA, b);
        } else {
            // 有重叠，计算非重叠部分
            int overlapStart = Math.max(aStart, bStart);
            int overlapEnd = Math.min(aEnd, bEnd);
            int overlapLength = overlapEnd - overlapStart;

            AtomicOp newA = null;
            AtomicOp newB = null;

            if (a.getLength() > overlapLength) {
                String remainContent = computeRemainingContent(a, overlapStart, overlapEnd);
                int newPos = aStart < bStart ? aStart : aStart - (bStart - aStart);
                newA = new AtomicOp(OpType.DELETE, Math.min(aStart, bStart), remainContent);
            }
            if (b.getLength() > overlapLength) {
                String remainContent = computeRemainingContent(b, overlapStart, overlapEnd);
                int newPos = bStart < aStart ? bStart : bStart - (aStart - bStart);
                newB = new AtomicOp(OpType.DELETE, Math.min(aStart, bStart), remainContent);
            }

            return new TransformPair(newA, newB);
        }
    }

    private String computeRemainingContent(AtomicOp op, int overlapStart, int overlapEnd) {
        int relStart = overlapStart - op.getPosition();
        int relEnd = overlapEnd - op.getPosition();
        String content = op.getContent();
        return content.substring(0, relStart) + content.substring(relEnd);
    }

    /**
     * 将操作对一系列历史操作进行变换
     * 
     * 算法：逐个应用变换，将客户端操作变换到服务端当前版本
     * 
     * 例如：客户端基于v3提交操作op，服务端已到v6
     * 需要对op依次与v4、v5、v6的操作进行变换
     */
    public Operation transformAgainstAll(Operation clientOp, 
                                         List<Operation> serverOps) {
        Operation current = clientOp;
        for (Operation serverOp : serverOps) {
            TransformResult result = transform(current, serverOp);
            current = result.getFirst(); // 取变换后的客户端操作
        }
        return current;
    }
}
```

### 3.2 CRDT算法对比

CRDT（Conflict-free Replicated Data Type，无冲突复制数据类型）是另一种实现协同编辑的算法方案。

```java
/**
 * CRDT实现 - 基于RGA（Replicated Growable Array）算法
 * 
 * 算法原理：
 * - 每个字符分配全局唯一、可比较的标识符
 * - 标识符在插入时生成，删除时标记为tombstone
 * - 不同节点可以独立操作，合并时通过标识符排序确定最终顺序
 * - 无需中心服务器进行操作变换
 * 
 * 与OT的对比：
 * - OT：需要中心服务器做操作变换，适合实时协作
 * - CRDT：去中心化，适合离线编辑后同步
 * - OT通信开销小（只传操作），CRDT存储开销大（每个字符带元数据）
 */
public class CRDTDocument {

    /**
     * CRDT字符节点
     * 每个字符带有唯一标识和逻辑时钟
     */
    static class CharNode {
        final String id;           // 全局唯一标识: siteId + logicalClock
        final char value;          // 字符值
        final String parentId;     // 父节点ID（前一个字符）
        final int siteId;          // 站点ID（标识不同客户端）
        final int logicalClock;    // 逻辑时钟（Lamport时间戳）
        boolean deleted;           // tombstone标记

        CharNode(String id, char value, String parentId, 
                 int siteId, int logicalClock) {
            this.id = id;
            this.value = value;
            this.parentId = parentId;
            this.siteId = siteId;
            this.logicalClock = logicalClock;
            this.deleted = false;
        }
    }

    private final int siteId;
    private int logicalClock;
    private final List<CharNode> sequence;  // 文档字符序列
    private final Map<String, CharNode> nodeIndex;  // ID -> 节点索引

    public CRDTDocument(int siteId) {
        this.siteId = siteId;
        this.logicalClock = 0;
        this.sequence = new ArrayList<>();
        this.nodeIndex = new HashMap<>();

        // 添加哨兵节点（文档首尾标记）
        CharNode head = new CharNode("HEAD", '\0', null, -1, 0);
        CharNode tail = new CharNode("TAIL", '\0', "HEAD", -1, 0);
        sequence.add(head);
        sequence.add(tail);
        nodeIndex.put("HEAD", head);
        nodeIndex.put("TAIL", tail);
    }

    /**
     * 本地插入操作
     * 
     * 算法步骤：
     * 1. 递增逻辑时钟
     * 2. 生成唯一标识 (siteId:clock)
     * 3. 确定父节点（插入位置的前一个字符）
     * 4. 创建新节点并插入到正确位置
     */
    public CharNode localInsert(int position, char value) {
        logicalClock++;
        String id = siteId + ":" + logicalClock;

        // 找到插入位置的前一个可见字符
        int visibleIndex = 0;
        int actualIndex = 0;
        for (int i = 0; i < sequence.size(); i++) {
            if (!sequence.get(i).deleted) {
                if (visibleIndex == position) {
                    actualIndex = i;
                    break;
                }
                visibleIndex++;
            }
        }

        CharNode parent = sequence.get(actualIndex);
        CharNode newNode = new CharNode(id, value, parent.id, siteId, logicalClock);

        // 插入到父节点之后，在所有具有相同父节点的子节点中
        // 按(logicalClock, siteId)排序确定位置
        int insertIndex = findInsertPosition(actualIndex + 1, newNode);
        sequence.add(insertIndex, newNode);
        nodeIndex.put(id, newNode);

        return newNode;
    }

    /**
     * 确定插入位置 - RGA算法的关键
     * 
     * 规则：在同一父节点的子节点中，按(逻辑时钟降序, 站点ID降序)排列
     * 这保证了后发生的操作排在前面（最新内容在前）
     */
    private int findInsertPosition(int startIndex, CharNode newNode) {
        int i = startIndex;
        while (i < sequence.size()) {
            CharNode existing = sequence.get(i);
            if (!existing.parentId.equals(newNode.parentId)) {
                break; // 不同父节点，跳过
            }
            // 按逻辑时钟降序，时钟相同按站点ID降序
            if (existing.logicalClock > newNode.logicalClock ||
                (existing.logicalClock == newNode.logicalClock && 
                 existing.siteId > newNode.siteId)) {
                i++;
            } else {
                break;
            }
        }
        return i;
    }

    /**
     * 本地删除操作 - Tombstone标记
     * 
     * CRDT不真正删除字符，而是标记为deleted（tombstone）
     * 这保证了其他节点的操作可以正确引用该位置
     */
    public void localDelete(int position) {
        int visibleIndex = 0;
        for (CharNode node : sequence) {
            if (!node.deleted) {
                if (visibleIndex == position) {
                    node.deleted = true;
                    return;
                }
                visibleIndex++;
            }
        }
    }

    /**
     * 合并远程操作
     * 
     * 接收来自其他站点的操作并合并到本地文档
     * 由于CRDT的性质，合并操作是交换律和结合律的
     * 即无论操作到达的顺序，最终结果一致
     */
    public void mergeRemoteInsert(CharNode remoteNode) {
        // 更新逻辑时钟
        logicalClock = Math.max(logicalClock, remoteNode.logicalClock) + 1;

        if (nodeIndex.containsKey(remoteNode.id)) {
            return; // 幂等性：已存在则跳过
        }

        // 找到父节点位置
        CharNode parent = nodeIndex.get(remoteNode.parentId);
        int parentIndex = sequence.indexOf(parent);

        // 在正确位置插入
        int insertIndex = findInsertPosition(parentIndex + 1, remoteNode);
        sequence.add(insertIndex, remoteNode);
        nodeIndex.put(remoteNode.id, remoteNode);
    }

    /**
     * 获取文档可见内容
     */
    public String getVisibleContent() {
        StringBuilder sb = new StringBuilder();
        for (CharNode node : sequence) {
            if (!node.deleted && node.value != '\0') {
                sb.append(node.value);
            }
        }
        return sb.toString();
    }
}
```

### 3.3 OT vs CRDT 选型分析

```java
/**
 * 协同算法选择器
 * 
 * 设计模式：策略模式(Strategy Pattern)
 * 根据场景选择OT或CRDT算法
 * 
 * 选型依据：
 * - 在线实时协作场景：选择OT，延迟低、存储开销小
 * - 离线编辑同步场景：选择CRDT，支持去中心化合并

public interface CollaborationAlgorithm {

     */
    String getDocumentContent();
}

        if (config.isRealTimeRequired() && config.hasCentralServer()) {
            return new OTBasedAlgorithm();
        } else if (config.isOfflineSupported()) {

        }
```

### 4.2 文档版本管理

```java
/**
 * 版本管理器 - 基于操作日志的版本控制
 * 
 * 算法：增量快照策略
 * - 每100个操作生成一次全量快照
 * - 中间版本通过操作日志回放恢复
 * - 类似数据库的WAL(Write-Ahead Logging)机制
 */
public class VersionManager {

    private static final int SNAPSHOT_INTERVAL = 100;

    private final OperationLogStore operationLogStore;
    private final SnapshotStore snapshotStore;

    /**
     * 记录新版本
     */
    public void recordVersion(String documentId, Operation operation, int version) {
        // 1. 写入操作日志
        operationLogStore.append(documentId, version, operation);

        // 2. 检查是否需要创建快照
        if (version % SNAPSHOT_INTERVAL == 0) {
            createSnapshot(documentId, version);
        }
    }

    /**
     * 恢复到指定版本
     * 
     * 算法步骤：
     * 1. 找到最近的快照（小于等于目标版本）
     * 2. 从快照开始，逐个回放操作日志
     * 3. 到达目标版本时停止
     */
    public DocumentState restoreToVersion(String documentId, int targetVersion) {
        // 找到最近的快照
        Snapshot snapshot = snapshotStore.findLatestBefore(documentId, targetVersion);
        
        DocumentState state;
        int startVersion;
        if (snapshot != null) {
            state = snapshot.getState();
            startVersion = snapshot.getVersion();
        } else {
            state = DocumentState.empty();
            startVersion = 0;
        }

        // 回放操作日志
        List<Operation> operations = operationLogStore.getOperations(
            documentId, startVersion + 1, targetVersion);

        for (Operation op : operations) {
            state = state.apply(op);
        }

        return state;
    }

    /**
     * 创建快照
     */
    private void createSnapshot(String documentId, int version) {
        DocumentState currentState = restoreToVersion(documentId, version);
        Snapshot snapshot = new Snapshot(documentId, version, currentState);
        snapshotStore.save(snapshot);
    }

    /**
     * 版本差异计算 - 用于展示版本对比
     * 
     * 算法：Myers Diff算法
     * 计算两个版本之间的最小编辑距离
     */
    public List<DiffEntry> computeDiff(String documentId, 
                                        int fromVersion, int toVersion) {
        DocumentState fromState = restoreToVersion(documentId, fromVersion);
        DocumentState toState = restoreToVersion(documentId, toVersion);

        String fromText = fromState.toPlainText();
        String toText = toState.toPlainText();

        return myersDiff(fromText, toText);
    }

    /**
     * Myers Diff算法实现
     * 
     * 时间复杂度：O(ND)，N为文本长度，D为编辑距离
     * 空间复杂度：O(N)
     */
    private List<DiffEntry> myersDiff(String a, String b) {
        int n = a.length();
        int m = b.length();
        int max = n + m;

        int[] v = new int[2 * max + 1];
        Arrays.fill(v, 0);
        List<int[]> trace = new ArrayList<>();

        for (int d = 0; d <= max; d++) {
            int[] snapshot = Arrays.copyOf(v, v.length);
            trace.add(snapshot);

            for (int k = -d; k <= d; k += 2) {
                int index = k + max;
                int x;
                if (k == -d || (k != d && v[index - 1] < v[index + 1])) {
                    x = v[index + 1]; // 向下移动
                } else {
                    x = v[index - 1] + 1; // 向右移动
                }

                int y = x - k;

                // 沿对角线移动（字符匹配）
                while (x < n && y < m && a.charAt(x) == b.charAt(y)) {
                    x++;
                    y++;
                }

                v[index] = x;

                if (x >= n && y >= m) {
                    return buildDiffFromTrace(trace, a, b, d, max);
                }
            }
        }

        return Collections.emptyList();
    }
```

## 五、实时通信

### 5.1 WebSocket长连接管理

```java
/**
 * WebSocket连接管理器
 * 
 * 设计模式：享元模式(Flyweight Pattern) + 对象池模式(Object Pool)
 * - 享元：共享文档状态信息，避免每个连接独立维护
 * - 对象池：复用消息缓冲区，减少GC压力
 */
public class WebSocketConnectionManager {

    // 文档ID -> 连接集合
    private final ConcurrentHashMap<String, CopyOnWriteArraySet<ClientConnection>> 
        documentConnections = new ConcurrentHashMap<>();

    // 用户ID -> 连接
    private final ConcurrentHashMap<String, ClientConnection> 
        userConnections = new ConcurrentHashMap<>();

    // 最大连接数限制
    private static final int MAX_EDITORS_PER_DOC = 40;
    private static final int MAX_VIEWERS_PER_DOC = 100;

    /**
     * 客户端连接封装
     */
    static class ClientConnection {
        private final String connectionId;
        private final String userId;
        private final String documentId;
        private final WebSocketSession session;
        private final Permission permission;
        private volatile long lastHeartbeat;
        private volatile ConnectionState state;

        // 消息发送队列 - 保证消息顺序
        private final BlockingQueue<Message> sendQueue;
        // 发送线程
        private final Thread senderThread;

        ClientConnection(String userId, String documentId, 
                         WebSocketSession session, Permission permission) {
            this.connectionId = UUID.randomUUID().toString();
            this.userId = userId;
            this.documentId = documentId;
            this.session = session;
            this.permission = permission;
            this.lastHeartbeat = System.currentTimeMillis();
            this.state = ConnectionState.CONNECTED;
            this.sendQueue = new LinkedBlockingQueue<>(1000);

            // 启动发送线程，从队列中取消息发送
            this.senderThread = new Thread(this::sendLoop, 
                "sender-" + connectionId);
            this.senderThread.setDaemon(true);
            this.senderThread.start();
        }

        /**
         * 异步发送消息
         */
        public void sendAsync(Message message) {
            if (!sendQueue.offer(message)) {
                // 队列满，丢弃非关键消息或断开连接
                handleQueueFull(message);
            }
        }

        private void sendLoop() {
            while (state == ConnectionState.CONNECTED) {
                try {
                    Message message = sendQueue.poll(30, TimeUnit.SECONDS);
                    if (message != null) {
                        session.sendMessage(new TextMessage(message.serialize()));
                    }
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                } catch (Exception e) {
                    handleSendError(e);
                }
            }
        }

        private void handleQueueFull(Message message) {
            // 丢弃光标位置等非关键消息，保留编辑操作消息
            if (message.getType() == MessageType.CURSOR_UPDATE) {
                return; // 可安全丢弃
            }
            // 关键消息队列满，触发重连
            close();
        }

        private void handleSendError(Exception e) {
            state = ConnectionState.ERROR;
        }

        public void close() {
            state = ConnectionState.DISCONNECTED;
            senderThread.interrupt();
        }
    }

    /**
     * 建立连接
     */
    public ClientConnection connect(String userId, String documentId, 
                                     WebSocketSession session, Permission permission) {
        CopyOnWriteArraySet<ClientConnection> connections = 
            documentConnections.computeIfAbsent(documentId, 
                k -> new CopyOnWriteArraySet<>());

        // 检查连接数限制
        long editorCount = connections.stream()
            .filter(c -> c.permission.canEdit())
            .count();
        long viewerCount = connections.size();

        if (permission.canEdit() && editorCount >= MAX_EDITORS_PER_DOC) {
            throw new ConnectionLimitException(
                "Editor limit reached: " + MAX_EDITORS_PER_DOC);
        }
        if (viewerCount >= MAX_VIEWERS_PER_DOC) {
            throw new ConnectionLimitException(
                "Viewer limit reached: " + MAX_VIEWERS_PER_DOC);
        }

        ClientConnection connection = new ClientConnection(
            userId, documentId, session, permission);
        connections.add(connection);
        userConnections.put(userId, connection);

        // 通知其他用户有新用户加入
        broadcastPresence(documentId, userId, PresenceAction.JOIN);

        return connection;
    }

    /**
     * 心跳检测 - 定时检查连接活性
     * 
     * 算法：定时扫描，超时断开
     * 心跳间隔30秒，超时90秒断开
     */
    @Scheduled(fixedRate = 30000)
    public void heartbeatCheck() {
        long now = System.currentTimeMillis();
        long timeout = 90_000; // 90秒超时

        for (Map.Entry<String, CopyOnWriteArraySet<ClientConnection>> entry : 
                documentConnections.entrySet()) {
            for (ClientConnection conn : entry.getValue()) {
                if (now - conn.lastHeartbeat > timeout) {
                    disconnect(conn.userId, entry.getKey());
                }
            }
        }
    }

    /**
     * 断开连接
     */
    public void disconnect(String userId, String documentId) {
        CopyOnWriteArraySet<ClientConnection> connections = 
            documentConnections.get(documentId);
        if (connections != null) {
            connections.removeIf(c -> c.userId.equals(userId));
            if (connections.isEmpty()) {
                documentConnections.remove(documentId);
            }
        }
        userConnections.remove(userId);

        // 通知其他用户
        broadcastPresence(documentId, userId, PresenceAction.LEAVE);
    }

    /**
     * 广播用户在线状态
     */
    private void broadcastPresence(String documentId, String userId, 
                                    PresenceAction action) {
        PresenceMessage message = new PresenceMessage(userId, action);
        broadcast(documentId, userId, message);
    }

    /**
     * 广播消息到文档所有连接（排除发送者）
     */
    public void broadcast(String documentId, String excludeUserId, Message message) {
        CopyOnWriteArraySet<ClientConnection> connections = 
            documentConnections.get(documentId);
        if (connections == null) return;
```

```java
/**
 * 操作广播服务
 * 
 * 设计模式：发布-订阅模式(Publish-Subscribe Pattern)
 * 
 * 流程：
 * 1. 客户端发送操作到服务端
 * 2. 服务端进行OT变换
 * 3. 应用到服务端文档
 * 4. 广播变换后的操作给其他客户端
 * 5. 回复确认给发送者
 */
public class OperationBroadcastService {

    private final CollaborationEngine collaborationEngine;
    private final WebSocketConnectionManager connectionManager;
    private final OperationBuffer operationBuffer;

    /**
     * 处理客户端操作
     */
    public void handleClientOperation(String documentId, String userId, 
                                       String operationJson) {
        // 1. 反序列化操作
        Operation operation = Operation.fromJson(operationJson);

        // 2. 放入操作缓冲区（合并短时间内的多个操作）
        Operation mergedOp = operationBuffer.bufferAndMerge(
            documentId, userId, operation);
        if (mergedOp == null) {
            return; // 操作已缓冲，等待合并
        }

        // 3. 提交到协同引擎处理
        OperationResult result = collaborationEngine.processOperation(
            documentId, userId, mergedOp);

        // 4. 回复确认给发送者
        AckMessage ack = new AckMessage(
            result.getNewVersion(), result.getTransformedOp());
        connectionManager.sendToUser(userId, ack);

        // 5. 广播给其他用户
        BroadcastMessage broadcast = new BroadcastMessage(
            userId, result.getTransformedOp(), result.getNewVersion());
        connectionManager.broadcast(documentId, userId, broadcast);
    }

    /**
     * 操作缓冲区 - 合并短时间内的连续操作
     * 
     * 算法：滑动窗口合并
     * - 50ms窗口内的连续输入操作合并为一个
     * - 减少网络传输和OT变换次数
     */
    static class OperationBuffer {
        private final Map<String, BufferEntry> buffers = new ConcurrentHashMap<>();
        private static final long MERGE_WINDOW_MS = 50;

        public Operation bufferAndMerge(String documentId, String userId, 
                                         Operation operation) {
            String key = documentId + ":" + userId;
            BufferEntry entry = buffers.get(key);

            if (entry != null && 
                System.currentTimeMillis() - entry.timestamp < MERGE_WINDOW_MS &&
                canMerge(entry.operation, operation)) {
                // 合并操作
                entry.operation = mergeOperations(entry.operation, operation);
                entry.timestamp = System.currentTimeMillis();
                return null; // 继续缓冲
            }

            // 提交之前缓冲的操作
            Operation result = entry != null ? entry.operation : null;
            buffers.put(key, new BufferEntry(operation, System.currentTimeMillis()));

            // 设置定时器，窗口结束后自动提交
            scheduleFlush(key, MERGE_WINDOW_MS);

            return result;
        }

        private boolean canMerge(Operation a, Operation b) {
            // 只合并连续的插入或删除操作
            return a.getOps().get(a.getOps().size() - 1).getType() == 
                   b.getOps().get(0).getType();
        }

        private Operation mergeOperations(Operation a, Operation b) {
            List<AtomicOp> merged = new ArrayList<>(a.getOps());
            merged.addAll(b.getOps());
            return new Operation(a.getUserId(), a.getBaseVersion(), merged);
        }

        private void scheduleFlush(String key, long delayMs) {
            // 使用ScheduledExecutorService延迟提交
        }
    }
}

/**
 * 冲突检测器
 * 
 * 检测编辑冲突并决定解决策略
 */
public class ConflictDetector {

    /**
     * 冲突类型
     */
    enum ConflictType {
        NO_CONFLICT,          // 无冲突
        POSITION_CONFLICT,    // 位置冲突（同位置编辑）
        RANGE_OVERLAP,        // 范围重叠
        STRUCTURAL_CONFLICT   // 结构冲突（如同时删除和修改同一段落）
    }

    /**
     * 检测两个操作是否冲突
     */
    public ConflictType detectConflict(Operation op1, Operation op2) {
        for (AtomicOp a : op1.getOps()) {
            for (AtomicOp b : op2.getOps()) {
                ConflictType conflict = checkAtomicConflict(a, b);
                if (conflict != ConflictType.NO_CONFLICT) {
                    return conflict;
                }
            }
        }
        return ConflictType.NO_CONFLICT;
    }

    private ConflictType checkAtomicConflict(AtomicOp a, AtomicOp b) {
        // 检查操作范围是否重叠
        int aStart = a.getPosition();
        int aEnd = aStart + a.getLength();
        int bStart = b.getPosition();
        int bEnd = bStart + b.getLength();

        if (aStart == bStart && a.getType() == b.getType()) {
            return ConflictType.POSITION_CONFLICT;
        }

        if (aStart < bEnd && bStart < aEnd) {
            return ConflictType.RANGE_OVERLAP;
        }

        return ConflictType.NO_CONFLICT;
    }
}
```

```java
/**
 * 划词评论系统
 * 
 * 核心挑战：文档内容变化后，评论锚点需要准确跟踪
 * 
 * 设计模式：锚点定位模式
 * 算法：基于文档树路径 + 字符偏移量的定位

public class CommentSystem {

    /**
     * 评论锚点 - 标记评论关联的文档位置
     * 
     * 锚点定位策略：
     * 1. 主锚点：文档树路径 + 字符偏移量
     * 2. 上下文锚点：锚点前后的文本片段（用于容错恢复）
     * 3. 节点ID锚点：直接引用文档节点ID
     */
    public static class CommentAnchor {
        private String documentId;
        private String nodeId;         // 锚定的节点ID
        private int startOffset;       // 节点内起始偏移
        private int endOffset;         // 节点内结束偏移
        private String contextBefore;  // 锚点前的文本（容错用）
        private String contextAfter;   // 锚点后的文本（容错用）
        private String selectedText;   // 选中的文本内容

        /**
         * 检查锚点是否仍然有效
         */
        public boolean isValid(DocumentNode currentNode) {
            if (currentNode == null) return false;
            if (!(currentNode instanceof TextNode)) return false;

            TextNode textNode = (TextNode) currentNode;
            String text = textNode.getText();

            // 检查偏移量是否在范围内
            if (startOffset >= text.length() || endOffset > text.length()) {
                return false;
            }

            // 检查选中文本是否匹配
            String currentSelected = text.substring(startOffset, endOffset);
            return currentSelected.equals(selectedText);
        }

        private long createTime;

            this.authorId = authorId;
            this.content = content;
            this.anchor = anchor;
            this.status = CommentStatus.ACTIVE;
            this.createTime = System.currentTimeMillis();
            this.replies = new ArrayList<>();
        }

    private final AnchorTracker anchorTracker;

        String selectedText = extractText(node, startOffset, endOffset);
        String contextBefore = extractContextBefore(node, startOffset, 20);
        String contextAfter = extractContextAfter(node, endOffset, 20);

        anchor.documentId = documentId;
        anchor.nodeId = nodeId;

        anchor.endOffset = endOffset;
```

### 6.2 锚点跟踪算法

```java
/**
 * 锚点跟踪器 - 文档变化时自动更新评论锚点位置
 * 
 * 算法：基于操作变换的锚点位置更新
 * 当文档发生编辑操作时，所有评论的锚点位置需要相应调整
 */
public class AnchorTracker {

    // documentId -> (commentId -> anchor)
    private final Map<String, Map<String, CommentSystem.CommentAnchor>> anchors;

    /**
     * 当文档发生操作时，更新所有锚点位置
     * 
     * 算法：
     * 对每个锚点，根据操作类型和位置关系调整偏移量
     * - 插入操作在锚点前：锚点后移
     * - 删除操作在锚点前：锚点前移
     * - 操作在锚点范围内：标记锚点需要修复
     */
    public void onOperationApplied(String documentId, Operation operation) {
        Map<String, CommentSystem.CommentAnchor> docAnchors = anchors.get(documentId);
        if (docAnchors == null) return;

        for (Map.Entry<String, CommentSystem.CommentAnchor> entry : 
                docAnchors.entrySet()) {
            CommentSystem.CommentAnchor anchor = entry.getValue();
            updateAnchorPosition(anchor, operation);
        }
    }

    private void updateAnchorPosition(CommentSystem.CommentAnchor anchor, 
                                       Operation operation) {
        for (AtomicOp op : operation.getOps()) {
            if (!op.getNodeId().equals(anchor.nodeId)) {
                continue; // 不在同一节点，跳过
            }

            switch (op.getType()) {
                case INSERT:
                    adjustForInsert(anchor, op.getPosition(), op.getLength());
                    break;
                case DELETE:
                    adjustForDelete(anchor, op.getPosition(), op.getLength());
                    break;
                default:
                    break;
            }
        }
    }

    /**
     * 插入操作的锚点调整
     */
    private void adjustForInsert(CommentSystem.CommentAnchor anchor, 
                                  int insertPos, int insertLength) {
        if (insertPos <= anchor.startOffset) {
            // 插入在锚点前，整体后移
            anchor.startOffset += insertLength;
            anchor.endOffset += insertLength;
        } else if (insertPos < anchor.endOffset) {
            // 插入在锚点范围内，结束位置后移
            anchor.endOffset += insertLength;
        }
        // 插入在锚点后，不影响
    }

    /**
     * 删除操作的锚点调整
     */
    private void adjustForDelete(CommentSystem.CommentAnchor anchor, 
                                  int deletePos, int deleteLength) {
        int deleteEnd = deletePos + deleteLength;

        if (deleteEnd <= anchor.startOffset) {
            // 删除在锚点前，整体前移
            anchor.startOffset -= deleteLength;
            anchor.endOffset -= deleteLength;
        } else if (deletePos >= anchor.endOffset) {
            // 删除在锚点后，不影响
        } else if (deletePos <= anchor.startOffset && deleteEnd >= anchor.endOffset) {
            // 删除覆盖整个锚点范围，锚点失效
            anchor.startOffset = deletePos;
            anchor.endOffset = deletePos;
            // 标记需要修复
        } else if (deletePos <= anchor.startOffset) {
            // 删除覆盖锚点前半部分
            anchor.startOffset = deletePos;
            anchor.endOffset -= deleteLength;
        } else if (deleteEnd >= anchor.endOffset) {
            // 删除覆盖锚点后半部分
            anchor.endOffset = deletePos;
        } else {
            // 删除在锚点中间
            anchor.endOffset -= deleteLength;
        }
    }

    /**
     * 锚点修复 - 当锚点位置不准确时，通过上下文文本重新定位
     * 
     * 算法：模糊匹配
     * 使用锚点保存的上下文文本和选中文本，在当前文档中搜索最匹配的位置
     */
    public void repairAnchor(String documentId, String commentId, 
                              DocumentNode currentDocument) {
        CommentSystem.CommentAnchor anchor = anchors
            .getOrDefault(documentId, Collections.emptyMap())
            .get(commentId);
        if (anchor == null) return;

        // 在当前文档中搜索匹配的文本
        String searchPattern = anchor.contextBefore + anchor.selectedText + anchor.contextAfter;
        int bestMatchPos = fuzzySearch(currentDocument, searchPattern);

        if (bestMatchPos >= 0) {
            // 更新锚点位置
            anchor.startOffset = bestMatchPos + anchor.contextBefore.length();
            anchor.endOffset = anchor.startOffset + anchor.selectedText.length();
        }
    }

    /**
     * 模糊搜索 - 在文档中查找最匹配的位置
     * 
     * 算法：编辑距离(Levenshtein Distance)匹配
     * 在文档中滑动窗口，找到与搜索模式编辑距离最小的位置
     */
    private int fuzzySearch(DocumentNode document, String pattern) {
        String docText = document.toPlainText();
        int patternLen = pattern.length();
        int bestPos = -1;
        int bestDistance = Integer.MAX_VALUE;

        for (int i = 0; i <= docText.length() - patternLen; i++) {
            String candidate = docText.substring(i, i + patternLen);
            int distance = levenshteinDistance(pattern, candidate);
            if (distance < bestDistance) {
                bestDistance = distance;
                bestPos = i;
            }
        }

        // 只接受编辑距离小于模式长度20%的匹配
        if (bestDistance <= patternLen * 0.2) {
            return bestPos;
        }
        return -1;
    }

    /**
     * Levenshtein编辑距离算法
     * 
     * 时间复杂度：O(mn)，m和n分别为两个字符串的长度
     * 空间复杂度：O(min(m,n))，使用滚动数组优化
     */
    private int levenshteinDistance(String a, String b) {
        int m = a.length();
        int n = b.length();

        // 滚动数组优化空间
        int[] prev = new int[n + 1];
        int[] curr = new int[n + 1];

        for (int j = 0; j <= n; j++) prev[j] = j;

        for (int i = 1; i <= m; i++) {
            curr[0] = i;
            for (int j = 1; j <= n; j++) {
                int cost = a.charAt(i - 1) == b.charAt(j - 1) ? 0 : 1;
                curr[j] = Math.min(
                    Math.min(curr[j - 1] + 1, prev[j] + 1),
                    prev[j - 1] + cost
                );
            }
            int[] temp = prev;
            prev = curr;
            curr = temp;
        }

        return prev[n];
    }
}
```

```java
 * 
 * 流程：
 * 1. 会前准备：主持人创建议程，参与者预读文档
 * 2. 默读+评论：所有人静默阅读并添加评论
 * 3. 讨论：逐一讨论评论
 * 4. 明确行动项：记录决策和待办
 * 
 * 设计模式：状态模式(State Pattern)
 * 不同阶段有不同的权限和行为
 */
public class SilentReadingMeeting {

    enum MeetingPhase {
        PREPARATION,   // 会前准备
        SILENT_READING,// 默读+评论
        DISCUSSION,    // 讨论
        ACTION_ITEMS   // 明确行动项
    }

    /**
     * 阶段状态接口 - 状态模式
     */
    interface PhaseState {
        boolean canEdit();
        boolean canComment();
        boolean canViewOtherComments();
        void onEnter(SilentReadingMeeting meeting);
        void onExit(SilentReadingMeeting meeting);
    }

    /**
     * 默读阶段 - 可评论但不能看到他人评论
     */
    static class SilentReadingState implements PhaseState {
        @Override
        public boolean canEdit() { return false; }

        @Override
        public boolean canComment() { return true; }

        @Override
        public boolean canViewOtherComments() { return false; }

        @Override
        public void onEnter(SilentReadingMeeting meeting) {
            // 锁定文档编辑
            meeting.lockEditing();
            // 隐藏他人评论
            meeting.hideOtherComments();
            // 启动计时器
            meeting.startTimer(meeting.silentReadingDuration);
        }

        @Override
        public void onExit(SilentReadingMeeting meeting) {
            // 显示所有评论
            meeting.showAllComments();
        }
    }

    /**
     * 讨论阶段 - 可看所有评论，可回复
     */
    static class DiscussionState implements PhaseState {
        @Override
        public boolean canEdit() { return false; }

        @Override
        public boolean canComment() { return true; }

        @Override
        public boolean canViewOtherComments() { return true; }

        @Override
        public void onEnter(SilentReadingMeeting meeting) {
            meeting.showAllComments();
            meeting.highlightFirstComment();
        }

        @Override
        public void onExit(SilentReadingMeeting meeting) { }
    }

    /**
     * 行动项阶段 - 可编辑行动项区域
     */
    static class ActionItemsState implements PhaseState {
        @Override
        public boolean canEdit() { return true; }

        @Override
        public boolean canComment() { return true; }

        @Override
        public boolean canViewOtherComments() { return true; }

        @Override
        public void onEnter(SilentReadingMeeting meeting) {
            meeting.unlockEditing();
            meeting.createActionItemsSection();
        }

        @Override
        public void onExit(SilentReadingMeeting meeting) {
            meeting.finalizeActionItems();
        }
    }

    private String meetingId;
    private String documentId;
    private String hostUserId;
    private List<String> participants;
    private MeetingPhase currentPhase;
    private PhaseState currentState;
    private int silentReadingDuration; // 默读时长（秒）

    /**
     * 切换阶段
     */
    public void advancePhase() {
        currentState.onExit(this);

        switch (currentPhase) {
            case PREPARATION:
                currentPhase = MeetingPhase.SILENT_READING;
                currentState = new SilentReadingState();
                break;
            case SILENT_READING:
                currentPhase = MeetingPhase.DISCUSSION;
                currentState = new DiscussionState();
                break;
            case DISCUSSION:
                currentPhase = MeetingPhase.ACTION_ITEMS;
                currentState = new ActionItemsState();
                break;
            case ACTION_ITEMS:
                endMeeting();
                return;
        }

        currentState.onEnter(this);
        broadcastPhaseChange(currentPhase);
    }

    // 辅助方法
    void lockEditing() { /* 锁定文档编辑 */ }
    void unlockEditing() { /* 解锁文档编辑 */ }
    void hideOtherComments() { /* 隐藏他人评论 */ }
    void showAllComments() { /* 显示所有评论 */ }
    void startTimer(int durationSeconds) { /* 启动计时器 */ }
    void highlightFirstComment() { /* 高亮第一条评论 */ }
    void createActionItemsSection() { /* 创建行动项区域 */ }
    void finalizeActionItems() { /* 确认行动项 */ }
    void endMeeting() { /* 结束会议 */ }
    void broadcastPhaseChange(MeetingPhase phase) { /* 广播阶段变更 */ }
}
```

## 八、系统总结

### 8.1 核心设计决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 协同算法 | OT (Operational Transformation) | 有中心服务器、实时性要求高、通信开销小 |
| 通信协议 | WebSocket长连接 | 全双工通信、低延迟、支持服务端推送 |
| 文档模型 | 树形结构 + JSON序列化 | 表达力强、适合富文本、便于OT操作 |
| 版本策略 | 操作日志 + 定期快照 | 兼顾存储效率和恢复速度 |
| 路由策略 | 一致性哈希 | 同文档路由到同节点，减少跨节点同步 |
| 缓存策略 | LRU缓存 + 权限缓存 | 热点文档高频访问 |

### 8.2 关键算法总结

1. **OT操作变换**：Insert-Insert、Insert-Delete、Delete-Delete三种组合的变换规则，保证TP1收敛性
2. **CRDT (RGA)**：基于逻辑时钟的字符标识，支持无冲突合并
3. **Myers Diff**：版本差异计算，O(ND)时间复杂度
4. **一致性哈希**：文档路由，150个虚拟节点保证均匀分布
5. **Levenshtein距离**：评论锚点的模糊匹配修复
6. **操作合并**：50ms滑动窗口合并连续输入

### 8.3 设计模式应用

| 设计模式 | 应用场景 |
|----------|----------|
| 策略模式 | 路由策略选择、协同算法选择 |
| 观察者模式 | 操作广播、视野追踪 |
| 中介者模式 | 协同编辑引擎 |
| 状态模式 | 默读会阶段控制 |

| 访问者模式 | 文档树遍历 |
| 模板方法模式 | 存储流程 |

| 享元模式 | 连接管理共享文档状态 |
| 工厂模式 | 连接处理器创建 |
| 发布-订阅模式 | 操作广播 |

### 8.4 性能指标

## 九、全链路实战案例

### 9.1 案例一：多人协同编辑全链路

**场景描述**：用户A和用户B同时打开同一份文档进行编辑。用户A在第5个字符位置插入"Hello"，与此同时用户B在第3个字符位置删除了2个字符。两个操作基于同一版本并发提交到服务端，服务端需要通过OT算法解决冲突，将变换后的操作广播给所有在线用户，最终保证所有客户端文档状态一致，并将操作持久化到操作日志中。

**全链路流程**：

```
用户A编辑(Insert@5) ──→ WebSocket发送 ──→ 接入层路由 ──→ 协同引擎
                                                           │
用户B编辑(Delete@3) ──→ WebSocket发送 ──→ 接入层路由 ──→ 协同引擎
                                                           │
                                                     OT变换处理
                                                           │
                                    ┌──────────────────────┤
                                    ▼                      ▼
                              广播给用户B              广播给用户A
                              (变换后的Insert)         (变换后的Delete)
                                    │                      │
                                    ▼                      ▼
                              用户B应用操作            用户A应用操作
                                    │                      │
                                    └──────────┬───────────┘
                                               ▼
                                         文档状态一致
                                               │
                                               ▼
                                      操作日志持久化
```

```java
/**
 * 多人协同编辑全链路服务
 * 
 * 设计模式：中介者模式(Mediator Pattern) + 命令模式(Command Pattern)
 * - 中介者模式：协同引擎作为中介协调各客户端操作
 * - 命令模式：每个编辑操作封装为命令对象，支持日志记录和回放
 * 
 * 全链路关键节点：
 * 1. 客户端提交操作（附带baseVersion）
 * 2. 服务端OT变换（解决版本差异导致的冲突）
 * 3. 应用到服务端文档模型
 * 4. 持久化操作日志（保证不丢失）
 * 5. 广播变换后的操作给其他客户端
 * 6. 回复ACK给提交者
 */
public class CollaborativeEditService {

    private static final Logger logger = LoggerFactory.getLogger(
        CollaborativeEditService.class);

    private final OTEngine otEngine;
    private final ConcurrentHashMap<String, EditSession> editSessions;
    private final OperationLogRepository operationLogRepository;
    private final WebSocketConnectionManager connectionManager;
    private final IdempotencyChecker idempotencyChecker;
    private final MetricsCollector metricsCollector;

    /**
     * 编辑会话 - 维护单个文档的服务端状态
     * 
     * 线程安全：使用ReentrantLock保证同一文档的操作串行处理
     * 这是OT算法正确性的基础 —— 服务端必须为每个文档维护全序
     */
    public static class EditSession {
        private final String documentId;
        private final ReentrantLock lock = new ReentrantLock();
        private volatile int currentVersion;
        private DocumentState documentState;
        // 操作历史缓存（内存中保留最近1000个操作，用于OT变换）
        private final LinkedList<VersionedOperation> operationHistory;
        private static final int MAX_HISTORY_SIZE = 1000;

        public EditSession(String documentId, DocumentState initialState, 
                           int initialVersion) {
            this.documentId = documentId;
            this.documentState = initialState;
            this.currentVersion = initialVersion;
            this.operationHistory = new LinkedList<>();
        }

        public String getDocumentId() { return documentId; }
        public int getCurrentVersion() { return currentVersion; }
        public DocumentState getDocumentState() { return documentState; }

        /**
         * 获取从指定版本开始的所有操作（用于OT变换）
         */
        public List<Operation> getOperationsSince(int sinceVersion) {
            List<Operation> result = new ArrayList<>();
            for (VersionedOperation vo : operationHistory) {
                if (vo.version > sinceVersion) {
                    result.add(vo.operation);
                }
            }
            return result;
        }

        /**
         * 应用操作到文档状态
         */
        public void applyOperation(Operation op, String userId, int newVersion) {
            this.documentState = this.documentState.apply(op);
            this.currentVersion = newVersion;

            operationHistory.addLast(new VersionedOperation(newVersion, op, userId));
            // 淘汰过早的历史操作
            while (operationHistory.size() > MAX_HISTORY_SIZE) {
                operationHistory.removeFirst();
            }
        }
    }

    /**
     * 带版本号的操作记录
     */
    static class VersionedOperation {
        final int version;
        final Operation operation;
        final String userId;

        VersionedOperation(int version, Operation operation, String userId) {
            this.version = version;
            this.operation = operation;
            this.userId = userId;
        }
    }

    public CollaborativeEditService(OTEngine otEngine,
                                     OperationLogRepository operationLogRepository,
                                     WebSocketConnectionManager connectionManager,
                                     IdempotencyChecker idempotencyChecker,
                                     MetricsCollector metricsCollector) {
        this.otEngine = otEngine;
        this.editSessions = new ConcurrentHashMap<>();
        this.operationLogRepository = operationLogRepository;
        this.connectionManager = connectionManager;
        this.idempotencyChecker = idempotencyChecker;
        this.metricsCollector = metricsCollector;
    }

    /**
     * 处理客户端编辑操作 - 全链路入口
     * 
     * 完整流程：
     * 1. 参数校验与幂等检查
     * 2. 获取文档编辑会话并加锁
     * 3. OT变换（如果客户端版本落后于服务端）
     * 4. 应用操作到服务端文档
     * 5. 持久化操作日志
     * 6. 广播给其他在线客户端
     * 7. 回复ACK给提交者
     * 
     * @param documentId 文档ID
     * @param userId     用户ID
     * @param clientOp   客户端提交的操作
     * @param requestId  请求唯一ID（用于幂等控制）
     * @return 操作处理结果
     */
    public EditResponse processEdit(String documentId, String userId, 
                                     Operation clientOp, String requestId) {
        long startTime = System.currentTimeMillis();
        logger.info("[协同编辑] 收到编辑操作, documentId={}, userId={}, " +
                    "baseVersion={}, opsCount={}, requestId={}", 
                    documentId, userId, clientOp.getBaseVersion(), 
                    clientOp.getOps().size(), requestId);

        try {
            // ===== 步骤1：参数校验 =====
            validateEditRequest(documentId, userId, clientOp);

            // ===== 步骤2：幂等校验 =====
            EditResponse cachedResponse = idempotencyChecker.checkDuplicate(
                documentId, requestId);
            if (cachedResponse != null) {
                logger.info("[协同编辑] 幂等命中, documentId={}, requestId={}, " +
                            "cachedVersion={}", 
                            documentId, requestId, cachedResponse.getNewVersion());
                return cachedResponse;
            }

            // ===== 步骤3：获取编辑会话 =====
            EditSession session = editSessions.get(documentId);
            if (session == null) {
                logger.error("[协同编辑] 文档会话不存在, documentId={}", documentId);
                throw new DocumentNotFoundException(
                    "文档编辑会话不存在: " + documentId);
            }

            // ===== 步骤4：加锁处理（保证同文档操作串行化） =====
            session.lock.lock();
            try {
                return processEditWithLock(session, userId, clientOp, 
                    requestId, startTime);
            } finally {
                session.lock.unlock();
            }

        } catch (DocumentNotFoundException | IllegalArgumentException e) {
            logger.error("[协同编辑] 业务异常, documentId={}, userId={}, error={}", 
                         documentId, userId, e.getMessage());
            throw e;
        } catch (Exception e) {
            logger.error("[协同编辑] 系统异常, documentId={}, userId={}", 
                         documentId, userId, e);
            metricsCollector.incrementCounter("collab.edit.error");
            throw new CollaborationException(
                "编辑操作处理失败: " + e.getMessage(), e);
        }
    }

    /**
     * 持有锁后的操作处理逻辑
     */
    private EditResponse processEditWithLock(EditSession session, String userId, 
                                              Operation clientOp, String requestId,
                                              long startTime) {
        String documentId = session.getDocumentId();
        int clientVersion = clientOp.getBaseVersion();
        int serverVersion = session.getCurrentVersion();

        // ===== 步骤5：OT变换 =====
        Operation transformedOp = clientOp;
        int transformCount = 0;

        if (clientVersion < serverVersion) {
            // 客户端版本落后于服务端，需要对操作进行OT变换
            List<Operation> concurrentOps = session.getOperationsSince(clientVersion);
            transformCount = concurrentOps.size();

            logger.info("[协同编辑] 执行OT变换, documentId={}, clientVersion={}, " +
                        "serverVersion={}, concurrentOpsCount={}", 
                        documentId, clientVersion, serverVersion, transformCount);

            transformedOp = otEngine.transformAgainstAll(clientOp, concurrentOps);

            logger.debug("[协同编辑] OT变换完成, 原始操作={}, 变换后操作={}", 
                         clientOp.getOps(), transformedOp.getOps());
        } else if (clientVersion > serverVersion) {
            // 客户端版本超前（异常情况）
            logger.error("[协同编辑] 客户端版本超前, documentId={}, clientVersion={}, " +
                         "serverVersion={}", documentId, clientVersion, serverVersion);
            throw new IllegalStateException(
                "客户端版本超前: client=" + clientVersion + 
                ", server=" + serverVersion);
        }
        // clientVersion == serverVersion 时无需变换

        // ===== 步骤6：应用操作到服务端文档 =====
        int newVersion = serverVersion + 1;
        session.applyOperation(transformedOp, userId, newVersion);

        logger.info("[协同编辑] 操作已应用, documentId={}, newVersion={}, userId={}", 
                    documentId, newVersion, userId);

        // ===== 步骤7：持久化操作日志 =====
        try {
            OperationLogEntry logEntry = new OperationLogEntry(
                documentId, userId, requestId, transformedOp, 
                newVersion, System.currentTimeMillis());
            operationLogRepository.save(logEntry);

            logger.debug("[协同编辑] 操作日志已持久化, documentId={}, version={}", 
                         documentId, newVersion);
        } catch (Exception e) {
            // 持久化失败：回滚内存状态（关键异常）
            logger.error("[协同编辑] 操作日志持久化失败, documentId={}, version={}, " +
                         "需要回滚内存状态", documentId, newVersion, e);
            // 注意：这里需要回滚session状态，实际生产中应使用更完善的事务机制
            throw new CollaborationException("操作日志持久化失败", e);
        }

        // ===== 步骤8：广播给其他在线客户端 =====
        try {
            BroadcastMessage broadcastMsg = new BroadcastMessage(
                documentId, userId, transformedOp, newVersion, 
                System.currentTimeMillis());
            connectionManager.broadcast(documentId, userId, broadcastMsg);

            logger.debug("[协同编辑] 操作已广播, documentId={}, excludeUser={}", 
                         documentId, userId);
        } catch (Exception e) {
            // 广播失败不回滚（其他客户端会通过重连机制追赶）
            logger.warn("[协同编辑] 操作广播异常（不影响主流程）, documentId={}", 
                        documentId, e);
        }

        // ===== 步骤9：构建响应并缓存（幂等） =====
        EditResponse response = new EditResponse(
            requestId, newVersion, transformedOp, true);

        idempotencyChecker.cacheResponse(documentId, requestId, response, 
            10, TimeUnit.MINUTES);

        // ===== 步骤10：记录指标 =====
        long costTime = System.currentTimeMillis() - startTime;
        metricsCollector.recordLatency("collab.edit.latency", costTime);
        metricsCollector.incrementCounter("collab.edit.success");

        logger.info("[协同编辑] 编辑操作处理完成, documentId={}, userId={}, " +
                    "newVersion={}, transformCount={}, costTime={}ms", 
                    documentId, userId, newVersion, transformCount, costTime);

        return response;
    }

    /**
     * 参数校验
     */
    private void validateEditRequest(String documentId, String userId, 
                                      Operation clientOp) {
        if (documentId == null || documentId.isEmpty()) {
            throw new IllegalArgumentException("documentId不能为空");
        }
        if (userId == null || userId.isEmpty()) {
            throw new IllegalArgumentException("userId不能为空");
        }
        if (clientOp == null || clientOp.getOps() == null || 
            clientOp.getOps().isEmpty()) {
            throw new IllegalArgumentException("操作内容不能为空");
        }
        if (clientOp.getBaseVersion() < 0) {
            throw new IllegalArgumentException(
                "无效的baseVersion: " + clientOp.getBaseVersion());
        }
        // 操作数量限制，防止恶意大批量操作
        if (clientOp.getOps().size() > 10000) {
            throw new IllegalArgumentException(
                "单次操作数量超限: " + clientOp.getOps().size());
        }
    }

    /**
     * 客户端断线重连 - 补齐缺失的操作
     * 
     * 场景：客户端断开WebSocket后重新连接，需要获取断线期间的所有操作
     * 
     * @param documentId     文档ID
     * @param userId         用户ID
     * @param lastKnownVersion 客户端最后已知的版本号
     * @return 缺失的操作列表
     */
    public ReconnectResponse handleReconnect(String documentId, String userId, 
                                               int lastKnownVersion) {
        logger.info("[协同编辑] 客户端重连, documentId={}, userId={}, " +
                    "lastKnownVersion={}", documentId, userId, lastKnownVersion);

        try {
            EditSession session = editSessions.get(documentId);
            if (session == null) {
                throw new DocumentNotFoundException(
                    "文档编辑会话不存在: " + documentId);
            }

            int currentVersion = session.getCurrentVersion();

            if (lastKnownVersion >= currentVersion) {
                // 客户端已是最新版本
                logger.info("[协同编辑] 客户端已是最新版本, documentId={}, version={}", 
                            documentId, currentVersion);
                return new ReconnectResponse(
                    currentVersion, Collections.emptyList(), false);
            }

            // 尝试从内存历史中获取缺失操作
            List<Operation> missedOps = session.getOperationsSince(lastKnownVersion);

            if (missedOps.isEmpty() || 
                missedOps.size() < (currentVersion - lastKnownVersion)) {
                // 内存历史不足，需要从操作日志中恢复
                logger.info("[协同编辑] 内存历史不足, 从操作日志恢复, documentId={}, " +
                            "lastKnownVersion={}, currentVersion={}", 
                            documentId, lastKnownVersion, currentVersion);

                List<OperationLogEntry> logEntries = operationLogRepository
                    .findByDocumentIdAndVersionBetween(
                        documentId, lastKnownVersion + 1, currentVersion);

                missedOps = logEntries.stream()
                    .map(OperationLogEntry::getOperation)
                    .collect(Collectors.toList());
            }

            // 如果缺失操作过多（超过500个），建议客户端全量重载
            boolean needFullReload = missedOps.size() > 500;
            if (needFullReload) {
                logger.info("[协同编辑] 缺失操作过多({}), 建议全量重载, documentId={}", 
                            missedOps.size(), documentId);
            }

            return new ReconnectResponse(currentVersion, missedOps, needFullReload);

        } catch (Exception e) {

    }

/**
 * 幂等检查器 - 基于Redis实现
 * 
 * 设计思路：
 * - 以 documentId:requestId 为key，缓存操作结果
 * - TTL设置为10分钟（覆盖客户端重试窗口）
 * - 同一requestId的重复请求直接返回缓存结果
 */
public class IdempotencyChecker {

    private static final Logger logger = LoggerFactory.getLogger(
        IdempotencyChecker.class);

    private final ConcurrentHashMap<String, EditResponse> cache = 
        new ConcurrentHashMap<>();

    /**
     * 检查是否为重复请求
     * 
     * @return 如果是重复请求返回缓存的响应，否则返回null
     */
    public EditResponse checkDuplicate(String documentId, String requestId) {
        if (requestId == null || requestId.isEmpty()) {
            return null; // 无requestId则不做幂等检查
        }
        String key = documentId + ":" + requestId;
        return cache.get(key);
    }

    /**
     * 缓存操作结果
     */
    public void cacheResponse(String documentId, String requestId, 
                               EditResponse response, long ttl, TimeUnit unit) {
        if (requestId == null || requestId.isEmpty()) {
            return;
        }
        String key = documentId + ":" + requestId;
        cache.put(key, response);

        // 异步清理过期缓存（简化实现，生产环境应使用Redis TTL）
        CompletableFuture.delayedExecutor(ttl, unit).execute(() -> {
            cache.remove(key);
            logger.debug("[幂等] 缓存过期清理, key={}", key);
        });
    }
}
```

### 9.2 案例二：文档版本管理全链路

**场景描述**：用户编辑文档时系统每30秒自动保存一次，每100个操作生成一次版本快照。用户可以查看历史版本列表、对比任意两个版本的差异，并可回滚到指定版本。回滚操作本身也作为一次正向操作记录，保证操作日志的不可变性。

**全链路流程**：

```
用户编辑 ──→ 操作累积 ──→ 自动保存触发（30秒/100操作）──→ 生成版本快照
                                                              │
用户查看历史 ←── 版本列表查询 ←── 快照索引检索 ←──────────────────┘
                  │
                  ▼
用户选择对比 ──→ 加载两个版本快照 ──→ Myers Diff计算差异 ──→ 返回差异结果
                  │
                  ▼
用户确认回滚 ──→ 生成逆向操作 ──→ 作为新版本追加 ──→ 广播给在线用户
```

```java
/**
 * 文档版本管理全链路服务
 * 
 * 设计模式：备忘录模式(Memento Pattern) + 命令模式(Command Pattern)
 * - 备忘录模式：版本快照保存文档在某一时刻的完整状态
 * - 命令模式：回滚操作封装为逆向命令，可追踪、可审计
 * 
 * 核心设计：
 * 1. 自动保存：30秒间隔 + 100操作间隔双触发
 * 2. 增量快照：操作日志 + 定期全量快照，兼顾存储效率和恢复速度
 * 3. 回滚即正向操作：不删除历史，将回滚作为新操作追加
 */
public class DocumentVersionService {

    private static final Logger logger = LoggerFactory.getLogger(
        DocumentVersionService.class);

    // 自动保存间隔（毫秒）
    private static final long AUTO_SAVE_INTERVAL_MS = 30_000;
    // 快照生成间隔（操作数）
    private static final int SNAPSHOT_INTERVAL = 100;
    // 版本快照最大保留数
    private static final int MAX_SNAPSHOTS_PER_DOC = 500;

    private final SnapshotStore snapshotStore;
    private final OperationLogRepository operationLogRepository;
    private final CollaborationEngine collaborationEngine;
    private final WebSocketConnectionManager connectionManager;
    private final IdempotencyChecker idempotencyChecker;
    private final ScheduledExecutorService autoSaveExecutor;

    // 文档ID -> 上次快照的版本号
    private final ConcurrentHashMap<String, Integer> lastSnapshotVersions = 
        new ConcurrentHashMap<>();
    // 文档ID -> 上次自动保存时间
    private final ConcurrentHashMap<String, Long> lastAutoSaveTime = 
        new ConcurrentHashMap<>();

    public DocumentVersionService(SnapshotStore snapshotStore,
                                   OperationLogRepository operationLogRepository,
                                   CollaborationEngine collaborationEngine,
                                   WebSocketConnectionManager connectionManager,
                                   IdempotencyChecker idempotencyChecker) {
        this.snapshotStore = snapshotStore;
        this.operationLogRepository = operationLogRepository;
        this.collaborationEngine = collaborationEngine;
        this.connectionManager = connectionManager;
        this.idempotencyChecker = idempotencyChecker;
        this.autoSaveExecutor = Executors.newScheduledThreadPool(2,
            r -> new Thread(r, "auto-save-" + r.hashCode()));

        // 启动自动保存定时任务
        this.autoSaveExecutor.scheduleAtFixedRate(
            this::autoSaveAllDocuments,
            AUTO_SAVE_INTERVAL_MS, AUTO_SAVE_INTERVAL_MS, TimeUnit.MILLISECONDS);
    }

    /**
     * 自动保存 - 定时扫描所有活跃文档，触发快照生成
     * 
     * 触发条件（满足其一即触发）：
     * 1. 距离上次快照已超过100个操作
     * 2. 距离上次自动保存已超过30秒且有新操作
     */
    private void autoSaveAllDocuments() {
        Map<String, EditSession> activeSessions = collaborationEngine.getAllActiveSessions();

        for (Map.Entry<String, EditSession> entry : activeSessions.entrySet()) {
            String documentId = entry.getKey();
            EditSession session = entry.getValue();

            try {
                int currentVersion = session.getCurrentVersion();
                int lastSnapshotVersion = lastSnapshotVersions
                    .getOrDefault(documentId, 0);
                long lastSaveTime = lastAutoSaveTime
                    .getOrDefault(documentId, 0L);

                boolean needSnapshot = false;
                String reason = "";

                // 条件1：操作数达到快照间隔
                if (currentVersion - lastSnapshotVersion >= SNAPSHOT_INTERVAL) {
                    needSnapshot = true;
                    reason = "操作数达到阈值(" + SNAPSHOT_INTERVAL + ")";
                }

                // 条件2：距上次保存超过30秒且有新操作
                if (!needSnapshot && currentVersion > lastSnapshotVersion &&
                    System.currentTimeMillis() - lastSaveTime > AUTO_SAVE_INTERVAL_MS) {
                    needSnapshot = true;
                    reason = "自动保存间隔到达(30s)";
                }

                if (needSnapshot) {
                    createVersionSnapshot(documentId, currentVersion, 
                        "AUTO_SAVE", reason);
                }
            } catch (Exception e) {
                logger.error("[版本管理] 自动保存异常, documentId={}", documentId, e);
            }
        }
    }

    /**
     * 创建版本快照
     * 
     * 算法步骤：
     * 1. 获取文档当前完整状态
     * 2. 序列化为快照对象
     * 3. 持久化到快照存储
     * 4. 更新快照索引
     * 5. 清理过期快照（超过最大保留数时删除最早的）
     * 
     * @param documentId 文档ID
     * @param version    当前版本号
     * @param trigger    触发来源（AUTO_SAVE / MANUAL / ROLLBACK）
     * @param reason     触发原因描述
     */
    public void createVersionSnapshot(String documentId, int version, 
                                       String trigger, String reason) {
        long startTime = System.currentTimeMillis();
        logger.info("[版本管理] 开始创建快照, documentId={}, version={}, trigger={}, " +
                    "reason={}", documentId, version, trigger, reason);

        try {
            // 1. 获取文档当前状态
            EditSession session = collaborationEngine.getSession(documentId);
            if (session == null) {
                logger.warn("[版本管理] 文档会话不存在, documentId={}", documentId);
                return;
            }

            DocumentState currentState = session.getDocumentState();

            // 2. 构建快照对象
            VersionSnapshot snapshot = new VersionSnapshot();
            snapshot.setSnapshotId(UUID.randomUUID().toString());
            snapshot.setDocumentId(documentId);
            snapshot.setVersion(version);
            snapshot.setDocumentState(currentState.serialize());
            snapshot.setTrigger(trigger);
            snapshot.setReason(reason);
            snapshot.setCreateTime(System.currentTimeMillis());
            snapshot.setDocumentSize(currentState.getContentLength());

            // 3. 持久化快照
            snapshotStore.save(snapshot);

            // 4. 更新内存索引
            lastSnapshotVersions.put(documentId, version);
            lastAutoSaveTime.put(documentId, System.currentTimeMillis());

            // 5. 清理过期快照
            cleanupOldSnapshots(documentId);

            long costTime = System.currentTimeMillis() - startTime;
            logger.info("[版本管理] 快照创建完成, documentId={}, version={}, " +
                        "snapshotId={}, costTime={}ms", 
                        documentId, version, snapshot.getSnapshotId(), costTime);

        } catch (Exception e) {
            logger.error("[版本管理] 快照创建失败, documentId={}, version={}", 
                         documentId, version, e);
            // 快照创建失败不影响主流程，仅记录告警
        }
    }

    /**
     * 清理过期快照 - 保留最近的MAX_SNAPSHOTS_PER_DOC个快照
     */
    private void cleanupOldSnapshots(String documentId) {
        try {
            int totalSnapshots = snapshotStore.countByDocumentId(documentId);
            if (totalSnapshots > MAX_SNAPSHOTS_PER_DOC) {
                int deleteCount = totalSnapshots - MAX_SNAPSHOTS_PER_DOC;
                snapshotStore.deleteOldest(documentId, deleteCount);
                logger.info("[版本管理] 清理过期快照, documentId={}, deleteCount={}", 
                            documentId, deleteCount);
            }
        } catch (Exception e) {
            logger.warn("[版本管理] 清理快照异常, documentId={}", documentId, e);
        }
    }

    /**
     * 查询版本历史列表
     * 
     * @param documentId 文档ID
     * @param page       页码（从1开始）
     * @param pageSize   每页数量
     * @return 版本快照列表（按版本号降序）
     */
    public VersionHistoryResponse getVersionHistory(String documentId, 
                                                      int page, int pageSize) {
        logger.info("[版本管理] 查询版本历史, documentId={}, page={}, pageSize={}", 
                    documentId, page, pageSize);

        try {
            List<VersionSnapshot> snapshots = snapshotStore.findByDocumentId(
                documentId, (page - 1) * pageSize, pageSize);
            int total = snapshotStore.countByDocumentId(documentId);

            List<VersionSummary> summaries = snapshots.stream()
                .map(this::toVersionSummary)
                .collect(Collectors.toList());

            return new VersionHistoryResponse(summaries, total, page, pageSize);

        } catch (Exception e) {
            logger.error("[版本管理] 查询版本历史失败, documentId={}", documentId, e);
            throw new VersionManagementException("查询版本历史失败", e);
        }
    }

    /**
     * 版本快照转摘要信息
     */
    private VersionSummary toVersionSummary(VersionSnapshot snapshot) {
        VersionSummary summary = new VersionSummary();
        summary.setSnapshotId(snapshot.getSnapshotId());
        summary.setVersion(snapshot.getVersion());
        summary.setTrigger(snapshot.getTrigger());
        summary.setReason(snapshot.getReason());
        summary.setCreateTime(snapshot.getCreateTime());
        summary.setDocumentSize(snapshot.getDocumentSize());
        return summary;
    }

    /**
     * 版本对比 - 计算两个版本之间的差异
     * 
     * 算法步骤：
     * 1. 分别恢复两个版本的文档状态
     * 2. 提取纯文本内容
     * 3. 使用Myers Diff算法计算差异
     * 4. 将差异结果按段落组织，便于前端展示
     * 
     * @param documentId  文档ID
     * @param fromVersion 起始版本号
     * @param toVersion   目标版本号
     * @return 差异结果列表
     */
    public VersionDiffResponse compareVersions(String documentId, 
                                                 int fromVersion, int toVersion) {
        long startTime = System.currentTimeMillis();
        logger.info("[版本管理] 开始版本对比, documentId={}, fromVersion={}, toVersion={}", 
                    documentId, fromVersion, toVersion);

        try {
            // 1. 恢复两个版本的文档状态
            DocumentState fromState = restoreDocumentState(documentId, fromVersion);
            DocumentState toState = restoreDocumentState(documentId, toVersion);

            if (fromState == null || toState == null) {
                throw new VersionManagementException(
                    "无法恢复版本状态, fromVersion=" + fromVersion + 
                    ", toVersion=" + toVersion);
            }

            // 2. 提取文本内容，按段落分割
            List<String> fromLines = splitToParagraphs(fromState.toPlainText());
            List<String> toLines = splitToParagraphs(toState.toPlainText());

            // 3. 使用Myers Diff算法按段落计算差异
            List<DiffEntry> diffs = computeParagraphDiff(fromLines, toLines);

            // 4. 统计差异概要
            int addedCount = (int) diffs.stream()
                .filter(d -> d.getType() == DiffType.ADDED).count();
            int deletedCount = (int) diffs.stream()
                .filter(d -> d.getType() == DiffType.DELETED).count();
            int modifiedCount = (int) diffs.stream()
                .filter(d -> d.getType() == DiffType.MODIFIED).count();

            long costTime = System.currentTimeMillis() - startTime;
            logger.info("[版本管理] 版本对比完成, documentId={}, fromVersion={}, " +
                        "toVersion={}, added={}, deleted={}, modified={}, " +
                        "costTime={}ms", documentId, fromVersion, toVersion,
                        addedCount, deletedCount, modifiedCount, costTime);

            return new VersionDiffResponse(diffs, addedCount, deletedCount, 
                                            modifiedCount);

        } catch (VersionManagementException e) {
            throw e;
        } catch (Exception e) {
            logger.error("[版本管理] 版本对比失败, documentId={}", documentId, e);
            throw new VersionManagementException("版本对比失败", e);
        }
    }

    /**
     * 恢复文档到指定版本状态
     * 
     * 算法：快照 + 操作日志回放
     * 1. 找到目标版本之前最近的快照
     * 2. 从快照状态开始，逐个回放操作日志到目标版本
     */
    private DocumentState restoreDocumentState(String documentId, int targetVersion) {
        // 找到最近的快照
        VersionSnapshot snapshot = snapshotStore.findLatestBefore(
            documentId, targetVersion);

        DocumentState state;
        int startVersion;

        if (snapshot != null) {
            state = DocumentState.deserialize(snapshot.getDocumentState());
            startVersion = snapshot.getVersion();
            logger.debug("[版本管理] 从快照恢复, documentId={}, snapshotVersion={}, " +
                         "targetVersion={}", documentId, startVersion, targetVersion);
        } else {
            state = DocumentState.empty();
            startVersion = 0;
            logger.debug("[版本管理] 无可用快照, 从空状态恢复, documentId={}, " +
                         "targetVersion={}", documentId, targetVersion);
        }

        // 回放操作日志
        if (startVersion < targetVersion) {
            List<OperationLogEntry> operations = operationLogRepository
                .findByDocumentIdAndVersionBetween(
                    documentId, startVersion + 1, targetVersion);

            for (OperationLogEntry entry : operations) {
                state = state.apply(entry.getOperation());
            }

            logger.debug("[版本管理] 操作日志回放完成, 回放操作数={}", 
                         operations.size());
        }

        return state;
    }

    /**
     * 版本回滚 - 将文档回滚到指定历史版本
     * 
     * 核心设计：回滚不是删除历史，而是生成一组逆向操作作为新版本追加
     * 这样保证了操作日志的不可变性和完整的审计轨迹
     * 
     * 算法步骤：
     * 1. 恢复目标版本的文档状态
     * 2. 获取当前文档状态
     * 3. 计算从当前状态到目标状态的差异
     * 4. 将差异转换为一组编辑操作
     * 5. 作为新操作提交（经过标准的协同编辑流程）
     * 6. 创建回滚快照，记录回滚元信息
     * 
     * @param documentId    文档ID
     * @param targetVersion 回滚到的目标版本号
     * @param userId        执行回滚的用户ID
     * @param requestId     请求唯一ID（幂等）
     * @return 回滚结果
     */
    public RollbackResponse rollbackToVersion(String documentId, int targetVersion, 
                                                String userId, String requestId) {
        long startTime = System.currentTimeMillis();
        logger.info("[版本管理] 开始版本回滚, documentId={}, targetVersion={}, " +
                    "userId={}, requestId={}", 
                    documentId, targetVersion, userId, requestId);

        try {
            // 幂等校验
            EditResponse cachedResponse = idempotencyChecker.checkDuplicate(
                documentId, requestId);
            if (cachedResponse != null) {
                logger.info("[版本管理] 回滚请求幂等命中, documentId={}, requestId={}", 
                            documentId, requestId);
                return new RollbackResponse(true, cachedResponse.getNewVersion(),
                    "回滚已执行（幂等）");
            }

            // 1. 获取当前文档状态
            EditSession session = collaborationEngine.getSession(documentId);
            if (session == null) {
                throw new VersionManagementException("文档编辑会话不存在");
            }
            int currentVersion = session.getCurrentVersion();
            DocumentState currentState = session.getDocumentState();

            // 2. 校验目标版本有效性
            if (targetVersion <= 0 || targetVersion >= currentVersion) {
                throw new VersionManagementException(
                    "无效的目标版本号: " + targetVersion + 
                    ", 当前版本: " + currentVersion);
            }

            // 3. 恢复目标版本状态
            DocumentState targetState = restoreDocumentState(documentId, targetVersion);

            // 4. 计算差异并生成逆向操作
            String currentText = currentState.toPlainText();
            String targetText = targetState.toPlainText();
            List<AtomicOp> rollbackOps = generateRollbackOperations(
                currentText, targetText);

            logger.info("[版本管理] 生成回滚操作, documentId={}, rollbackOpsCount={}", 
                        documentId, rollbackOps.size());

            // 5. 构建回滚操作并提交到协同引擎
            Operation rollbackOperation = new Operation(
                userId, currentVersion, rollbackOps);
            rollbackOperation.setMetadata("rollback", "true");
            rollbackOperation.setMetadata("rollbackTargetVersion", 
                String.valueOf(targetVersion));

            int newVersion = currentVersion + 1;
            session.applyOperation(rollbackOperation, userId, newVersion);

            // 6. 持久化操作日志
            OperationLogEntry logEntry = new OperationLogEntry(
                documentId, userId, requestId, rollbackOperation, 
                newVersion, System.currentTimeMillis());
            operationLogRepository.save(logEntry);

            // 7. 创建回滚快照
            createVersionSnapshot(documentId, newVersion, "ROLLBACK",
                "回滚到版本v" + targetVersion + ", 操作用户: " + userId);

            // 8. 广播给在线用户
            BroadcastMessage broadcastMsg = new BroadcastMessage(
                documentId, userId, rollbackOperation, newVersion,
                System.currentTimeMillis());
            broadcastMsg.setRollback(true);
            broadcastMsg.setRollbackTargetVersion(targetVersion);

                requestId, newVersion, rollbackOperation, true);

                10, TimeUnit.MINUTES);

            long costTime = System.currentTimeMillis() - startTime;
            logger.info("[版本管理] 版本回滚完成, documentId={}, targetVersion={}, " +
                        "newVersion={}, costTime={}ms", 
                        documentId, targetVersion, newVersion, costTime);

            return new RollbackResponse(true, newVersion,
                "回滚成功，从v" + currentVersion + "回滚到v" + targetVersion);

        } catch (VersionManagementException e) {

        }
    }

    /**

     * 
     * 算法：基于Diff结果生成Insert/Delete操作
     * 1. 使用Myers Diff计算文本差异
     * 2. 将差异条目转换为AtomicOp序列
     * 3. 从后向前生成操作，避免位置偏移问题
     */
    private List<AtomicOp> generateRollbackOperations(String currentText, 
                                                        String targetText) {
        List<DiffEntry> diffs = computeCharDiff(currentText, targetText);
        List<AtomicOp> ops = new ArrayList<>();

        int offset = 0;
        for (DiffEntry diff : diffs) {

                        diff.getPosition() + offset, diff.getContent()));
                    offset -= diff.getContent().length();
                    break;
                case ADDED:

                        diff.getPosition() + offset, diff.getContent()));
                    offset += diff.getContent().length();
                    break;
                default:

            }
```

### 9.3 案例三：文档权限管理全链路

**场景描述**：用户A创建了一份文档后，通过分享链接将文档分享给团队。系统生成带权限控制的分享链接，其他用户通过链接访问时进行多层权限校验。文档所有者可以管理协作者列表，添加或移除协作者，修改协作者的权限角色。权限变更实时生效，已连接的WebSocket会话会收到权限变更通知。

**全链路流程**：

```
所有者创建分享链接 ──→ 生成加密Token ──→ 绑定权限角色 ──→ 持久化分享记录
                                                              │
访问者点击链接 ──→ 解析Token ──→ 校验有效期 ──→ 校验权限层级 ──→ 返回文档
                                                              │
所有者管理协作者 ──→ 添加/移除/修改角色 ──→ 更新权限表 ──→ 清除缓存
                                                              │
                                      实时通知已连接用户 ←──────┘
```

```java
/**
 * 文档权限管理全链路服务
 * 
 * 设计模式：责任链模式(Chain of Responsibility) + 策略模式(Strategy Pattern)
 * - 责任链：多层权限校验依次执行
 * - 策略模式：不同分享类型使用不同的Token生成和校验策略
 * 
 * 权限校验优先级（从高到低）：
 * 1. 所有者权限 -> 2. 直接授权 -> 3. 组织架构权限 -> 4. 链接分享权限
 * 
 * 安全设计：
 * - 分享Token使用AES加密 + HMAC签名
 * - 支持设置过期时间和访问次数限制
 * - 权限变更实时推送到已连接的WebSocket会话
 */
public class DocumentPermissionService {

    private static final Logger logger = LoggerFactory.getLogger(
        DocumentPermissionService.class);

    // 分享Token加密密钥（实际应从配置中心获取）
    private static final String TOKEN_SECRET = "doc-share-secret-key-2024";
    // 分享链接默认有效期（7天）
    private static final long DEFAULT_LINK_EXPIRE_MS = 7 * 24 * 3600 * 1000L;
    // 权限缓存TTL（5分钟）
    private static final long PERMISSION_CACHE_TTL_MS = 5 * 60 * 1000L;

    private final ShareLinkRepository shareLinkRepository;
    private final CollaboratorRepository collaboratorRepository;
    private final PermissionCacheService permissionCacheService;
    private final WebSocketConnectionManager connectionManager;
    private final AuditLogService auditLogService;
    private final IdempotencyChecker idempotencyChecker;

    // ======================== 分享链接管理 ========================

    /**
     * 创建分享链接
     * 
     * 全链路流程：
     * 1. 校验当前用户是否有分享权限（需Admin及以上角色）
     * 2. 根据分享策略生成加密Token
     * 3. 绑定权限角色和有效期
     * 4. 持久化分享记录
     * 5. 记录审计日志
     * 
     * @param documentId 文档ID
     * @param userId     分享操作用户ID
     * @param request    分享请求参数
     * @return 分享链接信息
     */
    public ShareLinkResponse createShareLink(String documentId, String userId, 
                                               ShareLinkRequest request) {
        String requestId = request.getRequestId();
        logger.info("[权限管理] 创建分享链接, documentId={}, userId={}, " +
                    "targetRole={}, expireHours={}", 
                    documentId, userId, request.getTargetRole(), 
                    request.getExpireHours());

        try {
            // 1. 幂等校验
            ShareLinkResponse cachedResponse = checkShareLinkIdempotent(
                documentId, requestId);
            if (cachedResponse != null) {
                logger.info("[权限管理] 分享链接创建幂等命中, documentId={}, requestId={}", 
                            documentId, requestId);
                return cachedResponse;
            }

            // 2. 权限校验 - 只有Admin及以上才能分享
            PermissionManager.Role userRole = getUserRole(userId, documentId);
            if (userRole.getLevel() < PermissionManager.Role.ADMIN.getLevel()) {
                logger.warn("[权限管理] 用户无分享权限, userId={}, documentId={}, " +
                            "currentRole={}", userId, documentId, userRole);
                throw new PermissionDeniedException(
                    "无分享权限，需要管理员或所有者角色");
            }

            // 3. 校验目标角色不能高于当前用户角色
            PermissionManager.Role targetRole = PermissionManager.Role.valueOf(
                request.getTargetRole());
            if (targetRole.getLevel() >= userRole.getLevel()) {
                throw new PermissionDeniedException(
                    "不能分享高于或等于自身的权限角色");
            }

            // 4. 生成加密Token
            long expireTime = System.currentTimeMillis() + 
                (request.getExpireHours() > 0 
                    ? request.getExpireHours() * 3600 * 1000L 
                    : DEFAULT_LINK_EXPIRE_MS);

            ShareToken token = generateShareToken(documentId, targetRole, 
                expireTime, request.getMaxAccessCount());

            // 5. 持久化分享记录
            ShareLinkRecord record = new ShareLinkRecord();
            record.setLinkId(UUID.randomUUID().toString());
            record.setDocumentId(documentId);
            record.setCreatorId(userId);
            record.setToken(token.getTokenString());
            record.setTargetRole(targetRole.name());
            record.setExpireTime(expireTime);
            record.setMaxAccessCount(request.getMaxAccessCount());
            record.setCurrentAccessCount(0);
            record.setStatus("ACTIVE");
            record.setCreateTime(System.currentTimeMillis());
            record.setPasswordProtected(request.getPassword() != null);
            if (request.getPassword() != null) {
                record.setPasswordHash(hashPassword(request.getPassword()));
            }

            shareLinkRepository.save(record);

            // 6. 记录审计日志
            auditLogService.log(AuditEvent.builder()
                .action("CREATE_SHARE_LINK")
                .documentId(documentId)
                .userId(userId)
                .detail("targetRole=" + targetRole + ", expireHours=" + 
                        request.getExpireHours())
                .build());

            // 7. 构建响应
            String shareUrl = buildShareUrl(token.getTokenString());
            ShareLinkResponse response = new ShareLinkResponse(
                record.getLinkId(), shareUrl, targetRole.name(), 
                expireTime, true);

            // 缓存幂等结果
            cacheShareLinkResponse(documentId, requestId, response);

            logger.info("[权限管理] 分享链接创建完成, documentId={}, linkId={}, " +
                        "role={}", documentId, record.getLinkId(), targetRole);

            return response;

        } catch (PermissionDeniedException e) {
            throw e;
        } catch (Exception e) {
            logger.error("[权限管理] 分享链接创建失败, documentId={}, userId={}", 
                         documentId, userId, e);
            throw new PermissionManagementException("分享链接创建失败", e);
        }
    }

    /**
     * 生成分享Token
     * 
     * Token结构：AES(documentId + role + expireTime + maxAccess + nonce) + HMAC签名
     * - AES加密保证Token内容不可被篡改
     * - HMAC签名保证Token完整性
     * - nonce防止Token被预测
     */
    private ShareToken generateShareToken(String documentId, 
                                            PermissionManager.Role role,
                                            long expireTime, int maxAccessCount) {
        try {
            String payload = String.join("|",
                documentId,
                role.name(),
                String.valueOf(expireTime),
                String.valueOf(maxAccessCount),
                UUID.randomUUID().toString()  // nonce
            );

            // AES加密
            String encrypted = AESUtil.encrypt(payload, TOKEN_SECRET);
            // HMAC签名
            String signature = HMACUtil.sign(encrypted, TOKEN_SECRET);
            String tokenString = encrypted + "." + signature;

            return new ShareToken(tokenString, documentId, role, 
                expireTime, maxAccessCount);

        } catch (Exception e) {
            logger.error("[权限管理] Token生成失败, documentId={}", documentId, e);
            throw new PermissionManagementException("分享Token生成失败", e);
        }
    }

    // ======================== 分享链接访问校验 ========================

    /**
     * 通过分享链接访问文档 - 全链路权限校验
     * 
     * 校验流程（责任链模式）：
     * 1. Token格式校验 -> 2. HMAC签名校验 -> 3. Token解密 -> 
     * 4. 有效期校验 -> 5. 访问次数校验 -> 6. 密码校验（可选） -> 
     * 7. 授予对应权限
     * 
     * @param tokenString 分享Token
     * @param accessUserId 访问用户ID
     * @param password     访问密码（可选）
     * @return 访问授权结果
     */
    public ShareAccessResponse accessByShareLink(String tokenString, 
                                                    String accessUserId,
                                                    String password) {
        logger.info("[权限管理] 分享链接访问, accessUserId={}, tokenPrefix={}", 
                    accessUserId, 
                    tokenString.length() > 10 ? tokenString.substring(0, 10) + "..." : tokenString);

        try {
            // ===== 校验1：Token格式校验 =====
            if (tokenString == null || !tokenString.contains(".")) {
                logger.warn("[权限管理] Token格式无效, accessUserId={}", accessUserId);
                throw new InvalidShareLinkException("无效的分享链接");
            }

            String[] parts = tokenString.split("\\.", 2);
            String encryptedPayload = parts[0];
            String signature = parts[1];

            // ===== 校验2：HMAC签名校验 =====
            String expectedSignature = HMACUtil.sign(encryptedPayload, TOKEN_SECRET);
            if (!expectedSignature.equals(signature)) {
                logger.warn("[权限管理] Token签名校验失败, accessUserId={}", 
                            accessUserId);
                throw new InvalidShareLinkException("分享链接签名无效");
            }

            // ===== 校验3：Token解密 =====
            String payload;
            try {
                payload = AESUtil.decrypt(encryptedPayload, TOKEN_SECRET);
            } catch (Exception e) {
                logger.warn("[权限管理] Token解密失败, accessUserId={}", accessUserId);
                throw new InvalidShareLinkException("分享链接无法解析");
            }

            String[] payloadParts = payload.split("\\|");
            if (payloadParts.length < 5) {
                throw new InvalidShareLinkException("分享链接数据损坏");
            }

            String documentId = payloadParts[0];
            PermissionManager.Role grantedRole = PermissionManager.Role.valueOf(
                payloadParts[1]);
            long expireTime = Long.parseLong(payloadParts[2]);
            int maxAccessCount = Integer.parseInt(payloadParts[3]);

            // ===== 校验4：有效期校验 =====
            if (System.currentTimeMillis() > expireTime) {
                logger.warn("[权限管理] 分享链接已过期, documentId={}, expireTime={}", 
                            documentId, expireTime);
                throw new InvalidShareLinkException("分享链接已过期");
            }

            // ===== 校验5：访问次数校验 =====
            ShareLinkRecord record = shareLinkRepository.findByToken(tokenString);
            if (record == null || !"ACTIVE".equals(record.getStatus())) {
                throw new InvalidShareLinkException("分享链接已失效");
            }

            if (maxAccessCount > 0 && 
                record.getCurrentAccessCount() >= maxAccessCount) {
                logger.warn("[权限管理] 分享链接访问次数已用尽, documentId={}, " +
                            "maxAccess={}, currentAccess={}", 
                            documentId, maxAccessCount, 
                            record.getCurrentAccessCount());
                throw new InvalidShareLinkException("分享链接访问次数已用尽");
            }

            // ===== 校验6：密码校验（可选） =====
            if (record.isPasswordProtected()) {
                if (password == null || password.isEmpty()) {
                    return new ShareAccessResponse(false, documentId, null,
                        "NEED_PASSWORD", "请输入访问密码");
                }
                if (!verifyPassword(password, record.getPasswordHash())) {
                    logger.warn("[权限管理] 分享链接密码错误, documentId={}, " +
                                "accessUserId={}", documentId, accessUserId);
                    throw new InvalidShareLinkException("访问密码错误");
                }
            }

            // ===== 校验通过：授予权限 =====
            // 更新访问次数
            shareLinkRepository.incrementAccessCount(record.getLinkId());

            // 将访问者添加到协作者列表（如果尚未存在）
            addCollaboratorIfAbsent(documentId, accessUserId, grantedRole, 
                "SHARE_LINK", record.getLinkId());

            // 清除权限缓存
            permissionCacheService.invalidate(documentId, accessUserId);

            // 记录审计日志
            auditLogService.log(AuditEvent.builder()
                .action("ACCESS_BY_SHARE_LINK")
                .documentId(documentId)
                .userId(accessUserId)
                .detail("grantedRole=" + grantedRole + ", linkId=" + 
                        record.getLinkId())
                .build());

            logger.info("[权限管理] 分享链接访问成功, documentId={}, accessUserId={}, " +
                        "grantedRole={}", documentId, accessUserId, grantedRole);

            return new ShareAccessResponse(true, documentId, grantedRole.name(),
                "SUCCESS", "访问成功");

        } catch (InvalidShareLinkException e) {
            throw e;
        } catch (Exception e) {
            logger.error("[权限管理] 分享链接访问异常, accessUserId={}", 
                         accessUserId, e);
            throw new PermissionManagementException("分享链接访问失败", e);
        }
    }

    // ======================== 协作者管理 ========================

    /**
     * 添加协作者
     * 
     * 全链路流程：
     * 1. 校验操作者权限（需Admin及以上）
     * 2. 校验目标角色合法性
     * 3. 检查目标用户是否已是协作者
     * 4. 持久化协作者记录
     * 5. 清除权限缓存
     * 6. 实时通知目标用户和已连接用户
     * 7. 记录审计日志
     * 
     * @param documentId   文档ID
     * @param operatorId   操作者用户ID
     * @param targetUserId 目标用户ID
     * @param role         授予的角色
     * @param requestId    请求唯一ID（幂等）
     * @return 协作者信息
     */

                                                  String targetUserId, 
                                                  PermissionManager.Role role,

                    "targetUserId={}, role={}, requestId={}", 
                    documentId, operatorId, targetUserId, role, requestId);

        try {
            // 1. 幂等校验
            CollaboratorResponse cachedResponse = checkCollaboratorIdempotent(

            if (existing != null) {

            }

                .detail("role=" + role)
                .build());

            // 缓存幂等结果

            logger.info("[权限管理] 协作者添加完成, documentId={}, targetUserId={}, " +
                        "role={}", documentId, targetUserId, role);

            return response;

        } catch (PermissionDeniedException | PermissionManagementException e) {
            throw e;
        } catch (Exception e) {
            logger.error("[权限管理] 添加协作者失败, documentId={}, targetUserId={}", 
                         documentId, targetUserId, e);
            throw new PermissionManagementException("添加协作者失败", e);
        }
    }

    /**
     * 移除协作者
     * 
     * @param documentId   文档ID
     * @param operatorId   操作者用户ID
     * @param targetUserId 被移除的用户ID
     * @param requestId    请求唯一ID（幂等）
     * @return 操作结果
     */
    public CollaboratorResponse removeCollaborator(String documentId, 
                                                      String operatorId,
                                                      String targetUserId, 
                                                      String requestId) {
        logger.info("[权限管理] 移除协作者, documentId={}, operatorId={}, " +
                    "targetUserId={}, requestId={}", 
                    documentId, operatorId, targetUserId, requestId);

        try {
            // 1. 幂等校验
            CollaboratorResponse cachedResponse = checkCollaboratorIdempotent(
                documentId, requestId);
            if (cachedResponse != null) {
                return cachedResponse;
            }

            // 2. 权限校验
            PermissionManager.Role operatorRole = getUserRole(
                operatorId, documentId);
            PermissionManager.Role targetRole = getUserRole(
                targetUserId, documentId);

            if (operatorRole.getLevel() < PermissionManager.Role.ADMIN.getLevel()) {
                throw new PermissionDeniedException("无权移除协作者");
            }
            // 不能移除同级或更高权限的用户（所有者除外）
            if (operatorRole != PermissionManager.Role.OWNER &&
                targetRole.getLevel() >= operatorRole.getLevel()) {
                throw new PermissionDeniedException(
                    "不能移除同级或更高权限的协作者");
            }

            // 3. 不能移除所有者
            if (targetRole == PermissionManager.Role.OWNER) {
                throw new PermissionManagementException("不能移除文档所有者");
            }

            // 4. 删除协作者记录
            collaboratorRepository.deleteByDocumentIdAndUserId(
                documentId, targetUserId);

            // 5. 清除权限缓存
            permissionCacheService.invalidate(documentId, targetUserId);

            // 6. 实时通知 + 断开目标用户连接
            notifyPermissionChange(documentId, targetUserId, 
                PermissionManager.Role.NONE, PermissionChangeType.REMOVED);
            disconnectUser(documentId, targetUserId);

            // 7. 记录审计日志
            auditLogService.log(AuditEvent.builder()
                .action("REMOVE_COLLABORATOR")
                .documentId(documentId)
                .userId(operatorId)
                .targetUserId(targetUserId)
                .detail("removedRole=" + targetRole)
                .build());

            CollaboratorResponse response = new CollaboratorResponse(
                null, targetUserId, PermissionManager.Role.NONE.name(), true,
                "协作者已移除");

            cacheCollaboratorResponse(documentId, requestId, response);

            logger.info("[权限管理] 协作者移除完成, documentId={}, targetUserId={}", 
                        documentId, targetUserId);

            return response;

        } catch (PermissionDeniedException | PermissionManagementException e) {
            throw e;
        } catch (Exception e) {
            logger.error("[权限管理] 移除协作者失败, documentId={}, targetUserId={}", 
                         documentId, targetUserId, e);
            throw new PermissionManagementException("移除协作者失败", e);
        }
    }

    /**
     * 修改协作者角色
     */
    public CollaboratorResponse updateCollaboratorRole(String documentId, 
                                                         String operatorId,
                                                         String targetUserId,
                                                         PermissionManager.Role newRole,
                                                         String requestId) {
        logger.info("[权限管理] 修改协作者角色, documentId={}, targetUserId={}, " +
                    "newRole={}", documentId, targetUserId, newRole);

        try {
            // 1. 权限校验
            PermissionManager.Role operatorRole = getUserRole(
                operatorId, documentId);
            if (operatorRole.getLevel() < PermissionManager.Role.ADMIN.getLevel()) {
                throw new PermissionDeniedException("无权修改协作者角色");
            }
            if (newRole.getLevel() >= operatorRole.getLevel()) {
                throw new PermissionDeniedException(
                    "不能授予高于或等于自身的角色");
            }

            // 2. 查找现有记录
            CollaboratorRecord record = collaboratorRepository
                .findByDocumentIdAndUserId(documentId, targetUserId);
            if (record == null) {
                throw new PermissionManagementException(
                    "目标用户不是协作者: " + targetUserId);
            }

            String oldRole = record.getRole();

            // 3. 更新角色
            record.setRole(newRole.name());
            record.setUpdateTime(System.currentTimeMillis());
            collaboratorRepository.update(record);

            // 4. 清除权限缓存
            permissionCacheService.invalidate(documentId, targetUserId);

            // 5. 实时通知角色变更
            notifyPermissionChange(documentId, targetUserId, newRole, 
                PermissionChangeType.ROLE_CHANGED);

            // 6. 如果角色降级且用户在线编辑中，需要降级连接权限
            PermissionManager.Role oldRoleEnum = PermissionManager.Role.valueOf(oldRole);
            if (newRole.getLevel() < oldRoleEnum.getLevel()) {
                downgradeConnection(documentId, targetUserId, newRole);
            }

            // 7. 审计日志
            auditLogService.log(AuditEvent.builder()
                .action("UPDATE_COLLABORATOR_ROLE")
                .documentId(documentId)
                .userId(operatorId)
                .targetUserId(targetUserId)
                .detail("oldRole=" + oldRole + ", newRole=" + newRole)
                .build());

            logger.info("[权限管理] 协作者角色修改完成, documentId={}, targetUserId={}, " +
                        "oldRole={}, newRole={}", 
                        documentId, targetUserId, oldRole, newRole);

            return new CollaboratorResponse(
                record.getRecordId(), targetUserId, newRole.name(), true,
                "角色已更新: " + oldRole + " -> " + newRole);

        } catch (PermissionDeniedException | PermissionManagementException e) {
            throw e;
        } catch (Exception e) {
            logger.error("[权限管理] 修改协作者角色失败, documentId={}", documentId, e);
            throw new PermissionManagementException("修改协作者角色失败", e);
        }
    }

    // ======================== 实时通知 ========================

    /**
     * 权限变更实时通知
     * 
     * 通知策略：
     * 1. 通知目标用户权限变更（加入/移除/角色变更）
     * 2. 通知文档所有在线用户协作者列表变更
     * 3. 如果权限降级导致编辑者变为查看者，降级WebSocket连接权限
     */
    private void notifyPermissionChange(String documentId, String targetUserId, 
                                          PermissionManager.Role newRole,
                                          PermissionChangeType changeType) {
        PermissionChangeMessage message = new PermissionChangeMessage();
        message.setDocumentId(documentId);
        message.setTargetUserId(targetUserId);
        message.setNewRole(newRole.name());
        message.setChangeType(changeType.name());
        message.setTimestamp(System.currentTimeMillis());

        // 通知目标用户
        connectionManager.sendToUser(targetUserId, message);

        // 通知文档所有在线用户
        CollaboratorListMessage listMessage = new CollaboratorListMessage();
        listMessage.setDocumentId(documentId);
        listMessage.setCollaborators(getCollaboratorList(documentId));
        listMessage.setChangeType(changeType.name());
        listMessage.setChangedUserId(targetUserId);
        connectionManager.broadcast(documentId, null, listMessage);
    }

    /**
     * 降级WebSocket连接权限
     * 
     * 当协作者角色从Editor降级为Viewer时：
     * 1. 更新连接权限标记
     * 2. 发送权限降级通知
     * 3. 客户端收到后切换为只读模式
     */
    private void downgradeConnection(String documentId, String targetUserId, 
                                       PermissionManager.Role newRole) {
        logger.info("[权限管理] 降级连接权限, documentId={}, targetUserId={}, " +
                    "newRole={}", documentId, targetUserId, newRole);

        PermissionDowngradeMessage message = new PermissionDowngradeMessage();
        message.setDocumentId(documentId);
        message.setNewRole(newRole.name());
        message.setReason("角色已被管理员调整为: " + newRole.name());
        connectionManager.sendToUser(targetUserId, message);
    }

    /**
     * 断开用户连接（移除协作者时）
     */
    private void disconnectUser(String documentId, String targetUserId) {
        logger.info("[权限管理] 断开用户连接, documentId={}, targetUserId={}", 
                    documentId, targetUserId);

        DisconnectMessage message = new DisconnectMessage();
        message.setDocumentId(documentId);
        message.setReason("您已被移除协作者列表");
        connectionManager.sendToUser(targetUserId, message);

        // 延迟断开，给客户端处理时间
        connectionManager.scheduleDisconnect(documentId, targetUserId, 3000);
    }

    // ======================== 辅助方法 ========================

    /**
     * 如果用户不在协作者列表中则添加
     */
    private void addCollaboratorIfAbsent(String documentId, String userId, 
                                           PermissionManager.Role role,
                                           String source, String sourceId) {
        CollaboratorRecord existing = collaboratorRepository
            .findByDocumentIdAndUserId(documentId, userId);
        if (existing == null) {
            CollaboratorRecord record = new CollaboratorRecord();
            record.setRecordId(UUID.randomUUID().toString());
            record.setDocumentId(documentId);
            record.setUserId(userId);
            record.setRole(role.name());
            record.setSource(source);
            record.setSourceId(sourceId);
            record.setCreateTime(System.currentTimeMillis());
            record.setUpdateTime(System.currentTimeMillis());
            collaboratorRepository.save(record);
        }
    }

    /**
     * 获取协作者列表
     */
    private List<CollaboratorInfo> getCollaboratorList(String documentId) {
        List<CollaboratorRecord> records = collaboratorRepository
            .findByDocumentId(documentId);
        return records.stream()
            .map(r -> new CollaboratorInfo(r.getUserId(), r.getRole(), 
                r.getCreateTime()))
            .collect(Collectors.toList());
    }

    private PermissionManager.Role getUserRole(String userId, String documentId) {
        // 优先从缓存获取
        PermissionManager.Role cached = permissionCacheService.get(
            documentId, userId);
        if (cached != null) return cached;

        // 查询权限（复用第七章PermissionManager的多层级聚合逻辑）
        PermissionManager.Role role = PermissionManager.Role.NONE;

        // 检查是否是所有者
        CollaboratorRecord ownerRecord = collaboratorRepository
            .findOwner(documentId);
        if (ownerRecord != null && ownerRecord.getUserId().equals(userId)) {
            role = PermissionManager.Role.OWNER;
        } else {
            CollaboratorRecord record = collaboratorRepository
                .findByDocumentIdAndUserId(documentId, userId);
            if (record != null) {
                role = PermissionManager.Role.valueOf(record.getRole());
            }
        }

        permissionCacheService.put(documentId, userId, role, 
            PERMISSION_CACHE_TTL_MS);
        return role;
    }

    private String buildShareUrl(String token) {
        return "https://docs.example.com/share?token=" + token;
    }

    private String hashPassword(String password) {
        // BCrypt哈希
        return BCryptUtil.hash(password);
    }

    private boolean verifyPassword(String password, String hash) {
        return BCryptUtil.verify(password, hash);
    }

    private ShareLinkResponse checkShareLinkIdempotent(String documentId, 
                                                         String requestId) {
        if (requestId == null) return null;
        return idempotencyChecker.getCachedResponse(
            documentId, "share:" + requestId, ShareLinkResponse.class);
    }

    private void cacheShareLinkResponse(String documentId, String requestId, 
                                          ShareLinkResponse response) {
        if (requestId != null) {
            idempotencyChecker.cacheResponse(
                documentId, "share:" + requestId, response, 
                10, TimeUnit.MINUTES);
        }
    }

    private CollaboratorResponse checkCollaboratorIdempotent(String documentId, 
                                                               String requestId) {
        if (requestId == null) return null;
        return idempotencyChecker.getCachedResponse(
            documentId, "collab:" + requestId, CollaboratorResponse.class);
    }

    private void cacheCollaboratorResponse(String documentId, String requestId, 
                                             CollaboratorResponse response) {
        if (requestId != null) {
            idempotencyChecker.cacheResponse(
                documentId, "collab:" + requestId, response, 
                10, TimeUnit.MINUTES);
        }
    }
```
