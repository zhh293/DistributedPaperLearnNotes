# 购物车系统架构设计

## 一、问题背景

### 1.1 业务场景

购物车是电商交易链路中连接"浏览"与"下单"的核心枢纽。用户在商品详情页点击"加入购物车"后，商品暂存在购物车中，用户可以继续浏览其他商品、修改数量、选择部分商品结算、查看优惠明细，最终提交订单。

一个典型的购物车场景需要满足：

1. **加购/减购/清空**：用户可以自由添加、修改数量、删除商品
2. **多规格支持**：同一商品的不同规格（颜色/尺寸/做法）在购物车中独立计数
3. **实时算价**：购物车中的商品数量变化时，总价、优惠、应付金额需要实时更新
4. **登录/未登录打通**：用户未登录时也能加购，登录后自动合并到正式购物车
5. **多端同步**：用户在APP加购的商品，在网页端也能看到
6. **商品失效处理**：购物车中的商品可能已下架或库存不足，需要标记提示
7. **选中状态管理**：用户可以勾选/取消勾选部分商品进行结算

### 1.2 核心挑战

| 挑战维度 | 具体问题 | 影响 |
|---------|---------|------|
| 数据一致性 | 多端操作购物车，数据不同步 | 用户在APP加购，网页端看不到 |
| 合并冲突 | 未登录购物车与登录购物车合并时，同类商品如何处理 | 重复商品、数量错误 |
| 实时算价 | 优惠规则复杂（满减/折扣/叠加），算价性能要求高 | 页面卡顿、价格错误 |
| 商品失效 | 购物车中的商品可能已下架、价格变更、库存不足 | 下单失败、用户体验差 |
| 存储选型 | 购物车数据高频读写，传统DB扛不住 | 响应慢、数据库压力大 |
| 容量控制 | 用户无限加购导致购物车膨胀 | 内存溢出、性能下降 |

### 1.3 设计目标

| 目标维度 | 具体要求 |
|---------|---------|
| 响应时间 | 加购/减购 P99 < 50ms |
| 算价性能 | 全量算价 P99 < 100ms |
| 多端同步 | 数据变更后 < 3s 全端可见 |
| 购物车上限 | 单车最多 99 个SKU |
| 可用性 | 99.99% |
| 数据可靠性 | 购物车数据不丢失 |

### 2.2 存储选型

购物车数据的特点是**高频读写、低价值、可重建**，因此选择 Redis 为主存储，MySQL 为兜底持久化：

| 存储方案 | 用途 | 理由 |
|---------|------|------|
| Redis Hash | 购物车主存储 | 读写性能高，支持按字段操作 |
| MySQL | 持久化兜底 | Redis宕机后数据恢复 |
| LocalCache | 商品信息缓存 | 减少对商品中心的调用 |

## 三、核心链路设计

### 3.1 加购/减购链路

**问题**：用户点击"加入购物车"，需要原子性地完成"检查商品有效性 → 检查购物车上限 → 合并/新增 → 更新选中状态 → 返回最新购物车"。

**方案**：使用 Redis Lua 脚本保证原子性，避免并发加购导致数量错误。

```java
/**
 * 购物车核心服务
 * 
 * 加购流程：
 * 1. 校验商品是否在售、库存是否充足（调商品中心）
 * 2. 校验购物车是否超过上限（99个SKU）
 * 3. Lua脚本原子操作：判断SKU是否已在购物车 → 已在则数量叠加 → 不在则新增
 * 4. 异步同步到MySQL持久化
 * 5. 返回最新购物车数据
 */
@Service
public class CartService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private ProductFeignClient productClient;

    @Autowired
    private RocketMQTemplate mqTemplate;

    private static final int MAX_CART_SIZE = 99;
    private static final String CART_KEY_PREFIX = "cart:";
    private static final String TEMP_CART_PREFIX = "cart:temp:";

    /**
     * 加购/减购
     */
    public CartVO updateCart(CartUpdateRequest request, Long userId, String deviceId) {
        // 1. 确定购物车Key
        String cartKey = resolveCartKey(userId, deviceId, request.getStoreId());

        // 2. 校验商品有效性（调用商品中心）
        ProductDTO product = productClient.getProduct(request.getSpuId(), request.getStoreId());
        if (product == null || !product.isOnSale()) {
            throw new BizException("商品已下架");
        }
        if (product.getStock() < request.getQuantity()) {
            throw new BizException("库存不足");
        }

        // 3. 校验价格一致性（防止用户加购后商品涨价/降价）
        if (request.getPrice() != product.getCurrentPrice()) {
            // 价格已变更，使用最新价格
            request.setPrice(product.getCurrentPrice());
        }

        // 4. Lua脚本原子操作：检查上限 + 合并/新增
        String luaScript =
            // 获取当前购物车大小
            "local cartSize = redis.call('HLEN', KEYS[1])\n" +
            // 检查SKU是否已存在
            "local exists = redis.call('HEXISTS', KEYS[1], ARGV[1])\n" +
            "if exists == 0 and cartSize >= tonumber(ARGV[2]) then\n" +
            "    return -1\n" +  // 购物车已满
            "end\n" +
            // 如果已存在，读取当前数据并合并数量
            "if exists == 1 then\n" +
            "    local data = cjson.decode(redis.call('HGET', KEYS[1], ARGV[1]))\n" +
            "    data.quantity = data.quantity + tonumber(ARGV[3])\n" +
            "    if data.quantity <= 0 then\n" +
            "        redis.call('HDEL', KEYS[1], ARGV[1])\n" +
            "        return 0\n" +
            "    end\n" +
            "    data.selected = true\n" +
            "    data.price = tonumber(ARGV[4])\n" +
            "    redis.call('HSET', KEYS[1], ARGV[1], cjson.encode(data))\n" +
            "    return 1\n" +
            "else\n" +
            // 新增SKU到购物车
            "    local data = {\n" +
            "        skuId = tonumber(ARGV[5]),\n" +
            "        spuId = tonumber(ARGV[6]),\n" +
            "        name = ARGV[7],\n" +
            "        quantity = tonumber(ARGV[3]),\n" +
            "        selected = true,\n" +
            "        price = tonumber(ARGV[4]),\n" +
            "        specs = ARGV[8],\n" +
            "        addTime = tonumber(ARGVV[9])\n" +
            "    }\n" +
            "    redis.call('HSET', KEYS[1], ARGV[1], cjson.encode(data))\n" +
            "    return 1\n" +
            "end";

        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(luaScript);
        script.setResultType(Long.class);

        String skuKey = request.getSpuId() + "_" + request.getSpecs();
        long now = System.currentTimeMillis() / 1000;

        Long result = redisTemplate.execute(script,
            Collections.singletonList(cartKey),
            skuKey,
            String.valueOf(MAX_CART_SIZE),
            String.valueOf(request.getQuantity()),
            String.valueOf(request.getPrice()),
            String.valueOf(request.getSkuId()),
            String.valueOf(request.getSpuId()),
            request.getName(),
            request.getSpecs() != null ? request.getSpecs() : "",
            String.valueOf(now));

        if (result == null || result == -1L) {
            throw new BizException("购物车已满，最多存放" + MAX_CART_SIZE + "种商品");
        }

        // 5. 异步同步到MySQL（通过MQ）
        CartSyncMessage syncMsg = new CartSyncMessage();
        syncMsg.setUserId(userId);
        syncMsg.setDeviceId(deviceId);
        syncMsg.setStoreId(request.getStoreId());
        syncMsg.setOperation("UPDATE");
        syncMsg.setSkuKey(skuKey);
        mqTemplate.asyncSend("cart-sync-topic", syncMsg, new SendCallback() {
            @Override
            public void onSuccess(SendResult r) {}
            @Override
            public void onException(Throwable e) {
                log.error("购物车同步MQ失败", e);
            }
        });

        // 6. 返回最新购物车
        return getCart(userId, deviceId, request.getStoreId());
    }

    /**
     * 解析购物车Key
     */
    private String resolveCartKey(Long userId, String deviceId, Long storeId) {
        String prefix;
        if (userId != null && userId > 0) {
            prefix = CART_KEY_PREFIX + userId;
        } else {
            prefix = TEMP_CART_PREFIX + deviceId;
        }
        return prefix + ":" + storeId;
    }

    /**
     * 查询购物车
     */
    public CartVO getCart(Long userId, String deviceId, Long storeId) {
        String cartKey = resolveCartKey(userId, deviceId, storeId);
        Map<Object, Object> rawCart = redisTemplate.opsForHash().entries(cartKey);

        CartVO vo = new CartVO();
        List<CartItemVO> items = new ArrayList<>();

        for (Map.Entry<Object, Object> entry : rawCart.entrySet()) {
            CartItemVO item = JSON.parseObject(
                entry.getValue().toString(), CartItemVO.class);
            items.add(item);
        }

        // 按加购时间排序
        items.sort(Comparator.comparingLong(CartItemVO::getAddTime).reversed());
        vo.setItems(items);
        return vo;
    }

    /**
     * 清空购物车
     */
    public void clearCart(Long userId, String deviceId, Long storeId) {
        String cartKey = resolveCartKey(userId, deviceId, storeId);
        redisTemplate.delete(cartKey);

        // 异步同步
        CartSyncMessage syncMsg = new CartSyncMessage();
        syncMsg.setUserId(userId);
        syncMsg.setStoreId(storeId);
        syncMsg.setOperation("CLEAR");
        mqTemplate.syncSend("cart-sync-topic", syncMsg);
    }
}
```

### 3.2 登录/未登录购物车合并

**问题**：用户未登录时在临时购物车（按deviceId标识）中加购了商品，登录后需要将临时购物车的商品合并到正式购物车（按userId标识）中。

**合并策略**：
- 同一SKU：数量相加
- 不同SKU：直接添加
- 合并后清空临时购物车

```java
/**
 * 购物车合并服务
 * 
 * 合并流程：
 * 1. 读取临时购物车（cart:temp:{deviceId}:{storeId}）
 * 2. 读取正式购物车（cart:{userId}:{storeId}）
 * 3. 遍历临时购物车，逐个SKU合并到正式购物车
 * 4. 合并规则：同一SKU数量叠加，不同SKU直接添加
 * 5. 合并后删除临时购物车
 * 6. 检查合并后是否超过上限
 */
@Service
public class CartMergeService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 登录时合并购物车
     */
    public void mergeCart(Long userId, String deviceId, Long storeId) {
        String tempCartKey = "cart:temp:" + deviceId + ":" + storeId;
        String userCartKey = "cart:" + userId + ":" + storeId;

        // 1. 读取临时购物车
        Map<Object, Object> tempCart = redisTemplate.opsForHash().entries(tempCartKey);
        if (tempCart.isEmpty()) {
            return; // 临时购物车为空，无需合并
        }

        // 2. 读取正式购物车当前大小
        Long userCartSize = redisTemplate.opsForHash().size(userCartKey);

        // 3. 逐个SKU合并
        for (Map.Entry<Object, Object> entry : tempCart.entrySet()) {
            String skuKey = entry.getKey().toString();
            String tempItemJson = entry.getValue().toString();
            CartItemVO tempItem = JSON.parseObject(tempItemJson, CartItemVO.class);

            // 检查正式购物车是否已有该SKU
            String existItemJson = (String) redisTemplate.opsForHash()
                .get(userCartKey, skuKey);

            if (existItemJson != null) {
                // 已存在：数量叠加
                CartItemVO existItem = JSON.parseObject(existItemJson, CartItemVO.class);
                existItem.setQuantity(existItem.getQuantity() + tempItem.getQuantity());

                // 检查数量上限
                if (existItem.getQuantity() > 99) {
                    existItem.setQuantity(99);
                }

                redisTemplate.opsForHash().put(userCartKey, skuKey,
                    JSON.toJSONString(existItem));
            } else {
                // 不存在：检查购物车是否已满
                if (userCartSize >= 99) {
                    break; // 购物车已满，停止合并
                }
                redisTemplate.opsForHash().put(userCartKey, skuKey, tempItemJson);
                userCartSize++;
            }
        }

        // 4. 删除临时购物车
        redisTemplate.delete(tempCartKey);

        log.info("购物车合并完成, userId={}, deviceId={}, storeId={}",
            userId, deviceId, storeId);
    }
}
```

### 3.3 实时算价引擎

**问题**：购物车中商品数量变化时，需要实时计算总价、优惠金额、应付金额。优惠规则可能涉及满减、折扣、优惠券叠加等。

**方案**：使用策略模式 + 责任链模式实现算价引擎。

```java
/**
 * 算价引擎
 * 
 * 算价流程：
 * 1. 计算商品小计 = 数量 × 单价
 * 2. 计算商品总价 = 所有选中商品小计之和
 * 3. 应用门店活动优惠（满减/满赠）→ 策略模式
 * 4. 应用优惠券（如果用户选了券）→ 策略模式
 * 5. 应用会员折扣 → 策略模式
 * 6. 计算打包费（如果打包带走）
 * 7. 计算应付金额 = 总价 - 优惠 + 打包费
 */
@Service
public class PriceCalculateService {

    @Autowired
    private List<DiscountStrategy> discountStrategies;

    @Autowired
    private List<PromotionStrategy> promotionStrategies;

    /**
     * 全量算价
     */
    public PriceDetailVO calculate(CartVO cart, Long userId, Long storeId,
                                    boolean isTakeout) {
        PriceDetailVO detail = new PriceDetailVO();

        // 1. 计算商品总价（只算选中的商品）
        int itemTotal = 0;
        List<CartItemVO> selectedItems = cart.getItems().stream()
            .filter(CartItemVO::isSelected)
            .collect(Collectors.toList());

        for (CartItemVO item : selectedItems) {
            int itemSubtotal = item.getPrice() * item.getQuantity();
            itemTotal += itemSubtotal;
        }
        detail.setItemTotal(itemTotal);

        // 2. 应用促销活动优惠（满减/折扣/满赠）
        // 使用责任链模式，按优先级依次应用
        int promotionDiscount = 0;
        for (PromotionStrategy strategy : promotionStrategies) {
            if (strategy.supports(storeId, itemTotal)) {
                PromotionResult result = strategy.apply(selectedItems, itemTotal);
                promotionDiscount += result.getDiscountAmount();
                detail.addPromotionDetail(result);
            }
        }
        detail.setPromotionDiscount(promotionDiscount);

        // 3. 应用优惠券
        int couponDiscount = 0;
        for (DiscountStrategy strategy : discountStrategies) {
            if (strategy.supports(userId, itemTotal)) {
                DiscountResult result = strategy.apply(selectedItems,
                    itemTotal - promotionDiscount);
                couponDiscount += result.getDiscountAmount();
                detail.addCouponDetail(result);
                break; // 同类型优惠只取最优一个
            }
        }
        detail.setCouponDiscount(couponDiscount);

        // 4. 计算打包费
        int packingFee = 0;
        if (isTakeout) {
            packingFee = calculatePackingFee(selectedItems);
        }
        detail.setPackingFee(packingFee);

        // 5. 计算应付金额
        int payable = itemTotal - promotionDiscount - couponDiscount + packingFee;
        if (payable < 0) payable = 0; // 应付不能为负
        detail.setPayableAmount(payable);

        return detail;
    }

    /**
     * 计算打包费
     */
    private int calculatePackingFee(List<CartItemVO> items) {
        // 按商品类型计算打包费
        // 例如：汤类2元，普通菜1元，饮料0.5元
        int fee = 0;
        for (CartItemVO item : items) {
            fee += item.getPackingFee() * item.getQuantity();
        }
        return fee;
    }
}

/**
 * 促销策略接口（策略模式）
 */
public interface PromotionStrategy {
    boolean supports(Long storeId, int itemTotal);
    PromotionResult apply(List<CartItemVO> items, int itemTotal);
}

/**
 * 满减策略
 */
@Component
public class FullReductionStrategy implements PromotionStrategy {

    @Override
    public boolean supports(Long storeId, int itemTotal) {
        // 查询门店是否有满减活动
        return hasActivePromotion(storeId, itemTotal);
    }

    @Override
    public PromotionResult apply(List<CartItemVO> items, int itemTotal) {
        // 查询满减规则：满50减5，满100减15
        PromotionRule rule = getBestRule(itemTotal);
        if (rule == null) {
            return PromotionResult.empty();
        }

        PromotionResult result = new PromotionResult();
        result.setPromotionName(rule.getName());
        result.setDiscountAmount(rule.getReductionAmount());
        return result;
    }
}
```

### 3.4 商品失效检测

**问题**：用户购物车中的商品可能已经下架、价格变更或库存不足。需要在用户查看购物车时检测并标记。

**方案**：异步批量检测 + 缓存失效标记。

```java
/**
 * 商品失效检测服务
 * 
 * 检测流程：
 * 1. 用户查看购物车时，异步触发检测
 * 2. 批量调用商品中心查询商品状态
 * 3. 标记失效商品（下架/库存不足/价格变更）
 * 4. 前端展示失效提示
 */
@Service
public class CartItemValidityService {

    @Autowired
    private ProductFeignClient productClient;

    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 异步检测购物车商品有效性
     */
    @Async("cartTaskExecutor")
    public void checkCartItemsValidity(Long userId, Long storeId) {
        String cartKey = "cart:" + userId + ":" + storeId;
        Map<Object, Object> cart = redisTemplate.opsForHash().entries(cartKey);

        if (cart.isEmpty()) return;

        // 1. 批量查询商品状态（减少RPC调用次数）
        List<Long> spuIds = cart.values().stream()
            .map(v -> JSON.parseObject(v.toString()).getLong("spuId"))
            .distinct()
            .collect(Collectors.toList());

        Map<Long, ProductStatusDTO> statusMap = productClient
            .batchQueryStatus(spuIds, storeId);

        // 2. 逐个检查并标记
        for (Map.Entry<Object, Object> entry : cart.entrySet()) {
            String skuKey = entry.getKey().toString();
            CartItemVO item = JSON.parseObject(entry.getValue().toString(), CartItemVO.class);

            ProductStatusDTO status = statusMap.get(item.getSpuId());
            if (status == null) continue;

            boolean needUpdate = false;

            // 检查是否下架
            if (!status.isOnSale()) {
                item.setInvalidReason("商品已下架");
                item.setInvalid(true);
                needUpdate = true;
            }
            // 检查库存
            else if (status.getStock() < item.getQuantity()) {
                item.setInvalidReason("库存不足，当前库存" + status.getStock());
                item.setInvalid(status.getStock() == 0);
                needUpdate = true;
            }
            // 检查价格变更
            else if (status.getCurrentPrice() != item.getPrice()) {
                item.setPrice(status.getCurrentPrice());
                item.setPriceChanged(true);
                needUpdate = true;
            }

            if (needUpdate) {
                redisTemplate.opsForHash().put(cartKey, skuKey,
                    JSON.toJSONString(item));
            }
        }
    }
}
```

### 3.6 MySQL 持久化

**问题**：Redis 是内存存储，宕机会丢数据。需要将购物车数据持久化到MySQL。

**方案**：通过MQ异步同步，不阻塞主流程。

```java
/**
 * 购物车MySQL持久化消费者
 */
@Component
@RocketMQMessageListener(topic = "cart-sync-topic",
    consumerGroup = "cart-mysql-sync-group")
public class CartMysqlSyncConsumer implements RocketMQListener<CartSyncMessage> {

    @Autowired
    private CartItemMapper cartItemMapper;

    @Override
    public void onMessage(CartSyncMessage msg) {
        if ("CLEAR".equals(msg.getOperation())) {
            // 清空操作
            cartItemMapper.deleteByUserAndStore(msg.getUserId(), msg.getStoreId());
            return;
        }

        if ("UPDATE".equals(msg.getOperation())) {
            // 更新操作：先查后upsert
            CartItemDO existItem = cartItemMapper.selectByUserAndSku(
                msg.getUserId(), msg.getStoreId(), msg.getSkuKey());

            if (existItem != null) {
                // 更新数量
                cartItemMapper.updateQuantity(
                    msg.getUserId(), msg.getStoreId(), msg.getSkuKey(),
                    msg.getQuantity());
            } else {
                // 新增
                CartItemDO newItem = new CartItemDO();
                newItem.setUserId(msg.getUserId());
                newItem.setStoreId(msg.getStoreId());
                newItem.setSkuKey(msg.getSkuKey());
                newItem.setSpuId(msg.getSpuId());
                newItem.setQuantity(msg.getQuantity());
                newItem.setCreateTime(new Date());
                newItem.setUpdateTime(new Date());
                cartItemMapper.insert(newItem);
            }
        }
    }
}
```

```java
        ProductDTO cached = localCache.getIfPresent(spuId);

            return cached;
        }

        if (json != null) {
            ProductDTO product = JSON.parseObject(json, ProductDTO.class);

        // 3. 调用商品中心（带超时和降级）
        try {
            ProductDTO product = productClient.getProduct(spuId, storeId);
            if (product != null) {
                // 写入缓存
                redisTemplate.opsForValue().set(redisKey,
                    JSON.toJSONString(product), 10, TimeUnit.MINUTES);
                localCache.put(spuId, product);
            }
            return product;
        } catch (Exception e) {
            log.warn("商品中心调用失败, spuId={}, 降级返回null", spuId, e);
            return null; // 降级：返回null，前端展示"商品信息加载中"
        }
    }
```

```java
/**
 * 加购幂等控制
 * 
 * 防止用户快速双击导致重复加购
 */
public CartVO updateCartWithIdempotent(CartUpdateRequest request,
                                        Long userId, String deviceId,
                                        String requestId) {
    // 1. 幂等检查：同一requestId 60秒内只处理一次
    String idempotentKey = "cart:idempotent:" + requestId;
    Boolean isNew = redisTemplate.opsForValue()
        .setIfAbsent(idempotentKey, "1", 60, TimeUnit.SECONDS);

    if (isNew == null || !isNew) {
        // 重复请求，返回当前购物车
        return getCart(userId, deviceId, request.getStoreId());
    }

    // 2. 正常处理
    return updateCart(request, userId, deviceId);
}
```

### 5.3 购物车容量控制

```java
/**
 * 购物车容量控制策略
 * - 单车最多99个SKU
 * - 单SKU数量最多99
 * - 超限时LRU淘汰最早的商品
 */
public void enforceCartLimit(String cartKey, int maxItems) {
    Long size = redisTemplate.opsForHash().size(cartKey);
    if (size > maxItems) {
        // 超限：按addTime淘汰最早加入的商品
        int toRemove = size.intValue() - maxItems;
        Map<Object, Object> allItems = redisTemplate.opsForHash().entries(cartKey);

        allItems.entrySet().stream()
            .sorted(Comparator.comparingLong(e ->
                JSON.parseObject(e.getValue().toString()).getLong("addTime")))
            .limit(toRemove)
            .forEach(e -> redisTemplate.opsForHash()
                .delete(cartKey, e.getKey()));
    }
}
```

## 六、最佳实践与总结

### 6.1 设计原则

1. **Redis优先**：购物车是高频低价值数据，Redis Hash 是最佳存储方案
2. **异步持久化**：MySQL 通过MQ异步同步，不阻塞主流程
3. **算价策略化**：用策略模式 + 责任链模式实现优惠算价，可灵活扩展
4. **失效友好**：商品下架不删除购物车记录，而是标记失效，给用户选择
5. **合并幂等**：登录合并时同一SKU数量叠加，合并后清空临时购物车

### 6.2 核心设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 存储方案 | Redis Hash | 读写性能高，按字段操作灵活 |
| 持久化 | MQ异步写MySQL | 不阻塞主流程，Redis宕机可恢复 |
| 算价引擎 | 策略模式+责任链 | 优惠规则可灵活扩展 |
| 合并策略 | 同SKU叠加 | 简单直观，用户预期一致 |
| 选中状态 | Redis Set独立存储 | 避免频繁修改Hash中的JSON |
| 多端同步 | MQ广播+WebSocket | 实时性好，解耦清晰 |

### 6.3 容易踩的坑

1. **合并后超出上限**：合并时必须检查购物车SKU数量，超限则停止合并
2. **价格不一致**：加购时的价格可能已过期，算价时必须用商品中心的最新价格
3. **并发加购数量错误**：必须用Lua脚本保证"检查+合并"的原子性
4. **临时购物车丢失**：deviceId依赖Cookie，清Cookie后临时购物车丢失，需引导用户登录
5. **算价精度问题**：金额用整数分计算，避免浮点数精度问题
6. **失效商品参与算价**：算价时必须过滤掉失效商品，否则金额错误

#### 7.1.2 第 1 步：Controller 入口与参数校验

```java
/**
 * 购物车对外接口
 */
@Slf4j
@RestController
@RequestMapping("/cart")
public class CartController {

    @Autowired
    private CartFacadeService cartFacadeService;

    /**
     * 加入购物车
     *
     * @param request   加购请求体
     * @param requestId 前端生成的幂等 ID（防重复提交，双击/网络重试）
     */
    @PostMapping("/add")
    public Result<CartAddResultVO> addToCart(
            @RequestBody @Valid CartAddRequest request,
            @RequestHeader(value = "X-Request-Id", required = false) String requestId) {

        // ① 参数基础校验（@Valid 已校验非空/范围，这里做业务级补充校验）
        if (request.getQuantity() <= 0 || request.getQuantity() > 99) {
            return Result.fail(CartErrorCode.PARAM_INVALID, "加购数量必须在 1~99 之间");
        }
        if (request.getSkuId() == null || request.getSpuId() == null) {
            return Result.fail(CartErrorCode.PARAM_INVALID, "商品标识不能为空");
        }

        // ② 从登录上下文解析用户态（网关鉴权后写入 ThreadLocal）
        //    已登录：userId 非空；未登录：userId 为空，使用 deviceId
        UserContext ctx = UserContextHolder.get();
        Long userId = ctx.getUserId();          // 未登录时为 null
        String deviceId = ctx.getDeviceId();    // 设备指纹，未登录时必须存在

        if (userId == null && StringUtils.isBlank(deviceId)) {
            // 既未登录、又没有设备标识，无法定位购物车
            return Result.fail(CartErrorCode.NO_IDENTITY, "无法识别用户身份，请重新进入");
        }

        // requestId 缺失时用服务端兜底生成（幂等窗口内仍能防重）
        if (StringUtils.isBlank(requestId)) {
            requestId = "auto:" + userId + ":" + deviceId + ":"
                    + request.getSkuId() + ":" + (System.currentTimeMillis() / 1000);
        }

        try {
            CartAddResultVO vo = cartFacadeService.addToCart(request, userId, deviceId, requestId);
            return Result.success(vo);
        } catch (BizException e) {
            // 业务异常：下架/库存不足/限购/购物车满，返回明确错误码给前端提示
            log.warn("[cart-add] 加购业务异常 userId={}, deviceId={}, skuId={}, code={}, msg={}",
                    userId, deviceId, request.getSkuId(), e.getCode(), e.getMessage());
            return Result.fail(e.getCode(), e.getMessage());
        } catch (Exception e) {
            // 系统异常：兜底返回，避免异常栈暴露给前端
            log.error("[cart-add] 加购系统异常 userId={}, deviceId={}, skuId={}",
                    userId, deviceId, request.getSkuId(), e);
            return Result.fail(CartErrorCode.SYSTEM_ERROR, "系统繁忙，请稍后再试");
        }
    }
}
```

```java
    private StringRedisTemplate redisTemplate;
    @Autowired
    private ProductInfoService productInfoService;
    @Autowired
    private CartAtomicService cartAtomicService;
    @Autowired
    private RocketMQTemplate mqTemplate;

    private static final int MAX_CART_SIZE = 99;
    private static final int MAX_SKU_QUANTITY = 99;

    public CartAddResultVO addToCart(CartAddRequest req, Long userId,
                                     String deviceId, String requestId) {
        // ③ 幂等校验：同一 requestId 在 60s 内只处理一次（防双击 / 网络重试）
        String idempotentKey = "cart:idem:" + requestId;
        Boolean firstTime = redisTemplate.opsForValue()
                .setIfAbsent(idempotentKey, "1", 60, TimeUnit.SECONDS);
        if (Boolean.FALSE.equals(firstTime)) {
            log.info("[cart-add] 命中幂等，直接返回当前摘要 requestId={}", requestId);
            return buildSummary(resolveCartKey(userId, deviceId, req.getStoreId()));
        }

        // ④ 确定购物车 Key：已登录→正式车 cart:{userId}:{storeId}；
        //    未登录→临时车 cart:temp:{deviceId}:{storeId}
        String cartKey = resolveCartKey(userId, deviceId, req.getStoreId());

        // ⑤ 商品有效性校验（RPC 商品中心）：下架 / 库存 / 限购 / 最新价
        ProductCheckResult check = productInfoService.checkForAdd(
                req.getSpuId(), req.getSkuId(), req.getStoreId(), req.getQuantity(), userId);
        if (!check.isOnSale()) {
            throw new BizException(CartErrorCode.OFF_SHELF, "商品已下架");
        }
        if (check.getStock() < req.getQuantity()) {
            throw new BizException(CartErrorCode.OUT_OF_STOCK, "库存不足，仅剩 " + check.getStock() + " 件");
        }

        // ⑥ Redis Lua 原子写入（上限 + 限购 + 合并/新增 一次完成）
        String skuKey = req.getSpuId() + "_" + (req.getSpecs() == null ? "" : req.getSpecs());
        CartWriteResult writeResult = cartAtomicService.addOrMerge(
                cartKey, skuKey, req, check.getLatestPrice(), check.getPurchaseLimit());

        // 处理原子脚本返回的各类边界
        switch (writeResult.getCode()) {
            case CartWriteResult.CART_FULL:
                throw new BizException(CartErrorCode.CART_FULL,
                        "购物车最多存放 " + MAX_CART_SIZE + " 种商品");
            case CartWriteResult.SKU_QUANTITY_LIMIT:
                throw new BizException(CartErrorCode.SKU_LIMIT,
                        "单个商品最多购买 " + MAX_SKU_QUANTITY + " 件");
            case CartWriteResult.PURCHASE_LIMIT:
                throw new BizException(CartErrorCode.PURCHASE_LIMIT,
                        "该商品限购 " + check.getPurchaseLimit() + " 件");
            case CartWriteResult.SUCCESS:
                break;
            default:
                throw new BizException(CartErrorCode.SYSTEM_ERROR, "加购失败");
        }

        // ⑦ MQ 异步持久化（幂等 msgKey = cartKey:skuKey:version，消费端幂等落库）
        sendSyncMessage(userId, deviceId, req, skuKey, writeResult.getFinalQuantity());

        // ⑧ 组装并返回购物车摘要
        CartAddResultVO vo = buildSummary(cartKey);
        vo.setAddedSkuKey(skuKey);
        vo.setAddedQuantity(writeResult.getFinalQuantity());
        if (check.isPriceChanged(req.getDisplayPrice())) {
            vo.setPriceChangedTip("商品价格已更新为 ¥" + fmt(check.getLatestPrice()));
        }
        log.info("[cart-add] 加购成功 userId={}, deviceId={}, skuKey={}, qty={}, totalKinds={}",
                userId, deviceId, skuKey, writeResult.getFinalQuantity(), vo.getTotalKinds());
        return vo;
    }

    private String resolveCartKey(Long userId, String deviceId, Long storeId) {
        if (userId != null && userId > 0) {
            return "cart:" + userId + ":" + storeId;
        }
        return "cart:temp:" + deviceId + ":" + storeId;
    }

    /**
     * MQ 异步持久化：主流程不等待落库结果，发送失败仅告警（Redis 已成功，可后续对账补偿）
     */
    private void sendSyncMessage(Long userId, String deviceId, CartAddRequest req,
                                 String skuKey, int finalQuantity) {
        CartSyncMessage msg = new CartSyncMessage();
        msg.setUserId(userId);
        msg.setDeviceId(deviceId);
        msg.setStoreId(req.getStoreId());
        msg.setSkuKey(skuKey);
        msg.setSpuId(req.getSpuId());
        msg.setSkuId(req.getSkuId());
        msg.setQuantity(finalQuantity);
        msg.setOperation("UPSERT");
        msg.setBizKey(userId + ":" + skuKey + ":" + System.currentTimeMillis()); // 幂等键
        try {
            Message<CartSyncMessage> m = MessageBuilder.withPayload(msg)
                    .setHeader(RocketMQHeaders.KEYS, msg.getBizKey())
                    .build();
            mqTemplate.asyncSend("cart-sync-topic", m, new SendCallback() {
                @Override public void onSuccess(SendResult r) { }
                @Override public void onException(Throwable e) {
                    // Redis 已写成功，MQ 发送失败不影响用户，靠定时对账补偿落库
                    log.error("[cart-add] 持久化 MQ 发送失败 bizKey={}", msg.getBizKey(), e);
                }
            });
        } catch (Exception e) {
            log.error("[cart-add] 持久化 MQ 异常 bizKey={}", msg.getBizKey(), e);
        }
    }

    private CartAddResultVO buildSummary(String cartKey) {
        Map<Object, Object> raw = redisTemplate.opsForHash().entries(cartKey);
        int totalKinds = raw.size();
        int totalQuantity = 0;
        for (Object v : raw.values()) {
            totalQuantity += JSON.parseObject(v.toString()).getIntValue("quantity");
        }
        CartAddResultVO vo = new CartAddResultVO();
        vo.setTotalKinds(totalKinds);       // SKU 种类数
        vo.setTotalQuantity(totalQuantity); // 小红点数字 = 商品总件数
        return vo;
    }

    private static String fmt(int cents) {
        return new BigDecimal(cents).movePointLeft(2).toPlainString();
    }
}
```

#### 7.1.5 第 4 步细化：Lua 原子脚本（上限 + 限购 + 合并/新增）

将"购物车 SKU 上限校验、单 SKU 数量上限、限购校验、合并或新增"全部收敛进一段 Lua，保证并发下的原子性（例如用户在两端同时加购同一 SKU）。

```java
/**
 * 购物车原子写入服务
 */
@Slf4j
@Service
public class CartAtomicService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    private static final int MAX_CART_SIZE = 99;
    private static final int MAX_SKU_QUANTITY = 99;

    /**
     * Lua 返回值约定：
     *   -1 购物车已满（SKU 种类超 99）
     *   -2 单 SKU 数量超 99
     *   -3 超过限购
     *   >0 成功，返回该 SKU 合并后的最终数量
     */
    private static final String ADD_SCRIPT =
        "local cartSize = redis.call('HLEN', KEYS[1])\n" +
        "local exists = redis.call('HEXISTS', KEYS[1], ARGV[1])\n" +
        "local addQty = tonumber(ARGV[2])\n" +
        "local maxCart = tonumber(ARGV[3])\n" +
        "local maxSku = tonumber(ARGV[4])\n" +
        "local purchaseLimit = tonumber(ARGV[5])\n" +   // <=0 表示不限购
        "local price = tonumber(ARGV[6])\n" +
        "-- 新增 SKU 且已达种类上限\n" +
        "if exists == 0 and cartSize >= maxCart then\n" +
        "    return -1\n" +
        "end\n" +
        "if exists == 1 then\n" +
        "    local data = cjson.decode(redis.call('HGET', KEYS[1], ARGV[1]))\n" +
        "    local newQty = data.quantity + addQty\n" +
        "    if newQty > maxSku then return -2 end\n" +
        "    if purchaseLimit > 0 and newQty > purchaseLimit then return -3 end\n" +
        "    data.quantity = newQty\n" +
        "    data.selected = true\n" +
        "    data.price = price\n" +          // 用最新价刷新
        "    data.invalid = false\n" +
        "    redis.call('HSET', KEYS[1], ARGV[1], cjson.encode(data))\n" +
        "    return newQty\n" +
        "else\n" +
        "    if addQty > maxSku then return -2 end\n" +
        "    if purchaseLimit > 0 and addQty > purchaseLimit then return -3 end\n" +
        "    local data = {\n" +
        "        skuId = tonumber(ARGV[7]),\n" +
        "        spuId = tonumber(ARGV[8]),\n" +
        "        name = ARGV[9],\n" +
        "        quantity = addQty,\n" +
        "        selected = true,\n" +
        "        price = price,\n" +
        "        specs = ARGV[10],\n" +
        "        invalid = false,\n" +
        "        addTime = tonumber(ARGV[11])\n" +
        "    }\n" +
        "    redis.call('HSET', KEYS[1], ARGV[1], cjson.encode(data))\n" +
        "    -- 临时车 TTL 30 天兜底（正式车不设过期）\n" +
        "    if string.find(KEYS[1], 'cart:temp:') == 1 then\n" +
        "        redis.call('EXPIRE', KEYS[1], 2592000)\n" +
        "    end\n" +
        "    return addQty\n" +
        "end";

    public CartWriteResult addOrMerge(String cartKey, String skuKey, CartAddRequest req,
                                      int latestPrice, int purchaseLimit) {
        DefaultRedisScript<Long> script = new DefaultRedisScript<>(ADD_SCRIPT, Long.class);
        long now = System.currentTimeMillis() / 1000;

        Long ret = redisTemplate.execute(script,
                Collections.singletonList(cartKey),
                skuKey,
                String.valueOf(req.getQuantity()),
                String.valueOf(MAX_CART_SIZE),
                String.valueOf(MAX_SKU_QUANTITY),
                String.valueOf(purchaseLimit),
                String.valueOf(latestPrice),
                String.valueOf(req.getSkuId()),
                String.valueOf(req.getSpuId()),
                req.getName() == null ? "" : req.getName(),
                req.getSpecs() == null ? "" : req.getSpecs(),
                String.valueOf(now));

        if (ret == null) {
            throw new BizException(CartErrorCode.SYSTEM_ERROR, "加购失败");
        }
        CartWriteResult result = new CartWriteResult();
        long v = ret;
        if (v == -1) result.setCode(CartWriteResult.CART_FULL);
        else if (v == -2) result.setCode(CartWriteResult.SKU_QUANTITY_LIMIT);
        else if (v == -3) result.setCode(CartWriteResult.PURCHASE_LIMIT);
        else { result.setCode(CartWriteResult.SUCCESS); result.setFinalQuantity((int) v); }
        return result;
    }
}
```

```java
/**
 * 加购持久化消费者：UPSERT 到 MySQL，消费端做幂等，允许重复投递
 */
@Slf4j
@Component
@RocketMQMessageListener(topic = "cart-sync-topic", consumerGroup = "cart-mysql-sync-group")
public class CartUpsertConsumer implements RocketMQListener<CartSyncMessage> {

    @Autowired
    private CartItemMapper cartItemMapper;

    @Override
    public void onMessage(CartSyncMessage msg) {
        try {
            if (msg.getUserId() == null) {
                // 临时车不落库（仅存 Redis），登录合并后再持久化
                return;
            }
            // 幂等 UPSERT：唯一键 (user_id, store_id, sku_key)，ON DUPLICATE KEY UPDATE
            CartItemDO item = new CartItemDO();
            item.setUserId(msg.getUserId());
            item.setStoreId(msg.getStoreId());
            item.setSkuKey(msg.getSkuKey());
            item.setSpuId(msg.getSpuId());
            item.setSkuId(msg.getSkuId());
            item.setQuantity(msg.getQuantity());
            item.setUpdateTime(new Date());
            cartItemMapper.upsert(item); // INSERT ... ON DUPLICATE KEY UPDATE quantity=VALUES(quantity)
            log.info("[cart-sync] 落库成功 userId={}, skuKey={}, qty={}",
                    msg.getUserId(), msg.getSkuKey(), msg.getQuantity());
        } catch (Exception e) {
            // 抛异常触发 MQ 重试；达到最大重试进入死信队列，由对账任务兜底
            log.error("[cart-sync] 落库失败，触发重试 bizKey={}", msg.getBizKey(), e);
            throw e;
        }
    }
}
```

#### 7.1.7 异常与边界总结（案例一）

| 环节 | 异常 | 处理策略 | 用户感知 |
|------|------|---------|---------|
| 参数校验 | quantity 越界 / 标识为空 | 直接返回 PARAM_INVALID | "加购数量必须在 1~99 之间" |
| 身份识别 | 无 userId 且无 deviceId | 返回 NO_IDENTITY | "无法识别用户身份" |
| 幂等 | 双击 / 重试 | SETNX 命中直接返回当前摘要 | 无感，数量不翻倍 |
| 商品校验 | 已下架 | 抛 OFF_SHELF | "商品已下架" |
| 商品校验 | 库存不足 | 抛 OUT_OF_STOCK | "库存不足，仅剩 N 件" |
| 商品校验 | RPC 超时 | 抛 PRODUCT_TIMEOUT，不放行 | "网络繁忙，请稍后重试" |
| 原子写入 | SKU 种类 > 99 | 返回 -1 → CART_FULL | "购物车最多 99 种商品" |
| 原子写入 | 单 SKU > 99 | 返回 -2 → SKU_LIMIT | "单个商品最多 99 件" |
| 原子写入 | 超限购 | 返回 -3 → PURCHASE_LIMIT | "该商品限购 N 件" |
| 持久化 | MQ 发送失败 | 仅告警，Redis 已成功，对账补偿 | 无感 |
| 持久化 | 消费落库失败 | MQ 重试 + 死信 + 对账 | 无感 |

#### 7.2.3 第 2~5 步：读取选中条目、批量查价查库存、失效过滤

```java
@Slf4j
@Service
public class SettleService {

    @Autowired private StringRedisTemplate redisTemplate;
    @Autowired private ProductFeignClient productClient;
    @Autowired private StockFeignClient stockClient;
    @Autowired private PromotionEngine promotionEngine;
    @Autowired private ShippingFeeService shippingFeeService;

    public SettleVO settle(Long userId, Long storeId, List<String> skuKeys,
                           Long couponId, boolean takeout) {
        String cartKey = "cart:" + userId + ":" + storeId;

        // ① 从 Redis 读取选中的条目（HMGET 一次拿齐）
        List<Object> rawList = redisTemplate.opsForHash().multiGet(
                cartKey, new ArrayList<>(skuKeys));
        List<CartItemVO> selected = new ArrayList<>();
        for (int i = 0; i < skuKeys.size(); i++) {
            Object raw = rawList.get(i);
            if (raw == null) continue; // 该 SKU 已不在购物车，忽略
            selected.add(JSON.parseObject(raw.toString(), CartItemVO.class));
        }
        if (selected.isEmpty()) {
            throw new BizException(CartErrorCode.EMPTY_SETTLE, "所选商品均已失效");
        }

        List<Long> spuIds = selected.stream()
                .map(CartItemVO::getSpuId).distinct().collect(Collectors.toList());

        // ② 批量查最新价（商品中心）+ ③ 批量查库存（库存中心），并行提速
        CompletableFuture<Map<Long, Integer>> priceFuture = CompletableFuture.supplyAsync(
                () -> safeBatchPrice(spuIds, storeId));
        CompletableFuture<Map<Long, StockDTO>> stockFuture = CompletableFuture.supplyAsync(
                () -> safeBatchStock(spuIds, storeId));
        Map<Long, Integer> priceMap = priceFuture.join();
        Map<Long, StockDTO> stockMap = stockFuture.join();

        // ④ 失效识别：下架（价格缺失）/ 售罄，标记并从计价集合剔除
        List<CartItemVO> validItems = new ArrayList<>();
        List<CartItemVO> invalidItems = new ArrayList<>();
        for (CartItemVO item : selected) {
            Integer latestPrice = priceMap.get(item.getSpuId());
            StockDTO stock = stockMap.get(item.getSpuId());
            if (latestPrice == null) {
                item.setInvalid(true);
                item.setInvalidReason("商品已下架");
                invalidItems.add(item);
                continue;
            }
            if (stock == null || stock.getAvailable() <= 0) {
                item.setInvalid(true);
                item.setInvalidReason("商品已售罄");
                invalidItems.add(item);
                continue;
            }
            // 库存不足：按可用库存下调数量并提示
            if (stock.getAvailable() < item.getQuantity()) {
                item.setQuantity(stock.getAvailable());
                item.setPriceChanged(true);
                item.setInvalidReason("库存不足，已调整为 " + stock.getAvailable() + " 件");
            }
            // 价格变更：以最新价为准计价
            if (item.getPrice() != latestPrice) {
                item.setPrice(latestPrice);
                item.setPriceChanged(true);
            }
            validItems.add(item);
        }
        if (validItems.isEmpty()) {
            throw new BizException(CartErrorCode.EMPTY_SETTLE, "所选商品均已失效");
        }

        // ⑤ 优惠引擎算价（满减 + 券叠加 + 分摊）
        PriceResult price = promotionEngine.calculate(userId, storeId, validItems, couponId);

        // ⑥ 运费计算
        int shippingFee = shippingFeeService.calc(storeId, price.getItemTotal(),
                price.getPromotionDiscount() + price.getCouponDiscount(), takeout);

        // ⑦ 应付金额 = 商品总价 - 优惠 + 运费（+ 打包费已并入运费服务或单列，按需）
        int payable = price.getItemTotal()
                - price.getPromotionDiscount()
                - price.getCouponDiscount()
                + shippingFee;
        if (payable < 0) payable = 0;

        // ⑧ 组装结算页 VO
        SettleVO vo = new SettleVO();
        vo.setValidItems(validItems);
        vo.setInvalidItems(invalidItems);
        vo.setItemTotal(price.getItemTotal());
        vo.setPromotionDetails(price.getPromotionDetails());
        vo.setCouponDiscount(price.getCouponDiscount());
        vo.setPromotionDiscount(price.getPromotionDiscount());
        vo.setShippingFee(shippingFee);
        vo.setPayableAmount(payable);
        // 逐商品分摊后的实付，用于后续拆单/退款按比例退
        vo.setItemShareMap(price.getItemShareMap());
        log.info("[cart-settle] 算价完成 userId={}, itemTotal={}, promo={}, coupon={}, ship={}, payable={}",
                userId, price.getItemTotal(), price.getPromotionDiscount(),
                price.getCouponDiscount(), shippingFee, payable);
        return vo;
    }

    private Map<Long, Integer> safeBatchPrice(List<Long> spuIds, Long storeId) {
        try {
            return productClient.batchQueryPrice(spuIds, storeId);
        } catch (Exception e) {
            // 价格是计价核心，查不到不能瞎算：抛异常让用户重试
            log.error("[cart-settle] 批量查价失败 storeId={}", storeId, e);
            throw new BizException(CartErrorCode.PRICE_ERROR, "价格获取失败，请稍后重试");
        }
    }

    private Map<Long, StockDTO> safeBatchStock(List<Long> spuIds, Long storeId) {
        try {
            return stockClient.batchQueryStock(spuIds, storeId);
        } catch (Exception e) {
            // 库存降级：查不到时视为"库存充足"，下单环节还有二次库存校验兜底
            log.warn("[cart-settle] 批量查库存失败，降级放行 storeId={}", storeId, e);
            Map<Long, StockDTO> fallback = new HashMap<>();
            for (Long spuId : spuIds) {
                StockDTO s = new StockDTO();
                s.setSpuId(spuId);
                s.setAvailable(Integer.MAX_VALUE);
                fallback.put(spuId, s);
            }
            return fallback;
        }
    }
}
```

#### 7.2.4 第 6 步细化：优惠引擎与分摊算法

优惠分摊的核心：先算出总优惠，再按每个商品"参与优惠的金额占比"把优惠拆分到每一件商品上，最后一件用"总额减去前面之和"消除四舍五入误差，保证分摊之和严格等于总优惠。

```java
@Slf4j
@Service
public class PromotionEngine {

    @Autowired private PromotionFeignClient promotionClient;
    @Autowired private CouponFeignClient couponClient;

    public PriceResult calculate(Long userId, Long storeId,
                                 List<CartItemVO> items, Long couponId) {
        PriceResult result = new PriceResult();

        // 1. 商品总价（分）
        int itemTotal = 0;
        for (CartItemVO it : items) {
            itemTotal += it.getPrice() * it.getQuantity();
        }
        result.setItemTotal(itemTotal);

        // 2. 门店满减（可能命中多档，取最优；此处以单档满减示例）
        int promotionDiscount = 0;
        try {
            PromotionRuleDTO rule = promotionClient.bestFullReduction(storeId, itemTotal);
            if (rule != null && itemTotal >= rule.getThreshold()) {
                promotionDiscount = rule.getReduction();
                result.addPromotionDetail(rule.getName(), promotionDiscount);
            }
        } catch (Exception e) {
            log.warn("[promotion] 满减查询失败，跳过满减 storeId={}", storeId, e);
        }
        result.setPromotionDiscount(promotionDiscount);

        // 3. 优惠券（在满减后的金额基础上叠加）
        int couponDiscount = 0;
        int baseForCoupon = itemTotal - promotionDiscount;
        if (couponId != null) {
            try {
                CouponCalcDTO c = couponClient.calc(userId, couponId, storeId, baseForCoupon);
                if (c.isUsable()) {
                    // 券优惠不能超过可抵扣基数
                    couponDiscount = Math.min(c.getDiscount(), baseForCoupon);
                    result.addCouponDetail(c.getCouponName(), couponDiscount);
                } else {
                    result.setCouponUnusableReason(c.getReason()); // 如"未达门槛"
                }
            } catch (Exception e) {
                log.warn("[promotion] 优惠券计算失败，忽略券 userId={}, couponId={}", userId, couponId, e);
            }
        }
        result.setCouponDiscount(couponDiscount);

        // 4. 优惠分摊：把 (满减 + 券) 总优惠按各商品小计占比分摊到每件商品
        int totalDiscount = promotionDiscount + couponDiscount;
        Map<String, Integer> shareMap = allocateDiscount(items, itemTotal, totalDiscount);
        result.setItemShareMap(shareMap);
        return result;
    }

    /**
     * 优惠分摊：按小计占比分摊，最后一件用差额兜底，保证和恒等于 totalDiscount。
     */
    private Map<String, Integer> allocateDiscount(List<CartItemVO> items,
                                                  int itemTotal, int totalDiscount) {
        Map<String, Integer> shareMap = new LinkedHashMap<>();
        if (totalDiscount <= 0 || itemTotal <= 0) {
            for (CartItemVO it : items) {
                shareMap.put(it.getSkuKey(), it.getPrice() * it.getQuantity());
            }
            return shareMap;
        }
        int allocated = 0;
        for (int i = 0; i < items.size(); i++) {
            CartItemVO it = items.get(i);
            int subtotal = it.getPrice() * it.getQuantity();
            int itemDiscount;
            if (i == items.size() - 1) {
                itemDiscount = totalDiscount - allocated;      // 最后一件兜底差额
            } else {
                // 向下取整，避免累计超发
                itemDiscount = (int) ((long) totalDiscount * subtotal / itemTotal);
                allocated += itemDiscount;
            }
            int itemPayable = Math.max(0, subtotal - itemDiscount); // 单品实付
            shareMap.put(it.getSkuKey(), itemPayable);
        }
        return shareMap;
    }
}
```

#### 7.2.5 第 7 步细化：运费计算

```java
@Service
public class ShippingFeeService {

    /**
     * 运费：低于起送价不允许结算；达到满免门槛免运费；否则收基础运费。
     * takeout=true（到店打包/自提）通常免运费，只收打包费（此处示意）。
     */
    public int calc(Long storeId, int itemTotal, int totalDiscount, boolean takeout) {
        if (takeout) {
            return 0;
        }
        ShippingRuleDTO rule = queryRule(storeId);
        int afterDiscount = itemTotal - totalDiscount;
        if (afterDiscount < rule.getMinDelivery()) {
            throw new BizException(CartErrorCode.BELOW_MIN_DELIVERY,
                    "未达起送价 ¥" + fmt(rule.getMinDelivery()));
        }
        if (afterDiscount >= rule.getFreeThreshold()) {
            return 0; // 满额免运费
        }
        return rule.getBaseFee();
    }

    private ShippingRuleDTO queryRule(Long storeId) {
        // 查询门店配送规则（可缓存）
        return ShippingRuleCache.get(storeId);
    }

    private static String fmt(int cents) {
        return new BigDecimal(cents).movePointLeft(2).toPlainString();
    }
}
```

### 7.3 案例三：登录后购物车合并全链路

**场景**：用户未登录时以 deviceId 加购了若干商品，随后完成登录。登录成功回调触发合并：把临时车合并进正式车，处理同 SKU 叠加、不同 SKU 追加、超上限截断，写入正式车并删除临时车，最后通知前端刷新。

#### 7.3.3 第 2~5 步：加锁、逐 SKU 原子合并、删临时车

```java
@Slf4j
@Service
public class CartMergeService {

    @Autowired private StringRedisTemplate redisTemplate;
    @Autowired private RedissonClient redisson;
    @Autowired private RocketMQTemplate mqTemplate;

    private static final int MAX_CART_SIZE = 99;
    private static final int MAX_SKU_QUANTITY = 99;

    /**
     * 单 SKU 合并 Lua：
     *   已存在 → 数量叠加，封顶 99；
     *   不存在 → 若正式车未满则追加，返回 1；已满返回 -1（截断，不追加）。
     * KEYS[1]=正式车  ARGV[1]=skuKey ARGV[2]=临时车该 SKU 的 JSON ARGV[3]=maxCart ARGV[4]=maxSku
     */
    private static final String MERGE_ONE_SCRIPT =
        "local exists = redis.call('HEXISTS', KEYS[1], ARGV[1])\n" +
        "local maxCart = tonumber(ARGV[3])\n" +
        "local maxSku = tonumber(ARGV[4])\n" +
        "local tempData = cjson.decode(ARGV[2])\n" +
        "if exists == 1 then\n" +
        "    local cur = cjson.decode(redis.call('HGET', KEYS[1], ARGV[1]))\n" +
        "    local q = cur.quantity + tempData.quantity\n" +
        "    if q > maxSku then q = maxSku end\n" +
        "    cur.quantity = q\n" +
        "    cur.selected = true\n" +
        "    redis.call('HSET', KEYS[1], ARGV[1], cjson.encode(cur))\n" +
        "    return 1\n" +
        "else\n" +
        "    local size = redis.call('HLEN', KEYS[1])\n" +
        "    if size >= maxCart then return -1 end\n" +
        "    if tempData.quantity > maxSku then tempData.quantity = maxSku end\n" +
        "    redis.call('HSET', KEYS[1], ARGV[1], cjson.encode(tempData))\n" +
        "    return 1\n" +
        "end";

    public void merge(Long userId, String deviceId, Long storeId) {
        String tempKey = "cart:temp:" + deviceId + ":" + storeId;
        String userKey = "cart:" + userId + ":" + storeId;
        String lockKey = "lock:cart:merge:" + userId + ":" + storeId;

        // ① 分布式锁：防止同一用户多端同时登录并发合并
        RLock lock = redisson.getLock(lockKey);
        boolean locked = false;
        try {
            locked = lock.tryLock(2, 10, TimeUnit.SECONDS);
            if (!locked) {
                log.warn("[cart-merge] 未获取到锁，跳过 userId={}, storeId={}", userId, storeId);
                return;
            }

            // ② 读临时车
            Map<Object, Object> tempCart = redisTemplate.opsForHash().entries(tempKey);
            if (tempCart.isEmpty()) {
                return; // 无需合并
            }

            DefaultRedisScript<Long> script =
                    new DefaultRedisScript<>(MERGE_ONE_SCRIPT, Long.class);

            int merged = 0, truncated = 0;
            // ③ 逐 SKU 原子合并（每个 SKU 一次 Lua，保证与并发加购的原子性）
            for (Map.Entry<Object, Object> e : tempCart.entrySet()) {
                String skuKey = e.getKey().toString();
                String json = e.getValue().toString();
                Long ret = redisTemplate.execute(script,
                        Collections.singletonList(userKey),
                        skuKey, json,
                        String.valueOf(MAX_CART_SIZE),
                        String.valueOf(MAX_SKU_QUANTITY));
                if (ret != null && ret == 1L) {
                    merged++;
                } else {
                    truncated++; // 正式车已满，该 SKU 未能追加
                }
            }

            // ④ 删除临时车（合并完成，避免二次合并）
            redisTemplate.delete(tempKey);

            // ⑤ MQ 通知：全量持久化正式车 + 多端广播刷新
            notifyAfterMerge(userId, storeId);

            log.info("[cart-merge] 合并完成 userId={}, deviceId={}, storeId={}, merged={}, truncated={}",
                    userId, deviceId, storeId, merged, truncated);
        } catch (InterruptedException ie) {
            Thread.currentThread().interrupt();
            log.error("[cart-merge] 加锁中断 userId={}, storeId={}", userId, storeId, ie);
        } finally {
            if (locked && lock.isHeldByCurrentThread()) {
                lock.unlock();
            }
        }
    }

    /**
     * 合并后：发全量落库消息 + 变更广播消息，前端收到后刷新购物车角标与列表。
     */
    private void notifyAfterMerge(Long userId, Long storeId) {
        // 全量持久化（合并后正式车整体覆盖 MySQL，保证一致）
        CartSyncMessage sync = new CartSyncMessage();
        sync.setUserId(userId);
        sync.setStoreId(storeId);
        sync.setOperation("FULL_SYNC");
        sync.setBizKey("merge:" + userId + ":" + storeId + ":" + System.currentTimeMillis());
        mqTemplate.syncSend("cart-sync-topic", sync);

        // 多端广播：通知该用户其他端刷新
        CartChangeEvent change = new CartChangeEvent();
        change.setUserId(userId);
        change.setStoreId(storeId);
        change.setOperation("MERGE");
        change.setTimestamp(System.currentTimeMillis());
        mqTemplate.syncSend("cart-change-topic", change);
    }
}
```

#### 7.3.5 合并策略与幂等性说明（案例三）

| 情形 | 策略 | 结果 |
|------|------|------|
| 临时车为空 | 直接返回 | 不做任何操作 |
| 同 SKU 两车都有 | 数量叠加，封顶 99 | max(合并值, 99) |
| 不同 SKU | 追加到正式车 | 正式车新增该 SKU |
| 追加时正式车已满 | 截断，不追加，计入 truncated | 提示用户部分商品未合并 |
| 并发登录合并 | 分布式锁串行化 | 只有一个线程执行合并 |
| 合并重复触发 | 临时车已删除 → 二次合并读到空 | 天然幂等 |
| 合并后落库 | FULL_SYNC 全量覆盖 | Redis 与 MySQL 最终一致 |

### 7.4 三个案例的共性设计要点

1. **原子性靠 Lua**：所有"读—判断—写"复合操作（加购上限判断、合并叠加）都收敛进单段 Lua 脚本，杜绝并发下的数量错乱。
2. **写操作不轻易降级**：加购、算价的价格获取失败宁可让用户重试，也不放行未知状态商品；库存等非核心项可降级并由下单环节二次兜底。
3. **持久化异步且幂等**：主流程只写 Redis，MySQL 通过 MQ 异步 UPSERT，消费端凭唯一键幂等，失败重试 + 死信 + 对账三重兜底，保证数据不丢。
4. **幂等与防重贯穿始终**：加购用 requestId 防双击，合并靠"删临时车 + 分布式锁"实现天然幂等。
5. **金额全程用分（int）**：分摊时最后一件用差额兜底，保证分摊之和严格等于总优惠，避免浮点误差与对不上账。
6. **日志可追踪**：每个关键节点打印 userId/deviceId/storeId 与结果，异常分级（warn 业务、error 系统），便于全链路排障。

### 8.6 FULL_SYNC 消费者（案例三合并后全量落库）

第七章案例三在合并完成后发送 `operation=FULL_SYNC` 的消息。下面是消费端的处理逻辑：从 Redis 读取正式购物车全量数据，先逻辑删除再批量 UPSERT，保证 Redis 与 MySQL 最终一致。

```java
/**
 * FULL_SYNC 消费者：整体覆盖 MySQL 中该用户该门店的购物车数据
 * 消费幂等：最终态覆盖写入，重复消费结果一致
 */
@Slf4j
@Component
@RocketMQMessageListener(topic = "cart-sync-topic",
        consumerGroup = "cart-full-sync-group",
        selectorExpression = "FULL_SYNC",
        selectorType = SelectorType.TAG)
public class CartFullSyncConsumer implements RocketMQListener<CartSyncMessage> {

    @Autowired private StringRedisTemplate redisTemplate;
    @Autowired private CartItemMapper cartItemMapper;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void onMessage(CartSyncMessage msg) {
        Long userId = msg.getUserId();
        Long storeId = msg.getStoreId();
        try {
            // 1. 从 Redis 读取正式购物车全量数据
            String cartKey = "cart:" + userId + ":" + storeId;
            Map<Object, Object> raw = redisTemplate.opsForHash().entries(cartKey);

            // 2. 先逻辑删除 MySQL 中该用户该门店的旧数据
            cartItemMapper.softDeleteByUserAndStore(userId, storeId);

            // 3. 如果 Redis 车非空，批量 UPSERT 写入
            if (!raw.isEmpty()) {
                List<CartItemDO> items = new ArrayList<>();
                for (Map.Entry<Object, Object> entry : raw.entrySet()) {
                    CartItemVO vo = JSON.parseObject(
                            entry.getValue().toString(), CartItemVO.class);
                    CartItemDO item = new CartItemDO();
                    item.setUserId(userId);
                    item.setStoreId(storeId);
                    item.setSkuKey(entry.getKey().toString());
                    item.setSpuId(vo.getSpuId());
                    item.setSkuId(vo.getSkuId());
                    item.setQuantity(vo.getQuantity());
                    item.setPrice(vo.getPrice());
                    item.setSpecs(vo.getSpecs());
                    item.setName(vo.getName());
                    items.add(item);
                }
                // 分批写入，每批 50 条，防止 SQL 过长
                Lists.partition(items, 50).forEach(batch ->
                        cartItemMapper.batchUpsert(batch));
            }

            log.info("[cart-full-sync] 全量同步完成 userId={}, storeId={}, count={}",
                    userId, storeId, raw.size());
        } catch (Exception e) {
            log.error("[cart-full-sync] 全量同步失败 userId={}, storeId={}",
                    userId, storeId, e);
            throw e; // 抛异常触发 MQ 重试
        }
    }
}
```

### 8.7 临时购物车门店发现（案例三前置逻辑）

第七章案例三中 `LoginSuccessListener` 调用了 `cartQueryService.findTempCartStoreIds(deviceId)`，下面是该方法的实现。使用 Redis SCAN 命令按前缀匹配，避免 KEYS 命令阻塞主线程。

```java
@Slf4j
@Service
public class CartQueryService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 扫描该 deviceId 下所有临时购物车，提取 storeId 集合
     * Key 格式：cart:temp:{deviceId}:{storeId}
     *
     * 使用 SCAN 而非 KEYS，避免阻塞 Redis
     */
    public Set<Long> findTempCartStoreIds(String deviceId) {
        Set<Long> storeIds = new HashSet<>();
        String pattern = "cart:temp:" + deviceId + ":*";

        ScanOptions options = ScanOptions.scanOptions()
                .match(pattern)
                .count(100)
                .build();

        try (Cursor<byte[]> cursor = redisTemplate.getConnectionFactory()
                .getConnection().scan(options)) {
            while (cursor.hasNext()) {
                String key = new String(cursor.next(), StandardCharsets.UTF_8);
                // key = cart:temp:{deviceId}:{storeId}
                String[] parts = key.split(":");
                if (parts.length == 4) {
                    try {
                        storeIds.add(Long.parseLong(parts[3]));
                    } catch (NumberFormatException e) {
                        log.warn("[cart-query] 临时车 key 格式异常: {}", key);
                    }
                }
            }
        } catch (Exception e) {
            log.error("[cart-query] SCAN 临时车失败 deviceId={}", deviceId, e);
        }

        log.info("[cart-query] 发现临时车 deviceId={}, storeIds={}", deviceId, storeIds);
        return storeIds;
    }
}
```

### 8.9 定时对账补偿任务

MQ 异步持久化存在消息丢失的概率极低但非零。定时对账任务扫描 Redis 与 MySQL 的差异并补偿，保证数据最终一致。

```java
/**
 * Redis-MySQL 购物车对账任务
 *
 * 每 10 分钟扫描一批活跃用户的购物车，对比 Redis 与 MySQL：
 * 1. Redis 有但 MySQL 无/数量不一致 → 补写 MySQL
 * 2. Redis 已空但 MySQL 仍有记录 → 逻辑删除 MySQL
 *
 * 分页扫描，每批 200 用户，避免一次加载过多
 */
@Slf4j
@Component
public class CartReconcileJob {

    @Autowired private CartItemMapper cartItemMapper;
    @Autowired private StringRedisTemplate redisTemplate;

    /**
     * 每 10 分钟执行
     */
    @Scheduled(cron = "0 */10 * * * ?")
    public void reconcile() {
        log.info("[cart-reconcile] 对账任务开始");
        int fixed = 0;
        int page = 0;
        int pageSize = 200;

        while (true) {
            // 分页查询最近 1 小时有更新的 MySQL 记录（按 user_id + store_id 分组）
            List<CartGroupKey> groups = cartItemMapper.selectRecentGroups(
                    Duration.ofHours(1), page * pageSize, pageSize);
            if (groups.isEmpty()) break;

            for (CartGroupKey group : groups) {
                try {
                    fixed += reconcileOne(group.getUserId(), group.getStoreId());
                } catch (Exception e) {
                    log.warn("[cart-reconcile] 单组对账异常 userId={}, storeId={}",
                            group.getUserId(), group.getStoreId(), e);
                }
            }
            page++;
        }
        log.info("[cart-reconcile] 对账任务完成，修复 {} 条", fixed);
    }

    private int reconcileOne(Long userId, Long storeId) {
        String cartKey = "cart:" + userId + ":" + storeId;
        Map<Object, Object> redisCart = redisTemplate.opsForHash().entries(cartKey);
        List<CartItemDO> mysqlCart = cartItemMapper.selectByUserAndStore(userId, storeId);

        // 构建 MySQL 索引 Map
        Map<String, CartItemDO> mysqlMap = mysqlCart.stream()
                .collect(Collectors.toMap(CartItemDO::getSkuKey, Function.identity()));

        int fixed = 0;

        if (redisCart.isEmpty() && !mysqlCart.isEmpty()) {
            // Redis 已空（用户清空了），MySQL 还有 → 逻辑删除
            cartItemMapper.softDeleteByUserAndStore(userId, storeId);
            fixed += mysqlCart.size();
            return fixed;
        }

        for (Map.Entry<Object, Object> entry : redisCart.entrySet()) {
            String skuKey = entry.getKey().toString();
            CartItemVO redisItem = JSON.parseObject(
                    entry.getValue().toString(), CartItemVO.class);
            CartItemDO mysqlItem = mysqlMap.get(skuKey);

            if (mysqlItem == null || mysqlItem.getQuantity() != redisItem.getQuantity()) {
                // MySQL 缺失或数量不一致 → 以 Redis 为准补写
                CartItemDO upsertItem = new CartItemDO();
                upsertItem.setUserId(userId);
                upsertItem.setStoreId(storeId);
                upsertItem.setSkuKey(skuKey);
                upsertItem.setSpuId(redisItem.getSpuId());
                upsertItem.setSkuId(redisItem.getSkuId());
                upsertItem.setQuantity(redisItem.getQuantity());
                upsertItem.setPrice(redisItem.getPrice());
                upsertItem.setSpecs(redisItem.getSpecs() != null ? redisItem.getSpecs() : "");
                upsertItem.setName(redisItem.getName() != null ? redisItem.getName() : "");
                cartItemMapper.upsert(upsertItem);
                fixed++;
            }
        }

        // MySQL 有但 Redis 无的 → 以 Redis 为准，逻辑删除多余记录
        for (CartItemDO mysqlItem : mysqlCart) {
            if (!redisCart.containsKey(mysqlItem.getSkuKey())) {
                cartItemMapper.softDeleteBySkuKey(userId, storeId, mysqlItem.getSkuKey());
                fixed++;
            }
        }

        return fixed;
    }
}

@Data
public class CartGroupKey {
    private Long userId;
    private Long storeId;
}
```

### 8.12 三案例全链路数据流追踪示例

下面用一个具体的数据实例，展示一次完整的"加购 → 结算 → 合并"数据在 Redis 和 MySQL 中的流转过程。

```
================= 初始状态 =================

场景：deviceId="abc123" 的未登录用户在门店 2001 加购商品

Redis:
  (空)
MySQL:
  (空)

================= 案例一：未登录加购 =================

请求：POST /cart/add
  X-Device-Id: abc123
  Body: { storeId:2001, spuId:1001, skuId:30001, quantity:2, specs:"大份", name:"红烧肉" }

步骤：
  1. Controller: userId=null, deviceId="abc123" → 走临时车
  2. 幂等检查: SETNX cart:idem:auto:null:abc123:30001:1719900000 → 首次
  3. cartKey = "cart:temp:abc123:2001"
  4. 商品中心校验: onSale=true, stock=50, price=3500, purchaseLimit=0(不限购)
  5. Lua 原子写入: HSET cart:temp:abc123:2001 "1001_大份" '{"skuId":30001,...,"quantity":2,...}'
  6. Lua 设置 TTL: EXPIRE cart:temp:abc123:2001 2592000 (30天)
  7. MQ 发送: operation=UPSERT (但 userId=null, 消费端跳过不落库)
  8. 返回: { totalKinds:1, totalQuantity:2 }

Redis 最终态:
  cart:temp:abc123:2001
    "1001_大份" → {"skuId":30001,"spuId":1001,"name":"红烧肉","quantity":2,
                   "selected":true,"price":3500,"specs":"大份","addTime":1719900000}

================= 案例三：用户登录触发合并 =================

用户 userId=8888 登录，deviceId="abc123"

步骤：
  1. LoginSuccessListener 触发，找到临时车 storeIds=[2001]
  2. 加锁: lock:cart:merge:8888:2001
  3. 读临时车: cart:temp:abc123:2001 → 1 条记录
  4. 读正式车: cart:8888:2001 → 假设已有 {"1002_小份": {"skuId":30005,...,"quantity":1}}
  5. Lua 合并 "1001_大份": 正式车无此 SKU → 追加 → 正式车现有 2 种 SKU
  6. 删临时车: DEL cart:temp:abc123:2001
  7. 释放锁
  8. MQ 发送: operation=FULL_SYNC → 消费端全量覆盖 MySQL
  9. MQ 发送: operation=MERGE → WebSocket 通知前端刷新

Redis 最终态:
  cart:8888:2001
    "1002_小份" → {"skuId":30005,...,"quantity":1,...}
    "1001_大份" → {"skuId":30001,...,"quantity":2,...}
  cart:temp:abc123:2001 → (已删除)

MySQL 最终态:
  cart_item:
    | user_id | store_id | sku_key   | quantity | price |
    |---------|----------|-----------|----------|-------|
    | 8888    | 2001     | 1002_小份 | 1        | 2800  |
    | 8888    | 2001     | 1001_大份 | 2        | 3500  |

================= 案例二：用户结算 =================

请求：POST /cart/settle
  X-User-Id: 8888
  Body: { storeId:2001, skuKeys:["1002_小份","1001_大份"], couponId:50001, takeout:false }

步骤：
  1. Controller: userId=8888, 2 个 SKU 选中
  2. HMGET cart:8888:2001 ["1002_小份","1001_大份"] → 2 条
  3. 并行查询:
     - 商品中心 batchPrice([1001,1002], 2001) → {1001:3500, 1002:2800}
     - 库存中心 batchStock([1001,1002], 2001)  → {1001:{available:48}, 1002:{available:20}}
  4. 失效检测: 两个商品均正常，价格未变
  5. 计价:
     - itemTotal = 2800×1 + 3500×2 = 9800 (分)
     - 满减: 满80减10(满8000减1000) → promotionDiscount = 1000
     - 券: couponId=50001, baseForCoupon = 9800-1000 = 8800, 券面5元 → couponDiscount = 500
     - totalDiscount = 1500
  6. 优惠分摊:
     - "1002_小份": subtotal=2800, share = 1500*2800/9800 = 428(分), payable=2800-428=2372
     - "1001_大份": subtotal=7000, share = 1500-428=1072(分), payable=7000-1072=5928
     - 验证: 2372+5928=8300 = 9800-1500 ✓
  7. 运费: afterDiscount=8300, 满免门槛8000 → 免运费, shippingFee=0
  8. payable = 9800-1000-500+0 = 8300

返回:
  {
    validItems: [小份, 大份],
    invalidItems: [],
    itemTotal: 9800,
    promotionDiscount: 1000,
    couponDiscount: 500,
    shippingFee: 0,
    payableAmount: 8300,
    itemShareMap: { "1002_小份": 2372, "1001_大份": 5928 }
  }
```
