# 营销促销系统架构设计

## 一、问题背景

### 1.1 业务场景

营销促销系统是电商平台的"价格计算器"，负责在用户下单时计算最终的优惠金额。一个订单可能同时参与多种促销活动：满减、折扣、买赠、满件减等。如何让这些活动按优先级叠加计算，且保证高性能和可配置性，是核心挑战。

典型场景：用户下单买了一件100元的商品 → 店铺满100减20 → 会员95折 → 平台优惠券减10元 → 最终支付 = (100-20)×0.95-10 = 66元。

### 1.2 核心挑战

| 挑战维度 | 具体问题 |
|---------|---------|
| 活动叠加 | 多种促销活动如何叠加计算，谁先谁后 |
| 可配置性 | 新增促销类型不改代码 |
| 性能 | 下单时实时计算优惠，P99 < 50ms |
| 互斥规则 | 某些活动不能同时参与（如折扣和满减互斥） |
| 金额分摊 | 多商品订单，优惠如何分摊到每个SKU |
| 防超预算 | 促销活动有预算上限，不能超发 |

### 1.3 促销活动类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 整单满减 | 整单满X减Y | 满100减20 |
| 整单折扣 | 整单打X折 | 全场8折 |
| 单品折扣 | 单个商品打X折 | 指定商品7折 |
| 单品满减 | 单个商品满X减Y | 买1件减5元 |
| 买赠 | 买X送Y | 买2送1 |
| 满件减 | 满X件减Y件 | 3件任选1件免单 |
| 阶梯满减 | 不同档位不同优惠 | 满50减5, 满100减15, 满200减40 |

### 2.2 价格计算链路

```
用户下单
    │
    ▼
1. 查询商品参与的所有活动 ──→ 活动匹配
    │
    ▼
2. 互斥规则过滤 ──→ 筛选可叠加的活动组合
    │
    ▼
3. 按优先级排序 ──→ 满减 > 折扣 > 优惠券 > 积分抵扣
    │
    ▼

    ▼

    │
    ▼
6. 返回最终价格
```

## 三、核心链路设计

### 3.1 策略模式：促销类型

每种促销类型实现同一个接口，通过策略模式实现可扩展。

```java
/**
 * 促销策略接口
 */
public interface PromotionStrategy {

    /**
     * 获取促销类型
     */
    String getType();

    /**
     * 计算优惠
     * @param context 价格计算上下文（含商品列表、当前金额等）
     * @return 优惠结果
     */
    PromotionResult calculate(PriceContext context, PromotionActivity activity);
}

/**
 * 满减策略
 * 规则: {"threshold": 10000, "reduce": 2000, "stackable": true}
 * 含义: 满100元减20元
 */
@Component
public class FullReduceStrategy implements PromotionStrategy {

    @Override
    public String getType() { return "FULL_REDUCE"; }

    @Override
    public PromotionResult calculate(PriceContext context, PromotionActivity activity) {
        JSONObject rules = JSON.parseObject(activity.getRules());
        int threshold = rules.getIntValue("threshold");  // 满X（分）
        int reduce = rules.getIntValue("reduce");        // 减Y（分）

        // 当前订单金额（已经过上游促销计算后的金额）
        int currentAmount = context.getCurrentAmount();

        if (currentAmount < threshold) {
            return PromotionResult.noDiscount(); // 不满足满减条件
        }

        // 支持阶梯满减
        if (rules.containsKey("ladder")) {
            JSONArray ladders = rules.getJSONArray("ladder");
            int bestReduce = 0;
            for (int i = 0; i < ladders.size(); i++) {
                JSONObject ladder = ladders.getJSONObject(i);
                if (currentAmount >= ladder.getIntValue("threshold")) {
                    bestReduce = Math.max(bestReduce, ladder.getIntValue("reduce"));
                }
            }
            reduce = bestReduce;
        }

        return PromotionResult.of(reduce, "满" + threshold/100 + "减" + reduce/100);
    }
}

/**
 * 折扣策略
 * 规则: {"discount": 8.5}
 * 含义: 打8.5折
 */
@Component
public class DiscountStrategy implements PromotionStrategy {

    @Override
    public String getType() { return "DISCOUNT"; }

    @Override
    public PromotionResult calculate(PriceContext context, PromotionActivity activity) {
        JSONObject rules = JSON.parseObject(activity.getRules());
        BigDecimal discount = rules.getBigDecimal("discount")
            .divide(new BigDecimal("10"), 4, RoundingMode.DOWN);

        int currentAmount = context.getCurrentAmount();
        int discountAmount = new BigDecimal(currentAmount)
            .multiply(BigDecimal.ONE.subtract(discount))
            .intValue();

        return PromotionResult.of(discountAmount, "打" + discount.multiply(new BigDecimal("10")) + "折");
    }
}

/**
 * 买赠策略
 * 规则: {"buyQty": 2, "giftQty": 1, "giftSkuId": 123456}
 * 含义: 买2件送1件指定商品
 */
@Component
public class BuyGiftStrategy implements PromotionStrategy {

    @Override
    public String getType() { return "BUY_GIFT"; }

    @Override
    public PromotionResult calculate(PriceContext context, PromotionActivity activity) {
        JSONObject rules = JSON.parseObject(activity.getRules());
        int buyQty = rules.getIntValue("buyQty");
        int giftQty = rules.getIntValue("giftQty");
        Long giftSkuId = rules.getLong("giftSkuId");

        // 检查用户购买的商品数量是否满足买赠条件
        int totalQty = context.getOrderItems().stream()
            .filter(item -> item.getSkuId().equals(giftSkuId))
            .mapToInt(OrderItem::getQuantity)
            .sum();

        if (totalQty < buyQty) {
            return PromotionResult.noDiscount();
        }

        // 计算赠品数量
        int giftCount = (totalQty / buyQty) * giftQty;

        return PromotionResult.gift(giftSkuId, giftCount);
    }
}
```

### 3.2 责任链：促销叠加计算

```java
/**
 * 促销计算责任链
 *
 * 按优先级依次执行促销策略：
 * 1. 单品促销（单品折扣、单品满减）
 * 2. 整单促销（整单满减、整单折扣）
 * 3. 优惠券
 * 4. 积分抵扣
 *
 * 每个节点基于上游节点的结果继续计算
 */
@Service
public class PromotionChain {

    @Autowired
    private Map<String, PromotionStrategy> strategyMap;

    @Autowired
    private MutexRuleService mutexService;

    /**
     * 计算订单最终价格
     */
    public PriceResult calculate(OrderRequest order) {
        // 1. 查询所有匹配的活动
        List<PromotionActivity> allActivities = findMatchingActivities(order);

        // 2. 互斥过滤
        List<PromotionActivity> validActivities = mutexService.filterMutex(allActivities);

        // 3. 按优先级排序
        validActivities.sort(Comparator.comparingInt(PromotionActivity::getPriority));

        // 4. 构建价格上下文
        PriceContext context = new PriceContext();
        context.setOrderItems(order.getItems());
        context.setOriginalAmount(calculateOriginalAmount(order));
        context.setCurrentAmount(context.getOriginalAmount());

        List<PromotionDetail> details = new ArrayList<>();

        // 5. 责任链依次计算
        for (PromotionActivity activity : validActivities) {
            PromotionStrategy strategy = strategyMap.get(activity.getActivityType());
            if (strategy == null) continue;

            PromotionResult result = strategy.calculate(context, activity);

            if (result.hasDiscount()) {
                // 更新当前金额
                int newAmount = context.getCurrentAmount() - result.getDiscountAmount();
                if (newAmount < 0) newAmount = 0;

                details.add(new PromotionDetail(
                    activity.getActivityId(),
                    activity.getActivityName(),
                    activity.getActivityType(),
                    result.getDiscountAmount(),
                    context.getCurrentAmount(),
                    newAmount
                ));

                context.setCurrentAmount(newAmount);
            }

            if (result.hasGift()) {
                context.addGifts(result.getGifts());
            }
        }

        // 6. 金额分摊
        Map<Long, Integer> skuAllocation = allocateDiscount(
            context.getOriginalAmount(),
            details.stream().mapToInt(PromotionDetail::getDiscountAmount).sum(),
            order.getItems());

        // 7. 构建最终结果
        PriceResult priceResult = new PriceResult();
        priceResult.setOriginalAmount(context.getOriginalAmount());
        priceResult.setFinalAmount(context.getCurrentAmount());
        priceResult.setPromotionDetails(details);
        priceResult.setSkuAllocation(skuAllocation);
        priceResult.setGifts(context.getGifts());

        return priceResult;
    }

    /**
     * 金额分摊：将总优惠按比例分摊到每个SKU
     *
     * 示例：商品A 60元，商品B 40元，总优惠30元
     * A分摊: 30 × 60/100 = 18元
     * B分摊: 30 × 40/100 = 12元
     */
    private Map<Long, Integer> allocateDiscount(int originalAmount,
                                                 int totalDiscount,
                                                 List<OrderItem> items) {
        Map<Long, Integer> result = new HashMap<>();
        int allocated = 0;

        for (int i = 0; i < items.size(); i++) {
            OrderItem item = items.get(i);
            if (i == items.size() - 1) {
                // 最后一个SKU承担分摊余数，避免精度丢失
                result.put(item.getSkuId(), totalDiscount - allocated);
            } else {
                int itemAmount = item.getPrice() * item.getQuantity();
                int itemDiscount = (int) ((long) totalDiscount * itemAmount / originalAmount);
                result.put(item.getSkuId(), itemDiscount);
                allocated += itemDiscount;
            }
        }

        return result;
    }
}
```

### 3.3 互斥规则引擎

```java
/**
 * 互斥规则服务
 *
 * 互斥规则定义哪些活动不能同时参与
 * 例如：单品折扣 和 单品满减 互斥
 *       整单折扣 和 整单满减 互斥（但可以选最优的一个）
 */
@Service
public class MutexRuleService {

    @Autowired
    private PromotionMutexRuleMapper mutexRuleMapper;

    /**
     * 过滤互斥活动，选择最优组合
     */
    public List<PromotionActivity> filterMutex(List<PromotionActivity> activities) {
        if (activities.size() <= 1) {
            return activities;
        }

        // 加载互斥规则
        List<PromotionMutexRule> rules = mutexRuleMapper.selectAll();
        Map<String, Set<String>> mutexMap = buildMutexMap(rules);

        // 分组：同类型的活动按互斥规则只保留最优的一个
        Map<String, List<PromotionActivity>> grouped = activities.stream()
            .collect(Collectors.groupingBy(PromotionActivity::getActivityType));

        List<PromotionActivity> result = new ArrayList<>();
        Set<String> usedTypes = new HashSet<>();

        for (PromotionActivity activity : activities) {
            String type = activity.getActivityType();

            // 检查是否与已选活动互斥
            boolean isMutex = false;
            for (String usedType : usedTypes) {
                if (isMutex(type, usedType, mutexMap)) {
                    isMutex = true;
                    break;
                }
            }

            if (!isMutex) {
                result.add(activity);
                usedTypes.add(type);
            }
            // 如果互斥，跳过该活动（简化处理，实际应选择更优的）
        }

        return result;
    }

    private boolean isMutex(String typeA, String typeB, Map<String, Set<String>> mutexMap) {
        Set<String> mutexSet = mutexMap.get(typeA);
        return mutexSet != null && mutexSet.contains(typeB);
    }

    private Map<String, Set<String>> buildMutexMap(List<PromotionMutexRule> rules) {
        Map<String, Set<String>> map = new HashMap<>();
        for (PromotionMutexRule rule : rules) {
            map.computeIfAbsent(rule.getActivityTypeA(), k -> new HashSet<>())
                .add(rule.getActivityTypeB());
            map.computeIfAbsent(rule.getActivityTypeB(), k -> new HashSet<>())
                .add(rule.getActivityTypeA());
        }
        return map;
    }
}
```

### 3.4 预算管控

```java
/**
 * 预算管控服务
 *
 * 每个促销活动有预算上限，扣减预算要防超
 * 方案：Redis Lua原子扣减
 */
@Service
public class BudgetControlService {

    private static final String BUDGET_LUA =
        "local remaining = redis.call('GET', KEYS[1])\n" +
        "if not remaining then return -1 end\n" +
        "remaining = tonumber(remaining)\n" +
        "local need = tonumber(ARGV[1])\n" +
        "if remaining < need then return 0 end\n" +
        "redis.call('DECRBY', KEYS[1], need)\n" +
        "return 1\n";

    /**
     * 扣减预算
     * @return true=成功 false=预算不足
     */
    public boolean deductBudget(Long activityId, int amount) {
        String key = "promo:budget:" + activityId;
        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(BUDGET_LUA);
        script.setResultType(Long.class);

        Long result = redisTemplate.execute(script,
            Collections.singletonList(key),
            String.valueOf(amount));

        return result != null && result == 1L;
    }

    /**
     * 恢复预算（取消订单时）
     */
    public void restoreBudget(Long activityId, int amount) {
        String key = "promo:budget:" + activityId;
        redisTemplate.opsForValue().increment(key, amount);
    }

    /**
     * 初始化预算（活动上线时）
     */
    public void initBudget(Long activityId, long totalBudget) {
        String key = "promo:budget:" + activityId;
        redisTemplate.opsForValue().set(key, String.valueOf(totalBudget));
    }
}
```

## 四、性能优化

### 4.1 活动缓存

```java
/**
 * 活动查询走缓存
 *
 * 缓存策略：
 * 1. 所有进行中的活动缓存在Redis
 * 2. 按商品维度建立倒排索引：skuId → activityId列表
 * 3. 下单时只需查询商品对应的活动，不用全量扫描
 */
@Service
public class PromotionCacheService {

    /**
     * 查询商品参与的活动
     */
    public List<PromotionActivity> getActivitiesBySku(Long skuId) {
        String indexKey = "promo:index:sku:" + skuId;
        List<String> activityIds = redisTemplate.opsForList().range(indexKey, 0, -1);

        if (activityIds == null || activityIds.isEmpty()) {
            return Collections.emptyList();
        }

        // 批量查询活动详情
        List<PromotionActivity> activities = new ArrayList<>();
        for (String id : activityIds) {
            String detailKey = "promo:detail:" + id;
            String json = redisTemplate.opsForValue().get(detailKey);
            if (json != null) {
                activities.add(JSON.parseObject(json, PromotionActivity.class));
            }
        }

        return activities;
    }

    /**
     * 活动上线时构建缓存
     */
    public void buildActivityCache(PromotionActivity activity) {
        // 缓存活动详情
        String detailKey = "promo:detail:" + activity.getActivityId();
        redisTemplate.opsForValue().set(detailKey,
            JSON.toJSONString(activity), 24, TimeUnit.HOURS);

        // 构建倒排索引
        if (activity.getScopeType().equals("PRODUCT")) {
            List<Long> skuIds = JSON.parseArray(
                activity.getScopeValues(), Long.class);
            for (Long skuId : skuIds) {
                String indexKey = "promo:index:sku:" + skuId;
                redisTemplate.opsForList().rightPush(indexKey,
                    String.valueOf(activity.getActivityId()));
            }
        }
    }
}
```

## 五、最佳实践与总结

### 5.1 核心设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 促销类型扩展 | 策略模式 | 新增类型不改现有代码 |
| 叠加计算 | 责任链 | 按优先级依次计算 |
| 互斥规则 | 配置化 | 运营可调整 |
| 预算管控 | Redis Lua原子扣减 | 防超预算 |
| 金额分摊 | 按比例分摊+末尾兜底 | 避免精度丢失 |
| 活动缓存 | 倒排索引 | 高效查询 |

### 5.2 容易踩的坑

1. **促销叠加顺序错误**：先折扣再满减和先满减再折扣结果不同，必须按优先级执行
2. **金额分摊精度丢失**：按比例分摊后合计不等于总额，最后一个SKU要兜底
3. **预算超发**：并发扣减预算没做原子操作，导致预算超发
4. **互斥规则遗漏**：新增促销类型忘记配置互斥规则，导致不合理叠加
5. **缓存不一致**：活动修改后未刷新缓存，用户看到过期活动

### 案例一：满减活动命中与优惠计算全链路

#### 6.1.1 业务流程

#### 6.1.2 数据库表

```sql
-- 满减活动表（复用 promotion_activity，补充满减规则示例）
```

```java
package com.ecommerce.promotion.fullreduce;

import com.alibaba.fastjson.JSON;
import com.alibaba.fastjson.JSONArray;
import com.alibaba.fastjson.JSONObject;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.dao.DuplicateKeyException;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.math.BigInteger;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.*;
import java.util.concurrent.TimeUnit;

/**
 * 满减活动全链路服务
 *
 * 职责：从活动匹配 -> 优惠计算 -> 预算扣减 -> 记录持久化，全流程闭环。
 *
 * 幂等控制：基于 orderId + activityId 生成唯一 recordId，利用数据库唯一索引防重。
 * 异常处理：每一步都有 try-catch，异常时回滚预算并返回降级结果。
 * 日志记录：关键节点全量打日志，含 traceId 便于全链路追踪。
 */
@Service
public class FullReduceChainService {

    private static final Logger log = LoggerFactory.getLogger(FullReduceChainService.class);

    @Autowired
    private PromotionActivityMapper activityMapper;

    @Autowired
    private PromotionRecordMapper recordMapper;

    @Autowired
    private BudgetControlService budgetService;

    @Autowired
    private PromotionCacheService cacheService;

    @Autowired
    private StringRedisTemplate redisTemplate;

    /**
     * 满减优惠计算入口
     *
     * @param request 下单请求
     * @return 优惠计算结果
     */
    public FullReduceResult calculate(FullReduceRequest request) {
        String traceId = request.getTraceId() != null ? request.getTraceId() : UUID.randomUUID().toString();
        long start = System.currentTimeMillis();

        log.info("[FullReduce] traceId={}, orderId={}, userId={}, 开始满减计算, orderItems={}",
                traceId, request.getOrderId(), request.getUserId(),
                JSON.toJSONString(request.getItems()));

        try {
            // ========== 第1步：幂等检查 ==========
            String recordId = buildRecordId(request.getOrderId());
            PromotionRecord existRecord = recordMapper.selectByRecordId(recordId);
            if (existRecord != null && existRecord.getStatus() == 1) {
                log.info("[FullReduce] traceId={}, orderId={}, 幂等命中，已有优惠记录, discountAmount={}分",
                        traceId, request.getOrderId(), existRecord.getDiscountAmount());
                return FullReduceResult.fromRecord(existRecord);
            }

            // ========== 第2步：查询匹配的满减活动 ==========
            List<PromotionActivity> activities = findMatchingActivities(request.getItems(), traceId);
            if (activities.isEmpty()) {
                log.info("[FullReduce] traceId={}, orderId={}, 无匹配满减活动", traceId, request.getOrderId());
                return FullReduceResult.noDiscount(request.getOriginalAmount());
            }

            log.info("[FullReduce] traceId={}, orderId={}, 匹配到{}个满减活动: {}",
                    traceId, request.getOrderId(), activities.size(),
                    activities.stream().map(a -> a.getActivityId() + ":" + a.getActivityName())
                            .reduce((a, b) -> a + ", " + b).orElse(""));

            // ========== 第3步：选择最优满减活动 ==========
            PromotionActivity bestActivity = null;
            int bestDiscount = 0;
            int originalAmount = request.getOriginalAmount();

            for (PromotionActivity activity : activities) {
                int discount = calculateFullReduce(originalAmount, activity);
                if (discount > bestDiscount) {
                    bestDiscount = discount;
                    bestActivity = activity;
                }
            }

            if (bestActivity == null || bestDiscount <= 0) {
                log.info("[FullReduce] traceId={}, orderId={}, 订单金额{}分未满足任何满减门槛",
                        traceId, request.getOrderId(), originalAmount);
                return FullReduceResult.noDiscount(originalAmount);
            }

            log.info("[FullReduce] traceId={}, orderId={}, 选中活动[{}], 优惠={}分",
                    traceId, request.getOrderId(), bestActivity.getActivityName(), bestDiscount);

            // ========== 第4步：预算扣减 ==========
            boolean budgetOk = budgetService.deductBudget(bestActivity.getActivityId(), bestDiscount);
            if (!budgetOk) {
                log.warn("[FullReduce] traceId={}, orderId={}, 活动[{}]预算不足, discountAmount={}分, 降级返回无优惠",
                        traceId, request.getOrderId(), bestActivity.getActivityName(), bestDiscount);
                // 预算不足，降级：不享优惠但正常返回，不影响下单
                return FullReduceResult.noDiscount(originalAmount);
            }

            log.info("[FullReduce] traceId={}, orderId={}, 预算扣减成功, activityId={}, amount={}分",
                    traceId, request.getOrderId(), bestActivity.getActivityId(), bestDiscount);

            // ========== 第5步：持久化优惠记录 ==========
            int finalAmount = originalAmount - bestDiscount;
            PromotionRecord record = new PromotionRecord();
            record.setRecordId(recordId);
            record.setOrderId(request.getOrderId());
            record.setActivityId(bestActivity.getActivityId());
            record.setActivityType("FULL_REDUCE");
            record.setUserId(request.getUserId());
            record.setOriginalAmount(originalAmount);
            record.setDiscountAmount(bestDiscount);
            record.setFinalAmount(finalAmount);
            record.setStatus(1);

            try {
                recordMapper.insert(record);
                log.info("[FullReduce] traceId={}, orderId={}, 优惠记录持久化成功, recordId={}",
                        traceId, request.getOrderId(), recordId);
            } catch (DuplicateKeyException e) {
                // 并发场景：另一个线程已插入，回滚预算
                log.warn("[FullReduce] traceId={}, orderId={}, 并发写入冲突, 回滚预算, activityId={}, amount={}分",
                        traceId, request.getOrderId(), bestActivity.getActivityId(), bestDiscount);
                budgetService.restoreBudget(bestActivity.getActivityId(), bestDiscount);

                PromotionRecord concurrentRecord = recordMapper.selectByRecordId(recordId);
                if (concurrentRecord != null) {
                    return FullReduceResult.fromRecord(concurrentRecord);
                }
                return FullReduceResult.noDiscount(originalAmount);
            }

            // ========== 第6步：返回最终价格 ==========
            FullReduceResult result = new FullReduceResult();
            result.setOrderId(request.getOrderId());
            result.setOriginalAmount(originalAmount);
            result.setDiscountAmount(bestDiscount);
            result.setFinalAmount(finalAmount);
            result.setActivityId(bestActivity.getActivityId());
            result.setActivityName(bestActivity.getActivityName());
            result.setTraceId(traceId);

            // 金额分摊到SKU
            Map<Long, Integer> allocation = allocateDiscount(originalAmount, bestDiscount, request.getItems());
            result.setSkuAllocation(allocation);

            log.info("[FullReduce] traceId={}, orderId={}, 满减计算完成, 原价={}分, 优惠={}分, 最终={}分, 耗时={}ms, 分摊={}",
                    traceId, request.getOrderId(), originalAmount, bestDiscount, finalAmount,
                    System.currentTimeMillis() - start, JSON.toJSONString(allocation));

            return result;

        } catch (Exception e) {
            log.error("[FullReduce] traceId={}, orderId={}, 满减计算异常, 降级返回原价, errorMsg={}",
                    traceId, request.getOrderId(), e.getMessage(), e);
            // 任何异常都降级返回原价，不阻断下单
            return FullReduceResult.noDiscount(request.getOriginalAmount());
        }
    }

    /**
     * 订单取消时回滚满减优惠
     */
    @Transactional(rollbackFor = Exception.class)
    public boolean rollback(String orderId, String traceId) {
        log.info("[FullReduce] traceId={}, orderId={}, 开始回滚满减优惠", traceId, orderId);

        try {
            PromotionRecord record = recordMapper.selectByOrderId(orderId);
            if (record == null) {
                log.warn("[FullReduce] traceId={}, orderId={}, 未找到优惠记录，无需回滚", traceId, orderId);
                return true;
            }

            if (record.getStatus() == 2) {
                log.info("[FullReduce] traceId={}, orderId={}, 优惠记录已回滚，幂等返回", traceId, orderId);
                return true;
            }

            // 恢复预算
            budgetService.restoreBudget(record.getActivityId(), record.getDiscountAmount());
            log.info("[FullReduce] traceId={}, orderId={}, 预算恢复成功, activityId={}, amount={}分",
                    traceId, orderId, record.getActivityId(), record.getDiscountAmount());

            // 更新记录状态
            recordMapper.updateStatus(record.getRecordId(), 2);
            log.info("[FullReduce] traceId={}, orderId={}, 优惠记录状态更新为已回滚", traceId, orderId);

            return true;
        } catch (Exception e) {
            log.error("[FullReduce] traceId={}, orderId={}, 回滚满减优惠异常, errorMsg={}",
                    traceId, orderId, e.getMessage(), e);
            throw new RuntimeException("回滚满减优惠失败: " + e.getMessage(), e);
        }
    }

    // ==================== 私有方法 ====================

    /**
     * 查询匹配的满减活动（走缓存）
     */
    private List<PromotionActivity> findMatchingActivities(List<OrderItem> items, String traceId) {
        Set<Long> activityIdSet = new HashSet<>();
        for (OrderItem item : items) {
            List<PromotionActivity> skuActivities = cacheService.getActivitiesBySku(item.getSkuId());
            for (PromotionActivity act : skuActivities) {
                if ("FULL_REDUCE".equals(act.getActivityType()) && act.getStatus() == 1) {
                    activityIdSet.add(act.getActivityId());
                }
            }
        }

        if (activityIdSet.isEmpty()) {
            return Collections.emptyList();
        }

        // 批量查询活动详情
        List<PromotionActivity> result = new ArrayList<>();
        for (Long activityId : activityIdSet) {
            PromotionActivity activity = activityMapper.selectByActivityId(activityId);
            if (activity != null && isActivityActive(activity)) {
                result.add(activity);
            }
        }
        return result;
    }

    /**
     * 判断活动是否在有效期内
     */
    private boolean isActivityActive(PromotionActivity activity) {
        Date now = new Date();
        return activity.getStatus() == 1
                && now.after(activity.getStartTime())
                && now.before(activity.getEndTime());
    }

    /**
     * 计算满减金额（支持阶梯）
     */
    private int calculateFullReduce(int currentAmount, PromotionActivity activity) {
        JSONObject rules = JSON.parseObject(activity.getRules());
        int threshold = rules.getIntValue("threshold");
        int reduce = rules.getIntValue("reduce");

        // 阶梯满减
        if (rules.containsKey("ladder")) {
            JSONArray ladders = rules.getJSONArray("ladder");
            int bestReduce = 0;
            for (int i = 0; i < ladders.size(); i++) {
                JSONObject ladder = ladders.getJSONObject(i);
                if (currentAmount >= ladder.getIntValue("threshold")) {
                    bestReduce = Math.max(bestReduce, ladder.getIntValue("reduce"));
                }
            }
            return bestReduce;
        }

        // 普通满减
        if (currentAmount >= threshold) {
            return reduce;
        }
        return 0;
    }

    /**
     * 金额分摊到SKU（按比例 + 末尾兜底）
     */
    private Map<Long, Integer> allocateDiscount(int originalAmount, int totalDiscount, List<OrderItem> items) {
        Map<Long, Integer> result = new LinkedHashMap<>();
        int allocated = 0;

        for (int i = 0; i < items.size(); i++) {
            OrderItem item = items.get(i);
            if (i == items.size() - 1) {
                // 最后一个SKU承担余数
                result.put(item.getSkuId(), totalDiscount - allocated);
            } else {
                int itemAmount = item.getPrice() * item.getQuantity();
                int itemDiscount = (int) ((long) totalDiscount * itemAmount / originalAmount);
                result.put(item.getSkuId(), itemDiscount);
                allocated += itemDiscount;
            }
        }
        return result;
    }

    /**
     * 构建幂等记录ID：MD5(orderId)
     * 同一订单只能生成一条满减优惠记录
     */
    private String buildRecordId(String orderId) {
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(orderId.getBytes());
            return new BigInteger(1, digest).toString(16);
        } catch (NoSuchAlgorithmException e) {
            return orderId;
        }
    }
}
```

```java
/**
 * 限时折扣活动全链路服务
 *
 * 覆盖：创建 -> 生效 -> 缓存预热 -> 下单命中 -> 限购校验 -> 预算扣减 -> 到期结束
 *
 * 幂等控制：
 *   - 创建幂等：活动名 + 时间范围生成幂等键，DB唯一索引
 *   - 下单幂等：orderId 唯一索引，防止重复享受折扣

 * 日志记录：创建/生效/下单/结束全流程打日志
 */
@Service
public class FlashDiscountService {

    private static final Logger log = LoggerFactory.getLogger(FlashDiscountService.class);

    @Autowired
    private FlashDiscountActivityMapper activityMapper;

    @Autowired
    private FlashDiscountUserRecordMapper userRecordMapper;

    @Autowired
    private BudgetControlService budgetService;

    @Autowired
    private PromotionCacheService cacheService;

    @Autowired
    private StringRedisTemplate redisTemplate;

    // ==================== 活动创建 ====================

    /**
     * 创建限时折扣活动
     *
     * @param request 创建请求
     * @return 活动ID
     * @throws FlashDiscountException 创建失败时抛出
     */
    @Transactional(rollbackFor = Exception.class)
    public Long createActivity(FlashDiscountCreateRequest request) {
        String traceId = UUID.randomUUID().toString();
        log.info("[FlashDiscount] traceId={}, 创建限时折扣活动开始, name={}, creator={}, discount={}, start={}, end={}",
                traceId, request.getActivityName(), request.getCreator(),
                request.getDiscountRate(), request.getStartTime(), request.getEndTime());

        // ========== 1. 参数校验 ==========
        validateCreateRequest(request, traceId);

        // ========== 2. 时间重叠检查 ==========
        checkTimeOverlap(request, traceId);

        // ========== 3. 幂等检查 ==========
        String idempotentKey = buildIdempotentKey(request.getActivityName(),
                request.getStartTime(), request.getEndTime());

        FlashDiscountActivity existActivity = activityMapper.selectByIdempotentKey(idempotentKey);
        if (existActivity != null) {
            log.info("[FlashDiscount] traceId={}, 幂等命中, 活动已存在, activityId={}, name={}",
                    traceId, existActivity.getActivityId(), existActivity.getActivityName());
            return existActivity.getActivityId();
        }

        // ========== 4. 持久化 ==========
        Long activityId = generateActivityId(); // 雪花算法
        FlashDiscountActivity activity = new FlashDiscountActivity();
        activity.setActivityId(activityId);
        activity.setActivityName(request.getActivityName());
        activity.setCreator(request.getCreator());
        activity.setDiscountRate(request.getDiscountRate());
        activity.setScopeType(request.getScopeType());
        activity.setScopeValues(JSON.toJSONString(request.getScopeValues()));
        activity.setStartTime(request.getStartTime());
        activity.setEndTime(request.getEndTime());
        activity.setBudgetTotal(request.getBudgetTotal());
        activity.setBudgetUsed(0L);
        activity.setPerUserLimit(request.getPerUserLimit());
        activity.setStatus(0); // 待生效
        activity.setIdempotentKey(idempotentKey);

        try {
            activityMapper.insert(activity);
            log.info("[FlashDiscount] traceId={}, 活动持久化成功, activityId={}, idempotentKey={}",
                    traceId, activityId, idempotentKey);
        } catch (DuplicateKeyException e) {
            // 并发创建冲突
            log.warn("[FlashDiscount] traceId={}, 并发创建冲突, 幂等键={}, 返回已有活动",
                    traceId, idempotentKey);
            FlashDiscountActivity concurrent = activityMapper.selectByIdempotentKey(idempotentKey);
            return concurrent != null ? concurrent.getActivityId() : activityId;
        }

        // ========== 5. 初始化预算 ==========
        budgetService.initBudget(activityId, request.getBudgetTotal());
        log.info("[FlashDiscount] traceId={}, 预算初始化完成, activityId={}, budget={}分",
                traceId, activityId, request.getBudgetTotal());

        // ========== 6. 预热缓存（如果活动即将开始） ==========
        LocalDateTime now = LocalDateTime.now();
        LocalDateTime startLdt = LocalDateTime.ofInstant(
                request.getStartTime().toInstant(), ZoneId.systemDefault());
        if (startLdt.isBefore(now.plusMinutes(5))) {
            // 5分钟内开始的活动立即预热缓存
            warmupCache(activity, traceId);
        }

        log.info("[FlashDiscount] traceId={}, 创建限时折扣活动完成, activityId={}",
                traceId, activityId);
        return activityId;
    }

    // ==================== 定时任务：活动生效 ====================

    /**
     * 定时任务：每分钟扫描，将到期的待生效活动改为进行中
     * 由 XXL-JOB 或 Spring Scheduled 调用
     */
    public void activatePendingActivities() {
        String traceId = "scheduled-" + System.currentTimeMillis();
        log.info("[FlashDiscount] traceId={}, 定时任务扫描待生效活动开始", traceId);

        try {
            Date now = new Date();
            List<FlashDiscountActivity> pendingList = activityMapper.selectPendingToActivate(now, 100);

            if (pendingList.isEmpty()) {
                log.debug("[FlashDiscount] traceId={}, 无待生效活动", traceId);
                return;
            }

            log.info("[FlashDiscount] traceId={}, 发现{}个待生效活动", traceId, pendingList.size());

            for (FlashDiscountActivity activity : pendingList) {
                try {
                    // 状态改为进行中
                    int updated = activityMapper.updateStatus(activity.getActivityId(), 0, 1);
                    if (updated > 0) {
                        // 预热缓存
                        warmupCache(activity, traceId);
                        log.info("[FlashDiscount] traceId={}, 活动[{}]已生效, activityId={}",
                                traceId, activity.getActivityName(), activity.getActivityId());
                    } else {
                        // CAS失败，说明状态已被其他节点修改
                        log.debug("[FlashDiscount] traceId={}, 活动[{}]CAS更新失败，可能已被其他节点处理",
                                traceId, activity.getActivityName());
                    }
                } catch (Exception e) {
                    log.error("[FlashDiscount] traceId={}, 活动[{}]生效失败, activityId={}, error={}",
                            traceId, activity.getActivityName(), activity.getActivityId(), e.getMessage(), e);
                }
            }

            log.info("[FlashDiscount] traceId={}, 定时任务扫描完成, 处理{}个活动", traceId, pendingList.size());
        } catch (Exception e) {
            log.error("[FlashDiscount] traceId={}, 定时任务执行异常, error={}", traceId, e.getMessage(), e);
        }
    }

    /**
     * 定时任务：将到期活动改为已结束
     */
    public void endExpiredActivities() {
        String traceId = "scheduled-end-" + System.currentTimeMillis();
        log.info("[FlashDiscount] traceId={}, 定时任务扫描到期活动开始", traceId);

        try {
            Date now = new Date();
            List<FlashDiscountActivity> activeList = activityMapper.selectExpiredToEnd(now, 100);

            for (FlashDiscountActivity activity : activeList) {
                try {
                    int updated = activityMapper.updateStatus(activity.getActivityId(), 1, 2);
                    if (updated > 0) {
                        // 清理缓存
                        cleanupCache(activity, traceId);
                        log.info("[FlashDiscount] traceId={}, 活动[{}]已结束, activityId={}",
                                traceId, activity.getActivityName(), activity.getActivityId());
                    }
                } catch (Exception e) {
                    log.error("[FlashDiscount] traceId={}, 活动[{}]结束失败, activityId={}, error={}",
                            traceId, activity.getActivityName(), activity.getActivityId(), e.getMessage(), e);
                }
            }
        } catch (Exception e) {
            log.error("[FlashDiscount] traceId={}, 定时任务结束活动异常, error={}", traceId, e.getMessage(), e);
        }
    }

    // ==================== 下单时折扣计算 ====================

    /**
     * 下单时计算限时折扣
     *
     * @param request 下单请求
     * @return 折扣计算结果
     */
    public FlashDiscountResult calculateDiscount(FlashDiscountOrderRequest request) {
        String traceId = request.getTraceId() != null ? request.getTraceId() : UUID.randomUUID().toString();
        log.info("[FlashDiscount] traceId={}, orderId={}, userId={}, 开始限时折扣计算, items={}",
                traceId, request.getOrderId(), request.getUserId(), JSON.toJSONString(request.getItems()));

        try {
            // ========== 1. 幂等检查 ==========
            FlashDiscountUserRecord existRecord = userRecordMapper.selectByOrderId(request.getOrderId());
            if (existRecord != null) {
                log.info("[FlashDiscount] traceId={}, orderId={}, 幂等命中, 已有折扣记录, discountAmount={}分",
                        traceId, request.getOrderId(), existRecord.getQuantity());
                return FlashDiscountResult.fromRecord(existRecord);
            }

            // ========== 2. 查询活动 ==========
            FlashDiscountActivity activity = activityMapper.selectByActivityId(request.getActivityId());
            if (activity == null || activity.getStatus() != 1) {
                log.warn("[FlashDiscount] traceId={}, orderId={}, 活动[{}]不存在或未进行中, status={}",
                        traceId, request.getOrderId(), request.getActivityId(),
                        activity != null ? activity.getStatus() : "null");
                return FlashDiscountResult.noDiscount(request.getOriginalAmount());
            }

            // ========== 3. 限购校验 ==========
            if (activity.getPerUserLimit() > 0) {
                int userPurchased = userRecordMapper.countByActivityAndUser(
                        request.getActivityId(), request.getUserId());
                int requestQty = request.getItems().stream().mapToInt(OrderItem::getQuantity).sum();
                if (userPurchased + requestQty > activity.getPerUserLimit()) {
                    log.warn("[FlashDiscount] traceId={}, orderId={}, userId={}, 超出限购, 已购={}, 本次={}, 限购={}",
                            traceId, request.getOrderId(), request.getUserId(),
                            userPurchased, requestQty, activity.getPerUserLimit());
                    return FlashDiscountResult.noDiscount(request.getOriginalAmount());
                }
                log.info("[FlashDiscount] traceId={}, orderId={}, userId={}, 限购校验通过, 已购={}, 本次={}, 限购={}",
                        traceId, request.getOrderId(), request.getUserId(),
                        userPurchased, requestQty, activity.getPerUserLimit());
            }

            // ========== 4. 计算折扣金额 ==========
            int originalAmount = request.getOriginalAmount();
            BigDecimal discountRate = activity.getDiscountRate();
            int discountAmount = new BigDecimal(originalAmount)
                    .multiply(BigDecimal.ONE.subtract(discountRate))
                    .setScale(0, RoundingMode.DOWN)
                    .intValue();
            int finalAmount = originalAmount - discountAmount;

            log.info("[FlashDiscount] traceId={}, orderId={}, 折扣计算: 原价={}分, 折扣率={}, 优惠={}分, 最终={}分",
                    traceId, request.getOrderId(), originalAmount, discountRate, discountAmount, finalAmount);

            // ========== 5. 预算扣减 ==========
            boolean budgetOk = budgetService.deductBudget(activity.getActivityId(), discountAmount);
            if (!budgetOk) {
                log.warn("[FlashDiscount] traceId={}, orderId={}, 活动[{}]预算不足, 降级返回原价",
                        traceId, request.getOrderId(), activity.getActivityName());
                return FlashDiscountResult.noDiscount(originalAmount);
            }

            // ========== 6. 记录用户参与 ==========
            FlashDiscountUserRecord record = new FlashDiscountUserRecord();
            record.setActivityId(activity.getActivityId());
            record.setUserId(request.getUserId());
            record.setOrderId(request.getOrderId());
            record.setSkuId(request.getItems().get(0).getSkuId());
            record.setQuantity(request.getItems().stream().mapToInt(OrderItem::getQuantity).sum());

            try {
                userRecordMapper.insert(record);
            } catch (DuplicateKeyException e) {
                log.warn("[FlashDiscount] traceId={}, orderId={}, 并发写入冲突, 回滚预算",
                        traceId, request.getOrderId());
                budgetService.restoreBudget(activity.getActivityId(), discountAmount);
                FlashDiscountUserRecord concurrent = userRecordMapper.selectByOrderId(request.getOrderId());
                if (concurrent != null) {
                    return FlashDiscountResult.fromRecord(concurrent);
                }
                return FlashDiscountResult.noDiscount(originalAmount);
            }

            // ========== 7. 返回结果 ==========
            FlashDiscountResult result = new FlashDiscountResult();
            result.setOrderId(request.getOrderId());
            result.setActivityId(activity.getActivityId());
            result.setActivityName(activity.getActivityName());
            result.setOriginalAmount(originalAmount);
            result.setDiscountAmount(discountAmount);
            result.setFinalAmount(finalAmount);
            result.setTraceId(traceId);

            log.info("[FlashDiscount] traceId={}, orderId={}, 限时折扣计算完成, 最终价={}分",
                    traceId, request.getOrderId(), finalAmount);
            return result;

        } catch (Exception e) {
            log.error("[FlashDiscount] traceId={}, orderId={}, 限时折扣计算异常, 降级返回原价, error={}",
                    traceId, request.getOrderId(), e.getMessage(), e);
            return FlashDiscountResult.noDiscount(request.getOriginalAmount());
        }
    }

    // ==================== 私有方法 ====================

    /**
     * 参数校验
     */
    private void validateCreateRequest(FlashDiscountCreateRequest request, String traceId) {
        if (request.getActivityName() == null || request.getActivityName().trim().isEmpty()) {
            throw new FlashDiscountException("活动名称不能为空");
        }
        if (request.getDiscountRate() == null
                || request.getDiscountRate().compareTo(BigDecimal.ZERO) <= 0
                || request.getDiscountRate().compareTo(BigDecimal.ONE) >= 0) {
            throw new FlashDiscountException("折扣率必须在0~1之间（不含0和1）");
        }
        if (request.getStartTime() == null || request.getEndTime() == null) {
            throw new FlashDiscountException("开始时间和结束时间不能为空");
        }
        if (!request.getEndTime().after(request.getStartTime())) {
            throw new FlashDiscountException("结束时间必须大于开始时间");
        }
        if (request.getStartTime().before(new Date())) {
            throw new FlashDiscountException("开始时间不能早于当前时间");
        }
        if (request.getBudgetTotal() <= 0) {
            throw new FlashDiscountException("预算必须大于0");
        }
        log.info("[FlashDiscount] traceId={}, 参数校验通过", traceId);
    }

    /**
     * 检查同一范围的活动时间是否重叠
     */
    private void checkTimeOverlap(FlashDiscountCreateRequest request, String traceId) {
        List<FlashDiscountActivity> overlapping = activityMapper.selectOverlappingActivities(
                request.getScopeType(), request.getScopeValues(),
                request.getStartTime(), request.getEndTime());

        if (!overlapping.isEmpty()) {
            log.warn("[FlashDiscount] traceId={}, 时间重叠检查失败, scope={}, overlappingActivities={}",
                    traceId, request.getScopeType(),
                    overlapping.stream().map(a -> a.getActivityId() + ":" + a.getActivityName())
                            .reduce((a, b) -> a + "," + b).orElse(""));
            throw new FlashDiscountException("同一范围内已有活动时间重叠: "
                    + overlapping.get(0).getActivityName());
        }
        log.info("[FlashDiscount] traceId={}, 时间重叠检查通过", traceId);
    }

    /**
     * 缓存预热
     */
    private void warmupCache(FlashDiscountActivity activity, String traceId) {
        try {
            String detailKey = "flash:detail:" + activity.getActivityId();
            redisTemplate.opsForValue().set(detailKey, JSON.toJSONString(activity), 24, TimeUnit.HOURS);

            // 构建倒排索引
            if ("PRODUCT".equals(activity.getScopeType())) {
                List<Long> skuIds = JSON.parseArray(activity.getScopeValues(), Long.class);
                for (Long skuId : skuIds) {
                    String indexKey = "flash:index:sku:" + skuId;
                    redisTemplate.opsForList().rightPush(indexKey, String.valueOf(activity.getActivityId()));
                    redisTemplate.expire(indexKey, 24, TimeUnit.HOURS);
                }
            }
            log.info("[FlashDiscount] traceId={}, 缓存预热完成, activityId={}",
                    traceId, activity.getActivityId());
        } catch (Exception e) {
            log.error("[FlashDiscount] traceId={}, 缓存预热失败, activityId={}, error={}",
                    traceId, activity.getActivityId(), e.getMessage(), e);
        }
    }

    /**
     * 缓存清理
     */
    private void cleanupCache(FlashDiscountActivity activity, String traceId) {
        try {
            redisTemplate.delete("flash:detail:" + activity.getActivityId());
            if ("PRODUCT".equals(activity.getScopeType())) {
                List<Long> skuIds = JSON.parseArray(activity.getScopeValues(), Long.class);
                for (Long skuId : skuIds) {
                    redisTemplate.delete("flash:index:sku:" + skuId);
                }
            }
            log.info("[FlashDiscount] traceId={}, 缓存清理完成, activityId={}",
                    traceId, activity.getActivityId());
        } catch (Exception e) {
            log.error("[FlashDiscount] traceId={}, 缓存清理失败, activityId={}, error={}",
                    traceId, activity.getActivityId(), e.getMessage(), e);
        }
    }

    /**
     * 构建幂等键：MD5(activityName + startTime + endTime)
     */
    private String buildIdempotentKey(String name, Date startTime, Date endTime) {
        String raw = name + "|" + startTime.getTime() + "|" + endTime.getTime();
        try {
            MessageDigest md = MessageDigest.getInstance("MD5");
            byte[] digest = md.digest(raw.getBytes());
            return new BigInteger(1, digest).toString(16);
        } catch (NoSuchAlgorithmException e) {
            return raw;
        }
    }

    /**
     * 生成活动ID（简化版，实际用雪花算法）
     */
    private Long generateActivityId() {
        return System.currentTimeMillis() * 1000 + new Random().nextInt(1000);
    }
}

    public FlashDiscountException(String message) {
        super(message);
    }
```

#### 6.2.4 关键设计说明

| 维度 | 实现方式 | 说明 |
|------|---------|------|
| 创建幂等 | name + 时间范围 MD5 + DB唯一索引 | 防止重复提交创建相同活动 |
| 下单幂等 | orderId 唯一索引 | 同一订单不重复享受折扣 |
| 状态机 | 0待生效 -> 1进行中 -> 2已结束 | CAS更新防并发状态覆盖 |
| 定时任务 | 每分钟扫描生效/结束 | 分页处理，单条异常不影响整体 |
| 限购控制 | 查用户已购数量 + 本次数量比较 | 防止超出per_user_limit |
| 缓存预热 | 生效时写Redis，结束时清Redis | 保证下单时缓存可用 |
| 异常降级 | 下单计算异常时返回原价 | 不阻断下单主流程 |
| 预算管控 | Redis Lua原子扣减 + 回滚机制 | 防超预算 + 并发安全 |

#### 6.3.3 完整Java代码

```java
package com.ecommerce.promotion.groupbuy;

import com.alibaba.fastjson.JSON;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.dao.DuplicateKeyException;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.script.DefaultRedisScript;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.math.BigInteger;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.util.*;
import java.util.concurrent.TimeUnit;

/**
 * 拼团活动全链路服务
 *
 * 覆盖：开团 -> 参团 -> 成团/失败 -> 结算
 *
 * 幂等控制：
 *   - 开团幂等：userId + activityId 唯一约束（同一用户同一活动只能开一个团）
 *   - 参团幂等：group_id + user_id 唯一约束（同一用户不能重复参同一团）
 *   - 成团结算幂等：group_id 唯一约束（成团操作只执行一次）
 *
 * 异常处理：开团/参团失败抛业务异常，成团结算失败走重试 + 告警
 * 日志记录：全链路打日志，含groupId/userId/orderId
 * 并发控制：Redis原子计数 + DB唯一索引双重保障
 */
@Service
public class GroupBuyService {

    private static final Logger log = LoggerFactory.getLogger(GroupBuyService.class);

    @Autowired
    private GroupBuyActivityMapper activityMapper;

    @Autowired
    private GroupBuyGroupMapper groupMapper;

    @Autowired
    private GroupBuyMemberMapper memberMapper;

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private OrderService orderService;

    /**
     * Redis Lua脚本：原子增加参团人数，返回增加后的值
     * 如果增加后超过required_count则回滚返回-1
     */
    private static final String JOIN_GROUP_LUA =
        "local current = redis.call('GET', KEYS[1])\n" +
        "if not current then return -2 end\n" +
        "current = tonumber(current)\n" +
        "local required = tonumber(ARGV[1])\n" +
        "if current >= required then return -1 end\n" +
        "local newVal = redis.call('INCR', KEYS[1])\n" +
        "if newVal > required then\n" +
        "  redis.call('DECR', KEYS[1])\n" +
        "  return -1\n" +
        "end\n" +
        "return newVal\n";

    // ==================== 开团 ====================

    /**
     * 用户发起拼团（开团）
     *
     * @param request 开团请求
     * @return 拼团团信息
     * @throws GroupBuyException 开团失败时抛出
     */
    @Transactional(rollbackFor = Exception.class)
    public GroupBuyGroupVO createGroup(CreateGroupRequest request) {
        String traceId = request.getTraceId() != null ? request.getTraceId() : UUID.randomUUID().toString();
        log.info("[GroupBuy] traceId={}, userId={}, activityId={}, 用户发起开团",
                traceId, request.getUserId(), request.getActivityId());

        try {
            // ========== 1. 查询活动 ==========
            GroupBuyActivity activity = activityMapper.selectByActivityId(request.getActivityId());
            if (activity == null) {
                throw new GroupBuyException("拼团活动不存在");
            }
            if (activity.getStatus() != 1) {
                throw new GroupBuyException("拼团活动未进行中, status=" + activity.getStatus());
            }

            // 校验活动时间
            Date now = new Date();
            if (now.before(activity.getStartTime()) || now.after(activity.getEndTime())) {
                throw new GroupBuyException("不在活动有效期内");
            }

            log.info("[GroupBuy] traceId={}, activityId={}, 活动校验通过, skuId={}, groupPrice={}分, required={}",
                    traceId, activity.getActivityId(), activity.getSkuId(),
                    activity.getGroupPrice(), activity.getRequiredCount());

            // ========== 2. 限购校验 ==========
            if (activity.getPerUserLimit() > 0) {
                int userJoined = memberMapper.countByUserAndActivity(request.getUserId(), activity.getActivityId());
                if (userJoined >= activity.getPerUserLimit()) {
                    throw new GroupBuyException("已达到限购数量: " + activity.getPerUserLimit());
                }
                log.info("[GroupBuy] traceId={}, userId={}, 限购校验通过, 已参与={}, 限购={}",
                        traceId, request.getUserId(), userJoined, activity.getPerUserLimit());
            }

            // ========== 3. 开团数限制 ==========
            if (activity.getMaxGroups() > 0) {
                int updated = activityMapper.incrementCurrentGroups(
                        activity.getActivityId(), activity.getMaxGroups());
                if (updated == 0) {
                    throw new GroupBuyException("开团数量已达上限");
                }
                log.info("[GroupBuy] traceId={}, 开团数+1, activityId={}",
                        traceId, activity.getActivityId());
            }

            // ========== 4. 创建拼团团 ==========
            Long groupId = generateGroupId();
            GroupBuyGroup group = new GroupBuyGroup();
            group.setGroupId(groupId);
            group.setActivityId(activity.getActivityId());
            group.setLeaderUserId(request.getUserId());
            group.setRequiredCount(activity.getRequiredCount());
            group.setCurrentCount(1); // 团长算第1人
            group.setStatus(0); // 拼团中
            group.setExpireTime(new Date(System.currentTimeMillis()
                    + activity.getTimeLimit() * 3600 * 1000L));

            groupMapper.insert(group);
            log.info("[GroupBuy] traceId={}, 拼团团创建成功, groupId={}, leader={}, expire={}",
                    traceId, groupId, request.getUserId(), group.getExpireTime());

            // ========== 5. 团长加入成员表 ==========
            GroupBuyMember leaderMember = new GroupBuyMember();
            leaderMember.setGroupId(groupId);
            leaderMember.setUserId(request.getUserId());
            leaderMember.setOrderId(request.getOrderId());

            try {
                memberMapper.insert(leaderMember);
            } catch (DuplicateKeyException e) {
                log.error("[GroupBuy] traceId={}, userId={}, 团长重复加入, groupId={}",
                        traceId, request.getUserId(), groupId);
                throw new GroupBuyException("您已参与该拼团活动");
            }

            // ========== 6. 初始化Redis参团计数 ==========
            String countKey = "groupbuy:count:" + groupId;
            redisTemplate.opsForValue().set(countKey, "1",
                    activity.getTimeLimit(), TimeUnit.HOURS);

            // ========== 7. 创建团长订单 ==========
            orderService.createGroupBuyOrder(
                    request.getUserId(), activity.getSkuId(),
                    activity.getGroupPrice(), groupId, traceId);

            log.info("[GroupBuy] traceId={}, 开团完成, groupId={}, activityId={}, leader={}",
                    traceId, groupId, activity.getActivityId(), request.getUserId());

            return convertToVO(group, activity);

        } catch (GroupBuyException e) {
            log.warn("[GroupBuy] traceId={}, userId={}, 开团失败: {}",
                    traceId, request.getUserId(), e.getMessage());
            throw e;
        } catch (DuplicateKeyException e) {
            log.warn("[GroupBuy] traceId={}, userId={}, 开团冲突(并发重复), activityId={}",
                    traceId, request.getUserId(), request.getActivityId());
            throw new GroupBuyException("请勿重复发起拼团");
        } catch (Exception e) {
            log.error("[GroupBuy] traceId={}, userId={}, 开团异常, activityId={}, error={}",
                    traceId, request.getUserId(), request.getActivityId(), e.getMessage(), e);
            throw new GroupBuyException("开团失败，请稍后重试: " + e.getMessage());
        }
    }

    // ==================== 参团 ====================

    /**
     * 用户参加拼团
     *
     * @param request 参团请求
     * @return 参团结果
     * @throws GroupBuyException 参团失败时抛出
     */
    @Transactional(rollbackFor = Exception.class)
    public JoinGroupResult joinGroup(JoinGroupRequest request) {
        String traceId = request.getTraceId() != null ? request.getTraceId() : UUID.randomUUID().toString();
        log.info("[GroupBuy] traceId={}, userId={}, groupId={}, 用户参团",
                traceId, request.getUserId(), request.getGroupId());

        try {
            // ========== 1. 查询拼团团 ==========
            GroupBuyGroup group = groupMapper.selectByGroupId(request.getGroupId());
            if (group == null) {
                throw new GroupBuyException("拼团团不存在");
            }
            if (group.getStatus() != 0) {
                throw new GroupBuyException("拼团团状态异常, status=" + group.getStatus());
            }

            // 校验是否过期
            if (new Date().after(group.getExpireTime())) {
                log.warn("[GroupBuy] traceId={}, groupId={}, 拼团已过期, expireTime={}",
                        traceId, request.getGroupId(), group.getExpireTime());
                throw new GroupBuyException("拼团已过期");
            }

            // 不能参加自己开的团
            if (group.getLeaderUserId().equals(request.getUserId())) {
                throw new GroupBuyException("不能参加自己发起的拼团");
            }

            // 查询活动信息
            GroupBuyActivity activity = activityMapper.selectByActivityId(group.getActivityId());
            if (activity == null || activity.getStatus() != 1) {
                throw new GroupBuyException("拼团活动不存在或已结束");
            }

            log.info("[GroupBuy] traceId={}, groupId={}, 团校验通过, currentCount={}, required={}",
                    traceId, request.getGroupId(), group.getCurrentCount(), group.getRequiredCount());

            // ========== 2. 限购校验 ==========
            if (activity.getPerUserLimit() > 0) {
                int userJoined = memberMapper.countByUserAndActivity(
                        request.getUserId(), activity.getActivityId());
                if (userJoined >= activity.getPerUserLimit()) {
                    throw new GroupBuyException("已达到限购数量");
                }
            }

            // ========== 3. Redis原子增加参团人数 ==========
            String countKey = "groupbuy:count:" + request.getGroupId();
            DefaultRedisScript<Long> script = new DefaultRedisScript<>();
            script.setScriptText(JOIN_GROUP_LUA);
            script.setResultType(Long.class);

            Long newCount = redisTemplate.execute(script,
                    Collections.singletonList(countKey),
                    String.valueOf(group.getRequiredCount()));

            if (newCount == null || newCount == -2) {
                log.error("[GroupBuy] traceId={}, groupId={}, Redis计数键不存在, 可能缓存已过期",
                        traceId, request.getGroupId());
                throw new GroupBuyException("拼团已结束，请选择其他拼团");
            }
            if (newCount == -1) {
                log.warn("[GroupBuy] traceId={}, groupId={}, 拼团人数已满, required={}",
                        traceId, request.getGroupId(), group.getRequiredCount());
                throw new GroupBuyException("拼团人数已满");
            }

            log.info("[GroupBuy] traceId={}, groupId={}, Redis参团计数成功, newCount={}/{}",
                    traceId, request.getGroupId(), newCount, group.getRequiredCount());

            // ========== 4. 写入成员表（幂等） ==========
            GroupBuyMember member = new GroupBuyMember();
            member.setGroupId(request.getGroupId());
            member.setUserId(request.getUserId());
            member.setOrderId(request.getOrderId());

            try {
                memberMapper.insert(member);
            } catch (DuplicateKeyException e) {
                // 并发或重复参团，回滚Redis计数
                redisTemplate.opsForValue().decrement(countKey);
                log.warn("[GroupBuy] traceId={}, userId={}, groupId={}, 重复参团, 回滚Redis计数",
                        traceId, request.getUserId(), request.getGroupId());
                throw new GroupBuyException("您已参与该拼团");
            }

            // ========== 5. 更新DB团人数 ==========
            groupMapper.incrementCurrentCount(request.getGroupId());
            log.info("[GroupBuy] traceId={}, groupId={}, DB团人数+1", traceId, request.getGroupId());

            // ========== 6. 创建参团用户订单 ==========
            orderService.createGroupBuyOrder(
                    request.getUserId(), activity.getSkuId(),
                    activity.getGroupPrice(), request.getGroupId(), traceId);

            // ========== 7. 判断是否成团 ==========
            if (newCount >= group.getRequiredCount()) {
                log.info("[GroupBuy] traceId={}, groupId={}, 参团人数达到要求, 触发成团, count={}/{}",
                        traceId, request.getGroupId(), newCount, group.getRequiredCount());
                handleGroupSuccess(request.getGroupId(), traceId);
            }

            JoinGroupResult result = new JoinGroupResult();
            result.setGroupId(request.getGroupId());
            result.setUserId(request.getUserId());
            result.setCurrentCount(newCount.intValue());
            result.setRequiredCount(group.getRequiredCount());
            result.setGroupStatus(newCount >= group.getRequiredCount() ? 1 : 0);
            result.setTraceId(traceId);

            log.info("[GroupBuy] traceId={}, userId={}, groupId={}, 参团完成, currentCount={}/{}",
                    traceId, request.getUserId(), request.getGroupId(), newCount, group.getRequiredCount());

            return result;

        } catch (GroupBuyException e) {
            log.warn("[GroupBuy] traceId={}, userId={}, groupId={}, 参团失败: {}",
                    traceId, request.getUserId(), request.getGroupId(), e.getMessage());
            throw e;
        } catch (Exception e) {
            log.error("[GroupBuy] traceId={}, userId={}, groupId={}, 参团异常, error={}",
                    traceId, request.getUserId(), request.getGroupId(), e.getMessage(), e);
            throw new GroupBuyException("参团失败，请稍后重试: " + e.getMessage());
        }
    }

    // ==================== 成团处理 ====================

    /**
     * 成团处理
     * 幂等：CAS更新 status 0->1，只有一个线程能成功
     */
    @Transactional(rollbackFor = Exception.class)
    public void handleGroupSuccess(Long groupId, String traceId) {
        log.info("[GroupBuy] traceId={}, groupId={}, 开始成团处理", traceId, groupId);

        try {
            // CAS更新团状态：0(拼团中) -> 1(已成团)
            int updated = groupMapper.updateStatusCAS(groupId, 0, 1, new Date());
            if (updated == 0) {
                // 已被其他线程处理（成团或失败）
                log.info("[GroupBuy] traceId={}, groupId={}, CAS更新失败, 团状态已被其他线程修改, 幂等返回",
                        traceId, groupId);
                return;
            }

            GroupBuyGroup group = groupMapper.selectByGroupId(groupId);
            GroupBuyActivity activity = activityMapper.selectByActivityId(group.getActivityId());

            log.info("[GroupBuy] traceId={}, groupId={}, 团状态已更新为已成团, 成团时间={}, activityId={}",
                    traceId, groupId, group.getSuccessTime(), group.getActivityId());

            // 扣减活动库存
            int stockUpdated = activityMapper.deductStock(
                    activity.getActivityId(), group.getRequiredCount());
            if (stockUpdated == 0) {
                log.error("[GroupBuy] traceId={}, groupId={}, 活动库存不足, 需人工处理, activityId={}",
                        traceId, groupId, activity.getActivityId());
                // 库存不足，发告警
                // 实际应调用告警服务 alertService.sendAlert(...)
                return;
            }

            log.info("[GroupBuy] traceId={}, groupId={}, 活动库存扣减成功, deductCount={}",
                    traceId, groupId, group.getRequiredCount());

            // 更新所有成员订单状态为已成团
            List<GroupBuyMember> members = memberMapper.selectByGroupId(groupId);
            for (GroupBuyMember member : members) {
                try {
                    orderService.confirmGroupBuyOrder(member.getOrderId(), groupId, traceId);
                    log.info("[GroupBuy] traceId={}, groupId={}, 订单[{}]已确认成团, userId={}",
                            traceId, groupId, member.getOrderId(), member.getUserId());
                } catch (Exception e) {
                    log.error("[GroupBuy] traceId={}, groupId={}, 订单[{}]确认成团失败, userId={}, error={}",
                            traceId, groupId, member.getOrderId(), member.getUserId(), e.getMessage(), e);
                    // 单个订单失败不影响整体，后续补偿
                }
            }

            // 清理Redis缓存
            redisTemplate.delete("groupbuy:count:" + groupId);

            log.info("[GroupBuy] traceId={}, groupId={}, 成团处理完成, 成员数={}",
                    traceId, groupId, members.size());

        } catch (Exception e) {
            log.error("[GroupBuy] traceId={}, groupId={}, 成团处理异常, error={}",
                    traceId, groupId, e.getMessage(), e);
            throw e;
        }
    }

    // ==================== 拼团超时失败处理 ====================

    /**
     * 定时任务：处理超时未成团的拼团
     * 每分钟执行一次
     */
    public void handleExpiredGroups() {
        String traceId = "scheduled-group-" + System.currentTimeMillis();
        log.info("[GroupBuy] traceId={}, 定时任务扫描超时拼团开始", traceId);

        try {
            Date now = new Date();
            List<GroupBuyGroup> expiredGroups = groupMapper.selectExpiredGroups(now, 0, 100);

            if (expiredGroups.isEmpty()) {
                log.debug("[GroupBuy] traceId={}, 无超时拼团", traceId);
                return;
            }

            log.info("[GroupBuy] traceId={}, 发现{}个超时拼团", traceId, expiredGroups.size());

            for (GroupBuyGroup group : expiredGroups) {
                try {
                    handleGroupFail(group, traceId);
                } catch (Exception e) {
                    log.error("[GroupBuy] traceId={}, groupId={}, 超时拼团处理失败, error={}",
                            traceId, group.getGroupId(), e.getMessage(), e);
                }
            }

            log.info("[GroupBuy] traceId={}, 定时任务完成, 处理{}个超时拼团", traceId, expiredGroups.size());
        } catch (Exception e) {
            log.error("[GroupBuy] traceId={}, 定时任务异常, error={}", traceId, e.getMessage(), e);
        }
    }

    /**
     * 拼团失败处理：退款 + 更新状态
     * 幂等：CAS更新 status 0->2
     */
    @Transactional(rollbackFor = Exception.class)
    public void handleGroupFail(GroupBuyGroup group, String traceId) {
        log.info("[GroupBuy] traceId={}, groupId={}, 开始拼团失败处理", traceId, group.getGroupId());

        try {
            // CAS更新：0(拼团中) -> 2(已失败)
            int updated = groupMapper.updateStatusCAS(group.getGroupId(), 0, 2, null);
            if (updated == 0) {
                log.info("[GroupBuy] traceId={}, groupId={}, CAS更新失败, 团状态已变更, 幂等返回",
                        traceId, group.getGroupId());
                return;
            }

            log.info("[GroupBuy] traceId={}, groupId={}, 团状态已更新为已失败", traceId, group.getGroupId());

            // 查询所有成员，执行退款
            List<GroupBuyMember> members = memberMapper.selectByGroupId(group.getGroupId());
            for (GroupBuyMember member : members) {
                try {
                    orderService.refundGroupBuyOrder(member.getOrderId(), group.getGroupId(), traceId);
                    log.info("[GroupBuy] traceId={}, groupId={}, 订单[{}]退款成功, userId={}",
                            traceId, group.getGroupId(), member.getOrderId(), member.getUserId());
                } catch (Exception e) {
                    log.error("[GroupBuy] traceId={}, groupId={}, 订单[{}]退款失败, userId={}, error={}, 需人工补偿",
                            traceId, group.getGroupId(), member.getOrderId(), member.getUserId(), e.getMessage(), e);
                }
            }

            // 恢复活动开团数
            activityMapper.decrementCurrentGroups(group.getActivityId());

            // 清理Redis
            redisTemplate.delete("groupbuy:count:" + group.getGroupId());

            log.info("[GroupBuy] traceId={}, groupId={}, 拼团失败处理完成, 退款{}人",
                    traceId, group.getGroupId(), members.size());

        } catch (Exception e) {
            log.error("[GroupBuy] traceId={}, groupId={}, 拼团失败处理异常, error={}",
                    traceId, group.getGroupId(), e.getMessage(), e);
            throw e;
        }
    }

    // ==================== 私有方法 ====================

    /**
     * 生成团ID（简化版，实际用雪花算法）
     */
    private Long generateGroupId() {
        return System.currentTimeMillis() * 1000 + new Random().nextInt(1000);
    }

    /**
     * 转换为VO
     */
    private GroupBuyGroupVO convertToVO(GroupBuyGroup group, GroupBuyActivity activity) {
        GroupBuyGroupVO vo = new GroupBuyGroupVO();
        vo.setGroupId(group.getGroupId());
        vo.setActivityId(group.getActivityId());
        vo.setActivityName(activity.getActivityName());
        vo.setLeaderUserId(group.getLeaderUserId());
        vo.setRequiredCount(group.getRequiredCount());
        vo.setCurrentCount(group.getCurrentCount());
        vo.setStatus(group.getStatus());
        vo.setExpireTime(group.getExpireTime());
        vo.setGroupPrice(activity.getGroupPrice());
        vo.setOriginalPrice(activity.getOriginalPrice());
        return vo;
    }
}
```

#### 6.3.5 关键设计说明

| 维度 | 实现方式 | 说明 |
|------|---------|------|
| 开团幂等 | userId + activityId 业务校验 + max_groups CAS | 同一用户不可重复开团，开团数不超上限 |
| 参团幂等 | group_id + user_id 唯一索引 + orderId 唯一索引 | 防止重复参团和重复下单 |
| 成团幂等 | CAS更新 status 0->1 | 只有一个线程能成功成团 |
| 失败幂等 | CAS更新 status 0->2 | 超时失败只处理一次 |
| 并发控制 | Redis Lua原子计数 + DB唯一索引 | 参团人数不超限，双重保障 |
| 异常处理 | 开团/参团抛业务异常，成团/失败补偿重试 | 单个订单失败不影响整体流程 |
| 日志记录 | 全链路打日志，含traceId/groupId/userId/orderId | 精确追踪每个用户的拼团行为 |
| 超时处理 | 定时任务扫描过期团，自动退款 | 防止用户资金长时间占用 |
| 库存扣减 | 成团时扣减，失败时不扣 | 避免库存泄漏 |

### 6.4 三个案例的对比总结

| 维度 | 案例一：满减 | 案例二：限时折扣 | 案例三：拼团 |
|------|------------|----------------|------------|
| 核心链路 | 下单计算 -> 预算扣减 | 创建 -> 生效 -> 下单计算 | 开团 -> 参团 -> 成团/失败 |
| 幂等机制 | MD5(orderId) + DB唯一索引 | idempotentKey + orderId双幂等 | group_id+user_id + CAS状态机 |
| 并发控制 | DuplicateKeyException捕获 | CAS状态更新 + 限购计数 | Redis Lua原子计数 + DB唯一索引 |
| 异常降级 | 降级返回原价 | 降级返回原价 | 抛业务异常给用户 |
| 预算管控 | Redis Lua扣减 + 回滚 | Redis Lua扣减 + 回滚 | 成团时扣库存，失败不扣 |
| 定时任务 | 无 | 活动生效/结束 | 超时拼团失败处理 |
| 日志粒度 | 计算每步 + 分摊结果 | 创建/生效/下单全链路 | 开团/参团/成团/退款全链路 |
