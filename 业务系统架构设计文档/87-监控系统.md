# 分布式链路追踪与监控系统架构设计

## 一、系统概述

### 1.1 业务背景

在微服务架构下，一次用户请求往往会经过数十个服务节点。当出现性能瓶颈或故障时，需要一种机制能够追踪请求在各服务间的完整调用链路，精确定位问题所在。分布式链路追踪系统基于Google Dapper论文的核心思想，通过在每次请求中注入唯一标识，记录请求在各服务节点的处理信息，实现全链路的可观测性。

### 1.2 核心需求

1. **分布式会话追踪**：追踪一次请求在所有微服务间的完整调用链路
2. **Trace/Span模型**：Trace表示完整请求过程，Span为埋点上报单位
3. **全局唯一traceId**：标识一次完整的请求调用链
4. **层级spanId**：用点号分隔记录调用层级关系（如1.1、1.2、1.2.1）
5. **Span生命周期管理**：ClientSend → RPC调用 → ClientRecv，结束时异步上报
6. **上下文传递**：通过Thrift协议修改和HTTP Header实现跨服务传递
7. **采样策略**：默认1%采样率，支持每天2000多亿条数据
8. **ThreadLocal上下文管理**：支持跨线程传递追踪上下文

### 1.3 技术挑战

| 挑战 | 说明 |
|------|------|
| 海量数据 | 每天2000+亿条Span数据的采集、传输、存储 |
| 低侵入性 | 埋点对业务代码的侵入要尽量小 |
| 低性能损耗 | 追踪开销不能影响业务性能，目标<3% |
| 跨语言支持 | 支持Java/Go/Python等多语言服务 |
| 上下文传递 | 跨线程、跨协程的上下文透传 |
| 实时性 | 链路查询需秒级响应 |

### 1.4 设计目标

- 单次请求追踪的额外延迟 < 1ms
- CPU开销 < 3%
- 数据从产生到可查询 < 10s
- 链路查询响应时间 < 3s
- 系统可用性 99.99%
- 支持每天万亿级Span数据

```java
/**
 * 系统数据流转总览
 * 
 * 设计模式：管道-过滤器模式(Pipe-Filter Pattern)
 * 数据从采集到存储经过一系列处理阶段，
 * 每个阶段独立处理、可独立扩展
 * 
 * 流转过程：
 * 1. 业务服务埋点 → 本地缓冲
 * 2. 本地缓冲 → 批量发送到消息队列
 * 3. 消息队列 → 实时处理引擎
 * 4. 实时处理 → 多路存储（HBase/ES/HDFS）
 */
public class DataPipeline {

    private final List<PipelineStage> stages;

    /**
     * 管道阶段接口
     */
    interface PipelineStage {
        String getName();
        List<SpanData> process(List<SpanData> input);
    }

    /**
     * 构建数据处理管道
     */
    public DataPipeline() {
        stages = new ArrayList<>();
        stages.add(new DeserializationStage());  // 反序列化
        stages.add(new ValidationStage());        // 数据校验
        stages.add(new EnrichmentStage());         // 数据丰富（添加服务元数据）
        stages.add(new SamplingStage());           // 采样过滤
        stages.add(new AggregationStage());        // 实时聚合
        stages.add(new StorageDispatchStage());    // 存储分发
    }

    /**
     * 执行管道处理
     */
    public void execute(List<SpanData> rawData) {
        List<SpanData> data = rawData;
        for (PipelineStage stage : stages) {
            data = stage.process(data);
            if (data.isEmpty()) break;
        }
    }
}
```

## 三、链路追踪模型

### 3.1 Trace/Span模型

```java
/**
 * Trace模型 - 表示一次完整的请求调用链
 * 
 * 核心概念（源自Google Dapper）：
 * - Trace：一次完整的请求过程，由多个Span组成的有向无环图(DAG)
 * - Span：一个埋点上报单位，记录一次具体的操作
 * - traceId：全局唯一标识，贯穿请求全过程
 * - spanId：层级标识，用点号记录调用深度（如1.1, 1.2, 1.2.1）
 */
public class TraceModel {

    /**
     * Trace - 完整请求链路
     */
    public static class Trace {
        private final String traceId;
        private final List<Span> spans;
        private final long startTime;
        private long endTime;
        private final String rootService;

        public Trace(String traceId, String rootService) {
            this.traceId = traceId;
            this.rootService = rootService;
            this.spans = new ArrayList<>();
            this.startTime = System.currentTimeMillis();
        }

        /**
         * 添加Span到Trace
         */
        public void addSpan(Span span) {
            spans.add(span);
        }

        /**
         * 构建调用树
         * 
         * 算法：根据spanId的层级关系（点号分隔）构建树形结构
         * 例如：1 -> 1.1, 1.2 -> 1.2.1, 1.2.2
         * 
         * 时间复杂度：O(N log N)，N为Span数量
         */
        public SpanTreeNode buildCallTree() {
            // 按spanId排序
            Map<String, Span> spanMap = new HashMap<>();
            for (Span span : spans) {
                spanMap.put(span.getSpanId(), span);
            }

            // 找到根Span
            Span rootSpan = null;
            for (Span span : spans) {
                if (!span.getSpanId().contains(".")) {
                    rootSpan = span;
                    break;
                }
            }

            if (rootSpan == null) return null;

            // 递归构建子树
            return buildSubTree(rootSpan, spanMap);
        }

        private SpanTreeNode buildSubTree(Span span, Map<String, Span> spanMap) {
            SpanTreeNode node = new SpanTreeNode(span);
            String parentId = span.getSpanId();

            for (Map.Entry<String, Span> entry : spanMap.entrySet()) {
                String id = entry.getKey();
                // 判断是否为直接子节点：parentId.X（且X中不含点号）
                if (id.startsWith(parentId + ".")) {
                    String suffix = id.substring(parentId.length() + 1);
                    if (!suffix.contains(".")) {
                        node.addChild(buildSubTree(entry.getValue(), spanMap));
                    }
                }
            }

            // 按开始时间排序子节点
            node.getChildren().sort(
                Comparator.comparingLong(n -> n.getSpan().getStartTime()));

            return node;
        }

        /**
         * 计算关键路径
         * 
         * 算法：DAG最长路径（类似项目管理中的关键路径法CPM）
         * 找出耗时最长的调用链路，即性能瓶颈所在
         */
        public List<Span> findCriticalPath() {
            SpanTreeNode root = buildCallTree();
            if (root == null) return Collections.emptyList();

            List<Span> criticalPath = new ArrayList<>();
            findLongestPath(root, new ArrayList<>(), criticalPath);
            return criticalPath;
        }

        private void findLongestPath(SpanTreeNode node, List<Span> currentPath, 
                                      List<Span> longestPath) {
            currentPath.add(node.getSpan());

            if (node.getChildren().isEmpty()) {
                // 叶子节点，计算路径总耗时
                long currentDuration = currentPath.stream()
                    .mapToLong(Span::getDuration)
                    .sum();
                long longestDuration = longestPath.stream()
                    .mapToLong(Span::getDuration)
                    .sum();

                if (currentDuration > longestDuration) {
                    longestPath.clear();
                    longestPath.addAll(currentPath);
                }
            } else {
                for (SpanTreeNode child : node.getChildren()) {
                    findLongestPath(child, new ArrayList<>(currentPath), longestPath);
                }
            }

            currentPath.remove(currentPath.size() - 1);
        }
    }

    /**
     * Span - 埋点上报单位
     * 
     * 生命周期：
     * ClientSend(cs) → ServerRecv(sr) → ServerSend(ss) → ClientRecv(cr)
     * 
     * 耗时计算：
     * - 客户端耗时 = cr - cs
     * - 服务端耗时 = ss - sr
     * - 网络耗时 = (sr - cs) + (cr - ss)
     */
    public static class Span {
        private final String traceId;
        private final String spanId;
        private final String parentSpanId;
        private final String serviceName;
        private final String operationName;
        private final SpanKind kind;

        // 时间戳记录
        private long startTime;        // 开始时间
        private long endTime;          // 结束时间
        private long csTimestamp;      // ClientSend时间
        private long srTimestamp;      // ServerRecv时间
        private long ssTimestamp;      // ServerSend时间
        private long crTimestamp;      // ClientRecv时间

        // 标签和日志
        private final Map<String, String> tags;
        private final List<LogEntry> logs;

        // 状态
        private SpanStatus status;
        private String errorMessage;

        public Span(String traceId, String spanId, String parentSpanId,
                     String serviceName, String operationName, SpanKind kind) {
            this.traceId = traceId;
            this.spanId = spanId;
            this.parentSpanId = parentSpanId;
            this.serviceName = serviceName;
            this.operationName = operationName;
            this.kind = kind;
            this.tags = new HashMap<>();
            this.logs = new ArrayList<>();
            this.status = SpanStatus.OK;
        }

        /**
         * 记录ClientSend事件
         */
        public void clientSend() {
            this.csTimestamp = System.nanoTime();
            this.startTime = System.currentTimeMillis();
        }

        /**
         * 记录ServerRecv事件
         */
        public void serverRecv() {
            this.srTimestamp = System.nanoTime();
        }

        /**
         * 记录ServerSend事件
         */
        public void serverSend() {
            this.ssTimestamp = System.nanoTime();
        }

        /**
         * 记录ClientRecv事件 - Span结束，触发异步上报
         */
        public void clientRecv() {
            this.crTimestamp = System.nanoTime();
            this.endTime = System.currentTimeMillis();
        }

        /**
         * 计算各段耗时
         */
        public long getDuration() {
            return endTime - startTime;
        }

        public long getServerDuration() {
            return (ssTimestamp - srTimestamp) / 1_000_000; // 纳秒转毫秒
        }

        public long getNetworkDuration() {
            long send = srTimestamp - csTimestamp;
            long recv = crTimestamp - ssTimestamp;
            return (send + recv) / 1_000_000;
        }

        public void addTag(String key, String value) {
            tags.put(key, value);
        }

        public void addLog(String event, String message) {
            logs.add(new LogEntry(System.currentTimeMillis(), event, message));
        }

        // getters
        public String getTraceId() { return traceId; }
        public String getSpanId() { return spanId; }
        public String getParentSpanId() { return parentSpanId; }
        public String getServiceName() { return serviceName; }
        public String getOperationName() { return operationName; }
        public long getStartTime() { return startTime; }
    }

    /**
     * Span调用树节点
     */
    public static class SpanTreeNode {
        private final Span span;
        private final List<SpanTreeNode> children;

        public SpanTreeNode(Span span) {
            this.span = span;
            this.children = new ArrayList<>();
        }

        public void addChild(SpanTreeNode child) {
            children.add(child);
        }

        public Span getSpan() { return span; }
        public List<SpanTreeNode> getChildren() { return children; }
    }

    enum SpanKind { CLIENT, SERVER, PRODUCER, CONSUMER }
    enum SpanStatus { OK, ERROR, TIMEOUT }

    static class LogEntry {
        final long timestamp;
        final String event;
        final String message;

        LogEntry(long timestamp, String event, String message) {
            this.timestamp = timestamp;
            this.event = event;
            this.message = message;
        }
    }
}
```

### 3.2 TraceId生成算法

```java
/**
 * TraceId生成器 - 生成全局唯一的追踪标识
 * 
 * 算法：基于Snowflake思想的改进算法
 * 
 * traceId组成（128位）：
 * - 时间戳（42位）：毫秒级，可用139年
 * - 机器标识（10位）：支持1024个节点
 * - 进程标识（10位）：支持1024个进程
 * - 序列号（16位）：同一毫秒内支持65536个ID
 * - 随机数（50位）：降低碰撞概率
 * 
 * 设计模式：单例模式(Singleton) + 工厂方法模式(Factory Method)
 */
public class TraceIdGenerator {

    private static volatile TraceIdGenerator instance;

    private final int machineId;
    private final int processId;
    private final AtomicLong sequence;
    private volatile long lastTimestamp;

    // 各字段位数
    private static final int TIMESTAMP_BITS = 42;
    private static final int MACHINE_BITS = 10;
    private static final int PROCESS_BITS = 10;
    private static final int SEQUENCE_BITS = 16;

    private static final long MAX_SEQUENCE = (1L << SEQUENCE_BITS) - 1;

    private TraceIdGenerator() {
        this.machineId = resolveMachineId();
        this.processId = resolveProcessId();
        this.sequence = new AtomicLong(0);
        this.lastTimestamp = -1;
    }

    /**
     * 双重检查锁定单例
     */
    public static TraceIdGenerator getInstance() {
        if (instance == null) {
            synchronized (TraceIdGenerator.class) {
                if (instance == null) {
                    instance = new TraceIdGenerator();
                }
            }
        }
        return instance;
    }

    /**
     * 生成traceId
     * 
     * 算法步骤：
     * 1. 获取当前时间戳
     * 2. 如果同一毫秒内，递增序列号
     * 3. 如果序列号溢出，等待下一毫秒
     * 4. 组装各字段生成最终ID
     * 5. 转为32位十六进制字符串
     */
    public synchronized String generateTraceId() {
        long currentTimestamp = System.currentTimeMillis();

        if (currentTimestamp == lastTimestamp) {
            // 同一毫秒内，递增序列号
            long seq = sequence.incrementAndGet();
            if (seq > MAX_SEQUENCE) {
                // 序列号溢出，等待下一毫秒
                currentTimestamp = waitNextMillis(lastTimestamp);
                sequence.set(0);
            }
        } else {
            sequence.set(0);
        }

        lastTimestamp = currentTimestamp;

        // 组装traceId（高64位 + 低64位）
        long high = (currentTimestamp << (64 - TIMESTAMP_BITS))
                   | ((long) machineId << (64 - TIMESTAMP_BITS - MACHINE_BITS))
                   | ((long) processId << (64 - TIMESTAMP_BITS - MACHINE_BITS - PROCESS_BITS));

        long low = (sequence.get() << (64 - SEQUENCE_BITS))
                  | ThreadLocalRandom.current().nextLong(1L << 50);

        return String.format("%016x%016x", high, low);
    }

    /**
     * 等待下一毫秒
     */
    private long waitNextMillis(long lastTimestamp) {
        long timestamp = System.currentTimeMillis();
        while (timestamp <= lastTimestamp) {
            timestamp = System.currentTimeMillis();
        }
        return timestamp;
    }

    /**
     * 解析机器ID - 基于IP地址后10位
     */
    private int resolveMachineId() {
        try {
            InetAddress addr = InetAddress.getLocalHost();
            byte[] ip = addr.getAddress();
            return ((ip[2] & 0x03) << 8) | (ip[3] & 0xFF);
        } catch (Exception e) {
            return ThreadLocalRandom.current().nextInt(1024);
        }
    }

    /**
     * 解析进程ID
     */
    private int resolveProcessId() {
        String name = ManagementFactory.getRuntimeMXBean().getName();
        try {
            return Integer.parseInt(name.split("@")[0]) & 0x3FF;
        } catch (Exception e) {
            return ThreadLocalRandom.current().nextInt(1024);
        }
    }
}

/**
 * SpanId生成器 - 层级编码
 * 
 * 算法：点号分隔的层级编码
 * 
 * 编码规则：
 * - 根Span：spanId = "1"
 * - 第一层子调用：spanId = "1.1", "1.2", "1.3"
 * - 第二层子调用：spanId = "1.1.1", "1.2.1"
 * 
 * 优点：
 * 1. 直观表达调用层级关系
 * 2. 无需查询父Span即可确定层级
 * 3. 支持高效的前缀匹配查询
 */
public class SpanIdGenerator {

    private final AtomicInteger childCounter;
    private final String parentSpanId;

    public SpanIdGenerator(String parentSpanId) {
        this.parentSpanId = parentSpanId;
        this.childCounter = new AtomicInteger(0);
    }

    /**
     * 生成子SpanId
     */
    public String generateChildSpanId() {
        int childIndex = childCounter.incrementAndGet();
        if (parentSpanId == null || parentSpanId.isEmpty()) {
            return String.valueOf(childIndex);
        }
        return parentSpanId + "." + childIndex;
    }

    /**
     * 解析SpanId层级深度
     */
    public static int parseDepth(String spanId) {
        if (spanId == null || spanId.isEmpty()) return 0;
        int depth = 1;
        for (char c : spanId.toCharArray()) {
            if (c == '.') depth++;
        }
        return depth;
    }

    /**
     * 获取父SpanId
     */
    public static String getParentSpanId(String spanId) {
        if (spanId == null || !spanId.contains(".")) return null;
        return spanId.substring(0, spanId.lastIndexOf('.'));
    }

    /**
     * 判断是否为祖先关系
     */
    public static boolean isAncestor(String ancestorId, String descendantId) {
        return descendantId.startsWith(ancestorId + ".");
    }
}
```

## 四、埋点机制

### 4.1 上下文传递

```java
/**
 * 追踪上下文 - 跨服务传递追踪信息
 * 
 * 设计模式：上下文对象模式(Context Object Pattern)
 * 
 * 上下文传递方式：
 * 1. Thrift协议：修改TProtocol，在协议头中注入traceId/spanId
 * 2. HTTP协议：在Request Header中添加追踪字段
 * 3. 消息队列：在消息属性中附加追踪信息
 */
public class TraceContext {

    private String traceId;
    private String spanId;
    private String parentSpanId;
    private boolean sampled;        // 是否采样
    private Map<String, String> baggage;  // 透传的业务数据

    public TraceContext(String traceId, String spanId, boolean sampled) {
        this.traceId = traceId;
        this.spanId = spanId;
        this.sampled = sampled;
        this.baggage = new HashMap<>();
    }

    /**
     * 创建子上下文
     */
    public TraceContext createChild(String childSpanId) {
        TraceContext child = new TraceContext(this.traceId, childSpanId, this.sampled);
        child.parentSpanId = this.spanId;
        child.baggage = new HashMap<>(this.baggage);
        return child;
    }

    /**
     * 序列化为HTTP Header
     */
    public Map<String, String> toHttpHeaders() {
        Map<String, String> headers = new HashMap<>();
        headers.put("X-Trace-Id", traceId);
        headers.put("X-Span-Id", spanId);
        headers.put("X-Parent-Span-Id", parentSpanId != null ? parentSpanId : "");
        headers.put("X-Sampled", String.valueOf(sampled));

        // 透传业务数据
        for (Map.Entry<String, String> entry : baggage.entrySet()) {
            headers.put("X-Baggage-" + entry.getKey(), entry.getValue());
        }
        return headers;
    }

    /**
     * 从HTTP Header反序列化
     */
    public static TraceContext fromHttpHeaders(Map<String, String> headers) {
        String traceId = headers.get("X-Trace-Id");
        String spanId = headers.get("X-Span-Id");
        boolean sampled = Boolean.parseBoolean(
            headers.getOrDefault("X-Sampled", "false"));

        if (traceId == null) return null;

        TraceContext context = new TraceContext(traceId, spanId, sampled);
        context.parentSpanId = headers.get("X-Parent-Span-Id");

        // 解析透传数据
        for (Map.Entry<String, String> entry : headers.entrySet()) {
            if (entry.getKey().startsWith("X-Baggage-")) {
                String key = entry.getKey().substring("X-Baggage-".length());
                context.baggage.put(key, entry.getValue());
            }
        }

        return context;
    }

    /**
     * 序列化为Thrift协议字段
     * 
     * Thrift上下文传递原理：
     * 修改TProtocol的writeMessageBegin/readMessageBegin，
     * 在消息头中注入追踪上下文
     */
    public byte[] toThriftBytes() {
        // 简化实现：使用自定义二进制格式
        ByteBuffer buffer = ByteBuffer.allocate(256);

        byte[] traceIdBytes = traceId.getBytes(StandardCharsets.UTF_8);
        buffer.putInt(traceIdBytes.length);
        buffer.put(traceIdBytes);

        byte[] spanIdBytes = spanId.getBytes(StandardCharsets.UTF_8);
        buffer.putInt(spanIdBytes.length);
        buffer.put(spanIdBytes);

        buffer.put(sampled ? (byte) 1 : (byte) 0);

        buffer.flip();
        byte[] result = new byte[buffer.remaining()];
        buffer.get(result);
        return result;
    }

    // getters
    public String getTraceId() { return traceId; }
    public String getSpanId() { return spanId; }
    public String getParentSpanId() { return parentSpanId; }
    public boolean isSampled() { return sampled; }
```

```java
/**
 * ThreadLocal追踪上下文管理器
 * 
 * 设计模式：线程本地存储模式(Thread-Local Storage)
 * 
 * 核心问题：
 * 1. 同一线程内的多次RPC调用共享同一个traceId
 * 2. 跨线程（线程池、异步回调）需要传递上下文
 * 3. 上下文需要及时清理，避免内存泄漏
 */
public class TraceContextHolder {

    /**
     * 使用ThreadLocal存储当前线程的追踪上下文
     * InheritableThreadLocal使子线程可以继承父线程的上下文
     */
    private static final ThreadLocal<Deque<TraceContext>> CONTEXT_STACK = 
        ThreadLocal.withInitial(ArrayDeque::new);

    /**
     * 设置当前上下文（入栈）
     * 使用栈结构支持嵌套调用场景
     */
    public static void push(TraceContext context) {
        CONTEXT_STACK.get().push(context);
    }

    /**
     * 获取当前上下文（栈顶）
     */
    public static TraceContext current() {
        Deque<TraceContext> stack = CONTEXT_STACK.get();
        return stack.isEmpty() ? null : stack.peek();
    }

    /**
     * 弹出当前上下文
     */
    public static TraceContext pop() {
        Deque<TraceContext> stack = CONTEXT_STACK.get();
        TraceContext context = stack.isEmpty() ? null : stack.pop();
        if (stack.isEmpty()) {
            CONTEXT_STACK.remove(); // 清理ThreadLocal，防止内存泄漏
        }
        return context;
    }

    /**
     * 清除所有上下文
     */
    public static void clear() {
        CONTEXT_STACK.remove();
    }
}

/**
 * 跨线程上下文传递 - 装饰器模式
 * 
 * 设计模式：装饰器模式(Decorator Pattern)
 * 包装Runnable/Callable，在执行前恢复父线程的追踪上下文
 * 
 * 使用场景：
 * 1. 提交任务到线程池
 * 2. CompletableFuture异步回调
 * 3. 消息队列消费者
 */
public class TraceableRunnable implements Runnable {

    private final Runnable delegate;
    private final TraceContext parentContext;

    /**
     * 在创建时捕获当前线程的上下文
     */
    public TraceableRunnable(Runnable delegate) {
        this.delegate = delegate;
        this.parentContext = TraceContextHolder.current();
    }

    @Override
    public void run() {
        // 在新线程中恢复父线程的上下文
        if (parentContext != null) {
            TraceContextHolder.push(parentContext);
        }
        try {
            delegate.run();
        } finally {
            // 执行完毕后清理上下文
            if (parentContext != null) {
                TraceContextHolder.pop();
            }
        }
    }
}
```

### 4.3 异步上报机制

```java
/**
 * Span异步上报器
 * 
 * 设计模式：生产者-消费者模式(Producer-Consumer Pattern)
 * 
 * 上报流程：
 * 1. Span结束时放入本地缓冲队列
 * 2. 后台线程批量从队列取出
 * 3. 序列化后发送到消息队列
 * 
 * 关键设计：
 * - 异步上报，不阻塞业务线程
 * - 批量发送，减少网络开销
 * - 缓冲区满时丢弃，保护业务不受影响
 */
public class SpanReporter {

    // 本地缓冲队列
    private final BlockingQueue<SpanData> buffer;
    // 批量发送大小
    private static final int BATCH_SIZE = 100;
    // 批量发送最大等待时间
    private static final long BATCH_TIMEOUT_MS = 1000;
    // 消息发送客户端
    private final MessageQueueProducer producer;
    // 上报线程
    private final Thread reporterThread;
    // 运行标志
    private volatile boolean running;

    public SpanReporter(int bufferSize, MessageQueueProducer producer) {
        this.buffer = new ArrayBlockingQueue<>(bufferSize);
        this.producer = producer;
        this.running = true;

        this.reporterThread = new Thread(this::reportLoop, "span-reporter");
        this.reporterThread.setDaemon(true);
        this.reporterThread.start();
    }

    /**
     * 提交Span到缓冲区
     * 非阻塞，缓冲区满时丢弃
     */
    public void report(SpanData span) {
        if (!buffer.offer(span)) {
            // 缓冲区满，丢弃并记录metrics
            MetricsRecorder.increment("span.dropped");
        }
    }

    /**
     * 上报线程主循环
     */
    private void reportLoop() {
        List<SpanData> batch = new ArrayList<>(BATCH_SIZE);

        while (running) {
            try {
                // 等待第一条数据
                SpanData first = buffer.poll(BATCH_TIMEOUT_MS, TimeUnit.MILLISECONDS);
                if (first == null) continue;

                batch.add(first);

                // 尝试凑满一批
                long deadline = System.currentTimeMillis() + BATCH_TIMEOUT_MS;
                while (batch.size() < BATCH_SIZE) {
                    long remaining = deadline - System.currentTimeMillis();
                    if (remaining <= 0) break;

                    SpanData span = buffer.poll(remaining, TimeUnit.MILLISECONDS);
                    if (span == null) break;
                    batch.add(span);
                }

                // 批量发送
                sendBatch(batch);
                batch.clear();

            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            } catch (Exception e) {
                // 发送失败，记录日志但不中断
                MetricsRecorder.increment("span.send.error");
                batch.clear();
            }
        }

        // 关闭时，发送缓冲区中剩余的数据
        buffer.drainTo(batch);
        if (!batch.isEmpty()) {
            sendBatch(batch);
        }
    }

    /**
     * 批量发送Span数据
     */
    private void sendBatch(List<SpanData> batch) {
        byte[] serialized = serializeBatch(batch);
        producer.send("trace-topic", serialized);
        MetricsRecorder.increment("span.sent", batch.size());
    }

    /**
     * 序列化批次数据
     * 使用紧凑的二进制格式，减少网络传输
     */
    private byte[] serializeBatch(List<SpanData> batch) {
        // 使用Protocol Buffers或自定义二进制格式
        ByteBuffer buffer = ByteBuffer.allocate(batch.size() * 512);
        buffer.putInt(batch.size()); // 批次大小

        for (SpanData span : batch) {
            byte[] spanBytes = span.serialize();
            buffer.putInt(spanBytes.length);
            buffer.put(spanBytes);
        }

        buffer.flip();
        byte[] result = new byte[buffer.remaining()];
        buffer.get(result);
        return result;
    }

    /**
     * 优雅关闭
     */
    public void shutdown() {
        running = false;
        reporterThread.interrupt();
        try {
            reporterThread.join(5000);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}
```

### 5.1 概率采样

```java
/**
 * 采样策略管理器
 * 
 * 设计模式：策略模式(Strategy Pattern)
 * 支持多种采样策略，可动态切换
 * 
 * 采样的必要性：
 * - 每天2000+亿条数据，全量存储不现实
 * - 默认1%采样率，但需确保异常请求被采样
 */
public class SamplingManager {

    /**
     * 采样策略接口
     */
    interface SamplingStrategy {
        boolean shouldSample(String traceId, String serviceName, 
                            String operationName, Map<String, String> tags);
        String getName();
    }

    /**
     * 概率采样 - 默认策略
     * 
     * 算法：基于traceId的确定性采样
     * - 对traceId做哈希，对采样率取模
     * - 保证同一个traceId在所有服务中采样决策一致
     * - 避免出现一条链路部分Span被采样的情况
     */
    static class ProbabilisticSampling implements SamplingStrategy {
        private final double samplingRate;
        private static final long SAMPLING_BOUND = 10000L;

        public ProbabilisticSampling(double samplingRate) {
            this.samplingRate = Math.max(0, Math.min(1, samplingRate));
        }

        @Override
        public boolean shouldSample(String traceId, String serviceName, 
                                     String operationName, Map<String, String> tags) {
            // 使用traceId的哈希值做确定性采样
            long hash = deterministicHash(traceId);
            long threshold = (long) (SAMPLING_BOUND * samplingRate);
            return (hash % SAMPLING_BOUND) < threshold;
        }

        /**
         * 确定性哈希 - 同一traceId总是返回相同值
         * 使用FNV-1a哈希算法
         */
        private long deterministicHash(String traceId) {
            long hash = 0xcbf29ce484222325L; // FNV offset basis
            for (int i = 0; i < traceId.length(); i++) {
                hash ^= traceId.charAt(i);
                hash *= 0x100000001b3L; // FNV prime
            }
            return Math.abs(hash);
        }

        @Override
        public String getName() { return "probabilistic"; }
    }

    /**
     * 自适应采样 - 根据流量动态调整采样率
     * 
     * 算法：令牌桶(Token Bucket) + 概率采样
     * - 每秒固定采样N个请求（令牌桶限制）
     * - 超过令牌桶后，按概率采样
     * - 采样率根据历史流量自动调整
     */
    static class AdaptiveSampling implements SamplingStrategy {
        private final double targetRate;        // 目标采样率
        private final int maxSamplesPerSecond;  // 每秒最大采样数
        private final AtomicInteger currentSecondSamples;
        private volatile long currentSecond;

        // 指数移动平均计算实际采样率
        private volatile double currentRate;
        private static final double ALPHA = 0.3; // 平滑系数

        public AdaptiveSampling(double targetRate, int maxSamplesPerSecond) {
            this.targetRate = targetRate;
            this.maxSamplesPerSecond = maxSamplesPerSecond;
            this.currentSecondSamples = new AtomicInteger(0);
            this.currentSecond = System.currentTimeMillis() / 1000;
            this.currentRate = targetRate;
        }

        @Override
        public boolean shouldSample(String traceId, String serviceName, 
                                     String operationName, Map<String, String> tags) {
            long nowSecond = System.currentTimeMillis() / 1000;

            // 新的一秒，重置计数
            if (nowSecond != currentSecond) {
                adjustRate();
                currentSecond = nowSecond;
                currentSecondSamples.set(0);
            }

            // 检查令牌桶
            int samples = currentSecondSamples.get();
            if (samples < maxSamplesPerSecond) {
                // 按当前采样率决定
                if (shouldSampleByRate(traceId, currentRate)) {
                    currentSecondSamples.incrementAndGet();
                    return true;
                }
            }

            return false;
        }

        /**
         * 动态调整采样率
         * 
         * 使用指数移动平均(EMA)平滑采样率变化
         * 如果实际采样数过多，降低采样率
         * 如果实际采样数过少，提高采样率
         */
        private void adjustRate() {
            int actualSamples = currentSecondSamples.get();
            double actualRate = (double) actualSamples / maxSamplesPerSecond;
            
            // EMA: rate_new = alpha * actual + (1 - alpha) * rate_old
            currentRate = ALPHA * (targetRate / Math.max(actualRate, 0.001)) 
                        + (1 - ALPHA) * currentRate;
            
            // 限制采样率范围
            currentRate = Math.max(0.001, Math.min(1.0, currentRate));
        }

        private boolean shouldSampleByRate(String traceId, double rate) {
            long hash = Math.abs(traceId.hashCode());
            return (hash % 10000) < (long) (rate * 10000);
        }

        @Override
        public String getName() { return "adaptive"; }
    }

    /**
     * 强制采样 - 特定条件下必须采样
     * 
     * 场景：
     * 1. 请求出现异常/错误
     * 2. 请求耗时超过阈值
     * 3. 特定用户/服务的请求
     * 4. 通过debug标记强制采样
     */
    static class ForceSampling implements SamplingStrategy {
        private final SamplingStrategy delegateSampling;
        private final Set<String> forceSampledServices;
        private final long slowThresholdMs;

        public ForceSampling(SamplingStrategy delegate, 
                             Set<String> forceSampledServices, 
                             long slowThresholdMs) {
            this.delegateSampling = delegate;
            this.forceSampledServices = forceSampledServices;
            this.slowThresholdMs = slowThresholdMs;
        }

        @Override
        public boolean shouldSample(String traceId, String serviceName, 
                                     String operationName, Map<String, String> tags) {
            // 检查是否有强制采样标记
            if ("true".equals(tags.get("force_sample"))) {
                return true;
            }

            // 检查是否为强制采样服务
            if (forceSampledServices.contains(serviceName)) {
                return true;
            }

            // 检查是否有错误标记
            if ("true".equals(tags.get("error"))) {
                return true;
            }

            // 降级到委托策略
            return delegateSampling.shouldSample(
                traceId, serviceName, operationName, tags);
        }

        @Override
        public String getName() { return "force"; }
    }

    // 采样策略组合
    private final List<SamplingStrategy> strategies;

    public SamplingManager() {
        strategies = new ArrayList<>();
        // 优先级：强制采样 > 自适应采样 > 概率采样
        strategies.add(new ForceSampling(
            new AdaptiveSampling(0.01, 1000),
            new HashSet<>(Arrays.asList("payment-service", "order-service")),
            3000L
        ));
    }

    public boolean shouldSample(String traceId, String serviceName, 
                                 String operationName, Map<String, String> tags) {
        for (SamplingStrategy strategy : strategies) {
            if (strategy.shouldSample(traceId, serviceName, operationName, tags)) {
                return true;
            }
        }
        return false;
    }
}
```

```java
 * 
 * 行键设计（RowKey Design）是HBase性能的关键
 * 
 * 设计原则：

 *

    private static final String CF_INFO = "info";
    private static final String CF_TAGS = "tags";
    private static final String CF_LOGS = "logs";

    /**
     * 生成RowKey
     * 
     * 算法：
     * 1. 对traceId做MD5哈希，取前2字节作为散列前缀
     * 2. 拼接原始traceId和spanId
     * 3. 散列前缀保证数据均匀分布到不同Region

        byte[] prefix = new byte[]{hash[0], hash[1]};

        byte[] traceIdBytes = traceId.getBytes(StandardCharsets.UTF_8);
        byte[] spanIdBytes = spanId.getBytes(StandardCharsets.UTF_8);

        // 组装RowKey: prefix(2) + traceId + separator(1) + spanId
        byte[] rowKey = new byte[2 + traceIdBytes.length + 1 + spanIdBytes.length];
        System.arraycopy(prefix, 0, rowKey, 0, 2);
        System.arraycopy(traceIdBytes, 0, rowKey, 2, traceIdBytes.length);
        rowKey[2 + traceIdBytes.length] = 0x00; // 分隔符
```

```java
 * 索引策略：按天创建索引，支持自动清理
 */
public class TraceElasticsearchStore {

    /**
     * 索引映射定义
     */
    public static class IndexMapping {
        /**
         * 生成索引名（按天分索引）
         */
        public static String getIndexName(long timestamp) {
            SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd");
            return "trace-" + sdf.format(new Date(timestamp));
        }

        /**
         * 索引映射配置
         * 
         * 设计要点：
         * 1. traceId使用keyword类型，支持精确匹配
         * 2. serviceName使用keyword，支持聚合
         * 3. startTime使用date类型，支持范围查询
         * 4. duration使用long类型，支持范围查询和排序
         * 5. tags使用nested类型，支持嵌套查询
         */
        public static Map<String, Object> getMappings() {
            Map<String, Object> properties = new LinkedHashMap<>();

            properties.put("traceId", createField("keyword"));
            properties.put("spanId", createField("keyword"));
            properties.put("parentSpanId", createField("keyword"));
            properties.put("serviceName", createField("keyword"));
            properties.put("operationName", createField("keyword"));
            properties.put("startTime", createField("date"));
            properties.put("endTime", createField("date"));
            properties.put("duration", createField("long"));
            properties.put("status", createField("keyword"));
            properties.put("errorMessage", createField("text"));

            // tags使用扁平化存储
            properties.put("tags", createField("object"));

            Map<String, Object> mappings = new HashMap<>();
            mappings.put("properties", properties);
            return mappings;
        }

        private static Map<String, Object> createField(String type) {
            Map<String, Object> field = new HashMap<>();
            field.put("type", type);
            return field;
        }
    }

    /**
     * 存储Span到ES
     */
    public void indexSpan(SpanData span) {
        String indexName = IndexMapping.getIndexName(span.getStartTime());

        Map<String, Object> document = new HashMap<>();
        document.put("traceId", span.getTraceId());
        document.put("spanId", span.getSpanId());
        document.put("parentSpanId", span.getParentSpanId());
        document.put("serviceName", span.getServiceName());
        document.put("operationName", span.getOperationName());
        document.put("startTime", span.getStartTime());
        document.put("endTime", span.getStartTime() + span.getDuration());
        document.put("duration", span.getDuration());
        document.put("status", span.getStatus());
        document.put("tags", span.getTags());

        esClient.index(indexName, span.getSpanId(), document);
    }

    /**
     * 多条件搜索链路
     */
    public List<String> searchTraces(TraceSearchRequest request) {
        // 构建布尔查询
        Map<String, Object> boolQuery = new HashMap<>();
        List<Map<String, Object>> mustClauses = new ArrayList<>();

        // 服务名过滤
        if (request.getServiceName() != null) {
            mustClauses.add(termQuery("serviceName", request.getServiceName()));
        }

        // 时间范围过滤
        if (request.getStartTime() > 0 || request.getEndTime() > 0) {
            mustClauses.add(rangeQuery("startTime", 
                request.getStartTime(), request.getEndTime()));
        }

        // 耗时范围过滤
        if (request.getMinDuration() > 0 || request.getMaxDuration() > 0) {
            mustClauses.add(rangeQuery("duration", 
                request.getMinDuration(), request.getMaxDuration()));
        }

        // 状态过滤
        if (request.getStatus() != null) {
            mustClauses.add(termQuery("status", request.getStatus()));
        }

        // 标签过滤
        if (request.getTags() != null) {
            for (Map.Entry<String, String> tag : request.getTags().entrySet()) {
                mustClauses.add(termQuery("tags." + tag.getKey(), tag.getValue()));
            }
        }

        boolQuery.put("must", mustClauses);

        // 执行查询，按traceId去重
        Map<String, Object> query = new HashMap<>();
        query.put("bool", boolQuery);

        // 聚合获取唯一traceId列表
        List<Map<String, Object>> results = esClient.search(
            getIndexPattern(request.getStartTime(), request.getEndTime()),
            query, request.getLimit());

        return results.stream()
            .map(r -> (String) r.get("traceId"))
            .distinct()
            .collect(Collectors.toList());
    }

    private Map<String, Object> termQuery(String field, String value) {
        Map<String, Object> term = new HashMap<>();
        Map<String, Object> fieldValue = new HashMap<>();
        fieldValue.put(field, value);
        term.put("term", fieldValue);
        return term;
    }

    private Map<String, Object> rangeQuery(String field, long gte, long lte) {
        Map<String, Object> range = new HashMap<>();
        Map<String, Object> fieldRange = new HashMap<>();
        if (gte > 0) fieldRange.put("gte", gte);
        if (lte > 0) fieldRange.put("lte", lte);
        Map<String, Object> fieldMap = new HashMap<>();
        fieldMap.put(field, fieldRange);
        range.put("range", fieldMap);
        return range;
    }

    private String getIndexPattern(long startTime, long endTime) {
        // 根据时间范围计算需要查询的索引
        return "trace-*";
    }

    // ES客户端占位
    private ElasticsearchClient esClient;
}
```

### 7.1 告警引擎

```java
/**
 * 告警引擎 - 基于规则的告警系统
 * 
 * 设计模式：规则引擎模式(Rule Engine Pattern)
 * 
 * 告警触发条件：
 * 1. 错误率超过阈值
 * 2. 延迟P99超过阈值
 * 3. QPS异常波动
 * 4. 调用链异常（循环调用、链路过长）
 */
public class AlertEngine {

    /**
     * 告警规则接口
     */
    interface AlertRule {
        String getName();
        AlertLevel getLevel();
        boolean evaluate(MetricSnapshot snapshot);
        String formatMessage(MetricSnapshot snapshot);
    }

    enum AlertLevel {
        INFO, WARNING, CRITICAL
    }

    /**
     * 错误率告警规则
     */
    static class ErrorRateRule implements AlertRule {
        private final String serviceName;
        private final double threshold; // 错误率阈值
        private final int windowMinutes; // 统计窗口

        public ErrorRateRule(String serviceName, double threshold, int windowMinutes) {
            this.serviceName = serviceName;
            this.threshold = threshold;
            this.windowMinutes = windowMinutes;
        }

        @Override
        public String getName() {
            return "error_rate_" + serviceName;
        }

        @Override
        public AlertLevel getLevel() {
            return AlertLevel.CRITICAL;
        }

        @Override
        public boolean evaluate(MetricSnapshot snapshot) {
            double errorRate = snapshot.getErrorRate(serviceName, windowMinutes);
            return errorRate > threshold;
        }

        @Override
        public String formatMessage(MetricSnapshot snapshot) {
            double errorRate = snapshot.getErrorRate(serviceName, windowMinutes);
            return String.format("Service %s error rate %.2f%% exceeds threshold %.2f%% in last %d minutes",
                serviceName, errorRate * 100, threshold * 100, windowMinutes);
        }
    }

    /**
     * 延迟告警规则
     */
    static class LatencyRule implements AlertRule {
        private final String serviceName;
        private final long thresholdMs;  // 延迟阈值（毫秒）
        private final double percentile; // 百分位（如P99=0.99）

        public LatencyRule(String serviceName, long thresholdMs, double percentile) {
            this.serviceName = serviceName;
            this.thresholdMs = thresholdMs;
            this.percentile = percentile;
        }

        @Override
        public String getName() {
            return "latency_p" + (int)(percentile * 100) + "_" + serviceName;
        }

        @Override
        public AlertLevel getLevel() {
            return AlertLevel.WARNING;
        }

        @Override
        public boolean evaluate(MetricSnapshot snapshot) {
            long latency = snapshot.getLatencyPercentile(
                serviceName, percentile);
            return latency > thresholdMs;
        }

        @Override
        public String formatMessage(MetricSnapshot snapshot) {
            long latency = snapshot.getLatencyPercentile(
                serviceName, percentile);
            return String.format("Service %s P%d latency %dms exceeds threshold %dms",
                serviceName, (int)(percentile * 100), latency, thresholdMs);
        }
    }

    private final List<AlertRule> rules;
    private final AlertNotifier notifier;
    // 告警去重：同一规则在冷却期内不重复告警
    private final Map<String, Long> lastAlertTime;
    private static final long COOLDOWN_MS = 300_000; // 5分钟冷却

    public AlertEngine(AlertNotifier notifier) {
        this.rules = new ArrayList<>();
        this.notifier = notifier;
        this.lastAlertTime = new ConcurrentHashMap<>();
    }

    public void addRule(AlertRule rule) {
        rules.add(rule);
    }

    /**
     * 定时评估所有规则
     */
    @Scheduled(fixedRate = 60000) // 每分钟检查
    public void evaluate() {
        MetricSnapshot snapshot = MetricSnapshot.current();

        for (AlertRule rule : rules) {
            try {
                if (rule.evaluate(snapshot)) {
                    // 检查冷却期
                    Long lastTime = lastAlertTime.get(rule.getName());
                    if (lastTime != null && 
                        System.currentTimeMillis() - lastTime < COOLDOWN_MS) {
                        continue; // 冷却期内，跳过
                    }

                    // 触发告警
                    String message = rule.formatMessage(snapshot);
                    notifier.notify(rule.getLevel(), rule.getName(), message);
                    lastAlertTime.put(rule.getName(), System.currentTimeMillis());
                }
            } catch (Exception e) {
                // 规则评估异常不影响其他规则
            }
        }
    }
}
```

```java
/**
 * 链路可视化 - 将Trace数据转换为可视化结构
 * 
 * 设计模式：访问者模式(Visitor Pattern)
 * 遍历链路树，生成不同格式的可视化数据
 */
public class TraceVisualizer {

    /**
     * 甘特图数据生成 - 展示各Span的时间线
     */
    public GanttChartData toGanttChart(TraceModel.Trace trace) {
        GanttChartData chart = new GanttChartData();
        long traceStartTime = Long.MAX_VALUE;

        // 找到Trace的最早开始时间
        for (TraceModel.Span span : trace.getSpans()) {
            traceStartTime = Math.min(traceStartTime, span.getStartTime());
        }

        // 为每个Span创建甘特图条目
        for (TraceModel.Span span : trace.getSpans()) {
            GanttBar bar = new GanttBar();
            bar.setLabel(span.getServiceName() + " :: " + span.getOperationName());
            bar.setStart(span.getStartTime() - traceStartTime);
            bar.setDuration(span.getDuration());
            bar.setDepth(SpanIdGenerator.parseDepth(span.getSpanId()));
            bar.setStatus(span.getStatus());
            chart.addBar(bar);
        }

        chart.setTotalDuration(
            trace.getSpans().stream()
                .mapToLong(s -> s.getStartTime() + s.getDuration())
                .max().orElse(0) - traceStartTime
        );

        return chart;
    }

    /**
     * 服务依赖拓扑图生成
     * 
     * 算法：从Span数据中提取调用关系，构建有向图
     */
    public DependencyGraph toDependencyGraph(List<TraceModel.Trace> traces) {
        // 邻接表表示有向图
        Map<String, Map<String, EdgeMetrics>> graph = new HashMap<>();

        for (TraceModel.Trace trace : traces) {
            for (TraceModel.Span span : trace.getSpans()) {
                if (span.getParentSpanId() != null) {
                    // 找到父Span
                    TraceModel.Span parentSpan = trace.findSpan(span.getParentSpanId());
                    if (parentSpan != null) {
                        String from = parentSpan.getServiceName();
                        String to = span.getServiceName();

                        graph.computeIfAbsent(from, k -> new HashMap<>())
                            .computeIfAbsent(to, k -> new EdgeMetrics())
                            .recordCall(span.getDuration(), 
                                span.getStatus() == SpanStatus.ERROR);
                    }
                }
            }
        }

        return new DependencyGraph(graph);
    }

    /**
     * 边的指标聚合
     */
    static class EdgeMetrics {
        private long callCount;
        private long errorCount;
        private long totalDuration;
        private long maxDuration;

        public void recordCall(long duration, boolean isError) {
            callCount++;
            totalDuration += duration;
            maxDuration = Math.max(maxDuration, duration);
            if (isError) errorCount++;
        }

        public double getErrorRate() {
            return callCount > 0 ? (double) errorCount / callCount : 0;
        }

        public double getAvgDuration() {
            return callCount > 0 ? (double) totalDuration / callCount : 0;
        }
    }
}
```

## 八、系统总结

### 8.1 核心设计决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 数据模型 | Trace/Span树形模型 | 符合Google Dapper标准，直观表达调用链 |
| SpanId编码 | 点号分隔层级编码 | 直观表达层级，支持前缀匹配查询 |
| 上下文传递 | ThreadLocal + 协议注入 | 对业务透明，支持多种RPC协议 |
| 采样策略 | 概率采样 + 自适应 + 强制采样 | 兼顾存储开销与异常捕获 |
| 链路存储 | HBase + ES双写 | HBase存详情，ES支持多维检索 |
| 上报方式 | 异步批量上报 | 不影响业务性能 |

### 8.2 关键算法总结

1. **Snowflake变体TraceId生成**：时间戳(42位) + 机器ID(10位) + 进程ID(10位) + 序列号(12位)，保证全局唯一
2. **FNV-1a哈希**：确定性采样，保证同一TraceId在所有服务中采样决策一致
3. **指数移动平均(EMA)**：自适应采样率调整，平滑处理流量波动
4. **令牌桶算法**：限制每秒采样上限，防止存储压力过大
5. **MD5散列前缀**：HBase RowKey设计，避免写入热点
6. **点号层级编码**：SpanId表示调用深度和顺序关系

### 8.3 设计模式应用

| 设计模式 | 应用场景 |
|----------|----------|
| 策略模式 | 采样策略切换（概率/自适应/强制） |
| 装饰器模式 | 跨线程上下文传递（TraceableRunnable） |
| 生产者-消费者 | 异步Span上报 |
| 构建器模式 | 时序数据点构建 |
| 上下文对象模式 | TraceContext跨服务传递 |
| 规则引擎模式 | 告警规则评估 |
| 访问者模式 | 链路可视化数据转换 |
| 观察者模式 | 告警通知 |

### 8.4 性能指标

- TraceId生成：< 1μs，支持每毫秒4096个唯一ID
- Span上报延迟：< 1ms（放入本地缓冲区）
- 端到端采集延迟：< 5s（从Span产生到可查询）
- 每日数据处理量：2000+亿条
- 默认采样率：1%
- HBase写入吞吐：100万行/秒（集群级别）
- ES检索延迟：< 500ms（常规查询）
- 告警检测周期：60秒

### 8.5 数据流转架构

```
业务服务埋点 → 本地缓冲队列 → 批量发送 → 消息队列
                                              ↓
                              ┌────────────────┼──────────────────┐
                              ↓                ↓                  ↓
                         实时处理引擎      HBase存储          HDFS离线存储
                              ↓                ↓
                        ES索引写入        时序数据库
                              ↓                ↓
                        链路检索API        告警引擎
                              ↓                ↓
                        可视化平台         告警通知
```

### 8.6 高可用设计

1. **采集高可用**：异步上报 + 本地缓冲，采集组件故障不影响业务
2. **传输高可用**：消息队列多副本，保证数据不丢失
3. **存储高可用**：HBase/ES集群多副本，支持节点故障自动恢复
4. **降级策略**：
   - 消息队列不可用时，写入本地文件，恢复后补发
   - 存储不可用时，提高采样过滤率，降低数据量
   - 告警通道不可用时，切换备用通知渠道

#### 9.1.1 埋点采集：本地指标注册与聚合

```java
/**
 * 指标埋点SDK - 业务代码通过静态API打点
 *
 * 设计要点：
 * 1. 本地内存预聚合，避免每次调用都产生一次网络I/O
 * 2. 基于滑动时间窗口做Counter/Timer聚合，降低上报数据量级
 * 3. 打点操作必须是非阻塞、低开销的（目标 < 10μs），异常不能影响业务主流程
 */
public class MetricRegistry {

    private static final Logger logger = LoggerFactory.getLogger(MetricRegistry.class);

    // 指标名+标签组合 -> 聚合器，ConcurrentHashMap保证多线程安全
    private static final Map<String, MetricAggregator> AGGREGATORS = new ConcurrentHashMap<>();

    /**
     * Counter类型打点：计数类指标，如请求次数、错误次数
     *
     * @param name 指标名，如 order.create.count
     * @param tags 维度标签，如 {"appkey":"trade-service","result":"success"}
     */
    public static void incrCounter(String name, Map<String, String> tags) {
        try {
            String key = buildKey(name, tags);
            AGGREGATORS.computeIfAbsent(key, k -> new MetricAggregator(name, tags, MetricType.COUNTER))
                    .incr(1);
        } catch (Exception e) {
            // 埋点异常绝不能向上抛出影响业务主流程，只记录降级日志
            logger.warn("[Metric] incrCounter failed, name={}, tags={}, cause={}",
                    name, tags, e.toString());
        }
    }

    /**
     * Timer类型打点：耗时类指标，如接口RT
     */
    public static void recordTimer(String name, Map<String, String> tags, long costMs) {
        try {
            String key = buildKey(name, tags);
            AGGREGATORS.computeIfAbsent(key, k -> new MetricAggregator(name, tags, MetricType.TIMER))
                    .record(costMs);
        } catch (Exception e) {
            logger.warn("[Metric] recordTimer failed, name={}, tags={}, cost={}, cause={}",
                    name, tags, costMs, e.toString());
        }
    }

    /**
     * 便捷方法：包裹一段代码自动记录耗时和异常率
     */
    public static <T> T timed(String name, Map<String, String> tags, Supplier<T> action) {
        long start = System.currentTimeMillis();
        Map<String, String> resultTags = new HashMap<>(tags);
        try {
            T result = action.get();
            resultTags.put("result", "success");
            return result;
        } catch (Exception e) {
            resultTags.put("result", "error");
            throw e;
        } finally {
            recordTimer(name, resultTags, System.currentTimeMillis() - start);
        }
    }

    /**
     * 拉取并清空当前所有聚合结果，用于定时flush上报
     * 采用"拉取时替换"策略，避免上报过程中新数据写入丢失
     */
    public static List<MetricSnapshotDTO> pollAndReset() {
        List<MetricSnapshotDTO> snapshots = new ArrayList<>();
        long now = System.currentTimeMillis();
        for (Map.Entry<String, MetricAggregator> entry : AGGREGATORS.entrySet()) {
            MetricAggregator aggregator = entry.getValue();
            // 原子替换内部聚合状态，防止flush期间数据竞争
            MetricSnapshotDTO snapshot = aggregator.snapshotAndReset(now);
            if (snapshot != null) {
                snapshots.add(snapshot);
            }
        }
        return snapshots;
    }

    private static String buildKey(String name, Map<String, String> tags) {
        StringBuilder sb = new StringBuilder(name);
        // 标签需按key排序，保证同一维度组合生成相同的key
        tags.entrySet().stream()
                .sorted(Map.Entry.comparingByKey())
                .forEach(e -> sb.append('|').append(e.getKey()).append('=').append(e.getValue()));
        return sb.toString();
    }

    enum MetricType { COUNTER, TIMER, GAUGE }

    /**
     * 单个指标维度的聚合器，Counter累加、Timer做min/max/sum/count统计
     */
    static class MetricAggregator {
        private final String name;
        private final Map<String, String> tags;
        private final MetricType type;
        private final LongAdder count = new LongAdder();
        private final LongAdder sum = new LongAdder();
        private final AtomicLong max = new AtomicLong(Long.MIN_VALUE);
        private final AtomicLong min = new AtomicLong(Long.MAX_VALUE);

        MetricAggregator(String name, Map<String, String> tags, MetricType type) {
            this.name = name;
            this.tags = tags;
            this.type = type;
        }

        void incr(long delta) {
            count.add(delta);
        }

        void record(long value) {
            count.increment();
            sum.add(value);
            max.updateAndGet(prev -> Math.max(prev, value));
            min.updateAndGet(prev -> Math.min(prev, value));
        }

        synchronized MetricSnapshotDTO snapshotAndReset(long timestamp) {
            long c = count.sumThenReset();
            if (c == 0) return null; // 无数据无需上报，减少无效流量
            long s = sum.sumThenReset();
            long mx = max.getAndSet(Long.MIN_VALUE);
            long mn = min.getAndSet(Long.MAX_VALUE);
            return new MetricSnapshotDTO(name, tags, type, timestamp, c, s,
                    mx == Long.MIN_VALUE ? 0 : mx, mn == Long.MAX_VALUE ? 0 : mn);
        }
    }
}
```

#### 9.1.2 数据上报：批量发送与本地降级缓冲

```java
/**
 * 指标上报客户端 - 定时将本地聚合结果批量发送至采集网关
 *
 * 幂等设计：
 * 每批次生成唯一batchId(UUID)，网关侧基于batchId做去重，
 * 避免网络重试导致同一批数据被重复计入时序库
 *
 * 容错设计：
 * 网关不可用时数据先落本地磁盘队列，定时重试补发，
 * 避免瞬时故障造成监控数据整体丢失（监控系统自身也需要高可用）
 */
public class MetricReportClient {

    private static final Logger logger = LoggerFactory.getLogger(MetricReportClient.class);
    private static final int MAX_RETRY = 3;
    private static final int BATCH_SIZE = 500;

    private final MetricGatewayRpcClient rpcClient;
    private final LocalDiskQueue fallbackQueue;

    public MetricReportClient(MetricGatewayRpcClient rpcClient, LocalDiskQueue fallbackQueue) {
        this.rpcClient = rpcClient;
        this.fallbackQueue = fallbackQueue;
    }

    /**
     * 定时任务：每10秒执行一次采集与上报
     */
    @Scheduled(fixedRate = 10_000)
    public void flushAndReport() {
        List<MetricSnapshotDTO> snapshots = MetricRegistry.pollAndReset();
        if (snapshots.isEmpty()) {
            return;
        }
        // 按BATCH_SIZE切分，避免单次请求体过大
        for (int i = 0; i < snapshots.size(); i += BATCH_SIZE) {
            List<MetricSnapshotDTO> batch = snapshots.subList(
                    i, Math.min(i + BATCH_SIZE, snapshots.size()));
            reportBatchWithRetry(new ArrayList<>(batch));
        }
        // 顺带重试此前失败落盘的批次
        retryFallbackQueue();
    }

    /**
     * 上报单批数据，失败时重试，最终失败落本地磁盘
     */
    private void reportBatchWithRetry(List<MetricSnapshotDTO> batch) {
        // 幂等键：进程唯一标识 + 批次序号，网关侧用于去重
        String batchId = AgentIdentity.INSTANCE_ID + "-" + UUID.randomUUID();
        MetricReportRequest request = new MetricReportRequest(batchId, batch);

        int attempt = 0;
        while (attempt < MAX_RETRY) {
            attempt++;
            try {
                MetricReportResponse response = rpcClient.report(request);
                if (response.isSuccess()) {
                    logger.debug("[MetricReport] batch reported, batchId={}, size={}, attempt={}",
                            batchId, batch.size(), attempt);
                    return;
                }
                logger.warn("[MetricReport] gateway rejected batch, batchId={}, code={}, msg={}",
                        batchId, response.getCode(), response.getMessage());
            } catch (RpcTimeoutException e) {
                logger.warn("[MetricReport] rpc timeout, batchId={}, attempt={}/{}",
                        batchId, attempt, MAX_RETRY);
            } catch (Exception e) {
                logger.error("[MetricReport] rpc failed, batchId={}, attempt={}/{}, cause={}",
                        batchId, attempt, MAX_RETRY, e.toString(), e);
            }
            // 指数退避，避免网关故障期间的重试风暴
            sleepQuietly(100L * (1L << attempt));
        }

        // 多次重试仍失败，落盘等待后续补发，保证数据不丢
        logger.error("[MetricReport] batch failed after {} retries, fallback to disk, batchId={}",
                MAX_RETRY, batchId);
        fallbackQueue.offer(request);
    }

    /**
     * 重试本地磁盘队列中的历史失败批次
     */
    private void retryFallbackQueue() {
        List<MetricReportRequest> pending = fallbackQueue.pollBatch(50);
        for (MetricReportRequest request : pending) {
            try {
                MetricReportResponse response = rpcClient.report(request);
                if (response.isSuccess()) {
                    fallbackQueue.ack(request.getBatchId());
                    logger.info("[MetricReport] fallback batch resent successfully, batchId={}",
                            request.getBatchId());
                } else {
                    // 保留在队列中，等待下一轮重试；设置最大保留时长避免无限堆积
                    fallbackQueue.requeueIfNotExpired(request);
                }
            } catch (Exception e) {
                logger.warn("[MetricReport] retry fallback batch failed, batchId={}, cause={}",
                        request.getBatchId(), e.toString());
                fallbackQueue.requeueIfNotExpired(request);
            }
        }
    }

    private void sleepQuietly(long millis) {
        try {
            Thread.sleep(millis);
        } catch (InterruptedException ie) {
            Thread.currentThread().interrupt();
        }
    }
}
```

#### 9.1.3 采集网关：幂等写入时序数据库

```java
/**
 * 采集网关 - 接收Agent批量上报，做幂等校验后写入时序数据库
 *
 * 幂等实现：
 * 使用Redis SETNX记录batchId，TTL设置为略大于Agent最大重试窗口（如10分钟），
 * 重复batchId直接返回成功但跳过实际写入，避免指标值被重复累加导致误告警
 */
@RestController
@RequestMapping("/metric/gateway")
public class MetricGatewayController {

    private static final Logger logger = LoggerFactory.getLogger(MetricGatewayController.class);
    private static final long DEDUP_TTL_SECONDS = 600;

    private final RedisTemplate<String, String> redisTemplate;
    private final MetricsTimeSeriesStore timeSeriesStore;

    public MetricGatewayController(RedisTemplate<String, String> redisTemplate,
                                    MetricsTimeSeriesStore timeSeriesStore) {
        this.redisTemplate = redisTemplate;
        this.timeSeriesStore = timeSeriesStore;
    }

    @PostMapping("/report")
    public MetricReportResponse report(@RequestBody MetricReportRequest request) {
        String batchId = request.getBatchId();
        if (batchId == null || batchId.isEmpty()) {
            logger.warn("[MetricGateway] missing batchId, reject request, remote={}", request.getSourceIp());
            return MetricReportResponse.fail("INVALID_BATCH_ID", "batchId不能为空");
        }

        try {
            // 幂等校验：Redis分布式锁式去重，key = 幂等命名空间 + batchId
            String dedupKey = "metric:report:dedup:" + batchId;
            Boolean firstSeen = redisTemplate.opsForValue()
                    .setIfAbsent(dedupKey, "1", DEDUP_TTL_SECONDS, TimeUnit.SECONDS);

            if (Boolean.FALSE.equals(firstSeen)) {
                // 已处理过的批次，直接幂等返回成功，避免Agent因超时重试导致重复入库
                logger.info("[MetricGateway] duplicate batch ignored, batchId={}", batchId);
                return MetricReportResponse.success();
            }

            List<MetricSnapshotDTO> validPoints = validateAndFilter(request.getPoints());
            if (validPoints.isEmpty()) {
                logger.warn("[MetricGateway] all points invalid after validation, batchId={}", batchId);
                return MetricReportResponse.fail("EMPTY_VALID_DATA", "无有效数据点");
            }

            timeSeriesStore.batchWrite(validPoints);

            logger.info("[MetricGateway] batch persisted, batchId={}, size={}/{}",
                    batchId, validPoints.size(), request.getPoints().size());
            return MetricReportResponse.success();

        } catch (DataAccessException e) {
            // 存储层异常：释放幂等标记，允许Agent重试，同时告知失败
            redisTemplate.delete("metric:report:dedup:" + batchId);
            logger.error("[MetricGateway] store write failed, batchId={}, cause={}",
                    batchId, e.toString(), e);
            return MetricReportResponse.fail("STORE_ERROR", "存储写入失败，请重试");
        } catch (Exception e) {
            redisTemplate.delete("metric:report:dedup:" + batchId);
            logger.error("[MetricGateway] unexpected error, batchId={}, cause={}",
                    batchId, e.toString(), e);
            return MetricReportResponse.fail("INTERNAL_ERROR", "网关内部异常");
        }
    }

    /**
     * 数据校验：过滤非法指标点，防止脏数据污染时序库
     * - 指标名不能为空，长度不超过128
     * - 标签数量不超过20个，防止维度爆炸
     * - 时间戳必须在[当前时间-1小时, 当前时间+5分钟]范围内，防止乱序或恶意数据
     */
    private List<MetricSnapshotDTO> validateAndFilter(List<MetricSnapshotDTO> points) {
        long now = System.currentTimeMillis();
        List<MetricSnapshotDTO> valid = new ArrayList<>();
        for (MetricSnapshotDTO point : points) {
            if (point.getMetric() == null || point.getMetric().isEmpty()
                    || point.getMetric().length() > 128) {
                continue;
            }
            if (point.getTags() != null && point.getTags().size() > 20) {
                continue;
            }
            if (point.getTimestamp() < now - 3_600_000 || point.getTimestamp() > now + 300_000) {
                continue;
            }
            valid.add(point);
        }
        return valid;
    }
}
```

#### 9.1.4 告警规则匹配

```java
/**
 * 告警规则评估器 - 基于时序数据周期性扫描规则并触发告警
 *
 * 幂等设计：
 * 告警事件生成唯一alertFingerprint（规则名+维度标签的哈希），
 * 下游通知链路以fingerprint作为去重键，避免同一异常在多个检查周期
 * 内被反复推送为“新告警”
 */
@Component
public class AlertRuleEvaluator {

    private static final Logger logger = LoggerFactory.getLogger(AlertRuleEvaluator.class);

    private final MetricsTimeSeriesStore timeSeriesStore;
    private final AlertDispatchService dispatchService;
    private final List<AlertEngine.AlertRule> rules;

    public AlertRuleEvaluator(MetricsTimeSeriesStore timeSeriesStore,
                               AlertDispatchService dispatchService,
                               List<AlertEngine.AlertRule> rules) {
        this.timeSeriesStore = timeSeriesStore;
        this.dispatchService = dispatchService;
        this.rules = rules;
    }

    @Scheduled(fixedRate = 60_000)
    public void evaluateAll() {
        MetricSnapshot snapshot;
        try {
            snapshot = MetricSnapshot.current();
        } catch (Exception e) {
            // 拉取快照失败不能让整个评估任务挂掉，跳过本轮并记录
            logger.error("[AlertEvaluator] load metric snapshot failed, cause={}", e.toString(), e);
            return;
        }

        for (AlertEngine.AlertRule rule : rules) {
            try {
                if (!rule.evaluate(snapshot)) {
                    continue;
                }
                String fingerprint = buildFingerprint(rule);
                AlertEvent event = new AlertEvent(
                        fingerprint,
                        rule.getName(),
                        rule.getLevel(),
                        rule.formatMessage(snapshot),
                        System.currentTimeMillis());

                dispatchService.dispatch(event);
                logger.info("[AlertEvaluator] rule triggered, rule={}, level={}, fingerprint={}",
                        rule.getName(), rule.getLevel(), fingerprint);

            } catch (Exception e) {
                // 单条规则异常不能影响其他规则的评估，隔离故障
                logger.error("[AlertEvaluator] rule evaluate error, rule={}, cause={}",
                        rule.getName(), e.toString(), e);
            }
        }
    }

    private String buildFingerprint(AlertEngine.AlertRule rule) {
        return DigestUtils.md5Hex(rule.getName());
    }
}
```

#### 9.1.5 多渠道通知投递

```java
/**
 * 告警通知投递服务 - 支持短信/邮件/大象(IM)/电话多渠道，按级别路由
 *
 * 幂等实现：
 * 1. Redis记录 fingerprint+level 的最近发送时间，冷却窗口内不重复投递
 * 2. 每个渠道的发送均生成唯一notifyId，供渠道侧回执核对，防止MQ重试造成重复推送
 *
 * 容错设计：
 * 高优先级告警（CRITICAL）在主渠道失败时自动降级到备用渠道，
 * 确保关键告警"总有一条通路能送达"
 */
@Component
public class AlertDispatchService {

    private static final Logger logger = LoggerFactory.getLogger(AlertDispatchService.class);
    private static final long COOLDOWN_SECONDS = 300;

    private final RedisTemplate<String, String> redisTemplate;
    private final Map<NotifyChannel, AlertNotifyChannel> channels;
    private final OnCallDirectory onCallDirectory;

    public AlertDispatchService(RedisTemplate<String, String> redisTemplate,
                                 Map<NotifyChannel, AlertNotifyChannel> channels,
                                 OnCallDirectory onCallDirectory) {
        this.redisTemplate = redisTemplate;
        this.channels = channels;
        this.onCallDirectory = onCallDirectory;
    }

    public void dispatch(AlertEvent event) {
        String cooldownKey = "alert:cooldown:" + event.getFingerprint();
        Boolean firstFire = redisTemplate.opsForValue()
                .setIfAbsent(cooldownKey, String.valueOf(event.getTimestamp()),
                        COOLDOWN_SECONDS, TimeUnit.SECONDS);

        if (Boolean.FALSE.equals(firstFire)) {
            logger.info("[AlertDispatch] alert in cooldown, skip, fingerprint={}", event.getFingerprint());
            return;
        }

        List<NotifyChannel> targetChannels = resolveChannelsByLevel(event.getLevel());
        List<String> receivers = onCallDirectory.getOnCallReceivers(event.getRuleName());

        boolean anySuccess = false;
        for (NotifyChannel channelType : targetChannels) {
            String notifyId = event.getFingerprint() + "-" + channelType.name() + "-" + event.getTimestamp();
            try {
                AlertNotifyChannel channel = channels.get(channelType);
                if (channel == null) {
                    logger.warn("[AlertDispatch] channel not configured: {}", channelType);
                    continue;
                }
                channel.send(notifyId, receivers, event);
                anySuccess = true;
                logger.info("[AlertDispatch] sent via {}, notifyId={}, receivers={}",
                        channelType, notifyId, receivers);
            } catch (Exception e) {
                logger.error("[AlertDispatch] send via {} failed, notifyId={}, cause={}",
                        channelType, notifyId, e.toString(), e);
            }
        }

        // CRITICAL级别若所有既定渠道均失败，强制降级走电话通知On-Call负责人，避免关键告警漏发
        if (!anySuccess && event.getLevel() == AlertEngine.AlertLevel.CRITICAL) {
            try {
                AlertNotifyChannel phoneChannel = channels.get(NotifyChannel.PHONE_CALL);
                if (phoneChannel != null) {
                    phoneChannel.send(event.getFingerprint() + "-fallback-phone", receivers, event);
                    logger.warn("[AlertDispatch] all channels failed, fallback to phone call, fingerprint={}",
                            event.getFingerprint());
                }
            } catch (Exception e) {
                logger.error("[AlertDispatch] fallback phone call also failed, fingerprint={}, cause={}",
                        event.getFingerprint(), e.toString(), e);
            }
        }
    }

    private List<NotifyChannel> resolveChannelsByLevel(AlertEngine.AlertLevel level) {
        switch (level) {
            case CRITICAL:
                return Arrays.asList(NotifyChannel.IM, NotifyChannel.SMS, NotifyChannel.PHONE_CALL);
            case WARNING:
                return Arrays.asList(NotifyChannel.IM, NotifyChannel.EMAIL);
            default:
                return Collections.singletonList(NotifyChannel.EMAIL);
        }
    }

    enum NotifyChannel { IM, SMS, EMAIL, PHONE_CALL }

    interface AlertNotifyChannel {
        void send(String notifyId, List<String> receivers, AlertEvent event) throws Exception;
    }
}
```

**案例一小结**：全链路共设置3道幂等防线——Agent侧batchId、网关侧Redis去重、通知侧冷却窗口+notifyId，任意一环重试都不会造成指标重复计入或告警重复打扰；同时在Agent磁盘降级、网关幂等标记回滚、CRITICAL告警渠道降级三处做了针对性的容错处理。

#### 9.2.1 查询入口：鉴权、限流与参数校验

```java
/**
 * 监控大盘查询入口
 *
 * 设计要点：
 * 1. 查询是幂等的只读操作，但仍需通过requestId做结果缓存，
 *    避免前端因页面重复渲染/网络重试导致同一秒内重复查询后端
 * 2. 大盘查询往往聚合多个面板、多个指标，属于重量级查询，
 *    必须做限流保护，防止个别大盘拖垮时序数据库
 */
@RestController
@RequestMapping("/dashboard")
public class DashboardQueryController {

    private static final Logger logger = LoggerFactory.getLogger(DashboardQueryController.class);

    private final DashboardQueryOrchestrator orchestrator;
    private final RateLimiter dashboardRateLimiter; // 令牌桶限流器，每秒最多N次大盘查询
    private final Cache<String, DashboardQueryResponse> resultCache; // 短TTL结果缓存，做幂等+防重复渲染

    public DashboardQueryController(DashboardQueryOrchestrator orchestrator,
                                     RateLimiter dashboardRateLimiter,
                                     Cache<String, DashboardQueryResponse> resultCache) {
        this.orchestrator = orchestrator;
        this.dashboardRateLimiter = dashboardRateLimiter;
        this.resultCache = resultCache;
    }

    @PostMapping("/query")
    public DashboardQueryResponse query(@RequestBody DashboardQueryRequest request,
                                         @RequestHeader("X-User-Id") String userId) {
        long start = System.currentTimeMillis();

        // 参数校验：dashboardId必填，查询时间范围不能超过90天，防止超大范围查询拖垮存储
        String validateError = validateRequest(request);
        if (validateError != null) {
            logger.warn("[DashboardQuery] invalid request, userId={}, error={}", userId, validateError);
            return DashboardQueryResponse.fail("INVALID_PARAM", validateError);
        }

        // 幂等/去重：同一requestId在缓存TTL(5s)内直接返回上次结果，
        // 应对前端组件重复挂载、双击刷新等场景，避免重复打到存储层
        String cacheKey = request.getDashboardId() + ":" + request.getRequestId();
        DashboardQueryResponse cached = resultCache.getIfPresent(cacheKey);
        if (cached != null) {
            logger.info("[DashboardQuery] hit idempotent cache, cacheKey={}", cacheKey);
            return cached;
        }

        if (!dashboardRateLimiter.tryAcquire()) {
            logger.warn("[DashboardQuery] rate limited, userId={}, dashboardId={}",
                    userId, request.getDashboardId());
            return DashboardQueryResponse.fail("RATE_LIMITED", "查询过于频繁，请稍后再试");
        }

        try {
            DashboardQueryResponse response = orchestrator.query(request);
            resultCache.put(cacheKey, response);
            logger.info("[DashboardQuery] success, userId={}, dashboardId={}, panels={}, costMs={}",
                    userId, request.getDashboardId(), request.getPanelIds().size(),
                    System.currentTimeMillis() - start);
            return response;
        } catch (Exception e) {
            logger.error("[DashboardQuery] query failed, userId={}, dashboardId={}, cause={}",
                    userId, request.getDashboardId(), e.toString(), e);
            return DashboardQueryResponse.fail("INTERNAL_ERROR", "查询异常，请稍后重试");
        } finally {
            MetricRegistry.recordTimer("dashboard.query.latency",
                    Collections.singletonMap("dashboardId", request.getDashboardId()),
                    System.currentTimeMillis() - start);
        }
    }

    private String validateRequest(DashboardQueryRequest request) {
        if (request.getDashboardId() == null || request.getDashboardId().isEmpty()) {
            return "dashboardId不能为空";
        }
        if (request.getPanelIds() == null || request.getPanelIds().isEmpty()) {
            return "panelIds不能为空";
        }
        long rangeMillis = request.getEndTime() - request.getStartTime();
        if (rangeMillis <= 0) {
            return "时间范围非法";
        }
        if (rangeMillis > 90L * 24 * 3600 * 1000) {
            return "查询范围不能超过90天";
        }
        return null;
    }
}
```

#### 9.2.2 查询编排：并行拉取多面板指标

```java
/**
 * 大盘查询编排器 - 将一次大盘查询拆解为多个独立指标查询任务并行执行
 *
 * 设计模式：Fan-out/Fan-in（分发-归并）模式
 *
 * 容错设计：
 * 单个面板/指标查询失败不应影响其他面板正常展示，
 * 失败面板返回明确的错误占位数据，前端展示"加载失败"而非整页崩溃
 */
@Component
public class DashboardQueryOrchestrator {

    private static final Logger logger = LoggerFactory.getLogger(DashboardQueryOrchestrator.class);

    private final DashboardConfigRepository configRepository;
    private final MetricQueryService metricQueryService;
    private final ChartDataAssembler chartDataAssembler;
    private final ExecutorService queryExecutor; // 固定大小线程池，隔离大盘查询与其他业务线程

    public DashboardQueryOrchestrator(DashboardConfigRepository configRepository,
                                       MetricQueryService metricQueryService,
                                       ChartDataAssembler chartDataAssembler,
                                       ExecutorService queryExecutor) {
        this.configRepository = configRepository;
        this.metricQueryService = metricQueryService;
        this.chartDataAssembler = chartDataAssembler;
        this.queryExecutor = queryExecutor;
    }

    public DashboardQueryResponse query(DashboardQueryRequest request) {
        DashboardConfig config = configRepository.getById(request.getDashboardId());
        if (config == null) {
            return DashboardQueryResponse.fail("DASHBOARD_NOT_FOUND", "大盘配置不存在");
        }

        List<PanelConfig> panels = config.getPanels().stream()
                .filter(p -> request.getPanelIds().contains(p.getPanelId()))
                .collect(Collectors.toList());

        // 每个面板一个异步任务，超时统一控制，避免慢查询拖垮整体响应
        List<CompletableFuture<PanelResult>> futures = panels.stream()
                .map(panel -> CompletableFuture.supplyAsync(
                        () -> queryPanelSafely(panel, request), queryExecutor)
                        .orTimeout(3, TimeUnit.SECONDS)
                        .exceptionally(ex -> buildFailedPanelResult(panel, ex)))
                .collect(Collectors.toList());

        List<PanelResult> panelResults = futures.stream()
                .map(CompletableFuture::join)
                .collect(Collectors.toList());

        return DashboardQueryResponse.success(request.getRequestId(), panelResults);
    }

    /**
     * 单个面板查询：捕获所有异常，保证Fan-out中一个任务失败不影响其他任务
     */
    private PanelResult queryPanelSafely(PanelConfig panel, DashboardQueryRequest request) {
        long start = System.currentTimeMillis();
        try {
            List<MetricSeriesResult> seriesResults = new ArrayList<>();
            for (MetricQuerySpec spec : panel.getMetricSpecs()) {
                MetricSeriesResult series = metricQueryService.query(
                        spec, request.getStartTime(), request.getEndTime());
                seriesResults.add(series);
            }
            ChartData chartData = chartDataAssembler.assemble(
                    panel, seriesResults, request.getStartTime(), request.getEndTime());

            logger.debug("[DashboardOrchestrator] panel query success, panelId={}, costMs={}",
                    panel.getPanelId(), System.currentTimeMillis() - start);

            return PanelResult.success(panel.getPanelId(), chartData);
        } catch (Exception e) {
            logger.error("[DashboardOrchestrator] panel query failed, panelId={}, cause={}",
                    panel.getPanelId(), e.toString(), e);
            return PanelResult.fail(panel.getPanelId(), "查询失败: " + e.getClass().getSimpleName());
        }
    }

    private PanelResult buildFailedPanelResult(PanelConfig panel, Throwable ex) {
        logger.error("[DashboardOrchestrator] panel query timeout/exception, panelId={}, cause={}",
                panel.getPanelId(), ex.toString());
        return PanelResult.fail(panel.getPanelId(), "查询超时或异常");
    }
}
```

#### 9.2.3 指标查询服务：多级降级读取时序数据

```java
/**
 * 指标查询服务 - 从时序数据库读取指标序列，支持本地缓存与降级
 *
 * 容错策略（多级降级）：
 * 1. 优先查本地短TTL缓存（应对同一批面板复用相同指标的场景）
 * 2. 缓存未命中查询时序数据库
 * 3. 时序数据库查询失败/超时，尝试读取上一次成功查询结果作为兜底（标记为"陈旧数据"）
 * 4. 兜底也没有数据时，抛出明确异常由上层统一转换为失败面板
 */
@Component
public class MetricQueryService {

    private static final Logger logger = LoggerFactory.getLogger(MetricQueryService.class);

    private final TimeSeriesQueryClient tsQueryClient;
    private final Cache<String, MetricSeriesResult> localCache; // key: metric+tags+range，TTL 30s
    private final Cache<String, MetricSeriesResult> staleFallbackCache; // 兜底缓存，TTL较长(如1小时)

    public MetricQueryService(TimeSeriesQueryClient tsQueryClient,
                               Cache<String, MetricSeriesResult> localCache,
                               Cache<String, MetricSeriesResult> staleFallbackCache) {
        this.tsQueryClient = tsQueryClient;
        this.localCache = localCache;
        this.staleFallbackCache = staleFallbackCache;
    }

    public MetricSeriesResult query(MetricQuerySpec spec, long startTime, long endTime) {
        String cacheKey = buildCacheKey(spec, startTime, endTime);

        MetricSeriesResult cached = localCache.getIfPresent(cacheKey);
        if (cached != null) {
            return cached;
        }

        try {
            MetricSeriesResult result = doQueryWithRetry(spec, startTime, endTime);
            localCache.put(cacheKey, result);
            // 同步更新兜底缓存，供后续查询失败时使用
            staleFallbackCache.put(buildStaleKey(spec), result);
            return result;
        } catch (Exception e) {
            logger.error("[MetricQuery] query failed, metric={}, tags={}, cause={}",
                    spec.getMetric(), spec.getTags(), e.toString(), e);

            MetricSeriesResult stale = staleFallbackCache.getIfPresent(buildStaleKey(spec));
            if (stale != null) {
                logger.warn("[MetricQuery] fallback to stale data, metric={}, tags={}",
                        spec.getMetric(), spec.getTags());
                return stale.markStale();
            }
            throw new MetricQueryException("指标查询失败且无兜底数据: " + spec.getMetric(), e);
        }
    }

    /**
     * 带重试的实际查询，最多重试2次，短暂退避
     */
    private MetricSeriesResult doQueryWithRetry(MetricQuerySpec spec, long startTime, long endTime) {
        int attempt = 0;
        RuntimeException lastError = null;
        while (attempt < 2) {
            attempt++;
            try {
                return tsQueryClient.query(spec, startTime, endTime);
            } catch (RpcTimeoutException e) {
                lastError = e;
                logger.warn("[MetricQuery] rpc timeout, metric={}, attempt={}", spec.getMetric(), attempt);
                sleepQuietly(50L * attempt);
            }
        }
        throw lastError != null ? lastError : new MetricQueryException("查询未知失败: " + spec.getMetric());
    }

    private String buildCacheKey(MetricQuerySpec spec, long startTime, long endTime) {
        return spec.getMetric() + "|" + spec.getTags() + "|" + startTime + "|" + endTime;
    }

    private String buildStaleKey(MetricQuerySpec spec) {
        return spec.getMetric() + "|" + spec.getTags();
    }

    private void sleepQuietly(long millis) {
        try {
            Thread.sleep(millis);
        } catch (InterruptedException ie) {
            Thread.currentThread().interrupt();
        }
    }
}
```

#### 9.2.4 图表数据组装：时间轴对齐与降采样

```java
/**
 * 图表数据组装器 - 将多个指标序列对齐时间轴、按需降采样后转换为前端图表格式
 *
 * 降采样算法：
 * 当原始点数超过前端渲染上限（如1000点）时，按等比例区间做LTTB
 * (Largest-Triangle-Three-Buckets)近似算法降采样，
 * 在保留视觉关键特征（峰值/谷值）的同时大幅减少传输数据量
 */
@Component
public class ChartDataAssembler {

    private static final Logger logger = LoggerFactory.getLogger(ChartDataAssembler.class);
    private static final int MAX_RENDER_POINTS = 1000;

    public ChartData assemble(PanelConfig panel, List<MetricSeriesResult> seriesResults,
                               long startTime, long endTime) {
        ChartData chartData = new ChartData();
        chartData.setPanelId(panel.getPanelId());
        chartData.setChartType(panel.getChartType());

        for (MetricSeriesResult series : seriesResults) {
            try {
                List<DataPoint> points = series.getPoints();
                if (points.size() > MAX_RENDER_POINTS) {
                    points = downSample(points, MAX_RENDER_POINTS);
                    logger.debug("[ChartAssembler] downsampled series {} from {} to {} points",
                            series.getMetric(), series.getPoints().size(), points.size());
                }
                ChartSeries chartSeries = new ChartSeries(
                        series.getMetric(), series.getTags(), points, series.isStale());
                chartData.addSeries(chartSeries);
            } catch (Exception e) {
                // 单条series处理异常不能影响图表其他曲线的渲染
                logger.error("[ChartAssembler] assemble series failed, metric={}, cause={}",
                        series.getMetric(), e.toString(), e);
                chartData.addSeries(ChartSeries.empty(series.getMetric()));
            }
        }
        return chartData;
    }

    /**
     * LTTB降采样简化实现：将数据划分为目标点数-2个桶，
     * 每个桶内选择与前后邻居构成三角形面积最大的点，尽量保留波形特征
     */
    private List<DataPoint> downSample(List<DataPoint> points, int threshold) {
        if (threshold >= points.size() || threshold <= 2) {
            return points;
        }
        List<DataPoint> sampled = new ArrayList<>(threshold);
        sampled.add(points.get(0)); // 首点必选

        double bucketSize = (double) (points.size() - 2) / (threshold - 2);
        int a = 0;

        for (int i = 0; i < threshold - 2; i++) {
            int bucketStart = (int) (Math.floor((i + 1) * bucketSize) + 1);
            int bucketEnd = (int) (Math.floor((i + 2) * bucketSize) + 1);
            bucketEnd = Math.min(bucketEnd, points.size());

            // 下一个桶的平均点，用于计算三角形面积
            int nextStart = bucketEnd;
            int nextEnd = (int) Math.min(Math.floor((i + 3) * bucketSize) + 1, points.size());
            double avgX = 0, avgY = 0;
            int nextCount = Math.max(1, nextEnd - nextStart);
            for (int j = nextStart; j < nextEnd; j++) {
                avgX += points.get(j).getTimestamp();
                avgY += points.get(j).getValue();
            }
            avgX /= nextCount;
            avgY /= nextCount;

            DataPoint pointA = points.get(a);
            double maxArea = -1;
            int maxAreaIndex = bucketStart;

            for (int j = bucketStart; j < bucketEnd; j++) {
                DataPoint candidate = points.get(j);
                double area = Math.abs(
                        (pointA.getTimestamp() - avgX) * (candidate.getValue() - pointA.getValue())
                      - (pointA.getTimestamp() - candidate.getTimestamp()) * (avgY - pointA.getValue())
                ) * 0.5;
                if (area > maxArea) {
                    maxArea = area;
                    maxAreaIndex = j;
                }
            }
            sampled.add(points.get(maxAreaIndex));
            a = maxAreaIndex;
        }

        sampled.add(points.get(points.size() - 1)); // 末点必选
        return sampled;
    }
}
```

**案例二小结**：该链路本质是"读路径"，幂等主要体现在requestId结果缓存（防重复渲染触发的重复查询）；核心工程价值在于Fan-out并行查询 + 单面板异常隔离 + 多级降级（本地缓存→时序库→陈旧兜底）+ LTTB降采样，保证大盘"总能展示出东西"而不是因单个指标故障导致整页白屏。

### 9.3 案例三：告警收敛与升级全链路

**链路总览**：原始告警事件产生 → 告警收敛引擎按指纹合并去重 → 按分级策略计算告警级别 → 未确认告警按SLA定时检查并升级 → 升级后按On-Call排班表通知对应责任人。

#### 9.3.1 告警收敛：重复告警合并去重

```java
/**
 * 告警收敛服务 - 将短时间内同一根因产生的大量重复告警合并为一个告警组
 *
 * 收敛算法：
 * 1. 指纹（fingerprint）= 规则名 + 核心维度标签（如service+instance）的哈希，
 *    相同指纹的告警视为"同一问题的重复上报"
 * 2. 收敛窗口内（如5分钟）同指纹告警只创建/更新一条AlertRecord，
 *    并记录occurCount，供后续判断"故障是否在扩大"
 *
 * 幂等设计：
 * 使用数据库唯一索引(fingerprint + window_start)兜底，
 * 并发写入时通过"先查后insert，冲突则转update"处理竞态，
 * 保证同一窗口内不会产生两条重复的告警组记录
 */
@Component
public class AlertAggregationService {

    private static final Logger logger = LoggerFactory.getLogger(AlertAggregationService.class);
    private static final long AGGREGATION_WINDOW_MS = 5 * 60_000L;

    private final AlertRecordRepository alertRecordRepository;

    public AlertAggregationService(AlertRecordRepository alertRecordRepository) {
        this.alertRecordRepository = alertRecordRepository;
    }

    /**
     * 处理一条原始告警事件，合并到已有告警组或创建新组
     */
    public void aggregate(AlertEvent rawEvent) {
        String fingerprint = rawEvent.getFingerprint();
        long windowStart = alignToWindow(rawEvent.getTimestamp());

        try {
            // 先查询当前窗口是否已存在该指纹的告警组（同一根因）
            Optional<AlertRecord> existing = alertRecordRepository
                    .findByFingerprintAndWindowStart(fingerprint, windowStart);

            if (existing.isPresent()) {
                mergeIntoExisting(existing.get(), rawEvent);
            } else {
                createNewGroupIdempotently(rawEvent, fingerprint, windowStart);
            }
        } catch (Exception e) {
            // 收敛失败不能吞掉告警，降级为直接创建独立记录，保证告警不丢失（宁可重复，不能漏报）
            logger.error("[AlertAggregation] aggregate failed, fingerprint={}, fallback to raw insert, cause={}",
                    fingerprint, e.toString(), e);
            try {
                alertRecordRepository.insertRawFallback(rawEvent);
            } catch (Exception inner) {
                logger.error("[AlertAggregation] fallback insert also failed, fingerprint={}, cause={}",
                        fingerprint, inner.toString(), inner);
            }
        }
    }

    /**
     * 合并到已有告警组：出现次数+1，更新最后触发时间，判断是否需要重新分级
     */
    private void mergeIntoExisting(AlertRecord record, AlertEvent rawEvent) {
        // 乐观锁更新，避免高并发下同一告警组的计数丢失更新
        int updated = alertRecordRepository.incrementOccurrenceWithVersion(
                record.getId(), record.getVersion(), rawEvent.getTimestamp());

        if (updated == 0) {
            // 版本冲突，说明有并发更新，重新读取后重试一次
            logger.warn("[AlertAggregation] version conflict on merge, alertId={}, retry once", record.getId());
            AlertRecord latest = alertRecordRepository.findById(record.getId())
                    .orElseThrow(() -> new IllegalStateException("告警记录已被删除: " + record.getId()));
            alertRecordRepository.incrementOccurrenceWithVersion(
                    latest.getId(), latest.getVersion(), rawEvent.getTimestamp());
        }
        logger.info("[AlertAggregation] merged into existing group, alertId={}, fingerprint={}",
                record.getId(), record.getFingerprint());
    }

    /**
     * 幂等创建新告警组：利用数据库唯一索引兜底并发场景下的重复插入
     */
    private void createNewGroupIdempotently(AlertEvent rawEvent, String fingerprint, long windowStart) {
        AlertRecord record = AlertRecord.builder()
                .fingerprint(fingerprint)
                .windowStart(windowStart)
                .ruleName(rawEvent.getRuleName())
                .level(rawEvent.getLevel())
                .message(rawEvent.getMessage())
                .occurCount(1)
                .status(AlertStatus.OPEN)
                .firstOccurTime(rawEvent.getTimestamp())
                .lastOccurTime(rawEvent.getTimestamp())
                .version(0)
                .build();
        try {
            alertRecordRepository.insert(record);
            logger.info("[AlertAggregation] new alert group created, fingerprint={}, windowStart={}",
                    fingerprint, windowStart);
        } catch (DuplicateKeyException e) {
            // 唯一索引冲突：说明并发场景下另一线程已抢先插入，转为合并逻辑
            logger.info("[AlertAggregation] concurrent insert detected, fallback to merge, fingerprint={}",
                    fingerprint);
            AlertRecord winner = alertRecordRepository
                    .findByFingerprintAndWindowStart(fingerprint, windowStart)
                    .orElseThrow(() -> new IllegalStateException("并发冲突后未查到记录: " + fingerprint));
            mergeIntoExisting(winner, rawEvent);
        }
    }

    private long alignToWindow(long timestamp) {
        return (timestamp / AGGREGATION_WINDOW_MS) * AGGREGATION_WINDOW_MS;
    }
}
```

#### 9.3.2 告警分级：结合影响面与频次动态定级

```java
/**
 * 告警分级器 - 综合规则预设级别、影响面（受影响实例数）、历史频次
 * 计算告警的最终级别，支持动态升级（如WARNING因扩散范围扩大而升级为CRITICAL）
 */
@Component
public class AlertSeverityClassifier {

    private static final Logger logger = LoggerFactory.getLogger(AlertSeverityClassifier.class);

    /**
     * 计算告警最终级别
     *
     * 定级规则：
     * 1. 基础级别取规则预设级别
     * 2. 受影响实例数 >= 集群实例总数的50%，强制升级为CRITICAL（大面积故障）
     * 3. 5分钟内同指纹出现次数 >= 10次，说明问题持续未恢复，级别上调一档
     */
    public AlertEngine.AlertLevel classify(AlertRecord record, ClusterTopology topology) {
        try {
            AlertEngine.AlertLevel baseLevel = record.getLevel();

            double impactRatio = calcImpactRatio(record, topology);
            if (impactRatio >= 0.5) {
                logger.warn("[SeverityClassifier] large-scale impact detected, ratio={}, force CRITICAL, alertId={}",
                        impactRatio, record.getId());
                return AlertEngine.AlertLevel.CRITICAL;
            }

            if (record.getOccurCount() >= 10 && baseLevel != AlertEngine.AlertLevel.CRITICAL) {
                AlertEngine.AlertLevel escalated = upgradeOneLevel(baseLevel);
                logger.info("[SeverityClassifier] escalate by frequency, alertId={}, from={} to={}, occurCount={}",
                        record.getId(), baseLevel, escalated, record.getOccurCount());
                return escalated;
            }

            return baseLevel;
        } catch (Exception e) {
            // 分级异常时采用保守策略：不降低原有级别，避免因计算异常漏报重要告警
            logger.error("[SeverityClassifier] classify failed, alertId={}, fallback to original level, cause={}",
                    record.getId(), e.toString(), e);
            return record.getLevel();
        }
    }

    private double calcImpactRatio(AlertRecord record, ClusterTopology topology) {
        int totalInstances = topology.getInstanceCount(record.getServiceName());
        if (totalInstances <= 0) {
            return 0d;
        }
        int affected = topology.getAffectedInstanceCount(record.getServiceName(), record.getFingerprint());
        return (double) affected / totalInstances;
    }

    private AlertEngine.AlertLevel upgradeOneLevel(AlertEngine.AlertLevel level) {
        switch (level) {
            case INFO:
                return AlertEngine.AlertLevel.WARNING;
            case WARNING:
                return AlertEngine.AlertLevel.CRITICAL;
            default:
                return level;
        }
    }
}
```

#### 9.3.3 升级调度：SLA超时自动升级

```java
/**
 * 告警升级调度器 - 定时巡检未确认告警，超过SLA自动升级并重新通知
 *
 * 升级策略（分级SLA）：
 * - CRITICAL：5分钟未确认 -> 升级通知范围（从Owner扩大到Team Leader）
 * - WARNING：15分钟未确认 -> 升级为CRITICAL并通知Owner
 * - 每次升级都会重置SLA计时，最多升级至L3（全员+电话）后不再继续升级，避免无限扩散
 *
 * 幂等设计：
 * 升级操作先做状态机CAS（Compare-And-Set）：只有当前escalationLevel符合预期时才允许升级，
 * 防止定时任务并发执行（如多实例部署下的调度重叠）导致同一告警被重复升级多级
 */
@Component
public class AlertEscalationScheduler {

    private static final Logger logger = LoggerFactory.getLogger(AlertEscalationScheduler.class);

    private static final Map<AlertEngine.AlertLevel, Long> SLA_MILLIS = new EnumMap<>(AlertEngine.AlertLevel.class);
    static {
        SLA_MILLIS.put(AlertEngine.AlertLevel.CRITICAL, 5 * 60_000L);
        SLA_MILLIS.put(AlertEngine.AlertLevel.WARNING, 15 * 60_000L);
        SLA_MILLIS.put(AlertEngine.AlertLevel.INFO, 60 * 60_000L);
    }
    private static final int MAX_ESCALATION_LEVEL = 3;

    private final AlertRecordRepository alertRecordRepository;
    private final OnCallRotationService onCallRotationService;
    private final AlertDispatchService dispatchService;

    public AlertEscalationScheduler(AlertRecordRepository alertRecordRepository,
                                     OnCallRotationService onCallRotationService,
                                     AlertDispatchService dispatchService) {
        this.alertRecordRepository = alertRecordRepository;
        this.onCallRotationService = onCallRotationService;
        this.dispatchService = dispatchService;
    }

    /**
     * 每分钟巡检一次所有OPEN状态且未确认的告警
     */
    @Scheduled(fixedRate = 60_000)
    public void checkAndEscalate() {
        List<AlertRecord> openAlerts;
        try {
            openAlerts = alertRecordRepository.findUnacknowledged(AlertStatus.OPEN);
        } catch (Exception e) {
            logger.error("[AlertEscalation] load unacknowledged alerts failed, cause={}", e.toString(), e);
            return;
        }

        long now = System.currentTimeMillis();
        for (AlertRecord alert : openAlerts) {
            try {
                processOne(alert, now);
            } catch (Exception e) {
                // 单条告警处理异常不影响其他告警的巡检
                logger.error("[AlertEscalation] process alert failed, alertId={}, cause={}",
                        alert.getId(), e.toString(), e);
            }
        }
    }

    private void processOne(AlertRecord alert, long now) {
        long slaMillis = SLA_MILLIS.getOrDefault(alert.getLevel(), 30 * 60_000L);
        long silenceDuration = now - alert.getLastNotifyTime();

        if (silenceDuration < slaMillis) {
            return; // 尚未超过SLA，无需升级
        }

        int currentEscalation = alert.getEscalationLevel();
        if (currentEscalation >= MAX_ESCALATION_LEVEL) {
            logger.warn("[AlertEscalation] alert already at max escalation level, alertId={}, level={}",
                    alert.getId(), currentEscalation);
            return;
        }

        int nextEscalation = currentEscalation + 1;

        // CAS更新：只有escalationLevel仍等于currentEscalation时才更新成功，防止并发重复升级
        boolean casSuccess = alertRecordRepository.casEscalationLevel(
                alert.getId(), currentEscalation, nextEscalation, now);

        if (!casSuccess) {
            logger.info("[AlertEscalation] CAS failed, alert probably escalated by another worker, alertId={}",
                    alert.getId());
            return;
        }

        logger.warn("[AlertEscalation] alert escalated, alertId={}, fingerprint={}, from L{} to L{}, silence={}ms",
                alert.getId(), alert.getFingerprint(), currentEscalation, nextEscalation, silenceDuration);

        notifyEscalation(alert, nextEscalation);
    }

    /**
     * 根据升级层级查找扩大后的On-Call责任人并发送通知
     */
    private void notifyEscalation(AlertRecord alert, int escalationLevel) {
        try {
            List<String> receivers = onCallRotationService.resolveEscalationReceivers(
                    alert.getServiceName(), escalationLevel);

            AlertEvent escalatedEvent = new AlertEvent(
                    alert.getFingerprint() + "-escalation-L" + escalationLevel,
                    alert.getRuleName(),
                    escalationLevel >= MAX_ESCALATION_LEVEL
                            ? AlertEngine.AlertLevel.CRITICAL : alert.getLevel(),
                    String.format("[升级L%d] %s（已持续%d次未处理）",
                            escalationLevel, alert.getMessage(), alert.getOccurCount()),
                    System.currentTimeMillis());

            dispatchService.dispatchToReceivers(escalatedEvent, receivers);

            alertRecordRepository.updateLastNotifyTime(alert.getId(), System.currentTimeMillis());
            logger.info("[AlertEscalation] escalation notification sent, alertId={}, level=L{}, receivers={}",
                    alert.getId(), escalationLevel, receivers);
        } catch (Exception e) {
            logger.error("[AlertEscalation] notify escalation failed, alertId={}, level=L{}, cause={}",
                    alert.getId(), escalationLevel, e.toString(), e);
        }
    }
}
```

#### 9.3.4 On-Call轮转：按值班表定位责任人

```java
/**
 * On-Call轮转服务 - 维护值班排班表，按告警服务/升级层级解析当前责任人
 *
 * 排班算法：
 * 采用周期性轮转（如每周切换一次Primary/Secondary），
 * 结合当前时间与排班起始时间计算轮转偏移量，
 * 支持节假日/请假换班等临时覆盖（override）记录优先生效
 */
@Component
public class OnCallRotationService {

    private static final Logger logger = LoggerFactory.getLogger(OnCallRotationService.class);
    private static final long ROTATION_PERIOD_MS = 7L * 24 * 3600 * 1000; // 每周轮换

    private final OnCallScheduleRepository scheduleRepository;
    private final OnCallOverrideRepository overrideRepository;

    public OnCallRotationService(OnCallScheduleRepository scheduleRepository,
                                  OnCallOverrideRepository overrideRepository) {
        this.scheduleRepository = scheduleRepository;
        this.overrideRepository = overrideRepository;
    }

    /**
     * 获取指定服务当前的值班人（Primary）
     */
    public List<String> getOnCallReceivers(String serviceOrRuleName) {
        try {
            OnCallSchedule schedule = scheduleRepository.findByService(serviceOrRuleName);
            if (schedule == null || schedule.getRotationMembers().isEmpty()) {
                logger.warn("[OnCallRotation] no schedule configured, fallback to default owner, service={}",
                        serviceOrRuleName);
                return scheduleRepository.getDefaultOwners(serviceOrRuleName);
            }

            // 临时覆盖优先：如请假/换班场景下，覆盖记录直接生效
            Optional<String> override = overrideRepository.findActiveOverride(
                    serviceOrRuleName, System.currentTimeMillis());
            if (override.isPresent()) {
                logger.info("[OnCallRotation] using override receiver, service={}, receiver={}",
                        serviceOrRuleName, override.get());
                return Collections.singletonList(override.get());
            }

            String primary = resolveCurrentRotationMember(schedule);
            return Collections.singletonList(primary);
        } catch (Exception e) {
            // 排班解析异常时兜底通知服务默认Owner，保证告警"总有人收到"
            logger.error("[OnCallRotation] resolve receiver failed, service={}, fallback to default owner, cause={}",
                    serviceOrRuleName, e.toString(), e);
            return scheduleRepository.getDefaultOwners(serviceOrRuleName);
        }
    }

    /**
     * 按升级层级解析通知范围：
     * L1 = Primary On-Call
     * L2 = Primary + Secondary On-Call
     * L3 = 全部值班成员 + Team Leader（最高层级兜底）
     */
    public List<String> resolveEscalationReceivers(String serviceName, int escalationLevel) {
        OnCallSchedule schedule = scheduleRepository.findByService(serviceName);
        if (schedule == null) {
            return scheduleRepository.getDefaultOwners(serviceName);
        }

        Set<String> receivers = new LinkedHashSet<>();
        receivers.add(resolveCurrentRotationMember(schedule));

        if (escalationLevel >= 2) {
            receivers.addAll(schedule.getSecondaryMembers());
        }
        if (escalationLevel >= 3) {
            receivers.addAll(schedule.getRotationMembers());
            receivers.add(schedule.getTeamLeader());
        }
        return new ArrayList<>(receivers);
    }

    /**
     * 计算当前轮转应值班的成员
     * 算法：(当前时间 - 排班起始时间) / 轮转周期 % 成员数，得到当前轮转下标
     */
    private String resolveCurrentRotationMember(OnCallSchedule schedule) {
        List<String> members = schedule.getRotationMembers();
        long elapsed = System.currentTimeMillis() - schedule.getStartTime();
        long periodIndex = elapsed / ROTATION_PERIOD_MS;
        int memberIndex = (int) (periodIndex % members.size());
        return members.get(memberIndex);
    }
}
```

**案例三小结**：本案例的幂等/防重复核心在于两处状态机式的CAS操作——告警组创建时的"唯一索引+并发转合并"、升级时的"escalationLevel CAS"，二者共同保证在多实例调度器并发巡检的场景下，同一告警不会被重复创建或重复升级；同时通过收敛窗口大幅降低了告警风暴场景下的通知量，通过SLA分级升级机制确保关键告警不会因无人确认而被悄悄遗漏。

### 9.4 三个案例的共性工程原则

| 原则 | 案例一体现 | 案例二体现 | 案例三体现 |
|------|-----------|-----------|-----------|
| 幂等控制 | batchId去重 + 冷却窗口 | requestId结果缓存 | 唯一索引兜底 + CAS状态机 |
| 异常隔离 | 单规则异常不影响其他规则 | 单面板/单指标异常不影响其他面板 | 单告警处理异常不影响其他告警巡检 |
| 日志追踪 | 全链路记录batchId/fingerprint | 记录requestId/panelId/costMs | 记录alertId/fingerprint/escalationLevel |
| 降级兜底 | 磁盘队列缓存 + 电话强制降级 | 陈旧数据兜底 + 降采样 | 排班解析异常兜底默认Owner |
| 可观测性自监控 | 上报耗时/成功率自打点 | 查询耗时自打点 | 升级次数/未确认时长可统计 |

三个案例共同验证了监控系统作为"系统的系统"，其自身也必须具备高可用、幂等、可观测的工程特性——监控链路一旦在关键节点重复计数、重复告警或数据丢失，反而会误导故障排查，因此上述幂等与容错设计并非可选项，而是监控系统的基本工程红线。
