# 短链接系统架构设计

> 本文部分内容参考学城文档《短链接生成》（contentId: 1279960531）和《短链接服务》（contentId: 77823756）整理，去除了内部产品名称，保留了架构设计思路和技术实现细节。

## 一、问题背景

### 1.1 业务场景

短链接系统将冗长的URL转换为简短的链接，方便在短信、社交媒体、二维码等场景中传播。例如将 `https://www.example.com/product/detail?skuId=123456&channel=wechat&utm_source=mp` 转换为 `https://t.ly/abcD3e`。

学城文档中明确指出短链接服务的核心定位：**短链接服务是公司内部服务，用于将需要投放到外部的公司链接或业务需要的合法外部链接转换为短链接，以便于发送和用户查看。**

### 1.2 学城文档中的实践要点

从学城文档中提取的关键架构决策：

**安全策略**：学城文档中明确强调了安全问题——"短链接容易被暴力逆推原始链接，如果直接访问原始链接返回敏感信息（未做权限控制），请勿使用短链接"。这意味着短链接系统在设计时必须考虑防遍历机制。

**白名单机制**：学城文档中实现了域名白名单限制（限制到二级域名），不在白名单内的域名不予生成和跳转。这是一个重要的安全设计——防止短链接服务被滥用为任意URL跳转工具。

**过期策略**：学城文档中定义了精细的过期规则：
1. 业务方可传入自定义过期时间，最短不低于35天，最长不超过2年
2. 若传入过期时间为-1，则默认1095天过期
3. 若短链在过期前被访问且有效期低于30天，将自动续租30天

**短链长度**：学城文档中给出的短链格式为 `http://dpurl.cn/12345678`，长度24字符，其中短码为8位。

**原始链接长度限制**：不能超过2000字符。

### 1.3 核心挑战

| 挑战维度 | 具体问题 | 学城文档对应 |
|---------|---------|-------------|
| 发号器 | 全局唯一ID生成，高性能 | - |
| 编码 | 短码尽可能短，能还原 | 8位短码 |
| 跳转性能 | 每次点击都要查长链接，QPS极高 | - |
| 缓存穿透 | 不存在的短链接不能打穿到DB | - |
| 防遍历 | 短码不能被遍历推算 | 安全问题章节 |
| 白名单 | 只允许白名单域名生成短链 | 白名单限制章节 |
| 过期管理 | 短链接可能有过期时间+自动续租 | 过期时间章节 |

### 1.4 短码长度计算

Base62编码（a-z, A-Z, 0-9共62个字符）：

学城文档使用8位短码。8位Base62可表示 62^8 ≈ 218万亿个短链接，远超6位的568亿。

| 短码长度 | 可表示数量 | 够用场景 |
|---------|-----------|---------|
| 6位 | 62^6 ≈ 568亿 | 中小型平台 |
| 7位 | 62^7 ≈ 3.5万亿 | 大型平台 |
| 8位 | 62^8 ≈ 218万亿 | 超大型平台（学城文档方案） |

## 三、核心链路设计

### 3.1 白名单校验

学城文档明确要求：**"短链接服务增加了白名单限制（限制到二级域名），不在白名单内的域名不予生成和跳转"**。这是安全的第一道防线。

```java
/**
 * 域名白名单校验服务
 *
 * 学城文档实践：限制到二级域名，不在白名单内的域名不予生成和跳转
 * 这防止短链接服务被滥用为任意URL跳转工具
 */
@Service
public class DomainWhitelistService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    // 白名单缓存在Redis Set中
    private static final String WHITELIST_KEY = "shorturl:whitelist";

    /**
     * 校验URL的域名是否在白名单中
     */
    public boolean isAllowed(String url) {
        try {
            String domain = extractDomain(url);
            if (domain == null) return false;

            // 查Redis缓存
            Boolean isMember = redisTemplate.opsForSet().isMember(WHITELIST_KEY, domain);
            return Boolean.TRUE.equals(isMember);
        } catch (Exception e) {
            log.error("白名单校验失败, url={}", url, e);
            return false; // 安全失败：校验异常时拒绝
        }
    }

    /**
     * 从URL中提取二级域名
     * 示例: https://www.example.com/path → example.com
     */
    private String extractDomain(String url) {
        try {
            URI uri = new URI(url);
            String host = uri.getHost();
            if (host == null) return null;

            // 提取二级域名（最后两部分）
            String[] parts = host.split("\\.");
            if (parts.length < 2) return host;
            return parts[parts.length - 2] + "." + parts[parts.length - 1];
        } catch (URISyntaxException e) {
            return null;
        }
    }

    /**
     * 加载白名单到Redis（管理后台调用）
     */
    public void reloadWhitelist(List<String> domains) {
        redisTemplate.delete(WHITELIST_KEY);
        if (!domains.isEmpty()) {
            redisTemplate.opsForSet().add(WHITELIST_KEY,
                domains.toArray(new String[0]));
        }
    }
}
```

### 3.2 发号器：号段模式

```java
/**
 * 号段模式发号器
 *
 * 原理：
 * 1. DB存储当前最大ID和步长
 * 2. 应用从DB批量取一段ID到本地
 * 3. 本地原子递增分配
 * 4. 用完再从DB取下一段
 *
 * 性能：本地分配，无网络IO，单机QPS可达百万
 *
 * 双Buffer优化：当前号段用到20%时，异步预加载下一个号段
 * 避免号段用完时的等待
 */
@Service
public class SegmentIdGenerator {

    @Autowired
    private IdAllocMapper idAllocMapper;

    private volatile AtomicLong currentId = new AtomicLong(0);
    private volatile AtomicLong maxId = new AtomicLong(0);
    private volatile boolean isLoadingNext = false;

    // 双Buffer：当前号段和下一个号段
    private volatile long nextStart = 0;
    private volatile long nextEnd = 0;

    private static final int STEP = 10000; // 每次取1万个
    private static final double LOAD_THRESHOLD = 0.2; // 剩余20%时预加载

    public synchronized long nextId() {
        // 当前号段用完，切换到预加载的号段
        if (currentId.get() >= maxId.get()) {
            if (nextStart > 0) {
                // 切换到预加载的号段
                currentId.set(nextStart);
                maxId.set(nextEnd);
                nextStart = 0;
                nextEnd = 0;
            } else {
                // 没有预加载，同步加载
                fetchNewSegment();
            }
        }

        // 剩余量低于阈值，异步预加载下一个号段
        long remaining = maxId.get() - currentId.get();
        if (remaining < STEP * LOAD_THRESHOLD && !isLoadingNext && nextStart == 0) {
            isLoadingNext = true;
            executor.submit(() -> {
                try {
                    fetchNextSegment();
                } finally {
                    isLoadingNext = false;
                }
            });
        }

        return currentId.getAndIncrement();
    }

    private void fetchNewSegment() {
        IdAlloc alloc = idAllocMapper.selectByBizTag("short_url");
        long newMax = alloc.getMaxId() + alloc.getStep();
        int updated = idAllocMapper.updateMaxId(
            "short_url", newMax, alloc.getMaxId(), alloc.getVersion());
        if (updated > 0) {
            currentId.set(alloc.getMaxId());
            maxId.set(newMax);
        } else {
            throw new RuntimeException("发号器乐观锁冲突");
        }
    }

    private void fetchNextSegment() {
        IdAlloc alloc = idAllocMapper.selectByBizTag("short_url");
        long newMax = alloc.getMaxId() + alloc.getStep();
        int updated = idAllocMapper.updateMaxId(
            "short_url", newMax, alloc.getMaxId(), alloc.getVersion());
        if (updated > 0) {
            nextStart = alloc.getMaxId();
            nextEnd = newMax;
        }
    }
}
```

### 3.3 Base62编码

学城文档使用8位短码。8位Base62可表示218万亿个短链接。

```java
/**
 * Base62编码器
 *
 * 将长整型ID转换为Base62短码
 * 62个字符: 0-9, a-z, A-Z
 */
public class Base62Encoder {

    private static final String CHARS =
        "0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ";
    private static final int BASE = CHARS.length(); // 62

    /**
     * 将数字编码为Base62字符串
     * 示例: 1000000 → "4c92"
     *       568000000000 → "aBcD3eFg" (8位)
     */
    public static String encode(long num) {
        if (num == 0) return "0";
        StringBuilder sb = new StringBuilder();
        while (num > 0) {
            sb.append(CHARS.charAt((int) (num % BASE)));
            num /= BASE;
        }
        return sb.reverse().toString();
    }

    /**
     * 将Base62字符串解码为数字
     */
    public static long decode(String str) {
        long result = 0;
        for (char c : str.toCharArray()) {
            result = result * BASE + CHARS.indexOf(c);
        }
        return result;
    }

    /**
     * 生成8位定长短码（学城文档方案）
     * 不足8位左侧补0
     */
    public static String encodeFixedLength(long num, int length) {
        String encoded = encode(num);
        while (encoded.length() < length) {
            encoded = "0" + encoded;
        }
        return encoded;
    }
}
```

### 3.4 生成短链接（完整链路）

结合学城文档的参数（originUrl, bizType, appName, expireDays）和安全要求：

```java
/**
 * 短链接生成服务
 *
 * 完整链路：
 * 1. 白名单校验（学城文档要求：限制到二级域名）
 * 2. 长度校验（学城文档限制2000字符）
 * 3. 过期时间计算（学城文档规则：最短35天，最长2年，-1默认1095天）
 * 4. 长链接查重（相同长链接+bizType返回已有短码）
 * 5. 发号器获取ID
 * 6. Base62编码生成8位短码
 * 7. 写入DB + 缓存 + 布隆过滤器
 */
@Service
public class ShortUrlGenerateService {

    @Autowired
    private DomainWhitelistService whitelistService;

    @Autowired
    private ShortUrlMapper shortUrlMapper;

    @Autowired
    private SegmentIdGenerator idGenerator;

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private BloomFilterService bloomFilter;

    // 学城文档中的过期规则
    private static final int MIN_EXPIRE_DAYS = 35;
    private static final int MAX_EXPIRE_DAYS = 730; // 2年
    private static final int DEFAULT_EXPIRE_DAYS = 1095; // -1时默认

    /**
     * 生成长链接对应的短链接
     *
     * @param originUrl 原始链接（学城文档要求≤2000字符）
     * @param bizType 业务类型（学城文档中用于区分业务）
     * @param appName 应用名（学城文档要求传入）
     * @param expireDays 过期天数（学城文档规则：35~730，-1=1095）
     */
    public GenerateResult generate(String originUrl, int bizType,
                                    String appName, int expireDays) {
        // 1. 白名单校验（学城文档安全要求）
        if (!whitelistService.isAllowed(originUrl)) {
            return GenerateResult.fail("域名不在白名单中");
        }

        // 2. 长度校验（学城文档限制2000）
        if (originUrl == null || originUrl.length() > 2000) {
            return GenerateResult.fail("原始链接长度不能超过2000");
        }

        // 3. 过期时间计算（学城文档规则）
        int actualExpireDays = calculateExpireDays(expireDays);
        Date expireTime = DateUtils.addDays(new Date(), actualExpireDays);

        // 4. 长链接查重
        String urlHash = DigestUtils.md5Hex(originUrl);
        ShortUrl exist = shortUrlMapper.selectByHashAndBiz(urlHash, bizType);
        if (exist != null && exist.getStatus() == 1) {
            // 已存在且有效，返回已有短码
            return GenerateResult.success(exist.getShortCode());
        }

        // 5. 发号器获取ID
        long id = idGenerator.nextId();

        // 6. Base62编码生成8位短码（学城文档方案）
        String shortCode = Base62Encoder.encodeFixedLength(id, 8);

        // 7. 写入DB
        ShortUrl shortUrl = new ShortUrl();
        shortUrl.setShortCode(shortCode);
        shortUrl.setOriginalUrl(originUrl);
        shortUrl.setUrlHash(urlHash);
        shortUrl.setBizType(bizType);
        shortUrl.setAppName(appName);
        shortUrl.setExpireDays(actualExpireDays);
        shortUrl.setExpireTime(expireTime);
        shortUrl.setStatus(1);
        shortUrl.setCreateTime(new Date());
        shortUrlMapper.insert(shortUrl);

        // 8. 写入缓存
        String cacheKey = "shorturl:" + shortCode;
        redisTemplate.opsForValue().set(cacheKey, originUrl,
            actualExpireDays, TimeUnit.DAYS);

        // 9. 写入布隆过滤器
        bloomFilter.add(shortCode);

        return GenerateResult.success(shortCode);
    }

    /**
     * 过期时间计算（学城文档规则）
     * - 最短35天，最长2年（730天）
     * - -1默认1095天
     */
    private int calculateExpireDays(int expireDays) {
        if (expireDays == -1) {
            return DEFAULT_EXPIRE_DAYS;
        }
        return Math.max(MIN_EXPIRE_DAYS, Math.min(MAX_EXPIRE_DAYS, expireDays));
    }
}
```

### 3.5 短链接跳转（含学城文档的过期续租机制）

学城文档中的续租策略：**"若短链在过期前被访问且有效期低于30天，将自动为该短链续租30天"**。这是一个重要的设计——活跃的短链接不会意外过期。

```java
/**
 * 短链接跳转服务
 *
 * 完整链路：
 * 1. 布隆过滤器检查短码是否存在（防穿透）
 * 2. 查本地缓存（Caffeine）
 * 3. 查Redis缓存
 * 4. 缓存未命中查DB
 * 5. 检查过期时间
 * 6. 学城文档续租策略：有效期低于30天且被访问 → 自动续租30天
 * 7. 302重定向
 * 8. 异步统计点击量
 */
@Service
public class ShortUrlRedirectService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private ShortUrlMapper shortUrlMapper;

    @Autowired
    private BloomFilterService bloomFilter;

    // 学城文档续租阈值
    private static final int RENEW_THRESHOLD_DAYS = 30;
    private static final int RENEW_DAYS = 30;

    // 本地缓存
    private final Cache<String, String> localCache = Caffeine.newBuilder()
        .maximumSize(100000)
        .expireAfterWrite(1, TimeUnit.SECONDS)
        .build();

    public String redirect(String shortCode) {
        // 1. 布隆过滤器检查
        if (!bloomFilter.mightContain(shortCode)) {
            return null;
        }

        // 2. 查本地缓存
        String originalUrl = localCache.getIfPresent(shortCode);
        if (originalUrl != null) {
            asyncIncrementClick(shortCode);
            return originalUrl;
        }

        // 3. 查Redis缓存
        String cacheKey = "shorturl:" + shortCode;
        originalUrl = redisTemplate.opsForValue().get(cacheKey);
        if (originalUrl != null) {
            if (originalUrl.isEmpty()) {
                return null; // 缓存空值
            }
            localCache.put(shortCode, originalUrl);
            // 检查是否需要续租
            checkAndRenew(shortCode);
            asyncIncrementClick(shortCode);
            return originalUrl;
        }

        // 4. 查DB
        ShortUrl shortUrl = shortUrlMapper.selectByShortCode(shortCode);
        if (shortUrl == null || shortUrl.getStatus() != 1) {
            redisTemplate.opsForValue().set(cacheKey, "", 5, TimeUnit.MINUTES);
            return null;
        }

        // 5. 检查过期
        if (shortUrl.getExpireTime().before(new Date())) {
            return null;
        }

        // 6. 回填缓存
        redisTemplate.opsForValue().set(cacheKey,
            shortUrl.getOriginalUrl(), 30, TimeUnit.DAYS);
        localCache.put(shortCode, shortUrl.getOriginalUrl());

        // 7. 学城文档续租策略
        checkAndRenew(shortUrl);

        // 8. 异步统计
        asyncIncrementClick(shortCode);

        return shortUrl.getOriginalUrl();
    }

    /**
     * 学城文档续租策略
     * "若短链在过期前被访问且有效期低于30天，将自动为该短链续租30天"
     */
    private void checkAndRenew(ShortUrl shortUrl) {
        long remainingDays = (shortUrl.getExpireTime().getTime()
            - System.currentTimeMillis()) / (1000 * 60 * 60 * 24);

        if (remainingDays > 0 && remainingDays < RENEW_THRESHOLD_DAYS) {
            // 有效期低于30天，续租30天
            Date newExpireTime = DateUtils.addDays(
                shortUrl.getExpireTime(), RENEW_DAYS);
            shortUrlMapper.updateExpireTime(shortUrl.getShortCode(), newExpireTime);

            // 更新缓存TTL

            redisTemplate.expire(cacheKey, RENEW_THRESHOLD_DAYS + RENEW_DAYS,
                TimeUnit.DAYS);

            log.info("短链接续租, code={}, newExpire={}",
                shortUrl.getShortCode(), newExpireTime);
        }
    }

    private void asyncIncrementClick(String shortCode) {
        // 异步统计点击量（省略）
    }
```

### 3.6 布隆过滤器防穿透

```java
/**
 * 布隆过滤器
 *
 * 作用：防止不存在的短码打穿到DB
 * 学城文档安全问题章节提到"短链接容易被暴力逆推"，
 * 布隆过滤器同时起到了防止暴力遍历的作用
 *
 * 容量1亿，误判率0.1%，需要约179MB内存
 */
@Service
public class BloomFilterService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    private static final String BLOOM_KEY = "shorturl:bloom";
    private static final long EXPECTED_INSERTIONS = 100_000_000;
    private static final double FPP = 0.001;

    private static final long BIT_SIZE = optimalNumOfBits(EXPECTED_INSERTIONS, FPP);
    private static final int NUM_HASH_FUNCTIONS = optimalNumOfHashFunctions(
        EXPECTED_INSERTIONS, BIT_SIZE);

    public void add(String shortCode) {
        long hash = Hashing.murmur3_128()
            .hashString(shortCode, StandardCharsets.UTF_8).asLong();
        int hash1 = (int) hash;
        int hash2 = (int) (hash >>> 32);

        for (int i = 1; i <= NUM_HASH_FUNCTIONS; i++) {
            int combinedHash = hash1 + i * hash2;
            if (combinedHash < 0) combinedHash = ~combinedHash;
            redisTemplate.opsForValue().setBit(BLOOM_KEY,
                combinedHash % BIT_SIZE, true);
        }
    }

    public boolean mightContain(String shortCode) {
        long hash = Hashing.murmur3_128()
            .hashString(shortCode, StandardCharsets.UTF_8).asLong();
        int hash1 = (int) hash;
        int hash2 = (int) (hash >>> 32);

        for (int i = 1; i <= NUM_HASH_FUNCTIONS; i++) {
            int combinedHash = hash1 + i * hash2;
            if (combinedHash < 0) combinedHash = ~combinedHash;
            Boolean bit = redisTemplate.opsForValue().getBit(BLOOM_KEY,
                combinedHash % BIT_SIZE);
            if (bit == null || !bit) {
                return false;
            }
        }
        return true;
    }

    private static long optimalNumOfBits(long n, double p) {
        return (long) (-n * Math.log(p) / (Math.log(2) * Math.log(2)));
    }

    private static int optimalNumOfHashFunctions(long n, long m) {
        return Math.max(1, (int) Math.round((double) m / n * Math.log(2)));
    }
}
```

## 四、安全设计

### 4.1 防暴力遍历

学城文档明确指出安全问题：**"近期发现了两起暴力遍历短链接获取对应原链接（包括路径参数和页面）中敏感信息的case，请短链接的使用方做好原始链接中敏感信息的处理和页面的权限验证；短链接仅负责跳转，不具备隐藏原始链接中信息的功能"**

```java
/**
 * 防暴力遍历策略
 *
 * 学城文档安全要求：防止短码被暴力遍历推算
 *
 * 策略：
 * 1. 短码不连续：发号器ID经过混淆后再Base62编码
 * 2. 访问频率限制：同一IP对不存在短码的访问频率限制
 * 3. 短码不返回原始链接内容给非授权方
 */
@Service
public class AntiTraversalService {

    /**
     * ID混淆：防止短码连续可遍历
     * 将自增ID通过位运算混淆，使相邻ID的短码差异很大
     */
    public long obfuscateId(long id) {
        // 简单的位混淆：高低位交换 + 异或
        long obfuscated = ((id & 0xFFFF0000L) >> 16)
            | ((id & 0x0000FFFFL) << 16);
        obfuscated ^= 0x5A5A5A5AL; // 固定密钥异或
        return obfuscated;
    }

    /**
     * IP频率限制：防止遍历攻击
     */
    public boolean checkIpRate(String ip) {
        String key = "shorturl:iprate:" + ip;
        Long count = redisTemplate.opsForValue().increment(key);
        if (count == 1) {
            redisTemplate.expire(key, 1, TimeUnit.MINUTES);
        }
        // 每分钟最多100次访问
        return count <= 100;
    }
}
```

## 五、最佳实践与总结

### 5.1 核心设计决策

| 决策点 | 选择 | 理由 | 学城文档对应 |
|--------|------|------|-------------|
| 短码长度 | 8位Base62 | 218万亿容量 | 学城文档短链长度24字符 |
| 发号器 | 号段模式+双Buffer | 高性能、无网络IO | - |
| 白名单 | 限制到二级域名 | 安全防护 | 学城文档白名单机制 |
| 过期策略 | 35天~2年，-1=1095天 | 灵活控制 | 学城文档过期规则 |
| 续租策略 | 有效期<30天被访问时续30天 | 活跃链接不过期 | 学城文档续租策略 |
| 防穿透 | 布隆过滤器 | 内存效率高 | - |
| 防遍历 | ID混淆+IP限频 | 安全防护 | 学城文档安全问题 |
| 重定向 | 302临时重定向 | 可统计、可控制 | - |
| 长度限制 | 2000字符 | 防止超长URL | 学城文档长度限制 |
| 查重 | MD5哈希+bizType | 相同链接复用短码 | 学城文档bizType区分 |

### 5.2 容易踩的坑（学城文档实践总结）

1. **安全问题**（学城文档重点强调）：短链接容易被暴力逆推原始链接，短链接仅负责跳转，不具备隐藏原始链接中信息的功能。使用方必须做好原始链接中敏感信息的处理和页面的权限验证。
2. **白名单遗漏**：新业务域名忘记加入白名单，导致短链接生成失败
3. **过期时间过短**：学城文档要求最短35天，过短会导致链接失效
4. **续租机制缺失**：没有续租机制，活跃链接意外过期
5. **发号器单点**：号段模式如果DB宕机，发号中断，必须双Buffer预加载
6. **布隆过滤器不删除**：布隆过滤器不支持删除，过期的短链接仍可能"存在"

#### 6.1.2 Controller 入口

```java
/**
 * 短链接生成接口
 *
 * 全链路步骤：
 *   入口参数校验 → 幂等检查 → URL合法性校验 → 白名单校验
 *   → 长链接查重 → 短码生成（自定义别名/发号器+Base62）
 *   → 布隆过滤器去重 → 数据入库 → Redis缓存预热 → 返回短链URL
 */
@Slf4j
@RestController
@RequestMapping("/api/v1/short-url")
public class ShortUrlController {

    @Autowired
    private ShortUrlFullLinkService shortUrlFullLinkService;

    @PostMapping("/create")
    public Result<ShortUrlCreateResponse> create(
            @Valid @RequestBody ShortUrlCreateRequest request,
            HttpServletRequest httpRequest) {

        String clientIp = getClientIp(httpRequest);
        log.info("[短链接生成] 收到请求, originUrl={}, bizType={}, appName={}, "
                + "expireDays={}, customAlias={}, idempotentKey={}, clientIp={}",
                request.getOriginUrl(), request.getBizType(), request.getAppName(),
                request.getExpireDays(), request.getCustomAlias(),
                request.getIdempotentKey(), clientIp);

        try {
            ShortUrlCreateResponse response = shortUrlFullLinkService.createShortUrl(request);
            log.info("[短链接生成] 成功, shortCode={}, originUrl={}",
                    response.getShortCode(), request.getOriginUrl());
            return Result.ok(response);
        } catch (IllegalArgumentException e) {
            log.warn("[短链接生成] 参数校验失败, msg={}, originUrl={}",
                    e.getMessage(), request.getOriginUrl());
            return Result.fail(400, e.getMessage());
        } catch (DuplicateKeyException e) {
            log.warn("[短链接生成] 短码冲突（并发场景）, originUrl={}", request.getOriginUrl());
            return Result.fail(409, "短码冲突，请重试");
        } catch (Exception e) {
            log.error("[短链接生成] 系统异常, originUrl={}", request.getOriginUrl(), e);
            return Result.fail(500, "系统异常，请稍后重试");
        }
    }

    private String getClientIp(HttpServletRequest request) {
        String ip = request.getHeader("X-Forwarded-For");
        if (ip == null || ip.isEmpty() || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getHeader("X-Real-IP");
        }
        if (ip == null || ip.isEmpty() || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getRemoteAddr();
        }
        // X-Forwarded-For 可能包含多个IP，取第一个
        if (ip != null && ip.contains(",")) {
            ip = ip.split(",")[0].trim();
        }
        return ip;
    }
}
```

#### 6.1.3 核心服务：完整生成链路

```java
/**
 * 短链接生成全链路服务
 *
 * 包含完整的幂等控制、URL校验、短码生成、持久化和缓存预热
 */
@Slf4j
@Service
public class ShortUrlFullLinkService {

    @Autowired
    private DomainWhitelistService whitelistService;
    @Autowired
    private ShortUrlMapper shortUrlMapper;
    @Autowired
    private SegmentIdGenerator idGenerator;
    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private BloomFilterService bloomFilter;

    private static final String SHORT_URL_DOMAIN = "https://dpurl.cn/";
    private static final String IDEMPOTENT_PREFIX = "shorturl:idempotent:";
    private static final String CACHE_PREFIX = "shorturl:";

    // 学城文档过期规则
    private static final int MIN_EXPIRE_DAYS = 35;
    private static final int MAX_EXPIRE_DAYS = 730;
    private static final int DEFAULT_EXPIRE_DAYS = 1095;

    /**
     * 完整生成链路
     */
    @Transactional(rollbackFor = Exception.class)
    public ShortUrlCreateResponse createShortUrl(ShortUrlCreateRequest request) {

        // ===== 第一步：幂等检查（通过Redis SETNX实现） =====
        if (StringUtils.isNotBlank(request.getIdempotentKey())) {
            String idempotentResult = checkIdempotent(request.getIdempotentKey());
            if (idempotentResult != null) {
                log.info("[短链接生成] 幂等命中, idempotentKey={}, shortCode={}",
                        request.getIdempotentKey(), idempotentResult);
                return buildResponse(idempotentResult,
                        shortUrlMapper.selectByShortCode(idempotentResult));
            }
        }

        // ===== 第二步：URL合法性校验 =====
        validateUrl(request.getOriginUrl());

        // ===== 第三步：白名单校验（学城文档安全要求） =====
        if (!whitelistService.isAllowed(request.getOriginUrl())) {
            throw new IllegalArgumentException(
                    "域名不在白名单中，仅允许白名单内的二级域名生成短链接");
        }

        // ===== 第四步：过期时间计算（学城文档规则） =====
        int actualExpireDays = calculateExpireDays(request.getExpireDays());
        Date expireTime = DateUtils.addDays(new Date(), actualExpireDays);

        // ===== 第五步：长链接查重（相同 originUrl + bizType 复用已有短码） =====
        String urlHash = DigestUtils.md5Hex(request.getOriginUrl());
        ShortUrl existing = shortUrlMapper.selectByHashAndBiz(urlHash, request.getBizType());
        if (existing != null && existing.getStatus() == 1
                && existing.getExpireTime().after(new Date())) {
            log.info("[短链接生成] 长链接已存在, 复用短码={}, urlHash={}",
                    existing.getShortCode(), urlHash);
            saveIdempotent(request.getIdempotentKey(), existing.getShortCode());
            return buildResponse(existing.getShortCode(), existing);
        }

        // ===== 第六步：短码生成 =====
        String shortCode;
        if (StringUtils.isNotBlank(request.getCustomAlias())) {
            // 6a. 自定义别名模式 — 检查别名是否已被占用
            shortCode = request.getCustomAlias();
            if (bloomFilter.mightContain(shortCode)) {
                ShortUrl conflict = shortUrlMapper.selectByShortCode(shortCode);
                if (conflict != null && conflict.getStatus() == 1) {
                    throw new IllegalArgumentException("自定义别名已被占用: " + shortCode);
                }
            }
            log.info("[短链接生成] 使用自定义别名={}", shortCode);
        } else {
            // 6b. 发号器 + Base62编码（学城文档8位短码方案）
            shortCode = generateUniqueShortCode();
            log.info("[短链接生成] 发号器生成短码={}", shortCode);
        }

        // ===== 第七步：数据入库 =====
        ShortUrl shortUrl = new ShortUrl();
        shortUrl.setShortCode(shortCode);
        shortUrl.setOriginalUrl(request.getOriginUrl());
        shortUrl.setUrlHash(urlHash);
        shortUrl.setBizType(request.getBizType());
        shortUrl.setAppName(request.getAppName());
        shortUrl.setExpireDays(actualExpireDays);
        shortUrl.setExpireTime(expireTime);
        shortUrl.setStatus(1);
        shortUrl.setClickCount(0L);
        shortUrl.setCreateTime(new Date());
        shortUrlMapper.insert(shortUrl);
        log.info("[短链接生成] 入库完成, shortCode={}, expireTime={}", shortCode, expireTime);

        // ===== 第八步：写入布隆过滤器 =====
        bloomFilter.add(shortCode);

        // ===== 第九步：Redis缓存预热 =====
        String cacheKey = CACHE_PREFIX + shortCode;
        redisTemplate.opsForValue().set(cacheKey,
                request.getOriginUrl(), actualExpireDays, TimeUnit.DAYS);
        log.info("[短链接生成] 缓存预热完成, cacheKey={}, ttl={}天", cacheKey, actualExpireDays);

        // ===== 第十步：记录幂等键 =====
        saveIdempotent(request.getIdempotentKey(), shortCode);

        return buildResponse(shortCode, shortUrl);
    }

    // ---------- 私有方法 ----------

    /**
     * URL合法性校验
     * - 协议必须为 http 或 https
     * - 长度不超过2000（学城文档限制）
     * - 格式必须是合法URI
     */
    private void validateUrl(String url) {
        if (StringUtils.isBlank(url)) {
            throw new IllegalArgumentException("原始链接不能为空");
        }
        if (url.length() > 2000) {
            throw new IllegalArgumentException("原始链接长度不能超过2000");
        }
        try {
            URI uri = new URI(url);
            String scheme = uri.getScheme();
            if (scheme == null || (!scheme.equalsIgnoreCase("http")
                    && !scheme.equalsIgnoreCase("https"))) {
                throw new IllegalArgumentException("仅支持http/https协议");
            }
            if (uri.getHost() == null || uri.getHost().isEmpty()) {
                throw new IllegalArgumentException("URL缺少Host");
            }
        } catch (URISyntaxException e) {
            throw new IllegalArgumentException("URL格式非法: " + e.getMessage());
        }
    }

    /**
     * 生成唯一短码（发号器 + Base62 + 布隆过滤器去重）
     *
     * 通过布隆过滤器做前置去重检查，冲突时重试（极小概率）
     */
    private String generateUniqueShortCode() {
        int maxRetry = 3;
        for (int i = 0; i < maxRetry; i++) {
            long id = idGenerator.nextId();
            String shortCode = Base62Encoder.encodeFixedLength(id, 8);

            // 布隆过滤器前置去重
            if (!bloomFilter.mightContain(shortCode)) {
                return shortCode;
            }

            // 布隆过滤器误判（极小概率），查库确认
            ShortUrl conflict = shortUrlMapper.selectByShortCode(shortCode);
            if (conflict == null) {
                // 布隆过滤器误判，短码实际可用
                return shortCode;
            }

            log.warn("[短链接生成] 短码冲突，重试中, shortCode={}, retry={}", shortCode, i + 1);
        }
        throw new RuntimeException("短码生成失败，已重试" + maxRetry + "次");
    }

    /**
     * 过期时间计算（学城文档规则）
     */
    private int calculateExpireDays(Integer expireDays) {
        if (expireDays == null || expireDays == -1) {
            return DEFAULT_EXPIRE_DAYS;
        }
        if (expireDays < MIN_EXPIRE_DAYS) {
            throw new IllegalArgumentException(
                    "过期天数不能小于" + MIN_EXPIRE_DAYS + "天");
        }
        return Math.min(expireDays, MAX_EXPIRE_DAYS);
    }

    /**
     * 幂等检查 — Redis SETNX
     * 如果 idempotentKey 已存在，返回之前的短码；否则返回 null
     */
    private String checkIdempotent(String idempotentKey) {
        if (StringUtils.isBlank(idempotentKey)) {
            return null;
        }
        String key = IDEMPOTENT_PREFIX + idempotentKey;
        return redisTemplate.opsForValue().get(key);
    }

    /**
     * 保存幂等键（24小时过期）
     */
    private void saveIdempotent(String idempotentKey, String shortCode) {
        if (StringUtils.isNotBlank(idempotentKey)) {
            String key = IDEMPOTENT_PREFIX + idempotentKey;
            redisTemplate.opsForValue().set(key, shortCode, 24, TimeUnit.HOURS);
        }
    }

    private ShortUrlCreateResponse buildResponse(String shortCode, ShortUrl shortUrl) {
        ShortUrlCreateResponse response = new ShortUrlCreateResponse();
        response.setShortUrl(SHORT_URL_DOMAIN + shortCode);
        response.setShortCode(shortCode);
        response.setExpireTime(shortUrl != null ? shortUrl.getExpireTime() : null);
        return response;
    }
}
```

#### 6.2.2 跳转 Controller

```java
/**
 * 短链接跳转入口
 *
 * 全链路步骤：
 *   Nginx转发 → IP频率限制 → 布隆过滤器防穿透 → 多级缓存查询
 *   → 过期检查 → 续租判断 → 302重定向 → 异步访问统计
 */
@Slf4j
@RestController
public class RedirectController {

    @Autowired
    private ShortUrlRedirectFullLinkService redirectService;

    @Autowired
    private AntiTraversalService antiTraversalService;

    /**
     * 短链接跳转 — 302临时重定向
     *
     * 选择302而非301的原因：
     * - 301永久重定向，浏览器会缓存，后续访问不经过服务器，无法统计
     * - 302临时重定向，每次访问都经过服务器，可统计、可控制（过期/停用）
     */
    @GetMapping("/{shortCode:[0-9a-zA-Z]{6,8}}")
    public ResponseEntity<Void> redirect(
            @PathVariable String shortCode,
            HttpServletRequest request) {

        String clientIp = getClientIp(request);
        String userAgent = request.getHeader("User-Agent");
        String referer = request.getHeader("Referer");

        log.info("[短链接跳转] 收到请求, shortCode={}, clientIp={}, userAgent={}",
                shortCode, clientIp, userAgent);

        // 1. IP频率限制（防遍历攻击）
        if (!antiTraversalService.checkIpRate(clientIp)) {
            log.warn("[短链接跳转] IP频率超限, ip={}, shortCode={}", clientIp, shortCode);
            return ResponseEntity.status(HttpStatus.TOO_MANY_REQUESTS).build();
        }

        try {
            // 2. 执行跳转全链路
            RedirectContext context = new RedirectContext();
            context.setShortCode(shortCode);
            context.setClientIp(clientIp);
            context.setUserAgent(userAgent);
            context.setReferer(referer);

            String originalUrl = redirectService.resolve(context);

            if (originalUrl == null) {
                log.info("[短链接跳转] 短码不存在或已过期, shortCode={}", shortCode);
                return ResponseEntity.notFound().build();
            }

            // 3. 302重定向
            log.info("[短链接跳转] 重定向成功, shortCode={} → {}", shortCode, originalUrl);
            return ResponseEntity.status(HttpStatus.FOUND)
                    .header(HttpHeaders.LOCATION, originalUrl)
                    .header(HttpHeaders.CACHE_CONTROL, "no-cache, no-store")
                    .build();

        } catch (Exception e) {
            log.error("[短链接跳转] 系统异常, shortCode={}", shortCode, e);
            return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).build();
        }
    }

    private String getClientIp(HttpServletRequest request) {
        String ip = request.getHeader("X-Real-IP");
        if (ip == null || ip.isEmpty()) {
            ip = request.getHeader("X-Forwarded-For");
            if (ip != null && ip.contains(",")) {
                ip = ip.split(",")[0].trim();
            }
        }
        if (ip == null || ip.isEmpty()) {
            ip = request.getRemoteAddr();
        }
        return ip;
    }
}

/**
 * 跳转上下文（携带访问元信息，供统计使用）
 */
@Data
public class RedirectContext {
    private String shortCode;
    private String clientIp;
    private String userAgent;
    private String referer;
}
```

#### 6.2.3 核心服务：完整跳转链路

```java
/**
 * 短链接跳转全链路服务
 *
 * 查询链路：布隆过滤器 → 本地缓存(Caffeine) → Redis → MySQL
 * 附加处理：过期检查、续租、异步统计、缓存穿透防护
 */
@Slf4j
@Service
public class ShortUrlRedirectFullLinkService {

    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private ShortUrlMapper shortUrlMapper;
    @Autowired
    private BloomFilterService bloomFilter;
    @Autowired
    private AccessLogProducer accessLogProducer;

    private static final String CACHE_PREFIX = "shorturl:";
    // 缓存空值标记（防止穿透）
    private static final String NULL_VALUE = "<NULL>";
    private static final int NULL_CACHE_SECONDS = 300;

    // 学城文档续租阈值
    private static final int RENEW_THRESHOLD_DAYS = 30;
    private static final int RENEW_DAYS = 30;

    // 本地缓存：10万条，1秒过期（应对热点短链的瞬时高并发）
    private final Cache<String, String> localCache = Caffeine.newBuilder()
            .maximumSize(100_000)
            .expireAfterWrite(1, TimeUnit.SECONDS)
            .build();

    /**
     * 解析短码，返回原始URL
     *
     * @return 原始URL；null表示短码不存在或已过期
     */
    public String resolve(RedirectContext context) {
        String shortCode = context.getShortCode();

        // ===== 第一步：布隆过滤器防穿透 =====
        if (!bloomFilter.mightContain(shortCode)) {
            log.debug("[短链接跳转] 布隆过滤器拦截, shortCode={}", shortCode);
            return null;
        }

        // ===== 第二步：查本地缓存（Caffeine） =====
        String originalUrl = localCache.getIfPresent(shortCode);
        if (originalUrl != null) {
            if (NULL_VALUE.equals(originalUrl)) {
                return null; // 本地缓存的空值
            }
            // 命中本地缓存 → 异步统计 → 返回
            asyncRecordAccess(context);
            return originalUrl;
        }

        // ===== 第三步：查Redis缓存 =====
        String cacheKey = CACHE_PREFIX + shortCode;
        originalUrl = redisTemplate.opsForValue().get(cacheKey);
        if (originalUrl != null) {
            if (NULL_VALUE.equals(originalUrl)) {
                localCache.put(shortCode, NULL_VALUE);
                return null; // Redis缓存的空值（防穿透）
            }
            localCache.put(shortCode, originalUrl);
            asyncCheckAndRenew(shortCode);
            asyncRecordAccess(context);
            return originalUrl;
        }

        // ===== 第四步：缓存未命中，查数据库回源 =====
        log.info("[短链接跳转] 缓存未命中，查库回源, shortCode={}", shortCode);
        ShortUrl shortUrl = shortUrlMapper.selectByShortCode(shortCode);

        // 4a. 数据库中不存在
        if (shortUrl == null || shortUrl.getStatus() != 1) {
            log.info("[短链接跳转] 短码不存在, shortCode={}", shortCode);
            // 缓存空值5分钟（防穿透）
            redisTemplate.opsForValue().set(cacheKey, NULL_VALUE,
                    NULL_CACHE_SECONDS, TimeUnit.SECONDS);
            localCache.put(shortCode, NULL_VALUE);
            return null;
        }

        // 4b. 检查过期
        if (shortUrl.getExpireTime().before(new Date())) {
            log.info("[短链接跳转] 短链接已过期, shortCode={}, expireTime={}",
                    shortCode, shortUrl.getExpireTime());
            // 过期短链也缓存空值，避免反复穿透
            redisTemplate.opsForValue().set(cacheKey, NULL_VALUE,
                    NULL_CACHE_SECONDS, TimeUnit.SECONDS);
            localCache.put(shortCode, NULL_VALUE);
            return null;
        }

        // ===== 第五步：回填缓存 =====
        long remainingDays = calculateRemainingDays(shortUrl.getExpireTime());
        redisTemplate.opsForValue().set(cacheKey,
                shortUrl.getOriginalUrl(), remainingDays, TimeUnit.DAYS);
        localCache.put(shortCode, shortUrl.getOriginalUrl());

        // ===== 第六步：续租检查（学城文档续租策略） =====
        checkAndRenew(shortUrl);

        // ===== 第七步：异步访问统计 =====
        asyncRecordAccess(context);

        return shortUrl.getOriginalUrl();
    }

    /**
     * 学城文档续租策略：有效期低于30天且被访问时，自动续租30天
     */
    private void checkAndRenew(ShortUrl shortUrl) {
        long remainingDays = calculateRemainingDays(shortUrl.getExpireTime());

        if (remainingDays > 0 && remainingDays < RENEW_THRESHOLD_DAYS) {
            Date newExpireTime = DateUtils.addDays(shortUrl.getExpireTime(), RENEW_DAYS);
            int updated = shortUrlMapper.updateExpireTime(
                    shortUrl.getShortCode(), newExpireTime, shortUrl.getExpireTime());

            if (updated > 0) {
                // 更新缓存TTL
                String cacheKey = CACHE_PREFIX + shortUrl.getShortCode();
                long newRemainingDays = calculateRemainingDays(newExpireTime);
                redisTemplate.expire(cacheKey, newRemainingDays, TimeUnit.DAYS);

                log.info("[短链接跳转] 续租成功, shortCode={}, oldExpire={}, newExpire={}",
                        shortUrl.getShortCode(), shortUrl.getExpireTime(), newExpireTime);
            } else {
                // 乐观锁冲突（并发续租场景），忽略即可
                log.debug("[短链接跳转] 续租乐观锁冲突（已被其他线程续租）, shortCode={}",
                        shortUrl.getShortCode());
            }
        }
    }

    /**
     * 异步检查续租（Redis命中时调用，避免每次都查库）
     * 通过Redis TTL判断是否接近过期
     */
    private void asyncCheckAndRenew(String shortCode) {
        CompletableFuture.runAsync(() -> {
            try {
                String cacheKey = CACHE_PREFIX + shortCode;
                Long ttl = redisTemplate.getExpire(cacheKey, TimeUnit.DAYS);
                if (ttl != null && ttl > 0 && ttl < RENEW_THRESHOLD_DAYS) {
                    ShortUrl shortUrl = shortUrlMapper.selectByShortCode(shortCode);
                    if (shortUrl != null) {
                        checkAndRenew(shortUrl);
                    }
                }
            } catch (Exception e) {
                log.error("[短链接跳转] 异步续租异常, shortCode={}", shortCode, e);
            }
        });
    }

    /**
     * 异步记录访问日志（发送到Kafka，供统计消费）
     */
    private void asyncRecordAccess(RedirectContext context) {
        CompletableFuture.runAsync(() -> {
            try {
                AccessLogEvent event = new AccessLogEvent();
                event.setShortCode(context.getShortCode());
                event.setClientIp(context.getClientIp());
                event.setUserAgent(context.getUserAgent());
                event.setReferer(context.getReferer());
                event.setAccessTime(new Date());
                event.setEventId(UUID.randomUUID().toString());

                accessLogProducer.send(event);
            } catch (Exception e) {
                log.error("[短链接跳转] 异步统计写入失败, shortCode={}",
                        context.getShortCode(), e);
                // 统计失败不影响主链路
            }
        });
    }

    private long calculateRemainingDays(Date expireTime) {
        long diff = expireTime.getTime() - System.currentTimeMillis();
        return Math.max(1, diff / (1000L * 60 * 60 * 24));
    }
}
```

#### 6.3.3 Kafka 消费者：实时聚合统计

```java
/**
 * 访问日志Kafka消费者
 *
 * 消费链路：
 *   1. 反序列化事件
 *   2. 幂等检查（Redis SETNX eventId）
 *   3. 解析设备/地域信息
 *   4. 实时计数（Redis HyperLogLog + Hash）
 *   5. 写入明细表（供离线分析）
 *   6. 手动提交offset
 */
@Slf4j
@Component
public class AccessLogConsumer {

    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private AccessLogMapper accessLogMapper;

    private final ObjectMapper objectMapper = new ObjectMapper();

    private static final String IDEMPOTENT_PREFIX = "shorturl:stat:idempotent:";
    private static final String PV_PREFIX = "shorturl:stat:pv:";
    private static final String UV_PREFIX = "shorturl:stat:uv:";
    private static final String IP_PREFIX = "shorturl:stat:ip:";
    private static final String DEVICE_PREFIX = "shorturl:stat:device:";
    private static final String REGION_PREFIX = "shorturl:stat:region:";
    private static final String REFERER_PREFIX = "shorturl:stat:referer:";

    @KafkaListener(
            topics = "shorturl-access-log",
            groupId = "shorturl-stat-consumer",
            containerFactory = "manualAckListenerFactory"
    )
    public void consume(ConsumerRecord<String, String> record, Acknowledgment ack) {
        AccessLogEvent event = null;
        try {
            event = objectMapper.readValue(record.value(), AccessLogEvent.class);

            // ===== 第一步：幂等检查 =====
            if (!tryAcquireIdempotent(event.getEventId())) {
                log.debug("[访问统计] 重复事件，跳过, eventId={}", event.getEventId());
                ack.acknowledge();
                return;
            }

            // ===== 第二步：解析设备和地域信息 =====
            DeviceInfo deviceInfo = UserAgentParser.parse(event.getUserAgent());
            RegionInfo regionInfo = IpRegionParser.parse(event.getClientIp());

            // ===== 第三步：实时计数（Redis原子操作） =====
            String dateKey = formatDate(event.getAccessTime()); // yyyy-MM-dd
            String shortCode = event.getShortCode();

            updateRealtimeStats(shortCode, dateKey, event, deviceInfo, regionInfo);

            // ===== 第四步：写入明细表（供离线分析） =====
            saveAccessLog(event, deviceInfo, regionInfo);

            log.debug("[访问统计] 处理完成, eventId={}, shortCode={}",
                    event.getEventId(), shortCode);

        } catch (Exception e) {
            log.error("[访问统计] 消费异常, offset={}, eventId={}",
                    record.offset(),
                    event != null ? event.getEventId() : "unknown", e);
            // 异常不重试，写入死信队列由人工处理
        } finally {
            ack.acknowledge();
        }
    }

    /**
     * 幂等控制：Redis SETNX，24小时过期
     */
    private boolean tryAcquireIdempotent(String eventId) {
        String key = IDEMPOTENT_PREFIX + eventId;
        Boolean result = redisTemplate.opsForValue()
                .setIfAbsent(key, "1", 24, TimeUnit.HOURS);
        return Boolean.TRUE.equals(result);
    }

    /**
     * 更新实时统计数据（全部使用Redis原子操作）
     */
    private void updateRealtimeStats(String shortCode, String dateKey,
            AccessLogEvent event, DeviceInfo deviceInfo, RegionInfo regionInfo) {

        // PV：简单计数器
        String pvKey = PV_PREFIX + shortCode + ":" + dateKey;
        redisTemplate.opsForValue().increment(pvKey);
        redisTemplate.expire(pvKey, 90, TimeUnit.DAYS);

        // UV：HyperLogLog 基数估算（以客户端IP作为唯一标识）
        String uvKey = UV_PREFIX + shortCode + ":" + dateKey;
        redisTemplate.opsForHyperLogLog().add(uvKey, event.getClientIp());
        redisTemplate.expire(uvKey, 90, TimeUnit.DAYS);

        // 独立IP数：HyperLogLog
        String ipKey = IP_PREFIX + shortCode + ":" + dateKey;
        redisTemplate.opsForHyperLogLog().add(ipKey, event.getClientIp());
        redisTemplate.expire(ipKey, 90, TimeUnit.DAYS);

        // 设备分布：Hash { "iOS": 120, "Android": 85, "Windows": 200 }
        String deviceKey = DEVICE_PREFIX + shortCode + ":" + dateKey;
        redisTemplate.opsForHash().increment(deviceKey,
                deviceInfo.getOs(), 1);
        redisTemplate.expire(deviceKey, 90, TimeUnit.DAYS);

        // 地域分布：Hash { "北京": 300, "上海": 200 }
        String regionKey = REGION_PREFIX + shortCode + ":" + dateKey;
        redisTemplate.opsForHash().increment(regionKey,
                regionInfo.getProvince(), 1);
        redisTemplate.expire(regionKey, 90, TimeUnit.DAYS);

        // 来源渠道：Hash { "wechat": 500, "weibo": 120, "direct": 80 }
        String refererKey = REFERER_PREFIX + shortCode + ":" + dateKey;
        String channel = parseChannel(event.getReferer());
        redisTemplate.opsForHash().increment(refererKey, channel, 1);
        redisTemplate.expire(refererKey, 90, TimeUnit.DAYS);
    }

    /**
     * 写入访问明细表（供离线分析使用）
     */
    private void saveAccessLog(AccessLogEvent event,
            DeviceInfo deviceInfo, RegionInfo regionInfo) {
        AccessLog accessLog = new AccessLog();
        accessLog.setEventId(event.getEventId());
        accessLog.setShortCode(event.getShortCode());
        accessLog.setClientIp(event.getClientIp());
        accessLog.setProvince(regionInfo.getProvince());
        accessLog.setCity(regionInfo.getCity());
        accessLog.setDeviceType(deviceInfo.getDeviceType());
        accessLog.setOs(deviceInfo.getOs());
        accessLog.setBrowser(deviceInfo.getBrowser());
        accessLog.setReferer(event.getReferer());
        accessLog.setChannel(parseChannel(event.getReferer()));
        accessLog.setAccessTime(event.getAccessTime());
        accessLog.setCreateTime(new Date());

        accessLogMapper.insert(accessLog);
    }

    /**
     * 从Referer解析来源渠道
     */
    private String parseChannel(String referer) {
        if (StringUtils.isBlank(referer)) {
            return "direct";
        }
        String lower = referer.toLowerCase();
        if (lower.contains("weixin") || lower.contains("wechat")) return "wechat";
        if (lower.contains("weibo")) return "weibo";
        if (lower.contains("douyin") || lower.contains("tiktok")) return "douyin";
        if (lower.contains("baidu")) return "baidu";
        if (lower.contains("google")) return "google";
        return "other";
    }

    private String formatDate(Date date) {
        return new SimpleDateFormat("yyyy-MM-dd").format(date);
    }
}
```

#### 6.3.4 离线统计：定时汇总任务

```java
/**
 * 离线统计定时任务
 *
 * 每天凌晨2点执行，汇总前一天的访问明细为日维度统计报表
 * 离线统计是实时统计的补充，用于：
 *   - 修正HyperLogLog的估算误差
 *   - 生成精确的UV/IP去重数据
 *   - 计算复杂指标（新访客比例、跳出率等）
 */
@Slf4j
@Component
public class DailyStatAggregationJob {

    @Autowired
    private AccessLogMapper accessLogMapper;
    @Autowired
    private DailyStatMapper dailyStatMapper;
    @Autowired
    private StringRedisTemplate redisTemplate;

    private static final String LOCK_KEY = "shorturl:stat:daily-job-lock";

    /**
     * 每天凌晨2点执行（分布式锁保证单节点执行）
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void aggregateDailyStat() {
        // 分布式锁，防止多节点重复执行
        Boolean locked = redisTemplate.opsForValue()
                .setIfAbsent(LOCK_KEY, "1", 2, TimeUnit.HOURS);
        if (!Boolean.TRUE.equals(locked)) {
            log.info("[离线统计] 其他节点已在执行，跳过");
            return;
        }

        try {
            String yesterday = formatDate(DateUtils.addDays(new Date(), -1));
            log.info("[离线统计] 开始汇总, date={}", yesterday);

            // 查询前一天所有被访问的短码
            List<String> shortCodes = accessLogMapper
                    .selectDistinctShortCodes(yesterday);
            log.info("[离线统计] 待汇总短码数={}", shortCodes.size());

            int successCount = 0;
            int failCount = 0;

            for (String shortCode : shortCodes) {
                try {
                    aggregateForShortCode(shortCode, yesterday);
                    successCount++;
                } catch (Exception e) {
                    failCount++;
                    log.error("[离线统计] 单个短码汇总失败, shortCode={}, date={}",
                            shortCode, yesterday, e);
                }
            }

            log.info("[离线统计] 汇总完成, date={}, success={}, fail={}",
                    yesterday, successCount, failCount);

        } finally {
            redisTemplate.delete(LOCK_KEY);
        }
    }

    /**
     * 汇总单个短码的日统计数据
     */
    private void aggregateForShortCode(String shortCode, String dateStr) {
        // 从明细表精确统计
        long pv = accessLogMapper.countPv(shortCode, dateStr);
        long uv = accessLogMapper.countDistinctIp(shortCode, dateStr);
        Map<String, Long> regionDist = accessLogMapper
                .countGroupByProvince(shortCode, dateStr);
        Map<String, Long> deviceDist = accessLogMapper
                .countGroupByOs(shortCode, dateStr);
        Map<String, Long> channelDist = accessLogMapper
                .countGroupByChannel(shortCode, dateStr);

        // UPSERT 日统计表（幂等：重复执行覆盖更新）
        DailyStat stat = new DailyStat();
        stat.setShortCode(shortCode);
        stat.setStatDate(dateStr);
        stat.setPv(pv);
        stat.setUv(uv);
        stat.setRegionDistribution(toJson(regionDist));
        stat.setDeviceDistribution(toJson(deviceDist));
        stat.setChannelDistribution(toJson(channelDist));
        stat.setUpdateTime(new Date());

        dailyStatMapper.upsert(stat);
    }

    private String toJson(Object obj) {
        try {
            return new ObjectMapper().writeValueAsString(obj);
        } catch (JsonProcessingException e) {
            return "{}";
        }
    }

    private String formatDate(Date date) {
        return new SimpleDateFormat("yyyy-MM-dd").format(date);
    }
}
```

```java
/**
 * 统计查询服务
 */
@Slf4j
@Service
public class StatsQueryService {

    @Autowired
    private StringRedisTemplate redisTemplate;
    @Autowired
    private DailyStatMapper dailyStatMapper;

    private static final String PV_PREFIX = "shorturl:stat:pv:";
    private static final String UV_PREFIX = "shorturl:stat:uv:";
    private static final String DEVICE_PREFIX = "shorturl:stat:device:";
    private static final String REGION_PREFIX = "shorturl:stat:region:";
    private static final String REFERER_PREFIX = "shorturl:stat:referer:";

    /**
     * 查询统计概览
     *
     * 策略：当天数据从Redis实时统计读取，历史数据从MySQL离线统计读取
     */
    public StatsOverview query(String shortCode, String startDate, String endDate) {
        String today = new SimpleDateFormat("yyyy-MM-dd").format(new Date());

        StatsOverview overview = new StatsOverview();
        overview.setShortCode(shortCode);
        overview.setStartDate(startDate);
        overview.setEndDate(endDate);

        long totalPv = 0;
        long totalUv = 0;
        List<DailyStatDetail> dailyDetails = new ArrayList<>();
        Map<String, Long> mergedRegion = new HashMap<>();
        Map<String, Long> mergedDevice = new HashMap<>();
        Map<String, Long> mergedChannel = new HashMap<>();

        // 遍历日期范围
        List<String> dateRange = generateDateRange(startDate, endDate);
        for (String dateStr : dateRange) {
            DailyStatDetail detail;

            if (dateStr.equals(today)) {
                // 当天数据：从Redis实时读取
                detail = queryFromRedis(shortCode, dateStr);
            } else {
                // 历史数据：从MySQL离线统计读取
                detail = queryFromMySQL(shortCode, dateStr);
            }

            if (detail != null) {
                totalPv += detail.getPv();
                totalUv += detail.getUv();
                dailyDetails.add(detail);
                mergeDistribution(mergedRegion, detail.getRegionDistribution());
                mergeDistribution(mergedDevice, detail.getDeviceDistribution());
                mergeDistribution(mergedChannel, detail.getChannelDistribution());
            }
        }

        overview.setTotalPv(totalPv);
        overview.setTotalUv(totalUv);
        overview.setDailyDetails(dailyDetails);
        overview.setRegionDistribution(mergedRegion);
        overview.setDeviceDistribution(mergedDevice);
        overview.setChannelDistribution(mergedChannel);

        return overview;
    }

    /**
     * 从Redis读取实时统计（当天数据）
     */
    private DailyStatDetail queryFromRedis(String shortCode, String dateStr) {
        DailyStatDetail detail = new DailyStatDetail();
        detail.setDate(dateStr);

        // PV
        String pvStr = redisTemplate.opsForValue().get(PV_PREFIX + shortCode + ":" + dateStr);
        detail.setPv(pvStr != null ? Long.parseLong(pvStr) : 0);

        // UV（HyperLogLog基数估算）
        Long uvCount = redisTemplate.opsForHyperLogLog()
                .size(UV_PREFIX + shortCode + ":" + dateStr);
        detail.setUv(uvCount != null ? uvCount : 0);

        // 设备分布
        Map<Object, Object> deviceMap = redisTemplate.opsForHash()
                .entries(DEVICE_PREFIX + shortCode + ":" + dateStr);
        detail.setDeviceDistribution(convertMap(deviceMap));

        // 地域分布
        Map<Object, Object> regionMap = redisTemplate.opsForHash()
                .entries(REGION_PREFIX + shortCode + ":" + dateStr);
        detail.setRegionDistribution(convertMap(regionMap));

        // 渠道分布
        Map<Object, Object> channelMap = redisTemplate.opsForHash()
                .entries(REFERER_PREFIX + shortCode + ":" + dateStr);
        detail.setChannelDistribution(convertMap(channelMap));

        return detail;
    }

    /**
     * 从MySQL读取离线统计（历史数据）
     */
    private DailyStatDetail queryFromMySQL(String shortCode, String dateStr) {
        DailyStat stat = dailyStatMapper.selectByCodeAndDate(shortCode, dateStr);
        if (stat == null) {
            return null;
        }
        DailyStatDetail detail = new DailyStatDetail();
        detail.setDate(dateStr);
        detail.setPv(stat.getPv());
        detail.setUv(stat.getUv());
        detail.setRegionDistribution(parseJson(stat.getRegionDistribution()));
        detail.setDeviceDistribution(parseJson(stat.getDeviceDistribution()));
        detail.setChannelDistribution(parseJson(stat.getChannelDistribution()));
        return detail;
    }

    private Map<String, Long> convertMap(Map<Object, Object> raw) {
        Map<String, Long> result = new HashMap<>();
        raw.forEach((k, v) -> result.put(
                k.toString(), Long.parseLong(v.toString())));
        return result;
    }

    @SuppressWarnings("unchecked")
    private Map<String, Long> parseJson(String json) {
        if (StringUtils.isBlank(json)) return Collections.emptyMap();
        try {
            return new ObjectMapper().readValue(json, Map.class);
        } catch (Exception e) {
            return Collections.emptyMap();
        }
    }

    private void mergeDistribution(Map<String, Long> target, Map<String, Long> source) {
        if (source != null) {
            source.forEach((k, v) -> target.merge(k, v, Long::sum));
        }
    }

    private List<String> generateDateRange(String start, String end) {
        List<String> dates = new ArrayList<>();
        try {
            SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd");
            Date startDate = sdf.parse(start);
            Date endDate = sdf.parse(end);
            Date current = startDate;
            while (!current.after(endDate)) {
                dates.add(sdf.format(current));
                current = DateUtils.addDays(current, 1);
            }
        } catch (ParseException e) {
            throw new IllegalArgumentException("日期格式非法，应为yyyy-MM-dd");
        }
        return dates;
    }
}
```

### 6.5 全链路关键设计总结

| 设计要点 | 生成链路 | 跳转链路 | 统计链路 |
|---------|---------|---------|--------|
| 幂等控制 | idempotentKey + MD5查重 | 续租乐观锁 | eventId SETNX |
| 异常处理 | 发号器冲突重试、DuplicateKey捕获 | 缓存穿透空值回填 | 消费异常不阻塞队列 |
| 日志记录 | 每步关键节点打日志 | IP/UA/Referer完整记录 | 事件全链路可追踪 |
| 缓存策略 | 生成时预热Redis | 三级缓存(Caffeine→Redis→DB) + TTL续期 | 实时Redis + 离线MySQL |
| 安全防护 | 白名单 + URL合法性 + 长度限制 | IP限频 + 布隆过滤器 | 幂等 + 分布式锁 |
| 性能优化 | 号段双Buffer本地分配 | Caffeine 1秒热点缓存 | HyperLogLog近似UV |
