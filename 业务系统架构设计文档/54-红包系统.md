# 红包系统架构设计

## 一、问题背景

### 1.1 业务场景

红包系统是社交+金融场景下的经典系统。用户发起一个红包，将一定金额拆分成多份，群内其他用户抢红包，每人随机获得不同金额。典型场景包括群红包、拼手气红包、专属红包等。

一个完整的红包生命周期：用户发红包（支付资金→拆分金额→写入红包）→ 群内用户抢红包（并发抢→随机取一份→入账）→ 24小时未抢完自动退回。

### 1.2 核心挑战

| 挑战维度 | 具体问题 | 影响 |
|---------|---------|------|
| 拆分公平性 | 随机拆分要保证每个人抢到的金额相对公平 | 体验差、投诉 |
| 并发抢红包 | 100人群同时抢，如何保证不超抢、不重抢 | 资金损失 |
| 资金安全 | 发红包的钱要冻结，抢到的钱要入账，中间不能出错 | 资金损失 |
| 过期退回 | 24小时未抢完的金额要原路退回 | 用户投诉 |
| 防刷 | 黄牛用外挂抢红包 | 不公平 |
| 高性能 | 春节红包峰值QPS可达千万级 | 系统宕机 |

### 1.3 设计目标

| 目标维度 | 具体要求 |
|---------|---------|
| 抢红包响应 | P99 < 50ms |
| 并发安全 | 绝不超抢、不重抢 |
| 资金一致性 | 发→抢→退 全链路资金一分不差 |
| 可用性 | 99.99% |
| 防刷 | 识别并拦截外挂 |

## 三、核心链路设计

### 3.1 红包拆分算法：二倍均值法

**问题**：将100元拆成10份，要求随机且公平。如果用纯随机，可能第一个人抢到99元，后面的人只能抢到几分钱，体验极差。

**方案**：二倍均值法——每次抢的金额在 [0.01, 剩余金额/剩余人数×2 - 0.01] 之间随机。

**算法原理**：
- 假设剩余金额为 M，剩余人数为 N
- 每次抢的金额 = 随机值 × (M/N × 2)，范围在 [0.01, M/N×2 - 0.01]
- 期望值 = M/N，即每个人期望抢到平均金额
- 最后一个人抢到剩余全部金额

```java
/**
 * 红包拆分算法：二倍均值法
 * 
 * 示例：100元分10份
 * 第1次：剩余100元/10人，均值10元，二倍均值20元，随机[0.01, 19.99] → 假设抢到15元
 * 第2次：剩余85元/9人，均值9.44元，二倍均值18.88元，随机[0.01, 18.87] → 假设抢到8元
 * ...以此类推，最后一人抢到剩余全部
 */
public class RedPacketSplitter {

    private static final int MIN_AMOUNT = 1;  // 最小金额1分

    /**
     * 拆分红包
     * @param totalAmount 总金额（分）
     * @param totalCount 总份数
     * @return 拆分后的金额列表
     */
    public static List<Integer> split(int totalAmount, int totalCount) {
        if (totalAmount < totalCount * MIN_AMOUNT) {
            throw new BizException("总金额不足以分配");
        }

        List<Integer> amounts = new ArrayList<>(totalCount);
        int remainingAmount = totalAmount;
        int remainingCount = totalCount;

        Random random = new Random();

        for (int i = 0; i < totalCount - 1; i++) {
            // 二倍均值：本次最大金额 = 剩余金额/剩余人数 × 2 - 1
            int maxAmount = remainingAmount / remainingCount * 2 - MIN_AMOUNT;
            if (maxAmount <= MIN_AMOUNT) {
                maxAmount = MIN_AMOUNT;
            }

            // 随机金额：[MIN_AMOUNT, maxAmount]
            int amount = random.nextInt(maxAmount) + MIN_AMOUNT;

            // 确保剩余金额够后面的人分（每人至少1分）
            int minRemaining = (remainingCount - 1) * MIN_AMOUNT;
            if (remainingAmount - amount < minRemaining) {
                amount = remainingAmount - minRemaining;
            }

            amounts.add(amount);
            remainingAmount -= amount;
            remainingCount--;
        }

        // 最后一个人抢到剩余全部
        amounts.add(remainingAmount);

        // 打乱顺序，避免拆分顺序影响抢红包顺序
        Collections.shuffle(amounts);

        return amounts;
    }
}
```

### 3.2 发红包链路

**完整流程**：用户发起红包 → 支付扣款 → 资金冻结 → 拆分金额 → 写入Redis → 异步落库 → 通知群内用户

```java
/**
 * 发红包服务
 * 
 * 链路：
 * 1. 参数校验（金额/份数合法性）
 * 2. 调用支付渠道扣款
 * 3. 资金冻结（从用户余额冻结到红包中间账户）
 * 4. 拆分金额（二倍均值法）
 * 5. 写入Redis（红包信息+金额列表+状态）
 * 6. 异步写入MySQL
 * 7. 发送群通知
 */
@Service
public class RedPacketSendService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private WalletFeignClient walletClient;

    @Autowired
    private RocketMQTemplate mqTemplate;

    public SendResult send(SendRedPacketRequest request, Long senderId) {
        // 1. 参数校验
        int totalAmount = request.getTotalAmount();  // 分
        int totalCount = request.getTotalCount();
        if (totalAmount < totalCount) {
            throw new BizException("单份金额不能少于1分");
        }
        if (totalCount > 100) {
            throw new BizException("红包份数不能超过100");
        }

        // 2. 生成红包ID
        long redPacketId = idGenerator.nextId();

        // 3. 调用钱包冻结资金
        FreezeRequest freezeReq = new FreezeRequest();
        freezeReq.setUserId(senderId);
        freezeReq.setAmount(totalAmount);
        freezeReq.setBizId(String.valueOf(redPacketId));
        freezeReq.setBizType("RED_PACKET");
        walletClient.freeze(freezeReq);

        // 4. 拆分金额
        List<Integer> amounts = RedPacketSplitter.split(totalAmount, totalCount);

        // 5. 写入Redis
        // 5.1 红包基本信息
        String infoKey = "redpacket:" + redPacketId;
        Map<String, String> info = new HashMap<>();
        info.put("senderId", String.valueOf(senderId));
        info.put("totalAmount", String.valueOf(totalAmount));
        info.put("totalCount", String.valueOf(totalCount));
        info.put("grabbedCount", "0");
        info.put("grabbedAmount", "0");
        info.put("status", "ISSUED");
        info.put("createTime", String.valueOf(System.currentTimeMillis()));
        info.put("expireTime", String.valueOf(
            System.currentTimeMillis() + 24 * 3600 * 1000)); // 24小时过期
        redisTemplate.opsForHash().putAll(infoKey, info);
        redisTemplate.expire(infoKey, 25, TimeUnit.HOURS);

        // 5.2 金额列表（用List存储，RPUSH写入，LPOP弹出）
        String amountsKey = "redpacket:amounts:" + redPacketId;
        for (Integer amount : amounts) {
            redisTemplate.opsForList().rightPush(amountsKey, String.valueOf(amount));
        }
        redisTemplate.expire(amountsKey, 25, TimeUnit.HOURS);

        // 5.3 已抢用户Set初始化为空
        String grabbedKey = "redpacket:grabbed:" + redPacketId;
        redisTemplate.expire(grabbedKey, 25, TimeUnit.HOURS);

        // 6. 异步写入MySQL
        RedPacketMessage msg = new RedPacketMessage();
        msg.setRedPacketId(redPacketId);
        msg.setSenderId(senderId);
        msg.setTotalAmount(totalAmount);
        msg.setTotalCount(totalCount);
        msg.setAmounts(amounts);
        msg.setCreateTime(System.currentTimeMillis());
        mqTemplate.asyncSend("redpacket-create-topic", msg, new SendCallback() {
            @Override
            public void onSuccess(SendResult r) {
                log.info("红包创建MQ发送成功, id={}", redPacketId);
            }
            @Override
            public void onException(Throwable e) {
                log.error("红包创建MQ失败, id={}", redPacketId, e);
            }
        });

        // 7. 发送群通知（省略）
        return SendResult.success(redPacketId);
    }
}
```

### 3.3 抢红包链路（核心）

**问题**：100人同时抢一个红包，如何保证每个人抢到的金额不重复、不超抢？

**方案**：Redis Lua脚本原子操作——检查是否已抢 → 检查红包是否还有剩余 → 从金额列表弹出一个 → 记录已抢用户 → 更新红包计数。

```java
/**
 * 抢红包服务
 * 
 * 完整链路：
 * 1. 风控检查（频率/设备/黑名单）
 * 2. Lua脚本原子操作：
 *    a. 检查是否已抢过（Set中是否已有该用户）
 *    b. 检查红包状态是否为ISSUED
 *    c. 检查金额列表是否还有剩余
 *    d. 从List中LPOP一个金额
 *    e. SADD记录已抢用户
 *    f. 更新红包Hash中的grabbedCount和grabbedAmount
 *    g. 如果抢完了，更新状态为FINISHED
 * 3. 异步入账（MQ通知钱包系统加钱）
 * 4. 异步落库
 */
@Service
public class RedPacketGrabService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private RiskControlFeignClient riskClient;

    @Autowired
    private RocketMQTemplate mqTemplate;

    /**
     * Lua脚本：原子性抢红包
     * KEYS[1] = 红包信息Hash: redpacket:{id}
     * KEYS[2] = 金额列表List: redpacket:amounts:{id}
     * KEYS[3] = 已抢用户Set: redpacket:grabbed:{id}
     * ARGV[1] = userId
     * ARGV[2] = currentTime
     * 
     * 返回值：
     *   正数 = 抢到的金额（分）
     *   -1 = 已抢过
     *   -2 = 红包已过期/已抢完
     *   -3 = 手慢了，红包已被抢完
     */
    private static final String GRAB_LUA =
        // 1. 检查是否已抢过
        "if redis.call('SISMEMBER', KEYS[3], ARGV[1]) == 1 then\n" +
        "    return -1\n" +
        "end\n" +
        // 2. 检查红包状态
        "local status = redis.call('HGET', KEYS[1], 'status')\n" +
        "if status ~= 'ISSUED' then\n" +
        "    return -2\n" +
        "end\n" +
        // 3. 从金额列表弹出一个
        "local amount = redis.call('LPOP', KEYS[2])\n" +
        "if not amount then\n" +
        "    return -3\n" +
        "end\n" +
        // 4. 记录已抢用户
        "redis.call('SADD', KEYS[3], ARGV[1])\n" +
        // 5. 更新红包计数
        "local grabbedCount = tonumber(redis.call('HINCRBY', KEYS[1], 'grabbedCount', 1))\n" +
        "local grabbedAmount = tonumber(redis.call('HINCRBY', KEYS[1], 'grabbedAmount', tonumber(amount)))\n" +
        // 6. 如果抢完了，更新状态
        "local totalCount = tonumber(redis.call('HGET', KEYS[1], 'totalCount'))\n" +
        "if grabbedCount >= totalCount then\n" +
        "    redis.call('HSET', KEYS[1], 'status', 'FINISHED')\n" +
        "end\n" +
        // 7. 返回抢到的金额
        "return tonumber(amount)\n";

    public GrabResult grab(Long redPacketId, Long userId, String deviceId) {
        // 1. 风控检查
        RiskResult risk = riskClient.check(userId, deviceId, "RED_PACKET_GRAB");
        if (risk.isBlocked()) {
            return GrabResult.fail("操作频繁，请稍后再试");
        }

        // 2. Lua脚本原子抢红包
        String infoKey = "redpacket:" + redPacketId;
        String amountsKey = "redpacket:amounts:" + redPacketId;
        String grabbedKey = "redpacket:grabbed:" + redPacketId;

        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(GRAB_LUA);
        script.setResultType(Long.class);

        Long result = redisTemplate.execute(script,
            Arrays.asList(infoKey, amountsKey, grabbedKey),
            String.valueOf(userId),
            String.valueOf(System.currentTimeMillis()));

        // 3. 处理结果
        if (result == null) {
            return GrabResult.fail("系统异常");
        }
        if (result == -1L) {
            return GrabResult.fail("您已经抢过该红包");
        }
        if (result == -2L) {
            return GrabResult.fail("红包已过期");
        }
        if (result == -3L) {
            return GrabResult.fail("手慢了，红包已被抢完");
        }

        int grabbedAmount = result.intValue();

        // 4. 异步入账（MQ通知钱包系统加钱）
        GrabMessage msg = new GrabMessage();
        msg.setRedPacketId(redPacketId);
        msg.setUserId(userId);
        msg.setAmount(grabbedAmount);
        msg.setGrabTime(System.currentTimeMillis());

        mqTemplate.asyncSend("redpacket-grab-topic", msg, new SendCallback() {
            @Override
            public void onSuccess(SendResult r) {
                log.info("抢红包MQ发送成功, redPacketId={}, userId={}, amount={}",
                    redPacketId, userId, grabbedAmount);
            }
            @Override
            public void onException(Throwable e) {
                // MQ失败不影响用户体验，有对账兜底
                log.error("抢红包MQ失败, redPacketId={}, userId={}",
                    redPacketId, userId, e);
            }
        });

        return GrabResult.success(grabbedAmount);
    }
}
```

### 3.4 抢红包入账消费者

```java
/**
 * 抢红包入账消费者
 * 
 * 消费流程：
 * 1. 从MQ拉取抢红包消息
 * 2. 幂等检查（防止重复入账）
 * 3. 调用钱包系统入账（从冻结资金扣减→加到用户余额）
 * 4. 写入抢红包明细表
 */
@Component
@RocketMQMessageListener(topic = "redpacket-grab-topic",
    consumerGroup = "redpacket-grab-consumer-group")
public class RedPacketGrabConsumer implements RocketMQListener<GrabMessage> {

    @Autowired
    private WalletFeignClient walletClient;

    @Autowired
    private RedPacketGrabRecordMapper grabRecordMapper;

    @Override
    public void onMessage(GrabMessage msg) {
        // 1. 幂等检查
        RedPacketGrabRecord exist = grabRecordMapper.selectByRedPacketAndUser(
            msg.getRedPacketId(), msg.getUserId());
        if (exist != null) {
            return; // 已处理
        }

        // 2. 调用钱包系统：从红包发送者的冻结资金中扣减，加到抢红包用户的余额
        TransferRequest transfer = new TransferRequest();
        transfer.setFromUserId(msg.getSenderId());  // 发红包人
        transfer.setToUserId(msg.getUserId());       // 抢红包人
        transfer.setAmount(msg.getAmount());
        transfer.setBizId(msg.getRedPacketId() + "_" + msg.getUserId());
        transfer.setBizType("RED_PACKET_GRAB");
        walletClient.transferFromFrozen(transfer);

        // 3. 写入抢红包明细
        RedPacketGrabRecord record = new RedPacketGrabRecord();
        record.setRedPacketId(msg.getRedPacketId());
        record.setUserId(msg.getUserId());
        record.setAmount(msg.getAmount());
        record.setGrabTime(new Date(msg.getGrabTime()));
        grabRecordMapper.insert(record);

        log.info("抢红包入账成功, redPacketId={}, userId={}, amount={}",
            msg.getRedPacketId(), msg.getUserId(), msg.getAmount());
    }
}
```

### 3.5 红包过期退回

**问题**：红包发出24小时后如果还有人没抢，剩余金额需要退回给发送者。

**方案**：延时任务扫描 + 原子退回。

```java
/**
 * 红包过期退回服务
 * 
 * 退回流程：
 * 1. 定时任务扫描已过期但未退回的红包
 * 2. 检查红包状态是否为ISSUED（还有未抢的）
 * 3. 统计剩余金额（总金额 - 已抢金额）
 * 4. 调用钱包系统解冻退回
 * 5. 更新红包状态为REFUNDED
 */
@Service
public class RedPacketExpireService {

    @Autowired
    private StringRedisTemplate redisTemplate;

    @Autowired
    private WalletFeignClient walletClient;

    /**
     * 定时扫描过期红包（每分钟执行）
     */
    @Scheduled(fixedRate = 60000)
    public void scanExpiredRedPackets() {
        // 1. 从MySQL查询已过期但状态仍为ISSUED的红包
        List<RedPacketDO> expired = redPacketMapper.selectExpiredIssued(
            System.currentTimeMillis());

        for (RedPacketDO redPacket : expired) {
            try {
                refundExpiredRedPacket(redPacket);
            } catch (Exception e) {
                log.error("红包退回失败, id={}", redPacket.getId(), e);
            }
        }
    }

    /**
     * 退回单个过期红包
     */
    @Transactional(rollbackFor = Exception.class)
    public void refundExpiredRedPacket(RedPacketDO redPacket) {
        String infoKey = "redpacket:" + redPacket.getId();

        // 1. 原子性更新状态为EXPIRED（防止并发）
        String luaScript =
            "local status = redis.call('HGET', KEYS[1], 'status')\n" +
            "if status ~= 'ISSUED' then\n" +
            "    return 0\n" +  // 状态不对，可能已被处理
            "end\n" +
            "redis.call('HSET', KEYS[1], 'status', 'EXPIRED')\n" +
            "return 1\n";

        DefaultRedisScript<Long> script = new DefaultRedisScript<>();
        script.setScriptText(luaScript);
        script.setResultType(Long.class);

        Long result = redisTemplate.execute(script,
            Collections.singletonList(infoKey));

        if (result == null || result == 0L) {
            return; // 已被处理
        }

        // 2. 计算剩余金额
        int totalAmount = redPacket.getTotalAmount();
        int grabbedAmount = Integer.parseInt(
            (String) redisTemplate.opsForHash().get(infoKey, "grabbedAmount"));
        int refundAmount = totalAmount - grabbedAmount;

        if (refundAmount <= 0) {
            // 全部抢完了，直接标记完成
            redisTemplate.opsForHash().put(infoKey, "status", "FINISHED");
            redPacketMapper.updateStatus(redPacket.getId(), "FINISHED");
            return;
        }

        // 3. 调用钱包系统解冻退回
```

```java
/**
 * 红包金额分片
 * 将一个红包的金额列表拆分到多个Redis实例
 */
public void sendWithSharding(long redPacketId, List<Integer> amounts) {
    int shardCount = 4;  // 分4片
    int perShard = amounts.size() / shardCount;
    
    for (int i = 0; i < shardCount; i++) {
        int start = i * perShard;
        int end = (i == shardCount - 1) ? amounts.size() : (i + 1) * perShard;
        List<Integer> shard = amounts.subList(start, end);
        
        String shardKey = "redpacket:amounts:" + redPacketId + ":" + i;
        for (Integer amount : shard) {
            redisTemplate.opsForList().rightPush(shardKey, String.valueOf(amount));
        }
    }
    
    // 记录分片信息
    redisTemplate.opsForHash().put("redpacket:" + redPacketId,
        "shardCount", String.valueOf(shardCount));
}
```

## 六、最佳实践与总结

### 6.1 核心设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 拆分算法 | 二倍均值法 | 公平性好，期望值均等 |
| 抢红包 | Redis Lua原子操作 | 防超抢/重抢，高性能 |
| 资金管理 | 冻结→扣减→入账三阶段 | 资金安全 |
| 过期退回 | 定时任务扫描 | 简单可靠 |
| 异步落库 | MQ异步 | 不阻塞抢红包主流程 |
| 对账 | 每日全量对账 | 兜底保障 |

### 6.2 容易踩的坑

1. **拆分算法不公平**：纯随机导致第一个抢的人拿走大部分，必须用二倍均值法
2. **并发超抢**：没用Lua原子操作，检查和扣减之间有间隙，导致超抢
3. **重复抢**：忘记SISMEMBER检查已抢用户
4. **资金不一致**：抢红包MQ消息丢失，导致Redis扣了但钱包没入账，必须对账
5. **过期退回并发**：定时任务退回的同时用户还在抢，必须用Lua原子更新状态
6. **热点红包**：春晚级别红包单key扛不住，需要分片

#### 7.1.3 红包金额拆分算法（二倍均值法完整实现）

```java
/**
 * 红包拆分算法：二倍均值法（生产级完整实现）
 * 
 * 核心原理：
 *   每次拆分时，当前金额的随机范围为 [1分, 剩余金额/剩余人数 × 2 - 1分]
 *   期望值 = 剩余金额/剩余人数，保证公平性
 *   最后一份 = 剩余全部金额
 *
 * 边界处理：
 *   - 总金额 < 份数 × 1分 → 拒绝
 *   - 份数 = 1 → 全部给唯一一份
 *   - 拆分后打乱顺序，避免顺序偏差
 */
public class RedPacketSplitter {

    private static final int MIN_AMOUNT = 1;  // 最小金额1分
    private static final int MAX_SINGLE_AMOUNT = 2000000;  // 单份最大20000元

    private static final ThreadLocalRandom RANDOM = ThreadLocalRandom.current();

    /**
     * 拆分红包
     *
     * @param totalAmount 总金额（分）
     * @param totalCount  总份数
     * @return 拆分后的金额列表，顺序已打乱
     * @throws BizException 参数不合法
     */
    public static List<Integer> split(int totalAmount, int totalCount) {
        // ── 参数校验 ──
        if (totalAmount <= 0) {
            throw new BizException("INVALID_AMOUNT", "总金额必须大于0");
        }
        if (totalCount <= 0) {
            throw new BizException("INVALID_COUNT", "红包个数必须大于0");
        }
        if (totalAmount < totalCount * MIN_AMOUNT) {
            throw new BizException("AMOUNT_TOO_SMALL",
                String.format("总金额不足，%d份至少需要%d分", totalCount, totalCount * MIN_AMOUNT));
        }

        // ── 特殊情况：只有1份 ──
        if (totalCount == 1) {
            return Collections.singletonList(totalAmount);
        }

        // ── 特殊情况：均分（金额刚好等于份数，每人1分）──
        if (totalAmount == totalCount * MIN_AMOUNT) {
            List<Integer> result = new ArrayList<>(totalCount);
            for (int i = 0; i < totalCount; i++) {
                result.add(MIN_AMOUNT);
            }
            return result;
        }

        // ── 二倍均值法拆分 ──
        List<Integer> amounts = new ArrayList<>(totalCount);
        int remainingAmount = totalAmount;
        int remainingCount = totalCount;

        for (int i = 0; i < totalCount - 1; i++) {
            // 二倍均值：本次最大金额 = 剩余金额 / 剩余人数 × 2 - 1
            int maxAmount = (remainingAmount / remainingCount) * 2 - MIN_AMOUNT;

            // 边界保护：确保最小值为1分
            if (maxAmount < MIN_AMOUNT) {
                maxAmount = MIN_AMOUNT;
            }

            // 确保本次金额不超过单份上限
            maxAmount = Math.min(maxAmount, MAX_SINGLE_AMOUNT);

            // 确保剩余金额够后面的人分（每人至少1分）
            int minRemaining = (remainingCount - 1) * MIN_AMOUNT;
            int maxAllowed = remainingAmount - minRemaining;
            maxAmount = Math.min(maxAmount, maxAllowed);

            // 随机金额：[MIN_AMOUNT, maxAmount]
            int amount = RANDOM.nextInt(MIN_AMOUNT, maxAmount + 1);

            amounts.add(amount);
            remainingAmount -= amount;
            remainingCount--;
        }

        // 最后一个人抢到剩余全部
        amounts.add(remainingAmount);

        // 打乱顺序，避免拆分顺序影响抢红包顺序
        Collections.shuffle(amounts);

        // ── 校验拆分结果 ──
        int sum = amounts.stream().mapToInt(Integer::intValue).sum();
        if (sum != totalAmount) {
            // 理论上不会出现，防御性编程
            throw new IllegalStateException(
                String.format("拆分金额校验失败: sum=%d, expected=%d", sum, totalAmount));
        }

        return amounts;
    }
}
```

```java
@Slf4j
public class RedPacketSendService {

    public SendRedPacketResponse executeSend(SendRedPacketRequest request,

                                             String deviceId) {
        int totalAmount = request.getTotalAmount();
        int totalCount = request.getTotalCount();

        // ── 步骤3：拆分金额 ──
        List<Integer> amounts = RedPacketSplitter.split(totalAmount, totalCount);
        log.info("红包拆分完成, redPacketId={}, amounts={}", redPacketId, amounts);

        writeRedPacketToRedis(redPacketId, senderId, request, amounts);

        // ── 步骤5：异步写入MySQL（通过MQ）──
        RedPacketCreateMessage msg = RedPacketCreateMessage.builder()
            .redPacketId(redPacketId)
            .senderId(senderId)
            .type(request.getType())
            .totalAmount(totalAmount)
            .totalCount(totalCount)
            .amounts(amounts)
            .greeting(request.getGreeting())
            .targetId(request.getTargetId())
            .createTime(System.currentTimeMillis())
            .build();

        try {
            mqTemplate.syncSend("redpacket-create-topic", msg);
            log.info("红包创建MQ发送成功, redPacketId={}", redPacketId);
        } catch (Exception e) {
            // MQ发送失败不阻断主流程，Redis已有数据，后续对账补偿
            log.error("红包创建MQ发送失败, redPacketId={}, 依赖对账补偿", redPacketId, e);
        }

        // ── 步骤6：红包消息推送到群聊/个人 ──
        pushRedPacketMessage(redPacketId, senderId, request);

        // ── 步骤7：创建24小时过期延迟任务 ──
        scheduleExpireTask(redPacketId);

        return SendRedPacketResponse.builder()
            .redPacketId(redPacketId)
            .totalAmount(totalAmount)
            .totalCount(totalCount)
            .build();
    }

    /**
     * 写入Redis
     */
    private void writeRedPacketToRedis(long redPacketId, Long senderId,
                                       SendRedPacketRequest request,
                                       List<Integer> amounts) {
        long now = System.currentTimeMillis();
        long expireTime = now + 24 * 3600 * 1000L;

        // 4.1 红包基本信息 Hash
        String infoKey = "redpacket:" + redPacketId;
        Map<String, String> info = new HashMap<>();
        info.put("senderId", String.valueOf(senderId));
        info.put("totalAmount", String.valueOf(request.getTotalAmount()));
        info.put("totalCount", String.valueOf(request.getTotalCount()));
        info.put("grabbedCount", "0");
        info.put("grabbedAmount", "0");
        info.put("status", "ISSUED");
        info.put("type", request.getType().name());
        info.put("greeting", request.getGreeting());
        info.put("createTime", String.valueOf(now));
        info.put("expireTime", String.valueOf(expireTime));

        // Pipeline 批量写入
        redisTemplate.executePipelined((RedisCallback<Void>) connection -> {
            // 写 Hash
            byte[] infoKeyBytes = infoKey.getBytes();
            for (Map.Entry<String, String> entry : info.entrySet()) {
                connection.hSet(infoKeyBytes,
                    entry.getKey().getBytes(),
                    entry.getValue().getBytes());
            }
            connection.expire(infoKeyBytes, 25 * 3600);  // 25小时过期

            // 写金额列表
            String amountsKey = "redpacket:amounts:" + redPacketId;
            byte[] amountsKeyBytes = amountsKey.getBytes();
            for (Integer amount : amounts) {
                connection.rPush(amountsKeyBytes, String.valueOf(amount).getBytes());
            }
```

#### 7.2.2 红包状态校验（本地缓存预检查 + Redis 校验）

```java
/**
 * 抢红包门面服务
 */
@Service
@Slf4j
public class RedPacketGrabFacadeService {

    @Autowired private RedPacketAntiFraudService antiFraudService;
    @Autowired private RedPacketGrabService grabService;
    @Autowired private StringRedisTemplate redisTemplate;

    // 本地缓存：红包状态（1秒TTL，减少Redis访问）
    private final Cache<Long, String> statusCache = Caffeine.newBuilder()
        .maximumSize(50000)
        .expireAfterWrite(1, TimeUnit.SECONDS)
        .build();

    public GrabRedPacketResponse grab(Long redPacketId, Long userId, String deviceId) {
        // ── 步骤1：本地缓存预检查（快速失败）──
        String cachedStatus = statusCache.getIfPresent(redPacketId);
        if ("FINISHED".equals(cachedStatus)) {
            return GrabRedPacketResponse.fail("LATE", "手慢了，红包已被抢完");
        }
        if ("EXPIRED".equals(cachedStatus) || "REFUNDED".equals(cachedStatus)) {
            return GrabRedPacketResponse.fail("EXPIRED", "红包已过期");
        }

        // ── 步骤2：防刷风控检查 ──
        boolean pass = antiFraudService.check(userId, deviceId, redPacketId);
        if (!pass) {
            return GrabRedPacketResponse.fail("RISK_BLOCKED", "操作频繁，请稍后再试");
        }

        // ── 步骤3：Redis Lua 原子抢红包 ──
        GrabResult result = grabService.grab(redPacketId, userId, deviceId);

        // ── 步骤4：处理结果 ──
        if (result.isFail()) {
            // 缓存失败状态，快速拒绝后续请求
            if (result.getCode() == -3) {
                statusCache.put(redPacketId, "FINISHED");
            } else if (result.getCode() == -2) {
                statusCache.put(redPacketId, "EXPIRED");
            }
            return GrabRedPacketResponse.fail(
                String.valueOf(result.getCode()), result.getMsg());
        }

        // ── 步骤5：实时推送抢红包结果 ──
        grabService.pushGrabResult(redPacketId, userId, result.getAmount());

        return GrabRedPacketResponse.success(result.getAmount());
    }
}
```

#### 7.2.3 Redis + Lua 原子抢红包（核心）

```java
/**
 * 抢红包核心服务
 *
 * 并发安全设计：
 *   1. 防重复抢：Lua脚本中 SISMEMBER 检查已抢用户Set
 *   2. 防超发：Lua脚本中 LPOP 原子弹出金额，弹完即止
 *   3. 原子性：整个检查-弹出-记录操作在一个Lua脚本中执行，Redis单线程保证原子
 */
@Service
@Slf4j
public class RedPacketGrabService {

    @Autowired private StringRedisTemplate redisTemplate;
    @Autowired private RocketMQTemplate mqTemplate;
    @Autowired private MessagePushFeignClient messageClient;

    /**
     * Lua脚本：原子性抢红包
     *
     * KEYS[1] = 红包信息Hash: redpacket:{id}
     * KEYS[2] = 金额列表List: redpacket:amounts:{id}
     * KEYS[3] = 已抢用户Set: redpacket:grabbed:{id}
     * ARGV[1] = userId
     * ARGV[2] = currentTime（用于过期检查）
     *
     * 返回值：
     *   正数  = 抢到的金额（分）
     *   -1   = 已抢过（重复抢）
     *   -2   = 红包已过期/状态不对
     *   -3   = 手慢了，红包已被抢完
     */
    private static final String GRAB_LUA =
        // 1. 检查是否已抢过（防重复抢）
        "if redis.call('SISMEMBER', KEYS[3], ARGV[1]) == 1 then\n" +
        "    return -1\n" +
        "end\n" +
        // 2. 检查红包状态
        "local status = redis.call('HGET', KEYS[1], 'status')\n" +
        "if status ~= 'ISSUED' then\n" +
        "    return -2\n" +
        "end\n" +
        // 3. 检查是否过期
        "local expireTime = tonumber(redis.call('HGET', KEYS[1], 'expireTime'))\n" +
        "if tonumber(ARGV[2]) > expireTime then\n" +
        "    redis.call('HSET', KEYS[1], 'status', 'EXPIRED')\n" +
        "    return -2\n" +
        "end\n" +
        // 4. 从金额列表原子弹出一个（防超发）
        "local amount = redis.call('LPOP', KEYS[2])\n" +
        "if not amount then\n" +
        "    return -3\n" +
        "end\n" +
        // 5. 记录已抢用户（防重复抢）
        "redis.call('SADD', KEYS[3], ARGV[1])\n" +
        // 6. 更新红包计数
        "local grabbedCount = tonumber(redis.call('HINCRBY', KEYS[1], 'grabbedCount', 1))\n" +
        "local grabbedAmount = tonumber(redis.call('HINCRBY', KEYS[1], 'grabbedAmount', tonumber(amount)))\n" +
        // 7. 如果抢完了，更新状态为FINISHED
        "local totalCount = tonumber(redis.call('HGET', KEYS[1], 'totalCount'))\n" +
        "if grabbedCount >= totalCount then\n" +
        "    redis.call('HSET', KEYS[1], 'status', 'FINISHED')\n" +
        "end\n" +
        // 8. 返回抢到的金额
        "return tonumber(amount)\n";

    private DefaultRedisScript<Long> grabScript;

    @PostConstruct
    public void init() {
        grabScript = new DefaultRedisScript<>();
        grabScript.setScriptText(GRAB_LUA);
        grabScript.setResultType(Long.class);
    }

    /**
     * 抢红包
     */
    public GrabResult grab(Long redPacketId, Long userId, String deviceId) {
        String infoKey = "redpacket:" + redPacketId;
        String amountsKey = "redpacket:amounts:" + redPacketId;
        String grabbedKey = "redpacket:grabbed:" + redPacketId;

        Long result;
        try {
            result = redisTemplate.execute(grabScript,
                Arrays.asList(infoKey, amountsKey, grabbedKey),
                String.valueOf(userId),
                String.valueOf(System.currentTimeMillis()));
        } catch (Exception e) {
            log.error("Lua抢红包异常, redPacketId={}, userId={}", redPacketId, userId, e);
            return GrabResult.fail(-99, "系统繁忙");
        }

        if (result == null) {
            log.error("Lua抢红包返回null, redPacketId={}, userId={}", redPacketId, userId);
            return GrabResult.fail(-99, "系统异常");
        }

        if (result == -1L) {
            return GrabResult.fail(-1, "您已经抢过该红包");
        }
        if (result == -2L) {
            return GrabResult.fail(-2, "红包已过期");
        }
        if (result == -3L) {
            return GrabResult.fail(-3, "手慢了，红包已被抢完");
        }
        if (result <= 0) {
            log.error("Lua抢红包返回异常值, redPacketId={}, userId={}, result={}",
                redPacketId, userId, result);
            return GrabResult.fail(-99, "系统异常");
        }

        int grabbedAmount = result.intValue();

        // ── 异步入库：发送MQ消息 ──
        sendGrabMessage(redPacketId, userId, grabbedAmount);

        log.info("抢红包成功(Lua), redPacketId={}, userId={}, amount={}",
            redPacketId, userId, grabbedAmount);

        return GrabResult.success(grabbedAmount);
    }

    /**
     * 发送抢红包MQ消息（异步入库 + 入账）
     */
    private void sendGrabMessage(Long redPacketId, Long userId, int amount) {
        GrabMessage msg = GrabMessage.builder()
            .redPacketId(redPacketId)
            .userId(userId)
            .amount(amount)
            .grabTime(System.currentTimeMillis())
            .msgId(redPacketId + "_" + userId)  // 幂等键
            .build();

        try {
            mqTemplate.asyncSend("redpacket-grab-topic", msg, new SendCallback() {
                @Override
                public void onSuccess(SendResult r) {
                    log.debug("抢红包MQ发送成功, redPacketId={}, userId={}",
                        redPacketId, userId);
                }

                @Override
                public void onException(Throwable e) {
                    // MQ失败不影响用户体验，Redis已扣减，有对账兜底
                    log.error("抢红包MQ发送失败, redPacketId={}, userId={}, 依赖对账补偿",
                        redPacketId, userId, e);
                }
            });
        } catch (Exception e) {
            log.error("抢红包MQ发送异常, redPacketId={}, userId={}", redPacketId, userId, e);
        }
    }

    /**
     * 实时推送抢红包结果到群聊
     */
    public void pushGrabResult(Long redPacketId, Long userId, int amount) {
        try {
            // 查红包信息获取targetId和senderId
            String infoKey = "redpacket:" + redPacketId;
            String targetId = (String) redisTemplate.opsForHash().get(infoKey, "targetId");
            String senderId = (String) redisTemplate.opsForHash().get(infoKey, "senderId");

            GrabNotifyMessage notify = GrabNotifyMessage.builder()
                .redPacketId(redPacketId)
                .userId(userId)
                .amount(amount)
                .targetId(targetId != null ? Long.valueOf(targetId) : null)
                .build();

            messageClient.pushGrabResult(notify);
        } catch (Exception e) {
            log.warn("抢红包结果推送失败, redPacketId={}, userId={}, 不影响主流程",
                redPacketId, userId, e);
        }
    }
}
```

#### 7.2.4 异步入库：MQ消费端写入领取记录、更新红包状态、入账

```java
/**
 * 抢红包入账消费者
 *
 * 消费流程：
 *   1. 幂等检查（防止重复入账）
 *   2. 调用钱包系统：从冻结资金转账到抢红包用户余额
 *   3. 写入抢红包明细表
 *   4. 更新红包主表的已抢计数
 *   5. 异常重试 + 死信处理
 */
@Component
@RocketMQMessageListener(topic = "redpacket-grab-topic",
    consumerGroup = "redpacket-grab-consumer-group",
    maxReconsumeTimes = 3)  // 最多重试3次
@Slf4j
public class RedPacketGrabConsumer implements RocketMQListener<GrabMessage> {

    @Autowired private WalletFeignClient walletClient;
    @Autowired private RedPacketGrabRecordMapper grabRecordMapper;
    @Autowired private RedPacketMapper redPacketMapper;
    @Autowired private RedPacketItemMapper itemMapper;
    @Autowired private AlertService alertService;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void onMessage(GrabMessage msg) {
        log.info("消费抢红包消息, redPacketId={}, userId={}, amount={}, msgId={}",
            msg.getRedPacketId(), msg.getUserId(), msg.getAmount(), msg.getMsgId());

        // ── 步骤1：幂等检查（防止重复入账）──
        RedPacketGrabRecord existRecord = grabRecordMapper.selectByRedPacketAndUser(
            msg.getRedPacketId(), msg.getUserId());
        if (existRecord != null) {
            log.info("抢红包记录已存在，幂等跳过, redPacketId={}, userId={}",
                msg.getRedPacketId(), msg.getUserId());
            return;
        }

        // ── 步骤2：调用钱包系统入账（从冻结资金转账）──
        TransferRequest transfer = TransferRequest.builder()
            .fromUserId(msg.getSenderId())   // 发红包人（冻结账户）
            .toUserId(msg.getUserId())        // 抢红包人
            .amount(msg.getAmount())
            .bizId(msg.getRedPacketId() + "_" + msg.getUserId())  // 幂等键
            .bizType("RED_PACKET_GRAB")
            .build();

        TransferResult transferResult;
        try {
            transferResult = walletClient.transferFromFrozen(transfer);
        } catch (Exception e) {
            log.error("钱包入账调用失败, redPacketId={}, userId={}, 将重试",
                msg.getRedPacketId(), msg.getUserId(), e);
            throw e;  // 抛出异常触发MQ重试
        }

        if (!transferResult.isSuccess()) {
            // 钱包系统返回业务失败（如余额不足等），不重试，记录告警
            log.error("钱包入账业务失败, redPacketId={}, userId={}, errCode={}, errMsg={}",
                msg.getRedPacketId(), msg.getUserId(),
                transferResult.getErrCode(), transferResult.getErrMsg());
            alertService.send("抢红包入账失败",
                msg.getRedPacketId(), msg.getUserId(), msg.getAmount());
            return;
        }

        // ── 步骤3：写入抢红包明细表 ──
        RedPacketGrabRecord record = new RedPacketGrabRecord();
        record.setId(idGenerator.nextId());
        record.setRedPacketId(msg.getRedPacketId());
        record.setUserId(msg.getUserId());
        record.setAmount(msg.getAmount());
        record.setGrabTime(new Date(msg.getGrabTime()));
        record.setCreateTime(new Date());
        grabRecordMapper.insert(record);

        // ── 步骤4：更新红包主表计数 ──
        redPacketMapper.incrGrabbedCount(msg.getRedPacketId(), msg.getAmount());

        log.info("抢红包入账完成, redPacketId={}, userId={}, amount={}",
            msg.getRedPacketId(), msg.getUserId(), msg.getAmount());
    }
}
```

```
│  ...                                                             │
│  T11: UserK grab ───────> Lua执行: LPOP(nil) → return -3         │
│  T12: UserL grab ───────> Lua执行: status=FINISHED → return -2   │
│                                                                  │
│  关键点：                                                         │
│  1. Lua脚本在Redis中原子执行，不会被其他命令打断                   │
│  2. SISMEMBER 防重复抢：同一用户第二次请求直接返回-1              │
│  3. LPOP 防超发：金额列表弹完即止，第11个人返回-3                 │
│  4. HINCRBY 原子更新计数，不需要额外锁                           │
└──────────────────────────────────────────────────────────────────┘
```

### 7.3 案例三：红包过期退款全链路

#### 7.3.1 延迟任务触发（RocketMQ延迟消息 + 定时任务双重保障）

```java
/**
 * 红包过期检查消费者
 *
 * 触发方式：
 *   1. RocketMQ延迟消息：发红包时创建，每10分钟检查一次是否过期
 *   2. 定时任务扫描：每分钟扫描MySQL中已过期但未退款的红包（兜底）
 */
@Component
@RocketMQMessageListener(topic = "redpacket-expire-check-topic",
    consumerGroup = "redpacket-expire-check-consumer-group")
@Slf4j
public class RedPacketExpireCheckConsumer implements RocketMQListener<RedPacketExpireMessage> {

    @Autowired private RedPacketExpireService expireService;
    @Autowired private RocketMQTemplate mqTemplate;

    @Override
    public void onMessage(RedPacketExpireMessage msg) {
        long redPacketId = msg.getRedPacketId();
        log.info("收到红包过期检查消息, redPacketId={}", redPacketId);

        try {
            boolean expired = expireService.checkAndRefund(redPacketId);

            if (!expired) {
                // 还没过期，发送下一个检查消息（10分钟后）
                RedPacketExpireMessage next = RedPacketExpireMessage.builder()
                    .redPacketId(redPacketId)
                    .checkTime(System.currentTimeMillis() + 10 * 60 * 1000L)
                    .build();
                mqTemplate.syncSend("redpacket-expire-check-topic", next);
                log.debug("红包未过期，重新调度检查, redPacketId={}", redPacketId);
            }
        } catch (Exception e) {
            log.error("红包过期检查异常, redPacketId={}", redPacketId, e);
        }
    }
}

/**
 * 定时任务兜底扫描（每分钟执行）
 */
@Component
@Slf4j
public class RedPacketExpireScheduler {

    @Autowired private RedPacketExpireService expireService;
    @Autowired private RedPacketMapper redPacketMapper;

    @Scheduled(fixedRate = 60000)
    public void scanExpiredRedPackets() {
        long now = System.currentTimeMillis();
        List<RedPacketDO> expired = redPacketMapper.selectExpiredAndNotRefunded(now, 100);

        if (expired.isEmpty()) {
            return;
        }

        log.info("扫描到过期红包{}个", expired.size());

        for (RedPacketDO rp : expired) {
            try {
                expireService.checkAndRefund(rp.getId());
            } catch (Exception e) {
                log.error("定时任务退款失败, redPacketId={}", rp.getId(), e);
            }
        }
    }
}
```

#### 7.3.2 过期退款完整服务（检查剩余金额、退款、更新状态、通知）

```java
/**
 * 红包过期退款服务
 *
 * 退款流程：
 *   1. Lua原子检查并更新红包状态：ISSUED → EXPIRED（防止并发）
 *   2. 计算剩余金额 = 总金额 - 已抢金额
 *   3. 调用钱包系统解冻退回
 *   4. 更新Redis和MySQL状态为REFUNDED
 *   5. 推送退款通知
 *
 * 幂等控制：
 *   - Lua脚本原子更新状态，只有ISSUED才能变为EXPIRED
 *   - 钱包系统通过bizId幂等
 *   - MySQL状态机保证不重复退款
 */
@Service
@Slf4j
public class RedPacketExpireService {

    @Autowired private StringRedisTemplate redisTemplate;
    @Autowired private WalletFeignClient walletClient;
    @Autowired private RedPacketMapper redPacketMapper;
    @Autowired private RedPacketItemMapper itemMapper;
    @Autowired private MessagePushFeignClient messageClient;
    @Autowired private AlertService alertService;

    /**
     * Lua脚本：原子性检查并更新状态
     *
     * KEYS[1] = 红包信息Hash: redpacket:{id}
     * ARGV[1] = currentTime
     *
     * 返回值：
     *   1  = 成功标记为EXPIRED
     *   0  = 状态不对（已被处理或已抢完）
     *   -1 = 还未过期
     */
    private static final String EXPIRE_LUA =
        "local status = redis.call('HGET', KEYS[1], 'status')\n" +
        "if status ~= 'ISSUED' then\n" +
        "    return 0\n" +
        "end\n" +
        "local expireTime = tonumber(redis.call('HGET', KEYS[1], 'expireTime'))\n" +
        "if tonumber(ARGV[1]) < expireTime then\n" +
        "    return -1\n" +
        "end\n" +
        "redis.call('HSET', KEYS[1], 'status', 'EXPIRED')\n" +
        "return 1\n";

    private DefaultRedisScript<Long> expireScript;

    @PostConstruct
    public void init() {
        expireScript = new DefaultRedisScript<>();
        expireScript.setScriptText(EXPIRE_LUA);
        expireScript.setResultType(Long.class);
    }

    /**
     * 检查并退款
     * @return true=已过期并处理完成, false=还未过期
     */
    public boolean checkAndRefund(Long redPacketId) {
        String infoKey = "redpacket:" + redPacketId;

        // ── 步骤1：Lua原子检查并标记EXPIRED ──
        Long result;
        try {
            result = redisTemplate.execute(expireScript,
                Collections.singletonList(infoKey),
                String.valueOf(System.currentTimeMillis()));
        } catch (Exception e) {
            log.error("Lua过期检查异常, redPacketId={}", redPacketId, e);
            return false;
        }

        if (result == null || result == 0L) {
            log.info("红包状态非ISSUED，可能已处理, redPacketId={}", redPacketId);
            return true;  // 已被处理
        }
        if (result == -1L) {
            // 还未过期
            return false;
        }

        // ── 步骤2：获取红包信息，计算剩余金额 ──
        RedPacketDO redPacket = redPacketMapper.selectById(redPacketId);
        if (redPacket == null) {
            log.error("红包记录不存在, redPacketId={}", redPacketId);
            return true;
        }

        int totalAmount = redPacket.getTotalAmount();
        int grabbedAmount = redPacket.getGrabbedAmount() != null
            ? redPacket.getGrabbedAmount() : 0;
        int refundAmount = totalAmount - grabbedAmount;

        log.info("红包过期退款计算, redPacketId={}, total={}, grabbed={}, refund={}",
            redPacketId, totalAmount, grabbedAmount, refundAmount);

        if (refundAmount <= 0) {
            // 全部抢完了，直接标记FINISHED
            updateStatus(redPacketId, "FINISHED", 0);
            log.info("红包已全部抢完，标记FINISHED, redPacketId={}", redPacketId);
            return true;
        }

        // ── 步骤3：调用钱包系统解冻退回 ──
        UnfreezeRequest unfreeze = UnfreezeRequest.builder()
            .userId(redPacket.getSenderId())
            .amount(refundAmount)
            .bizId(String.valueOf(redPacketId))       // 幂等键
            .bizType("RED_PACKET_REFUND")
            .build();

        UnfreezeResult unfreezeResult;
        try {
            unfreezeResult = walletClient.unfreeze(unfreeze);
        } catch (Exception e) {
            // 退款失败，回滚Redis状态为ISSUED，等待下次重试
            log.error("钱包解冻失败, redPacketId={}, 回滚Redis状态等待重试",
                redPacketId, e);
            redisTemplate.opsForHash().put(infoKey, "status", "ISSUED");
            alertService.send("红包退款失败", redPacketId, refundAmount);
            return true;
        }

        if (!unfreezeResult.isSuccess()) {
            log.error("钱包解冻业务失败, redPacketId={}, errCode={}, errMsg={}",
                redPacketId, unfreezeResult.getErrCode(), unfreezeResult.getErrMsg());
            redisTemplate.opsForHash().put(infoKey, "status", "ISSUED");
            alertService.send("红包退款业务失败", redPacketId, refundAmount);
            return true;
        }

        // ── 步骤4：更新红包状态为REFUNDED（Redis + MySQL）──
        updateStatus(redPacketId, "REFUNDED", refundAmount);

        // 更新未抢的子红包记录状态
        itemMapper.updateUngrabbedToRefunded(redPacketId);

        log.info("红包过期退款完成, redPacketId={}, refundAmount={}",
            redPacketId, refundAmount);

        // ── 步骤5：推送退款通知 ──
        pushRefundNotification(redPacket, refundAmount);

        return true;
    }

    /**
     * 更新红包状态（Redis + MySQL 双写）
     */
    private void updateStatus(Long redPacketId, String status, int refundAmount) {
        // 更新Redis
        String infoKey = "redpacket:" + redPacketId;
        redisTemplate.opsForHash().put(infoKey, "status", status);
        if (refundAmount > 0) {
            redisTemplate.opsForHash().put(infoKey, "refundAmount",
                String.valueOf(refundAmount));
        }

        // 更新MySQL
        RedPacketDO update = new RedPacketDO();
        update.setId(redPacketId);
        update.setStatus(status);
        update.setRefundAmount(refundAmount);
        update.setRefundTime(new Date());
        redPacketMapper.updateById(update);
    }

    /**
     * 推送退款通知
     */
    private void pushRefundNotification(RedPacketDO redPacket, int refundAmount) {
        try {
            RefundNotifyMessage notify = RefundNotifyMessage.builder()
                .userId(redPacket.getSenderId())
                .redPacketId(redPacket.getId())
                .refundAmount(refundAmount)
                .build();

            messageClient.pushRefundNotification(notify);
            log.info("退款通知推送成功, redPacketId={}, userId={}, refundAmount={}",
                redPacket.getId(), redPacket.getSenderId(), refundAmount);
        } catch (Exception e) {
            log.warn("退款通知推送失败, redPacketId={}, 不影响主流程",
                redPacket.getId(), e);
        }
    }
}
```

#### 7.3.4 异常处理与幂等控制汇总

```java
/**
 * 红包系统全局异常处理与幂等控制策略汇总
 */

// ─── 1. 发红包链路异常处理 ───
//
// 异常场景                        处理策略
// ──────────────────────────── ──────────────────────────────
// 支付密码错误                    返回错误，不冻结资金
// 余额不足                        返回错误，不冻结资金
// 风控拦截                        返回错误，不冻结资金
// 资金冻结成功但后续流程失败       自动补偿解冻，资金原路退回
// MQ发送失败(落库消息)            不阻断主流程，Redis已有数据，对账补偿
// MQ发送失败(过期检查消息)        不阻断主流程，定时任务兜底扫描

// ─── 2. 抢红包链路异常处理 ───
//
// 异常场景                        处理策略
// ──────────────────────────── ──────────────────────────────
// 风控拦截                        返回"操作频繁"，不进入抢红包流程
// Lua脚本执行异常                 返回"系统繁忙"，Redis状态不变
// MQ发送失败(入账消息)            不影响用户抢红包结果，对账补偿入账
// 钱包入账失败(消费端)            MQ重试3次 → 死信队列 → 告警人工介入
// 重复消费(MQ重试)                幂等检查：selectByRedPacketAndUser，已存在则跳过

// ─── 3. 过期退款链路异常处理 ───
//
// 异常场景                        处理策略
// ──────────────────────────── ──────────────────────────────
// 钱包解冻失败                    回滚Redis状态为ISSUED，等待下次重试
// 重复触发退款(延迟消息+定时任务)  Lua原子更新状态，只有ISSUED→EXPIRED成功
// 钱包系统bizId幂等               同一redPacketId的unfreeze只执行一次
// MySQL状态机                     状态只能单向流转，不会重复退款

// ─── 4. 幂等控制设计 ───
//
// 环节                    幂等键                    实现方式
// ────────────────── ──────────────────────── ──────────────────
// 发红包资金冻结          redPacketId             钱包系统bizId去重
// 抢红包(防重复抢)        redPacketId+userId      Redis SISMEMBER
// 抢红包入账              redPacketId+userId      MySQL唯一索引 + 查重
// 钱包转账                redPacketId+userId      钱包系统bizId去重
// 过期退款                redPacketId             Lua原子状态机 + 钱包bizId
// 红包落库                redPacketId             MySQL主键 + 查重

// ─── 5. 对账兜底（最终一致性保障）───
//
// 对账公式：红包总金额 = 已抢金额合计 + 退款金额
// 执行频率：每天凌晨2点全量对账 + 每10分钟增量对账
// 异常处理：发现不一致 → 告警 → 人工介入
```
