# 直播系统后端架构设计

## 一、问题背景

### 1.1 业务场景与挑战

直播作为一种实时音视频交互形式，已经渗透到电商带货、在线教育、秀场娱乐、企业培训等多个业务领域。一个完整的直播系统后端需要解决以下核心问题：

- **高并发推拉流**：热门直播间可能有数十万甚至百万级观众同时在线，系统需要支撑海量并发的拉流请求，同时保证推流端的稳定性
- **低延迟传输**：端到端延迟直接影响用户体验，直播场景下典型延迟需控制在 3~5 秒以内，连麦场景更需要控制在 400ms 以内
- **弹幕与互动消息的实时分发**：直播间内弹幕、点赞、礼物等互动消息需要毫秒级分发到全部在线用户
- **礼物打赏的资金安全**：涉及真实金额的扣款操作，需要保证并发扣款的一致性与幂等性
- **在线人数统计的准确性与内存效率**：百万级用户的去重计数不能简单使用 Set 存储
- **直播录制与回放**：直播结束后需要提供完整的回放能力，包括视频流与弹幕的时间轴对齐
- **CDN 调度与容灾**：融合多家 CDN 进行智能调度，确保全国范围内推拉流的流畅度

### 1.2 典型业务流程

一次完整的直播生命周期涵盖以下阶段：

```
主播创建直播间 → 配置直播参数 → 获取推流地址 → 开始推流 → 观众进入拉流 
→ 弹幕/礼物/连麦互动 → 主播结束直播 → 生成回放 → 观众点播回看
```

### 1.3 设计目标

| 指标 | 目标值 |
|------|--------|
| 端到端延迟（单向直播） | < 5 秒 |
| 端到端延迟（连麦场景） | < 400ms |
| 首帧耗时 | < 500ms |
| 5 分钟卡顿率 | < 10% |
| 同时推流能力 | > 10000 路 |
| 同时在线观看 | > 100000 路 |
| 推流成功率 | > 99.9% |
| 系统可用性 | > 99.995% |

## 三、核心链路设计

### 3.1 推拉流架构（RTMP推流 → 转码 → HTTP-FLV/HLS拉流）

#### 3.1.1 推流链路详细设计

推流链路是直播系统的核心数据通路，主播端采集的音视频数据通过该链路到达源站服务器。

**完整推流流程：**

1. 主播端向业务后台请求推流地址
2. 业务后台调用推流调度服务，调度服务根据主播 IP 确定运营商和地理位置
3. 调度服务选择最优推流边缘节点，调用鉴权模块生成流名称和认证码
4. 组装完整推流 URL 返回给主播端：`rtmp://edge-ip:1935/live/stream_name?token=xxx&expire=yyy`
5. 主播端通过 RTMP 协议向边缘节点推流
6. 边缘节点向鉴权模块校验流名称和认证码
7. 鉴权通过后，边缘节点将流转发到源站服务器集群
8. 源站服务器进行 HLS 切片、转码和收录

**推流调度核心算法：**

```java
/**
 * 推流调度服务
 * 根据主播的运营商和地理位置选择最优推流节点
 */
@Service
public class StreamScheduleService {

    @Autowired
    private IpLocationService ipLocationService;
    
    @Autowired
    private EdgeNodeManager edgeNodeManager;
    
    @Autowired
    private StreamAuthService streamAuthService;

    /**
     * 为主播分配推流地址
     * @param anchorId 主播ID
     * @param clientIp 主播客户端IP
     * @return 推流URL
     */
    public PublishUrlResult allocatePublishUrl(Long anchorId, String clientIp) {
        // Step1: 解析主播IP的运营商和地理位置
        IpLocation location = ipLocationService.resolve(clientIp);
        String isp = location.getIsp();          // 运营商：电信/联通/移动
        String province = location.getProvince(); // 省份
        String city = location.getCity();          // 城市
        
        // Step2: 根据调度策略选择推流边缘节点
        // 优先同运营商+就近接入原则
        EdgeNode selectedNode = edgeNodeManager.selectOptimalNode(isp, province, city);
        
        // Step3: 生成流名称和鉴权码
        String streamName = generateStreamName(anchorId);
        String token = streamAuthService.generateToken(streamName);
        long expireTime = System.currentTimeMillis() / 1000 + 7200; // 2小时过期
        
        // Step4: 组装推流URL
        String publishUrl = String.format("rtmp://%s:%d/live/%s?token=%s&expire=%d",
                selectedNode.getIp(), selectedNode.getPort(),
                streamName, token, expireTime);
        
        return new PublishUrlResult(publishUrl, streamName, selectedNode.getNodeId());
    }

    /**
     * 生成全局唯一的流名称
     * 格式: {业务标识}_{主播ID}_{时间戳}_{随机数}
     */
    private String generateStreamName(Long anchorId) {
        return String.format("live_%d_%d_%s",
                anchorId,
                System.currentTimeMillis(),
                RandomStringUtils.randomAlphanumeric(8));
    }
}
```

**边缘节点选择策略实现：**

```java
/**
 * 推流边缘节点管理器
 * 实现多CDN融合调度
 */
@Component
public class EdgeNodeManager {

    /**
     * CDN调度配置：不同地区使用不同CDN
     * key: 省份_运营商, value: CDN提供商列表（按优先级排序）
     */
    private final Map<String, List<CdnProvider>> scheduleConfig = new ConcurrentHashMap<>();

    /**
     * 所有边缘节点的健康状态
     */
    private final Map<String, EdgeNodeHealth> nodeHealthMap = new ConcurrentHashMap<>();

    /**
     * 选择最优推流边缘节点
     */
    public EdgeNode selectOptimalNode(String isp, String province, String city) {
        // 1. 构建调度键：省份_运营商
        String scheduleKey = province + "_" + isp;
        List<CdnProvider> providers = scheduleConfig.getOrDefault(
                scheduleKey, scheduleConfig.get("default"));

        // 2. 遍历候选CDN提供商，选择健康且负载最低的节点
        for (CdnProvider provider : providers) {
            List<EdgeNode> candidateNodes = provider.getEdgeNodes().stream()
                    .filter(node -> isNodeHealthy(node.getNodeId()))
                    .filter(node -> isNodeLoadAcceptable(node.getNodeId()))
                    .sorted(Comparator.comparingDouble(
                            node -> getNodeLoad(node.getNodeId())))
                    .collect(Collectors.toList());

            if (!candidateNodes.isEmpty()) {
                // 加权随机选择，避免热点集中
                return weightedRandomSelect(candidateNodes);
            }
        }

        // 3. 兜底：选择任意可用节点
        throw new ScheduleException("No available edge node for: " + scheduleKey);
    }

    /**
     * 加权随机选择节点
     * 权重与节点剩余容量成正比
     */
    private EdgeNode weightedRandomSelect(List<EdgeNode> nodes) {
        double totalWeight = nodes.stream()
                .mapToDouble(n -> 1.0 - getNodeLoad(n.getNodeId()))
                .sum();
        double random = ThreadLocalRandom.current().nextDouble(totalWeight);
        double cumulative = 0;
        for (EdgeNode node : nodes) {
            cumulative += (1.0 - getNodeLoad(node.getNodeId()));
            if (random <= cumulative) {
                return node;
            }
        }
        return nodes.get(0);
    }

    private boolean isNodeHealthy(String nodeId) {
        EdgeNodeHealth health = nodeHealthMap.get(nodeId);
        return health != null && health.isHealthy();
    }

    private boolean isNodeLoadAcceptable(String nodeId) {
        return getNodeLoad(nodeId) < 0.85; // 负载超过85%不再分配
    }

    private double getNodeLoad(String nodeId) {
        EdgeNodeHealth health = nodeHealthMap.get(nodeId);
        return health != null ? health.getLoadFactor() : 1.0;
    }
}
```

**推流鉴权模块：**

```java
/**
 * 推流鉴权服务
 * 统一生成和校验推流名称与认证码
 */
@Service
public class StreamAuthService {

    private static final String AUTH_SECRET = "stream_auth_secret_key";

    /**
     * 生成推流认证令牌
     * 算法: MD5(streamName + secret + expireTime)
     */
    public String generateToken(String streamName) {
        long expireTime = System.currentTimeMillis() / 1000 + 7200;
        String raw = streamName + AUTH_SECRET + expireTime;
        return DigestUtils.md5Hex(raw);
    }

    /**
     * 校验推流认证令牌
     * 边缘节点收到推流请求后调用此方法
     */
    public boolean verifyToken(String streamName, String token, long expireTime) {
        // 检查是否过期
        if (System.currentTimeMillis() / 1000 > expireTime) {
            return false;
        }
        // 重新计算token进行比对
        String raw = streamName + AUTH_SECRET + expireTime;
        String expectedToken = DigestUtils.md5Hex(raw);
        return expectedToken.equals(token);
    }

    /**
     * 使某个流的认证码失效（用于禁播）
     */
    public void invalidateStream(String streamName) {
        // 将流名称加入黑名单，后续推流请求会被拒绝
        redisTemplate.opsForSet().add("stream:blacklist", streamName);
        redisTemplate.expire("stream:blacklist", 24, TimeUnit.HOURS);
    }
}
```

#### 3.1.2 拉流链路详细设计

拉流链路负责将源站的音视频流分发到观众端，支持 RTMP、HTTP-FLV、HLS 三种协议。

**各协议特点对比：**

| 协议 | 延迟 | 兼容性 | 特点 |
|------|------|--------|------|
| RTMP | 1~3 秒 | 需Flash/专用播放器 | 延迟最低，但浏览器兼容性差 |
| HTTP-FLV | 2~4 秒 | 需flv.js等组件 | 基于HTTP长连接，兼容性好 |
| HLS | 10~30 秒 | 原生H5支持 | 跨平台最好，延迟较高 |

**播放调度服务：**

```java
/**
 * 播放调度服务
 * 根据观众的运营商、地理位置和请求协议分配最优播放地址
 */
@Service
public class PlayScheduleService {

    @Autowired
    private IpLocationService ipLocationService;

    @Autowired
    private CdnDispatcher cdnDispatcher;

    /**
     * 为观众分配播放地址
     * @param streamName 流名称
     * @param clientIp 观众IP
     * @param protocol 请求的播放协议
     * @return 播放URL
     */
    public PlayUrlResult allocatePlayUrl(String streamName, String clientIp,
                                          StreamProtocol protocol) {
        IpLocation location = ipLocationService.resolve(clientIp);

        // 根据协议生成不同格式的播放URL
        String playUrl;
        switch (protocol) {
            case RTMP:
                playUrl = buildRtmpPlayUrl(streamName, location);
                break;
            case HTTP_FLV:
                playUrl = buildHttpFlvPlayUrl(streamName, location);
                break;
            case HLS:
                playUrl = buildHlsPlayUrl(streamName, location);
                break;
            default:
                // 默认返回HTTP-FLV，兼顾延迟和兼容性
                playUrl = buildHttpFlvPlayUrl(streamName, location);
        }

        return new PlayUrlResult(playUrl, protocol);
    }

    private String buildRtmpPlayUrl(String streamName, IpLocation location) {
        String cdnDomain = cdnDispatcher.selectPlayDomain(location, "rtmp");
        return String.format("rtmp://%s/live/%s", cdnDomain, streamName);
    }

    private String buildHttpFlvPlayUrl(String streamName, IpLocation location) {
        String cdnDomain = cdnDispatcher.selectPlayDomain(location, "flv");
        return String.format("https://%s/live/%s.flv", cdnDomain, streamName);
    }

    private String buildHlsPlayUrl(String streamName, IpLocation location) {
        String cdnDomain = cdnDispatcher.selectPlayDomain(location, "hls");
        return String.format("https://%s/live/%s.m3u8", cdnDomain, streamName);
    }
}
```

#### 3.1.3 源站架构与回源机制

源站是直播系统的核心枢纽，承担流汇聚、协议转换、切片和回源路由功能。

**源站控制中心实现：**

```java
/**
 * 源站控制中心
 * 负责流的注册、路由查询和HLS重定向
 */
@Service
public class OriginControlManager {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    private static final String STREAM_ROUTE_PREFIX = "ocm:route:";
    private static final String HLS_ROUTE_PREFIX = "ocm:hls:";

    /**
     * 流注册：源站服务器收到推流后，将流信息注册到控制中心
     * @param streamName 流名称
     * @param originServerIp 源站服务器IP
     * @param originServerPort 源站服务器端口
     */
    public void registerStream(String streamName, String originServerIp,
                                int originServerPort) {
        String routeKey = STREAM_ROUTE_PREFIX + streamName;
        String routeValue = originServerIp + ":" + originServerPort;
        
        // 注册流路由，设置过期时间（流结束时主动删除，过期作为兜底）
        redisTemplate.opsForValue().set(routeKey, routeValue, 24, TimeUnit.HOURS);
        
        // 同时注册HLS切片路由
        String hlsKey = HLS_ROUTE_PREFIX + streamName;
        redisTemplate.opsForValue().set(hlsKey, originServerIp, 24, TimeUnit.HOURS);
    }

    /**
     * RTMP路由查询：边缘服务器请求某路流时，查询流所在的源站服务器
     * @param streamName 流名称
     * @return 源站服务器地址
     */
    public String queryStreamRoute(String streamName) {
        String routeKey = STREAM_ROUTE_PREFIX + streamName;
        String route = redisTemplate.opsForValue().get(routeKey);
        if (route == null) {
            throw new StreamNotFoundException("Stream not found: " + streamName);
        }
        return route;
    }

    /**
     * HLS 302跳转：接收HLS播放请求，重定向到对应的切片服务器
     * @param streamName 流名称
     * @param tsFileName 切片文件名
     * @return 重定向URL
     */
    public String resolveHlsRedirect(String streamName, String tsFileName) {
        String hlsKey = HLS_ROUTE_PREFIX + streamName;
        String hlsServer = redisTemplate.opsForValue().get(hlsKey);
        if (hlsServer == null) {
            throw new StreamNotFoundException("HLS stream not found: " + streamName);
        }
        return String.format("http://%s/hls/%s/%s", hlsServer, streamName, tsFileName);
    }

    /**
     * 流注销：直播结束时清理路由信息
     */
    public void deregisterStream(String streamName) {
        redisTemplate.delete(STREAM_ROUTE_PREFIX + streamName);
        redisTemplate.delete(HLS_ROUTE_PREFIX + streamName);
    }
}
```

#### 3.1.4 转码服务设计

转码服务将原始推流转换为多种码率，供不同网络条件的观众选择。

```java
/**
 * 直播转码服务
 * 将源流转为不同码率，提供自适应码率播放
 */
@Service
public class TranscodeService {

    /**
     * 预设转码模板
     */
    private static final Map<String, TranscodeProfile> PROFILES = Map.of(
        "1080p", new TranscodeProfile(1920, 1080, 4000, 30, "high"),
        "720p",  new TranscodeProfile(1280, 720,  2000, 30, "main"),
        "480p",  new TranscodeProfile(854,  480,  1000, 25, "main"),
        "360p",  new TranscodeProfile(640,  360,  600,  25, "baseline")
    );

    /**
     * 提交转码任务
     * @param streamName 源流名称
     * @param profiles 需要转出的码率列表
     */
    public void submitTranscodeTask(String streamName, List<String> profiles) {
        for (String profile : profiles) {
            TranscodeProfile tp = PROFILES.get(profile);
            if (tp == null) continue;

            TranscodeTask task = TranscodeTask.builder()
                    .streamName(streamName)
                    .targetStreamName(streamName + "_" + profile)
                    .width(tp.getWidth())
                    .height(tp.getHeight())
                    .bitrate(tp.getBitrate())
                    .fps(tp.getFps())
                    .profile(tp.getProfile())
                    .codec("H264")
                    .build();

            // 发送到转码任务队列
            transcodeTaskQueue.send(task);
        }
    }
}

/**
 * 转码档位配置
 */
@Data
@AllArgsConstructor
class TranscodeProfile {
    private int width;
    private int height;
    private int bitrate;    // kbps
    private int fps;
    private String profile; // H264 Profile: baseline/main/high
}
```

### 3.2 直播间状态管理

#### 3.2.1 状态机设计

直播间具有明确的生命周期，采用有限状态机（FSM）管理状态流转：

```
                    ┌─────────┐
        创建直播间 → │ CREATED │
                    └────┬────┘
                         │ 配置完成
                    ┌────▼────┐
                    │ PREPARED│
                    └────┬────┘
                         │ 开始推流
                    ┌────▼────┐
           ┌───────►│  LIVE   │◄──────────┐
           │        └────┬────┘           │
           │             │ 暂停           │ 恢复
           │        ┌────▼────┐           │
           │        │ PAUSED  ├───────────┘
           │        └────┬────┘
           │             │ 结束
           │        ┌────▼────┐
           │        │  ENDED  │
           │        └────┬────┘
           │             │ 生成回放
           │        ┌────▼────┐
           │        │ PLAYBACK│
           │        └─────────┘
           │
    异常恢复（从 ENDED 重新开播）
```

**状态机核心实现：**

```java
/**
 * 直播间状态机
 * 使用状态模式管理直播间生命周期
 */
@Service
public class LiveRoomStateMachine {

    /**
     * 合法的状态转换映射
     */
    private static final Map<RoomState, Set<RoomState>> VALID_TRANSITIONS = Map.of(
        RoomState.CREATED,  Set.of(RoomState.PREPARED),
        RoomState.PREPARED, Set.of(RoomState.LIVE),
        RoomState.LIVE,     Set.of(RoomState.PAUSED, RoomState.ENDED),
        RoomState.PAUSED,   Set.of(RoomState.LIVE, RoomState.ENDED),
        RoomState.ENDED,    Set.of(RoomState.PLAYBACK, RoomState.LIVE)
    );

    @Autowired
    private LiveRoomRepository roomRepository;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private ApplicationEventPublisher eventPublisher;

    /**
     * 状态转换
     * @param roomId 直播间ID
     * @param targetState 目标状态
     * @return 转换后的直播间信息
     */
    @Transactional
    public LiveRoom transition(Long roomId, RoomState targetState) {
        // 加分布式锁，防止并发状态变更
        String lockKey = "lock:room:state:" + roomId;
        boolean locked = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, "1", 10, TimeUnit.SECONDS);
        if (!locked) {
            throw new ConcurrentModificationException(
                    "Room state is being modified by another request");
        }

        try {
            LiveRoom room = roomRepository.findById(roomId)
                    .orElseThrow(() -> new RoomNotFoundException(roomId));

            RoomState currentState = room.getState();

            // 校验状态转换合法性
            Set<RoomState> allowedStates = VALID_TRANSITIONS.get(currentState);
            if (allowedStates == null || !allowedStates.contains(targetState)) {
                throw new InvalidStateTransitionException(
                        currentState, targetState);
            }

            // 执行状态转换前的钩子
            executePreTransitionHook(room, targetState);

            // 更新状态
            room.setState(targetState);
            room.setUpdateTime(LocalDateTime.now());
            roomRepository.save(room);

            // 更新Redis缓存中的状态
            updateRoomStateCache(roomId, targetState);

            // 发布状态变更事件
            eventPublisher.publishEvent(
                    new RoomStateChangedEvent(roomId, currentState, targetState));

            return room;
        } finally {
            redisTemplate.delete(lockKey);
        }
    }

    /**
     * 状态转换前的钩子处理
     */
    private void executePreTransitionHook(LiveRoom room, RoomState targetState) {
        switch (targetState) {
            case LIVE:
                // 开播前：校验推流地址是否已分配，记录开播时间
                if (room.getStreamName() == null) {
                    throw new IllegalStateException("Stream not allocated");
                }
                room.setStartTime(LocalDateTime.now());
                break;
            case ENDED:
                // 结束前：记录结束时间，触发录制任务
                room.setEndTime(LocalDateTime.now());
                break;
            case PLAYBACK:
                // 生成回放前：校验录制文件是否就绪
                if (room.getRecordFileUrl() == null) {
                    throw new IllegalStateException("Record file not ready");
                }
                break;
        }
    }

    /**
     * 更新Redis中的直播间状态缓存
     */
    private void updateRoomStateCache(Long roomId, RoomState state) {
        String cacheKey = "room:state:" + roomId;
        redisTemplate.opsForValue().set(cacheKey, state.name(), 24, TimeUnit.HOURS);
    }
}
```

### 3.3 连麦架构（SFU 选择性转发）

#### 3.3.1 连麦模式概述

连麦是直播场景中主播与观众或多个主播之间进行实时音视频互动的能力。与单向直播 3~5 秒的延迟不同，连麦场景要求端到端延迟在 400ms 以内，这意味着不能走传统的 CDN 分发链路，需要使用 WebRTC 技术栈。

**连麦架构中有三种媒体服务器模型：**

| 模型 | 全称 | 特点 |
|------|------|------|
| MCU | Multipoint Control Unit | 服务端混流后下发，客户端压力小但服务端计算量大 |
| SFU | Selective Forwarding Unit | 服务端只做转发不做混流，延迟最低 |
| Mesh | 点对点 | 无服务端，N方通话需N*(N-1)/2条连接，不适合多人场景 |

直播连麦场景选择 **SFU 模式**，原因是：
- 延迟最低：不需要编解码，直接转发
- 灵活性好：每个观众可以选择性接收/不接收某路流
- 扩展性强：增加连麦者只需增加转发路数

#### 3.3.2 SFU 连麦调度服务

```java
/**
 * 连麦调度服务

@Service
public class InteractiveScheduleService {

    private static final int MAX_INTERACT_USERS = 6;

    @Autowired
    private SfuNodeManager sfuNodeManager;

    @Autowired

     * @param userId 观众ID

     */

        // 检查当前连麦人数是否已满
        Long currentCount = redisTemplate.opsForSet().size(interactKey);
        if (currentCount != null && currentCount >= MAX_INTERACT_USERS) {
            return InteractResult.fail("连麦人数已达上限");
        }

        // 将连麦申请加入待审批队列
        String applyKey = "room:interact:apply:" + roomId;
        InteractApply apply = new InteractApply(userId, System.currentTimeMillis());
        redisTemplate.opsForList().rightPush(applyKey, apply);

        // 通知主播有新的连麦申请
        signalService.notifyAnchor(roomId,
                new InteractApplyNotification(userId, apply));

        return InteractResult.pending("等待主播同意");
    }

    /**
     * 主播同意连麦
     * @param roomId 直播间ID
     * @param anchorId 主播ID
     * @param userId 被同意的观众ID
     * @return 连麦信息（包含SFU地址和token）
     */
    public InteractInfo acceptInteraction(Long roomId, Long anchorId, Long userId) {
        // 分配SFU节点
        SfuNode sfuNode = sfuNodeManager.allocateSfuNode(roomId);

        // 将用户加入连麦集合
        String interactKey = "room:interact:" + roomId;
        redisTemplate.opsForSet().add(interactKey, userId.toString());

        // 生成连麦Token
        String interactToken = generateInteractToken(roomId, userId);

        // 构建连麦信息
        InteractInfo info = InteractInfo.builder()
                .sfuServerUrl(sfuNode.getWebsocketUrl())
                .roomId(roomId.toString())
                .userId(userId.toString())
                .token(interactToken)
                .iceServers(sfuNode.getIceServers())
                .build();

        // 通知观众连麦已被接受，下发SFU连接信息
        signalService.notifyUser(userId,
                new InteractAcceptedNotification(info));

        // 通知直播间所有观众有新连麦者
        signalService.broadcastToRoom(roomId,
                new NewInteractorNotification(userId));

        return info;
    }

    /**
     * 结束连麦
     */
    public void endInteraction(Long roomId, Long userId) {
        String interactKey = "room:interact:" + roomId;
        redisTemplate.opsForSet().remove(interactKey, userId.toString());

        // 通知SFU节点断开该用户的流
        sfuNodeManager.disconnectUser(roomId, userId);

        // 通知直播间所有观众
        signalService.broadcastToRoom(roomId,
                new InteractEndedNotification(userId));
    }

    private String generateInteractToken(Long roomId, Long userId) {
        String raw = roomId + ":" + userId + ":" + System.currentTimeMillis();
        return DigestUtils.sha256Hex(raw);
    }
}
```

#### 3.3.3 SFU 节点管理

```java
/**
 * SFU节点管理器
 * 管理SFU媒体服务器集群的负载均衡和故障转移
 */
@Component
public class SfuNodeManager {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /** 所有可用SFU节点 */
    private final List<SfuNode> sfuNodes = new CopyOnWriteArrayList<>();

    /** 房间与SFU节点的映射 */
    private final Map<Long, SfuNode> roomSfuMapping = new ConcurrentHashMap<>();

    /**
     * 为直播间分配SFU节点
     * 同一直播间的所有连麦者必须连接到同一个SFU节点
     */
    public SfuNode allocateSfuNode(Long roomId) {
        // 如果该房间已经分配了SFU节点，直接返回
        SfuNode existingNode = roomSfuMapping.get(roomId);
        if (existingNode != null && existingNode.isHealthy()) {
            return existingNode;
        }

        // 选择负载最低的SFU节点
        SfuNode selectedNode = sfuNodes.stream()
                .filter(SfuNode::isHealthy)
                .min(Comparator.comparingInt(SfuNode::getCurrentRoomCount))
                .orElseThrow(() -> new NoAvailableSfuException(
                        "No available SFU node"));

        roomSfuMapping.put(roomId, selectedNode);
        selectedNode.incrementRoomCount();

        return selectedNode;
    }

    /**
     * 断开用户与SFU的连接
     */
    public void disconnectUser(Long roomId, Long userId) {
        SfuNode node = roomSfuMapping.get(roomId);
        if (node != null) {
            // 调用SFU节点API断开用户
            node.disconnectUser(roomId, userId);

            // 如果房间内没有连麦者了，释放SFU节点
            String interactKey = "room:interact:" + roomId;
            Long remainCount = redisTemplate.opsForSet().size(interactKey);
            if (remainCount == null || remainCount == 0) {
                roomSfuMapping.remove(roomId);
                node.decrementRoomCount();
            }
        }
    }
}
```

### 3.4 直播弹幕系统

#### 3.4.1 弹幕系统架构

弹幕是直播间最高频的互动形式，热门直播间每秒可能收到数千条弹幕消息。弹幕系统需要解决以下问题：

- **高吞吐写入**：需要承受瞬间大量弹幕发送请求
- **实时广播**：弹幕需要毫秒级下发到同一直播间的所有在线用户
- **消息过滤**：需要过滤敏感词、控制发送频率
- **消息聚合**：防止消息风暴导致客户端卡顿

```
观众发送弹幕 → API网关 → 弹幕服务 → 敏感词过滤 → 频率控制
                                                    ↓
    客户端渲染 ← WebSocket推送 ← 长连接网关 ← 消息聚合器 ← MQ
                                                    ↓
                                              弹幕持久化(异步)
```

#### 3.4.2 弹幕服务核心实现

```java
/**
 * 弹幕服务
 * 处理弹幕的发送、过滤、聚合和分发
 */
@Service
public class BarrageService {

    /** 单用户发送频率限制：每秒最多2条 */
    private static final int RATE_LIMIT_PER_SECOND = 2;

    @Autowired
    private SensitiveWordFilter sensitiveWordFilter;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private MessageQueueProducer mqProducer;

    @Autowired
    private BarrageRepository barrageRepository;

    /**
     * 发送弹幕
     * @param roomId 直播间ID
     * @param userId 发送者ID
     * @param content 弹幕内容
     * @return 发送结果
     */
    public BarrageSendResult sendBarrage(Long roomId, Long userId, String content) {
        // Step1: 频率控制
        if (!checkRateLimit(userId)) {
            return BarrageSendResult.fail("发送太快了，请稍后再试");
        }

        // Step2: 内容长度校验
        if (content.length() > 50) {
            return BarrageSendResult.fail("弹幕内容不能超过50个字符");
        }

        // Step3: 敏感词过滤（基于DFA算法）
        FilterResult filterResult = sensitiveWordFilter.filter(content);
        if (filterResult.isBlocked()) {
            return BarrageSendResult.fail("弹幕包含违规内容");
        }
        // 将敏感词替换为*号
        String filteredContent = filterResult.getFilteredText();

        // Step4: 构建弹幕消息
        BarrageMessage message = BarrageMessage.builder()
                .id(IdGenerator.nextId())
                .roomId(roomId)
                .userId(userId)
                .content(filteredContent)
                .timestamp(System.currentTimeMillis())
                .build();

        // Step5: 发送到MQ进行异步广播（削峰）
        mqProducer.send("topic_barrage", roomId.toString(), message);

        // Step6: 异步持久化到数据库（用于回放）
        CompletableFuture.runAsync(() -> barrageRepository.save(message));

        return BarrageSendResult.success(message.getId());
    }

    /**
     * 频率限制：滑动窗口算法
     * 使用Redis的ZSET实现精确的滑动窗口限流
     */
    private boolean checkRateLimit(Long userId) {
        String key = "barrage:rate:" + userId;
        long now = System.currentTimeMillis();
        long windowStart = now - 1000; // 1秒窗口

        // 移除窗口外的请求记录
        redisTemplate.opsForZSet().removeRangeByScore(key, 0, windowStart);

        // 统计窗口内的请求数
        Long count = redisTemplate.opsForZSet().zCard(key);
        if (count != null && count >= RATE_LIMIT_PER_SECOND) {
            return false;
        }

        // 添加当前请求记录
        redisTemplate.opsForZSet().add(key, String.valueOf(now), now);
        redisTemplate.expire(key, 2, TimeUnit.SECONDS);

        return true;
    }
}
```

#### 3.4.3 敏感词过滤器（DFA 算法）

```java
/**
 * 基于DFA（确定有限自动机）的敏感词过滤器
 * 构建前缀树进行高效的多模式匹配
 */
@Component
public class SensitiveWordFilter {

    /** DFA状态转移表 */
    private Map<Character, Object> dfaMap = new HashMap<>();

    private static final String END_FLAG = "isEnd";

    /**
     * 初始化：从词库加载敏感词，构建DFA
     */
    @PostConstruct
    public void init() {
        Set<String> sensitiveWords = loadSensitiveWords();
        buildDfa(sensitiveWords);
    }

    /**
     * 构建DFA状态转移表
     */
    @SuppressWarnings("unchecked")
    private void buildDfa(Set<String> words) {
        for (String word : words) {
            Map<Character, Object> currentMap = dfaMap;
            for (int i = 0; i < word.length(); i++) {
                char c = word.charAt(i);
                Object existing = currentMap.get(c);
                if (existing instanceof Map) {
                    currentMap = (Map<Character, Object>) existing;
                } else {
                    Map<Character, Object> newMap = new HashMap<>();
                    currentMap.put(c, newMap);
                    currentMap = newMap;
                }
            }
            currentMap.put(END_FLAG.charAt(0), Boolean.TRUE);
        }
    }

    /**
     * 过滤文本中的敏感词
     * @param text 原始文本
     * @return 过滤结果
     */
    @SuppressWarnings("unchecked")
    public FilterResult filter(String text) {
        StringBuilder filtered = new StringBuilder(text);
        boolean hasBlocked = false;
        int i = 0;

        while (i < text.length()) {
            Map<Character, Object> currentMap = dfaMap;
            int matchLength = 0;
            int j = i;
            boolean found = false;

            while (j < text.length()) {
                char c = text.charAt(j);
                Object next = currentMap.get(c);

                if (next == null) {
                    break;
                }

                matchLength++;

                if (next instanceof Map) {
                    currentMap = (Map<Character, Object>) next;
                    // 检查是否到达终态
                    if (currentMap.containsKey(END_FLAG.charAt(0))) {
                        found = true;
                    }
                }
                j++;
            }

            if (found) {
                // 替换敏感词为*号
                for (int k = i; k < i + matchLength; k++) {
                    filtered.setCharAt(k, '*');
                }
                hasBlocked = true;
                i += matchLength;
            } else {
                i++;
            }
        }

        return new FilterResult(filtered.toString(), hasBlocked);
    }

    private Set<String> loadSensitiveWords() {
        // 从数据库或配置文件加载敏感词库
        // 实际场景中会定期刷新
        return new HashSet<>();
    }
}
```

#### 3.4.4 弹幕消息聚合与广播

```java
/**
 * 弹幕消息聚合消费者
 * 从MQ消费弹幕消息，聚合后批量下发到长连接网关
 * 
 * 设计思路：不是来一条推一条，而是攒一小批再推送，
 * 避免热门直播间消息风暴导致客户端卡顿
 */
@Component
public class BarrageAggregateConsumer {

    /** 聚合窗口时间：200ms */
    private static final long AGGREGATE_WINDOW_MS = 200;

    /** 单次最大推送条数 */
    private static final int MAX_BATCH_SIZE = 20;

    @Autowired
    private LongConnectionGateway gateway;

    /** 每个直播间的弹幕缓冲区 */
    private final Map<Long, List<BarrageMessage>> roomBuffers = new ConcurrentHashMap<>();

    /**
     * MQ消费：接收弹幕消息
     */
    @RocketMQMessageListener(topic = "topic_barrage")
    public void onMessage(BarrageMessage message) {
        Long roomId = message.getRoomId();
        roomBuffers.computeIfAbsent(roomId, k -> new CopyOnWriteArrayList<>())
                .add(message);
    }

    /**
     * 定时任务：每200ms聚合一次各房间的弹幕并推送
     */
    @Scheduled(fixedRate = 200)
    public void flushBuffers() {
        for (Map.Entry<Long, List<BarrageMessage>> entry : roomBuffers.entrySet()) {
            Long roomId = entry.getKey();
            List<BarrageMessage> buffer = entry.getValue();

            if (buffer.isEmpty()) continue;

            // 取出缓冲区中的消息（最多MAX_BATCH_SIZE条）
            List<BarrageMessage> batch;
            if (buffer.size() <= MAX_BATCH_SIZE) {
                batch = new ArrayList<>(buffer);
                buffer.clear();
            } else {
                // 消息过多时只取最新的，丢弃较早的（防止雪崩）
                batch = new ArrayList<>(buffer.subList(
                        buffer.size() - MAX_BATCH_SIZE, buffer.size()));
                buffer.clear();
            }

            // 批量推送到长连接网关
            BarrageBatchMessage batchMessage = new BarrageBatchMessage(roomId, batch);
            gateway.broadcastToRoom(roomId, batchMessage);
        }
    }
}
```

#### 3.5.2 礼物打赏核心流程

```java
/**
 * 礼物打赏服务
 * 采用预扣款+异步确认的方式，保证资金安全
 */
@Service
public class GiftService {

    @Autowired
    private AccountService accountService;

    @Autowired
    private GiftRepository giftRepository;

    @Autowired
    private MessageQueueProducer mqProducer;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private GiftComboService comboService;

    /**
     * 发送礼物
     * @param senderId 送礼用户ID
     * @param roomId 直播间ID
     * @param anchorId 主播ID
     * @param giftId 礼物ID
     * @param count 数量
     * @return 打赏结果
     */
    @Transactional
    public GiftSendResult sendGift(Long senderId, Long roomId, Long anchorId,
                                    Long giftId, int count) {
        // Step1: 查询礼物信息
        GiftInfo giftInfo = giftRepository.findById(giftId)
                .orElseThrow(() -> new GiftNotFoundException(giftId));

        long totalAmount = giftInfo.getPrice() * count;

        // Step2: 生成幂等键，防止重复扣款
        String idempotentKey = generateIdempotentKey(senderId, roomId, giftId);
        if (isProcessed(idempotentKey)) {
            return GiftSendResult.duplicate("礼物已发送，请勿重复操作");
        }

        // Step3: 预扣款（使用乐观锁）
        boolean deductResult = accountService.deductBalance(
                senderId, totalAmount, idempotentKey);
        if (!deductResult) {
            return GiftSendResult.fail("余额不足");
        }

        // Step4: 记录礼物流水
        GiftRecord record = GiftRecord.builder()
                .orderId(IdGenerator.nextId())
                .senderId(senderId)
                .anchorId(anchorId)
                .roomId(roomId)
                .giftId(giftId)
                .giftName(giftInfo.getName())
                .count(count)
                .totalAmount(totalAmount)
                .status(GiftRecordStatus.DEDUCTED)
                .createTime(LocalDateTime.now())
                .build();
        giftRepository.saveRecord(record);

        // Step5: 发送MQ，异步处理后续逻辑（主播入账、礼物展示）
        GiftEvent event = new GiftEvent(record);
        mqProducer.send("topic_gift", roomId.toString(), event);

        // Step6: 处理连击逻辑
        comboService.handleCombo(senderId, roomId, giftId, count);

        // 标记已处理
        markProcessed(idempotentKey);

        return GiftSendResult.success(record.getOrderId());
    }

    /**
     * 生成幂等键
     * 同一用户、同一直播间、同一礼物在500ms内的请求视为重复
     */
    private String generateIdempotentKey(Long senderId, Long roomId, Long giftId) {
        long timeSlot = System.currentTimeMillis() / 500;
        return String.format("gift:idempotent:%d:%d:%d:%d",
                senderId, roomId, giftId, timeSlot);
    }

    private boolean isProcessed(String key) {
        return Boolean.TRUE.equals(redisTemplate.hasKey(key));
    }

    private void markProcessed(String key) {
        redisTemplate.opsForValue().set(key, "1", 5, TimeUnit.SECONDS);
    }
```

```java
/**
 * 账户服务
 * 使用乐观锁保证并发扣款安全
 */
@Service
public class AccountService {

    @Autowired
    private AccountMapper accountMapper;

    /** 最大重试次数 */
    private static final int MAX_RETRY = 3;

    /**
     * 扣减余额（乐观锁实现）
     * @param userId 用户ID
     * @param amount 扣减金额（单位：分）
     * @param idempotentKey 幂等键
     * @return 是否扣减成功
     */
    @Transactional
    public boolean deductBalance(Long userId, long amount, String idempotentKey) {
        for (int retry = 0; retry < MAX_RETRY; retry++) {
            // 查询当前余额和版本号
            Account account = accountMapper.selectByUserId(userId);
            if (account == null) {
                throw new AccountNotFoundException(userId);
            }

            // 余额不足
            if (account.getBalance() < amount) {
                return false;
            }

            // 使用版本号进行CAS更新
            // SQL: UPDATE account SET balance = balance - #{amount},
            //      version = version + 1
            //      WHERE user_id = #{userId} AND version = #{version}
            //      AND balance >= #{amount}
            int affected = accountMapper.deductWithVersion(
                    userId, amount, account.getVersion());

            if (affected > 0) {
                // 记录流水
                AccountFlow flow = AccountFlow.builder()
                        .userId(userId)
                        .type(FlowType.DEDUCT)
                        .amount(amount)
                        .balanceBefore(account.getBalance())
                        .balanceAfter(account.getBalance() - amount)
                        .idempotentKey(idempotentKey)
                        .createTime(LocalDateTime.now())
                        .build();
                accountMapper.insertFlow(flow);
                return true;
            }

            // CAS失败，重试
            try {
                Thread.sleep(10 * (retry + 1)); // 退避重试
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }

        return false;
    }

    /**
     * 主播收益入账
     * 由MQ消费者调用，异步执行
     */
    @Transactional
    public void creditToAnchor(Long anchorId, long amount, String orderId) {
        // 幂等校验
        if (accountMapper.existsFlow(orderId, FlowType.CREDIT)) {
            return;
        }

        accountMapper.addBalance(anchorId, amount);

        AccountFlow flow = AccountFlow.builder()
                .userId(anchorId)
                .type(FlowType.CREDIT)
                .amount(amount)
                .relatedOrderId(orderId)
                .createTime(LocalDateTime.now())
                .build();
        accountMapper.insertFlow(flow);
    }
```

### 3.6 在线人数统计（Redis HyperLogLog）

#### 3.6.1 统计方案对比

在线人数统计看似简单，但在大规模直播场景下面临以下挑战：

| 方案 | 内存消耗（100万用户） | 精确性 | 适用场景 |
|------|----------------------|--------|----------|
| Redis Set | ~64MB | 精确 | 小房间（<1万人） |
| Redis Bitmap | ~125KB | 精确 | 用户ID连续 |
| Redis HyperLogLog | 12KB | 误差0.81% | 大房间（万人以上） |

对于直播场景，在线人数不需要绝对精确（误差在1%以内用户无感知），因此采用 **HyperLogLog** 作为主要统计方案，辅以 Redis Set 用于小房间精确统计。

#### 3.6.2 在线人数服务实现

```java
 * 直播间在线人数统计服务
 * 采用HyperLogLog + Set的混合策略
 */

public class OnlineCountService {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /** 小房间阈值：低于此值使用Set精确统计 */
    private static final long SMALL_ROOM_THRESHOLD = 10000;

    private static final String HLL_KEY_PREFIX = "room:online:hll:";
    private static final String SET_KEY_PREFIX = "room:online:set:";
    private static final String COUNT_KEY_PREFIX = "room:online:count:";
    private static final String TOTAL_VIEW_KEY_PREFIX = "room:total:view:";

    /**
     * 用户进入直播间
     * @param roomId 直播间ID
     * @param userId 用户ID
     */
    public void userJoin(Long roomId, Long userId) {
        String hllKey = HLL_KEY_PREFIX + roomId;
        String setKey = SET_KEY_PREFIX + roomId;
        String totalViewKey = TOTAL_VIEW_KEY_PREFIX + roomId;

        // HyperLogLog统计总观看人次（UV去重）
        redisTemplate.opsForHyperLogLog().add(hllKey, userId.toString());

        // Set统计当前在线人数（实时在线）
        redisTemplate.opsForSet().add(setKey, userId.toString());
        redisTemplate.expire(setKey, 4, TimeUnit.HOURS);

        // 累计观看人次（非去重）
        redisTemplate.opsForValue().increment(totalViewKey);

        // 更新在线人数缓存
        updateOnlineCountCache(roomId);
    }

    /**
     * 用户离开直播间
     */
    public void userLeave(Long roomId, Long userId) {
        String setKey = SET_KEY_PREFIX + roomId;
        redisTemplate.opsForSet().remove(setKey, userId.toString());

        updateOnlineCountCache(roomId);
    }

    /**
     * 获取当前在线人数
     * 小房间使用Set精确值，大房间使用缓存值
     */
    public long getOnlineCount(Long roomId) {
        String countKey = COUNT_KEY_PREFIX + roomId;
        String cached = redisTemplate.opsForValue().get(countKey);
        if (cached != null) {
            return Long.parseLong(cached);
        }

        // 缓存未命中，实时计算
        String setKey = SET_KEY_PREFIX + roomId;
        Long count = redisTemplate.opsForSet().size(setKey);
        return count != null ? count : 0;
    }

    /**
     * 获取总观看人数（UV去重）
     * 使用HyperLogLog，误差约0.81%
     */
    public long getTotalViewers(Long roomId) {
        String hllKey = HLL_KEY_PREFIX + roomId;
        return redisTemplate.opsForHyperLogLog().size(hllKey);
    }

    /**
     * 获取累计观看人次（非去重）
     */
    public long getTotalViewCount(Long roomId) {
        String totalViewKey = TOTAL_VIEW_KEY_PREFIX + roomId;
        String count = redisTemplate.opsForValue().get(totalViewKey);
        return count != null ? Long.parseLong(count) : 0;
    }

    /**
     * 更新在线人数缓存
     * 使用缓存避免每次请求都执行SCARD
     */
    private void updateOnlineCountCache(Long roomId) {
        String setKey = SET_KEY_PREFIX + roomId;
        String countKey = COUNT_KEY_PREFIX + roomId;
        Long count = redisTemplate.opsForSet().size(setKey);
        if (count != null) {
            // 缓存5秒，避免频繁更新
            redisTemplate.opsForValue().set(countKey, count.toString(),

        }
    }
```

### 3.7 直播录制与回放

#### 3.7.1 录制架构设计

直播录制需要将推流端发送的实时音视频流完整保存下来，以便直播结束后提供回放功能。

录制系统的核心设计要点：
- 录制与直播分发解耦，录制失败不影响直播
- 支持从源站实时录制和事后从CDN拉取录制
- 录制文件分段存储，避免单文件过大
- 支持自动合并和转码为MP4格式

```java
/**
 * 直播录制服务
 * 监听直播开播/结束事件，管理录制任务的生命周期
 */
@Service
public class RecordService {

    @Autowired
    private RecordTaskRepository taskRepository;

    @Autowired
    private ObjectStorageService ossService;

    @Autowired
    private TranscodeService transcodeService;

    @Autowired
    private LiveRoomRepository roomRepository;

    /**
     * 监听开播事件，自动启动录制
     */
    @EventListener
    public void onLiveStart(RoomStateChangedEvent event) {
        if (event.getTargetState() != RoomState.LIVE) return;

        Long roomId = event.getRoomId();
        LiveRoom room = roomRepository.findById(roomId).orElse(null);
        if (room == null) return;

        RecordTask task = RecordTask.builder()
                .roomId(roomId)
                .streamName(room.getStreamName())
                .status(RecordTaskStatus.RECORDING)
                .startTime(LocalDateTime.now())
                .segmentDuration(300) // 每5分钟一个分片
                .build();
        taskRepository.save(task);

        // 通知源站开始录制
        notifyOriginToRecord(room.getStreamName(), task.getId());
    }

    /**
     * 监听直播结束事件，停止录制并触发后处理
     */
    @EventListener
    public void onLiveEnd(RoomStateChangedEvent event) {
        if (event.getTargetState() != RoomState.ENDED) return;

        Long roomId = event.getRoomId();
        RecordTask task = taskRepository.findByRoomIdAndStatus(
                roomId, RecordTaskStatus.RECORDING);
        if (task == null) return;

        task.setStatus(RecordTaskStatus.PROCESSING);
        task.setEndTime(LocalDateTime.now());
        taskRepository.save(task);

        // 异步执行后处理：合并分片 → 转码 → 上传OSS
        CompletableFuture.runAsync(() -> postProcess(task));
    }

    /**
     * 录制后处理流程
     * 合并分片文件 → 转码为MP4 → 上传对象存储 → 更新直播间回放地址
     */
    private void postProcess(RecordTask task) {
        try {
            // Step1: 合并FLV分片文件
            String mergedFilePath = mergeSegments(task);

            // Step2: 转码为MP4（FLV → MP4）
            String mp4FilePath = transcodeToMp4(mergedFilePath);

            // Step3: 上传到对象存储
            String ossUrl = ossService.upload(mp4FilePath,
                    "record/" + task.getRoomId() + "/" + task.getId() + ".mp4");

            // Step4: 更新任务状态和直播间回放地址
            task.setStatus(RecordTaskStatus.COMPLETED);
            task.setRecordUrl(ossUrl);
            taskRepository.save(task);

            // 更新直播间的录制文件URL
            LiveRoom room = roomRepository.findById(task.getRoomId()).orElse(null);
            if (room != null) {
                room.setRecordFileUrl(ossUrl);
                roomRepository.save(room);
            }

            // 清理临时文件
            cleanTempFiles(mergedFilePath, mp4FilePath);

        } catch (Exception e) {
            task.setStatus(RecordTaskStatus.FAILED);
            task.setErrorMessage(e.getMessage());
            taskRepository.save(task);
        }
    }

    private String mergeSegments(RecordTask task) {
        // 从源站收集所有分片文件
        // 使用FFmpeg进行无损合并
        // ffmpeg -i "concat:seg1.flv|seg2.flv|..." -c copy merged.flv
        return "/tmp/record/" + task.getId() + "/merged.flv";
    }

    private String transcodeToMp4(String flvPath) {
        // 使用FFmpeg将FLV转码为MP4
        // ffmpeg -i merged.flv -c:v copy -c:a aac -movflags faststart output.mp4
        // movflags faststart 将moov atom移到文件头，支持边下载边播放
        return flvPath.replace(".flv", ".mp4");
    }

    private void notifyOriginToRecord(String streamName, Long taskId) {
        // 通过RPC通知源站服务器开始录制
    }

    private void cleanTempFiles(String... paths) {
        for (String path : paths) {
            new File(path).delete();
        }
    }
}
```

### 3.8 CDN 调度

#### 3.8.1 融合 CDN 调度策略

大规模直播系统通常接入多家 CDN 服务商，通过智能调度实现成本优化和质量保障。

```java
/**
 * CDN调度器
 * 根据运营商、地理位置、CDN质量等因素选择最优CDN
 */
@Service
public class CdnDispatcher {

    @Autowired
    private CdnConfigRepository configRepository;

    @Autowired
    private CdnQualityMonitor qualityMonitor;

    /**
     * CDN提供商枚举
     */
    public enum CdnProvider {
        SELF,      // 自建CDN
        TENCENT,   // 腾讯云CDN
        ALIYUN,    // 阿里云CDN
        BAIDU      // 百度云CDN
    }

    /**
     * 选择推流域名
     * 策略：优先自建节点，自建节点不覆盖的区域使用三方CDN
     */
    public String selectPushDomain(IpLocation location) {
        // 查询该地区的推流CDN配置
        CdnConfig config = configRepository.findByRegionAndIsp(
                location.getProvince(), location.getIsp());

        if (config != null) {
            return config.getPushDomain();
        }

        // 无特定配置，使用默认策略
        return getDefaultPushDomain(location);
    }

    /**
     * 选择播放域名
     * 策略：根据历史质量数据动态调度
     * @param location 用户位置
     * @param protocol 播放协议(rtmp/flv/hls)
     */
    public String selectPlayDomain(IpLocation location, String protocol) {
        // 获取该地区所有可用的CDN提供商
        List<CdnConfig> availableConfigs = configRepository
                .findAvailableByRegion(location.getProvince(), location.getIsp());

        if (availableConfigs.isEmpty()) {
            return getDefaultPlayDomain(protocol);
        }

        // 根据质量评分选择最优CDN
        CdnConfig bestConfig = availableConfigs.stream()
                .max(Comparator.comparingDouble(config ->
                        calculateScore(config, location)))
                .orElse(availableConfigs.get(0));

        return bestConfig.getPlayDomain();
    }

    /**
     * 计算CDN评分
     * 综合考虑：卡顿率(40%) + 首帧时间(30%) + 成本(20%) + 可用性(10%)
     */
    private double calculateScore(CdnConfig config, IpLocation location) {
        CdnQualityMetrics metrics = qualityMonitor.getMetrics(
                config.getProvider(), location.getProvince());

        double stutterScore = (1 - metrics.getStutterRate()) * 40;
        double firstFrameScore = Math.max(0, (1000 - metrics.getFirstFrameMs())) / 1000.0 * 30;
        double costScore = (1 - config.getCostFactor()) * 20;
        double availabilityScore = metrics.getAvailability() * 10;

        return stutterScore + firstFrameScore + costScore + availabilityScore;
    }

    private String getDefaultPushDomain(IpLocation location) {
        return "publish.live.example.com";
    }

    private String getDefaultPlayDomain(String protocol) {
        switch (protocol) {
            case "rtmp": return "rtmp-play.live.example.com";
            case "hls":  return "hls-play.live.example.com";
            default:     return "flv-play.live.example.com";
        }
    }
}
```

```java
/**
 * CDN质量监控
 * 实时采集各CDN的质量指标，为调度决策提供数据支撑
 */
@Component
public class CdnQualityMonitor {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /**
     * 上报质量数据（由客户端SDK周期性上报）
     */
    public void reportMetrics(String provider, String province,
                               double stutterRate, long firstFrameMs) {
        String key = String.format("cdn:quality:%s:%s", provider, province);
        long now = System.currentTimeMillis();

        // 使用Redis SortedSet存储最近5分钟的上报数据
        String value = String.format("%f:%d", stutterRate, firstFrameMs);
        redisTemplate.opsForZSet().add(key, value, now);

        // 清理5分钟前的数据
        redisTemplate.opsForZSet().removeRangeByScore(key, 0, now - 300_000);
    }

    /**
     * 获取CDN质量指标
     */
    public CdnQualityMetrics getMetrics(CdnDispatcher.CdnProvider provider,
                                         String province) {
        String key = String.format("cdn:quality:%s:%s",
                provider.name(), province);

        Set<String> recentData = redisTemplate.opsForZSet().range(key, 0, -1);

        if (recentData == null || recentData.isEmpty()) {
            return CdnQualityMetrics.defaultMetrics();
        }

        // 计算平均卡顿率和首帧时间
        double avgStutter = 0;
        long avgFirstFrame = 0;
        int count = recentData.size();

        for (String data : recentData) {
            String[] parts = data.split(":");
            avgStutter += Double.parseDouble(parts[0]);
            avgFirstFrame += Long.parseLong(parts[1]);
        }

        return new CdnQualityMetrics(
                avgStutter / count,
                avgFirstFrame / count,
                0.999 // 可用性从独立监控系统获取
        );
    }
```

## 四、异常处理与容错机制

### 4.1 推流断线重连

推流过程中网络抖动是常见现象，系统需要支持断线后快速重连，而不是创建一个全新的直播流。

```java
/**
 * 推流断线重连处理
 */
@Service
public class StreamReconnectHandler {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private OriginControlManager ocm;

    /** 断线保护时间窗口：60秒内重连视为同一次直播 */
    private static final int RECONNECT_WINDOW_SECONDS = 60;

    /**
     * 推流断开时调用
     * 不立即清理流信息，而是设置保护期
     */
    public void onStreamDisconnect(String streamName) {
        String protectKey = "stream:protect:" + streamName;
        // 设置保护期，60秒内不清理流注册信息
        redisTemplate.opsForValue().set(protectKey, "1",
                RECONNECT_WINDOW_SECONDS, TimeUnit.SECONDS);

        // 启动延迟任务：保护期结束后检查是否已重连
        ScheduledExecutorService scheduler = Executors.newSingleThreadScheduledExecutor();
        scheduler.schedule(() -> {
            String protect = redisTemplate.opsForValue().get(protectKey);
            if (protect != null) {
                // 保护期内未重连，真正清理流
                ocm.deregisterStream(streamName);
                redisTemplate.delete(protectKey);
            }
        }, RECONNECT_WINDOW_SECONDS + 5, TimeUnit.SECONDS);
    }

    /**

     * 清除保护标记，复用原有的流信息
     */
    public boolean onStreamReconnect(String streamName, String token) {
```

```java
                }
            } catch (Exception e) {

    private void handleServerDown(OriginServer downServer) {

        List<String> streams = downServer.getActiveStreams();
```

```java
/**
 * 弹幕系统性能优化：批量处理 + 背压控制
 */
@Component
public class BarragePerformanceOptimizer {

    /**
     * 热门房间弹幕采样策略
     * 当弹幕QPS超过阈值时进行智能采样，
     * 保证客户端不会因为消息过多而卡顿
     */
    public List<BarrageMessage> sampleBarrages(
            List<BarrageMessage> messages, long onlineCount) {

        // 计算采样率
        double sampleRate = calculateSampleRate(messages.size(), onlineCount);

        if (sampleRate >= 1.0) {
            return messages; // 不需要采样
        }

        // 优先保留VIP用户和主播的弹幕
        List<BarrageMessage> sampled = new ArrayList<>();
        List<BarrageMessage> normalMessages = new ArrayList<>();

        for (BarrageMessage msg : messages) {
            if (msg.isVip() || msg.isAnchor()) {
                sampled.add(msg); // VIP和主播弹幕始终保留
            } else {
                normalMessages.add(msg);
            }
        }

        // 对普通弹幕按采样率随机选取
        int targetCount = (int) (normalMessages.size() * sampleRate);
        Collections.shuffle(normalMessages);
        sampled.addAll(normalMessages.subList(0,
                Math.min(targetCount, normalMessages.size())));

        return sampled;
    }

    /**
     * 计算采样率
     * 目标：每次推送不超过20条弹幕
     */
    private double calculateSampleRate(int messageCount, long onlineCount) {
        int maxPerBatch = 20;
        if (messageCount <= maxPerBatch) {
            return 1.0;
        }
        return (double) maxPerBatch / messageCount;
    }
}
```

## 六、最佳实践与总结

### 6.1 直播系统建设核心原则

**1. 分层解耦原则**

直播系统应严格分为三层：
- **音视频传输层**：负责推拉流、转码、CDN分发，这是基础设施
- **实时互动层**：负责弹幕、礼物、连麦等实时消息，基于长连接网关
- **业务层**：负责直播间管理、电商带货、运营活动等业务逻辑

每一层之间通过标准接口通信，任何一层的技术升级不影响其他层。

**2. 推拉流协议选型指南**

| 场景 | 推荐协议 | 理由 |
|------|----------|------|
| 主播推流 | RTMP (或QUIC优化) | 成熟稳定，编码器支持广泛 |
| 观众低延迟观看 | HTTP-FLV | 延迟3~5秒，兼容性好 |
| H5/小程序播放 | HLS | 跨平台兼容性最佳，延迟10~30秒可接受 |
| 连麦互动 | WebRTC (SFU) | 端到端延迟<400ms |
| 大规模直播回放 | HLS | 支持CDN缓存，适合大规模分发 |

**3. 消息系统设计要点**

- 弹幕消息使用MQ异步解耦，聚合窗口200ms批量推送
- 礼物消息保证可靠性，使用幂等键防止重复扣款
- 连麦信令使用独立的信令通道，不与弹幕共享
- 大房间采用消息采样策略，保证客户端渲染流畅

### 6.2 关键技术选型总结

| 组件 | 技术选型 | 备选方案 |
|------|----------|----------|
| 流媒体服务器 | Nginx-RTMP + SRS | 纯SRS |
| 消息队列 | RocketMQ | Kafka |
| 缓存 | Redis Cluster | 本地缓存 + Redis |
| 长连接网关 | Netty WebSocket | Socket.IO |
| 在线人数统计 | Redis HyperLogLog | Redis Set |
| 分布式锁 | Redis SetNX | ZooKeeper |
| 对象存储 | 自建OSS / 云存储 | MinIO |
| CDN | 融合CDN（自建+三方） | 单一CDN |
| 数据库 | MySQL分库分表 | TiDB |
| 搜索 | Elasticsearch | - |

### 6.3 容量规划参考

| 指标 | 参考值 | 说明 |
|------|--------|------|
| 单源站服务器并发推流 | 500~1000路 | 取决于转码需求 |
| 单WebSocket网关连接数 | 50万+ | 需要OS内核参数调优 |
| 弹幕消息QPS | 10万+/秒 | 热门直播间峰值 |
| 礼物消息TPS | 1万+/秒 | 含扣款+入账 |

| 推流成功率 | >99.9% | 含重连 |
| 系统可用性 | 99.995% | 年度SLA |

### 6.4 常见陷阱与规避

**陷阱1：弹幕消息风暴**
- 现象：热门直播间每秒数千条弹幕，客户端渲染卡顿
- 规避：使用聚合窗口+采样策略，每200ms批量推送最多20条

**陷阱2：礼物重复扣款**
- 现象：网络抖动导致用户重复点击，多次扣款
- 规避：幂等键设计（用户ID+房间ID+礼物ID+时间槽），500ms内去重

**陷阱3：在线人数不准**
- 现象：用户异常退出未触发leave事件，在线人数虚高
- 规避：心跳机制+定时清理，30秒心跳间隔，90秒超时剔除

**陷阱4：推流断线丢失**
- 现象：主播网络抖动断线重连后变成新的直播间
- 规避：断线保护窗口（60秒），保护期内重连复用原有流和直播间

**陷阱5：回放文件过大**
- 现象：长时间直播产生数GB的录制文件，转码和传输耗时长
- 规避：录制时分段存储（每5分钟一个分片），结束后再合并

**陷阱6：CDN单点故障**
- 现象：单一CDN服务商出现区域性故障，大量用户无法观看
- 规避：融合CDN架构，实时质量监控+自动调度切换

### 6.5 总结

直播系统后端是一个涉及音视频传输、实时通信、高并发处理、资金安全等多个领域的复杂系统。本文从推拉流架构、直播间状态管理、连麦互动、弹幕系统、礼物打赏、在线人数统计、录制回放、CDN调度八个核心维度，系统阐述了直播后端的设计思路与实现方案。

整体架构遵循以下核心设计思想：

1. **分层解耦**：音视频层、互动层、业务层各司其职，独立演进
2. **异步削峰**：弹幕、礼物等高频操作通过MQ异步处理，避免峰值压垮系统
3. **最终一致**：礼物打赏采用预扣款+异步入账，保证资金最终一致性
4. **优雅降级**：大房间消息采样推送，保证核心消息（礼物、系统通知）可靠送达
5. **容错兜底**：推流断线保护、源站高可用、CDN自动切换，层层设防

直播系统的建设是一个持续演进的过程，随着业务规模的增长和玩法的丰富，还需要在音视频编码效率、低延迟协议升级、AI内容审核、边缘计算等方向持续投入和优化。

### 7.1 案例一：主播开播全链路

#### 7.1.1 链路概述

主播在 App 端点击"开始直播"按钮后，后端需要完成以下一系列操作：

```
主播点击"开始直播"
    │
    ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 1. 创建直播间（房间ID、标题、封面、分类）                              │
│ 2. 推流地址生成（RTMP推流URL、鉴权Token）                              │
│ 3. CDN节点分配（融合CDN调度，选择最优边缘节点）                          │
│ 4. 直播间状态流转（CREATED → PREPARED → LIVE）                         │
│ 5. 直播间信息写入缓存和搜索索引                                         │

└─────────────────────────────────────────────────────────────────────┘
    │
    ▼
主播获取推流地址，开始推流 → 源站注册流 → 状态转为LIVE
```

#### 7.1.2 全链路编排服务

```java
/**
 * 主播开播编排服务
 * 将创建直播间、推流地址分配、CDN调度、状态流转、缓存索引、粉丝通知
 * 串联为一个完整的开播流程，每一步都有异常处理和日志记录
 */
@Service
@Slf4j
public class LiveStartOrchestrator {

    @Autowired
    private LiveRoomRepository roomRepository;

    @Autowired
    private StreamScheduleService streamScheduleService;

    @Autowired
    private LiveRoomStateMachine stateMachine;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private ElasticsearchClient esClient;

    @Autowired
    private FollowService followService;

    @Autowired
    private MessageQueueProducer mqProducer;

    /**
     * 主播开播入口
     * @param request 开播请求
     * @return 开播结果（含推流地址）
     */
    public LiveStartResult startLive(LiveStartRequest request) {
        Long anchorId = request.getAnchorId();
        String requestId = request.getRequestId();
        long startTime = System.currentTimeMillis();

        log.info("[LiveStart] 开始开播流程, anchorId={}, requestId={}, title={}",
                anchorId, requestId, request.getTitle());

        // Step0: 幂等控制——防止主播快速双击"开始直播"导致重复创建
        if (!tryAcquireStartLock(anchorId, requestId)) {
            log.warn("[LiveStart] 重复开播请求被拦截, anchorId={}, requestId={}",
                    anchorId, requestId);
            return LiveStartResult.duplicate("正在开播中，请勿重复操作");
        }

        try {
            // Step1: 创建直播间
            LiveRoom room = createRoom(request);
            log.info("[LiveStart] 直播间创建成功, roomId={}, anchorId={}",
                    room.getId(), anchorId);

            // Step2: 状态流转 CREATED → PREPARED
            stateMachine.transition(room.getId(), RoomState.PREPARED);
            log.info("[LiveStart] 直播间状态流转至PREPARED, roomId={}", room.getId());

            // Step3: 生成推流地址（含CDN节点分配）
            PublishUrlResult publishResult = streamScheduleService.allocatePublishUrl(
                    anchorId, request.getClientIp());
            log.info("[LiveStart] 推流地址分配成功, roomId={}, streamName={}, nodeId={}",
                    room.getId(), publishResult.getStreamName(), publishResult.getNodeId());

            // Step4: 将推流信息写入直播间
            room.setStreamName(publishResult.getStreamName());
            roomRepository.save(room);

            // Step5: 状态流转 PREPARED → LIVE
            // 注意：此时主播还未真正推流，状态转为LIVE表示"等待推流"
            // 源站收到推流后会回调确认，此时才真正对观众可见
            stateMachine.transition(room.getId(), RoomState.LIVE);
            log.info("[LiveStart] 直播间状态流转至LIVE, roomId={}", room.getId());

            // Step6: 写入缓存
            cacheRoomInfo(room);
            log.info("[LiveStart] 直播间缓存写入完成, roomId={}", room.getId());

            // Step7: 写入搜索索引（异步）
            indexRoomToSearch(room);
            log.info("[LiveStart] 搜索索引写入完成, roomId={}", room.getId());

            // Step8: 通知关注用户（异步，通过MQ解耦）
            notifyFollowers(anchorId, room.getId());
            log.info("[LiveStart] 粉丝通知任务已投递, roomId={}", room.getId());

            long elapsed = System.currentTimeMillis() - startTime;
            log.info("[LiveStart] 开播流程完成, roomId={}, anchorId={}, elapsed={}ms",
                    room.getId(), anchorId, elapsed);

            return LiveStartResult.success(room.getId(), publishResult.getPublishUrl());

        } catch (StreamNotFoundException e) {
            log.error("[LiveStart] 推流调度失败, anchorId={}, error={}",
                    anchorId, e.getMessage(), e);
            throw new BizException("推流服务暂时不可用，请稍后重试");
        } catch (InvalidStateTransitionException e) {
            log.error("[LiveStart] 状态流转异常, anchorId={}, from={}, to={}",
                    anchorId, e.getFromState(), e.getToState(), e);
            throw new BizException("直播间状态异常，请刷新后重试");
        } catch (Exception e) {
            log.error("[LiveStart] 开播流程异常, anchorId={}, error={}",
                    anchorId, e.getMessage(), e);
            throw new BizException("开播失败，请稍后重试");
        } finally {
            // 释放幂等锁（延迟释放，防止极端并发场景下竞态）
            releaseStartLock(anchorId, requestId, 3);
        }
    }

    /**
     * 创建直播间
     */
    private LiveRoom createRoom(LiveStartRequest request) {
        // 校验标题长度
        if (request.getTitle() == null || request.getTitle().length() > 128) {
            throw new BizException("直播标题不能为空且不能超过128个字符");
        }

        // 校验封面URL
        if (request.getCoverUrl() == null || !request.getCoverUrl().startsWith("https://")) {
            throw new BizException("请上传合法的直播封面");
        }

        LiveRoom room = new LiveRoom();
        room.setTitle(request.getTitle());
        room.setAnchorId(request.getAnchorId());
        room.setState(RoomState.CREATED);
        room.setRoomType(RoomType.SINGLE);
        room.setCoverUrl(request.getCoverUrl());
        room.setCategoryId(request.getCategoryId());
        room.setPeakOnlineCount(0);
        room.setTotalViewCount(0L);
        room.setCreateTime(LocalDateTime.now());
        room.setUpdateTime(LocalDateTime.now());

        return roomRepository.save(room);
    }

    /**
     * 幂等控制：使用Redis分布式锁防止重复开播
     * key格式: live:start:lock:{anchorId}
     * value: requestId（用于区分不同请求）
     */
    private boolean tryAcquireStartLock(Long anchorId, String requestId) {
        String lockKey = "live:start:lock:" + anchorId;
        // 30秒过期，足够完成开播流程
        Boolean acquired = redisTemplate.opsForValue()
                .setIfAbsent(lockKey, requestId, 30, TimeUnit.SECONDS);
        return Boolean.TRUE.equals(acquired);
    }

    /**
     * 释放幂等锁
     * @param delaySeconds 延迟释放秒数，防止竞态
     */
    private void releaseStartLock(Long anchorId, String requestId, int delaySeconds) {
        String lockKey = "live:start:lock:" + anchorId;
        // 使用Lua脚本保证原子性：只有requestId匹配时才删除
        String luaScript =
                "if redis.call('get', KEYS[1]) == ARGV[1] then " +
                "  return redis.call('del', KEYS[1]) " +
                "else " +
                "  return 0 " +
                "end";
        // 延迟释放：将锁的TTL延长一段时间，防止极端并发
        redisTemplate.opsForValue().set(lockKey, requestId, delaySeconds, TimeUnit.SECONDS);
    }

    /**
     * 缓存直播间信息
     * 使用Hash结构存储，方便部分字段更新
     */
    private void cacheRoomInfo(LiveRoom room) {
        String roomKey = "room:info:" + room.getId();
        Map<String, String> roomInfo = new HashMap<>();
        roomInfo.put("roomId", room.getId().toString());
        roomInfo.put("title", room.getTitle());
        roomInfo.put("anchorId", room.getAnchorId().toString());
        roomInfo.put("state", room.getState().name());
        roomInfo.put("coverUrl", room.getCoverUrl());
        roomInfo.put("streamName", room.getStreamName());
        roomInfo.put("categoryId", room.getCategoryId() != null
                ? room.getCategoryId().toString() : "");
        roomInfo.put("startTime", room.getStartTime() != null
                ? room.getStartTime().toString() : "");

        redisTemplate.opsForHash().putAll(roomKey, roomInfo);
        // 直播期间缓存不过期，直播结束时主动清理
        redisTemplate.expire(roomKey, 24, TimeUnit.HOURS);

        // 将房间ID加入"正在直播"集合，用于首页推荐和列表查询
        redisTemplate.opsForSet().add("room:live:set", room.getId().toString());
    }

    /**
     * 将直播间信息写入Elasticsearch搜索索引
     * 异步执行，不阻塞开播主流程
     */
    private void indexRoomToSearch(LiveRoom room) {
        try {
            Map<String, Object> doc = new HashMap<>();
            doc.put("roomId", room.getId());
            doc.put("title", room.getTitle());
            doc.put("anchorId", room.getAnchorId());
            doc.put("categoryId", room.getCategoryId());
            doc.put("state", room.getState().name());
            doc.put("coverUrl", room.getCoverUrl());
            doc.put("startTime", System.currentTimeMillis());

                    .id(room.getId().toString())
                    .document(doc));
        } catch (Exception e) {
            // 索引写入失败不影响开播，记录日志后续补偿
            log.warn("[LiveStart] 搜索索引写入失败, roomId={}, error={}",
                    room.getId(), e.getMessage());
        }
    }

    /**
     * 通知关注该主播的用户
     * 通过MQ异步投递，避免阻塞开播主流程
     */
    private void notifyFollowers(Long anchorId, Long roomId) {

        event.setRoomId(roomId);
        event.setNotifyTime(System.currentTimeMillis());

    }
```

```java
/**
 * 主播开播通知消费者
 * 从MQ消费开播事件，查询粉丝列表并批量推送通知
 */
@Component
@Slf4j
public class AnchorLiveNotifyConsumer {

    @Autowired
    private FollowService followService;

    @Autowired
    private PushService pushService;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    /** 每批推送的粉丝数量 */
    private static final int BATCH_SIZE = 500;

    /**
     * 消费开播通知事件
     */
    @RocketMQMessageListener(topic = "topic_anchor_live_notify",
            consumerGroup = "cg_anchor_live_notify")
    public void onMessage(AnchorLiveNotifyEvent event) {
        Long anchorId = event.getAnchorId();
        Long roomId = event.getRoomId();

        log.info("[AnchorNotify] 收到开播通知事件, anchorId={}, roomId={}",
                anchorId, roomId);

        try {
            // 分批查询粉丝列表
            Long lastFollowId = 0L;
            int totalNotified = 0;

            while (true) {
                List<Long> followerIds = followService.getFollowers(
                        anchorId, lastFollowId, BATCH_SIZE);

                if (followerIds.isEmpty()) {
                    break;
                }

                // 批量推送"正在直播"通知
                for (Long followerId : followerIds) {
                    // 检查用户是否在线（通过长连接网关心跳判断）
                    if (isUserOnline(followerId)) {
                        PushMessage message = PushMessage.builder()
                                .type("ANCHOR_LIVE")
                                .anchorId(anchorId)
                                .roomId(roomId)
                                .timestamp(System.currentTimeMillis())
                                .build();
                        pushService.sendToUser(followerId, message);
                        totalNotified++;
                    }
                }

                lastFollowId = followerIds.get(followerIds.size() - 1);

                // 粉丝数量过多时，分批之间稍微延迟，避免推送洪峰
                if (followerIds.size() == BATCH_SIZE) {
                    Thread.sleep(50);
                }
            }

            log.info("[AnchorNotify] 开播通知推送完成, anchorId={}, roomId={}, notified={}",
                    anchorId, roomId, totalNotified);

        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            log.warn("[AnchorNotify] 通知推送被中断, anchorId={}", anchorId);
        } catch (Exception e) {
            log.error("[AnchorNotify] 通知推送异常, anchorId={}, roomId={}, error={}",
                    anchorId, roomId, e.getMessage(), e);
            // 抛出异常让MQ重试
            throw new RuntimeException(e);
        }
    }

    private boolean isUserOnline(Long userId) {
        String key = "user:online:" + userId;
        return Boolean.TRUE.equals(redisTemplate.hasKey(key));
    }
}
```

```java
/**
 * 观众进入直播间编排服务

@Service
@Slf4j
public class ViewerEnterOrchestrator {

    @Autowired
    private LiveRoomRepository roomRepository;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private PlayScheduleService playScheduleService;

    @Autowired
    private OnlineCountService onlineCountService;

    @Autowired
    private AnchorInfoService anchorInfoService;

    @Autowired
    private GiftPanelService giftPanelService;

    @Autowired
    private WebSocketSessionManager sessionManager;

    @Autowired
    private IpLocationService ipLocationService;

    /**
     * 观众进入直播间
     * @param userId 观众ID
     * @param roomId 直播间ID
     * @param clientIp 观众客户端IP
     * @param protocol 拉流协议
     * @return 进入直播间结果
     */
    public EnterRoomResult enterRoom(Long userId, Long roomId, String clientIp,
                                      StreamProtocol protocol) {
        long startTime = System.currentTimeMillis();
        log.info("[EnterRoom] 观众进入直播间, userId={}, roomId={}, protocol={}",
                userId, roomId, protocol);

        try {
            // Step1: 直播间状态校验
            LiveRoom room = validateRoomStatus(roomId);
            log.info("[EnterRoom] 直播间状态校验通过, roomId={}, state={}",
                    roomId, room.getState());

            // Step2: 获取拉流地址（CDN就近节点）
            PlayUrlResult playResult = playScheduleService.allocatePlayUrl(
                    room.getStreamName(), clientIp, protocol);
            log.info("[EnterRoom] 拉流地址分配成功, roomId={}, playUrl={}",
                    roomId, playResult.getPlayUrl());

            // Step3: 加载直播间聚合信息
            RoomAggregateInfo aggregateInfo = loadRoomAggregateInfo(room);
            log.info("[EnterRoom] 直播间信息加载完成, roomId={}, onlineCount={}",
                    roomId, aggregateInfo.getOnlineCount());

            // Step4: 观众加入房间（更新在线用户集合和计数）
            onlineCountService.userJoin(roomId, userId);
            // 记录观众进入时间，用于离开时计算观看时长
            recordViewerEnterTime(roomId, userId);
            log.info("[EnterRoom] 观众加入房间成功, roomId={}, userId={}",
                    roomId, userId);

            // Step5: 建立WebSocket连接（返回连接地址和token）
            WsConnectInfo wsInfo = allocateWebSocket(roomId, userId);
            log.info("[EnterRoom] WebSocket连接信息分配完成, roomId={}, userId={}",
                    roomId, userId);

            // Step6: 构建返回结果
            EnterRoomResult result = EnterRoomResult.builder()
                    .roomId(roomId)
                    .title(room.getTitle())
                    .coverUrl(room.getCoverUrl())
                    .playUrl(playResult.getPlayUrl())
                    .protocol(playResult.getProtocol())
                    .anchorInfo(aggregateInfo.getAnchorInfo())
                    .onlineCount(aggregateInfo.getOnlineCount())
                    .totalViewCount(aggregateInfo.getTotalViewCount())
                    .giftPanel(aggregateInfo.getGiftPanel())
                    .wsConnectInfo(wsInfo)
                    .build();

            long elapsed = System.currentTimeMillis() - startTime;
            log.info("[EnterRoom] 进入直播间完成, userId={}, roomId={}, elapsed={}ms",
                    userId, roomId, elapsed);

            return result;

        } catch (RoomNotFoundException e) {
            log.warn("[EnterRoom] 直播间不存在, roomId={}", roomId);
            throw new BizException("直播间不存在或已下线");
        } catch (RoomNotLiveException e) {
            log.warn("[EnterRoom] 直播间未在直播中, roomId={}, state={}",
                    roomId, e.getCurrentState());
            throw new BizException("直播已结束");
        } catch (StreamNotFoundException e) {
            log.error("[EnterRoom] 拉流地址分配失败, roomId={}, error={}",
                    roomId, e.getMessage());
            throw new BizException("暂时无法观看，请稍后重试");
        } catch (Exception e) {
            log.error("[EnterRoom] 进入直播间异常, userId={}, roomId={}, error={}",
                    userId, roomId, e.getMessage(), e);
            throw new BizException("进入直播间失败，请稍后重试");
        }
    }

    /**
     * 校验直播间状态
     * 只有LIVE状态的直播间允许进入
     */
    private LiveRoom validateRoomStatus(Long roomId) {
        // 优先从缓存读取状态
        String stateCacheKey = "room:state:" + roomId;
        String cachedState = redisTemplate.opsForValue().get(stateCacheKey);

        if (cachedState != null) {
            RoomState state = RoomState.valueOf(cachedState);
            if (state != RoomState.LIVE) {
                throw new RoomNotLiveException(state);
            }
        }

        // 缓存未命中或状态为LIVE，从数据库确认
        LiveRoom room = roomRepository.findById(roomId)
                .orElseThrow(() -> new RoomNotFoundException(roomId));

        if (room.getState() != RoomState.LIVE) {
            throw new RoomNotLiveException(room.getState());
        }

        return room;
    }

    /**
     * 加载直播间聚合信息
     * 将主播信息、在线人数、礼物面板等聚合返回，减少客户端多次请求
     */
    private RoomAggregateInfo loadRoomAggregateInfo(LiveRoom room) {
        RoomAggregateInfo info = new RoomAggregateInfo();

        // 主播信息（从缓存读取）
        AnchorInfo anchorInfo = anchorInfoService.getAnchorInfo(room.getAnchorId());
        info.setAnchorInfo(anchorInfo);

        // 在线人数
        long onlineCount = onlineCountService.getOnlineCount(room.getId());
        info.setOnlineCount(onlineCount);

        // 累计观看人次
        long totalViewCount = onlineCountService.getTotalViewCount(room.getId());
        info.setTotalViewCount(totalViewCount);

        // 礼物面板（从缓存读取，主播可配置礼物清单）
        List<GiftInfo> giftPanel = giftPanelService.getGiftPanel(room.getAnchorId());
        info.setGiftPanel(giftPanel);

        return info;

    /**
     * 记录观众进入时间
     * 用于离开时计算观看时长，以及生成观看行为日志
     */
    private void recordViewerEnterTime(Long roomId, Long userId) {
        String enterTimeKey = "room:enter:time:" + roomId + ":" + userId;
        redisTemplate.opsForValue().set(enterTimeKey,
                String.valueOf(System.currentTimeMillis()), 4, TimeUnit.HOURS);
    }

    /**
     * 分配WebSocket连接信息
     * 根据用户IP选择就近的长连接网关节点
     */
    private WsConnectInfo allocateWebSocket(Long roomId, Long userId) {
        IpLocation location = ipLocationService.resolve(
                RequestContextHolder.getClientIp());

        // 选择WebSocket网关节点
        String wsGatewayUrl = selectWsGateway(location);

        // 生成WebSocket连接token
        String wsToken = generateWsToken(roomId, userId);

        return WsConnectInfo.builder()
                .wsUrl(wsGatewayUrl + "/ws/live")
                .token(wsToken)
                .roomId(roomId.toString())
                .userId(userId.toString())
                .heartbeatInterval(30) // 30秒心跳
                .build();
    }

    private String selectWsGateway(IpLocation location) {
        // 简化实现：根据运营商选择网关
        // 生产环境中会根据网关负载、健康状态动态选择
        return "wss://ws-gateway-" + location.getIsp() + ".live.example.com";
    }

    private String generateWsToken(Long roomId, Long userId) {
        String raw = roomId + ":" + userId + ":" + System.currentTimeMillis();
        return DigestUtils.sha256Hex(raw);
    }
```

#### 7.2.3 WebSocket连接建立与消息分发

```java
/**
 * WebSocket连接处理器
 * 处理观众与长连接网关之间的连接生命周期
 */
@Component
@Slf4j
public class LiveWebSocketHandler extends TextWebSocketHandler {

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private OnlineCountService onlineCountService;

    @Autowired
    private WsTokenService wsTokenService;

    /** 房间 → 在线WebSocket Session集合 */
    private final Map<Long, Set<WebSocketSession>> roomSessions = new ConcurrentHashMap<>();

    /** 用户 → WebSocket Session */
    private final Map<Long, WebSocketSession> userSessions = new ConcurrentHashMap<>();

    /**
     * 连接建立
     */
    @Override
    public void afterConnectionEstablished(WebSocketSession session) throws Exception {
        Long userId = (Long) session.getAttributes().get("userId");
        Long roomId = (Long) session.getAttributes().get("roomId");
        String token = (String) session.getAttributes().get("token");

        log.info("[WebSocket] 连接建立, userId={}, roomId={}, sessionId={}",
                userId, roomId, session.getId());

        try {
            // 校验token有效性
            if (!wsTokenService.validateToken(token, roomId, userId)) {
                log.warn("[WebSocket] Token校验失败, userId={}, roomId={}", userId, roomId);
                session.close(CloseStatus.POLICY_VIOLATION);
                return;
            }

            // 将session加入房间集合
            roomSessions.computeIfAbsent(roomId, k -> ConcurrentHashMap.newKeySet())
                    .add(session);
            userSessions.put(userId, session);

            // 记录用户WebSocket在线状态
            String onlineKey = "user:online:" + userId;
            redisTemplate.opsForValue().set(onlineKey, roomId.toString(),
                    90, TimeUnit.SECONDS); // 3个心跳周期

            log.info("[WebSocket] 用户加入房间成功, roomId={}, userId={}, roomOnline={}",
                    roomId, userId, getRoomOnlineCount(roomId));

        } catch (Exception e) {
            log.error("[WebSocket] 连接建立异常, userId={}, roomId={}, error={}",
                    userId, roomId, e.getMessage(), e);
            session.close(CloseStatus.SERVER_ERROR);
        }
    }

    /**
     * 收到消息（主要是心跳和弹幕）
     */
    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) {
        Long userId = (Long) session.getAttributes().get("userId");
        Long roomId = (Long) session.getAttributes().get("roomId");

        try {
            JsonNode node = objectMapper.readTree(message.getPayload());
            String type = node.get("type").asText();

            switch (type) {
                case "heartbeat":
                    // 心跳续约
                    handleHeartbeat(session, userId, roomId);
                    break;
                case "barrage":
                    // 弹幕消息由HTTP接口处理，WebSocket仅做接收确认
                    break;
                default:
                    log.debug("[WebSocket] 未知消息类型, userId={}, type={}", userId, type);
            }
        } catch (Exception e) {
            log.warn("[WebSocket] 消息处理异常, userId={}, error={}",
                    userId, e.getMessage());
        }
    }

    /**
     * 心跳处理
     */
    private void handleHeartbeat(WebSocketSession session, Long userId, Long roomId) {
        // 续约在线状态
        String onlineKey = "user:online:" + userId;
        redisTemplate.opsForValue().set(onlineKey, roomId.toString(),
                90, TimeUnit.SECONDS);

        // 续约直播间心跳
        onlineCountService.heartbeat(roomId, userId);

        // 回复心跳
        try {
            session.sendMessage(new TextMessage(
                    "{\"type\":\"heartbeat_ack\",\"timestamp\":"
                    + System.currentTimeMillis() + "}"));
        } catch (IOException e) {
            log.warn("[WebSocket] 心跳回复失败, userId={}", userId);
        }
    }

    /**
     * 连接关闭
     */
    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
        Long userId = (Long) session.getAttributes().get("userId");
        Long roomId = (Long) session.getAttributes().get("roomId");

        log.info("[WebSocket] 连接关闭, userId={}, roomId={}, status={}",
                userId, roomId, status);

        try {
            // 从房间集合移除
            Set<WebSocketSession> sessions = roomSessions.get(roomId);
            if (sessions != null) {
                sessions.remove(session);
                // 房间没有在线用户时清理
                if (sessions.isEmpty()) {
                    roomSessions.remove(roomId);
                }
            }
            userSessions.remove(userId);

            // 触发观众离开流程
            handleViewerLeave(roomId, userId);

        } catch (Exception e) {
            log.error("[WebSocket] 连接关闭处理异常, userId={}, roomId={}, error={}",
                    userId, roomId, e.getMessage(), e);
        }
    }

    /**
     * 观众离开处理
     */
    private void handleViewerLeave(Long roomId, Long userId) {
        // 更新在线人数
        onlineCountService.userLeave(roomId, userId);

        // 删除在线状态
        redisTemplate.delete("user:online:" + userId);

        // 计算观看时长
        String enterTimeKey = "room:enter:time:" + roomId + ":" + userId;
        String enterTimeStr = redisTemplate.opsForValue().get(enterTimeKey);
        if (enterTimeStr != null) {
            long enterTime = Long.parseLong(enterTimeStr);
            long watchDuration = (System.currentTimeMillis() - enterTime) / 1000;
            log.info("[WebSocket] 观众离开, roomId={}, userId={}, watchDuration={}s",
                    roomId, userId, watchDuration);

            // 异步记录观看行为日志（用于数据分析）
            recordWatchBehavior(roomId, userId, watchDuration);
            redisTemplate.delete(enterTimeKey);
        }
    }

    /**
     * 向房间内所有在线观众广播消息
     */
    public void broadcastToRoom(Long roomId, String message) {
        Set<WebSocketSession> sessions = roomSessions.get(roomId);
        if (sessions == null || sessions.isEmpty()) {
            return;
        }

        TextMessage textMessage = new TextMessage(message);
        for (WebSocketSession session : sessions) {
            if (session.isOpen()) {
                try {
                    session.sendMessage(textMessage);
                } catch (IOException e) {
                    log.warn("[WebSocket] 消息推送失败, sessionId={}, error={}",
                            session.getId(), e.getMessage());
                }
            }
        }
    }

    private int getRoomOnlineCount(Long roomId) {
        Set<WebSocketSession> sessions = roomSessions.get(roomId);
        return sessions != null ? sessions.size() : 0;
    }

    private void recordWatchBehavior(Long roomId, Long userId, long watchDuration) {
        // 异步写入行为日志表，用于数据分析
        CompletableFuture.runAsync(() -> {
            // 实际场景中写入HBase或Kafka
            log.debug("[WatchLog] roomId={}, userId={}, duration={}s",
                    roomId, userId, watchDuration);
        });
    }
}
```

#### 7.3.2 全链路打赏编排服务

```java
/**
 * 礼物打赏全链路编排服务
 * 在GiftService的基础上，串联排行榜更新、特效广播、主播入账等完整流程
 */
@Service
@Slf4j
public class GiftOrchestrator {

    @Autowired
    private GiftService giftService;

    @Autowired
    private AccountService accountService;

    @Autowired
    private GiftRankService rankService;

    @Autowired
    private LiveWebSocketHandler wsHandler;

    @Autowired
    private MessageQueueProducer mqProducer;

    @Autowired
    private RedisTemplate<String, String> redisTemplate;

    @Autowired
    private GiftComboService comboService;

    @Autowired
    private GiftRepository giftRepository;

    /**
     * 送礼物全链路入口
     * @param request 打赏请求
     * @return 打赏结果
     */
    public GiftSendResult sendGift(GiftSendRequest request) {
        Long senderId = request.getSenderId();
        Long roomId = request.getRoomId();
        Long anchorId = request.getAnchorId();
        Long giftId = request.getGiftId();
        int count = request.getCount();
        String clientRequestId = request.getClientRequestId();

        long startTime = System.currentTimeMillis();
        log.info("[GiftOrchestrator] 送礼物请求, senderId={}, roomId={}, giftId={}, count={}, clientRequestId={}",
                senderId, roomId, giftId, count, clientRequestId);

        try {
            // Step1: 客户端幂等控制（基于clientRequestId）
            // 防止网络抖动导致客户端重试，同一个clientRequestId只处理一次
            GiftSendResult idempotentResult = checkClientRequestId(clientRequestId);
            if (idempotentResult != null) {
                log.info("[GiftOrchestrator] 幂等命中, clientRequestId={}, senderId={}",
                        clientRequestId, senderId);
                return idempotentResult;
            }

            // Step2: 调用核心打赏流程（预扣款 + 流水记录 + MQ投递）
            GiftSendResult result = giftService.sendGift(
                    senderId, roomId, anchorId, giftId, count);

            if (!result.isSuccess()) {
                log.warn("[GiftOrchestrator] 打赏失败, senderId={}, reason={}",
                        senderId, result.getMessage());
                return result;
            }

            log.info("[GiftOrchestrator] 扣款成功, senderId={}, orderId={}, amount={}",
                    senderId, result.getOrderId(), result.getTotalAmount());

            // Step3: 更新礼物排行榜（Redis ZSET）
            rankService.updateRank(roomId, senderId, result.getTotalAmount());
            rankService.updateAnchorIncomeRank(anchorId, result.getTotalAmount());
            log.info("[GiftOrchestrator] 排行榜更新完成, roomId={}, senderId={}",
                    roomId, senderId);

            // Step4: 礼物特效广播（WebSocket推送到房间所有观众）
            broadcastGiftEffect(roomId, senderId, anchorId, giftId, count, result);
            log.info("[GiftOrchestrator] 礼物特效广播完成, roomId={}", roomId);

            // Step5: 记录客户端幂等标记
            markClientRequestId(clientRequestId, result);

            // Step6: 处理连击逻辑
            comboService.handleCombo(senderId, roomId, giftId, count);

            long elapsed = System.currentTimeMillis() - startTime;
            log.info("[GiftOrchestrator] 送礼物全链路完成, senderId={}, roomId={}, orderId={}, elapsed={}ms",
                    senderId, roomId, result.getOrderId(), elapsed);

            return result;

        } catch (InsufficientBalanceException e) {
            log.warn("[GiftOrchestrator] 余额不足, senderId={}", senderId);
            return GiftSendResult.fail("余额不足，请充值");
        } catch (DuplicateGiftException e) {
            log.info("[GiftOrchestrator] 重复打赏被拦截, senderId={}, roomId={}",
                    senderId, roomId);
            return GiftSendResult.duplicate("礼物已发送，请勿重复操作");
        } catch (Exception e) {
            log.error("[GiftOrchestrator] 送礼物异常, senderId={}, roomId={}, error={}",
                    senderId, roomId, e.getMessage(), e);
            // 异常时回滚幂等标记，允许客户端重试
            clearClientRequestId(clientRequestId);
            throw new BizException("送礼物失败，请稍后重试");
        }
    }

    /**
     * 客户端幂等控制
     * 基于客户端生成的唯一requestId，防止网络重试导致重复扣款
     */
    private GiftSendResult checkClientRequestId(String clientRequestId) {
        if (clientRequestId == null) {
            return null;
        }
        String key = "gift:client:req:" + clientRequestId;
        String cached = redisTemplate.opsForValue().get(key);
        if (cached != null) {
            // 返回之前的结果
            return GiftSendResult.duplicate("请求已处理");
        }
        return null;
    }

    private void markClientRequestId(String clientRequestId, GiftSendResult result) {
        if (clientRequestId == null) return;
        String key = "gift:client:req:" + clientRequestId;
        redisTemplate.opsForValue().set(key, result.getOrderId(), 60, TimeUnit.SECONDS);
    }

    private void clearClientRequestId(String clientRequestId) {
        if (clientRequestId == null) return;
        redisTemplate.delete("gift:client:req:" + clientRequestId);
    }

    /**
     * 广播礼物特效到直播间所有观众
     */
    private void broadcastGiftEffect(Long roomId, Long senderId, Long anchorId,
                                      Long giftId, int count, GiftSendResult result) {
        GiftEffectMessage message = GiftEffectMessage.builder()
                .type("GIFT_EFFECT")
                .roomId(roomId)
                .senderId(senderId)
                .anchorId(anchorId)
                .giftId(giftId)
                .count(count)
                .orderId(result.getOrderId())
                .timestamp(System.currentTimeMillis())
                .build();

        // 直接通过WebSocket广播（礼物消息为CRITICAL优先级，不走聚合窗口）
        wsHandler.broadcastToRoom(roomId, JsonUtils.toJson(message));
    }
}
```

```java
@Service

            log.error("[GiftRank] 排行榜更新异常, roomId={}, senderId={}, error={}",
                    roomId, senderId, e.getMessage(), e);
        }
    }

    /**
     * 更新主播收入排行榜
     */
    public void updateAnchorIncomeRank(Long anchorId, long amount) {
        try {
            String key = ANCHOR_INCOME_RANK_PREFIX + getDateStr();
            redisTemplate.opsForZSet().incrementScore(key,
                    anchorId.toString(), amount);
            redisTemplate.expire(key, 7, TimeUnit.DAYS);
        } catch (Exception e) {
            log.error("[GiftRank] 主播收入榜更新异常, anchorId={}, error={}",
                    anchorId, e.getMessage(), e);
        }
    }

    /**
     * 获取直播间打赏排行榜TopN
     */
    public List<RankItem> getRoomDailyRank(Long roomId, int topN) {
        String key = DAILY_RANK_PREFIX + "room:" + roomId + ":" + getDateStr();
        Set<ZSetOperations.TypedTuple<String>> tuples =
                redisTemplate.opsForZSet().reverseRangeWithScores(key, 0, topN - 1);

        if (tuples == null || tuples.isEmpty()) {
            return Collections.emptyList();
        }

        List<RankItem> rankList = new ArrayList<>();
        int rank = 1;
        for (ZSetOperations.TypedTuple<String> tuple : tuples) {
            RankItem item = new RankItem();
            item.setRank(rank++);
            item.setUserId(Long.parseLong(tuple.getValue()));
            item.setAmount(tuple.getScore().longValue());
            rankList.add(item);
        }
        return rankList;
    }

        return LocalDate.now().format(DateTimeFormatter.ofPattern("yyyyMMdd"));
```

#### 7.3.5 高并发合并推送策略

热门直播间可能每秒产生数千个礼物，直接逐条推送会导致WebSocket网关压力过大。以下是合并推送策略的实现：

```java
/**
 * 礼物消息合并推送服务
 * 在聚合窗口内合并同一房间的礼物消息，批量推送给观众
 *
 * 设计思路：
 * 1. 礼物消息先写入每个房间的缓冲队列
 * 2. 定时任务每200ms扫描一次所有缓冲队列
 * 3. 将缓冲队列中的礼物合并为一条批量消息推送
 * 4. 合并策略：同一用户送同一礼物合并为连击，不同礼物分别展示
 */
@Component
@Slf4j
public class GiftMessageBatchPusher {

    /** 聚合窗口：200ms */
    private static final long AGGREGATE_WINDOW_MS = 200;

    /** 单次推送最大礼物条数 */
    private static final int MAX_BATCH_SIZE = 50;

    @Autowired
    private LiveWebSocketHandler wsHandler;

    /** 每个房间的礼物消息缓冲区 */
    private final Map<Long, List<GiftEffectMessage>> roomGiftBuffers = new ConcurrentHashMap<>();

    /**
     * 将礼物消息加入缓冲区
     */
    public void bufferGiftMessage(Long roomId, GiftEffectMessage message) {
        roomGiftBuffers.computeIfAbsent(roomId, k -> new CopyOnWriteArrayList<>())
                .add(message);
    }

    /**
     * 定时任务：每200ms刷新一次缓冲区，合并推送
     */
    @Scheduled(fixedRate = 200)
    public void flushBuffers() {
        for (Map.Entry<Long, List<GiftEffectMessage>> entry : roomGiftBuffers.entrySet()) {
            Long roomId = entry.getKey();
            List<GiftEffectMessage> buffer = entry.getValue();

            if (buffer.isEmpty()) {
                continue;
            }

            try {
                // 合并同一用户送同一礼物的消息
                List<GiftEffectMessage> merged = mergeMessages(buffer);
                buffer.clear();

                // 如果合并后仍超过最大条数，分批推送
                for (int i = 0; i < merged.size(); i += MAX_BATCH_SIZE) {
                    int end = Math.min(i + MAX_BATCH_SIZE, merged.size());
                    List<GiftEffectMessage> batch = merged.subList(i, end);

                    GiftBatchMessage batchMessage = new GiftBatchMessage(roomId, batch);
                    wsHandler.broadcastToRoom(roomId, JsonUtils.toJson(batchMessage));
                }

                if (merged.size() > 10) {
                    log.debug("[GiftBatchPush] 房间{}合并推送{}条礼物消息", roomId, merged.size());
                }

            } catch (Exception e) {
                log.error("[GiftBatchPush] 合并推送异常, roomId={}, error={}",
                        roomId, e.getMessage(), e);
                buffer.clear(); // 清空缓冲区，防止积压
            }
        }
    }

    /**
     * 合并礼物消息
     * 策略：同一用户 + 同一礼物 → 合并为一条（累加数量）
     */
    private List<GiftEffectMessage> mergeMessages(List<GiftEffectMessage> messages) {
        // 使用 "senderId:giftId" 作为合并键
        Map<String, GiftEffectMessage> mergedMap = new LinkedHashMap<>();

        for (GiftEffectMessage msg : messages) {
            String mergeKey = msg.getSenderId() + ":" + msg.getGiftId();
            GiftEffectMessage existing = mergedMap.get(mergeKey);

            if (existing != null) {
                // 合并：累加数量
                existing.setCount(existing.getCount() + msg.getCount());
                existing.setTimestamp(msg.getTimestamp()); // 使用最新时间戳
            } else {
                // 复制一份，避免修改原始对象
                GiftEffectMessage copy = GiftEffectMessage.builder()
                        .type(msg.getType())
                        .roomId(msg.getRoomId())
                        .senderId(msg.getSenderId())
                        .anchorId(msg.getAnchorId())
                        .giftId(msg.getGiftId())
                        .count(msg.getCount())
                        .orderId(msg.getOrderId())
                        .timestamp(msg.getTimestamp())
                        .build();
                mergedMap.put(mergeKey, copy);
            }
        }

        return new ArrayList<>(mergedMap.values());
    }

    /**
     * 定时清理空缓冲区，防止内存泄漏
     */
    @Scheduled(fixedRate = 60000)
    public void cleanEmptyBuffers() {
        roomGiftBuffers.entrySet().removeIf(entry -> entry.getValue().isEmpty());
    }
}
```

#### 7.3.7 异常场景与补偿机制

| 异常场景 | 处理策略 | 补偿机制 |
|----------|----------|----------|
| 扣款成功但MQ发送失败 | 本地事务表记录待发送事件 | 定时任务扫描重发 |
| MQ消费失败（主播入账失败） | MQ自动重试（最多3次） | 重试失败后转入死信队列，人工处理 |
| WebSocket推送失败 | 礼物特效丢失，不影响资金 | 客户端可通过礼物流水接口补拉 |
| 排行榜更新失败 | 不影响打赏主流程 | 定时任务从数据库补偿同步 |
| 连击处理失败 | 不影响打赏主流程 | 记录日志，下次连击重新计数 |

```java
/**
 * 礼物事件补偿服务
 * 定时扫描本地事务表，重发未确认的MQ消息
 * 保证"扣款成功 → 主播入账"的最终一致性
 */
@Component
@Slf4j
public class GiftEventCompensationService {

    @Autowired
    private LocalTransactionTable txTable;

    @Autowired
    private MessageQueueProducer mqProducer;

    @Autowired
    private GiftRepository giftRepository;

    /**
     * 每30秒扫描一次未确认的礼物事件
     */
    @Scheduled(fixedRate = 30000)
    public void compensateUnconfirmedEvents() {
        List<LocalTxRecord> unconfirmed = txTable.findUnconfirmed(
                "GIFT_SEND", 50); // 每次最多处理50条

        if (unconfirmed.isEmpty()) {
            return;
        }

        log.info("[GiftCompensate] 发现{}条未确认的礼物事件", unconfirmed.size());

        for (LocalTxRecord tx : unconfirmed) {
            try {
                // 检查礼物流水是否已结算
                GiftRecord record = giftRepository.findByOrderId(tx.getBusinessId());
                if (record != null && record.getStatus() == GiftRecordStatus.SETTLED) {
                    // 已结算，直接标记为已确认
                    txTable.markConfirmed(tx.getId());
                    continue;
                }

                // 重新发送MQ
                GiftEvent event = new GiftEvent(record);
                mqProducer.send("topic_gift", record.getRoomId().toString(), event);

                // 重试次数+1，超过5次告警
                txTable.incrementRetryCount(tx.getId());
                if (tx.getRetryCount() >= 5) {
                    log.error("[GiftCompensate] 礼物事件重试超过5次, orderId={}, 需人工介入",
                            tx.getBusinessId());
                    triggerAlert(tx);
                }

            } catch (Exception e) {
                log.error("[GiftCompensate] 补偿重发异常, orderId={}, error={}",
                        tx.getBusinessId(), e.getMessage(), e);
            }
        }
    }

    private void triggerAlert(LocalTxRecord tx) {
        // 触发运维告警（大象通知/邮件/短信）
        log.error("[GiftCompensate] ALERT: 补偿失败告警, businessId={}, retryCount={}",
                tx.getBusinessId(), tx.getRetryCount());
    }
}
```
