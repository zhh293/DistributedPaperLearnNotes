# Elasticsearch 高亮搜索功能使用指南

## 功能简介

本项目实现了 Elasticsearch 的高亮搜索功能，允许在搜索结果中高亮显示匹配的文本片段。高亮功能在搜索应用中非常有用，因为它可以帮助用户快速识别搜索词在文档中的具体位置。

## 功能特性

1. **多种搜索模式**:
   - 全文搜索（match）
   - 精确搜索（term）
   - 多字段搜索（multi-match）
   - 分页搜索

2. **灵活的高亮配置**:
   - 可自定义高亮字段
   - 可配置高亮标签样式
   - 支持片段大小控制

3. **前端友好**:
   - 提供直观的Web界面
   - 实时展示高亮效果
   - 清晰的结果展示

## 使用步骤

### 1. 启动应用

首先确保您的 Elasticsearch 服务正在运行，然后启动 Spring Boot 应用：

```bash
mvn spring-boot:run
```

应用将在 `http://localhost:8080` 上运行。

### 2. 准备测试数据

在使用高亮搜索之前，您需要确保 Elasticsearch 中有相应的索引和文档。如果还没有测试数据，可以通过以下 API 添加一些示例数据：

```bash
# 创建索引
curl -X PUT "localhost:9200/users"

# 添加示例文档
curl -X POST "localhost:9200/users/_doc/1" -H "Content-Type: application/json" -d'
{
  "name": "张三",
  "age": 25,
  "sex": "男",
  "tags": ["开发者", "Java", "Spring Boot"]
}'
```

### 3. 使用 Web 界面

打开浏览器访问 `http://localhost:8080/`，点击"进入高亮搜索页面"按钮，即可使用图形界面进行高亮搜索。

在搜索页面中，您可以：
- 输入搜索关键词
- 选择搜索类型（全文搜索、精确搜索、多字段搜索）
- 选择搜索字段
- 指定需要高亮的字段
- 查看高亮后的搜索结果

### 4. 直接使用 API

您也可以直接调用 API 进行搜索：

```bash
# 全文高亮搜索
curl "http://localhost:8080/es/highlight/search/match/users/name/张三?highlightFields=name,tags"

# 多字段高亮搜索
curl "http://localhost:8080/es/highlight/search/multi/users/Java?searchFields=name,tags&highlightFields=name,tags"
```

## 高亮效果

搜索结果中的高亮部分会被 `<mark class='highlight'>` 和 `</mark>` 标签包围，前端会将其显示为黄色背景的突出文本。

## 技术架构

### 后端架构

- **HighlightSearchService**: 核心搜索服务，负责构建 Elasticsearch 查询和处理高亮配置
- **HighlightSearchController**: REST API 控制器，对外暴露搜索接口
- **HighlightSearchResult**: 搜索结果包装类，包含原始文档和高亮信息
- **User**: 数据模型类

### 前端架构

- **highlight-search.html**: 搜索界面，提供用户交互功能
- **JavaScript**: 处理搜索请求和结果显示
- **CSS**: 样式美化和高亮效果展示

## 自定义配置

### 修改高亮样式

如果您想更改高亮的视觉效果，可以在 `HighlightSearchService` 中修改 `buildHighlight` 方法中的标签配置：

```java
highlightBuilder.fields(field, new HighlightField.Builder()
    .preTags("<span class='my-highlight'>")  // 修改为自定义样式
    .postTags("</span>")
    .fragmentSize(150)
    .numberOfFragments(3)
    .build());
```

### 调整搜索参数

您还可以调整片段大小、返回片段数量等参数以优化搜索结果：

- `fragmentSize`: 控制每个高亮片段的最大长度
- `numberOfFragments`: 控制返回的高亮片段数量
- `preTags/postTags`: 定义高亮文本的开始和结束标签

## 故障排除

如果遇到问题，请检查以下几点：

1. Elasticsearch 服务是否正常运行
2. 指定的索引是否存在
3. 搜索字段是否存在于文档中
4. 网络连接是否正常
