ELK高亮搜索系统

高亮搜索功能
支持在搜索结果中高亮显示匹配的关键字，便于用户快速定位相关内容。
进入高亮搜索页面
API 接口说明
全文高亮搜索: GET /es/highlight/search/match/{indexName}/{fieldName}/{value}?highlightFields={fields}
精确高亮搜索: GET /es/highlight/search/term/{indexName}/{fieldName}/{value}?highlightFields={fields}
多字段高亮搜索: GET /es/highlight/search/multi/{indexName}/{value}?searchFields={fields}&highlightFields={fields}
分页高亮搜索: GET /es/highlight/search/paginated/{indexName}?query={query}&searchFields={fields}&highlightFields={fields}&page={page}&size={size}
功能特点
  • 支持多种搜索模式：全文搜索、精确搜索、多字段搜索
  • 可自定义高亮字段
  • 前端实时展示高亮效果
  • 支持分页查询
  • 灵活的高亮样式定制
