这份文档的核心是 Spring AI 中 Prompt（提示词）的核心组件与使用方法，日常开发中最常用的就是 Message 角色定义 + PromptTemplate 动态模板，下面帮你提炼出核心知识点 + 高频用法，省略冗余细节：
一、Prompt 核心定位
Prompt 是 AI 模型的输入载体，类比 Spring MVC 的 View 或带占位符的 SQL —— 它由多条不同角色的 Message 组成，还可携带模型参数（如 temperature），最终通过 ChatModel.call(prompt) 发送给 AI 模型。
二、核心组件（日常开发必用）
1. Message：Prompt 的最小组成单元
   Message 是承载文本内容的对象，核心是「角色（MessageType）」—— 不同角色告诉 AI 模型这条消息的用途，决定模型的响应逻辑。


核心角色	作用	日常使用频率
SYSTEM	设定 AI 的行为准则、角色身份（如 “你是一个 Java 技术顾问，回答简洁”）	✅ 高频（几乎所有场景都要设置）
USER	代表用户的输入（问题、指令）	✅ 最高频（每次请求都有）
ASSISTANT	代表 AI 之前的响应，用于维护对话上下文（搭配聊天记忆 Advisor 使用）	✅ 中高频（多轮对话必备）
TOOL	工具调用的返回结果（如调用函数获取数据后，传给模型做进一步处理）



// 1. 创建用户消息（最基础）
Message userMsg = new UserMessage("什么是 Spring AI？");

// 2. 创建系统消息（设定 AI 角色）
Message systemMsg = new SystemMessage("你是一个简洁的技术助手，回答不超过50字");

// 3. 多轮对话中，添加 AI 之前的响应（assistant 消息）
Message assistantMsg = new AssistantMessage("Spring AI 是 Spring 生态的 AI 开发框架");





2. Prompt：Message 的容器
   Prompt 本质是 Message 列表 + 模型配置（ChatOptions），作用是把多条不同角色的 Message 组合成完整的输入，传给 AI 模型。
   核心用法：
   java
   运行
   // 组合多条 Message 成 Prompt
   List<Message> messages = Arrays.asList(systemMsg, userMsg, assistantMsg);
   // 可选：设置模型参数（如 temperature 控制随机性）
   ChatOptions options = OpenAiChatOptions.builder().temperature(0.3).build();

Prompt prompt = new Prompt(messages, options);

// 发送给模型获取响应
ChatResponse response = chatModel.call(prompt);
String content = response.getResult().getOutput().getContent();






3. PromptTemplate：动态提示词模板（日常开发最核心）
   PromptTemplate 是解决硬编码提示词的关键，支持占位符动态替换，类比 String.format() 但更灵活。
   默认模板语法：{变量名}（基于 StringTemplate 引擎）
   核心能力：动态渲染模板 → 生成 Message 或 Prompt
   （1）基础用法：动态替换占位符
   java
   运行
   // 1. 定义带占位符的模板
   String templateText = "推荐 {count} 本 {type} 领域的经典书籍，回答简洁";
   PromptTemplate promptTemplate = new PromptTemplate(templateText);

// 2. 传入参数渲染模板 → 生成 String
String renderedText = promptTemplate.render(Map.of("count", 3, "type", "微服务"));
// renderedText = "推荐 3 本 微服务 领域的经典书籍，回答简洁"

// 3. 直接生成 Prompt（更常用）
Prompt prompt = promptTemplate.create(Map.of("count", 3, "type", "微服务"));


（2）高频场景：多角色 Message 模板（System + User）
日常开发中，SystemMessage 通常带动态参数，可用 SystemPromptTemplate 简化：
java
运行
// 1. System 消息模板（带占位符）
String systemTemplate = "你是一个 {role}，回答风格要 {style}";
SystemPromptTemplate systemPromptTemplate = new SystemPromptTemplate(systemTemplate);
// 渲染生成 SystemMessage
Message systemMsg = systemPromptTemplate.createMessage(Map.of("role", "Java顾问", "style", "专业"));

// 2. User 消息模板
String userTemplate = "解释一下 {tech} 的核心原理";
PromptTemplate userPromptTemplate = new PromptTemplate(userTemplate);
Message userMsg = userPromptTemplate.createMessage(Map.of("tech", "Spring Bean"));

// 3. 组合成 Prompt
Prompt prompt = new Prompt(Arrays.asList(systemMsg, userMsg));
（3）关键技巧：自定义模板分隔符（避免 JSON 冲突）
默认 {} 分隔符如果和提示词中的 JSON 冲突（比如要求模型输出 JSON），可以自定义分隔符（如 <>）：
java
运行
// 自定义渲染器，分隔符改为 < >
StTemplateRenderer renderer = StTemplateRenderer.builder()
.startDelimiterToken('<')
.endDelimiterToken('>')
.build();

// 模板中用 <变量名>
PromptTemplate promptTemplate = PromptTemplate.builder()
.template("生成一个 <field> 为 <value> 的 JSON 对象")
.renderer(renderer)
.build();

// 渲染
String rendered = promptTemplate.render(Map.of("field", "name", "value", "Spring AI"));
// rendered = "生成一个 name 为 Spring AI 的 JSON 对象"
（4）实用技巧：从外部文件加载模板（Resource）
把提示词写在外部文件（如 classpath:/prompts/system.st），避免硬编码，方便维护：
java
运行
// 1. 注入外部模板文件（Spring 环境下）
@Value("classpath:/prompts/system.st")
private Resource systemResource;

// 2. 直接加载为 SystemPromptTemplate
SystemPromptTemplate systemPromptTemplate = new SystemPromptTemplate(systemResource);

// 3. 渲染使用
Message systemMsg = systemPromptTemplate.createMessage(Map.of("role", "技术助手"));
三、日常开发高频组合用法
场景：用 PromptTemplate 定义系统角色，接收用户动态输入，生成完整 Prompt 调用模型
java
运行
// 1. 配置系统模板（固定角色）
String systemText = "你是一个 {role}，回答不超过 {limit} 字";
SystemPromptTemplate systemTemplate = new SystemPromptTemplate(systemText);
Message systemMsg = systemTemplate.createMessage(Map.of("role", "Java顾问", "limit", 100));

// 2. 接收用户动态输入
String userInput = "什么是 Spring Boot？";
Message userMsg = new UserMessage(userInput);

// 3. 组合 Prompt 并调用
Prompt prompt = new Prompt(Arrays.asList(systemMsg, userMsg));
String response = chatModel.call(prompt).getResult().getOutput().getContent();
四、提示词工程最佳实践（写好提示词的关键）
文档里提到的提示词设计技巧，日常开发直接套用：
指令清晰：明确告诉 AI 要做什么（如 “解释 Spring AI，分 3 点说明”）；
添加上下文：给 AI 补充必要背景（如 “基于 Spring AI 1.0 版本”）；
指定输出格式：要求 AI 按固定格式返回（如 “输出 JSON 格式，字段包括 name、description”）；
示例引导：复杂任务给 AI 举例子（如 “参考格式：{name: 'Spring AI', desc: 'xxx'}”）。
五、Token 基础认知（避坑必备）
Token 是 AI 模型处理文本的最小单位，1 个 Token ≈ 0.75 个英文单词；
每个模型有最大上下文窗口（如 GPT-3.5 是 4k Token），Prompt + 响应的总 Token 不能超过这个限制；
日常开发注意：长文本 Prompt 要做截断，避免超出 Token 限制导致报错。
核心总结（日常开发就用这些）
最常用组件：SystemMessage（定角色） + UserMessage（传输入） + PromptTemplate（动态模板）；
核心流程：写模板 → 渲染 Message → 组合 Prompt → 调用模型；
关键技巧：用外部文件存模板、自定义分隔符避免 JSON 冲突、按角色组织 Message。














说一下上面那些API的具体应用场景吧（其实我感觉挺鸡肋的）


ChatClient 的 prompt() 方法提供了重载版本：
prompt()：无参，开启 fluent 链式配置（你平时用的 user()/system() 就是这个）；
prompt(String content)：快捷传用户文本（等价于 prompt().user(content)）；
prompt(Prompt prompt)：直接传入手动构建的 Prompt 对象 —— 这正是你想的：先对系统提示词、用户输入做任意自定义处理，封装成完整的 Prompt 对象，再直接塞进去，完全不用调用 user()/system() 方法。
这种方式适合需要对 Prompt 做复杂预处理的场景（比如动态拼接多轮 Message、自定义 ChatOptions、复杂模板渲染等），下面结合你的代码，一步步演示怎么写：
一、核心示例：手动构建 Prompt 对象，传给 chatClient.prompt ()
1. 同步调用（你的 demo 改造）
   java
   运行
   @GetMapping
   public String demo() {
   // 步骤1：先自定义处理系统提示词、用户输入，构建 Message 列表
   // 1.1 构建 SystemMessage（可先做任意处理，比如从数据库查、模板渲染）
   String systemText = "你是一个友好的助手，回答用中文"; // 自定义预处理后的系统提示词
   Message systemMsg = new SystemMessage(systemText);

   // 1.2 构建 UserMessage（比如先清洗、校验用户输入）
   String userInput = "hello"; // 可先做自定义处理（如过滤敏感词、补全上下文）
   Message userMsg = new UserMessage(userInput);

   // 步骤2：构建完整的 Prompt 对象（可加自定义 ChatOptions，比如 temperature）
   ChatOptions options = OpenAiChatOptions.builder().temperature(0.5).build();
   Prompt customPrompt = new Prompt(List.of(systemMsg, userMsg), options);

   // 步骤3：直接传入 Prompt 对象，无需 user()/system() 链式调用
   return chatClient.prompt(customPrompt) // 核心：传手动构建的 Prompt
   .call() // 同步调用
   .content();
   }
2. 流式调用（你的 demo2 改造）
   java
   运行
   @GetMapping("/demo2")
   public Flux<String> demo2() {
   // 步骤1：手动构建复杂的 Prompt 对象（比如带多轮对话的 AssistantMessage）
   Message systemMsg = new SystemMessage("逐字返回回答，不要省略");
   Message userMsg = new UserMessage("hello");
   // 可选：加历史对话的 AssistantMessage（多轮场景）
   Message assistantMsg = new AssistantMessage("之前的回复...");

   Prompt customPrompt = new Prompt(List.of(systemMsg, assistantMsg, userMsg));

   // 步骤2：传入 Prompt 对象，流式调用
   Flux<String> hello = chatClient.prompt(customPrompt) // 传 Prompt 对象
   .stream() // 流式调用
   .content();

   new Thread(() -> hello.subscribe(System.out::println));
   return hello;
   }
   二、结合 PromptTemplate 做预处理（更实用的场景）
   如果需要先通过 PromptTemplate 渲染动态模板，再构建 Prompt 对象，流程如下：
   java
   运行
   @GetMapping("/demo3")
   public String demo3(@RequestParam String type) {
   // 步骤1：用 PromptTemplate 渲染系统消息（自定义预处理）
   String systemTemplate = "你是一个{role}，只推荐{language}相关内容";
   PromptTemplate systemTemplateObj = new PromptTemplate(systemTemplate);
   String renderedSystemText = systemTemplateObj.render(Map.of("role", "技术顾问", "language", "Java"));
   Message systemMsg = new SystemMessage(renderedSystemText);

   // 步骤2：用 PromptTemplate 渲染用户消息（自定义预处理）
   String userTemplate = "推荐3本{type}领域的经典书籍";
   PromptTemplate userTemplateObj = new PromptTemplate(userTemplate);
   String renderedUserText = userTemplateObj.render(Map.of("type", type));
   Message userMsg = new UserMessage(renderedUserText);

   // 步骤3：构建 Prompt 对象
   Prompt customPrompt = new Prompt(List.of(systemMsg, userMsg));

   // 步骤4：传入 ChatClient
   return chatClient.prompt(customPrompt)
   .call()
   .content();
   }
