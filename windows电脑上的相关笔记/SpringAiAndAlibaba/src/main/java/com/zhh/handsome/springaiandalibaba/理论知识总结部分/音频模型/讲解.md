这份文档的核心是 Spring AI 中「文本转语音（TTS）」的音频 API（基于 OpenAI TTS 模型） —— 它定义了调用 OpenAI TTS（tts-1/tts-1-hd）的标准化接口，核心能力是「文本生成语音音频」；而它与 ChatClient 的核心结合场景有两个：
静态生成：先用 ChatClient 把用户简短需求转化为自然流畅的文本（如 “把‘天气好’扩写成播报语”），再用音频 API 生成语音；
实时流式：把 ChatClient 流式返回的文本回答，实时传给音频 API 生成流式语音（实现 “AI 边回答边播报”）。
下面从「核心概念→关键类→完整结合示例」超详细讲解，代码可直接落地，贴合你现有的 ChatClient 使用习惯。
一、音频 API（TTS）核心定位（先理清核心逻辑）
1. 核心作用
   Spring AI 音频 API 是对接 OpenAI TTS 模型的统一抽象，核心能力：
   输入：文本内容 + 配置参数（模型、音色、语速、音频格式）；
   输出：音频字节数组（静态）或流式音频片段（实时）；
   核心场景：文本转语音（如 AI 回答转语音播报、博文朗读、多语言配音）。
