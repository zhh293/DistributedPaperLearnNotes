这份文档的核心是 Spring AI 中「文生图」的统一抽象 API（Image Model API） —— 它定义了调用 DALL・E、Stability AI 等图像生成模型的标准化接口，核心用途是「文本生成图像」；而它与 ChatClient 的核心结合场景是：先用 ChatClient（聊天模型）生成高质量的文生图提示词，再用 ImageModel 生成图像（解决手动写提示词效果差的问题）。
下面从「核心概念→关键类→完整结合示例」超详细讲解，全程聚焦「可落地、可运行」的代码，贴合你现有的 ChatClient 使用习惯。
一、Image Model API 核心定位（先理清核心逻辑）
1. 核心作用
   Image Model API 是 Spring AI 对接所有文生图模型（如 OpenAI DALL・E 3、Stability AI Stable Diffusion）的统一抽象，核心能力：
   输入：文本描述（ImageMessage）+ 模型参数（ImageOptions，如尺寸、数量）；
   输出：生成的图像（URL/Base64 格式）；
   核心场景：文生图（Text-to-Image），比如 “生成一张赛博朋克风格的猫咪图片”。
2. 与 ChatClient 的核心结合点
   ChatClient 是聊天模型（文本生成文本），ImageModel 是图像模型（文本生成图像），两者结合的最佳场景：
   plaintext
   用户简单描述 → ChatClient 优化为专业文生图提示词 → ImageModel 生成高质量图像
   比如：用户说 “画只猫” → ChatClient 生成 “一只赛博朋克风格的橘猫，背景是霓虹都市，细节丰富，8K 分辨率，光影效果拉满” → ImageModel 基于这个精准提示词生成图像（远优于手动写的简单提示词）。
   二、Image Model API 核心接口 & 关键类（提炼高频用法）
1. 核心接口：ImageModel（所有文生图模型的统一抽象）
   java
   运行
   @FunctionalInterface
   public interface ImageModel extends Model<ImagePrompt, ImageResponse> {
   // 唯一核心方法：传入ImagePrompt，返回生成的图像响应
   ImageResponse call(ImagePrompt request);
   }
   常用实现：OpenAiImageModel（对接 OpenAI DALL・E）、StabilityAiImageModel（对接 Stability AI）；
   无需手动实现，Spring Boot 自动配置后直接注入即可使用。

步骤 2：核心配置（ChatClient + ImageModel Bean）
java
运行
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.openai.OpenAiChatModel;
import org.springframework.ai.openai.OpenAiChatOptions;
import org.springframework.ai.openai.image.OpenAiImageModel;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class AiImageConfig {

    // 1. 你的原有 ChatClient（新增「文生图提示词优化」的默认系统消息）
    @Bean
    public ChatClient chatClient(OpenAiChatModel openAiChatModel) {
        return ChatClient.builder(openAiChatModel)
                .defaultSystem("你是专业的文生图提示词优化师，能将简单描述转化为精准、专业的文生图提示词，要求：1. 细节丰富（如风格、分辨率、光影）；2. 适配 DALL·E 3 模型；3. 只返回优化后的提示词，无多余解释。")
                .defaultOptions(OpenAiChatOptions.builder().model("gpt-4o").temperature(0.8).build())
                .build();
    }

    // 2. 配置 ImageModel（文生图核心 Bean，Spring 自动注入 OpenAI 配置）
    @Bean
    public OpenAiImageModel openAiImageModel() {
        // 若需自定义全局参数，可传入 OpenAiImageOptions
        // OpenAiImageOptions options = OpenAiImageOptions.builder().model("dall-e-3").width(1024).build();
        // return new OpenAiImageModel(openAiApi, options);
        return new OpenAiImageModel(); // 自动读取配置文件的参数
    }
}
关键说明：
ChatClient 的默认系统消息是核心：明确要求它只生成 “专业的文生图提示词”，避免返回多余内容；
OpenAiImageModel 无需手动传 API Key，Spring Boot 会自动读取配置文件的 spring.ai.openai.api-key。
步骤 3：核心业务逻辑（ChatClient 优化提示词 + ImageModel 生成图像）
封装成 Service，对外提供 “输入简单描述 → 输出图像 URL” 的能力：
java
运行
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.image.ImageGeneration;
import org.springframework.ai.image.ImageMessage;
import org.springframework.ai.image.ImageOptions;
import org.springframework.ai.image.ImagePrompt;
import org.springframework.ai.image.ImageResponse;
import org.springframework.ai.openai.image.OpenAiImageOptions;
import org.springframework.ai.openai.image.OpenAiImageModel;
import org.springframework.stereotype.Service;

@Service
public class ImageGenerateService {

    private final ChatClient chatClient;
    private final OpenAiImageModel openAiImageModel;

    // 注入 ChatClient 和 ImageModel
    public ImageGenerateService(ChatClient chatClient, OpenAiImageModel openAiImageModel) {
        this.chatClient = chatClient;
        this.openAiImageModel = openAiImageModel;
    }

    /**
     * 核心方法：结合 ChatClient + ImageModel 生成图像
     * @param simplePrompt 用户简单描述（如“画只赛博朋克风格的猫”）
     * @return 生成的图像URL
     */
    public String generateImage(String simplePrompt) {
        // ========== 步骤1：用 ChatClient 优化提示词 ==========
        String professionalPrompt = chatClient.prompt()
                .user(simplePrompt) // 传入用户简单描述
                .call() // 同步调用，获取优化后的提示词
                .content();
        System.out.println("优化后的文生图提示词：" + professionalPrompt);

        // ========== 步骤2：用 ImageModel 生成图像 ==========
        // 1. 构建 ImageMessage（优化后的提示词）
        ImageMessage imageMessage = new ImageMessage(professionalPrompt);

        // 2. 构建 ImageOptions（可选：覆盖全局配置，如尺寸、数量）
        ImageOptions imageOptions = OpenAiImageOptions.builder()
                .width(1024)
                .height(1024)
                .responseFormat("url") // 返回URL（base64则写"b64_json"）
                .n(1)
                .build();

        // 3. 构建 ImagePrompt（输入容器）
        ImagePrompt imagePrompt = new ImagePrompt(imageMessage, imageOptions);

        // 4. 调用 ImageModel 生成图像
        ImageResponse imageResponse = openAiImageModel.call(imagePrompt);

        // 5. 解析响应：获取第一个图像的URL
        ImageGeneration generation = imageResponse.getResults().get(0);
        return generation.getOutput().getUrl();
    }
}
关键说明：
ImageMessage：仅需传入优化后的提示词，weight 字段大部分模型（如 DALL・E）暂不支持，可忽略；
ImageOptions：responseFormat 选 url（返回图像链接，方便直接访问）或 b64_json（返回 Base64 编码的图像二进制）；
解析响应：imageResponse.getResults() 返回生成的图像列表（数量由 n 指定），取第一个即可。
步骤 4：暴露接口测试（验证结合效果）
java
运行
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class ImageController {

    private final ImageGenerateService imageGenerateService;

    public ImageController(ImageGenerateService imageGenerateService) {
        this.imageGenerateService = imageGenerateService;
    }

    /**
     * 测试接口：输入简单描述，返回图像URL
     * 示例：http://localhost:8080/generate/image?prompt=画一只赛博朋克风格的橘猫
     */
    @GetMapping("/generate/image")
    public String generateImage(@RequestParam String prompt) {
        return imageGenerateService.generateImage(prompt);
    }
}
