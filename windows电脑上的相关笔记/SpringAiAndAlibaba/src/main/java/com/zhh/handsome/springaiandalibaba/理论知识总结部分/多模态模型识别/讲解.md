你关注的多模态 API 核心是 给 UserMessage 附加图片 / 音频 / 视频等媒体内容，让 AI 模型能理解文本 + 多媒体输入 —— 这完全可以融入你平时的 ChatClient 调用方式（不管是 fluent 链式、还是手动传 Prompt 对象），下面帮你梳理核心用法 + 结合你的代码改造，重点讲日常最常用的「图片输入」场景：
一、多模态核心认知（先搞懂关键规则）
仅 UserMessage 支持媒体：SystemMessage/AssistantMessage 只能传文本，只有 UserMessage 可以附加 media 字段（图片 / 音频等）；
Media 核心构成：MimeType（指定媒体类型，如 IMAGE_PNG） + Resource（媒体内容，支持本地文件、ClassPath、URL 等）；
模型要求：必须用支持多模态的模型（如 GPT-4o、Claude3、Gemini 1.5），普通文本模型（如 GPT-3.5）不支持；
响应仅文本：AI 模型的响应还是文本（比如描述图片内容），要生成图片 / 音频需用专用单模态模型。
二、结合你的代码：两种多模态调用方式
方式 1：Fluent 链式写法（你平时用的 chatClient.prompt().user()）
这是最简洁的方式，直接在 user() 里通过 .media() 附加图片，完全贴合你现有的代码风格：
java
运行
// 你的 demo 改造：传图片+文本，让 AI 描述图片
@GetMapping("/multimodal-demo")
public String multimodalDemo() {
// 1. 加载图片资源（ClassPath 资源，比如放在 resources/ 下）
Resource imageResource = new ClassPathResource("/test-image.png");

    // 2. Fluent 链式调用：文本 + 图片（多模态）
    return chatClient.prompt()
            .user(u -> u.text("描述这张图片里有什么，用中文简洁说明") // 文本提问
                        .media(MimeTypeUtils.IMAGE_PNG, imageResource)) // 附加图片
            .call()
            .content();
}

// 流式调用改造（你的 demo2）
@GetMapping("/multimodal-stream")
public Flux<String> multimodalStream() {
Resource imageResource = new ClassPathResource("/test-image.png");

    Flux<String> response = chatClient.prompt()
            .user(u -> u.text("逐字描述这张图片内容")
                        .media(MimeTypeUtils.IMAGE_JPEG, imageResource)) // 比如 JPG 图片
            .stream()
            .content();
    
    new Thread(() -> response.subscribe(System.out::println));
    return response;
}
方式 2：手动构建 Prompt 对象（你之前关注的传 Prompt 方式）
如果需要对媒体内容做预处理（比如校验、转换格式），先手动构建带 media 的 UserMessage，再封装成 Prompt 对象：
java
运行
@GetMapping("/multimodal-prompt")
public String multimodalPrompt() {
// 步骤1：加载图片资源（也可以是本地文件/URL）
// 本地文件示例：Resource imageResource = new FileSystemResource("/Users/xxx/test.png");
// URL 示例：Resource imageResource = new UrlResource("https://xxx.com/test.png");
Resource imageResource = new ClassPathResource("/test-image.png");

    // 步骤2：构建带媒体的 UserMessage
    UserMessage userMessage = new UserMessage(
        "分析这张图片的内容，重点说明主体", // 文本内容
        new Media(MimeTypeUtils.IMAGE_PNG, imageResource) // 附加图片媒体
    );
    
    // 步骤3：构建 Prompt 对象（可选加 SystemMessage）
    SystemMessage systemMsg = new SystemMessage("回答要客观，只描述图片可见内容");
    Prompt multimodalPrompt = new Prompt(List.of(systemMsg, userMessage));
    
    // 步骤4：传入 ChatClient
    return chatClient.prompt(multimodalPrompt)
            .call()
            .content();
}
三、支持的媒体类型 & Resource 类型（日常常用）
1. 常见 MimeType（对应不同媒体）
   媒体类型	MimeType 常量	适用场景
   PNG 图片	MimeTypeUtils.IMAGE_PNG	本地图片、ClassPath 图片
   JPG 图片	MimeTypeUtils.IMAGE_JPEG	最常用的图片格式
   MP3 音频	MimeTypeUtils.AUDIO_MPEG	音频输入（仅支持的模型可用，如 GPT-4o）
2. 常见 Resource 类型（加载媒体内容）
   Resource 类型	示例	适用场景
   ClassPathResource	new ClassPathResource("/test.png")	项目内置图片（resources 目录下）
   FileSystemResource	new FileSystemResource("D:/test.png")	本地磁盘文件
   UrlResource	new UrlResource("https://xxx.com/test.png")	网络图片 / 音频
   四、关键注意事项（避坑）
   模型兼容性：必须确认所用模型支持多模态（比如 OpenAI 要选 gpt-4o，而不是 gpt-3.5-turbo）；
   文件大小限制：不同模型有媒体文件大小限制（比如 GPT-4o 单张图片≤20MB），过大的文件要先压缩；
   流式调用兼容：多模态也支持 stream() 流式响应，写法和纯文本流式完全一致；
   多媒体附加：一个 UserMessage 可以加多个媒体（比如多张图片），用 .media() 多次调用即可：
   java
   运行
   .user(u -> u.text("对比这两张图片的区别")
   .media(MimeTypeUtils.IMAGE_PNG, img1Resource)
   .media(MimeTypeUtils.IMAGE_PNG, img2Resource))
   核心总结
   核心用法：多模态的本质是给 UserMessage 加 Media 对象（MimeType + Resource），ChatClient 既支持 fluent 链式 .media()，也支持手动构建带 Media 的 UserMessage 封装成 Prompt；
   日常场景：最常用的是「文本 + 图片」输入，用 ClassPathResource 加载项目内图片，MimeTypeUtils.IMAGE_PNG/JPEG 指定类型；
   兼容你的写法：完全不用改你现有 chatClient.prompt() 的核心逻辑，只需在 user() 里加 .media()，或手动构建带 Media 的 UserMessage 即可。
