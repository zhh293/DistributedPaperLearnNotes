如果说你想使用 Prometheus和Grafana实现对后端系统、MySQL/PostgreSQL 数据库、Redis 等中间件，以及服务器基础资源的全方位指标监控，我将使用docker向你演示具体的配置和做法以及如何监控各种指标并且展示在绚丽的可视化图表上面




Prometheus	核心采集器：定时拉取各类 Exporter 暴露的指标，存储并提供查询能力
Grafana	可视化面板：对接 Prometheus 数据源，通过 Dashboard 展示监控图表
Node Exporter	服务器监控：暴露 CPU、内存、磁盘、网络等服务器基础指标
MySQL Exporter	MySQL 监控：暴露数据库连接数、QPS、慢查询、表空间等指标
Redis Exporter	Redis 监控：暴露内存使用、命中率、连接数、key 数量等指标
自定义 Exporter（可选）	后端系统监控：如 Java 应用可通过 JMX Exporter 暴露 JVM / 业务指标


二、环境准备
1. 基础环境要求
服务器已安装 Docker + Docker Compose（推荐 Docker Compose V2）
确保端口未被占用：9090（Prometheus）、3000（Grafana）、9100（Node Exporter）、9104（MySQL Exporter）、9121（Redis Exporter）
服务器有基础的目录读写权限
2. 安装 Docker + Docker Compose（Linux 示例）

三、分步部署与配置
1. 目录结构规划
先创建统一的监控目录，便于管理配置和数据持久化：

# 创建主目录
mkdir -p /opt/prometheus-monitor/{prometheus,grafana,mysql-exporter,redis-exporter}
cd /opt/prometheus-monitor

# 设置目录权限（避免容器启动权限不足）
sudo chmod -R 777 /opt/prometheus-monitor


/opt/prometheus-monitor/
├── docker-compose.yml       # 所有容器的编排配置
├── prometheus/
│   └── prometheus.yml       # Prometheus 核心配置
├── grafana/                 # Grafana 数据持久化目录（自动生成）
├── mysql-exporter/          # MySQL Exporter 配置（可选）
└── redis-exporter/          # Redis Exporter 配置（可选）




2. 编写 Prometheus 核心配置文件
编辑 /opt/prometheus-monitor/prometheus/prometheus.yml，配置全局参数和采集目标：


# 全局配置
global:
  scrape_interval: 15s  # 采集指标的间隔（默认15秒，可根据需求调整）
  evaluation_interval: 15s  # 规则评估间隔

# 告警规则文件（本次暂不配置告警，可留空）
rule_files:
  # - "alert_rules.yml"

# 采集目标配置（核心）
scrape_configs:
  # 1. 监控 Prometheus 自身
  - job_name: 'prometheus'
    static_configs:
      - targets: ['prometheus:9090']

  # 2. 监控服务器（Node Exporter）
  - job_name: 'node_exporter'
    static_configs:
      - targets: ['node_exporter:9100']

  # 3. 监控 MySQL（MySQL Exporter）
  - job_name: 'mysql_exporter'
    static_configs:
      - targets: ['mysql_exporter:9104']

  # 4. 监控 Redis（Redis Exporter）
  - job_name: 'redis_exporter'
    static_configs:
      - targets: ['redis_exporter:9121']

  # 5. 监控自定义后端服务（示例：如Java应用的JMX Exporter，需自行调整）
  # - job_name: 'backend_service'
  #   static_configs:
  #     - targets: ['你的后端服务IP:9200']



3. 编写 Docker Compose 配置文件
编辑 /opt/prometheus-monitor/docker-compose.yml，统一管理所有容器：


version: '3.8'

services:
  # 1. Prometheus 核心服务
  prometheus:
    image: prom/prometheus:v2.45.0  # 固定版本，避免自动更新出问题
    container_name: prometheus
    restart: always
    ports:
      - "9090:9090"  # 宿主机端口:容器端口
    volumes:
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml  # 挂载配置文件
      - prometheus_data:/prometheus  # 持久化Prometheus数据
    command:
      - '--config.file=/etc/prometheus/prometheus.yml'
      - '--storage.tsdb.path=/prometheus'
      - '--web.console.libraries=/usr/share/prometheus/console_libraries'
      - '--web.console.templates=/usr/share/prometheus/consoles'
    networks:
      - monitor_network

  # 2. Grafana 可视化服务
  grafana:
    image: grafana/grafana:10.2.2
    container_name: grafana
    restart: always
    ports:
      - "3000:3000"
    volumes:
      - grafana_data:/var/lib/grafana  # 持久化Grafana数据（面板、用户等）
    environment:
      - GF_SECURITY_ADMIN_USER=admin  # 默认管理员账号
      - GF_SECURITY_ADMIN_PASSWORD=admin123  # 默认密码（首次登录需修改）
      - GF_USERS_ALLOW_SIGN_UP=false  # 禁止注册
    depends_on:
      - prometheus  # 依赖Prometheus，确保先启动
    networks:
      - monitor_network

  # 3. Node Exporter（服务器监控）
  node_exporter:
    image: prom/node-exporter:v1.6.1
    container_name: node_exporter
    restart: always
    ports:
      - "9100:9100"
    volumes:
      - /proc:/host/proc:ro  # 只读挂载服务器proc目录
      - /sys:/host/sys:ro    # 只读挂载服务器sys目录
      - /:/rootfs:ro         # 只读挂载根目录（监控磁盘）
    command:
      - '--path.procfs=/host/proc'
      - '--path.sysfs=/host/sys'
      - '--collector.filesystem.ignored-mount-points=^/(sys|proc|dev|host|etc)($$|/)'
    networks:
      - monitor_network

  # 4. MySQL Exporter（MySQL监控）
  mysql_exporter:
    image: prom/mysqld-exporter:v0.15.0
    container_name: mysql_exporter
    restart: always
    ports:
      - "9104:9104"
    environment:
      # 配置MySQL连接信息（替换为你的实际信息）
      - DATA_SOURCE_NAME=root:你的MySQL密码@(你的MySQLIP:3306)/
    depends_on:
      - prometheus
    networks:
      - monitor_network

  # 5. Redis Exporter（Redis监控）
  redis_exporter:
    image: oliver006/redis_exporter:v1.52.0
    container_name: redis_exporter
    restart: always
    ports:
      - "9121:9121"
    environment:
      # 配置Redis连接信息（替换为你的实际信息）
      - REDIS_ADDR=redis://你的RedisIP:6379
      - REDIS_PASSWORD=你的Redis密码（无则留空）
    depends_on:
      - prometheus
    networks:
      - monitor_network

# 数据卷（持久化数据）
volumes:
  prometheus_data:
  grafana_data:

# 自定义网络（容器间通信）
networks:
  monitor_network:
    driver: bridge




cd /opt/prometheus-monitor

# 启动容器（-d 后台运行）
docker compose up -d

# 检查容器状态（确保所有容器都是 Up 状态）
docker compose ps

# 查看日志（如有容器启动失败，查看日志排查）
docker compose logs -f prometheus  # 查看Prometheus日志
docker compose logs -f grafana     # 查看Grafana日志




四、Grafana 配置与可视化
1. 登录 Grafana
访问地址：http://你的服务器IP:3000
账号：admin，密码：admin123（首次登录会提示修改密码，建议修改为安全密码）
2. 添加 Prometheus 数据源
登录后，点击左侧菜单栏的 Configuration（齿轮图标）> Data sources
点击 Add data source，选择 Prometheus
配置 Prometheus 地址：http://prometheus:9090（容器内域名，无需改 IP）
点击 Save & test，提示 “Data source is working” 即配置成功
3. 导入现成的监控 Dashboard
Grafana 社区有大量现成的 Dashboard，直接导入即可快速实现可视化：


监控对象	Dashboard ID	导入步骤
服务器（Node）	1860	1. 左侧菜单栏 > Dashboards > Import2. 输入 ID 1860 > Load3. 选择 Prometheus 数据源 > Import
MySQL	7362	同上，输入 ID 7362
Redis	763	同上，输入 ID 763





自定义后端系统 Dashboard：如果是 Java 应用，可导入 JVM 监控 Dashboard（ID：8563）；其他语言（如 Go/Python）可根据对应的 Exporter 查找社区 Dashboard，或自行创建面板。
五、验证监控是否生效
验证 Prometheus 采集指标：访问 http://服务器IP:9090/targets，查看所有采集目标（job）的状态是否为 UP，如果是 DOWN，检查对应 Exporter 的配置（如 MySQL/Redis 连接信息）。
验证 Grafana 面板数据：导入 Dashboard 后，查看面板中的图表是否有数据（可能需要等待 1-2 分钟，Prometheus 采集指标需要时间）。如果无数据，检查：
Prometheus 数据源是否配置正确
对应 Exporter 容器是否正常运行
被监控的服务（MySQL/Redis）是否能正常访问
六、进阶配置（可选）
自定义监控指标：后端系统可通过埋点暴露自定义指标（如接口 QPS、业务成功率），Prometheus 配置采集后，在 Grafana 中创建自定义面板展示。
配置告警规则：在 Prometheus 中配置告警规则（如 CPU 使用率 > 90%、Redis 内存不足），结合 AlertManager 实现邮件 / 钉钉 / 微信告警。
数据持久化与清理：Prometheus 默认会持久化数据，可在 prometheus.yml 中配置 retention.time 限制数据保留时间（如 retention.time: 15d 保留 15 天）。
总结
核心流程：通过 Docker Compose 一键部署 Prometheus + Grafana + 各类 Exporter → 配置 Prometheus 采集目标 → Grafana 对接数据源并导入 Dashboard → 验证监控数据。
关键配置：prometheus.yml 中的 scrape_configs 是采集目标核心，需确保每个 Exporter 的地址和端口正确；Grafana 数据源必须指向 Prometheus 容器（http://prometheus:9090）。
排障重点：容器启动状态、Exporter 连接信息（如 MySQL/Redis 的 IP 和密码）、Prometheus Targets 状态，是监控无数据的主要排查方向。
