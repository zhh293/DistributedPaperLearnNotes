一、入门：二维码生成的核心概念（扫盲）
二维码（QR Code，Quick Response Code）本质是将文本 / 数字 / 二进制数据编码成黑白方块（模块）矩阵，通过扫码设备识别矩阵的明暗分布还原数据。
1. 二维码的核心结构（以最常见的 QR Code Version 1 为例）
一个标准二维码由以下关键部分组成（可视化更易理解）：



┌─────────────────────────┐
│ 定位图案 □  时间模式 ░  │
│  □□□    对齐图案 ○     │
│  □ □    数据区 ■■■■■   │
│  □□□    纠错码区 ▓▓▓▓   │
│ 格式信息 ▲ 版本信息 ▼   │
└─────────────────────────┘


定位图案：3 个大正方形（左上 / 右上 / 左下），用于扫码设备识别二维码的位置、方向和尺寸。
对齐图案：版本≥2 时出现，用于校正扫码时的透视变形（版本越高，对齐图案越多）。
时间模式：一条黑白交替的线，辅助确定每个模块的坐标。
格式信息：存储纠错级别和掩码模式（2 个字节，带纠错）。
版本信息：版本≥7 时出现，存储二维码版本（1-40，版本越高，矩阵越大，可存储数据越多）。
数据区 + 纠错码区：核心部分，存储编码后的原始数据 + 纠错码（保证污损后仍能识别）。


2. 关键参数（决定二维码的能力）


参数	说明
版本	Version 1（21×21 模块）~ Version 40（177×177 模块），版本越高容量越大
纠错级别	L (7%)/M (15%)/Q (25%)/H (30%)，容错率越高，可存储数据越少
编码模式	数字 / 字母 / 字节 / 中文（Kanji），不同模式压缩效率不同

示例：Version 1 + 纠错级别 M，可存储：
数字：41 个
字母 / 数字混合：25 个
中文（UTF-8）：10 个左右


二、进阶：二维码生成的核心算法流程（底层原理）
二维码生成的核心是将原始数据→编码成二进制→填充到矩阵→处理掩码→输出图像，以下是标准化的生成步骤（简化版，符合 ISO/IEC 18004 标准）：
步骤 1：确定基础参数（版本 + 纠错级别）
根据原始数据长度和期望的纠错级别，计算所需的二维码版本（比如 10 个中文 + 纠错 M，选 Version 1 即可）。
确定纠错级别（默认选 M，平衡容量和容错）。



步骤 2：数据编码（核心！将文本转二进制）
这是算法的核心，目的是将原始数据转换成符合二维码规则的二进制流，分 5 个子步骤：
子步骤 2.1：选择编码模式
根据数据类型选择最优编码模式（压缩效率最高）：
数字模式（Numeric）：仅数字 0-9，每 3 位数字转 10 位二进制（比如 123→000001111011）。
字母模式（Alphanumeric）：数字 + 大写字母 + 符号（空格 /$/%/*/+/-/./:），每 2 位转 11 位二进制（比如 AB→00000001000）。
字节模式（Byte）：任意字符（UTF-8/GBK），每个字符转 8 位二进制（比如 "你"→UTF-8 的 0xE4BD A0，即 11100100 10111101 10100000）。
中文模式（Kanji）：仅 Shift_JIS 编码的日文 / 中文，每 2 个字符转 13 位二进制（压缩效率更高）。



子步骤 2.2：添加模式标识 + 字符长度
模式标识：数字 (0001)/ 字母 (0010)/ 字节 (0100)/ 中文 (1000)（4 位二进制）。
字符长度：不同版本支持的长度位数不同（比如 Version 1，数字长度用 10 位，字节长度用 8 位）。
示例：编码 "123456"（数字模式）：
模式标识：0001（4 位）。
字符长度：6（转 10 位二进制：0000000110）。
数据编码：123→000001111011，456→000111001000 → 合并为 000001111011000111001000。
临时二进制流：0001 + 0000000110 + 000001111011000111001000。



子步骤 2.3：添加结束符
在二进制流末尾添加 0，直到满足当前版本 + 纠错级别要求的总比特数（比如 Version 1+M 需要 208 位）；如果流过长，截断到指定长度。
子步骤 2.4：填充数据（补 0）
如果结束符添加后仍未达到总比特数，用固定序列11101100 00010001循环填充，直到满足长度。
子步骤 2.5：分块 + 生成纠错码
将填充后的二进制流分成若干数据块（块数由版本 + 纠错级别决定）。
对每个数据块，用Reed-Solomon（里德 - 所罗门）算法生成纠错码（纠错级别越高，纠错码越长）。
将数据块和对应的纠错码合并，得到最终的 "数据 + 纠错" 二进制流。





步骤 3：构造二维码矩阵
创建空白矩阵：根据版本创建 N×N 的空矩阵（Version 1=21×21）。
绘制固定图案：
绘制 3 个定位图案（左上 / 右上 / 左下）。
绘制时间模式（一条贯穿矩阵的黑白线）。
绘制对齐图案（版本≥2 时）。
绘制版本信息（版本≥7 时）。
填充数据 + 纠错码：从矩阵右下角开始，以 "之" 字形（交替上下）的顺序，将二进制流的每一位填充到矩阵的空白模块（1 = 黑色，0 = 白色）。
掩码处理：对矩阵应用掩码（共 8 种掩码规则，比如 "模块坐标 (i+j) 是 2 的倍数则反转颜色"），目的是避免矩阵出现大面积黑白块，提升扫码识别率；选择识别效果最好的掩码，同时将掩码编号写入格式信息区。
添加格式信息：将纠错级别 + 掩码编号编码后，绘制到矩阵的固定位置（格式信息区）。
步骤 4：矩阵转图像
将矩阵的每个模块映射为像素（比如 1 个模块 = 10 像素），1→黑色像素，0→白色像素，最终生成二维码图片。







简单代码实现





/**
 * 从零实现二维码生成（Version 1，纠错级别M，字节编码模式）
 * 无任何第三方库依赖，纯Java原生实现核心算法
 */
public class QRCodeRawGenerator {
    // ===================== 核心常量（Version 1 + 纠错级别M） =====================
    /** Version 1二维码矩阵尺寸（21×21模块） */
    public static final int QR_VERSION_1_SIZE = 21;
    /** 纠错级别M对应的参数：每个数据块的纠错码长度（Version 1+M：10个纠错码字） */
    public static final int EC_CODE_LENGTH_M = 10;
    /** Version 1+M 字节模式最大数据容量（16个字节） */
    public static final int MAX_DATA_BYTES_V1_M = 16;
    /** 字节编码模式标识（4位二进制：0100） */
    public static final String BYTE_MODE_FLAG = "0100";
    /** Version 1字节模式长度位（8位二进制） */
    public static final int BYTE_LENGTH_BITS = 8;
    /** 掩码规则0：(i + j) % 2 == 0 时反转模块颜色 */
    public static final int MASK_PATTERN_0 = 0;

    // ===================== 基础工具方法 =====================
    /**
     * 将字节数组转换为二进制字符串（补前导0到8位）
     */
    private static String byteTo8BitString(byte b) {
        StringBuilder sb = new StringBuilder();
        for (int i = 7; i >= 0; i--) {
            sb.append((b >> i) & 1);
        }
        return sb.toString();
    }

    /**
     * 将二进制字符串转换为字节数组（不足8位补0）
     */
    private static byte[] binaryStringToBytes(String binaryStr) {
        int length = binaryStr.length();
        int byteCount = (length + 7) / 8;
        byte[] bytes = new byte[byteCount];
        for (int i = 0; i < length; i += 8) {
            String chunk = binaryStr.substring(i, Math.min(i + 8, length));
            // 补前导0到8位
            while (chunk.length() < 8) {
                chunk = "0" + chunk;
            }
            bytes[i / 8] = (byte) Integer.parseInt(chunk, 2);
        }
        return bytes;
    }

    /**
     * 填充二进制流到指定长度（用11101100 00010001循环填充）
     */
    private static String padBinaryString(String binaryStr, int targetLength) {
        String padSequence = "1110110000010001"; // 标准填充序列
        StringBuilder sb = new StringBuilder(binaryStr);
        while (sb.length() < targetLength) {
            sb.append(padSequence);
        }
        // 截断到目标长度
        return sb.substring(0, targetLength);
    }



二、步骤 1：数据编码（文本→二进制流）
实现字节模式的编码逻辑，包含模式标识、长度编码、结束符、填充：


    // ===================== 步骤1：数据编码 =====================
    /**
     * 字节模式编码：将UTF-8文本转换为符合二维码规则的二进制字符串
     * @param content 待编码文本
     * @return 编码后的二进制字符串
     * @throws IllegalArgumentException 数据过长异常
     */
    private static String encodeData(String content) {
        // 1. 将文本转换为UTF-8字节数组
        byte[] contentBytes;
        try {
            contentBytes = content.getBytes("UTF-8");
        } catch (Exception e) {
            throw new RuntimeException("UTF-8编码失败", e);
        }

        // 2. 校验数据长度（Version 1+M 字节模式最大16字节）
        if (contentBytes.length > MAX_DATA_BYTES_V1_M) {
            throw new IllegalArgumentException("数据过长：Version 1+M 字节模式最多支持16个UTF-8字节");
        }

        // 3. 编码模式标识（4位：0100）
        StringBuilder binarySb = new StringBuilder(BYTE_MODE_FLAG);

        // 4. 编码字符长度（Version 1字节模式用8位）
        String lengthBinary = String.format("%8s", Integer.toBinaryString(contentBytes.length))
                .replace(' ', '0'); // 补前导0到8位
        binarySb.append(lengthBinary);

        // 5. 编码数据字节（每个字节转8位二进制）
        for (byte b : contentBytes) {
            binarySb.append(byteTo8BitString(b));
        }

        // 6. 添加结束符（最多4个0，直到总长度接近目标）
        // Version 1+M 总数据位（含纠错）：208位 → 数据位=208 - 纠错位（10×8=80）= 128位
        int targetDataBits = 128;
        while (binarySb.length() < targetDataBits && binarySb.length() + 4 >= targetDataBits) {
            binarySb.append("0");
        }

        // 7. 填充数据到目标长度（128位）
        String paddedBinary = padBinaryString(binarySb.toString(), targetDataBits);

        return paddedBinary;
    }




三、步骤 2：Reed-Solomon 纠错码生成（核心难点）
实现简化版的 Reed-Solomon 算法（GF (2^8) 有限域），生成纠错码：

    // ===================== 步骤2：Reed-Solomon纠错码生成 =====================
    /**
     * GF(2^8)有限域乘法（使用二维码标准的本原多项式 x^8 + x^4 + x^3 + x^2 + 1）
     */
    private static int gfMultiply(int a, int b) {
        int p = 0;
        int primPoly = 0x11D; // 本原多项式：100011101
        for (int i = 0; i < 8; i++) {
            if ((b & 1) != 0) {
                p ^= a;
            }
            boolean carry = (a & 0x80) != 0;
            a <<= 1;
            if (carry) {
                a ^= primPoly;
            }
            b >>= 1;
        }
        return p & 0xFF;
    }

    /**
     * 生成Reed-Solomon纠错码
     * @param dataBytes 数据字节数组
     * @param ecLength 纠错码长度
     * @return 纠错码字节数组
     */
    private static byte[] generateReedSolomonEC(byte[] dataBytes, int ecLength) {
        int[] generator = new int[ecLength + 1];
        generator[0] = 1;

        // 生成生成多项式：(x + α^0)(x + α^1)...(x + α^(ecLength-1))
        for (int i = 0; i < ecLength; i++) {
            int alpha = 1 << i; // α^i（简化版，符合二维码标准）
            for (int j = i + 1; j > 0; j--) {
                generator[j] = (byte) (generator[j] ^ gfMultiply(generator[j - 1], alpha));
            }
        }

        // 初始化余数
        int[] remainder = new int[ecLength];
        for (byte b : dataBytes) {
            int fb = (b ^ remainder[0]) & 0xFF;
            if (fb != 0) {
                for (int i = 1; i < ecLength; i++) {
                    remainder[i] ^= gfMultiply(generator[i], fb);
                }
            }
            // 移位
            System.arraycopy(remainder, 1, remainder, 0, ecLength - 1);
            remainder[ecLength - 1] = fb;
        }

        // 转换为字节数组
        byte[] ecBytes = new byte[ecLength];
        for (int i = 0; i < ecLength; i++) {
            ecBytes[i] = (byte) remainder[i];
        }
        return ecBytes;
    }

    /**
     * 合并数据+纠错码为最终二进制流
     */
    private static String mergeDataAndEC(String dataBinary) {
        // 1. 数据二进制转字节数组
        byte[] dataBytes = binaryStringToBytes(dataBinary);

        // 2. 生成纠错码（10个字节）
        byte[] ecBytes = generateReedSolomonEC(dataBytes, EC_CODE_LENGTH_M);

        // 3. 合并数据+纠错码的二进制字符串
        StringBuilder mergedSb = new StringBuilder(dataBinary);
        for (byte b : ecBytes) {
            mergedSb.append(byteTo8BitString(b));
        }

        return mergedSb.toString();
    }


四、步骤 3：构造二维码矩阵（绘制图案 + 填充数据 + 掩码）
实现 21×21 矩阵的构造，包含定位图案、时间模式、数据填充、掩码处理：


    // ===================== 步骤3：构造二维码矩阵 =====================
    /**
     * 初始化空矩阵（false=白色，true=黑色）
     */
    private static boolean[][] createEmptyMatrix() {
        boolean[][] matrix = new boolean[QR_VERSION_1_SIZE][QR_VERSION_1_SIZE];
        // 初始全为白色（false）
        for (int i = 0; i < QR_VERSION_1_SIZE; i++) {
            for (int j = 0; j < QR_VERSION_1_SIZE; j++) {
                matrix[i][j] = false;
            }
        }
        return matrix;
    }

    /**
     * 绘制定位图案（三个角的7×7正方形）
     */
    private static void drawPositionPatterns(boolean[][] matrix) {
        // 左上定位图案（0-6行，0-6列）
        drawPositionPattern(matrix, 3, 3);
        // 右上定位图案（0-6行，14-20列）
        drawPositionPattern(matrix, 3, 17);
        // 左下定位图案（14-20行，0-6列）
        drawPositionPattern(matrix, 17, 3);
    }

    /**
     * 绘制单个定位图案（中心坐标x,y，7×7）
     */
    private static void drawPositionPattern(boolean[][] matrix, int x, int y) {
        for (int i = x - 3; i <= x + 3; i++) {
            for (int j = y - 3; j <= y + 3; j++) {
                // 外层正方形（黑色）
                if (i == x - 3 || i == x + 3 || j == y - 3 || j == y + 3) {
                    matrix[i][j] = true;
                }
                // 内层正方形（黑色）
                else if (i >= x - 1 && i <= x + 1 && j >= y - 1 && j <= y + 1) {
                    matrix[i][j] = true;
                }
                // 中间层（白色）
                else {
                    matrix[i][j] = false;
                }
            }
        }
    }

    /**
     * 绘制时间模式（黑白交替线）
     */
    private static void drawTimingPatterns(boolean[][] matrix) {
        // 水平时间模式（第6行，7-13列）
        for (int j = 7; j < 14; j++) {
            matrix[6][j] = (j % 2) == 0;
        }
        // 垂直时间模式（第6列，7-13行）
        for (int i = 7; i < 14; i++) {
            matrix[i][6] = (i % 2) == 0;
        }
    }

    /**
     * 填充数据到矩阵（之字形填充）
     */
    private static void fillDataToMatrix(boolean[][] matrix, String mergedBinary) {
        int bitIndex = 0;
        int size = QR_VERSION_1_SIZE;

        // 从右下角开始，之字形填充（跳过定位/时间图案）
        for (int col = size - 1; col >= 0; col -= 2) {
            // 偶数列：从上到下
            if (col == 6) col--; // 跳过时间模式列
            for (int row = 0; row < size; row++) {
                if (bitIndex >= mergedBinary.length()) break;
                // 跳过定位/时间图案的模块
                if (!isReservedModule(row, col)) {
                    matrix[row][col] = mergedBinary.charAt(bitIndex) == '1';
                    bitIndex++;
                }
                // 处理相邻列（col-1）
                if (col - 1 >= 0 && !isReservedModule(row, col - 1)) {
                    if (bitIndex >= mergedBinary.length()) break;
                    matrix[row][col - 1] = mergedBinary.charAt(bitIndex) == '1';
                    bitIndex++;
                }
            }

            // 奇数列：从下到上
            if (col - 1 == 6) col--; // 跳过时间模式列
            for (int row = size - 1; row >= 0; row--) {
                if (bitIndex >= mergedBinary.length()) break;
                if (col - 2 >= 0 && !isReservedModule(row, col - 2)) {
                    matrix[row][col - 2] = mergedBinary.charAt(bitIndex) == '1';
                    bitIndex++;
                }
                if (col - 3 >= 0 && !isReservedModule(row, col - 3)) {
                    if (bitIndex >= mergedBinary.length()) break;
                    matrix[row][col - 3] = mergedBinary.charAt(bitIndex) == '1';
                    bitIndex++;
                }
            }
        }
    }

    /**
     * 判断是否是保留模块（定位/时间图案）
     */
    private static boolean isReservedModule(int row, int col) {
        // 定位图案区域（7×7）
        boolean isPosition = (row < 7 && col < 7) || (row < 7 && col > 13) || (row > 13 && col < 7);
        // 时间模式区域
        boolean isTiming = (row == 6 && col > 6 && col < 14) || (col == 6 && row > 6 && row < 14);
        return isPosition || isTiming;
    }

    /**
     * 应用掩码（掩码0：(row + col) % 2 == 0 时反转）
     */
    private static void applyMask(boolean[][] matrix, int maskPattern) {
        if (maskPattern != MASK_PATTERN_0) return; // 仅实现掩码0
        int size = QR_VERSION_1_SIZE;
        for (int row = 0; row < size; row++) {
            for (int col = 0; col < size; col++) {
                if (isReservedModule(row, col)) continue; // 保留模块不掩码
                if ((row + col) % 2 == 0) {
                    matrix[row][col] = !matrix[row][col]; // 反转颜色
                }
            }
        }
    }

    /**
     * 绘制格式信息（纠错级别M + 掩码0）
     */
    private static void drawFormatInfo(boolean[][] matrix) {
        // 格式信息二进制：纠错级别M(01) + 掩码0(000) → 01000 → 加纠错码后为 111011111000100（15位）
        String formatBinary = "111011111000100";
        int[] formatRow = {0, 0, 0, 0, 0, 0, 0, 0, 1, 2, 3, 4, 5, 7, 8};
        int[] formatCol = {8, 7, 5, 4, 3, 2, 1, 0, 0, 0, 0, 0, 0, 0, 0};
        // 绘制上侧格式信息
        for (int i = 0; i < formatRow.length; i++) {
            matrix[formatRow[i]][formatCol[i]] = formatBinary.charAt(i) == '1';
        }
        // 绘制右侧格式信息
        int[] formatRow2 = {20, 20, 20, 20, 20, 20, 20, 19, 18, 17, 16, 15, 14, 13, 12};
        int[] formatCol2 = {8, 9, 10, 11, 12, 13, 14, 14, 14, 14, 14, 14, 14, 14, 14};
        for (int i = 0; i < formatRow2.length; i++) {
            matrix[formatRow2[i]][formatCol2[i]] = formatBinary.charAt(i) == '1';
        }
    }

    /**
     * 构造完整的二维码矩阵
     */
    private static boolean[][] buildQRMatrix(String content) {
        // 1. 数据编码
        String dataBinary = encodeData(content);

        // 2. 生成并合并纠错码
        String mergedBinary = mergeDataAndEC(dataBinary);

        // 3. 初始化空矩阵
        boolean[][] matrix = createEmptyMatrix();

        // 4. 绘制固定图案（定位+时间）
        drawPositionPatterns(matrix);
        drawTimingPatterns(matrix);

        // 5. 填充数据+纠错码
        fillDataToMatrix(matrix, mergedBinary);

        // 6. 应用掩码
        applyMask(matrix, MASK_PATTERN_0);

        // 7. 绘制格式信息
        drawFormatInfo(matrix);

        return matrix;
    }


五、步骤 4：矩阵转图像并保存
将布尔矩阵转换为可视化的图片（PNG 格式）：

    // ===================== 步骤4：矩阵转图像并保存 =====================
    /**
     * 将二维码矩阵转换为BufferedImage
     * @param matrix 二维码矩阵
     * @param moduleSize 每个模块的像素大小
     * @return 二维码图片
     */
    private static BufferedImage matrixToImage(boolean[][] matrix, int moduleSize) {
        int size = matrix.length;
        int imageSize = size * moduleSize;
        BufferedImage image = new BufferedImage(imageSize, imageSize, BufferedImage.TYPE_INT_RGB);
        Graphics2D g2d = image.createGraphics();

        // 设置背景为白色
        g2d.setColor(Color.WHITE);
        g2d.fillRect(0, 0, imageSize, imageSize);

        // 绘制二维码模块（黑色）
        g2d.setColor(Color.BLACK);
        for (int row = 0; row < size; row++) {
            for (int col = 0; col < size; col++) {
                if (matrix[row][col]) {
                    int x = col * moduleSize;
                    int y = row * moduleSize;
                    g2d.fillRect(x, y, moduleSize, moduleSize);
                }
            }
        }

        g2d.dispose();
        return image;
    }

    /**
     * 生成二维码并保存到文件
     * @param content 二维码内容
     * @param outputPath 保存路径（如：D:/raw_qrcode.png）
     * @param moduleSize 每个模块的像素大小（建议10）
     */
    public static void generateQRCode(String content, String outputPath, int moduleSize) {
        // 1. 构造二维码矩阵
        boolean[][] matrix = buildQRMatrix(content);

        // 2. 转换为图片
        BufferedImage image = matrixToImage(matrix, moduleSize);

        // 3. 保存图片
        try {
            ImageIO.write(image, "PNG", new File(outputPath));
            System.out.println("从零实现的二维码生成成功：" + outputPath);
        } catch (IOException e) {
            throw new RuntimeException("保存图片失败", e);
        }
    }

    // ===================== 测试主方法 =====================
    public static void main(String[] args) {
        // 生成Version 1二维码（内容：Hello World，保存到D盘）
        String content = "Hello World";
        String outputPath = "D:/raw_qrcode.png";
        int moduleSize = 10; // 每个模块10像素 → 图片尺寸210×210
        generateQRCode(content, outputPath, moduleSize);
    }
}



模块	作用
数据编码	将 UTF-8 文本转换为符合 Version 1 规则的二进制流（模式标识 + 长度 + 数据 + 填充）
Reed-Solomon 纠错	基于 GF (2^8) 有限域生成纠错码，保证二维码污损后可恢复
矩阵构造	绘制定位 / 时间图案→填充数据→掩码处理→绘制格式信息
图像转换	将布尔矩阵（true = 黑 /false = 白）转换为 BufferedImage 并保存为 PNG



2. 运行注意事项
数据限制：仅支持 Version 1+M，字节模式最多 16 个 UTF-8 字节（如 "Hello World"、短 URL）。
权限问题：确保输出路径（如 D:/）有写入权限，否则会抛出 IO 异常。
